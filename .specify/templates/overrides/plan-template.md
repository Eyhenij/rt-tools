## Раскладка

### Документы этой работы

```text
specs/[номер]-[короткое-имя]/
├── spec.md              # описание (/speckit-specify)
├── plan.md              # этот файл (/speckit-plan)
├── research.md          # чем закрыты открытые вопросы (/speckit-plan)
├── data-model.md        # если работа заводит модель данных (/speckit-plan)
├── contracts/           # если работа заводит внешний контракт (/speckit-plan)
└── tasks.md             # задачи (/speckit-tasks)
```

Файл, которому в этой работе нечего содержать, не заводится пустым: пустой `data-model.md`
выглядит так же, как заполненный, и читается как действующее описание.

### Исходники

Раскладку задаёт монорепозиторий, а не эта работа:

```text
projects/<пакет>/
├── src/
│   ├── lib/<область>/<штука>/
│   │   ├── <штука>.ts
│   │   ├── <штука>.spec.ts          # спека рядом с источником
│   │   └── <штука>.stories.ts       # если у штуки есть видимое состояние
│   └── public-api.ts                # опубликованная поверхность
└── README.md
```

# Надстройки над разложенными ресурсами

Сюда кладётся то, что этот репозиторий дописывает к тексту `@rt-tools/agent-kit`. Путь файла
повторяет идентификатор ресурса: `laws/verifiability.md` надстраивается файлом
`laws/verifiability.md` рядом с этим README.

Править разложенный файл на месте нельзя: правка теряется на следующем `pnpm run agent-kit:sync`,
и он на такой файл отказывает вместо того, чтобы переписать его молча.

Слияние идёт по разделам `## `:

| В надстройке | Что происходит |
| --- | --- |
| заголовок, который есть у пакета | раздел замещается целиком |
| заголовок, которого у пакета нет | раздел дописывается в конец |
| заголовок без тела | раздел пакета снимается |

От ресурса целиком отказываются не здесь, а списком `skip` в `.claude/rt-kit.json`.

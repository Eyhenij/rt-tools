## Язык записи о правке

- **Описание коммита пишется на языке дерева.** История этого репозитория русская целиком, и
  английская строка читается в ней как чужая: по ней не видно ни рода правки, ни довода — она
  выглядит служебной, даже когда говорит о деле. Судится присутствие русской буквы, а не
  отсутствие латиницы: в заголовке законно стоят область правки, номер версии, имя команды и
  служебная пометка пропуска конвейера, и запрет латиницы отбивал бы их вместе с английским
  описанием. Проверка стоит на хуке гита, то есть судит руку; запись, которую делает конвейер,
  мимо хука идёт, и язык там держат сами шаблоны выпуска — правка в одном месте промах не
  закрывает.

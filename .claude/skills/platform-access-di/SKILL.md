# Окно, документ и проверка среды

Паттерн правила `platform-access`. Что при этом должно быть верно — закон
`docs/constitution/frontend-application.md`.

## Когда брать

- В компонент, службу или директиву заходит окно, документ или проверка среды.
- Появляется работа с разметкой, которой нельзя случиться до первой отрисовки.
- Чистой функции нужен доступ к окну.

## Внедрение

```typescript
@Injectable({ providedIn: 'root' })
export class SomeService {
    readonly #document: Document = inject(DOCUMENT);
    readonly #platform: PlatformService = inject(PlatformService);
    readonly #window: Window = inject(WINDOW);
}
```

## Когда нужен тип глобальной области

Интерфейс окна не описывает глобальные конструкторы и пространства имён — наблюдателей
пересечения и размера, объекты внешних карт. Токен отдаёт тот же самый объект, поэтому тип
уточняется приведением, и рядом ставится комментарий с причиной:

```typescript
// Конструкторы наблюдателей объявлены на глобальной области, а не на интерфейсе окна —
// токен отдаёт тот же объект, тип лишь уточняется.
readonly #window: Window & typeof globalThis = inject(WINDOW) as Window & typeof globalThis;
```

## Чистая функция принимает окно параметром

В файлах чистой логики внедрения нет, и глобал внутрь не тянется:

```typescript
export function mapsReady(windowRef: Window & typeof globalThis): boolean {
    return typeof windowRef.maps?.importLibrary === 'function';
}
```

Внедряет его вызывающий компонент.

## Проверка среды и первая отрисовка

Среда спрашивается у службы платформы, а работа с разметкой уходит в крючок первой отрисовки.
Проверка «глобал определён» не годится: она верна случайно и ломается на первой же среде, где
глобал подставлен.

## Частые промахи

- **Проверка среды прямым обращением к признаку платформы** вместо службы.
- **Проверка среды вокруг чтения и записи в хранилище:** служба хранилища и так уходит в память
  вне браузера, и такое условие — мёртвый код.
- **Окно полем класса в службе, обязанной работать без разметки вовсе:** там оно берётся внутри
  метода под проверкой среды.
- **Правка добавила окно в службу, создающуюся на подъёме, а проверили одной сборкой:** падение
  видно только на поднятом сервере отдачи страниц.
- **Приведение без комментария:** в переводчиках моделей приведение запрещено, и строка
  читается как нарушение.

# Checking the running application

Rule under the law `docs/constitution/verifiability.md`. Cold part: `pitfalls.md`.

## How the law applies here

- **A running application is not raised a second time.** Who answers on the port is found first; used only if built from this edit's branch; a duplicate stops by process id.
- **The browser is driven by one driver on the pinned profile.** Not a second driver, `open`, `osascript` or the binary.
- **A browser a script raises counts as launching the binary.** The file run is judged, not the command line.
- **The browser choice goes stale; the call is repeated.**
- **A refused profile choice stops browser work.** Named to the owner; no workaround.
- **A profile is neither picked from the list nor asked of the owner.**
- **An unconfigured guard is a stop, not a permission.** Empty helper output goes to the owner.
- **A screen behind sign-in is checked on a stand, not a live account.** Through the form, seeded account; a step asked of a person means a wrong path.
- **A move into a sign-in system is checked by signing in as a moved person.** The stand holds real profile fields.
- **A container's element count change is a layout edit.** Measured: document vs viewport width, every threshold, both sides.
- **A measurement takes the longest value, not the sample.** The extreme a consumer can give.
- **The longest value is set for every node sharing the line.**
- **A kit piece reused for values of another size is measured, not looked at.**
- **The stand proxy supplies the request's tenant sign.** Found by swapping the header, not reading code.
- **The production configuration is checked only behind the real proxy.**
- **What a person is shown is built from the work's branch.** Named with it.
- **A shared frame's edit is checked on every screen under it.** Before the push.
- **The work branch keeps its base tip merged in all the time.**
- **A public screen's first visit carries the service-visit sign.**
- **A screen whose data the dev database lacks is measured with the component's real styles.**
- **A measurement to repeat is an end-to-end test, not the driver.**
- **Measure before showing the owner, not after their remark.** Reference numbers too.
- **Work carrying a sample's look is accepted by its own screen's frame beside the sample's.** Every remade screen opened; the measure set written before the edit.

A layout conclusion is backed by a number.

## This tree

- **No profile file and one connected browser: it is driven, its id written.** Two or more: named to the owner; browser work waits.
- **A showcase check is done live before the owner looks.**

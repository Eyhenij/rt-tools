# Стили компонента

Паттерн правила `styling-bem`. Что при этом должно быть верно — закон
`docs/constitution/frontend-application.md`.

## Когда брать

- Правится компонент источника вида.
- Правится оформление отдельного компонента.
- Нужно перебить умолчание источника вида в своём компоненте.

## Хост — сам блок

Хост несёт класс блока, раскладка на хосте, элементы вложены внутрь:

```scss
:host {
    display: inline-flex;

    .<блок > {
        display: inline-flex;
        gap: var(--<токен отступа>);
        align-items: center;

        &--<модификатор > {
            border-radius: var(--<токен скругления>);
        }
    }
}
```

Модификатор — вложенным селектором или привязкой класса на хосте. У экрана вне источника вида
такого раздела нет: раскладка на хосте — это общий слой приложения, а не файл экрана.

## Значения — только токенами

```scss
✗ color: #fff;
✗ box-shadow: 0 1px 2px rgb(0 0 0 / 12%);
✓ color: var(--<токен цвета поверхности>);
✓ box-shadow: var(--<токен тени>);
```

Составное значение берётся готовым токеном целиком, а не собирается из частей. Переменные
препроцессора для значений оформления не используются вовсе: они разрешаются на сборке и темой
не переключаются.

## Перебить умолчание источника вида

Стили компонента без инкапсуляции весят столько же, сколько умолчания источника вида: у обоих
селекторов по одному классу, и исход решает порядок подключения. Переопределение пишется
потомком блока — так вес растёт на единицу, и порядок перестаёт что-либо решать:

```scss
& &__item {
    color: var(--<токен приглушённого текста>);
}
```

## Частые промахи

- **Комментарий-выключатель линтера стилей:** селекторы объединяются вложенностью, а не
  отключением правила.
- **Приоритетное объявление:** запрещено, и оформление, заданное на месте, перебить им всё
  равно не выйдет.
- **Новые объявления при переносе стилей:** переносится существующее, новое появляется, только
  когда задача — фича.
- **Замечание линтера, лежавшее в файле раньше, оставлено:** правятся все, и новые, и старые.
- **Своё наследование гарнитуры в компоненте:** оно включено глобально, и местное объявление
  только расходится с ним.

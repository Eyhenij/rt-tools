# Виджет чата

Один файл, который страница потребителя подключает скриптом. Скрипт объявляет тег `rt-chat-widget`;
где виджету стоять, решает страница:

```html
<script src="https://bus.example/widget.js"></script>
<rt-chat-widget site="ключ-площадки"></rt-chat-widget>
```

Ключ площадки открыт и лежит в коде страницы: прав, кроме приёма реплики с адресов из списка
площадки, он не даёт. Адрес сервиса виджет берёт оттуда, откуда приехал сам скрипт; площадка,
которая держит сервис на своём поддомене, называет его признаком `service`.

Виджет рисует себя в теневом дереве: стили страницы до него не достают, а его — до страницы.
Кит дерева он с собой не везёт — в чужую страницу приехал бы каркас целиком.

- Что он показывает и чем закрыт — `docs/specs/chat/widget/spec.md`.
- Операции, к которым он обращается, — `docs/specs/chat/spec.md` и подобласти рядом.
- Сборка: `pnpm exec nx build chat-widget`, выход — `dist/apps/chat-widget/widget.js`.

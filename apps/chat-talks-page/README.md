# Страница переписок для админки потребителя

Отдельное приложение: его показывает рамка, которую скрипт сервиса ставит в админку потребителя.
Рисуется частями набора `@rt-tools/ui-kit-v2` — тем же списком и той же лентой, что и панель
оператора.

```html
<iframe src="https://bus.example/talks/?site=ключ-площадки"></iframe>
```

Ключ площадки едет адресом рамки: он и так лежит в коде страницы потребителя открыто. Подпись
потребителя едет сообщением — она тайна на пять минут, а адрес виден и в журналах, и в истории
браузера. Скрипт установки и образец сервера потребителя пишет задача RT-2314.

- Что страница показывает и чем закрыта — `docs/specs/chat/embedded-talks/spec.md`.
- Операции, к которым она обращается, — там же, раздел «Contract».
- Сборка: `pnpm exec nx build chat-talks-page`, выход — `dist/apps/chat-talks-page`.
- Своя машина: `pnpm exec nx serve chat-talks-page` — обращения к `/api` уходят на приёмник.

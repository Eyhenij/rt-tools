# message-bus-api-access-util

Объявление доступа: чем закрыта операция — ничем, токеном дерева или входом человека, — и метки,
которыми это объявляется.

Живёт отдельным доменом, потому что читают его обе стороны: и проверка токена дерева, и проверка
входа человека. Положенное к одной из них, оно сделало бы вторую её потребителем — и домен
деревьев знал бы про людей, которых не заводит.

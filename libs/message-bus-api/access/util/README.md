# message-bus-api-access-util

Объявление доступа: чем закрыта операция — ничем, токеном дерева, входом человека или правом
вошедшего, — и метки, которыми это объявляется.

Само имя права здесь не объявляется: набор лежит в общей либе, потому что его называет и админка
— пунктом меню и адресом раздела.

Живёт отдельным доменом, потому что читают его обе стороны: и проверка токена дерева, и проверка
входа человека. Положенное к одной из них, оно сделало бы вторую её потребителем — и домен
деревьев знал бы про людей, которых не заводит.

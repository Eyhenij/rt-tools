# message-bus-api-access-feature

Единственная проверка доступа приёмника. Стоит на всём приложении и закрыта по умолчанию:
операция, не объявившая, чем она закрыта, не отвечает никому.

Способов представиться два, и проверка одна на оба намеренно: две глобальные проверки подряд
означали бы, что запрос с токеном дерева доходит до чтения груза, если вторая забыла отказать.

Отказ не называет, что именно не сошлось: ненайденный токен, отозванный, просроченный вход и
отключённая запись отвечают одинаково.

# message-bus-api-accounts-feature

Операции входа — заведение, обрыв и ответ о том, кто вошёл, — чтение и правка людей из
админки, и команды учётных записей: заведение, смена пароля, отключение, список.

Вход открыт всем: закрытый входом, он требовал бы того, что им и заводится. Выход и ответ о
вошедшем закрыты входом. Объявляют это метки домена объявления доступа, а исполняет единственная
проверка приёмника.

Правки людей из админки закрыты правом `accounts:manage`: заведение по имени и первому паролю,
новый пароль, отключение с обрывом живых входов. Те же правки умеют команды строки запуска — до
задачи, которая их снимет; пароль команда не берёт доводом, его спрашивает точка входа.

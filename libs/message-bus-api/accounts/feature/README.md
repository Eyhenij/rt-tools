# message-bus-api-accounts-feature

Операции входа — заведение, обрыв и ответ о том, кто вошёл, — и команды учётных записей:
заведение, смена пароля, отключение, список.

Вход открыт всем: закрытый входом, он требовал бы того, что им и заводится. Выход и ответ о
вошедшем закрыты входом. Объявляют это метки домена объявления доступа, а исполняет единственная
проверка приёмника.

Записи заводятся только командами: заведение из веба — это ещё экран, право на него и вопрос,
кем заводится первая запись. Пароль команда не берёт доводом — строка запуска остаётся в истории
оболочки и в списке процессов машины; его спрашивает точка входа и передаёт службе.

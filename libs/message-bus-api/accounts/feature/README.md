# message-bus-api-accounts-feature

Операции входа — заведение, обрыв и ответ о том, кто вошёл, — чтение и правка людей из
админки, роли и доступ человека, и первая запись узла: ответ, ждёт ли её узел, и её заведение с
ролью владельца и входом тем же запросом.

Вход открыт всем: закрытый входом, он требовал бы того, что им и заводится. Выход и ответ о
вошедшем закрыты входом. Объявляют это метки домена объявления доступа, а исполняет единственная
проверка приёмника.

Правки людей из админки закрыты правом `accounts:manage`: заведение по имени и первому паролю,
новый пароль, отключение с обрывом живых входов. Команд учётных записей у строки запуска нет:
первая запись заводится экраном первичной настройки, остальные — из раздела людей.

Первая запись открыта без входа, пока в хранилище нет ни одной записи, и отвечает отказом
навсегда, как только запись есть. Выдачу входа обе операции — вход по паре и первая запись —
берут из одного места: две выдачи разошлись бы молча.

# message-bus-api-accounts-data-access

Всё, что домен учётных записей читает из хранилища и пишет в него: запись по приведённому имени,
её заведение, смена пароля, отключение вместе с обрывом живых входов, список записей, заведение
и обрыв входа, вход по хешу куки.

Зовут их команды строки запуска, операции входа, правки людей из админки и проверка входа из слоя
`feature`.

Отключение записи и обрыв её входов идут одной транзакцией: порознь это два состояния, между
которыми отключённая запись читает груз.

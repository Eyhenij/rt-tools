# message-bus-api-accounts-data-access

Всё, что домен учётных записей читает из хранилища и пишет в него: запись по приведённому имени,
её заведение, первая запись под замком таблицы, смена пароля, отключение вместе с обрывом живых
входов, заведение и обрыв входа, вход по хешу куки, роли и доступ человека.

Зовут их операции входа, первая запись, правки людей и ролей из админки и проверка входа из слоя
`feature`.

Отключение записи и обрыв её входов идут одной транзакцией: порознь это два состояния, между
которыми отключённая запись читает груз.

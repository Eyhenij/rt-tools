# message-bus-api-accounts-util

Имя учётной записи, хеш пароля, значение входа и его срок, разбор команд учётных записей и
строки, которые эти команды печатают, — чистые функции без хранилища и каркаса.

Зовут их проверка входа в слое `feature`, операции входа и все операции чтения груза: вошедшего
читают они все, а вторая копия этого чтения разошлась бы с первой в коде отказа.

Пароль сюда приходит доводом и не уходит никуда, кроме собственного хеша: ни в строку запуска,
ни в журнал, ни в хранилище он не попадает. Заглушка хеша живёт здесь же — ею сверяется пароль,
когда записи с таким именем нет вовсе, и без неё время ответа перебирало бы имена.

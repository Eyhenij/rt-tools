# message-bus-api-observability-feature

Журнал приёмника: одна строка на запись, машинная на проде и читаемая вне его.

Ставится приложением в `useLogger()`, поэтому уже написанные вызовы каркаса и доменов начинают
писать так же, ничего в них не правя. Поля вычищаются до вывода — решать на каждом вызове, есть
ли в них секрет, значит однажды ошибиться.

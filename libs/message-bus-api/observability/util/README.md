# message-bus-api-observability-util

Разбор ошибки в поля и вычистка полей строки журнала — чистые функции без хранилища и каркаса.

Разбор раскладывает ошибку на класс, текст, код клиента хранилища, его подробности, ответ
драйвера и срезанный стек, разворачивая цепочку причин: настоящий ответ базы лежит вложенной
причиной, а первый уровень называет обёртку.

Вычистка идёт по имени ключа, а не по виду значения, и зовётся всегда: решать на каждом вызове,
есть ли в полях секрет, — значит однажды ошибиться. Внутри разобранной причины поле текста
ошибки остаётся целиком — ради него всё и заведено.

Зовут их разбор отказов приёмника и логгер приложения. Здесь же живёт признак отказа хранилища:
по нему выбирается код ответа — «повтори» вместо «внутренняя ошибка».

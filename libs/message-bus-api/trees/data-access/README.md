# message-bus-api-trees-data-access

Запросы к деревьям и их токенам: дерево годного токена по хешу, дерево по имени, заведение с
первым токеном, замена токена, отзыв и список деревьев.

Чтение по хешу зовёт проверка токена в слое `feature`, остальное — команды деревьев оттуда же.
Отозванный токен из выборки по хешу выпадает, но в хранилище остаётся — груз, приехавший по
нему, читается по-прежнему, и в списке такое дерево названо вместе с днём последнего прогона.

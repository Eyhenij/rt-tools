# message-bus-api-trees-feature

Проверка токена дерева и метка открытой операции.

Проверка закрыта по умолчанию и ставится на всё приложение сразу: операция закрыта с того
мгновения, как объявлена, а открывает её метка `@Public()`. Модуль подключает приложение —
цепочка проверок его решение, а не решение домена.

# message-bus-api-trees-feature

Проверка токена дерева, метка открытой операции и команды деревьев.

Проверка закрыта по умолчанию и ставится на всё приложение сразу: операция закрыта с того
мгновения, как объявлена, а открывает её метка `@Public()`. Модуль подключает приложение —
цепочка проверок его решение, а не решение домена.

Команды — заведение дерева, выдача нового токена, отзыв и список — живут в своём модуле:
операциями запроса они не делаются вовсе, и токен дерева ни одной из них не открывает.
Печатает их вывод вызывающий, а служба отвечает строками: так решение проверяется вызовом, а
напечатанный один раз токен не уходит в логи.

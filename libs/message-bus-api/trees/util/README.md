# message-bus-api-trees-util

Хеш токена дерева, его выпуск, дерево запроса и разбор команд деревьев — чистые функции без
хранилища и каркаса.

Зовут их проверка токена в слое `feature` и все три операции приёма: дерево, опознанное по
токену, читают они все, а вторая копия этого чтения разошлась бы с первой в коде отказа.

Здесь же — то, что команды деревьев разбирают и печатают: доводы строки запуска, перечень
команд, строки списка и токен, напечатанный один раз. Печать — это решение, и проверяется оно
вызовом; сам токен остаётся доводом функции и в хранилище не попадает.

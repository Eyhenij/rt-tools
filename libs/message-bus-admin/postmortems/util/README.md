# message-bus-admin-postmortems-util

Модели разбора происшествия и перевод ответа приёмника в них.

Строка списка и запись целиком, столбцы таблицы и поля порядка. Времена приезжают строками и
здесь же становятся тем, что показывает экран.

Зовут её остальные слои раздела; сама она зовёт словарь и выборку общего слоя.

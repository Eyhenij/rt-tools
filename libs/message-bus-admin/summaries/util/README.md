# message-bus-admin-summaries-util

Модели записи месяца и перевод ответа приёмника в них.

Строка списка и запись целиком, столбцы таблицы и поля порядка. Время приезжает строкой и
здесь же становится тем, что показывает экран; сводка приезжает телом и здесь же становится
текстом.

Зовут её остальные слои раздела; сама она зовёт словарь и выборку общего слоя.

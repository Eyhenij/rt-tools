# message-bus-admin-summaries-ui

Вид одной записи месяца: поля записи и сводка последнего прогона.

Сводка показывается текстом, а не размеченным содержимым: приёмник содержимого груза не
разбирает, и дерево с токеном иначе получало бы исполнение своего тела в браузере вошедшего.
Месяц без сводки объясняет себя словами.

Зовёт её панель подробностей.

# message-bus-admin-common-core-ui

Общий вид списочного экрана: то, что у трёх разделов одинаково.

Заголовок, тулбар с отбором, место под таблицу раздела и переключатель страниц. Своей разметки
списка у разделов нет — переписанная заново, она расходится молча.

Зовут её `feature` общего слоя и экраны разделов; сама она зовёт `util` общего слоя.

# message-bus-admin-common-core-api

Обращение к операциям чтения груза: один вид запроса на три раздела.

- `admin-read.api.ts` — страница списка и одна запись целиком: предел ожидания, куки входа и
  разбор отказа в род, понятный экрану.
- `trees.api.service.ts` — деревья для отбора: имена, которыми человек их узнаёт.

Разделы отличаются адресом и формой строки, а не способом спросить, — поэтому спрашивает за
всех эта либа. Зовёт её `data-access` общего слоя; сама она зовёт `util` того же слоя и форму
контракта.

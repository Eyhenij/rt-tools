# message-bus-admin-common-core-data-access

Состояние списков груза.

- `admin-list-store.base.ts` — общая основа списочного стора: страница, её чтение, отказ и
  повтор. Наследнику остаётся назвать адрес операции.
- `trees.store.ts` — деревья для отбора, один экземпляр на приложение.

Зовут её три домена груза; сама она зовёт `api` и `util` общего слоя.

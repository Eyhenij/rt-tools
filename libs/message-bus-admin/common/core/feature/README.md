# message-bus-admin-common-core-feature

Общая основа списочного экрана: связь адреса, состояния и таблицы.

Выборка читается из адреса и пишется в адрес, страница читается стором, а отбор и порядок
приходят от вида. Раздел объявляет столбцы, поля сортировки и адрес операции — остальное здесь.

Зовут её экраны трёх разделов груза; сама она зовёт `ui`, `data-access`, `api` и `util` общего
слоя.

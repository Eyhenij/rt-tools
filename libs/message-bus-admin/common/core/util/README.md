# message-bus-admin-common-core-util

Словарь админки, выборка списка и род отказа чтения — то, что знают все три раздела груза и
что не принадлежит ни одному из них.

- `admin-labels.ts` — подписи экранов и подписи, которые рисует кит. Язык один, русский;
  неназванный ключ кит берёт своим английским умолчанием.
- `list-query.ts` — выборка в адресе раздела: разбор, сборка и сравнение. Чистые функции.
- `read-fault.ts` — чем кончилось чтение, если не грузом, и номер обращения из ответа.

Зовут её слои `api`, `data-access`, `ui` и `feature` этого же общего слоя и все три домена
груза. Сама она не зовёт ничего, кроме формы контракта `@rt/message-bus-common`.

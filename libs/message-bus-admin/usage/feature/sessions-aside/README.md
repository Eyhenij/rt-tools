# message-bus-admin-usage-feature-sessions-aside

Панель сессий одного скила: день, признак сессии и сколько раз, открытая нажатием на строку.

Живёт маршрутом в аутлете `ro` и наследует общую основу панели из кита: закрытие, гашение и
возврат к списку держит она. Дерево и период берёт из того же адреса, каким читана таблица.

Зовут её маршруты раздела.

# message-bus-admin-usage-util

Модели использования правил и перевод ответа приёмника в них.

Строка таблицы скилов и сессия одного скила, столбцы таблицы, адрес операций и подписи родов.
Род приезжает словом закрытого набора и здесь же становится значением набора.

Зовут её остальные слои раздела; сама она зовёт словарь общего слоя и форму контракта.

# message-bus-admin-usage-api

Обращение к операции чтения сессий одного скила за период.

Своего способа спросить у неё нет — предел ожидания, куку и разбор отказа держит общий слой.
Страницу таблицы скилов просит общая основа стора сама; здесь только сессии и перевод ответа в
модели раздела.

Зовёт её слой состояния раздела.

# message-bus-admin-proposals-util

Модели предложения по слою правил и перевод ответа приёмника в них.

Строка списка и запись целиком, столбцы таблицы и поля порядка. Время приезжает строкой и
здесь же становится тем, что показывает экран.

Зовут её остальные слои раздела; сама она зовёт словарь и выборку общего слоя.

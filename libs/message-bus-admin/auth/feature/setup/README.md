# message-bus-admin-auth-feature-setup

Экран первой записи: форма имени и пароля на готовом блоке входа кита. Открыт, пока в приёмнике
нет ни одной записи; с первой закрыт навсегда и уводит на вход. Заведение и вход — один запрос,
после него человек попадает на первый раздел.

Проверки: `nx test message-bus-admin-auth-feature-setup`.

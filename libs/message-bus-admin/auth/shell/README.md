# message-bus-admin-auth-shell

Отбивка без входа: маршрут экрана входа, гвард закрытой ветки и перехватчик кончившегося входа.

Гвард отвечает на переход, перехватчик — на обращение: вход обрывается посреди работы, когда
человек никуда не переходит, и первым об этом узнаёт запрос, а не роутер. Оба уводят на один и
тот же адрес и запоминают, куда человек шёл.

Зовут её маршруты приложения и его настройка обращений.

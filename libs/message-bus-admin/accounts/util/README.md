# message-bus-admin-accounts-util

Модель человека приёмника на стороне экрана, перевод ответа приёмника в неё, столбцы таблицы и
адрес операции чтения.

Здесь же решения раздела чистыми функциями: подписи роли, состояния записи и пустого последнего
входа. Сторона контракта своей копии не заводит — форма строки объявлена один раз, в общей либе
обеих сторон.

Зовут её остальные слои раздела; сама она зовёт словарь общего слоя и кит.

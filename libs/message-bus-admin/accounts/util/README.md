# message-bus-admin-accounts-util

Модели человека, роли и доступа человека на стороне экрана, переводы ответов приёмника в них,
столбцы двух таблиц, адреса операций и панелей.

Здесь же решения разделов чистыми функциями: подписи роли, состояния записи и пустого последнего
входа; подписи прав по разделам, признак удаления роли, слово на право и исход из роли и слов. Сторона контракта своей копии не заводит — форма строки объявлена один раз, в общей либе
обеих сторон.

Зовут её остальные слои раздела; сама она зовёт словарь общего слоя и кит.

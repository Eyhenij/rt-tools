# message-bus-admin-accounts-data-access

Стор списка людей: наследник общей основы списочного стора. Своего у него два — адрес операции и
перевод строки; страницу, порядок, гонку ответов и отказ чтения с повтором держит основа.

Правок над записями здесь нет ни одной: заводит, отключает и меняет пароль команда строки запуска
на узле приёмника — из веба такого действия нет вовсе.

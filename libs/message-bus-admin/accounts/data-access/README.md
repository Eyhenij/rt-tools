# message-bus-admin-accounts-data-access

Сторы списков людей и ролей: наследники общей основы списочного стора. Своего у каждого адрес
операции, перевод строки и правки; страницу, порядок, гонку ответов и отказ чтения с повтором
держит основа.

У людей правок четыре — заведение, новый пароль, отключение и замена доступа; у ролей три —
заведение, правка и удаление, и рядом чтение одной роли и всех ролей разом для панели прав.
Правки, которые зовут панели, отвечают потоком; отключение и удаление зовёт меню строки, и об их
исходе говорит общая шина оповещений. Всякая удавшаяся правка перечитывает список целиком.

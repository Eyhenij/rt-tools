# message-bus-admin-accounts-data-access

Стор списка людей: наследник общей основы списочного стора. Своего у него адрес операции, перевод
строки и три правки — заведение, новый пароль и отключение; страницу, порядок, гонку ответов и
отказ чтения с повтором держит основа.

Заведение и новый пароль отвечают потоком — их зовут панели; отключение зовёт меню строки, и о его
исходе говорит общая шина оповещений. Всякая удавшаяся правка перечитывает список целиком.

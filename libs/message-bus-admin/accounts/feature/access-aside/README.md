# message-bus-admin-accounts-feature-access-aside

Панель прав пользователя, названного адресом «people/<имя>/access»: роль и одно из трёх слов на
каждое право набора — «по роли», «дано», «отнято» — с исходом рядом: есть право или нет.

Исход считается тем же сложением, что у приёмника, из общей либы, и меняется с каждым выбором до
сохранения: право, о котором роль молчит, читается словом «нет» на самой панели. Сохранение
заменяет доступ целиком; после удачи панель закрывается, и строка списка людей несёт новую роль.

Читает доступ записи и все роли одним чтением — выбирать роль иначе не из чего. Наследует общую
основу панели из кита. Зовут её маршруты раздела людей.

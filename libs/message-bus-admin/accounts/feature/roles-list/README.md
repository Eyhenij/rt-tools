# message-bus-admin-accounts-feature-roles-list

Экран раздела ролей: имя роли, её права словами и сколько пользователей её держат.

Своего у экрана трое — стор ролей, его столбцы и его поле порядка. Выборку из адреса, чтение,
порядок и повтор держит основа списочного экрана, а заголовок, тулбар, переключатель страниц и
отказ с повтором — общий вид страницы.

Отбора у раздела нет, и левый слот тулбара пуст. В правом стоит кнопка заведения, а меню строки
даёт правку и удаление с вопросом; удаление есть только у роли, которую никто не держит. Весь
раздел закрыт правом на роли, и до ответа о вошедшем не прячется ничего. Строка не нажимается —
панель роли открывает пункт меню.

# message-bus-admin-accounts-feature-role-aside

Панель роли: название и по чекбоксу на каждое право набора, сгруппированные по разделам.

Живёт двумя маршрутами в аутлете `ro`: «roles/new» заводит роль, «roles/<ключ>» правит
существующую — роль читается по ключу из адреса, а не берётся из списка. Наследует общую основу
панели из кита: занятость записи, отказ, закрытие и вопрос о несохранённых правках держит она.
После удачи панель закрывается.

Зовут её маршруты раздела.

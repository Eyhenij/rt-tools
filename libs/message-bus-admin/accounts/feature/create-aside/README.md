# message-bus-admin-accounts-feature-create-aside

Панель заведения пользователя: имя и первый пароль. Пароль называет заводящий и передаёт человеку
сам — приёмник его не показывает и не рассылает.

Живёт маршрутом в аутлете `ro` и наследует общую основу панели из кита: занятость записи, отказ,
закрытие и возврат к списку держит она. После удачи панель закрывается, список несёт новую строку.

Зовут её маршруты раздела.

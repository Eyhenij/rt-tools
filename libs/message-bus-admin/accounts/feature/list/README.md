# message-bus-admin-accounts-feature-list

Экран раздела людей: имя, роль, состояние записи и время последнего входа.

Своего у экрана трое — стор раздела, его столбцы и его поля порядка. Выборку из адреса, чтение,
порядок и повтор держит основа списочного экрана, а заголовок, тулбар, переключатель страниц и
отказ с повтором — общий вид страницы.

Отбора у раздела нет, и оба слота тулбара пусты: сузить список людей нечем. Ни строка, ни меню
строки не нажимаются — панели подробностей у человека нет, а правки записей делает команда строки
запуска.

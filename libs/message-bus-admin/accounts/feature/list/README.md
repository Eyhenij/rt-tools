# message-bus-admin-accounts-feature-list

Экран раздела людей: имя, роль, состояние записи и время последнего входа.

Своего у экрана трое — стор раздела, его столбцы и его поля порядка. Выборку из адреса, чтение,
порядок и повтор держит основа списочного экрана, а заголовок, тулбар, переключатель страниц и
отказ с повтором — общий вид страницы.

Отбора у раздела нет, и левый слот тулбара пуст: сузить список людей нечем. В правом стоит кнопка
заведения, а меню строки даёт права, новый пароль и отключение с вопросом. Кнопку и правки записи
экран рисует только с правом на правку людей, права записи — с правом на роли; своя строка
отключения не получает. Строка не нажимается —
панели подробностей у человека нет.

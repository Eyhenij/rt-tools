# message-bus-admin-accounts-feature-password-aside

Панель нового пароля: одно поле для пользователя, названного адресом `people/<имя>/password`.
Прежние входы пользователя не обрываются — пароль сменил тот, кто заведует записями.

Живёт маршрутом в аутлете `ro` и наследует общую основу панели из кита: занятость записи, отказ,
закрытие и возврат к списку держит она. После удачи панель закрывается.

Зовут её маршруты раздела.

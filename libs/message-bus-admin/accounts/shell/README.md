# message-bus-admin-accounts-shell

Адрес раздела людей и его маршруты. Маршрутов три — список, панель заведения по адресу
«people/new» и панель нового пароля по адресу «people/<имя>/password»; обе панели живут в
аутлете `ro`. Панели подробностей у человека нет: всё известное о нём стоит в строке.

Экран приезжает отложенной загрузкой; настройку столбцов раздел получает объявлением рядом с
маршрутами приложения, как и соседи.

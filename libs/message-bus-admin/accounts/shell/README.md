# message-bus-admin-accounts-shell

Адреса разделов людей и ролей и их маршруты. У людей маршрутов четыре — список, панель заведения
по адресу «people/new», панель нового пароля по адресу «people/<имя>/password» и панель прав по
адресу «people/<имя>/access». У ролей три — список, панель заведения по адресу «roles/new» и
панель роли по адресу «roles/<ключ>». Все панели живут в аутлете `ro`. Панели подробностей нет ни
у человека, ни у роли: всё известное стоит в строке, панели правят.

Экран приезжает отложенной загрузкой; настройку столбцов раздел получает объявлением рядом с
маршрутами приложения, как и соседи.

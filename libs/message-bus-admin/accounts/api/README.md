# message-bus-admin-accounts-api

Обращение к правкам над людьми: заведение записи, новый пароль и отключение. Список читает общая
основа стора по адресу, который называет слой моделей; здесь только три правки.

Каждая отвечает строкой списка после правки, а отказ несёт слово приёмника — панель показывает его
как есть. Зовёт службу стор раздела.

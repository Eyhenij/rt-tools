# message-bus-admin-accounts-api

Обращение к правкам над людьми — заведение записи, новый пароль, отключение, чтение и замена
доступа — и к ролям: одна роль, все роли разом, заведение, правка и удаление. Списки читает общая
основа стора по адресу, который называет слой моделей.

Каждая правка отвечает записью после правки, а отказ несёт слово приёмника — панель показывает его
как есть. Зовут службы сторы раздела.

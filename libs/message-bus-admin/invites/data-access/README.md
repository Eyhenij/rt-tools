# message-bus-admin-invites-data-access

Состояние раздела приглашений: список страницами и отзыв одного приглашения.

Список наследует общую основу списочного стора — своими остаются адрес операции и перевод
строки. Отзыв живёт здесь же: он единственная правка, которую админка делает над записями
приёмника, и об исходе говорит общая шина оповещений.

Зовёт её экран раздела; сама она зовёт слой обращения и слой моделей раздела.

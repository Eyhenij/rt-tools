# message-bus-admin-invites-feature-list

Экран списка приглашений.

Собран общей основой списочного экрана и общим видом страницы: свои у него столбцы, поля
порядка, ключ хранения столбцов, стор раздела и меню строки с отзывом. Отбора по дереву у
раздела нет, панели подробностей — тоже: всё, что о приглашении известно, стоит в строке.

Зовут его маршруты раздела.

# message-bus-admin-invites-feature-create-aside

Панель создания приглашения: владелец называет имя будущего дерева, приёмник выдаёт код.

Живёт маршрутом в аутлете `ro` и наследует общую основу панели из кита: занятость записи,
закрытие и возврат к списку держит она. Код показывается один раз, в самой панели, — второго
места, где его взять, нет ни в списке, ни в хранилище.

Зовут её маршруты раздела.

# message-bus-admin-invites-util

Модель приглашения на стороне экрана, перевод ответа приёмника в неё, столбцы таблицы и поля
порядка.

Здесь же решения раздела чистыми функциями: подпись состояния по-русски и то, у какого
приглашения отзыв доступен. Сторона контракта своей копии не заводит — форма строки объявлена
один раз, в общей либе обеих сторон.

Зовут её остальные слои раздела; сама она зовёт словарь общего слоя и кит.

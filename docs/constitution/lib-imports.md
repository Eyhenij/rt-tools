# Импорты между либами

Кто кого видит. Приложение нарезано на либы, и у каждой объявлен список тех, от кого ей
разрешено зависеть: так домен, которому незачем знать про чужой транспорт или чужие экраны,
и не получает к ним доступа. Список этот работает, только пока символ приходит оттуда, где
объявлен.

Закон отвечает на вопрос, откуда берётся импорт. Раскладка самих либ и слоёв — не его
предмет.

## Статьи

- **Либа отдаёт наружу только то, что объявила сама.** Чужой символ через неё не проходит:
  потребитель импортирует его у той либы, где символ объявлен.
- **Право видеть либу даётся списком её тега, а не соседом.** Не хватает права — оно
  дописывается строкой с объяснением, зачем оно понадобилось.
- **У либы, общей всем трём приложениям, список зависимостей пуст.** Её видит и бэкенд, и
  любая её зависимость стала бы общей для всех сразу.

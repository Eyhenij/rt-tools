# Привязка — показ текста груза разметкой

Кода на день записи нет: договорённость написана раньше него. Привязки проставляются последним
коммитом заявки, при вливании в спек админки, — тогда символы уже объявлены.

| Правило                                                            | Где исполняется                                               |
| ------------------------------------------------------------------ | ------------------------------------------------------------- |
| Текст груза показывается разметкой, а не сырым текстом.            | Не исполняется: показ разметкой заводится этой работой        |
| Разбирается только разметка `.md`, и перечень её закрыт.           | Не исполняется: разборщик заводится этой работой              |
| Сырой HTML не вычищается, а не разбирается вовсе.                  | Не исполняется: разборщик заводится этой работой              |
| Размеченное содержимое строится узлами, а не вклеивается строкой.  | Не исполняется: шаблон компонента заводится этой работой      |
| Перечень разметки зашит в компоненте и входом не задаётся.         | Не исполняется: компонент кита заводится этой работой         |
| Картинки и вставки в вывод не попадают.                            | Не исполняется: разборщик заводится этой работой              |
| Ссылка ведёт наружу и ничего не исполняет.                         | Не исполняется: разбор ссылки заводится этой работой          |
| Блок кода показывается моноширинным и без раскраски по языкам.     | Не исполняется: оформление компонента заводится этой работой  |
| Длинная строка внутри блока кода не растягивает панель.            | Не исполняется: оформление компонента заводится этой работой  |
| Одиночный перенос строки остаётся переносом.                       | Не исполняется: разборщик заводится этой работой              |
| Разбор — чистая функция, и решение живёт в ней, а не в компоненте. | Не исполняется: разборщик заводится этой работой              |
| Компонент показа один на все три раздела груза.                    | Не исполняется: вид каждого раздела правится этой работой     |
| Текста нет — нет и блока.                                          | Частично: условие раздела панели уже стоит и правится работой |
| Строка списка текста по-прежнему не несёт.                         | Исполняется столбцами списка: текста среди них нет и сегодня  |

# Списки одним языком разметки — где исполняются правила

Первая колонка — правило дословно, как оно написано в разделе «Правила» договорённости. Правило
без строки и строка без правила — расхождение.

Привязки ставятся по ходу работы: код на день заведения договорённости ещё не написан, и пустая
привязка здесь законна ровно до последнего коммита PR, которым договорённость въезжает в спек
поддомена.

| Правило                                                                    | Где исполняется                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Таблицу раздел объявляет элементом кита, а не атрибутом на своей разметке. | `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts:hostRole` — форма своего тега получает роль таблицы от кита: у native `<table>` она от самого тега, а у элемента её нет, и роли строк от CDK висели бы вне таблицы |
| Признаки проверки на странице раздела собраны из его префикса.             | `libs/message-bus-admin/common/core/feature/src/lib/admin-list-screen.base.ts:qaTable` — префикс раздел называет одним полем, а якоря таблицы и строки собирает основа                                                                |
| Пустой список показывает пустое состояние, а не фразу внутри таблицы.      | `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts:isEmpty` — вид пустоты кит рисует сам, и только когда чтение кончилось: идущее показывает скелетоны, отказ — тост страницы                                         |
| Пустое состояние называет, откуда записи приходят.                         | `libs/message-bus-admin/common/core/feature/src/lib/admin-list-screen.base.ts:emptyDescription` — вторая строка вида; у приглашений её перебивает свой раздел, потому что их приносит команда владельца                               |
| Свой отбор раздел кладёт в слот тулбара общей страницы.                    |                                                                                                                                                                                                                                       |
| Раздел без своего отбора слота не занимает.                                |                                                                                                                                                                                                                                       |

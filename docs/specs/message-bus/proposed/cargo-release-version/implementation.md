# Привязка — версия выпуска на записи груза

Кода на день записи нет: договорённость написана раньше него. Привязки проставляются последним
коммитом заявки, при вливании в поддомен правки состояния, в спек админки и в спек наблюдений
пакета, — тогда символы уже объявлены.

| Правило                                                                           | Где исполняется                                             |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Версия выпуска приезжает полем строки правки состояния, а не своей операцией.     | Не исполняется: пятое поле строки заводится этой работой    |
| Переход в «выпущено» без версии выпуска отбивается построчно.                     | Не исполняется: пятая причина отбоя заводится этой работой  |
| Версия выпуска принимается только со строкой, переводящей в «выпущено».           | Не исполняется: решение о годности версии заводится работой |
| Строка с версией ложится и тогда, когда состояние ею не меняется.                 | Не исполняется: отбор пишущих строк правится этой работой   |
| Пустая версия версией не считается.                                               | Не исполняется: разбор строки правится этой работой         |
| Формы версии приёмник не разбирает.                                               | Не исполняется: разбор строки правится этой работой         |
| У версии выпуска свой предел длины, и он короткий.                                | Не исполняется: предел заводится этой работой               |
| Версия выпуска заводится обоим родам записей груза.                               | Не исполняется: колонка обеих таблиц заводится этой работой |
| Отбитая строка не пишет ни состояния, ни версии.                                  | Не исполняется: запись состояния правится этой работой      |
| Второй приезд версии затирает прежнюю.                                            | Не исполняется: запись состояния правится этой работой      |
| Строка, несущая разом текст починки и версию выпуска, отбивается.                 | Не исполняется: решение о годности версии заводится работой |
| Версия выпуска видна в панели подробностей и не видна в списке.                   | Не исполняется: строка панели заводится этой работой        |
| У записи без версии выпуска строки в панели нет вовсе.                            | Не исполняется: строка панели заводится этой работой        |
| Команда строки запуска несёт версию доводом.                                      | Не исполняется: довод команды заводится этой работой        |
| Отбой по недостающей версии ложится строкой журнала наравне с прежними причинами. | Не исполняется: причина отбоя заводится этой работой        |

Где это ляжет:

| Что                                    | Где                                                                                                                                                              |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Колонка у обоих родов записей          | `prisma/schema.prisma`, миграция рядом с прежними в `prisma/migrations/`                                                                                         |
| Разбор строки правки и предел длины    | `libs/message-bus-api/cargo-state/util/src/lib/cargo-state-body.ts`                                                                                              |
| Причины отбоя в ответе                 | `libs/message-bus-api/cargo-state/api/src/lib/cargo-state.response.ts`                                                                                           |
| Решение о годности версии при переходе | `libs/message-bus-common/src/lib/`                                                                                                                               |
| Просьба о переходе, несущая версию     | `libs/message-bus-common/src/lib/cargo-state-move.ts`                                                                                                            |
| Запись версии вместе с состоянием      | `libs/message-bus-api/postmortems/data-access/src/lib/postmortem.queries.ts`, `libs/message-bus-api/proposals/data-access/src/lib/proposal.queries.ts`           |
| Строка журнала об отбое                | `libs/message-bus-api/cargo-state/feature/src/lib/cargo-state.controller.ts`                                                                                     |
| Отдача поля чтением одной записи       | `libs/message-bus-api/postmortems/feature/src/lib/postmortems-read.controller.ts`, `libs/message-bus-api/proposals/feature/src/lib/proposals-read.controller.ts` |
| Модель и маппер админки                | `libs/message-bus-admin/postmortems/util/src/lib/`, `libs/message-bus-admin/proposals/util/src/lib/`                                                             |
| Строка панели подробностей             | `libs/message-bus-admin/postmortems/ui/src/lib/postmortem-view/`, `libs/message-bus-admin/proposals/ui/src/lib/proposal-view/`                                   |
| Подпись свойства                       | `libs/message-bus-admin/common/core/util/src/lib/admin-labels.ts`                                                                                                |
| Довод команды строки запуска           | `projects/agent-kit/src/bin/agent-kit.ts`, `projects/agent-kit/src/lib/cargo-state.ts`, `projects/agent-kit/src/lib/cargo.ts`                                    |

Куда вливаются правила: показ в панели и отсутствие строки у записи без версии — в
`docs/specs/message-bus/admin/`; довод команды строки запуска — в
`docs/specs/agent-kit/observations/`; остальные тринадцать — в
`docs/specs/message-bus/cargo-state/`.

# Сценарии — подписи админки берутся из словаря

Номер стоит в начале заголовка теста, дальше тире. Пока сценарий не покрыт, он несёт пометку «Not
covered» с причиной. Приставка общая на домен.

### SC-MB-402 — подпись приходит из словаря на выбранном языке

Дано в наборе есть ключ, и у него есть русский и английский текст
Когда экран спрашивает словарь этим ключом при выборе `ru`, а затем при выборе `en`
Тогда первый раз приходит русский текст, второй — английский

### SC-MB-403 — ненайденный ключ виден, а не пуст

Дано ключа в наборе нет
Когда экран спрашивает словарь этим ключом
Тогда вместо подписи приходит признак ненайденного ключа: пустая строка читалась бы как «подписи
здесь нет» и дожила бы до жалобы человека

### SC-MB-404 — переключение языка меняет оба словаря без перезагрузки

Дано открыт экран, подписи которого берутся из словаря админки, и рядом стоят кнопки кита
Когда человек переключает язык в оболочке
Тогда меняются и подписи админки, и подписи кита, и страница не перезагружается

Not covered: переключатель сводится с обоими словарями третьим этапом задачи.

### SC-MB-405 — выбор языка переживает перезагрузку и не уходит на сервер

Дано человек выбрал английский
Когда страница перезагружена
Тогда выбор остался английским, и ни один запрос к приёмнику о языке не спрашивал

Not covered: третий этап задачи.

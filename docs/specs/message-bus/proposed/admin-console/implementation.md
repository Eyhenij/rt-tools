# Вход в админку и чтение груза — где будут исполняться правила

Кода, с которым сверять, ещё нет: это договорённость о продукте, записанная до работы. Поэтому
вторая колонка пока пуста, а сверка спеков привязок у `proposed/` не спрашивает вовсе.

Заполняется она по ходу работы: правило закрыто — в его строку встаёт `` `файл:символ` ``.
Договорённость вливается в `docs/specs/message-bus/spec.md` последним коммитом отчёта, и строки
отсюда переезжают в компаньон домена — там пустых уже не бывает: правило без строки означает
обещание, которого в коде нет.

— сам текст правила, поэтому переформулировать его, не поправив строку здесь, нельзя.

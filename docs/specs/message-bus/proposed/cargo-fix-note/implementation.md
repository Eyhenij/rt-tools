# Привязка — приём починки на записи груза

Кода на день записи нет: договорённость написана раньше него. Привязки проставляются последним
коммитом заявки, при вливании в поддомен правки состояния, в спек админки и в спек наблюдений
пакета, — тогда символы уже объявлены.

| Правило                                                                                  | Где исполняется                                              |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Текст починки приезжает полем строки правки состояния, а не своей операцией.             | Не исполняется: четвёртое поле строки заводится этой работой |
| Переход в «починено и не выпущено» без текста починки отбивается построчно.              | Не исполняется: третья причина отбоя заводится этой работой  |
| Текст починки принимается только со строкой, переводящей в «починено и не выпущено».     | Не исполняется: разбор строки заводится этой работой         |
| Пустой текст текстом не считается.                                                       | Не исполняется: разбор строки заводится этой работой         |
| Приём починки заводится обоим родам записей груза.                                       | Не исполняется: колонка обеих таблиц заводится этой работой  |
| Отбитая строка не пишет ни состояния, ни текста.                                         | Не исполняется: запись состояния правится этой работой       |
| Второй приезд текста починки затирает прежний.                                           | Не исполняется: запись состояния правится этой работой       |
| Своего предела длины у текста починки нет.                                               | Не исполняется: разбор строки заводится этой работой         |
| Текст починки виден в панели подробностей и не виден в списке.                           | Не исполняется: строка панели заводится этой работой         |
| У записи без текста починки строки в панели нет вовсе.                                   | Не исполняется: строка панели заводится этой работой         |
| Команда строки запуска несёт текст доводом.                                              | Не исполняется: довод команды заводится этой работой         |
| Отбой по недостающему тексту ложится строкой журнала наравне с двумя прежними причинами. | Не исполняется: причина отбоя заводится этой работой         |

Где это ляжет:

| Что                                  | Где                                                                                                                                                              |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Колонка у обоих родов записей        | `prisma/schema.prisma`, миграция рядом с прежними в `prisma/migrations/`                                                                                         |
| Разбор строки правки и причины отбоя | `libs/message-bus-api/cargo-state/util/src/lib/cargo-state-body.ts`, `libs/message-bus-api/cargo-state/api/src/lib/cargo-state.response.ts`                      |
| Просьба о переходе, несущая текст    | `libs/message-bus-common/src/lib/cargo-state-move.ts`                                                                                                            |
| Запись текста вместе с состоянием    | `libs/message-bus-api/postmortems/data-access/src/lib/postmortem.queries.ts`, `libs/message-bus-api/proposals/data-access/src/lib/proposal.queries.ts`           |
| Строка журнала об отбое              | `libs/message-bus-api/cargo-state/feature/src/lib/cargo-state.controller.ts`                                                                                     |
| Отдача поля чтением одной записи     | `libs/message-bus-api/postmortems/feature/src/lib/postmortems-read.controller.ts`, `libs/message-bus-api/proposals/feature/src/lib/proposals-read.controller.ts` |
| Модель и маппер админки              | `libs/message-bus-admin/postmortems/util/src/lib/`, `libs/message-bus-admin/proposals/util/src/lib/`                                                             |
| Строка панели подробностей           | `libs/message-bus-admin/postmortems/ui/src/lib/postmortem-view/`, `libs/message-bus-admin/proposals/ui/src/lib/proposal-view/`                                   |
| Подпись свойства                     | `libs/message-bus-admin/common/core/util/src/lib/admin-labels.ts`                                                                                                |
| Довод команды строки запуска         | `projects/agent-kit/src/bin/agent-kit.ts`, `projects/agent-kit/src/lib/cargo-state.ts`, `projects/agent-kit/src/lib/cargo.ts`                                    |

Куда вливаются правила: показ в панели и отсутствие строки у записи без текста — в
`docs/specs/message-bus/admin/`; довод команды строки запуска — в
`docs/specs/agent-kit/observations/`; остальные девять — в
`docs/specs/message-bus/cargo-state/`.

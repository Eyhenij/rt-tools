# The binding — usage of the rules in the sessions of the trees, the receiving side

There is no code yet: the lines name the place foreseen for every rule, and the addresses are filled
in by the work and checked by the spec audit at the merge. The paths are from the root of the tree;
the ones that do not exist yet are named without the file extension, so the address check does not
read them as a dead link.

# Сборка требует клиента хранилища — где исполняются правила

Первая колонка — правило дословно, как оно написано в разделе «Правила» договорённости.
Привязки проставляются, когда код написан: до этого договорённость говорит о намерении.

| Правило                                                   | Где исполняется |
| --------------------------------------------------------- | --------------- |
| Сборка приёмника отказывает, когда клиента хранилища нет. | не исполняется  |
| Отказ называет и причину, и починку.                      | не исполняется  |
| Проверка идёт до компиляции.                              | не исполняется  |
| Решение живёт чистой функцией, а конфиг сборки её зовёт.  | не исполняется  |
| Конвейер собирает приёмник, и отказ сборки роняет прогон. | не исполняется  |

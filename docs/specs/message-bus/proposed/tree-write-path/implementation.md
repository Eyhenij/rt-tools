# Привязка — путь записи для дерева

Кода на день записи нет: договорённость написана раньше него. Привязки проставляются последним
коммитом PR, при вливании в спек приёма, — тогда символы уже объявлены.

| Утверждение                                                          | Где исполняется                                                        |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Состояние правит дерево своим токеном, а не вошедший человек         | Не исполняется: операция заводится этой работой                        |
| Правка закрыта токеном дерева наравне с приёмом груза                | Не исполняется: метка доступа ставится этой работой                    |
| Дерево правит только свои записи                                     | Не исполняется: операция заводится этой работой                        |
| Запись другого дерева отвечает так же, как ненайденная               | Не исполняется: поиск записи заводится этой работой                    |
| Правятся оба рода записей груза                                      | Не исполняется: операция заводится этой работой                        |
| Правка состояния других полей записи не трогает                      | Не исполняется: операция заводится этой работой                        |
| Опознание записи правка не меняет                                    | Не исполняется: поиск по ключу заводится этой работой                  |
| Признак предложения считается одним способом на обе стороны          | Не исполняется: счёт признака на стороне дерева заводится этой работой |
| Состояния приходят перечислением, а не строкой в теле запроса        | Не исполняется: разбор строки правки заводится этой работой            |
| Шаг идёт вперёд на соседний                                          | `libs/message-bus-common/src/lib/cargo-state-move.ts:cargoStateMove`   |
| Назад ходит один возврат — из «в работе» в «новое»                   | `libs/message-bus-common/src/lib/cargo-state-move.ts:cargoStateMove`   |
| Правка в то же состояние переходом не считается и строку не отбивает | `libs/message-bus-common/src/lib/cargo-state-move.ts:cargoStateMove`   |
| Переход судится по тому, что лежит в хранилище                       | Не исполняется: операция заводится этой работой                        |
| Правка приезжает пакетом: одна операция на несколько строк           | Не исполняется: операция заводится этой работой                        |
| Записи обоих родов едут одним пакетом                                | Не исполняется: разбор строки правки заводится этой работой            |
| Строка пакета отбивается сама по себе, а не уносит пакет целиком     | Не исполняется: операция заводится этой работой                        |
| Ответ называет, сколько записей переведено                           | Не исполняется: форма ответа заводится этой работой                    |
| Отбитая строка называется местом в пакете, ключом и причиной         | Не исполняется: форма ответа заводится этой работой                    |
| Пакет без строк отбивается по форме                                  | Не исполняется: проверка формы заводится этой работой                  |
| Отбитая строка пишется в журнал приёмника наравне с отказом операции | Не исполняется: строка журнала заводится этой работой                  |
| Строка журнала несёт род записи, признак дерева и причину            | Не исполняется: строка журнала заводится этой работой                  |

Где это ляжет:

| Что                    | Где                                                                                                                                                                    |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| операция правки        | рядом с приёмом обоих родов — `libs/message-bus-api/postmortems/feature/` и `libs/message-bus-api/proposals/feature/` — либо своим домом на оба рода: выбирает замысел |
| порядок переходов      | `libs/message-bus-common/src/lib/` — рядом с перечислением состояний                                                                                                   |
| отказ по форме запроса | `libs/message-bus-common/src/lib/cargo-fault.ts`                                                                                                                       |
| метка доступа          | `libs/message-bus-api/access/util/src/lib/operation-access.ts`                                                                                                         |
| дерево из токена       | `libs/message-bus-api/trees/util`                                                                                                                                      |
| строка журнала         | `libs/message-bus-api/observability`                                                                                                                                   |
| команда строки запуска | `projects/agent-kit` — она часть слоя правил, а не приёмника                                                                                                           |

Три сценария о порядке переходов — `SC-MB-174`, `SC-MB-175` и `SC-MB-176` — закрыты частично:
решение о переходе проверено вызовом в `libs/message-bus-common/src/lib/cargo-state-move.spec.ts`.
Их путь запроса и остальные шесть сценариев закрывает спека операции правки состояния: её файл
заводится этой работой, и адрес встанет сюда последним коммитом PR.

| Правило                                                           | Где исполняется                |
| ----------------------------------------------------------------- | ------------------------------ |
| Приёмник отвечает только по защищённому соединению.               | `deploy/Caddyfile`             |
| Сертификат выписывает и продлевает проксировщик сам.              | `deploy/Caddyfile`             |
| Наружу узел открывает только два порта дороги.                    | `docker-compose.prod.yml`      |
| Админка и приём отвечают с одного имени.                          | `deploy/Caddyfile`             |
| Адрес раздела админки открывается прямой ссылкой.                 | `deploy/Caddyfile`             |
| Узел поднимает готовый образ, а не собирает его у себя.           | `.github/workflows/deploy.yml` |
| Образ на узле опознаётся sha коммита, а не подвижной меткой.      | `.github/workflows/deploy.yml` |
| Миграции накатываются до того, как приёмник начинает отвечать.    | `docker-compose.prod.yml`      |
| Выкатка начинается рукой человека, а не слиянием.                 | `.github/workflows/deploy.yml` |
| Выкатка кончается пробой живости, а не подъёмом контейнеров.      | `.github/workflows/deploy.yml` |

| Чистка отбирает образы по имени своего реестра, а не по возрасту. | `deploy/prune-images.sh`       |
| Хранилище лежит на именованном томе, а не внутри контейнера.      | `docker-compose.prod.yml`      |
| Контейнеры поднимаются сами после перезапуска узла.               | `docker-compose.prod.yml`      |
| Дамп снимается и загружается одной командой каждый.               | `deploy/dump.sh`               |
| Загруженный дамп возвращает и свод, и годность выданных токенов.  | `deploy/dump.sh`               |
| Адрес приёма в настройке дерева — имя, а не местная машина.       | `.claude/rt-kit.json`          |

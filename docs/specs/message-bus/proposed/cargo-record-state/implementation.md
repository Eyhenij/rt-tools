# Привязка — состояние записи груза

Кода на день записи нет: договорённость написана раньше него. Привязки проставляются последним
коммитом PR, при вливании в спек домена, — тогда символы уже объявлены.

| Утверждение                                                          | Где исполняется                                                                     |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Состояние есть у разбора происшествия и у предложения                | Не исполняется: колонка заводится этой работой                                      |
| Состояний четыре, и других нет                                       | Не исполняется: перечисление заводится этой работой                                 |
| Состояние приходит перечислением, а не строкой в месте использования | Не исполняется: перечисление заводится этой работой                                 |
| Приехавшая запись встаёт в «новое»                                   | Не исполняется: умолчание заводится этой работой                                    |
| Записи, приехавшие до заведения поля, читаются как новые             | Не исполняется: миграция пишется этой работой                                       |
| Переход назад не ходит, кроме возврата из «в работе» в «новое»       | Не исполняется: проверка перехода заводится этой работой                            |
| Приезд, изменивший текст разбора, возвращает его в «новое»           | Не исполняется: правка приёма разборов идёт этой работой                            |
| Приезд, не изменивший текста, состояния не трогает                   | Не исполняется: правка приёма разборов идёт этой работой                            |
| Состояние приезжает чтением — и списком, и одной записью             | Не исполняется: правка чтения идёт этой работой                                     |
| Приём груза состояния не принимает                                   | Не исполняется: форма груза этой работой не меняется, и это сверяется тестом приёма |
| Состояние видно столбцом в разделах разборов и предложений           | Не исполняется: столбец заводится этой работой                                      |
| Слова состояний берутся из словаря приложения                        | Не исполняется: подписи заводятся этой работой                                      |

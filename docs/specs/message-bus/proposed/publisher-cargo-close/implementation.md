# Закрытие записи груза издателем — где исполняются правила

Первая колонка — правило дословно, как оно написано в разделе «Правила» спека. Правило без
строки и строка без правила — расхождение: спек обещает то, чего в коде нет, либо в коде стоит
то, о чём спек молчит.

Кода пока нет: договорённость предложена и ждёт вливания. Строки проставляются той работой,
которая её исполняет, — вместе со снятием пометок «Не покрыто» у сценариев.

- **Закрытие записи закрыто входом человека, а не токеном дерева.** — не исполняется: кода нет
- **Издатель закрывает запись любого дерева, включая своё.** — не исполняется: кода нет
- **Закрытие ходит только вперёд и только по двум последним шагам.** — не исполняется: кода нет
- **Приём починки обязателен при переходе в «починено и не выпущено», версия — при переходе в «выпущено».** — не исполняется: кода нет
- **Закрытие называет, кто его сделал.** — не исполняется: кода нет
- **Своё право дерева закрытие не отменяет.** — не исполняется: кода нет
- **Закрытие приезжает пакетом.** — не исполняется: кода нет
- **Строка пакета отбивается сама по себе.** — не исполняется: кода нет
- **Ответ называет число переведённых, число уже стоявших и отбитые строки.** — не исполняется: кода нет

# Сценарии — образцы, которые пакет везёт

Идентификатор ставится в начало заголовка теста через тире. Пока сценарий не покрыт, он несёт
пометку «Не покрыто» с причиной.

### SC-AK-202 — образец ложится по своему пути внутри каталога документов

Дано дерево не называло роду образцов своего каталога
Когда считается, куда ложится образец папки задачи
Тогда путь идёт от умолчания рода и повторяет раскладку внутри него

Покрыто: `projects/agent-kit/src/lib/assets.spec.ts`.

### SC-AK-203 — дерево называет образцам свой каталог

Дано дерево назвало роду образцов свой каталог в раскладке
Когда считается, куда ложится образец
Тогда он ложится туда, а не в умолчание пакета

Покрыто: `projects/agent-kit/src/lib/assets.spec.ts`.

# Привязка — заведение дерева токеном из админки

| Утверждение                                                          | Где исполняется           |
| -------------------------------------------------------------------- | ------------------------- |
| Дерево заводится двумя путями, и человек выбирает доводом            | `enroll.ts:enroll`        |
| Выданный токен в сеть не уходит                                      | `enroll.ts:accept`        |
| Два довода вместе отбиваются                                         | `enroll.ts:enroll`        |
| Ни одного довода — отказ называет оба пути                           | `enroll.ts:enroll`        |
| Токен ложится на диск одинаково, каким бы путём ни пришёл            | `enroll.ts:lay`           |
| Лежащий токен не перезаписывается молча ни у одного из путей         | `enroll.ts:enroll`        |
| Проверки, общие обоим путям, стоят до развилки                       | `enroll.ts:enroll`        |
| Адрес приёма и запрет открытого пути требуются только обмену по коду | `enroll.ts:intakeAllowed` |

Пути от корня пакета правил: `projects/agent-kit/src/lib/`.

# Где это будет исполняться — ревью текстов слоя правил

Ключ связи — сам текст правила из `spec.md` рядом. Кода под эту договорённость ещё нет: таблица
называет место, куда правило ляжет, и вместе с вливанием в спек домена превращается в привязку
`файл:символ`. Строка без места означала бы намерение, а не правило, — такому место в открытых
вопросах.

## Что из этого уже есть

- `projects/agent-kit/tests/texts.test.sh` — четыре запрета по словам; новые роды расхождений
  дописываются в него, а не заводят второй набор.
- `projects/agent-kit/src/lib/integrity.ts` — связь снизу вверх: у паттерна есть правило, у
  правила есть закон. Обратная сторона в нём не сверялась ни разу.
- `projects/agent-kit/src/lib/catalog.ts` — обход набора по родам и видам.
- `projects/agent-kit/src/lib/config.ts` — перечень родов; набора разделов при них пока нет.

## Чего нет вовсе

- Роли ревью и команды при ней: `assets/agents/rules-reviewer.md` и
  `assets/commands/rules-review.md` — задача RT-704.
- Графов хода: ни один ресурс пакета их не несёт — задача RT-705.

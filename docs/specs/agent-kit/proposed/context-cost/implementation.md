# Привязка — цена контекста считается командой

Привязки ниже указывают на места, которых в дереве ещё нет: договорённость написана до кода.
Заполняются они той же работой, которая код пишет, и до вливания в спек домена ни одна строка
здесь не остаётся пустой.

| Утверждение                                                         | Где исполняется |
| ------------------------------------------------------------------- | --------------- |
| Цена контекста считается в токенах, а не в байтах                   | `cost.ts`       |
| Команда называет три числа: цену входа, вес правила и вес слоя      | `cost.ts`       |
| Число снимается с того, что получает заход, а не с файла на диске   | `cost.ts`       |
| Один и тот же текст считается в двух языках, и разница печатается   | `cost.ts`       |
| Команда ничего не пишет                                             | `cost.ts`       |
| В сеть команда ходит только за счётом токенов и ни за чем больше    | `cost.ts`       |
| Без доступа к счёту команда отказывает и называет, чем он заводится | `cost.ts`       |
| Имя токенизатора стоит в выводе рядом с числами                     | `cost.ts`       |
| Вывод бывает машиночитаемым по требованию                           | `cost.ts`       |

Пути от каталога `projects/agent-kit/src/lib/`. Разбор доводов и подсказка команды — в
`projects/agent-kit/src/bin/agent-kit.ts`.

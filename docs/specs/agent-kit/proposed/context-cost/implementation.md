# Привязка — цена контекста считается командой

Привязки к разбору доводов указывают на место, которого в дереве ещё нет: договорённость
написана до кода. Заполняется оно той же работой, которая код пишет, и до вливания в спек
домена ни одна строка здесь не остаётся пустой.

| Утверждение                                                       | Где исполняется      |
| ----------------------------------------------------------------- | -------------------- |
| Цена меряется тем, что считается на месте: символами и байтами    | `cost.ts:weigh`      |
| Чем считано, стоит рядом с числами                                | `cost.ts:COUNTED_BY` |
| Команда называет три числа: цену входа, вес правила и вес слоя    | `cost.ts:costOf`     |
| Число снимается с того, что получает заход, а не с файла на диске | `cost.ts:entryTexts` |
| Символы и байты печатаются оба                                    | `cost.ts:weigh`      |
| Команда ничего не пишет и в сеть не ходит                         | `cost.ts:costOf`     |
| Вывод бывает машиночитаемым по требованию                         | `agent-kit.ts`       |

Пути от каталога `projects/agent-kit/src/lib/`. Разбор доводов и подсказка команды — в
`projects/agent-kit/src/bin/agent-kit.ts`.

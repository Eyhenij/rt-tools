# Сценарии — привязками считается одна таблица компаньона

Идентификатор ставится в начало заголовка теста через тире. Пока сценарий не покрыт, он несёт
пометку «Не покрыто» с причиной.

### SC-AK-56 — строка описательной таблицы привязкой не считается

Дано компаньон правила называет имя дерева строкой таблицы «Где это лежит»
Когда идёт сверка спеков
Тогда она молчит о ней, а строку той же формы в таблице привязок судит по-прежнему

### SC-AK-57 — компаньон правила без раздела привязок отбивается

Дано в компаньоне правила нет раздела «Где исполняются статьи»
Когда идёт сверка спеков
Тогда она называет это расхождением и говорит, какого раздела не хватает

### SC-AK-58 — у компаньона спека домена раздел не требуется

Дано компаньон спека домена держит одну таблицу без раздела
Когда идёт сверка спеков
Тогда его привязки читаются, как читались

# Чем исполняется — закрытие захода командой

Кода под эту договорённость ещё нет: она лежит в `proposed/` и описывает то, чего в пакете не
существует. Колонка «Где окажется» поэтому называет место, а не существующий символ. Привязка к
символам проставляется тем же изменением, что и код, и вливается в спек домена вместе со всей
договорённостью.

## Где исполняются статьи

| Статья                                                                                          | Где окажется                                                                        | Сценарий   |
| ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------- |
| Заход закрывается одной командой.                                                               | ресурс рода «команда» в активах пакета и его раскладка в каталог команд дерева      | `SC-AK-60` |
| Команда сперва узнаёт, ведётся ли работа по правилу.                                            | шаг разбора состояния в теле команды: имя ветки против формы номера и папка задачи  | `SC-AK-60` |
| У работы по правилу с влитым отчётом дерево переходит на главную ветку и подтягивает удалённую. | ветка «работа по правилу» в теле команды                                            | `SC-AK-60` |
| Во всех прочих случаях главная ветка вливается в текущую.                                       | вторая ветка шага о главной ветке в теле команды                                    | `SC-AK-61` |
| Незакоммиченная правка останавливает команду до первого действия.                               | первый шаг команды — состояние рабочего дерева                                      | `SC-AK-59` |

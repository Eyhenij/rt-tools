# Привязка — команда отметки состояния груза

Кода на день записи нет: договорённость написана раньше него. Привязки проставляются последним
коммитом PR, при вливании в поддомен наблюдений и груза наружу, — тогда символы уже объявлены.

| Утверждение                                                    | Где исполняется                                         |
| -------------------------------------------------------------- | ------------------------------------------------------- |
| Отметка ставится командой пакета, а не запросом руками         | Не исполняется: команда заводится этой работой          |
| Одна отметка несёт одно состояние и сколько угодно записей     | Не исполняется: разбор доводов заводится этой работой   |
| Записи обоих родов уезжают одним запросом                      | Не исполняется: сборка пакета заводится этой работой    |
| Записи называются теми же ключами, которыми приехали           | Не исполняется: разбор доводов заводится этой работой   |
| Признак предложения считается тем же способом, что и у приёма  | Не исполняется: счёт признака заводится этой работой    |
| Незнакомое состояние отбивается до сети                        | Не исполняется: проверка доводов заводится этой работой |
| Вызов без записей отбивается и называет, чего не хватает       | Не исполняется: проверка доводов заводится этой работой |
| Без токена дерева команда в сеть не идёт                       | Не исполняется: чтение настройки заводится этой работой |
| Холостой ход печатает, что уехало бы, и в сеть не идёт         | Не исполняется: холостой ход заводится этой работой     |
| Отбитые приёмом записи печатаются поимённо, с причиной         | Не исполняется: вывод заводится этой работой            |
| Отметка, которая ничего не перевела, кончается ненулевым кодом | Не исполняется: коды возврата заводятся этой работой    |
| Ни токен дерева, ни текст записи в вывод не попадают           | Не исполняется: вывод заводится этой работой            |
| Приём отвечает счётом, и команда пересказывает его человеку    | Не исполняется: разбор ответа заводится этой работой    |

Где это ляжет:

| Что                    | Где                                                                |
| ---------------------- | ------------------------------------------------------------------ |
| команда и её доводы    | `projects/agent-kit` — рядом с отправкой груза и заведением дерева |
| форма запроса и ответа | `projects/agent-kit` — там же, где объявлена форма груза           |
| адрес приёма и токен   | настройка пакета в дереве — та же, из которой ходит отправка       |

Все шесть сценариев закрывает спека команды отметки: её файл заводится этой работой, и адрес
встанет сюда последним коммитом PR.

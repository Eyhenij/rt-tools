# Привязка — заход продолжается сжатием

Утверждение спека и место, где оно исполняется. Связь идёт по тексту утверждения: снятое
утверждение снимается вместе со своей строкой.

Кода пока нет: договорённость записана до него. Строки проставляются при вливании в спек
домена, когда привязки известны.

| Правило                                                  | Где исполняется                    |
| -------------------------------------------------------- | ---------------------------------- |
| Порог сжатия стоит ниже порога остановки.                | Не исполняется — работа не начата. |
| Совпадение порогов — расхождение, а не согласие.         | Не исполняется — работа не начата. |
| Расстояние между порогами объявлено, а не выведено.      | Не исполняется — работа не начата. |
| Страж после порога сжатия остаётся страховкой.           | Не исполняется — работа не начата. |
| Заполненное окно кончает ход только там, где сжатия нет. | Не исполняется — работа не начата. |
| Дерево, не объявившее сжатия, работает как прежде.       | Не исполняется — работа не начата. |
| Отказ называет обе стороны числами.                      | Не исполняется — работа не начата. |

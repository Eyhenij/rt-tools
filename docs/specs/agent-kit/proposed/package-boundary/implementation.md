# Где это исполняется — граница пакета правил

Ключ связи — сам текст правила. Договорённость записана раньше кода, поэтому места названы
теми, какими они станут: строка привязки ставится тем изменением, которым место заводится.

## Правила и их места

| Правило                                                                      | Где исполняется                                                                       |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Пакет везёт потребителю только то, что потребитель исполняет.                | Проверка границы в своих проверках дерева — заводится первой задачей                  |
| Признак «не для везения» — не оценка, а два вопроса к ресурсу.               | Там же: два вопроса становятся двумя правилами отбора в теле проверки                 |
| Ресурс не для везения живёт своим ресурсом дерева, а не отменяется перечнем. | Там же: перечень отменяемого проверкой не читается                                    |
| Отправляющая сторона остаётся в пакете целиком.                              | Не исполняется машиной: держится составом ресурсов, который проверка не трогает       |
| Ресурс, ещё не переехавший, стоит в перечне долга и назван адресом переезда. | Перечень долга рядом с проверкой — заводится первой задачей, пустеет второй и третьей |
| Граница держится проверкой, а не чтением.                                    | Состав гейта пуша этого дерева — проверка добавляется туда же, где остальные          |
| Своё правило дерева объявляется наравне с пакетным.                          | Своя карта гейта дерева — ветка правила разбора груза заводится второй задачей        |

## Что здесь своё

Проверка границы — своя проверка этого дерева, а не ресурс пакета: судить ресурсы пакета
чужому дереву нечего. Живёт она там же, где остальные свои проверки, и зовётся тем же способом.

Своё правило дерева заводится по образцу двух уже живущих: у них та же форма, что у пакетных,
компаньон рядом и своя ветка в карте гейта.

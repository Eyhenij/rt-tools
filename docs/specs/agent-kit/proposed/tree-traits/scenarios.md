# Сценарии — свойства дерева и ресурсы, которые их требуют

Идентификатор ставится в начало заголовка теста через тире. Пока сценарий не покрыт, он несёт
пометку «Не покрыто» с причиной.

### SC-AK-168 — ресурс с неотвеченным требованием не кладётся

Дано ресурс требует свойства `db`, а набор свойств дерева его не называет
Когда идёт раскладка
Тогда ни ресурс, ни черновик его компаньона в дерево не попадают

### SC-AK-169 — отвеченное требование ресурс не задерживает

Дано ресурс требует свойства `db`, и дерево назвало `db` своим
Когда идёт раскладка
Тогда ресурс ложится под именем без требования в имени

### SC-AK-170 — молчание дерева о себе требованию не отвечает

Дано набор свойств дерева пуст
Когда идёт раскладка
Тогда ни один помеченный требованием ресурс не кладётся

### SC-AK-171 — ресурс без требования кладётся любому дереву

Дано ресурс требования не несёт, а набор свойств дерева пуст
Когда идёт раскладка
Тогда ресурс ложится

### SC-AK-172 — выбор поимённо сильнее неотвеченного требования

Дано ресурс требует свойства, которого у дерева нет, и назван деревом поимённо
Когда идёт раскладка
Тогда ресурс ложится, а неотвеченное требование названо строкой перечня

### SC-AK-173 — требование неизвестного свойства — отказ раскладки

Дано ресурс требует свойства, которого пакет не объявлял
Когда идёт раскладка
Тогда она отказывает и называет и ресурс, и незнакомое свойство

### SC-AK-174 — незнакомое свойство в настройке дерева — отказ раскладки

Дано набор свойств дерева называет свойство, которого пакет не объявлял
Когда идёт раскладка
Тогда она отказывает и называет это свойство

### SC-AK-175 — вид и требование в одном имени читаются каждый своим перечнем

Дано имя ресурса несёт и вид оси, и требуемое свойство
Когда имя разбирается
Тогда вид опознан по перечню осей, требование — по перечню свойств, и оба сняты с имени

### SC-AK-176 — неположенное требованием отделено в перечне от снятого деревом

Дано один ресурс снят строкой отказа, другой не положен неотвеченным требованием
Когда печатается перечень ресурсов
Тогда у первого стоит «пропущен», у второго — своё слово с названием требуемого свойства

### SC-AK-177 — отказ по пустому компаньону называет требуемое свойство

Дано компаньон ресурса пуст, а ресурс требует свойства, которого у дерева нет
Когда идёт сверка разложенного
Тогда отказ называет требуемое свойство и снятие ресурса строкой отказа, а не заполнение
черновика

# Сценарии — разбор состояния раскладки

Идентификатор ставится в начало заголовка теста через тире. Префикс общий на домен, и номера при
переезде в поддомен не пересчитывались: номер связывает сценарий с заголовком теста.

### SC-AK-435 — незаданный порог сжатия разбор называет вместе с готовыми числами

Дано дерево объявило размер окна, а порога сжатия не объявляло вовсе
Когда разбор состояния печатает пороги
Тогда он называет числа стража и говорит, что порог сжатия назначает инструмент, — с готовыми
значениями для обеих настроек

Покрыто: `projects/agent-kit/src/lib/thresholds.spec.ts`.

### SC-AK-716 — разбор состояния называет разделы, замещённые надстройками

Дано надстройка дерева замещает раздел пакета совпавшим заголовком
Когда идёт разбор состояния раскладки
Тогда он называет такой раздел поимённо — ресурс и заголовок: всё, что пакет допишет в него
новой версией, пропадает молча, и других свидетелей у потери нет. Дерево без надстроек об этом
молчит

### SC-AK-729 — сводка называет местные значения, которых ждут взятые хуки

Дано взятый хук назвал строкой шапки местное значение, которым живёт
Когда сводка состояния читает дерево
Тогда она говорит, сколько таких значений ждут хуки, и называет отсутствующие поимённо — с
именем хука и тем, что без значения перестаёт проверяться; лежащее значение она не перечисляет

Ключ шапки при этом читается на обоих языках: хук с русским ключом сводка считает наравне с
английским

### SC-AK-730 — надстройка, не подобранная ни к одному ресурсу, называется

Дано в каталоге надстроек лежит файл, чьё имя не совпадает ни с одним идентификатором ресурса
Когда раскладка или её сверка читает дерево
Тогда файл называется строкой предупреждения — применён он не был; файл вне рода ресурсов,
README каталога, надстройкой не считается вовсе

### SC-AK-731 — долг привязок считается по разложенному телу правила

Дано дерево замещает раздел статей правила своей надстройкой
Когда раскладка считает статьи без адреса
Тогда в долг идут статьи разложенного текста, а не пакетной редакции: замещённого раздела в
дереве нет, и привязывать в компаньоне нечего

### SC-AK-846 — пометка называет ресурс, статью и день отправки

Дано раздел надстройки несёт комментарий разметки с ресурсом пакета, статьёй и днём
Когда пометки файла разбираются
Тогда раздел назван вместе с этими тремя значениями, а раздел без пометки считается постоянным

Покрыто: `projects/agent-kit/src/lib/override-marks.spec.ts`.

### SC-AK-847 — раскладка называет надстройки, чья статья уже есть в пакете

Дано в новой редакции пакета статья помеченного раздела уже есть
Когда идёт раскладка
Тогда раздел назван строкой вывода вместе с файлом и днём отправки, а сам он не снимается: это
делает человек. Статья, перенесённая по ширине строки, находится так же, как сплошная; статьи в
редакции нет — раздел не называется

Покрыто: `projects/agent-kit/src/lib/override-marks.spec.ts`.

### SC-AK-848 — пометка на ресурс, которого в редакции нет, молчит

Дано пометка называет ресурс, которого в новой редакции нет, либо каталога надстроек нет
Когда идёт раскладка
Тогда ничего не называется: пакет мог ресурс переименовать, и называть надстройку лишней на этом
основании значило бы советовать снять то, чему замена не пришла

Покрыто: `projects/agent-kit/src/lib/override-marks.spec.ts`.

### SC-AK-854 — незаполненная дырка расхождением не считается

Дано дерево разложено и компаньоны заполнены, а один ресурс держит дырку, значения которой в
настройке нет
Когда идёт сверка раскладки
Тогда код возврата нулевой, а дырка названа отдельным блоком — с именем ключа настройки и словом
о том, что до значения ресурс не раскладывается

Покрыто: `projects/agent-kit/src/lib/commands.spec.ts`.

# Сценарии — гарды завершения хода

Идентификатор ставится в начало заголовка теста через тире. Префикс общий на домен, и номера при
переезде в поддомен не пересчитывались: номер связывает сценарий с заголовком теста.

### SC-AK-95 — ход с признанием промаха не закрывается без записи

Дано в ходе прозвучало признание промаха, а записи о происшествии в дереве не появилось
Когда ход завершается
Тогда гард его отбивает и называет каталог записей

Покрыто: `projects/agent-kit/tests/postmortem-guard.test.sh`.

### SC-AK-797 — каталог записей называет настройка дерева

Дано дерево унесло каталог разборов из истории и назвало его ключом `postmortems` в настройке
Когда ход с признанием промаха завершается без записи
Тогда гард его отбивает — каталог он берёт из настройки, а не из прежнего умолчания

Ключ, названный пустым, требование снимает: это отказ дерева от него, и настройка говорит здесь
то же, что переменная окружения. Переменная перебивает настройку — она обход на один запуск.

Покрыто: `projects/agent-kit/tests/postmortem-guard.test.sh`.

### SC-AK-96 — запись появилась, и ход закрывается

Дано в ходе прозвучало признание промаха и в каталоге записей появился файл
Когда ход завершается

Покрыто: `projects/agent-kit/tests/postmortem-guard.test.sh`.

### SC-AK-262 — прочитанный красный прогон судится наравне с открытым PR

### SC-AK-263 — зелёный прогон и чтение без красного ответа гард не судит

### SC-AK-818 — на этот вопрос владелец уже отвечал

Дано владелец дал указание репликой, а в записи хода уже был вызов меню вопросов
Когда исполнитель шлёт меню, тема которого пересекается с этой репликой значимыми словами
Тогда вызов отбивается, и отказ велит продолжать работу, а не спрашивать иначе

Дано тема нового меню общих значимых слов с репликой владельца не набирает
Когда исполнитель шлёт это меню
Тогда вызов проходит: разбор просьбы идёт вопросами по разным предметам

Покрыто: `projects/agent-kit/tests/grill-gate.test.sh`.

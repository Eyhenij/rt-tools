# Сценарии — гарды завершения хода

Идентификатор ставится в начало заголовка теста через тире. Префикс общий на домен, и номера при
переезде в поддомен не пересчитывались: номер связывает сценарий с заголовком теста.

### SC-AK-95 — ход с признанием промаха не закрывается без записи

Дано в ходе прозвучало признание промаха, а записи о происшествии в дереве не появилось
Когда ход завершается
Тогда гард его отбивает и называет каталог записей

Покрыто: `projects/agent-kit/tests/postmortem-guard.test.sh`.

### SC-AK-96 — запись появилась, и ход закрывается

Дано в ходе прозвучало признание промаха и в каталоге записей появился файл

Покрыто: `projects/agent-kit/tests/postmortem-guard.test.sh`.

### SC-AK-97 — ход с вопросом владельцу отбивается до отправки вопроса

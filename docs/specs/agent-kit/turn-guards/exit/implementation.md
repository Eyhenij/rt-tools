# The binding — the guard of the exits of a turn

A statement of the spec and the place where it is carried out. The link goes by the text of the
statement: a removed statement is removed together with its line.

| Rule                                                                                                              | Where it is carried out                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The last action of a turn is only ever work.                                                                      | `projects/agent-kit/assets/hooks/turn-exit-guard.sh:ended_working` — an edit of a file or the changing part of the last command of the turn                                                                                                                                                 |
| An answer to the owner does not work as an action.                                                                | `projects/agent-kit/assets/hooks/turn-exit-guard.sh:ended_working` — the calls of the tools are judged, the text of the answer does not count as an action at all                                                                                                                           |
| Exploration does not count as work.                                                                               | `projects/agent-kit/assets/hooks/turn-exit-patterns.sh:read_re` — the reading subcommands of the version control system and of the hosting client                                                                                                                                           |
| A redirection of the output does not count as work.                                                               | `projects/agent-kit/assets/hooks/turn-exit-patterns.sh:work_re` — there is no arrow in the sample of work: the signs stay an edit of a file and the listed commands                                                                                                                         |
| Waiting for someone else's step is never the end of a turn.                                                       | `projects/agent-kit/assets/hooks/turn-exit-patterns.sh:wait_re` — a loop until the run is ready, watching it, a call of a sleep                                                                                                                                                             |
| Handed-in work ends a turn only together with the next one begun.                                                 | `projects/agent-kit/assets/hooks/turn-exit-patterns.sh:handover_re` — the tail of the turn after the opening of the request is compared with the sample of the start of the next work                                                                                                       |
| A task taken without a task folder does not end the turn.                                                         | `projects/agent-kit/assets/hooks/turn-exit-guard.sh:task_key` — the branch is compared with the sample of the key of the tasks, the sign is the absence of the directory of the task                                                                                                        |
| A branch named by the header of an epic plan is an epic branch, and the tier of the taken task does not judge it. | `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_epic_branch` — the plans directory from the settings, the branch in backticks in a header line of a plan. The tier of the taken task is skipped when it is true.                                                                   |
| A closed stage is confirmed by the command of the check of the same turn.                                         | `projects/agent-kit/assets/hooks/turn-exit-guard.sh:stage_was` — the number of the stage is compared with the history of the branch, the command is taken from the line of the plan                                                                                                         |
| A next step rewritten into the progress is begun by the same turn.                                                | `projects/agent-kit/assets/hooks/turn-exit-verdict.sh:after_progress` — the work after the last edit of the progress, the commit and the push of it left out; `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_next_step_deny` — the tier in a running stage; scenario `SC-AK-1132` |
| The lawful exits are judged before all the tiers.                                                                 | `projects/agent-kit/assets/hooks/turn-exit-guard.sh:released` — a question to the owner, a refusal of a guard, a written handover and a word of the owner about a stop                                                                                                                      |
| The parts of a compound command are judged one by one.                                                            | `projects/agent-kit/assets/hooks/turn-exit-patterns.sh:part_re` — the command is split by the joiners, and every part is judged apart                                                                                                                                                       |
| A service message neither starts a turn nor is a word of the owner.                                               | `projects/agent-kit/assets/hooks/turn-exit-verdict.sh:is_service` — the sign `isMeta`, the sign of the compaction summary and the first line of the feedback of a stop guard                                                                                                                |
| A refusal of a guard is an exit only as the last action of the turn.                                              | `projects/agent-kit/assets/hooks/turn-exit-verdict.sh:last_out` — the last result of a tool over the turn is matched against the refusal samples, not all of them together                                                                                                                  |
| A refusal of the closing tool is not an exit.                                                                     | `projects/agent-kit/assets/hooks/turn-exit-verdict.sh:last_out` — the refusal sample excludes the closing guard by its name; scenario SC-AK-1122                                                                                                                                            |
| A question at the head of an empty turn in a running stage is a stop.                                             | `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_question_without_work_deny` — the tier fires on the question tool without work in the state `этап-идёт`                                                                                                                            |
| Under an open epic a turn that ended with work does not end.                                                      | `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_epic_deny` — the tier stands right before the release by the sign of work and names the unfinished tasks                                                                                                                           |
| Under an open epic a second pass over the turn is judged again.                                                   | `projects/agent-kit/assets/hooks/turn-exit-guard.sh:active` — the second pass leaves with zero only where the epic is not open                                                                                                                                                              |
| A handover written by hand releases a turn only outside an open epic.                                             | `projects/agent-kit/assets/hooks/turn-exit-verdict.sh:handed_by_hand` — a handover command without a question, a refusal or a word of the owner in the same turn                                                                                                                            |
| The owner's standing word quoted in the line «Waiting for the owner» releases the turn.                           | `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_owner_word_quoted` — the waiting line is matched against « » of three characters and more.                                                                                                                                         |
| The end of an epic read from the table releases the whole turn on the way to a refusal.                           | `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_epic_over` — the shared cache of the reading, read and empty; `projects/agent-kit/assets/hooks/turn-exit-guard.sh:rt_te_deny` leaves with zero on it before any refusal is printed                                                 |
| The epic is read once per turn and only on the way to a refusal.                                                  | `projects/agent-kit/assets/hooks/turn-exit-epic.sh:rt_te_epic_left` — the answer of the shared reading of the epic is cached for the turn; the reading stands inside the tiers                                                                                                              |

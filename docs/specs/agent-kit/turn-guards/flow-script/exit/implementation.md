# Binding — the guard of the exits of a turn

A statement of the spec and the place where it is carried out. The link goes by the text of the
statement: a removed statement is removed together with its line.

- **A turn ends with the scenario: the engine measures the branch, and a turn whose scenario is not over is held.** — `projects/agent-kit/assets/hooks/turn-exit-guard.sh:verdict` — the input handed to the engine and its verdict turned into the answer; `projects/agent-kit/assets/checks/task-flow-script.mjs:runVerdict` — the measurement and the release cases; scenario `SC-AK-1427`
- **A turn is released by the first release case of the description that is met, in the order of the cases.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:releaseCase` — the cases in their order; scenarios `SC-AK-1427`, `SC-AK-1428`
- **A held turn names one move: the action of the measured state, and in a running stage the current step with the command that measures it.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:holdReason` — the state, its action, the step; `projects/agent-kit/assets/checks/flow-verdict.mjs:currentStep` — the step marked current in the progress
- **On a taken-apart task folder a held turn names the step by its number from the last progress of the history and the marks, with the move `git revert` of the commit that took it apart.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:archivedStep` — the step read from the history; `projects/agent-kit/assets/checks/flow-verdict.mjs:pendingStep` — the first step not done or without a matched mark; `projects/agent-kit/assets/checks/task-flow-script.mjs:runVerdict` — called when the folder is absent; scenario `SC-AK-1833`
- **The owner's last word releases the turn when it begins with a stop word and nothing after it asks to go on.** — `projects/agent-kit/assets/task-flow/measure/owner.mjs:saidStop` — the last word by `words.stop`; `projects/agent-kit/assets/checks/flow-data.mjs:saysStop` — the head word and what holds after it; scenarios `SC-AK-1429`, `SC-AK-1430`, `SC-AK-1431`, `SC-AK-1463`, `SC-AK-1505`, `SC-AK-1556`
- **A session that wrote nothing to the tree releases the turn unless the owner's last word pushes the work on, and a branch outside the scenario releases it always.** — `projects/agent-kit/assets/task-flow/measure/session.mjs:wrote` — an edit or a command of the work; `projects/agent-kit/assets/task-flow/measure/owner.mjs:nudged` — `words.nudge` or a named task; `projects/agent-kit/assets/checks/flow-data.mjs:commandHead` — a command read past the variables and the options of git; scenarios `SC-AK-1432`, `SC-AK-1433`, `SC-AK-1440`, `SC-AK-1465`, `SC-AK-1555`
- **A role session with no edit tool ends with its report.** — `projects/agent-kit/assets/hooks/turn-exit-role.sh:rt_te_read_only_role` — the role header before the engine is called; `projects/agent-kit/assets/task-flow/measure/session.mjs:role` — the same case in the description; scenario `SC-AK-1434`
- **The silent hosting releases the turn only when the measurement itself stopped on the silence.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:SILENCE` — the measurer read from where the measurement stopped; `projects/agent-kit/assets/task-flow/measure/host.mjs:silent` — a read failed twice; scenario `SC-AK-1435`
- **A menu of a refusal that did not reach the owner a second time in a row releases the turn.** — `projects/agent-kit/assets/task-flow/measure/session.mjs:menuLost` — the refusals with the menu and the menus after them; `projects/agent-kit/assets/task-flow/source/session.mjs:eventsOf` — the events of the record; scenario `SC-AK-1444`
- **An engine that fails, runs past its limit or cannot be called releases the turn and writes «движок упал» to the journal.** — `projects/agent-kit/assets/hooks/turn-exit-guard.sh:journal` — the line and its moment; `projects/agent-kit/assets/hooks/dispatch.sh:rt_dispatch_journal` — a branch the dispatcher did not wait for; scenarios `SC-AK-1436`, `SC-AK-1437`, `SC-AK-1438`
- **The eighth refusal in a row is written to the journal.** — `projects/agent-kit/assets/hooks/turn-exit-guard.sh:row` — the count kept until a release; scenario `SC-AK-1439`
- **A service message is no word of the owner.** — `projects/agent-kit/assets/task-flow/source/owner.mjs:wordOf` — a meta entry, a summary of a compaction and a message of a hook are skipped
- **When another check refused the same step twice for the same reason, or the executor stopped again with no call after a refusal, the one move is the owner's menu.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:menuCause` — the cause read from the measurers; `projects/agent-kit/assets/task-flow/measure/session.mjs:forbidden` — the last two refusals of calls by one guard for one reason; `projects/agent-kit/assets/task-flow/measure/session.mjs:idle` — a refusal of a stop with no call after it; scenarios `SC-AK-1442`, `SC-AK-1701`
- **The menu of a refusal carries exactly the options of the description: «отложить RT-N» with the task number and «стоп».** — `projects/agent-kit/assets/checks/flow-verdict.mjs:menuOptions` — `words.menu` with the number of the task put in; scenario `SC-AK-1445`
- **The owner's choice is carried out: a deferral marks the task «отложено» and the next unblocked task is taken; «стоп» releases the turn.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:holdReason` — the refusal names what each option does; `projects/agent-kit/assets/checks/flow-guard.mjs:judgeCall` — the answer of the menu is the owner's word for the mark; `projects/agent-kit/assets/task-flow/measure/epic.mjs:nextTaken` — a deferred task is skipped; scenarios `SC-AK-1443`, `SC-AK-1467`, `SC-AK-1468`
- **The engine measures the copy the session works in, and a worktree copy whose branch does not carry the engine is not judged.** — `projects/agent-kit/assets/hooks/turn-exit-guard.sh:copy_top` — the directory of the hook input and the engine of that copy; `projects/agent-kit/assets/hooks/turn-exit-role.sh:rt_te_read_only_role` — the role of that copy; scenario `SC-AK-1554`
- **The session source names the background tasks of a record: the start of a command or an agent sent to the background, and its end by a notice with a final status or by a call that stops it.** — `projects/agent-kit/assets/task-flow/source/session.mjs:eventsOf` — the events `background`, `backgroundEnd` and `ended`; `projects/agent-kit/assets/task-flow/source/session.mjs:taskOver` — the notice of the record kind `queue-operation`; scenario `SC-AK-1759`
- **A turn that waits for a background task of its own session is released while the task has a start, no end, and is younger than twenty minutes.** — `projects/agent-kit/assets/task-flow/measure/session.mjs:waiting` — a running task not spent yet; `projects/agent-kit/assets/task-flow/measure/session.mjs:BACKGROUND_BOUND` — the bound in minutes; `projects/agent-kit/assets/task-flow/flow.js:background` — the release case and its order; scenarios `SC-AK-1761`, `SC-AK-1762`

# Binding — the CI hold at the end of a turn

A statement of the spec and the place where it is carried out. The link goes by the text of the
statement: a removed statement is removed together with its line.

- **The CI hold is read before the release cases and the menu: a CI run nobody watches or a red run nobody read holds the stop, at the end of the scenario too.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:decide` — the hold first, then the release cases; `projects/agent-kit/assets/checks/flow-verdict.mjs:ciHoldReason` — the run and its ready command; `projects/agent-kit/assets/checks/task-flow-script.mjs:runVerdict` — the verdict before the menu; `projects/agent-kit/assets/task-flow/flow.js:ci` — the measurer declared; scenarios `SC-AK-1801`, `SC-AK-1808`, `SC-AK-1812`
- **The CI hold judges the open PRs whose base wakes the pipeline and whose branch is the current one, the epic branch of the work, or one pushed in this record.** — `projects/agent-kit/assets/task-flow/measure/ci.mjs:hold` — the heads and the bases; `projects/agent-kit/assets/task-flow/measure/ci.mjs:pushedHeads` — `git push` and `--head` of `gh pr create`; scenarios `SC-AK-1806`, `SC-AK-1809`
- **A watch of a CI run is a wait like any other background task of the session.** — `projects/agent-kit/assets/task-flow/measure/session.mjs:running` — every start but a server counts among the running tasks; scenario `SC-AK-1840`
- **A running run holds the stop until an open background task watches it by the hosting client, naming the run, the PR, the branch or the head; the watch lifts the hold, and the release cases decide the turn.** — `projects/agent-kit/assets/task-flow/measure/ci.mjs:watches` — the run, the PR or the head named as a whole word; `projects/agent-kit/assets/task-flow/measure/ci.mjs:openTasks` — the tasks with no end; scenario `SC-AK-1802`
- **A red run holds the stop until a call of the hosting client after its end, neither refused nor failed, names it, or a command or a read takes the output of its watch.** — `projects/agent-kit/assets/task-flow/measure/ci.mjs:wasRead` — the call after `endedAt`; `projects/agent-kit/assets/task-flow/source/session.mjs:eventsOf` — the field `failed`; `projects/agent-kit/assets/task-flow/measure/ci.mjs:NOT_RED` — the conclusions that are no red; scenarios `SC-AK-1803`, `SC-AK-1804`, `SC-AK-1805`, `SC-AK-1811`
- **A head with no run holds the stop for two minutes after the result of its push or the opening of its PR.** — `projects/agent-kit/assets/task-flow/measure/ci.mjs:FRESH_MINUTES` — the bound; `projects/agent-kit/assets/task-flow/measure/ci.mjs:pushedHeads` — the time of the result of the push; scenario `SC-AK-1810`
- **A hosting that does not answer about the CI holds nothing.** — `projects/agent-kit/assets/checks/flow-verdict.mjs:ciHold` — `HostSilent` read as no hold; scenario `SC-AK-1807`
- **The owner's stop word passes a fresh head with no run and nothing else: a running run still asks for its watch, and a red one for its read.** — `projects/agent-kit/assets/task-flow/measure/ci.mjs:hold` — `saidStop` of the owner's source, asked only where the head has no run; scenarios `SC-AK-1912`, `SC-AK-1801`
- **After the mark of Esc the CI hold holds nothing until the owner writes again.** — `projects/agent-kit/assets/task-flow/measure/ci.mjs:hold` — the hold asks `interrupted` of the owner's source first; `projects/agent-kit/assets/task-flow/flow.js:ci` — the measurer declared with the owner; scenario `SC-AK-1839`
- **The host adapter reads the open PRs and the runs of the PR pipeline file on a head past the clock.** — `projects/agent-kit/assets/task-flow/source/host.mjs:pipelineRuns` — the runs of the pipeline file; `projects/agent-kit/assets/task-flow/source/host.mjs:pullRequestBases` — the bases of `pull_request`; scenario `SC-AK-1799`
- **A call event carries its time and the branch of its record entry, and a background event the command of its call.** — `projects/agent-kit/assets/task-flow/source/session.mjs:eventsOf` — the fields `at`, `branch` and `command`; scenario `SC-AK-1800`

# Сценарии — предел длины описания правила

Идентификатор ставится в начало заголовка теста через тире. Пока сценарий не покрыт, он несёт
пометку «Не покрыто» с причиной. Префикс общий на домен: номера продолжают сквозной счёт
`SC-AK`.

### SC-AK-630 — описание длиннее предела названо поимённо

Дано у скила описание в четыреста знаков при пределе в триста
Когда зовут проверку длины описаний
Тогда она отказывает и называет имя скила вместе с числом знаков

Покрыто: `projects/agent-kit/tests/checks-descriptions.test.sh`.

### SC-AK-631 — описание в пределе проверку не тревожит

Дано у скила описание в двести знаков
Когда зовут проверку длины описаний
Тогда она молчит об этом скиле

Покрыто: `projects/agent-kit/tests/checks-descriptions.test.sh`.

### SC-AK-632 — принятый долг проверку не роняет

Дано описание длиннее предела, а имя скила стоит в перечне принятого долга
Когда зовут проверку длины описаний
Тогда она не отказывает, но называет этот скил строкой долга

Покрыто: `projects/agent-kit/tests/checks-descriptions.test.sh`.

### SC-AK-633 — скил без описания проверке не интересен

Дано у скила в шапке нет поля описания
Когда зовут проверку длины описаний
Тогда она проходит его молча

Покрыто: `projects/agent-kit/tests/checks-descriptions.test.sh`.

# Сценарии — граница пакета правил

Идентификатор ставится в начало заголовка теста через тире. Пока сценарий не покрыт, он несёт
пометку «Не покрыто» с причиной. Префикс общий на домен: номера продолжают его нумерацию и
после вливания поддомена не пересчитываются.

### SC-AK-508 — ресурс пакета, заговоривший о приёме, отбивается

Дано в ресурсах пакета лежит текст, называющий приём груза или его админку
Когда гоняется проверка границы
Тогда она краснеет и называет этот ресурс с причиной «предмет есть только у дерева пакета»

### SC-AK-509 — ресурс, зовущийся только в дереве пакета, отбивается

Дано ресурс пакета говорит о себе, что зовётся в репозитории самого пакета
Когда гоняется проверка границы
Тогда она краснеет и называет этот ресурс с причиной «звать его у потребителя некому»

### SC-AK-510 — отправляющая сторона проверку проходит

Дано в пакете лежат форма груза, отправка и команда предложения
Когда гоняется проверка границы
Тогда она молчит о них: потребитель их исполняет

### SC-AK-511 — перечень отменяемого границу не закрывает

Дано ресурс не для везения стоит в перечне отменяемого у этого дерева
Когда гоняется проверка границы
Тогда она всё равно краснеет: перечень снимает раскладку здесь и не снимает везение остальным

### SC-AK-505 — своё правило дерева грузится наравне с пакетным

Дано правило разбора груза переехало в свои правила дерева
Когда правка задевает файл, за который правило отвечает
Тогда гейт правил требует его по своей ветке карты гейта, как и всякое пакетное

### SC-AK-506 — проверка границы входит в гейт пуша

Дано ресурс не для везения вернулся в пакет правкой
Когда идёт пуш ветки
Тогда гейт отбивает пуш отказом проверки границы

### SC-AK-507 — известный долг держится перечнем, а не молчанием проверки

Дано ресурс не для везения ещё лежит в пакете и назван перечнем долга с адресом переезда
Когда гоняется проверка границы
Тогда она печатает его строкой долга и отвечает нулём, а на ресурсе не из перечня краснеет

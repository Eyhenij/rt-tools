# Где это исполняется — граница пакета правил

Ключ связи — сам текст правила. Места названы теми, какими они стали: работа кончилась, и
каждое правило указывает на живой символ.

## Правила и их места

| Правило                                                                      | Где исполняется                                                                                   |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Пакет везёт потребителю только то, что потребитель исполняет.                | `tools/check-boundary.mjs:CARRIED` — судятся ресурсы и код, которые везёт раскладка               |
| Признак «не для везения» — не оценка, а два вопроса к ресурсу.               | `tools/check-boundary.mjs:MARKS` — образцы обоих вопросов и причина отбоя при каждом              |
| Ресурс не для везения живёт своим ресурсом дерева, а не отменяется перечнем. | `tools/check-boundary.mjs:ROOT` — судится состав пакета, а перечень отменяемого не читается вовсе |
| Отправляющая сторона остаётся в пакете целиком.                              | Не исполняется машиной: держится составом ресурсов, который проверка не трогает                   |
| Ресурс, ещё не переехавший, стоит в перечне долга и назван адресом переезда. | `tools/check-boundary.mjs:DEBT` — перечень читается, если лежит рядом; пустой снимается с дерева  |
| Граница держится проверкой, а не чтением.                                    | `.claude/rt-kit/project.sh:rt_push_checks` — проверка стоит в наборе гейта пуша наравне с прочими |
| Своё правило дерева объявляется наравне с пакетным.                          | `.claude/rt-kit/gate-map.sh:skill_for` — своя ветка требует правило дерева на правке его предмета |

## Что здесь своё

Проверка границы — своя проверка этого дерева, а не ресурс пакета: судить ресурсы пакета
чужому дереву нечего. Живёт она там же, где остальные свои проверки, и зовётся тем же способом.

Перечня долга на диске сейчас нет: он опустел, когда переехал последний ресурс, и снят вместе
с эпиком. Чтение его проверка держит по-прежнему — заведённый заново, он снова начнёт держать
известное молча.

Свои правила дерева заведены по образцу пакетных: у них та же форма, компаньон рядом и своя
ветка в карте гейта. К моменту конца эпика своими стали правило разбора груза с паттерном при
нём, обе команды дерева пакета и памятка о правке источника.

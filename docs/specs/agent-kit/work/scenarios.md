# Сценарии — ведение работы командами

Идентификатор ставится в начало заголовка теста через тире. Пока сценарий не покрыт, он несёт
пометку «Не покрыто» с причиной. Префикс общий на домен, и номера при переезде в поддомен не
пересчитывались: номер связывает сценарий с заголовком теста.

### SC-AK-12 — слияние отбивается, пока ветка несёт папку своей задачи

Дано ветка под задачу, и папка её задачи закоммичена в ветку
Когда идёт команда слияния PR
Тогда гард отказывает, называет лежащую папку и то, чем отказ снимается

### SC-AK-13 — разобранная папка слиянию не мешает

Дано ветка под задачу, и папки её задачи в ветке больше нет, а в каталоге архива прибыл файл
Когда идёт команда слияния PR
Тогда гард пропускает

### SC-AK-14 — судится содержимое ветки, а не рабочее дерево

Дано папка задачи снесена в рабочем дереве, но снос не закоммичен
Когда идёт команда слияния PR
Тогда гард отказывает: в главную ветку папка уедет

### SC-AK-15 — снос без записи в архив не проходит

Дано папка задачи снесена в ветке целиком, и в каталоге архива ветка ничего не прибавила
Когда идёт команда слияния PR
Тогда гард отказывает и называет отсутствие записи в архиве

### SC-AK-16 — открытие PR папкой не отбивается

Дано ветка под задачу, и папка её задачи лежит
Когда идёт команда открытия PR
Тогда гард пропускает, а о лежащей папке говорит подсказкой

### SC-AK-17 — обход из текста команды действует без сети

Дано папка задачи лежит в ветке, а в тексте команды слияния стоит строка обхода с причиной
Когда идёт команда слияния PR
Тогда гард пропускает, не спрашивая очередь работ

### SC-AK-18 — обход без причины обходом не считается

Дано папка задачи лежит в ветке, а строка обхода стоит без причины
Когда идёт команда слияния PR
Тогда гард отказывает

### SC-AK-19 — папка старой формы имени находится вложенным каталогом

Дано ветка формы с косой, и папка её задачи лежит вложенным каталогом
Когда идёт команда слияния PR
Тогда гард отказывает и называет вложенный путь целиком

### SC-AK-20 — сверка очереди видит папку закрытой задачи во вложенном каталоге

Дано в каталоге задач лежит вложенная папка старой формы, и задача за ней закрыта
Когда идёт сверка очереди работ
Тогда папка названа расхождением, а образец и черновики разбора — нет

### SC-AK-21 — дерево без каталога задач требования не получает

Дано профиль дерева каталога задач не называет
Когда идёт команда слияния PR
Тогда гард пропускает молча

### SC-AK-59 — незакоммиченная правка останавливает закрытие захода

Дано в рабочем дереве есть незакоммиченная правка
Когда исполнитель зовёт закрытие захода
Тогда ни одна ветка не снимается, дерево остаётся на текущей ветке, а исполнителю называются
незакоммиченные файлы

Не покрыто: команду исполняет агент, и прогоном она не проверяется — проверка идёт вызовом в
дереве.

### SC-AK-60 — работа по правилу с влитым PR возвращает дерево на главную ветку

Дано работа ведётся в ветке под номером задачи, её PR влит, рабочее дерево чистое
Когда исполнитель зовёт закрытие захода
Тогда дерево переходит на главную ветку и подтягивает её из удалённого

Не покрыто: команду исполняет агент, и прогоном она не проверяется — проверка идёт вызовом в
дереве.

### SC-AK-61 — работа вне правила оставляет дерево в своей ветке

Дано работа идёт в ветке, за которой задачи нет, рабочее дерево чистое
Когда исполнитель зовёт закрытие захода
Тогда главная ветка вливается в текущую, а дерево остаётся на ней

Не покрыто: команду исполняет агент, и прогоном она не проверяется — проверка идёт вызовом в
дереве.

### SC-AK-62 — снимаются влитые ветки, невлитая остаётся названной

Дано среди локальных веток есть влитая в главную и есть ветка с коммитами, которых в главной нет
Когда исполнитель зовёт закрытие захода
Тогда влитая снимается, невлитая остаётся, и её имя вместе с числом несвёденных коммитов
называется исполнителю

Не покрыто: команду исполняет агент, и прогоном она не проверяется — проверка идёт вызовом в
дереве.

### SC-AK-63 — мёртвые отслеживания снимаются тем же вызовом

Дано в дереве есть ссылка на удалённую ветку, которой в удалённом больше нет
Когда исполнитель зовёт закрытие захода
Тогда ссылка снимается вместе с остальной уборкой

Не покрыто: команду исполняет агент, и прогоном она не проверяется — проверка идёт вызовом в
дереве.

### SC-AK-64 — передача пишется последней и лежит вне дерева

Дано закрытие захода дошло до записи передачи
Когда команда её пишет
Тогда файл ложится в каталог передачи из профиля дерева, одним файлом на ветку, в историю не
попадает, а путь к нему называется исполнителю последней строкой

Не покрыто: команду исполняет агент, и прогоном она не проверяется — проверка идёт вызовом в
дереве.

### SC-AK-152 — заведение кончается ответом очереди работ

Дано задача заведена и стоит в очереди работ с колонкой и исполнителем
Когда команда заведения складывает свой вывод
Тогда она называет колонку и исполнителя и кончается нулевым кодом

Покрыто: `projects/agent-kit/tests/checks-config.test.sh`.

### SC-AK-153 — задача вне очереди работ кончает команду отказом

Дано задача заведена, а в очереди работ её нет
Когда команда заведения складывает свой вывод
Тогда она называет отсутствие отдельной строкой и кончается ненулевым кодом

Покрыто: `projects/agent-kit/tests/checks-config.test.sh`.

### SC-AK-154 — задача без исполнителя названа отдельно

Дано задача стоит в очереди работ, но исполнителя у неё нет
Когда команда заведения складывает свой вывод
Тогда она называет это отдельной строкой и кончается ненулевым кодом

Покрыто: `projects/agent-kit/tests/checks-config.test.sh`.

### SC-AK-155 — неспрошенная очередь подтверждением не считается

Дано очередь работ спросить не удалось
Когда команда заведения складывает свой вывод

### SC-AK-194 — упоминание обхода посреди строки обходом не считается

Дано команда слияния несёт слова об обходе, но строку он не начинает
Когда идёт вызов слияния при лежащей папке задачи
Тогда гард отбивает: текст, называющий обход, обходом не является

Покрыто: `projects/agent-kit/tests/git-guards.test.sh`.

### SC-AK-195 — подстановка вместо причины обходом не считается

Дано строка обхода стоит верно, а причина у неё записана подстановкой в угловых скобках
Когда идёт вызов слияния при лежащей папке задачи
Тогда гард отбивает: подстановка причиной не бывает

Покрыто: `projects/agent-kit/tests/git-guards.test.sh`.

### SC-AK-277 — вершина открытого PR без прогона названа расхождением

Дано открытый PR, на вершине которого не завёлся ни один прогон, а лежит она дольше отпущенного
Когда идёт сверка очереди работ
Тогда она называет вершину, её возраст и то, чем событие возвращается, и кончается ненулевым
кодом

Покрыто: `projects/agent-kit/tests/checks-board.test.sh`.

### SC-AK-278 — свежая вершина без прогона не судится

Когда идёт сверка очереди работ

Покрыто: `projects/agent-kit/tests/checks-board.test.sh`.

### SC-AK-279 — прогон на вершине снимает вопрос

Дано открытый PR, на вершине которого прогон есть
Когда идёт сверка очереди работ
Тогда она молчит о нём, каким бы ни был его цвет

Покрыто: `projects/agent-kit/tests/checks-board.test.sh`.

### SC-AK-280 — дерево без файла конвейера прогонов не спрашивает

Дано дерево, у которого названного файла конвейера нет, и открытый PR без прогона на вершине

### SC-AK-341 — черновик у PR без разбора не снимается

Дано у PR нет ни запрошенного ревьювера, ни оставленного отзыва
Когда снимается черновик — любым из клиентов хостинга
Тогда снятие отбито, названы номер PR и нехватка разбора; чтение того же PR снятием не считается

Покрыто: `projects/agent-kit/tests/git-guards-readiness.test.sh`.

### SC-AK-344 — состояние PR называет его разбор

Когда спрашивается состояние PR
Тогда PR найден, разбор у него есть, и в списке стоят оба — и запрошенный, и оставивший отзыв

Покрыто: `projects/agent-kit/tests/checks-board.test.sh`.

### SC-AK-345 — разбор автора разбором не считается

Дано единственный, кто назван при PR, — его же автор
Когда спрашивается состояние PR

отвечает отсутствием

# Чем исполняется — уход с route-панели

Первая колонка — правило спека рядом дословно. Вторая — где оно исполняется в дереве; там же
назван сценарий, которым это проверяется, а чем именно покрыт каждый сценарий, сказано в
`scenarios.md`.

Правило без строки и строка без правила — расхождение: спек обещает то, чего в дереве нет, либо
в дереве стоит то, о чём спек молчит.

| Правило | Где исполняется |
| ------- | --------------- |
| Панель, начавшая уход сама, о правках не спрашивает.                                             | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts:canDeactivate` читает разрешение до намерения; сценарий `SC-UKV-21`                                                                                                                                                                                                   |
| Разрешение выдаётся в одной точке — перед тем, как панель зовёт роутер.                          | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts:navigateAllowed` — единственная точка, через неё идут `#navigateAway` и `#navigateRelated`; сценарий `SC-UKV-23`                                                                                                                                                      |
| Разрешение действует ровно на один уход и не переживает навигацию, которая не состоялась.        | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts:consumeLeaveAllowance`, снятие по итогу обещания в `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts:navigateAllowed`; сценарии `SC-UKV-22`, `SC-UKV-25`                                                                                        |
| О правках спрашивают панель, учтённую под маршрутом ухода.                                       | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.registry.ts:find`, `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.guard.ts:rtAsideUnsavedGuard`; сценарии `SC-UKV-24`, `SC-UKV-28`                                                                                                                           |
| Панель, которой на учёте нет, но которая умеет ответить о правках, спрашивается всё равно.       | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.guard.ts:fallbackPanel`; сценарий `SC-UKV-30`                                                                                                                                                                                                                                 |
| Ответ о правках не зависит от того, есть ли у промежуточного маршрута компонент.                 | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.registry.ts:register` ключует запись объявлением маршрута, `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.guard.ts:rtAsideUnsavedGuard` спрашивает по нему; сценарий `SC-UKV-24`                                                                             |
| Компонент, не умеющий ответить о правках, уход не роняет.                                        | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.guard.ts:fallbackPanel`; сценарий `SC-UKV-26`                                                                                                                                                                                                                                 |
| Ответ панели, который отказал, уход отменяет и снимает панель с учёта.                           | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.guard.ts:rtAsideUnsavedGuard` — `defer` и `catchError`, `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.registry.ts:forget`; сценарий `SC-UKV-31`                                                                                                             |
| Панель отвечает о правках, пока она на экране, и перестаёт отвечать после того, как ушла.        | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts` — постановка в эффекте открытия панели, снятие на `DestroyRef`; `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.registry.ts:register`, `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.registry.ts:unregister`; сценарий `SC-UKV-27` |
| Уход, которого панель не начинала, о правках спрашивает — откуда бы он ни пришёл.                | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts:canDeactivate`; сценарии `SC-UKV-29`, `SC-UKV-34`                                                                                                                                                                                                                     |
| Уход, пришедший во второй раз, пока открыто окно о правках, второго окна не открывает.           | `projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.ts:askUnsaved`; сценарий `SC-UKV-32`                                                                                                                                                                                                                                     |

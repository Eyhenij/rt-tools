# What it is carried out by — the KPI block of the assistant chat

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **`kpi` is a type the kit draws itself, next to `markdown`, `notice` and `table`; an application gets it without registering anything, and a renderer registered for `kpi` is not taken.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:OWN_TYPES`, `toBlockViews`; scenario `SC-UKV-1436`
- **A KPI block has `items`, a list of cards.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.model.ts:KpiBlock`; `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiItem`; scenarios `SC-UKV-1444`, `SC-UKV-1476`
- **A KPI block whose `items` is not a list, or holds no card left after the rules below, is shown as the plate with its type name, like a table block without columns.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiItems` gives `null`, and `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:kpiBlockItems` leaves `toBlockViews` the kind `unsupported`; scenarios `SC-UKV-1447`, `SC-UKV-1482`
- **An item that is not an object, has no label, or has no value is dropped; the other cards stay in their order.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiItem`, `rtKpiItems`; scenario `SC-UKV-1444`
- **A malformed optional part of a card is absent, not refused.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiItem`; scenario `SC-UKV-1445`
- **An item of a format the kit does not know, or with no format, is written as `number`.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:kpiFormat`; scenario `SC-UKV-1446`
- **The block draws every card it is given; the kit sets no cap on the number of cards.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:cards`; scenario `SC-UKV-1460`
- **A new `block` input of the same block instance redraws the cards.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:cards` is computed from the input `items`; scenario `SC-UKV-1463`
- **The kit exports the JSON schema of the KPI block (JSON Schema 2020-12), so that an application gives it to the model as the parameters of a tool.** — `projects/ui-kit-v2/src/lib/util/kpi.schema.ts:RT_AI_CHAT_KPI_SCHEMA`; scenario `SC-UKV-1483`
- **A block the schema accepts is drawn with nothing dropped or emptied.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiItems`; scenario `SC-UKV-1459`
- **A number value is written by the rules of a number cell of the table block.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiValueWriter` takes the cell writer `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter` for the column of `COLUMN_OF_FORMAT`; scenario `SC-UKV-1440`
- **A `number` or `currency` value of a million and more, by its absolute value, is written in the short form of the kit locale.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiValueWriter`, `SHORT_FROM`, `SHORT_SIGNIFICANT_DIGITS`; scenarios `SC-UKV-1441`, `SC-UKV-1484`
- **A `number` or `currency` value from 100 000 to below a million, by its absolute value, is written in full without fraction digits.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:WHOLE_FROM`, `rounded`; scenario `SC-UKV-1484`
- **The number of a value always fits one line of a card 160 wide; the unit may not.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiValueWriter` caps the number by `WHOLE_FROM` and `SHORT_SIGNIFICANT_DIGITS`; scenario `SC-UKV-1484`
- **A value wider than its row at 24 px is drawn at 20 px, and wider still at 18 px.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.fit.ts:rtStatTileValueFit`, `rtStatTileFitStep`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:rt-stat-tile__value--fit--smaller`; scenario `SC-UKV-1485`
- **The space between a written number and its unit is an ordinary one, on either side of the number and for the digits of any locale; the spaces between digit groups stay non-breaking.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:breakAtUnit`; scenario `SC-UKV-1484`
- **A `currency` item whose code is missing or is not three Latin upper-case letters writes its value as `number`.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCurrency`, called by `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiValueWriter`; scenario `SC-UKV-1442`
- **A string value is written as given; the kit does not read a number out of a string.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiValueWriter`; scenario `SC-UKV-1443`
- **A minus of a value is the one `Intl.NumberFormat` writes for the locale, and the value is not coloured.** — `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiValueWriter` gives the text of the cell only, without its negative mark; scenario `SC-UKV-1441`
- **Values and deltas are written for the locale of the kit labels; a locale `Intl.NumberFormat` refuses writes them as `en`.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableNumberFormat`; `projects/ui-kit-v2/src/lib/util/delta-number.ts:deltaFormat`; scenario `SC-UKV-1477`
- **A drawn block follows a change of the kit label locale: its values and deltas are written anew.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:#locale` is read by `cards`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:#locale`; scenario `SC-UKV-1452`
- **`delta` is the change in percent, as the tile reads it: 12.5 is «+12,5 %», -4 is «-4 %».** — `projects/ui-kit-v2/src/lib/util/delta-number.ts:asFraction`; `projects/ui-kit-v2/src/lib/util/kpi-data.ts:rtKpiItem` reads `deltaUnit`; scenarios `SC-UKV-1449`, `SC-UKV-1476`
- **The delta number carries a plus on growth, the locale minus on a fall and no sign at zero.** — `projects/ui-kit-v2/src/lib/util/delta-number.ts:DELTA_OPTIONS`, `rtDeltaNumber`; scenario `SC-UKV-1449`
- **The colour of the delta follows the theme state tokens: with `growthIsGood` true growth is the success colour and a fall the danger colour; with `growthIsGood` false the two swap; a zero delta is muted.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:card` maps `growthIsGood` to `growthIsWorse`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:growth-worse`; scenarios `SC-UKV-1448`, `SC-UKV-1449`
- **The arrow shows the sign of the delta whatever `growthIsGood` says: up on growth, down on a fall, flat at zero.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:DIRECTION_ICONS`; `projects/ui-kit-v2/src/lib/util/delta-number.ts:rtDeltaNumber`; scenario `SC-UKV-1448`
- **A card without a delta draws no delta line and no base caption; its value, label and period stay.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:card` gives the delta `null`; scenario `SC-UKV-1450`
- **The base caption stands after the delta number in the delta line, visible, in 12 Regular muted text; a delta without a `base` stands alone.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.html:deltaLabelVisible`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:primaryCaption`; scenario `SC-UKV-1451`
- **The delta line of a card shows one base; the kit draws no second delta (no «YoY» chip) and no «was …» line in a KPI card.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:card` gives no year delta and no `baseline`; scenario `SC-UKV-1478`
- **A card is a compact `rt-stat-tile` framed by the block, and the frame takes kit tokens only.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.scss:__card`; scenarios `SC-UKV-1475`, `SC-UKV-1464`
- **The card label is 14 SemiBold, the value 24/24 Bold, the delta 14 Bold, the base caption and the period 12 Regular muted.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:compact`, `__caption`; scenario `SC-UKV-1454`
- **The cards stand in a grid with a gap of 8, `--rt-space-2`: one column while the block is narrower than 328, two from 328, four from 664.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.scss:__grid`; scenarios `SC-UKV-1437`, `SC-UKV-1438`, `SC-UKV-1439`, `SC-UKV-1472`, `SC-UKV-1473`
- **The columns of the grid are equal, and a last row with fewer cards keeps the column width; its cards are not stretched.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.scss:minmax`; scenario `SC-UKV-1460`
- **The frames of one row stand on one top and are as high as the tallest of the row; the period stands at the bottom of its frame.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.scss:__card`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:__secondary`; scenario `SC-UKV-1464`
- **No text goes past its card.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:overflow-wrap`; scenario `SC-UKV-1461`
- **Under `dir="rtl"` the order of the cards in the grid and the delta line mirror, while a written value and a delta number keep their own order.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.html:bdi`; scenario `SC-UKV-1474`
- **The block takes the width of the answer and never widens the feed.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.scss:container-type`; scenario `SC-UKV-1479`
- **The answer copy gives a KPI block as one line per card, joined by LF, in the order of the cards.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:kpiPlainText`, called by `blockText`; scenarios `SC-UKV-1457`, `SC-UKV-1481`
- **A card line holds the label, the value, the delta with its base caption and the period, separated by a tab; an absent part is an empty field.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:kpiPlainText`, `kpiDelta`; scenario `SC-UKV-1457`
- **A dropped item gives no line, and a tab or a line break inside a text becomes a space.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:copyField`; scenarios `SC-UKV-1458`, `SC-UKV-1480`
- **The block is a list whose items are the cards, so a screen reader announces how many cards there are.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.html:role`; scenario `SC-UKV-1462`
- **The arrow of the delta is hidden from a screen reader; the sign of the number tells the direction.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.html:aria-hidden`; scenario `SC-UKV-1462`
- **The block has no fixed text of its own and adds no kit label.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:RtAiChatKpiComponent` injects the kit locale only, no kit labels; scenario `SC-UKV-1462`

## Tokens the frame and the compact size take

`--rt-color-border-default` and `--rt-color-bg-surface` are declared in
`projects/ui-kit-v2/src/styles/tokens.light-color.mjs` with their dark values; the steps
`--rt-space-0-5`, `--rt-space-1`, `--rt-space-2`, `--rt-radius-sm` and `--rt-radius-md` in
`projects/ui-kit-v2/src/styles/tokens.scale-metrics.mjs`. 12 is `--rt-space-2` plus `--rt-space-1`,
6 is `--rt-space-1` plus `--rt-space-0-5`, the radius 12 is `--rt-radius-md` plus `--rt-radius-sm`.

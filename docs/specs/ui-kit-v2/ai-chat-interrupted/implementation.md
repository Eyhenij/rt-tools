# What it is carried out by — the interrupted answer of the assistant chat

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by. Scenarios `SC-UKV-1576`, `SC-UKV-1577` and
`SC-UKV-1580` are not covered by a test: the layout comes from the styles, and the play steps of
the showcase stories `Widths`, `Rtl` and `Themes` hold it.

- **An assistant message has the optional field `interrupted`; `true` makes the answer interrupted, and an absent field or `false` draws the answer as before.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.model.ts:AssistantMessage`, `interrupted`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isInterrupted`; scenarios `SC-UKV-1563`, `SC-UKV-1566`
- **The kit does not set the flag, does not derive it from the run state and does not clear it.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isInterrupted` reads the flag of the message alone; scenario `SC-UKV-1566`
- **The label is drawn whatever the run state, `running` included.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isInterrupted`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:ai-chat-run`, `ai-chat-interrupted`; scenario `SC-UKV-1578`
- **While `streaming` is `true`, an interrupted answer draws neither the label nor the action; they appear once `streaming` is no longer `true`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isInterrupted`; scenario `SC-UKV-1569`
- **An interrupted answer draws the interrupted label under its blocks and its attachments, and the action in the row of «Copy» and the rating under the label.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:ai-chat-interrupted`, `ai-chat-feedback`, `ai-chat-ask-again`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.scss:rt-space-sm`; scenario `SC-UKV-1563`
- **A partial answer draws its blocks as given, the label under them and the action in its row of actions.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:rt-ai-chat-blocks`, `ai-chat-interrupted`, `ai-chat-ask-again`; scenario `SC-UKV-1563`
- **An empty interrupted answer draws the run line when it has one, then the consumer's attachments, then the label, then a row with the action alone.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:rt-ai-run-status`, `ngTemplateOutlet`, `ai-chat-interrupted`, `ai-chat-feedback`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isWritten`, `isInterrupted`; scenarios `SC-UKV-1564`, `SC-UKV-1565`
- **The label is a quiet line: muted 12 px text with a line of 135%, with no icon, no strip and no plate.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.scss:rt-color-text-muted`, `rt-text-xs`, `rt-leading-snug`; showcase stories `Cases`, `Themes`
- **The action is the kit icon button of the row of «Copy» and the rating, with the icon `sync`: the same size, colour and gap of 4.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:rt-icon-button`, `sync`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.scss:rt-space-xs`; scenario `SC-UKV-1563`
- **The action shows the tooltip «Ask again» on hover and on focus from the keyboard, as the other buttons of the row show theirs.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:tooltip`; `projects/ui-kit-v2/src/lib/components/icon-button/rt-icon-button.component.html:rtTooltip`; showcase story `States`; scenario `SC-UKV-1574`
- **The action shows the kit hover fill, the kit focus ring and the kit disabled look of the icon button; the focus ring is not clipped.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:rt-icon-button`, `disabled`; showcase stories `States`, `Widths`; `SC-UKV-1576`
- **The label «Answer interrupted» is a new kit label; the name and the tooltip of the action are the existing kit label of «Ask again».** — `projects/ui-kit-v2/src/lib/i18n/rt-kit-labels.en.ts:aiInterrupted`, `aiRetry`; `projects/ui-kit-v2/.storybook/showcase-labels.ru.ts:aiInterrupted`, `aiRetry`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:aiInterrupted`, `aiRetry`; scenario `SC-UKV-1575`
- **A press on the action makes `rt-ai-chat` emit `askAgain` with the id of that answer.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:askAgain`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html:askAgain`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:askAgain`; scenarios `SC-UKV-1567`, `SC-UKV-1573`
- **The chat emits `askAgain` on every press; the kit does not merge repeated presses, does not change the answer and does not hide the action.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:clicked`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html:askAgain`; scenario `SC-UKV-1567`
- **While the chat input `sending` is `true`, the action is disabled natively and a press emits nothing.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:sending`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html:sending`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:sending`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:disabled`; scenario `SC-UKV-1568`
- **A press on the action emits neither `retry` nor `send`, and the kit sends no question by itself.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html:askAgain`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:askAgain`, `retry`, `send`; scenarios `SC-UKV-1567`, `SC-UKV-1572`
- **The input `error` and the output `retry` of the chat keep their shape and behaviour: `retry` carries no id, the error strip stands under the feed and describes the last run only.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:error`, `retry`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html:ai-chat-error`, `ai-chat-retry`; `SC-UKV-1572`
- **The flag of an answer and the run error are independent: the kit draws both when both are given, and each action emits its own output.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html:askAgain`, `retry`; scenario `SC-UKV-1572`
- **A partial answer keeps «Copy» and the rating by the rules of the chat: they appear once the answer is no longer written.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isWritten`, `canCopy`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:ai-chat-like`, `ai-chat-dislike`; scenarios `SC-UKV-1570`, `SC-UKV-1579`
- **The copy of a partial answer is the text of its blocks, as for any answer; the interrupted label and «Ask again» do not go into the copy.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:plainText`; scenario `SC-UKV-1571`
- **An empty interrupted answer shows neither «Copy» nor the rating.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:isWritten`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.html:ai-chat-feedback`; scenario `SC-UKV-1564`

in the tree, with the handle name as the symbol, and the scenario it is checked by.

## The showcase

Three stories stand in `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/stories/`:
**Properties** (the default cell and the font, header, suggestion, author and background cells),
**Properties · focus** (the prompt box focused, Send and Stop hovered, a chosen like) and
**Properties · row actions** (rows with `threadMenu` on and off, the row with the unread badge
hovered, its time hidden on request). The former stories of the family keep their references.

## The tests

The defaults, the part declarations, the pass-downs and the reads with no fallback are asked of the
compiled CSS in `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.theme-tokens.spec.ts`,
next to the existing `rt-ai-chat.styles.spec.ts`; the same file holds the test of `SC-UKV-1597`,
which reads the CSS the three stories set. The test of `questionAuthor` lives in
`projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.question-author.spec.ts`:
the component spec is at its length limit.

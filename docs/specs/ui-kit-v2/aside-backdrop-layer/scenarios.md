# Сценарии — подложка панели и слои оформления

Префикс `SC-UKV`, общий на домен вместе с поддоменами.

Чем покрыт сценарий, сказано под ним. Где прогон сценарий не покрывает, это сказано прямо.

### SC-UKV-84 — закрытая подложка невидима и нажатий не ловит у потребителя со слоями

Дано стили кита взяты слоями, а библиотека оверлеев объявила свои правила подложки вне слоя
Когда каркас создал оверлей панели и держит его закрытым
Тогда подложка прозрачна и нажатий не ловит: её правила видимости объявлены вне слоя и
неслоевому правилу библиотеки не проигрывают

Покрыто: `projects/ui-kit-v2/src/lib/components/aside/rt-aside-overlay.styles.spec.ts`.

### SC-UKV-85 — закрытая панель нажатий не ловит

Дано панель шириной во весь экран, её сдвиг за край ещё не досчитан
Когда пользователь нажимает по странице
Тогда нажатие доходит до страницы: правило нажатий закрытой панели объявлено вне слоя

Покрыто: `projects/ui-kit-v2/src/lib/components/aside/rt-aside-overlay.styles.spec.ts`.

### SC-UKV-86 — оформление подложки остаётся переопределяемым

Дано приложение объявило свои цвет и размытие подложки
Когда панель открыта
Тогда подложка берёт значения приложения: цвет, размытие и переход объявлены в слое кита

Покрыто: `projects/ui-kit-v2/src/lib/components/aside/rt-aside-overlay.styles.spec.ts`.

# Сценарии — полоса прокрутки

### SC-UKV-88 — место под полосу занято и в покое, и при наведении

Дано зона прокрутки с содержимым длиннее её самой
Когда на зону наводят указатель
Тогда ширина её клиентской области не меняется ни на пиксель

Покрыто: замером на витрине — `docs/specs/ui-kit-v2/scrollbar/implementation.md`.

### SC-UKV-89 — в покое ползунок невидим, при наведении виден

Дано зона прокрутки в покое
Когда на зону наводят указатель
Тогда цвет ползунка меняется с прозрачного на цвет рамки

Покрыто: замером на витрине — `docs/specs/ui-kit-v2/scrollbar/implementation.md`.

### SC-UKV-90 — фокус внутри зоны показывает полосу наравне с наведением

Дано внутри зоны есть элемент, принимающий фокус
Когда фокус попадает внутрь зоны
Тогда ползунок виден так же, как при наведении

Покрыто: замером на витрине — `docs/specs/ui-kit-v2/scrollbar/implementation.md`.

### SC-UKV-91 — там, где наведения не бывает, ползунок виден всегда

Дано указатель грубый — сенсорный экран
Когда зона прокрутки в покое
Тогда ползунок виден

Покрыто: замером на витрине — `docs/specs/ui-kit-v2/scrollbar/implementation.md`.

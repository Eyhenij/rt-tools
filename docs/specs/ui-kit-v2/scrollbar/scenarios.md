# Сценарии — полоса прокрутки

### SC-UKV-88 — место под полосу занято и в покое, и при наведении

Дано зона прокрутки с содержимым длиннее её самой
Когда на зону наводят указатель
Тогда ширина её клиентской области не меняется ни на пиксель

Не покрыто: тестом это не закрыть — полосу прокрутки рисует браузер, а в среде спек её не рисует
ничто: ни ширины, ни цвета ползунка там не существует. Проверено на месте — замером драйвером на
собранной витрине, числа названы в описании прошлого работы.

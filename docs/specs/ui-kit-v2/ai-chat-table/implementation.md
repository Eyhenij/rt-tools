# What it is carried out by — the table block of the assistant chat

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **`table` is a type the kit draws itself, next to `markdown` and `notice`; an application gets it without registering anything, and a renderer registered for `table` is not taken.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:OWN_TYPES`, `toBlockViews`; scenario `SC-UKV-1396`
- **A table block has `columns`, `rows`, an optional `total` and an optional `title`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:tableBlockData`; scenarios `SC-UKV-1402`, `SC-UKV-1433`
- **A table block whose `columns` is not a non-empty list, or whose `rows` is not a list, is shown as the plate with its type name, like a markdown block without text.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:tableBlockData` gives `null`, and `toBlockViews` gives the kind `unsupported`; scenario `SC-UKV-1405`
- **A malformed part of a valid block is dropped or emptied, not refused.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableColumn`, `rtTableValue`, `rtTableFitRow`; scenario `SC-UKV-1402`
- **A column of a type the kit does not know, or with no type, is a `text` column.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableColumn`; scenario `SC-UKV-1403`
- **A row shorter than the columns gets empty cells at its end; the values of a longer row past the last column are dropped. The total row follows the same rule.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableFitRow`; scenario `SC-UKV-1402`
- **A `total` that is `null`, an empty list or a row whose every cell is empty after fitting is absent: no `tfoot`, no line in the CSV and none in the answer copy.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableTotal`; scenario `SC-UKV-1424`
- **A block with an empty `rows` draws the head row and, if present, the total row; «Copy CSV» stays.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.html:head`; the template draws the head and the `tfoot` for an empty `rows`; scenario `SC-UKV-1404`
- **The block draws every row it is given; the kit sets no cap on the number of rows.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:rows`; scenario `SC-UKV-1432`
- **A new `block` input of the same block instance redraws the table and keeps the scroll position of the scroll box and the «Copied» state.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:copied`; the scroll box element lives with the instance, not the input; scenario `SC-UKV-1429`
- **«Copy CSV» stands while the answer is written and copies the rows drawn at the moment of the press.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:onCopy`; scenario `SC-UKV-1430`
- **The kit exports the JSON schema of the table block (JSON Schema 2020-12), so that an application gives it to the model as the parameters of a tool.** — `projects/ui-kit-v2/src/lib/util/table.schema.ts:RT_AI_CHAT_TABLE_SCHEMA`; scenario `SC-UKV-1433`
- **A block the schema accepts is drawn with nothing dropped or emptied.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableData`; scenario `SC-UKV-1433`
- **A number column writes a number value by `Intl.NumberFormat`.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter`; scenario `SC-UKV-1398`
- **Values are written for the locale of the kit labels; a locale `Intl.NumberFormat` refuses writes them as `en`.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter` falls back to `en` when `Intl.NumberFormat` throws; scenario `SC-UKV-1427`
- **A `currency` column whose code is missing or is not three Latin upper-case letters writes its values as `number`.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter`; scenario `SC-UKV-1399`
- **A value that is not a number in a number column is written as given, aligned as the column, and never coloured; the kit does not read a number out of a string.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter`; scenario `SC-UKV-1401`
- **`null` and a missing value give an empty cell, and so do `NaN` and an infinity; zero is written as a zero.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter`; scenario `SC-UKV-1428`
- **A `text` column writes a value as given; a number in it is written as its plain digits, not formatted.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter`; scenario `SC-UKV-1403`
- **The minus is the one `Intl.NumberFormat` writes for the locale; the kit adds no sign and no spacing of its own.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter` takes the minus sign from `formatToParts`; scenario `SC-UKV-1400`
- **A value whose written form is zero, such as -0.001 in a `number` column, is written without a minus and is not coloured.** — `projects/ui-kit-v2/src/lib/util/table-data.ts:rtTableCellWriter`; scenario `SC-UKV-1428`
- **A number value whose written form is below zero, in a number column and the total row included, is written in the error text colour of the theme (`--rt-color-state-error-text`); other values keep the text colour.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.scss:__cell` with the modifier `--negative`; scenario `SC-UKV-1400`
- **A drawn table follows a change of the kit label locale: its values are written anew for the new locale.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:#writers` reads `RT_KIT_LOCALE`; scenario `SC-UKV-1415`
- **Number columns are aligned to the end and `text` columns to the start; a head cell is aligned as its column, and under `dir="rtl"` both mirror.** — `projects/ui-kit-v2/src/styles/_mixins.scss:chat-table-cell-end`; the value of a number column stands in `bdi` in `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.html`; scenario `SC-UKV-1397`
- **A number column is as wide as its widest value, the head included, and a value in it never wraps.** — `projects/ui-kit-v2/src/styles/_mixins.scss:chat-table-cell-end`; scenario `SC-UKV-1409`
- **The first `text` column takes the width left over; other `text` columns are as wide as their content allows, and every `text` cell wraps between words, never inside a word.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:fitsContent`; `projects/ui-kit-v2/src/styles/_mixins.scss:chat-table-cell`; scenarios `SC-UKV-1409`, `SC-UKV-1422`
- **A table wider than the block scrolls sideways inside the scroll box; the block and the feed keep their width.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.scss:__scroll`; scenario `SC-UKV-1407`
- **The scroll box is 200 high at most; a taller table scrolls down inside it, and the head row stays on the top of the box while the rows scroll under it.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.scss:__scroll`; `projects/ui-kit-v2/src/styles/_mixins.scss:chat-table-head-cell`; scenario `SC-UKV-1408`
- **The total row stands after the last row, semibold, with a top border of the default border colour (`--rt-color-border-default`), and scrolls with the rows.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.scss:__row` with the modifier `--total` and the block property `--rt-ai-chat-table-total-border-width`; scenario `SC-UKV-1406`
- **A `title` given as a non-empty string stands above the table in the 14 px semibold primary text, as the chart title; it names the scroll box in place of «Table», opens the answer copy on a line of its own and stays out of the CSV.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:label`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:tableTitle`; scenario `SC-UKV-1435`
- **The table has a top border of the subtle border colour, and every row a bottom one.** — `projects/ui-kit-v2/src/styles/_mixins.scss:chat-table`; scenario `SC-UKV-1425`
- **Rows are at least 28 high, and a row whose text wraps grows with it.** — `projects/ui-kit-v2/src/styles/_mixins.scss:chat-table-cell`; scenario `SC-UKV-1425`
- **The data table under the chart block takes the same look: rows, padding, head row and number column widths.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.scss:kv`; the chart cells take the mixins `chat-table-cell` and `chat-table-head-cell`; scenario `SC-UKV-1434`
- **«Copy CSV» puts the head, the rows and the total row into the clipboard as CSV: values separated by commas, lines by CRLF, under every locale.** — `projects/ui-kit-v2/src/lib/util/table-csv.ts:rtTableCsv`; scenario `SC-UKV-1411`
- **Every string value and every head label is a CSV text field, whatever the type of its column.** — `projects/ui-kit-v2/src/lib/util/table-csv.ts:rtTableCsv`; scenario `SC-UKV-1410`
- **A CSV field holding a comma, a double quote, a CR or an LF is wrapped in double quotes, and a double quote inside it is doubled; other fields stand bare.** — `projects/ui-kit-v2/src/lib/util/table-csv.ts:rtTableCsv`; scenario `SC-UKV-1410`
- **A number value in the CSV is written as `String(value)`: a dot, no grouping, no currency sign and no percent sign.** — `projects/ui-kit-v2/src/lib/util/table-csv.ts:rtTableCsv`; scenarios `SC-UKV-1411`, `SC-UKV-1428`
- **A CSV text field that starts with `=`, `+`, `-`, `@`, a tab or a CR gets an apostrophe in front; a number is never prefixed.** — `projects/ui-kit-v2/src/lib/util/table-csv.ts:rtTableCsv`; scenario `SC-UKV-1421`
- **After a successful copy the button shows «Copied» with a check for two seconds and then returns to «Copy CSV»; a refused copy leaves «Copy CSV» as it was.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:onCopy`, `status`; scenarios `SC-UKV-1412`, `SC-UKV-1413`
- **A press while «Copied» shows copies again and starts the two seconds anew; a locale change shows «Copied» in the new language and does not restart them.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.ts:onCopy`, `actionLabel`; scenario `SC-UKV-1431`
- **The answer copy gives a table block as tab-separated lines joined by LF, as the markdown table copy does: the head, the rows, the total row.** — `projects/ui-kit-v2/src/lib/util/table-csv.ts:rtTablePlainText`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.ts:plainText` passes the kit locale; scenarios `SC-UKV-1414`, `SC-UKV-1423`
- **A markdown table reads its divider row.** — `projects/ui-kit-v2/src/lib/util/markdown-parse.ts:columnAlign`, `readTable`; scenario `SC-UKV-1416`
- **A markdown table takes the look of the table block, with no maximum height and no sticky head; its column widths are the browser's.** — `projects/ui-kit-v2/src/lib/components/markdown-text/rt-markdown-text.component.ts:align`; the styles take the mixins of `projects/ui-kit-v2/src/styles/_mixins.scss`; scenario `SC-UKV-1417`
- **A markdown table detects no type by content: its cells stay inline nodes, no value is formatted or coloured, and it has no total row and no «Copy CSV».** — `projects/ui-kit-v2/src/lib/components/markdown-text/rt-markdown-text.component.ts:align`; the template draws inline nodes only; scenario `SC-UKV-1417`
- **A markdown row shorter than the head gets empty cells at its end, and cells past the head are dropped; the answer copy of a markdown table carries the fitted rows.** — `projects/ui-kit-v2/src/lib/util/markdown-parse.ts:fitCells`; scenario `SC-UKV-1418`
- **The table block is a `<table>` with `thead`, `tbody` and, for the total row, `tfoot`; head cells are `th` with `scope="col"`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.html:scope`; scenario `SC-UKV-1419`
- **The head cells of a markdown table are `th` with `scope="col"`.** — `projects/ui-kit-v2/src/lib/components/markdown-text/rt-markdown-text.component.html:scope`; scenario `SC-UKV-1419`
- **The scroll box of the block and the scroll box of a markdown table are reachable by Tab, named «Table», and scroll by the arrow keys.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.html:tabindex`; `projects/ui-kit-v2/src/lib/components/markdown-text/rt-markdown-text.component.ts:tableLabel`; scenario `SC-UKV-1419`
- **«Copy CSV» is a button whose accessible name is its visible text; «Copied» is announced politely, as a status.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/table/rt-ai-chat-table.component.html:aria-label`, `aria-live`; scenarios `SC-UKV-1412`, `SC-UKV-1419`
- **Every fixed text of the block — «Copy CSV», «Copied», «Table» — is a kit label in the `rtKit` namespace, English in the package.** — `projects/ui-kit-v2/src/lib/i18n/rt-kit-labels.en.ts:aiTableCopyCsv`, `aiTableLabel`; scenario `SC-UKV-1412`

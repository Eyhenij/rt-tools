# Панель раздела: закрепление и поиск

**Статус:** предложено · **Ревизия:** 2026-08-31 · **Префикс сценариев:** `SC-UKV`
**Зависимости:** нет
**Законы:** `frontend-application`, `navigation`, `reuse-first`
**Процедуры:** нет

Договорённость называет вторую моду панели второго уровня в `rt-page-header` — ту, в которой
панель стоит раскрытой, — и отбор её пунктов по подстроке подписи.

## Зачем

Панель раздела живёт в оверлее и открывается наведением: уход указателя её закрывает. Человек,
который весь день ходит по одному разделу, наводит на его кнопку перед каждым переходом, а
пунктов в панели бывает несколько десятков — глазами по трём колонкам ищут дольше, чем набирают
три буквы.

## Терминология

| Термин             | Что это                                                                     |
| ------------------ | --------------------------------------------------------------------------- |
| Панель раздела     | второй уровень навигации: колонки, группы и пункты одного раздела шапки     |
| Мода панели        | чем панель держится открытой: всплытием под указателем или закреплением     |
| Всплывающая мода   | сегодняшнее поведение: оверлей, наведение открывает, уход закрывает         |
| Закреплённая мода  | панель стоит в потоке разметки и держится открытой до нажатия переключателя |
| Переключатель моды | кнопка внутри панели, которой человек просит другую моду                    |
| Запрос поиска      | строка, набранная в поле панели; отбирает её пункты по подстроке подписи    |

### Как это называется в интерфейсе

| В спеке            | На экране                                                  |
| ------------------ | ---------------------------------------------------------- |
| Переключатель моды | булавка у края панели, подпись — «Закрепить» и «Открепить» |
| Запрос поиска      | поле с подписью «Поиск»                                    |
| Совпадений нет     | строка «Ничего не найдено» вместо колонок                  |

## Правила

- **Мода панели приходит входом, а нажатие переключателя уходит выходом.** Предпочтение человека
  хранит потребитель кита: своего состояния о нём кит не заводит и в хранилище браузера не ходит.
  Образец рядом — `rt-section-nav`, которому активность приходит в самом наборе.
- **Умолчание моды — всплывающая.** Потребитель, не знающий о втором значении входа, получает
  сегодняшнее поведение целиком.
- **Закреплённая панель стоит в потоке разметки, а не поверх страницы.** Она сдвигает содержимое
  под шапкой, и уход указателя её не закрывает.
- **Закреплённая мода показывает панель раздела, чей адрес открыт.** Раздел берётся тем же
  счётом активного, которым шапка подсвечивает кнопку; своего входа под закреплённый раздел нет.
- **Активного раздела нет — закреплённой панели нет вовсе.** Пустая панель занимала бы место и
  читалась бы поломкой.
- **Обе моды рисуются одним шаблоном.** Два шаблона разойдутся при первой правке одного из них.
- **Запрос поиска отбирает пункты по подстроке подписи, без учёта регистра.** Группа и колонка,
  из которых после отбора ничего не осталось, не рисуются, а ширина панели пересчитывается по
  оставшимся колонкам.
- **Пустой запрос возвращает набор целиком.** Отбор при нём не применяется вовсе.
- **Отбор считается вне шаблона.** Форму пункта решает `rt-page-header.logic.ts`, и ветвление
  отбора туда же: порог сложности шаблона шапки снят точечно, и это записанный долг.
- **Запрос поиска живёт, пока панель открыта, и предпочтением не является.** Он держится
  состоянием компонента, а не входом.
- **На узком экране переключателя не видно.** Панели там нет вовсе: разделы раскрываются
  аккордеоном в отдельной разметке. Мода на входе при этом жива и возвращается с расширением
  окна.

## Что не входит

- Поиск по всем разделам сразу: результат перестал бы принадлежать разделу, и это другой
  компонент по сути.
- Хранение предпочтения человека: его хранит потребитель кита.
- Закрепление на узком экране: что оно там означает, договорённость не решает.
- Отдельный компонент бокового меню: панель остаётся частью `rt-page-header`.

## Контракт

Поверхность — входы и выходы компонента кита; процедур поддомен не обслуживает.

| Что         | Род   | Умолчание   | О чём                                         |
| ----------- | ----- | ----------- | --------------------------------------------- |
| мода панели | вход  | всплывающая | чем панель держится открытой                  |
| запрос моды | выход | —           | мода, которую человек попросил переключателем |

## Экраны и состояния

| Состояние                             | Что видно                                           |
| ------------------------------------- | --------------------------------------------------- |

| закреплённая мода, адрес в разделе    | панель в потоке под шапкой, булавка закрытая        |
| закреплённая мода, адрес вне разделов | панели нет                                          |
| запрос набран, совпадения есть        | только колонки и группы с совпавшими пунктами       |
| запрос набран, совпадений нет         | строка «Ничего не найдено» вместо колонок           |
| узкий экран                           | бургер и аккордеон; поля поиска и переключателя нет |

## Сквозные требования

### Локали

Подписей заводится две — имя переключателя в каждой моде. Подпись поля поиска и строка о
пустой выдаче в наборе уже есть. Перевод даёт потребитель; ключ без перевода падает на
английское умолчание.

### SEO

Не применимо.

### Мобильная раскладка

Узкая разметка не трогается: переключателя и поля поиска в ней нет.

### Мультиобъектность

Не применимо.

## Решения

- **Второго входа под закреплённый раздел не заводится.** Довод: раздел берётся из уже
  считающегося множества активных, и второй источник того же разошёлся бы с первым молча.
  Отвергнуто: вход с идентификатором закреплённого раздела — он нужен только моде «раздел
  выбирает человек», которой договорённость не обещает.
- **Панель второго уровня остаётся частью шапки.** Довод: отдельный компонент бокового меню
  пришлось бы кормить тем же набором и держать в нём вторую копию счёта активного раздела.
  Отвергнуто: новый компонент кита.

## Открытые вопросы

- **`Q-31` — что закрепление означает на узком экране.** Панели там нет, и решать это до того,
  как узкая раскладка получит второй уровень, не с чего.

# Сценарии — материальный набор оформления

Номера продолжают нумерацию второго кита и после вливания не меняются. Пока сценарий не покрыт,
он несёт пометку «Не покрыто» с причиной.

### SC-UKV-99 — страница без признака набора рисуется базовым видом

Дано на корне страницы нет ни признака набора, ни признака темы
Когда кит рисует компонент
Тогда назначения приходят базовые, ровно те же, что до появления второго набора

Не покрыто: набора ещё нет.

### SC-UKV-100 — признак набора на корне перекрашивает кит

Дано на корне страницы стоит признак материального набора
Когда кит рисует компонент
Тогда цветовые назначения приходят из материального набора

Не покрыто: набора ещё нет.

### SC-UKV-101 — снятый признак возвращает базовый вид без пересборки

Дано страница нарисована с признаком материального набора
Когда признак снимают на живой странице
Тогда назначения возвращаются к базовым, а страница не перезагружается

Не покрыто: набора ещё нет.

### SC-UKV-102 — признак на контейнере красит только его

Дано корень страницы стоит без признака набора, а внутри есть контейнер с признаком
Когда кит рисует один и тот же компонент снаружи и внутри контейнера
Тогда снаружи приходят базовые назначения, внутри — материальные

Не покрыто: набора ещё нет.

### SC-UKV-103 — признак тёмной темы выигрывает у признака набора

Дано на корне страницы стоят оба признака — тёмной темы и материального набора
Когда кит рисует компонент
Тогда назначения приходят из тёмной темы базового набора

Не покрыто: набора ещё нет.

### SC-UKV-104 — цветовое назначение без ответа материального набора роняет проверку

Дано в базовом наборе есть цветовое назначение, которого материальный набор не переопределяет и
общим не помечает
Когда идёт проверка полноты наборов
Тогда она называет имя назначения и отвечает ненулевым кодом

Не покрыто: проверка ещё не расширена на второй набор.

### SC-UKV-105 — пометка «цвет общий» у переопределённого назначения роняет проверку

Дано у назначения стоит пометка об общем цвете, а материальный набор его всё-таки переопределяет
Когда идёт проверка полноты наборов
Тогда она называет имя назначения: пометка пережила правку

Не покрыто: проверка ещё не расширена на второй набор.

### SC-UKV-106 — ступень шкалы, переписанная материальным набором, роняет проверку

Дано материальный набор переопределяет ступень шкалы
Когда идёт проверка наборов
Тогда она называет имя ступени и отвечает ненулевым кодом

Не покрыто: проверка ещё не расширена на второй набор.

### SC-UKV-107 — пара «текст и фон» материального набора ниже порога роняет проверку

Дано в материальном наборе есть пара «цвет текста и его фон» с отношением ниже порога
Когда идёт замер контраста
Тогда считалка называет оба имени, отношение и набор

Не покрыто: замер ещё не расширен на второй набор.

### SC-UKV-108 — правка собранного файла набора роняет сверку

Дано собранный файл материального набора правлен мимо источника оформления
Когда идёт сверка собранного с источником
Тогда она называет файл и командует пересборкой

Не покрыто: набора ещё нет.

### SC-UKV-109 — ссылка материального набора на необъявленное имя роняет проверку графа

Дано материальный набор ссылается на имя, которого не объявляет ни один слой и которое не названо
ручкой потребителя
Когда идёт проверка графа токенов
Тогда она называет имя и место ссылки

Не покрыто: набора ещё нет.

### SC-UKV-110 — витрина показывает историю в обоих наборах рядом

Дано история витрины показана в режиме сравнения наборов
Когда страница нарисована
Тогда на ней стоят два показа одного компонента — базовый и материальный, каждый со своей
подписью

Не покрыто: показа сравнения ещё нет.

### SC-UKV-111 — значок приезжает из набора, выбранного вместе с оформлением

Дано на странице стоит признак материального набора
Когда разметка просит имя значка
Тогда приезжает материальный рисунок этого имени, а не рисунок своего набора

Не покрыто: второго набора значков ещё нет.

### SC-UKV-112 — ступени бренда потребителя красят оба набора

Дано приложение объявило свои ступени бренда после подключения файла токенов
Когда кит рисует действие, ссылку и кольцо фокуса в каждом из наборов
Тогда все три берут цвет из объявленных ступеней в обоих наборах

Не покрыто: набора ещё нет.

# Привязка — материальный набор оформления

Кода ещё нет, поэтому привязок вида `файл:символ` здесь нет ни одной: договорённость написана до
кода, и место исполнения появится вместе с ним. Здесь — только предвиденные места, чтобы при
вливании в спек домена было видно, куда смотреть.

## Где предвидится исполнение

| Правило                                                        | Где предвидится                                                        |
| -------------------------------------------------------------- | ---------------------------------------------------------------------- |
| два набора назначений, базовый по умолчанию                    | источник оформления `projects/ui-kit-v2/src/styles/tokens.source.mjs`  |
| набор выбирается признаком; признак действует и на контейнере  | слой оформления в `projects/ui-kit-v2/src/styles/`                     |
| набор не трогает шкалу; отвечает на каждое цветовое назначение | `tools/check-tokens-theme.mjs`                                         |
| пара «текст и фон» держит порог в каждом наборе                | `tools/check-tokens-theme.mjs`, `tools/tokens-contrast-pairs.json`     |
| набор собирается из источника                                  | `tools/build-tokens-v2.mjs`                                            |
| ссылка набора на необъявленное имя                             | `tools/check-tokens-graph.mjs`                                         |
| значения снимаются с первого кита                              | `projects/ui-kit/src/styles/base/_tokens.scss` — читается, не правится |
| значок приходит своим рисунком                                 | набор значков `projects/ui-kit-v2/src/assets/icons`                    |
| витрина показывает два набора рядом                            | витрина второго кита                                                   |

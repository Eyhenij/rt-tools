# Привязка — материальный набор оформления

Кода ещё нет, поэтому привязок вида `файл:символ` здесь нет ни одной: договорённость написана до
кода, и место исполнения появится вместе с ним. Здесь — только предвиденные места, чтобы при
вливании в спек домена было видно, куда смотреть.

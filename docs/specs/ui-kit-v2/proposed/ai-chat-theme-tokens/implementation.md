# What it will be carried out by — the look handles of the assistant chat

There is no code yet, so every line here is a planned binding: the file that is to be edited and
the property the rule is to live in. At the merge into the domain spec each line becomes a
`file:symbol` binding with the handle name as the symbol, as the scroll area and the action bar have.

The first column is the rule of the spec next to it verbatim.

- **The question text takes its size from `--rt-ai-chat-question-font-size`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the declaration on `.rt-ai-chat` and `font-size` of `__bubble-text`; scenario `SC-UKV-1582`
- **The answer text takes its size from `--rt-ai-chat-answer-font-size`, which the chat passes down to the markdown text.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the declaration on `.rt-ai-chat` and the pass-down of `--rt-markdown-text-font-size`; scenario `SC-UKV-1582`
- **The markdown text takes its family and size from `--rt-markdown-text-font-family` and `--rt-markdown-text-font-size`.** — planned: `projects/ui-kit-v2/src/lib/components/markdown-text/rt-markdown-text.component.scss`, the declarations on `.rt-markdown-text` and its `font-family` and `font-size`; scenario `SC-UKV-1594`
- **A set `--rt-ai-chat-font-family` gives its family to the question and to the answer; unset, the question inherits the page family and the answer keeps the kit sans family.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, `font-family` of `__feed` with no fallback and the pass-down of `--rt-markdown-text-font-family` with the sans family as the fallback; scenario `SC-UKV-1583`
- **Send and Stop take their fill and hover fill from `--rt-ai-chat-send-bg` and `--rt-ai-chat-send-bg-hover`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the pass-down of `--rt-ai-prompt-input-send-bg` and `--rt-ai-prompt-input-send-bg-hover`; scenario `SC-UKV-1584`
- **The prompt box in focus takes its border colour and ring from `--rt-ai-chat-focus-border-color` and `--rt-ai-chat-focus-shadow`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the pass-down of `--rt-ai-prompt-input-focus-border-color` and `--rt-ai-prompt-input-focus-shadow`; scenario `SC-UKV-1585`
- **The prompt input reads its box background, its Send and Stop fills and its focus border and ring from its own `--rt-ai-prompt-input-*` handles.** — planned: `projects/ui-kit-v2/src/lib/components/ai-prompt-input/rt-ai-prompt-input.component.scss`, the declarations on `.rt-ai-prompt-input`, `background` and `:focus-within` of `__box`, and `--rt-icon-button-bg` with `--rt-icon-button-bg-hover` on the Send and Stop buttons; scenario `SC-UKV-1594`
- **A chosen rating button takes its fill and icon colour from `--rt-ai-chat-rating-active-bg` and `--rt-ai-chat-rating-active-color`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss` for the declarations and `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/answer/rt-ai-chat-answer.component.scss`, the active button of `__feedback`; scenario `SC-UKV-1586`
- **The header draws a divider under it, `--rt-ai-chat-header-border-width` wide in `--rt-ai-chat-header-border-color`, and the default width 0 draws none.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, `border-block-end` of `__header`; scenario `SC-UKV-1587`
- **The header is never lower than `--rt-ai-chat-header-min-height`, and its content stays centred across a taller header.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, `min-block-size` of `__header`; scenario `SC-UKV-1587`
- **A suggestion card on the start screen is `--rt-ai-chat-suggestion-width` wide and stands at the start of the column when narrower than it.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, `inline-size` of `rt-prompt-suggestion` inside `__suggestions`; scenario `SC-UKV-1588`
- **A suggestion card takes its rounding from `--rt-ai-chat-suggestion-radius`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the pass-down of `--rt-prompt-suggestion-radius`; scenario `SC-UKV-1588`
- **The chat input `questionAuthor` draws the author label in the question bubble; it defaults to `true`, and `false` leaves the label node out of the page.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts`, the input `questionAuthor`, and `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.html`, the condition around `author`; scenarios `SC-UKV-1589`, `SC-UKV-1590`
- **The chat panel takes its background from `--rt-ai-chat-bg` and the prompt box from `--rt-ai-chat-prompt-bg`, each set apart from the other.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, `background` of `.rt-ai-chat` and the pass-down of `--rt-ai-prompt-input-bg`; scenario `SC-UKV-1591`
- **The row actions take their background from `--rt-ai-chat-thread-actions-bg`, and on the active row from `--rt-ai-chat-thread-actions-bg-active`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the pass-down of `--rt-thread-list-row-actions-bg` and `--rt-thread-list-row-actions-bg-active`; scenario `SC-UKV-1592`
- **A button of the row actions takes its rounding from `--rt-ai-chat-thread-action-radius`.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the pass-down of `--rt-thread-list-row-action-radius`; scenario `SC-UKV-1592`
- **The conversation list reads the row actions backgrounds and the action rounding from its own `--rt-thread-list-*` handles.** — planned: `projects/ui-kit-v2/src/lib/components/thread-list/rt-thread-list.component.scss`, the declarations on `.rt-thread-list`, `background` of `__row-actions` and of the active row's actions, and `--rt-icon-button-radius` on the buttons inside `__row-actions`; scenario `SC-UKV-1594`
- **While the row actions are shown, the time of that row is not drawn under them.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, `__thread-time` under the shown row actions; scenario `SC-UKV-1593`
- **A chat handle set on the chat root reaches its part, though the part declares a handle of its own.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.scss`, the pass-down rules, stronger than the part's own declaration; scenario `SC-UKV-1595`
- **Without the new handles the chat draws as before.** — planned: every file above, each default equal to the value the property takes today; scenario `SC-UKV-1596`
- **Without the input `questionAuthor` the question bubble draws as before.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts`, the default `true` of `questionAuthor`; scenario `SC-UKV-1590`
- **The kit README names the type sizes, the header height and the suggestion width of the chat as an exception to the line that keeps type size and dimensions on scale steps.** — planned: `projects/ui-kit-v2/README.md`, the section «Настройка компонента снаружи»; no scenario, a text rule
- **The chat overview lists every new chat handle and the input `questionAuthor`, and the overview of each part lists its new handles.** — planned: `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/Overview.mdx`, the sections «Оформление» and «Входы»; `projects/ui-kit-v2/src/lib/components/markdown-text/Overview.mdx`, `projects/ui-kit-v2/src/lib/components/ai-prompt-input/Overview.mdx`, `projects/ui-kit-v2/src/lib/components/thread-list/Overview.mdx`; no scenario, a text rule

# What it will be carried out by — the look handles of the assistant chat

There is no code yet, so every line here is a planned binding: the file that is to be edited and
the property the rule is to live in. At the merge into the domain spec each line becomes a
`file:symbol` binding with the handle name as the symbol, as the scroll area and the action bar have.

The first column is the rule of the spec next to it verbatim.

## The showcase

Three stories are planned in `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/stories/`:
**Properties** (the default cell and the font, header, suggestion, author and background cells),
**Properties · focus** (the prompt box focused, Send hovered, a chosen like) and **Properties · row
actions** (rows with `threadMenu` on and off, the actions shown, the row time hidden on request). The
former stories of the family keep their references.

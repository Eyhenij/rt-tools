# Боковое меню

**Статус:** предложено · **Ревизия:** 29 сентября 2026 · **Префикс сценариев:** `SC-UKV`
**Зависимости:** хранилище `@rt-tools/core` — режим и ширина подменю помнятся в нём
**Законы:** `verifiability`, `frontend-application`
**Процедуры:** нет

Договорённость о продукте, написанная до кода. Вливается в описание второго кита последним
коммитом PR — с прежними номерами сценариев; описание компонента ляжет в его `CONTEXT.md`.

## Зачем

Приложение, которое переходит на второй кит, держит навигацию по разделам в боковом меню первого
кита. Во втором ките такого меню нет, и без него переезд стоит. `rt-menu` второго кита — выпадающее
меню действий, а не навигация, и владелец запретил его заменять: боковое меню встаёт рядом
отдельным компонентом.

## Словарь

| Слово         | Что это                                                            |
| ------------- | ------------------------------------------------------------------ |
| полоса        | узкий столбец пунктов верхнего уровня с иконками                   |
| подменю       | панель рядом с полосой: пункты раздела, папки и поиск по ним       |
| папка         | пункт подменю со своими пунктами внутри                            |
| режим подменю | наведение или закрепление: чем подменю держится открытым           |
| номер меню    | `menuId` — имя, под которым лежат настройки этого меню в хранилище |

### Как это названо в интерфейсе

| В договорённости | На экране                     |
| ---------------- | ----------------------------- |
| поиск            | поле с подсказкой «Поиск»     |
| закрепление      | кнопка «Закрепить меню»       |
| ручка ширины     | полоса у правого края подменю |

## Правила

- **Активность приходит снаружи.** Какие пункты активны, меню узнаёт из `activeMenuIds`; нажатие на
  пункт ведёт по его ссылке, подсветку двигает новый набор после перехода. Держи меню активность
  само, оно спорило бы с адресом.
- **Подменю держится наведением или закреплением.** В режиме наведения оно закрывается, когда
  указатель ушёл с панели. Закреплённое стоит открытым и показывает раздел, выбранный человеком, а
  пока выбора нет — раздел активного адреса. Иначе до соседнего раздела не добраться.
- **Режим и ширина подменю помнятся под номером меню.** Они переживают перезагрузку. Запись одного
  меню не трогает соседние меню и незнакомые поля: их могло положить приложение.
- **Отказ хранилища меню не останавливает.** В приватном окне хранилище закрыто, и выбор просто не
  переживает перезагрузку. Незнакомый режим и нечисловая ширина читаются как отсутствие выбора.
- **Поиск спускается внутрь папок и оставляет только совпавшее.** Папка остаётся путём к совпавшим
  детям, её состав отбирается тем же правилом. Папка, совпавшая только по имени, стоит одной
  строкой без детей. Набор потребителя не правится.
- **Папки выдачи стоят раскрытыми, а стёртый запрос возвращает прежнюю раскрытость.**
- **В подписи отмечено каждое вхождение запроса, а не вся подпись.** Сравнение без учёта регистра,
  куски режутся из оригинала.
- **Клавиатура ходит по видимым строкам.** Стрелки вверх и вниз двигают подсветку, строки свёрнутой
  папки пропускаются, у краёв подсветка стоит. Без подсветки вниз берёт первую строку, вверх —
  последнюю. Вправо и влево раскрывают и сворачивают папку, Enter нажимает строку пункта или
  раскрывает папку, Escape стирает запрос. Остальные клавиши поле принимает как обычно.
- **Ширину подменю тянут ручкой в пределах от 120 до 480 пикселей.** Тянет основная кнопка
  указателя: мышь, палец, перо. На ручке стрелки ходят шагом 16 пикселей, `Home` и `End` ведут к
  пределам. Своей ширины нет — её ставит оформление.
- **Пустой `menuId` читается как не заданный — номер `default`.**

## Что не входит

- Блок избранного в подменю — отдельная задача эпика RT-2353 следом за этой.
- `rt-menu` второго кита не правится и не заменяется.
- Первый кит не правится: он открывается образцом.

## Контракт

Не применимо: процедур у компонента нет.

# Чем исполняется — снимки витрины второго кита

Кода под эту договорённость ещё нет: она лежит в `proposed/` и описывает то, чего в дереве не
существует. Колонка «Где окажется» поэтому называет место, в котором правило окажется, а не
существующий символ. Привязка к символам проставляется тем же изменением, что и код, и вливается в
спек пакета вместе со всей договорённостью.

## Что уже лежит в дереве и берётся за основу

- Обвязка снимков первой витрины и её эталоны — образец, с которого снимается подход; общим файлом
  он не становится.
- Помощники витрины второго кита в `projects/ui-kit-v2/src/showcase/` — сетки, ряды, сравнение
  тем, открытие перекрытий. Три помощника рисуют показ своими селекторами, общего признака корня у
  них сегодня нет — он заводится этой работой, и по нему берётся область кадра.
- Открытие перекрытия в тех же помощниках держится на кадрах отрисовки: в окне, которое их не
  даёт, жест не случается вовсе. Переписывается этой же работой — без этого истории с
  перекрытиями снимаются с закрытой панелью и выглядят исправными.
- Правило `.claude/skills/ui-component-tests/SKILL.md` — сегодня знает только первую витрину: один
  порт, один каталог эталонов, две команды.
- План покрытия `docs/plans/ui-kit-v2-state-coverage.md` — таблица хода и открытый вопрос о том,
  нужна ли сверка кадров, который эта договорённость и закрывает.

## Что придётся сделать разово по всей витрине

- **Пометить исключением истории со значениями по умолчанию.** Набор задан вычитанием, поэтому без
  пометок в кадр пойдут и они. Пометка требует причины — общая для всех: значения по умолчанию уже
  стоят ячейкой внутри матрицы этого же компонента.
- **Проставить перечень порогов** тем одиннадцати папкам, которые ширину называют: десять
  медиазапросами и одна через службу порогов.

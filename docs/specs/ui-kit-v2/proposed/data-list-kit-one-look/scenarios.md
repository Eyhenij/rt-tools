# Сценарии — семья таблицы в виде первого кита

Номера продолжают нумерацию второго кита и после вливания не меняются. Пока сценарий не покрыт,
он несёт пометку «Не покрыто» с причиной.

### SC-UKV-351 — история тем списка читается на узком холсте

Дано история тем списка открыта на холсте шириной 900 px
Когда витрина рисует обе половины каждого набора
Тогда ни один узел половины не выходит за её правый край

Не покрыто: правки ещё нет.

### SC-UKV-352 — панель колонок рисует вид первого кита

Дано панель колонок открыта
Когда в ней три колонки, одна из них скрыта
Тогда видны заголовок с подписью, два переключателя полос и список колонок с кнопкой-глазом у
каждой, а у скрытой глаз перечёркнут

Не покрыто: правки ещё нет.

### SC-UKV-353 — у семьи таблицы есть парные кадры с первым китом

Дано список пар кадров двух китов
Когда проверка пар читает семью таблицы
Тогда у неё названы кадры обоих китов и нет причины «ещё не перенесено»

Не покрыто: правки ещё нет.

# Сценарии — панель раздела: закрепление и поиск

Номера продолжают нумерацию домена второго кита и не меняются.

### SC-UKV-96 — потребитель, не назвавший моду, получает всплывающую панель

Дано шапка собрана без входа моды
Когда указатель наводится на раздел с панелью и уходит с него
Тогда панель открывается наведением и закрывается уходом, как до правки

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

### SC-UKV-97 — закреплённая панель не закрывается уходом указателя

Дано шапке задана закреплённая мода и открыт адрес пункта одного из разделов
Когда указатель уходит с панели
Тогда панель остаётся в разметке

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

### SC-UKV-98 — нажатие переключателя моду не меняет, а просит её

Дано шапке задана закреплённая мода
Когда человек нажимает переключатель
Тогда выход отдаёт всплывающую моду, а вход остаётся закреплённым, пока потребитель его не сменит

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

### SC-UKV-99 — закреплённая панель показывает раздел открытого адреса

Дано шапке задана закреплённая мода и открыт адрес пункта второго раздела
Когда шапка рисуется
Тогда в потоке стоит панель второго раздела

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

### SC-UKV-100 — активного раздела нет — закреплённой панели нет

Дано шапке задана закреплённая мода и открыт адрес, которого нет ни в одной панели
Когда шапка рисуется
Тогда панели в разметке нет

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

### SC-UKV-101 — запрос отбирает пункты по подстроке подписи

Дано панель открыта и её пункты подписаны по-разному
Когда в поле набрана подстрока одной из подписей в другом регистре
Тогда в панели остаются только пункты, чья подпись эту подстроку содержит

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.logic.spec.ts`.

### SC-UKV-102 — группа без совпадений не рисуется

Дано в колонке две группы, и совпадения есть только в первой
Когда запрос набран
Тогда вторая группа вместе со своим заголовком из панели уходит

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.logic.spec.ts`.

### SC-UKV-103 — колонка без совпадений уходит, и ширина панели пересчитывается

Дано в панели три колонки, и совпадения есть только в одной
Когда запрос набран
Тогда в панели остаётся одна колонка, и число колонок, которым считается ширина, равно одному

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.logic.spec.ts`.

### SC-UKV-104 — совпадений нет — панель говорит об этом строкой

Дано панель открыта
Когда набран запрос, которого нет ни в одной подписи
Тогда вместо колонок стоит строка «Ничего не найдено»

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

### SC-UKV-105 — пустой запрос возвращает набор целиком

Дано запрос был набран и отобрал часть пунктов
Когда поле очищается
Тогда в панели снова все колонки, группы и пункты исходного набора

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.logic.spec.ts`.

### SC-UKV-106 — на узком экране переключателя нет

Дано ширина окна ниже порога узкого экрана и шапке задана закреплённая мода
Когда открывается панель бургера
Тогда переключателя моды в разметке нет

Покрыто: `projects/ui-kit-v2/src/lib/components/page-header/rt-page-header.component.spec.ts`.

# What it is carried out by — load error and placeholder states of the table and the lists

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree; the scenario it is checked by is named there too, and what exactly every scenario is
covered by is said in `scenarios.md`.

A rule without a line and a line without a rule is a divergence: the spec promises what is not in the
tree, or the tree holds what the spec is silent about.

- **The error wins over loading and emptiness.** — `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts:isInitialLoading`, `projects/ui-kit-v2/src/lib/components/data-list/rt-data-list.component.html:loadError`, `projects/ui-kit-v2/src/lib/components/dynamic-list/rt-dynamic-list.component.html:loadError` and `projects/ui-kit-v2/src/lib/components/bar-list/rt-bar-list.component.html:loadError` — the error is asked before loading, fetching and emptiness; scenarios `SC-UKV-1279`, `SC-UKV-1282`, `SC-UKV-1283`, `SC-UKV-1284`
- **An error after a page, sort or filter change looks the same as the first one.** — `projects/ui-kit-v2/src/lib/components/table/rt-table.component.scss:cdk-row` and `projects/ui-kit-v2/src/lib/components/data-list/rt-data-list.component.html:isPaginationShown` — the table hides the rows under the error and keeps the head; the data list keeps the toolbar and the pagination; scenario `SC-UKV-1280`
- **The retry button emits `retry` and nothing else.** — `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts:retry`, `projects/ui-kit-v2/src/lib/components/data-list/rt-data-list.component.ts:retry`, `projects/ui-kit-v2/src/lib/components/dynamic-list/rt-dynamic-list.component.ts:retry` and `projects/ui-kit-v2/src/lib/components/bar-list/rt-bar-list.component.ts:retry` — the outputs; no component reloads by itself; scenarios `SC-UKV-1282`, `SC-UKV-1283`, `SC-UKV-1284`
- **The default error view is `rt-empty-state` with the alert icon, a title, a hint and an outlined «Повторить» button.** — `projects/ui-kit-v2/src/lib/components/empty-state/rt-load-error.ts:rtLoadErrorView` and `projects/ui-kit-v2/src/lib/components/table/rt-table.component.html:defaultError` — the title, the hint and the template context; each component draws the same `defaultError` template; scenario `SC-UKV-1279`
- **An own view replaces the default one whole.** — `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts:errorTemplate`, `projects/ui-kit-v2/src/lib/components/data-list/rt-data-list.component.ts:errorTemplate`, `projects/ui-kit-v2/src/lib/components/dynamic-list/rt-dynamic-list.component.ts:errorTemplate` and `projects/ui-kit-v2/src/lib/components/bar-list/rt-bar-list.component.ts:emptyTemplate` — a declared template is rendered instead of the default placeholder; scenarios `SC-UKV-1285`, `SC-UKV-1286`
- **The table keeps its `#rtTableEmpty` reference.** — `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts:emptyView` — the directive template first, the reference second; scenario `SC-UKV-1281`
- **The table error placeholder is 400 wide in the middle of the row; the data list error takes the width of the list.** — `projects/ui-kit-v2/src/lib/components/table/rt-table.component.scss:rt-empty-state-max-width` and `projects/ui-kit-v2/src/lib/components/data-list/rt-data-list.component.scss:inline-size` — the table value and the data list stretch; no scenario: the width is measured in the showcase against the approved frames

# Чем исполняется — поле ввода

Первая колонка — правило спека рядом дословно. Вторая — где оно исполняется в дереве; там же
назван сценарий, которым это проверяется, а чем именно покрыт каждый сценарий, сказано в
`scenarios.md`.

Правило без строки и строка без правила — расхождение: спек обещает то, чего в дереве нет, либо
в дереве стоит то, о чём спек молчит.

| Правило                                                      | Где исполняется                                                                                              |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| У поля ввода есть тип адреса, и он уезжает на нативное поле. | `projects/ui-kit-v2/src/lib/components/input/rt-input.model.ts:Type`; сценарий `SC-UKV-55`                   |
| Прежние четыре типа работают как раньше.                     | `projects/ui-kit-v2/src/lib/components/input/rt-input.model.ts:Type`; сценарий `SC-UKV-56`                   |
| Проверка введённого остаётся за приложением.                 | `projects/ui-kit-v2/src/lib/components/input/rt-input.component.ts:type` — тип уезжает на разметку, и только |

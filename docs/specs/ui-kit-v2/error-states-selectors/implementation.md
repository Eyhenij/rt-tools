# What it is carried out by — load error and own placeholders of the selectors, the local lists and the PDF viewer

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree; the scenario it is checked by is named there too, and what exactly every scenario is
covered by is said in `scenarios.md`.

A rule without a line and a line without a rule is a divergence: the spec promises what is not in the
tree, or the tree holds what the spec is silent about.

- **A server selector draws the load error instead of the options.** — `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.html:loadError` and `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.html:loadError` — the error is asked before loading and the options; scenarios `SC-UKV-1287`, `SC-UKV-1293`
- **In `rt-dynamic-selector` the view stands in its selection window.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:hasOffer`, `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:isBusy` and `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector-load-state.directive.ts:RtDynamicSelectorLoadStateDirective` — the field counts an error as something to open, the window hides «Применить» and «Выбрать все», and the field and the standalone window share the inputs; scenario `SC-UKV-1295`
- **In `rt-autocomplete` the panel stays open after «Повторить».** — `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.ts:optionList` — the keyboard counts no options while the error stands; the error line carries `role="presentation"`; scenarios `SC-UKV-1287`, `SC-UKV-1288`
- **The retry button emits `retry` and nothing else.** — `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.ts:retry` and `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector-load-state.directive.ts:retry` — the outputs; no selector reloads by itself; scenario `SC-UKV-1288`
- **The default error view of a server selector is `rt-empty-state` with the alert icon, the title, the hint and an outlined «Повторить» button.** — `projects/ui-kit-v2/src/lib/components/empty-state/rt-load-error.ts:rtLoadErrorView` and `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.html:defaultError` — the title, the hint and the template context; scenario `SC-UKV-1294`
- **The error view in the `rt-autocomplete` panel is compact.** — `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.scss:rt-empty-state-icon-wrap-size` and `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.html:defaultError` — the sizes of the circle, the icon, the title and the button; no scenario: the sizes are measured in the showcase against the approved frame
- **A server selector takes both own views.** — `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.ts:emptySlot`, `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.ts:errorTemplate`, `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector-load-state.directive.ts:emptySlot` and `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector-load-state.directive.ts:errorSlot` — the directive templates; scenario `SC-UKV-1289`
- **A directive template wins over the present empty inputs.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector-load-state.directive.ts:emptyTemplate` and `projects/ui-kit-v2/src/lib/components/autocomplete/rt-autocomplete.component.html:emptySlot` — the directive is asked first, the input second; scenario `SC-UKV-1290`
- **A local list takes an own empty view and has no error.** — `projects/ui-kit-v2/src/lib/components/select/rt-select.component.ts:emptyTpl`, `projects/ui-kit-v2/src/lib/components/multiselect/rt-multiselect.component.ts:emptyTpl`, `projects/ui-kit-v2/src/lib/components/tree/rt-tree.component.ts:emptySlot`, `projects/ui-kit-v2/src/lib/components/draggable-tree/rt-draggable-tree.component.ts:emptyTpl`, `projects/ui-kit-v2/src/lib/components/tree-selector/rt-tree-selector.component.ts:emptyTpl` and `projects/ui-kit-v2/src/lib/components/side-menu/rt-side-menu.component.ts:emptyTpl` — each list reads its directive and keeps its line without one; scenarios `SC-UKV-1291`, `SC-UKV-1296`
- **The PDF viewer takes an own error view and keeps its error internal.** — `projects/ui-kit-v2/src/lib/components/pdf-viewer/rt-pdf-viewer.component.ts:errorTemplate`, `projects/ui-kit-v2/src/lib/components/pdf-viewer/rt-pdf-viewer.component.ts:errorContext` and `projects/ui-kit-v2/src/lib/components/pdf-viewer/rt-pdf-viewer-error.directive.ts:RtPdfViewerErrorDirective` — the template from the opening data and its context; scenarios `SC-UKV-1292`, `SC-UKV-1296`

# Сценарии — разряды числового поля

Префикс `SC-UKV`, общий на домен вместе с поддоменами.

Чем покрыт сценарий, сказано под ним. Где прогон сценарий не покрывает, это сказано прямо.

### SC-UKV-113 — числовое поле разделяет разряды, пока не сказано обратного

Дано числовое поле без указания вида
Когда в него набрано число длиннее трёх цифр
Тогда разряды в поле разделены знаком локали

### SC-UKV-114 — полю, которому названо сплошное число, разделители не ставятся

Дано числовое поле, которому названо сплошное число
Когда в него набран год и фокус ушёл
Тогда в поле стоит год без разделителей, а в форму пришло то же число

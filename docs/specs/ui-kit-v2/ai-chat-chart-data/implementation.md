# What it is carried out by — the data table of the chart block

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **The switch stands under the chart as soon as the block is in the drawn state; the data table is hidden until it is pressed.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:open`; scenarios `SC-UKV-1383`, `SC-UKV-1384`
- **The table is closed when the block is created; it stays open across a locale change and a re-render of the same block, and closes when the input `block` brings another spec.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:open`; scenarios `SC-UKV-1385`, `SC-UKV-1395`
- **The pending, the invalid and the empty block have no switch; a block that turns one of them while its table is open loses the switch and the table.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:table`; scenario `SC-UKV-1386`
- **The data table is built from the data the chart gets (`rtAiChatChartData`), not from the spec anew: the same categories in the same order, the same labels, the same values.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:rtAiChatChartTable`; scenario `SC-UKV-1387`
- **A value is written exactly as the format of the chart writes it for the kit locale, its sign included; the table adds no sign and no spacing of its own.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:valueCell`; scenario `SC-UKV-1388`
- **The head row per kind:** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:rtAiChatChartTable`; scenarios `SC-UKV-1387`, `SC-UKV-1389`
- **The rows per kind.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:cartesianTable`, `binsTable`, `pieTable`, `heatmapTable`, `scatterTable`; scenario `SC-UKV-1389`
- **`treemap` and `sunburst` give a row per path that carries a value after equal paths are summed: every leaf, and an inner node whose own path was given, holding only its own value.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:treeRows`; scenario `SC-UKV-1390`
- **A missing point is an empty cell; a zero is written as a zero.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:valueCell`; scenarios `SC-UKV-1387`, `SC-UKV-1388`
- **Value columns — `y` values, cells and the `scatter` `x` — are aligned right; names, categories, bins and paths left. A number never wraps; a long name wraps inside its cell.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.scss:__cell`, the column kind — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.table.ts:numberCell`; scenario `SC-UKV-1391`
- **A table wider than the block scrolls inside the block and never widens the feed; its height is not limited, the block grows with it.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.scss:__data`; scenario `SC-UKV-1391`
- **The open table follows a change of the kit label locale: its values, its head labels and the switch name change with it.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:table`; scenario `SC-UKV-1393`
- **The full-screen dialog has no switch and no table.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/dialog/rt-ai-chat-chart-dialog.component.ts:RtAiChatChartDialogComponent`; scenario `SC-UKV-1394`
- **The copy button of an answer gives the same text with the table open or hidden.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartBlockText`; scenario `SC-UKV-1392`
- **The switch is a button with `aria-expanded`; while hidden the table is absent, and the switch keeps `aria-controls` with the table id, unique per block instance.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:nextTableId`; scenarios `SC-UKV-1383`, `SC-UKV-1384`
- **Every fixed text of the switch and the head — «View data», «Hide data», «Category», «Bin», «Value», «Series», «X», «Y», «Path», «Chart» — is a kit label in the `rtKit` namespace, English in the package.** — `projects/ui-kit-v2/src/lib/i18n/rt-kit-labels.en.ts:RT_KIT_LABELS_EN`; scenario `SC-UKV-1393`

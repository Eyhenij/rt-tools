# Сценарии — сегментированный переключатель

### SC-UKV-84 — нажатие в множественном выборе добавляет сегмент

Дано группа объявлена множественной, и выбран один сегмент
Когда человек нажимает соседний
Тогда наружу уходит набор из обоих, а оба сегмента подсвечены

Покрыто: `projects/ui-kit-v2/src/lib/components/toggle-button-group/rt-toggle-button-group.component.spec.ts`.

### SC-UKV-85 — повторное нажатие в множественном выборе снимает сегмент

Дано группа объявлена множественной, и выбраны два сегмента
Когда человек нажимает выбранный
Тогда наружу уходит набор без него

Покрыто: `projects/ui-kit-v2/src/lib/components/toggle-button-group/rt-toggle-button-group.component.spec.ts`.

### SC-UKV-86 — недоступный сегмент виден и нажатия не пропускает

Дано у одного сегмента объявлена недоступность
Когда человек нажимает его
Тогда сегмент на месте, наружу не уходит ничего

Покрыто: `projects/ui-kit-v2/src/lib/components/toggle-button-group/rt-toggle-button-group.component.spec.ts`.

### SC-UKV-87 — отключённая группа делает недоступными все сегменты

Дано группа отключена, а у сегментов недоступность не объявлена
Когда человек нажимает любой из них
Тогда все сегменты недоступны, наружу не уходит ничего

Покрыто: `projects/ui-kit-v2/src/lib/components/toggle-button-group/rt-toggle-button-group.component.spec.ts`.

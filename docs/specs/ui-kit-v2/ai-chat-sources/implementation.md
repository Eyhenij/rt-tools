# What it is carried out by — the sources block of the assistant chat

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **`sources` is a type the kit draws itself, next to `markdown`, `notice`, `table`, `kpi` and `link`; an application gets it without registering anything, and a renderer registered for `sources` is not taken.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:OWN_TYPES`, `toBlockViews`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.model.ts:SourcesBlock`; scenario `SC-UKV-1541`
- **A sources block has `items`, a list; a source has `title` and the optional `detail`, `icon` and `url`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.model.ts:SourcesBlock`; `projects/ui-kit-v2/src/lib/util/sources-data.ts:IRtSourceItem`, `IRtSourcesData`, `rtSourceItem`, `rtSourcesData`; scenarios `SC-UKV-1548`, `SC-UKV-1550`
- **A source whose `title` is not a string, or is empty after trimming, is dropped; a block whose `items` is not a list, or holds no source after the dropping, is shown as the plate with its type name.** — `projects/ui-kit-v2/src/lib/util/sources-data.ts:rtSourceItem`, `rtSourcesData` drop the source and give `null`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:sourcesBlockData`, `toBlockViews` show the plate; scenarios `SC-UKV-1548`, `SC-UKV-1549`
- **The title, the detail and the address are trimmed; the list draws, the event carries and the copy writes the trimmed text.** — `projects/ui-kit-v2/src/lib/util/sources-data.ts:rtSourceItem`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:copyField`; scenario `SC-UKV-1550`
- **An `icon` that is not a non-empty string, or a name the kit icon set does not hold, is the kit icon `file`; the name is trimmed like the other texts and is not changed in case.** — `projects/ui-kit-v2/src/lib/util/sources-data.ts:DEFAULT_ICON`, `rtSourceItem`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/sources/rt-ai-chat-sources.component.ts:FALLBACK_ICON`, `rows`; scenarios `SC-UKV-1550`, `SC-UKV-1551`

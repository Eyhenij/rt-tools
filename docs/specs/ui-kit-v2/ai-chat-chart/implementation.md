# What it is carried out by — the chart block of the assistant chat

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **The chart block lives in its own entry `ai-chat-chart`: the `rich-editor` entry never imports d3, and the `chart` entry never imports the editor.** — `projects/ui-kit-v2/ai-chat-chart/ng-package.json:entryFile`; scenario `SC-UKV-1372`
- **The application connects the block by one provider of the entry, registered at the same level as its other renderers.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.providers.ts:provideRtAiChatChart`; scenario `SC-UKV-1373`
- **The block draws the ten kinds of the spec through `rt-chart`, by the mapping of the data section.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:rtAiChatChartData`; scenarios `SC-UKV-1341`, `SC-UKV-1346`
- **`bar` and `grouped_bar` bars with a negative value go below zero, from the zero line down.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:cartesianOf`; scenario `SC-UKV-1343`
- **A zero value is a value: in the cartesian kinds, scatter and heatmap it stands at zero and in the hint; in every kind it stands in the copy and is never taken for a missing point.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:valuesOf`, the copy — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartText`; scenario `SC-UKV-1344`
- **`x` is a string for the category kinds and a number for `scatter` and `histogram`; any other type makes the spec invalid.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.check.ts:checkPoint`; scenario `SC-UKV-1374`
- **A category is drawn as given and never signed by the format; in `scatter` the format signs only `y`.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:scatterOf`; scenario `SC-UKV-1377`
- **The categories are the `x` in their first appearance, series by series; a series that repeats an `x` makes the spec invalid.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:categoriesOf`, the repeat — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.check.ts:checkOneSeries`; scenarios `SC-UKV-1342`, `SC-UKV-1361`
- **A `histogram` is one series whose `x` strictly ascend with equal steps; anything else is invalid.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.check.ts:checkHistogram`; scenario `SC-UKV-1362`
- **The block parses a spec given as a JSON string, takes a parsed one as is, and checks both against the spec schema before drawing.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.check.ts:rtAiChatChartCheck`; scenarios `SC-UKV-1347`, `SC-UKV-1375`
- **A spec that does not parse or breaks the schema shows the notice «The chart could not be drawn» in place of the chart, and the blocks around it stay in place.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartState`; scenarios `SC-UKV-1348`, `SC-UKV-1349`
- **A block marked pending shows the placeholder «Drawing the chart…», never the notice, whatever its spec string holds.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartState`; scenario `SC-UKV-1350`
- **A spec with no point, or with all values zero in `pie`, `treemap` or `sunburst`, shows the empty state of `rt-chart` under the title row, and that row shows neither «Download PNG» nor «Open full screen».** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartIsEmpty`, the buttons — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:actions`; scenario `SC-UKV-1363`
- **Without a title the title row holds only the two buttons at its end; without a subtitle no subtitle line is drawn.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:spec`; scenario `SC-UKV-1364`
- **`yLabel` stands above the plot at its left edge, and `xLabel` under the chart, after the legend, at the right edge.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/plot/rt-ai-chat-chart-plot.component.ts:axisNames`; scenario `SC-UKV-1351`
- **`pie`, `treemap` and `sunburst` ignore both axis names; in `heatmap` `xLabel` names the columns and `yLabel` the rows.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/plot/rt-ai-chat-chart-plot.component.ts:axisNames`; scenario `SC-UKV-1351`
- **The format of the spec signs every value of the chart the same way: on the value axis, in the hint, in the pie, the heatmap and the tree.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:rtAiChatChartData`; scenarios `SC-UKV-1352`, `SC-UKV-1353`, `SC-UKV-1354`
- **`percent` signs a value with the percent sign, `currency` with the currency of the spec, `number` with the grouping of digits.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:rtAiChatChartFormat`; scenarios `SC-UKV-1352`, `SC-UKV-1353`, `SC-UKV-1354`
- **`number` keeps up to 2 fraction digits, `percent` up to 1, `currency` the digits of its currency.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.data.ts:optionsOf`; scenario `SC-UKV-1352`
- **A currency code that is not three capital letters accepted by `Intl.NumberFormat` makes the spec invalid.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.check.ts:rtAiChatChartIsCurrency`; scenario `SC-UKV-1374`
- **The formats take the locale of the kit labels: a drawn chart follows a change of that locale, and the copy reads it at the moment of the copy.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/plot/rt-ai-chat-chart-plot.component.ts:data`, the copy — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.providers.ts:provideRtAiChatChart`; scenario `SC-UKV-1370`
- **The category labels never overlap: the block shows every n-th label so that each fits its width.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartLabelEvery`; scenario `SC-UKV-1368`
- **The legend stands under the plot and never covers the axis labels, at any number of series and any length of category names.** — `projects/ui-kit-v2/src/lib/components/chart/rt-chart.cartesian.ts:legendOf`; scenario `SC-UKV-1355`
- **The colours of the series are the eight series tokens of the chart, in the light and the dark theme.** — `projects/ui-kit-v2/src/lib/components/chart/rt-chart.scene.ts:rtChartSlot`; scenario `SC-UKV-1369`
- **Sectors and top-level tree groups take the eight tokens in turn; a ninth item repeats the first.** — `projects/ui-kit-v2/src/lib/components/chart/rt-chart.scene.ts:rtChartSlot`; scenario `SC-UKV-1369`
- **«Open full screen» opens the kit dialog whose chart fills the dialog height, with «Download PNG» there too.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:openFullScreen`, the height — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/dialog/rt-ai-chat-chart-dialog.component.ts:FULL_HEIGHT`; scenario `SC-UKV-1356`
- **«Close» or Escape closes the full-screen dialog, and focus returns to «Open full screen».** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:openFullScreen`; scenario `SC-UKV-1356`
- **«Download PNG» saves the chart as a PNG file named by the title of the spec, by the name rule of Q-12.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:download`, the name — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartFileName`; scenario `SC-UKV-1357`
- **When the chart is not drawn yet, «Download PNG» is disabled.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/block/rt-ai-chat-chart.component.ts:drawn`; scenario `SC-UKV-1365`
- **The chart's accessible name is the title of the spec; without a title it is the kit label «Chart».** — `projects/ui-kit-v2/src/ai-chat-chart/lib/components/plot/rt-ai-chat-chart-plot.component.ts:label`; scenario `SC-UKV-1371`
- **The kit exports the spec schema from the entry.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.schema.ts:RT_AI_CHAT_CHART_SCHEMA`; scenario `SC-UKV-1358`
- **Every spec the block accepts, the schema accepts. The schema also accepts a spec the block refuses only when it holds more than 200 distinct leaves after equal paths are summed.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.check.ts:checkHierarchy`; scenarios `SC-UKV-1358`, `SC-UKV-1360`
- **The copy is the title, the subtitle, then one line per series `name: x — y; x — y`.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartText`; scenario `SC-UKV-1359`
- **In the copy the trees give one line per leaf, the path joined by « / », then « — » and the value; a histogram writes `x` as the bin `low–high`.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:leavesOf`, the bin — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:xTextOf`; scenario `SC-UKV-1366`
- **A pending or an invalid block gives nothing to the copy.** — `projects/ui-kit-v2/src/ai-chat-chart/lib/ai-chat-chart.view.ts:rtAiChatChartBlockText`; scenario `SC-UKV-1367`

# What it is carried out by — delta unit and «growth is worse» on the stat tile

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **The unit is set on the delta row, and percent is the default.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.model.ts:unit`, `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:deltaRow`; scenario `SC-UKV-1125`
- **The two rows of one tile may carry different units.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:yearDelta`; scenario `SC-UKV-1127`
- **Points are written by a kit label with a value parameter.** — `projects/ui-kit-v2/src/lib/i18n/rt-kit-labels.en.ts:uiPercentagePoints`, `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:deltaRow`, `projects/ui-kit-v2/src/lib/util/delta-number.ts:rtDeltaNumber`; scenario `SC-UKV-1126`
- **A row with an unknown base is not drawn in any unit.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:#visibleDelta`; scenario `SC-UKV-1128`
- **«Growth is worse» is a tile sign, and it paints both rows.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:growthIsWorse`, `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:growth-worse`; scenarios `SC-UKV-1129`, `SC-UKV-1130`, `SC-UKV-1131`
- **The arrow shows the sign of the number whatever the «growth is worse» sign.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:deltaRow`, `projects/ui-kit-v2/src/lib/util/delta-number.ts:rtDeltaNumber`; scenarios `SC-UKV-1129`, `SC-UKV-1130`
- **A tile without the «growth is worse» sign paints its rows as now.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:direction--up`; scenario `SC-UKV-1132`
- **The tile has a value size option: the default keeps the value at 32/32, the compact size writes it at 24/24 and the delta at 14.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:size`, `compact`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:compact`; scenarios `SC-UKV-1453`, `SC-UKV-1454`
- **The compact size sets the gaps of the tile to 6, `calc(var(--rt-space-1) + var(--rt-space-0-5))`, and puts the delta line on a line of its own under the value.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:compact` sets `rt-stat-tile__value-row` to a column; scenario `SC-UKV-1468`
- **In the compact size the secondary line and the base caption wrap between words; the default size keeps each on a single line with an ellipsis.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:compact`, `__secondary`; scenario `SC-UKV-1467`
- **The tile writes both delta rows, the primary delta and the year chip, by `Intl.NumberFormat` for the kit label locale, with a plus on growth and no sign at zero.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:#written` reads `#locale`; `projects/ui-kit-v2/src/lib/util/delta-number.ts:rtDeltaNumber`; scenarios `SC-UKV-1455`, `SC-UKV-1466`, `SC-UKV-1470`
- **A tile delta keeps at most one fraction digit and none when it is integral: 3.75 is «+3,8 %», -4 is «-4 %».** — `projects/ui-kit-v2/src/lib/util/delta-number.ts:DELTA_OPTIONS`, `asFraction`; scenario `SC-UKV-1469`
- **A locale `Intl.NumberFormat` refuses writes the tile delta as `en`.** — `projects/ui-kit-v2/src/lib/util/delta-number.ts:deltaFormat`; scenario `SC-UKV-1471`
- **The direction, the arrow and the colour of a delta follow the written number: a delta written as zero, such as 0.04 or -0.04 written «0 %», has no sign, is flat and muted.** — `projects/ui-kit-v2/src/lib/util/delta-number.ts:rtDeltaNumber`; `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:deltaRow`; scenario `SC-UKV-1456`
- **The tile can show the label of the primary delta as visible text after the delta; the option is off by default, and with it on the delta carries no `title` of the same text.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.ts:deltaLabelVisible`, `primaryCaption`, `primaryTitle`; scenarios `SC-UKV-1451`, `SC-UKV-1453`
- **«Growth is worse» of the tile, its colours and its arrow do not change; the KPI card maps `growthIsGood: false` to it.** — `projects/ui-kit-v2/src/lib/components/stat-tile/rt-stat-tile.component.scss:growth-worse`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/kpi/rt-ai-chat-kpi.component.ts:card`; scenario `SC-UKV-1448`

# What it is carried out by — the look of a field under the material preset

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenarios it is checked by; what exactly every scenario is covered by is said in
`scenarios.md`. The preset values live in `projects/ui-kit-v2/src/styles/_preset-material.scss`, the
kit-look values of the same properties in `projects/ui-kit-v2/src/styles/_semantic.scss`.

- **The preset sign on the field itself puts the label inside, the same as the sign on an ancestor.** — `projects/ui-kit-v2/src/lib/components/field/rt-field-label-inside.scss:label-inside`, `projects/ui-kit-v2/src/lib/components/input/rt-input-floating-label.scss:preset`; scenario `SC-UKV-950`
- **A density step set on an ancestor reaches a field that carries its own preset sign.** — `projects/ui-kit-v2/src/styles/_density.scss:rt-input-density`, `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-height-app`; scenarios `SC-UKV-941`, `SC-UKV-949`
- **Under the preset a filled field follows the Material filled field.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-fill-focus-shadow`, `projects/ui-kit-v2/src/lib/components/field/rt-field-label-inside.scss:rt-field-floating-start`, `projects/ui-kit-v2/src/lib/components/input/rt-input-floating-label.scss:rt-input-fill-floating-height`; scenario `SC-UKV-951`
- **Under the preset the placeholder, the resting label, the icons and the arrow take the Material theme's muted colour, and the caret takes the brand colour.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-icon-color`, `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-caret-color`, the icon size and place — `projects/ui-kit-v2/src/lib/components/input/rt-input-icons.scss:rt-input-icon-size`; scenario `SC-UKV-952`
- **Under the preset the required mark stands right after the label.** — `projects/ui-kit-v2/src/lib/components/field/rt-field.component.scss:rt-field-required-gap`, `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-field-required-gap`; scenario `SC-UKV-953`
- **A field's least width is a property set on an ancestor.** — `projects/ui-kit-v2/src/lib/components/input/rt-input.component.scss:rt-input-min-width`, `projects/ui-kit-v2/src/lib/components/select/rt-select.component.scss:rt-input-min-width`, the zero default — `projects/ui-kit-v2/src/styles/_semantic.scss:rt-input-min-width`; scenario `SC-UKV-955`
- **An icon button inside a field is never taller than the field inside its border.** — `projects/ui-kit-v2/src/lib/components/input/rt-input-icons.scss:__clear`, `projects/ui-kit-v2/src/lib/components/select/rt-select-clear.scss:__clear` — the button size is capped by the field height less two borders; scenario `SC-UKV-956`
- **Under the preset the text of a field starts 16 px from its outer edge.** — `projects/ui-kit-v2/src/lib/components/input/rt-input.component.scss:rt-input-edge`, `projects/ui-kit-v2/src/lib/components/textarea/rt-textarea.component.scss:rt-textarea-edge`; scenario `SC-UKV-957`
- **Under the preset a disabled field is not faded as a whole.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-disabled-field-opacity`, `projects/ui-kit-v2/src/lib/components/input/rt-input.component.scss:rt-input-disabled-field-opacity`; scenario `SC-UKV-958`
- **Under the preset the clearing cross is the first kit's cross.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-clear-size`, `projects/ui-kit-v2/src/lib/components/input/rt-input-icons.scss:rt-input-clear-size`; scenario `SC-UKV-959`
- **Under the preset the cross lies on the first kit's round grey ground.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-clear-bg`, `projects/ui-kit-v2/src/lib/components/input/rt-input-icons.scss:rt-input-clear-bg`, `projects/ui-kit-v2/src/lib/components/select/rt-select-clear.scss:rt-input-clear-bg`; scenario `SC-UKV-962`
- **Under the preset the line under a field is Material's subscript.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-field-messages-padding-top`, `projects/ui-kit-v2/src/lib/components/field/rt-field.component.scss:rt-field-messages-line-height`; scenario `SC-UKV-960`
- **A textarea has the filled look of an input.** — `projects/ui-kit-v2/src/lib/components/textarea/rt-textarea.component.scss:appearance--fill`, the label inside — `projects/ui-kit-v2/src/lib/components/textarea/rt-textarea.component.scss:rt-field__label-row`; scenarios `SC-UKV-961`, `SC-UKV-967`
- **Under the preset a value drawn by an option template does not raise the select.** — `projects/ui-kit-v2/src/lib/components/select/rt-select-material.scss:__option-content`; scenario `SC-UKV-966`
- **Under the preset a clearable input keeps Material's right inset.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-clear-offset-start`, `projects/ui-kit-v2/src/lib/components/input/rt-input-icons.scss:rt-input-clear-offset-start`; scenario `SC-UKV-964`
- **Under the preset a disabled filled field is filled with on-surface 4 %.** — `projects/ui-kit-v2/src/styles/_preset-material.scss:rt-input-fill-color-bg-disabled`, `projects/ui-kit-v2/src/lib/components/input/rt-input.component.scss:rt-input-fill-color-bg-disabled`; scenario `SC-UKV-965`
- **Under the preset an icon button stands where a plain icon stands.** — `projects/ui-kit-v2/src/lib/components/input/rt-input-icons.scss:rt-input-icon-overhang`; scenario `SC-UKV-963`

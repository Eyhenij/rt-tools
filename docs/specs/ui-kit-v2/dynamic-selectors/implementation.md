# What it is carried out by — the dynamic selectors

The rule of the subdomain is on the left, the place where it is carried out is on the right. The
paths are given from the root of the tree.

- **The value of the selector is an array of keys, in the order of the chosen list.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:#change`
- **The value the form writes becomes the chosen list and the initial value at once.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:writeValue`
- **Reset returns the initial value, and it is off while the list equals it in the same order.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onReset`. The off state is `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:sameDynamicKeys`
- **Clear keeps only the read-only keys, in the order of the value.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:clearDynamicKeys`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onCleared`
- **A row of a read-only key cannot be removed from the chosen list.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onRemoved`. The disabled button stands at `projects/ui-kit-v2/src/lib/components/dynamic-selector/list/rt-dynamic-selector-list.component.html:row.locked`
- **A dragged row moves one key in the value.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:moveDynamicKey`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onMoved`
- **The popup offers only the entities that are not chosen yet and whose label is a string or a number.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:selectableDynamicItems`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:offered`
- **The local search keeps a row whose label holds every word of the query.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:dynamicSelectorMatches`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:found`
- **The server search hands the query to the caller 500 ms after the last keystroke and filters nothing itself.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:RT_DYNAMIC_SELECTOR_SEARCH_DEBOUNCE`, the query leaves by `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:searchChange`
- **During a search the rows ticked before the query last changed stay above the results, separated from them.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:dynamicPopupRows`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:rows` with the ticks that `onQueryChange` keeps in `raised`
- **Select all works on the visible rows only.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:selectAllDynamicKeys`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:onSelectAll`
- **In single mode the popup holds radio buttons, and apply replaces the chosen list with one key.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:onRadioChange`. The replacement stands at `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onApplied`
- **With the multi toggle off, a plain click leaves one tick, and Ctrl-click adds a tick.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:onRowClick`
- **Apply appends the ticked keys to the chosen list and closes the popup.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onApplied`
- **Cancel, Escape and a click outside close the popup and drop the ticks.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onCancelled`. The ticks live in the popup view, which the popover creates anew at every opening: `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.html:popupTpl`
- **The popup reports its ticks by the temporary choice output.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:temporaryChoiceChange`
- **The end of the popup list asks for the next page when lazy loading is on.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.html:rtInfiniteScroll`
- **A popup with no rows to show says «No results», and a loading popup shows a spinner.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.html:dynamic-selector-no-results`
- **A divider follows the last visible pinned row of the popup.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:lastPinnedDynamicKey`, called by `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:lastPinnedKey`
- **The add button stands while the popup has something to offer.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:isAddShown`
- **A selector with nothing chosen, no query and nothing to choose shows «There are no available items to choose» and no buttons.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:isNothingToChoose`
- **While the caller turns the invitation on, it replaces the row of buttons.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.html:invitation`
- **A disabled selector keeps the add, reset and clear buttons off.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:isDisabled`, passed to the chosen list at `projects/ui-kit-v2/src/lib/components/dynamic-selector/list/rt-dynamic-selector-list.component.html:disabled`
- **A key no entity holds stays in the value and draws no row.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:#entitiesOf`
- **An empty array written by the form empties the chosen list.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:writeValue`
- **The popup footer shows a navigation link when the caller names its title and address.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/popup/rt-dynamic-selector-popup.component.ts:isNavShown`
- **The caller can add controls to every row and replace the row title.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.directives.ts:RtDynamicSelectorRowControlsDirective` and `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.directives.ts:RtDynamicSelectorRowTitleDirective`
- **The value of the string list is an array of strings.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/dynamic-input/rt-dynamic-input.component.ts:RtDynamicInputComponent`
- **Enter or leaving the field of the string list adds the trimmed text to the end and hides the field.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/dynamic-input/rt-dynamic-input.component.ts:onCommit`. The trimming is `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:addDynamicText`
- **A text already in the string list is not added a second time.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:addDynamicText`
- **The icon buttons of the list are round unless the caller names another rounding step.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/list/rt-dynamic-selector-list.component.ts:buttonRadius`; the selector passes it on by `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:buttonRadius`, the string list by `projects/ui-kit-v2/src/lib/components/dynamic-selector/dynamic-input/rt-dynamic-input.component.ts:buttonRadius`
- **The popup opens from the add button that was pressed.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.component.ts:onAdd`
- **A dragged row keeps its background and paddings in flight.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/list/rt-dynamic-selector-list.component.scss:cdk-drag-preview`
- **Editing a row of the string list is on only when the caller turns it on.** — `projects/ui-kit-v2/src/lib/components/dynamic-selector/list/rt-dynamic-selector-list.component.ts:editable`. The edit is applied by `projects/ui-kit-v2/src/lib/components/dynamic-selector/rt-dynamic-selector.logic.ts:renameDynamicText`

The scenarios of the subdomain are bound to the tests by the number in the title of a test, not by a
table here: the bond is checked both ways by the checking of the specs.

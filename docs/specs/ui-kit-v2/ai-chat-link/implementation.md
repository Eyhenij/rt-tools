# What it is carried out by — the link block of the assistant chat

The first column is the rule of the spec next to it verbatim. The second is where it is carried out
in the tree, and the scenario it is checked by.

- **`link` is a type the kit draws itself, next to `markdown`, `notice`, `table` and `kpi`; an application gets it without registering anything, and a renderer registered for `link` is not taken.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:OWN_TYPES`, `toBlockViews`; scenario `SC-UKV-1487`
- **A link block has `title` and `url`, and the optional `section`, `icon`, `state` and `reason`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.model.ts:LinkBlock`; `projects/ui-kit-v2/src/lib/util/link-data.ts:rtLinkData`; scenario `SC-UKV-1489`
- **A link block whose `title` or `url` is not a string, or is empty after trimming, is shown as the plate with its type name, like a KPI block without a card.** — `projects/ui-kit-v2/src/lib/util/link-data.ts:rtLinkData` gives `null`, and `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:linkBlockData`, `toBlockViews` show the plate; scenario `SC-UKV-1488`
- **The title, the section, the reason and the address are trimmed; the card draws, the event carries and the copy writes the trimmed text.** — `projects/ui-kit-v2/src/lib/util/link-data.ts:rtLinkData`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:copyField`; scenario `SC-UKV-1489`
- **A malformed optional part is absent, not refused.** — `projects/ui-kit-v2/src/lib/util/link-data.ts:rtLinkData`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:FALLBACK_ICON`, `icon`; scenario `SC-UKV-1489`
- **A card whose `state` is not `pending`, `opened` or `failed`, or is absent, draws no status and keeps both buttons enabled.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:STATUS_LOOK`; scenario `SC-UKV-1489`
- **A `reason` is drawn only in the `failed` state; a `failed` block without a reason draws no reason line.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:reason`; scenario `SC-UKV-1492`
- **A new answer with the same block holding another state redraws the same card: a card that came as `pending` and was replaced by `opened` shows the new status.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:data`; scenario `SC-UKV-1495`
- **The kit exports the JSON schema of the link block (JSON Schema 2020-12), so that an application gives it to the model as the parameters of a tool.** — `projects/ui-kit-v2/src/lib/util/link.schema.ts:RT_AI_CHAT_LINK_SCHEMA`; scenario `SC-UKV-1497`
- **A block the schema accepts is drawn as a card with nothing dropped.** — `projects/ui-kit-v2/src/lib/util/link.schema.ts:RT_AI_CHAT_LINK_SCHEMA`, `projects/ui-kit-v2/src/lib/util/link-data.ts:rtLinkData`; scenario `SC-UKV-1497`
- **The card has two buttons: «Open» opens the page in place, «Open in new tab» opens it in a new tab.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.html:rtButton`; scenario `SC-UKV-1493`
- **A press of «Open» makes `rt-ai-chat` emit `linkOpen` with the message id, the address and `newTab: false`; a press of «Open in new tab» emits the same with `newTab: true`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:onOpen`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:onLinkOpen`, `linkOpen`; scenarios `SC-UKV-1493`, `SC-UKV-1494`
- **The chat emits `linkOpen` synchronously, inside the press handler.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:onLinkOpen`; scenario `SC-UKV-1493`
- **In the `pending` state both buttons are drawn disabled, are `aria-disabled="true"`, keep the keyboard focus and emit nothing on a press; in the other states both are enabled.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.html:aria-disabled`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:pending`; scenario `SC-UKV-1490`
- **The buttons follow the state alone, whether the answer is still being written or not.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:pending`; scenario `SC-UKV-1490`
- **The kit does not change the state on a press.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:onOpen`; scenario `SC-UKV-1493`
- **The chat emits `linkOpen` on every enabled press; the kit does not merge repeated presses.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/rt-ai-chat.component.ts:onLinkOpen`; scenario `SC-UKV-1494`
- **The status is an `rt-tag` of the size `sm`, solid, with an icon before its label.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:STATUS_LOOK`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.html:rt-tag`; scenarios `SC-UKV-1490`, `SC-UKV-1491`, `SC-UKV-1492`
- **The `pending` spinner turns, as `rt-icon` turns it, and under reduced motion it turns slowly.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.html:iconSpin`; `projects/ui-kit-v2/src/lib/components/tag/rt-tag.component.ts:iconSpin`; scenarios `SC-UKV-1490`, `SC-UKV-1506`
- **The status labels are kit labels: «Opening», «Opened» and «Failed to open» by default.** — `projects/ui-kit-v2/src/lib/i18n/rt-kit-labels.en.ts:aiLinkOpening`, `aiLinkOpened`, `aiLinkFailed`; scenario `SC-UKV-1501`
- **A change of the state of a drawn card is announced by the polite region of the feed, naming the card: «<title>: Opened», «<title>: Failed to open. <reason>».** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:announced`; scenario `SC-UKV-1495`
- **The card takes the width of the answer and never widens the feed.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:min-width`
- **The card frame takes kit tokens only.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:rt-ai-chat-link-radius`; scenario `SC-UKV-1505`
- **The row has the icon box on the start side and the text column next to it, 12 apart.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:rt-ai-chat-link-icon-radius`
- **The title is 14 SemiBold in the primary text colour, the section 12 Regular muted, the reason 12 Regular in `--rt-color-state-error-text`.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:rt-leading-tight`, `rt-leading-snug`
- **The title and the section stand 2 apart; the status stands 6 under them, and the reason 6 under the status, in the text column.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:rt-space-0-5`
- **The title takes at most two lines and ends with an ellipsis; the section takes one line with an ellipsis.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:line-clamp`; scenario `SC-UKV-1498`
- **The two buttons are of the size `sm` and the theme `primary`, 8 apart, under the row of the card: «Open» is outlined, «Open in new tab» is a text button with the `external-link` icon.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.html:rtButton`; `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:flex-wrap`; scenario `SC-UKV-1503`
- **Under `dir="rtl"` the row and the buttons mirror; the icons are drawn as they are.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:flex-direction`; scenario `SC-UKV-1504`
- **In the dark theme the danger status reads at 2.94 : 1 and the reason line at 3.16 : 1, below the 4.5 : 1 of AA.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.scss:rt-color-state-error-text`; scenario `SC-UKV-1505`
- **The answer copy gives a link block as one line: the title, the section and the address, separated by a tab; an absent section is an empty field.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:linkPlainText`; scenario `SC-UKV-1496`
- **The status and the reason are not copied: they describe the minute of the opening, not the page.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:linkPlainText`; scenario `SC-UKV-1496`
- **A tab or a line break inside a text becomes a space.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/rt-ai-chat-blocks.logic.ts:copyField`; scenario `SC-UKV-1496`
- **The card is a group named by its title, so that the two buttons of several cards are told apart.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.ts:role`; scenario `SC-UKV-1499`
- **The icon of the card is hidden from a screen reader.** — `projects/ui-kit-v2/src/rich-editor/lib/components/ai-chat/blocks/link/rt-ai-chat-link.component.html:aria-hidden`; scenario `SC-UKV-1499`
- **The labels «Open» and «Open in new tab» are kit labels.** — `projects/ui-kit-v2/src/lib/i18n/rt-kit-labels.en.ts:aiLinkOpen`, `aiLinkOpenNewTab`; scenario `SC-UKV-1501`

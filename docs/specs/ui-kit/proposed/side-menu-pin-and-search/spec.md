# Закреплённое подменю бокового меню и поиск по нему

**Статус:** предложено · **Ревизия:** 2026-08-31 · **Префикс сценариев:** `SC-UK`
**Зависимости:** нет
**Законы:** `frontend-application`, `reuse-first`
**Процедуры:** нет

Предмет — второй уровень бокового меню `rtui-side-menu`: то, чем он держится открытым, и то,
чем в нём находят нужный пункт.

## Зачем

Подменю сегодня живёт ровно столько, сколько на нём стоит указатель. Человек, который весь день
работает в одном разделе, открывает его заново на каждый переход, а уведя мышь мимо — теряет и
то, что успел прочитать. Это стоит действия на каждый переход и делает боковое меню
непригодным для работы с большим разделом.

Второе: подменю раскладывается только глазами. У раздела с двумя десятками пунктов человек ищет
нужный перебором, и длина списка растёт вместе с приложением, а способ поиска остаётся прежним.

## Терминология

| Термин               | Что это                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| Подменю              | Второй уровень бокового меню: пункты, вложенные в пункт главного списка |
| Шторка подменю       | Панель, в которой подменю показано на широком экране                    |
| Мода подменю         | Чем подменю держится открытым: наведением или закреплением              |
| Закреплённое подменю | Подменю, которое стоит открытым, пока человек сам его не свернёт        |
| Активный пункт       | Пункт главного списка, названный входом активности                      |
| Запрос               | Строка, набранная в поле подменю                                        |
| Отбор                | Пункты подменю, подпись которых содержит запрос                         |

### Как это называется в интерфейсе

| В домене             | На экране                                                        |
| -------------------- | ---------------------------------------------------------------- |
| Мода подменю         | переключатель со значком булавки в самом подменю                 |
| Закреплённое подменю | подменю, стоящее рядом с главным списком и не гаснущее страницей |
| Запрос               | поле со значком лупы над списком пунктов                         |
| Пустой отбор         | строка сообщения вместо списка                                   |

## Правила

### Мода подменю

- **Мода приходит входом, и умолчание — сегодняшнее поведение.** Потребитель, не назвавший
  моду, получает подменю, которое открывается наведением и закрывается уходом указателя.
- **Нажатие переключателя моду не меняет, а просит её.** Кит отдаёт наружу моду, которую
  человек попросил, и ждёт её обратно входом. Предпочтение хранит потребитель: своего состояния
  о нём кит не заводит и в хранилище браузера не ходит.
- **Закреплённое подменю показывает активный пункт.** Какой пункт активен, кит узнаёт входом
  активности; своего вычисления по адресу у него нет.
- **Активного пункта нет — закреплённого подменю нет.** Пустое место вместо подменю честнее
  подменю наугад.
- **Закреплённое подменю не закрывается ни уходом указателя, ни переходом по своему пункту.**
  Иначе закрепление отменяется первым же действием человека.
- **Под закреплённым подменю нет подложки.** Подложка гасит остальную страницу и ловит нажатия;
  у панели, стоящей открытой постоянно, это делает страницу нерабочей.

### Поиск по подменю

- **Поле ищет по открытому подменю, а не по всем разделам.** Результат остаётся принадлежащим
  разделу: иначе это другой предмет — поиск по приложению.
- **Отбор идёт по подстроке подписи без учёта регистра.**
- **Пустой запрос показывает подменю целиком.**
- **Совпадений нет — подменю говорит об этом строкой.** Пустая панель неотличима от поломки.
- **Запрос живёт, пока подменю открыто.** Он не предпочтение: закрытое и открытое заново
  подменю показывает всё.

### Подписи

- **Подписи поля, переключателя и пустого отбора зашиты по-английски.** Словаря у кита нет, и
  соседняя подпись — кнопка возврата к главному списку — зашита тем же способом.

## Что не входит

- Узкая раскладка закрепления не знает: подменю там занимает экран целиком, и закреплять нечего.
  Переключателя на узком экране нет, поле поиска есть.
- Своего вычисления активного пункта по адресу кит не заводит: активность приходит входом.
- Поиск по всему приложению — другой предмет: его результат разделу не принадлежит.
- Отдельного компонента подменю не заводится: второй уровень остаётся частью `rtui-side-menu`.

## Данные

Не применимо: своих записей хранилища домен не заводит. Предпочтение моды хранит потребитель
кита, а запрос поиска живёт, пока открыто подменю.

## Экраны и состояния

Своих экранов у домена нет — есть состояния подменю внутри чужого экрана:

| Состояние            | Что видно                                           |
| -------------------- | --------------------------------------------------- |
| Свёрнуто             | только главный список пунктов                       |
| Открыто наведением   | шторка подменю поверх страницы, под ней подложка    |
| Закреплено           | подменю стоит рядом с главным списком, подложки нет |
| Отбор с совпадениями | список из пунктов, подпись которых содержит запрос  |
| Отбор пустой         | строка сообщения вместо списка                      |
| Активного пункта нет | при закреплённой моде подменю не открыто вовсе      |

## Сквозные требования

### Локали

Словаря у кита нет. Три новые подписи — подсказка поля, имя переключателя и строка пустого
отбора — зашиты по-английски, как кнопка возврата к главному списку рядом.

### SEO

Не применимо: боковое меню живёт внутри приложения за входом.

### Мобильная раскладка

Подменю замещает главный список целиком, шторки и подложки там нет вовсе. Поле поиска есть,
переключателя моды нет: закреплять нечего.

### Мультиобъектность

Не применимо: у кита нет объектов владения.

## Решения

- **Мода приходит входом, а нажатие переключателя уходит выходом** — предпочтение хранит
  потребитель. Отвергнуто: держать моду внутри кита — тогда предпочтение живёт до перезагрузки
  страницы и только на той вкладке, где его нажали.
- **Закреплённое подменю показывает активный пункт** — вход активности у компонента уже есть.
  Отвергнуто: последний открытый пункт — он расходится с адресом страницы после перехода по
  ссылке мимо меню.
- **Под закреплённым подменю нет подложки** — она гасит остальную страницу и ловит нажатия.
  Отвергнуто: оставить подложку и гасить её прозрачностью — нажатия она ловит и невидимой.
- **Отбор считает чистая функция, а не разметка** — шаблон компонента держит две раскладки
  разом. Отвергнуто: отбор выражением в шаблоне.
- **Подписи зашиты по-английски** — слово владельца; словаря у кита нет. Отвергнуто: входы с
  умолчанием и заведение словаря.

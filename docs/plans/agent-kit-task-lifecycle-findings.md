# Находки разбора закрытых работ эпика RT-974

Эпик «Работа не стоит между ходами» закрыт 22 августа 2026 года, и его замысел уехал в описание
прошлого записью «agent-kit-task-lifecycle-line» — она отстояла свой срок и снята, а найти её
можно в истории по имени файла.

## Разобрано 29 августа 2026 года задачей RT-1553

Девять пунктов трёх разборов сведены с нынешними ресурсами пакета. Закрытыми оказались шесть, и
они сняты отсюда:

| Пункт                                          | Чем закрыт                                                                   |
| ---------------------------------------------- | ---------------------------------------------------------------------------- |
| раскладка не кладёт объявление хука            | задача RT-1206: объявление едет вместе с хуком, сверка его читает            |
| правило ведения работы упёрлось в предел длины | задача RT-1204 и деление правила: холодная часть уехала своим файлом         |
| порядок закрытия: вливание после прогонов      | паттерн закрытия ставит прогон после вливания и приведения текстов           |
| порог остановки и порог сжатия сведены         | страж окна разводит их сам — задача RT-997                                   |
| набор гейта зовёт сверку раскладки поздно      | сверка стоит первой строкой набора, до сборок и прогонов                     |
| правило зовёт роли безусловно                  | раздел о выключенной роли: выключается обязательность вызова, а не сама роль |

Два внесены правкой ресурсов той же задачей:

| Пункт                                       | Куда легло                                                                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| красный набор на нетронутой ветке           | паттерн возвращения к работе: соседние заходы спрашиваются раньше своей правки                                                 |
| ответ владельцу и необещанное подтверждение | холодная часть правила хода: ответ на реплику ход не кончает, работа не гейтится на подтверждение, которого владелец не обещал |

## Отпало

- **Ход начинается репликой человека.** Изнутри захода это не закрывается: инструмента, который
  отправит реплику себе, у исполнителя нет. Закрывается снаружи — обвязкой машины, а не слоем
  правил, и в ресурсах пакета места этому нет.

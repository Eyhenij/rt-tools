# Angular Doctor: формы на signal forms, имена файлов по классам и тесты рядом с исходниками

**Эпик:** RT-3568 · **Ветка эпика:** `RT-3568-ngdoctor-big-changes`

## Что даёт

Angular Doctor больше не держит в пороге трёх больших групп находок. Формы кита, cms, админки и
темы входа собраны на signal forms Angular. Имя каждого файла совпадает с именем его класса. У
каждого компонента, директивы, пайпа, сервиса и обёртки витрины есть тест рядом.

Эпик вынесен из эпика Angular Doctor (RT-3476) словом владельца 23.11.2026: большие изменения в
том эпике не делаются, они уходят в новый эпик, а RT-3476 доводится до конца. Задачи RT-3486…RT-3490
были заведены в RT-3476 и перешли сюда целиком.

## Точки

- **A:** порог `check:ngdoctor` на ветке RT-3476 после RT-3485: `prefer-signal-forms` 97,
  `filename-class-mismatch`, `file-hyphen-case` и `project-layout` около 550,
  `missing-spec-file` около 530.
- **B (RT-3486, RT-3487):** формы на signal forms. Signal forms в Angular 22 ещё помечены
  экспериментальными, а перевод полей кита меняет входы, которые видит потребитель: выпуск кита —
  решение владельца. Признак: вывод `--json` не называет `prefer-signal-forms`.
- **C (RT-3488):** имена файлов по классам; имена публичных классов не меняются, сгенерированный
  код prisma и protobuf и правило `project-layout` — вопросы владельцу. Признак: вывод `--json` не
  называет трёх правил, кроме того, что владелец оставит.
- **G (веха эпика):** RT-3489 и RT-3490 — тесты рядом; порог `check:ngdoctor` без всех трёх групп.
  Признак: `pnpm run check:ngdoctor` на ветке эпика.

## Как стоят ветки

Ветка эпика отведена от главной после слияния эпика RT-3476: до него главная не мерит себя
Angular Doctor. Ветки задач — стопкой, каждая от предыдущей, PR задач идут в предыдущую ветку.

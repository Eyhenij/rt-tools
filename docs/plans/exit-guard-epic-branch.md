# Проверка выхода из хода не знает ветку эпика и конец эпика

**Эпик:** RT-2228 · **Ветка эпика:** `RT-2228-exit-guard-epic-branch`

17.09.2026 исполнитель получил три отказа проверки выхода из хода подряд на законной остановке в
конце эпика RT-2190: два на ветке эпика ярусом «работа взята и не начата», один на `main` после
слияния ярусом «последнее действие не работа». Ярус узнаёт ветку задачи по форме
`<КЛЮЧ>-<номер>-…` и отсутствию папки, а ветка эпика той же формы и папки по правилу не несёт.
Признак конца эпика снимает в проверке выхода только ярус «жду твоего слова», хотя правило обещает
общее чтение с проверкой ожидания.

## Что даёт

Ход на ветке эпика, названной в плане эпика строкой «Ветка эпика», не читается как задача без
папки. Конец эпика, прочитанный по таблице, отпускает ход целиком, как в проверке ожидания. На
`main` номер эпика не читается, там ход судится как прежде, и правило говорит это словами.
Описание домена выхода несёт сценарии на оба случая, тесты пакета их держат.

## Как стоят ветки

Ветка эпика отведена от главной, PR задач идут в неё. Задачи стоят стопкой: вторая от первой,
потому что обе правят одни файлы проверки, её описание и тесты.

## Чего эпик не делает

- Не читает номер эпика на `main` из последнего слияния в главную ветку: это отпускало бы ход по
  чужому эпику. Отложено до слова владельца.
- Не правит проверку ожидания: она уже отпускает конец эпика.
- Не правит таблицу эпика и аудит доски.

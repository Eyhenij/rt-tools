**Эпик:** RT-3564 · **Ветка эпика:** `RT-3564-intake-0-40`

## Что даёт

Первая тройка задач приёмника перед выпуском кита 0.40.0, по слову владельца 23.11: «бери по 2
замечания и по 1 одному предложения в каждый выпуск», «заводи новый эпик под каждые 2+1 задачи».
Третья задача тройки, RT-3535, сделана в эпике #3471.

## Точки

- **A:** после одобрения плана с невидимой правкой кита исполнитель задаёт второй вопрос «вид не
  меняется?»; задача, заведённая вне эпика, стоит на втором шаге движка.
- **B (RT-3563):** владелец одобряет такой план один раз. Признак: правило `kit-approval` называет
  одобрение плана ответом «без вида».
- **B (RT-3565):** работа вне эпика по слову владельца идёт дальше второго шага. Признак: случай в
  наборе проверки движка.
- **G (веха эпика):** обе правки вошли в выпуск кита 0.40.0. Признак: `npm view @rt-tools/agent-kit
  version` → 0.40.0.

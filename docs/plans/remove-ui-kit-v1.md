# Первый кит удалён из репозитория

**Эпик:** RT-3232 · **Ветка эпика:** `RT-3232-remove-ui-kit-v1`

## Что даёт

Владелец 12.11.2026: «удали полностью первый кит и весь связанный код». 14.11.2026: «первым делом
нужно полностью удалить ui kit v1». Пакет `@rt-tools/ui-kit` больше не развивается, а его витрина,
снимки, сборка и проверки идут в каждой отправке ветки. После эпика в репозитории остаётся один
кит — `@rt-tools/ui-kit-v2`, и отправка ветки перестаёт платить за первый.

## Объём по измерению 14.11.2026

- `projects/ui-kit` — 490 файлов. Код других пакетов и приложений его не импортирует: поиск
  `from '@rt-tools/ui-kit'` по `apps`, `libs` и `projects` вне самого кита пуст.
- Описание домена `docs/specs/ui-kit` — 15 файлов.
- Ссылки вне кита — около 60 файлов: путь в `tsconfig.base.json`, команды в `package.json`, шаг
  снимков в `.github/workflows/ci.yml`, конвейер выпуска `.github/workflows/publish.yml`, настройки
  линтеров, инструменты в `tools/`, сценарии в `projects/agent-kit/tests`, правила и паттерны
  дерева, профиль дерева, `README.md`, `CLAUDE.md`, скрипты версий `update-version.cjs`.
- Шаг набора перед отправкой `node tools/visual-gate.mjs ui-kit` уходит вместе с пакетом.

## Как стоят ветки

Три задачи друг за другом. Ветка каждой отведена от ветки эпика, PR задачи идёт в ветку эпика.

## Состав

| #   | Задача                                                                | Состояние |
| --- | --------------------------------------------------------------------- | --------- |
| 1   | RT-3304 — первый кит, его описание, инструменты и проверки удалены    | влита     |
| 2   | RT-3308 — остатки первого кита убраны, в дереве есть knip             | влита     |
| 3   | RT-3310 — находки knip: файлы, зависимости и экспорты без потребителя | в работе  |

Удаление задумано одной задачей: каждая лишняя ветка — ещё одна отправка с полным набором
проверок. Вторая задача появилась после проверки эпика ролью `goal-critic`: она нашла остатки
первого кита. Слово владельца 14.11.2026: «Вторая задача в эпике», затем «заведи задачу в эпике
3232 и добавь knip». Третья — находки knip, не связанные с первым китом: слово владельца 14.11.2026
«Верни в эпик».

## Признак готовности

- Каталогов `projects/ui-kit` и `docs/specs/ui-kit` нет.
- Поиск по `@rt-tools/ui-kit` без `-v2` находит только архив и журналы изменений.
- `pnpm run check:all` и набор перед отправкой зелёные.
- В наборе перед отправкой нет шага снимков первого кита.

## Чего эпик не делает

- Пометку пакета `@rt-tools/ui-kit` устаревшим на npm запускает владелец или даёт на неё
  отдельное слово. Ответ владельца 12.11.2026: «Пометить устаревшим».
- Пересмотр проверок перед отправкой идёт отдельной работой после эпика: этот эпик только
  убирает шаги, которые относятся к первому киту.

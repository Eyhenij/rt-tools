# Кит: панель отборов полосы открывается маршрутом приложения

**Эпик:** RT-3566 · **Ветка эпика:** `RT-3566-toolbar-filters-app-route`

Решение владельца 23.11.2026: «заведи эпик». Эпик из одной задачи: проверки отправки не ведут
задачу вне эпика.

## Что даёт

Приложение открывает панель отборов полосы `rt-toolbar` своим маршрутом в аутлете `ro`: панель
переживает перезагрузку, передаётся ссылкой и попадает в историю браузера. Сегодня кнопка фильтров
сама открывает панель кита службой боковых панелей, и приложение, где боковые панели открываются
только маршрутом, не может её принять. Порог кнопки сдвигается: на 1080 и шире отборы в строке, на
1079 и уже — кнопка фильтров.

## Точки

- **A:** в выпуске 0.51.0 кнопка фильтров открывает свою панель, режима «панель у приложения»
  нет; на ровно 1080 уже кнопка вместо отборов.
- **B (RT-3528):** вход `filtersPanel="app"` и выход `filtersOpen` у полосы, готовая часть кита
  `rt-toolbar-filters-route-aside` для маршрута, порог 1079/1080, кнопка фильтров последней в
  ряду, после настроек таблицы. Признак: тесты SC-UKV-1710…1716 и SC-UKV-1086 зелёные, кадры
  витрины `ButtonAt1079` и `InRowAt1080`, слова владельца «Одобряю» о макете и «Одобряю витрину».
- **G (веха эпика):** новая minor-версия `@rt-tools/ui-kit-v2` на npm с режимом
  `filtersPanel="app"`. Признак: `npm view @rt-tools/ui-kit-v2 version` отвечает 0.52.0.

## Как стоят ветки

Ветка эпика отведена от главной, PR задачи идёт в неё, затем PR эпика — в главную. Ветка RT-3528
взята от главной до того, как заведён эпик: ветка эпика вливается в неё.

## Выпуск

После слияния PR эпика в главную по слову владельца — выпуск кита конвейером с входом `minor`.

## Чего эпик не делает

- Вид панели отборов кита не меняется: маршрутная панель рисует ту же часть
  `rt-toolbar-filters-panel`.
- Маршрут `ro:filters` в самом приложении-потребителе эпик не объявляет: это работа приложения
  после выпуска.

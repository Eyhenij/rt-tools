# Деревья, крошки, палитра и карусель из приложения есть во втором ките

**Эпик:** RT-2542 · **Ветка эпика:** `RT-2542-kit2-app-parts`

## Что даёт

Приложения, которые ставят второй кит, держат у себя общие компоненты, которых в ките нет: дерево
выбора, перетаскиваемое дерево, хлебные крошки, правку значения на месте, палитру цветов, карусель
и быстрое меню. Каждое приложение пишет и чинит их само. После эпика они берутся из кита, с одним
видом и одной клавиатурой во всех приложениях.

Состав взят по ответу владельца «1-9 берем» на список, разобранный в сессии 5 октября 2026 года.
Каждый компонент сначала показывается владельцу на витрине :6007, PR открывается после его слова.

## Как стоят ветки

Ветка эпика отведена от главной, PR задач идут в неё. Три задачи о деревьях стоят стопкой:
RT-2549 и RT-2550 опираются на дерево из RT-2548, а RT-2551 решается после RT-2550. Ветка каждой
из них отводится от ветки предыдущей. Остальные пять задач не связаны ни с деревьями, ни друг с
другом, и ветка каждой отводится от ветки эпика.

## Решения

- **Дерево стоит на логике, которая уже есть у выбора из списка.** `rt-select` и `rt-multiselect`
  рисуют дерево вариантов из чистого модуля `rt-select-tree.ts`. `rt-tree` берёт тот же модуль, а
  не вторую копию логики из приложения.
- **Выбор деревом с кнопкой «Применить» переносится из приложения как `rt-tree-selector`.** Владелец:
  «При чем здесь rt multiselect работа по переносу компоненто в кит????». Живой образец — панель
  выбора отелей: поиск, раскрытие всего, «выбрать всё», дерево и «Применить». Прежняя запись о режиме
  `rt-multiselect` снята.
- **Сторонние пакеты в кит не входят.** Палитра рисует свои образцы, карусель листает нативной
  прокруткой, перетаскивание берёт CDK drag-drop, который кит уже использует.
- **Приложение переходит на оба дерева без своих обходов.** Владелец выбрал «Закрыть всё в ките»,
  когда увидел, чего китовым деревьям не хватает для приложения. В `rt-draggable-tree`
  раскрытие веток становится входом и выходом — в RT-2549. В `rt-tree` добавляются группы без
  флажка, клик с выбором одного узла и Ctrl или Cmd для добавления, место для разметки под
  подписью, метки узла с подсветкой найденного и поиск без отбора строк — в RT-2572: PR #2568 к
  решению уже был влит. Отметки, скрытые только у строк, и текст `info` в конце строки не
  делаются: в приложении их не задаёт ни одно место. Выбор в `value`, а не на узлах, остаётся: на
  него приложение переходит само.

## Чего эпик не делает

- Код приложений не правится: они переходят на кит сами, после выпуска.
- Предметные обёртки приложений не переносятся: назначение прав, выбор отелей, справочники.
- Выпуска пакета нет: это отдельное решение владельца.
- Уведомления «нет сети» и «вышла новая версия», свёртка подвала бокового меню и полноэкранный
  режим из оболочки приложения в эпик не входят: по ним ответа владельца ещё нет.

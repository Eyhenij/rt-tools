# Находки ночи 23.11: проверка согласий кита, сборка графов, правила ночной работы

**Эпик:** RT-3586 · **Ветка эпика:** `RT-3586-night-findings-fixes`

## Что даёт

Ночь 23.11.2026 по эпику Angular Doctor трижды вставала и один раз оставила в истории ложную цитату
владельца. После эпика проверка согласий кита не требует от ветки задачи согласий за правки чужих
задач, сборка графов не краснит `check:ngdoctor`, правила ночной работы признают действия, которые
владелец разрешил сам, а защиты не открывают ночью окно вопроса. Находки ревью правил эпика Angular
Doctor и дневных разборов 23.11 стоят статьями правил.

Слово владельца 24.11.2026: «Отправь разборы и исправь все что нашел».

## Точки

- **A:** проверка согласий судит ветку со своей записью по всем правкам кита от главной; после
  `pnpm run graph:build` под проверкой лежат файлы graph.html; правило ночной работы запрещает
  отправку, PR и слияние без исключения; защита конца хода и защита согласий кита ночью открывают
  окно владельцу; находки ревью лежат в файле находок и ни в одном правиле.
- **G (веха эпика):** проверка согласий судит слитые задачи по их записям; сборка графов удаляет
  graph.html; ночью защиты дают умолчание вместо окна; каждая находка файла находок и разборов
  23.11 названа там, где исправлена. Признак: `bash tools/tests/check-kit-approval.test.sh`,
  `pnpm run agent-kit:hooks`, `pnpm run agent-kit:check`, и в файле находок у каждого пункта
  строка «Исправлено в RT-…» или довод, почему нет.

## Как стоят ветки

Ветка эпика отведена от главной. Ветки задач стоят цепочкой: RT-3585 от ветки эпика, каждая
следующая — от предыдущей. PR каждой задачи идёт в предыдущую ветку, первый — в ветку эпика;
сливаются снизу вверх.

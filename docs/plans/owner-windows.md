# Окна владельцу только там, где его ответа ещё нет

**Эпик:** RT-3720 · **Ветка эпика:** `RT-3720-owner-windows`

## Что даёт

Владельцу не задаются окна, ответ на которые уже есть: повтор прежнего ответа, одобрение плана по
слову на эпик, старт эпика одним окном, разбор задачи без вопросов, кроме выбора в продукте.

Задачи вынесены из эпика RT-3693 словом владельца 27.11: «Вынеси эти задачи в отдельный эпик, но не
начинай его». Эпик не начат и ждёт слова владельца.

## Точки

- **A:** в эпике RT-3693 медиана обращений к владельцу на задачу — 4. Перед каждой из четырёх задач
  этого эпика стоит измерение: в RT-3693 оно показало, что RT-3698, RT-3699 и RT-3700 почти не
  снижают медиану. Две трети обращений — сообщения, которые владелец набирает сам.
- **B (RT-3697):** окно не повторяет ответ, который владелец уже дал. Признак: сценарии задачи и счёт
  окон командой измерения.
- **G (веха эпика):** не названа: её называет владелец при старте эпика. Признак: `pnpm run
  owner:touches` после слияния эпика.

## Как стоят ветки

Ветка эпика отведена от главной, ветки задач — от неё, PR задач идут в неё. Ветки задач берутся по
одной: каждая следующая — после слияния предыдущей, задачи правят одни и те же правила хода работы,
судью вопросов и хуки. Сделанное в RT-3697 лежит в ветке `RT-3697-no-repeat-windows`, план RT-3698 —
в ветке `RT-3698-plan-by-epic-word`; обе отведены от ветки эпика RT-3693.

## Состав

| #   | Задача                                                                       | Состояние |
| --- | ---------------------------------------------------------------------------- | --------- |
| 1   | RT-3697 — окна не повторяют ответ и не отдают владельцу шаг исполнителя (П5) | впереди   |
| 2   | RT-3698 — план задачи эпика одобряется словом на эпик, без окна (П1)         | впереди   |
| 3   | RT-3699 — старт эпика идёт одним окном (П4)                                  | впереди   |
| 4   | RT-3700 — разбор задачи без вопросов, кроме выбора в продукте (П2)           | впереди   |

Измерения и находки по каждой задаче лежат в файле находок эпика RT-3693, в его ветке; в главную
ветку он придёт со слиянием того эпика.

## Чего эпик не делает

- Сообщения, которые владелец набирает сам, этот эпик не снимает: их виды размечает команда
  измерения эпика RT-3693, мера по ним — отдельная работа.

# Кит: кнопка-квадрат и точка метки

**Эпик:** RT-3390 · **Ветка эпика:** `RT-3390-kit-icon-tag-dot`

Решение владельца, переданное запустившей сессией 18.11.2026: «Решение (а): заводи эпик «Кит:
кнопка-квадрат и точка метки» с одной задачей RT-3389».

## Что даёт

Экран записи на узком экране собирается из компонентов кита: кнопки в шапке стоят квадратами без
подписи, статус записи — цветной точкой. Сегодня в дизайн-системе нет ни кнопки-квадрата, ни
точки у метки, и макет экрана не собирается.

## Точки

- **A:** в Figma нет варианта «только значок» у кнопок и вида «точка» у метки; в коде нет
  `appearance="dot"` у `rt-tag`.
- **B (RT-3389):** обе детали в Figma и в витрине, `rt-tag` рисует точку. Признак: строка
  `kit-match numbers` N из N и одобрение витрины владельцем.
- **G (веха эпика):** новая версия `@rt-tools/ui-kit-v2` с точкой у метки на npm. Признак:
  `npm view @rt-tools/ui-kit-v2 version`.

## Как стоят ветки

затем PR эпика — в главную.

# Проверки пакета правил останавливают работу — переделка, вторая часть

**Эпик:** RT-3293 · **Ветка эпика:** `RT-3293-checks-rework-2`

Заведён по слову владельца от 13.11.2026, после слияния первой части (эпик RT-3269, PR #3291):
«переноси в новый эпик все задачи которые не были сделаны в текущем».

## Что даёт

Владелец ставит задачу и получает результат без надзора за каждым шагом. Первая часть сократила
набор перед отправкой. Остальное не тронуто: проверки угадывают решение владельца по словам,
теряют состояние работы после сжатия разговора и держат правила поставки в сессии.

## Точки

- **A:** проверки угадывают решение владельца по словам, читают состояние работы из записи
  разговора и отказывают ложно. Набор перед отправкой не запускает шаги, которых правка не
  касается, но 10 шагов идут на любую правку: отбор не видит, что они читают.
- **D (RT-3272):** правила поставки держит хостинг, а не проверки сессии. Признак: защита главной
  ветки на хостинге и список правил, оставшихся в сессии, с причиной для каждого.
- **C (RT-3271, RT-3274–RT-3276):** проверка не переспрашивает решение владельца и не теряет его
  после сжатия разговора. Признак: запуск проверок на настоящей записи разговора (RT-3277).
- **B (RT-3280, отложено):** шаг снимков при упавшей истории называет эту историю. Судьбу задачи
  решает владелец.
- **G (веха эпика):** эпик из нескольких задач доходит до `main` без повторных вопросов владельцу и
  без ложных отказов. Признак: отчёт метрик (RT-3270) за этот эпик — ноль повторных вопросов и ноль
  ложных отказов.

## Как стоят ветки

Ветка эпика отведена от главной, ветки задач стоят стопкой: первая от ветки эпика, каждая следующая
от предыдущей. PR задачи идёт в предыдущую ветку.

| —   | RT-3296 — десять шагов набора идут на любую правку             | сделано   |

Что осталось сделать с набором перед отправкой после первой части: снимки только задетых историй,
сценарии только тех файлов, что вызывают изменённый хук, сквозные наборы только по коду, который
грузит приложение. Ещё десять шагов идут на любую правку, потому что отбор не видит их чтений. Шаги
без предела надо измерить: снимки первого кита, сборку образов, сборку токенов. Задач на это пока
нет, их заводит владелец.

RT-3280 лежит в ветке `RT-3280-snapshot-step-names-failed-story`. Три латки выбора шагов набора оттуда
уже в `main`. Судьбу самой RT-3280 решает владелец.

## Чего эпик не делает

- Выпуск пакета: его назначает владелец отдельно.
- Правку текстов законов: их правит владелец.

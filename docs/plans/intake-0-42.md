# Приёмник, выпуск 0.42.0: одобрение плана не держит работу, проверка выхода не судит чужую задачу

**Эпик:** RT-3576 · **Ветка эпика:** `RT-3576-intake-0-42`

## Что даёт

Третья тройка задач приёмника, по слову владельца 23.11: «заводи новый эпик под каждые 2+1
задачи». Работа не стоит на отдельном круге одобрения плана, когда все его развилки уже решены.
Проверка выхода из хода не приписывает сессии задачу ветки, которую сменила соседняя сессия. Эпик
для ночной работы заводится до ухода владельца.

## Точки

- **A:** 23.11 одобрение плана держало работу днём (владелец присылал его по три раза) и всю
  ночь (пять задач из восьми ждали «Одобряю»). Проверка выхода трижды отбила ход сессии ревью по
  задаче соседней сессии. Ветка эпика ночью ушла на сервер вопреки плану эпика.
- **B (RT-3577, разбор `2026-11-23-plan-approval-blocks-work.md`):** план после двух ролей и
  проверки `plan-red` проходит выход 5 без «Одобряю». Признак: случай набора движка.
- **B (RT-3578, разбор `2026-11-23-exit-guard-held-review-for-neighbour-task.md`):** сессия без
  правок на ветке, которую сменил сосед, кончает ход. Признак: случаи набора проверки выхода.
- **B (RT-3579, предложение к `rules/autonomous-work.md`):** эпик ночной работы заводится вечером.
  Признак: статья правила и строка `/night`.
- **G (веха эпика):** все три правки выходят в кит 0.42.0. Признак: строки RT-3577, RT-3578 и
  RT-3579 в `projects/agent-kit/CHANGELOG.md` раздела 0.42.0; коммиты типа `fix` или `feat`.

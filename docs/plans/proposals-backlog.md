# Остаток предложений, заведённых прежним порядком в очередь работ

Замысел работ, а не отчёт: он говорит, что осталось сделать по предложениям, приехавшим грузом
до того, как правило разбора груза отменило заведение таких записей в очередь работ.

Собран задачей RT-1490. Тридцать три задачи прочитаны и сверены с деревом по всем веткам
хранилища; восемь оказались закрыты редакциями 0.10–0.17 и закрыты комментарием, одна закрыта
невлитой веткой. Ниже — то, что не закрыто ничем.

## Как это проверялось

Сверка идёт по всем веткам хранилища, а не по рабочей копии: правки лежат в ветках, которые
ждут слияния, и проверка по одной копии называет сделанное несделанным. Дословное совпадение
готового текста предложения с деревом ответом не является — правка принималась по смыслу, и
совпадение шести слов подряд говорит только о том, что формулировку взяли целиком.

## Что с этим делать

Работы делятся по семьям: одна ветка на семью, как шли задачи эпика RT-1198. Порядок — сверху
вниз таблицы: семья поставки самая крупная и самая старая.

Записи груза в самом приёме при этом не трогаются: чужие отмечает только отправитель, а свои
стоят в «готово» и ждут выпуска редакции.

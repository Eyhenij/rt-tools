# Разбор правил по закрытию RT-3715 — ждёт слова владельца

Ответ роли `skill-curator` от 2026-11-27, пересказан по пунктам. Ничего из этого не внесено. Исполнитель эти пункты по
коду не перепроверял. Размеры текстов после правки роль посчитала приблизительно.

## Предложения

1. **Проверки плана идут до вопроса об одобрении** (ресурс пакета `rules/task-flow-plan.md`). План коммитится,
   идут команды движка `plan-check` и `plan-red`. Неизвестная форма ожидаемого ответа и проверка, зелёная до работы,
   исправляются первыми. Заодно согласовать строку таблицы состояний в `task-flow`.
2. **Замена оператора и выигрыш на одной сборке** (ресурс пакета `patterns/code-design-choose.md`). Зелёные прежние
   тесты ничего не говорят о гарантии, которую не спрашивал ни один тест. Каждая такая гарантия получает случай, красный
   на мутанте. Выигрыш веса измеряется на приложении, которое берёт общую часть само, и на том, которое не берёт. Правила
   файлов, названных в плане, загружаются до записи решения.
3. **Проверка веса кита не показывает вес приложения** (новое переопределение дерева над образцом
   `code-design-choose`). `rxjs`, `@angular/*` и `@rt-tools/core` для неё внешние.
   План называет оба числа и приложение, на котором они сняты.
4. **«Без вида» и повторная живая проверка** (`.claude/skills/task-delivery-loop/SKILL.md`). Строка «Без вида»
   коммитится сразу после одобрения плана: без неё разница отвечает «смена вида». Правка, меняющая то, что измеряла
   живая проверка, повторяет измерение. Если повторить нельзя, описание PR называет версию, к которой относятся числа.
5. **Команды git в изолированной копии** (`.claude/skills/task-delivery-loop-run/SKILL.md`, раздел про круги ревью).
   Каждая строка — отдельный вызов, путь scratchpad пишется целиком. После правки файл упирается в предел в 330 строк.
6. **Правка инструментом теряет пробел в конце** (ресурс пакета `pitfalls/testing.md`). Дважды склеилось название теста.
   Надёжнее отдельная задача пакету: `check-specs` требует « — » после номера сценария в названии теста.

## Без нового текста

- Движок читает только первую строку имени шага: это первый пункт разбора по RT-3682, случай повторился.
- Расхождение, нужно слово владельца: `.claude/rt-kit/overrides/rules/browser-verification.md` и образец цикла задачи
  разрешают измерять во встроенном браузере, когда закреплённый Chrome теряет локальную вкладку. По прежнему слову
  владельца встроенная панель запрещена. Что из двух действует, должен сказать владелец.

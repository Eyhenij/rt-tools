# Чат ИИ-ассистента второго кита на телефоне

Эпик RT-2958. Чат ассистента второго кита собран из `rt-ai-chat`, `rt-markdown-text` и
`rt-thread-list`. На iPhone им трудно пользоваться: лента шире экрана, прокрутка с краёв двигает
страницу, разметка портит слова с подчёркиванием, меню беседы на сенсорном экране не видно.
Поломки нашлись в админке VillaManager, задача VM-3125, пакет 0.34.2.

## Решения

- **Эпик чинит четыре поломки и заводит поле ввода ИИ-чата.** Вид компонентов вне названных мест
  не меняется. Слово владельца о поле ввода, 28.10.2026: «окей, делай этот компонент в ui kit v2».
- **Новая версия пакета выходит после слияния всех пяти задач.** В VillaManager поднимается
  один номер.

## Образцы

Чужой кит в пакет не подключается: компоненты собираются из примитивов второго кита. Образцы
читаются приёмом.

- Vercel AI Elements: поле ввода со строкой контролов, выбор модели, кольцо расхода контекста,
  ход рассуждений, вызов инструмента, вложения, источники.
- assistant-ui: поведение беседы, ветки ответов, правка сообщения, повтор запроса, прокрутка к
  низу.

Состав образцов назван по памяти 28.10.2026 и сверяется с их репозиториями перед первой задачей.

## Задачи

Порядок выполнения сверху вниз. Ветка каждой задачи берётся от ветки эпика.

| № | Задача | Что закрывает |
| --- | --- | --- |
| 1 | RT-2959 | длинное слово и адрес в ответе переносятся, лента не шире экрана |
| 2 | RT-2960 | у ленты и списка бесед стоит `overscroll-behavior: contain` |
| 3 | RT-2961 | `_` внутри слова остаётся знаком, голый адрес становится ссылкой |
| 4 | RT-2962 | кнопка меню беседы видна при `hover: none` |
| 5 | RT-2964 | поле ввода ИИ-чата со строкой контролов и кольцом расхода по макету |

## Закрыто, когда

Все пять задач влиты, новая версия `@rt-tools/ui-kit-v2` вышла и поднята в VillaManager.

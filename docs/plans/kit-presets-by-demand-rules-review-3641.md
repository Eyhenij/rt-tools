## Предложения

1. **Образец перемотки `main` двигает не ту ветку** (`.claude/skills/task-delivery-loop-run/SKILL.md`, две строки). Когда `main` открыт в другой копии, первая команда отказывает, и `merge` идёт в текущей ветке. Заменить на `git fetch -q origin; git fetch -q origin main:main || git worktree list`: после отказа видно, в какой копии открыт `main`, а текущая ветка не меняется. Отдельно нужно решение, кто перематывает `main` в копии, которую трогать запрещено.
2. **PR эпика с незаконченными задачами никто не держит** (`.claude/skills/git-workflow/implementation.md`, `.claude/skills/epic-flow/implementation.md`, ресурсы пакета — правило эпика и образец его объявления). Проверка смотрит только на папки задач в ветке, а у неначатой задачи папки нет. Файл привязок говорит, что это держит аудит доски, но `tools/board-epics.mjs` такой PR не называет. Поправить привязку, свести две разные формулировки условия и добавить отказ при открытых подзадачах.
3. **Проверка меню пропустила вариант против статьи правила** (ресурс пакета `hooks/ask-judge.md`). Прошёл рекомендованный вариант «Влить эпик сейчас» при открытых задачах. Проверка должна удерживать вариант с шагом поставки, который правило запрещает в текущем состоянии работы, и до меню искать этот шаг в правилах.
4. **Проверка согласования на выпуске читает отставший диск** (`tools/check-kit-approval.mjs`, `.claude/skills/kit-approval/SKILL.md`). Слияния она берёт из `origin/main`, а записи одобрения — из файлов копии сессии. Читать записи тоже из `origin/main` и добавить сценарий «копия отстаёт, запись есть на сервере». Тогда перемотка основной копии выпуску не нужна.
5. **`git hash-object` принят за запись** (ресурс пакета `checks/flow-guard.mjs`). Без ключа `-w` считать чтением, с ключом — записью, с двумя сценариями.
6. **Черновик плана эпика нельзя убрать** (ресурсы пакета `checks/flow-guard.mjs` и образец объявления эпика). Разрешить удалять неотслеживаемый файл из каталога планов и сказать в образце, что черновик убирается в том же ходе, когда заполненный план попал в ветку эпика. Обе части вносить вместе.
7. **Не сказано, чем подтверждается выпуск** (`.claude/skills/package-release-run/SKILL.md`, комментарий в `.github/workflows/publish-ui-kit-v2.yml`). Номер в npm появился раньше архива пакета. Считать выпуск подтверждённым, когда архив скачивается; образец расширить на кит. Комментарий о задержке «в секунды» исправить на «до нескольких минут».

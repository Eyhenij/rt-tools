# Приёмник, выпуск 0.41.0: ночная работа без вопросов и без окон разрешения

**Эпик:** RT-3570 · **Ветка эпика:** `RT-3570-intake-0-41`

## Что даёт

Вторая тройка задач приёмника, по слову владельца 23.11: «заводи новый эпик под каждые 2+1
задачи», «работай далее без остановок в режиме ночной автономной работы». Ночная работа без
владельца не встаёт: исполнитель не задаёт вопросов и не запускает команд, на которые среда
спросит разрешение, а проверка выхода из хода не требует меню владельцу.

## Точки

- **A:** ночью 23.11 исполнитель задал владельцу пять вопросов, работа стояла на окне разрешения
  команды `rm -rf`, проверка выхода из хода дважды требовала меню владельцу.
- **B (RT-3571, разбор `2026-11-23-questions-and-stop-under-autonomous-order.md`):** в автономной
  сессии вопросов владельцу нет. Признак: статья правила `autonomous-work`.
- **B (RT-3572, разбор `2026-11-23-night-stalled-on-permission-prompt.md`):** команда `/night`
  читает правила `permissions.ask` перед первой работой. Признак: строка команды и статья правила.
- **B (RT-3573, предложение к `rules/autonomous-work.md`):** при списке к утру этого дня проверка
  выхода из хода не называет меню владельцу. Признак: случай набора проверки.
- **G (веха эпика):** все три правки выходят в кит 0.41.0. Признак: строки RT-3571, RT-3572 и
  RT-3573 в `projects/agent-kit/CHANGELOG.md` раздела 0.41.0.

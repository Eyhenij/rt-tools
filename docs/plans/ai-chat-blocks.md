# Ответ AI-чата кита рисует графики, таблицы, KPI, ссылки и источники

**Эпик:** RT-3346 · **Ветка эпика:** `RT-3346-ai-chat-blocks`

## Что даёт

Ответ ассистента в `rt-ai-chat` собирается из типизированных блоков: текст, уведомление, график,
таблица, KPI, ссылка на страницу, источники, сетка секции. Кит рисует их сам. Сегодня всё, кроме
markdown-текста, приложение рисует своим шаблоном `rtAiChatMessageExtra` и переопределяет
внутренние классы кита.

## Точки

- **A:** `IRtAiChat.Message` несёт markdown-текст, ход работы и оценку; остальное рисует шаблон
  приложения.
- **B (RT-3334):** ответ рисуется массивом `blocks` из блоков `markdown` и `notice`; блок без
  отрисовщика показан заглушкой с именем типа и в копию не попадает, блок из реестра попадает в
  копию текстом функции `toText` своего отрисовщика.
  Признак: история витрины с каждым типом блока и с неизвестным типом, юнит-тест
  `blocksToPlainText`.
- **G (веха эпика):** опубликованная версия кита рисует ответ «обзор месяца» (итог, 4 KPI, 2
  графика, таблица) одним массивом `blocks` без шаблона приложения. Признак: история витрины
  RT-3342 на опубликованной версии.
- **G2 (вторая веха, второй выпуск):** опубликованная версия кита рисует ответ с карточкой ссылки
  на страницу, источниками цифр, меткой прерванного ответа и `Reply` без шаблона приложения.
  Признак: истории витрины RT-3339, RT-3340, RT-3341 и RT-3343 на опубликованной версии. Слово
  владельца 19.11.2026: «Вторая веха G2».

## Как стоят ветки

Ветка эпика отведена от главной, ветки задач — от неё, PR задач идут в неё. Ветки задач стоят
стопкой: каждая от предыдущей, PR — в предыдущую ветку.

Находки RT-3342 для следующих задач эпика:

- `pnpm run check:unused` называет три неиспользуемых экспорта `rt-chart.scene.ts` и две
  зависимости d3 в корневом `package.json`. Они пришли с графиком. Проверка не входит в набор перед
  отправкой, но входит в `check:all`.
- Схему секции для модели собирает `rtAiChatSectionSchema`. Новый тип кита — карточка ссылки,
  источники — отдаёт свою схему и встаёт в `OWN_SCHEMAS` той же правкой.
- История чата, которой нужен кадр с начала ответа, ждёт покоя ленты: чат подтягивает её к хвосту
  ещё несколько раз после отрисовки.

## Чего эпик не делает

- Разбор потока событий модели: чат получает готовые сообщения, поток разбирает приложение.
- Навигацию по карточке ссылки и открытие источника: кит отдаёт событие, действие делает
  приложение.

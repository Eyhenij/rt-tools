# Проверки пакета правил останавливают работу — переделка, третья часть

**Эпик:** RT-3302 · **Ветка эпика:** `RT-3302-checks-rework-3`

Заведён по слову владельца от 14.11.2026: «доделывай RT-3274, будем мержить эту задачу тоже в
рамках текущего эпика, остальные задачи вынеси с новый эпик».

План восстановлен 14.11.2026 из описания карточки эпика: описание ссылалось на этот файл, но его не
было ни в одной ветке. Ветка эпика взята от `main` при первой задаче, RT-3276, по слову владельца
«Да, в RT-3276».

## Что даёт

Владелец ставит задачу и получает результат без надзора за каждым шагом. Проверки перестают
угадывать решение владельца по словам разговора и отказывать в ответе на его вопрос.

## Точки

- **A:** проверки судят разговор регулярными выражениями и отказывают ложно. За 14.10–14.11.2026
  `turn-exit-guard` отказал 921 раз; около 41% этих отказов пришлись на ход, который правильно было
  закончить ответом владельцу.
- **C (RT-3271, RT-3275, RT-3276):** проверка не переспрашивает решение владельца и не запрещает
  ему отвечать. Признак: ход, который ждёт решения владельца, заканчивается без отказа; вопрос
  владельцу после отказа другой проверки уходит.
- **D (RT-3272, отложено):** правила поставки держит хостинг, а не проверки сессии.
- **B (RT-3280, отложено):** шаг снимков при упавшей истории называет эту историю.
- **G (веха эпика):** за рабочий день отказов меньше пяти на сто команд, и ни одного тупика, из
  которого исполнитель не может выйти сам. Признак: отчёт метрик (RT-3270).

## Как стоят ветки

Ветка эпика отведена от главной, ветки задач стоят стопкой: первая от ветки эпика, каждая следующая
от предыдущей. PR задачи идёт в предыдущую ветку.

## Проверки, которые судят разговор

Список и решение по каждой ведёт RT-3276. Решение — одно из двух: удалить проверку и оставить
требование текстом правила, или отдать решение хуку на модели.

| Проверка | Отказов по журналу | Отказов по стенограммам | Решение |
| -------- | ------------------ | ----------------------- | ------- |
| `turn-exit-guard` | 921 | 838 | модель — все уровни, которые читают текст ответа или сообщения владельца, включая «обещание работы» и «ожидание чужого шага»; уровни про дерево и команды остаются командой |
| `grill-gate` (с `grill-gate-ask`) | 277 | 495 | модель — удаляется целиком, включая счёт меню: он тоже судит ответы владельца |
| `claim-guard` | 77 | 70 | модель |
| `waiting-turn-guard` | 21 | 13 | модель |
| `postmortem-guard` | 8 | 9 | модель — признание промаха ловится образцами слов |
| `work-start-guard` | 0 | 0 | модель — просьбу владельца о работе ловят образцы слов |
| `proposal-guard` | 0 | 0 | модель — просьбу отправить предложение ловят образцы слов |
| `stand-login-guard` | 0 | 0 | модель — просьбу владельцу войти на стенд ловят образцы слов |
| `conscience-guard` | 0 | 0 | вне списка — читает первую строку ответа роли «СОВЕСТЬ: повтор», а не смысл разговора |
| `cargo-mark-guard` | 0 | 0 | вне списка — судит вызовы команд приёмника, а не слова разговора |

Решение «модель» значит: проверка или её уровни удаляются из пакета, а требование за ними судит
agent-хук Claude Code по сообщению владельца и ответу агента. Переключателя нет — слово владельца
«замени полностью, убери старые проверки совсем».

Список собран по тому, что проверка читает текст записи разговора. Журнал наблюдений —
`.claude/rt-kit/observations/`, 14.10–14.11.2026. Стенограммы — 26 сессий этого дерева за тот же
срок; часть сессий в них не попала, а `grill-gate` пишет в журнал не каждый отказ на вызове меню.

## Чего эпик не делает

- Выпуск пакета: его назначает владелец отдельно.
- Правку текстов законов: их правит владелец.
- Восстановление ветки второй части (RT-3293): её на сервере нет, осталась ветка
  `revert-3297-RT-3296-always-run-steps`. Что с ней делать, решает владелец.

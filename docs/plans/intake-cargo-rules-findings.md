| Пункт                                                 | Чем закрыт                                                                               |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------- |

| номер сценария занимают две невлитые ветки            | свободный номер ищется во всех ветках — задача RT-1205                                   |

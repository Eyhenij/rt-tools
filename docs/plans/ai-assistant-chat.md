# Чат с ИИ-ассистентом нельзя взять из второго кита: приложение собирает панель само

**Эпик:** RT-2649 · **Ветка эпика:** `RT-2649-ai-assistant-chat`

## Что даёт

Приложение подключает панель ИИ-ассистента одним компонентом `rt-ai-chat` и отдаёт ей данные:
сообщения, ход работы модели, подсказки, беседы, ошибку. Сегодня во втором ките есть `rt-chat` для
переписки людей и примитивы (поле сообщения, лента шагов, markdown, список бесед), а части
ассистента приложение рисует само.

Макеты — Figma-файл второго кита, страница «AI-чат — макеты»: 12 состояний панели шириной 420.

## Решения

- **Работа идёт эпиком: молекулы отдельными задачами, затем организм, затем выпуск.** Слово
  владельца.
- **Иконки искры и оценки ответа — SVG в ките.** Шрифт Material Symbols кит не поставляет, и имя
  без сопоставления на витрине пустое. Слово владельца.
- **Нетекстовое содержимое ответа приходит шаблоном приложения.** Кит рисует текст ответа через
  `rt-markdown-text`; графики и другие вложения приложение отдаёт `ng-template`, который получает
  сообщение. Кит про графики не знает. Слово владельца.
- **Организм живёт в точке входа `rich-editor`.** Он держит `rt-message-composer`, а тот тянет
  Quill; главная точка входа Quill не импортирует. Молекулы без Quill живут в главной.
- **Протокол ассистента в кит не входит.** Кит получает готовое состояние: список шагов, статус,
  текст. Разбор потока событий модели остаётся в приложении.

## Как стоят ветки

Ветка эпика отведена от главной, ветки задач — каждая от ветки эпика, заявки задач идут в неё.
Задачи 1–4 независимы и идут параллельно. Задача 5 берётся после слияния 1–4: организм собирается
из их частей. Задача 6 — после 5.

## Чего эпик не делает

- Не меняет `rt-chat`: переписка людей остаётся отдельным организмом.
- Не разбирает поток событий модели и не ходит в сеть.
- Не добавляет переводы: кит несёт английские подписи, остальные языки даёт приложение.

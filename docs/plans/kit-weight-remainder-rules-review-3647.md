# Разбор правил по RT-3647

Ответ роли `skill-curator` после слияния [PR 3724](https://github.com/Eyhenij/rt-tools/pull/3724). Тексты предложены,
но не внесены: они ждут слова владельца. Роль дважды запустила `git diff`, хотя команды git ей запрещены. Дерево эти
команды не изменили.

1. **Браузер и процессы в рамке каждого круга.** Образец `task-delivery-loop-run`: свой браузер не поднимается и
   безголовым, процесс завершается по номеру. В первом круге проверяющий нарушил оба запрета, во втором они стояли в
   задании и выполнялись.
2. **Измерение на витрине.** Привязки `browser-verification`: дополнение псевдосостояний переписывает селекторы с
   отрицанием состояния, и они совпадают при настоящем фокусе. Значение берётся при исходном селекторе, и PR это
   называет.
3. **Имя служебного свойства стиля.** Образец `rt-tools-styling-tokens`: `--rt-private-<блок>-<что>`, дефисами,
   объявлено на блоке с выключенным значением и читается без запасного.
4. **Встроенный браузер.** То же противоречие, что в разборе по RT-3715. Роль предлагает запрет во всех четырёх местах.
   Проверки инструменты этого браузера не знают, это отдельная задача.
5. **Тест «только здесь».** Ресурс пакета `testing-unit`: такое утверждение проверяется добавлением второго задающего
   правила, а не только удалением первого.

Без нового текста:

- сценарии проверок на этапе не запущены: шаг уже есть в образце цикла, это пропуск исполнителя;
- отказ команды разбора папки из-за пунктов «Цена» и «Отменено» верен;
- правка файла командой оболочки уже запрещена правилом о текстах.

# Пакет правил: хуки судят правку без команды timeout

**Эпик:** RT-3686 · **Ветка эпика:** `RT-3686-guards-without-timeout`

Слово владельца 25.11.2026: «Взять задачу из очереди» — взята RT-3621. Эпик из одной задачи заведён
по слову владельца «Завести эпик»: движок хода работы не ведёт задачу вне эпика.

## Что даёт

На машине без команды `timeout` хук хода работы судит правку и запись плана так же, как на машине
с ней. Сегодня там он пропускает любую правку молча.

## Точки

- **A:** без `timeout` в PATH набор хука хода работы — 69 провалов из 118, наборы записи плана —
  11 и 6 провалов.
- **B (RT-3621):** хук зовёт движок под первым ограничителем времени, который есть на машине, а
  без них — без предела. Признак: три набора зелёные под PATH без `timeout` и `gtimeout`.
- **G (веха эпика):** правка влита в главную ветку. Признак: PR эпика в главную ветку влит. Выпуск
  пакета — отдельное решение владельца.

## Как стоят ветки

Ветка эпика отведена от главной, ветка RT-3621 — от неё, PR задачи идёт в ветку эпика, затем PR
эпика — в главную.

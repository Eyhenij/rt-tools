- Правило ведения работы признаёт границу: перевёрнутый надстройкой порядок отдачи ломает часть
  шагов пакета, и какие именно — не считает ничто.
- Скил пакета называет ловушку: своё, стоящее рядом с разложенным, повторяет его механику молча.
- Раскладка сходится, длина текстов в пределе, набор обвязки зелёный.

## Этапы

### 1. Статья о границе проверки

- **Что делается:** абзац в раздел «Чего из закона здесь нет» правила ведения работы
- **Признак готовности:** абзац стоит, длина правила в пределе
- **Чем проверяется:** `node tools/check-file-size.mjs` — строка о новых сверх предела

### 2. Ловушка о своём рядом с разложенным

- **Что делается:** пункт в скил пакета
- **Признак готовности:** пункт стоит, раскладка сходится
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

### 3. Закрытие

  ветки наружу не отправлять

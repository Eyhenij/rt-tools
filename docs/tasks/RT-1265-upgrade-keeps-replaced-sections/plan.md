# Замысел

**Поведение:** не меняется — правится разбор состояния раскладки и текст скила, требований к
продукту задача не трогает.

Замещённый надстройкой раздел теряет всё, что пакет дописал в него новой версией, и об этом
молчат все три команды. Половину вопроса машина закрыть может: какие разделы замещены, она знает
и без прежней редакции.

## Этапы

1. Разбор состояния перечисляет замещённые разделы поимённо: ресурс и заголовок.
2. Раздел «Подъём версии» в скиле — порядок из трёх шагов: снимок прежней редакции до установки,
   установка, сверка замещённых разделов по снимку.
3. Сценарий на перечень замещённых разделов.
4. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Второй половины просьбы — «и из них те, что в новой версии изменились» — задача не делает:
прежней редакции у команды нет, установка стирает её без следа. Закрывается это снимком, который
описан порядком, а не командой.

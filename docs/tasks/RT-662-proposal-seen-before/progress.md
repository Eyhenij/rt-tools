# Ход работы

## Где стоим

Этапы 1–4 закрыты одним коммитом: договорённость, схема с миграцией, приём и пакет. Дальше —
этап 5: отчёт, вливание договорённости и закрытие `Q-16`.

## Решения по ходу

- **Разбор предложений идёт по одному, задачей на предложение или на связанную их пачку.** В
  очереди работ девятнадцать открытых предложений; первым разбирается самое свежее — №657.
- **Сценарии получили номера `SC-MB-81`…`SC-MB-85`, а не `SC-MB-80`…`SC-MB-84`, как назвал
  замысел.** Номер 80 занят договорённостью об админке — сверка спеков это и показала.

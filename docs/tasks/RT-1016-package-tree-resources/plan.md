## Что считается сделанным

- Команды сведения предложений и ревью слоя правил живут своими командами дерева, без шапки
  раскладки, и раскладка их больше не везёт.
- Памятка о пакете разделена: пакетная говорит потребителю о раскладке и надстройках, своя
  памятка дерева — о правке источника, сборке, разборе предложений и двух командах.
- В перечне долга не осталось ни одной строки, и сам перечень с дерева снят.
- Договорённость влита в спек домена, директории «предложено» не осталось.
- Проверка границы зелёная и краснеет на новом ресурсе не для везения так же, как краснела.

## Этапы

### 1. Две команды переезжают в дерево

- **Что делается:** команды сведения предложений и ревью слоя правил уходят из ресурсов пакета
  в свои команды дерева; шапки раскладки с разложенных копий снимаются.
- **Признак готовности:** раскладка их больше не везёт, а команды на месте и читаются.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом, и ни одной
  из двух команд раскладка не называет.

### 2. Памятка делится надвое

- **Что делается:** из пакетной памятки уходят порядок правки ресурса, две строки о командах
  дерева пакета и абзац о разборе предложений; они встают своей памяткой дерева, и обе стороны
  ссылаются друг на друга.
- **Признак готовности:** потребитель читает памятку, в которой нет ничего о правке источника,
  а дерево пакета — обе.
- **Чем проверяется:** `pnpm run agent-kit:check` — раскладка сходится, и `npm run check:docs`
  — код ноль: адреса в обеих памятках ведут в существующее.

### 3. Перечень долга пустеет

- **Что делается:** две строки о переехавших командах снимаются с перечня; чтение перечня
  проверкой остаётся — оно ещё пригодится следующему переезду.
- **Признак готовности:** проверка границы зелёная, и в её выводе нет ни одной строки долга.
- **Чем проверяется:** `npm run check:boundary` — код ноль и ни одного ресурса в выводе.

### 4. Перечень снимается, договорённость вливается

- **Что делается:** главная ветка с влитой #1019 подтягивается сюда, перечень долга уходит с
  дерева целиком, договорённость эпика вливается в спек домена последним коммитом заявки.
- **Признак готовности:** перечня в дереве нет, директории «предложено» нет, домен пакета
  говорит о границе своим поддоменом.
- **Чем проверяется:** `npm run check:specs` — код ноль и ни одной готовой к вливанию
  договорённости, и `npm run check:boundary` — код ноль без перечня на диске.

## Чего эта работа не делает

- Не трогает отправляющую сторону: форма груза, отправка и команда предложения остаются в
  пакете целиком.
- Не трогает код приёмника и его админки.
- Не заводит статьи закона о поставке по вопросу `Q-PB-2`: она приносится владельцу текстом
  отдельно от этой работы.

Первая задача эпика RT-702. Замысел эпика — `docs/plans/agent-kit-rules-review.md`.

## След задачи

| Что      | Где                                                                        |
| -------- | -------------------------------------------------------------------------- |
| Спеки    | `docs/specs/agent-kit/`, договорённость в `proposed/rules-review/`         |
| Законы   | `docs/constitution/project-documentation.md` и его исходник в пакете       |
| Правила  | `.claude/skills/spec-driven/`, `.claude/skills/doc-style/`                 |
| Код      | `projects/agent-kit/assets/laws/`, `projects/agent-kit/tests/`             |
| Проверки | набор пакета `projects/agent-kit/tests/run.sh`, гейт пуша `rt_push_checks` |

## Что считается сделанным

- Проверка находит четыре рода расхождений в текстах пакета и называет ресурс, род и строку.
- Расхождение образца правила с корпусом правил либо починено, либо перечислено поимённо в
  самой проверке — молчаливо зелёной она не осталась.
- Правка, снявшая обязательный раздел у ресурса, отбивается перед пушем; после возврата раздела
  пуш проходит.
- Закон о документации проекта несёт статьи о непротиворечивости слоя правил, и они разложены в
  `docs/constitution/`.
- В договорённости не осталось вопроса, ответ на который меняет код.

## Этапы

### 1. Договорённость дописана по находкам разбора

- **Что делается:** набор требований к текстам пакета назван поимённо; сказано, какое из двух
  старше — новое требование или действующее «Переносимый текст из сверки адресов выведен»;
  признак «адрес конкретного дерева в блоке кода» сведён к перечню; накопленный долг «правило
  без паттерна» перечислен поимённо; названы роды, у которых набора разделов нет вовсе; закрыты
  открытые вопросы, ответ на которые меняет код.
- **Признак готовности:** каждое правило договорённости имеет названное место будущего
  исполнения; открытых вопросов, меняющих код, не осталось.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`.

### 2. Статьи в закон о документации проекта

- **Что делается:** текст статей приносится владельцу отдельно и после его слова правится в
  `projects/agent-kit/assets/laws/project-documentation.md`, затем раскладывается.
- **Признак готовности:** статьи стоят в законе пакета и в `docs/constitution/`.
- **Чем проверяется:** `pnpm run agent-kit:sync`, `pnpm run agent-kit:check`.

### 3. Проверка текстов пакета

- **Что делается:** набор сценариев в `projects/agent-kit/tests/`, читающий `assets/` вместе со
  всеми видами ресурса. Четыре считаемых рода: нет обязательного раздела своего рода, у правила
  нет ни одного паттерна, имя соседа не отвечает набору, адрес конкретного дерева внутри блока
  кода. Роды без объявленного набора разделов молчат, а не краснеют.
- **Признак готовности:** на подставленном ресурсе каждого из четырёх родов набор краснеет и
  печатает имя ресурса и строку; на нынешнем наборе он зелёный либо называет накопленный долг
  поимённо.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`.

### 4. Отказ в гейте пуша

- **Что делается:** проверка встаёт в набор, гоняемый перед пушем, и объявляется в конвейере,
  чтобы набор гейта не оказался уже набора конвейера.
- **Признак готовности:** на ветке с намеренно снятым обязательным разделом пуш отбивается и
  ресурс назван; после возврата раздела пуш проходит.
- **Чем проверяется:** `node tools/check-push-gate.mjs`.

## Чего эта работа не делает

- Роль-ревьюер и команда смыслового ревью — задача RT-704.
- Графы хода в правилах и вливание договорённости — задача RT-705.
- Вливание двух висячих договорённостей — задача RT-706.
- Хук на правке файла ресурса — выкинут решением владельца, задачи под него нет.
- Пробел уровня «статья закона без правила» — его ищет роль, не машина.

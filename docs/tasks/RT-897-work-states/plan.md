# Замысел

**Задача:** RT-897 · **Ветка:** RT-897-work-states
**Поведение:** не меняется — правка задевает ресурсы слоя правил и его гарды, кода приложения
в ней нет ни строки.

## След задачи

| Что     | Где                                                          |
| ------- | ------------------------------------------------------------ |
| Эпик    | `docs/plans/work-conduct-rework.md`                          |
| Законы  | читается, не правится: закон о ведении работы                |
| Правила | пакет слоя правил: правило ведения работы и паттерны при нём |
| Гарды   | пакет слоя правил: гард хода работы и гард ожидания          |
| Код     | пакет слоя правил: его ресурсы и сценарии его гардов         |

## Что считается сделанным

- Перечень состояний работы объявлен: у каждого названы вход, выход и обязательное следующее
  действие.
- Состояние объявляется машиночитаемо одной строкой в ходе работы, и гард читает её, а не
  наличие файлов.
- Гард хода работы судит переход: артефакт без объявленного перехода отказ не снимает.
- Сценарии гардов покрывают каждый переход и каждый отказ; прогон сценариев зелёный.
- Правило ведения работы после правки не длиннее предела, а список шагов заменён перечнем
  состояний, а не дополнен им.

## Этапы

### 1. Перечень состояний и переходов

- **Что делается:** чтение семьи текстов ведения работы целиком — закон, правило, паттерны при
  нём, оба гарда; перечень состояний с входом, выходом и обязательным следующим действием;
  сверка того, что каждый шаг правила лёг в состояние и ни один не потерялся.
- **Признак готовности:** таблица состояний покрывает все шаги правила, и у каждого состояния
  названо действие, исполнимое сейчас.
- **Чем проверяется:** обход шагов правила против таблицы состояний, роль ревью текстов.

### 2. Машиночитаемая строка состояния и гард перехода

- **Что делается:** строка состояния в ходе работы, чтение её гардом, отказ на артефакт без
  перехода; сценарии гардов на каждый переход.
- **Признак готовности:** сценарий на каждый переход и на каждый отказ, прогон зелёный.
- **Чем проверяется:** набор сценариев гардов пакета, сборка, линт.

### 3. Правило переписано перечнем состояний

- **Что делается:** список шагов заменяется перечнем состояний; паттерны начала, возвращения и
  закрытия приводятся к нему; предел длины соблюдён.
- **Признак готовности:** правило не длиннее предела, шагов в нём нет, состояния названы.
- **Чем проверяется:** проверка длины, сверка спеков, прогон сценариев, раскладка в это дерево.

## Чего эта работа не делает

- Разрешённые выходы хода и запрет ожидания — задача RT-898: она стоит на этом перечне, но
  правит другое место.
- Готовность к поставке, красное, отчёт владельцу и место правки слоя правил — задачи
  RT-899…RT-902.
- Правку закона о ведении работы: его статьи приносятся владельцу текстом.
- Выпуск редакции пакета и раскладку её во все деревья.

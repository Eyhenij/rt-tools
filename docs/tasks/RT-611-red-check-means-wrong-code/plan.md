- **Что делается:** в закон о проверяемости добавляется статья о красной проверке — после
  пункта о выключении правила инструмента в его настройке, как указала запись.
- **Признак готовности:** статья не называет ни путей, ни имён дерева.
- **Чем проверяется:** чтение закона, `pnpm run check:docs`.

### 2. Статья правила и её адрес

- **Что делается:** правило тестов получает статью о том, когда строка в список известного не
  заводится; компаньон — адреса обеих статей.
- **Признак готовности:** число статей без адреса не выросло.
- **Чем проверяется:** `pnpm run agent-kit:sync`, затем `pnpm run agent-kit:check`.

### 3. Записи закрыты

- **Что делается:** #593 и #594 закрываются ссылкой на задачу.
- **Признак готовности:** обе записи закрыты, комментарий называет номер задачи.

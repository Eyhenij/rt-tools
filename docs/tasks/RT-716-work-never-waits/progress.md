## Решения по ходу

- **Тело задачи RT-716 пустое и таким осталось** — правило поставки запрещает править тело уже
  заведённой задачи без слова владельца. Промах мой: тело не было передано команде заведения.
  Затронутый этап замысла: нет.
- **Текстовой считается ветка, у которой каждый задетый файл — `.md` либо лежит под `docs/`** —
  признак ошибается в сторону лишнего прогона, а не пропущенного: обвязка, настройки и файлы
  конвейера идут как код. Затронутый этап замысла: 4.
- **Шаг «Состав правки» объявлен исключением набора гейта** — он ничего не проверяет, а считает
  признак для остальных шагов. Без объявления `check-push-gate` отбивает пуш. Затронутый этап
  замысла: 4.
- **Находки разбора в каталог предложений не ложатся** — иначе `agent-kit propose` увёз бы их
  наружу тем же прогоном, что и сводку наблюдений. Переносит их туда человек, после разбора.
  Затронутый этап замысла: 3.

- **Находки разбора закрытой работы** лежат в `curator.md` этой папки — тринадцать штук, наружу
  не уезжали. При разборе папки переезжают к замыслу эпика RT-702.

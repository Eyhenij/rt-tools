## Этапы

### 1. Договорённость влита в два поддомена

- **Что делается:** правила, сценарии и привязки переезжают по предмету — числа и их сверка в
  поддомен передачи захода, поведение стража в поддомен гардов завершения хода; каталог
  предложенного снимается.
- **Признак готовности:** сверка спеков не называет договорённость в разделе «Пора вливать», а
  все одиннадцать сценариев находятся по прежним номерам.
- **Чем проверяется:** `node tools/check-specs.mjs` — расхождений нет.

### 2. Папка задачи разобрана

- **Что делается:** разбор просьбы и решения по ходу уезжают записью в архив, указатель архива
  дополняется, находки — к замыслу эпика, замысел удаляется.
- **Признак готовности:** папки в дереве нет, запись в архиве есть, указатель с каталогом
  сходится.
- **Чем проверяется:** `node tools/check-doc-paths.mjs` — расхождений нет.

### 3. Эпик закрыт

- **Что делается:** замысел эпика уезжает в описание прошлого записью о линии работ, карточка
  эпика закрывается.
- **Признак готовности:** три признака конца эпика названы верными поимённо, карточка закрыта.
- **Чем проверяется:** `npm run check:board` — папки закрытой задачи и брошенного черновика в
  выводе нет.

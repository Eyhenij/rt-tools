## What counts as done

- Приложение-потребитель не объявляет ни одного правила оформления для панели и её формы:
  ни блока формы, ни имён разделов, ни промежутков между ними.
- Иерархия объявлена в ките один раз и берётся разметкой директивами.
- Показано в витрине пакета: раздел, колонка контролов, строка контрола, элемент в ряду.
- Прогон пакета зелёный: линт, стили, юниты, сборка, снимки.

## Stages

### 1. Словарь формы объявлен в ките

- **What is done:** в стилях пакета заводится блок формы с иерархией «раздел, колонка
  контролов, строка контрола, элемент в ряду» плюс заголовок раздела и описание под ним.
  Промежутки задаёт соседство, а не сам элемент.
- **Readiness sign:** правила лежат в слое `rt-kit.components`, значения взяты токенами,
  свой отступ у элемента не написан.
- **Verified by:** `npx nx lint ui-kit-v2` — ноль замечаний.

### 2. Витрина показывает иерархию

- **What is done:** история витрины с формой панели: два раздела, строка с одним контролом,
  строка с двумя элементами в ряду, заголовок и описание.
- **Readiness sign:** история открывается и показывает все пять имён.
- **Verified by:** `npx nx build ui-kit-v2` — сборка проходит.

### 3. Панель кита берёт словарь сама

- **What is done:** `rt-aside-section` и содержимое панели размечаются новым словарём, а не
  своими правилами; лишние правила раздела снимаются.
- **Readiness sign:** в стилях `rt-aside-section` не остаётся правил раскладки, которые
  теперь объявлены словарём.
- **Verified by:** `npx nx test ui-kit-v2` — юниты зелёные.

### 4. Описание приведено к сделанному

- **What is done:** `CONTEXT.md` панели и раздела называют словарь, спек пакета описывает
  иерархию, правило оформления ссылается на неё.
- **Readiness sign:** описание словаря есть в одном месте, и оно совпадает с кодом.
- **Verified by:** `npm run check:specs` — ноль расхождений.

## What this work does not do

- Не переводит потребителей на новый словарь: это работа их деревьев, отдельными задачами.
- Не трогает первую редакцию кита: там свой словарь формы, и он остаётся как есть.
- Не заводит вкладок в панели: `contentLayout="tabs"` у панели уже есть.

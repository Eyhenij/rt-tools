## Замечания хода

- Ветка стоит каскадом от `RT-1715-interpreter-not-writer`; в удалённое дерево не отправляется.

## Что сделано

- Пути из тела интерпретатора берутся, только если в самом теле есть вызов записи: запись файла,
  перенаправление, копирование, перенос, снятие. Тело без них не отдаёт ничего.
- Тело, которое пишет, отдаёт свои пути целиком — путь и вызов записи стоят там разными строками.
- Три сценария SC-AK-858 в наборе гарда места правки; набор — 23 зелёных.
- Статья и адрес в домене места правки. Весь shell-набор зелёный, раскладка сходится, спеки,
  адреса и слог чисты.

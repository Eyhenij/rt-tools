# Замысел

**Поведение:** не меняется — правится помощник слоя правил, кода приложения работа не трогает.

## Этап 1. Тело без записи путей не отдаёт

Пути из тела интерпретатора берутся, только если в самом теле есть признак записи: вызов записи
файла, перенаправление, копирование, перенос, снятие. Тело без них не отдаёт ничего.

## Этап 2. Сценарии, спека и набор

Сценарии в наборе гарда места правки, статья и адрес в домене, весь shell-набор пакета.

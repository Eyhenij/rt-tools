## What counts as done

- Голый атрибут открывает нижний лист, и то же верно для каждого логического входа кита.
- Вход, логический только по объявленному типу, назван отдельно с причиной.
- Требование держит проверка дерева, а не память того, кто заводит вход.
- Договорённость влита в спеку домена, номера сценариев не сдвинуты.

## Stages

### 1. Счёт логических входов без превращения

- **What is done:** названо, сколько в ките логических входов объявлено без превращения строки в
  истину, и каждый выписан поимённо. Открытый вопрос `Q-1` закрыт числом.
- **Readiness sign:** число названо, список лежит в ходе работы, и по нему видно, чинится один вход
  или весь кит.
- **Verified by:** счёт по объявлениям своим скриптом — число совпало с числом строк списка.

### 2. Входы берут превращение

- **What is done:** каждому логическому входу из списка задано превращение строки в истину. Вход,
  логический только по типу, в список не попал и назван отдельно с причиной.
- **Readiness sign:** голый атрибут открывает лист; спеки на вход листа проходят; съёмка снимков
  зелёная — вид кита не сдвинулся ни на точку.
- **Verified by:** `pnpm exec nx test @rt-tools/ui-kit-v2` и `node tools/visual-snapshots-v2.mjs`.

### 3. Проверка держит требование

- **What is done:** проверка дерева читает объявления входов кита и отбивает логический вход без
  превращения, если он не назван отдельно. Проверка встала в набор перед push.
- **Readiness sign:** проверка отбивает нарочно испорченное объявление и молчит на целом дереве.
- **Verified by:** своя проба — испортить объявление, вызвать проверку, вернуть назад.

### 4. Договорённость влита в спеку домена

- **What is done:** правила и сценарии перенесены в спеку домена, папка `proposed/` снята.
- **Readiness sign:** `node tools/check-specs.mjs` не называет эту договорённость среди готовых к
  вливанию, расхождений нет.
- **Verified by:** `node tools/check-specs.mjs` — код выхода 0.

## What this work does not do

- **Не трогает входы, которые не логические.** Число, взятое из атрибута, несёт ту же ловушку и
  свой ответ; здесь он не решается.
- **Не трогает первый кит.** Он читается образцом и не правится.
- **Не трогает разметку показов витрины.** Голый атрибут в истории вылечен привязкой по ходу
  RT-1956, и после этой работы обе формы будут верны.

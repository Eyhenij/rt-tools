# Grill

## Откуда взялась работа

Находка по ходу RT-1956, владелец её не заказывал.

> Логический вход нижнего листа объявлен без превращения строки в истину, и голый атрибут его не
> открывает: `<rt-bottom-sheet open>` даёт входу пустую строку, а она ложна. Лист остаётся
> закрытым, разметка при этом выглядит верной, и ни сборка, ни проверка типов, ни линтер об этом
> не говорят.

Слова взяты из самой задачи 2082 — их писал исполнитель, не владелец.

## Что дерево уже имеет

- Вход листа: `projects/ui-kit-v2/src/lib/components/bottom-sheet/rt-bottom-sheet.component.ts`,
  `open: InputSignal<boolean> = input.required<boolean>()` — без превращения.
- Образец рядом: `projects/ui-kit-v2/src/lib/components/tabs/rt-tab.directive.ts` — там
  `InputSignalWithTransform<boolean, BooleanInput>` с `transform: booleanAttribute`.
- Правило `component-structure` и правило `angular-patterns` говорят о входах компонента; о
  превращении строки в истину ни одно из них статьи не имеет.

## Измерено по ходу RT-1956

- Три матрицы листа объявляли открытость голым атрибутом, и все три рисовали пустые рамки.
  После починки ящика показа кадры всё равно выходили пустыми — лист оставался закрытым.
- В историях вылечено привязкой `[open]="true"`. Сам вход кита не тронут: следующий, кто напишет
  голый атрибут, наступит на то же.

## Вопросы, на которые работа отвечает сама

- **Сколько в ките логических входов без превращения?** Счёт по коду, не на глаз. От числа
  зависит, чинится один вход или заводится правило на весь кит.
- **Меняется ли поведение для потребителя?** Да: голый атрибут начнёт открывать лист. Это правка
  дефекта, но она меняет то, что получает потребитель пакета, — значит нужна договорённость.
- **Держит ли эту статью хоть одна проверка?** Сегодня нет: ни сборка, ни проверка типов, ни
  линтер про строку в логическом входе не говорят.

## Решения

Пока нет: разбор закрыт, договорённость не написана.

## Что считается сделанным

- Замер названной владельцем командой не находит ни одного цикла.
- Проверка дерева зовёт тот же замер и краснеет, когда цикл появляется снова.
- Проверка стоит и в наборе гейта пуша, и в конвейере — набор гейта не бывает уже конвейера.
- Поверхность пакетов не изменилась: сборка, линт и спеки зелёные.

## Этапы

### 1. Циклы сняты

- **Что делается:** импорт из барреля своего каталога заменяется прямым импортом файла там, где
  он замыкает цикл; взаимные импорты компонентов разводятся по месту объявления символа.
- **Признак готовности:** замер не находит циклов.
- **Чем проверяется:** `npx madge --circular --extensions ts ./projects` — в выводе «No circular dependency found».

### 2. Проверка держит их снятыми

- **Что делается:** заводится проверка дерева, зовущая тот же замер; она встаёт в набор гейта
  пуша и в конвейер.
- **Признак готовности:** проверка красна на подложенном цикле и зелена на чистом дереве.
- **Чем проверяется:** `npm run check:cycles` — «циклов нет» в выводе и нулевой код возврата.

## Чего эта работа не делает

- Разбор границ между либами: их судит своя проверка, и правка сюда не тащится.
- Переезд символов между пакетами: работа разводит импорты, а не раскладку.

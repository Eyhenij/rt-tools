# Замысел

**Поведение:** не меняется — раскладка кладёт то же и отвечает тем же кодом; счёт долга начинает
считать по тому тексту, который в дерево и ложится.

## Что делается

1. Сборка тела ресурса — пакетный текст с наложенной надстройкой — становится общей: сейчас она
   живёт внутри раскладки и снаружи недоступна.
2. Счёт долга привязок читает это тело, а не пакетный текст: раздел, замещённый надстройкой,
   статей пакетной редакции больше не несёт, и привязывать в компаньоне нечего.
3. Спека при команде: статья замещённого раздела в долг не идёт.

## Чем проверяется

`pnpm exec nx test @rt-tools/agent-kit`, `pnpm exec nx lint @rt-tools/agent-kit`,
`npm run agent-kit:sync`, `npm run agent-kit:check`, `npm run check:specs`.

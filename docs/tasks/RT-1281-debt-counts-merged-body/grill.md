# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `lib/commands.js`. Отметить её этому дереву
нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Долг привязок считается по тексту, которого в дереве нет

Строка о долге считает статьи пакетной редакции ресурса против компаньона дерева, а дерево эти
разделы замещает надстройкой. В дереве строка назвала семнадцать статей в двух компаньонах, и ни
одна из них в разложенном правиле не стоит вовсе: один раздел замещён своей редакцией правила
поставки, другой — своей редакцией правила наблюдаемости. Долга за этими числами нет, а строка
читается как «семнадцать статей правил дерева некуда привязать» и приходит при каждой раскладке.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

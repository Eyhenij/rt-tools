# Замысел

**Задача:** RT-1951 · **Ветка:** RT-1951-playground-one-name
**Поведение:** не меняется — правятся имена страниц витрины и имена эталонных снимков, код кита не
трогается.

После записи этот файл не правится. Пересмотр этапа уходит в ход работ решением по пути.

## След задачи

| Что     | Где                                            |
| ------- | ---------------------------------------------- |
| Спеки   | `docs/specs/ui-kit-v2/snapshots/`              |
| Правила | `.claude/skills/rt-tools-storybook/`           |
| Код     | `projects/ui-kit-v2/src/**/stories/`           |
| Эталоны | `projects/ui-kit-v2/.storybook/__snapshots__/` |

## Что считается сделанным

- Страница с входами во всех семействах второго кита зовётся одним словом — `Playground`.
- Эталонные снимки переименованы вместе со страницами, а не пересняты: сличение снимков зелёное
  без единой новой картинки.
- Семейство, у которого страницы с входами нет по существу, названо причиной на своей странице
  обзора, а не молчанием.

## Этапы

### 1. Счёт снят и записан

- **Что делается:** считается, сколько семейств зовут страницу `Default`, сколько `Playground` и
  сколько не имеют её вовсе.
- **Признак готовности:** три числа названы командой, а не памятью.
- **Проверено:** `grep -rl "export const Default" projects/ui-kit-v2/src | grep "stories.ts$" | wc -l`
  — 22 файла; то же по `Playground` — 60; эталонов с именем `default` — 19, с именем
  `playground` — 5.

### 2. Страница везде зовётся одним словом

- **Что делается:** двадцать два `Default` переименовываются в `Playground`; эталоны
  переименовываются тем же ходом.
- **Признак готовности:** страниц с именем `Default` не осталось, лишних эталонов нет.
- **Проверено:** `grep -rl "export const Default" projects/ui-kit-v2/src | grep "stories.ts$" | wc -l`
  — ноль; `node tools/visual-gate.mjs ui-kit-v2` — сличение снимков без расхождений и без
  осиротевших эталонов.

### 3. Семейство без страницы входов названо причиной

- **Что делается:** семейства, у которых страницы входов нет по существу, получают строку с
  причиной на своей странице обзора.
- **Признак готовности:** у каждого такого семейства причина написана словами.
- **Проверено:** `node tools/check-kit-coverage.mjs` — счёт семейств сходится, и в исключениях
  стоят причины.

## Чего эта работа не делает

- Не трогает витрину первого кита: там свой набор страниц и свои имена.
- Не пересниматет ни одного эталона: имена меняются переименованием файлов.
- Не меняет порядок страниц внутри семейства — это соседняя работа, если он разойдётся.

держат сценарии, а не память.

## Этапы

### Этап 1 — признак знает, что кит рисует админку

Мерка до правки: на предмете `kit2` выходит один тяжёлый шаг — кадры витрины второго кита.

Признак готовности: выходит два — кадры витрины и сквозной набор админки; при двух предметах
сразу сквозной набор выходит один раз.

### Этап 2 — сценарии поверх признака

Сценарий дерева судит карту предметов и шагов. Сценарии пакета, где эта карта уже описана,
переписываются на новое поведение: они и есть та память, которая иначе разъедется.

Признак готовности: `bash tools/tests/run.sh` и `bash projects/agent-kit/tests/run.sh` зелёные,
а снятие правки этапа 1 роняет обе.

### Этап 3 — тексты и разбор папки

Отметка в ловушках плана эпика; папка задачи разбирается последним коммитом, запись уходит в
описание прошлого.

Признак готовности: `npm run check:docs` зелёная, папки задачи в ветке нет, запись в
`docs/archive/` есть.

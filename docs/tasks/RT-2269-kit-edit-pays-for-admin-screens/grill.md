# Разбор просьбы

## Просьба владельца

Задача заведена по находке при работе RT-2257. Слово владельца 19 сентября 2026 года — «Делай» —
сказано о всей цепочке, где эта работа названа последней.

## Что не так

Админка рисуется набором стилей второго кита: в её корневом файле оформления стоит одна строка
подключения. Значит правка кита меняет каждый её экран. Проверки перед отправкой про эту связь не
знают: сквозной набор админки они зовут только на путях приёмника, его выкатки и схемы хранилища.

Цена уже заплачена. RT-1993 привезла гарнитуру, пересняла 600 кадров витрины и ушла зелёной
честно — по своему признаку. Экраны админки после неё не сличались ни разу, и красное всплыло
через день у соседней ветки: 102 прошли, 25 упали, 23 из них кадр.

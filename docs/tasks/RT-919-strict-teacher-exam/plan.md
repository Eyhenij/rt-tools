# Замысел

**Задача:** RT-919 · **Ветка:** RT-919-strict-teacher-exam
**Поведение:** не меняется — правка задевает роли и гарды слоя правил, кода приложения в ней нет
ни строки.

## След задачи

| Что     | Где                                                                   |
| ------- | --------------------------------------------------------------------- |
| Законы  | читается, не правится: закон о проверяемости и закон о ведении работы |
| Правила | пакет слоя правил: правило ведения работы                             |
| Роли    | пакет слоя правил: новая роль экзаменатора                            |
| Гарды   | пакет слоя правил: гард экзамена                                      |
| Код     | пакет слоя правил: его ресурсы и сценарии его гардов                  |

## Что считается сделанным

- Роль экзаменатора заведена: читает загруженные за сессию правила, задаёт по ним предметные
  вопросы и сверяет ответы с текстом правила, а не с собственным мнением.
- Экзамен идёт дважды: на старте сессии до первой правки и перед снятием черновика с PR.
- Провал блокирует работу: правка файлов отбивается, пока правило не перечитано и экзамен не
  пересдан.
- Ответ, списанный из правила, экзаменом не считается: чтение правила между вопросами и ответами
  гард видит и засчитывает провал.
- Сценарии на сдачу, провал, пересдачу и на молчание роли; прогон зелёный.

## Этапы

### 1. Роль экзаменатора

- **Что делается:** файл роли: что читает, как выбирает вопросы, чем сверяет ответы, в какой
  форме возвращает вердикт.
- **Признак готовности:** роль возвращает вердикт машиночитаемо — сдано или нет и по какому
  правилу.
- **Чем проверяется:** `pnpm run agent-kit:check` — роль разложена в дерево.

### 2. Гард экзамена

- **Что делается:** гард на правке файла отбивает работу, пока за сессию экзамена не было или
  последний вердикт — провал; чтение правил между вопросами и ответами засчитывает провалом.
- **Признак готовности:** сценарий на сдачу, провал, пересдачу, списывание и молчание роли.
- **Чем проверяется:** `bash tests/run.sh` — набор гарда зелёный и краснеет на его поломке.

### 3. Второй экзамен перед снятием черновика

- **Что делается:** гард снятия черновика спрашивает вердикт второго экзамена — по правилам
  поставки и по тому, чего требовала задача.
- **Признак готовности:** черновик не снимается, пока второго экзамена не было.
- **Чем проверяется:** `bash tests/run.sh` — сценарии обоих гардов зелёные.

## Чего эта работа не делает

- Роль совести — задача RT-918.
- Линтер слога — задача RT-920.
- Правку закона: его статьи приносятся владельцу текстом.

# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `skills/agent-kit.md`. Отметить её этому
дереву нечем: токен двигает только свои записи, работа при этом наша.

## Подъём версии молча теряет дописанное пакетом

> Совпавший заголовок замещает раздел целиком, поэтому всё, что пакет дописал в такой раздел
> новой версией, пропадает молча: `sync --check` зелен, заголовки сходятся, а утверждения нет.
> Ни `doctor`, ни `sync --check`, ни сверка заголовков надстроек этого не показывают: сверка
> заголовков ловит переименование раздела, а не пополнение. На подъёме одной редакции восемь
> разделов из пяти надстроек замещали пакетные, и в шести из них пакет дописал новые
> утверждения. Дерево узнаёт о пропаже, только если кто-то вручную сравнит две поставки.

Просьба: чтобы разделы, которые надстройки замещают, называла команда осмотра, а в скиле стоял
шаг подъёма версии.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Сравнения двух поставок не будет: прежней редакции пакета в дереве нет вовсе — лежит одна,
текущая. Команда назовёт замещённые разделы; какие из них пакет пополнил, читает человек,
сравнивая с историей пакета. Названо ценой в записи о закрытой работе.

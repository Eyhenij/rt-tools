# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 4 — код пропуска объявлен и назван один раз

## Решения по ходу

- **Пропуск не отбивает пуш.** Проверка, которой нечего смотреть, поломкой не является:
  отбивать ею работу значило бы требовать базу от дерева, где её нет. Отличается пропуск не
  отказом, а тем, что его называют вслух.

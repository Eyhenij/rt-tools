## Этапы

### 1. Уборка перенесена в свою ветку

- **Что делается:** коммит `787db616` с пересозданной ветки RT-703 переносится сюда.
- **Признак готовности:** папки RT-703 в ветке нет, запись в описании прошлого и строка
  указателя на месте, образец правила приведён к набору.
- **Чем проверяется:** `npm run check:docs`, `bash projects/agent-kit/tests/run.sh`.

### 2. Своя папка разобрана

- **Что делается:** разбор просьбы уезжает в описание прошлого, замысел удаляется, строка
  дописывается в указатель.
- **Признак готовности:** `docs/tasks/` не держит ни одной папки закрытой задачи.
- **Чем проверяется:** `npm run check:board`, `npm run check:docs`.

## Чего эта работа не делает

- Не заводит гарда на слияние кнопкой: хуков в браузере нет, и заводить их негде.
- Не трогает договорённость `proposed/rules-review/`: её вливание назначено задаче RT-705.
- Не чинит остальные находки о текстах пакета — их ищет роль из задачи RT-704.

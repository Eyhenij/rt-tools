# Разбор

## Запрос владельца

Вопрос задан по предложениям разбора RT-2378. Ответ владельца дословно:

> Всё одной задачей (Рекомендую)

Что входит: три пункта в правила стилей этого дерева — панели наложения под набором, тёмная схема,
свои ступени набора — и починка пересъёмки кадров по шаблону путей со скобками.

## Что уже есть в дереве

- `rt-tools-styling` — правило этого дерева, статья о признаке набора на корне или контейнере.
- `rt-tools-styling-tokens` — образец этого дерева, пункт «A name used by both kits is refused».
- `ui-component-tests-visual` — предупреждение: шаблон путей идёт в оболочку как есть.
- `tools/visual-snapshots-v2.mjs` передаёт шаблон `test-storybook`, а тот собирает команду Jest
  строкой для оболочки.

## Что уже говорят правила

- Правила этого дерева правятся здесь; выложенные из пакета — нет. Все три файла без заголовка
  выкладки.

## Вопросы и ответы

**Что делать с предложениями разбора?**
«Всё одной задачей (Рекомендую)».

## Решения

- **Шаблон берётся в кавычки оболочки в самом скрипте.** Строку команды собирает `test-storybook`,
  не скрипт дерева; массив аргументов её не спасает. Отвергнуто: править сторонний пакет.
- **Ветка стоит цепочкой на RT-2380.** Правило называет помощник набора, которого в ветке эпика ещё
  нет.

## Что осталось неясным

- Ничего.

# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `hooks/task-context-load.sh`. Отметить её
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Папка задачи зовётся не именем ветки

Большая задача, чьи этапы идут отдельными ветками, держит одну папку на все этапы, и зовётся эта
папка не именем текущей ветки. Хук ищет строго по имени ветки, не находит и печатает, что ход
работы записывать некуда. Заход читает это как «записей нет», хотя они лежат в соседней папке, и
дальше отвечает владельцу из кода — выводит заново поведение, о котором в записях есть закрытый
вопрос и сценарий с прогоном.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

# Замысел

**Поведение:** не меняется — хук по-прежнему отдаёт ход работы, найдя папку по имени ветки, и
по-прежнему не рвёт сессию, не найдя её.

## Что делается

1. `hooks/task-context-load.sh`: не найдя папку по имени ветки, хук смотрит, что лежит в каталоге
   задач, и называет найденное поимённо. Каталог пуст — отказ прежний, слово в слово.
2. Набор сценариев `task-context-load.test.sh`: папка по имени ветки, папка под другим именем,
   пустой каталог задач.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`.

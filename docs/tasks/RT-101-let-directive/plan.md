## Что считается сделанным

- Директива объявляет имя для значения и отдаёт его содержимому двумя именами.
- Содержимое рисуется при любом значении, включая пустое.
- Смена значения не пересоздаёт содержимое и перерисовывает его при перерисовке по требованию.
- Тип значения доезжает до содержимого: строгая проверка шаблона знает его без приведения.
- Директива вывезена из пакета и покрыта спекой на все четыре сценария.

## Этапы

### 1. Директива и её вывоз

- **Что делается:** пишется `projects/core/src/lib/directives/let.directive.ts` — сигнальный вход,
  представление, создаваемое один раз, контекст с двумя именами и страж типа; имя дописывается в
  бочку директив.
- **Признак готовности:** пакет собирается, директива видна снаружи.
- **Чем проверяется:** `pnpm exec nx build @rt-tools/core` — сборка без отказов.

### 2. Спека на четыре сценария

- **Что делается:** `let.directive.spec.ts` — хозяин с полем ввода внутри содержимого, смена
  значения, пустота, оба имени, перерисовка по требованию.
- **Признак готовности:** все четыре сценария зелёные.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/core` — прогон без провалов.

### 3. Договорённость сведена с кодом

- **Что делается:** привязки статей и сценариев в `implementation.md` называют настоящие символы и
  файл спеки.
- **Признак готовности:** сверка спеков не находит расхождений.
- **Чем проверяется:** `node tools/check-specs.mjs` — строка без расхождений.

## Чего эта работа не делает

- Условного показа и ветки «иначе» — это работа условия, и она есть в языке разметки.
- Заведения домена ядра: договорённость лежит предложением, пока владелец не скажет заводить.

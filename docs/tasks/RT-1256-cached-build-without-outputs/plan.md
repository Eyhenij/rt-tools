# Замысел

**Поведение:** не меняется — правится текст правила, ни одной проверки и ни одного гарда задача
не трогает.

Ловушка о кэше говорит про кэш зависимостей и учит не закрывать им разбор. Кэш готовых
артефактов шага сборки ведёт себя противоположно: он не объясняет расхождение, а создаёт его.

## Этапы

1. Ловушка рядом с прежней — в разделе «Ловушки» правила проверки работающего приложения.
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Объявления выходов у своего шага сборки задача не касается: это правка одного дерева, а правило
говорит о свойстве любого кэширующего сборщика.

## Что считается сделанным

- Гард снятия черновика отбивает завершение хода, когда открытым черновиком стоит **любая**
  заявка машинной записи с зелёным прогоном на вершине и разобранной папкой задачи, — а не
  только заявка текущей ветки.
- Уход в соседнюю ветку гард не выключает: брошенная заявка называется по номеру вместе с
  вызовом её снятия.
- Отказ в пользу работы сохранён целиком: нет сети, нет помощника хостинга, нет `jq`, повторный
  заход — ход разрешается.
- Сценарии `tools/check-hooks.mjs` покрывают новый ярус: брошенный черновик отбивает, чужая
  заявка с открытыми этапами молчит, отсутствие списка молчит.

## Этапы

### 1. Второй ярус гарда: чужие черновики

- **Что делается:** гард спрашивает у хостинга список открытых черновиков машинной записи и
  судит каждый по вершине и по папке задачи в его ветке; заявка текущей ветки судится прежним
  ярусом.
- **Признак готовности:** брошенный черновик соседней ветки отбивает завершение хода.
- **Чем проверяется:** `node tools/check-hooks.mjs` — строка «все сошлись» и число сценариев
  больше десяти.

### 2. Сценарии на новый ярус

- **Что делается:** в `tools/check-hooks.mjs` заводится подставной ответ `pr list`, вторая ветка
  в репозитории сценария и исходы нового яруса.
- **Признак готовности:** сломанный ярус краснит набор.
- **Чем проверяется:** `node tools/check-hooks.mjs` — все сценарии сошлись.

### 3. Разбор происшествия и статья правила

- **Что делается:** в `docs/postmortems/` ложится разбор «Прогон запущен и оставлен без
  присмотра»; в правило поставки дописывается статья о том, что гард судит все свои черновики.
- **Признак готовности:** разбор лежит, статья стоит, сверка адресов зелёная.
- **Чем проверяется:** `pnpm run check:docs` — расхождений нет.

### 4. Набор гейта и отдача

- **Что делается:** прогоняется набор гейта пуша, ветка уезжает на хостинг, папка задачи
  разбирается последним коммитом, заявка открывается черновиком.
- **Признак готовности:** заявка открыта, номер назван владельцу.
- **Чем проверяется:** `git push` — гейт пропустил.

## Чего эта работа не делает

- Не трогает ветку RT-1131 и её заявку #1146 — владелец сказал прямо.
- Не заводит счётчика времени между зелёным прогоном и снятым черновиком: числа цели нет.
- Не правит сверку очереди работ: она уже называет черновик при зелёном прогоне отдельной
  строкой, и промах не в ней.

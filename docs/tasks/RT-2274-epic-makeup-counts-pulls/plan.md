### Этап 1 — состав эпика считает только задачи

Столбец задачи в составе — тот, по которому строка вообще признаётся строкой состава: заголовок
несёт слово «Задача» или «Task». Номер берётся из него, а состояние и примечания в счёт не идут.

Признак готовности: `node tools/check-board.mjs` без строк «the plan names tasks that are not
sub-issues», `bash projects/agent-kit/tests/run.sh` зелёный, `node tools/check-specs.mjs` без
расхождений.

## Что считается сделанным

- В правиле ведения работы стоят три статьи: этапы покрывают признак закрытия; признак готовности
  этапа снимается с вывода команды, прогнанной при написании плана; план работы, переносящей приём
  со стороны, пишется по замеру своего кода.
- Образец плана говорит, что команда запускается при написании плана, а не в конце этапа.
- У каждой новой статьи есть привязка или вердикт с причиной.
- Записи груза, закрытые этой правкой, помечены в приёмнике сделанными.

## Этапы

### 1. Три статьи правила ведения работы

- **Что делается:** статьи о покрытии признака закрытия, о происхождении признака готовности этапа
  и о плане переноса приёма со стороны встают в раздел о применении закона
- **Признак готовности:** аудит описаний не называет ни статьи без адреса, ни адреса без статьи
- **Проверено:** `npm run check:specs` — расхождений нет

### 2. Образец плана называет время первого запуска команды

- **Что делается:** абзац под строкой о проверке дописывается предложением о том, что команда
  запускается при написании плана
- **Признак готовности:** образец прочитан, и в нём сказано, когда команда запускается впервые
- **Проверено:** `npm run check:specs` — расхождений нет

### 3. Установка файлов из пакета и пометки в приёмнике

- **Что делается:** пакет собирается и раскладывается, три записи груза помечаются сделанными
- **Признак готовности:** аудит установки молчит
- **Проверено:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

## Чего работа не делает

- Не трогает порядок сдачи и черновик: это задача #2038, и она ждёт слова владельца.
- Не заводит проверки на покрытие признака закрытия: машине оно не видно.

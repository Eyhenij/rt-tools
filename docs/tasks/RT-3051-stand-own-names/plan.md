## Stages

### 1. Стенд читает имена из окружения

- **Steps:**
    1. Порты в compose и области входа
    2. Адрес Keycloak и порты примера в стендах
    3. Проверка стенда и браузер кадров
    4. Раздача примера подставляет адрес Keycloak
- **Readiness sign:** ни одного записанного порта стенда вне умолчаний.
- **Verified by:** `docker compose -f deploy/auth/compose.yml config` с заданными переменными — в
  выводе порты из окружения; без переменных — прежние.

### 2. Набор получает имена копии

- **Steps:**
    1. Вывод имён копии в профиле дерева
    2. Набор сценариев на вывод
    3. Конвейер называет свои имена
- **Readiness sign:** две папки дают разные имена, одна папка даёт одни и те же, явная переменная
  сильнее.
- **Verified by:** `bash tools/tests/stand-env.test.sh` — все сценарии зелёные.

### 3. Два стенда рядом

- **Steps:**
    1. Два стенда входа подняты одновременно
    2. Набор примера идёт на своём стенде
    3. Спек и документы обновлены
- **Readiness sign:** оба стенда отвечают, и каждый проходит проверку.
- **Verified by:** `pnpm run check:auth-stand` на каждом — ни одной строки `FAIL`.

## What the tree already has

- Стенд админки читает порты из окружения: `E2E_API_PORT`, `E2E_ADMIN_PORT`, `E2E_FOREIGN_PORT`,
  `E2E_DB_PORT`. Умолчания оставлены для ручного запуска.
- Браузер кадров уже держит свои имя и порт на копию: `tools/shot-browser-name.mjs` выводит их из
  пути копии.
- Keycloak стенда общий: порты записаны в `deploy/auth/compose.yml`, проект назван `rt-auth`, адрес
  `http://localhost:58080` записан в обоих `stand.mjs`, в `tools/auth-stand-check.mjs`, в
  `tools/shot-browser.mjs` и в собранной админке примера.
- Порты примера 3410 и 4410 записаны в `apps/auth-example-e2e/stand/stand.mjs`.
- Набор идёт в одной оболочке с профилем: `rt_push_set_profile` читает профиль дерева, а шаги
  исполняются через `eval`. То, что профиль экспортировал, видят все шаги.
- Строки набора сверяются с шагами конвейера по точному тексту в `.claude/rt-kit/checks.json`.

## Decisions

- **Имена копии выводятся из её пути в профиле дерева.** Запись в файл вне истории требовала бы
  настройки в каждой копии, и забытая настройка молча вернула бы общий стенд. Отвергнуто: файл
  окружения на копию.
- **Умолчания для ручного запуска не меняются.** Владелец держит на них свои стенды, и документы
  называют эти порты. Своё окружение получает только набор перед отправкой. Явная переменная сильнее
  выведенной.
- **Имя compose — штатная переменная `COMPOSE_PROJECT_NAME`.** Она сильнее строки `name:` в файле и
  разводит оба файла compose одним значением: база копии не пересоздаётся на другом порту. Отвергнуто:
  своя переменная в строке `name:` у каждого файла.
- **Строки набора не меняются.** Их сверяют с конвейером по тексту, поэтому окружение задаёт профиль,
  а не приставка к строке.
- **Собранная админка примера не меняется.** Адрес Keycloak в ней подставляет раздача стенда, когда
  порт стенда не умолчание.

## What is left unclear

- Стенды копий остаются поднятыми между прогонами: у контейнеров `restart: unless-stopped`. Цена
  названа в описании PR, снятие стенда — не эта задача.

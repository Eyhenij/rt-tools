## Что делается

Две половины приехавшей записи проверяются на нынешней редакции пакета: команда чтения с
заглушённым потоком и подпись у коммита слияния. Починенное закрывается с доказательством,
оставшееся чинится.

## Что считается сделанным

- Про каждую из двух половин сказано числом или выводом команды, верна она сегодня или нет.
- Оставшееся верным починено; починенное прежде — названо местом правки.

### 1. Проверка обеих половин

- **Что делается:** признак записи зовётся на команде чтения с заглушённым потоком и на
  настоящей записи; блок команд слияния читается на предмет переменных подписи.
- **Признак готовности:** про каждую половину есть вывод команды либо строка ресурса.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — 0 провалов.

### 2. Починка оставшегося

- **Что делается:** то из двух, что сегодня ещё верно, чинится в источнике пакета; остальное
  закрывается с доказательством в описании прошлого.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — 0 провалов.

## Что считается сделанным

- Вводная история каждого из трёх компонентов показывает правдоподобный набор, а не пустой.
- Набор лежит в одном месте и берётся оттуда и матрицей, и вводной.
- Пропуск снимка у трёх вводных снят, эталоны сняты после осмотра глазами.
- Названо, чем пустая история отбивается впредь, или записано, что этого нет и почему.

## Этапы

### 1. Наборы вынесены рядом с обёртками

- **Что делается:** `ROWS`, `MESSAGES` и месяцы переезжают в отдельный файл рядом с обёртками;
  матрица берёт их оттуда.
- **Признак готовности:** сборка кита и типы проходят, матрицы показывают то же, что и раньше.
- **Проверено:** `pnpm exec nx run @rt-tools/ui-kit-v2:typecheck` — ошибок нет.

### 2. Вводные истории наполнены

- **Что делается:** вводная каждого из трёх берёт набор из общего файла; пропуск снимка снят.
- **Признак готовности:** в кадре список, месяц и лента сообщений, а не пустое состояние.
- **Проверено:** `pnpm run test:stories:v2` — 529 историй и 79 страниц обзора без ошибок; кадры
  трёх вводных просмотрены глазами до съёмки эталонов.

### 3. Эталоны сняты и правило поправлено

- **Что делается:** эталоны трёх вводных снимаются точечно; спутник правила показа правится —
  число «десять» устарело.
- **Признак готовности:** снимки лежат под гитом, спутник называет нынешнее число.
- **Проверено:** `pnpm run test:visual:v2` — расхождений нет.

## Чего эта работа не делает

- Не заводит истории семи компонентам без своей — это RT-2021.
- Не двигает порог площади показа: он про пустой кадр, а не про пустой набор.

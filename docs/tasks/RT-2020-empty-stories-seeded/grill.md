# Разбор

## Просьба владельца

> овервью с ошибками!!! закрываем дыры

Дыры названы в ответе на вопрос «второй кит на данный момент полностью покрыт тестами + в
сторибуке вьюха?». Эта задача — вторая из трёх; первая, RT-2019, закрыта.

## Что в дереве уже есть

- У каждого из трёх компонентов два файла историй: вводная `Default` и матрица состояний.
- Матрицы наполнены: у полосчатого списка шесть историй, у календаря восемь, у переписки девять.
  Наборы для них лежат прямо в обёртках матриц — `ROWS`, `MESSAGES`, и месяцы, собранные
  вспомогательными `day` и `month`.
- Вводная история у всех трёх подаёт пустой набор и помечена пропуском снимка с причиной
  «наполнение — волна покрытия составных компонентов».

## Что уже сказано правилами

- Правило `rt-tools-storybook`: «A story that renders an empty collection is not coverage».
- Правило `ui-component-tests`: эталон снимается после того, как в кадр посмотрели глазами,
  иначе снимок закрепляет пустоту образцом.
- Спутник правила показа: «Ten stories draw an empty collection today» — число устарело, живых
  осталось три.

## Замер

`pnpm run test:stories:v2` пустого показа у этих трёх не видит: помост показа рисует рамку и
подпись ячейки, и площадь проходит порог в сто квадратных пикселей. Проверка покрытия
`tools/check-kit-coverage.mjs` о содержимом истории не спрашивает вовсе.

## Решения

- **Набор выносится в отдельный файл рядом с обёртками, а не копируется во вводную.** Две копии
  одного набора расходятся первой же правкой, и матрица с вводной начинают показывать разное.
- **Пропуск снимка снимается вместе с наполнением.** Пометка стояла ровно потому, что показывать
  было нечего.

## Что осталось неясным

- Чем такая история отбивается впредь. Порог площади её не видит, а «набор непустой» машине
  негде спросить: вход подаёт обёртка. Решение уносится в этап 3.

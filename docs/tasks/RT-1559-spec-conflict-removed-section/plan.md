## Этапы

### 1. Ловушка говорит о снятом разделе

- **Что делается:** к ловушке о конфликте дописывается случай снятого раздела и признак.
- **Признак готовности:** сложение названо ответом на дописи, а не на снятие.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка кладёт файл без отказа.

### 2. Пределы выдержаны

- **Что делается:** прогон проверки длины.
- **Признак готовности:** долг 0, новых нет.
- **Чем проверяется:** `node tools/check-file-size.mjs` — долг 0, новых нет.

## Чего эта работа не делает

- Не заводит проверки на разрешённый конфликт: примет конфликта в разрешённом файле не остаётся.

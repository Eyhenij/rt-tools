# Grill

## The owner request

Разбор всего эпика лежит в записи архива задачи RT-3152. Карточка задачи: чтобы понять, что улучшать,
сейчас надо считать руками. В админке приёмника нужен раздел «Качество»: три числа итога за период,
строка о полноте данных и таблица причин. Готово, когда раздел открывается на стенде на всех
состояниях, включая пустое и период меньше десяти задач, и проверен на ширинах 1440, 768 и 375.

## Decisions

- **Макета нет.** Дерево рисует макеты только для своих китов, экран админки собирается из кита по
  образцу раздела «Использование».
- **Раздел читает строки дня.** Числа считает пакет, приёмник их только складывает.
- **`Postmortem.resource` и `RecordTransition` входят сюда.** Их читает только этот раздел.
- **Принятые с первого раза считаются при сложении дней.** В строке дня число идёт без вычета откатов,
  раздел вычитает сумму откатов из суммы и не опускается ниже нуля.

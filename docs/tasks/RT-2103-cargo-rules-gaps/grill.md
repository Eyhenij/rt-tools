## Questions and answers

**Меняет ли задача поведение приложения?**
Нет: правятся тексты правил пакета и их установленные копии.

**Нужна ли правка закона или правила?**
Правила — да, это и есть работа. Законы не трогаются.

**Одна задача или несколько?**
Одна: обе правки — текст правил, откатываются вместе.

**Что не входит в задачу?**
Блокирующая проверка разрушительных команд гита — отдельная задача, там код и тесты.

**Что покажет, что задача закрыта?**
`pnpm run agent-kit:check` без расхождений; `grep -c` по трём статьям даёт 1 в каждом файле.

**Есть ли образец?**
Статьи того же правила в варианте для GitHub — переносятся в Azure и GitLab слово в слово, с
заменой команды хостинга.

## Decisions

- **Статья о приёмке вида пишется в правило проверки в браузере, а не в паттерн** — запись
  адресует её разделу «Как закон применяется здесь», и там уже стоит соседняя статья об измерении
  до показа. Спросить было некого: сессия автономная. Цена ошибки: перенести абзац в паттерн —
  десять минут.
- **Две статьи о поставке переносятся в варианты Azure и GitLab без своей редакции** — правило
  одно, хостинги разные, и запись пришла из дерева не на GitHub. Спросить было некого: сессия
  автономная. Цена ошибки: снять два абзаца.

  метки, сценарии с привязкой к заголовкам проб и таблица привязок. Два новых обещания — размеры и
  усечение — пишутся здесь же: договорённость идёт до кода.
- **Readiness sign:** аудит описаний не называет ни одного сценария метки без пробы и ни одной
  статьи без адреса.
- **Verified by:** `npm run check:specs` — сегодня код выхода 0; после этапа он остаётся нулём, а
  строк `no test` про `ui-kit-v2/tag` нет ни одной.

### 2. Три размера

- **What is done:** вход `size` с тремя ступенями. Отступы, кегль и размер значка берутся токеном
  шкалы, а не числом в месте; ступень ставится модификатором блока через директиву.
- **Readiness sign:** проверки метки ловят все три ступени; прежние остаются зелёными.
- **Verified by:** `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=src/lib/components/tag/rt-tag.component.spec.ts` — было 30 из 30.

### 3. Усечение подписи с подсказкой

- **What is done:** подпись, которой не хватило места, усекается многоточием и получает подсказку с
  целым значением. Переполнение считается наблюдателем за размером, а не задержкой: задержка
  отвечает о машине, а не о раскладке. Подсказка берётся готовой — `rt-tooltip`, своей разметки не
  пишется.
- **Readiness sign:** проверка ловит появление подсказки на длинном значении и её отсутствие на
  коротком.
- **Verified by:** та же команда — число проверок растёт, все зелёные.

### 4. Матрица витрины и эталонные кадры

- **What is done:** в матрицу метки встают оси размеров и усечения; кадры снимаются и кладутся под

- **Readiness sign:** два подъёма подряд зелёные, и новые кадры не пустые.
- **Verified by:** `node tools/visual-gate.mjs ui-kit-v2` — было 589 из 589 (замерено дважды: первый

## What this work does not do

- **Своё семейство `rt-info-badge` рядом с меткой не заводится** — правило единообразия называет
  одну дорогу: готовое дополняется. Заводить своё можно только по прямому слову владельца.
- **Произвольный цвет фона со счётом цвета текста по нему не переносится** — палитра второго кита
  закрытая и берётся токеном. Приложению, которому нужен свой цвет, отвечает переопределение
  свойства компонента.
- **Первый кит не правится** — он открыт образцом: разметка, стили и истории читаются, не правятся.
- **Снятие значка-бейджа из первого кита сюда не входит** — первый кит снимается целиком, задачей
  эпика о снятии, а не по одному семейству.

## What counts as done

- Кадр показа берёт содержимое, вышедшее за рамку узла, и не трогает страницу под затвором.
- Показ, назвавший свою ширину, снимается при названной ширине, а не при раздвинутой.
- Эталоны, прятавшие обрез, пересняты после осмотра.

## Stages

### 1. Измерение: где режет и чем это снимать

- **What is done:** обойдена вся витрина, посчитано, у скольких показов нарисованное выходит за
  рамку узла; проверено, трогает ли страницу кадр с обрезкой по охвату.
- **Readiness sign:** названо число показов с обрезом и названа причина, по которой очевидный
  способ не годится.
- **Verified by:** обход витрины своим скриптом — 545 показов, 113 без корня, режется у 35.
  Кадр страницы с обрезкой по охвату двигает показ: высота узла 514 → 512, охват 912 → 910.

### 2. Правка обвязки

- **What is done:** окно раздвигается по охвату нарисованного, а не по рамке узла, и кадр берётся
  обрезкой внутри окна. Показ, снимаемый при названной ширине, окно не раздвигает.
- **Readiness sign:** у показа с выносом кадр шире рамки узла; у показа с названной шириной окно
  осталось названным.
- **Verified by:** `node tools/visual-snapshots-v2.mjs` — расхождения только у тех показов, что
  названы в первом этапе.

### 3. Осмотр и пересъёмка

- **What is done:** кадры показов с обрезом осмотрены поштучно, эталоны пересняты.
- **Readiness sign:** съёмка зелёная, сирот в каталоге нет.
- **Verified by:** `node tools/visual-snapshots-v2.mjs` — расхождений нет, сирот нет.

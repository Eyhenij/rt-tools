- **Кадр страницы с обрезкой по охвату тоже не годится** — он повторяет ту самую подмену окна:
  высота узла ушла с 514 на 512, охват с 912 на 910. Кадр по узлу страницу не трогает вовсе.
  Affected stage of the plan: 1.
- **Охват режется предком, который прокручивается или прячет выход** — без этого в охват попадало
  и то, чего браузер не рисует вовсе: лента внутри окна высотой в экран давала охват в три с
  лишним тысячи точек. Affected stage of the plan: 2.
- **Окно считается по краям охвата, а не по его размерам** — показ стоит с отступом от края
  страницы, и окна ростом ровно в охват не хватало на этот отступ: кадр выходил короче прежнего,
  и сверка краснела на 145 кадрах. Affected stage of the plan: 2.
- **Округление взято то же, каким его брала съёмка по узлу** — край наружу, начало внутрь. Иначе
  кадр выходил на точку короче у каждого показа с дробной высотой: 222 размерных расхождения, ни
  одно из которых не было правкой. Affected stage of the plan: 2.
- **Окно раздвигается по охвату нарисованного, а не по рамке узла** — рамку узел получает от
  окна, и вынос в ней не виден. Показ, снимаемый при названной ширине, окно не раздвигает: там
  раздвигание и подменяло проверяемую сторону порога. Affected stage of the plan: 2.

## Что считается сделанным

- Замысел кончившегося эпика лежит в описании прошлого записью о состоявшемся: чем кончилась
  каждая из пяти задач, что осталось за границами.
- В каталоге замыслов его больше нет, а в указателе описания прошлого есть строка о нём.
- Карточка эпика закрыта.
- `pnpm run check:docs` зелёная.

## Этапы

### 1. Замысел переезжает в описание прошлого

- **Что делается:** запись собирается из замысла — расхождение с образцом, порядок задач с их
  исходом, границы; строка встаёт в указатель, замысел снимается.
- **Признак готовности:** запись на месте, замысла в каталоге нет, указатель сходится.
- **Чем проверяется:** `pnpm run check:docs`.

### 2. Карточка эпика закрывается

- **Что делается:** задача эпика закрывается в очереди работ.
- **Признак готовности:** карточка закрыта, сверка очереди работ на неё не краснеет.
- **Чем проверяется:** `pnpm run check:board`.

## Чего эта работа не делает

- Не трогает другие открытые эпики и их замыслы.
- Не переснимает эталонные кадры и не правит показ админки: эпик кончился, его работа сделана.

## Что считается сделанным

- Ни один файл стилей компонента не обращается к `--rt-radius-*`, `--rt-shadow-*`,
  `--rt-border-width-*` и `--rt-duration-*` напрямую: между ступенью и местом употребления стоит
  своё свойство компонента.
- Набор свойств каждого тронутого компонента полон: компонент потребляет только свои свойства по
  этим четырём семействам, а не половину своих и половину ступеней.
- Имя свойства выводится из имени блока — `--rt-<блок>-<что>`, — и ни одно не заводится под
  место употребления.
- Проверка отбивает прямое обращение к ступени этих четырёх семейств в стилях компонента;
  накопленное стоит поимённо в списке принятого, и список только убывает.
- Вид кита не двигается: все 445 эталонов витрины зелёные без пересъёмки. Разошедшийся кадр —
  дефект правки, а не названное исключение: свойство по умолчанию равно снятой ступени.
- Витрина показывает, что свойство работает: страница или история с китом на разных значениях.
- Роли перечислены в `README.md` кита и на странице оформления витрины — с указанием, какое
  свойство где применяется.
- `check:all` зелёный; гейты графа, литералов и тёмной темы зелёные.

## Этапы

### 1. Имя и форма свойства, приём обкатан

- **Что делается:** называется форма — `--rt-<блок>-<что>`, объявление в корне блока со ступенью
  как значением по умолчанию, употребление через `var()` без запасного значения. Приём
  прогоняется на трёх файлах разного рода: компонент, уже объявляющий свои свойства (кнопка);
  компонент, не объявляющий ни одного; часть, у которой нет своего селектора.
- **Признак готовности:** три файла переведены, вычисленные значения на витрине совпадают с
  замером до правки, кадры этих трёх компонентов зелёные без пересъёмки.
- **Чем проверяется:** замер вычисленных значений в браузере, `pnpm test:visual:v2`,
  `pnpm run lint:styles`.

### 2. Радиус — 46 файлов

- **Что делается:** 97 обращений к `--rt-radius-*` переезжают на свои свойства компонентов.
  Ступень остаётся значением по умолчанию, поэтому вид не двигается ни в одном кадре.
- **Признак готовности:** поиск `var(--rt-radius-` по стилям компонентов даёт ноль совпадений;
  кадры зелёные без пересъёмки.
- **Чем проверяется:** поиск по дереву, `pnpm test:visual:v2`, `pnpm run lint:styles`.

### 3. Тень, толщина рамки и длительность

- **Что делается:** оставшиеся 144 обращения трёх семейств переезжают тем же приёмом. Длительность
  и толщина рамки чаще стоят в составных значениях — они разбираются на части, а не переносятся
  строкой целиком.
- **Признак готовности:** поиск трёх приставок по стилям компонентов даёт ноль совпадений;
  кадры зелёные без пересъёмки.
- **Чем проверяется:** поиск по дереву, `pnpm test:visual:v2`, `pnpm run lint:styles`.

### 4. Проверка и список принятого

- **Что делается:** в `tools/stylelint-tokens.config.mjs` заводится правило, отбивающее прямое
  обращение к ступеням четырёх семейств в наборе стилей компонентов; всё, что осталось
  необъяснимым, уезжает в свой список принятого записью «файл и значение», без номера строки.
  Список только убывает: запись, которой в стилях больше ничего не отвечает, роняет прогон.
- **Признак готовности:** проверка красная на подложенном нарушении и зелёная на дереве; список
  принятого пуст либо каждая его запись объяснена.
- **Чем проверяется:** `pnpm run check:tokens-styles`, подложенное нарушение и его снятие.

### 5. Тексты кита и договорённость

- **Что делается:** страница оформления витрины получает раздел свойств компонента и показ кита
  на разных значениях; `README.md` кита перечисляет свойства с указанием, где применяется каждое.
  В договорённость дописывается закрытие `Q-2` ответом владельца и привязка `SC-UKV-49` к коду.
  В правило оформления надстройкой дописывается новая проверка и её граница.
- **Признак готовности:** `Q-2` стоит в разделе закрытых; `SC-UKV-49` назван покрытым или
  непокрытым честно; ни одна страница витрины не обещает того, чего нет.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`, `pnpm run agent-kit:check`.

### 6. Кадры и общий набор проверок

- **Что делается:** сверяются кадры витрины целиком. Расхождений быть не должно ни одного: у
  работы нет названного вслух изменения вида. Разошедшийся кадр разбирается как дефект, а не
  переснимается.
- **Признак готовности:** 445 эталонов зелёные без единой пересъёмки; `check:all` зелёный.
- **Чем проверяется:** `pnpm test:visual:v2`, `pnpm run check:all`.

## Чего эта работа не делает

- **Отступ, кегль и габариты.** Три семейства из шести — 386 обращений — остаются на ступенях:
  роль отступа и кегля одним словом не называется, и свойство под неё вышло бы именем места, а не
  именем роли.
- **Настройка оформления кодом.** `Q-2` закрыт ответом владельца: конфигурации поверх свойств не
  заводится, а конфигурация первого кита в этот кит не едет.
- **Слой ролей между шкалой и компонентом.** Тело задачи предлагало `--rt-control-radius` и
  родню; владелец выбрал свои свойства компонента, и промежуточного слоя не заводится.
- **Слой каскада `@layer rt-kit`** — RT-387, позиция 9.
- **Источник токенов объектом** — RT-388, позиция 10.
- **Расширение проверки на размеры числом.** Граница правила оформления остаётся прежней:
  `width`, `height`, `inline-size` и `outline` она не судит.

## What counts as done

- Пакетная проверка выхода из хода при открытом эпике не отпускает ни второй проход, ни ход,
  кончившийся работой: ход возвращается с названным следующим шагом.
- Отказ проверки считается выходом только последним действием хода; сообщение с признаком meta
  не начинает ход и не читается как слово владельца.
- Вопрос владельцу без работы в состоянии «этап идёт» отбивается.
- Сценарии пакета покрывают каждое из этого и зелёные.

## Stages

### 1. Разбор записи хода

- **What is done:** в `turn-exit-verdict.sh` служебные сообщения с признаком meta исключены из
  начала хода и из слов владельца; отказ проверки читается по последнему результату инструмента;
  образец слова об остановке дополнен формами «не двигайся», «не продолжай», «прекрати».
- **Readiness sign:** набор сценариев проверки зелёный, новые сценарии на оба чтения в нём.
- **Verified by:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — в последней строке «0 провалов».

### 2. Суд об открытом эпике

- **What is done:** в `turn-exit-guard.sh` второй проход судится; ход с работой отпускается только
  закрытым эпиком; вопрос без работы в состоянии «этап идёт» отбивается; чтение незакрытых задач
  эпика идёт той же командой, что печатает таблицу владельцу, и только на пути к отказу.
- **Readiness sign:** набор сценариев зелёный, объявление проверки сходится с телом.
- **Verified by:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — «0 провалов»;
  `node tools/check-hook-scope.mjs` — «it matches».

### 3. Сборка и установка в дереве

- **What is done:** пакет собран, файлы установлены в дерево, привязки в компаньоне правила о ходе
  обновлены.
- **Readiness sign:** установленное сходится с пакетом, наборы дерева зелёные.
- **Verified by:** `npm run agent-kit:check` — нет строки о расхождении; `bash tools/tests/run.sh` —
  «ALL SETS ARE GREEN».

## Что считается сделанным

- Сверка называет каталог договорённости, чей последний коммит старше месяца, и молчит о свежей.
- Проба закрывает обе стороны.

## Этапы

### 1. Возраст договорённости

- **Что делается:** сверка читает дату последнего коммита каждого каталога договорённости и
  печатает отдельным разделом те, что старше месяца.
- **Признак готовности:** на дереве раздел печатается по делу, а свежая договорённость в него
  не попадает.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка проходит; `node tools/check-specs.mjs`
  — расхождений нет, раздел печатается по возрасту.

### 2. Проба и договорённость

- **Что делается:** в пробу сверки заводятся два сценария — старая договорённость названа,
  свежая нет; спек поддомена получает статью, сценарии и привязку.
- **Признак готовности:** набор проб пакета зелёный, сверка спеков молчит.
- **Чем проверяется:** `pnpm run agent-kit:hooks` — 0 провалов; `node tools/check-specs.mjs` —
  расхождений нет.

## Чего эта работа не делает

- Не заводит срока договорённости и ничего не сносит: раздел называет, а решает человек.

## Что считается сделанным

- Потребитель, не назвавший моду, видит сегодняшнее поведение подменю без изменений.
- Закреплённое подменю стоит открытым: его не закрывают ни уход указателя, ни переход по
  своему пункту, и подложки под ним нет.
- Поле в подменю отбирает пункты по подстроке подписи; пустой отбор говорит о себе строкой.
- На узком экране поле есть, переключателя нет.
- Тринадцать сценариев `SC-UK-17`…`SC-UK-29` закрыты тестами.

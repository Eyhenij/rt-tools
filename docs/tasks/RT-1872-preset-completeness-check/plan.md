## What counts as done

- Проверка отбивает цветовое назначение базового набора, у которого в материальном нет ни
  переопределения, ни названной причины общего цвета.
- Проверка отбивает пару «цвет подписи и её подложка», не берущую порог 4.5:1, в каждом из двух
  наборов.
- Пометка «цвет общий», которой больше ничего не отвечает, роняет проверку по имени.
- Накопленное на день включения стоит в списке принятого поимённо, и список только убывает.
- Проверка стоит в наборе перед пушем и в шагах конвейера.
- Вид без признака набора не изменился: 469 снимков второго кита сходятся.

## Stages

### 1. Молчание набора называется причиной

- **What is done:** в источнике набора появляется способ сказать «цвет общий намеренно» — рядом с
  именем, а не отдельным файлом; девять цветовых имён, у которых сейчас нет ни того ни другого,
  разбираются поимённо: одним даётся переопределение, другим причина.
- **Readiness sign:** ни одного цветового назначения базового набора без ответа — либо
  переопределение, либо причина.
- **Verified by:** `pnpm -w run check:tokens-build` — собранное сходится с источником

### 2. Проверка полноты

- **What is done:** заводится проверка, которая читает оба набора и отбивает молчание без
  причины, а также пометку, которой больше ничего не отвечает.
- **Readiness sign:** снятая причина у любого имени роняет проверку; лишняя пометка роняет её по
  имени.
- **Verified by:** `node tools/check-preset-complete.mjs` — расхождений нет

### 3. Порог читаемости в обоих наборах

- **What is done:** проверка считает контраст пар «подпись и подложка» в базовом и в материальном
  наборе; накопленное на день включения — в списке принятого поимённо, с причиной.
- **Readiness sign:** пара, не берущая 4.5:1 и не стоящая в списке, роняет прогон.
- **Verified by:** `node tools/check-preset-complete.mjs` — перечень пар и ни одной новой

### 4. Проверка в наборе перед пушем и в конвейере

- **What is done:** строка добавляется в набор гарда и в шаг конвейера; правило `rt-tools-styling`
  получает статью о том, что молчание набора называется причиной, с привязкой в спутнике.
- **Readiness sign:** гард зовёт проверку, статья стоит рядом с тремя о наборе.
- **Verified by:** `pnpm -w run check:specs` — привязки правила сходятся

## What this work does not do

- **Не трогает сам материальный набор сверх дыр, которые найдёт.** Подбор вида — первая задача.
- **Не трогает значки и витрину** — четвёртая и пятая задачи эпика.
- **Не трогает первый кит** — он не правится вовсе.
- **Не заводит проверку на тёмные ответы, объявленные в файлах компонентов.** Ловушка плана эпика
  названа, но она о другом месте объявления; если найдётся — идёт карточкой.

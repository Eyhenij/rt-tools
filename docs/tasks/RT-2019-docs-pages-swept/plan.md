# Замысел

**Задача:** RT-2019 · **Ветка:** RT-2019-docs-pages-swept
**Поведение:** не меняется — правятся страницы витрины и обход витрины; кода кита работа не
трогает, потребитель пакета получает те же компоненты.

После записи этот файл не правится. Пересмотр этапа уходит в ход работ решением по пути.

## Что считается сделанным

- Три страницы основ открываются без единой ошибки в консоли.
- Обход витрины открывает записи вида `docs` наравне с историями и краснеет на ошибке в любой.
- Вывод обхода называет два числа отдельно: сколько историй и сколько страниц обзора открыто.
- Правило показа говорит, чем открываются страницы обзора: сегодня об этом нет ни строчки.

## Этапы

### 1. Обход витрины открывает страницы обзора

- **Что делается:** обход берёт из указателя записи обоих видов, открывает страницу обзора в
  режиме `docs` и судит её по тем же двум признакам — площадь показа и ошибки в консоли.
- **Признак готовности:** обход краснеет на трёх страницах основ и называет их поимённо.
- **Проверено:** `pnpm run test:stories:v2` — в выводе три страницы с ошибкой и два числа
  открытого: историй и страниц обзора.

### 2. Три страницы чинятся

- **Что делается:** внешний `<p style={s.intro}>` заменяется на `<div>` в трёх файлах.
- **Признак готовности:** ошибок в консоли не остаётся ни на одной из 79 страниц.
- **Проверено:** `pnpm run test:stories:v2` — ни одной страницы с ошибкой.

### 3. Правило показа называет страницы обзора

- **Что делается:** в правило `ui-component-tests` добавляется статья о том, что обход открывает и
  страницы обзора, а не только истории.
- **Признак готовности:** статья стоит, привязка к оснастке записана в спутнике.
- **Проверено:** `npm run check:specs` — расхождений по этому правилу нет.

## Чего эта работа не делает

- Не наполняет три истории с пустым набором — это RT-2020.
- Не заводит истории семи компонентам без своей — это RT-2021.
- Не трогает порог площади показа: он про истории, и страницы обзора его проходят с запасом.

## What counts as done

- У каждого из четырёх стражей есть набор проб, судящий его поведение, а не имя.
- Обещание каждой пробы записано сценарием в спеке того предмета, о котором проба говорит.
- Список исключений снят с пробы о наборах, и она зелёная без него.
- Проверка спек зелёная: сценарии и заголовки проб сходятся в обе стороны.

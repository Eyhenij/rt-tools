**Поведение:** не меняется — заводится показ и замер того, что уже есть

## Что считается сделанным

- Есть истории на все виды из карточки: три части разом, одно тело, шапка с телом без подвала,
  короткое содержимое, длинное содержимое.
- Прокрутка тела при стоящих шапке и подвале подтверждена замером.
- Витрина собирается, спека кита зелёная.

## Этапы

### 1. Обёртка и истории

- **Что делается:** заводится `TestScrollableComponent` с ручками подачи частей и длины
  содержимого, рядом — файл историй на перечисленные виды.
- **Признак готовности:** каждый вид из карточки показан своей историей.
- **Чем проверяется:** `pnpm run build-storybook` — собирается.

### 2. Спека сборки и замер прокрутки

- **Что делается:** спека проверяет, какие части нарисованы при какой подаче; замер на витрине
  снимает высоты и положение шапки с подвалом до и после прокрутки тела.
- **Признак готовности:** числа записаны в ход работы.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit` — зелено.

## Чего эта работа не делает

- Не заводит эталонных снимков: набора снимков у первого кита нет.
- Не трогает сам компонент.

## Что считается сделанным

- Договорённость о рабочем столе переписок лежит черновиком, и проверка спек о ней молчит.
- Свойства разговора, его заголовок и действия над ним считаются чистыми функциями раздела чата, и
  у каждой есть спека со сценой в названии.
- Строка списка показывает состояние разговора тегом кита, а не словом среди слов.
- Оба экрана эпика могут взять эти части: они лежат в либах, которые встраиваемой странице
  разрешены границами.

## Этапы

### 1. Договорённость записана

- **Шаги:**
    1. Написать `spec.md` черновика: правила о раскладке, о месте действий и об общих частях.
    2. Написать `scenarios.md`: сцены `SC-CH-94` … `SC-CH-98`, сцены двух следующих задач помечены
       непокрытыми.
- **Признак готовности:** проверка спек не называет ни одной строки о `talks-workspace`.
- **Проверено:** `npm run check:specs` — в выводе нет строк со словом `talks-workspace`.

### 2. Свойства, заголовок и действия разговора

- **Шаги:**
    1. Завести в `chat/util` чистые функции: строки свойств для панели подробностей, заголовок
       ленты, набор действий над разговором.
    2. Написать на них спеку со сценами `SC-CH-95` и `SC-CH-96` в названиях.
    3. Дописать переводы подписей в словарь админки.
- **Признак готовности:** спеки раздела зелены, и в выводе видны названия со сценами.
- **Проверено:** `npx nx run message-bus-admin-chat-util:test` — «Successfully ran target test».

### 3. Состояние разговора тегом в строке списка

- **Шаги:**
    1. Показать состояние в `admin-chat-talk` тегом кита вместо пролёта со словом.
    2. Написать спеку строки со сценой `SC-CH-94` в названии.
- **Признак готовности:** спека строки проходит, тег стоит на месте слова.
- **Проверено:** `npx nx run message-bus-admin-chat-ui:test` — «Successfully ran target test».

### 4. Договорённость слита и работа отдана

- **Шаги:**
    1. Слить черновик в спеки раздела: правила о раскладке уходят подобластью чата.
    2. Привести спеки панели и встраиваемой страницы к тому, что стало.
    3. Прогнать набор перед отправкой и открыть заявку в ветку эпика.
- **Признак готовности:** проверка спек зелена, набор перед отправкой зелен.
- **Проверено:** `npm run check:specs` — «расхождений нет» по разделу чата.

## Чего эта работа не делает

- Не пересобирает экраны: панель — задача RT-2337, встраиваемая страница — RT-2338.
- Не заводит данных в приёмнике: имени посетителя, языка, непрочитанного и вложений в моделях чата
  нет, и это названо в договорённости.

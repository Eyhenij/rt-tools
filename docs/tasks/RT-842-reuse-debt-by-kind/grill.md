# Разбор просьбы

## Просьба владельца

Задача заведена исполнителем по замыслу эпика RT-806: задачи под долг повторов и единообразия
заводятся, когда кончится четвёртая задача порядка, — числами того дня. Числа сняты 18 августа
2026 года.

## Что уже есть в дереве

- `npm run check:reuse` — мест, где готовое обошли, 211 в 198 признаках, принято 0, долг 198.
- Раскладка долга по местам: 158 `inline-template` и 28 `inline-styles` — обёртки историй
  витрины; 3 `inline-template` — обвязка показа в `src/showcase/`; 5 `inline-template` —
  компоненты второго кита; 4 `decorator-io` — обёртка истории первого кита; 3 `decorator-io` —
  директивы BEM ядра и таблица второго кита; 1 `decorator-io` в историях.
- Из пяти компонентов кита три несут `template: ''`, а подсказка — одну интерполяцию
  `{{ text() }}`: своей вёрстки за ними нет вовсе, блок рисуется стилями на хосте. Настоящий
  инлайновый шаблон только у значка — четыре строки с `<svg>` и `<use>`.
- Признаки `inline-template` и `inline-styles` приезжают набором пакета; своё дерево дописывает
  признаки файлом `.claude/rt-kit/signals.json`, и `decorator-io` — оттуда.

## Что уже сказано в правилах

- Правило `reuse-first`: «Компонент объявляется тремя файлами: `.ts`, `.html`, `.scss`» —
  `template:` и `styles:` в декораторе до кита и `stylelint` не дотягиваются.
- Правило `rt-tools-storybook`: «История целит в обёртку, а не в компонент кита… обёртка держит
  демонстрационное состояние и не едет в пакет» — то есть обёртки инлайном законны по
  договорённости витрины.
- Правило `angular-patterns`: вход и выход компонента — `input()`, `output()`, а не декораторы.
- Замысел эпика RT-806: разбор — это либо правка кода, либо строка в списке принятого с
  причиной; список не пополняется под красную проверку.

## Вопросы и ответы

Вопросов владельцу пока не задавалось: роды долга различимы по правилам дерева, и каждый из них
получает свой исход — принятие с причиной либо правку кода. Вопрос появится, если правка входов
таблицы второго кита окажется правкой публичного API пакета.

## Этапы

### 1. Роды долга разведены замером

- **Что делается:** 198 строк раскладываются по местам и родам, каждый род называется словами.
- **Признак готовности:** сумма родов равна 198, и у каждого рода сказано, законен он или нет.
- **Чем проверяется:** пересчёт по списку принятого.

### 2. Обёртки историй витрины приняты с причиной

- **Что делается:** 186 строк обёрток и 3 строки обвязки показа переезжают в принятое.
- **Признак готовности:** причина называет договорённость витрины, по которой обёртка держит
  демонстрационное состояние инлайном и в пакет не едет.
- **Чем проверяется:** `npm run check:reuse` — долг уменьшился ровно на принятое.

### 3. Компоненты без шаблона вовсе приняты с причиной

- **Что делается:** `template: ''` у трёх компонентов кита и одна интерполяция у подсказки
  принимаются: своей вёрстки за ними нет — блок рисуется стилями на хосте.
- **Признак готовности:** причина отличает пустой шаблон от инлайновой вёрстки.
- **Чем проверяется:** `npm run check:reuse`.

### 4. Настоящие обходы сняты кодом

- **Что делается:** шаблон значка переезжает в свой файл; входы директив BEM и таблицы второго
  кита переводятся с декораторов на сигнальный API.
- **Признак готовности:** ни одного `@Input`/`@Output` в названных файлах, шаблон значка — в
  `.html`.
- **Чем проверяется:** `npm run check:reuse`, `pnpm run check:all`, снимки витрины второго кита.

### 5. Эпик знает итог

- **Что делается:** в замысел эпика RT-806 вписывается, чем кончилась задача и какими числами.
- **Признак готовности:** итог записан, границы эпика перечитаны целиком.
- **Чем проверяется:** чтением файла замысла; `npm run check:docs`.

## Чего эта работа не делает

- Не правит пакетные признаки проверки: `inline-template` и `inline-styles` приезжают набором
  пакета, и уточнять их в дереве нечем — законное отступление объявляется списком принятого.
- Не трогает долг повторов — он разобран задачей RT-841.
- Не двигает предела и не гасит проверку: строка принятого несёт причину и заводится только
  под накопленное на день замера.

# Замысел

**Задача:** RT-807 · **Ветка:** RT-807-split-oversized-files
**Поведение:** не меняется — деление файлов, вывод сборки тот же байт в байт. Подтверждено
владельцем; признак — снимки витрины и сборка обоих китов, а не спек.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- `node tools/check-file-size.mjs` зелёная, ключ `debt` в `tools/file-size-allowlist.json` пуст,
  а ключ `accepted` не пополнился ни одной строкой.
- Гейт пуша зелёный целиком: остальные пять проверок дерева от деления не покраснели, а
  покрасневшая починена правкой, а не строкой в списке принятого.
- `pnpm run agent-kit:check` зелёная: обе пары «исходник и его разложенная копия» поделены
  одинаково, и новые ресурсы пакета доехали в дерево раскладкой.
- Снимки витрин обоих китов сходятся с эталонами, сборка китов зелёная: вывод у делимых
  токенов и стилей кнопки тот же.
- Ни один заведённый этой работой файл не длиннее предела.

## Этапы

### 1. Спек домена пакета правил делится на поддомены

- **Что делается:** `docs/specs/agent-kit/spec.md` и `scenarios.md` режутся по границам, которые
  уже проведены группами правил; корневой спек держит общее, корневые сценарии становятся
  указателем, префикс `SC-AK-` остаётся один на домен вместе с поддоменами. Образец —
  `docs/specs/message-bus/`, читается обходом каталога целиком.
- **Признак готовности:** ни один файл спека не длиннее предела, номера сценариев не сдвинуты,
  каждый поддомен несёт обязательные разделы.
- **Чем проверяется:** `node tools/check-file-size.mjs`, `npm run check:specs`.

### 2. Спек домена второго кита делится тем же приёмом

- **Что делается:** `docs/specs/ui-kit-v2/spec.md` режется по группам своего раздела «Правила»;
  корневой спек держит зачем, терминологию, контракт, решения и открытые вопросы.
- **Признак готовности:** ни один файл спека не длиннее предела, привязки правил к коду
  переехали вместе с правилами.
- **Чем проверяется:** `node tools/check-file-size.mjs`, `npm run check:specs`.

### 3. Сверка спеков делится по предмету сверки

- **Что делается:** `projects/agent-kit/assets/checks/check-specs.mjs` режется по предметам —
  правила и привязки, сценарии и тесты, контракт и коды, разделы; общее уезжает в модуль-помощник
  рядом. Копия `tools/check-specs.mjs` приезжает раскладкой, а не правится руками.
- **Признак готовности:** оба файла пары короче предела и поделены одинаково; имя помощника не
  попадает под перебор имён, которым умолчание пакета печатает набор гейта.
- **Чем проверяется:** `node tools/check-file-size.mjs`, `pnpm run agent-kit:check`,
  `npm run check:specs`, набор сценариев проверок пакета.

### 4. Сверка раскладки делится тем же приёмом

- **Что делается:** `projects/agent-kit/assets/checks/check-lib-layers.mjs` режется по восьми
  вызовам своего хвоста — доменная сетка, границы и теги, барели и реэкспорты; общее уезжает в
  помощник. Копия в `tools/` приезжает раскладкой.
- **Признак готовности:** оба файла пары короче предела и поделены одинаково.
- **Чем проверяется:** `node tools/check-file-size.mjs`, `pnpm run agent-kit:check`,
  `node tools/check-lib-layers.mjs`.

### 5. Гард хранилища и набор сценариев проверок делятся по разделам

- **Что делается:** `projects/agent-kit/assets/hooks/sql-guard.sh` режется по своим разделам —
  нормализация, разбор команды, прод, разрушительное, адресация;
  `projects/agent-kit/tests/checks.test.sh` — по проверкам, которые он гоняет.
- **Признак готовности:** оба файла короче предела, сценарии гарда и проверок по-прежнему
  зелёные и по-прежнему краснеют на нарочно сломанной копии.
- **Чем проверяется:** `node tools/check-file-size.mjs`, `npm run check:hooks`, набор сценариев
  пакета.

### 6. Источник токенов второго кита делится по своим экспортам

- **Что делается:** `projects/ui-kit-v2/src/styles/tokens.source.mjs` режется по четырём
  экспортам — шкала, светлая тема, тёмная раскладка, грубый указатель; сам файл остаётся входом
  и собирает их.
- **Признак готовности:** собранные токены совпадают с прежними; ни один заведённый файл не
  длиннее предела.
- **Чем проверяется:** пересборка токенов и сверка вывода с прежним, проверки токенов дерева,
  `node tools/check-file-size.mjs`.

### 7. Стили кнопки первого кита делятся по своим частям

- **Что делается:** `projects/ui-kit/src/styles/components/_rtui_button.scss` режется на основу,
  палитры и текстовые виды; прежний файл остаётся входом и подключает части.
- **Признак готовности:** собранный CSS кнопки совпадает с прежним, снимки витрины сходятся.
- **Чем проверяется:** сборка кита и сверка собранного CSS с прежним, снимки витрины,
  `node tools/check-file-size.mjs`.

### 8. Долг закрывается, гейт гоняется целиком

- **Что делается:** ключ `debt` в `tools/file-size-allowlist.json` пустеет, причина в нём
  переписывается на состоявшееся; прогоняется весь набор гейта пуша.
- **Признак готовности:** всё из раздела «Что считается сделанным» верно; в `accepted` не
  прибавилось ни строки.
- **Чем проверяется:** набор гейта пуша целиком.

## Чего эта работа не делает

- **Редакцию пакета правил не поднимает** — слово владельца: отдельным ходом.
- **Предела не двигает и правил не смягчает** — это статья замысла эпика.
- **Строк в список принятого не дописывает.** Красное от своей же правки чинится правкой.
- **Долга `check-dupes` и `check-reuse` не разбирает** — под них задачи в эпике ещё не заведены.
- **Сорока двух либ и сорока восьми классов вёрстки не трогает** — это RT-808 и RT-809.

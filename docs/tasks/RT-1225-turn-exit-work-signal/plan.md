# Замысел

**Задача:** RT-1225 · **Ветка:** RT-1225-turn-exit-work-signal
**Поведение:** не меняется — правится гард завершения хода; `apps/**` и `libs/**` работа не задевает.
Приехало предложением в приёмник, ключ `b10b1849`.

## След задачи

Страж отбил два хода из семи, простоявших без работы. Пять остальных он засчитал работой по
перенаправлению вывода: тело будущей заявки писалось во временный каталог вне рабочего дерева, а
одно из ожиданий несло только отвод потока ошибок в устройство пустоты. Ни то ни другое дерева не
касается. Страж ловит ход, пустой от команд, а не ход, пустой от работы, — а ход, пустой от
работы, почти всегда несёт хоть одну команду.

| Что   | Где                                                  |
| ----- | ---------------------------------------------------- |
| Код   | `projects/agent-kit/assets/hooks/turn-exit-guard.sh` |
| Спеки | `docs/specs/agent-kit/turn-guards/`                  |

## Что считается сделанным

- Перенаправление вывода признаком работы не считается ни в каком виде.
- Ход, вся работа которого — запись во временный каталог или отвод потока ошибок, не выпускается.
- Ход с правкой файла и с командой из перечня выпускается по-прежнему.

## Этапы

### 1. Перенаправление уходит из признака работы

- **Что делается:** последняя ветка образца снимается целиком, довод встаёт комментарием.
- **Признак готовности:** образец не содержит ветки о перенаправлении.
- **Чем проверяется:** `bash -n projects/agent-kit/assets/hooks/turn-exit-guard.sh` — синтаксис
  сходится.

### 2. Сценарии на обе стороны

- **Что делается:** заводятся сценарии: запись вне дерева работой не считается, правка файла и
  команда из перечня считаются по-прежнему.
- **Признак готовности:** первый падает на прежнем образце, остальные зелены на обоих.
- **Чем проверяется:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — набор зелёный.

### 3. Пакет собран, разложен, сверен

- **Что делается:** сборка пакета, раскладка, сверка.
- **Признак готовности:** разложенное сходится с пакетом.
- **Чем проверяется:** `npm run agent-kit:check` — строка о том, что разложенное сходится.

## Чего эта работа не делает

- Не судит неотданную работу: ночью ветки не пушатся по слову владельца, и такой гард отбивал бы
  каждый ход.
- Не расширяет перечня команд: расширение под ту же строку вернуло бы снятое.

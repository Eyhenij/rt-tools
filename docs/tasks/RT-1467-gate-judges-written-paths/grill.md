## Что уже есть в дереве

Умолчание `rt_shell_paths_default` уже делит команду на куски и берёт пути только у пишущих —
и вырезает тело документа, кроме интерпретаторов. Внутри пишущего куска оно по-прежнему берёт
всякое слово, похожее на путь: аргумент, значение переменной, кусок текста.

Этот же промах случился здесь трижды за заход: гейт требовал правило слоя компонентов на
команду, которая имя компонента лишь называла в тексте.

## Решения

- **Кусок, который пишет только перенаправлением, отдаёт цель записи** — прочие слова в нём
  путями назначения не бывают. Остальные виды записи — правка по месту, копирование, перенос,
  интерпретатор — остаются с прежним разбором: там путь стоит в самой команде и не в одном месте.

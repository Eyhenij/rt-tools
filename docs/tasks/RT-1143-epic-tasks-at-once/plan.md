# Замысел

**Задача:** RT-1143 · **Ветка:** RT-1143-epic-tasks-at-once
**Поведение:** не меняется — правится слой правил, кода приложения работа не касается

## След задачи

| Что     | Где                                                              |
| ------- | ---------------------------------------------------------------- |
| Законы  | `docs/constitution/work-conduct.md`                              |
| Правила | `.claude/skills/task-flow/`, `.claude/skills/task-flow-start/`   |
| Пакет   | `projects/agent-kit/assets/laws/`, `.../rules/`, `.../patterns/` |

## Что считается сделанным

- Закон о ведении работы называет статью о том, что каждая задача объявленного эпика получает
  карточку сразу, а её номер возвращается в замысел той же правкой.
- Правило и паттерн начала работы говорят приёмом: вызов заведения задачи на каждую строку
  таблицы порядка, номера — обратно в ту же таблицу.
- `agent-kit:check` не находит расхождений, компаньон правила без пустых привязок.

## Этапы

### 1. Статья заведена в законе

- **Что делается:** в закон о ведении работы дописывается статья о карточках задач эпика.
- **Признак готовности:** статья стоит рядом с той, что назначает порядок задач.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом.

### 2. Приём назван в правиле и паттерне

- **Что делается:** правило `task-flow` получает статью о заведении задач разом, паттерн начала
  работы — шаг с вызовами и возвратом номеров в таблицу.
- **Признак готовности:** у новой статьи правила есть адрес в компаньоне.
- **Чем проверяется:** `npm run check:specs` — ни одной строки о пустой привязке.

## Чего эта работа не делает

- Номера задач эпика о весе слоя правил вписываются в его замысел там, где этот замысел живёт, —
  в ветке задачи RT-1126.
- Форма ответа владельцу о состоянии работы — задача RT-1141.

## Что считается сделанным

- В `_semantic.scss` нет ни одного пиксельного литерала: всё, чему нет места в существующих
  шкалах, стоит ступенью шкалы размеров в `_primitives.scss`.
- Шкала нейтрального — двенадцать ступеней `0 50 100 200 300 400 500 600 700 800 900 950`,
  посчитанных в OKLCH ровным шагом светлоты; ни одной off-grid ступени в объявлениях и ни одной

- Поиск по `--rt-space-1-5`, `-2-5`, `-3`, `-7` по стилям кита даёт ноль совпадений, а гейт
  литералов не даёт им вернуться.
- Шкала высот контролов — `32/40/48/56/64`; кнопка, иконочная кнопка и семейство полей берут её,
  и высота кнопки и поля одного размера совпадает — подтверждено замером в браузере.
- Список принятых литералов пуст: пять записей сняты починкой, а не пометкой.
- Гейты графа, литералов и тёмной темы зелёные; `check:all` зелёный; витрина собирается.
- Разошедшиеся эталоны названы поимённо и пересняты; неназванных расхождений нет.

## Этапы

### 1. Шкала размеров и литералы из назначений

- **Что делается:** в `_primitives.scss` заводится шкала размеров под габариты, которым нет
  места в существующих шкалах; двенадцать пиксельных литералов `_semantic.scss` заменяются
  ссылками на ступени — `--rt-space-2xs` на ступень отступа, `--rt-text-base` на ступень кегля,
  габариты навигации, аватара и счётчика на ступени новой шкалы. Значение, которому ступени нет,
  заводит ступень, а не подбирается в назначении.
- **Признак готовности:** `grep` пиксельного литерала по `_semantic.scss` даёт ноль совпадений;
  вид не двигается — ступень равна снятому числу.
- **Чем проверяется:** `npm run check:tokens-graph`, `npm run check:tokens-styles`,
  `pnpm run lint:styles`.

### 2. Off-grid отступы сняты

- **Что делается:** `--rt-space-1-5` (6px), `-2-5` (10px), `-3` (12px) и `-7` (28px) снимаются из
  шкалы, их употребления переезжают на соседнюю ступень. Каждое место, где сдвиг двигает вид
  заметно, называется в ходе работы до правки.
- **Признак готовности:** ни одного объявления и ни одного употребления снятых имён; пометки
  `@deprecated` в шкале отступов не осталось — снимать нечего.
- **Чем проверяется:** поиск по дереву, `npm run check:tokens-graph`, `pnpm run lint:styles`.

### 3. Ряд нейтрального пересчитывается ровным

- **Что делается:** двенадцать канонических ступеней считаются в OKLCH — тон и цветность общие,
  светлота ровным шагом, как у линейки бренда в RT-385. Девять off-grid ступеней снимаются,
  каждое их употребление переезжает на ближайшую каноническую. Оттенок, который нужен ровно
  одному назначению и ни на одну ступень не ложится, поднимается в назначение с говорящим
  именем, а не остаётся ступенью.
- **Признак готовности:** ряд однороден — соседние ступени расходятся одинаково; ни одного
  употребления снятых имён; посчитанные значения записаны в ход работы вместе со снятыми.
- **Чем проверяется:** `npm run check:tokens-graph`, `npm run check:tokens-theme`.

### 4. Общая шкала высот контролов

- **Что делается:** `--rt-control-height-*` пересчитывается в `32/40/48/56/64` и получает пять
  ступеней вместо трёх; кнопка снимает своё `--rt-btn-height` числом и берёт шкалу, иконочная
  кнопка берёт её же, семейство полей переезжает с 36/45/52. Отступы, кегль и размер значка
  внутри контрола проверяются на каждой ступени — высота меняется, содержимое обязано остаться
  соразмерным.
- **Признак готовности:** ни одной высоты контрола числом в стилях кита; кнопка и поле одного
  размера в одной строке дают одинаковую высоту.
- **Чем проверяется:** замер вычисленных значений в браузере в обеих темах — сценарий
  `SC-UKV-48`; `pnpm run lint:styles`.

### 5. Пять литералов цвета и роль info

- **Что делается:** оверлей боковой панели, две тени окна и дорожка спиннера переезжают на
  назначения — прозрачные оттенки считаются от ступени, а не записываются тройкой каналов;
  подложка группы кнопок `#eef0f4` берёт ступень пересчитанного ряда. Роль info встаёт в
  пересчитанный ряд: сводится с брендом или разводится с ним намеренно, и выбор записывается в
  ход работы с доводом.
- **Признак готовности:** `tools/tokens-styles-allowlist.json` пуст, и ни одна запись из него не
  снята пометкой — только починкой.
- **Чем проверяется:** `npm run check:tokens-styles`, `pnpm run lint:styles`.

### 6. Тёмная тема и пары контраста

- **Что делается:** тёмная тема отвечает на каждое новое и на каждое сдвинутое назначение —
  переопределением или пометкой общего цвета с причиной. Пары «текст и фон», чьи оба конца
  сдвинулись пересчётом ряда, перемеряются; пара, ушедшая ниже порога, либо чинится, либо встаёт
  в список с замеренным отношением и причиной. Заводя назначение, которым что-то красится,
  завожу и его пару — в `tools/tokens-contrast-pairs.json` **и** в таблицу замера
  `projects/ui-kit-v2/docs/Colors.mdx`: проверка сверяет два перечня между собой.
- **Признак готовности:** гейт тёмной темы зелёный, ни одного молчания без причины; ни одной
  пары, которой нет в обоих перечнях.
- **Чем проверяется:** `npm run check:tokens-theme`.

### 7. Тексты кита и договорённость

- **Что делается:** страницы витрины `Colors`, `Scales`, `Semantic` и `Theming` приводятся к
  сделанному; описания кнопки и поля — тоже. В договорённость линии дописываются закрытие `Q-4`
  ответом владельца, привязки правил `SC-UKV-41` и `SC-UKV-48` к коду и два новых названных
  вслух исключения вида — пересчитанный ряд нейтрального и общая шкала высот. В правиле
  `styling-bem` надстройкой снимается оговорка «до шкалы высот размер числом законен».
- **Признак готовности:** ни одна страница витрины не называет снятых имён; договорённость
  называет пять исключений вида, а не три; `Q-4` стоит в разделе закрытых.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`, `pnpm run agent-kit:check`,
  поиск снятых имён по дереву.

### 8. Замер в браузере и пересъёмка эталонов

- **Что делается:** вид проверяется замером вычисленных значений в обеих темах — со снятым
  переходом, иначе первое чтение после смены темы показывает тёмную тему неотличимой от светлой.
  Затем сверяются кадры витрины; каждый разошедшийся кадр смотрится глазами и объясняется, и
  только объяснённый переснимается. Кадры пороговой ширины разбираются отдельно: провалившийся
  прогон в разбор их не отдаёт.
- **Признак готовности:** расхождений, которым нет объяснения, нет; переснятые кадры названы
  поимённо в ходе работы; `check:all` зелёный.
- **Чем проверяется:** `pnpm test:visual:v2`, точечная пересъёмка `pnpm test:visual:v2:update`,
  `pnpm run check:all`.

## Чего эта работа не делает

- **Девять имён, общих с первым китом.** Требуют правки выпущенного первого кита; договорённость
  выводит это за границу всей линии, а починка заведена задачей RT-391.
- **Починка пар контраста, стоявших ниже порога до этой работы.** Их чинит RT-394. Эта работа
  отвечает только за пары, которые сдвинул её собственный пересчёт.
- **Свои свойства компонента как настроечный API.** `--rt-btn-*` и родня остаются внутренними —
  RT-274, позиция 8.
- **Слой каскада `@layer rt-kit`** — RT-387, позиция 9.
- **Источник токенов объектом** — RT-388, позиция 10.
- **Правило линтера на размер числом в `width` и `height`.** Шкала высот заводится этой работой,
  а суд линтера над размерами — вопрос следующей: сначала шкала, потом гейт, иначе гейт краснеет
  на сотне мест в день включения.

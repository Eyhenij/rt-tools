## Что уже есть в дереве

Измерение 27.11. Файлы токенов собранного кита минифицированы `esbuild`, gzip уровня 9, brotli уровня 11. Байты.

| Файл                      | Минифицированный | gzip  | brotli |
| ------------------------- | ---------------- | ----- | ------ |
| `tokens.css`, 0.51.0      | 297255           | 27989 | 10418  |
| `tokens.css`, ветка эпика | 297298           | 28002 | 10435  |

- Против 0.51.0 файл `tokens.css` вырос на 43 байта, в brotli на 17. Рост веса 0.52.0 не в токенах.
- Повторы лежат в `tokens.scope.css` и в той же части `tokens.css`: одинаковые блоки свойств под разными селекторами.
  Если записать каждый такой блок один раз, `tokens.css` станет легче на 104725 байт, это 35 процентов. В gzip это 9375
  байт, в brotli 92. Это верхняя граница: объединение селекторов меняет порядок правил, а тёмная тема побеждает набор
  порядком. Часть блоков стоит под разными условиями и не объединяется.
- `tokens.base.css` почти без повторов: его берёт приложение без местных островов темы и набора.
- Angular 22.2.2 по умолчанию поддерживает Chrome 119, Edge 119, Firefox 119, Safari 17.0: это список `browserslist`
  `baseline widely available on 2026-05-07`. `light-dark()` начинается с Chrome 123, Firefox 120 и Safari 17.5, по
  статье web.dev. Часть браузеров из списка Angular потеряла бы цвета.
- Прежняя запись цели «островам переопределять только отличия» расходится с правилом этого дерева: тема на узле
  объявляет весь набор, а не отличия.
- Отдельного файла пресета сборка не выдаёт, поэтому цель «файл пресета не больше 40 процентов прежнего» измерить не на
  чем.

- Пять из этих копий пишет генератор `tools/build-tokens-v2.mjs` в `_theme-scope.scss`. Три светлых блока по 31971
  байт одинаковы: «набор на узле», «светлый кусок между тёмным и узлом», «светлый кусок внутри набора». Два тёмных по
  41801 байт тоже одинаковы: «набор под тёмной темой» и «тёмный кусок внутри набора».
- Их можно объединить без смены каскада. Селекторы светлых копий переходят в первое светлое правило, а тёмное правило
  под набором они побеждают специфичностью, а не местом. Селекторы второй тёмной копии переходят в первое тёмное
  правило. Оно остаётся после светлого. Элемент не может совпасть и со светлой, и с тёмной копией по своей теме.
- Пробное объединение собранных файлов: `tokens.css` 192570 вместо 297298, легче на 104728 байт, gzip на 9181, brotli на
  50. `tokens.scope.css` 121811 вместо 226539.

## Что уже говорят правила

Вид кита не меняется без согласия владельца. Здесь вид обязан совпасть по снимкам, согласование вида не нужно. Тема и
набор на узле объявляют весь набор значений, а не отличия: объединение селекторов это правило сохраняет.

## Решения

- **Цель: `tokens.css` в минифицированном виде легче не меньше чем на 100000 байт.** Выигрыш по сети мал, и в итоге
  это называется прямо: в brotli около 50 байт, в gzip около 9 КБ. Байты без сжатия считает бюджет стартового набора
  Angular.
- **Объединяются только одинаковые блоки.** Отброшены `light-dark()` и запись одних отличий: первое ломает браузеры из
  списка Angular, второе нарушает правило о полном наборе на узле.

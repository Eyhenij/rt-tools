- Все пятнадцать законов пакета написаны по-английски. Число статей и открытых вопросов в каждом
  совпадает с русской редакцией и записано в ходе работы.
- Три надстройки законов этого дерева переведены.

## Этапы

### 1. Законы пакета

- **Что делается:** пятнадцать файлов законов переводятся на английский; заголовки разделов
  `## Articles` и `## Open questions`; проверка спеков и спека команд принимают оба имени.
- **Признак готовности:** в каждом законе число статей и вопросов равно прежнему.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — все наборы зелены;
  `node tools/check-prose-style.mjs projects/agent-kit/assets/laws/*.md` — без замечаний.

### 2. Надстройки законов дерева

- **Что делается:** три файла в `.claude/rt-kit/overrides/laws/` переводятся по разделам.
- **Признак готовности:** разложенные законы в `docs/constitution/` целиком английские.
- **Чем проверяется:** `pnpm run agent-kit:sync && pnpm run agent-kit:check` — сходится;
  `grep -c '[А-Яа-я]' docs/constitution/*.md` — нули.

### 3. Сверка и запись

- **Что делается:** слияние главной ветки, английская фраза границы состояния в тесте, счёт
  статей в ход работы, замысел эпика получает отметку о задаче.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `npm run check:specs` — законы без замечаний; `npm run agent-kit:cost` —
  число байт входа записано.

- Экран входа пускает по учётной записи приёмника и не пускает без неё; вход живёт кукой,
  которую заводит приёмник, а не своим хранилищем.
- Адрес раздела без входа отправляет на вход, а после входа человек попадает туда, куда шёл.

  перезагрузку страницы.
- Пять законов сняты из `skip`, их правила и паттерны разложены, `agent-kit:check` сходится.
- У каждого разложенного правила есть компаньон с привязками, и ни одной пустой среди них.
- Гейт правил пропускает правку файла списочного экрана.
- `npm run check:specs` не прибавил расхождений, `nx affected -t lint typecheck test build`
  зелёный.

## Этапы

### 1. Приложение админки

- **Что делается:** `apps/message-bus-admin` генератором Nx: сборка, линт, спеки, точка входа,
  каркас без зон, стили из кита.
- **Признак готовности:** `nx build message-bus-admin` и `nx lint message-bus-admin` зелёные,
  приложение поднимается и показывает пустую оболочку.
- **Чем проверяется:** сборка, живой подъём.

### 2. Вход в админку

- **Что делается:** домен входа — экран, служба, гвард маршрута; вход спрашивается у приёмника
  теми операциями, что завела задача #585, и живёт его кукой.
- **Признак готовности:** годная пара пускает, негодная нет; адрес раздела без входа отправляет
  на вход и возвращает после него.
- **Чем проверяется:** спеки домена входа, живой прогон против поднятого приёмника.

### 3. Оболочка и меню

- **Что делается:** оболочка с меню по декларации, пустой раздел под первый список, адреса
  разделов, подписи из словаря приложения.
- **Признак готовности:** раздел открывается прямой ссылкой и переживает перезагрузку; пункт
  меню заведён вместе со своим экраном.
- **Чем проверяется:** спеки маршрутов, замер в браузере.

### 4. Раскладка законов и правил

- **Что делается:** пять законов снимаются из `skip`, дерево объявляет свойство `admin`,
  раскладываются правила `lists`, `entity-conventions`, `entity-models`, `navigation`,
  `permissions` и их паттерны.
- **Признак готовности:** `pnpm run agent-kit:check` сходится; гейт правил требует нужное
  правило на файле списочного экрана.
- **Чем проверяется:** `agent-kit:check`, пробная правка файла под гейтом.

### 5. Компаньоны с привязками

- **Что делается:** `implementation.md` каждому разложенному правилу — имена этого дерева и
  привязка статей к файлам админки.
- **Признак готовности:** ни одной пустой привязки у пяти новых компаньонов.
- **Чем проверяется:** `npm run check:specs`.

### 6. Тексты и отчёт

- **Что делается:** ход работы, отчёт со списком проверенного.
- **Признак готовности:** набор гейта зелёный целиком.
- **Чем проверяется:** набор гейта, `check:docs`, `check:specs`.

# Замысел

**Задача:** RT-1724 · **Ветка:** RT-1724-spec-lists-split
**Поведение:** не меняется — делятся спеки пакета, кода приложения работа не касается

## След задачи

| Что     | Где                                                                 |
| ------- | ------------------------------------------------------------------- |
| Спеки   | `docs/specs/agent-kit/observations/`, `docs/specs/agent-kit/texts/` |
| Законы  | `docs/constitution/project-documentation.md`                        |
| Правила | `.claude/skills/spec-driven/`                                       |
| Код     | `tools/file-size-allowlist.json`                                    |

## Что считается сделанным

- Поддомен груза наружу выделен из наблюдений: спек, сценарии, компаньон; домен ссылается на него.
- Поддомен сверки спеков выделен из текстов тем же образцом.
- Ни один из шести файлов не длиннее предела; долг за задачей снят из списка известного.
- Сверка спеков — код 0; проверка длины без новых и без долга за задачей.

## Этапы

### 1. Груз наружу из наблюдений

- **Что делается:** папка `docs/specs/agent-kit/observations/cargo/` с тремя файлами; правила,
  сценарии и привязки о предложениях, отправке, заведении дерева и токене переезжают туда;
  разделы «Зачем» и история изменений домена называют поддомен.
- **Признак готовности:** оба перечня и спек короче предела; сверка спеков код 0.
- **Чем проверяется:** `node tools/check-specs.mjs`; `node tools/check-file-size.mjs`.

### 2. Сверка спеков из текстов

- **Что делается:** папка `docs/specs/agent-kit/texts/spec-checks/` тем же образцом: пути и
  указатели, привязки и якоря, номера сценариев, договорённости.
- **Признак готовности:** те же.
- **Чем проверяется:** те же команды.

### 3. Долг снят

- **Что делается:** записи за RT-1724 сняты из `tools/file-size-allowlist.json`.
- **Признак готовности:** проверка длины называет долг без этой задачи.
- **Чем проверяется:** `node tools/check-file-size.mjs`; `node tools/check-prose-style.mjs`
  по правленым файлам.

## Чего эта работа не делает

- Формулировок правил и сценариев не меняет; номера сценариев не пересчитывает.

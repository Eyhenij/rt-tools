## Что считается сделанным

- Команда `/next-session` разложена в дерево и прогнана вживую: главная ветка приведена к
  удалённой либо влита в текущую, влитые локальные ветки сняты, передача написана и её путь
  назван.
- Сверка спеков видит сценарий с однозначным номером — и в спеке, и в заголовке теста; это
  подтверждено тестом пакета, который на прежних шаблонах красный.
- Правило ведения работы держит полный список шагов, а счёт шагов в трёх паттернах сплошной:
  каждый номер встречается один раз.
- Правило о документации проекта отвечает на три случая жизни номера сценария — выдачу,
  изменение, удаление, — а не только на конфликт мержа.
- Правило об оформлении документов держит раздел под скилы дерева.
- `pnpm exec nx test @rt-tools/agent-kit`, `npm run agent-kit:check` и `npm run check:specs`
  зелёные; число расхождений сверки названо до и после.
- Файла предложений в корне дерева нет.

## Этапы

### 1. Терпимый шаблон номера сценария

- **Что делается:** шаблоны заголовка сценария и ссылки на него в сверке спеков принимают номер
  из одной, двух и трёх цифр.
- **Признак готовности:** сценарий `SC-XX-1` виден сверке в спеке и засчитывается покрытым по
  заголовку теста.
- **Чем проверяется:** новый тест в наборе проверок пакета — красный до правки, зелёный после;
  `npm run check:specs` с названным числом расхождений до и после.

### 2. Команда закрытия захода

- **Что делается:** в активы пакета заводится команда `/next-session`: состояние рабочего дерева,
  разбор «работа по правилу или нет», главная ветка, уборка веток, передача.
- **Признак готовности:** команда разложена в дерево, зовётся по имени и проходит все четыре
  состояния из договорённости.
- **Чем проверяется:** вызов в этом дереве; `npm run agent-kit:sync` и `--check` зелёные.

### 3. Сплошной счёт шагов и список в правиле

- **Что делается:** нумерация шагов в трёх паттернах ведения работы становится сплошной, а в
  правило добавляется список всех шагов со скилом при каждом.
- **Признак готовности:** каждый номер шага встречается один раз; список покрывает путь от
  разведки до разбора папки задачи.
- **Чем проверяется:** тест текстов пакета на неповторяемость номеров; чтение списка против трёх
  паттернов.

### 4. Жизнь номера сценария и место скилам дерева

- **Что делается:** в правило о документации проекта дописываются статьи о выдаче, изменении и
  удалении номера; в правило об оформлении документов — раздел под скилы дерева.
- **Признак готовности:** оба правила отвечают на свой вопрос, не отправляя читателя в ловушки.
- **Чем проверяется:** тест текстов на наличие раздела; `npm run agent-kit:check`.

### 5. Уборка и отчёт

- **Что делается:** файл предложений в корне сносится, спеки и тексты приводятся к сделанному,
  открывается отчёт.
- **Признак готовности:** дерево чистое, все проверки зелёные, отчёт открыт от учётной записи
  машинной работы.
- **Чем проверяется:** `npm run check:all` дерева пакета, `git status`.

## Чего эта работа не делает

- Выпуск версии в реестр — отдельное решение владельца, названо в договорённости.
- Разбор долга сверки спеков (135 расхождений и то, что прибавит терпимый шаблон) — отдельная
  работа.
- Судьба ветки с архивными записями, не влитыми в главную, — отдельное решение владельца.

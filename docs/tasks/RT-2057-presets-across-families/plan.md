## What counts as done

- Каждое семейство, которому набор оформления что-то меняет, показывает обе половины на всех
  своих матрицах.
- Семейство, которому набор не меняет ничего, пары не получает, и причина записана.
- Эталоны затронутых показов пересняты после осмотра, съёмка зелёная.

## Stages

### 1. Счёт: каким семействам пара нужна

- **What is done:** обойдена вся витрина, у каждого показа прочитаны вычисленные значения узлов
  кита со своим набором и с материальным.
- **Readiness sign:** названо число семейств, которым набор что-то меняет, и поимённо — те,
  которым не меняет ничего.
- **Verified by:** обход витрины своим скриптом — показов с корнем 431, набор меняет узлы у 208,
  семейств 84, затронуто 70.

### 2. Обёртка по волнам, семейство за семейством

- **What is done:** матрицы затронутых семейств обёрнуты парой половин; показ, которому пара не
  помещается по ширине, назван с причиной прямо в разметке.
- **Readiness sign:** у каждого затронутого семейства пара стоит на всех его матрицах.
- **Verified by:** `pnpm exec nx run @rt-tools/ui-kit-v2:typecheck` — код выхода 0.

### 3. Осмотр и пересъёмка

- **What is done:** кадры обёрнутых показов осмотрены поштучно, эталоны пересняты.
- **Readiness sign:** съёмка зелёная, кадров без своего показа нет.
- **Verified by:** `node tools/visual-snapshots-v2.mjs` — расхождений нет, сирот нет.

## What this work does not do

- Не заводит пару семействам, которым набор ничего не меняет: кадр стал бы вдвое шире без
  единого нового сведения.
- Не чинит панель подробностей рабочего стола — это задача RT-2074.
- Не трогает первый кит.

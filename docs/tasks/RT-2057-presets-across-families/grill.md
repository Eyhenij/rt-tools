# Grill

## The owner request

> на сторьке кнопок темы нет кнопок материал, проверь все сторьки

Слова владельца, сказанные по ходу RT-2046. Первая половина закрыта там же: вся группа кнопок
показывает оба набора оформления. Вторая половина — «проверь все сторьки» — и есть эта задача.

## What the tree already has

- Пара половин заводится обвязкой показа: она берёт матрицу содержимым и рисует её дважды —
  своим набором и материальным. Хост пары несёт корень показа, поэтому обе половины входят в
  один кадр.
- Половины переносятся по ширине своего содержимого, а не по порогу в единицах длины.
- Вся группа кнопок обёрнута: девять матриц кнопки и по нескольку у значковой кнопки, ссылки на
  загрузку, кнопки с выбором и группы переключателей — 23 показа.
- Счёт по витрине на день RT-2046: матриц 502, пару показывают 98, остальные 404 у 71 семейства.

## What the rules already say

- Правило витрины: набор оформления оборачивает всю матрицу парой половин и никогда не становится
  осью внутри неё.
- Правило витрины: пара принадлежит каждому показу семейства, которого набор касается, а не
  одному показу из десяти.
- Правило витрины: половины переносятся по ширине своего содержимого.

## Questions and answers

- **Оборачивать ли семейства, которых набор не касается?** Нет. Набор переписывает значения
  назначений, и какое семейство читает какое назначение, видно только отрисовкой. Семейство, у
  которого обе половины совпадают, получает пару впустую — кадр вдвое шире и ничего не говорит.

## Decisions

- **Сначала счёт, потом обёртка** — 404 показа вслепую не оборачиваются: у части семейств набор
  ничего не меняет, и это видно только сравнением половин.

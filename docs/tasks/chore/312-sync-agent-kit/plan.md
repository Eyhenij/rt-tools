# Замысел

Задача: #312. Ветка: `chore/312-sync-agent-kit`.

**Поведение:** не меняется — раскладывается слой правил агента, приложений и пакетов правка не
касается. Подтверждено владельцем на разборе.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- `pnpm run agent-kit:check` проходит без отказа.
- `agent-kit doctor` не печатает ни «отстал от пакета», ни «нет в дереве», ни «положен не
  пакетом».
- Каждая из одиннадцати проверок запущена хотя бы раз и ответила по делу, а не падением.
- Правило, разложенное заново, читает `implementation.md` этого дерева, а не пустой скелет:
  `sync --check` на компаньонах отказа не даёт.

## Этапы

### 1. Тексты законов и правил

- **Что делается:** пересобрать `skip` по признаку предметности — в нём остаётся то, чего у
  библиотеки компонентов нет вовсе; разложить законы, правила и паттерны новой редакции.
- **Признак готовности:** `doctor` не печатает «отстал от пакета» ни по одному тексту;
  надстройки дерева (`overrides/laws/verifiability.md`, `overrides/rules/styling-bem.md`)
  пережили раскладку и видны в разложенном.
- **Чем проверяется:** `pnpm run agent-kit:check`; глазами — раздел надстройки в двух
  названных файлах.

### 2. Исполнители и умолчания

- **Что делается:** хуки новой редакции, роли, слеш-команда, конвейеры, умолчания карты гейта
  и профиля дерева; три хука дерева заменяются пакетными, расхождения — если они найдутся —
  уезжают в надстройку.
- **Признак готовности:** «положен не пакетом» исчезло; карта хуков в настройках агента зовёт
  то, что лежит на диске; своё в `.claude/rt-kit/` (`gate-map.sh`, `project.sh`) не тронуто.
- **Чем проверяется:** `doctor`; подача входа на каждый новый хук — гард отвечает, а не падает
  на отсутствии файла.

### 3. Проверки и их настройка

- **Что делается:** одиннадцать проверок в `tools/`, `.claude/rt-kit/checks.json` под это
  дерево, команды запуска в `package.json`.
- **Признак готовности:** каждая проверка запущена и ответила по делу; правила, называющие
  `npm run check:specs`, `check:board` и `task:new`, перестали называть несуществующее.
- **Чем проверяется:** прогон всех одиннадцати поштучно с записью того, что ответила каждая.

## Чего эта работа не делает

- **Не правит пакет.** Найденное в нём заводится задачей, а не чинится по ходу: иначе дерево
  и пакет снова разъедутся, и откатить порознь будет нечем.
- **Не заводит долги проверок.** Проверка, нашедшая в дереве настоящие нарушения, их здесь не
  чинит — она приносит число, и на него заводится задача.
- **Не трогает `AGENT-KIT-AUDIT.md`, `RUNNER-MONITOR.md` и `analytics` в `nx.json`.** Решено
  на разборе: три вещи остаются вне истории.

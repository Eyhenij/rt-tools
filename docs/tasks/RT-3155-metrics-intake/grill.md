# Grill

## The owner request

Разбор всего эпика лежит в записи архива задачи RT-3152. Карточка задачи: приёмник принимает старую и новую запись, а повторная отправка дня не меняет итог.

## Decisions

- **Числа идут строкой дня.** Карточка писалась до договорённости и называет новые колонки наблюдений. Договорённость после разбора роли заменила их таблицей `MetricsDay`: с приложений уходят только числа.
- **Прежний груз наблюдений не меняется.** Его шлёт команда человека, старая и новая версия пакета шлют его одинаково.

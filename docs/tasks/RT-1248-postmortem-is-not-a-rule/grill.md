# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `patterns/task-flow-resume.md`.

- **место:** в конец
- **повод:** разбор происшествия, написанный заходом, на поведение того же захода не повлиял:
  через один ход после записи механизм повторился в той же форме. Написать разбор оказалось
  легче, чем его исполнить.
- **готовый текст:** «Разбор, написанный этим заходом, требованием для него не становится.
  Запись объясняет механизм, а исполняется он тем же, чем исполнялось прежнее, — вниманием
  того, кто ведёт ход. Поэтому разбор кончается не текстом, а тем, что из него вышло: правкой
  ресурса, гардом или предложением с адресом. Заход, дописавший разбор и вернувшийся к работе
  прежним, платит за него дважды.»

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

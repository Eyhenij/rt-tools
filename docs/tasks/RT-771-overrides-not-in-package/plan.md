# Замысел

**Задача:** RT-771 · **Ветка:** RT-771-overrides-not-in-package
**Поведение:** не меняется — правятся тексты слоя правил, которые везёт пакет; продукт их не исполняет

## След задачи

| Что                    | Где                                  |
| ---------------------- | ------------------------------------ |
| Правила                | `projects/agent-kit/assets/rules`    |
| Паттерны               | `projects/agent-kit/assets/patterns` |
| Зеркала                | `.claude/skills`                     |
| Правило о самом пакете | `.claude/skills/agent-kit`           |

## Что считается сделанным

- Ни один ресурс пакета не называет имён, принадлежащих одному дереву-потребителю: имена в
  готовом коде принадлежат киту, а не приложению, которое его ставит.
- Всё, что накопилось надстройками у потребителя и верно для любого дерева этого класса, стоит в
  исходниках пакета.
- Предметное для одного дерева в пакет не переехало, и по каждой такой надстройке названо, почему.
- `pnpm run agent-kit:check` зелёный, разложенные копии сходятся с исходниками.

## Этапы

### 1. Разбор восемнадцати надстроек

- **Что делается:** каждая надстройка читается целиком и относится к одному из двух: переносимо
  в пакет либо предметно для дерева-потребителя.
- **Признак готовности:** список из восемнадцати строк с решением и доводом по каждой.
- **Чем проверяется:** чтение владельцем.

### 2. Перенос переносимого в исходники пакета

- **Что делается:** отнесённое к переносимому вносится в `projects/agent-kit/assets`, по разделам.
- **Признак готовности:** ни один перенесённый абзац не называет имён одного дерева.
- **Чем проверяется:** поиск чужих имён по ресурсам пакета.

### 3. Раскладка и сверка

- **Что делается:** `pnpm run agent-kit:sync`, разложенные копии обновляются в этом дереве.
- **Признак готовности:** `pnpm run agent-kit:check` зелёный.
- **Чем проверяется:** та же команда.

### 4. Проверки перед отдачей

- **Что делается:** набор гейта целиком.
- **Признак готовности:** зелено.
- **Чем проверяется:** `pnpm run check:all`, `pnpm run check:specs`, `pnpm run check:docs`.

## Чего эта работа не делает

- Списочные экраны админки приёмника не переписывает: их устройство сходится с образцом,
  расхождение оказалось в текстах пакета. Пять точечных отличий показа заведены отдельно.
- Версию пакета не поднимает и не публикует: выпуск — решение владельца.

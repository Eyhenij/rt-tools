# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `hooks/skill-gate.sh`.

- **место:** текст отказа гейта правил — он называет правило и отсылает к его файлу; туда же
  добавляется спутник правила, второй файл, который у правила есть всегда.
- **повод:** правило говорит, что должно быть верно, а спутник — чем это верно здесь и что
  здесь сломано. Загрузка правила приносит только первый, и приём, взятый из правила, в дереве
  не работает: правило называет способ, а спутник рядом отдельным разделом объявляет его
  невозможным из-за ограничения на стороне хостинга. За один заход по этому разошлись работа и
  её результат — заявка была открыта способом из правила, отвечала номером и адресом своему же
  автору и при этом не существовала для того, кому предназначалась. Разделы спутника были
  написаны за три дня до этого и за тот же заход не открывались ни разу.
- **чем закрывается:** ничего из надстроек этого дерева — спутники здесь уже описывают
  расхождения, их просто не читают вместе с правилом.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

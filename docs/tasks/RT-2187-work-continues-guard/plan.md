## What counts as done

- Пока у эпика есть незакрытая задача, ход без законного выхода возвращается исполнителю с
  названным следующим шагом. Четыре выхода правила и закрытый эпик отпускают ход.
- Две остановки прошлой сессии на настоящей записи хода отбиваются проверкой.
- Статья о проверке стоит в правиле о ходе через надстройку и привязана к коду в компаньоне.

## Stages

### 1. Проверка и её сценарии

- **What is done:** `.claude/hooks/work-continues-guard.sh` на событии конца хода и набор
  сценариев в тестах дерева. Сценарии: отказ без причины, второй проход, четыре выхода, слово
  владельца в строке ожидания, служебные сообщения, закрытый и нечитаемый эпик.
- **Readiness sign:** все сценарии зелёные, объявление проверки сходится с телом.
- **Verified by:** `bash tools/tests/work-continues-guard.test.sh` — в последней строке «0 failures»;
  `node tools/check-hook-scope.mjs` — в выводе «it matches».

### 2. Привязка к правилу

- **What is done:** надстройка `.claude/rt-kit/overrides/rules/turn-conduct.md` с разделом об
  открытом эпике, раскладка, строки привязки в `.claude/skills/turn-conduct/implementation.md`.
- **Readiness sign:** разложенное правило несёт раздел, раскладка сходится с пакетом.
- **Verified by:** `npm run agent-kit:check` — в выводе нет строки о расхождении; `npm run check:docs` —
  ни одной строки о пути из этой ветки.

## What this work does not do

- Пакетная проверка выхода из хода не правится: в пакет уходит предложение той же сессией.
- Запрет на инструмент закрытия разговора здесь не лежит: он стоит в глобальных настройках машины.

## Что считается сделанным

- Гард отбивает создание ветки задачи от главной, когда у задачи назван эпик, и называет ветку
  эпика.
- Гард отбивает открытие заявки задачи с основанием «главная», когда у задачи назван эпик.
- Гард отбивает открытие заявки эпика, пока в его ветке лежит хоть одна папка задачи.
- Свежести главной гард требует от основания ветки задачи не напрямую, а через ветку эпика:
  требование остаётся, но чинится вливанием главной в ветку эпика.
- Пробы набора пакета покрывают каждый случай и приняты на нарушении.

## Этапы

### 1. Гард знает эпик задачи

- **Что делается:** второй ярус гарда читает тело карточки задачи и достаёт номер эпика — тем же
  видом строки, каким её пишет команда и читает сверка очереди.
- **Признак готовности:** по номеру задачи гард отвечает номером эпика или молчанием, и без сети
  молчит.
- **Проверяется:** пробы набора пакета.

### 2. Ветка задачи от главной вместо ветки эпика отбивается

- **Что делается:** при создании ветки с номером задачи, у которой назван эпик, основание судится
  против ветки эпика, а не против главной; отказ называет ветку эпика.
- **Признак готовности:** ветка от `origin/main` отбита, ветка от ветки эпика прошла, ветка
  задачи без эпика прошла как прежде.
- **Проверяется:** пробы набора пакета.

### 3. Заявка задачи мимо ветки эпика отбивается

- **Что делается:** при открытии заявки основание из довода команды судится против ветки эпика.
- **Признак готовности:** заявка с основанием «главная» отбита, с основанием ветки эпика прошла.
- **Проверяется:** пробы набора пакета.

### 4. Заявка эпика с непустыми папками отбивается

- **Что делается:** при открытии заявки из ветки эпика в главную гард смотрит папки задач в
  ветке; хоть одна — отказ.
- **Признак готовности:** заявка эпика с папкой отбита и названа папка; без папок прошла.
- **Проверяется:** пробы набора пакета.

### 5. Раскладка и тексты

- **Что делается:** `pnpm run agent-kit:sync`, спека подобласти и её привязки, компаньон правила.
- **Признак готовности:** `pnpm run agent-kit:check` и `node tools/check-specs.mjs` без
  расхождений.
- **Проверяется:** обе команды и `bash projects/agent-kit/tests/run.sh`.

## Чего эта работа не делает

- Не правит сверку очереди — это #1926.
- Не переводит на новый порядок эпики, заведённые прежним.
- Не отменяет требование свежести главной: оно остаётся, но за эпик чинится вливанием главной в
  ветку эпика.

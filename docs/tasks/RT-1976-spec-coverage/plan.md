### Этап 1 — свести с главной и отдать

Конфликты слоя правил разбираются по существу: что главная переписала новее — берётся из неё, что
эпик добавил своего — сохраняется. Разложенные копии руками не правятся, а пересобираются
раскладкой.

Признак готовности: `pnpm run agent-kit:check` без расхождений, набор перед отправкой зелёный, PR
эпика открыт.

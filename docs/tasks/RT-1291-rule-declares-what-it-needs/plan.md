# Замысел

**Поведение:** не меняется — правится текст паттерна, по которому заводят правило.

## Что делается

1. В разделе «Правило» паттерна `spec-driven-rule`, сразу под образцом шапки, встаёт строка
   требования к соседним ресурсам: чем она пишется, чем называются ресурсы и когда её не
   бывает вовсе.
2. Там же — почему требование не выводится из фразы в тексте: у потребителя разложено не всё.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `npm run check:specs`,
`node tools/check-file-size.mjs`, `node tools/check-doc-paths.mjs`.

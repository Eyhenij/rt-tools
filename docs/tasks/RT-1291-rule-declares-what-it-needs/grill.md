# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `patterns/spec-driven-rule.md`. Отметить
её этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт
здесь.

## Паттерн заведения правила не показывает строку требования

Правило слоя правил велит переносимому тексту называть своё требование к соседнему ресурсу
строкой в шапке, а не выводить его из фразы в тексте. Паттерн, которым это же правило велит
заводить новое правило, строки не показывает вовсе: он даёт поля шапки, перечисляет разделы и
кончается порядком шагов. Пишущий правило по паттерну требования не встречает — и строки не
пишет.

Счёт подтверждает: строку несёт один текст на весь набор правил, и он написан до паттерна.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки на эту строку не заводится: она законна и отсутствующая — правило, которому нечего
требовать, её не пишет, и отличить такое от промаха машине нечем.

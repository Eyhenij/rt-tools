# Разбор просьбы

Запись груза из приёма, соседнее дерево, ресурс `patterns/doc-style-write.md`. Отметить её этому
дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

- **место:** раздел «Простыми словами», вместо строки о проверке чтением вслух
- **повод:** признак «прочитать фразу вслух» работает на той фразе, которую читают, и не
  работает на файле в сотни строк: оборот всплывает по всему тексту, и глазами он не считается.
  У приёма нет второй половины — счёта, — и каждый исполнитель собирает набор оборотов заново,
  из своей памяти о прошлых работах.
- **готовый текст:** к чтению вслух добавляется счёт грепом по набору оборотов, накопленному
  разбором прошлых работ. Число отказом само по себе не является: у оборота бывает законное
  употребление. Отказ — когда один оборот стоит в тексте десятками.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

# Замысел

**Поведение:** не меняется — правится текст паттерна, ни одной проверки и ни одного гарда задача
не трогает.

Приём проверки простых слов у паттерна один — прочитать фразу вслух. На длинном тексте он не
работает: слух судит одну фразу, а повтор оборота виден только счётом.

## Этапы

1. Вторая половина приёма вместо прежней строки: счёт по набору оборотов, чем считается отказ и
   откуда набор берётся.
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Самого набора оборотов паттерн не перечисляет: он свой у каждого дерева и живёт там, где стоит
проверка слога.

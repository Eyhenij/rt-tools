## Что считается сделанным

- Ресурс, требующий свойства, которого дерево не назвало, не кладётся вовсе — ни файлом, ни
  черновиком компаньона.
- Требование неизвестного свойства и незнакомое свойство в настройке дерева роняют раскладку с
  именем ресурса и именем свойства.
- Ресурс, названный деревом поимённо, кладётся и при неотвеченном требовании, а перечень
  раскладки это называет.
- Отказ по пустому компаньону такого ресурса говорит требуемое свойство и предлагает снять
  ресурс, а не заполнить черновик.
- Правила наблюдаемости и владеющей сущности захода помечены требованием и из этого дерева
  уехали вместе со своими пустыми компаньонами.
- Прогон пакета зелёный, `pnpm run agent-kit:check` сходится.

## Этапы

### 1. Свойства пакета и требование в имени

- **Что делается:** перечень свойств в ресурсах пакета, чтение требования из имени файла рядом с
  чтением вида, отбор по набору свойств дерева.
- **Признак готовности:** ресурс с неотвеченным требованием не кладётся; ресурс без требования
  кладётся всякому дереву; вид и требование в одном имени разбираются каждый своим перечнем.
- **Чем проверяется:** сценарии SC-AK-168…171, 175 в прогоне пакета.

### 2. Набор свойств в настройке дерева

- **Что делается:** ключ `has` в разборе настройки; отказ на свойство, которого пакет не
  объявлял, — с обеих сторон, и у дерева, и у ресурса.
- **Признак готовности:** незнакомое свойство роняет раскладку и названо по имени.
- **Чем проверяется:** сценарии SC-AK-173, 174.

### 3. Выбор поимённо и перечень

- **Что делается:** отбор поимённо ставится сильнее требования; перечень ресурсов отделяет
  неположенное требованием от снятого деревом.
- **Признак готовности:** названный поимённо ресурс ложится, и строка перечня называет
  неотвеченное требование.
- **Чем проверяется:** сценарии SC-AK-172, 176.

### 4. Отказ по компаньону

- **Что делается:** состояние компаньона у ресурса с неотвеченным требованием называется своим
  словом — требуемым свойством и предложением снять ресурс.
- **Признак готовности:** отказ не предлагает заполнять то, что заполнить нечем.
- **Чем проверяется:** сценарий SC-AK-177.

### 5. Два правила помечены, дерево их отдаёт

- **Что делается:** правила наблюдаемости и владеющей сущности захода получают требование в имени;
  в этом дереве проходит раскладка, и они уезжают вместе с пустыми компаньонами.
- **Признак готовности:** `pnpm run agent-kit:sync` снимает оба и говорит об этом; сверка зелёная.
- **Чем проверяется:** `pnpm run agent-kit:sync`, `pnpm run agent-kit:check`.

### 6. Правило и договорённость

- **Что делается:** статья о свойствах дерева в правило `agent-kit`; договорённость вливается в
  спек домена последним коммитом отчёта.
- **Признак готовности:** статья стоит в правиле, `proposed/tree-traits/` в главную ветку не
  едет, привязки сценариев на месте.
- **Чем проверяется:** `pnpm run check:specs`, `pnpm run check:docs`.

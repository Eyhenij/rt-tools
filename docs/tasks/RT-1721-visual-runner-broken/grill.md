## Откуда работа

Условие выхода предыдущей задачи оказалось неисполнимым: визуальный прогон витрины не
запускается вовсе. Все двадцать одна группа показов падает одинаково — `TypeError: Cannot read
properties of undefined (reading 'goto')` в `setupPage`: окружение прогона не отдаёт страницу.
Падают и наборы, которых никакая правка не касалась, — значит сломана обвязка, а не показы.

Цена этого прямая: снимок эталона не снять ни для нового показа, ни для правки старого, и
визуальная проверка витрины не работает ни у кого.

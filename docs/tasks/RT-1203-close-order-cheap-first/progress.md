# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 4 — условие взятия паттерна закрытия перестаёт требовать прогона

## Решения по ходу

- **Порядок переставляется, а не смягчается.** Прогон остаётся обязательным и остаётся до
  разбора папки: двигается он на один шаг, а не отменяется.

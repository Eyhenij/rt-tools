# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 5 — Команда чтения груза
- **Сделано:** разбор просьбы и замысел записаны; задача заведена и стоит в работе; ветка от
  свежей главной
- **Следующий шаг:** поднять местный приёмник с базой, завести там учётную запись службы,
  написать команду чтения
- **Незакоммиченное:** папка задачи целиком
- **Ждём владельца:** нет — до этапа 5, где нужна одна команда заведения учётной записи на проде
- **PR:** ещё не открыт

## Решения по ходу

- **Шапка раскладки снята с копий образца папки задачи** — `cp -r docs/tasks/_template` приносит
  файлы с шапкой `rt-kit`, и гард места правки отбивает первую же правку разбора просьбы. Копия
  образца образцом не является: шапка снята тремя строками. Затронутый этап замысла: нет —
  находка уходит к замыслу эпика о слое правил.

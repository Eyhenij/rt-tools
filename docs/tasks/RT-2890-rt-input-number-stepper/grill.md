# Grill

## The owner request

> давай по порядку, только убедись что никто не взял в работу и когда возьме заасайни на меня и тащи тикет в работу

RT-2890 идёт третьей в списке после RT-2907 и RT-2927. Задачу никто не брал: исполнителя не было,
ветки и записи в архиве тоже. Она назначена на `treble3d` и стоит в колонке «В работе».

Тело задачи:

> - Справа в поле две стрелки: верхняя прибавляет шаг, нижняя вычитает.
> - Входы `step`, `min` и `max`. На границе диапазона своя стрелка гаснет.
> - Клавиши «вверх» и «вниз» в поле делают то же, что стрелки.
> - Стрелки отключаются входом, по умолчанию они видны.
> - В выключенном поле стрелки тоже выключены.

## What the tree already has

- Поле числа во втором ките собрано на текстовом поле с цифровой клавиатурой. Входы `min` и `max`
  уже есть и зажимают значение при уходе из поля. Шага, стрелок и обработки клавиш нет.
- Справа в поле уже стоит крестик очистки, он виден только при значении.
- В наборе значков кита есть `chevron-up` и `chevron-down`.
- Подписей кита для стрелок нет. Их добавляют в английские подписи кита и в русские подписи
  витрины, как подпись пунктов в RT-2927.
- Макет: файл кита, страница Input Number.
    - У набора поля есть свойство `Stepper`, по умолчанию включено.
    - Набор Input Number Stepper: столбец 20×32 из двух кнопок 20×16 со скруглением 4 и значком 12.
    - Значок приглушённый. При наведении у кнопки фон наведения, значок основного цвета.
    - На границе и в выключенном поле значок цвета выключенного текста.
    - Стрелки стоят последними в поле, после крестика, во всех размерах и видах поля.
    - Кадр «Примеры: стрелки шага»: шаг вверх, шаг вниз, верхняя гаснет на максимуме, нижняя на
      минимуме, поле без стрелок.

## What the rules already say

- Видимая правка кита идёт по правилу `kit-approval`: макет и слово владельца до кода, витрина и
  второе слово до PR.
- Подписи кита пишутся по-английски в подписях кита и по-русски в подписях витрины.

## Questions and answers

Вопросов владельцу нет: тело задачи и макет закрывают все шесть.

- Поведение меняется: у поля появляются стрелки. Вопрос закрыт допущением.
- Правка закона или правила не нужна. Вопрос закрыт допущением.
- Задача одна. Вопрос закрыт допущением.
- Чего в задаче нет — ниже, в последнем разделе. Вопрос закрыт допущением.
- Задачу закрывают тесты по сценариям, витрина и слово владельца. Вопрос закрыт допущением.
- Образец — макет кита и обычное числовое поле браузера. Вопрос закрыт допущением.

## Decisions

- **Шаг по умолчанию — 1.** Так у числового поля браузера.
- **Пустое поле шагает от нуля, результат зажимается в диапазон.** Так у числового поля браузера.
  Отвергнуто: начинать с `min` — у поля без границ его нет.
- **Результат шага округляется до знаков шага.** Иначе 0,1 + 0,2 даёт 0,30000000000000004.
- **Стрелка на границе выключена и остаётся на месте.** Так в макете.
- **Стрелки не берут фокус табом.** Клавиатура меняет значение клавишами «вверх» и «вниз» в самом
  поле. Две лишние остановки таба на каждом поле формы мешают.
- **Вход называется `stepper`, по умолчанию `true`.** Как свойство набора в макете.
- **В режиме только для чтения стрелок нет.** Там нет поля ввода, только текст.
- **Каждый шаг сразу отдаёт значение наружу.** Так же, как набор с клавиатуры в этом поле.

## Что считается сделанным

- Своя команда зелёная на текущем дереве и печатает число принятых мест.
- Добавленный код цвета или размер числом в любом файле набора роняет её с именем файла и
  свойства.
- Удалённая из кода строка, оставшаяся в списке, роняет её отдельным сообщением.
- Числа в медиазапросах проверку не роняют.
- `pnpm run lint:styles` и `pnpm run agent-kit:check` остаются зелёными.
- Правило `styling-bem` называет проверку и её список — надстройкой, а не правкой разложенного
  файла.

## Этапы

### 1. Конфиг проверки и её точка входа

- **Что делается:** заводится конфиг stylelint для набора — основной плюс правила `color-no-hex` и
  `rt-tools/no-hardcoded-design-tokens` на `projects/ui-kit-v2/src/lib/**/*.scss`; пишется
  `tools/check-tokens-styles.mjs`, зовущий stylelint программно и печатающий находки ключами.
- **Признак готовности:** команда выполняется и печатает список находок текущего дерева.
- **Чем проверяется:** запуск команды; число находок сверяется с замером договорённости.

### 2. Список принятого и отказ на новом

- **Что делается:** накопленное уезжает в `tools/tokens-styles-allowlist.json` флагом
  `--baseline`; проверка отказывает на находке вне списка и на записи, которой больше ничего не
  отвечает.
- **Признак готовности:** зелёный прогон на текущем дереве, красный — на заведённой пробе.
- **Чем проверяется:** проба заводится и снимается в этой же ветке: код цвета в файле набора,
  затем снятие записи из списка.

### 3. Команда, границы и медиазапрос

- **Что делается:** команда заводится в `package.json`; проверяется, что числа в медиазапросах в
  находки не попадают, а исключения набора из договорённости не судятся.
- **Признак готовности:** ни одно из девятнадцати чисел медиазапросов не значится в списке
  принятого.
- **Чем проверяется:** поиск по списку принятого; `pnpm run lint:styles`.

### 4. Правило и тексты

- **Что делается:** надстройка `.claude/rt-kit/overrides/rules/styling-bem.md` называет проверку,
  её список и вид записи; `implementation.md` договорённости получает точные имена файлов вместо
  описаний.
- **Признак готовности:** имя команды и путь списка названы в правиле и в договорённости
  одинаково.
- **Чем проверяется:** `pnpm run agent-kit:check`; `node tools/check-specs.mjs` не называет
  `design-tokens`.

## Чего эта работа не делает

- Не чинит ни одного накопленного литерала: уборка идёт фоном под гейтом.
- Не трогает `tools/check-styles.mjs` и `tools/styles-allowlist.json`.
- Не судит обходы чужой вёрстки и `!important` — это `styling-bem`.
- Не заводит проверку графа токенов и полноты тёмной темы — RT-383 и RT-384.

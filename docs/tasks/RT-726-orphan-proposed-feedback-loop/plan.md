# Замысел

**Задача:** RT-726 · **Ветка:** RT-726-orphan-proposed-feedback-loop
**Поведение:** не меняется — доделывается вливание, сделанное наполовину: сценарии уже стоят в
спеке домена, а директория договорённости осталась лежать рядом.

## След задачи

| Что              | Где                                            |
| ---------------- | ---------------------------------------------- |
| Договорённость   | `docs/specs/agent-kit/proposed/feedback-loop/` |
| Спек домена      | `docs/specs/agent-kit/scenarios.md`            |

| Сверка           | `npm run check:specs`                          |

## Что считается сделанным

- Директории `proposed/feedback-loop/` в дереве нет.
- Сценарии `SC-AK-156`…`SC-AK-158` остались в спеке домена с прежними номерами и прежней
  пометкой о покрытии.
- `npm run check:specs` не печатает ни одной строки о занятом идентификаторе и ни одной о
  сценарии, помеченном непокрытым при живом тесте.

## Этапы

### 1. Директория снята, указатель спеков сверен

- **Что делается:** `docs/specs/agent-kit/proposed/feedback-loop/` удаляется; раздел
  указателя спеков о невыкаченном читается целиком — строка о фиче снимается, если стоит.
- **Признак готовности:** сверка спеков молчит по всем шести строкам.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`.

## Чего эта работа не делает

- Не трогает сценариев в спеке домена: они влиты верно, и номера у них те же, что в заголовках
  тестов.
- Не чинит второй директории `proposed/push-gate-scope/`: её работа ещё не выкачена, и лежит
  она законно.
- Не заводит проверки на «влито наполовину»: признака у машины нет — сверка видит двойной
  номер, а не незакрытый переезд.

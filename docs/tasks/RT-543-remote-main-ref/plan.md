## Что считается сделанным

- Ни один шаг закрытия захода не читает локальную главную ветку.
- Шаг приведения дерева к главной исполним при незакоммиченном в рабочем дереве.
- Все три редакции правила поставки называют удалённую ссылку и для действия, а не только для
  слова владельцу.

## Этапы

### 1. Шаги команды закрытия захода

- **Что делается:** подтягивание главной без перехода на неё; счёт влитого и невлитого от
  `origin/<главная>`.
- **Признак готовности:** в тексте команды локальной главной как основания сравнения не осталось.
- **Чем проверяется:** `grep -n 'merged\|pull --ff-only' projects/agent-kit/assets/commands/next-session.md` — ни одной строки с локальной главной.

### 2. Статья в трёх редакциях правила

- **Что делается:** к статье об утверждении дописывается, что основание новой ветки, счёт влитого
  и подтягивание берут удалённую ссылку.
- **Признак готовности:** статья стоит в github, gitlab и azure.
- **Чем проверяется:** `node tools/check-file-size.mjs` — новых длинных нет.

### 3. Спек и раскладка

- **Что делается:** статья и сценарий в спеке, привязка, раскладка.
- **Признак готовности:** сверка молчит.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом.

## Чего эта работа не делает

- Не заводит проверки, читающей текст команды: грепать прозу на предмет ссылки нечем.

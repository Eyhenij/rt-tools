## Этапы

### 1. Слот вкладок и вход строки

**Входит:** слот `rtThreadListTabs` под шапкой списка, вход `subtitle` у шапки чата, подспек,
сценарии, тесты, витрина.
**Не входит:** другие компоненты.
**Готово, когда:** тесты `rt-thread-list` и `rt-chat` зелёные, `npm run check:specs` без
расхождений.

### 2. Снимки и выпуск

**Входит:** пересъёмка эталонов витрины, PR, выпуск версии.
**Не входит:** подъём версии у потребителя.
**Готово, когда:** прогон PR зелёный, версия в реестре.

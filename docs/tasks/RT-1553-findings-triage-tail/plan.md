## Этапы

### 1. Сверка пунктов с нынешними ресурсами

- **Что делается:** каждый пункт проверяется по источникам пакета — стоит ли он там уже.
- **Признак готовности:** у каждого пункта есть ответ «закрыт» либо «жив».
- **Чем проверяется:** чтение источников грепом по формулировке пункта.

### 2. Правка ресурсов по живым пунктам

- **Что делается:** живое вносится статьями в правила, их холодные части и паттерны.
- **Признак готовности:** формулировка стоит в ресурсе, предел веса выдержан.
- **Чем проверяется:** `node tools/check-file-size.mjs` — новых длиннее предела нет.

### 3. Разбор самих файлов находок

- **Что делается:** разобранные пункты снимаются, у файла остаётся только неразобранное.
- **Признак готовности:** таблицы пунктов пусты либо файла нет вовсе.
- **Чем проверяется:** `pnpm run agent-kit:check` и `node tools/check-doc-paths.mjs` — расхождений нет.

## Что считается сделанным

- Посетитель открывает страницу с одним скриптом и ключом сайта, видит виджет, пишет первую
  реплику и получает свой разговор.
- Ответ оператора приходит в открытый виджет сам, без обновления страницы.
- Вернувшийся посетитель попадает в свой разговор: признак из браузера открывает ту же переписку.
- Виджет показывает приветствие площадки и говорит, когда оператор отвечает, а когда нет.
- На узком экране виджет занимает экран целиком, на широком — стоит углом страницы.
- Сценарии `SC-CH-49` и дальше закрыты пробами или несут пометку с причиной; то, что видит
  посетитель, закрыто сквозными пробами.

## Этапы

### 1. Договорённость о виджете

- **Что делается:** описание в `docs/specs/chat/proposed/widget/` — что показывает виджет, чем
  он закрыт, где живёт признак посетителя, что происходит при отказе и вне часов работы;
  сценарии к нему.
- **Признак готовности:** аудит описаний не называет по новому описанию ни пропущенного раздела,
  ни занятого номера сценария.
- **Проверяется:** `node tools/check-specs.mjs` — ни строки про пропущенный раздел.

### 2. Настройки площадки и открытая операция для виджета

- **Что делается:** приветствие и часы работы на записи сайта миграцией, открытая операция,
  которой виджет спрашивает их вместе с признаком включённости; пробы домена.
- **Признак готовности:** пробы домена чата зелёные, расхождения схемы нет, сборка приёмника
  зелёная.
- **Проверяется:** `pnpm exec nx run-many -t test -p message-bus-api-chat-feature message-bus-api-chat-util`
  — «Successfully ran target test»; `node tools/check-schema-drift.mjs` — нулевой код.

### 3. Виджет: первая реплика, лента и поле набора

- **Что делается:** веб-компонент в теневом дереве — приветствие, форма первой реплики, лента
  обеих сторон, поле набора, признак посетителя в хранилище браузера, подписка на поток событий.
- **Признак готовности:** пробы чистых решений виджета зелёные, сборка виджета зелёная.
- **Проверяется:** `pnpm exec nx build chat-widget` — «Successfully ran target build»;
  `pnpm exec nx test chat-widget` — «Successfully ran target test».

### 4. Вид виджета и узкий экран

- **Что делается:** свои стили в теневом дереве — пузырь на широком экране, экран целиком на
  узком, обрезка длинных реплик, состояние отказа и слово о часах работы.
- **Признак готовности:** страница стенда с виджетом поднимается, кадры сняты и просмотрены
  глазами.
- **Проверяется:** `node ../../tools/shot-browser.mjs npx playwright test src/chat-widget.spec.ts`
  — все пробы зелёные.

### 5. Сквозные пробы, договорённость вливается и PR

- **Что делается:** сквозные пробы на то, что видит посетитель; описание переезжает в спеку
  домена вместе с привязками, папка задачи разбирается записью в `docs/archive/`, набор перед
  отправкой прогоняется целиком, PR открывается в ветку эпика готовым.
- **Признак готовности:** сквозной набор зелёный и длиннее прежних 140 сценариев, аудит описаний
  — нулевой код, PR открыт с рецензентом.
- **Проверяется:** `pnpm exec nx run message-bus-admin-e2e:e2e` — «141 passed» и больше;
  `node tools/check-specs.mjs` — нулевой код; `gh pr view <номер> --json isDraft,reviewRequests`
  — черновика нет, рецензент назван.

## Чего эта работа не делает

- **Извещения оператору и выкатка** — задачи RT-2183 и RT-2184.
- **Экран правки настроек площадки.** Приветствие и часы работы кладутся на запись сайта, а
  правит их сегодня тот, кто правит записи площадок; экрана для этого в дереве нет ни одного, и
  тело задачи его не называет.
- **Вложения, звонки и боты-ответчики.** Эпик их не держит.
- **Признак «оператор набирает текст».** Ни телом задачи, ни описанием сервиса он не обещан.

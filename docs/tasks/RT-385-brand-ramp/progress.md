## Решения по ходу

- **Рамка задачи сменилась посреди разбора** — владелец потребовал гибкую дизайн-систему по образцу
  чужого кита, без оглядки на сегодняшнюю реализацию. Отменены два ранних ответа: «ноль расхождений
  кадров» и «сегодняшний ряд один в один». Взамен: ровная линейка из одиннадцати ступеней, палитра
  синего снимается, каталог эталонов переснимается скопом. Затронутые этапы замысла: все.
- **Тёмная подложка обвязки уезжает в `--rt-navy-900`, а не в ступень бренда** — `#182142` не
  синий и не марка; палитра navy в дереве уже есть (`--rt-navy-600`). Назначение зовётся
  `--rt-color-bg-nav`: имя `--rt-color-bg-inverse` занято нейтральным, а роль здесь другая.
  Затронутый этап замысла: 2.

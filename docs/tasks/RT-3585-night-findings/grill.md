## Решения

- **Проверка согласий судит слитые задачи по их записям и у ветки с записью.** Своя запись отвечает
  только за правки самой ветки. Строка «Без вида» из записи RT-3569 убирается: RT-3569 правок кита
  не несёт.
- **Сборка графов удаляет graph.html после `graphify update`.**
- **Сценарии не копят временные каталоги.** Каждый набор сценариев хуков получает свой TMPDIR, а
  тест выпуска пакета убирает свой каталог `rt-release-*`.
- **Правила ночной работы, защита конца хода и статьи правил по находкам** — задачи RT-3587 и
  RT-3588 того же эпика.

**Описание фичи:** не нужно — правка проверок и правил, поведение приложений не меняется.

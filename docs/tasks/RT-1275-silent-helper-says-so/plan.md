# Замысел

**Поведение:** не меняется для настроенного дерева — помощник по-прежнему печатает
идентификатор и выходит нулём. Меняется поведение ненастроенного: молчание получает голос.

## Что делается

1. `hooks/browser-device-id.sh`: не найдя значения ни в переменной, ни в файле, помощник печатает
   строку в поток ошибок — один раз на признак, по метке во временном каталоге. Выход остаётся
   нулевым: гарды пропускают, как пропускали.
2. Признак берётся первым доводом; его передаёт гард выбора браузера, который сессию и так
   читает. Довода нет — метка дневная.
3. Набор сценариев `browser-device-id.test.sh`: значение из переменной, значение из файла, слово
   о ненастроенности один раз и молчание на повторе.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`.

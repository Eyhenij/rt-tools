## Что считается сделанным

- У обеих таблиц записей груза есть необязательная колонка текста починки, и миграция едет этой же веткой.
- Строка правки состояния принимает четвёртое поле; переход в «починено и не выпущено» без текста отбивается построчно третьей причиной, а строка с текстом и другим переходом отбивается целиком.
- Отбитая строка не пишет ни состояния, ни текста и попадает в журнал приёмника наравне с двумя прежними причинами.
- Панель подробностей показывает текст у обоих родов записей; у записи без текста строки в панели нет вовсе.
- Команда строки запуска несёт текст доводом.
- Договорённость влита в спек поддомена правки состояния, правило показа уехало в спек админки, довод команды — в спек наблюдений пакета; сценарии начинаются с `SC-MB-181`, каждое правило привязано, сверка спеков зелёная.

## Этапы

### 1. Колонка у обоих родов записей

- **Что делается:** моделям записей груза добавляется необязательное текстовое поле текста починки; миграция пишется через `migrate diff` и накатывается на местную базу. Ограничений и индексов колонка не несёт.
- **Признак готовности:** миграция лежит рядом с прежними, местная база её приняла, клиент хранилища пересобран; лежащие записи получили пустоту.
- **Чем проверяется:** `pnpm run check:schema` — расхождения схемы и миграций не названо.

### 2. Приём текста приёмником

- **Что делается:** разбор строки правки принимает четвёртое необязательное поле; просьба о переходе несёт текст; заводится третья причина отбоя — переход в «починено и не выпущено» без текста — и отбой строки, где текст стоит не при том переходе; запись состояния кладёт текст тем же запросом; отбитая строка идёт в журнал прежней строкой.
- **Признак готовности:** пустой текст и строка из пробелов отбиваются наравне с отсутствующим полем; отбитая строка не пишет ни состояния, ни текста; счёт исполненных и список отбитых прежней формы.
- **Чем проверяется:** `pnpm exec nx run-many -t test -p message-bus-api-cargo-state-feature message-bus-api-cargo-state-util message-bus-common` — спеки новых сценариев зелёные.

### 3. Текст доезжает до админки и виден в панели

- **Что делается:** чтение одной записи отдаёт поле у обоих родов; модель и маппер админки его принимают; панель подробностей показывает строку «Чем исправлено», а у записи без текста строки нет вовсе; подпись заводится ключом рядом с подписями соседних свойств.
- **Признак готовности:** запись с текстом показывает его в панели, запись без текста не показывает ни подписи, ни пустого значения; список раздела не тронут.
- **Чем проверяется:** `pnpm exec nx run-many -t test -p message-bus-admin-postmortems-ui message-bus-admin-proposals-ui message-bus-admin-postmortems-util message-bus-admin-proposals-util` — спеки обоих родов зелёные.

### 4. Довод командной строки

- **Что делается:** довод текста встаёт в перечень доводов команды отметки, разбор доводов кладёт текст в запись груза, запись груза получает необязательное поле; подсказка помощи и описание пакета называют довод.
- **Признак готовности:** команда с доводом собирает тело с текстом, без довода — прежнее тело; неизвестный довод отбивается как прежде.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit` — спеки команды зелёные.

### 5. Договорённость вливается в спеки

- **Что делается:** сценарии с `SC-MB-181` и привязки правил пишутся рядом с договорённостью; последним коммитом заявки правила вливаются в спек поддомена правки состояния, правило показа уезжает в спек админки, довод команды — в спек наблюдений пакета, каталог договорённости удаляется.
- **Признак готовности:** ни одного правила без привязки, ни одного сценария без теста с тем же номером в заголовке, номера не переиспользованы.
- **Чем проверяется:** `pnpm run check:specs` — сценарии, привязки и коды отказа сошлись.

## Чего эта работа не делает

- **Версия выпуска на записи** — RT-911, ложится тем же путём.
- **Показ текста разметкой** — RT-912; панель показывает текст как есть.
- **Отбор, столбец и порядок по состоянию** — RT-913.
- **Рабочий порядок разбора груза** — RT-914.
- **Правка текста починки из админки** — админка груз читает, правит его дерево.
- **Исходы обоих родов, сложенные в одну карту по ключу записи.** Разведка нашла это рядом с местом правки: ключ разбора, совпавший с признаком предложения, затирает чужой исход. Своей задачи под починку нет, и здесь она не делается.

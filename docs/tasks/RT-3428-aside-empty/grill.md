# Grill

## The owner request

> добавить в общий компонент асайда плейсхолдер по умолчанию "иконка" и "нет данных" и возможность переопределить для каждого случая свои

Передано сессией задачи приложения (админка аренды): владелец показал пустую панель «События» —
под вкладками белое поле без единого слова. Приложение кит не правит; после выпуска пакета оно
поднимет версию и включит заглушку в своих панелях.

## What the tree already has

- `rt-aside` (`projects/ui-kit-v2/src/lib/components/aside/`) — рамка с шапкой, блоком ошибки,
  зоной содержимого `rt-aside__content`, подвалом и слоем ожидания. Признака пустоты нет.
- `rt-empty-state` — готовая заглушка: иконка, заголовок, описание, слот действия.
- Подпись `uiNoData` в подписях кита (`en`: «No data yet», витрина `ru`: «Пока нет данных»);
  на ней уже стоит пустой `rt-bar-list`.
- Образец слота-шаблона: `RtWorkspaceDetailsErrorDirective` (`ng-template[rtWorkspaceDetailsError]`).

## What the rules already say

- Видимая правка кита — правило `kit-approval`: макет Figma и одобрение владельца до кода,
  витрина и второе одобрение до push.
- Подписи кита берутся через `rtKitLabel`, строкой в коде не держатся.

## Questions and answers

Вопросы закрыты допущением — ответы есть в просьбе, переданной сессией приложения:

- **Меняет ли поведение** — да: у панели появляется признак пустоты и заглушка.
- **Правка закона или правила** — нет.
- **Одна задача или несколько** — одна.
- **Что не входит** — выпуск пакета (делает сессия приложения), правка самих панелей приложения.
- **Что покажет готовность** — в витрине панель с `empty` показывает иконку и «нет данных» по
  центру тела, шапка и подвал на месте; входы и слот подменяют заглушку; тесты зелёные; PR влит.
- **Образец** — `rtWorkspaceDetailsError` для слота, `rt-bar-list` для подписи `uiNoData`.

## Decisions

- **Подпись по умолчанию — существующая `uiNoData`**, не новый ключ — приложение, которое уже
  дало `uiNoData`, получает свой текст без правок. Rejected: новый ключ — второй ключ с тем же смыслом.
- **Входы:** `empty`, `emptyIcon`, `emptyTitle`, `emptyDescription`; слот `ng-template[rtAsideEmpty]`.

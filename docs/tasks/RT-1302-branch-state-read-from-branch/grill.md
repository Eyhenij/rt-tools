# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `patterns/doc-style-write.md`. Отметить её
этому дереву нечем: токен двигает только свои записи, работа при этом наша.

## Своя копия чужой ветки отвечает и не говорит, что отстала

> Своя копия чужой ветки отвечает на любой вопрос и не сообщает, что отстала. Трижды за один
> заход состояние общей ветки выведено из файла на своей, отставшей на семь коммитов. Дважды —
> о том, что предписывает словарь проекта; третий раз — о том, подмела ли дерево та ветка,
> которая ввела запрет. Все три вывода неверны, один доехал до документа задачи и был назван
> владельцу как факт. Поймано ребейзом, то есть случайно.

Раздел паттерна о проверке факта говорит про код и про отказы и молчит о том, из какой ветки
читается файл, по которому судят.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки не заводится: чтение своего файла от чтения чужой ветки командой ничем не отличается,
и утверждение о чужой ветке машине не видно вовсе.

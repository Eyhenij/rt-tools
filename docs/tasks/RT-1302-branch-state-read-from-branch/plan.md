# Замысел

**Поведение:** не меняется — правится текст паттерна о том, как писать.

## Что делается

1. В раздел о проверке факта встаёт абзац: утверждение о состоянии другой ветки читается из
   неё, а не из своей копии, и называется команда чтения.
2. Там же — почему промах не виден: копия отвечает на любой вопрос и отставания не показывает.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

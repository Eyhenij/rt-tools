# Замысел

**Задача:** RT-303 · **Ветка:** RT-303-exact-versions
**Поведение:** не меняется — правится запись версий, состав зависимостей тот же

## След задачи

| Что     | Где                                   |
| ------- | ------------------------------------- |
| Спеки   | нет — работа не задевает домена       |
| Законы  | `docs/constitution/delivery.md`       |
| Правила | `.claude/skills/dependencies/`        |
| Код     | `package.json`, `pnpm-workspace.yaml` |

## Что считается сделанным

- В `package.json` не осталось ни одной записи с `^` или `~`.
- Лок-файл не изменился: записаны те версии, что стоят в нём сейчас.
- Привязка статьи в компаньоне правила не несёт вердикта «Не исполняется».

## Этапы

### 1. Точные номера в манифесте

- **Что делается:** 54 диапазона заменяются номерами из лок-файла.
- **Признак готовности:** поиск `"^` и `"~` по манифесту не находит ничего.
- **Чем проверяется:** `pnpm install --frozen-lockfile` — лок-файл принят без правки.

### 2. Привязка статьи правила

- **Что делается:** вердикт «Не исполняется» в компаньоне сменяется привязкой к манифесту.
- **Признак готовности:** привязка называет файл и то, чем держится.
- **Чем проверяется:** `npm run check:specs` — расхождений нет.

## Чего эта работа не делает

- Не поднимает версий: записывается то, что стоит в дереве сейчас.
- Не трогает подмен в рабочем пространстве: их смысл — «не ниже», и точный номер его отменяет.

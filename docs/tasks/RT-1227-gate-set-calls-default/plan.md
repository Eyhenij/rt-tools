## След задачи

Правило требует, чтобы набор гейта пуша не был уже набора конвейера, и молчит о том, чем этот
набор собирается. Собранный строками, он верен в день, когда его пишут: следующая редакция
пакета привозит проверку, которую он не зовёт, и не хватится её ничто — полнота судится по
именам шагов конвейера, а проверки, которой нет и в конвейере, там нет тоже.

| Что   | Где                                                      |
| ----- | -------------------------------------------------------- |
| Код   | `projects/agent-kit/assets/rules/git-workflow.github.md` |
| Спеки | `docs/specs/agent-kit/texts/`                            |

## Что считается сделанным

- Правило говорит, что набор дерева зовёт умолчание пакета, а не перечисляет его строками.
- Отсев из умолчания назван законным, но поимённым и с причиной у каждого рода.
- Случай с числами лежит в холодной части, а не при статье.

## Этапы

### 1. Статья о наборе, зовущем умолчание

- **Что делается:** при статье о наборе гейта встаёт статья о том, чем набор собирается.
- **Признак готовности:** статья называет отсев поимённым и требует причину.
- **Чем проверяется:** `node tools/check-file-size.mjs` — предел веса текста не взят.

### 2. Случай уезжает в холодную часть

- **Что делается:** числа разбора — шесть непрогоняемых проверок из четырнадцати строк — встают
  пунктом холодной части правила.
- **Признак готовности:** при статье чисел нет, в холодной части они есть.
- **Чем проверяется:** `node tools/check-prose-style.mjs` — слог сходится.

### 3. Пакет собран, разложен, сверен

- **Что делается:** сборка пакета, раскладка, сверка, привязка статьи в компаньоне.
- **Признак готовности:** разложенное сходится с пакетом, статей без адреса нет.
- **Чем проверяется:** `npm run agent-kit:check` и `npm run check:specs`.

## Чего эта работа не делает

- Не трогает набор гейта самого дерева: он свой в любом дереве, и переписывать его этой задачей
  нечем.
- Не заводит проверки на полноту набора: она уже есть и судит по именам шагов конвейера — этой
  правкой её граница не двигается.

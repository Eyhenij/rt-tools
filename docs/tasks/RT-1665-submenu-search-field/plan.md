## Что считается сделанным

- Поле поиска подменю нарисовано `mat-form-field` со значком и кнопкой очистки — тем же
  набором, что и поиск таблицы.
- Своих правил рамки, скругления и кегля у поля не осталось; форма пилюли задана ручкой
  оформления поля.
- Кнопка очистки видна при непустом запросе и очищает его.
- То же на узком экране.

## Этапы

### 1. Переезд разметки на готовое

- **Что делается:** обе раскладки меню рисуют поле связкой `mat-form-field` + `matInput` +
  значок + `rtui-clear-button`; свои правила стилей снимаются
- **Признак готовности:** тест находит поле готового и очищает запрос кнопкой
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit --testFile=projects/ui-kit/src/lib/ui-kit/side-menu`

### 2. Форма пилюли и кадры

- **Что делается:** скругление поля задаётся ручкой оформления; кадры витрины пересняты после осмотра
- **Признак готовности:** замер даёт полное скругление, кадры сходятся
- **Чем проверяется:** `pnpm run test:visual` и замер вычисленных значений

## Чего эта работа не делает

- Поиска по дереву меню целиком: отвергнуто словом владельца в первой задаче эпика.
- Выноса `rtui-clear-button` в публичный список пакета: внутри кита он берётся напрямую.

# Замысел

**Поведение:** не меняется — правится текст скила о переносимом слое правил.

## Что делается

1. В раздел о подъёме версии встают две команды: снимок прежней редакции ресурсов до установки
   и сверка статей замещённого раздела между двумя редакциями.
2. Там же — что строка вывода сверки означает и что с ней делают: статья переносится в
   надстройку руками.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

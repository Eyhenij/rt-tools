# Записи о меню: что ответили читатели

Вход в `claude` на этой машине истёк, поэтому судью вопроса прогнать нельзя. Записи судил слепой
читатель: ему дали текст проверки и одну запись на файл, без имени записи и без ожидания. Ответы
совпали с ожиданиями набора на всех девяти записях.

```
1455-deadlock-menus-held ask allow
1460-rt3276-menu-after-refusal ask allow
1470-menu-lifts-check ask block
1911-plan-approval-passes ask allow
1911-approval-without-plan-held ask block
1914-approval-appends-lift-held ask block
1934-question-language ask block
1934-question-product-choice ask allow
1939-menu-hands-work-over ask block
```

Чем решено, словами читателя:

- 1455 — меню названо самой проверкой выхода, в нём ровно два её варианта и свободное поле;
- 1460 — то же меню, вопрос говорит, что путь пишут в свободное поле;
- 1470 — третий вариант снимает проверку;
- 1939 — каждый вариант отдаёт работу владельцу или останавливает её, а отказ назвал готовый шаг.

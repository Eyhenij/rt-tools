## Что считается сделанным

- Отказ гарда ожидания снимается обоими действиями сразу: прочитанным состоянием отданной
  работы и взятой следующей; ход, где сделано только первое, отбивается снова.
- Страж выходов не выпускает ход, в котором ветка ушла вперёд удалённой ссылки, а открытой
  заявки при ней нет: работа сделана и не видна никому.
- Оба яруса закрыты сценариями, и ни один файл не перерос предел длины.

## Этапы

### 1. Отказ гарда ожидания требует обоих действий

- **Что делается:** гард ожидания перестаёт считать отказ снятым по одному прочитанному
  состоянию — судятся оба признака, и второй отказ называет недостающий.
- **Признак готовности:** ход, в котором прочитано только состояние отданной работы,
  отбивается; ход с взятой следующей задачей проходит.
- **Чем проверяется:** `bash projects/agent-kit/tests/waiting-turn-guard.test.sh` — «0 провалов»
  с новыми сценариями на обе стороны.

### 2. Неотданная работа не кончает ход

- **Что делается:** страж выходов сравнивает вершину ветки с удалённой ссылкой; ушедшая вперёд
  без открытой заявки ход не кончает, отказ называет число неотданных коммитов.
- **Признак готовности:** ярус стоит после признака отданной работы и молчит там, где ссылки
  нет вовсе или заявка открыта.
- **Чем проверяется:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — «0 провалов»;
  `node tools/check-file-size.mjs` — «длиннее предела 0».

### 3. Тексты и раскладка приведены

- **Что делается:** сценарии обоих гардов дописаны в спек, правило `turn-conduct` называет оба
  требования, раскладка переложена.
- **Признак готовности:** сверка спеков и сверка раскладки сходятся.
- **Чем проверяется:** `npm run check:specs` — расхождений нет; `pnpm run agent-kit:check` —
  «разложенное сходится с пакетом».

## Чего эта работа не делает

- Не переписывает признак работы стража на «работу по следу задачи»: у стража нет следа задачи
  под рукой, а файл при пределе в 500 строк стоит на 480 — это отдельная работа с делением.
- Не трогает чужие записи груза: их отмечает то дерево, которое их прислало.

## Решения по ходу

- **Список хостов прокси пускает все поддомены `githubcopilot.com`.** Страница GitHub называет
  только `api.githubcopilot.com`, а среда ревью на личном плане ходит на
  `api.individual.githubcopilot.com`: журнал сеанса и загрузка `git-proxy` идут туда. Без этого
  хоста задание падает на шаге настройки. Этап плана: 1.
- **Службу launchd ставит владелец, проверка идёт разовым запуском цикла.** Автоматический режим
  сессии не пустил `setup.sh` с причиной «Unauthorized Persistence». Образы, сеть и прокси
  подняты теми же командами по одной, без службы. Этап плана: 2.

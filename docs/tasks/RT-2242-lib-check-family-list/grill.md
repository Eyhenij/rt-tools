## Что уже есть в дереве

- Проверка расположения либ: `projects/agent-kit/assets/checks/check-lib-layers.mjs` с модулями
  `lib-common.mjs` и `lib-domains.mjs`. Семья бэкенда читается из ключа `apiFamily` одной строкой:
  `API_FAMILY = CONFIG.apiFamily`, обход `collectApiDomainLibs` идёт по одному каталогу.
- Утверждения о проверке лежат в описании домена `docs/specs/agent-kit/hooks/spec.md`, не в
  `checks/`: там статья «A check whose walk came back empty refuses; it does not answer zero» и
  сценарий SC-AK-1087 в `projects/agent-kit/tests/checks-lib-layers.test.sh`.
- Настройки дерева сливаются с умолчаниями функцией `mergeDeep`: список в дереве заменяет строку
  умолчания, ключ менять не нужно.
- Свободный номер сценария по всем ветвям — SC-AK-1131. Команда `spec:next-id` называет
  SC-AK-1000: она сравнивает номера как строки. Находка, в задачу не входит.

## Что уже говорят правила

- Правило `testing`: отрицательная проверка идёт в паре с положительной; проверка, чей обход пуст,
  отказывает, а не отвечает нулём.
- Правило `spec-driven-domain`: утверждение в описании домена, привязка в файле привязок, сценарий
  с номером, строка истории.

## Вопросы и ответы

Все шесть закрыты словом владельца и текстом предложения.

**Меняет ли поведение приложения** — нет, правится проверка пакета правил.
**Нужна ли правка закона или правила** — нет, только описание домена hooks.
**Одна задача или несколько** — одна: список семей, обход, вывод, описание и тест откатываются вместе.
**Что не входит** — ключ `apiFamily` дерева не меняется: вторая серверная семья в main ещё не
лежит; ошибку сортировки в `spec:next-id` эта задача не чинит.
**Что покажет, что задача закрыта** — набор `checks-lib-layers.test.sh` зелёный с новым сценарием,
`agent-kit:check` без расхождений, проверка в этом дереве по-прежнему называет 36 либ бэкенда.
**Образец** — статья и сценарий SC-AK-1087 о семьях фронта.

## Решения

- **Ключ `apiFamily` принимает строку и список** — строка читается как список из одного, дерево с
  одной семьёй ничего не меняет. Отклонено: новый ключ `apiFamilies` — две настройки об одном.
- **Вывод называет семьи бэкенда поимённо** — иначе пропущенная семья неотличима от пройденной.
- **Объявленная серверная семья без каталога отказом не судится** — умолчание пакета `api` стоит
  у деревьев без бэкенда, и отказ покраснел бы у них на ровном месте.

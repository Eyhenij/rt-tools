# Grill

## The owner request

> бери в работу изменения по остановке работ прямо сейчас, заводи новый эпик и бери в работу, эпик по над которым ты работал ранее пока откладываем

Третья задача эпика RT-2190. Слово владельца, под которым идёт эпик: «пока эпик не закрыт — агент
не имеет права самовольно останавливаться». О закрытии сессии владелец сказал в той же сессии: «ты
сам завершил прошлую сессию — это было незаконно».

## What the tree already has

- Запрет на инструмент закрытия разговора стоит в настройках одной машины: список запрещённых
  инструментов и хук рядом с настройками. В другие деревья с пакетом он не приезжает.
- Диспетчер событий пакета подписан на событие перед вызовом инструмента без сужения по имени и
  сам выбирает проверки по строке объявления в их заголовке: проверка на один инструмент
  объявляется именем инструмента.
- Образец проверки на один инструмент — `browser-guard-no-asking.sh`; образец отказа в форме JSON
  — `epic-stop-guard.sh`; общий хвост отказа — `deny-tail.sh`.
- Правило о ходе пакета после RT-2192 говорит об открытом эпике; о закрытии разговора в нём нет
  статьи. Разбор происшествия о самовольном закрытии сессии отправлен в приёмник 17.09.

## What the rules already say

- Правило `turn-conduct`: ход кончается четырьмя выходами; закрытие разговора среди них нет.
- Правило `agent-kit-source`: правка, сборка, установка файлов; у каждой проверки пакета свой
  набор сценариев и строка в описании.

## Questions and answers

Владелец ответил указанием на весь эпик; отдельных вопросов задача не открывает.

## Decisions

- **Поведение приложений не меняется** — закрыто разведкой: проверка пакета, её сценарии, статья.
- **Правки закона нет** — закрыто разведкой: статья ложится в правило `turn-conduct`.
- **Отказ всегда, без законной формы обхода** — закрыто словом владельца: сессию заканчивает
  только он; форма отказа — JSON с решением «deny», как у остальных проверок перед вызовом.
- **Имя инструмента читается с окончанием** — закрыто допущением: вызов может прийти под именем
  с префиксом поставщика; сравнивается хвост имени.
- **Признак закрытия** — проверка установлена в дереве, набор зелёный, статья с привязкой стоит,
  аудит описаний зелёный.

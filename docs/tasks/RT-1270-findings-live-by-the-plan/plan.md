# Замысел

**Поведение:** не меняется — правятся тексты слоя правил, кода за ними нет.

## Что делается

1. `patterns/task-flow-archive.md`, раздел находок: заголовок и первые абзацы переписываются —
   находки пишутся сразу в файл рядом с замыслом эпика, а не в папку задачи; там же говорится,
   что делать с находками, вернувшимися после снятия ветки.
2. Тот же раздел: абзац о том, что накопительный файл находок меряется длиной до дописи.
3. `patterns/task-flow-close.md`, список «Порядок переезда»: пункт о правке уже заведённого
   сценария на месте — номер прежний, текст новый, заголовок теста тем же коммитом.
4. Тот же паттерн, раздел об отдаче работы: абзац о границе готовности — непройденная по
   причине вне работы проверка называется, а не отменяет готовность.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `npm run check:specs`.

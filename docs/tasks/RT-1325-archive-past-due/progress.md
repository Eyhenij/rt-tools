# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 1 — снять перестоявшее
- **Сделано:** папка задачи заведена, замысел записан
- **Следующий шаг:** снять записи командой и прогнать проверку срока
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет
- **PR:** ещё не открыт

## Решения по ходу

- **Уборка идёт своей задачей, а не попутным коммитом в чужую ветку.** Записи лежат в главной
  ветке, поэтому в них упирается пуш каждой из ста пяти веток; попутный коммит смешал бы уборку
  с чужой темой в ста пяти заявках.

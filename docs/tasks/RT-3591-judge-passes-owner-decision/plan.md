## What counts as done

- Судья вопросов пускает вариант, которым владелец решает: одобрение плана, слияния, выпуска,
  новой рабочей копии, отложить задачу, отменить прежнее решение. Даже если решение меняет
  проверку: решает владелец, вариант только записывает решение.
- Пункт «держать» не советует больше ничего, кроме исполнения того, что требует проверка: совет
  «назвать отказанный шаг в меню» убран.
- Исключение стоит в самом пункте «держать» и в последней строке раздела, а не только в списке
  «пустить»: два пункта больше не противоречат друг другу.
- Вариант записывает решение, только если он называет решение и ключ задачи и больше ничего:
  «Одобряю план RT-N». Вариант «Одобряю план RT-N: снять проверку отметок» несёт действие и
  держится.
- Две записанные фикстуры: вопрос с вариантом «Одобряю план RT-N» для плана, который правит
  проверку, — судья-модель пускает; вариант одобрения с приписанным снятием проверки — держит.
- Вариант, который снимает, отключает или ослабляет проверку сам, без плана, судья держит, как
  раньше (SC-AK-1470 зелёный).
- Одобрение плана сообщением в чате засчитывается (SC-AK-1873 зелёный).

# Разбор просьбы

## Просьба владельца

> бера в работу пропозалы из свежих

Работа выведена из записи приёма #599: ресурс, место, повод и готовый текст правки названы в
её теле.

## Вопросы и ответы

**Сколько берём за этот заход?**
«Все семь задач подряд» — весь разбор свежих записей целиком. Эта задача в нём третья.

## Решения

- **Правятся обе формы обхода, а не одна названная** — их порог причины общий намеренно, и
  комментарий при признаке говорит это прямо: сделанные по-разному, они станут двумя разными
  обходами одного требования. Откатывать порознь их незачем — значит это одна задача.
- **Запрет подстановки записывается набором знаков, а не заглядыванием вперёд** — признак
  читает `grep -E`, а заглядывания вперёд в нём нет вовсе. Первый знак причины просто не
  бывает угловой скобкой.

## Что осталось невыясненным

- Считать ли обходом строку, у которой причина начинается с кавычки. Взято: не считать —
  кавычка в начале причины приходит из примера, а не из живого тела. Работу не держит.

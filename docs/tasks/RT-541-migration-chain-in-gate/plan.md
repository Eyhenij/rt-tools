## Что считается сделанным

- Ветка, тронувшая схему или миграции, пропуска проверки не получает: он становится отказом.
- Ветка, хранилища не трогавшая, ведёт себя как прежде — пропуск с прежним словом.
- Отказ называет, чем поднять базу, а не только то, что её нет.

## Этапы

### 1. Пропуск, ставший отказом на тронутом хранилище

- **Что делается:** проверка спрашивает у истории, тронула ли ветка схему или каталог миграций, и
  при пропуске по недоступной базе отвечает отказом, а не кодом пропуска.
- **Признак готовности:** без базы и с правкой схемы — ненулевой код; без базы и без правки —
  прежний код пропуска.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-schema-drift.test.sh` — все ok.

### 2. Статья правила и спека

- **Что делается:** статья в трёх редакциях правила выкатки, статья и сценарий в спеке проверок,
  привязка в компаньоне.
- **Признак готовности:** сценарий назван номером, привязка отвечает файлом и символом.
- **Чем проверяется:** `npm run check:specs` — расхождений нет.

### 3. Раскладка

- **Что делается:** раскладка пакета и сверка.
- **Признак готовности:** сверка молчит.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом.

## Чего эта работа не делает

- Не поднимает одноразовый контейнер сама: докер есть не у всякого дерева, а проверка, берущая
  порт без спроса, отбирает машину у того, кто её позвал.

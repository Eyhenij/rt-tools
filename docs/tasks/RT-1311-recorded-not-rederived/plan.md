# Замысел

**Поведение:** не меняется — правится текст паттерна о возвращении к работе.

## Что делается

1. В раздел «Чего не делать» встаёт пункт: записанное не выводится заново из кода и не подаётся
   находкой.
2. Пункт называет, чем это хуже лишнего вопроса и где искать запись раньше, чем выводить.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

# Grill

## The owner request

> окей, делай этот компонент в ui kit v2, и бери в работу задачи по тем проблемам что ты заводил
> ранее, давай пожалуйста закончим эти правки и изменения, этого очень ждут на проде

(Слово владельца 28.10.2026 в сессии VillaManager, задача VM-3125. Макет утверждён этим словом: Design System V2, страница AI Prompt Input, наборы AI Prompt Input и Usage Ring.)

## What the tree already has

- `rt-ai-chat` берёт поле переписки с людьми `rt-message-composer`: капсула, скрепка в поле, без модели, усилия, режима и расхода.
- Кольца расхода в ките нет. Значка микрофона в наборе значков кита нет.

## Questions and answers

- **Какой вид у поля.** Макет AI Prompt Input: одна рамка, текст сверху, ряд действий внутри снизу, скругление `radius/xl`.
- **Где подсказка об ошибках ассистента.** Слово владельца: «показывай "Ассистент может ошибаться." под или над композером».

## Decisions

- **Поле ввода ИИ-чата заведено своим компонентом `rt-ai-prompt-input` основного входа.** Слово владельца «делай этот компонент в ui kit v2». Поле переписки с людьми остаётся прежним.
- **Модель, усилие и режим кит показывает подписью и сообщает о нажатии.** Список моделей и усилий знает приложение, кит его не держит.
- **Голоса в поле нет.** В макете он выключен по умолчанию, а значка микрофона в ките нет.

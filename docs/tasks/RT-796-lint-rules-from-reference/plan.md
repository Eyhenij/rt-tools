# Замысел

**Задача:** RT-796 · **Ветка:** RT-796-lint-rules-from-reference
**Поведение:** не меняется — правка задевает слой проверок, а не то, что видит пользователь

## След задачи

| Что     | Где                                                  |
| ------- | ---------------------------------------------------- |
| Правила | `.claude/skills/typescript-conventions`              |
| Код     | `eslint.config.mjs`, `eslint/`, `tools/eslint-rules` |
| Стили   | `stylelint.config.js`, `tools/stylelint-rules`       |

## Что считается сделанным

- Свои правила дерева — те же двенадцать, что у образца, со своими спеками, и спеки зелёные.
- `sonarjs` подключён целиком на отказ, предел длины файла стоит, двухступенчатое приведение и
  обращение к глобалям окружения запрещены.
- Приставка селектора компонента и директивы проверяется.
- Стили приложений проверяются наравне со стилями пакетов.
- Пакет линтера объявлен зависимостью, а не подхватывается из хранилища по случайности.
- Отказы, которые новые правила нашли, сосчитаны и разложены по областям; владельцу названо, что
  из этого правится этой задачей, а что отдельной.

## Этапы

### 1. Свод правил и настройка

- **Что делается:** двенадцать своих правил со спеками, базовый конфиг, корневой конфиг по
  образцу, настройка stylelint и маска стилей, недостающие пакеты.
- **Готово, когда:** спеки правил зелёные, конфиг грузится, число активных правил на файл
  выросло, прогон по дереву даёт сосчитанный список отказов.

### 2. Разбор накопленного

- **Что делается:** отказы, найденные новыми правилами, разбираются по областям; решается, что
  чинится здесь, а что уезжает своими задачами.
- **Готово, когда:** гейт пуша зелёный, а всё, что не чинится этой веткой, стоит задачами в
  очереди работ.

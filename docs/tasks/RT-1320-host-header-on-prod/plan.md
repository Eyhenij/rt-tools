# Замысел

**Поведение:** не меняется — правится текст паттерна о стенде.

## Что делается

1. Строка о чужом заголовке хоста называет, кто на него отвечает отказом: дев-сервер, а не
   собранное приложение.
2. В раздел о прод-сборке дописывается абзац: поведение, зависящее от хоста, проверяется одним
   запросом с заданным заголовком, и прокси с подменой для этого не нужен.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `patterns/browser-verification-stand.md`.
Отметить её этому дереву нечем: токен двигает только свои записи, работа при этом наша.

## Строка о чужом заголовке хоста верна только для дев-сервера

> Строка о том, что сервер отдачи страниц отвечает отказом на чужой заголовок хоста, верна
> только для дев-сервера: прод-сборка берёт заголовок от клиента как есть. Прочитанная
> буквально, она заставляет поднимать прокси с подменой заголовка там, где хватает одного
> запроса, — лишний процесс, чьё поведение потом приходится отделять от проверяемого.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки не заводится: чей заголовок ушёл в запрос, ни одна команда дерева не сверяет.

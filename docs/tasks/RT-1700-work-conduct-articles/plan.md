# Замысел

**Задача:** RT-1700 · **Ветка:** RT-1700-work-conduct-articles
**Поведение:** не меняется — правится закон о ведении работы

## След задачи

| Что   | Где                                              |
| ----- | ------------------------------------------------ |
| Закон | `projects/agent-kit/assets/laws/work-conduct.md` |
| Спека | `docs/specs/agent-kit/work/`                     |

## Что считается сделанным

- В законе стоит статья о перечне работ, разрешённых вне эпика: он повторяет слово владельца, а
  не заменяет его.
- В законе стоит статья о назначении эпика: оно принадлежит рабочему дереву и объявляется в
  главной ветке прежде первой задачи.
- Обе статьи получили адреса, раскладка положила закон, сверка зелёная.

## Этапы

### 1. Две статьи закона

- **Что делается:** статьи в разделе о порядке работ; адреса в компаньоне закона.
- **Признак готовности:** раскладка кладёт закон, проверки спек и адресов зелёные.
- **Чем проверяется:** `pnpm run agent-kit:sync`, `agent-kit:check`, `node tools/check-specs.mjs`,
  `node tools/check-doc-paths.mjs`, тесты пакета.

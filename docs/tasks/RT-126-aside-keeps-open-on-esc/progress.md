## Решения по ходу

- **2026-08-19. Ветка остаётся локальной, отчёт не открывается.** Владелец сказал прямо: «Не пуш
  ветки, храни их только локально».
- **2026-08-19. Умолчание — Esc не закрывает.** Так стоит в самой просьбе владельца: «не
  закрывать по Esc». Прежнее поведение остаётся доступным настройкой открытия. Альтернатива —
  оставить умолчание прежним и завести выключатель — отвергнута: тогда просьба не исполнена
  нигде, кроме тех мест, которые кто-то перенастроит.
- **2026-08-19. Приём взят у второго кита.** Там шторка уже принимает настройку закрытия и
  подписывается на нажатия условно, отдавая пустой поток при запрете. Своё третье решение
  разошлось бы с ним молча.

## Что считается сделанным

- Стенд сквозного набора поднимается на каждом прогоне: переиспользования нет ни на одной машине.
- Форматтер на коммите получает пути изменённых файлов и чужих не трогает.
- Строка таблицы контракта, чья вторая ячейка — код отказа, процедурой не считается.
- Закрытый промах не переоткрывается, а не воспроизводящийся назван в записи прошлого.

## Этапы

### 1. Стенд поднимается на каждом прогоне

- **Что делается:** переиспользование поднятого стенда снимается вместе с доводом в комментарии.
- **Признак готовности:** подъём стенда идёт и на своей машине, то есть идут сборка и засев.
- **Чем проверяется:** `grep -n reuseExistingServer apps/message-bus-admin-e2e/playwright.config.ts`
  — значение `false` без условия.

### 2. Форматтер трогает только изменённые файлы

- **Что делается:** из вызова форматтера уходит точка — пути подставляет тот, кто его зовёт.
- **Признак готовности:** правка одного файла оставляет остальные нетронутыми.
- **Чем проверяется:** правка одного файла, коммит и `git status --short` — чужих файлов нет.

### 3. Мина в сверке контракта убрана

- **Что делается:** строка таблицы с кодом отказа во второй ячейке процедурой не считается.
- **Признак готовности:** спек, объявивший процедуры, не получает свою таблицу кодов прочитанной
  как список процедур.
- **Чем проверяется:** `node tools/check-specs.mjs` — сверка зелёная; сценарий на случай кода.

## Чего эта работа не делает

- Не трогает порядок проверок в наборе гейта пуша: сверка раскладки уже стоит первой.
- Не переписывает разделов контракта в спеках: мина убирается там, где лежит.
- Не заводит своего засева под переиспользуемый стенд: стенд поднимается сам, целиком.

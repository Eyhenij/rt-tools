# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 2 — чужая папка разбирается
- **Сделано:** задача заведена, ветка от свежей главной, папка собрана, разбор и замысел
  написаны
- **Следующий шаг:** собрать запись о состоявшемся из разбора просьбы и решения закрытой
  задачи, назвать её в указателе
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет
- **PR:** ещё не открыт

## Решения по ходу

- **Работа взята посреди ожидания чужого шага.** Две заявки эпика границы пакета ждут: одна —
  прогона и вливания, вторая — вливания первой. Ожидание работой не считается, а эта папка
  висит расхождением сверки с утра и названа просьбой владельца.

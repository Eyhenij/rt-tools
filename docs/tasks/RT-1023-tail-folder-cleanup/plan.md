- **Что делается:** разбор просьбы и решение по ходу закрытой задачи уезжают в описание
  прошлого одной записью, замысел удаляется, запись называется в указателе.
- **Признак готовности:** папки нет, запись есть, указатель её называет.
- **Чем проверяется:** `npm run check:docs` — код ноль: адрес записи существует, а указатель
  сошёлся с каталогом.

### 2. Своя папка разбирается и очередь сходится

- **Что делается:** папка этой работы разбирается тем же последним коммитом, что и чужая.
- **Признак готовности:** в дереве не осталось ни одной папки закрытой задачи.
- **Чем проверяется:** `npm run check:board` — ни строки о папке среди текущих.

# Замысел

**Задача:** RT-1113 · **Ветка:** RT-1113-free-port-for-cargo-fixtures
**Поведение:** не меняется — правятся наборы проверок пакета правил; `apps/**` и `libs/**` работа
не задевает.

## След задачи

Прогон краснеет по причине, которой в правке нет: рядом идёт второй прогон, назначенный числом
порт занят, сервер падает с отказом «адрес занят», и вместе с ним падают восемь проверок. Читается
это как поломка ветки — отчёт называет провалившиеся проверки, а настоящая причина лежит строкой
ниже, в чужом наборе.

| Что | Где                                           |
| --- | --------------------------------------------- |
| Код | `projects/agent-kit/tests/lib.sh`             |
| Код | `projects/agent-kit/tests/cargo-pull.test.sh` |
| Код | `projects/agent-kit/tests/cargo-mark.test.sh` |

## Что считается сделанным

- Ни один набор не назначает порт числом: все три фиктивных приёмника берут свободный у системы.
- Выбранный номер доезжает до проверки, которая к нему стучится.
- Два прогона, идущие одновременно, оба зелёные.

## Этапы

### 1. Приём выбора свободного порта в общей обвязке

- **Что делается:** в обвязку наборов встаёт ожидание файла с номером порта.
- **Признак готовности:** приём один на оба набора, второй копии счёта нет.
- **Чем проверяется:** `bash -n projects/agent-kit/tests/lib.sh` — синтаксис сходится.

### 2. Оба набора берут порт у системы

- **Что делается:** три числа уходят, серверы слушают нулевой порт и пишут выбранный в файл.
- **Признак готовности:** ни одного назначенного числом порта в наборах груза.
- **Чем проверяется:** `bash projects/agent-kit/tests/cargo-pull.test.sh` и
  `bash projects/agent-kit/tests/cargo-mark.test.sh` — оба зелёные.

### 3. Два прогона рядом

- **Что делается:** оба набора запускаются одновременно дважды.
- **Признак готовности:** все четыре прогона зелёные.
- **Чем проверяется:** одновременный запуск двух копий каждого набора — ноль провалов у всех.

## Чего эта работа не делает

- Не трогает портов приложений и стенда: там номер назван настройкой и виден снаружи.
- Не заводит своего разбора занятого порта: система выдаёт свободный сама.

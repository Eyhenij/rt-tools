# Grill

## The owner request

Эпик заведён не по отдельной просьбе, а по находке эпика RT-1976: спеки о роде стражей и проверок
назвали долг поимённо, и списки исключений остались лежать в наборе проб.

## What the tree already has

- Набор проб о роде стражей с тремя списками исключений: молчащие помощники — 13, стражи без
  объявленного отказа в пользу работы — 4, стражи без проб — 4.
- Спека `docs/specs/agent-kit/hooks/` — она говорит верно, расходится с ней пакет.
- Замысел эпика в `docs/plans/hooks-debt.md`.

## What the rules already say

- Помощник рядом со стражем события не объявляет и говорит о себе в первых строках.
- Страж отбивает в пользу работы: любая ошибка и любой неузнанный путь пропускают правку.
- У каждого стража есть свой набор проб: линтер их не читает, спеки не исполняют.

## Questions and answers

Вопросов владельцу не было: долг посчитан командой и назван поимённо.

## Decisions

- **Ветка эпика держит только замысел** — правки идут ветками задач, каждая от ветки эпика.

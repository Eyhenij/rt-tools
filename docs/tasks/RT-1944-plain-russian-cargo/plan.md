## What counts as done

- Отправка груза судит слог каждой записи и не увозит ту, у которой есть находки.
- Отбитая запись названа файлом, строкой и находкой; остальные записи пачки уезжают.
- Отбитая запись остаётся лежать на диске без отметки об отправке и уедет после починки.
- Разбор происшествия судится тем же вызовом, что и предложение.
- Дерево без разложенной проверки слога отправляет как прежде, и вывод это называет.
- Есть роль, пишущая запись груза обычным русским в готовую форму, и она не правит файлов.

### 2. Слог судится на дороге наружу

- **What is done:** отправка зовёт проверку слога на тексте каждой записи; отбитая не уезжает и

### 3. Дерево без проверки и разборы происшествий

- **Verified by:** `bash projects/agent-kit/tests/cargo-prose.test.sh` — пробы обеих дорог зелёные.

### 4. Роль, пишущая запись

  связи.
- **Readiness sign:** роль разложена в дерево, названа правилом и не имеет права писать файлы.
- **Verified by:** `pnpm run agent-kit:check` — разложенное сходится с пакетом.

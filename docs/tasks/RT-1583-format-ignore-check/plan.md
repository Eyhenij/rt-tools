## Что считается сделанным

- Файл с шапкой раскладки, вынутый из списка исключений форматтера, роняет проверку.
- Проверка стоит в наборе гейта пуша и молчит на нынешнем дереве.

## Этапы

### 1. Проверка

- **Что делается:** заводится `tools/check-format-ignore.mjs`: он обходит дерево, берёт файлы с
  шапкой раскладки и сверяет каждый с образцами `.prettierignore`.
- **Признак готовности:** на нынешнем дереве расхождений нет, а файл, вынутый из списка,
  называется поимённо.
- **Чем проверяется:** `node tools/check-format-ignore.mjs` — расхождений нет; тот же вызов
  после снятия строки из списка — расхождение названо.

### 2. Место в наборе и договорённость

- **Что делается:** проверка встаёт строкой в набор гейта пуша; в спек домена уходит статья со
  сценарием и привязкой.
- **Признак готовности:** гейт пуша гоняет её, сверка спеков молчит.
- **Чем проверяется:** `node tools/check-push-gate.mjs` — расхождений нет;
  `node tools/check-specs.mjs` — расхождений нет.

## Чего эта работа не делает

- Не чинит сам список: поимённый перечень разложенных проверок в нём уже стоит.
- Не трогает пакета: проверка своя дереву, потому что читает список именно этого форматтера.

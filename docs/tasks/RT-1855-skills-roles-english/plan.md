## Что считается сделанным

- Скилы, команды, роли, шаблоны, образцы, рабочие процессы и текст умолчаний пакета написаны
  по-английски; код сценариев и процессов не тронут, переведены проза, подсказки и комментарии.
- Кириллицы в этих каталогах не остаётся, кроме перечисленных поимённо исключений: имена
  состояний, ключи папки задачи, которые читают хуки, и образцы русских текстов владельцу.
- Набор пакета, спек текстов слоя и проверка спеков читают разделы скила, образца паттерна и
  спека домена под двумя именами.
- Раскладка сходится, набор пакета, спеки, сверка спеков и проверка слога зелены; замер записан
  в замысел эпика.

## Этапы

### 1. Проверки читают разделы под двумя именами

- **Что делается:** набор пакета и таблица наборов разделов принимают «When to use» у скила и
  образца паттерна; проверка спеков принимает английские имена обязательных разделов спека.
- **Признак готовности:** русские тексты проходят, как прежде; английский пробный — тоже.
- **Чем проверяется:** `bash projects/agent-kit/tests/rules-review.test.sh` и
  `bash projects/agent-kit/tests/checks-specs.test.sh` — без провалов.

### 2. Перевод

- **Что делается:** тридцать один файл переводится заходами по родам; ключи, которые читают
  хуки, остаются дословно.
- **Признак готовности:** в каждом файле число заголовков и оград равно прежнему; кириллица —
  только в исключениях.
- **Чем проверяется:** `node tools/check-prose-style.mjs` по каталогам — без замечаний;
  `node tools/check-glossary.mjs` — без находок.

### 3. Раскладка и замер

- **Что делается:** переведённое раскладывается; замер байтов записывается в замысел эпика.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `pnpm run agent-kit:sync && pnpm run agent-kit:check` — сходится;
  `bash projects/agent-kit/tests/run.sh` — без провалов.

## Что считается сделанным

- Статья об открытой карточке стоит в разделе о состояниях работы, в абзаце о том, откуда берётся
  следующая задача.
- Статья о расстановке веток эпика стоит за статьёй о том, что задачи эпика заводятся все разом.
- Строка над таблицей шести вопросов больше не отменяет вычет разведки, стоящий абзацем ниже.
- Раскладка положила правки, сверка зелёная, каждая новая статья получила адрес в компаньоне.

## Этапы

### 1. Правки источников

- **Что делается:** две статьи в правило, одна строка в паттерн.
- **Признак готовности:** текст стоит на местах, названных записями груза.
- **Чем проверяется:** `pnpm run agent-kit:check`.

### 2. Раскладка и адреса

- **Что делается:** `pnpm run agent-kit:sync`, адреса новым статьям в компаньоне.
- **Признак готовности:** раскладка не сообщает о статьях без адреса.
- **Чем проверяется:** тесты `@rt-tools/agent-kit`, `check-doc-paths`.

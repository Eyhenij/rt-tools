# Замысел

**Задача:** RT-1035 · **Ветка:** RT-1035-entry-cost-epic-close
**Поведение:** не меняется — работа вписывает итог в тексты об эпике и не трогает ни правил,
ни гардов, ни кода приложения.

## След задачи

| Что            | Где                            |
| -------------- | ------------------------------ |
| Замысел эпика  | `docs/plans/`                  |
| Карточка эпика | задача RT-961 в очереди работ  |
| Наблюдения     | `.claude/rt-kit/observations/` |
| Слой правил    | `.claude/skills/`              |

## Что считается сделанным

- Замысел эпика называет числа до и после и отвечает на свои открытые вопросы.
- Карточка эпика закрыта, и в очереди работ не осталось ни одной его открытой задачи.
- Все числа в тексте получены командами этого захода, а не взяты из отчётов работ.

## Этапы

### 1. Замер повторён теми же командами

- **Что делается:** считаются вес слоя правил, вход в работу, время хуков медианой пятнадцати
  прогонов и наблюдения по дням.
- **Признак готовности:** числа сняты на свободной машине.
- **Чем проверяется:** `find .claude/skills -type f -name '*.md' -exec cat {} + | wc -c` —
  печатает вес слоя правил одним числом.

### 2. Итог вписан в замысел эпика

- **Что делается:** в замысел уходит раздел о том, чем эпик кончился: числа до и после,
  ответы на открытые вопросы, что из состава сделано не так, как задумывалось.
- **Признак готовности:** ни один открытый вопрос замысла не остался без ответа.
- **Чем проверяется:** `npm run check:docs` — «расхождений нет» в выводе.

### 3. Карточка эпика закрыта

- **Что делается:** в карточку уходит итог одной сводкой, задача закрывается.
- **Признак готовности:** открытых задач эпика в очереди нет.
- **Чем проверяется:** `npm run check:board` — ни одной строки о задачах этого эпика.

## Чего эта работа не делает

- Не правит правил и гардов: эпик их уже поделил, и правка здесь была бы новой работой.
- Не трогает открытых задач соседнего эпика об обратной связи слоя правил.

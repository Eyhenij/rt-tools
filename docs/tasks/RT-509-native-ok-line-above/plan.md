## Что считается сделанным

- Признак не срабатывает в строке, над которой стоит комментарий с маркером.
- Признак срабатывает через строку после маркера — то есть маркер дальше следующей строки не
  достаёт.
- Правило и паттерн называют одну и ту же форму записи маркера.
- Разложенное в дереве совпадает с пакетом: `pnpm run agent-kit:check` зелёный.
- Предложение #466 закрыто ссылкой на эту задачу.

## Этапы

### 1. Проверка снимает строку под маркером

- **Что делается:** `withoutMarked` вычёркивает строку с маркером и следующую за ней.
- **Признак готовности:** файл с комментарием-маркером над нативным тегом расхождением не
  числится, а такой же файл без маркера — числится.
- **Чем проверяется:** прогон `node tools/check-reuse.mjs` на пробном файле в обеих формах.

### 2. Правило и паттерн говорят одно

- **Что делается:** в правиле форма маркера названа комментарием строкой выше или в самой
  строке; в паттерне сказано, почему атрибутом в разметке маркер не ставится.
- **Признак готовности:** обе формы, названные текстами, работают на проверке.
- **Чем проверяется:** чтение обоих текстов подряд и прогон этапа 1.

### 3. Правка доезжает до дерева

- **Что делается:** сборка пакета и раскладка.
- **Признак готовности:** разложенные копии несут новую сумму, `sync --check` молчит.
- **Чем проверяется:** `pnpm run agent-kit:sync`, затем `pnpm run agent-kit:check`.

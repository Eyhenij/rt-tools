# Замысел

**Задача:** RT-966 · **Ветка:** RT-966-rule-tails-move
**Поведение:** не меняется — работа переносит текст между файлами слоя правил, кода приложения
не трогает. Так сказал владелец в замысле эпика: содержание правил не переписывается.

## Что считается сделанным

- У каждого правила с холодной частью раздел «Ловушки» лежит в ней, а не в самом правиле.
- Правило называет свою холодную часть строкой в шапке — той же, что стоит в образце.
- Текст перенесён дословно: ни одна строка не переписана и не выброшена.
- Сверка раскладки и проверка адресов зелёные, наборы сценариев пакета тоже.

## Решения, принятые без владельца

Владелец отклонил вопросы, значит работа идёт по замыслу эпика и умолчаниям:

- **Переезжают правила, а не паттерны.** Механизм заведён под правило: холодная часть ищет
  родителя по имени и ложится третьим файлом рядом с ним. У двух самых крупных паттернов
  раздела «Ловушки» нет вовсе — им переезд ничего не даёт.
- **Хвост — это «Ловушки».** Раздел разборов происшествий у пакета пуст, а у этого дерева он
  уже переехал предыдущей задачей. «Чего из закона здесь нет» остаётся в правиле: он говорит о
  границах самого правила, и читают его вместе со статьями.
- **Предел длины назначает следующая задача.** Перенос идёт по составу разделов, а не по метке
  длины: так записано в замысле эпика.

## Этапы

### 1. Хвосты правил без видов переезжают

- **Что делается:** раздел «Ловушки» уезжает из `task-flow`, `doc-style`, `testing`,
  `spec-driven` и `styling-bem` в холодную часть при каждом; правило получает строку о ней.
- **Признак готовности:** горячая часть каждого правила кончается разделом «Паттерны»,
  холодная — несёт перенесённый текст дословно.
- **Чем проверяется:** `pnpm run agent-kit:sync` — «разложено файлов» без строки отказа, затем
  `pnpm run agent-kit:check`: «разложенное сходится с пакетом» означает «сошлось».

### 2. Хвост правила поставки переезжает по видам

- **Что делается:** у правила поставки три вида — своя холодная часть у каждого; сперва
  проверяется, что раскладка видов знает новый род ресурса.
- **Признак готовности:** дерево получает холодную часть того вида, который выбрало, и ни
  одного файла чужого вида.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit` — ноль упавших спек, включая
  новую на вид холодной части.

### 3. Ссылки и проверки

- **Что делается:** сверяются адреса, названные перенесённым текстом, и ссылки на разделы
  правил из паттернов и спеков.
- **Признак готовности:** проверки дерева не называют расхождений.
- **Чем проверяется:** `npm run agent-kit:hooks` — «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ» означает «сошлось».

## Чего эта работа не делает

- **Ни одна строка не переписывается.** Переносится дословно; замеченное по ходу расхождение
  становится задачей, а не правкой в этой ветке.
- **Предел длины не заводится.** Это следующая задача эпика, RT-967.
- **Паттерны не трогаются.** Их хвосты — отдельный разговор, и механизм под них не заведён.

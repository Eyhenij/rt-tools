# План

**Задача:** RT-2034 · **Ветка:** RT-2034-tree-checks
**Behaviour:** unchanged — правка проверок пакета правил, приложения не касается

## Что задача затрагивает

| Что      | Где                                                                                        |
| -------- | ------------------------------------------------------------------------------------------ |
| Описания | `docs/specs/agent-kit/checks/`, `docs/specs/agent-kit/exam/`                               |
| Код      | `projects/agent-kit/assets/checks/check-glossary.mjs`, `check-reuse.mjs`, `lib-common.mjs` |
| Гард     | `projects/agent-kit/assets/hooks/exam-guard.sh`                                            |
| Карта    | `projects/agent-kit/assets/defaults/gate-map.sh`                                           |

## Что считается сделанным

- Раздел запретов читается обеими формами: списком пар и таблицей из двух колонок.
- Гард экзамена ищет заглушённые вызовы по ключу, а не обходом списка на каждой записи.
- Набор признаков готового объявляется вместе с областью дерева, к которой относится.
- Сверка ярусов, не нашедшая ни одной либы, отказывает, а не печатает «расхождений нет».
- Карта проверок ведёт конвейер, описание образа, конфиг прокси и образец окружения прода в правило
  о выкатке.
- Чтение объявленных имён либ вместо вывода формулой заведено отдельной задачей.
- Записи груза, закрытые этой правкой, помечены в приёмнике сделанными.

## Этапы

### 1. Словарь читается таблицей

- **Что делается:** разбор раздела запретов принимает строку таблицы `| слева | справа |` наравне
  со списком пар; пропуск объявляется там, где раздела нет вовсе
- **Признак готовности:** дерево, набравшее запреты таблицей, судится, а не пропускается
- **Проверено:** `bash projects/agent-kit/tests/checks-glossary.test.sh` — пробы зелёные

### 2. Гард экзамена ищет по ключу

- **Что делается:** список заглушённых вызовов собирается словарём, обе проверки принадлежности
  идут обращением по ключу
- **Признак готовности:** разбор той же записи даёт тот же вердикт и укладывается в отведённое время
- **Проверено:** `bash projects/agent-kit/tests/exam-guard.test.sh` — пробы зелёные

### 3. Набор признаков объявляется с областью

- **Что делается:** объявление набора принимает область дерева — каталог или их список; приложение
  вне области из обхода выпадает по объявлению
- **Признак готовности:** дерево с двумя источниками вида судит каждое приложение своим набором
- **Проверено:** `bash projects/agent-kit/tests/checks-reuse.test.sh` — пробы зелёные

### 4. Сверка ярусов отказывает на пустом обходе

- **Что делается:** ненайденный корень либ, пустой список семей и ноль просмотренных либ становятся
  отказом, а не зелёным ответом
- **Признак готовности:** дерево без объявленных семей получает отказ с причиной
- **Проверено:** `bash projects/agent-kit/tests/checks-lib-layers.test.sh` — пробы зелёные

### 5. Карта проверок знает правило о выкатке

- **Что делается:** три ветки — конвейер, описание образа, конфиг прокси и образец окружения прода —
  ведут в правило о выкатке
- **Признак готовности:** правка конфига прокси требует правило о выкатке, а не о задачах и ветках
- **Проверено:** `bash projects/agent-kit/tests/skill-gate.test.sh` — пробы карты зелёные

### 6. Описания, установка файлов из пакета и пометки в приёмнике

- **Что делается:** сценарии в описания, пакет собирается и раскладывается, записи груза помечаются
- **Признак готовности:** аудит описаний и аудит установки молчат
- **Проверено:** `npm run check:specs` — расхождений нет

## Чего работа не делает

- Не меняет способ вывода имени либы: чтение объявленного вместо формулы — своя задача.
- Не трогает порядок сдачи: это задача #2038, и она ждёт слова владельца.

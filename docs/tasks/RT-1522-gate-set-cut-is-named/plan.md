## Что считается сделанным

- Закон называет, что проверка, снятая ради прохождения прогона, работу не подтверждает.
- Правило ведения хода называет, какого варианта в меню владельцу не бывает.
- Сверка расхождения профиля называет проверки, которые умолчание пакета зовёт, а набор дерева —
  нет, и отвечает ненулевым кодом.
- Сценарии заведены в спек домена и покрыты пробами.

## Этапы

### 1. Сверка

- **Что делается:** сверка расхождения профиля собирает набор гейта дважды — одним умолчанием и
  умолчанием с надстройкой — и называет вызовы, пропавшие во втором.
- **Признак готовности:** дерево, выкусившее проверку, получает строку и ненулевой код; дерево
  без надстройки набора — прежний вывод.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-profile-drift.test.sh` — все ok,
  провалов ноль.

### 2. Статьи

- **Что делается:** статья в закон проверяемости и статья в правило ведения хода.
- **Признак готовности:** обе стоят, пределы длины и веса выдержаны, слог зелёный.
- **Чем проверяется:** `node tools/check-file-size.mjs && npm run check:prose` — ни одной строки
  о правленных файлах.

### 3. Раскладка и закрытие

- **Что делается:** сценарии заведены в спек домена, правки разложены, тексты приведены, папка
  разобрана, заявка открыта черновиком.
- **Признак готовности:** раскладка сходится, спеки сверены, набор зелёный.
- **Чем проверяется:** `pnpm run agent-kit:check && npm run check:specs && npm run check:all` —
  ни одной новой строки расхождения.

## Чего эта работа не делает

- Гейт пуша не трогает: он зовёт то, что ему собрали, и о полноте набора не судит.
- Сверку функций профиля целиком не заводит: судится один набор — тот, которым закрывают пуш.

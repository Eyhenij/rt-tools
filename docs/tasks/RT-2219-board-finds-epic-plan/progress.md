## Решения по ходу

Записаны в разборе просьбы: работа идёт по заголовку задачи — её тело описывает другую работу.

- **Таблица эпика осталась с прежним чтением: её источник править нечем.** Источник
  `projects/agent-kit/assets/checks/epic-table.github.mjs` несёт шапку раскладки «rt-kit v0.26.0»,
  хотя это и есть источник пакета. Проверка источника правил отказывает в правке такого файла и
  указывает в ответе на тот же самый путь — выхода не называет. Шапка лежит там и в главной ветке,
  то есть промах старше этой работы. Таблица эпика от этого читает план с диска по-прежнему и на
  чужой ветке отвечает «карточка указывает в пустоту».

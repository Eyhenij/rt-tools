## Что считается сделанным

- У основы есть сигнал удачи, симметричный сигналу отказа: наполняется своим доводом, гаснет в
  начале каждой попытки, гасится отказом и гасит отказ.
- Панель правки после удачной записи остаётся открытой; панель создания закрывается, пока довод
  о закрытии не сказал обратного.
- Названный довод о закрытии решает в обе стороны.
- Витринный потребитель перестаёт передавать текст тоста и довод о закрытии и рисует удачу тем
  же сообщением, что и отказ, — видом удачи.

## Этапы

### 1. Сигнал удачи и управляемое закрытие

- **Что делается:** в основу добавляется сигнал удачи и довод, который его наполняет; оба
  сигнала гасятся в начале попытки и гасят друг друга; закрытие считается по названному доводу,
  а при его отсутствии — по режиму панели.
- **Признак готовности:** оба исхода читаются наследником одинаково, умолчание закрытия
  прежнее.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=projects/ui-kit-v2/src/lib/components/container/rt-route-aside.base.spec.ts` — все тесты зелёные.

### 2. Спека на семь сценариев

- **Что делается:** сценарии SC-UKV-66…72 закрываются проверками в спеке основы.
- **Признак готовности:** каждый сценарий назван в спеке своим номером.
- **Чем проверяется:** `npm run check:specs` — сценарии не значатся непокрытыми.

### 3. Витринный потребитель и вид удачи

- **Что делается:** витринная панель бронирования переходит на новый довод, перестаёт закрывать
  панель правки и рисует удачу тем же сообщением, что и отказ.
- **Признак готовности:** после удачной записи панель правки остаётся открытой и показывает
  сообщение видом удачи.
- **Чем проверяется:** `pnpm run test:stories:v2` — обход историй без отказов.

### 4. Вливание договорённости и общий набор

- **Что делается:** договорённость вливается в спек панели с прежними номерами, тексты
  приводятся к сделанному, гоняется набор.
- **Признак готовности:** каталога «предложено» в ветке нет, набор зелёный.
- **Чем проверяется:** `npm run check:specs` и `pnpm exec nx test @rt-tools/ui-kit-v2` —
  без расхождений и без упавших тестов.

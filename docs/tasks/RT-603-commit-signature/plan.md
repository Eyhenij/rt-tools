## Что считается сделанным

- Пуш ветки, где коммит назвался машинной записью, а почта в нём другая, отбит; отказ называет
  короткий хеш коммита, найденную почту и объявленную.
- Тот же пуш с верной почтой проходит.
- Коммит, назвавшийся не машинной записью, пуша не отбивает.
- Дерево, не назвавшее почты машинной записи, требования не получает.
- Проверка идёт без сети и судит только вклад ветки против вершины главной ветки у хостинга.
- Профиль этого дерева называет логин и почту машинной записи, и они совпадают с готовой
  строкой компаньона правила поставки.
- Компаньон правила поставки говорит, чем личность машинной записи подтверждается у хостинга.
- `pnpm exec nx test @rt-tools/agent-kit` и прогон сценариев гардов зелёные; каждое новое
  правило спека имеет строку в таблице привязки.

## Этапы

### 1. Умолчание профиля

- **Что делается:** пакет объявляет почту машинной записи отдельным свойством профиля рядом с
  учётной записью исполнителя; умолчание пустое.
- **Признак готовности:** свойство объявлено и описано тем же слогом, что соседние.
- **Чем проверяется:** чтение файла умолчаний; пустое значение оставляет гард молчаливым.

### 2. Гард читает подпись на пуше

- **Что делается:** гард поставки получает третью точку — вызов пуша; он читает автора каждого
  коммита вклада ветки и отбивает пуш при расхождении с объявленной почтой.
- **Признак готовности:** отказ называет коммит, обе почты и способ переписать подпись; пробный
  пуш и дерево без объявленной почты проходят молча.
- **Чем проверяется:** сценарии гардов поставки.

### 3. Сценарии

- **Что делается:** в набор гардов поставки добавляются случаи: чужая почта у машинного имени,
  верная почта, чужое имя, дерево без объявления, пробный пуш.
- **Признак готовности:** набор красный на сломанной строке гарда и зелёный на целом.
- **Чем проверяется:** `bash projects/agent-kit/tests/git-guards.test.sh`.

### 4. Спек домена

- **Что делается:** правила о подписи машинного коммита в спек, сценарии с новыми номерами,
  строки в таблице привязки.
- **Признак готовности:** правил без строк и строк без правил нет.
- **Чем проверяется:** `pnpm run check:docs` и чтение таблицы.

### 5. Дерево: профиль, компаньон, раскладка

- **Что делается:** профиль дерева называет логин и почту машинной записи; компаньон правила
  поставки получает способ подтвердить личность у хостинга; разложенные копии обновляются
  раскладкой.
- **Признак готовности:** `agent-kit sync --check` расхождений не находит, а пуш этой самой
  ветки проходит гард уже по объявленной почте.
- **Чем проверяется:** `pnpm run agent-kit:sync`, затем `pnpm run agent-kit:check`.

## Чего эта работа не делает

- История главной ветки не трогается: она уже переписана и отправлена принудительно.
- Подпись ключом (`commit.gpgsign`) не заводится — ключ лежит за менеджером паролей.
- Гард не судит коммит, назвавшийся не машинной записью: коммиты владельца, сделанные его
  руками, остаются его делом.
- Точка коммита не трогается: почта задаётся переменными самой команды, и разбор её из текста
  ловил бы ровно ту строку, которая и так видна глазами.

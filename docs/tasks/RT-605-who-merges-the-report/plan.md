## Этапы

### 1. Статья закона

- **Что делается:** в закон о поставке добавляется статья о том, чья рука вливает отчёт.
- **Признак готовности:** статья стоит рядом с прочими статьями о слиянии и не называет ни
  путей, ни имён дерева.
- **Чем проверяется:** чтение закона, `pnpm run check:docs`.

### 2. Правило и компаньон

- **Что делается:** правило поставки под GitHub получает ту же статью приёмом, компаньон —
  строку адреса.
- **Признак готовности:** число статей без адреса не выросло.
- **Чем проверяется:** `pnpm run agent-kit:sync`, затем `pnpm run agent-kit:check`.

# Разбор просьбы

## Просьба владельца

> исправь в приёмнике колонку "Вкакой версии" - нужно указывать только номер версии как ты это
> сделал в 0.18.0, предыдущие записи содержат тектс @rt-tools/agent-kit 0.17.0 - перепиши это

## Что уже есть в дереве

- Данные приёма переписаны тем же ходом: 282 записи из 319 несли имя пакета рядом с номером,
  теперь у всех колонка — один номер. Формы было две: `@rt-tools/agent-kit 0.17.0` у 171 записи
  и `rt-agent-kit@<номер>` у 111.
- Паттерн `cargo-triage-mark` — свой ресурс этого дерева, не пакетный — показывает версию в двух
  примерах вызова, и оба несут `rt-agent-kit@…`. Отсюда обе формы и приехали: исполнитель берёт
  строку из примера.
- Правило `cargo-triage` называет версию «строкой, которой дерево назвало выпуск», и формы не
  требует.
- Приём длину версии судит (предел 100 знаков), а форму — нет: он принимает любую строку.

## Решения

- **Правится пример в паттерне и статья в правиле, а не проверка приёма** — форма версии у
  каждого дерева своя: чужое дерево вправе называть выпуск по-своему, и запрет в приёме отбивал
  бы его записи.
- **Данные переписаны повторной отметкой в то же состояние** — приём принимает её, когда
  приезжает приложенное значение: ради исправления опечатки это и заведено.

## Что осталось невыясненным

- Форму версии у соседних деревьев никто не сводит: приём принимает любую строку, и разнобой
  вернётся, если сосед назовёт выпуск иначе.

# Разбор просьбы

## Просьба владельца

> Делай долги их приемника дальше, токен выпущу позже

Задача заведена работой RT-1839 по находке на узле: замысел эпика RT-733 говорил о выгрузке
дампа по расписанию, а на узле не было ни задания в расписании, ни каталога дампов. Долг
приёмника — покрыт тем же словом владельца.

## Что уже есть в дереве

- `deploy/dump.sh`: `save`, `load`, `probe`. Выгрузка кладёт файл с меткой времени в
  `/opt/message-bus/dumps`; число хранимых файлов ничем не ограничено.
- `.github/workflows/deploy.yml`: шаг «Sync deploy files» переносит `deploy/` на узел и
  следом ходит на узел по ключу — путь, которым файлы и команды доезжают до узла без руки
  человека на нём.
- `deploy/prune-images.sh`: образец «оставить N последних» с переменной `KEEP`.
- Спек узла: раздел «Что не входит» называет хранение копий дампа вне узла отдельной работой;
  о расписании выгрузки спек молчит.
- `docs/PROD.md`, раздел «Дамп»: снятие рукой, проба; о расписании ни слова.
- Пользователь `deploy` на узле зовёт compose без sudo — задание расписания от него же.

## Что уже сказано в правилах

- Проверяемость: утверждение о состоянии внешней службы пишется способом её спросить, а не
  снимком ответа.
- Поставка: на узел уезжает только то, из чего он поднимается; кода там нет.

## Вопросы и ответы

Вопросов владельцу нет: слово о долгах приёмника покрывает задачу, а способ доставки на узел
задан конвейером выкатки.

## Решения

- **Расписание едет на узел выкаткой, а не ставится рукой.** Файл задания лежит в `deploy/`,
  а шаг конвейера ставит его в расписание пользователя узла. Отвергнуто: строка в описании
  прода «поставьте руками» — снимается первым же переносом узла и ничем не проверяется.
- **Шаг конвейера не затирает чужие строки расписания.** Своя строка узнаётся по имени
  сценария: прежние строки без него остаются. Отвергнуто: `crontab <файл>` целиком — на узле
  могут стоять задания, которых дерево не знает.
- **Хранится семь последних дампов.** Дамп снимается раз в сутки; неделя — глубина, за которую
  промах в данных замечают, а семь файлов не съедают диск узла. Число — переменная сценария,
  как у чистки образов.
- **Дамп снимается ночью по времени узла.** Груз с деревьев приезжает днём; ночью выгрузка не
  спорит с приёмом за память.

## Что осталось невыясненным

- Копии дампа вне узла: спек называет это отдельной работой, здесь не делается.

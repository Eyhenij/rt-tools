## Что считается сделанным

- Сценарий, называющий человека в «Дано» и местоимением в «Тогда», из отбора обещаний не
  выпадает.
- Слова левой колонки словаря дерева судятся проверкой слога наравне с пакетными.
- Привязка номером строки и именем класса читается сверкой и судится на живость.
- Критик договорённости ищет недостижимое «Дано».

## Этапы

### 1. Признак обещания видит местоимение

- **Что делается:** тело сценария копится целиком, местоимение при глаголе восприятия
  засчитывается человеком, если человек назван в теле.
- **Признак готовности:** сценарий с местоимением и юнит-покрытием сверка называет.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-specs.test.sh` — «0 провалов».

### 2. Слова дерева в проверке слога

- **Что делается:** образцы читаются из `CONFIG.prose.glossaryBans` и ложатся в тот же набор.
- **Признак готовности:** слово дерева ловится, пакетные остаются, негодный образец проверку
  не роняет.
- **Чем проверяется:** `bash projects/agent-kit/tests/check-prose-style.test.sh` — «0 провалов».

### 3. Якорь номером строки и именем класса

- **Что делается:** образец привязки принимает число и имя с точкой, живость номера судится по
  длине файла.
- **Признак готовности:** обе привязки читаются, несходящейся не названа ни одна.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-specs.test.sh` — «0 провалов».

### 4. Критик договорённости проверяет «Дано»

- **Что делается:** в перечень того, что роль ищет, встаёт пункт о недостижимом «Дано».
- **Признак готовности:** пункт стоит в ресурсе и разложен в дерево.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет.

## Чего эта работа не делает

- Приёмника и его клиентов не касается: они заведены задачей RT-1779.

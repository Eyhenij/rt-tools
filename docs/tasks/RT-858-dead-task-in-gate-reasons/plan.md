- **Признак готовности:** ни одна строка настройки проверок не называет RT-427; очередь работ
  по номеру 857 отдаёт открытую задачу.

- **Что делается:** заводится блок предложения: причина исключения, называющая задачу, судится

  это закрывается надстройкой дерева.

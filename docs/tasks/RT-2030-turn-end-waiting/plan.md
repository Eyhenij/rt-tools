**Задача:** RT-2030 · **Ветка:** RT-2030-turn-end-waiting
**Behaviour:** unchanged — правка хуков и текстов слоя правил, приложения не касается

## Что задача затрагивает

| Что      | Где                                                                |
| -------- | ------------------------------------------------------------------ |
| Описания | `docs/specs/agent-kit/turn-guards/`, `docs/specs/agent-kit/rules/` |

| Правила  | `projects/agent-kit/assets/rules/turn-conduct.md`                  |
| Код      | `projects/agent-kit/assets/hooks/turn-exit-guard.sh`               |

## Что считается сделанным

- Ход, у которого последним действием стоит фоновый запуск проверок или чтение лога фоновой
  задачи, не выпускается.
- Ход, кончившийся обещанием сделать работу следующим ходом, не выпускается — даже когда команды
  в тексте нет.
- Ход, у которого последним действием стоит взятие задачи, не выпускается: взятие — подготовка.
- Ход, кончившийся ожиданием слова владельца при его же неотменённом указании работать без
  остановок, не выпускается.
- Вопрос владельцу считается законным концом хода только вместе с выводом команды об очереди
  работ.
- Из двух статей закона о проверяемости убран хвост «несогласие с проверкой — вопрос к владельцу».
- Каждое из шести мест покрыто пробой в наборе проверки конца хода.

## Этапы

### 1. Пробы на шесть новых родов последнего действия

- **Что делается:** в набор проб проверки конца хода добавляются шесть проб: фоновый запуск,
  чтение лога, обещание без команды, взятие задачи, ожидание слова при указании работать, вопрос
  владельцу при непустой очереди
- **Признак готовности:** все шесть проб красные — поведения ещё нет
- **Проверено:** `bash projects/agent-kit/tests/run.sh` — шесть провалов, названных поимённо

### 2. Проверка конца хода судит новые роды последнего действия

- **Что делается:** образец ожидания расширяется фоновым запуском и чтением лога; заводится
  признак обещания без команды и признак взятия задачи
- **Признак готовности:** шесть проб этапа 1 зелёные, прежние пробы набора не покраснели
- **Проверено:** `bash projects/agent-kit/tests/run.sh` — все наборы зелёные

### 3. Статьи правила ведения хода

- **Что делается:** три статьи — обещание следующим ходом, остановка при неотменённом указании
  работать, вопрос владельцу при непустой очереди — и привязки к ним
- **Признак готовности:** аудит описаний не называет ни статьи без адреса, ни адреса без статьи
- **Проверено:** `npm run check:specs` — расхождений нет

### 4. Хвост «вопрос к владельцу» убран из закона

- **Что делается:** из двух статей закона о проверяемости убирается конец, называющий остановку
  работы законным ходом при красной проверке
- **Признак готовности:** в законе не остаётся места, где несогласие с проверкой названо поводом
  остановить работу
- **Проверено:** `npm run check:specs` — расхождений нет

### 5. Установка файлов из пакета

- **Что делается:** пакет собирается и раскладывается
- **Признак готовности:** аудит установки молчит
- **Проверено:** `pnpm run agent-kit:check` — расхождений нет

## Чего работа не делает

- Не трогает порядок сдачи и черновик: это задача #2038 и она ждёт слова владельца.
- Не правит проверку начала работы и проверку утверждений: они о другом моменте хода.

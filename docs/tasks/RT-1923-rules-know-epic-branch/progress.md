# Ход работы

## Где стоим

Переписывается каждым заходом, а не дописывается.

- **State:** `этапы-кончились`
- **Этап:** все четыре закрыты
- **Сделано:** правило поставки и правило хода работы говорят о ветке эпика; схемы обоих правил
  перерисованы; паттерны поставки во всех трёх изданиях показывают команды нового порядка;
  компаньоны получили строки привязки; всё разложено.
- **Следующий шаг:** разобрать папку в запись архива и открыть заявку в ветку эпика.
- **Незакоммиченное:** нет.
- **Ждём владельца:** нет.
- **Заявка:** ещё не открыта.

## Решения по ходу

- **Правлены все три издания паттернов, а не только своё.** Правило говорит о ветке эпика для
  любого дерева; оставленное издание для другого хостинга давало бы готовую команду мимо правила.
- **Новые статьи помечены «не держится ничем пока».** Гард и сверка правятся задачами #1925 и
  #1926, а привязка обязана быть у каждой статьи: без пометки правило обещало бы проверку,
  которой нет.
- **Правило перевалило за предел веса, и доводы ужаты.** Довод о чужой учётной записи клиента
  ушёл в холодную часть целиком, ещё четыре сложены в строку. Утверждения не тронуты: сокращался
  довод, не требование.

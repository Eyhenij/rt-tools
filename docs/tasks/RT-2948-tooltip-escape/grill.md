# Grill

## The owner request

> Escape должен закрывать тултип, правка делается в самой библиотеке. Задержка показа 300 мс уже принята, её не трогать. Плейсмент по умолчанию: `top`, при `data-preset="material"` — `bottom`, его тоже не менять.

(Решение владельца 27.10.2026, передано сессией-постановщиком.)

## What the tree already has

- `RtTooltipDirective` прячет панель по `mouseleave`, `focusout`, `click`. Обработчика `keydown` нет.
- Спек `docs/specs/ui-kit-v2/component-additions/` держит то, что части кита берут у Material; задержка подсказки записана там же.

## What the rules already say

- Поведение кита пишется в спек домена `ui-kit-v2` вместе с кодом; сценарии связаны с тестами номером в имени теста.

## Questions and answers

Вопросов нет: поведение задано постановкой.

## Decisions

- **Escape гасится только при открытой подсказке** — иначе подсказка отбирала бы Escape у диалога и боковой панели выше по дереву. Rejected: глобальная подписка на `keydownEvents` оверлея — панель подсказки не получает фокус, клавиши приходят в хост.
- **Escape снимает и отложенный показ** — иначе панель появлялась бы через 300 мс после Escape. Событие при этом не гасится: панели на экране ещё нет.

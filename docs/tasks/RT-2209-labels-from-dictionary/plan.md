## What counts as done

- У админки есть свой словарь: ключ → текст, два набора, русский и английский.
- Подпись берётся из словаря вызовом, а не строкой в разметке; ключ один и тот же для обоих
  языков.
- Выбор языка переключает и подписи кита, и подписи админки — без перезагрузки страницы.
- Один экран переведён целиком как доказательство: на английском выборе в нём нет русских слов.
- Остальные экраны не тронуты: их переводят задачи RT-2210 и RT-2211.

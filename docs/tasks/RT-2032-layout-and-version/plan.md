# План

**Задача:** RT-2032 · **Ветка:** RT-2032-layout-and-version
**Behaviour:** unchanged — правка пакета правил и его проверок, приложения не касается

## Что задача затрагивает

| Что      | Где                                                                                                 |
| -------- | --------------------------------------------------------------------------------------------------- |
| Описания | `docs/specs/agent-kit/layout/`, `docs/specs/agent-kit/edit-place/`                                  |
| Правила  | `projects/agent-kit/assets/skills/agent-kit.md`                                                     |
| Код      | `projects/agent-kit/src/lib/plan.ts`, `commands.ts`, `hooks-map.ts`                                 |
| Гард     | `projects/agent-kit/assets/hooks/rule-source-guard.sh`                                              |
| Пробы    | `projects/agent-kit/src/lib/commands.spec.ts`, `projects/agent-kit/tests/rule-source-guard.test.sh` |

## Что считается сделанным

- Файл, чьё тело совпадает с пакетным, отказом не бывает: установка кладёт его заново и говорит,
  что разошлась шапка.
- Запись о вызове хука дописывается только тому хуку, который этой же установкой лёг на диск.
- Осмотр по доводу со снимком прежней редакции называет статьи, дописанные новой редакцией внутрь
  замещённых разделов.
- Отказ гарда места правки обещает слияние по разделам только там, где разделы есть, и судит цель
  правки, а не упоминание имени в тексте команды.
- Записи груза, закрытые этой правкой, помечены в приёмнике сделанными.

## Этапы

### 1. Разошедшаяся шапка — не правка руками

- **Что делается:** решение о файле получает шестой исход: тело совпало с пакетным, шапка с ним
  разошлась. Файл кладётся заново, отказом это не считается
- **Признак готовности:** установка не отказывает целиком из-за одной шапки, а слово «правлен
  руками» остаётся тому, у кого тело отличается
- **Проверено:** `pnpm exec nx test @rt-tools/agent-kit` — пробы установки зелёные

### 2. Запись о хуке — только вместе с самим хуком

- **Что делается:** запись в настройку агента дописывается тому хуку, который лёг на диск этой же
  установкой; обещание не возвращать снятое снимается из статьи, потому что списка снятого нет
- **Признак готовности:** хук, не названный в перечне взятого, записи не получает
- **Проверено:** `pnpm exec nx test @rt-tools/agent-kit` — пробы карты хуков зелёные

### 3. Осмотр сверяет замещённые разделы по снимку

- **Что делается:** команда осмотра принимает довод с путём снимка прежней редакции и печатает
  статьи, которые новая редакция дописала внутрь замещённого раздела
- **Признак готовности:** без довода поведение прежнее; с доводом названы ресурс, заголовок и
  зачин статьи
- **Проверено:** `pnpm exec nx test @rt-tools/agent-kit` — пробы осмотра зелёные

### 4. Отказ гарда места правки

- **Что делается:** обещание слияния по разделам остаётся ресурсу, у которого разделы есть; у
  остального отказ говорит прямо, что переопределения под этот род ресурса нет. Цель правки
  берётся из разбора команды, а не поиском имени по её тексту
- **Признак готовности:** команда, правящая свой файл и упоминающая разложенный строкой, проходит
- **Проверено:** `bash projects/agent-kit/tests/rule-source-guard.test.sh` — пробы зелёные

### 5. Статьи правила, описания и пометки в приёмнике

- **Что делается:** статьи правила установки и описания обеих областей приводятся к сделанному,
  четыре записи груза помечаются сделанными
- **Признак готовности:** аудит описаний молчит, записи стоят в состоянии «сделано»
- **Проверено:** `npm run check:specs` — расхождений нет

## Чего работа не делает

- Не трогает порядок сдачи и черновик: это задача #2038, и она ждёт слова владельца.
- Не правит проверку словаря: задача #2034.
- Не заводит списка снятого деревом: обещание снимается, а не исполняется.

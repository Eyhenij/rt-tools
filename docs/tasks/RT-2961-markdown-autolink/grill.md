## What the tree already has

- Разборщик строки `projects/ui-kit-v2/src/lib/util/markdown-inline.ts` делает курсив из любой пары
  `_`. Имя поля `booking_source_id` в ответе теряет подчёркивания, половина слова идёт курсивом.
- Ссылкой становится только `[текст](адрес)`. Голый адрес в ответе остаётся текстом.

## Questions and answers

- **Что делать с подчёркиванием внутри слова.** Задача RT-2961: знак остаётся знаком.
- **Какие голые адреса становятся ссылкой.** `http://` и `https://`, как у разметки ссылки.

## Decisions

- **Подчёркивание открывает и закрывает разметку только на краю слова.** Так поступает CommonMark.
  Звёздочка внутри слова работает как раньше.
- **Точка, запятая и закрывающая скобка после адреса остаются текстом.** Скобка с парой внутри
  адреса остаётся в адресе.

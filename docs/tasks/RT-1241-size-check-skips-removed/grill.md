# Разбор просьбы

Запись груза из приёма, своё дерево.

- **место:** чтение файла, там, где считаются строки
- **повод:** файл, снятый из рабочего дерева и ещё не проиндексированный, проверка читает и
  падает трассировкой Node — `ENOENT` из `readFileSync`. Обход дерева она делает системой
  контроля версий, а та показывает снятый файл до индексации удаления. Со стороны это выглядит
  сломанной проверкой, а не незакоммиченным сносом: за один заход это отняло ход.
- **ближайшее:** строка чтения в счётчике строк.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

# Замысел

**Поведение:** не меняется — предмет правки внутренний: проверка перестаёт падать трассировкой там, где прежде падала, и ни одного отказа не заводит и не снимает.

Проверка длины обходит дерево системой контроля версий, а та знает и о файле, который из
рабочего дерева уже снят, но снос ещё не проиндексирован. Читать такой файл нечем, и проверка
падает трассировкой вместо своего отказа.

## Этапы

1. Отбор судимого отсеивает пути, которых в рабочем дереве нет: файл, который нельзя прочитать,
   проверка не считает. Место — там же, где спрашивается дерево, а не в каждом счётчике порознь:
   счётчиков два, и охрана при каждом разошлась бы.
2. Сценарий в наборе проверки: снятый из рабочего дерева файл не роняет прогон.
3. Раскладка, сверка, сценарии, коммит, запись описания прошлого.

## Границы

Строка списка известного на снятый файл остаётся отказом «строка устарела» — это другой случай
и другой ответ.

# Grill

## The owner request

Разбор всего эпика лежит в записи архива задачи RT-3152. Карточка задачи: человек забывает отправлять
данные, поэтому приёмник видит приложения неровно. Готово, когда на дереве с приёмником данные приходят
без команды, без адреса и токена запрос не уходит, а гард при выключенной сети не задерживается.

Слова владельца: «поменяй спеку и гарды, пусть отправляют аналитику сами + агент в конце каждой
сессии», «Только числа (Recommended)».

## Decisions

- **Уходит только строка дня.** Разборы, предложения и сводка по-прежнему уходят командой человека.
- **Имена ресурсов отсекает отправитель.** Приёмник судит имя только по форме, поэтому ключ строится
  из имён пакета, а своё пишется постоянным словом `own`.
- **Учёт итогов лежит в общем каталоге git.** Иначе две копии посчитают одни PR дважды.

# Замысел

**Задача:** RT-967 · **Ветка:** RT-967-rule-size-limit
**Поведение:** не меняется — работа задевает проверку дерева и настройку, кода приложения не
трогает. Так сказано в замысле эпика: он о цене входа в работу, а не о продукте.

## Что считается сделанным

- У текстов слоя правил свой предел длины, заметно ниже предела кода.
- Проверка знает оба предела и в каждой строке отказа называет тот, по которому судила файл.
- Накопленное сверх нового предела стоит в перечне долгом поимённо, а не спрятано поднятием
  границы; сводка проверки называет его числом.
- Правило текстов говорит про два предела, а не про один.

## Решения, принятые без владельца

Владелец отклонил вопросы разведки на прошлой задаче, значит работа идёт по замыслу эпика:

- **Предел текстов слоя правил — 300 строк.** Это половина предела кода и вдвое меньше самого
  длинного нынешнего текста: деление наступает, пока текст ещё читается целиком. Под него
  сразу не влезают одиннадцать файлов — они уходят в долг, а не отменяют число.
- **Накопленное уходит в долг, а не в принятое.** Принятое означает «так и останется»; здесь
  каждый файл делится своей задачей, и перечень должен убывать.

## Этапы

### 1. Предел становится парой чисел

- **Что делается:** настройка объявляет второе число — предел текстов слоя правил — и говорит,
  по какому признаку файл попадает под него; проверка судит каждым своим.
- **Признак готовности:** отказ проверки называет предел, по которому судил файл.
- **Чем проверяется:** `node tools/check-file-size.mjs` — «новых нет» означает «сошлось».

### 2. Накопленное встаёт долгом

- **Что делается:** файлы длиннее нового предела перечисляются долгом с числом строк.
- **Признак готовности:** сводка проверки называет число долгов, и оно совпадает с перечнем.
- **Чем проверяется:** `node tools/check-file-size.mjs --baseline` против перечня.

### 3. Правило и спек говорят про два предела

- **Что делается:** правило текстов и спек домена проверок называют оба числа и признак, по
  которому файл судится тем или другим.
- **Признак готовности:** сверка спеков не называет расхождений.
- **Чем проверяется:** `npm run check:specs` — код возврата ноль означает «сошлось».

## Чего эта работа не делает

- **Предел кода и стилей не двигается.** Он остаётся прежним.
- **Ни один текст не делится.** Деление накопленного — своя работа на каждый файл; эта ставит
  число и называет долг.

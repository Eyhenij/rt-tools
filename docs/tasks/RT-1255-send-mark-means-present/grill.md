# Разбор просьбы

Две записи груза из приёма, своё дерево, об одном предмете — как читается нуль принятых.

## Первая: отправитель груза

- **место:** проставление отметки об отправке после ответа приёма
- **повод:** отметка ставится по числу принятых записей, а приём отвечает двумя числами —
  сколько принято и сколько уже лежало. Запись, которая в приёме есть, отдаёт «принято 0», и
  отправитель читает это как «не уехало». Файл остаётся без отметки навсегда: он уже там, и
  принятым не станет больше никогда.
- **чем это стоит:** гард предложений судит конец хода по отметкам в файлах. Файл без отметки
  отбивает ход у каждого следующего захода, тот отправляет груз заново, получает тот же ответ и
  снова остаётся без отметки. Круг не размыкается ничем, кроме правки руками.
- **готовый текст:** «Отметка об отправке говорит, что запись в приёме есть, а не что её туда
  положил этот вызов.»

## Вторая: правило разбора груза

- **место:** раздел о том, чем груз отправляется
- **повод:** правило говорит, что отправка пишет отметки в файлы предложений и делает дерево
  грязным. Случая, когда отправка прошла, а дерево осталось чистым, оно не называет — и
  исполнитель читает чистое дерево как «отправка не сработала», хотя груз доехал.
- **готовый текст:** «Чистое дерево после отправки значит, что весь груз в приёме уже лежал.
  Отметок в этом ходе не появилось, потому что ставить их было не на что.»

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

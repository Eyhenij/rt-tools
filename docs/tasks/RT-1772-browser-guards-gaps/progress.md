- Осталось: отметить записи приёма починенными, разобрать папку, открыть заявку черновиком.

## Решения по ходу

- **Три этапа из пяти пришли на уже закрытое.** Записи приёма приехали до выпуска 0.24.0, а
  правки по ним доехали вместе с ним. Проверено чтением самих ресурсов: гард чужих драйверов
  судит текст запускаемого файла, помощник профиля говорит о своей ненастроенности один раз за
  заход, а правило проверки в браузере уже несёт статьи об отказе выбора, о замере до показа и о
  подставленном заголовке арендатора. Задача заводилась по записи, а не по дереву, — отсюда и
  разрыв.
- **Каталоги спек из-под суда не выводятся.** Присланный код правки пропускал файлы из `e2e`,
  `tests` и `__tests__`. Гард, обходимый переносом скрипта в каталог с таким именем, стоит
  дешевле своей строки, а прогон сквозных спек проходит мимо него и так: его команда не называет
  ни интерпретатора, ни файла. Из присланного взято другое — глаголы вождения без имени движка
  перед точкой.
- **У правила проверки в браузере закрыта и четвёртая запись, тремя статьями замысла не
  названная.** Она про тот же файл и стоит в перечне записей этой задачи; отдельной веткой на
  тот же ресурс она стоила бы дороже.
- **Спек браузерных гардов дописан не только по правке.** Гард свежести выбора стоял в пакете с
  самого начала, а спек о нём молчал вовсе: без статьи о свежести статья о канале отказа висела
  бы ни на чём.

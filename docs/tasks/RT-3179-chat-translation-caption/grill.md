# Grill

## The owner request

Передано сессией приложения 09.11.2026, текст задачи:

> Приложение переводит сообщения переписки на язык читателя. В `rt-chat` 0.42.0 у сообщения нет
> подписи перевода и нет кнопки, которая возвращает перевод после показа оригинала.
>
> - У сообщения есть необязательная подпись перевода рядом с временем, например «Переведено · 12:58».
>   Текст подписи даёт приложение.
> - Ответ, ушедший без перевода, получает ту же подпись другим текстом, например «Без перевода · 13:02».
> - Под сообщением, показанным в оригинале, стоит кнопка «Показать перевод». Нажатие отдаётся
>   приложению событием.
> - Пункт «Показать оригинал» приложение кладёт в меню сообщения само, через `rtChatMessageActions`.
> - История в сторибуке: переведённое сообщение, оригинал с кнопкой, ответ без перевода; светлая и
>   тёмная тема, виды `messenger` и обычный.

Порядок от той же сессии: макет, код, сторибук с наложением на кадр, показ владельцу. Пуш, PR и
выпуск идут только после слова владельца «одобряю». Три правки кита выходят одним выпуском.

12.11.2026 владелец в этой сессии: «подтяни свежий main и продолжай работу».

## Decisions

- **Подпись перевода — отдельное поле реплики, а не часть `dateLabel`** — время остаётся в формате
  кита, приложение даёт только слово. Отвергнуто: писать «Переведено · 12:58» в `dateLabel`, тогда
  приложение само форматирует время.
- **Кнопка — признак реплики и выход чата, а не слот** — кнопка у всех одна и стоит в одном месте.
  Отвергнуто: слот шаблона под текстом, он заставляет каждое приложение рисовать кнопку заново.
- **Работа идёт вне эпика** — слово владельца передано сессией приложения, записано в таблице
  назначений копии.

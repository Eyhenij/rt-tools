# Grill

## The owner request

> заведи правила что любая правка ui kit сначала должны быть сделана на макетах figma, затем нужно показать человеку и получать его аппрув, после аппрува нужно внести изменения в код и показать все состояния в storybook, ui в браузере должен соотвествовать макетам pixel perfect, совпадение должно быть 100%, после того как storybook будет готов и все состяния пропаботаны в нём - ты обязан показать результат человеку и получить его аппрув, только после этого пуш пр и публикация нового кита

> заведи гейт на это правило

Сообщения владельца 29.10.2026, во время работы над RT-2982 и RT-2987.

## What the tree already has

- Пакет правил несёт закон и правило `mockups` (утверждённый макет — источник правды, код пишется после его одобрения), но в этом дереве они выключены: `.claude/rt-kit.json`, `has` без `mockups`.
- Правило `mockups` само говорит, что ничто не проверяет совпадение с макетом и одобрение владельца.
- Гард пуша запускает набор `rt_push_checks` из `.claude/rt-kit/project.sh` — это место для своей проверки на пуш. Для открытия PR и запуска выпуска (`gh workflow run publish-ui-kit-v2.yml`, `publish.yml`) места нет — нужен свой гард.
- Ни один гард не читает одобрение владельца: оно живёт только в прозе.
- Своих инструментов Figma в дереве нет; у сессии есть подключение Figma.

## What the rules already say

Закон `mockups` из пакета говорит то же, что первая половина просьбы. Вторая половина — показ витрины и одобрение перед пушем, PR и выпуском — нигде не записана.

## Decisions

- **Одобрение — дословный ответ владельца, записанный исполнителем; гард сверяет цитату с сообщениями владельца в разговорах сессий этого дерева.** Так велит ответ владельца. Отказ владельца не записывается: исполнитель правит и показывает снова.
- **Правкой кита считается всё видимое:** шаблоны, стили, токены и код компонентов в `projects/ui-kit*/src`. Спеки, тесты, истории и описания витрины, эталоны кадров идут без макета.
- **RT-2987 проходит через Figma задним числом; RT-2982 вид не меняет и идёт как есть.**

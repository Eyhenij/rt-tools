# Grill

## The owner request

Пришло из сессии эпика мессенджеров приложения-потребителя, 23.10.2026, дословно:

> Остались две правки из моих прошлых сообщений, отчёт о них молчит. 1) Chat Bubble в Figma шириной от ленты, а не FIXED 320: на 375 пузыри вылезают из колонки. 2) У Chat Bubble статус «не доставлено» в коде и в Figma-варианте Status: значок предупреждения и подпись «Не доставлено» под текстом, без кнопки повтора; подпись из подписей приложения. Сделай обе одной заявкой. 0.32.0 пока не выпускай: выпустим один раз со знаком и новым статусом, чтобы владельцу хватило одного слова.

Пояснение из прошлого сообщения той же сессии:

> у Chat Bubble нужен статус «не доставлено» — ответ записан, но служба гостя его не приняла. Под текстом реплики значок предупреждения и подпись «Не доставлено», кнопки повтора нет: повтор записал бы ответ второй раз. Это отдельное значение рядом с sent/read/sending/failed/deleted, и в коде, и в Figma-варианте Status. Подпись кит берёт из подписей приложения, как остальные статусы.

## What the tree already has

- `ERtChatMessageStatus` в `rt-chat.model.ts`: `sending`, `sent`, `read`, `failed`. Удалённая реплика — флаг `deleted`, не статус.
- Шаблон `rt-chat.component.html`: `failed` рисует значок `exclamation-circle` и кнопку повтора `chat-message-retry`; остальные статусы — значок `clock` или `check-double`.
- Подписи статусов — ключи `rtKit.chatStatus*` (`rt-kit-labels.en.ts`, модель `rt-kit-labels.model.ts`), пайп `rtChatStatusLabel` отдаёт ключ для `aria-label`.
- Ширина строки сообщения в коде: `max-width: min(80%, 480px)`. В Figma пузыри ленты «Chat» стоят FIXED 320.

## What the rules already say

- Компонент кита, его описание (`CONTEXT.md`, `Overview.mdx`), описание пакета, витрина и снимки идут вместе.
- Подписи кита — в наборе `rtKit`, приложение может их переопределить.

## Questions and answers

**Брать RT-2938 — статус «не доставлено» в коде и Figma и пузыри Chat шириной от ленты — работой вне эпика?** (23.10.2026)
Выбрано из вариантов «Да, бери» / «Только код, без Figma» / «Не брать»: «Да, бери».

Остальное просьба называет целиком:

- Вопрос закрыт допущением: имя значения — `undelivered`, в ряд с `sending`/`sent`/`read`/`failed`.
- Вопрос закрыт допущением: подпись видна текстом рядом со значком (в отличие от остальных статусов, где текст только для скринридера), ключ `rtKit.chatStatusUndelivered`.
- Вопрос закрыт допущением: значок — `exclamation-circle`, тот же, что у `failed`; цвет — предупреждения.

## Decisions

- **Новое значение перечисления, не флаг** — так сказано в просьбе: «отдельное значение рядом с sent/read/sending/failed». Отклонено: флаг у модели — статус и флаг могли бы противоречить друг другу.
- **Кнопки повтора нет** — повтор записал бы ответ второй раз.
- **Выпуска пакета в этой работе нет** — просьба: выпустить один раз вместе со знаком канала.

## What is left unclear

- Правка дизайн-системы Figma в прошлом ходе отбита проверкой авто-режима; без слова владельца в этой сессии часть Figma может остаться несделанной.

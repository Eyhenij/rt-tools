# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `patterns/git-workflow-secrets.md`.

- **место:** новым разделом сразу после «Когда брать»
- **повод:** паттерн загрузили под работу с четырьмя секретами выкатки и отдельным ключом
  доступа к узлу — и не нашли о них ни строки: он про ключи внешних служб, которые заводит
  владелец.
- **готовый текст:** «Секрет выкатки — не ключ внешней службы. Ключи из этого паттерна живут в
  хранилище или в составе прода, и читает их приложение. Секреты выкатки — ключ доступа к узлу,
  пароль реестра, адрес и токен приёма — приложением не читаются вовсе: их читает конвейер,
  лежат они в настройках репозитория, и хранилище о них не знает.»

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

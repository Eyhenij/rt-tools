# Grill

## The owner request

> Одна задача на четыре находки (Recommended)

Ответ владельца в меню на вопрос о четырёх находках после выпуска `agent-kit` 0.35.0. Варианты были:
«Одна задача на четыре находки» и «Пока ничего». Обновление остальных приложений остаётся за владельцем.

## What the tree already has

1. Карта проверки правил (`.claude/rt-kit/gate-map.sh`) отвечает пустотой на любой путь под
   `.claude/worktrees/<копия>/`: ветка `*/.claude/*` стоит выше остальных, а путь приходит абсолютным.
2. Правило `task-flow` занимает 23 958 символов из 24 000.
3. `tools/release-metric.mjs` пишет «**Метрика выпуска:** нет. <причина>», и причина идёт со строчной
   буквы после точки.
4. Проверка конца эпика (`epic-stop-guard.sh`) снимает отказ ответом владельца только по номеру задачи
   в команде, а у `task:new` номера ещё нет.

## Questions and answers

Вопросов нет: владелец выбрал одну задачу на четыре находки.

## Decisions

- **Одна задача, вне эпика.** Слово владельца.

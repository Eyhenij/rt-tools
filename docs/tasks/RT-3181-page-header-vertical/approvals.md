# Одобрения

- **Макет:** «Одобряю» — https://www.figma.com/design/vyV42sJXccfKNG8yFSCpSL/Design-System-V2?node-id=7626-734
- **Совпадение:** 250 из 250 чисел
- **Витрина:** «Одобряю»

Числа сняты заново после сверки «сверь макеты с вьюхой в сторибук», с маленькими кнопками и полями:
шапка в одну и две строки, с чатом, вкладки, рейка с подвалом, телефон. Витрину после сверки
владелец одобрил тем же словом: «Одобряю».

Тот же ответ относится к режиму вкладок «Ещё»: https://www.figma.com/design/vyV42sJXccfKNG8yFSCpSL/Design-System-V2?node-id=7658-534

# Grill

## The owner request

> выпусти новую версию кита и отметь в приёмнике какие задачи включены в новую версию, затем бери
> новый эпик - исправь все замечания и предложения из приёмника которые ещё не обработаны

## What the tree already has

- Приёмник спрошен командой: `new` — 0 предложений и 1 разбор (свой, об этой сессии), `in_work`
  — 0, карантин — 0. Необработанного чужого груза нет.
- Карточка RT-2123 «Восемь находок обзора правил после RT-2079 не применены»: четыре правки этого
  дерева и четыре предложения в пакет. Предложения уходят в приёмник только по слову владельца
  (правило `task-flow`: находки обзора ждут владельца); правки дерева — обычная работа.
- `.claude/skills/dependencies/implementation.md` — файл привязок правила зависимостей: вшитое
  число переопределений (21: 16 полов, 5 потолков) в двух строках; о границах, которых не
  объявляет ни один peer-диапазон, ни слова; в «What this is checked by» нет визуальных проверок.
- `.claude/skills/ui-component-tests-visual/SKILL.md` — паттерн визуальных проверок, свой у
  дерева; в «Traps» нет ловушек о подъёме браузера и генератора данных.
- `.claude/rt-kit/overrides/pitfalls/task-flow.md` — надстройка ловушек ведения работы, 57 строк.

## What the rules already say

- `task-flow`: находки обзора закрытой работы ждут владельца, в пакет уходит только сводка;
  эпик кончился — находки уходят задачей своей.
- `agent-kit`: надстройка правится по разделам, запись целиком запрещена второй проверкой.
- `spec-driven`: файл привязок — имена дерева и привязки; ловушки — в холодной части.

## Questions and answers

**Какие из восьми применять?** Владелец сказал «исправь все замечания и предложения из
приёмника которые ещё не обработаны». Четыре правки дерева не требуют его слова и берутся;
четыре предложения в пакет остаются в карточке до его слова.

## Decisions

- **Берутся четыре правки дерева, предложения в пакет — нет.** Правило: находки обзора ждут
  владельца; предложение, ушедшее без него, — чужая работа. Цена ошибки: если владелец скажет
  слать — четыре записи в приёмник, десять минут.

## What is left unclear

- Слать ли четыре предложения в пакет — слово владельца, не блокирует.

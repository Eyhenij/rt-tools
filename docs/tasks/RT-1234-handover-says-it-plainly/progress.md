## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — перечитывание заявки другой стороной
- **Сделано:** задача заведена, ветка и папка на месте, замысел записан, две записи отмечены
  готовыми, две взяты в работу
- **Следующий шаг:** дописать абзац о перечитывании заявки
- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** не открывается — ночью ветки держатся локально по слову владельца

- **Две записи из четырёх отмечены готовыми без правки** — их предложения закрыты редакциями,
  вышедшими позже отправки: порядок отдачи перевёрнут, а образец сообщения уже называет взятое.
  Затронутый этап замысла: нет.

## Решения по ходу

- **Подписи в эпик не входят** — спек домена требует словарь приложения, и это выполнено;
  многоязычия владелец не просил. Затронутый этап замысла: нет.
- **Вход создания записи страница не заводит вовсе** — замысел называл в этапе 3 флаги, но
  единственным их предметом оказалось создание записи, а создавать админке нечего: заведённый
  заранее и никем не включённый вход проверяется только чтением кода. Записан открытым вопросом
  `Q-27` договорённости. Затронутый этап замысла: 3 — флагов у страницы не появится.
- **Подсказку называют все три раздела** — вход, который не включает никто, проверяется только
  чтением кода, а замысел держит подсказку в сделанном. Тексты трёх подсказок заведены в
  словаре приложения рядом с названиями разделов. Затронутый этап замысла: нет.
- **Слоты объявлены своими директивами, а не проекцией по образцу тулбара кита** — тулбар
  кита рисует левую половину только тогда, когда в ней что-то есть, и разметку раздела надо
  провести через это условие; проекция отдала бы её тулбару безусловно, и пустая половина
  занимала бы место. Затронутый этап замысла: нет.

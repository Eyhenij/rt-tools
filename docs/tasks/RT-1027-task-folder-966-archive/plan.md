- **Что делается:** просьба владельца и решения по ходу уезжают в `docs/archive/`, папка

- **Что делается:** сверка гоняется целиком и читается её вывод.

- **Чем проверяется:** `npm run check:board` — ни одной строки со словами «папка лежит среди
  текущих».

# Ход работы RT-1774

## Где стоим

- **Состояние:** `этапы-кончились`
- Четыре этапа закрыты, набор проб пакета зелёный целиком, раскладка сходится.
- Осталось: отметить записи приёма починенными, разобрать папку, открыть заявку черновиком.

## Решения по ходу

- **Из одиннадцати предложений темы открыты пять.** Сверено чтением ресурсов до замысла.
- **Гард свежести отдельным файлом не заводится:** названного предложением файла в пакете нет, а
  его предмет — отставание всей стопки — закрыт приёмом в паттерне стопки.
- **Статья о теле заявки встала в правило, а не в паттерн.** Паттерн заявки стоял на 298 строках
  при пределе в 300, и четыре строки правки сделали бы новый долг по длине. Правило — законное
  место статьи, и адрес ей дописан в компаньоне.
- **Проверка папок вынесена отдельным файлом проверок.** Сверка очереди с новой функцией
  переваливала предел кода; сама проверка стоит наособицу — она единственная читает местный
  репозиторий и обходится без сети.
- **Повтор чтения очереди не идёт, когда спросить нечем.** Отказ по недоступности хостинга —
  не запоздавший ответ, и три лишние секунды на нём тратить не за что.

## Что считается сделанным

- Ширина, поставленная человеком, читается обратно после перезагрузки.
- Ширина вне пределов приводится к пределу, а не применяется как есть.
- Незакреплённая панель края не тянет.

## Этапы

### 1. Чистая часть: пределы и хранение ширины

- **Что делается:** ключ, чтение с приведением к пределам, запись
- **Признак готовности:** пробы на пустое, чужое, слишком узкое и слишком широкое значение зелёные
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit --testFile=projects/ui-kit/src/lib/ui-kit/side-menu` — пробы меню зелёные

### 2. Тянущийся край у закреплённой панели

- **Что делается:** узел края, слежение за указателем, применение ширины переменной оформления
- **Признак готовности:** протяжка меняет ширину панели; у незакреплённой края нет
- **Чем проверяется:** `pnpm run test:visual` — кадры витрины сходятся, новый кадр снят осознанно

## Чего эта работа не делает

- Ширину незакреплённой панели: тянуть её нечем, указатель уходит с пункта и панель закрывается.
- Ширину узкой раскладки: там панель занимает экран целиком.

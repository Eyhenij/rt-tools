# Замысел

**Поведение:** не меняется — правится холодная часть правила ведения работы.

## Что делается

1. В раздел ловушек холодной части встаёт пункт: чужой шаг бывает двух родов, и упершаяся в
   разрешение работа доводится до конца без той части, которую разрешение открывает.
2. Пункт называет, где живёт непройденное: строки тела заявки, а не реплика владельцу.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

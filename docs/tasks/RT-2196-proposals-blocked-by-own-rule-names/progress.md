## Decisions along the way

- **Путь к файлу пишется целиком, без переменной оболочки.** Хук проверки слога отпускает папки
  задач по образцу `docs/tasks/*`, а путь берёт из текста команды: `$D/progress.md` под образец не
  подходит, и хук судит файл, который судить не должен. Обратное тоже верно — файл, который судить
  надо, проезжает мимо, если путь к нему собран переменной.
- **Судятся все роды ресурса, а не одни правила.** `skillKindOf` знает только правила, образцы и
  скилы, а имя хука или проверки тоже пакетное и уезжать должно. Отдельная проверка `packaged`
  спрашивает установленные из пакета файлы по имени, не разбирая род.
- **Сценарий SC-AK-1103 переписан, а не выброшен.** Он обещал отказ на имени ресурса с адресом
  дерева — ровно то, что эта работа отменяет. Теперь он обещает отказ на адресе дерева в свободном
  поле строки: проверка на утечку с наблюдений не снята, ей просто больше нечего найти в имени.

## What counts as done

- Сухая отправка из этого дерева не находит ни одной утечки и печатает, что уехало бы.
- Имени собственного правила дерева нет ни в одной строке груза — ни у загрузки правила, ни у
  отказа проверки.
- Приём по-прежнему узнаёт, что загружали своё правило дерева, а не пакетное.
- Проверки пакета зелёные.

## Stages

### 1. Имя своего правила не уезжает

- **What is done:** в строке груза наблюдений имя ресурса, которого нет среди установленных из
  пакета файлов, замещается постоянным словом; род правила рядом остаётся прежним. Замещение
  идёт и у загрузки правила, и у отказа проверки — имя стоит в обеих записях.
- **Readiness sign:** новая проверка рядом с `linesOfDay` красная до правки и зелёная после;
  счёт проверок пакета растёт с 447.
- **Verified by:** `pnpm exec nx test @rt-tools/agent-kit --skip-nx-cache` — «Tests: N passed,
  N total» при N больше 447 и ни одной красной.

### 2. Отправка доходит до конца

- **What is done:** пакет собирается заново, и сухая отправка запускается на этом дереве.
- **Readiness sign:** вместо отказа «отправка не начата: в грузе назван адрес этого дерева — 5»
  печатается перечень того, что уехало бы.
- **Verified by:** `npm run build:agent-kit && node dist/agent-kit/bin/agent-kit.js propose --dry-run`
  — в выводе нет строки «в грузе назван адрес этого дерева».

## What this work does not do

- Подсказки дерева — карта загрузки правил, привязки правила о браузере, перечень стендов — правит
  задача RT-2197 этого же эпика.
- Сама отправка наружу здесь не делается: она уходит по слову владельца, отдельным шагом после
  слияния.
- Пропавший каталог разборов происшествий не восстанавливается: он лежит вне истории, и брать
  запись неоткуда.

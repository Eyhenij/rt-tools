## Этапы

### 1. Замер до и порядок

- **Что делается:** считается вес каждого грузимого правила и доля довода в нём; назначается
  порядок — от самого тяжёлого.
- **Признак готовности:** названы числа по каждому правилу, которое режется.
- **Чем проверяется:** `pnpm run agent-kit:cost` — вес слоя до правки.

### 2. Сжатие правила `task-flow`

- **Что делается:** статьи разбираются по трём исходам формы; уехавшее ложится в холодную часть.
- **Признак готовности:** перечень статей до и после совпал.
- **Чем проверяется:** `pnpm run agent-kit:check` — раскладка сходится с пакетом.

### 3. Сжатие правил без холодной части

- **Что делается:** режутся `turn-conduct`, `ui-component-tests`, `testing`; двум первым
  заводится холодная часть, третьему дописывается.
- **Признак готовности:** у каждого правила перечень статей совпал, холодная часть есть.
- **Чем проверяется:** `node tools/check-specs.mjs` — расхождений нет.

### 4. Замер после

- **Что делается:** считается вес слоя и вес входа в работу; разница называется числом.
- **Признак готовности:** названа разница по каждому правилу и по слою.
- **Чем проверяется:** `pnpm run agent-kit:cost` — вес слоя после правки.

### 5. Отдача

- **Что делается:** набор гейта, разбор папки задачи, заявка черновиком.
- **Признак готовности:** заявка открыта, номер назван владельцу.
- **Чем проверяется:** `git push` — гейт пропустил.

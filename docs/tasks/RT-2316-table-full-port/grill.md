## What the tree already has

Сверка 22 сентября: таблица первого кита — `projects/ui-kit/src/lib/ui-kit/table/`, второго —
`projects/ui-kit-v2/src/lib/components/table/` и `dynamic-list/`. Во втором уже есть: столбцы по
описанию, свои шаблоны ячеек, ячейка копирования, сортировка, строка отбора, клик строки с
клавиатурой, меню действий строки, настройки столбцов с сохранением, панель над списком со слотами,
листание, загрузка, пустое состояние, карточки на узком экране, плотность.

Нет во втором:

1. Колонка отметок: галочка строки, галочка страницы с промежуточным состоянием.
2. Одиночный выбор радиокнопкой.
3. Хранение выбора — `RtTableSelectorsDirective`, `RtDynamicListSelectorsDirective`: заданные
   отметки, «все на всех страницах» со списком исключений, запрет колонки. У динамического списка
   второго кита есть только входы вида для «выбрать все».
4. `rowDoubleClick`.
5. Дополнительные действия строки рядом с меню — `RtuiTableAdditionalRowActionsDirective`.
6. Готовые ячейки по типу столбца — `TableBaseCellComponent`: дата, процент, сумма, да/нет,
   список, значок с цветом, обрезка с подсказкой.
7. Переключатели полос прокрутки в настройках столбцов.
8. Явный запрет клика строки — `rtStopTableRowClick`; во втором ките клик по интерактивному
   элементу строку не открывает сам.

Истории первого кита: «Components/Table» — `ManyItems`, `CopyButtonOnHover`, `FewItems`;
«Components/DynamicList» — `ManyItems`, `FewItems`, `NoItems`; «Components/Pagination». Без пары
во втором: выбор многих строк, одиночный выбор, ячейка копирования внутри таблицы; боковая панель
настроек столбцов своей истории не имеет.

## Decisions

- **Таблица первого кита переносится отдельным компонентом рядом с таблицей второго, а не
  дописывается в неё.** Слово владельца «эта таблица не должна заменять таблицу второго кита а как
  альтернатива отдельные стори под нее». Вид первого кита: без карточек, на узком экране —
  прокрутка вбок. Отклонено: восемь пунктов сверки как добавки к `rt-table` — первая запись
  договорённости была о них, она переписывается.
- **Сначала переносится то, на чём таблица стоит, потом сама таблица.** Слово владельца. Из
  материальных частей таблицы во втором ките нет одной — радиокнопки; первый кит своей не имеет,
  берёт `mat-radio-button`.

- **Переносятся все восемь пунктов** — слово владельца «весь функционал». Отклонено: переносить
  только отметки и двойной клик — владелец ответил шире вопроса.
- **Вид — первого кита в материальном наборе оформления второго**, на компонентах второго кита —
  решения 2 и 5 плана эпика.
- **Вопрос `Q-DL-1` закрывается** — выбор строк в ките будет.

## What is left unclear

- Пункт 8: нужен ли явный запрет клика, если второй кит уже пропускает клик по интерактивному
  элементу. Решается в плане: явный запрет нужен для неинтерактивного узла, которому клик строки
  мешать не должен.

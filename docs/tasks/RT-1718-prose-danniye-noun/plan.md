# Замысел

**Поведение:** не меняется — правится проверка слоя правил, кода приложения работа не трогает.

## Этап 1. «Данные» судятся по тому, что стоит следом

Форма «данные» ловится только перед существительным, при котором она читается местоимением;
«данные стенда», «данные базы» и прочее существительное проходит.

## Этап 2. Сценарии, спека и прогон

Сценарии в наборе проверки слога, статья и адрес в домене, прогон по текстам дерева.

## What counts as done

- Есть страница переписок: список слева, лента выбранного разговора, поле ответа, закрытие
  разговора. Нарисована частями набора, не своей разметкой.
- Страница живёт признаком: обменивает подпись на признак, держит его в памяти вкладки, по
  истечении берёт новый, ни о чём не спрашивая человека.
- Отказ входа виден человеку словами, а не кодом; язык страницы берётся из словаря набора.
- Выбора площадки на странице нет: сайт назван ключом, с которым её встроили.
- Узкий экран ставит список и ленту друг под другом.
- Проверки страницы зелёные, набор перед отправкой проходит.

## Stages

### 1. Приложение страницы и его сборка

1. Завести `apps/chat-talks-page`: приложение каркаса на наборе, цели сборки, проверки и линта.
2. Написать вход страницы: ключ площадки и адрес сервиса приезжают признаками, подпись — сообщением.
3. Покрыть проверками разбор признаков и приём сообщения с подписью.

Признак готовности: `nx build chat-talks-page` и `nx test chat-talks-page` зелёные.

### 2. Вход и жизнь признака

1. Обмен подписи на признак страницы при открытии, признак живёт в памяти вкладки.
2. Просроченный признак: страница просит у скрипта новую подпись и меняет её на новый признак.
3. Отказ входа: страница показывает слова, а не код.

Признак готовности: проверки входа зелёные, сцена `SC-CH-88` закрыта со стороны страницы.

### 3. Экран переписок

1. Список переписок и лента выбранного разговора частями набора.
2. Ответ и закрытие разговора операциями под признаком.
3. Пустое состояние, узкий экран, слова страницы из словаря набора.

Признак готовности: сцены `SC-CH-89`, `SC-CH-90` и `SC-CH-91` закрыты, пометки о непокрытии сняты.

### 4. Отдать работу

1. Привести компаньон описания: правила страницы получают адреса в коде.
2. Разобрать папку задачи последним коммитом, добавив запись в `docs/archive/`.
3. Набор перед отправкой, отправка, PR в ветку эпика, рецензент, номер владельцу.

Признак готовности: PR открыт, номер назван.

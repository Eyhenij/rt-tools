  неразбираем; правило слоя API требует процедур Connect, которых здесь не будет.
  Затронутые этапы: 2 и 6.
- **2026-08-14. Тег либы и её алиас выводятся из пути, а не из имени домена.** Сверка раскладки

  `libs/message-bus-api`, поэтому теги вышли длиннее образцовых. Решение владельца о дословных
  слоях этим не задето: слои те же четыре. Затронутый этап: 1.

# Папки задач

По папке на ветку. Имя каталога повторяет имя ветки, косые заменены дефисом:
`fix/290-drop-legacy-button-styles` → `fix-290-drop-legacy-button-styles`.

Пока задача не заведена в очереди и номера нет, папка зовётся `_draft-<slug>` и в историю не
едет. Как появился номер — `git mv` под имя ветки.

Три файла, образец — `_template/`:

| Файл          | Что держит                                                                    |
| ------------- | ------------------------------------------------------------------------------- |
| `grill.md`    | просьба владельца дословно, его ответы его словами, решения с доводами          |
| `plan.md`     | замысел: этапы с признаками готовности. После написания не правится             |
| `progress.md` | ход работы: «Где стоим», решения по ходу, записи заходов. Единственное место, где отмечается сделанное |

Правило — `.claude/skills/task-flow/`, закон — `docs/constitution/work-conduct.md`.

Замысел работ, которые шире одной ветки, лежит не здесь, а в `docs/plans/`.

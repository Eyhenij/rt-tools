## Что считается сделанным

- В файле находок нет ни одного пункта без пометки о том, чем он кончился.
- Живое, чинящееся строкой текста, закрыто правкой источника пакета.
- Живое, требующее кода, заведено своими задачами, и их номера стоят у пунктов.

## Этапы

### 1. Находки разобраны, живое отделено от закрытого

- **Что делается:** по каждому пункту читается нынешний код или текст и называется исход.
- **Признак готовности:** у каждого пункта есть ответ — номер работы, своя правка или причина.
- **Чем проверяется:** `grep -c '^- \*\*' docs/plans/rules-feedback-loop.md` — число пунктов сходится с числом разобранных.

### 2. Живое, чинящееся текстом, закрыто правкой пакета

- **Что делается:** в правило ведения спеков, паттерн заведения правила и ловушки хода работы
  дописываются статьи по пяти живым находкам.
- **Признак готовности:** каждая статья стоит в своём слое и не перерастает предел веса.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет; `node tools/check-file-size.mjs` — длиннее предела нет.

### 3. Живое, требующее кода, заведено задачами

- **Что делается:** заводятся задачи на исключение разложенных проверок из форматтера, на
  молчащий гард в сводке наблюдений и на возраст договорённости в сверке.
- **Признак готовности:** у каждой находки в файле стоит номер её задачи.
- **Чем проверяется:** `npm run agent-kit:hooks` — все наборы зелёные.

# Замысел

**Задача:** RT-1006 · **Ветка:** RT-1006-turn-exit-without-branch
**Поведение:** не меняется — правка задевает слой правил, а не код приложения; так сказал
владелец, потребовав чинить остановки, а не заводить новое поведение.

## След задачи

| Что     | Где                                            |
| ------- | ---------------------------------------------- |
| Правила | `projects/agent-kit/assets/rules/task-flow.md` |
| Хуки    | `projects/agent-kit/assets/hooks/`             |
| Разборы | `docs/postmortems/`                            |

## Что считается сделанным

- Страж выходов хода отбивает пустой ход и там, где ветки, папки задачи или строки состояния нет.
- Хук передачи пишет файл и на отсоединённой голове.
- Правило ведения работы называет ложным концом хода строку, где команда названа и не запущена.
- Пакет собран, раскладка прошла, сверка разложенного молчит.

## Этапы

### 1. Второй признак в страже выходов хода

- **Что делается:** ранние выходы по пустой ветке, отсутствующей папке и пустой строке состояния
  заменяются суждением по второму признаку — была ли за ход хоть одна правка дерева.
- **Признак готовности:** страж отбивает ход без работы на ветке без папки задачи.
- **Чем проверяется:** `bash -n projects/agent-kit/assets/hooks/turn-exit-guard.sh` — молчание означает «сошлось».

### 2. Передача на отсоединённой голове

- **Что делается:** пустое имя ветки перестаёт останавливать хук; файл называется коротким
  снимком головы.
- **Признак готовности:** файл передачи пишется и там, где имени ветки нет.
- **Чем проверяется:** `bash -n projects/agent-kit/assets/hooks/handoff-write.sh` — молчание означает «сошлось».

### 3. Статья в правиле ведения работы

- **Что делается:** в раздел о выходах хода дописывается статья о названной и не запущенной команде.
- **Признак готовности:** статья стоит рядом с объявлением намерения.
- **Чем проверяется:** `grep -c 'запускается в том же ходе' projects/agent-kit/assets/rules/task-flow.md` — единица означает «сошлось».

### 4. Сборка и раскладка

- **Что делается:** пакет собирается, раскладка кладёт исправленные ресурсы в дерево.
- **Признак готовности:** сверка разложенного не называет расхождений по этим трём файлам.
- **Чем проверяется:** `pnpm run agent-kit:sync` — строка о разложенном без отказа означает «сошлось».

## Чего эта работа не делает

- Не трогает порогов окна и сжатия: они настроены владельцем в `.claude/settings.json`.
- Не закрывает эпик RT-974: третий его признак живьём не подтверждён.

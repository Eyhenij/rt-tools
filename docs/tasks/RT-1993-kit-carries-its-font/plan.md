## What counts as done

- Кит везёт те начертания, которые называет, либо перестаёт называть те, которых не везёт.
- Витрина рисует тем же шрифтом, каким кит нарисуется у потребителя.
- Набор снимков второго кита зелёный на машине, где ни одного названного семейства не стоит.
- В README кита сказано, откуда у потребителя берётся шрифт.

## Stages

### 1. Замер: какими семействами рисует образ сегодня

- **What is done:** ширина строки в 16 точек измеряется в образе для каждого названного семейства
  и для запасных. Образ — та самая машина без Montserrat, о которой говорит задача.
- **Readiness sign:** таблица ширин, из которой видно, нашёл ли браузер образа хоть одно из
  названных семейств.
- **Verified by:** `node tools/visual-gate.mjs ui-kit-v2` — эталоны сняты образом сегодня и
  зелёные; замер берётся тем же образом.

### 2. Кит везёт свои начертания

- **What is done:** файлы начертаний ложатся в `projects/ui-kit-v2/src/assets/fonts`, рядом
  встают объявления `@font-face` в слое оформления; сборка пакета уносит их в `dist`.
- **Readiness sign:** в собранном пакете лежат файлы шрифта, и объявление на них ссылается.
- **Verified by:** `pnpm exec nx build @rt-tools/ui-kit-v2` — файлы начертаний в выводе сборки.

### 3. Витрина рисует тем же шрифтом

- **What is done:** витрина берёт начертания оттуда же, откуда возьмёт потребитель, — из самого
  кита, а не из шрифтовой службы: отсечка чужой сети в съёмке всё внешнее обрывает.
- **Readiness sign:** ширина строки в образе перестаёт совпадать с запасным семейством.
- **Verified by:** `node tools/visual-gate.mjs ui-kit-v2 --update`, следом
  `node tools/visual-gate.mjs ui-kit-v2` — два подъёма подряд зелёные.

### 4. Тексты: README кита и устаревшая строка компаньона

- **What is done:** в README кита сказано, откуда берётся шрифт; в компаньоне правила о проверке
  через браузер снимается утверждение «эталон привязан к машине» — машин теперь две, и кадры
  снимает образ.
- **Readiness sign:** ни один текст дерева не привязывает эталон к машине разработчика.
- **Verified by:** `npm run check:docs` и `node tools/check-specs.mjs` — оба зелёные.

## What this work does not do

- Первый кит не трогается: его шрифт — отдельный разговор, и эпик его правки запрещает.
- Набор значков не трогается: он уже везётся китом.
- Токены размеров и высот строк не пересчитываются: работа возвращает тот шрифт, под который они
  и рассчитаны.

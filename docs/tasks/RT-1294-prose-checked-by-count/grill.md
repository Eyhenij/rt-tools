# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `patterns/doc-style-write.md`. Отметить
её этому дереву нечем: токен двигает только свои записи, работа при этом наша.

## Слухом длинный текст не судится

> Признак «прочитать фразу вслух» работает на той фразе, которую читают, и не работает на файле
> в сотни строк: оборот всплывает по всему тексту, и глазами он не считается. У приёма нет
> второй половины — счёта, — и каждый исполнитель собирает набор оборотов заново, из своей
> памяти о прошлых работах.

Соседнее дерево просит счёт грепом по накопленному набору. Здесь набор накоплен иначе: слог
судит проверка, и признаки в ней перечислены поимённо, каждый с заменой. Про неё паттерн молчит
вовсе — исполнитель читает «прочитать вслух» и не знает, что то же самое считает машина.

Чего проверка не видит: повтора законного оборота. Один и тот же оборот, стоящий в тексте
десятками, каждым своим появлением законен, и порога у проверки нет.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Порог повторов в саму проверку не заводится: это правка её поведения со своей ценой — законное
употребление оборота она начала бы отбивать числом. Названо ценой в записи о закрытой работе.

# Замысел

**Поведение:** не меняется — правится текст паттерна о том, как писать.

## Что делается

1. Строка о чтении вслух получает вторую половину: чем судится длинный текст, где у слуха
   граница и какая проверка считает то же самое поимённо.
2. Проверка называется именем ресурса и условно — разложена она не в каждом дереве.
3. Там же — что счётом ловится, а проверкой нет: повтор законного оборота.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`,
`node tools/check-prose-style.mjs projects/agent-kit/assets/patterns/doc-style-write.md`.

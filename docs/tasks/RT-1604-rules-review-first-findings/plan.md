# Замысел

**Поведение:** не меняется — правятся тексты слоя правил и файл находок, кода приложения работа
не касается вовсе.

## Что делается

Пять живых пунктов вносятся правкой ресурсов, остальные помечаются закрытыми или отпавшими, а
первый раздел файла находок пустеет — как это сделали задачи RT-1210…RT-1213 со своими.

## Этап 1 — живое внесено

**Что делается:** статья закона поставки о видимости заведённого; приём открытия заявки вызовом
REST при отказе языка запросов; статья паттерна начала работы о теле задачи; ловушка о вызове
команд дерева из корня; ловушка компаньона о соседней очереди на той же машине.

**Чем проверяется:** `pnpm run agent-kit:check` — раскладка сходится; `node
tools/check-file-size.mjs` — предела никто не перерос.

## Этап 2 — файл находок пустеет

**Что делается:** первый раздел получает пометку о разборе с таблицей «пункт — чем кончился», а
разобранные пункты снимаются из него.

**Чем проверяется:** в разделе не осталось ни одного неразобранного пункта; `node
tools/check-doc-paths.mjs` — расхождений нет.

## Чего не делается

- Выпуск новой редакции пакета: правки ложатся в источник, публикация — решение владельца.
- Разбор находок эпика RT-733: он не кончился, и его файл читается вместе с его последней задачей.

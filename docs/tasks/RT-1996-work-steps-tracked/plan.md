## What counts as done

- Замысел задачи держит шаги перечнем: у каждого номер этапа, номер шага и короткое название.
- Ход работы держит тот же перечень с отметками: сделан, идёт сейчас, не начат. Текущий ровно
  один.
- Проверка сверяет перечень хода работы с замыслом: расхождение по числу шагов, по номерам или
  по названиям — отказ.
- Страж конца хода считает шаги, не отмеченные сделанными, и отбивает ход, пока их больше нуля и
  владелец об остановке не говорил.
- Отказ называет номер текущего шага, его название, сколько шагов осталось и команду, которой это
  посчитано.
- Законные выходы остаются прежними: вопрос владельцу, отказ другого стража, передача захода,
  слово владельца об остановке.

## Stages

### 1. Шаги в замысле и отметки в ходе работы

- **Steps:**
    1. раздел шагов в образце замысла: номер этапа, номер шага, название
    2. раздел отметок в образце хода работы: три состояния, ровно один текущий
    3. проверка `work-steps.mjs` — сверяет перечень хода работы с замыслом
    4. пробы проверки: сходится, разошлось числом, разошлось названием, текущих не один
- **Readiness sign:** проверка красная на каждом из трёх расхождений и зелёная на сошедшемся.
- **Verified by:** `bash projects/agent-kit/tests/work-steps.test.sh` — без провалов.

### 2. Ярус стража и пробы под него

- **Steps:**
    1. чтение числа несделанных шагов рядом с чтением эпика
    2. ярус отказа в страже перед выходом по признаку сделанной работы
    3. текст отказа: номер шага, название, остаток, команда
    4. пробы на четыре случая — шаги остались, шаги кончились, слово владельца, занятый шаг
- **Readiness sign:** каждая проба падает, если снять ярус.
- **Verified by:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — без провалов.

### 3. Статьи правил, спека и раскладка

- **Steps:**
    1. статья в `task-flow` о том, что шаги записаны и текущий отмечен
    2. статья в `turn-conduct` о том, что несделанный шаг запрещает остановку
    3. спека `work-steps`: утверждения, сценарии, привязки
    4. сборка пакета и раскладка
- **Readiness sign:** аудит спек и аудит раскладки без расхождений.
- **Verified by:** `npm run check:specs && pnpm run agent-kit:check` — обе зелёные.

## What this work does not do

- Не трогает ярус по незакрытому эпику: он о задачах эпика, а не о шагах внутри задачи.
- Не заводит спеки на непокрытые ресурсы пакета — это задачи цепи эпика.
- Не переписывает состояния работы: единицей остаётся состояние, шаги живут внутри этапа.

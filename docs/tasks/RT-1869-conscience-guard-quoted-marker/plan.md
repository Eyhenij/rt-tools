## Что считается сделанным

- Маркер, напечатанный в ответе читающего или пишущего инструмента, вердиктом роли совести не
  считается: ход, в котором прочитан файл с маркером, отпускается.
- Маркер в собственном тексте исполнителя вердиктом не считается: написать нужную строку в реплике
  стоит одного движения.
- Ответ самой роли по-прежнему держит ход, и деяние по находке ищется по всей записи хода — командой
  разбора, словом владельцу, строкой `СОВЕСТЬ: разобрано`.
- Отказ цитирует ту находку, которую судил, а не первую строку с маркером в сырой записи.
- Отбор ответов инструментов у гарда экзамена узнаёт вызов по его идентификатору: сейчас выражение
  написано так, что при любом чтении файла в заходе глушатся все ответы инструментов разом.
- Обе статьи стоят в спеках со строками компаньонов и сценариями; набор пакета зелёный целиком.

## Этапы

### 1. Гард совести узнаёт вердикт по ответу роли

- **Что делается:** поток записи хода делится надвое — где отвечает роль и где лежит деяние по
  находке. Вердикт ищется только в первой половине: ответы читающих и пишущих инструментов
  глушатся по идентификатору вызова, собственный текст исполнителя не считается вердиктом никогда,
  извещения ведущего считаются целиком. Деяние ищется по-прежнему по всей записи. Отказ берёт
  цитату из того ответа, который судил.
- **Признак готовности:** три новые пробы зелёные — прочитанный файл с маркером отпускает ход,
  маркер в тексте реплики отпускает ход, ответ самой роли держит; тринадцать прежних проб не
  покраснели.
- **Чем проверяется:** `bash projects/agent-kit/tests/conscience-guard.test.sh` — `0 провалов`.

### 2. Отбор у гарда экзамена узнаёт вызов по идентификатору

- **Что делается:** в двух выборках гарда экзамена идентификатор вызова связывается именем, а не
  берётся точкой внутри трубы: точка после трубы означает уже сам список, и поиск по нему даёт `0`
  на любом непустом списке — глушатся все ответы инструментов разом.
- **Признак готовности:** проба, где в заходе есть и чтение файла, и ответ роли с вердиктом, гард
  отпускает; проба, где вердикт только в ответе читающего инструмента, — держит.
- **Чем проверяется:** `bash projects/agent-kit/tests/exam-guard.test.sh` — `0 провалов`.

### 3. Спеки, раскладка и набор целиком

- **Что делается:** статьи о том, чем узнаётся вердикт роли, встают в спеки обоих поддоменов со
  строками компаньонов и сценариями; пакет собирается и раскладывается.
- **Признак готовности:** сценарии привязаны, раскладка сходится, набор пакета и проверки дерева
  зелёные.
- **Чем проверяется:** `pnpm run check:all` — выход `0`.

## Чего эта работа не делает

- Не сводит общий отбор двух гардов в один помощник: выражение фильтра из файла в файл переносится
  текстом, и помощник тут стоил бы больше, чем экономит.
- Не трогает роль совести и её ответ: форма первой строки остаётся прежней.
- Не чинит прочие места, где маркер роли встречается в записях архива: перечни кириллицы там стоят
  намеренно и после этой правки безвредны.

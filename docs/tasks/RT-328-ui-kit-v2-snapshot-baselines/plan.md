## Что считается сделанным

- Ни одной папки компонента без снимаемой матрицы, кроме поимённо названных с причиной; размер
  списка исключений назван числом.
- Полный прогон снимков в CI на своём раннере зелёный; шаги двух витрин независимы, и каталог
  эталонов первой не изменён ни одним файлом.
- Повторный прогон без правок зелёный.
- Красный прогон, вызванный намеренно, выкладывает картинки различий и не оставляет в дереве ни
  одного файла на коммит.
- Каждое расхождение, вскрытое съёмкой, либо починено, либо заведено задачей очереди с причиной —
  молчаливых наблюдений не добавилось.
- Время полного прогона названо числом; `Q-2` договорённости закрыт или явно передан владельцу.
- Договорённость влита в спек пакета `docs/specs/ui-kit-v2/`, директории `proposed/` не осталось.

## Этапы

### 1. Разбор витрины: что снимается, что помечается, где пороги

- **Что делается:** обход всех папок компонентов. Истории со значениями по умолчанию получают
  `storySnapshotSkip` с причиной; истории, чей показ рисует не сетка, — `fullPage`; панельные —
  тоже `fullPage`, потому что панель лежит вне корня показа. Одиннадцати папкам, называющим
  ширину, проставляется перечень порогов помощниками `storyWidthAtMost`, `storyWidthAtLeast`,
  `storyWidthOver`, `storyWidthUnder`.
- **Признак готовности:** прогон по всей витрине не отказывает ни на одной истории по причине
  «нет корня показа» и «исключение без причины»; остаются только отказы про отсутствующий эталон.
- **Чем проверяется:** `pnpm run test:visual:v2` при поднятой витрине; `nx run @rt-tools/ui-kit-v2:typecheck`.

### 2. Съёмка эталонов и разбор расхождений

- **Что делается:** пересъёмка всего каталога, затем повторный прогон сверки. Каждый кадр
  просматривается: пустая ячейка, обрезанная подпись, схлопнувшийся по содержимому компонент —
  это дефект показа, а не эталон. Найденное чинится или заводится задачей.
- **Признак готовности:** два прогона подряд зелёные; число эталонов и вес каталога названы
  числами; ни один кадр не показывает пустоту вместо компонента.
- **Чем проверяется:** двойной прогон; просмотр кадров; `du -sh` по каталогу эталонов.

### 3. Починка вскрытого

- **Что делается:** расхождения, показывающие дефект кита, чинятся. Правка выпущенного компонента
  едет отдельным коммитом с отметкой в журнале изменений пакета; эталон снимается уже с
  починенного. Что не чинится здесь — заводится задачей с причиной.
- **Признак готовности:** ни одного эталона поверх известного дефекта; список заведённых задач
  назван в отчёте.
- **Чем проверяется:** `pnpm run check:all`; точечная пересъёмка затронутых историй.

### 4. Шаг прогона в CI

- **Что делается:** свой шаг в `.github/workflows/ci.yml` — витрина второго кита поднимается на
  своём порту, прогон идёт по `STORYBOOK_URL`, картинки различий выкладываются вложением при
  отказе. Шаг блокирующий с первого дня.
- **Признак готовности:** прогон в CI зелёный; намеренно внесённое расхождение роняет его и
  оставляет вложение; шаг первой витрины не задет.
- **Чем проверяется:** прогон CI на ветке; чтение выкладки вложения.

### 5. Договорённость вливается в спек пакета

- **Что делается:** `docs/specs/ui-kit-v2/proposed/visual-snapshots/` переезжает в спек пакета,
  сценарии отмечаются покрытыми там, где появились тесты, непокрытые — с причиной. `Q-2`
  закрывается замером или передаётся владельцу числом.
- **Признак готовности:** директории `proposed/` не осталось; `npm run check:specs` не добавил
  замечаний по этому спеку сверх тех, что дерево имеет на главной ветке.
- **Чем проверяется:** `npm run check:specs`; `npm run check:board`.

## Чего эта работа не делает

- **Волны покрытия 4 и 5** — составные компоненты и двенадцать без историй; свои работы в
  `docs/plans/ui-kit-v2-state-coverage.md`. Их истории привезут свои эталоны сами.
- **Проверка доступности** — своя задача: число нарушений неизвестно, и красный прогон
  доступности не должен держать зелёные снимки.
- **Долг по спекам компонентов** — одиннадцать папок, своя работа.
- **Витрина первого кита** — её обвязка, эталоны и шаг прогона не трогаются.
- **Страж `check:specs`, шумящий на всём дереве** — он ищет исходники по раскладке, которой в
  библиотечном дереве нет; своя работа.

## Что считается сделанным

- Ловушка называет приём и команду, которой снимают два числа.
- Команда работает на этом дереве и печатает законы, которых не назвало ни одно правило.

## Этапы

### 1. Ловушка и команда счёта

- **Что делается:** ловушка в холодной части правила о договорённости.
- **Признак готовности:** команда из ловушки печатает список законов без правила.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка кладёт файл без отказа.

### 2. Пределы и пути сходятся

- **Что делается:** прогон проверок текстов.
- **Признак готовности:** расхождений нет.
- **Чем проверяется:** `node tools/check-file-size.mjs` — долг 0, новых нет.

## Чего эта работа не делает

- Не заводит отказа: закон, которому в дереве нечего исполнять, — законное состояние.

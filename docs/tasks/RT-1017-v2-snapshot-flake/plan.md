## Что считается сделанным

- Каждое из двух расхождений названо своей причиной, и причина подтверждена серией, а не
  чтением кода.
- Кадр второй витрины перестаёт зависеть от того, застали ли страницу дорисованной.
- История, у которой в кадр попадало чужое состояние, ждёт свой признак и без него роняет
  прогон, а не снимает кадр молча.
- Десять прогонов снимков второго кита подряд идут без единого расхождения.
- Правило проверки компонента говорит, что статья об устойчивом кадре относится к обеим
  обвязкам, и называет, чем они при этом остаются разведёнными.

## Этапы

### 1. Обе причины подтверждаются серией

- **Что делается:** прогон снимков второй витрины гоняется серией на неподвижном дереве, с
  сохранением картинок различий; каждое пойманное расхождение разбирается по доле и области.
- **Признак готовности:** названо, сколько расхождений на скольких прогонах, и по каждому — та
  ли это история и та ли доля; для просмотрщика фото названо, чужое состояние это или сдвиг.
- **Чем проверяется:** `bash <временный сценарий серии> 30` — печатает счёт расхождений, и
  картинки различий лежат рядом.

### 2. Кадр снимается до совпадения двух подряд

- **Что делается:** в обвязку второй витрины ставится тот же приём, что и у первой, — копией, а
  не импортом; снимается кадр по корню показа, а не по странице, поэтому цикл ложится на оба
  вида съёмки.
- **Признак готовности:** расхождения порядка сотых долей процента на серии не повторяются.
- **Чем проверяется:** та же серия — счёт расхождений по историям, где виновата растеризация,
  становится нулём.

### 3. Чужое состояние в кадр не попадает

- **Что делается:** история, у которой в кадре оказался чужой индекс, получает ожидание своего
  признака — узла, который есть только в её состоянии; не дождавшись, обвязка роняет прогон.
- **Признак готовности:** прогон с намеренно сорванным признаком отказывает словами о признаке,
  а не расхождением снимка.
- **Чем проверяется:** `pnpm run test:visual:v2` — сходится; и тот же прогон со снятым шагом
  ожидания — отказывает по признаку.

### 4. Устойчивость подтверждается десятью прогонами

- **Что делается:** прогон снимков второй витрины гоняется десять раз подряд на неподвижном
  дереве.
- **Признак готовности:** десять прогонов из десяти без расхождений.
- **Чем проверяется:** `bash <временный сценарий серии> 10` — «разошлось 0 из 10».

### 5. Найденное записывается в правило

- **Что делается:** в правило проверки компонента дописывается, что статья об устойчивом кадре
  верна для обеих обвязок и почему это не повод свести их в общий модуль.
- **Признак готовности:** статья стоит, привязка к коду названа для обеих обвязок.
- **Чем проверяется:** `npm run check:docs` и `pnpm run agent-kit:check` — код ноль.

## Чего эта работа не делает

- Не трогает обвязку снимков первого кита: она только что приведена в порядок, и правка ради
  второго сдвинула бы момент съёмки у первого.
- Не пересъёмывает эталоны: оба расхождения ложные, и закреплять их нельзя.
- Не сводит две обвязки в общий модуль — это прямо запрещено правилом.
- Не трогает половину параллельного захода: правила о папке задачи, гарды поставки и эпик об
  обратной связи слоя правил.

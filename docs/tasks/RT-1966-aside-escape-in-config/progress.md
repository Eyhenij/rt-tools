# Ход работы

## Где стоим

Переписывается каждым заходом, а не дописывается.

- **State:** `этап-идёт`
- **Этап:** идёт 1 — строка панели в настройках кита
- **Сделано:** заведена задача, ветка от главной, папка и замысел.
- **Следующий шаг:** настройка и три пробы.
- **Незакоммиченное:** папка задачи.
- **Ждём владельца:** ничего.
- **Заявка:** ещё не открыта.

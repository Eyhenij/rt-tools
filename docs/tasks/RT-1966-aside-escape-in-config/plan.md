## Что считается сделанным

- Приложение возвращает закрытие панели по клавише одной строкой настроек.
- Довод вызова сильнее настройки приложения, а умолчание кита не меняется.
- Пробы на все три случая стоят, сценарии — в спеке кита.

## Этапы

### 1. Строка панели в настройках кита

- **Что делается:** `aside` в разделе компонентов настройки; служба читает его, когда вызов о
  клавише молчит.
- **Признак готовности:** три пробы — настройка возвращает клавишу, довод вызова её перебивает,
  без настройки умолчание прежнее.
- **Проверяется:** `pnpm exec nx test @rt-tools/ui-kit --testFile=aside.service.spec.ts`.

### 2. Спека и примечания к выпуску

- **Что делается:** утверждение и сценарии в спеке кита; смена умолчания названа отдельной
  строкой в примечаниях к выпуску кита.
- **Признак готовности:** `node tools/check-specs.mjs` без расхождений.
- **Проверяется:** та же команда и сборка кита.

## Чего эта работа не делает

- Не меняет умолчание: клавиша по-прежнему панель не закрывает.
- Не заводит настройки для других источников закрытия: разбор просил только о клавише.

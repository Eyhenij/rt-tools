## Что считается сделанным

- Проверка слога ловит английский канцелярит и называет замену; русский набор остаётся.
- Проверка словаря ловит английское слово из раздела «Так не пишем», и это записано сценарием.
- Роль правки слога отвечает на языке текста, который переписывает.
- Спек гарда слога называет два языка и привязку английского набора.
- Сценарии проверок зелены, пакет собран и разложен.

## Этапы

### 1. Английский набор признаков в проверке слога

- **Что делается:** в проверку слога дописан набор `MARKS_EN` с границами слова по латинице и
  заменой у каждого признака; оба набора судят каждую строку.
- **Признак готовности:** пробный английский файл с «in order to» отбит с заменой «to», чистый
  английский текст проходит, русские случаи проходят как прежде.
- **Чем проверяется:** `bash projects/agent-kit/tests/check-prose-style.test.sh` — все строки
  зелены, среди них новые с номером сценария.

### 2. Сценарии, спек и роль

- **Что делается:** сценарий английского признака в спеке гарда слога с привязкой; сценарий
  английского слова в тесте словаря; раздел «Локали» спека говорит о двух языках; роль
  `prose-editor` отвечает на языке текста.
- **Признак готовности:** `npm run check:specs` не называет ни сценария без теста, ни статьи
  без привязки по этому спеку.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-glossary.test.sh` — зелено;
  `npm run check:specs` — по гарду слога и текстам расхождений нет.

### 3. Сборка и раскладка

- **Что делается:** пакет собран и разложен, копии проверок в `tools/` и роли в
  `.claude/agents/` обновлены.
- **Признак готовности:** раскладка сходится, проверка слога в дереве зелена на своих файлах.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет;
  `node tools/check-prose-style.mjs docs/plans/rules-layer-language.md` — находок нет.

## Что считается сделанным

- В форме записи предложения стоит третья обязательная строка — чем закрывается: какие
  надстройки и добавки дерева снимаются, когда правка приедет редакцией пакета.
- Форма строки описана там же, где и две имеющиеся, и её видно из самого шаблона.
- Пустая строка обходом не считается: сказано, что писать, когда снимать нечего.
- `bash projects/agent-kit/tests/run.sh`, `node tools/check-specs.mjs` и
  `pnpm run agent-kit:check` зелёные.

## Этапы

### 1. Третья строка в шаблоне записи

- **Что делается:** в образец записи и в пояснение к нему встаёт строка «чем закрывается»
  наравне с «местом» и «поводом»; названо, что писать, когда снимать нечего.
- **Признак готовности:** обе записи образца несут три строки, и по шаблону видно, чем каждая
  из них отличается.
- **Чем проверяется:** чтение шаблона целиком; `bash projects/agent-kit/tests/texts.test.sh`.

### 2. Строка названа там, где о предложениях говорят

- **Что делается:** скил слоя правил называет третью строку в разделе об обратной связи — иначе
  о ней узнают только те, кто откроет шаблон.
- **Признак готовности:** раздел называет все три строки и говорит, зачем нужна третья.
- **Чем проверяется:** чтение раздела; `pnpm run agent-kit:check` после раскладки.

### 3. Сценарий и раскладка

- **Что делается:** сценарий заводится в спеке пакета, если строку судит машина; не судит —
  это говорится прямо в разделе «Чего из закона здесь нет» либо в самом шаблоне.
- **Признак готовности:** `node tools/check-specs.mjs` зелёный, раскладка сошлась.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`, `pnpm run agent-kit:check`.

## Чего эта работа не делает

- **Снятием надстроек сама не занимается.** Строка говорит, что снять, — снимает это работа по
  обновлению редакции пакета.
- **Уже написанные предложения задним числом не правятся.** Форма действует на новые записи;
  лежащие в дереве закрыты и снимаются своим порядком.

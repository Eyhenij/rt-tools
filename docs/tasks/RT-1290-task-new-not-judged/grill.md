# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `hooks/task-flow-guard.sh`. Отметить её
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Команда заведения задачи отбивается сама собой

Команда заведения задачи пишет папку задачи и карточку в очереди работ, а её текст несёт тело
задачи целиком: цитата со знаком «больше» подходит под признак записи, путь к коду в прозе тела —
под признак пути. Отбитая, она отбивается тем гардом, который сам же и печатает её в тексте
своего отказа: заведение задачи после этого невозможно ни с ветки закрытой задачи, ни с главной.
За один заход это случилось дважды подряд.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

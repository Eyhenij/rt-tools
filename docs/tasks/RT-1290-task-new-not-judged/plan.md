# Замысел

**Поведение:** не меняется — правку кода гард судит по-прежнему; из-под требования выходит одна
команда, которой он сам же и учит.

## Что делается

1. Гард хода работы не судит команду заведения задачи: имя её берётся из профиля дерева — того
   же, откуда его берёт гард поставки для текста отказа.
2. Сценарий при гарде: команда заведения проходит с главной ветки, а правка кода той же командой
   отбивается по-прежнему.

## Чем проверяется

`bash projects/agent-kit/tests/task-flow-guard.test.sh`, `npm run agent-kit:sync`,
`npm run agent-kit:check`, `npm run check:specs`.

- **Milestone G of the epic:** пакет готов улучшаться по числам: отчёт собирает данные подключённых приложений.

## What counts as done

- Повтор того же вызова на том же содержимом считается пустым отказом, правка между отказами его снимает.
- Каждый запуск набора пишет исход, секунды и род шага, красный запуск на том же содержимом считается пустым.
- PR при открытии оставляет подпись дерева в файле, который не уходит из дерева.
- Сообщение человека считается хуком по набору образцов, текст не хранится.
- Итог PR читается функцией профиля, значение по умолчанию — для GitHub.
- Отчёт считает первую приёмку, откат и повторный PR той же задачи за 14 дней.
- Вызов роли считается по имени пакета, своя роль дерева — постоянным словом.
- Гард объявляет своё правило, итог экзамена записан, у доли правок есть знаменатель.

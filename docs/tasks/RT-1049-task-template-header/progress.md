# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `задача-взята`
- **Этап:** замысла ещё нет — следующий шаг его написать
- **Сделано:** задача заведена и стоит в работе, ветка от свежей главной, папка собрана; промах
  воспроизведён на ней же дословно — гард отбил правку `progress.md` с текстом отказа
- **Следующий шаг:** разведка — перекладывает ли раскладка папку задачи вообще, и есть ли ещё
  роды копий образца; от ответа зависит выбор между двумя ходами починки
- **Незакоммиченное:** папка задачи целиком
- **Ждём владельца:** нет
- **PR:** ещё не открыт

## Решения по ходу

- **Шапка снята с копий образца руками, как и в прошлой работе** — иначе не написать ни разбора
  просьбы, ни этой строки. Это и есть предмет задачи: пока она не закрыта, каждая работа платит
  тремя строками `sed`. Затронутый этап замысла: замысла ещё нет.

## Решения по ходу

- **Междупакетные совпадения имён принимаются списком, а проверка не правится** — решение
  владельца на прямой вопрос; предложенный вариант «научить проверку различать пакеты, кода не
  делящие» отвергнут. Затронутый этап замысла: 1.
- **Имя блока вёрстки осталось объявленным локально в каждом компоненте** — вынос в основание
  семейства отбило своё правило линтера дерева `rt/require-host-bem-block`: оно требует
  локальную const ровно с именем `BEM_BLOCK`. Ответ нашёлся в компаньоне правила
  `component-structure` — «константа рядом с классом», — поэтому владельцу вопрос не
  задавался, а строка принята с причиной. Затронутый этап замысла: 3.
- **Наборы сортировки и обязательные поля груза переехали в общую всем либу, а не в основание
  семейства** — их читают обе стороны, админка и приёмник, и основание семейства приёмнику не
  видно вовсе. Затронутый этап замысла: 4.

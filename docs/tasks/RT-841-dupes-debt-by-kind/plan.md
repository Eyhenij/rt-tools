## Этапы

### 1. Роды долга названы, междупакетные совпадения приняты

- **Что делается:** десять строк, где одно имя стоит в двух пакетах, кода не делящих
  (`projects/ui-kit` против `projects/ui-kit-v2`, `projects/core` и `projects/agent-kit`
  против `projects/ui-kit-v2`), переезжают из долга в принятое; причина каждого рода стоит в
  самом списке. Решение владельца: принять списком, проверку не трогать.
- **Признак готовности:** в `debt` не осталось ни одной междупакетной строки, а причина
  названа так, что по ней видно, почему это не повтор.
- **Чем проверяется:** `npm run check:dupes` — долг уменьшился ровно на принятое, новых нет.

### 2. Повторы внутри одного пакета сняты кодом

- **Что делается:** набор ширин показа и пороги съёмки, объявленные в витрине второго кита
  дважды, сводятся к одному объявлению.
- **Признак готовности:** имя объявлено один раз, второе место читает первое.
- **Чем проверяется:** `npm run check:dupes`, прогон снимков витрины второго кита.

### 3. Общие символы админки вынесены

- **Что делается:** `INITIAL_STATE` трёх сторов и значение `admin-panel` у `BEM_BLOCK` трёх
  либ показа переезжают туда, откуда их видно всем трём.
- **Признак готовности:** объявление одно, три потребителя его импортируют, границы либ не
  нарушены.
- **Чем проверяется:** `npm run check:dupes`, `npm run check:layers`, юниты админки.

### 4. Наборы полей и адреса разведены

- **Что делается:** четыре пары наборов полей между либами админки и приёмника и две строки
  между сквозным набором и либами (`SIGN_IN_PATH`, `qa`) разбираются: общее выносится,
  законно разное принимается с причиной.
- **Признак готовности:** каждая из шести строк либо снята кодом, либо принята с причиной.
- **Чем проверяется:** `npm run check:dupes`, `npm run check:layers`, сквозной набор админки.

### 5. Эпик знает итог

- **Что делается:** в замысел эпика RT-806 вписывается, чем кончилась эта задача и какими
  числами; границы эпика перечитываются целиком.
- **Признак готовности:** порядок эпика называет обе заведённые задачи, итог этой записан.
- **Чем проверяется:** чтением файла замысла; `npm run check:docs`.

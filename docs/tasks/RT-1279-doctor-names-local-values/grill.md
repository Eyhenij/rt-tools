# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `cli/doctor`. Отметить её этому дереву
нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Ненастроенное дерево выглядит настроенным

Дерево с выключенной браузерной стражей выглядит у сводки полностью настроенным: «на месте:
172», «функции профиля — все определены». Разложенные файлы сводка считает, функции профиля
проверяет, а местные значения, без которых разложенный хук мёртв, не смотрит вовсе. Отсутствие
такого значения не видно ни сверкой раскладки, ни набором сценариев — набор подменяет корень
одноразовым каталогом и сам кладёт туда значение, поэтому судит механизм, а не дерево.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

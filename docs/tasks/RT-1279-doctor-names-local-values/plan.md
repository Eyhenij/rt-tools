# Замысел

**Поведение:** не меняется — сводка по-прежнему печатает состояние раскладки и ничего не правит;
у неё прибавляется строка.

## Что делается

1. Хук называет местное значение, которым живёт, строкой шапки — тем же приёмом, каким называет
   требуемые ресурсы: `# Местное значение: <путь> — <что перестаёт проверяться без него>`.
   Первым такую строку получает помощник профиля браузера.
2. Сводка состояния читает эти строки у взятых хуков, смотрит, лежит ли значение в дереве, и
   называет ненастроенные поимённо — с именем хука и последствием.
3. Спека при команде: сводка называет ненастроенное значение и молчит о лежащем.

## Чем проверяется

`pnpm exec nx test @rt-tools/agent-kit`, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`.

# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `rules/doc-style.md`. Отметить её этому
дереву нечем: токен двигает только свои записи, работа при этом наша.

## Чем запись указателя считается названной, правило не говорит

> Правило требует сверять указатель каталога с содержимым и молчит о том, чем запись считается
> названной. Форма живёт только в пояснении внутри самой проверки — там её не прочитает никто,
> кто пишет указатель. Два указателя дерева называли записи ссылкой с заголовком, имени файла в
> обратных кавычках в строке не стояло вовсе: для читателя записи названы, для сверки строка
> пуста. Семнадцать записей были невидимы.

Здесь проверка та же и читает так же: записью считается первое имя в обратных кавычках строки
таблицы, и другой формы она не знает. Сказано это только пояснением внутри самой проверки.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Вторую форму проверка не учится читать: ссылка с заголовком несёт адрес, и отличить в ней
запись каталога от любой другой ссылки строки нечем.

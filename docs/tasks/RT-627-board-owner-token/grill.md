# Разбор просьбы

## Просьба владельца дословно

> вмержил, продолжай работу по линии

и, на вопрос о том, что делать с бордой, которую машинная запись не правит:

> делай всё через токен владельца

## Как всплыло

Работа по линии — задача #586. Перед тем как за неё браться, `npm run check:board` и
`npm run task:move -- 585 in-review` отказали текстом `API rate limit already exceeded for user
ID 314674161`. Текст читается как временный, поэтому первым движением был проверен предел:

```
$ GH_TOKEN=$(cat ~/.config/rt-tools-bot-token) gh api rate_limit --jq '.resources'
{"core":{"limit":60,"remaining":60},"graphql":{"limit":0,"remaining":0}}
```

Предел не исчерпан — его нет. Квота GraphQL у машинной записи ноль, а борда живёт только в
GraphQL. То есть очередь работ этой записью не правится вовсе и не будет.

## Что уже сказано в правилах

- Компаньон правила `git-workflow` уже знает об ограничении: «Машинная учётная запись ограничена
  хостингом, и заведённое ею видно только ей… Пока оно стоит, задачи заводятся учётной записью
  владельца». Про борду там не сказано ничего — а она отказывает по той же причине.
- Правило `git-workflow`: «Колонка задачи двигается тем же движением, что и работа… делает это
  команда перевода, а не набор вызовов GraphQL по памяти».
- Спек `agent-kit`: «Ресурс с неотвеченным требованием дереву не кладётся» — про раскладку, но
  та же мысль: обвязка, которую нечем исполнить, хуже отсутствующей.

## Решения

- **Токен машинной записи для борды становится необязательным.** Слово владельца: делать всё
  токеном владельца. Не назвавшее токена дерево правит борду тем, чем залогинен клиент
  хостинга. Отвергнуто: научить обвязку читать второй токен — второй токен пришлось бы завести
  и держать, а работает уже имеющийся вход владельца.
- **Правка идёт в пакет, а не в разложенное.** Все три файла несут шапку раскладки: правка на
  месте теряется на следующем `agent-kit sync`, и он на неё отказывает.
- **Дерево снимает `board.tokenPath`.** Пока ключ на месте, обвязка берёт машинный токен и
  отказ повторяется — необязательность сама по себе ничего не чинит.

## Что осталось невыясненным

- **Вернётся ли машинная запись.** Ограничение хостинга снять нечем со стороны дерева, и когда
  оно пройдёт, неизвестно. Правка от этого не зависит: вернувшаяся запись снова называется
  ключом `board.tokenPath`, и обвязка возьмёт её.

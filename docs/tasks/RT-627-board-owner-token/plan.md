## Что считается сделанным

- `npm run check:board` доходит до конца и печатает сводку очереди работ, а не отказ хостинга.
- `npm run task:move -- <номер> in-progress` переставляет колонку задачи.
- Заведение задачи доходит до борды: тикет виден в очереди работ и стоит в первой колонке.
- Дерево, не назвавшее токена машинной записи, работает с очередью так же — правит её учётной
  записью, под которой залогинен клиент хостинга.
- `.claude/rt-kit/checks.json` больше не называет токен машинной записи, а `git-workflow`
  говорит, почему.
- `pnpm run agent-kit:check` сходится: разложенное совпадает с пакетом.

## Этапы

### 1. Токен машинной записи становится необязательным

- **Что делается:** режим `move` файла борды и команда заведения задачи перестают отказывать
  без токена; оба зовут хостинг тем, чем он залогинен. Правка идёт в пакет и раскладывается.
- **Признак готовности:** дерево без `board.tokenPath` двигает колонку и заводит задачу.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`, живой вызов `task:move`.

### 2. Дерево перестаёт называть токен машинной записи

- **Что делается:** ключ `board.tokenPath` снимается из `.claude/rt-kit/checks.json`; почему
  именно здесь он снят — в компаньоне правила `git-workflow`.
- **Признак готовности:** `npm run check:board` сходится; в компаньоне названо ограничение
  хостинга и то, чем оно проверяется.
- **Чем проверяется:** `npm run check:board`, `npm run check:docs`.

### 3. Тексты домена

- **Что делается:** статья в спеке `agent-kit` о необязательности машинного токена, её привязка
  и сценарий.
- **Признак готовности:** `npm run check:specs` не прибавил расхождений.
- **Чем проверяется:** `npm run check:specs`, `pnpm run agent-kit:check`.

## Чего эта работа не делает

- **Не снимает машинную запись с подписи коммитов.** Подпись читается гардом поставки и живёт в
  `RT_COMMIT_EMAIL`; ограничение хостинга её не задевает.
- **Не трогает пуш.** Он идёт токеном машинной записи через помощник учётных данных и работает.
- **Не разбирает папку задачи #585** — она лежит в главной ветке неразобранной, и это своя
  работа.

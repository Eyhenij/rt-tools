# Замысел

**Задача:** RT-277 · **Ветка:** RT-277-sync-hook-exec-bit
**Поведение:** не меняется — правка внутри пакета правил: разложенный хук получает право на
запуск и теряет его молча; для потребителя это починка, а не новая возможность.

## След задачи

| Что     | Где                                                           |
| ------- | ------------------------------------------------------------- |
| Код     | `projects/agent-kit/src/lib/plan.ts`, `sync.ts`               |
| Тесты   | `projects/agent-kit/src/lib/plan.spec.ts`, `commands.spec.ts` |
| Правила | `.claude/skills/agent-kit-source/`                            |

## Что считается сделанным

- Разложенный хук, у которого бит исполнения снят рукой, возвращается раскладкой в исполнимое
  состояние: содержимое при этом не переписывается.
- `sync --check` называет такой файл расхождением, а не молчит.
- Неисполнимый ресурс бита не получает: право переносится с файла пакета, а не раздаётся всем.
- Оба случая держатся тестами, и каждый из них падает при откате починки.

## Этапы

### 1. План файла знает о праве на запуск

- **Что делается:** решение о судьбе файла получает право исполнения — своё у ресурса пакета и
  своё у файла в дереве; при расхождении исход перестаёт быть `ok`.
- **Признак готовности:** файл с верным содержимым и снятым битом назван расхождением.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit --testFile=src/lib/plan.spec.ts` —
  новые тесты зелёные, прежние не тронуты.

### 2. Раскладка возвращает право, сверка о нём говорит

- **Что делается:** запись ставит бит и там, где содержимое не переписывается; `--check` считает
  такой файл расхождением.
- **Признак готовности:** на дереве со снятым битом `sync` чинит, `sync --check` отвечает
  ненулевым кодом.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit --testFile=src/lib/commands.spec.ts`
  — тест раскладки со снятым битом зелёный.

### 3. Дерево осталось зелёным

- **Что делается:** прогон набора пакета, линтеров и сверки раскладки.
- **Признак готовности:** прогоны зелёные, разложенное в дереве не разошлось.
- **Чем проверяется:** `pnpm run agent-kit:check` — вывод без строк расхождения.

## Чего эта работа не делает

- Не трогает набора хуков и их тел: правится раскладка, а не то, что она кладёт.
- Не заводит своего права на файлы вне каталога хуков: признак берётся с ресурса пакета.

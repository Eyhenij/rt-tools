# Замысел

**Задача:** RT-896 · **Ветка:** RT-896-work-conduct-rework
**Поведение:** не меняется — работа кладёт замысел эпика и очередь задач под ним; кода
приложения в ней нет ни строки.

## Что считается сделанным

- Груз приёма прочитан целиком: 49 разборов происшествий и 54 предложения, оба дерева.
- Разборы разнесены по группам механизма, и группы покрывают все 49 без остатка.
- Причина повторов названа и подкреплена числами из самого груза.
- Карточка эпика стоит в очереди работ с меткой эпика, задача на каждую группу заведена, и
  номера задач стоят в замысле эпика.
- Указатель архива сходится с каталогом — `node tools/check-doc-paths.mjs` зелёная.

## Этапы

### 1. Груз прочитан и разобран

- **Что делается:** чтение всех разборов и предложений приёма, счёт по деревьям и по ресурсам,
  разнесение по группам механизма, разбор причины повторов.
- **Признак готовности:** каждая из 49 записей отнесена к группе, счёт по группам сходится с
  общим числом.
- **Чем проверяется:** счёт по ресурсам и по деревьям, снятый с самого приёма.

### 2. Эпик и очередь задач под ним

- **Что делается:** замысел эпика в каталоге замыслов, карточка эпика в очереди работ, задача
  на каждую группу, номера задач в замысле.
- **Признак готовности:** карточка несёт метку эпика; у каждой строки порядка стоит номер
  заведённой задачи; сверка очереди работ не называет ни одной из них неправильно названной.
- **Чем проверяется:** `npm run check:board`, `node tools/check-doc-paths.mjs`,
  `node tools/check-file-size.mjs`.

## Чего эта работа не делает

- Саму переработку ведения работы: она разложена на семь задач и делается ими, а не здесь.
- Правку законов: статьи о ведении работы и о поставке приносятся владельцу текстом.
- Работу в дереве-потребителе: оно получит исправленную редакцию пакета, задач в его очереди
  этот эпик не заводит.
- Два продуктовых дефекта из груза — о показе слова слоя правил и о вёрстке ячейки: они
  чинятся кодом и заводятся своими задачами.

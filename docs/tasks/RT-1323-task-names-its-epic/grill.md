# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `patterns/task-flow-start.md`. Отметить её
этому дереву нечем: токен двигает только свои записи, работа при этом наша.

## Привязка задачи к эпику держалась подражанием

> Эпик объявляется дважды — карточкой и замыслом, — и оба текста это требуют. Обратной ссылки не
> требует ни один. Держалось подражанием: пока тело задачи писалось с образца соседней задачи
> того же эпика, строка связи копировалась вместе с формой. Задача, заведённая посреди работы
> как находка сверки, писалась не с образца — строки в ней не оказалось, а строка в замысле была
> дописана, отчего привязка выглядела целой.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки не заводится: тело карточки читает только хостинг, и сверить его с замыслом эпика
машине дерева нечем.

# Замысел

**Поведение:** не меняется — правится текст паттерна о начале работы.

## Что делается

1. В раздел об объявлении эпика, в конец, встаёт абзац: задача, заведённая под эпик, называет
   его в своём теле — номер карточки и путь к замыслу одной строкой.
2. Абзац называет, чем опасна односторонняя привязка: она выглядит целой ровно так же, как
   двусторонняя.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

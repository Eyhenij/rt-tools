## Что считается сделанным

- Передача ветки с папкой задачи ложится разделом «Передача захода» в её `progress.md`.
- Повторное сжатие переписывает раздел, а не дописывает второй.
- Работа без папки задачи по-прежнему получает файл вне дерева.
- Вход захода читает раздел из хода работы, а файл вне дерева — только когда раздела нет.

## Этапы

### 1. Хук пишет раздел хода работы

- **Что делается:** `handoff-write.sh` кладёт передачу в `progress.md`, когда папка задачи есть.
- **Признак готовности:** раздел появляется и переписывается на втором прогоне.
- **Чем проверяется:** `bash projects/agent-kit/tests/handoff-write.test.sh` — 0 провалов.

### 2. Вход читает раздел

- **Что делается:** `turn-entry-load.sh` берёт раздел из хода работы, файл — запасным путём.
- **Признак готовности:** заход видит передачу из папки задачи.
- **Чем проверяется:** `npm run agent-kit:hooks` — все наборы зелёные.

### 3. Тексты и сценарии

- **Что делается:** правила, паттерн, сценарии спека.
- **Признак готовности:** статья о передаче вне дерева переписана, сценарии записаны.
- **Чем проверяется:** `npm run check:specs` — расхождений нет.

## Чего эта работа не делает

- Не трогает гард входа из передачи: он судит реплику владельца, а не место хранения.

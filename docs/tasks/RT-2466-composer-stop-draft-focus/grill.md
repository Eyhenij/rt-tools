# Grill

## The owner request

> возьми композер для сообщения из ui-kit v2 из rt-tools

> Доработать композер в rt-tools (ответ на вопрос «как останавливать ответ, если у композера нет кнопки Stop»)

> иди делай изменения в композере самостоятельно, открой рабочее дерево rt-worktree-2 и делай изменения непосредственно там

## What the tree already has

- `rt-message-composer` в `projects/ui-kit-v2/src/rich-editor/lib/components/message-composer/`, спека
  `docs/specs/ui-kit-v2/message-composer/` (сценарии `SC-UKV-480`…`SC-UKV-488`).
- При `sending` форма блокируется эффектом в конструкторе, кнопка отправки крутит спиннер; остановить
  нечем.
- Текст живёт в собственной `FormGroup`; входа или модели для текста нет; публичных методов нет.
- Значок `stop` есть в наборе кита (`src/assets/icons/stop.svg`).
- Подписи: английский набор `rt-kit-labels.en.ts` и русский набор витрины
  `.storybook/showcase-labels.ru.ts` (полный `Record`); приложения дерева держат `Partial`.
- Следующий свободный номер сценария — `SC-UKV-537`.

## What the rules already say

- Новое поведение компонента описывается в спеке подобласти до кода, с номером сценария на каждое
  правило (`spec-driven-domain`).
- Спек компонента и кадры витрины — `ui-component-tests`, `rt-tools-storybook`.

## Questions and answers

**Как останавливать ответ, если у композера нет кнопки Stop?**
Доработать композер в rt-tools.

**Что ещё нужно от композера потребителю-чату с ответом потоком?**
Из постановки владельца: остановка ответа, черновик снаружи (двусторонний `text`), публичный `focus()`.

## Decisions

- **Режим остановки — новый вход `stoppable`, а не новое поведение `sending`.** Существующие
  потребители (`rt-chat`) при `sending` ждут блокировку формы и спиннер. Rejected: менять смысл
  `sending` — ломает их.
- **При `stoppable` + `sending` поле не блокируется.** Пользователь набирает следующий вопрос, пока
  идёт ответ; `Enter` в это время не отправляет и текст не стирает.
- **Текст — `model<string>`, а не CVA.** Композер — не поле формы, у него своя форма с файлами;
  потребителю нужно задать и очистить черновик, а не встраивать компонент в чужую форму.

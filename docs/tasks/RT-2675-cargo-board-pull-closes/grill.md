## Decisions

- **PR с базой не в main и строкой `Closes` получает находку** — она говорит, что задача не
  закроется слиянием, и велит назвать задачу словами и закрыть рукой.
- **PR с базой не в main строки `Closes` не требует** — иначе у такого PR всегда была бы одна из
  двух находок.
- PR в main судится как раньше.

## Что считается сделанным

- Читающая команда с перенаправлением в пустое устройство правило не требует.
- Путь, названный только в теле документа на месте, правкой не считается — кроме случая, когда
  команду ведёт интерпретатор.
- Ни один сценарий обхода из набора гардов не проходит: правка, положенная командой, отбивается
  по-прежнему.
- Доля отбитий не на правке файла, посчитанная сводкой, стала меньше на том же дереве.

## Этапы

### 1. Пустое устройство перестаёт считаться записью

- **Что делается:** признак записи не считает записью перенаправление в пустое устройство и в
  поток ошибок.
- **Признак готовности:** чтение с таким перенаправлением признаком не судится, а запись в
  настоящий файл судится по-прежнему.
- **Чем проверяется:** `pnpm run agent-kit:hooks` — «сошлось» означает ноль упавших сценариев,
  включая новый на пустое устройство.

### 2. Тело документа на месте перестаёт давать пути

- **Что делается:** пути берутся из заголовка команды, а не из тела документа на месте. Тело
  читается по-прежнему там, где команду ведёт интерпретатор: код записи стоит именно в нём.
- **Признак готовности:** запись текста, называющего чужой путь, правила под этот путь не
  требует; запись файла интерпретатором отбивается, как и раньше.
- **Чем проверяется:** `pnpm run agent-kit:hooks` — ноль упавших, включая оба новых сценария:
  текст с чужим путём и запись интерпретатором.

### 3. Замер на дереве до и после

- **Что делается:** доля отбитий не на правке файла снимается сводкой на том же отрезке до
  правки и после неё.
- **Признак готовности:** доля названа числом в описании PR, и она меньше прежних 94 процентов.
- **Чем проверяется:** `node dist/agent-kit/bin/agent-kit.js stats` после сборки пакета —
  строка доли в блоке отбитий.

## Чего эта работа не делает

- **Список имён в признаке не сужается.** Он подкреплён разбором происшествия, а пришедшее из
  разбора не снимается, пока разбор не признан неверным.
- **Карта гейта и его однократность не трогаются** — они судят верно.
- **Текст отказа не правится** — это RT-964, следующая задача эпика.

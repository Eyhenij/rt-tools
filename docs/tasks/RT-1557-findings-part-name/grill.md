# Разбор просьбы

## Просьба владельца

> Работай

Работа взята из приехавшего предложения — заявка #852 «Имя файла находок эпика сталкивается у
двух рабочих деревьев»:

> Находки разбора закрытой задачи копятся у замысла эпика одним файлом. Имя файла и следующий
> свободный номер каждое рабочее дерево видит своим, а деревьев у эпика несколько —
> столкновение обнаруживается только при вливании главной ветки, конфликтом на весь файл.
> Замечено на пятой задаче эпика из десяти: файл находок, заведённый веткой, в главной оказался
> занят другим содержанием и другим диапазоном номеров.

## Что уже есть в дереве

- `patterns/task-flow-archive.md`, абзац «Накопительный файл находок делится до дописи, а не
  после»: сказано, что не влезает — заводится следующая часть; чем эта часть называется, не
  сказано.
- Там же статья RT-1555: имя самого файла — `<имя замысла>-findings.md` рядом с замыслом. Она
  закрывает первое столкновение — то, где два дерева выбирают имя первому файлу.
- `docs/plans/` — двадцать два файла, ни один пока не поделён на части: случая деления в этом
  дереве ещё не было.

## Что уже сказано в правилах

Нумерации у нынешней формы находок нет вовсе — строка на находку, номеров у строк нет, — и
половина предложения, требующая «нумерацию от задачи», отпала вместе с той формой, о которой
писалась. Осталась вторая: имя части.

## Решения

- **Часть называется задачей, которая её завела** — `<имя замысла>-findings-<КЛЮЧ>-<номер>.md`.
  Номер занят задачей одной, и двум деревьям одинаковое имя не достанется. Отвергнуто:
  порядковый номер части — его и видит каждое дерево своим, ровно та поломка, о которой
  предложение.
- **Части не переименовываются задним числом** — первый файл остаётся `<замысел>-findings.md`.
  Переименование правит ссылки во всех текстах, которые на него смотрят, ради ровного ряда имён.

## Что осталось невыясненным

- Порядок чтения частей владельцем: имена не выстраиваются в ряд по алфавиту. Читает их владелец
  разом, когда эпик кончился, и порядок между частями ему не нужен — находки не продолжают
  друг друга.

## Что считается сделанным

- Имя части файла находок названо и не оставляет выбора рабочему дереву.
- Образец находок говорит то же самое там, где он говорит о делении.

## Этапы

### 1. Имя части названо в паттерне и в образце

- **Что делается:** абзац о делении дописывается именем части — `<имя замысла>-findings-<КЛЮЧ>-<номер>.md`;
  та же строка правится в образце находок.
- **Признак готовности:** имя названо в обоих текстах, порядковых номеров частей нигде нет.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка кладёт оба файла без отказа.

### 2. Пределы и пути сходятся

- **Что делается:** прогон проверок текстов.
- **Признак готовности:** расхождений нет.
- **Чем проверяется:** `node tools/check-file-size.mjs` — долг 0, новых нет.

## Чего эта работа не делает

- Не переименовывает уже лежащие файлы находок: первая часть остаётся без номера задачи.
- Не заводит проверки на имя части — правило держится образцом, как и имя самого файла.

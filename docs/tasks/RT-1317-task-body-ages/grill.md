# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `rules/task-flow.md`. Отметить её этому
дереву нечем: токен двигает только свои записи, работа при этом наша.

## Тело задачи прочитано как действующее указание

> Три задачи одной серии подряд предлагали ход, который разведка отменила. Задачи заводились
> разом, за недели до того, как их брали: к этому дню пакет привёз то, что задача звала
> написать, а посылки, на которых ход стоял, не подтверждались. Читалось тело задачи как
> действующее указание.

Здесь то же: задачи эпика заводятся все разом, а берутся по одной неделями позже.

Ветка отведена от ветки соседней задачи: тот же раздел она уже правила.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки не заводится: старение способа машине не видно — тело задачи и в день заведения, и
через месяц выглядит одинаково.

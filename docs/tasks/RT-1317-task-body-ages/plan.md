# Замысел

**Поведение:** не меняется — правится холодная часть правила ведения работы.

## Что делается

1. В раздел ловушек холодной части встаёт пункт: тело задачи называет способ, и способ стареет
   раньше дефекта.
2. Пункт называет порядок: работа начинается с чтения того файла, к которому задача относится,
   а расхождение уходит решением по ходу и меняет способ, но не цель.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

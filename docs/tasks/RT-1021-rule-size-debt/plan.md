# Замысел

**Задача:** RT-1021 · **Ветка:** RT-1021-rule-size-debt
**Поведение:** не меняется — работа делит тексты слоя правил и не трогает кода приложения:
ни одна статья не снимается и ни один отказ не пропадает.

## След задачи

| Что                | Где                              |
| ------------------ | -------------------------------- |
| Правила и паттерны | `projects/agent-kit/assets/`     |
| Разложенные копии  | `.claude/skills/`                |
| Перечень долга     | `tools/file-size-allowlist.json` |
| Проверка длины     | `tools/check-file-size.mjs`      |
| Спек пакета        | `docs/specs/agent-kit/`          |

## Что считается сделанным

- В перечне известного у проверки длины нет ни одной записи долга.
- `node tools/check-file-size.mjs` зелёная и без этих записей.
- Каждый новый ресурс назван своим правилом, а раскладка сходится с пакетом.

## Этапы

### 1. Паттерн о коммите делится по границе «до пуша» и «после пуша»

- **Что делается:** три вида паттерна о коммите теряют разделы про заявку — они уезжают в новый
  паттерн о заявке, тремя видами; оба паттерна называет правило поставки.
- **Признак готовности:** ни один из шести файлов не длиннее предела текста.
- **Чем проверяется:** `node tools/check-file-size.mjs` — в выводе нет ни одного файла с именем
  паттерна о коммите.

### 2. Паттерн закрытия работы делится по предметам

- **Что делается:** разбор закрытой работы правилами уезжает из паттерна закрытия в свой
  паттерн; оба называет правило ведения работы.
- **Признак готовности:** ни источник, ни разложенная копия не длиннее предела текста.
- **Чем проверяется:** `node tools/check-file-size.mjs` — имени паттерна закрытия в выводе нет.

### 3. Правило поставки делится по границе «работа с очередью» и «выкатка»

- **Что делается:** статьи о выкатке, образах и проде уезжают во второе правило под тем же
  законом; паттерны о выкатке переходят к нему.
- **Признак готовности:** оба правила короче предела, у каждого объявлен свой закон.
- **Чем проверяется:** `node tools/check-file-size.mjs` — имени правила поставки в выводе нет.

### 4. Правило ведения работы делится по границе «ход работы» и «выходы хода»

- **Что делается:** статьи о выходах хода, о стражах и об утверждениях уезжают во второе
  правило под тем же законом.
- **Признак готовности:** оба правила короче предела.
- **Чем проверяется:** `node tools/check-file-size.mjs` — имени правила ведения работы в выводе
  нет.

### 5. Правило оформления освобождается от надстройки дерева

- **Что делается:** разделы дерева про токены и темы уезжают в свой скил дерева, а надстройка
  правила оставляет при себе только то, что правит пакетные разделы.
- **Признак готовности:** разложенное правило короче предела.
- **Чем проверяется:** `node tools/check-file-size.mjs` — имени правила оформления в выводе нет.

### 6. Перечень долга пустеет, набор гейта гоняется целиком

- **Что делается:** из перечня известного снимаются все одиннадцать записей долга.
- **Признак готовности:** ключ долга пуст, проверка зелёная.
- **Чем проверяется:** `node tools/check-file-size.mjs` — «длиннее предела 0, из них принято 0,
  долг 0».

## Чего эта работа не делает

- Не переписывает содержания текстов: статьи переезжают дословно.
- Не трогает самого предела и его проверки — они поставлены прежней задачей эпика.

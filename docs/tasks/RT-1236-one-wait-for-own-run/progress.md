## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этапы-кончились`
- **Этап:** 3 из 3 — пакет собран, разложен, сверен
- **Сделано:** статья заведена, привязка дописана, разложенное сходится

- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** не открывается — ночью ветки держатся локально по слову владельца

## Решения по ходу

- **Соседняя запись о гарде ожидания не взята** — она называет дыру, которой в разборе кода не
  видно: логика гарда судит оба действия одним ходом. Заводить правку по неподтверждённой посылке
  дороже, чем оставить запись новой. Затронутый этап замысла: нет.

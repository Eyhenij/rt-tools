# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — статья об ожидании своего замера
- **Сделано:** задача заведена, ветка и папка на месте, замысел записан, запись груза отмечена
- **Следующий шаг:** дописать статью
- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** не открывается — ночью ветки держатся локально по слову владельца

## Решения по ходу

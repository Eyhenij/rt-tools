## What the tree already has

В `main` два сценария носят номер `SC-AUTH-98`: `docs/specs/auth/angular/scenarios.md` и
`docs/specs/auth/example/scenarios.md`. `node tools/check-specs.mjs` красный, и ни одна ветка эпика не
уходит на сервер, пока номер не разведён.

## Decisions

- **Номер получает сценарий примера: SC-AUTH-104.** Команда `npm run spec:next-id -- AUTH` назвала его
  следующим свободным. Сценарий и заголовок теста правятся одним коммитом.
- **Правка идёт по ветке эпика.** Ветка задачи не может открыть PR, пока ветки эпика нет на сервере, а
  ветка эпика не проходит набор с этим номером.

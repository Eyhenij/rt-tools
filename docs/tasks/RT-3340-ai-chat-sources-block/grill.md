# Grill

## The owner request

> Делай эпик дальше

Следующей в плане эпика RT-3346 стоит RT-3340. Карточка задачи: пользователь не видит, откуда
ассистент взял цифры ответа — какой отчёт, страница, период и фильтры. От кита нужен блок
`sources` для `rt-ai-chat`: свёрнутый по умолчанию список «Sources» под ответом с числом источников;
элемент — название источника, уточнение (страница, период, фильтры), иконка вида источника; элемент
по желанию кликабелен, кит отдаёт событие, приложение открывает источник. Готово, когда список
раскрывается и сворачивается с клавиатуры, клик по элементу отдаёт событие, в витрине есть история с
одним и с пятью источниками.

## What the tree already has

- Образец блока: `link` — данные `src/lib/util/link-data.ts`, схема `link.schema.ts`, тип в
  `rt-ai-chat.model.ts`, логика `blocks/rt-ai-chat-blocks.logic.ts` (`OWN_TYPES`, `leafView`,
  `leafText`), карточка `blocks/link/`, событие `linkOpen` в `rt-ai-chat.component.ts`.
- Раскрываемый список: `rt-expansion-panel` со своим заголовком-кнопкой (Enter и Space работают
  нативно), областью `role="region"`, скрытым телом в свёрнутом виде и вращением шеврона. Заголовок
  принимает проекцию, поэтому название и число источников встают в него.
- Значки: `chart-bar`, `table`, `file`, `file-pdf`, `database`, `folder`, `book`, `link` есть в
  наборе кита; `file-text`, `document`, `report` нет. Проверка имени — `isKitIconName`.
- Спеки про источники нет. Три спеки (`ai-chat-section`, `ai-chat-link`, `ai-chat-kpi`) называют
  блок источников вне своих границ.
- Схема нового типа входит в `OWN_SCHEMAS` в `section.schema.ts` той же правкой.

## What the rules already say

- Блок рисует кит сам, без регистрации отрисовщика; событие уходит выходом чата с номером
  сообщения (как `linkOpen`). Кит не открывает источник.
- Видимая правка кита идёт через макет и слово владельца (`kit-approval`), затем код и истории.

## Questions and answers

Шесть вопросов закрыты допущением: владелец дважды подряд брал рекомендованный вариант и велел
вести эпик дальше. Решения идут в разбор как принятые.

## Decisions

- **Задача меняет поведение кита; закон не правится; одна задача.** — новый тип блока с событием;
  законы и правила не меняются; блок откатывается целиком.
- **Не входит:** открытие источника (делает приложение), поиск и ранжирование источников,
  группировка по видам, предпросмотр источника, поле в протоколе. — граница эпика.
- **Признак готовности — слова карточки.** — список раскрывается и сворачивается с клавиатуры,
  нажатие на источник отдаёт событие, в витрине есть истории с одним и с пятью источниками.
- **Образец — блок `link` и `rt-expansion-panel`.** — оба в дереве, оба читались целиком.
- **Поля блока: `items`, у каждого `title`, необязательные `detail`, `icon`, `url`.** — `url` делает
  источник нажимаемым; без него строка просто текст. Имя значка пишет модель, поэтому оно
  сверяется с набором кита, запасной значок `file`. Рассматривали поле `kind` с таблицей значков:
  оно закрывает набор видов, а модели нужна свобода.
- **Список свёрнут при первой отрисовке и не помнит выбор кита.** — раскрыт или свёрнут, решает
  человек; кит состояние наружу не отдаёт. Рассматривали открытый список: ответ с десятью
  источниками тогда теряет начало.
- **Нажатие уходит выходом `sourceOpen` чата с номером сообщения, адресом и названием.** —
  как `linkOpen`; событие приходит синхронно, внутри обработчика нажатия.
- **Заголовок «Sources» с числом источников, подписи — подписи кита.** — английские в ките,
  русские в витрине, как у карточки ссылки.
- **Копия ответа: строка заголовка и по строке на источник через табуляцию.** — название,
  уточнение, адрес; как таблица и KPI.
- **Макет в Figma делается до кода.** — правило `kit-approval`; владелец одобряет макет и витрину.

## What is left unclear

- Какой набор значков вида источника использует модель: кит даёт имена, список видов не
  закрывается. Это не блокирует работу: запасной значок покрывает чужое имя.
- Нужен ли источнику номер, по которому ответ ссылается на него в тексте: в карточке задачи этого
  нет, и в границы он не входит.

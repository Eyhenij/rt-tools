# Замысел

**Поведение:** не меняется — правится ловушка паттерна о возвращении к работе.

## Что делается

1. Условие ловушки расширяется с деления работы на любое употребление числа: перенесённое в
   разбор просьбы или в ход работы, оно читается следующими заходами как замер.
2. Прежний довод — разошедшаяся оценка объёма — остаётся: он показывает цену на деле.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

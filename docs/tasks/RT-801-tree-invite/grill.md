# Разбор просьбы

## Просьба владельца

Дословно, одной репликой.

> нужно чтобы пакет сам предоставлял команду для выдачи токена, продумай процесс и проведи аудит
> безопасности своего решения, то есть приложение-потребитель должно самостоятельно запросить
> токен , заведи одельной задачей и возьми в работу прямо сейчас

## Что установлено до первого вопроса

Разведка шла командами, а не догадками.

- Токен дерева сейчас выдаёт только команда строки запуска на самом приёме — `tree:add` и
  `tree:token` в `libs/message-bus-api/trees/util/src/lib/tree-command.util.ts`. Дерево получить
  его само не может ничем: операции такой нет.
- Приём закрыт по умолчанию: `libs/message-bus-api/access/feature/src/lib/access.guard.ts`
  отвечает только на операцию с объявленным доступом, а видов доступа три — публично, токеном
  дерева, входом человека.
- Токен живёт в хранилище только хешем — `tree-token.util.ts`: тридцать два случайных байта,
  `sha256` без соли, сверка за постоянное время. Срока годности у токена нет, отзыв есть.
- Признак дерева считается на самом дереве — хеш от адреса удалённого репозитория,
  `projects/agent-kit/src/lib/shipment.ts:treeSlugOf`. Приём его не вычисляет, а принимает.
- Ограничитель частоты у публичных операций правило доступа требует, но в приёме его нет ни
  одного: публичная операция там сейчас только проба живости, а она ничего не заводит.

## Ответы владельца

| Вопрос                                       | Ответ                                                                                   |
| -------------------------------------------- | --------------------------------------------------------------------------------------- |
| Чем приём отличит своё дерево от чужого      | Одноразовым приглашением: владелец заводит код, дерево предъявляет его и получает токен |
| Что входит в задачу                          | Пакет, приём и экран в админке для приглашений                                          |
| Срок годности токена дерева                  | Не трогаем: токен годен, пока не отозван                                                |
| Меняет ли задача поведение приложения        | Да — у приёма появляется операция, у админки раздел; договорённость о продукте нужна    |
| Требует ли правки закона или правила         | Закона нет; словарь дерева получает слово «Приглашение» надстройкой                     |
| Есть ли образец, с которого снимается подход | Да: выдача и отзыв токена дерева уже написаны — приглашение повторяет их устройство     |

## Решения

- **Приглашение — одноразовый код с сроком годности.** Заводит его владелец, предъявляет
  дерево; сгорает при первом же успехе. Чужой без кода не заводится никак.
- **Признак дерева приходит с обращением, а не берётся приёмом.** Иначе приём считал бы его от
  адреса, которого не знает: адрес репозитория наружу не уезжает вовсе.
- **Токен печатается дереву один раз — в ответ на обращение.** Второго пути забрать его нет: у
  приёма его нет тоже, там лежит хеш.
- **Ограничитель частоты заводится вместе с операцией.** Обращение за токеном — публичная операция, заводящая
  запись, и правило доступа требует его прямо.

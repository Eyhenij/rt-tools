## Что считается сделанным

- Команда линтера, в которой нет пути правленого файла, названа в потоке ошибок один раз за
  сессию.
- Работу это не останавливает: команда исполняется по-прежнему.
- Все наборы проб зелёные.

## Этапы

### 1. Хук называет команду без пути

- **Что делается:** после печати команды хук сверяет, стоит ли в ней путь файла, и один раз за
  сессию говорит, если не стоит.
- **Признак готовности:** строка появляется на команде без пути и молчит на команде с путём.
- **Чем проверяется:** `bash projects/agent-kit/tests/lint-after-edit.test.sh`.

### 2. Статья и сценарий

- **Что делается:** статья в спек гардов, сценарий в его список, привязка компаньона.
- **Признак готовности:** `check:specs` без расхождений.
- **Чем проверяется:** `npm run check:specs`, полный прогон наборов.

## Чего эта работа не делает

- Не отбивает такую команду: дерево, честно линтующее весь набор одной командой, от промаха по
  одному признаку пути неотличимо.

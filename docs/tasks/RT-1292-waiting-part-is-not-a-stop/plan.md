# Замысел

**Поведение:** не меняется — правится холодная часть правила ведения работы.

## Что делается

1. В холодную часть правила ведения работы, в раздел ловушек, встают два пункта: ожидание
   одной части этапа остановкой этапа не бывает, и строка с путём поручением не бывает.
2. Правило при этом не трогается: оно стоит в девяноста знаках от предела веса, и статьи туда
   не встают без деления — цена называется в записи о закрытой работе.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`.

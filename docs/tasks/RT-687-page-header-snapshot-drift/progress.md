# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Этап:** 1 из 3 — возврат второго значения
- **Сделано:** причина падения найдена по логам конвейера, задача и ветка заведены, витрина поднята
- **Следующий шаг:** вернуть подпись в трёх файлах шапки страницы и прогнать снимки
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет
- **PR:** ещё не открыт

## Решения по ходу

- **Задача заведена под учётной записью владельца, а не машинной** — публичный профиль
  `rt-tools-agent` отвечает 404, а его токен получает лимит неаутентифицированного клиента:
  запись перестала существовать для GitHub. Затронутый этап замысла: нет, это заведение задачи.

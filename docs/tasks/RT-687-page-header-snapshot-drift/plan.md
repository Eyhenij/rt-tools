## Этапы

### 1. Возврат второго значения

- **Что делается:** в трёх файлах шапки страницы подпись `Отчёт` возвращается к `Отчёты` —
  сплошная замена слова задела значение, которое остаётся законным.
- **Признак готовности:** ни одного вхождения `label: 'Отчёт'` в дереве.
- **Чем проверяется:** греп по `projects/`.

### 2. Прогон снимков и спеки

- **Что делается:** поднятая витрина, полный прогон снимков второй витрины, спека компонента.
- **Признак готовности:** снимки сходятся, осиротевших эталонов нет, спека зелёная.
- **Чем проверяется:** `pnpm run test:visual:v2`, `pnpm exec nx test @rt-tools/ui-kit-v2`.

### 3. Папка задачи и чужая

- **Что делается:** папка RT-685 разбирается по трём исходам, своя — тем же коммитом.
- **Признак готовности:** в `docs/tasks/` не остаётся ни одной папки закрытой задачи.

## Чего эта работа не делает

- Не пересъёмывает эталоны шапки страницы: расхождение здесь — след правки текста, а не
  изменение показа.
- Не трогает остальные возвраты второго значения того же слова: в дереве их больше нет,
  греп показывает только законные вхождения.
- Не заводит проверку, которая ловила бы правку демо-данных витрины сплошной заменой: такую
  проверку выбирает владелец, а прогон снимков её уже заменяет.

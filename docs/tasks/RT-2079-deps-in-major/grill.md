# Grill

## The owner request

> подтяни свежий main и почисти ветки, обнови макеты которые используются на проекте

На вопрос, что такое «макеты», владелец ответил:

> пакеты, обнови npm пакеты

## What the tree already has

- Правило `dependencies` и паттерн `dependencies-upgrade`: версии точным числом, верхняя граница
  по peer-диапазонам, снимок дерева в том же коммите, сборка раньше линтеров.
- Файл привязок правила: срок ожидания свежей версии в дереве не задан (`minimumReleaseAge` нет);
  список подмен `overrides` в `pnpm-workspace.yaml` пересматривается при каждом обновлении.
- `pnpm outdated` — 104 отставших пакета: 81 в пределах текущего мажора, 23 с новым мажором.
- Peer-диапазоны сняты командой: Angular 22.1.6 держит `typescript >=6.0 <6.1`; `ng-packagr`
  22.1.1 — то же; `@storybook/angular` 10.6.0 требует `storybook ^10.6.0`;
  `@analogjs/vitest-angular` 2.7.2 — `vitest ^4`; `@nx/angular` 23.2.1 — Angular `<23`.
- `@oxc-project/runtime` 0.115.0 — прямая зависимость корня, которой не пользуется никто
  (`pnpm why` показывает только корень).
- `conventional-changelog-cli` 5.0.0 — помечен устаревшим, новой версии нет.

## What the rules already say

- Пакет с новым мажором и пакет, несущий оформление, поднимаются своей задачей — правило
  `dependencies`.
- Работа вне эпика идёт по слову владельца о ней — правило `task-flow`.

## Questions and answers

**Меняет ли задача поведение приложения?**
Закрыто допущением: нет — правятся только версии инструментов и рамок в пределах мажора.

**Нужна ли правка закона или правила?**
Закрыто допущением: нет.

**Одна задача или несколько?**
Одна — минорные и патч-версии. Мажоры (eslint 10, typescript 7, vitest 5, NestJS 12, stylelint 17,
jsdom 30, @types/node 26, commitlint 21, webpack-dev-server 6, eslint-plugin-simple-import-sort 14,
jsonc-eslint-parser 3) — отдельными задачами, по правилу `dependencies`.

**Что не входит в задачу?**
Мажоры; `@oxc-project/runtime` (0.x, никем не используется); `prisma` 8.1.0-dev (предвыпуск);
собственные пакеты `@rt-tools/*`.

**Что покажет, что задача закрыта?**
`pnpm install --frozen-lockfile` проходит; `pnpm run check:all` зелёный; в `package.json` ни одного
`^` или `~`; `pnpm outdated` показывает только мажоры и исключённое.

**Есть ли образец?**
Нет — порядок задан паттерном `dependencies-upgrade`.

## Decisions

- **Свежие версии берутся без ожидания** — срок в дереве не задан, а правило требует ждать только
  при заданном сроке. Rejected: отбирать версии старше N дней по своему усмотрению — это срок,
  которого владелец не назначал.
- **`@storybook/angular` поднимается с 10.1.2 до 10.6.0 вместе с остальным Storybook** —
  один диапазон `^10.6.0`, отдельной причины держать 10.1.2 в истории нет (последняя правка
  строки — «build: upgrade angular» без объяснения).

## What is left unclear

- Отдельные задачи на мажоры — заводятся по одной на пакет или одной карточкой: заведу одну
  карточку со списком, владелец разобьёт, если захочет.

## What counts as done

- Приёмник отвечает на отклонённое обращение кодом отказа, а не написанным по-русски текстом.
- Админка рисует текст по коду из словаря — на выбранном языке, на каждой отрисовке.
- Код, которого админка не знает, виден признаком, а не пустотой: человек видит, что чинить.

## Stages

### 1. Договорённость о кодах отказа

- **What is done:** описание будущего обещания: набор кодов, кто их называет, что делает админка с
  незнакомым кодом, что делает дерево со старым ответом.
- **Readiness sign:** описание лежит в `proposed/`, и проверка описаний видит его сценарии.
- **Verified by:** `node tools/check-specs.mjs` — новый домен назван, провалов нет.

### 2. Набор кодов в общей либе

- **What is done:** коды отказа объявлены один раз на обе стороны, рядом с `ECargoFault`, и их
  разбор проверяется вызовом.
- **Readiness sign:** обе стороны берут набор из общей либы, своей копии ни у одной нет.
- **Verified by:** `pnpm exec nx test message-bus-common` — 0 провалов.

### 3. Приёмник отвечает кодом

- **What is done:** броски отказа в приёмнике называют код, а не русский текст; тело ответа несёт
  код и подстановки к нему.
- **Readiness sign:** `grep -rn "throw new" --include='*.ts' libs/message-bus-api | grep -P "[А-Яа-яЁё]" | wc -l` — 0.
- **Verified by:** `pnpm exec nx run-many -t lint test -p message-bus-api-accounts message-bus-api-trees message-bus-api-access message-bus-api-observations` — 0 провалов.

### 4. Админка рисует текст по коду

- **What is done:** слово приёмника заменено текстом словаря по коду; незнакомый код виден
  признаком.
- **Readiness sign:** ни одна панель не показывает строку из тела ответа как есть.
- **Verified by:** `pnpm exec nx affected -t lint typecheck test build` — 0 провалов.

### 5. Сквозной набор и отказ на двух языках

- **What is done:** сквозной тест открывает отказ и убеждается, что его текст идёт за выбором
  языка; договорённость влита в описание приёмника.
- **Readiness sign:** набор зелёный, тест падает, если вернуть текст отказа с сервера.
- **Verified by:** `pnpm exec nx run message-bus-admin-e2e:e2e` — 0 провалов.

## What this work does not do

- Не трогает отказы приёма груза: их читает средство дерева, а не человек в браузере.
- Не заполняет английский набор целиком: это RT-2213.
- Не ставит проверку, запрещающую строку мимо словаря: это RT-2214.

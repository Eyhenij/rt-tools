# Grill

## The owner request

> заводи новый эпик - в приёмнике текст написаны хуй пойми как, половина на русском, половина на
> английском, везде должны быть ключи и переводы

> веди RT-2208

Задача эпика #2208, четвёртая по его плану.

## Ответы владельца

Даны при заведении эпика 17 сентября; новых вопросов задача не открывает.

- **Сколько языков:** два — русский и английский.
- **Откуда берётся текст отказа:** сервер отдаёт код, текст рисует админка.
- **Чем переводить:** свой загрузчик словаря, как у кита, а не новая зависимость.

## Что в дереве уже есть

- Словарь на два набора и службу подписей завела RT-2209; экраны входа перевела RT-2210, экраны
  разделов — RT-2211.
- У приёмника уже есть образец кода отказа: набор `ECargoFault` в общей либе — им приём груза
  называет дереву, чем груз не прошёл проверку формы.
- Админка показывает слово приёмника как есть: `spokenFaultText` берёт его из тела ответа у кодов
  400, 404 и 409, а на поломку службы показывает свою строку.

## Измерение на 18 сентября

Бросков отказа с русским текстом в приёмнике 43: учётные записи 19, деревья 8, права 7,
наблюдения 5, предложения 2, разборы 2. Каждый из них уезжает человеку как есть — при любом выборе
языка.

Мест, где админка показывает это слово, девять: семь панелей и два стора.

## Решения

- **Задача пишет свою договорённость.** Набор кодов отказа — это обещание обеим сторонам: приёмник
  отвечает кодом, админка рисует по нему текст. Прежние описания такого обещания не содержат.
- **Отказы приёма груза в счёт не входят.** Их читает не человек в браузере, а средство дерева, и
  печатает владельцу оно само; трогать их — отдельная работа и отдельное слово владельца.

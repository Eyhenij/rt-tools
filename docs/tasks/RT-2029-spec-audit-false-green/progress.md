## Решения по ходу

- **Исключение теста действует только для кода приложения** — помощник, объявленный в самой
  обвязке тестов, тестами и зовётся по своему назначению: судимые той же мерой, статьи правила о
  тестах покраснели бы разом. Затронут этап плана: 2.
- **Дерево называет файлы обвязки ключом `harnessDirs`** — первым заходом туда попал весь каталог
  витрины, и красными стали компоненты, которые истории зовут по-настоящему. Список сужен до
  одного файла обвязки съёмки. Затронут этап плана: 2.
- **Символ опубликованного файла считается живым** — у кита, который ставят другие деревья, зовут
  его снаружи, и по видимым здесь вызовам весь публичный набор читался бы мёртвым кодом.
  Опубликованные файлы собираются обходом `public-api.ts` и `index.ts`. Затронут этап плана: 2.
- **Статья о двусмысленных именах получила вердикт, а не адрес** — функция написана, покрыта
  тестом и не зовётся ниоткуда: набор с двусмысленным именем проходит молча. Заведена задача
  #2041, вердикт называет её. Затронут этап плана: 2.

- **Номер сценария расширен до четырёх цифр, префикс — до шести букв** — выражение брало номер из
  одной-трёх цифр, и вся тысячная серия этого дерева не считалась вовсе: 54 сценария, их отметки
  покрытия и ссылки на них из тестов. Затронут этап плана: 1.
- **Слово «нет» в строке процедур принимается с пояснением, а не одно** — пятнадцать законных
  шапок писали «none — операции объявлены контроллерами», и требование одного слова сделало их
  неразобранными разом. Затронут этап плана: 1.

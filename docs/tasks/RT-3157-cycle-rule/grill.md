# Grill

## The owner request

Разбор всего эпика лежит в записи архива задачи RT-3152. Карточка задачи: правки идут из мнения, и
нельзя понять, помогла ли правка. Нужно правило цикла: отчёт называет худшую причину, задача и заметка
о выпуске называют метрику и ожидаемое направление, следующий отчёт показывает итог. Правка, которая
ничего не сдвинула, называется так прямо. Готово, когда правило лежит в пакете, а шаблон выпуска требует
метрику.

## Decisions

- **Цикл лежит паттерном правила `task-flow`.** Его может выполнить любое дерево: своя правка правил тоже
  называет число. Вопрос закрыт допущением: граница пакета пускает то, что потребитель выполняет сам.
- **Выпуск живёт в этом дереве.** Выпуск пакета запускается только отсюда, поэтому обязательное поле и его
  разбор стоят в шаге выпуска и в `agent-kit-source`, а не в пакете.
- **Шаблон выпуска — обязательное поле запуска.** Журнал собирается из коммитов, и отдельного файла шаблона
  нет. Запуск без метрики отказан, а строка встаёт под заголовком версии.
- **Выпуск без такой правки называет причину.** Починка ничего не обязана сдвигать, но молчание неотличимо
  от забытого поля.
- **Договорённость вливается здесь.** Владелец решил это при заведении эпика: последним коммитом RT-3157.

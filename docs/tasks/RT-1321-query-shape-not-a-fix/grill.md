# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `patterns/git-workflow-migration.md`.
Отметить её этому дереву нечем: токен двигает только свои записи, работа при этом наша.

## Форма запроса переписывалась, пока не прошла

> Гард записи в хранилище одинаково спрашивает и на условии по одному идентификатору, и на
> условии по их списку — отказ он даёт только на условие не по идентификатору. В режиме, где
> вопрос читается отказом, исполнитель переписывает форму запроса до тех пор, пока она не
> пройдёт, и уносит из захода вывод «гард требует форму со списком». Вывод неверен, а проверить
> его нечем, кроме прогона самого гарда на обеих формах.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки не заводится: переписывание формы запроса от обычной правки запроса машине неотличимо.

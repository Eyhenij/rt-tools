# Замысел

**Поведение:** не меняется — правится текст паттерна о миграциях.

## Что делается

1. В частые промахи, следом за пунктом об адресации строк по первичному ключу, встаёт пункт:
   формой запроса вопрос гарда не снимается.
2. Пункт называет ход: назвать владельцу отбитую команду и попросить режим, в котором вопрос
   дойдёт, — а не переписывать запрос, пока он не пройдёт.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

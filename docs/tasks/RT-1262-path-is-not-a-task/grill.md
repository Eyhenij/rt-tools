# Разбор просьбы

Запись груза из приёма, соседнее дерево. Отметить её этому дереву нечем — токен двигает только
свои записи; работа при этом наша, ресурс живёт здесь.

- **место:** раздел «Ловушки» правила ведения работы, в конец
- **повод:** строка с адресом файла прочитана как поручение, потому что другой реплики в заходе
  не было; своего смысла у неё нет вовсе.
- **готовый текст:** «Путь к файлу заданием не бывает. Строка с адресом называет файл, а не
  действие; прочитанная как поручение, она даёт заходу задание, которого владелец не давал. То
  же и с любой репликой, где нет глагола: уточнить дешевле, чем написать полсотни файлов мимо
  просьбы.»

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

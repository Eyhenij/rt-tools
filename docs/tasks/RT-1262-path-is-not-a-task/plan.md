# Замысел

**Поведение:** не меняется — правится правило и его компаньон, требований к продукту задача не
трогает.

Правило хода говорит, как читается реплика владельца — пересказ порядка, прерывание работы, —
и молчит о реплике, в которой действия нет вовсе.

## Этапы

1. Статья в «Как закон применяется здесь» правила хода — рядом со статьями о чтении реплик
   владельца.
2. Привязка в компаньоне правила этого дерева.
3. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Гарда на это не заводится: отличить реплику без глагола от короткого поручения машине нечем, а
отбитие каждой такой реплики стоило бы вопроса владельцу там, где всё ясно.

## Что считается сделанным

- В закреплённой моде панель без разделов места не занимает: она не помечена открытой, ручки
  тяги в разметке нет.
- Нажатие пункта полосы переставляет закреплённое подменю на его разделы.
- Переход на страницу без разделов снимает закреплённое подменю.
- Закреплённый пункт полосы помечен залитым значком, а не только цветом.
- Главная ветка влита, сценарии кита перенумерованы без столкновений.

## Этапы

### 1. Панель без разделов и залитый значок

- **Что делается:** ширина панели ставится только открытой панели; значок закреплённого пункта
  залитый.
- **Признак готовности:** сценарии SC-UK-50, SC-UK-51, SC-UK-52 зелёные.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit --testFile=side-menu/menu` — тесты
  бокового меню зелёные.

### 2. Главная ветка влита, спеки сошлись

- **Что делается:** вливание `origin/main`, разбор столкновения номеров сценариев.
- **Признак готовности:** сверка спеков без расхождений.
- **Чем проверяется:** `npm run check:specs` — код выхода 0.

## Чего эта работа не делает

- Не меняет нижний предел ширины подменю: он решён в RT-1673. Замена ширины оформления шириной
  тяги в ветку не идёт, пока владелец не скажет обратного.

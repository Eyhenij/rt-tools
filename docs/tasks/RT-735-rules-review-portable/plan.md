# Замысел

**Задача:** RT-735 · **Ветка:** RT-735-rules-review-portable
**Поведение:** не меняется — правятся тексты ресурсов пакета и привязки при них; кода эта работа
не трогает.

## След задачи

| Что            | Где                                                           |
| -------------- | ------------------------------------------------------------- |
| Команда        | `projects/agent-kit/assets/commands/rules-review.md`          |
| Роль           | `projects/agent-kit/assets/agents/rules-reviewer.md`          |
| Правило слоя   | `projects/agent-kit/assets/skills/agent-kit.md`               |
| Договорённость | `docs/specs/agent-kit/proposed/rules-review/`                 |
| Сверки         | `npm run check:specs`, `bash projects/agent-kit/tests/run.sh` |

## Что считается сделанным

- Команда говорит первой строкой, что зовётся в репозитории самого пакета: чужое дерево не
  получает от неё уверенного неверного ответа.
- Сбор семьи находит паттерны и у тех правил, чьё имя несёт суффикс требования, а не только вид.
- Правило слоя перечисляет все команды, которые исполняет агент, и число в тексте не расходится
  с составом каталога.
- Ни одна привязка утверждения о роли не держится словом из чужой строки.
- Ни один сценарий договорённости не помечен непокрытым по причине, которой больше нет.
- В переносимых текстах нет ни истории одного дерева, поданной фактом, ни снимка счёта, который
  стареет сам.

## Этапы

### 1. Команда и роль приведены к переносимости

- **Что делается:** оговорка о репозитории пакета; сбор семьи учитывает суффикс требования
  наравне с видом — и в команде, и в роли; снимок счёта законов снят; история одного дерева из
  роли убрана.
- **Признак готовности:** ни в команде, ни в роли нет утверждения, которое в чужом дереве
  окажется ложным.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`, чтение обоих текстов целиком.

### 2. Правило слоя и привязки договорённости

- **Что делается:** перечень команд агента приведён к составу каталога; три привязки утверждений
  о роли переставлены на слова, которые эти утверждения и держат; два сценария и утверждение
  компаньона приведены к тому, что в дереве уже есть.
- **Признак готовности:** сверка спеков не печатает новых строк, а каждая правленая привязка
  ведёт в предложение о том же, о чём утверждение.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`.

### 3. Раскладка

- **Что делается:** правленые ресурсы раскладываются в это дерево.
- **Признак готовности:** разложенное сходится с пакетом.
- **Чем проверяется:** `pnpm run agent-kit:sync`, `pnpm run agent-kit:check`.

## Чего эта работа не делает

- Не заводит проверки на адреса дерева в командах: набор запретов читает правила и паттерны, а
  расширение его области — своя работа с своей ценой.
- Не трогает машинной половины ревью и графов хода: это задачи RT-703 и RT-705.
- Не переписывает сверку привязок: то, что она ищет слово по всему файлу, — известная её
  граница, названная в правиле спеков.

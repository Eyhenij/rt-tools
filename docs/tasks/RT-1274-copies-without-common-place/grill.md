# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `rules/shared-code.md`. Отметить её этому
дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Копии, которым общего места не найти

Три копии одной таблицы переводили значение схемы хранилища, а общая либа контракта его не видит
и видеть не должна: ребро оттуда развернуло бы зависимость. Правило требует свести копии и
молчит о случае, когда общего места у них нет по границам импортов, — и следующий исполнитель
либо заведёт либу, либо расширит границы общей.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

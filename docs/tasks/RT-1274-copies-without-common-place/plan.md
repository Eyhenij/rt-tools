# Замысел

**Поведение:** не меняется — правится текст слоя правил, кода за ним нет.

## Что делается

В раздел «Как закон применяется здесь» в `rules/shared-code.md` встаёт статья о копиях, у
которых общего места нет по границам импортов: сводятся они в слой, который видят обе стороны, а
не в общий, и новая либа под это не заводится.

Статья получает строку в компаньоне правила — привязку или вердикт с причиной.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `npm run check:specs`,
`node tools/check-file-size.mjs`, `node tools/check-doc-paths.mjs`.

# Разбор просьбы

## Просьба владельца

> заводи новый эпик на изменения в меню навигации которые ты сейчас делаешь

Задача — вторая в эпике RT-1657. Исходная просьба, из которой она вышла, звучала так:

> нужно сделать его статичным по настройке пользователя

## Что уже есть в дереве

- Мода подменю — вход компонента; смену он только просит выходом. Хранит её потребитель.
- В показе выбор лежал полем в памяти обёртки и терялся при перезагрузке.
- У кита есть образец хранения настройки человека — служба темы: она пишет выбор в хранилище
  браузера и допускает его отсутствие.

## Решения

- **Ключ и разбор значения даёт кит, а хранит потребитель.** Кит не знает, где у приложения лежат
  настройки человека, но общий ключ избавляет каждое приложение от своего.
- **Отказ хранилища работу не останавливает.** Приватное окно и запрет данных сайта отдают
  хранилище закрытым; упавшее чтение оставило бы человека без меню вовсе.
- **Незнакомое значение читается как пустое.** Прежней модой, наведением.

## Что осталось невыясненным

- Показ хранение не демонстрирует: Storybook подставляет вход своим значением аргумента и
  перебивает поле обёртки. Признак записи в браузере снят, признак чтения после перезагрузки —
  нет. Названо ценой решения в описании прошлого.

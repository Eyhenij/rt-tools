## Done sign

У обеих семей выбора есть вход, которым потребитель подставляет свой указатель вместо зашитого
поля: подпись, значок, метка-бейдж — что угодно. Панель, выбор, клавиши и закрытие при этом те же.
`@angular/material` в правке не появляется. Кадры показов сняты, и на них видно оба указателя —
зашитый и свой.

## Stages

1. **Измерение: годится ли один вход обеим семьям.** Читаются указатели `select` и `multiselect` и
   два образца приложения; выписывается, чем они отличаются и что указателю нужно от семьи —
   состояние открытости, выбранное значение, отключённость. Признак готовности: в состоянии задачи
   записано решение с числами — один вход на обе семьи или своя семья поверх них, и почему.
2. **Договорённость.** Правила о своём указателе дописываются в `docs/specs/ui-kit-v2/select/`;
   сценарии берут следующие свободные номера `SC-UKV`. Признак: `npm run check:specs` называет
   новые сценарии без теста — это законно до этапа 4.
3. **Вход написан.** Указатель подставляется шаблоном, зашитый остаётся умолчанием. Признак:
   `pnpm exec nx run-many -t lint typecheck build -p @rt-tools/ui-kit-v2` зелёный.
4. **Проверки.** Тесты на обе семьи: свой указатель рисуется, панель открывается им, выбор доходит.
   Признак: `pnpm exec nx test @rt-tools/ui-kit-v2` зелёный, `npm run check:specs` без расхождений.
5. **Витрина.** Показ со своим указателем у обеих семей; кадры сняты. Признак:
   `node tools/visual-gate.mjs ui-kit-v2` — все снимки сходятся, осиротевших нет.
6. **Сличение с образцом.** Кадр своего указателя рядом с `cc-badge-select` приложения: расхождение
   цвета, скругления, кегля, тени или отступа — дефект. Признак: расхождения названы словами и
   закрыты или объявлены с причиной.

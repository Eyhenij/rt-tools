## Что делается

1. Обоснование запрета на имя файла предложения переписывается: держать каталог в истории дерево
   вправе, а имя всё равно не называют — читателю чужого дерева оно не даёт ничего.
2. В «Ловушки раскладки» встаёт пункт о том, что запись файла командой оболочки судится по всем
   путям её тела, и что инструмент правки судится одним своим путём.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`.

# Разбор просьбы

Девять записей груза из приёма, соседние деревья, ресурс `skills/agent-kit.md`. Отметить их
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Запрет на имя файла предложения держится ни на чём

Статья объясняет запрет тем, что каталог предложений в историю не едет. В дереве-источнике он
едет: три с половиной десятка файлов лежат в истории отдельными коммитами. Под таким деревом
объяснение не работает, адрес на файл ведёт куда надо, и причина не называть его остаётся
неназванной.

## Запись файла командой судится по всем путям её тела

Гейт правил вынимает пути из текста команды, а тело документа читает целиком, как только в
команде встречается имя интерпретатора. Строка импорта разложенного модуля требует тогда правило
пакетного слоя наравне с правилом самого файла, а требуется за раз одно: два отказа подряд, и
каждый унёс уже написанное тело файла.

## Что в работу не берётся

Семь записей закрыты прежними редакциями: строка `enroll` в списке команд, абзац о том, откуда
берутся адрес приёма и токен, раздел «Подъём версии» со снимком прежней редакции, ловушка о
сценариях гардов, ловушка о своём, что стоит рядом с разложенным, и разбор адреса репозитория не
у одного `origin` — он сделан правкой самой команды.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Этапы

### 1. Раскладка новой редакции

- **Что делается:** `npm run agent-kit:sync` — сборка пакета из исходников дерева и раскладка
  из неё.
- **Признак готовности:** `agent-kit:check` сходится с v0.4.0.
- **Чем проверяется:** `npm run agent-kit:check`.

### 2. Разбор папки закрытой задачи

- **Что делается:** разбор просьбы, решения и прогон утверждений задачи #322 складываются одним
  файлом в `docs/archive/`; замысел и задание аудита удаляются.
- **Признак готовности:** сверка очереди не называет папок закрытых задач среди текущих.
- **Чем проверяется:** `npm run check:board`.

### 3. Проверки дерева на новой раскладке

- **Что делается:** прогон проверок, которые раскладка задела, — сверка спеков ходит по новым
  корням, сверка путей в документах видит меньше битых ссылок.
- **Признак готовности:** число расхождений не выросло ни у одной проверки.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`, `npm run check:board`,
  `nx run-many -t lint typecheck test build verify --all`.

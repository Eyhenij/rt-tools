# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — Ярус «ход кончился ожиданием»
- **Сделано:** задача, ветка, папка, замысел, разбор происшествия
- **Следующий шаг:** ярус «ход кончился ожиданием» в страже
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет
- **PR:** ещё не открыт

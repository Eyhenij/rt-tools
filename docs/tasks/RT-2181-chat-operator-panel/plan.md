## Что считается сделанным

- Оператор открывает раздел чата в админке, видит переписки своих сайтов с отбором по сайту и
  состоянию и читает ленту выбранного разговора.
- Оператор отвечает посетителю из поля набора, и отправленная реплика видна на экране сразу, до
  ответа сервиса.
- Пришедшая реплика посетителя появляется в открытой ленте сама, без обновления страницы.
- Раздел закрыт правом своего пункта меню и тем же правом — по адресу; данные закрыты записью
  оператора чата.
- Сценарии `SC-CH-36` и дальше закрыты пробами или несут пометку с причиной; то, что человек
  видит на экране, закрыто сквозными пробами.

## Этапы

### 1. Договорённость о панели оператора

- **Что делается:** описание в `docs/specs/chat/proposed/operator-panel/` — что на экране, чем
  закрыт раздел, что происходит с отправленной репликой до ответа сервиса и что видно тому, кто
  оператором не числится; сценарии к нему.
- **Признак готовности:** сверка спек не называет по новому описанию ни пропущенного раздела, ни
  занятого номера сценария.
- **Проверяется:** `node tools/check-specs.mjs` — ни строки про пропущенный раздел.

### 2. Ответ оператора и право раздела

- **Что делается:** операция приёма ответа оператора в приёмнике — закрыта входом человека,
  пишет сообщение стороной оператора и шлёт событие подписчикам; имя права `chat:read` в общем
  наборе прав.
- **Признак готовности:** пробы домена чата зелёные, сборка приёмника зелёная.
- **Проверяется:** `pnpm exec nx run-many -t test -p message-bus-api-chat-feature message-bus-api-chat-util`
  — «Successfully ran target test»; `pnpm exec nx build message-bus` — «Successfully ran target build».

### 3. Слой данных панели в админке

- **Что делается:** область чата в админке слоями — модель и сопоставление ответа приёмника,
  обращения к операциям чтения, отправки и потока событий.
- **Признак готовности:** пробы новых либ зелёные, границы раскладки не нарушены.
- **Проверяется:** `pnpm exec nx run-many -t test,lint -p message-bus-admin-chat-util message-bus-admin-chat-data-access`
  — «Successfully ran targets».

### 4. Экран раздела

- **Что делается:** список переписок с отбором, лента разговора, поле набора; пункт меню,
  маршруты раздела и подписи в обоих наборах админки.
- **Признак готовности:** пробы и сборка админки зелёные, подписи есть в обоих наборах.
- **Проверяется:** `pnpm exec nx run-many -t test -p message-bus-admin` — «Successfully ran target
  test»; `pnpm exec nx build message-bus-admin` — «Successfully ran target build».

### 5. Сквозные пробы, договорённость вливается и PR

- **Что делается:** сквозные пробы на то, что видит человек; описание переезжает в спеку домена
  вместе с привязками, папка задачи разбирается записью в `docs/archive/`, набор перед отправкой
  прогоняется целиком, PR открывается в ветку эпика готовым.
- **Признак готовности:** сквозной набор зелёный и длиннее прежних 133 сценариев, сверка спек —
  нулевой код, PR открыт с рецензентом.
- **Проверяется:** `pnpm exec nx run message-bus-admin-e2e:e2e` — «134 passed» и больше;
  `node tools/check-specs.mjs` — нулевой код; `gh pr view <номер> --json isDraft,reviewRequests`
  — черновика нет, рецензент назван.

## Чего эта работа не делает

- **Виджет посетителя, извещения и выкатка** — задачи RT-2182 … RT-2184.
- **Признак «посетитель набирает текст».** Ни телом задачи, ни описанием сервиса он не обещан.
- **Разделение чата в отдельное приложение.** Оно отложено на выкатку RT-2184, и панель идёт
  туда же, где лежат операции.

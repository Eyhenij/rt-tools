## Решения по ходу

- **Ветка заведена без номера задачи, потому что номер выдать было нечем.** Имя без номера
  законно, пока ветка живёт локально; PR с неё не открывается. Номер получен позже, и ветка с
  папкой переименованы под него.
- **Ждать возврата предела было незачем: очередь работ ходит записью владельца.** Заведение
  задачи упёрлось в отказ про исчерпанный предел и было отложено до срока, который назвал
  хостинг. Отложено зря: квота машинной записи на язык запросов не исчерпана, а равна нулю, и
  ключа `board.tokenPath` в настройках дерева нет с той поры — обвязка борды и без него ходит
  учётной записью, под которой залогинен клиент хостинга. Сказано это прямым текстом в
  `.claude/skills/git-workflow/implementation.md`, и прочитать его стоило раньше, чем поверить
  тексту отказа.
- **Префикс сценариев остался один на домен, а сверка научена этому.** Своя нумерация у каждого
  поддомена потребовала бы пересчёта всех 109 номеров, а номер связывает сценарий с заголовком
  теста. Владельцем префикса стало дерево домена, а не отдельный каталог.
- **Границы поддоменов взяты те, что уже были проведены группами правил.** Пятнадцать групп
  легли в четыре поддомена без остатка, ни одна не поделена пополам.

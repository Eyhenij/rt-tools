# Grill

## The owner request

> поставь задачу той сессии кита которая делала пакет протокола

Суть задачи: в пакете протокола чата нет готового контроллера запуска. Каждое приложение пишет повтор запроса, остановку и цикл браузерных инструментов заново.

## What the tree already has

- Пакет `@rt-tools/ai-chat-protocol` версии 0.2.1: порты запуска и потоков, чтение событий, редьюсер состояния, записанные потоки в `fixtures/`.
- Редьюсер знает результат `awaitingFrontendTools` и список `pendingToolCallIds`.
- `isRetryableBeforeStream` называет виды ошибок, после которых запрос повторяется.

## What the rules already say

- Покрытие пакета 100%: каждая ветка новых файлов закрыта тестом.
- Публичный интерфейс только дополняется; без реестра инструментов всё работает как раньше.

## Questions and answers

Вопросов владельцу нет: условия заданы поручением.

## Decisions

- **Транспорта в пакете нет** — контроллер работает через порт запуска. Rejected: свой fetch.
- **Контроллер и реестр — фабрики без Angular** — пакет без фреймворка.

## What is left unclear

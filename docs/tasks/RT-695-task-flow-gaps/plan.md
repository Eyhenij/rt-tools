## Что считается сделанным

- Образцы папки задачи и образец спека домена приезжают раскладкой: свежее дерево получает их
  установкой, а не заводит руками.
- Ни одного вхождения слова, снятого словарём для эпика, в ресурсах пакета и в разложенном слое.
- У замысла эпика назван род записи в правиле, путь — в компаньоне дерева, и в счёте шагов есть
  шаг, которым эпик объявляется.
- Разбор закрытой задачи правилами стоит в счёте шагов, а сами шаги идут в том порядке, в каком
  работа случается.
- Компаньон правила `task-flow` не расходится с тем, что делает команда заведения задачи.
- Зелёные: `pnpm exec nx test @rt-tools/agent-kit`, `npm run check:specs`, `npm run check:docs`,
  `npm run agent-kit:check`, линтеры и сборка.

## Этапы

### 1. Род образцов в пакете

- **Что делается:** новый род ресурса в `config.ts` с раскладкой в каталог документов; в
  ресурсы пакета кладутся три образца папки задачи и образец спека домена.
- **Признак готовности:** план раскладки называет образцы, дерево вправе назвать им свой путь и
  снять их списком отказа.
- **Чем проверяется:** сценарии `SC-AK-202`, `SC-AK-203`, `SC-AK-204` в `plan.spec.ts`.

### 2. Образцы приезжают в это дерево

- **Что делается:** раскладка; свои образцы дерева заменяются разложенными, расхождение с ними
  уходит в надстройку, если оно нужно дереву.
- **Признак готовности:** `agent-kit:check` зелёный, отказ гарда хода работы советует каталог,
  который есть.
- **Чем проверяется:** `npm run agent-kit:check`, `npm run check:docs`.

### 3. Счёт шагов пересобран

- **Что делается:** в правиле `task-flow` таблица шагов идёт в порядке, в каком работа
  случается; в счёт встают объявление эпика и разбор закрытой задачи правилами; номера разделов
  в паттернах `task-flow-start`, `task-flow-resume`, `task-flow-close`, `task-flow-handoff`
  правятся тем же коммитом.
- **Признак готовности:** ни одного номера шага, стоящего в паттерне и не стоящего в таблице, и
  наоборот.
- **Чем проверяется:** чтение четырёх паттернов целиком, поиск по номерам шагов.

### 4. У эпика есть адрес, у слова — замена

- **Что делается:** правило называет род записи замысла эпика, компаньон дерева — путь; слово,
  снятое словарём, вычищается из ресурсов пакета сплошным поиском.
- **Признак готовности:** поиск по снятому слову в ресурсах пакета и в разложенном слое пуст.
- **Чем проверяется:** сплошной поиск, просмотр самой правки.

### 5. Компаньон дерева приведён к сделанному

- **Что делается:** строка о переименовании папки задачи руками правится на то, что делает
  команда заведения задачи.
- **Признак готовности:** компаньон и вывод команды говорят одно и то же.
- **Чем проверяется:** чтение вывода `task:new` из этой же работы.

### 6. Проверки и PR

- **Что делается:** гейт пуша целиком, вливание договорённости в спек домена, приведение
  текстов, разбор папки задачи.
- **Признак готовности:** PR открыт, прогон зелёный, за работой убрано.
- **Чем проверяется:** гейт пуша, `check:specs`, `check:board`.

## Чего эта работа не делает

- Статьи закона не правит: если по ходу окажется, что закону не хватает статьи об адресе
  замысла эпика, её текст приносится владельцу отдельно.
- Ограничение машинной учётной записи не снимает — это `RT-572`.
- Двух других предложений домена (`feedback-loop`, `push-gate-scope`) не трогает.

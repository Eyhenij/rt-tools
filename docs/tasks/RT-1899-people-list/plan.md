## What counts as done

- В админке есть раздел со списком людей: имя, роль, состояние записи, последний вход.
- Раздел закрыт правом `accounts:read`: без него пункт меню не показывается и адрес не открывается.
- Операция чтения в приёмнике закрыта тем же правом и без него отвечает отказом.
- Договорённость влита в описание домена, сценарии связаны с тестами.

## Stages

### 1. Договорённость о разделе

- **Steps:**
    1. договорённость о разделе: что показывает список и чем закрыт
    2. сценарии на список, отбор и отказ без права
- **What is done:** обещание записано до кода.
- **Readiness sign:** проверка описаний видит договорённость и её сценарии.
- **Verified by:** `node tools/check-specs.mjs` — договорённость названа в списке готовых к слиянию.

### 2. Чтение записей в приёмнике

- **Steps:**
    1. чтение записей в приёмнике: операция закрыта правом `accounts:read`
    2. тесты на операцию: без права отказ, с правом список
- **What is done:** приёмник отдаёт список людей и закрывает его правом.
- **Readiness sign:** тесты операции зелёные, без права приходит отказ.
- **Verified by:** `pnpm exec nx test message-bus-api-accounts-feature` — 0 провалов.

### 3. Раздел админки

- **Steps:**
    1. раздел админки: пункт меню, адрес, экран списка
    2. тесты экрана
- **What is done:** человек с правом видит пункт и список, без права — не видит ни того, ни другого.
- **Readiness sign:** тесты экрана зелёные.
- **Verified by:** `pnpm exec nx test message-bus-admin-accounts-feature` — 0 провалов.

### 4. Закрытие

- **Steps:**
    1. договорённость влита в описание домена
    2. сквозной тест на раздел
- **What is done:** обещание живёт в описании домена, путь человека пройден целиком.
- **Readiness sign:** сквозной набор зелёный.
- **Verified by:** `pnpm exec nx e2e message-bus-admin-e2e` — 0 провалов.

# Замысел

**Спек:** `docs/specs/ui-kit-v2/chat-actions/spec.md`

## Что делается

У реплики переписки заводится точка проекции для действий потребителя — тем же приёмом, каким
она сделана у строки таблицы: шаблон, захваченный директивой, предикат видимости и вывод в меню.

## Этап 1 — точка действий у реплики

**Что делается:** директива захвата шаблона с контекстом реплики, предикат видимости входом кита,
чистый пайп над ним и вывод шаблона в меню рядом с точечными действиями реплики. Точечные
действия остаются на месте.

**Чем проверяется:** `nx test @rt-tools/ui-kit-v2` — спека покрывает объявленный шаблон,
необъявленный и предикат, отдающий ложь.

## Этап 2 — показ и снимок

**Что делается:** история витрины показывает своё действие у реплики; снимки пересняты, если
разметка реплики без шаблона осталась прежней — не пересняты вовсе.

**Чем проверяется:** `node tools/visual-gate.mjs ui-kit-v2` — кадры сходятся.

## Этап 3 — договорённость домена

**Что делается:** поддомен спека второго кита получает статьи, сценарии и привязки; оглавление
домена и перечень сценариев называют новый поддомен.

**Чем проверяется:** `node tools/check-specs.mjs` — расхождений нет.

## Чего не делается

- Точечные действия реплики не снимаются и в шаблон не переезжают: удаление, повтор отправки и
  скачивание общи для любой переписки.
- Поле действий в модели реплики не заводится: действие приходит разметкой потребителя.

# Разбор просьбы

## Просьба владельца

> после обновления agent kit делай задачи из техдолга из приёмника, одну за другой, без
> остановок… не пуш ветки - храни все ветки локально… твоя задача - закрыть как можно больше
> задач в локальных ветках до утра.

## Что взято из приёмника

Две записи своего дерева, обе о том, что ответ хостинга читается не той стороной.

**Ключ `787ace21`** — место: рядом со статьёй о том, что PR открывается учётной записью машинной
работы. Повод: ответ хостинга приходит той же записи, которая запись и завела, и для неё
заведённое существует всегда. Полнотой это не является: PR открывается для человека, задача
заводится для очереди работ. Ограниченная запись отвечает остальным «не найдено», и с её стороны
это выглядит успехом. Шестнадцать задач так были заведены дважды, а PR назван номером, которого
для владельца нет.

**Ключ `7d3c8f1a`** — место: ловушки правила. Повод: предел запросов у ограниченной записи не
исчерпан, а равен нулю, и отказ по нему — единственный ранний признак ограничения. Обойдённый
вызовом другого рода, он унёс с собой этот признак: обход сработал, работа пошла дальше, а
расхождение всплыло у владельца через двадцать минут и четыре следа, которые пришлось
переписывать.

## Чего владелец не спрашивал

Вопросов ночью не задаётся. Прочтение принято такое: обе записи об одном корне — ограниченная
учётная запись видит своё и не видит чужого, — и чинятся они одной правкой.

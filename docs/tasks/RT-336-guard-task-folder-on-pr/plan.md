**Задача:** RT-336 · **Ветка:** RT-336-guard-task-folder-on-pr
**Драфт:** `docs/specs/agent-kit/`
**Поведение:** меняется

Договорённость ведётся прямо в спеке пакета, без `proposed/`: так решил владелец — работа
закрывается одной веткой, и директория предложенного завелась бы и умерла в том же отчёте.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Слияние отчёта отбивается, пока ветка несёт папку своей задачи; отказ называет папку и то,
  чем снимается.
- Отказ проверен опытом на самой этой работе: текст отказа настоящего разложенного гарда
  записан в `progress.md` дословно.
- Обход с причиной проходит и без сети; обход без причины — нет.
- Сверка очереди работ называет расхождением вложенную папку закрытой задачи и не называет ни
  образец, ни черновики разбора.
- Прогон пакета зелёный, и каждый сценарий `SC-AK-12`…`SC-AK-21` покрыт хотя бы одним тестом.
- Правка разложена в это дерево; ни один файл с шапкой `rt-kit v…` не правлен на месте.
- Правило `task-flow` больше не утверждает, что разбор папки не проверяется ничем.

## Этапы

### 1. Гард поставки: требование папки на слиянии

- **Что делается:** в `projects/agent-kit/assets/hooks/git-guard-delivery.sh` заводится ярус
  папки — перехват команды слияния, поиск папки по имени ветки целиком в содержимом ветки,
  требование прибыли в каталоге архива, обход строкой с причиной из текста команды и из тела
  отчёта, когда очередь доступна. На открытии отчёта — подсказка вместо отказа.
- **Признак готовности:** сценарии `SC-AK-12`…`SC-AK-19` и `SC-AK-21` описаны тестами и
  зелёные; намеренно сломанная строка требования красит прогон.
- **Чем проверяется:** `bash projects/agent-kit/tests/git-guards.test.sh`,
  `bash projects/agent-kit/tests/syntax.test.sh`.

### 2. Сверка очереди работ видит вложенную папку

- **Что делается:** в `projects/agent-kit/assets/checks/check-board.github.mjs` обход каталога
  задач идёт вглубь; номером считается и голое число в имени; образец и черновики разбора
  отсеиваются на любом уровне.
- **Признак готовности:** `SC-AK-20` покрыт; вложенная папка закрытой задачи названа
  расхождением, образец и черновики — нет.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks.test.sh`, `npm run check:board`.

### 3. Закон и правило

- **Что делается:** статья в `projects/agent-kit/assets/laws/work-conduct.md`; статьи о новой
  сторожевой точке и обходе в `projects/agent-kit/assets/rules/task-flow.md` и в паттерне
  закрытия; из раздела «Чего из закона здесь нет» уходит утверждение, что разбор папки не
  стережёт ничто.
- **Признак готовности:** ни один текст пакета не утверждает снятого; формулировка статьи
  закона показана владельцу.
- **Чем проверяется:** `bash projects/agent-kit/tests/texts.test.sh`, чтение владельцем.

### 4. Раскладка в это дерево

- **Что делается:** `pnpm run agent-kit:sync`; своё значение дерева — надстройкой, а не правкой
  разложенного.
- **Признак готовности:** разложенное сходится с пакетом.
- **Чем проверяется:** `pnpm run agent-kit:check`, `pnpm exec nx run-many -t lint test build
--projects=agent-kit`.

### 5. Привязки договорённости к коду

- **Что делается:** в `docs/specs/agent-kit/implementation.md` появляется строка
  «правило → файл:символ» на каждое новое правило спека.
- **Признак готовности:** названный символ находится грепом.
- **Чем проверяется:** `npm run check:specs`.

### 6. Проверка опытом на самой этой работе

- **Что делается:** папка задачи разбирается последним коммитом; попытка слить отчёт до разбора
  отбивается настоящим разложенным гардом, и текст отказа записывается в `progress.md`.
- **Признак готовности:** отказ показан, обход с причиной проходит, без причины — нет.
- **Чем проверяется:** сами команды; `npm run check:board`, `pnpm run check:all`.

## Чего эта работа не делает

- Не стережёт взятие задачи в работу: владелец выкинул это вторым заходом разбора — колонка про
  борду, а не про папку, и отставшую колонку сверка очереди уже находит.
- Не судит, что именно увезено в архив: это судит владелец, а не машина.
- Не объявляет старую форму имени ветки снятой: пока законна форма ветки, законна и папка.
- Не выпускает редакцию пакета в реестр — отдельным запуском позже.
- Не трогает 31 расхождение сверки очереди, не относящееся к папкам: долг задачи #318.

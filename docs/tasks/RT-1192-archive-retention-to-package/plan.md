# Замысел

**Задача:** RT-1192 · **Ветка:** RT-1192-archive-retention-to-package
**Поведение:** не меняется — правка задевает пакет правил, его раскладку и тексты; кода приложений в ней нет

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## След задачи

| Что     | Где                                                                                  |
| ------- | ------------------------------------------------------------------------------------ |
| Спеки   | `docs/specs/agent-kit/package-boundary/` — граница пакета судит новый ресурс         |
| Законы  | `docs/constitution/project-documentation.md` — описание прошлого под ним             |
| Правила | `.claude/skills/doc-style/`, `.claude/skills/archive-record/`                        |
| Код     | `projects/agent-kit/assets/`, `tools/`, `.claude/rt-kit/checks.json`, `package.json` |

## Что считается сделанным

- Ресурсы пакета несут отбор, команду чистки и проверку; в дереве они лежат разложенными
  копиями с шапкой, а не своими файлами.
- Умолчание пакета — срок не назначен: у дерева без ключа проверка молчит и ничего не сносит.
- Это дерево назначает неделю ключом настройки, и проверка остаётся зелёной.
- Пакетное правило текстов называет срок статьёй; надстройка дерева держит только своё.
- Выпущена новая версия пакета.

## Этапы

### 1. Ресурсы едут в пакет

- **Что делается:** отбор, команда чистки и проверка переносятся в `assets/checks/`; число
  суток читается из настроек, умолчание — не назначено.
- **Признак готовности:** раскладка кладёт три файла в `tools/` с шапкой пакета, свои копии
  сняты.
- **Чем проверяется:** `pnpm run agent-kit:sync` — в выводе три разложенных файла;
  `head -2 tools/check-archive-age.mjs` — шапка `rt-kit v…`.

### 2. Срок назначается деревом

- **Что делается:** ключ числа суток в `.claude/rt-kit/checks.json`.
- **Признак готовности:** проверка видит неделю и остаётся зелёной; без ключа — молчит.
- **Чем проверяется:** `node tools/check-archive-age.mjs` — зелено, называет срок;
  `RT_ARCHIVE_NO_CONFIG=1` не заводится — проверяется временным снятием ключа вручную.

### 3. Статья едет в пакетное правило

- **Что делается:** раздел о сроке переносится из надстройки в `assets/rules/doc-style.md`; в
  надстройке остаётся только своё.
- **Признак готовности:** разложенное правило несёт статью, а надстройка её не дублирует.
- **Чем проверяется:** `pnpm run agent-kit:check` — сходится; `npm run check:docs` — зелено.

### 4. Граница и набор

- **Что делается:** новый ресурс проходит проверку границы пакета; набор гейта и конвейер
  зовут разложенную проверку.
- **Признак готовности:** обе проверки зелёные.
- **Чем проверяется:** `node tools/check-boundary.mjs` и `node tools/check-push-gate.mjs`.

### 5. Выпуск

- **Что делается:** после слияния поднимается версия пакета и он публикуется.
- **Признак готовности:** npm отдаёт новую версию.
- **Чем проверяется:** `npm view @rt-tools/agent-kit version`.

## Чего эта работа не делает

- **Не меняет назначенного срока** — неделя остаётся неделей, меняется только место, где она
  записана.
- **Не трогает записи описания прошлого** — чистка сделана прошлой задачей.
- **Не навязывает срок чужим деревьям** — умолчание пакета молчит.
- **Не выпускает пакет до слияния** — публикация идёт отдельным решением владельца.

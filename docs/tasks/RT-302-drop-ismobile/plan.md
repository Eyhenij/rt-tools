## Что считается сделанным

- Ни один компонент кита не объявляет входа `isMobile`.
- `narrow` читает только службу замера.
- Витрина показывает мобильный вид без входа.
- `CHANGELOG.md` называет снятие ломающим изменением.

## Этапы

### 1. Снятие входа с компонентов

- **Что делается:** убираются объявления входа, отметки об устаревании и перекрытие замера в
  `narrow`.
- **Признак готовности:** поиск `isMobile` по коду кита находит только службу.
- **Чем проверяется:** `pnpm exec nx run @rt-tools/ui-kit:typecheck` — зелено.

### 2. Витрина и спеки

- **Что делается:** истории переводятся на рамку кадра, спеки правятся под новый договор.
- **Признак готовности:** мобильный вид виден без входа.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit` — зелено.

### 3. Запись выпуска

- **Что делается:** раздел ломающих изменений в `CHANGELOG.md`.
- **Признак готовности:** названо, что снято и чем заменено.
- **Чем проверяется:** `node tools/check-file-size.mjs` — новых длинных нет.

## Чего эта работа не делает

- Не заводит контейнерных запросов: узкую панель на широком экране кит по-прежнему не различает.

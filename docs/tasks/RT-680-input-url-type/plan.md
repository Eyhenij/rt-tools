## Что считается сделанным

- У перечня типов поля пятый член — адрес, и он уезжает на нативное поле.
- Спека перечисляет его наравне с прежними четырьмя своим списком, без правки тела теста.
- Документ компонента называет пятый тип там же, где называет прежние.
- Прежние четыре типа работают как раньше.

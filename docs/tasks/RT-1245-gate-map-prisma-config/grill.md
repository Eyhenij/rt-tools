# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `defaults/gate-map.sh`.

- **место:** ветка миграций
- **повод:** файл настройки клиента хранилища не ведёт ни к одному правилу, и правился он без
  правила под рукой.
- **готовый текст:** третий образец в той же ветке — настройка клиента рядом со схемой и
  каталогом миграций.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

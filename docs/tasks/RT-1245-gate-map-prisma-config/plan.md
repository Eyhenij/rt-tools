# Замысел

**Поведение:** не меняется — правится карта гейта правил, требования к продукту задача не
трогает.

Ветка миграций знает схему хранилища и каталог миграций и молчит о настройке клиента, которая
лежит рядом и читается тем же накатом.

## Этапы

1. Третий образец в ту же ветку карты.
2. Сценарий в наборе карты гейта.
3. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Правило ветка называет прежнее: делить её на две ради разных правил задача не берётся.

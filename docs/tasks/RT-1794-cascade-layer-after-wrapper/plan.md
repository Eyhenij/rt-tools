## Что считается сделанным

- Правило, дописанное после закрывающей скобки обёртки без отметки, роняет проверку слоя
  каскада.
- Правило, вынесенное с отметкой, проверку не роняет и названо в её выводе числом.
- Вынос правил видимости подложки панели проходит по отметке, а не строкой списка принятого.

## Этапы

### 1. Проверка видит правила после обёртки

- **Что делается:** проверка читает хвост файла за закрывающей скобкой обёртки и судит его:
  правило без отметки выноса — расхождение, с отметкой — принятый вынос.
- **Признак готовности:** дописанное после скобки правило роняет проверку, а файл панели с
  отметкой её проходит.
- **Чем проверяется:** `pnpm run check:cascade-layer` — зелёная на дереве как есть.

### 2. Проба на оба исхода

- **Что делается:** проба гоняет проверку на временном дереве — файл с отметкой и файл без
  неё.
- **Признак готовности:** проба падает, если проверка перестала видеть хвост файла.
- **Чем проверяется:** `bash tools/tests/run.sh` — все пробы зелёные.

## Чего эта работа не делает

- Стилей первого кита не касается: они в слой не обёрнуты вовсе, и проверка их не читает.
- Вынос правил видимости подложки не меняет: он сделан задачей RT-1771.

# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этапы-кончились`
- **Этап:** оба сделаны
- **Сделано:** проверка слоя каскада читает хвост файла за обёрткой и судит его по отметке
  выноса; заведён первый набор сценариев по проверкам дерева — 14 проб, на сломанной проверке
  краснеют 4 из них
- **Следующий шаг:** привести тексты, прогнать набор, разобрать папку и открыть заявку
- **Незакоммиченное:** правка проверки, набор проб, правило и его спутник
- **Ждём владельца:** нет
- **PR:** ещё не открыт

## Решения по ходу

- **Нарочный вынос узнаётся по отметке в файле, а не строкой списка принятого** — отметку
  читает тот, кто правит файл; список — только тот, кто его открыл. Затронутый этап: 1.
- **Набор сценариев по проверкам дерева заведён свой, а не дописан к набору пакета** — тот
  судит ресурсы пакета и поднимает фикстуру из его раскладки; проверки дерева читают корень от
  своего файла, и фикстура им нужна другая. Затронутый этап: 2.
- **Набор встал в гейт пуша строкой `bash tools/tests/run.sh`** — проверка, живущая только в
  сводной цели, отвечает тому, кто её вспомнил. Затронутый этап: 2.

# Замысел

**Задача:** RT-554 · **Ветка:** RT-554-empty-signals-green
**Спек:** `docs/specs/agent-kit/checks/spec.md`

## Что делается

Проверка единообразия отказывает там, где признаков не осталось ни одного, и признак глобали
судит положение имени, а не подстроку.

## Что считается сделанным

- Дерево без единого признака получает ненулевой код и строку с перечнем наборов при пакете.
- Признак глобали не срабатывает ни на имени внутри строки в кавычках, ни на обращении через
  поле объекта, ни в коде, у которого окна браузера нет вовсе.

## Этапы

### 1. Отказ при пустом наборе признаков

- **Что делается:** `loadSignals` отказывает, когда итоговый список пуст, и называет наборы,
  которые есть при пакете.
- **Признак готовности:** дерево без объявленных наборов получает ненулевой код.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — 0 провалов.

### 2. Признак глобали судит положение имени

- **Что делается:** признаки `raw-window` и `raw-media-query` перестают считать имя внутри
  строки в кавычках и обращение через поле объекта, а код без разметки под них не попадает.
- **Признак готовности:** прогон на образцах трёх законных случаев даёт ноль совпадений.
- **Чем проверяется:** `npm run check:reuse` — новых расхождений нет.

### 3. Договорённость

- **Что делается:** спек проверок получает две статьи с привязками и сценарии.
- **Чем проверяется:** `node tools/check-specs.mjs` — расхождений нет.

## Чего эта работа не делает

- Область действия набора не заводится: запись называет её пожеланием, а признак закрытия
  перечисляет другое.

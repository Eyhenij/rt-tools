# План

**Задача:** RT-2023 · **Ветка:** RT-2023-rights-migration-grants
**Behaviour:** changes

## Что задача затрагивает

| Что      | Где                                |
| -------- | ---------------------------------- |
| Миграции | `prisma/migrations/`               |
| Описание | `docs/specs/message-bus/accounts/` |

## Что считается сделанным

- У записей, заведённых до закрытия операций правами, права есть: приёмник открывается как раньше.
- У служебной записи `cargo-triage` есть права на чтение и пометку груза.
- Повторный прогон миграции ничего не меняет и лишнего не выдаёт.

## Шаги

### 1. Миграция выдаёт права

- **Что делается:** заводятся две роли и назначаются записям, которые существовали до закрытия операций правами
- **Признак готовности:** роли и назначения появляются в базе, повторный прогон ничего не меняет
- **Проверено:** `pnpm exec prisma migrate deploy` на чистой базе — код возврата 0

### 2. Чтение груза открывается

- **Что делается:** проверка команды чтения груза против поднятого приёмника
- **Признак готовности:** команда печатает записи, а не отказ по правам
- **Проверено:** `npm run cargo:pull -- --state new` — записи напечатаны

## Чего работа не делает

- Не заводит экран правки ролей и прав: это задача #1901 в эпике #1896.

# Grill

## The owner request

> как исправить гейт чтобы он не гонял лишние проверки?

Ответ сессии назвал три правки, владелец сказал: «Да, делай».

## What the tree already has

- Функция выбора предметов `rt_push_touched` в `.claude/rt-kit/project.sh` делит ветку на предметы и запускает тяжёлые шаги только для затронутых.
- Всё, чего функция не знает, попадает в последнюю строку и запускает все шесть тяжёлых шагов.
- Сценарии выбора лежат в `tools/tests/push-heavy-subjects.test.sh`.
- Разбор `.claude/rt-kit/postmortems/2026-11-18-push-set-steals-time.md` называет сужение набора и не внесён.

## What the rules already say

- Шаг запускается по предмету, которого коснулась ветка; неизвестный путь запускает всё: лучше лишний запуск, чем пропуск.

## Questions and answers

Вопросов нет: правки названы в ответе владельцу и приняты.

## Decisions

- **Пакеты `ai-chat-protocol` и `cms-*` не поднимают тяжёлых шагов** — их не импортирует ни приложение, ни другой пакет, их закрывают проверки затронутых проектов. Rejected: `core`, `store`, `utils`: их берут приложения как исходники.
- **Файлы процесса `.github/` не поднимают тяжёлых шагов** — шаги набора процесс не проверяют. Rejected: оставить их в общем случае.
- **Корневые настройки остаются в общем случае** — они действуют на любой предмет.
- **Строка «не запускалось» для тяжёлых шагов не вносится здесь** — разбор того, как её читает запускающий набор, отдельная задача.

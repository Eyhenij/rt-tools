## Что считается сделанным

- Груз с этого дерева доезжает до приёмника по имени, и адрес приёма в настройке дерева — имя.
- Обращение по открытому протоколу уводится на защищённое, браузер сертификат принимает.
- Приёмник, база и проксировщик поднимаются сами после перезагрузки узла.
- Выкатка идёт запуском рабочего потока рукой, поднимает образ по sha и кончается пробой живости.
- Дамп снимается и загружается одной командой каждый; загруженный возвращает и свод, и годность
  выданных токенов.
- Строка «Выкатка, сертификат, обратный проксировщик и арендованный узел» ушла из «Что не входит»
  спека домена, `Q-4` замысла линии закрыт, оба отвергнутых паттерна разложены.

## Этапы

### 1. Состав прода и проксировщик

- **Что делается:** `docker-compose.prod.yml` — база с именованным томом, накат миграций,
  приёмник, проксировщик с именем; `deploy/Caddyfile`; ни один порт, кроме дороги, наружу не
  публикуется.
- **Признак готовности:** состав разбирается без ошибок, порядок контейнеров ставит накат
  миграций перед приёмником, хранилище лежит на томе.
- **Чем проверяется:** `docker compose -f docker-compose.prod.yml config` на своей машине.

### 2. Конвейер выкатки

- **Что делается:** `.github/workflows/deploy.yml` — сборка образа под платформу узла, отправка
  в реестр по sha, выкатка по SSH запуском руками, проба живости, чистка образов
  `deploy/prune-images.sh`.
- **Признак готовности:** файл принимается хостингом (прогон не кончается за ноль секунд), сборка
  образа проходит, выкатка стоит под условием главной ветки.
- **Чем проверяется:** ручной запуск рабочего потока с ветки — он доходит до сборки и там встаёт.

### 3. Узел поднят и отвечает по имени

- **Что делается:** секреты выкатки заведены, окружение прода положено на узел, первая выкатка
  прогнана, сертификат выписан.
- **Признак готовности:** проба живости отвечает по имени, браузер открывает админку без
  предупреждения, перезагрузка узла поднимает всё обратно.
- **Чем проверяется:** запрос к пробе живости по имени, перезагрузка узла, браузер.

### 4. Дамп: выгрузка и загрузка

- **Что делается:** `deploy/dump.sh` — снятие и загрузка одной командой каждая.
- **Признак готовности:** дамп снят, хранилище очищено, дамп загружен, свод и токены на месте.
- **Чем проверяется:** прогон на узле с настоящим грузом.

### 5. Дерево шлёт на имя, тексты приведены к сделанному

- **Что делается:** `intake` в настройке дерева переведён на имя, отправка прогнана вживую;
  оба паттерна сняты из отказов; `Q-4` закрыт в замысле линии; описание прода написано.
- **Признак готовности:** сводка с этого дерева видна в админке узла, `agent-kit:check` зелёный.
- **Чем проверяется:** прогон отправки, `pnpm run agent-kit:check`, гейт пуша целиком.

## Чего эта работа не делает

- Не заводит оповещений о том, что приёмнику плохо — их нет у службы вовсе.
- Не увозит копию дампа за пределы узла — отдельная работа.
- Не заводит второго узла и переключения между ними.
- Не чинит отказ раннера на скачивании образов — это соседняя поломка, задача под неё не заведена.

# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — признак дерева при описании отправки
- **Сделано:** задача заведена, ветка и папка на месте, замысел записан, четыре записи отмечены
- **Следующий шаг:** дописать абзац о признаке дерева
- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** не открывается — ночью ветки держатся локально по слову владельца

## Решения по ходу

- **Две одинаковые записи чинятся одним абзацем** — то же предложение отправлено дважды, второй
  раз с дописанной строкой ближайшего. Затронутый этап замысла: 1.

# Замысел

**Поведение:** не меняется — правится холодная часть правила ведения работы.

## Что делается

1. В раздел ловушек холодной части встаёт пункт: слово владельца об устройстве — постановка, а
   не решение, и сверяется оно с деревом до правки.
2. Пункт называет, с чем сверять: имя на экране, раздел спека, поле модели — и что делать при
   расхождении.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

# Разбор просьбы

Три записи груза из приёма, соседние деревья, ресурсы `patterns/spec-driven-sweep.md`,
`rules/seo.md`, `rules/api-layer.md`. Отметить их этому дереву нечем — токен двигает только свои
записи; работа при этом наша, ресурсы живут здесь.

## Сплошной разбор привязки нигде не записан

Сплошной разбор привязки домена идёт десятую задачу подряд одними и теми же проходами, а
записаны они только в файлах находок — то есть в замысле, который читает владелец и который ни
одному будущему заходу не достаётся. Каждый заход собирает набор проходов заново и заново
наступает на две вещи: считает срабатывание находкой и ждёт от прохода той же урожайности, что на
прошлом домене.

## Что в работу не берётся

Две записи о предметности в переносимом тексте закрыты прежними редакциями: у правила видимости
в поиске раздел «Чего из закона здесь нет» уже отсылает к компаньону, а в правиле слоя API пример
серверного стрима уже назван родом — живой срез показателей и лента входящих записей.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

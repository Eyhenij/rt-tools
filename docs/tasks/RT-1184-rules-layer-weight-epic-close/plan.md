- В замысле эпика стоит раздел о том, чем эпик кончился: числа замера дня заведения и дня

- Обещание «вдвое меньше» из заглавия сверено с полученным и названо прямо.

## Этапы

### 1. Итог эпика записан числами

- **Что делается:** в замысел эпика дописывается раздел о том, чем он кончился: таблица «до и
  после» по трём строкам замера и вывод по обещанию заглавия.
- **Признак готовности:** раздел стоит в замысле, числа в нём — вывод команды этого дня, а не
  пересказ отчётов отдельных задач.
- **Чем проверяется:** `npm run agent-kit:cost` — три строки вывода совпадают с числами «после»
  в таблице раздела.

### 2. Границы и открытые вопросы приведены к состоявшемуся

- **Что делается:** закрывается Q-2 словами владельца; раздел «Что в эпик не входит»
  перечитывается целиком, и то, что состоялось иначе, правится.
- **Признак готовности:** ни один открытый вопрос замысла не остаётся без ответа, а границы
  описывают то, что вышло.
- **Чем проверяется:** `npm run check:docs` — ни одной строки о несуществующем пути.

### 3. Карточка эпика закрыта

- **Что делается:** карточка RT-1125 закрывается с указанием на запись итога.
- **Признак готовности:** задача в состоянии закрытой, очередь работ сходится.
- **Чем проверяется:** `npm run check:board` — про RT-1125 в выводе ни строки.

  заказывал.
- Не назначает числа цели задним числом.
- Не правит команду счёта и её вывод.

# Разбор просьбы

## Просьба владельца

> Набор @rt-tools/ui-kit-v2@0.8.0 не собирается: он зовёт EListSortOrder из @rt-tools/utils, а
> последняя опубликованная версия utils (0.3.2) такого символа не отдаёт. Версия 0.6.0

Ответ на разбор: «да, публикуй новую версию».

## Что уже есть в дереве

- `EListSortOrder` объявлен в `projects/utils/src/lib/interfaces/list.interface.ts` и
  экспортирован наружу; в utils он с 18 августа.
- Последняя публикация utils — 0.3.2 от 10 августа (тег `rt-utils@0.3.2`). В опубликованном
  пакете символа нет — проверено распаковкой tarball.
- Опубликованные ui-kit-v2 0.7.0 (26 августа) и 0.8.0 (30 августа) импортируют
  `EListSortOrder` из `@rt-tools/utils`; 0.6.0 (13 августа) — нет. Оба требуют
  `@rt-tools/utils ^0.3.1`.
- `update-version-utils.cjs` переписывает зависимость на utils у core, store и ui-kit; ui-kit-v2
  в списке нет.
- `pnpm-lock.yaml` разрешает `@rt-tools/utils` для ui-kit-v2 из реестра (0.3.1), не из
  рабочего пространства.
- Опубликованные ui-kit 0.4.0, core 0.3.1, store 0.3.1 символ не импортируют.

## Что уже сказано в правилах

- Публикация — ручной запуск рабочего потока, отдельное решение владельца
  (`git-workflow/implementation.md`, `dependencies/implementation.md`).
- Лок-файл расходится с манифестами после каждой публикации и правится отдельным коммитом
  (`dependencies/implementation.md`).
- Порядок публикации: utils → core → store → ui-kit; ui-kit-v2 от них не зависит по каскаду,
  но зависит от utils.

## Вопросы и ответы

**Публиковать utils 0.4.0 и ui-kit-v2 0.8.1?**
Да, публикуй новую версию.

Остальные вопросы закрыты фактами из дерева:

- Поведение приложения не меняется: правятся манифесты и скрипт публикации.
- Законы и правила не правятся.
- Одна задача. Проверка импортов против опубликованных версий — отдельная задача.
- Не входит: публикация core, store, ui-kit; они на новые экспорты utils не опираются.
- Готово, когда `npm view @rt-tools/ui-kit-v2@0.8.1 peerDependencies` показывает
  `@rt-tools/utils: ^0.4.0` и `pnpm install --frozen-lockfile` на `main` проходит.
- Образец — прошлые публикации: bump utils, синхронизация лок-файла, публикация зависимого.

## Решения

- **utils выходит минором 0.4.0** — новый экспорт; в 0.x это минор, как и в прошлых выпусках.
- **ui-kit-v2 выходит патчем 0.8.1** — меняется только зависимость.
- **Зависимость пишется кареткой `^0.4.0`** — так пишет каскад `update-version-utils.cjs` и
  так объявлены соседи у ui-kit. Отвергнуто: точный номер — разошёлся бы с каскадом.

## Что осталось невыясненным

- Нужна ли публикация ui-kit с новым utils — не спрашивали: опубликованный ui-kit 0.4.0 символ
  не использует, а в дереве уже использует; это закроет проверка из отдельной задачи.

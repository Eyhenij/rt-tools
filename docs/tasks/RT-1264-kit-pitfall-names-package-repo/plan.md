# Замысел

**Поведение:** не меняется — правится текст холодной части скила, ни одной проверки и ни одного
гарда задача не трогает.

Из двух предложенных ходов берётся второй: пункт говорит, где живёт обвязка и чего в поставке
нет. Первый — отгружать сценарии вместе с гардами — меняет состав поставки всем деревьям и
решается владельцем, а не этой задачей.

## Этапы

1. Пункт называет репозиторий пакета местом обвязки и прямо говорит, что в поставке её нет.
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Состав поставки не трогается: сценарии гардов в неё не добавляются.

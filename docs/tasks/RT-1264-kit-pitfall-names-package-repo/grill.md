# Разбор просьбы

Запись груза из приёма, соседнее дерево, холодная часть скила слоя правил. Отметить её этому
дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

- **место:** пункт про прогон сценариев гардов
- **повод:** пункт обещает обвязку набора и переменную с каталогом гардов. В поставке их нет: ни
  каталога сценариев, ни файлов набора — они живут в репозитории пакета. Дерево, поверившее
  совету, ищет у себя то, чего ему не отгружали, и приходит ровно к тому заходу на диагноз по
  последствиям, от которого совет обещал избавить. Приём при этом хороший, и стоит он дёшево.
- **готовый ход:** одно из двух, но не молчание — сценарии гардов и их обвязка едут в поставке
  рядом с самими гардами, либо пункт прямо говорит, что они живут в репозитории пакета, называет
  обвязку и переменную и добавляет, что в поставке их нет.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

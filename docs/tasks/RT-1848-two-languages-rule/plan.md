## Что считается сделанным

- Правило `doc-style` называет два языка и границу между ними одной статьёй.
- Паттерн `doc-style-human` показывает образец: слой по-английски, задача по-русски.
- Памятка дерева говорит о языках одной строкой.
- Раскладка сходится, проверки слога и адресов зелены.

## Этапы

### 1. Статья о двух языках в правиле

- **Что делается:** в раздел «Тексты для человека» правила `doc-style` дописана статья: слой
  правил и документы дерева — по-английски, задача, заявка, коммит и ответ владельцу — на его
  языке; компаньон правила в этом дереве получает строку исполнения.
- **Признак готовности:** статья в правиле, строка в компаньоне, пакет собран и разложен.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет;
  `grep -n 'язык' .claude/skills/doc-style/SKILL.md` — статья в разложенной копии.

### 2. Образец в паттерне и строка в памятке

- **Что делается:** паттерн `doc-style-human` получает образец «так и не так» на границу
  языков; `CLAUDE.md` — одну строку о языках.
- **Признак готовности:** образец в паттерне, строка в памятке.
- **Чем проверяется:** `node tools/check-prose-style.mjs` по правленым файлам — находок нет;
  `npm run check:docs` — расхождений нет.

## Чего эта работа не делает

- Не переписывает проверки слога и словаря под английский: это RT-1849.
- Не переводит само правило `doc-style`: это RT-1853.

# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `lib/commands.js`. Отметить её этому дереву
нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Надстройка, которую раскладка не подобрала, молчит

Надстройка правила лежала под именем без приставки свойства, а идентификатор ресурса у пакета её
несёт. Такая надстройка не привязывается к ресурсу ничем: раскладка молча положила пакетный
текст, и разложенное правило двое суток говорило о дереве неправду — тридцать пять строк своей
редакции до него не доехало.

Сверка раскладки этого не видит и видеть не может: она сравнивает разложенное с тем, что
собирает сама, а неподобранную надстройку в сборку не берёт — обе стороны сходятся. Молчание
здесь читается как «всё применено».

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

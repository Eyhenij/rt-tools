# Замысел

**Поведение:** не меняется — раскладка кладёт то же и отвечает тем же кодом; прибавляется строка
предупреждения.

## Что делается

Надстройка, которую раскладка не подобрала ни к одному ресурсу, называется отдельной строкой
предупреждения: имя файла и слово о том, что применена она не была. Строка печатается на любом
исходе раскладки, в том числе на сошедшемся дереве, и расхождением не считается.

## Чем проверяется

`pnpm exec nx test @rt-tools/agent-kit`, `pnpm exec nx lint @rt-tools/agent-kit`,
`npm run agent-kit:sync`, `npm run agent-kit:check`, `npm run check:specs`.

# Замысел

**Задача:** RT-1037 · **Ветка:** RT-1037-agent-kit-release
**Поведение:** не меняется — работа выпускает редакцию уже написанных текстов и сверяет с ней
раскладку; ни одной статьи, ни одного гарда она не правит.

## След задачи

| Что               | Где                                       |
| ----------------- | ----------------------------------------- |
| Пакет правил      | `projects/agent-kit/`                     |
| Конвейер выпуска  | `.github/workflows/publish-agent-kit.yml` |
| Разложенные копии | `.claude/skills/`, `tools/`, `docs/`      |
| Журнал изменений  | `projects/agent-kit/CHANGELOG.md`         |

## Что считается сделанным

- Редакция стоит в реестре пакетов, и её номер выше прежнего.
- Раскладка в этом дереве сходится с выпущенной редакцией.
- Шапки разложенных файлов называют новый номер.

## Этапы

### 1. Редакция выпущена

- **Что делается:** конвейер выпуска запускается ручным запуском на главной ветке с минорным
  подъёмом; он поднимает версию, собирает журнал изменений, ставит метку и публикует.
- **Признак готовности:** прогон зелёный, в реестре пакетов стоит новый номер.
- **Чем проверяется:** `npm view @rt-tools/agent-kit version` — печатает новый номер.

### 2. Раскладка сходится с новой редакцией

- **Что делается:** главная ветка с подъёмом версии вливается в эту, пакет собирается, раскладка
  сверяется.
- **Признак готовности:** сверка раскладки называет новый номер.
- **Чем проверяется:** `pnpm run agent-kit:check` — «разложенное сходится с пакетом v<номер>».

### 3. Набор гейта прогнан целиком

- **Что делается:** гоняются наборы пакета и сверки текстов.
- **Признак готовности:** всё зелёное.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ».

## Чего эта работа не делает

- Не правит текстов слоя правил: они уже написаны и влиты эпиком о цене входа.
- Не выпускает прочих пакетов дерева: они самостоятельны, и спеки друг другу не каскадят.

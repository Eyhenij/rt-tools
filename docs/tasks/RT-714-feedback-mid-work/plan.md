## Что считается сделанным

- Слово человека посреди работы становится блоком в файле предложений без разбора закрытой
  задачи.
- Блок ложится в файл сегодняшнего дня; файла нет — заводится с образца.
- Непонятный адрес спрашивается вопросом, и до ответа в файл не записано ничего.
- Команда в сеть не ходит и называет, чем блок отправить.
- Положенный блок уезжает обычной отправкой наравне с блоками разбора.
- Договорённость влита в спек домена, команда разложена в это дерево.

## Этапы

### 1. Команда пакета

- **Что делается:** `projects/agent-kit/assets/commands/feedback.md` — порядок для агента: как
  разобрать реплику в адрес и ресурс, куда положить блок, что сказать человеку.
- **Признак готовности:** команда лежит в ресурсах пакета и видна `agent-kit list`.
- **Чем проверяется:** `pnpm run agent-kit:sync` раскладывает её в это дерево.

### 2. Файл дня и его заведение

- **Что делается:** порядок заведения файла с образца, когда его за сегодня ещё нет, и дописи
  блока, когда он есть.
- **Признак готовности:** два прогона подряд в один день дают два блока в одном файле.
- **Чем проверяется:** спека на разбор и склейку блоков, прогон команды руками.

### 3. Отправка увозит положенное

- **Что делается:** ничего нового — проверяется, что блок, положенный командой, отбирается
  отправкой наравне с блоками разбора.
- **Признак готовности:** `agent-kit propose --dry-run` считает его в числе предложений.
- **Чем проверяется:** прогон вживую на этом дереве.

### 4. Тексты приведены к сделанному

- **Что делается:** договорённость влита в спек домена; правило `agent-kit` называет команду;
  замысел линии отмечает четвёртую задачу закрытой.
- **Признак готовности:** `npm run check:specs` не даёт новых расхождений, `agent-kit:check`
  зелёный.
- **Чем проверяется:** обе проверки и гейт пуша целиком.

## Чего эта работа не делает

- Не заводит отправки из самой команды: в сеть уходит только позванное отдельно.
- Не сводит и не правит уже лежащие блоки.
- Не заводит своей очереди и своего хранилища — файл предложений и есть очередь.

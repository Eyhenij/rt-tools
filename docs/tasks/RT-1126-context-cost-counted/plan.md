## Что считается сделанным

- Команда пакета печатает три числа — цену входа, вес названного правила и вес слоя — в токенах,
  и рядом с ними стоит имя токенизатора.
- Восемь сценариев драфта покрыты спекой, и прогон пакета зелёный.
- Дерево зовёт команду своим скриптом наравне с раскладкой и её сверкой.
- Первый вывод команды записан в замысел эпика, и там же названо число разницы между текстом на
  кириллице и его переводом на латиницу.

## Этапы

### 1. Токенизатор выбран и назван

- **Что делается:** разведка по тому, чем считать токены без сети, выбор одного и запись его в
  драфт ответом на Q-1.
- **Признак готовности:** выбранное считает токены на образцовой строке, работает без сети, и
  его имя стоит в драфте.
- **Чем проверяется:** `node -e "…"` с вызовом выбранного токенизатора на образцовой строке —
  напечатанное число означает «сошлось»; отказ о недоступности сети означает, что выбран не тот.

### 2. Команда считает три числа

- **Что делается:** счёт цены входа, веса правила и веса слоя в пакете, подкоманда и её доводы.
- **Признак готовности:** команда печатает три числа и имя токенизатора, ничего не пишет и в
  сеть не ходит.
- **Чем проверяется:** `nx build @rt-tools/agent-kit && node dist/agent-kit/bin/agent-kit.js cost`
  — три числа и имя токенизатора в выводе означают «сошлось».

### 3. Сценарии покрыты спекой

- **Что делается:** спека на восемь сценариев драфта, с идентификатором в начале заголовка.
- **Признак готовности:** каждый из восьми сценариев несёт покрытие вместо пометки «Не покрыто».
- **Чем проверяется:** `nx test @rt-tools/agent-kit` — зелёный прогон означает «сошлось».

### 4. Дерево зовёт команду своим скриптом

- **Что делается:** скрипт дерева рядом с раскладкой и её сверкой.
- **Признак готовности:** команда зовётся из дерева одной строкой, без пути к собранному файлу.
- **Чем проверяется:** `npm run agent-kit:cost` — напечатанная таблица означает «сошлось».

### 5. Первый замер записан в замысел эпика

- **Что делается:** снятие чисел на этом дереве и запись их в замысел эпика вместе с разницей
  между кириллицей и латиницей на одном правиле.
- **Признак готовности:** в замысле эпика стоят числа и названа команда, которой они сняты;
  вопрос эпика о языке отвечен числом, а не прозой.
- **Чем проверяется:** `npm run agent-kit:cost -- --json` — вывод, совпадающий с числами в
  замысле, означает «сошлось».

## Чего эта работа не делает

- **Не режет ни одной строки слоя.** Резать начинает следующая задача эпика; эта только считает.
- **Не заводит порога и не становится проверкой гейта.** Число цели назначает владелец после
  первого замера — до него порог назначать не из чего.
- **Не переводит слой.** Она печатает разницу между языками; перевод — отдельная работа и
  решение владельца.
- **Не считает спеки доменов.** Целиком в заход они не грузятся, и вес их ни о чём не говорит.

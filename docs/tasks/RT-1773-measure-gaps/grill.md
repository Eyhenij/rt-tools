# Разбор просьбы

## Слова владельца

> продолжай с остальными жалобами и предложениями, заведи задачи и бери в работу по очереди

## Что это значит

Груз приёма разложен на восемь тем. Эта — вторая: замер вёрстки. Четыре записи о том, что замер
выглядит сделанным, а меряет не то.

## Ответы владельца

Вопросов по этой задаче владельцу не задавалось: записи называют место правки, повод и готовый
текст.

## Решения с доводами

- **Записи сверены с деревом до замысла, а не после.** На первой задаче стопки три этапа из пяти
  пришли на уже закрытое: записи приехали до выпуска 0.24.0, а правки по ним доехали вместе с
  ним. Здесь сверка сделана заранее, и из четырёх записей открытой осталась одна — приём замера
  на задержанном запросе. Три других уже стоят: событие ввода подделкой значения не заменяется,
  долгий прогон запускается в странице, замер снимается до показа владельцу.

## Решения по ходу

- **Ветка отведена от ветки RT-1970 цепочкой.** Та работа правила тот же файл обхода. Затронут
  этап плана: ни один.

- **Срыв из карточки оказался следствием протухшей витрины, а не самого ожидания.** Замер на
  здоровой витрине: поток горячей перезагрузки остаётся открытым, но тишина в сети наступает за
  1 мс. Сорок шесть незакрытых запросов из карточки — это протухшая витрина, где на страницу
  приходит 40–65 отбитых запросов; это закрыто работой RT-1970. Осталось укрепление самого обхода,
  и оно сделано. Затронут этап плана: 1.
- **Ожидание корня показа идёт по присутствию узла, а не по видимости.** История, рисующая в
  наложении, оставляет свой корень пустым, и по видимости такая страница читается как неоткрытая.
  Затронут этап плана: 2.
- **Рисование ждётся самим измерением.** Узел, прикреплённый к странице, ещё не нарисован: без
  этого ожидания два показа из 625 назывались пустыми. Затронут этап плана: 2.

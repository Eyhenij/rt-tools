# Замысел

**Поведение:** не меняется — правится текст закона о проверяемости.

## Что делается

1. В раздел статей, следом за статьёй о тесте, выключенном признаком окружения, встаёт статья о
   тесте, снимающем себя по тому, что застал на экране.
2. Второй статьёй — требование к тесту: экран в нужное состояние приводит он сам, а общее
   состояние возвращает таким, каким застал.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

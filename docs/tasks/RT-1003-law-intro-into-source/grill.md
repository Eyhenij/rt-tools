# Разбор просьбы

## Просьба владельца дословно

> да, это я меню текст законов
> не трогай мои изменения

Сказано в ответ на то, что сверка раскладки нашла правку руками в `docs/constitution/work-conduct.md`
и гард закрыл пуш.

## Что уже сказано в правилах

| Вопрос                                | Что говорят правила                                                                                                                            |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Где правится разложенный текст        | Правило `agent-kit`: правка на месте теряется на следующей раскладке и до тех пор выглядит применённой. Источник закона лежит в этом же дереве |
| Своей ли задачей это делается         | Правило поставки: одна работа — одна задача; делится то, что придётся откатывать порознь                                                       |
| Можно ли снять чужую правку из дерева | Компаньон правила ведения работы: правка рабочего дерева не своей правкой — без слова владельца не делается                                    |

## Решения

| Что решено                                  | Довод                                                                                             |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Абзац переносится в источник дословно       | Владелец выбрал это вариантом ответа: текст выживает раскладку и уезжает во все деревья с пакетом |
| Текст владельца не правится ни по чему      | Он пишет закон; исполнитель переносит, а не редактирует                                           |
| Работа ведётся своей задачей и своей веткой | RT-1002 о другом и откатывается порознь                                                           |
| Надстройка дерева не заводится              | Владелец правит закон для всех деревьев, а не для этого одного                                    |

**Задача:** RT-1003 · **Ветка:** RT-1003-law-intro-into-source
**Поведение:** не меняется — правится текст закона, кода приложения работа не задевает

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## След задачи

| Что     | Где                                              |
| ------- | ------------------------------------------------ |
| Законы  | `docs/constitution/work-conduct.md`              |
| Код     | `projects/agent-kit/assets/laws/work-conduct.md` |
| Правила | `.claude/skills/agent-kit/`                      |

Закон разложен из пакета, и правится он в источнике. Разложенная копия перезаписывается
раскладкой, а сверка раскладки стоит в наборе гейта пуша — поэтому расхождение между копией и
источником закрывает пуш всему дереву, а не только этой ветке.

## Что считается сделанным

- В `projects/agent-kit/assets/laws/work-conduct.md` стоит вступление, написанное владельцем.
- `pnpm run agent-kit:check` печатает `разложенное сходится с пакетом` и не называет расхождений.
- Текст владельца не переписан: ни по словарю, ни по слогу.

## Этапы

### 1. Абзац владельца перенесён в источник

- **Что делается:** вступление из разложенной копии кладётся в источник закона дословно
- **Признак готовности:** источник несёт текст владельца, разложенная копия ему не противоречит
- **Чем проверяется:** `git diff projects/agent-kit/assets/laws/work-conduct.md` — в выводе стоит текст владельца, и других правок в файле нет

### 2. Дерево разложено под источник

- **Что делается:** раскладка гоняется, копия закона получает шапку нынешней редакции
- **Признак готовности:** копия и источник сошлись, сверка молчит
- **Чем проверяется:** `pnpm run agent-kit:check` — строка `разложенное сходится с пакетом v0.11.0` и ни одного расхождения

## Чего эта работа не делает

- Не правит слог и слова владельца: словарь дерева зовёт заходом то, что он назвал сессией, но
  это его формулировка закона, а не проза исполнителя. Разойдётся — скажет он сам.
- Не трогает RT-1002 о закрывающем коммите: та задача стоит на решении владельца и откатывается
  порознь с этой.

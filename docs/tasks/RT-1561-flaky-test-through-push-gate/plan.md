## Этапы

### 1. Ловушка называет цену повтора и исход расхождения

- **Что делается:** за ловушкой о первом прогоне дописывается ловушка о повторе через гейт.
- **Признак готовности:** сказано, что полный набор гоняется руками до пуша, а тест, упавший в
  наборе и прошедший порознь, заводится задачей.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка кладёт файл без отказа.

### 2. Пределы выдержаны

- **Что делается:** прогон проверки длины.
- **Признак готовности:** долг 0, новых нет.
- **Чем проверяется:** `node tools/check-file-size.mjs` — долг 0, новых нет.

## Чего эта работа не делает

- Не заводит машинного признака нестабильности: отличить своё падение от чужого нечем, кроме
  прогона на нетронутой ветке.

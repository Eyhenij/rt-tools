# Grill

## The owner request

Владелец в меню: «Работа вне эпика». Содержание задачи пришло поручением: у чата нужен открытый
метод `setDraft(text: string): void`. Метод заменяет содержимое поля ответа и ставит фокус с
курсором в конце. Он работает в классическом и rich-композере, выбранные файлы не трогает, при
закрытом поле ничего не делает. Вид чата не меняется, кадр не нужен.

## What the tree already has

- У `rt-message-composer` и `rt-ai-prompt-input` есть вход `text` и метод `focus()`.
- У чата три поля ответа: классическое, композер и поле мессенджера.
- Поддомены переписки лежат в `docs/specs/ui-kit-v2/`, образец — `chat-typing`.

## What the rules already say

- Правило `kit-approval`: вид не меняется, кадр и сверка с ним не нужны.
- Показ владельцу стоит до отправки: так сказано в поручении.

## Questions and answers

**Куда отнести задачу: вне эпика или в эпик?**
«Работа вне эпика»

## Decisions

- **Метод работает и в поле мессенджера** — поручение называет два поля, а у чата их три. Без
  третьего метод молча ничего не сделал бы в режиме мессенджера. Rejected: оставить два поля.
- **Закрытым считается поле из `composerDisabled`** — загрузка и обновление закрывают поле так же,
  как отправка. Rejected: проверять только `sending`.

## What is left unclear

- Ничего: вид не меняется, вопросов о нём нет.

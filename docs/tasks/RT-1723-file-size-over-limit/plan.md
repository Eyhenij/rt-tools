## Этапы

### 1. Тексты, переросшие вес в знаках

- **Что делается:** режется довод в правиле поставки и в законе о ведении работы — повторы и
  примеры, не несущие статьи.
- **Признак готовности:** оба файла весят меньше 22 000 знаков, ни одна статья не пропала.
- **Чем проверяется:** `node tools/check-file-size.mjs` — в выводе нет строк про эти два файла.

### 2. Тексты, переросшие число строк

- **Что делается:** режутся правило хода работы и правило слоя правил.
- **Признак готовности:** оба короче 300 строк.
- **Чем проверяется:** `node tools/check-file-size.mjs` — строк про них нет.

### 3. Гард поставки делится

- **Что делается:** предмет гарда выносится помощником рядом, тем же приёмом, каким уже вынесена
  подпись машинного коммита.
- **Признак готовности:** оба файла короче 500 строк, гард ведёт себя как прежде.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ».

### 4. Спеки и набор

- **Что делается:** режутся три перечня сценариев и набор сверки очереди.
- **Признак готовности:** каждый короче 500 строк, пары «сценарий ↔ тест» целы.
- **Чем проверяется:** `node tools/check-specs.mjs` — расхождений нет.

### 5. Раскладка и гейт

- **Что делается:** `pnpm run agent-kit:sync`, затем полный набор перед пушем.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `pnpm run check:all` — код 0.

# Grill

Работа начата по слову владельца в эпике RT-3641; груза из приёмника нет.

## The owner request

> Выпуск `@rt-tools/ui-kit-v2` 0.52.0 заметно тяжелее 0.51.0, и два потребителя вышли за бюджет стартового пакета. Задача: найти, что утяжелило части кита, и вернуть вес без потери возможностей 0.52.0. [...] Готово, когда размер этих частей возвращён к уровню 0.51.0 плюс только необходимое для фильтров, а замер до и после приложен цифрами.

> «напиши новый план чтобы реализовать всё что ты сейчас написал» — «запускай task flow»

## What the tree already has

- Нет проверки веса частей кита: рост 0.51.0 → 0.52.0 (+29,4 КБ на старте потребителя) никто не поймал.
- Образец сторожа с порогом в файле: `tools/check-ngdoctor.mjs` и `tools/ngdoctor-threshold.json`, порог пишется командой `--write`.
- Наборы проверок перед пушем перечислены в `.claude/rt-kit/project.sh` (`rt_push_checks`), общий прогон — `pnpm run check:all`.
- Сборка кита кладёт `dist/ui-kit-v2/fesm2022/*.mjs`; точки входа — по одной на часть.

## What the rules already say

- Правило `dependencies`: версия зависимости точным номером, без диапазона.
- Закон о проверяемости: проверка проверяется на настоящей записи и рядом с соседними до сдачи.

## Questions and answers

Владелец подтвердил эпик и порядок слов «запускай task flow»; отдельных вопросов по этой задаче не задавалось: способ измерения и состав набора определены планом эпика.

## Decisions

- **Измерение собирает набор частей esbuild'ом из `dist/ui-kit-v2`, с минификацией и `ngDevMode=false`** — так считает сборка потребителя; сырой размер файлов `fesm2022` завышает вес на метаданные. Rejected: размер файлов `fesm2022` как есть — он включает комментарии и отладочные метки, которых в сборке потребителя нет.
- **Набор «старт потребителя»: select, menu, input, icon, popover, dialog, bottom-sheet** — части, которые потребитель тянет на старте по его измерению.
- **Порог хранится в файле рядом с порогом ngdoctor и пишется командой** — тот же приём, что у сторожа ngdoctor.

## What is left unclear

- Какие части входят в набор у других потребителей: набор расширяется записью в порог, без правки скрипта.

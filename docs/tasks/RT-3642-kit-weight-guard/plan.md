## What counts as done

- Измерение набора из собранного кита совпадает с измерением пакета 0.52.0 из npm (331452 байта).
- Порог записан командой и сверяется в обе стороны: рост набора, части, gzip или файла стилей красный, снижение красное,

       Check: `grep -c 'check:kit-weight' package.json` → >= 2

## What this work does not do

- Не уменьшает вес кита: это задачи RT-3643…RT-3650 того же эпика, каждая снижает порог командой `--write`.
- Не режет `tokens.css` на файлы: раскладка токенов — RT-3643; порог стилей после неё пишется командой `--write`.
- Не включает ленивые чанки в набор: на старте лежит только файл точки входа (`splitting`), ленивый `import()` в вес не идёт.

# Разбор

## Запрос владельца

Замечание владельца по пакету, дословно:

> 2. Иконки колонок вне iconMaterialMap. dataTableIconName для иконки, которой нет в списке, возвращает null, и иконка не
>    рисуется. Нужен запасной вариант, например отдавать исходное имя иконки.

Ответ на вопрос, делать ли шапку: «Задачей в RT-1870 (Рекомендую)».

## Что уже есть в дереве

- Ячейка рисует имя без пары глифом Material Symbols — RT-2374, сценарий SC-UKV-319.
- Шапка колонки берёт значок только из перечня и без пары не рисует ничего.

## Что уже говорят правила

- Правило SC-UKV-319 в описании `table-full-port` говорит о ячейке; о шапке — ничего.

## Вопросы и ответы

**Делать ли шапку?**
«Задачей в RT-1870 (Рекомендую)».

## Решения

- **Шапка рисует глиф так же, как ячейка.** Та же разметка и те же правила шрифта. Отвергнуто:
  отдавать исходное имя из `dataTableIconName` — тогда `rt-icon` искал бы в наборе имя, которого
  там нет.

## Что осталось неясным

- Ничего.

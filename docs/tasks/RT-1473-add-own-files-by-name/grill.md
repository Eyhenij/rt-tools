## Что уже есть в дереве

Паттерн коммита говорит про подпись, заголовок и то, что `git add` с несколькими путями не
добавляет ничего, если хоть один не существует. О добавлении каталога целиком при чужом
незакоммиченном рядом не сказано нигде.

## Решения

- **Раздел паттерна, а не ловушка** — у требования есть готовый вид команды, и читают его
  в момент коммита.

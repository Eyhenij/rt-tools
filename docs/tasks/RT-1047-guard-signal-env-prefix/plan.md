## Что считается сделанным

- Вызов с присваиванием переменной перед именем команды судится каждым гардом наравне с голым.
- Ни один из шести замеренных вызовов не проходит мимо своего гарда.
- Образец приставки объявлен в одном месте, а не переписан десятью литералами: разойдясь, они
  чинятся по одному и молчат об этом.
- Голый вызов и вызов за разделителем судятся, как судились: набор сценариев прежних отказов
  зелёный.
- Присваивание, у которого нет команды за ним, вызовом не считается.

## Этапы

### 1. Образец приставки объявлен общим местом

- **Что делается:** в общий помощник ввода хуков кладётся образец приставки вызова, считающий
  присваивания переменных частью команды.
- **Признак готовности:** образец объявлен один раз и виден всем хукам, которые помощник
  источают; носители литерала на него ещё не переведены.
- **Чем проверяется:** `bash -c '. projects/agent-kit/assets/hooks/hook-input.sh; echo "$RT_CMD_BOUND"'` — печатает образец, а не пустую строку.

### 2. Носители литерала переведены на общий образец

- **Что делается:** десять мест в пяти хуках берут образец из общего места вместо своей копии.
- **Признак готовности:** литерала приставки в наборе не остаётся ни одного; каждый носитель
  получает образец оттуда, где он объявлен.
- **Чем проверяется:** `grep -rn '\[;&|(\]' projects/agent-kit/assets/hooks/ | grep -v RT_CMD_BOUND` — печатает только объявление самого образца.

### 3. Слепота закрыта замером на всех шести формах

- **Что делается:** каждая форма из разбора просьбы подаётся своему гарду и сверяется с
  ожидаемым исходом.
- **Признак готовности:** голый вызов и вызов с подстановкой токена судятся одинаково; вызов за
  разделителем судится, как судился.
- **Чем проверяется:** `bash projects/agent-kit/tests/git-guard-delivery.test.sh` — все сценарии зелёные.

### 4. Сценарии закреплены набором

- **Что делается:** в наборы сценариев затронутых гардов дописываются случаи с присваиванием
  перед командой — по одному на гард.
- **Признак готовности:** снятая правка признака роняет новые сценарии, а не проходит молча.
- **Чем проверяется:** `pnpm exec nx run @rt-tools/agent-kit:test-hooks` — набор зелёный.

### 5. Правка разложена и описана

- **Что делается:** пакет собирается, раскладка кладёт правку в дерево; сценарий заводится в
  спеке домена, привязка ставится в компаньон.
- **Признак готовности:** сверка раскладки сходится, сверка спеков не находит расхождений.
- **Чем проверяется:** `pnpm run agent-kit:check && node tools/check-specs.mjs` — обе зелёные.

## Чего эта работа не делает

- **Не чинит коммит `69c42f9f` в главной ветке.** Он приписан постороннему человеку, и правится
  только переписыванием истории с силовой отправкой; та рвёт основание у открытых веток и
  рабочих копий. Решение владельца, и оно не сказано.
- **Не переносит подпись коммита на точку коммита.** Об этом заведена отдельная задача, и она
  про другой предмет: там судится когда, здесь — узнаётся ли вызов вообще.
- **Не трогает требование подставлять токен в команду.** Требование верное; чинится то, что
  соседний признак его формы не понимает.

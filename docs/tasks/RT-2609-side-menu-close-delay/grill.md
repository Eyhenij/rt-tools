# Grill

## The owner request

> делай необзодимые изменения в компоненте мень в rt-tools самостоятельно через отдельный worktree, открывай пр из ui гитхаба если это необходимо и выпускай новую версию пакета

Требование, переданное владельцем вместе с поручением: незакреплённое подменю `rtui-side-menu` закрывается через 500 мс после ухода указателя, а не сразу.

## What the tree already has

- `projects/ui-kit/src/lib/ui-kit/side-menu/menu/rtui-side-menu.component.html` — `(mouseleave)="toggleSubMenu()"` на панели подменю и `(mouseenter)="toggleSubMenu(item)"` на пунктах полосы; оба закрывают сразу.
- `docs/specs/ui-kit/side-menu/` — правила второго уровня меню; правила о задержке нет.
- Стенд тестов `side-menu.harness.ts` с `leavePanel` и `hoverFirstItem`.

## What the rules already say

Закреплённое подменю не закрывается уходом указателя; удержание полем поиска и избранным держит подменю (spec.md, Rules).

## Questions and answers

Вопросов владельцу не было: поручение и требование названы целиком.

## Decisions

- **Задержка — вход `subMenuCloseDelay`, 500 по умолчанию** — потребитель может выбрать своё значение, 0 возвращает прежнее поведение. Отвергнуто: константа без входа.
- **Пункт полосы без разделов тоже закрывает через задержку** — рука, идущая с панели поперёк полосы, иначе теряет подменю на первом же пункте. Пункт с разделами переключает сразу.
- **`toggleSubMenu()` остаётся немедленным** — его зовут избранное (бросок за панель) и тесты; задержку несут обработчики указателя.

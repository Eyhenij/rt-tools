# Замысел

**Поведение:** не меняется — правятся тексты пакета и два отказа, кода приложения работа не трогает.

## Этап 1. README называет источник адреса

Строка таблицы говорит, откуда адрес берётся, и абзац под таблицей — что код приглашения и адрес
идут парой и спрашиваются у одного человека.

## Этап 2. Отказы называют то же

Отказ приглашения и отказ отправки говорят не только ключ настройки, но и у кого спросить
значение.

## Этап 3. Проверки

Спеки пакета, проверки слога и адресов, сверка раскладки.

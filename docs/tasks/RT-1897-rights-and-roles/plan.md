## Что считается сделанным

- В хранилище есть роль с набором прав, у записи человека есть роль, и поверх роли лежат точечные
  правки — по одной строке на право.
- Проверка доступа знает четвёртый вид — «по праву» — и читает права на каждом вызове, а не берёт
  их из выданного входа.
- Запрос без входа отвечает 401, а вход без права — 403: два разных ответа, а не один.
- Ответ о вошедшем несёт его права, и админка получает их вместе с именем.
- Право, о котором роль молчит, считается не данным: операция, объявившая право, которого у
  человека нет, отвечает отказом.

## Этапы

### 1. Договорённость о правах записана черновиком

- **Что делается:** поддомен `docs/specs/message-bus/proposed/access-rights/` — правила,
  сценарии, привязки: что такое право, роль и точечная правка, как они складываются, чем
  отличаются два отказа.
- **Признак готовности:** черновик лежит, сценарии пронумерованы следующими свободными номерами
  префикса `SC-MB`.
- **Проверяется:** `npm run check:specs` — черновик виден в разделе готовых к вливанию или
  числится с покрытием, и ни одного расхождения по привязкам.

### 2. Роль, право и точечная правка появились в хранилище

- **Что делается:** правка `prisma/schema.prisma` — роль с ключом, именем и набором прав; роль у
  записи человека; строка точечной правки «человек, право, дано или отнято». Переезд схемы.
- **Признак готовности:** схема собирается, клиент хранилища перегенерирован, засев стенда
  заводит роли.
- **Проверяется:** `pnpm run prisma:generate` — клиент собран без отказа.

### 3. Проверка доступа судит по праву

- **Что делается:** четвёртый вид объявления доступа в `operation-access.ts`; чтение прав
  человека на каждом вызове; отказ 403 отдельно от 401.
- **Признак готовности:** операция, объявившая право, отбивает вошедшего без него отказом 403, а
  не пускает; операция без объявления по-прежнему не отвечает никому.
- **Проверяется:** `pnpm exec nx test message-bus-api-access-feature` — спеки проверки доступа
  зелёные, включая новые ветки о праве.

### 4. Права вошедшего приезжают в админку

- **Что делается:** ответ о вошедшем несёт список прав; хранилище входа в админке их держит.
- **Признак готовности:** ответ `/api/auth/session` содержит права, и сторона админки их читает.
- **Проверяется:** `pnpm exec nx test message-bus-api-accounts-feature` — спеки входа зелёные.

### 5. Договорённость влита, тексты приведены

- **Что делается:** черновик переезжает в спек домена; компаньон правила `permissions` теряет
  строку «прав здесь нет» по тем статьям, которые задача закрыла.
- **Признак готовности:** `proposed/` пуст, у каждой статьи правила о правах есть строка привязки.
- **Проверяется:** `npm run check:specs` — расхождений нет.

## Чего эта работа не делает

- Не закрывает пункты меню и адреса разделов правом — задача #1898.
- Не заводит ни списка людей, ни страницы ролей — задачи #1899 и #1901.
- Не трогает токен дерева: приём груза и смена его состояния закрыты как прежде.
- Не делит груз по деревьям: все вошедшие видят груз всех деревьев, как и сейчас.

# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Этап:** 3 из 5 — находки оформлены и внесены в ресурсы пакета, разложены в дерево
- **Сделано:** шесть предложений написаны по форме слоя правил, все шесть разобраны в правки
  ресурсов: статья в закон о поставке, перечень паттерна панели, две статьи и две ловушки в
  правило проверок. Разложено в дерево, привязки новых статей стоят в компаньоне.
- **Следующий шаг:** PR, слияние владельцем, затем ручной запуск публикации с доводом `minor` —
  из главной ветки, а не из этой.
- **Незакоммиченное:** правки ресурсов пакета, разложенное, компаньон правила проверок, папка
  задачи
- **Ждём владельца:** слияния PR — публиковать из ветки задачи нельзя
- **PR:** ещё не открыт

## Решения по ходу

- **18 августа 2026. Версия пакета руками не правится.** Рабочий процесс публикации сам
  поднимает её доводом `minor`, пишет журнал изменений, ставит метку и публикует. Правка
  манифеста веткой дала бы подъём дважды. Затронутый этап замысла: 3.

- **18 августа 2026. Публикация идёт после слияния.** Рабочий процесс коммитит подъём версии и
  ставит метку на ту ветку, на которой запущен: запущенный из ветки задачи, он опубликовал бы
  невлитое. Затронутый этап замысла: 4.

- **18 августа 2026. Надстройка дерева над паттерном панели не снимается.** Она держит имена
  компонентов кита, а пакет их назвать не может. Правка пакета закрывает другое — перечень
  больше не ставит свою разметку первой. В предложении так и записано. Затронутый этап
  замысла: 2.

## Этапы

### 1. Закон и словарь

- **Что делается:** статьи об эпике и о показе его положения; строка словаря и запрет прежнего
  слова
- **Признак готовности:** понятие названо одним словом во всех текстах пакета
- **Чем проверяется:** поиск прежнего слова по дереву

### 2. Правило, паттерны и гард

- **Что делается:** таблица имён, шаг работы, ловушка, раздел передачи, таблица при остановке,
  комментарий гарда слоёв
- **Признак готовности:** сценарии гардов зелёные, раскладка сходится
- **Чем проверяется:** `projects/agent-kit/tests/run.sh`, `pnpm run agent-kit:check`

### 3. Отчёт

- **Что делается:** метка эпика на борде, набор проверок, отчёт, разбор папки
- **Признак готовности:** отчёт открыт и зелёный
- **Чем проверяется:** набор конвейера, `npm run check:docs`

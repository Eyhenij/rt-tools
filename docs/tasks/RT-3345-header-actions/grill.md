# Grill

## The owner request

> Кнопка ИИ-помощника переезжает из плавающей круглой кнопки в правом нижнем углу в шапку
> `rt-page-header`, между колокольчиком и кнопкой профиля, в том же виде, что колокольчик. На
> телефоне профиль показывается маленькой кнопкой со значком `user` вместо кружка с буквой и имени.

Решение владельца передано запустившей сессией вместе с поручением: четыре правки кита (поле ввода
чата с `fill`, правая группа шапки, кнопка шапки с любым значком, компактный профиль до 768).
Порядок: кадры Figma, слово владельца, код, истории витрины, сравнение с кадрами, показ, «одобряю»,
потом пуш, PR и выпуск.

## What the tree already has

- `rt-page-header` горизонтальный: ряд с `justify-content: space-between`; слот
  `[rtHeaderBell]` и `rt-page-header-user` (хост `display: contents`) стоят прямыми участниками ряда.
- `rt-notifications-bell` рисует `rt-icon name="bell"` без входа для значка.
- `.rt-chat--fill { block-size: 100% }` без `min-block-size: 0`.
- В Figma у Page Header рамка `right`: колокольчик и профиль через 8.

## What the rules already say

- `kit-approval`: кадр Figma и слово владельца до кода, витрина на каждое состояние, совпадение
  чисел, второе слово владельца; только после двух записей — пуш, PR и выпуск.
- `reuse-first`: сначала расширить готовое. Отсюда вход `icon` у колокольчика вместо новой кнопки.

## Questions and answers

Вопросы владельцу задаёт запустившая сессия; ответы записываются дословно в `approvals.md`.

## Decisions

- **Вход `icon` у `rt-notifications-bell`** — вид, токены `--rt-nav-*`, маркер и шаг скругления
  уже есть в этом компоненте. Отклонено: отдельный компонент кнопки шапки, он повторил бы те же
  стили один в один.
- **Page Header в Figma — набор вариантов `Profile=full|compact` и булево `Action`** — компактный
  профиль и вторая кнопка видны свойствами одного компонента, без отдельных копий.

## What is left unclear

- Строки списка разговоров (тень аватарки, фон наведения после касания) сюда не входят: причина
  не доказана, задача придёт отдельно.

# Plan

## Points

- **A:** вторую кнопку шапки в виде колокольчика поставить нельзя; с двумя узлами в слоте
  колокольчик уезжает в середину шапки; на телефоне профиль занимает место кружком, именем и
  кареткой; чат с `fill` при длинной ленте уводит поле ввода ниже края колонки.
- **This task reaches:** колокольчик, вторая кнопка с любым значком и профиль стоят вместе у правого
  края через 8 на любой ширине; до 768 профиль — один значок `user`; поле ввода чата всегда видно.
- **Sign:** истории витрины на 375, 768, 1080, 1440 с одной и двумя кнопками и длинная лента чата;
  совпадение чисел с кадрами Figma печатает `node tools/kit-match.mjs numbers`; видит владелец.
- **Milestone G of the epic:** вне эпика, решение владельца передано запустившей сессией.
- **Metric:** нет: шапка и чат кита расходились с макетом.

## What counts as done

- Кадры Figma одобрены владельцем, слова записаны в `approvals.md`.
- `.rt-chat--fill` с `min-block-size: 0`: при 375, 480, 768, 769 и сорока сообщениях низ
  `.rt-chat__composer` не ниже низа колонки; при одном сообщении и на 1081+ раскладка прежняя.
- Слот `[rtHeaderBell]` и профиль стоят в элементе `end` шапки: при 375, 768, 1080 и 1440 с одной и
  двумя кнопками кнопки и профиль рядом у правого края через 8, пункты меню на 1080+ на месте.
- У `rt-notifications-bell` вход `icon`, по умолчанию `bell`.
- До 768 включительно профиль — значок `user`, аватар, имя и каретка скрыты; у кнопки профиля
  `aria-label` с именем.
- Истории витрины на каждое состояние, совпадение чисел с кадрами, наложение показано владельцу,
  витрина одобрена, PR влит, кит выпущен, номер версии назван.

## Stages

### 1. Кадры Figma и слово владельца

- **Steps:**
    1. Нарисовать в Figma правую группу шапки, вторую кнопку, компактный профиль и замену значка колокольчика
    2. Замерить кадры по координатам узлов
    3. Получить слово владельца по кадрам и записать его в `approvals.md`
- **Readiness sign:** в `approvals.md` строка «Макет» со словами владельца.
- **Verified by:** `grep -c 'Макет:' docs/tasks/RT-3345-header-actions/approvals.md` — `1`.

### 2. Код кита

- **Steps:**
    1. Поле ввода чата с `fill`: `min-block-size: 0`
    2. Элемент `end` шапки со слотом и профилем
    3. Вход `icon` у `rt-notifications-bell`
    4. Компактный профиль до 768 и `aria-label` кнопки профиля
    5. Спеки компонентов, `CONTEXT.md` и подраздел описания кита
- **Readiness sign:** тесты трёх компонентов зелёные, сборка кита проходит.
- **Verified by:** `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=src/lib/components/page-header` — `Tests:` без `failed`.

### 3. Витрина и сравнение с кадрами

- **Steps:**
    1. Истории шапки: одна и две кнопки на 375, 768, 1080, 1440, светлая и тёмная тема
    2. Истории чата: длинная и короткая лента с `fill` под полосой
    3. История колокольчика со значком `sparkle`
    4. Сравнение чисел кадров и витрины и кадр наложения
- **Readiness sign:** `kit-match.mjs numbers` печатает N из N.
- **Verified by:** `node tools/kit-match.mjs numbers <figma.json> <showcase.json>` — строка «N из N».

### 4. Показ и выпуск

- **Steps:**
    1. Показать витрину владельцу с адресами историй и числом совпадения
    2. Записать слово владельца по витрине в `approvals.md`
    3. Разобрать папку задачи в архив, запустить набор, отправить ветку и открыть PR
    4. Влить PR и выпустить кит, назвать номер версии
- **Readiness sign:** версия кита на npm выше 0.45.0 и содержит правки.
- **Verified by:** `npm view @rt-tools/ui-kit-v2 version` — номер выше 0.45.0.

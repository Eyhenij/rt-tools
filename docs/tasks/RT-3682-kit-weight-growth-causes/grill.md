## Что уже есть в дереве

- План эпика `docs/plans/kit-weight-remainder.md` задаёт этой задаче признак. Для каждой строки с ростом названы причина и возвратимые байты. Строки: popover, input, core, menu, «вне частей», bottom-sheet, icon-button, form-control, select, dialog, button и gzip набора. Не меньше 90 процентов прироста отнесено к коммитам или возможностям. Каждая причина подтверждена сборкой с ней и без неё. Возвратимые байты измерены, нулевой возврат обоснован.
- Вес считает `tools/check-kit-weight.mjs`, порог лежит в `tools/kit-weight-threshold.json`. Ключ `--package <каталог>` меряет опубликованный пакет.
- Веса по частям для 0.51.0, 0.52.0 и состояния после RT-3648 записаны в `docs/plans/kit-presets-by-demand.md`, раздел «Остаток против 0.51.0 по проверке веса».
- Часть `button` в набор проверки не входит: она сравнивается отдельно, при равном составе.
- Задача ничего в ките не меняет. По итогам владелец по каждой возвратимой строке говорит «вернуть» или «принять рост». Эту развилку задаёт план эпика.

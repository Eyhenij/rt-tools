## Что считается сделанным

- Ход, заведший задачу по записи груза без отметки «в работе», отбивается.
- Ход, отдавший работу по такой задаче без отметки «готово», отбивается.
- Дерево, груза не возящее, гарда не замечает вовсе.
- Отказ называет ключи записей и готовую команду отметки.
- Сценарии заведены в спек домена гардов хода и покрыты пробами.

## Этапы

### 1. Гард

- **Что делается:** хук события `Stop`. Судит два момента: ход, в котором заведена папка задачи с
  ключами груза в разборе просьбы, и ход, в котором работа отдана — открыта заявка либо разобрана
  папка. Отметкой считается вызов команды отметки или закрытия за тот же ход.
- **Признак готовности:** сценарии набора зелёные, отказ называет ключи и команду.
- **Чем проверяется:** `bash projects/agent-kit/tests/cargo-mark-guard.test.sh` — все ok, провалов
  ноль.

### 2. Объявление и правило

- **Что делается:** гард назван ресурсом пакета, объявлен строкой «Требует» в правиле разбора
  груза, статья правила сменила «проверки на это не будет» на названный гард, привязка в
  компаньоне дерева указывает на файл гарда.
- **Признак готовности:** раскладка сходится, сверка спеков новых расхождений не находит.
- **Чем проверяется:** `pnpm run agent-kit:check && npm run check:specs` — ни одной новой строки.

### 3. Раскладка и закрытие

- **Что делается:** сценарии заведены в спек домена, тексты приведены, папка разобрана, заявка
  открыта черновиком.
- **Признак готовности:** набор проб пакета зелёный целиком.
- **Чем проверяется:** `npm run agent-kit:hooks` — все наборы зелёные.

## Чего эта работа не делает

- Не судит разбор: решение «работы по записи не будет» следа не оставляет, и признака у него нет.
- Не требует отметки на каждом ходу работы — только в двух названных моментах.
- Отметку за исполнителя не ставит: гард судит, а не действует.

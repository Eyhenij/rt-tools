# Замысел

**Поведение:** не меняется — правится текст правила о ведении хода.

## Что делается

1. В раздел «Выходы хода», в конец, встаёт абзац: ход, кончающийся при идущем эпике, показывает
   владельцу его положение — тем же, чем оно показывается в передаче.
2. Абзац называет, почему пересказ по памяти не годится: задачу закрывает слияние, которое
   делает владелец.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

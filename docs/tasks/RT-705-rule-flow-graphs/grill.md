# Разбор просьбы

## Просьба владельца

> Делай без остановок, весь эпик

Третья задача эпика RT-702, взятая по назначенному порядку. Разбор просьбы закрыт при заведении
эпика; ответы владельца лежат в `docs/archive/RT-703-rules-review-machine.md`.

## Что уже есть в дереве

- **Двадцать шесть правил** в наборе пакета, все одной раскладки: «Как это называется здесь»,
  «Где это лежит», «Как закон применяется здесь», «Чего из закона здесь нет», «Паттерны»,
  «Ловушки». Два правила несут по седьмому разделу своего.
- **Графа хода нет ни у одного** — ни в тексте, ни рядом файлом.
- **Договорённость** `docs/specs/agent-kit/proposed/rules-review/` держит три правила о графе и
  два сценария при них: `SC-AK-225` и `SC-AK-230`, оба помечены непокрытыми по причине «графа
  ещё нет».
- **Набор полноты текстов** `projects/agent-kit/tests/rules-review.test.sh` судит обязательные
  разделы по роду ресурса — место для проверки графа в нём уже есть.

## Что уже сказано в правилах

- **Граф лежит в тексте самого правила** — решение владельца, записано договорённостью: граф в
  отчёте видит один исполнитель и один раз, а отдельный файл рядом расходится с прозой так же.
- **Граф заводится каждому правилу, а не ветвящемуся** — решение владельца против довода о
  налоге на корпус: правило с графом и без графа стали бы двумя видами одного ресурса.
- **Узлы графа не несут адресов дерева** — правило переносится между репозиториями.

## Вопросы и ответы

Вопросов нет: всё, что решал владелец, решено при заведении эпика, а способ исполнения назван
договорённостью.

## Решения

- **Граф ложится своим разделом, а не внутрь существующего.** Внутри чужого раздела его
  замещает надстройка дерева вместе с разделом — молча; свой раздел хотя бы виден в снимке
  надстроек отдельной строкой.
- **Проверка на отсутствие графа заводится в наборе полноты текстов**, а не отдельной: у неё уже
  есть обход правил и форма отказа.

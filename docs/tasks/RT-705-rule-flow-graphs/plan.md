# Замысел

**Задача:** RT-705 · **Ветка:** RT-705-rule-flow-graphs
**Драфт:** `docs/specs/agent-kit/proposed/rules-review/`
**Поведение:** меняется — правила приезжают в дерево с разделом, которого у них не было, и
проверка полноты текстов получает новый род отказа.

## След задачи

| Что            | Где                                                        |
| -------------- | ---------------------------------------------------------- |
| Правила        | `projects/agent-kit/assets/rules/` — двадцать шесть файлов |
| Проверка       | `projects/agent-kit/tests/rules-review.test.sh`            |
| Образец        | `projects/agent-kit/assets/templates/rule.md`              |
| Договорённость | `docs/specs/agent-kit/proposed/rules-review/`              |
| Спек домена    | `docs/specs/agent-kit/`                                    |

## Что считается сделанным

- У каждого из двадцати шести правил стоит раздел с графом хода, и узлы его не называют ни
  одного адреса конкретного дерева.
- Проверка полноты текстов называет правило без графа — и молчит, когда графы есть у всех.
- Образец правила несёт раздел графа: заводящий новое правило видит его в форме.
- Сценарии `SC-AK-225` и `SC-AK-230` больше не помечены непокрытыми по причине «графа ещё нет».
- Договорённость влита в спек домена, каталог `proposed/rules-review/` снят.
- Ревью прогнано по двум-трём семьям, находки показаны владельцу.

## Этапы

### 1. Раздел графа и проверка при нём

- **Что делается:** в образец правила дописывается раздел графа; в набор полноты текстов —
  отказ на правило без него.
- **Признак готовности:** набор краснеет на двадцати шести правилах разом — это и есть замер до
  работы.
- **Чем проверяется:** `bash projects/agent-kit/tests/rules-review.test.sh`.

### 2. Графы двадцати шести правил

- **Что делается:** каждому правилу пишется граф хода — того хода, который правило и описывает.
- **Признак готовности:** набор зелёный; ни один узел не несёт адреса дерева.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`, `pnpm run agent-kit:sync`.

### 3. Вливание договорённости и прогон ревью

- **Что делается:** правила, сценарии и привязки договорённости переезжают в спек домена;
  каталог `proposed/` снимается; ревью гоняется по двум-трём семьям.
- **Признак готовности:** сверка спеков не печатает новых строк, находки ревью записаны
  владельцу.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`.

## Чего эта работа не делает

- Не переписывает прозу правил под граф: граф изображает то, что уже написано.
- Не заводит графов паттернам, законам и скилам без закона — у закона хода нет, у паттерна он
  уже готовым кодом.
- Не чинит находок, которые вернёт ревью: на них заводятся задачи.

# Замысел

**Поведение:** не меняется — правится текст закона о ведении работы.

## Что делается

1. В раздел статей встаёт статья: постоянное указание среды исполнения слабее правила дерева, и
   расхождение разрешается в пользу дерева.
2. Статья называет признак, по которому расхождение опознаётся: среда описывает своё умолчание
   и о дереве не знает, а дерево отменяет его молча — тем, что говорит иначе.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

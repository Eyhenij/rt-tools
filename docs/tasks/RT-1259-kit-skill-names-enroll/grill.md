# Разбор просьбы

Две записи груза из приёма, соседнее дерево, ресурс `skills/agent-kit.md`. Отметить их этому
дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Первая: откуда берётся объявляемое

- **место:** раздел «Обратная связь наверх», абзац о приёме — после предложения о ключах
- **повод:** абзац называет, чем приём объявляется, и молчит о том, откуда берётся объявляемое.
  Оба значения выдаёт владелец приёма, а не потребитель, и потребителю неоткуда узнать, что
  ждать надо приглашения, а не настройки. Отказ отправки называет ключ и тем самым уводит
  читателя в конфиг — то есть ровно туда, где ответа нет.

## Вторая: команда приглашения в списке

- **место:** раздел «Команды», в список — шестой строкой, перед отправкой
- **повод:** список команд читается как полный: пять строк, и отправка среди них. Упёршийся в
  отказ отправки видит только ключи конфига и не находит команды, которая ключ токена наполняет.
  README пакета это описывает, но его не читает никто: в контекст его не приносит ни гейт, ни
  хук запуска.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

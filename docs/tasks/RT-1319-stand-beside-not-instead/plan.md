# Замысел

**Поведение:** не меняется — правится текст правила о проверке в браузере.

## Что делается

1. В раздел ловушек, следом за пунктом о шаблоне имени команды, встаёт пункт: снятие процесса
   бывает отбито, и тогда стенд поднимается рядом, а не вместо.
2. Пункт называет второй шаг: список оставленного уходит владельцу в конце захода — снять их
   может только он.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

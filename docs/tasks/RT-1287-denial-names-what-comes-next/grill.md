# Разбор просьбы

Две записи груза из приёма, соседнее дерево, ресурс `hooks/skill-gate.sh`. Отметить их этому
дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Отказы идут по одному и читаются как разные требования

На сквозной правке отказы идут по одному на вызов: за одну задачу их было тринадцать, и каждый
стоил хода. Список файлов правки при этом известен заранее — он лежит в самой команде.

## Что в работу не берётся

Вторая запись просит не требовать правило по имени файла, который в команде лишь назван. Это
закрыто прежней редакцией: пути берутся у тех кусков команды, которые пишут, а не у всей строки.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

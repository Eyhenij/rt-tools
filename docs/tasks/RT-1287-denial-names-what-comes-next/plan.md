# Замысел

**Поведение:** не меняется — гейт требует по одному правилу за раз, как и требовал: отказ,
перечисляющий три правила, читается как «загрузи три», и однократность теряется.

## Что делается

Отказ, кроме требуемого правила, называет те, которых по этой же команде потребуется дальше:
строкой «дальше по этой команде потребуются: …». Тринадцать отказов подряд перестают читаться
как тринадцать разных требований — заход видит длину пути с первого раза.

## Чем проверяется

`bash projects/agent-kit/tests/skill-gate.test.sh`, `npm run agent-kit:sync`,
`npm run agent-kit:check`, `npm run check:specs`.

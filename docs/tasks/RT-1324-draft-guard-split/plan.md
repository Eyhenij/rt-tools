# Замысел

**Поведение:** не меняется — те же две правки отбиваются теми же словами; меняется то, что
дерево вправе отказаться от требования договорённости, сохранив требование папки задачи.

## Что делается

1. Требование договорённости о продукте уезжает из гарда хода работы в свой ресурс — гард
   договорённости, объявленный на те же события.
2. В гарде хода работы остаются папка задачи, замысел и объявленное состояние; отказ о
   договорённости из него уходит целиком.
3. Сценарии делятся тем же движением: отбитие по договорённости переезжает в набор нового
   гарда, остальные остаются на месте.
4. Гард договорённости называет в шапке, что требует гарда хода работы: без него он судит
   договорённость у работы, у которой нет ни папки, ни замысла.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`, `node tools/check-file-size.mjs`.

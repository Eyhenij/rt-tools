## Что считается сделанным

- В ресурсах пакета не осталось ни одного имени класса или компонента, принадлежащего
  дереву-потребителю: поиск по каталогу ресурсов это подтверждает.
- Проверка единообразия на этом дереве не даёт ни одного ложного срабатывания на его ките:
  сегодня их два.
- Гард единообразия отбивает переизобретение. Сегодня он не отбивает ничего: профили печатают два
  поля, а он читает четыре, и пустое поле схлопывается табом в `IFS`.
- Гард и сплошная проверка читают один и тот же объявленный набор.
- Дерево-потребитель объявляет наборы по пакетам rt-tools и дописывает свои признаки файлом.
- Набор сценариев на гард единообразия заведён и зелёный.

## Этапы

### 1. Договорённость о продукте

- **Что делается:** `docs/specs/agent-kit/proposed/reuse-signals/` — правила, коды отказов,
  сценарии `SC-AK-142`…`SC-AK-150`.
- **Признак готовности:** ни одного нового правила без сценария.
- **Чем проверяется:** `node tools/check-specs.mjs`.

### 2. Наборы признаков по пакетам

- **Что делается:** `assets/checks/signals/<пакет>.json` — по файлу на пакет rt-tools, плюс набор
  признаков самого фреймворка. Имена в них — только свои.
- **Признак готовности:** каждый признак прежнего списка нашёл себе набор либо ушёл к дереву.
- **Чем проверяется:** разбор JSON и поиск чужих имён по каталогу ресурсов.

### 3. Общий читатель наборов

- **Что делается:** `assets/checks/signals.mjs` — объявленные наборы, свои признаки поверх них,
  отказ на неизвестный набор.
- **Признак готовности:** проверка единообразия признаков в своём коде не держит.
- **Чем проверяется:** прогон проверки на этом дереве.

### 4. Гард читает те же наборы

- **Что делается:** `reuse-first-guard.sh` — чтение объявленных наборов, разбор полей без потери
  пустых, слово о том, что признаков нет вовсе. Функция профиля остаётся и читается вместе с ними.
- **Признак готовности:** гард отбивает переизобретение на этом дереве.
- **Чем проверяется:** набор сценариев гарда.

### 5. Набор сценариев на гард

- **Что делается:** `projects/agent-kit/tests/reuse-guard.test.sh` — отбитие, пропуск по маркеру,
  область признака, пустое поле, дерево без наборов.
- **Признак готовности:** набор зелёный и ловит прежнее поведение как отказ.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`.

### 6. Дерево объявляет свои наборы

- **Что делается:** `.claude/rt-kit/checks.json` — объявленные наборы; свои признаки дерева
  файлом; профиль приводится к четырём полям.
- **Признак готовности:** ложных срабатываний на ките нет, снимок долга пересмотрен.
- **Чем проверяется:** `pnpm run check:reuse` и прогон гарда на живой правке.

### 7. Тексты

- **Что делается:** правило `reuse-first` и его спутник, правило `agent-kit`; вливание
  договорённости в спек домена.
- **Признак готовности:** в текстах не осталось утверждения, что признаки лежат в коде проверки.
- **Чем проверяется:** `node tools/check-specs.mjs`, `node tools/check-doc-paths.mjs`.

## Чего эта работа не делает

- Не заводит сплошной сверки предметных имён по всем ресурсам пакета: чинится один ресурс.
- Не сверяет объявленные наборы с зависимостями дерева — это `Q-18` договорённости.
- Не трогает накопленный долг других проверок дерева.

## Decisions along the way

- **Строка правила о доступе к платформе тоже получила `#doc`.** Она называет
  `this.#document.defaultView` примером пути, который линтер пропускает; после переименования образца
  пример в правиле назывался бы иначе, чем код по образцу.
- **Примеры в комментариях рисуют значок через `svg` с `use`.** Так пример остаётся рабочей
  разметкой и не содержит тега картинки, который ищет инструмент.
- **Верное число картинок — 11, «10» в разделе «Что считается сделанным» плана — описка.** Точки
  плана, признак шага 1.2 и вывод инструмента дают 11; план после записи не правится.
- **Первый круг ревью.** Принято: описка 10/11, строка 9 плана эпика — «в ревью», «Что даёт» плана
  эпика — «кроме оговорок вехи G», причина превью загрузки уточнена. Списано: директива прокрутки
  core на сервере по-прежнему не прокрутит — это не регрессия (раньше она падала на глобальном
  `document`), и директивой в дереве никто не пользуется. Перевод картинок с известным размером
  не сделан по одобренному плану: «большие изменения — в новый эпик», это RT-3561.

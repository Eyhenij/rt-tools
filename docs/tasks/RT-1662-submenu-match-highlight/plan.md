# Замысел

**Задача:** RT-1662 · **Ветка:** RT-1662-submenu-match-highlight
**Поведение:** меняется — в отобранной подписи отмечено то, чем она совпала
**Спек:** `docs/specs/ui-kit/spec.md`

## Что считается сделанным

- В подписи отобранного пункта отмечено ровно то, что человек набрал, и все вхождения.
- Регистр подписи не меняется.
- Пустой запрос не отмечает ничего: список полон, отмечать в нём нечего.

## Этапы

### 1. Чистая часть: резка подписи на куски

- **Что делается:** функция, режущая подпись на совпавшие и несовпавшие куски
- **Признак готовности:** пробы на пустой запрос, одно вхождение, несколько, другой регистр и
  запрос, которого в подписи нет, зелёные
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit --testFile=projects/ui-kit/src/lib/ui-kit/side-menu`

### 2. Отметка в разметке подпункта

- **Что делается:** запрос доходит до подпункта входом, подпись рисуется кусками, совпавший
  помечен элементом со своим оформлением
- **Признак готовности:** в отобранном списке отмечено набранное; без запроса разметка прежняя
- **Чем проверяется:** `pnpm run test:visual` — кадры витрины сходятся, новый кадр снят осознанно

## Чего эта работа не делает

- Поиска по чему-либо, кроме подписи: ни по адресу, ни по вложенным пунктам закрытого раздела.
- Перехода к следующему совпадению клавишей: заявлено не было.

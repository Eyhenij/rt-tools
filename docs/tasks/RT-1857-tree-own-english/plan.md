## Этапы

### 1. Надстройки

- **Что делается:** двадцать одна надстройка переводится вместе с проверкой слитого документа;
  раздел своим именем остаётся своим разделом.
- **Признак готовности:** разложенный файл после раскладки одноязычен по всем разделам.
- **Чем проверяется:** `pnpm run agent-kit:sync && pnpm run agent-kit:check` — сходится;
  `npm run check:specs` — без расхождений.

### 2. Свои правила и их компаньоны

- **Что делается:** тринадцать своих правил и паттернов переводятся вместе с компаньонами;
  цитата статьи в компаньоне правится той же правкой.
- **Признак готовности:** привязки сходятся, число статей в каждом правиле равно прежнему.
- **Чем проверяется:** `npm run check:specs` — без расхождений; `npm run check:descriptions`.

### 3. Свои хуки и свои проверки

- **Что делается:** два своих хука и двадцать шесть своих проверок переводятся вместе со своими
  наборами; текст владельцу остаётся русским.
- **Признак готовности:** наборы своих хуков и проверок зелены при английском тексте.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — без провалов; `npm run check:all`.

### 4. Карта гейта, профиль и памятка дерева

- **Что делается:** комментарии карты гейта и профиля, памятка `CLAUDE.md` переводятся.
- **Признак готовности:** гейт зовёт те же правила на тех же путях, что и до перевода.
- **Чем проверяется:** вызов гейта на трёх путях — правленом, соседнем и без правила.

### 5. Замер и разбор

- **Что делается:** замер байтов своего дерева записывается в замысел эпика; исключения
  перечисляются поимённо.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `pnpm run check:all` — зелено; гейт пуша проходит.

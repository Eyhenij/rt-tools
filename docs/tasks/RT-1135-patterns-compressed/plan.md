## Что считается сделанным

- Паттерны сжаты по той же форме: из них вырезаны случаи и числа, а готовый код и порядок
  остались нетронутыми.
- Ни один блок кода не тронут: паттерн ценен именно кодом, и правка примера — это правка того,
  что из него копируют.
- Вес назван числом: сколько знаков было в паттернах и сколько стало.
- Названа граница: паттерн грузится по имени, а не вместе с правилом, поэтому выигрыш здесь
  меньше, чем у правил, и считается он иначе.

## Этапы

### 1. Замер до и отбор

- **Что делается:** считается вес всех паттернов, выбираются те, где рассказа больше, чем кода.
- **Признак готовности:** названы числа — общий вес и список отобранных.
- **Чем проверяется:** `pnpm run agent-kit:cost` — вес слоя до правки.

### 2. Сжатие отобранных паттернов

- **Что делается:** вырезаются случаи, числа и повторы довода правила; блоки кода не трогаются.
- **Признак готовности:** ни один блок кода не изменён, перечень разделов у каждого паттерна
  прежний.
- **Чем проверяется:** `bash projects/agent-kit/tests/rules-review.test.sh` — полнота текстов.

### 3. Сверка и замер после

- **Что делается:** гоняются сверки слоя, считается вес после.
- **Признак готовности:** названа разница числом.
- **Чем проверяется:** `pnpm run agent-kit:check` — раскладка сходится с пакетом.

### 4. Отдача

- **Что делается:** набор гейта, разбор папки задачи, заявка черновиком.
- **Признак готовности:** заявка открыта, номер назван владельцу.
- **Чем проверяется:** `git push` — гейт пропустил.

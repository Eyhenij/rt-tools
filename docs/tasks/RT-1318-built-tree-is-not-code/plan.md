# Замысел

**Поведение:** не меняется — гейт требует те же правила; из-под требования выходит собранное
дерево, которое правкой не бывает.

## Что делается

1. В карту гейта, первой веткой правки, встаёт выход на каталоги сборки и зависимостей.
2. Ветка стоит раньше прочих: под артефактом лежат те же имена каталогов, что и под исходником,
   и любая ветка ниже совпала бы с ним.
3. Сценарий при карте: путь под каталогом сборки правила не требует, а тот же путь под
   исходниками требует прежнее.

## Чем проверяется

Набор сценариев карты гейта, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`, `node tools/check-file-size.mjs`.

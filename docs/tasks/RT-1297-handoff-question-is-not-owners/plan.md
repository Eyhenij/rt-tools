# Замысел

**Поведение:** не меняется — правится текст правила о входе в заход.

## Что делается

1. В раздел ловушек правила входа в заход, рядом с пунктом о том, что передача пишется для
   машины, встаёт пункт о вопросе в ней: адресован он автору передачи, а не владельцу.
2. Пункт называет порядок: до владельца такой вопрос доходит после сверки с ходом работы —
   часть таких вопросов закрыта его шагом.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

Шестая задача эпика RT-3603: ревью смотрит структуру кода, а переделки после ревью считает команда.

## Что уже есть в дереве

- Роль `qa-engineer` ищет поломки: тесты, браузер, сборка, чужие входы. О модулях, связях и лишнем наружу в её тексте
  слова нет. Граней ревью в `workflows/feature.js` четыре, структуры среди них нет.
- `check-coupling` печатает «было → стало» по модулям ветки. Роль его вывода не получает: на зелёном наборе его никто
  не видит.
- Паттерн `task-delivery-loop-run` называет, что получает каждая роль: роль `qa-engineer` получает описание и грань
  ревью, без раздела «Решение» и без зацепления.
- Строк, которые переделал круг ревью, и файлов вне следа плана не считает ничто. Коммит круга узнаётся по заголовку
  «… после первого круга ревью (RT-N)».
- След плана читает `task-flow/measure/text.mjs:footprintRows` и `touches`; маски `*` и `**` `touches` раскрывает с
  RT-3611.
- С RT-3611 конец этапов сравнивает код с «Решением» плана: места, наборы, новые файлы, бюджет и связи. Зависимости и
  границы словами мерило не читает — это оставлено роли этой задачи.

## Что измерено

Записанная правка: модуль читает файл кассы и складывает текст отчёта, рядом экспорт, который никто не зовёт, и
импорт без употребления. Роль запущена дважды, с прежним текстом и с новым.

| Находка | Прежний текст | Новый текст |
| --- | --- | --- |
| модуль с двумя обязанностями | край строки о расхождении с планом, важность низкая | первая находка, важность средняя, с правкой |
| лишний экспорт `legacyTotalsOf` | названа | названа |
| второй экспорт без вызова снаружи | названа | названа |
| импорт без употребления прячет число `taken by nobody` | названа | названа |
| числа зацепления против плана | сравнены | сравнены, с цитатой вывода |

Вывод честный: прежний текст видит почти то же, когда ему дали план и вывод зацепления. Новый текст поднимает модуль
с двумя обязанностями из примечания в находку. Больше всего меняет то, что роль их получает.

Черновая команда на вершине эпика `a79855d82`, след через `touches`: RT-3535 — 265 строк первого круга; RT-3592 —
коммита первого круга нет, 17 файлов вне следа; RT-3611 — 314 строк, вне следа 0. Последние 20 задач: новых циклов 0,
новых обходов 0, превышений 18, медиана первого круга 275,5 строки. Счёт двадцати идёт 2 мин 22 с.

Чтение плана ролями нашло, что строки круга считали и разложенные копии с ходом работы. Без копий, папки задачи,
архива и планов: RT-3535 — 150 строк, RT-3611 — 182, медиана двадцати — 177,5.

Случай набора нашёл ложный ноль первого черновика: `check-coupling` на самом слиянии собственных коммитов ветки не
видит, и превышений было 0. Считается вершина ветки.

## Вопросы и ответы

- **Что делать с первой половиной вехи эпика?** Новых циклов и обходов у 20 задач до выпуска уже ноль. Половина вехи
  «новых циклов и обходов ноль» выполнена до работы, отличие покажут превышения и медиана строк. Ответ владельца: ждёт
  утра.

## Решения

- **Команда лежит в `tools/`, а не в пакете.** Довод: заголовок коммита круга и заголовок слияния — порядок этого
  дерева. Цена ошибки: перенос одного файла.
- **Вне следа не считаются папка задачи, архив, планы и разложенные копии.** Довод: их не называет ни один план. Цена
  ошибки: одна строка образца.
- **План берётся первым написанным.** Довод: строка, дописанная после кода, прячет файл вне следа. Цена ошибки: одна
  функция.
- **Слияния эпиков пропускаются по отсутствию плана.** Довод: у эпика нет папки задачи. Цена ошибки: слияние задачи без
  плана тоже пропущено.

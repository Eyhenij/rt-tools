# Замысел

**Задача:** RT-1009 · **Ветка:** RT-1009-pr-author-machine-account
**Поведение:** не меняется — правка задевает компаньон правила поставки, а не код приложения;
так сказал владелец, потребовав открывать PR машинной записью.

## След задачи

| Что     | Где                                             |
| ------- | ----------------------------------------------- |
| Правила | `.claude/skills/git-workflow/implementation.md` |
| Законы  | `docs/constitution/delivery.md`                 |
| Разборы | `docs/postmortems/`                             |

## Что считается сделанным

- Компаньон говорит, что PR открывает машинная запись, и называет команду, которой это делается.
- Утверждение о невидимости PR стоит при прежней записи, названо её именем и несёт срок, после
  которого оно неверно.
- В компаньоне не осталось строки, велящей открывать PR записью владельца.
- Промах записан разбором происшествия: правило и компаньон говорили об одном разное, и
  исполнитель пошёл за компаньоном.

## Этапы

### 1. Статья компаньона о невидимости привязана к прежней записи

- **Что делается:** статья называет `rt-tools-agent` поимённо и говорит, что для нынешней
  записи проверено обратное; строка «PR открывается учётной записью владельца» снимается,
  вместо неё стоит открытие машинной записью с готовой командой.
- **Признак готовности:** в компаньоне нет требования открывать PR записью владельца.
- **Чем проверяется:** `grep -c 'PR открывается учётной записью владельца' .claude/skills/git-workflow/implementation.md` — ноль означает «сошлось».

### 2. Разбор происшествия

- **Что делается:** пишется запись о том, как расхождение правила и компаньона увело PR к
  записи владельца и чем это кончилось.
- **Признак готовности:** запись лежит в каталоге разборов и названа днём происшествия.
- **Чем проверяется:** `ls docs/postmortems/2026-08-22-pr-opened-as-owner.md` — вывод с именем файла означает «сошлось».

## Чего эта работа не делает

- Не трогает ключа борды: очередь работ этой записью не правится по другой причине — нулевой
  квоте на язык запросов, — и та статья компаньона остаётся как есть.
- Не разбирает правило ведения работы у предела длины: это задача RT-990.

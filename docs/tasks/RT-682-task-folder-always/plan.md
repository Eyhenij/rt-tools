## Что считается сделанным

- Правило `task-flow` не даёт ни одного исключения из требования папки задачи: ловушка о
  работе без своей папки и статья «гард замысла — нижняя граница» сняты.
- Паттерн `task-flow-close` говорит, как разобрать две папки одним коммитом.
- Гард хода работы отбивает команду оболочки, которая пишет файл под требованием, — так же,
  как отбивает вызов инструмента правки.
- Сценарий на каждый правленый гард закрывает обе двери: вызов инструмента и команду оболочки.
- Разбор происшествия назван в правиле, в разделе о поведении исполнителя.

## Этапы

### 1. Гард хода работы судит команду оболочки

- **Что делается:** в `task-flow-guard.sh` заводится разбор `Bash`: из текста команды достаются
  имена файлов, которые она пишет, и каждое судится тем же признаком, что и путь из вызова
  правки.
- **Признак готовности:** правка файла под требованием командой оболочки отбивается.
- **Чем проверяется:** сценарий набора гардов.

### 2. Тот же ярус у остальных гардов пути

- **Что делается:** приём выносится в общую функцию и подключается к гардам, которые судят путь
  правки, — по одному, с проверкой каждого.
- **Признак готовности:** ни один гард пути не пропускает правку через оболочку.
- **Чем проверяется:** сценарии наборов.

### 3. Правило и паттерны

- **Что делается:** из `rules/task-flow.md` снимаются оба исключения; в раздел о поведении
  исполнителя встаёт статья об отказе гарда; `patterns/task-flow-close.md` учится разбирать две
  папки; `patterns/task-flow-start.md` перестаёт разрешать работу без папки.
- **Признак готовности:** в правиле не осталось формы, разрешающей работать без папки задачи.
- **Чем проверяется:** чтение правила целиком.

### 4. Раскладка и проверки

- **Что делается:** форматтер, `agent-kit:sync`, весь набор гейта.
- **Признак готовности:** раскладка сходится с пакетом, проверки зелёные.
- **Чем проверяется:** `agent-kit:check`, `check:docs`, сценарии гардов, юниты пакета.

## Чего эта работа не делает

- Не трогает признак «код приложения»: владелец выбрал править правило, а не признак.
- Не заводит гард на команды, которые файл не пишут: чтение и поиск отбивать незачем.

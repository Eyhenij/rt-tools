- **место:** статьёй сразу после «Признак режима исполнения объявлен в самом артефакте
  развёртывания…»
- **повод:** образ службы не копировал файл настройки клиента хранилища, и накат изменений
  хранилища отказал на первом же подъёме прода. Ни линтер, ни сборка, ни шаг сборки образа в
  конвейере этого не видят: образ собирается, а отказывает он только при запуске наката.

## Решения по ходу

- **Записывается приём, а не разовое решение.** Владелец назвал каскад сам, увидев цену веток из
  одного основания; сказанное в переписке следа в дереве не оставляет и на следующем заходе не
  действует.
- **Перестройка накопленного вынесена из этой работы.** Сперва приём, потом его применение:
  перестраивать сто шесть веток по ненаписанному правилу — значит писать правило задним числом
  под то, что уже сделано.

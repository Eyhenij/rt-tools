## Этапы

### 1. Статья закона

- **Что делается:** в закон о поставке встаёт статья о ветвлении работ, идущих одна за другой.
- **Признак готовности:** статья говорит утверждением о продукте, путей и имён в ней нет.
- **Чем проверяется:** `npm run check:specs` — закон, назвавший файл проекта, роняет сверку.

### 2. Статьи правила и место исполнения

- **Что делается:** в правило поставки встают статьи о каскаде и о том, чем он платится;
  компаньон получает строку привязки.
- **Признак готовности:** каждой новой статье отвечает строка компаньона.
- **Чем проверяется:** `npm run agent-kit:sync` — «статей без адреса» не называет.

### 3. Готовый приём в паттерне

- **Что делается:** паттерн стопки получает раздел о каскаде: сборка, порядок отдачи, чем он
  отличается от веток одного основания.
- **Признак готовности:** команды в паттерне запускаются как написаны.
- **Чем проверяется:** `node tools/check-file-size.mjs` — паттерн не перерос предел веса.

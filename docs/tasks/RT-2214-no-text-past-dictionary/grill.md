# Grill

## The owner request

> заводи новый эпик - в приёмнике текст написаны хуй пойми как, половина на русском, половина на
> английском, везде должны быть ключи и переводы

> веди RT-2208

Шестая и последняя задача эпика #2208 по его плану.

## Ответы владельца

Даны при заведении эпика 17 сентября; новых вопросов задача не открывает.

- **Сколько языков:** два — русский и английский.
- **Чем переводить:** свой загрузчик словаря, как у кита, а не новая зависимость.
- **Признак конца эпика:** на английском экран не содержит русских слов, и проверка запрещает
  новую строку текста мимо словаря.

## Что в дереве уже есть

- Словарь на два набора завела RT-2209; экраны входа перевела RT-2210, экраны разделов — RT-2211,
  отказы приёмника — RT-2212, английский набор наполнила RT-2213.
- Русского текста мимо словаря в админке не осталось: экраны берут подписи по ключу. Но ничто не
  мешает написать его заново — ни линтер, ни сборка такую строку не видят.
- В дереве уже есть проверки такого рода: словарь запретных слов, размер файлов, пути в текстах.
  Набор перед отправкой их зовёт, и новая встаёт в тот же ряд.

## Измерение на 18 сентября

Строк с кириллицей в разметке админки вне комментариев — одна: `<title>Приёмник</title>` в
`apps/message-bus-admin/src/index.html`. Она показывается до запуска приложения, когда словаря
ещё нет. Строковых значений с кириллицей в коде админки — ноль.

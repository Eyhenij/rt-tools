# Разбор — RT-3047

## Просьба владельца

> читай что нового в приёмнике, заводи эпик и задачи под каждую находку и бери в работу, открывай
> пр по одному и отдавай мне на ревью, не переходи к следующей задаче пока я не дам аппрув и пока
> не будет вмержен этот пр

После слияния #3111: «влил, бери следующую».

## Что не так

PR в ветку эпика открыт с `--draft` по привычке. Конвейер на эту базу не запускается, и черновик
полчаса ждал CI, которого не будет. Статья правила есть, проверки нет.

## Решения

- Открытие PR с `--draft` отказывает, если база не входит в ветки, на которые конвейер запускается.
- Список баз читается из файла конвейера, который дерево уже назвало для проверки набора.
- Неизвестно — не судим: нет файла, нет фильтра по веткам, другой хостинг.
- Законы не правятся, договорённость о продукте не нужна: код приложений не тронут.

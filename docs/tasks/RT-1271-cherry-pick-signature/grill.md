# Разбор просьбы

Пять записей груза из приёма, соседнее дерево, ресурс `patterns/git-workflow-merge.md`.
Отметить их этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс
живёт здесь.

## Черри-пик обещан и не описан

Раздел «Когда брать» прямо называет перенос коммита черри-пиком, а в теле паттерна о нём нет ни
команды, ни слова о подписи. Порядок собирается по памяти, и первый же промах стоит
перебазирования: черри-пик сохраняет автора и ставит коммиттером того, кто его зовёт, — то есть
человека, а коммиттера читает набор проверок перед пушем.

## Что в работу не берётся

Четыре записи того же ресурса закрыты прежними редакциями: переменные подписи стоят в самой
команде слияния, строка о спеке и строка о компаньоне правила стоят в таблице приёмов, ловушки
о снятом разделе и об ушедшем за подписью человека мерже — в «Частых промахах».

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

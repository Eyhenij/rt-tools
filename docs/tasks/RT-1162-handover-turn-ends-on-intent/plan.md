## Что считается сделанным

- Ход, в котором открыта заявка, не кончается, пока после неё нет действия по следующей работе.
- Действием считается заведение задачи или ветки, перевод колонки, правка файла — то есть шаг,
  сделанный уже не по сданной работе.
- Ход, в котором заявка открыта и следующая задача начата, отпускается как прежде.
- Ход без открытия заявки этим ярусом не судится.
- Набор стража краснеет, если ярус выключить.

## Этапы

### 1. Ярус «работа отдана, а следующая только названа»

- **Что делается:** страж ищет вызов открытия заявки и смотрит, что было после него.
- **Признак готовности:** в хуке есть образец начала следующей работы и суд по хвосту хода.
- **Чем проверяется:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — все сценарии зелёные.

### 2. Сценарии на новый ярус

- **Что делается:** заводятся сценарии на отдачу без начала следующей, на отдачу с началом и на
  ход без отдачи.
- **Признак готовности:** набор краснеет при выключенном ярусе.
- **Чем проверяется:** `bash projects/agent-kit/tests/turn-exit-guard.test.sh` — счёт сценариев вырос.

### 3. Статья правила и разбор происшествия

- **Что делается:** статья в `turn-conduct` о том, что отдача работы концом хода сама по себе не
  бывает; разбор ложится в `docs/postmortems/`.
- **Признак готовности:** статья привязана, тексты сходятся с деревом.
- **Чем проверяется:** `npm run check:docs` — путей-призраков нет.

## Чего эта работа не делает

- Не трогает ярус ожидания и ярус разведки: они судят другой конец хода.
- Не требует, чтобы следующая задача была доведена до конца тем же ходом: требуется первое
  действие по ней, а не её закрытие.

## Этапы

### Этап 1 — пересъёмка эталонов

Кадры снимаются одним вызовом с доводом обновления; браузер берётся из образа, иначе кадры не
годятся ни на одной другой машине.

Мерка до правки: 102 прошли, 25 упали — 23 кадра и два следствия.

Признак готовности: прогон без довода обновления даёт 123 из 123.

### Этап 2 — второй прогон на заново поднятом стенде

Кадр, снятый один раз, говорит, что машина нарисовала в ту минуту, а не что она рисует. Стенд
поднимается набором заново на каждом прогоне, поэтому второй вызов той же команды и есть второе
поднятие.

Признак готовности: второй прогон подряд даёт 123 из 123, и ни один эталон не изменился после
первого.

### Этап 3 — тексты и разбор папки

Отметка в прогрессе, строка 7.8 плана эпика дополняется сделанным, папка задачи разбирается
последним коммитом, запись уходит в описание прошлого.

Признак готовности: `npm run check:docs` зелёная, папки задачи в ветке нет, запись в
`docs/archive/` есть.

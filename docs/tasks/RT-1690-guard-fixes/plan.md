## Этапы

### 1. Диспетчер и гард источника правил

- **Что делается:** имя упавшей ветки в отказе; пропуск файла в конфликте.
- **Признак готовности:** прогон гардов на подготовленных строках даёт ожидаемые коды.
- **Чем проверяется:** прямой вызов гарда с готовым вводом.

### 2. Гард прогона и гард главной ветки

- **Что делается:** строка наблюдения на каждый исход; нормализация команды перед отбором.
- **Признак готовности:** команда с флагами между `git` и глаголом отбивается, чтение истории —
  нет.
- **Чем проверяется:** прямой вызов гарда на обеих строках, `pnpm run agent-kit:check`, тесты
  пакета правил.

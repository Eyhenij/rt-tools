**Behaviour:** unchanged — правка отправки груза пакета правил, приложения не касается

## Что задача затрагивает

| Что      | Где                                           |
| -------- | --------------------------------------------- |
| Код      | `projects/agent-kit/src/lib/shipment.ts`      |
| Описания | `docs/specs/agent-kit/cargo-prose/`           |
| Пробы    | `projects/agent-kit/src/lib/shipment.spec.ts` |

## Что считается сделанным

- Оба прогона — сухой и настоящий — называют блоки, которые сочли уже уехавшими: файлом, строкой и
  значением пометки.
- Строка о пропущенном печатается и при нуле пропущенных.
- Пометка со значением, которого отправка не ставила, названа отдельно.
- Запись груза помечена в приёмнике сделанной.

## Этапы

### 1. Пропущенное называется обоими прогонами

- **Что делается:** отбор груза разделяется надвое; пропущенные как отправленные печатаются строкой
  со счётом и перечнем «файл:строка — пометка»; ноль печатается тоже
- **Признак готовности:** дерево с проставленной рукой пометкой видит блок в выводе обоих прогонов
- **Проверено:** `pnpm exec nx test @rt-tools/agent-kit --testFile=src/lib/shipment.spec.ts` —
  сейчас набор зелёный; после этапа проб больше, провалов нет

### 2. Пометка не своей формы названа отдельно

- **Что делается:** значение пометки сверяется с формой `приём:<месяц>`; не своё называется словами
  о том, что поставлено рукой
- **Признак готовности:** блок с пометкой «нет» назван поставленным рукой, а блок с пометкой
  отправки — просто пропущенным
- **Проверено:** тот же набор проб

### 3. Описания, установка файлов из пакета и пометка в приёмнике

- **Что делается:** сценарии в описание, пакет собирается и раскладывается, запись груза помечается
- **Признак готовности:** аудит описаний и аудит установки молчат
- **Проверено:** `npm run check:specs` — сейчас 6 областей, 1547 сценариев, расхождений нет

## Чего работа не делает

- Не трогает счёт «уже лежало N»: он приходит от приёмника и его значение верно.

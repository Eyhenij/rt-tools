## Что считается сделанным

- Ни один одноразовый контейнер в текстах дерева и пакета не оставляет за собой анонимный том:
  `--rm` везде идёт с `-v`.
- Проба дампа на прод-сервере снимает свой контейнер, а не копит их от прогона к прогону.
- Паттерн работы с образами называет уборку томов наравне с замером места и говорит, чем
  чистить накопленное отбором, а не общей чисткой.
- `pnpm run agent-kit:check` расхождений не даёт: правка исходника пакета разложена в дерево.
- `npm run check:docs` расхождений не прибавил.

## Этапы

### 1. Одноразовые контейнеры убирают за собой

- **Что делается:** `--rm` получает `-v` там, где образ объявляет том; проба дампа получает
  снятие контейнера.
- **Признак готовности:** ни одной команды `docker run --rm` без `-v` и ни одной `docker run -d`
  без парного снятия в текстах дерева и пакета.
- **Чем проверяется:** поиск по дереву, `npm run check:docs`.

### 2. Уборка названа там, где её прочтут

- **Что делается:** паттерн работы с образами получает раздел о томах: чем они родятся, чем
  меряются и чем снимаются отбором.
- **Признак готовности:** раздел стоит, команда отбора в нём не трогает чужого.
- **Чем проверяется:** `pnpm run agent-kit:check`, `npm run check:docs`.

## Чего эта работа не делает

- Не чистит машину: накопленное снято до заведения задачи, по слову владельца.
- Не трогает кэш сборщика: он свежий и нужен сборкам образов.
- Не заводит чистку в конвейер отдельным шагом — сперва надо, чтобы мусор перестал родиться.

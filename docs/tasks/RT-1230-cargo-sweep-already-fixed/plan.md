# Замысел

**Задача:** RT-1230 · **Ветка:** RT-1230-cargo-sweep-already-fixed
**Поведение:** не меняется — заводится команда разбора груза; `apps/**` и `libs/**` работа не
задевает.

## След задачи

Запись груза, чья правка уже приехала редакцией пакета, остаётся в «новом» и разбирается заново
каждым заходом: предложение читается, ресурс открывается, статья находится стоящей. За одну ночь
так было пять раз подряд на правиле проверяемости. Отличить такую запись от неразобранной можно
на месте: у предложения есть цитата статьи, и заголовок статьи либо стоит в источниках пакета,
либо нет.

| Что   | Где                           |
| ----- | ----------------------------- |
| Код   | `tools/cargo-fixed.mjs`       |
| Спеки | `docs/specs/agent-kit/cargo/` |

## Что считается сделанным

- Команда дерева читает груз, берёт свои записи и печатает, у каких предложенная статья уже
  стоит в источниках пакета.
- Сухой прогон — умолчание: отметка ставится только явным доводом.
- Отобранные записи переведены в «готово» с приёмом починки.

## Этапы

### 1. Команда отбора

- **Что делается:** заводится `tools/cargo-fixed.mjs`: читает груз чтением, отбирает свои
  записи, достаёт из тела заголовок предложенной статьи и ищет его в `projects/agent-kit/assets`.
- **Признак готовности:** команда печатает три числа — своих записей, со стоящей статьёй, без
  цитаты — и перечень ключей первой группы.
- **Чем проверяется:** `node tools/cargo-fixed.mjs` — печатает перечень и не ходит наружу.

### 2. Отметка отобранных

- **Что делается:** отобранные записи переводятся в «готово» вызовом команды отметки с приёмом
  починки.
- **Признак готовности:** ответ отметки называет число переведённых.
- **Чем проверяется:** вывод `node tools/cargo-mark.mjs --state fixed …`.

### 3. Место команды и её сценарии

- **Что делается:** команда встаёт в манифест дерева, заводятся сценарии на отбор.
- **Признак готовности:** команда зовётся именем, сценарии зелены.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh`.

## Чего эта работа не делает

- Не трогает записей чужих деревьев: токен отметки двигает только свои.
- Не судит соответствия по смыслу: сходится заголовок статьи — и только он. Запись, чьё
  предложение легло в дерево другими словами, командой не находится и остаётся новой.

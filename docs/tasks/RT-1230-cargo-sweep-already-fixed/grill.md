# Разбор просьбы

## Просьба владельца

> после обновления agent kit делай задачи из техдолга из приёмника, одну за другой, без
> остановок… не пуш ветки - храни все ветки локально… твоя задача - закрыть как можно больше
> задач в локальных ветках до утра.

## Что взято

Не запись груза, а весь его разбор. Разбирая приёмник задачу за задачей, видно повторяющееся: у
части записей правка уже стоит в дереве — её привезла редакция пакета, вышедшая позже отправки.
Такая запись висит в «новом», и следующий заход берёт её заново, читает предложение, идёт в
ресурс и находит статью уже стоящей. За эту ночь так было пять раз подряд на одном правиле.

## Прочтение

Записи, чья правка уже в главной ветке, переводятся в «готово» с приёмом починки. Отбираются они
не на глаз: у записи есть цитата предложенной статьи, и статья ищется по её заголовку в
источниках пакета. Найденная — запись готова; ненайденная — остаётся новой и ждёт своей задачи.

## Чего владелец не спрашивал

Вопросов ночью не задаётся. Записи чужих деревьев не трогаются вовсе: токен отметки двигает
только свои.

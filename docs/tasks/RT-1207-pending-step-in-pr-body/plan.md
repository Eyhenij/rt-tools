# Замысел

**Задача:** RT-1207 · **Ветка:** RT-1207-pending-step-in-pr-body
**Поведение:** не меняется — правятся гард поставки, его тексты и профиль дерева; `apps/**` и

Задача 9 эпика RT-1198.

## След задачи

Кнопку слияния нажимает человек на хостинге, куда гард не достаёт. Всё, чем требование там
держится, — то, что владелец увидел на странице заявки. Раздел об оставшемся шаге паттерн уже
требует, но стоит требование ниже описания открытия заявки: читающий доходит до открытия,
открывает — и раздела ещё не прочитал. Заявка этого же эпика открылась без него.

Что перечитать при закрытии: паттерн закрытия работы — порядок его разделов; спека гарда
поставки — что он судит на открытии заявки.

| Что     | Где                                                     |
| ------- | ------------------------------------------------------- |
| Спеки   | `docs/specs/agent-kit/delivery-gate/`                   |
| Правила | `.claude/skills/task-flow-close/`                       |
| Код     | `projects/agent-kit/assets/hooks/git-guard-delivery.sh` |

## Что считается сделанным

- Открытие заявки, в теле которой нет обязательного раздела, отбивается гардом поставки вместе
  с остальным несошедшимся — одним отказом, а не по одному.
- Образец раздела называет дерево; не названный, требования не даёт вовсе.
- Тело, переданное файлом, судится наравне с телом в доводе команды.
- Требование раздела стоит в паттерне там, где описано открытие заявки, а не после него.

## Этапы

### 1. Гард поставки судит тело заявки на обязательный раздел

- **Что делается:** к условиям открытия заявки прибавляется раздел тела; образец приходит от
  профиля дерева, и без него требования нет.
- **Признак готовности:** вызов без раздела отбивается и называет, чего не хватает; вызов с
  разделом проходит.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — набор сценариев гардов зелёный.

### 2. Дерево называет свой образец

- **Что делается:** в профиль дерева встаёт функция, печатающая образец обязательного раздела.
- **Признак готовности:** открытие заявки без раздела в этом дереве отбивается.
- **Чем проверяется:** `bash .claude/hooks/git-guard-delivery.sh < <ввод с командой без раздела>`
  — отказ называет раздел.

### 3. Сценарии и тексты

- **Что делается:** сценарии на три случая, спека гарда поставки и паттерн закрытия работы —
  требование переезжает в шаг открытия заявки.
- **Признак готовности:** ни один текст не ставит требование раздела после открытия.
- **Чем проверяется:** `node tools/check-specs.mjs` — сверка спеков зелёная.

### 4. Пакет собран, разложен, сверен

- **Что делается:** сборка пакета, раскладка, сверка.
- **Признак готовности:** разложенное сходится с пакетом.
- **Чем проверяется:** `npm run agent-kit:check` — строка о том, что разложенное сходится.

## Чего эта работа не делает

- Не судит правку тела уже открытой заявки: раздел там переписывается тем же вызовом, а промах
  дешевле — заявку владелец уже видел.
- Не заводит проверки тела в сверке очереди работ: гард ловит промах в минуту открытия, то есть
  раньше и там, где он ещё исправим одним вызовом.
- Не трогает требование разбора папки задачи: оно уже стоит на открытии заявки и держится.

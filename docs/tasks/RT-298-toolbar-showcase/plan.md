# Замысел

**Задача:** RT-298 · **Ветка:** RT-298-toolbar-showcase
**Спек:** тело карточки — оно перечисляет виды показа поимённо
**Поведение:** не меняется — заводится показ и замер того, что уже есть

## Что считается сделанным

- У панели есть истории на все виды из карточки: три слота, один левый, один правый, пустая
  панель, закрепление включено и выключено, узкий экран.
- Раскладка слотов подтверждена замером, а не взглядом.
- Витрина собирается, спека кита зелёная.

## Этапы

### 1. Обёртка и истории

- **Что делается:** заводится `TestToolbarComponent` с ручками под содержимое каждого слота и
  признак закрепления, рядом — файл историй на перечисленные виды.
- **Признак готовности:** каждый вид из карточки показан своей историей.
- **Чем проверяется:** `pnpm run build-storybook` — собирается.

### 2. Замер раскладки

- **Что делается:** спека компонента читает вычисленные значения краёв трёх слотов и проверяет,
  что середина не съезжает, когда подан один слот.
- **Признак готовности:** замер повторяется прогоном, а не заходом в браузер.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit` — зелено.

## Чего эта работа не делает

- Не заводит эталонных снимков: набора снимков у первого кита нет вовсе, и заводить его —
  своя работа.
- Не трогает саму панель: показ заводится для того, что есть.

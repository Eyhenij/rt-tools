# Разбор просьбы

Четыре записи груза из приёма, соседние деревья, ресурс `hooks/task-flow-guard.sh`. Отметить их
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Гард навязывает способ записи договорённости

Гард требует в замысле строку «Драфт» и каталог «предложено» в спеке — то есть вместе с
проверкой «работа идёт по замыслу» навязывает способ записи договорённостей. Дереву, которое
пишет договорённость прямо в спек домена, он останавливал бы каждую правку кода, поэтому не
берётся вовсе — и вместе с ним не берётся единственная машинная проверка того, что у работы есть
папка задачи.

Две записи из четырёх говорят об одном: одна просит разделить гарда надвое, вторая — принимать
договорённость в двух видах.

## Что в работу не берётся

Запись о новом гарде начала работы — просьба завести ещё один гард, судящий, кто заказал правку:
это новое требование, а не починка этого. Запись о команде заведения задачи уходит своей задачей
— она о разборе команды оболочки, а не о договорённости.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

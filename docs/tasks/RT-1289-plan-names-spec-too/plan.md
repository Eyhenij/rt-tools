# Замысел

**Поведение:** не меняется — гард отбивает то же и теми же словами там, где договорённость
названа прежней строкой; прибавляется второй вид записи.

## Что делается

1. Гард принимает договорённость в двух видах: прежняя строка называет отдельный документ,
   новая — спек домена, в который договорённость пишется прямо.
2. Отказ называет оба вида: дерево без каталога «предложено» иначе читает его как требование
   завести каталог.
3. Сценарии при гарде: вид со спеком проходит, отсутствие обеих строк отбивается.

## Чем проверяется

`bash projects/agent-kit/tests/task-flow-guard.test.sh`, `npm run agent-kit:sync`,
`npm run agent-kit:check`, `npm run check:specs`.

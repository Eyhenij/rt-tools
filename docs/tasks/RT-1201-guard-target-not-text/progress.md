# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 4 — стрелка перестаёт быть перенаправлением

## Решения по ходу

- **Чинится признак записи, а не разбор путей.** Тело документа из путей уже выведено прежними
  правками; осталась причина, по которой читающая команда вообще попадает под суд.

## Записи заходов

### 26 августа 2026 — заход первый

Взята задача 3 эпика. Причина найдена прогоном признака записи: стрелка `->` в форматной строке
читается как перенаправление. Отбитый этим заходом вызов — прогон карты гейта, печатавший
таблицу «путь -> правило», — попал ровно сюда.

Ложных срабатываний найдено пять: стрелка, толстая стрелка, закрывающая скобка комментария
разметки, чтение со стрелкой в тексте, цитата разметки. Слияние потоков и подстановка процесса
признак уже не путает.

## What the tree already has

- `rt-field` второго кита умеет держать строку под ошибку: флаг `reserveHintSpace`. Тема его не
  включает ни на одном поле.
- Тема берёт тексты Keycloak через `msgStr` и выводит их как текст. В текстах Keycloak кавычки
  записаны HTML-кодом (`&laquo;`, `&raquo;`), поэтому код виден буквально.
- Выбор языка в шапке карточки — ряд текстовых кнопок, по одной на язык
  (`rt-kc-root.component.html`).

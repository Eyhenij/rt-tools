# Замысел

**Поведение:** не меняется — сверка судит то же и теми же строками; убавляется один ложный отказ.

## Что делается

1. Сверка читает у файла конвейера список путей, которых он не слушает: имя файла уже стоит в
   настройке проверок и читается ради сверки набора гейта.
2. Прогон не требуется у заявки, каждый файл которой лежит под одним из этих путей: события у
   неё не бывает, и совет вернуть его не исполним.
3. Список пуст или состав заявки не прочитать — строка прежняя: молчать наугад дороже.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run check:board`, `npm run agent-kit:sync`,
`npm run agent-kit:check`.

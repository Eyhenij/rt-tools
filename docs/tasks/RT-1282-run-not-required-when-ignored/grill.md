# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `checks/check-board.github.mjs`. Отметить
её этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт
здесь.

## Прогон требуется у ветки, у которой его не бывает

Ветка, правящая только тексты, разметку, обвязку разработки и инструменты, прогона не создаёт:
все четыре рода путей стоят у конвейера в списке игнорируемых. Сверка требует прогон и у неё,
называет расхождением и советует вернуть событие новым коммитом либо перезакрытием PR — ни то ни
другое не помогает, потому что события не будет никогда. За два дня так покраснели два PR
подряд, и оба раза красная строка означала «сверка не знает», а не «конвейер отказал».

Пока такой ветки не отличить, красная строка учит пропускать сверку целиком: она стоит рядом с
настоящими расхождениями и выглядит так же.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

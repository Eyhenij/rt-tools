## Что считается сделанным

- У каждого из шестидесяти шести семейств, чьи стили читают переписываемые набором имена, есть
  история с показом двух наборов рядом.
- Восемь семейств, которые этих имён не читают, названы с причиной — в описании набора, а не
  молчанием.
- Эталон каждой новой истории снят по одному и просмотрен глазами до съёмки.
- Полный прогон снимков второго кита зелёный, и число эталонов выросло ровно на число новых
  историй.
- Ни один прежний эталон не пересъёмлен: страница без признака набора осталась прежней.

## Этапы

### 1. Список семейств посчитан командой, а не глазами

- **Что делается:** замер, какие семейства читают переписываемые набором имена, ложится в дерево
  проверкой, а не остаётся в переписке.
- **Признак готовности:** проверка печатает три числа — всего семейств, с показом двух наборов,
  без показа с причиной — и отказывает, когда семейство без показа не названо причиной.
- **Чем показано:** `node tools/check-preset-stories.mjs` — вывод называет числа и не имеет
  неназванных семейств.

### 2. Показ двух наборов заведён семействам, где он что-то показывает

- **Что делается:** история с готовым показом добавляется семействам из первого списка. Идёт
  порциями, чтобы прогон снимков не рос одним куском.
- **Признак готовности:** проверка первого этапа зелёная, неназванных семейств не осталось.
- **Чем показано:** `node tools/check-preset-stories.mjs`, затем сборка витрины
  `pnpm run build-storybook:ui-kit-v2` — она единственная читает `.storybook`.

### 3. Эталоны сняты по одному и просмотрены

- **Что делается:** для каждой новой истории снимается эталон; перед съёмкой на кадр смотрят.
- **Признак готовности:** число эталонов выросло ровно на число новых историй, прежние не
  тронуты.
- **Чем показано:** `pnpm run test:stories:v2` — зелено; `git status` по каталогу эталонов
  показывает только добавленные файлы, ни одного изменённого.

### 4. Восемь семейств без показа названы с причиной

- **Что делается:** причина пишется туда, где её прочитают, — в описание набора оформления, а не
  в комментарий кода.
- **Признак готовности:** проверка первого этапа читает причину оттуда же и молчит.
- **Чем показано:** `node tools/check-preset-stories.mjs` и `node tools/check-doc-paths.mjs`.

## Чего работа не делает

- Тёмной половины нового набора не показывает — прямо исключено карточкой.
- Третьего набора не показывает — исключено там же.
- Семейств первого кита не трогает: он читается образцом и не правится.

## Решения по ходу

- **Холодная часть заводится своим родом ресурса, а не именем внутри рода правил.** Родом
  управляются отказ списком и каталог раскладки; имя внутри рода правил не даёт ни того ни
  другого. Разведка по коду раскладки: род ресурса объявлен перечнем, целевой путь собирается
  одной функцией — у скилов она кладёт `<имя>/SKILL.md`, значит холодной части нужна своя
  ветка на `<имя>/pitfalls.md`. Каскад отказа берётся с паттернов при законе: отказано правило —
  холодная часть при нём не кладётся. Затронутый этап замысла: 1.

- **Холодная часть раскладывается как обычный ресурс, а не как черновик спутника.** Её текст
  принадлежит пакету целиком — это ловушки и поведение по разборам, — значит она
  перекладывается на каждой раскладке и сверяется наравне с правилом.

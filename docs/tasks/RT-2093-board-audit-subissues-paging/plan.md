## Этапы

### 1. Сценарий, который краснеет на прежнем вызове

- **Что делается:** помощник хостинга в наборе сценариев учится отвечать по-разному на вызов с
  пролистыванием и без него, и новый сценарий требует, чтобы проверка прочла весь список.
- **Признак готовности:** сценарий падает на нынешнем коде и называет ту самую строку.
- **Проверяется:** `bash projects/agent-kit/tests/checks-board.test.sh` — сейчас «79 ok, 0
  провалов»; на этом шаге станет 81 испытание и хотя бы один провал.

### 2. Правка источника и укладка

- **Что делается:** вызову списка подзадач добавляется пролистывание. Правится источник пакета,
  не копия в дереве; после правки дерево получает файл заново.
- **Признак готовности:** набор сценариев зелёный целиком, а положенный файл совпадает с
  источником.
- **Проверяется:** `bash projects/agent-kit/tests/checks-board.test.sh` — 81 испытание, ноль
  провалов; `npx agent-kit sync --check` — расхождений нет.

### 3. Описание области и правило

- **Что делается:** в описание области добавляется статья про чтение целого списка с привязкой к
  коду и сценарием; правило `task-flow` говорит то же одной строкой.
- **Признак готовности:** описание не называет статью без привязки и сценарий без теста.
- **Проверяется:** `node tools/check-specs.mjs` — сейчас «domains 6, scenarios 1559 — covered
  1411, partial 12, without tests 136», расхождений нет; после работы сценариев на один больше и
  без тестов не больше прежнего.

### 4. Проверка на живой очереди работ

- **Что делается:** проверка запускается на этом дереве, где у эпика тридцать шесть задач.
- **Признак готовности:** строки про непривязанные задачи эпика #1870 нет.
- **Проверяется:** `node tools/check-board.mjs` — сейчас строка «#1870: the plan names tasks that

  её нет.

## Чего эта работа не делает

- **Другие вызовы хостинга не пересматриваются.** Пролистывание добавляется тому вызову, на
  котором поломка измерена; сплошной пересмотр — работа своего объёма.
- **Имена столбцов доски не правятся.** В главной ветке они устарели, и это чинит правка #2088
  соседней работы.
- **Остальные строки проверки не трогаются.** Задачи без эпика и эпики без ветки — чужой предмет.

- **Что делается:** из тела карточки берутся все пути на документы, а не первый; замыслом
  считается первый из лежащих на диске, у которого читается таблица состава. Разводятся две строки
  отказа: ни одного документа на диске и ни одной таблицы состава среди лежащих.
- **Признак готовности:** новые пробы зелёные — карточка с решением перед замыслом состав читает,
  карточка без единого документа на диске даёт прежнюю строку.

# Ход работы

## Где стоим

Все шесть этапов замысла закрыты. Обвязка снимков второй витрины работает: набор задан
вычитанием, кадр берётся по корню показа, кадры порогов читаются из параметров истории, отказ
проверен опытом в четырёх местах. Эталоны сняты у группы замера — `rt-tag`, `rt-menu`,
`rt-menu-item`, 14 кадров. `Q-1` закрыт замером, `Q-2` замерен и ждёт границы от владельца.

Следующее — задача эталонов на всю витрину: разовая пометка `Playground` по всем папкам, съёмка
полного набора, шаг прогона в CI. Здесь она не делается намеренно — замысел этой задачи её не
включает.

## Решения по ходу

- **Порядок работ развёрнут владельцем во втором заходе разбора: обвязка и эталоны идут первыми,
  волны 4–5 после них** — довод аналитика перевесил первый ответ. Волны 4–5 по замеру дерева это
  около 84–90 файлов историй и 30 страниц обзоров, примерно два объёма всей сделанной работы по
  линии покрытия, и всё это время 44 матрицы волн 1–3 не защищены ничем; при старом порядке порог
  расхождения и время прогона выяснялись бы в самом конце. Затронутый этап замысла: весь замысел —
  он написан уже по развёрнутому порядку.

- **Задача заведена одна, а не шесть** — остальные работы линии (волны 4 и 5, эталоны на всю
  витрину, доступность, долг по спекам) названы разделом «Чего эта работа не делает» и живут в
  `docs/plans/ui-kit-v2-state-coverage.md`. Задача, заведённая под работу, которую начнут через
  месяц, висит в очереди мусором. Затронутый этап замысла: —

- **Аддон состояний отключается на время прогона признаком `RT_SNAPSHOT_RUN`, а не выносится из
  витрины** — `storybook-addon-pseudo-states` в Node не грузится вовсе (`Element is not defined`),
  а настройку витрины прогон читает именно в Node. Второй копии настройки заводить не стали:
  копия разъезжается с оригиналом молча, а признак виден в одном месте и объяснён там же.
  Затронутый этап замысла: 4.

- **Точечная пересъёмка отбирает файлы историй по пути, а не истории по имени** — отбор по имени
  (`-t`) ломает окружение прогона: страница не создаётся, и все 124 файла падают. Проверено флаг
  за флагом на обеих витринах. Договорённость поправлена под то, что работает. Затронутый этап
  замысла: 4.

- **Панельным историям кадр берётся целой страницей** — панель живёт в контейнере перекрытий CDK,
  за пределами корня показа, и кадром по сетке её не снять вовсе. Затронутый этап замысла: 4.

- **Эталоны сняты не только у одной группы, а у трёх компонентов** (`rt-tag`, `rt-menu`,
  `rt-menu-item`): меню понадобилось, чтобы доказать открытую панель в безголовом браузере —
  ради чего переписывалось успокоение кадра. Затронутый этап замысла: 5.

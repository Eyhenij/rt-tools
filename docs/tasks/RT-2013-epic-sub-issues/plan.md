## Что считается сделанным

- Задача, заведённая с `--epic-of <номер>`, становится подзадачей эпика в GitHub.
- У всех открытых эпиков задачи привязаны подзадачами.
- Аудит доски называет задачу эпика, которая подзадачей не привязана.

## Шаги

### 1. Привязка при заведении задачи

- **Что делается:** `task-new.mjs` после создания задачи с `--epic-of` зовёт GitHub и привязывает её подзадачей
- **Признак готовности:** у эпика в `sub_issues_summary` вырос `total`
- **Проверено:** `node tools/board-epics.mjs` — код возврата 0

### 2. Привязка задним числом

- **Что делается:** задачи семи открытых эпиков привязаны подзадачами
- **Признак готовности:** у каждого открытого эпика `sub_issues_summary.total` равен числу его задач
- **Проверено:** `node tools/check-board.mjs` — код возврата 0

### 3. Аудит доски видит непривязанную задачу

- **Что делается:** в аудит доски добавлена проверка привязки
- **Признак готовности:** задача эпика без привязки называется отдельной строкой
- **Проверено:** `bash projects/agent-kit/tests/checks-board.test.sh` — 0 провалов

## What counts as done

- Списочные экраны, их панели, столбцы таблиц и заголовки разделов берут подписи из словаря на
  каждой отрисовке, а не один раз при загрузке файла.
- Вызовов старого способа — того, что отдаёт текст постоянной, — в админке не остаётся.
- Экран раздела меняет язык вместе с оболочкой, без перезагрузки страницы.

## Stages

### 1. Подпись столбца становится ключом

- **What is done:** объявления столбцов держат ключ, а не готовый текст; текст по ключу берёт
  экран — там же, где он берёт остальные свои подписи.
- **Readiness sign:** ни одно объявление столбцов не зовёт словарь при загрузке файла, и таблица
  каждого раздела показывает те же подписи, что и прежде.
- **Verified by:** `pnpm exec nx run-many -t test -p message-bus-admin-postmortems-util message-bus-admin-proposals-util message-bus-admin-summaries-util message-bus-admin-usage-util message-bus-admin-invites-util message-bus-admin-accounts-util` — 0 провалов.

### 2. Основа списочного экрана спрашивает словарь

- **What is done:** общая основа списочного экрана, панели подробностей и общий слой вида берут
  подписи производными от выбора языка.
- **Readiness sign:** вызовов старого способа в общем слое не остаётся.
- **Verified by:** `grep -rn "adminLabel(" --include='*.ts' libs/message-bus-admin/common | grep -v spec | wc -l` — 0.

### 3. Разделы по одному

- **What is done:** списки, панели и заголовки маршрутов шести разделов переведены на словарь.
- **Readiness sign:** вызовов старого способа в админке не остаётся вовсе.
- **Verified by:** `grep -rn "adminLabel(" --include='*.ts' libs/message-bus-admin | grep -v spec | wc -l` — 0.

### 4. Сквозной набор и экран раздела на двух языках

- **What is done:** сквозной тест открывает раздел и убеждается, что подписи экрана идут за
  выбором языка.
- **Readiness sign:** набор зелёный, тест падает, если подпись вернуть постоянной.
- **Verified by:** `pnpm exec nx run message-bus-admin-e2e:e2e` — 0 провалов.

## What this work does not do

- Не заполняет английский набор целиком: экран раздела на английском выборе покажет признаки
  ненайденных ключей там, где перевода ещё нет. Набор заполняет RT-2213.
- Не трогает тексты отказов сервера: это RT-2212.
- Не ставит проверку, запрещающую строку мимо словаря: это RT-2214.

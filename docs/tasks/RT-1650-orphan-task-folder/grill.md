## Что уже сказано в правилах

Паттерн `task-flow-archive` говорит всё нужное и вопросов владельцу не оставляет:

- `grill.md` уезжает в описание прошлого — слова владельца невосстановимы;
- `progress.md` уезжает туда же, если в нём есть решения по ходу с причинами;
- `plan.md` удаляется — после выкатки на его вопрос отвечает код;
- уезжающее складывается одним файлом с говорящим именем, а не папкой из трёх;
- работа, разбирающая чужую папку, разбирает две: сперва чужую, потом свою.

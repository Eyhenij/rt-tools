## Что считается сделанным

- Цена входа посчитана командой до работы и после неё, обе цифры названы.
- Снятая запись словаря либо не встречается в слое правил вовсе, либо заменена простым словом, и
  это показано поиском, а не памятью.
- Ни одно слово, оставшееся в текстах пакета, из словаря не пропало: обратная сверка идёт по
  корпусу, а не по чтению.
- Карта хода обрезана до того, что заход исполняет; проверка над ней остаётся зелёной.

## Этапы

### 1. Замер: что из словаря живёт, а что нет

- **Что делается:** разовый счёт по корпусу слоя правил — сколько раз встречается каждая запись.
- **Признак готовности:** список записей с числом употреблений и вес каждой в знаках.
- **Чем проверяется:** `pnpm exec nx run @rt-tools/agent-kit:cost` — цена входа до работы.

### 2. Словарь обрезан

- **Что делается:** снимаются записи, которых нет в корпусе; остальные ужимаются по форме сжатой
  статьи — утверждение остаётся, довод уходит.
- **Признак готовности:** словарь легче, ни одна снятая запись в корпусе не встречается.
- **Чем проверяется:** `node tools/check-doc-paths.mjs` — путей-призраков нет.

### 3. Карта хода обрезана

- **Что делается:** из карты уходит то, что повторяет правила и не исполняется на входе.
- **Признак готовности:** проверка карты хода зелёная, вход легче.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit` — набор пакета зелёный.

### 4. Число выигрыша названо

- **Что делается:** цена входа считается снова и обе цифры уезжают в тело заявки и в замысел эпика.
- **Признак готовности:** разница названа числом, а не словом.
- **Чем проверяется:** `pnpm exec nx run @rt-tools/agent-kit:cost` — цена входа после работы.

## Чего эта работа не делает

- Не трогает описания скилов — они обрезаны задачей 2 эпика.
- Не заводит проверки на длину словаря: предел длины пересчитывается задачей 10.

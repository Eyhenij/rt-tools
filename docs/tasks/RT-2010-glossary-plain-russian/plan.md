- **Что делается:** правый столбец словаря переписан обычными русскими словами

- **Проверено:** `grep -c 'спек\|заход\|прогон\|замысел\|гард' projects/agent-kit/assets/docs/GLOSSARY.md` — 0

### 2. Список запрещённых слов

- **Что делается:** старые слова добавлены в `prose.glossaryBans`
- **Признак готовности:** проверка слога отказывает на них
- **Проверено:** `node tools/check-prose-style.mjs` — код возврата 0 на дереве

### 3. Установка из пакета

- **Что делается:** пакет пересобран, файлы установлены заново
- **Признак готовности:** установленная копия совпадает с исходником

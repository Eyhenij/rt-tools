Работа начата с груза. Ключ записи полностью:
`fe80c61f139244bff4fe9fe348742b020dcdca3c00d52a3bb932c53ab4750535` — предложение стороннего
дерева, в приёмнике `556ab517-f778-4fd8-b51c-28d46eefe5c6`.

## Просьба владельца

> **место:** строка `# rt-hook: PreToolUse Edit|Write|MultiEdit|…` в шапке каждого из трёх
>
> **повод:** заход в авто-режиме получает указание править файлы через `sed`, `python3` и
> heredoc. Ни один из трёх гардов такой правки не видит. Проба на дереве-потребителе: тот же
> ввод с именем `Edit` даёт отказ, с именем `Bash` даёт тишину. Так в дерево уехал шаблон формы
> со своим словарём стилей вместо общего. Промах нашёл владелец глазами через две недели.
>
> **ближайшее:** шапка `docs-guard.sh` — приём в пакете уже есть, и три гарда правки его не взяли
>
> Гард правки судит и правку командой оболочки. Имя файла берётся из текста команды тем же
> разбором, каким его берёт гард пары «правка и её документ».

## Что в дереве уже есть

- `projects/agent-kit/assets/hooks/qa-dataid-guard.sh`, `prose-style-guard.sh`,
  `handoff-entry-guard.sh` — в объявлении событий у всех трёх только имена инструментов правки.
- `projects/agent-kit/assets/hooks/docs-guard.sh` — в объявлении есть и оболочка, но тело
  разбирает её только ради `git commit`: путей записи оттуда он не берёт.
- Замер этого захода: правка `.prettierignore` командой `python3` с heredoc была отбита гардом
  места правки, потому что в теле команды стояло имя разложенного файла. То есть приём разбора
  путей из текста команды в дереве уже работает — у гарда места правки.

## Что уже говорят правила

- `agent-kit`, раздел ловушек: «правка файла командой оболочки проверяется по всем путям,
  названным в её теле» — приём объявлен и описан, но взят не всеми гардами.
- `agent-kit-extend`: объявление событий стоит в шапке разложенного файла, надстройкой оно не
  правится — значит правка идёт в пакет.

## Решения

- **Разбор путей объявляется один раз общим помощником, а не тремя разборами в трёх гардах** —
  три разбора разойдутся молча, и это уже случилось с признаком дерева при отправке груза.
- **Судится запись, а не всякое упоминание пути** — перенаправление, `sed -i`, `tee` и heredoc.
  Чтение файла командой правкой не считается, иначе каждый `grep` будил бы три гарда.

## Что осталось неясным

- Ближайшая строка в предложении названа шапкой `docs-guard.sh`, а приём разбора путей живёт не
  там, а у гарда места правки. На существо это не влияет: приём в пакете есть, и вопрос в том,
  какие гарды его берут.

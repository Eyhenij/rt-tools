## What counts as done

- Правка файла командой оболочки судится теми же тремя гардами, что и правка инструментом правки:
  запись через перенаправление, `sed -i`, `tee` и heredoc.
- Путь берётся из текста команды одним общим приёмом, а не тремя разными разборами.
- Команда, которая файлов не пишет, гарды не будит: молчание остаётся молчанием.

## Stages

### 1. Приём разбора пути объявляется один раз

- **What is done:** общий помощник берёт из текста команды пути, в которые команда пишет; проба
  набора закрывает перенаправление, `sed -i`, `tee` и heredoc.
- **Readiness sign:** помощник называет путь на всех четырёх формах записи и молчит на чтении.
- **Verified by:** `bash projects/agent-kit/tests/shell-write-paths.test.sh` — строка «0 провалов».

### 2. Три гарда правки берут этот приём

- **What is done:** объявление событий каждого из трёх дополняется оболочкой, тело зовёт общий
  помощник; пробы наборов этих гардов закрывают правку командой.
- **Readiness sign:** тот же ввод с именем оболочки даёт тот же отказ, что с именем правки.
- **Verified by:** `bash projects/agent-kit/tests/run.sh` — строка «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ».

## What this work does not do

- Не трогает гард пары «правка и её документ»: он судит коммит, а не запись файла.
- Не расширяет на оболочку гарды, которые о правке файлов вообще не говорят.

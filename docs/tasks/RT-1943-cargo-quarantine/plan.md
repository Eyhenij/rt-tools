## What counts as done

- Карантин — состояние записи в приёмнике, а не папка на диске: запись переходит в него из
  «нового» и возвращается из него в «новое» по слову человека.
- Переход в карантин без причины отбивается: у каждой записи в карантине стоит, чем она спорна.
- Из карантина запись не уходит вперёд: «починено» и «выпущено» из него не ставятся.
- Список карантина читается командой чтения груза отбором по состоянию.
- Слово состояния показано человеку по-русски, и по нему отбирается список в админке.

## Stages

- **What is done:** заводится поддомен `cargo-quarantine` — спека, сценарии и спутник; сценарии
  берут свободные номера от `SC-MB-308`.
- **Readiness sign:** спека называет, откуда и куда ходит запись, что несёт переход и что видит
  человек.
- **Verified by:** `node tools/spec-next-id.mjs MB` — свободный номер вырос ровно на число
  заведённых сценариев.

### 2. Состояние в наборах и в хранилище

- **What is done:** состояние добавляется в набор общего основания, в перечисление хранилища и в
  набор пакета; пишется миграция; порядок переходов пускает «новое» в карантин и обратно.
- **Readiness sign:** сверка схемы с миграциями зелёная; шаг из карантина вперёд отбивается
  решением о переходе.
- **Verified by:** `npm run check:schema` — код ноль; `pnpm exec nx test @rt/message-bus-common`
  — пробы порядка переходов зелёные.

### 3. Причина карантина

- **What is done:** у записи заводится колонка причины; правка состояния принимает её только с
  переходом в карантин и отбивает переход без неё.
- **Readiness sign:** переход в карантин без причины отбивается строкой с названной причиной
  отказа; причина, приехавшая с другим переходом, тоже отбивается.
- **Verified by:** `pnpm exec nx test @rt/message-bus-api-cargo-state-feature` — пробы отказов
  зелёные.

### 4. Показ и чтение

- **What is done:** слово состояния по-русски, отбор по нему в админке, чтение списка карантина
  командой чтения груза.
- **Readiness sign:** список карантина читается одной командой, и у каждой записи в выводе стоит
  причина.
- **Verified by:** `pnpm exec nx test @rt/message-bus-admin-common-core-util` — пробы слова и
  отбора зелёные.

### 5. Привязки и статья правила

- **What is done:** спутник поддомена заполняется привязками; в правило `cargo-triage` встаёт
  статья о карантине как о месте спорных предложений.
- **Readiness sign:** проверка спек не называет ни одной статьи без привязки и ни одного сценария
  без пробы.
- **Verified by:** `npm run check:specs` — код ноль.

## What this work does not do

- Не судит, какое предложение спорно: это делает разбор по правилу предыдущей задачи эпика.
- Не заводит экрана карантина: запись видна в общем списке отбором по состоянию.
- Не достаёт записи из карантина сама: оттуда их возвращает человек своим словом.

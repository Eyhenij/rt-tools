## What counts as done

- Ни один адрес витрины, названный на странице обзора, не ведёт в никуда.
- Ссылка на семейство, которого во втором ките нет, снята, а само семейство названо словами.
- Проверка читает адреса из обзоров, сверяет их с перечнем страниц витрины и отказывает на

## Stages

### 1. Проверка адресов витрины лежит в дереве

- **What is done:** проверка собирает адреса из `*.mdx` и сверяет их с заголовками страниц,
  выведенными из `<Meta title>`, — без поднятой витрины.
- **Readiness sign:** проверка печатает число адресов и число мёртвых и отказывает на мёртвом.
- **Verified by:** `node tools/check-showcase-links.mjs` — на непочиненном дереве отказ со списком.

### 2. Адреса переведены на настоящие

- **What is done:** сто два адреса переписаны по перечню страниц; ссылки на непереехавшие
  семейства сняты, а семейства названы словами.
- **Readiness sign:** проверка первого этапа зелёная.
- **Verified by:** `node tools/check-showcase-links.mjs` — мёртвых ноль.

### 3. Переход проверен на поднятой витрине

- **What is done:** страница обзора значка открывается, и её ссылки ведут на существующие адреса.
- **Readiness sign:** каждый адрес со страницы стоит в перечне страниц витрины.
- **Verified by:** замер по `index.json` поднятой витрины — все адреса страницы найдены.

### 4. Проверка встала в конвейер и в гейт

- **What is done:** шаг заведён в `.github/workflows/ci.yml`, в `.claude/rt-kit/checks.json` и в
  наборе гейта пуша.
- **Readiness sign:** гейт пуша не уже конвейерного.
- **Verified by:** `node tools/check-push-gate.mjs` — расхождений нет.

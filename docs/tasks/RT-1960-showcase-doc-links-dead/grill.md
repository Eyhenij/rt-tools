# Grill

## The owner request

> Overview на иконках сломан может и на других сторях

## What the tree already has

- Страницы обзора — `projects/ui-kit-v2/src/lib/components/*/Overview.mdx`, семьдесят три файла.
  Обзора нет у двух семейств: `form-control` и `ripple`.
- Заголовок страницы объявляется `<Meta title="…" />`, и адрес витрины выводится из него: заголовок
  `Atoms/Icon/Overview` даёт адрес `atoms-icon-overview--docs`.
- Разделы витрины разложены по уровням атомарного проектирования — `Atoms`, `Molecules`,
  `Organisms`, `Templates`, — а ссылки написаны под прежний общий раздел `Components`.
- Проверка адресов в документах — `tools/check-doc-paths.mjs` — читает пути к файлам дерева и об
  адресах витрины не знает ничего.

## What the rules already say

Правило `doc-style`: путь, названный в документе, существует, иначе ссылка на переехавший файл
читается как действующее указание. Про адреса витрины там не сказано ничего — это адреса не файлов
дерева, и проверка их не видит.

## Questions and answers

Владельцу не задано ни одного: он назвал сломанное место, а размер поломки читается замером.

## Decisions

- **Замер снят по поднятой витрине, а не выведён из заголовков.** Перечень страниц взят из
  `index.json` витрины: страниц документации 79, различных адресов в обзорах 102, живых ноль.
  Страница обзора значка при этом рисуется целиком — 3206 знаков текста, ноль ошибок страницы:
  сломаны переходы, а не показ.
- **Заводится проверка, а не только правка адресов.** Разделы витрины уже переезжали однажды, и
  ссылки оборвались молча: без проверки следующее переименование оборвёт их так же.

## What is left unclear

- Куда вести ссылкам на семейства, которых во втором ките ещё нет, — `action-bar` и `info-badge`.
  Работа идёт с допущением, что такая ссылка снимается, а само семейство называется словами:
  обещать страницу, которой нет, хуже, чем её не обещать.

## What counts as done

- Экран входа и экран первой записи берут все свои подписи из словаря по ключу.
- Тексты отказов входа и заголовки вкладки домена входа идут теми же ключами.
- На английском выборе оба экрана не содержат русских слов — измерено на стенде.
- Экраны разделов не тронуты: их переводит RT-2211.

## Stages

### 1. Ключи входа в обоих наборах

- **What is done:** подписи полей, подсказки внутри полей, подпись кнопки и тексты отказов входа
  заведены ключами в русском наборе и переведены в английском.
- **Readiness sign:** оба набора отвечают на каждый новый ключ, и ни один не приходит признаком
  ненайденного.
- **Verified by:** `pnpm exec nx test message-bus-admin-common-core-util` — 0 провалов.

### 2. Экраны входа берут подписи из словаря

- **What is done:** форма входа, экран первой записи и заголовки вкладки домена входа спрашивают
  словарь на каждой отрисовке, а не берут текст один раз.
- **Readiness sign:** в шаблонах домена входа не осталось русского текста вне комментариев, и
  вызовов `adminLabel` там тоже не осталось.
- **Verified by:** `grep -rn "adminLabel(" --include='*.ts' libs/message-bus-admin/auth | grep -v spec | wc -l` — ноль.

### 3. Тест на обоих языках

- **What is done:** сквозной тест открывает вход на английском выборе и убеждается, что русских
  слов на нём нет.
- **Readiness sign:** тест зелёный, и он падает, если подпись вернуть строкой в разметку.
- **Verified by:** `pnpm exec nx run message-bus-admin-e2e:e2e` — 0 провалов.

## What this work does not do

- Не переводит экраны разделов, их списки и панели: это RT-2211.
- Не трогает тексты отказов сервера: сервер начнёт отвечать кодом в RT-2212.
- Не заполняет английский набор целиком: это RT-2213.

## Что считается сделанным

- Нажатие на кнопку — обычную и значковую — пускает волну от точки касания; отключённая и
  загружающаяся кнопка волны не даёт.
- Волна работает без `@angular/material`: во втором ките его не появляется ни одного импорта.
- Цвет и длительность волны задаются своим свойством компонента, а не числом на месте.
- У кнопки есть подъём тенью, и он приходит из материального набора; без признака набора вид
  не меняется — эталонные снимки второго кита не расходятся.
- У кнопки-значка есть своё свойство тени, а не только кольцо фокуса.
- Матрица состояний обеих кнопок показана историей витрины в обоих наборах.

## Этапы

### 1. Волна нажатия своей директивой

- **Что делается:** во втором ките заводится директива волны: слушает нажатие, ставит слой волны в
  своём блоке, гасит его по окончании, молчит при отключённости и загрузке. Цвет, длительность и
  предельный радиус — свои свойства компонента.
- **Признак готовности:** проба поднимает кнопку, шлёт нажатие и видит появившийся и убранный узел
  волны; отключённая кнопка узла не даёт.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=src/lib/components/ripple/rt-ripple.directive.spec.ts` — пробы зелёные.

### 2. Волна на кнопке и на кнопке-значке

- **Что делается:** директива ставится на обе кнопки; цвет волны берётся из цвета подписи кнопки,
  чтобы светлая волна не пропадала на светлой заливке.
- **Признак готовности:** обе кнопки дают волну, отключённые — нет; стили компонентов остаются в
  своём слое каскада.
- **Чем проверяется:** `pnpm run check:cascade-layer` — пустой перечень мест.

### 3. Подъём тенью у кнопки и кнопки-значка

- **Что делается:** `--rt-btn-shadow` перестаёт быть постоянным `none`: заводится назначение тени
  подъёма, у кнопки-значка появляется своё свойство тени и переход по нему. Значение по умолчанию
  оставляет вид без признака набора неизменным.
- **Признак готовности:** в материальном наборе кнопка приподнята и тень растёт под курсором;
  без признака набора вид тот же, что до работы.
- **Чем проверяется:** `pnpm run check:tokens-build` — собранное сходится с источником.

### 4. Матрица состояний в витрине и снимки

- **Что делается:** истории обеих кнопок показывают матрицу в обоих наборах; снимки пересняты.
- **Признак готовности:** расхождения снимков либо нет, либо оно поимённо названо и объяснено.
- **Чем проверяется:** `pnpm run check:tokens-styles` — литералов в стилях компонентов не
  прибавилось.

## Чего эта работа не делает

- **Вырез рамки поля ввода и плотность** — вынесены отдельной работой: их цена выясняется только
  на разметке поля, и мешать их с волной значило бы держать волну в ветке до конца обеих.
- **Волну в остальных семействах** — таблица, пункт меню, вкладка: приём после этой задачи готов,
  и они идут по требованию.
- **Первый кит** — заморожен, читается образцом.

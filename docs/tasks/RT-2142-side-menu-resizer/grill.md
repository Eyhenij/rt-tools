# Grill

## The owner request

> делай по порядку

Сказано 17 сентября 2026 года в ответ на порядок работ, где эта задача стояла первой, а рядом
стоял прямой вопрос: «Чинить ли RT-2142 (правка замороженного первого кита)». Так снят запрет
эпика «Один кит» на правку первого кита — для этой работы.

## What the tree already has

- Ручка — `projects/ui-kit/src/lib/ui-kit/side-menu/menu/rtui-side-menu.component.html:236`,
  блок `rtui-side-menu-resizer`, роль разделителя, слушатель `mousedown`.
- Тяга — `rtui-side-menu.component.ts:onResizeStart`: слушатели вешаются на документ, потому что
  рука уходит с узкой полоски в первое же движение.
- Пределы — `side-menu.logic.ts`: `SUB_MENU_WIDTH_MIN` 120, `SUB_MENU_WIDTH_MAX` 480,
  `clampSubMenuWidth`.
- Панель рисуется по большей из двух ширин — `rtui-side-menu.component.scss:275`:
  `max(var(--rt-side-menu-sub-menu-width), var(--rt-side-menu-sub-menu-dragged-width, 0px))`.
  Наружу же уходит своё число, урезанное нижним пределом.
- Проверок у компонента 39, все зелёные; у ручки есть свои утверждения в
  `stories/side-menu.resizer-asserts.ts`.

## What the rules already say

- `ui-component-tests`: решение проверяется вызовом, вид — кадром; состояние, невидимое в кадре,
  получает свою историю.
- `rt-tools-styling`: размер элемента управления выбирается по признаку указателя, а не по ширине
  экрана — `pointer: coarse` отвечает о способе нажатия.

## Questions and answers

Вопросов владельцу задача не открывает: пять находок измерены командой Avalon и описаны в теле
задачи, лечение названо там же.

## Decisions

- **Тяга переходит на указательные события с захватом указателя** — один источник вместо трёх
  (мышь, палец, перо), и захват держит тягу, когда указатель уходит на чужой кадр. Отвергнуто:
  добавить слушатели касания рядом с мышиными — три ветки об одном разошлись бы молча.

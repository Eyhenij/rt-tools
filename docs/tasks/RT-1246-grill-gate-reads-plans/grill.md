# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `hooks/grill-gate.sh`.

- **место:** образец каталогов чтения и текст отказа
- **повод:** гард отбил вопрос дважды; второй отказ снялся только поиском по трём каталогам,
  которые он называет, — а ответ лежал в каталоге замыслов, в его подсказке не названном.
- **готовый текст:** «Замысел эпика и описание прошлого читаются наравне с законами: решение,
  связывающее задачи эпика, лежит именно там, а не в правилах. Каталоги берутся из профиля
  дерева и оба входят и в образец чтения, и в текст отказа.»

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

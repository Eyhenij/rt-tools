## What counts as done

- Скрипт собирается одним файлом и ставится на чужую страницу одним тегом с ключом площадки.
- Скрипт ставит рамку со страницей переписок, отвечает на её просьбу подписью, взятой у сервера
  потребителя, и меняет подпись на новую, когда страница просит её снова.
- Страница-образец стенда показывает встроенный раздел переписок, и подпись ей выдаёт стенд.
- Сквозной набор открывает эту страницу на рабочей сборке и проверяет список, ответ и закрытие.
- Описание подобласти говорит, чем страница ставится, и правила установки получают адреса в коде.

## Stages

### 1. Скрипт установки

1. Завести `apps/chat-talks-embed`: сборка одним файлом, цели сборки, проверок и линта.
2. Написать чистую часть: разбор признаков тега, сборка адреса рамки, разбор просьбы о подписи.
3. Написать тег: рамка, слушатель просьбы, обращение к точке выдачи подписи, передача её в рамку.
4. Покрыть проверками разбор признаков, сборку адреса и ответ на просьбу.

Признак готовности: `pnpm exec nx build chat-talks-embed` даёт файл в `dist/apps/chat-talks-embed`,
`pnpm exec nx test chat-talks-embed` зелёный.

### 2. Образец потребителя на стенде

1. Точка выдачи подписи на стенде: подписывает ключ площадки и минуту тайной площадки засева.
2. Страница чужой админки со вставленным разделом переписок; раздача отдаёт её, скрипт и страницу.
3. Поднять стенд и посмотреть глазами: список, ответ, закрытие внутри рамки.

Признак готовности: `pnpm run serve:stand` поднимает страницу, раздел виден, отвечает и закрывает.

### 3. Сквозной набор

1. Сцены `SC-CH-92` и далее в описании подобласти: установка, выдача подписи, экран внутри рамки.
2. Спека сквозного набора на страницу потребителя: список, ответ, закрытие.
3. Снимок экрана встроенного раздела рядом с той же спекой.

Признак готовности: `pnpm exec nx run message-bus-admin-e2e:e2e` зелёный вместе с новой спекой.

### 4. Отдать работу

1. Описание подобласти и его файл привязок: правила установки получают адреса в коде.
2. Разобрать папку задачи последним коммитом, добавив запись в `docs/archive/`.
3. Набор перед отправкой, отправка, PR в ветку эпика, рецензент, номер владельцу.

Признак готовности: PR открыт, номер назван.

## What the work does not do

- Операций сервиса не добавляет: скрипт и страница зовут написанные задачей RT-2312.
- Учётных записей потребителя не заводит и прав у себя не хранит.
- Готового серверного кода потребителю не даёт: точка выдачи подписи на стенде — образец, а не
  библиотека.
- PR эпика в главную ветку не открывает: он идёт после того, как эта задача влита.

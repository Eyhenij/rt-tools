## Что считается сделанным

- `doctor` печатает итоговый набор перед пушем — команды по одной, как их вернула функция
  профиля.
- `doctor` называет снятое надстройкой: что дерево выкусило из умолчания.
- Гард пуша один раз за сессию называет, чего в его наборе нет против конвейера.

## Этапы

### 1. Строки набора в разборе состояния

- **Что делается:** `doctor` зовёт функцию профиля и печатает набор и снятое.
- **Признак готовности:** в выводе стоит раздел набора, а выкушенная проверка названа по имени.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit` — пробы зелёные.

### 2. Слово гарда о разнице с конвейером

- **Что делается:** умолчание печатает вслух, чего в наборе нет против конвейера, один раз.
- **Признак готовности:** строка приходит на первом пуше сессии и не повторяется.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-push-gate.test.sh` — все ok.

### 3. Спек, правило и раскладка

- **Что делается:** статьи в спек и правило, сценарий, привязки, раскладка.
- **Признак готовности:** сверка молчит.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом.

## Чего эта работа не делает

- Не выводит набор из файла конвейера: у каждого дерева он свой, и разбирать его нечем.

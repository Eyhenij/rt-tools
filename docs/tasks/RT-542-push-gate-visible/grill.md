# Разбор просьбы

## Просьба владельца

> бери остальные задачи одну за другой начиная с самой свежей, работай локально и не пуш ветки
> в репозиторий, работай полностью автономно … создавай новую ветку от предыдущей каскадом

Тело работы — карточка RT-542 «Набор проверок перед пушем собирается вслепую и снимается
незаметно». Повод у неё свой: три предложения и разбор происшествия, приехавшие грузом от
деревьев-потребителей.

## Что уже есть в дереве

- `projects/agent-kit/assets/defaults/project.sh` — умолчание набора `rt_push_checks_default` и
  строка `rt_push_checks() { rt_push_checks_default "$@"; }`, которую дерево переписывает.
- `projects/agent-kit/assets/hooks/git-guard-push-tests.sh` — гард, который набор гоняет.
- `projects/agent-kit/src/lib/commands.ts:doctor` — разбор состояния дерева; рядом уже стоят
  `profileLines` и `localValueLines`, читающие профиль текстом.
- `projects/agent-kit/src/lib/cost.ts:hookOutput` — готовый приём запуска: `execFileSync` с
  таймаутом и молчанием на отказе.

## Что уже сказано в правилах

Правило поставки требует, чтобы набор гейта не был уже набора конвейера. Требование есть,
собрать его нечем: итоговый набор не печатается нигде, и прочитать его можно, только позвав
функцию профиля руками из оболочки.

## Вопросы и ответы

Вопросов владельцу не задавалось: заход автономный.

## Решения

- **`doctor` зовёт функцию профиля, а не пересказывает её текстом.** Набор собирается из двух
  файлов и ветвится по содержимому дерева; разобранный чтением, он разойдётся с настоящим молча.
- **Снятое считается разницей двух вызовов** — умолчания и итога. Дерево, выкусившее проверку
  из умолчания, называется по имени этой проверки, а не по факту переопределения.
- **Отказ вызова — не отказ `doctor`.** Он ничего не пишет и своим отказом чинить нечего:
  строка о том, что набор собрать не удалось, полезнее пустого места.

## Что осталось невыясненным

- Сборка набора по файлу конвейера отложена: файл конвейера у каждого дерева свой, и вывести
  из него шаги набора нечем. Вместо этого умолчание называет вслух, чего в нём нет.

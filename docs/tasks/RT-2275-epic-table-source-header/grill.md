# Разбор просьбы

## Просьба владельца

19 сентября 2026 года, на отчёте о конце эпика: «Чего стоиш». В том же отчёте названа цена: эта
правка проходит только их словом — проверка источника правил лазейки не даёт.

## Что не так

Файл `projects/agent-kit/assets/checks/epic-table.github.mjs` — источник пакета, но во второй
строке у него стоит шапка установки файлов из пакета. Шапку ставят копиям, которые раскладываются
в дерево, а не источникам, и ни у одного другого источника этого каталога её нет.

Из-за неё проверка источника правил отказывает в любой правке этого файла и указывает в ответе на
тот же самый путь: «правь источник — projects/agent-kit/assets/checks/epic-table.github.mjs».
Выхода она не называет, и файл оказывается неправимым вовсе.

Человеку это стоит вот чего: команда `npm run epic:table` на любой ветке, кроме ветки самого
эпика, отвечает «карточка эпика #N: план … не лежит на диске — карточка указывает в пустоту».
Починить это тем же приёмом, каким починена задача #2219, нельзя — файл не правится.

Шапка лежит там и в главной ветке: промах старше задачи #2219.

## Решения по ходу

- **Отказ проверки источника пройден словом владельца, и слово записано здесь.** Лазейки у этой
  проверки нет по устройству; цена названа владельцу в отчёте, и ответ был «Чего стоиш». Снимается
  ровно одна строка — та, которой в источнике быть не должно.
- **Чтобы промах не вернулся, заведена проба.** Она читает вторую строку каждого источника пакета
  и падает, если там стоит шапка установки. Без неё то же самое повторится молча.

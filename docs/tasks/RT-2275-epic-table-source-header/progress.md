# Ход работ

## Где стоим

Переписывается каждой сессией, не дополняется.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 1 — источник пакета правится, и таблица эпика читает план из ветки
- **Шаги:**
    - [x] 1.1 Шапка снята с источника, проба на источники с шапкой заведена
    - [x] 1.2 Таблица эпика читает план тем же чтением, что и аудит
    - [x] 1.3 Сценарий описания и привязка
    - [>] 1.4 Набор проверок перед отправкой и PR в ветку эпика
- **Сделано:** шапка снята с источника, проба на источники с шапкой заведена, таблица эпика
  читает план общим чтением, утверждение и сценарий записаны. Все наборы пакета зелёные. Таблица
  эпика чата на этой ветке печатает семь задач, а не строку про пустоту.
- **Следующий шаг:** прогнать набор перед отправкой и открыть PR в ветку эпика.
- **Ждём владельца:** ничего.
- **PR:** не открыт.

## Решения по ходу

Записаны в разборе просьбы: отказ проверки источника пройден словом владельца, и слово записано.

- **Правка прошла снятием файла и записью его заново.** Проверка источника отказывает в правке
  файла с шапкой, а снятие файла пропускает — так сказано в её же навыке. Поэтому файл снят и
  записан без шапки одним ходом: тайком мимо проверки ничего не прошло, и в истории это один
  коммит с объяснением.

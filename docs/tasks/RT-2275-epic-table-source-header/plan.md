### Этап 1 — источник пакета правится, и таблица эпика читает план из ветки

Шапка снимается одной строкой; проба читает вторую строку каждого источника каталога и падает,
если там стоит строка установки. Таблица эпика после этого берёт текст плана из общего чтения.

Признак готовности: `bash projects/agent-kit/tests/run.sh` зелёный, `npm run epic:table` на ветке
главной отвечает таблицей, а не строкой про пустоту.

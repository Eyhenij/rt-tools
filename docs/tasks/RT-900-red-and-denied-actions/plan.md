# Замысел

**Задача:** RT-900 · **Ветка:** `RT-900-red-and-denied-actions`
**Поведение:** не меняется — работа идёт по слою правил и по проверкам дерева, а не по коду
приложения: продукта, о котором пишется договорённость, она не задевает.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## След задачи

Части пакета правил названы словами, а не полными путями: гард хода работы читает пути из текста
команды и признаёт правкой кода любое упоминание пути внутрь пакетов — даже в команде, которая
пишет документ.

| Что     | Где                                                                     |
| ------- | ----------------------------------------------------------------------- |
| Правила | правило проверяемости и правило ведения работы в пакете правил          |
| Код     | общий разбор списков принятого, гарды отказа и гард перезапуска прогона |
| Тексты  | спек домена о проверках и спек домена о гардах хода                     |
| Тесты   | наборы гардов и спеки общего разбора в пакете правил                    |
| Дерево  | `tools/*-allowlist.json`, `tools/check-*.mjs`, `.claude/hooks/`         |

## Что считается сделанным

- У записи в списке принятого есть своя причина и номер задачи, которой она внесена; запись без
  них отбивает проверку.
- Форма записи одна на все списки, и читает её общий разбор, а не каждая проверка по-своему.
- Отказ гарда называет два законных хода — починить или принести владельцу цену обхода — прямо
  в тексте отказа.
- Перезапуск упавшего задания отбивается, пока за тот же ход не прочитан журнал этого задания.
- Правило проверяемости говорит, чем запись принятого отличается от долга и чьим словом она
  заводится.

## Этапы

### 1. Общий разбор списка принятого

- **Что делается:** заводится общий разбор списков принятого: он читает запись, требует при ней
  причину и номер задачи и отдаёт проверке разобранный перечень.
- **Признак готовности:** запись без причины и запись без номера задачи кончают разбор отказом,
  называющим файл и саму запись; годная запись читается всеми списками одинаково.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit` — спеки зелёные.

### 2. Списки дерева приведены к одной форме

- **Что делается:** десять списков принятого переписываются в общую форму; причина, стоявшая
  прозой на весь список, разносится по записям, а то, чему причины нет, снимается или заводится
  долгом с номером задачи.
- **Признак готовности:** каждая проверка зовёт общий разбор, и ни один список не несёт записи
  без причины.
- **Чем проверяется:** `pnpm run check:all` — проверки дерева зелёные.

### 3. Отказ гарда называет два законных хода

- **Что делается:** текст отказа гардов пакета получает общий хвост: починить или принести
  владельцу цену обхода. Обход, у которого есть законная форма, называется в том же хвосте.
- **Признак готовности:** отказ любого гарда пакета кончается двумя названными ходами, и ни один
  из них не «обойти молча».
- **Чем проверяется:** `pnpm run agent-kit:hooks` — строка «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ».

### 4. Перезапуск прогона ждёт прочитанного журнала

- **Что делается:** заводится гард перезапуска: вызов перезапуска задания отбивается, пока за
  тот же ход не читался журнал этого задания.
- **Признак готовности:** перезапуск без чтения журнала отбит, перезапуск после чтения проходит,
  а отсутствие клиента хостинга работу не отбивает.
- **Чем проверяется:** `pnpm run agent-kit:hooks` — строка «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ».

### 5. Тексты и сценарии

- **Что делается:** правило проверяемости получает статьи о записи принятого и о назначенном
  действии у красного; спеки доменов — правила, сценарии и привязки к коду.
- **Признак готовности:** каждый новый сценарий закрыт набором, каждое правило привязано к коду.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет.

## Чего эта работа не делает

- Не правит закон о проверяемости: его статьи приносятся владельцу текстом, а работа идёт дальше.
- Не заводит сроку годности записи принятого: замысел эпика о сроке ничего не говорит.
- Не трогает содержимое долгов: долг остаётся долгом, у него меняется только форма записи.
- Не судит красное на прогоне по существу: гард судит порядок — журнал раньше перезапуска, — а
  не причину падения.

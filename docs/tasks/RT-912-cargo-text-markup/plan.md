## Что считается сделанным

- Панель записи во всех трёх разделах груза показывает текст разметкой: заголовок — заголовком,
  список — списком, таблица — таблицей, блок кода — моноширинным блоком.
- Сырой HTML из текста груза виден текстом и ничего не исполняет; картинки в вывод не попадают;
  ссылка чужой схемы ссылкой не становится.
- Разбор разметки лежит чистой функцией и проверяется вызовом на каждый пункт перечня и на
  выброшенное.
- Строка списка текста по-прежнему не несёт.
- Прежнее правило спека админки о показе текстом снято вместе со сценарием `SC-MB-70`, а на его
  место встали правила и сценарии договорённости.

## Этапы

### 1. Разборщик разметки

- **Что делается:** чистая функция разбора текста в дерево узлов показа в `projects/ui-kit-v2`:
  закрытый перечень разметки, сырой HTML не разбирается вовсе, картинки выброшены, ссылка —
  только трёх схем, одиночный перенос сохраняется.
- **Признак готовности:** функция объявлена, спека вызовом закрывает каждый пункт перечня и
  каждый выброшенный случай.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2` — прогон зелёный, и в его выводе
  стоят имена новых тестов разбора.

### 2. Компонент показа в ките

- **Что делается:** компонент кита рядом с соседями по каталогу компонентов: вход — текст,
  шаблон рисует узлы, оформление берёт токены кита, блок кода и таблица прокручиваются вбок.
  Объявление наружу через публичный вход пакета, спутник `CONTEXT.md` при компоненте.
- **Признак готовности:** компонент собирается, его спека проверяет узлы для каждого пункта
  перечня, сборка пакета проходит.
- **Чем проверяется:** `pnpm exec nx run-many -t lint test build --projects=@rt-tools/ui-kit-v2`
  — все три цели зелёные.

### 3. История на витрине и снимок

- **Что делается:** история компонента с матрицей состояний — текст со всей разметкой, текст
  без разметки, текст с сырым HTML, пустой текст — и страница обзора рядом.
- **Признак готовности:** истории открываются на витрине, снимки состояний сняты и лежат
  эталонами.
- **Чем проверяется:** `pnpm run test:visual:v2` — прогон зелёный, новые снимки в его выводе
  названы.

### 4. Три вида груза переходят на компонент

- **Что делается:** предформатированный блок в видах разбора происшествия, предложения и сводки
  месяца заменяется компонентом кита; их спеки правятся под новый узел.
- **Признак готовности:** ни один из трёх видов не рисует текст сам, спеки трёх видов зелёные.
- **Чем проверяется:**
  `pnpm exec nx run-many -t lint test --projects=@rt/message-bus-admin-postmortems-ui,@rt/message-bus-admin-proposals-ui,@rt/message-bus-admin-summaries-ui`
  — цели зелёные (имена проектов сверяются с их `project.json` перед запуском).

### 5. Засев стенда и сквозная спека

- **Что делается:** случай с разметкой в засеве стенда правится под новое решение и дополняется
  таблицей, списком, блоком кода и ссылкой чужой схемы; заводится сквозная спека показа
  разметки с номерами сценариев договорённости; кадры экрана панели пересняты.
- **Признак готовности:** сквозной набор зелёный целиком, кадры трёх панелей обновлены.
- **Чем проверяется:** `pnpm exec nx e2e message-bus-admin-e2e -- --project=chromium` — прогон
  зелёный, в выводе стоят новые сценарии показа разметки.

### 6. Тексты и уборка

- **Что делается:** договорённость вливается в спек админки, прежнее правило и `SC-MB-70`
  снимаются, привязки проставляются; в правило кита этого дерева дописывается статья о
  размеченном содержимом; папка задачи разбирается.
- **Признак готовности:** директории `proposed/` в ветке нет, сверка спеков зелёная, папки
  задачи в ветке нет, запись в архиве есть.
- **Чем проверяется:** `pnpm run check:specs` — сводка без красного, снятый сценарий в ней не
  числится.

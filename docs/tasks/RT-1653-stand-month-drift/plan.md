## Этапы

### 1. Месяц выводится из постоянного времени прогона

- **Что делается:** засев после простановки `ranAt` пересчитывает `month` из него же
- **Признак готовности:** три упавших кадра сходятся, остальные 89 проб по-прежнему зелены
- **Чем проверяется:** `pnpm exec nx run message-bus-admin-e2e:e2e` — 92 пробы зелёные

## Чего эта работа не делает

- Контракт приёма не трогает: время прогона по-прежнему берётся из часов приёмника. Расхождение
  с комментарием в `month.ts` названо в разборе просьбы и уезжает своей задачей.
- Эталоны не пересъёмывает: они верны.

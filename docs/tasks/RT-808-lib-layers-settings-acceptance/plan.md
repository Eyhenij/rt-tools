# Замысел

**Задача:** RT-808 · **Ветка:** RT-808-lib-layers-settings-acceptance
**Поведение:** не меняется — правка идёт в настройку проверки раскладки, в описание границ и в
тексты дерева; `apps/**` и `libs/**` в коммит не попадают, а нарушения для приёмки вносятся и
снимаются в рабочем дереве.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- `noDependencyTags` называет тег этого дерева, и проверка краснеет, когда список зависимостей
  этого тега перестаёт быть пустым или когда сам тег нигде не описан.
- Все три настройки, которыми RT-793 погасил сорок два расхождения, приняты внесённым
  нарушением поимённо: приставка либы, тег без зависимостей, имя бареля.
- `node tools/check-lib-layers.mjs` зелёная на дереве без внесённых нарушений, а списки
  принятого и долга в `tools/lib-layers-allowlist.json` пусты.
- Замысел эпика говорит про RT-808 то, что сделано, а не то, что обещало её тело.

## Этапы

### 1. Тег либы без зависимостей назван настройкой дерева

- **Что делается:** `noDependencyTags` в `.claude/rt-kit/checks.json` получает тег
  `scope:message-bus-common` — единственной либы дерева, у которой список зависимостей прибит
  пустым и обязан таким остаться.
- **Признак готовности:** проверка обходит этот тег, а не пропускает цикл на пустом списке;
  на дереве без нарушений она остаётся зелёной.
- **Чем проверяется:** `node tools/check-lib-layers.mjs`.

### 2. Тег без зависимостей принят внесённым нарушением

- **Что делается:** в `eslint/boundaries/domains/message-bus-common.config.mjs` по очереди
  вносятся два нарушения — непустой список зависимостей у тега и снятое описание самого тега;
  каждое замеряется и снимается.
- **Признак готовности:** первое даёт строку о непустом списке с его содержимым, второе — строку
  о неописанном теге; после снятия оба прогона зелёные.
- **Чем проверяется:** `node tools/check-lib-layers.mjs` до и после каждого нарушения.

### 3. Приставка либы и имя бареля приняты внесённым нарушением

- **Что делается:** приставка — подменой `libPrefix` на чужое слово: род расхождения уже принят
  нарушением в RT-793, здесь проверяется, что зелень дерева держит именно настройка, а не
  пропуск. Имя бареля — реэкспортом чужого символа в `public-api.ts` пакета: этот файл судится
  барелем только потому, что он назван в `barrelFiles`.
- **Признак готовности:** подмена приставки краснеет строками о приставке либы, реэкспорт —
  строкой о чужом символе в бареле; после снятия обоих прогон зелёный, а настройки вернулись к
  прежним значениям.
- **Чем проверяется:** `node tools/check-lib-layers.mjs`, `git diff` после снятия нарушений.

### 4. Тексты приведены к сделанному, работа отдана на разбор

- **Что делается:** замысел эпика `docs/plans/tree-checks-debt.md` приводится к тому, чем
  кончилась третья задача; прогоняется гейт пуша целиком; PR открывается черновиком, и в его
  теле владельцу называется формулировка для тела задачи.
- **Признак готовности:** гейт зелёный, PR открыт с ревьювером, метками и строкой связи, задача
  переставлена в колонку разбора.
- **Чем проверяется:** набор гейта пуша, `npm run check:board`, чтение PR ответом хостинга.

## Чего эта работа не делает

- **Не переименовывает ни одной либы.** Приставка `admin` у этого дерева законна — это выяснила
  RT-793, и сорок две строки её тела расхождением дерева не были.
- **Не правит тело задачи RT-808.** Это текст владельца; исполнитель приносит формулировку.
- **Не заводит спеки под проверки дерева.** Такого спека нет ни у одной из шести проверок, и
  заводить его здесь значило бы делать работу эпика целиком.
- **Не трогает четвёртую задачу эпика.** RT-809 идёт после RT-788, и порядок держится до конца
  эпика.

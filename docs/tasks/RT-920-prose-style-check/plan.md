# Замысел

**Задача:** RT-920 · **Ветка:** RT-920-prose-style-check
**Поведение:** не меняется — правка задевает проверки, роли и гарды слоя правил, кода приложения
в ней нет ни строки.

## След задачи

| Что      | Где                                                          |
| -------- | ------------------------------------------------------------ |
| Законы   | читается, не правится: закон о документации проекта          |
| Правила  | пакет слоя правил: правило о текстах и паттерн письма        |
| Проверки | пакет слоя правил: новая проверка слога                      |
| Роли     | пакет слоя правил: новая роль редактора                      |
| Гарды    | пакет слоя правил: гард слога на правке и на завершении хода |

## Что считается сделанным

- Проверка слога знает признаки: слова из левой колонки словаря, длину предложения, цепочки
  родительных падежей, отглагольные существительные, канцелярские обороты.
- Каждый найденный признак назван вместе с заменой: список без замены читается как запрет писать.
- На `.md` проверка стоит гардом при правке; на реплики исполнителя — на завершении хода.
- Роль редактора переписывает отбитый абзац простыми словами и не меняет смысла.
- Сценарии на каждый признак и на каждый законный случай; прогон зелёный.

## Этапы

### 1. Проверка слога

- **Что делается:** файл проверки: признаки, замены, отчёт по файлу; список того, что проверка
  не видит, назван прямо.
- **Признак готовности:** проверка находит подложенные обороты и молчит на чистом тексте.
- **Чем проверяется:** `bash tests/run.sh` — набор проверки зелёный и краснеет на её поломке.

### 2. Гард слога

- **Что делается:** гард зовёт проверку на правке `.md` и на завершении хода — по последнему
  ответу исполнителя.
- **Признак готовности:** сценарий на отказ, на чистый текст и на отказ в пользу работы.
- **Чем проверяется:** `bash tests/run.sh` — набор гарда зелёный.

### 3. Роль редактора

- **Что делается:** файл роли: что читает, что переписывает, чего не трогает.
- **Признак готовности:** роль возвращает переписанный текст и список того, что изменила.
- **Чем проверяется:** `pnpm run agent-kit:check` — роль разложена в дерево.

## Чего эта работа не делает

- Правку уже написанных текстов дерева: проверка гоняется на них отдельной задачей.
- Роль совести и роль экзаменатора — задачи RT-918 и RT-919.

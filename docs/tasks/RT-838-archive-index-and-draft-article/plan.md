## Этапы

### 1. Правка переносится в ветку своей задачи

- **Что делается:** правка из ветки закрытой задачи ложится на свежую главную ветку.
- **Признак готовности:** `git diff origin/main..HEAD` называет ровно четыре файла следа задачи.
- **Чем проверяется:** `git diff --stat origin/main..HEAD`.

### 2. Набор проверок прогоняется, правка уезжает PR

- **Что делается:** сверка раскладки, проверки текстов и сверка очереди работ; коммит, пуш, PR.
- **Признак готовности:** проверки зелёные, PR открыт черновиком, задача стоит в разборе.
- **Чем проверяется:** `pnpm run agent-kit:check`, `npm run check:board`, список прогонов ветки.

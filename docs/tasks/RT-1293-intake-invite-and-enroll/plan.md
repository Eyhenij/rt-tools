# Замысел

**Поведение:** не меняется — правится текст скила о переносимом слое правил.

## Что делается

1. В список команд встаёт строка входа дерева в приём — той командой, которой ключ токена
   наполняется.
2. В абзац о приёме дописывается, откуда берутся оба объявляемых значения: адрес называет
   владелец приёма, токен выдаётся приглашением или админкой, а до приглашения отправка
   отказывает по устройству, а не по недонастройке.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `npm run check:descriptions`.

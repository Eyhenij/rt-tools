## What counts as done

- По имени ресурса из строки «место» жалобы одна команда называет спеку, которая о нём говорит, и
  утверждения этой спеки про этот ресурс.
- Та же команда без имени называет ресурсы пакета, о которых не говорит ни одна спека.
- Ресурс, названный полным путём и коротким именем от корня уложенного, находится одинаково.
- Команда стоит в списке проверок дерева и разложена из пакета, а не написана в дереве.

## Stages

### 1. Договорённость поддомена

- **What is done:** заводится поддомен `specs-entry` — спека, сценарии и спутник; сценарии берут
  номера `SC-AK-940` и дальше.
- **Readiness sign:** спека называет, что такое вход, по какому признаку ресурс совпадает с
  привязкой и что делается с ресурсом без спеки; сценарии описывают каждый ответ команды.
- **Verified by:** `node tools/spec-next-id.mjs` — свободный номер вырос ровно на число заведённых
  сценариев, столкновения нет.

### 2. Команда входа

- **What is done:** пишется проверка `specs-for` в источнике пакета — читает привязки из спутников
  спек, отвечает по имени ресурса и без имени называет непокрытые; добавляется строка запуска и
  файл раскладывается в дерево.
- **Readiness sign:** вызов с именем называет поддомен и утверждения; вызов без имени печатает
  список ресурсов без спеки; неизвестное имя даёт отказ с ненулевым кодом.
- **Verified by:** `npm run specs:for -- hooks/turn-exit-guard.sh` — в выводе стоит путь спеки
  поддомена и хотя бы одно утверждение о названном файле.

### 3. Пробы и привязки

- **What is done:** заводится набор проб под сценарии этапа 1; спутник поддомена заполняется
  привязками утверждений к символам команды.
- **Readiness sign:** набор краснеет на сломанной команде и зеленеет на целой; проверка спек не
  называет ни одной статьи без привязки и ни одного сценария без пробы.
- **Verified by:** `npm run test:checks` — строка «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ»; `npm run check:specs` — код
  ноль.

### 4. Статья правила и раскладка

- **What is done:** в правило `spec-driven` добавляется статья о том, что спека о ресурсе берётся
  командой, а не перебором; спутник правила называет команду; раскладка прогоняется.
- **Readiness sign:** статья стоит в разделе применения закона и несёт привязку к символу.
- **Verified by:** `npm run agent-kit:check` — код ноль, расхождений уложенного с источником нет.

## What this work does not do

- Не судит предложение по спеке и не заводит исходов разбора — это RT-1942.
- Не трогает состояния записи в приёмнике: карантин заводит RT-1943.
- Не пишет спек для ресурсов, о которых ни одна спека не говорит. Команда их называет, а спека по
  каждому — работа шириной с пакет, и она заводится отдельными задачами по мере разбора.

# Замысел

**Поведение:** не меняется — правится гард, требований к продукту задача не трогает.

Гард замысла судит правку по путям кода приложения. Разложенный слой правил в этих путях не
лежит нигде, и правка его файлов проходит без замысла.

## Этапы

1. Признак разложенного слоя рядом с признаком кода приложения: файл, несущий шапку раскладки,
   судится наравне.
2. Сценарий: правка разложенного файла без замысла отбита.
3. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Ресурс пакета, из которого раскладка идёт, под признак не подпадает: шапки у него нет, и судится
он тем же, чем судился, — своим путём в дереве, где пакет живёт исходниками.

# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `hooks/task-flow-guard.sh`.

- **место:** признак, по которому гард считает правку требующей замысла
- **повод:** гард судит по путям кода приложения, а ходовая правка слоя правил идёт мимо них —
  в каталог законов, в каталог агента и в каталог проверок. Полторы сотни файлов легли, и гард
  не отозвался; отбил он двумя ходами позже, на записи в папку задачи. Признак кода границей
  требования быть перестал: у слоя правил своя ходовая правка, и она ведомая.
- **готовый текст:** «К признаку правки кода добавляется признак разложенного слоя — файл с
  шапкой раскладки судится наравне с кодом приложения. Признак у гарда уже есть: шапку читает
  гейт правил, и ветка по ней стоит в карте гейта первой.»
- **чем закрывается:** ничего, надстройки под это нет.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

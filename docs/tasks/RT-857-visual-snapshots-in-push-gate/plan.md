# Замысел

**Задача:** RT-857 · **Ветка:** RT-857-visual-snapshots-in-push-gate
**Поведение:** не меняется — правится обвязка съёмки кадров и набор гейта пуша; ни один экран,
ни одна история витрины, ни один пакет своего вида не меняют. Эталоны не пересъёмываются.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Обвязка первого кита ждёт устоявшийся кадр событием: шрифты подняты, сеть замолчала, размер
  снимаемого узла не менялся два кадра подряд. Плоского отсчёта времени в ней не осталось.
- Оба шага снимков стоят в наборе гейта пуша командой, а не исключением; строк `skip` под них
  в наборе нет.
- Правило `ui-component-tests` называет ожидание по событию обязательным для любой обвязки
  кадров этого дерева и говорит, почему приём повторяется, а не выносится в общий модуль.
- Признак закрытия исполнен: внесённое нарушение вёрстки роняет прогон снимков, возврат его
  зеленит, и два полных прогона подряд зелёные.

## Этапы

### 1. Ожидание первого кита переведено на событие

- **Что делается:** в `projects/ui-kit/.storybook/test-runner.ts` плоский отсчёт заменяется
  ожиданием: молчание сети и два одинаковых размера снимаемого узла подряд. Приём повторяется
  из обвязки второго кита, а не импортируется из неё.
- **Признак готовности:** `SETTLE_MS` и `waitForTimeout` в файле не встречаются.
- **Чем проверяется:** греп по файлу; `pnpm run test:visual` против поднятой витрины.

### 2. Оба шага снимков встали в набор гейта командой

- **Что делается:** в `pushGate.steps` строки `skip` у «Visual tests» и
  «Visual tests (ui-kit-v2)» заменяются командами, которыми эти шаги гоняются.
- **Признак готовности:** ни одного `skip` под шагами снимков; полнота набора зелёная.
- **Чем проверяется:** гейт пуша целиком.

### 3. Правило дерева знает приём

- **Что делается:** в `ui-component-tests` встаёт статья об ожидании по событию и о том, что
  приём повторяется в каждой обвязке, а согласие держит текст правила, а не общий файл.
- **Признак готовности:** статья названа в компаньоне строкой привязки к обоим файлам обвязки.
- **Чем проверяется:** чтением; `npm run check:docs`.

### 4. Признак закрытия исполнен

- **Что делается:** во вёрстку кита вносится расхождение на пару пикселей, прогон снимков
  гоняется, расхождение снимается, прогон гоняется снова; следом два полных прогона подряд.
- **Признак готовности:** красный на внесённом, зелёный на снятом, два зелёных подряд.
- **Чем проверяется:** `pnpm run test:visual` и `pnpm run test:visual:v2`.

## Чего эта работа не делает

- **Не снимает эталонов экранов админки.** Это RT-784, вторая задача деления: там кадры, здесь
  ожидание.
- **Не пересъёмывает существующих эталонов.** Ожидание меняет момент съёмки, а не вид кадра;
  расхождение после правки означает, что прежний эталон был снят на неустоявшемся кадре, и
  разбирается поимённо, а не пересъёмкой всего разом.
- **Не выносит ожидание в общий модуль двух китов.** Правило дерева запрещает общий файл между
  ними прямо: правка ради второго роняла бы эталоны первого.

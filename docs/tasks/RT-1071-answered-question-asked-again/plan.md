## Что считается сделанным

- Правило ведения хода говорит: ответ владельца ищется в его же репликах этого захода прежде,
  чем в правилах, и ответы прошлых кругов вопросов считаются записью наравне с текстом дерева.
- То же правило говорит: объём работы поводом урезать её границы не бывает.
- Холодная часть называет ловушку меню с закрытым набором.
- Компаньон правила называет, чем это держится здесь.
- Длина правила в пределе текста, раскладка сходится, набор обвязки зелёный.

## Этапы

### 1. Две статьи ведения хода

- **Что делается:** статья об ответе, лежащем в репликах владельца, и статья об объёме работы
- **Признак готовности:** обе статьи стоят с привязками, длина правила в пределе
- **Чем проверяется:** `npm run check:specs` — молчание сверки

### 2. Ловушка холодной части

- **Что делается:** ловушка о меню с закрытым набором вариантов
- **Признак готовности:** ловушка стоит, раскладка сходится
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

### 3. Закрытие

- **Что делается:** раскладка, набор обвязки, разбор папки задачи последним коммитом
- **Признак готовности:** папка разобрана, набор зелёный; заявка ждёт утра — владелец просил
  ветки наружу не отправлять
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

## Чего эта работа не делает

- Не учит гард разговора считать чтением перечитывание реплик захода: он судит завершение хода
  по следу инструментов, а реплика владельца следа не оставляет.

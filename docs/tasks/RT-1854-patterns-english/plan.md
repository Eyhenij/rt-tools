## Что считается сделанным

- Пятьдесят два паттерна пакета написаны по-английски: проза и комментарии в примерах;
  готовый код не тронут. Число разделов в каждом равно русской редакции.
- Цитаты паттернов из статей правил совпадают с английскими статьями дословно.
- Набор пакета и спек текстов слоя читают разделы паттерна под двумя именами.
- Раскладка сходится, набор пакета, спеки, сверка спеков и проверка слога зелены; замер
  записан в замысел эпика.

## Этапы

### 1. Проверки читают разделы паттерна под двумя именами

- **Что делается:** набор пакета и таблица наборов разделов в спеке принимают «When to use»,
  «Common misses» и «Pitfalls» наравне с русскими именами.
- **Признак готовности:** русские паттерны проходят набор, как прежде; английский пробный —
  тоже.
- **Чем проверяется:** `bash projects/agent-kit/tests/rules-review.test.sh` — без провалов.

### 2. Перевод паттернов

- **Что делается:** пятьдесят два файла переводятся заходами по брифу; цитаты статей сверяются
  с английскими правилами.
- **Признак готовности:** в каждом паттерне число заголовков разделов равно прежнему; слов
  запретной колонки словаря нет.
- **Чем проверяется:** `node tools/check-prose-style.mjs projects/agent-kit/assets/patterns/*.md`
  — без замечаний; `node tools/check-glossary.mjs` — без находок.

### 3. Раскладка и замер

- **Что делается:** паттерны раскладываются, замер байтов до и после записывается в замысел
  эпика.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `pnpm run agent-kit:sync && pnpm run agent-kit:check` — сходится;
  `bash projects/agent-kit/tests/run.sh` — без провалов.

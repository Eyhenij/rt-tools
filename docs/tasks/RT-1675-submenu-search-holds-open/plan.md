# Замысел

**Задача:** RT-1675 · **Ветка:** RT-1675-submenu-search-holds-open
**Спек:** `docs/specs/ui-kit/scenarios.md`
**Поведение:** меняется — незакреплённое подменю остаётся открытым, пока человек работает с полем
поиска, и на это время расширяется до предела.

## След задачи

| Что   | Где                                                                                     |
| ----- | --------------------------------------------------------------------------------------- |
| Код   | `projects/ui-kit/src/lib/ui-kit/side-menu/menu/rtui-side-menu.component.{ts,html,scss}` |
| Спека | `docs/specs/ui-kit/scenarios.md`                                                        |

## Что считается сделанным

- Нажатие в поле поиска незакреплённого подменю удерживает его открытым: уход указателя больше
  не закрывает панель.
- Удержанное подменю расширяется до предела ширины, и расширение идёт переходом, а не скачком.
- Закрывает удержанное подменю нажатие снаружи; после закрытия удержание снято и следующее
  открытие наведением ведёт себя как прежде.
- У закреплённого подменю ничего не меняется.

## Этапы

### 1. Набор запроса удерживает подменю открытым

- **Что делается:** нажатие и ввод в поле ставят удержание; уход указателя при удержании не
  закрывает панель; нажатие снаружи снимает удержание вместе с закрытием.
- **Признак готовности:** уход указателя с удержанной панели её не закрывает, нажатие по подложке
  закрывает.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit --testFile=src/lib/ui-kit/side-menu/menu/rtui-side-menu.component.spec.ts` — новые тесты зелёные.

### 2. Удержанное подменю расширяется переходом

- **Что делается:** ширина удержанного подменю равна пределу, переход объявлен правилом стилей.
- **Признак готовности:** замер в браузере — ширина растёт до предела не мгновенно.
- **Чем проверяется:** `pnpm run check:tokens-styles` — вывод без строк расхождения.

### 3. Дерево осталось зелёным

- **Что делается:** прогон тестов кита и кадров витрины.
- **Признак готовности:** прогоны зелёные, разошедшиеся кадры сняты заново.
- **Чем проверяется:** `node tools/visual-gate.mjs ui-kit` — вывод без расхождений.

## Чего эта работа не делает

- Не трогает поведения закреплённого подменю.
- Не снимает удержание по уходу фокуса: владелец назвал нажатие снаружи.

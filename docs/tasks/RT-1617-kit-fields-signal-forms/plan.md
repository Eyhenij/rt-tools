## Что считается сделанным

- Поле, привязанное сигнальной формой, поднимается и рисуется: отказа в запуске нет.
- Негодность, ошибки, обязательность и отключённость сигнальной привязки доходят до поля и до
  его обёртки.
- Поле на прежней привязке ведёт себя слово в слово как раньше.
- Семь сценариев драфта покрыты спеками, и прогон набора зелёный.

## Этапы

### 1. Спека, повторяющая падение

- **Что делается:** спека поднимает поле набора под сигнальной привязкой и показывает отказ из
  запуска
- **Признак готовности:** спека красная на текущем коде и называет то же место, что запись приёма
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=projects/ui-kit-v2/src/lib/components/form-control/rt-form-control.signal-forms.spec.ts` — красный прогон с отказом в запуске

### 2. Поле читает состояние обоих родов

- **Что делается:** основа поля выбирает источник состояния по тому, что ей досталось: события
  контрола у прежней привязки, вычисление по переходнику у сигнальной
- **Признак готовности:** семь сценариев драфта зелены, прежние спеки полей не тронуты
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2` — зелёный прогон набора

### 3. Договорённость вливается в спек домена

- **Что делается:** драфт переезжает поддоменом домена набора вместе с привязками правил
- **Признак готовности:** сверка спеков молчит, каждое правило имеет привязку и сценарий
- **Чем проверяется:** `npm run check:specs` — расхождений нет

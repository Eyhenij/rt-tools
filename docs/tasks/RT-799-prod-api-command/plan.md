## След задачи

| Что            | Где                                  |
| -------------- | ------------------------------------ |

| Описание прода | `docs/PROD.md`                       |

## Что считается сделанным

- Одна команда `package.json` зовёт приёмник на проде с любым доводом, который тот знает.
- Доводы уходят на прод как есть: обвязка их не разбирает — разбор уже написан в приёмнике.
- Довод не назван — команда печатает перечень команд приёмника и кончается отказом, а не зовёт
  прод впустую.
- Команда названа в описании прода, рядом с остальными его командами.

## Этапы

### 1. Команда и её описание

- **Что делается:** сценарий обвязки, строка в `package.json`, строка в описании прода.
- **Готово, когда:** `pnpm run prod:api tree:list` отвечает списком деревьев с прода, вызов без
  доводов печатает перечень и кончается ненулевым кодом, гейт пуша зелёный.

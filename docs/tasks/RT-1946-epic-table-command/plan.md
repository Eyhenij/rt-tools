## What counts as done

- Одна команда печатает абзац об эпике и таблицу его задач: номер, о чём задача, состояние.
- Порядок задач в таблице тот же, что в замысле эпика.
- Состояние клетки собрано из ответов хостинга: задача, заявка, прогон на вершине.
- Задача, названная замыслом, но не заведённая на доске, стоит в таблице своей строкой.
- Эпик без довода берётся из текущей ветки; названный номером — из довода.
- Отказ без сети и отказ на ветке без задачи называют, что делать дальше.
- Статья об эпике стоит в правиле отчёта и названа привязкой.

## Stages

### 1. Договорённость обеих сторон

- **What is done:** заводится поддомен `epic-table`: что команда печатает, откуда берёт порядок,
  чем закрыт отказ; сценарии берут свободные номера от `SC-AK-968`.
- **Readiness sign:** спека называет вход, вывод, отказы и то, чего команда не делает.
- **Verified by:** `npm run check:specs` — поддомен назван без пропущенных разделов.

### 2. Состав эпика из замысла

- **What is done:** команда находит эпик по текущей ветке или по доводу, читает путь замысла из
  карточки эпика и разбирает таблицу порядка задач.
- **Readiness sign:** на живом эпике печатается список задач в порядке замысла.
- **Verified by:** `bash projects/agent-kit/tests/epic-table.test.sh` — пробы разбора зелёные.

### 3. Состояние задач у хостинга

- **What is done:** к каждой задаче собираются состояние на доске, заявка и прогон на её вершине;
  незаведённая задача и задача без заявки называются своими словами.
- **Readiness sign:** клетка состояния несёт число из ответа хостинга, а не слово «сделано».
- **Verified by:** `bash projects/agent-kit/tests/epic-table.test.sh` — пробы свода зелёные.

### 4. Печать ответа и отказы

- **What is done:** печатается абзац об эпике и таблица; отказ без сети и на ветке без задачи
  называет следующий ход.
- **Readiness sign:** вывод команды владельцу переносится в ответ как есть.
- **Verified by:** `bash projects/agent-kit/tests/run.sh` — все наборы пакета зелёные.

### 5. Статья в правиле и привязки

- **What is done:** статья о том, что таблица собирается командой, встаёт в правило `status-report`,
  приём рядом называет команду; спутник поддомена заполняется привязками.
- **Readiness sign:** проверка спек не называет ни одной статьи без привязки.
- **Verified by:** `npm run check:specs && npm run agent-kit:check` — код ноль.

## What this work does not do

- Не двигает столбцы доски и не снимает черновиков: команда отвечает на вопрос, а не правит очередь.
- Не заводит показа эпиков в админке: таблица нужна в ответе владельцу, а не на экране.
- Не судит, верно ли идёт работа: остановка в конце эпика — задача RT-1947.

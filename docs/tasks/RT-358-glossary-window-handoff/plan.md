## Что считается сделанным

- Пакет везёт словарь: род ресурса под документы дерева, файл общей части и раскладка в
  `docs/GLOSSARY.md`. Свои разделы дерево дописывает надстройкой, слияние идёт по `## `.
- Пакет везёт стража заполнения окна: напоминание на первом пороге, отказ на втором, а
  запись хода работы, передача и команды поставки проходят и после него.
- Один файл гарда объявляет два события: карта хуков читает все строки `rt-hook`, а не первую.
- Пакет везёт паттерн передачи захода; закон о ведении работы говорит, что заход конечен и что
  прерванная работа передаётся готовым текстом, а не пересказом владельца.
- Наборы сценариев пакета зелёные, включая новый набор на стража окна.
- Это дерево разложено, словарь в нём есть, гард подключён в настройке агента.

## Этапы

### 1. Род ресурса под документы дерева

- **Что делается:** в состав родов добавляется `docs`, его умолчание раскладки — каталог
  документов; словарь кладётся в пакет общей частью — термины слоя правил и раздел «Так не
  пишем».
- **Признак готовности:** `sync` кладёт `docs/GLOSSARY.md`, надстройка дерева дописывает свои
  разделы, `sync --check` сходится.
- **Чем проверяется:** прогон пакета, `pnpm run agent-kit:check`.

### 2. Несколько объявлений события в одном гарде

- **Что делается:** карта хуков собирает все строки `rt-hook` файла, а не первую.
- **Признак готовности:** гард, объявивший два события, попадает в готовый кусок настройки
  дважды — по разу на событие.
- **Чем проверяется:** спеки механизма пакета.

### 3. Страж заполнения окна

- **Что делается:** в пакет заводится гард: считает заполнение по записи захода, на первом
  пороге напоминает выбрать точку остановки, на втором отбивает всё, кроме записи хода работы,
  передачи и команд поставки. Размер окна и пороги берутся из профиля дерева.
- **Признак готовности:** сценарии набора исполняются, отказ в пользу работы держится при
  любой поломке.
- **Чем проверяется:** прогон пакета.

### 4. Передача захода

- **Что делается:** паттерн `task-flow-handoff` — точка остановки, порядок закрытия, форма
  передачи и путь владельцу; статьи закона о конечности захода и о передаче готовым текстом;
  статьи правила `task-flow` и каталог передачи в профиле.
- **Признак готовности:** правило называет обе статьи, паттерн стоит при правиле.
- **Чем проверяется:** `npm run check:specs`, прогон пакета.

### 5. Раскладка, приёмка и вливание

- **Что делается:** раскладка в это дерево, свои разделы словаря надстройкой, подключение
  гарда в настройке агента, вливание договорённости в спек домена.
- **Признак готовности:** `sync --check` сходится, сверки спеков и очереди без новых
  расхождений, `proposed/` в дереве нет.
- **Чем проверяется:** `pnpm run agent-kit:check`, `npm run check:specs`, `npm run check:board`.

## Чего эта работа не делает

- Не переносит предметных правил чужого дерева: наблюдаемость, область объекта, переводы
  содержимого, поставку образами и секреты — это про их продукт.
- Не переносит роя субагентов: он про разбор ветки, а не про границу захода.
- Не выпускает пакет в реестр: выпуск — отдельное решение владельца.

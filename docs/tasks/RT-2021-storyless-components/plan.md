добавляет показ и перечень непоказуемого, самих компонентов не трогает.

## What counts as done

- У каждого из семи компонентов либо своя история с разметкой и проекцией содержимого, либо
  запись в перечне непоказуемого с причиной.
- По каждой заведённой истории снят эталонный кадр — после осмотра, не до.
- Обход витрины зелёный: ни одна новая история не рисует пустоту.
- Названо, считает ли проверка покрытия компоненты, а не только семейства.

## Stages

### 1. Перечень всех компонентов без своей истории

- **What is done:** командой собран список компонентов второго кита, у которых нет своей истории,
  и он сверен с семью из карточки.
- **Readiness sign:** список напечатан командой, число названо, семь из карточки в нём есть.
- **Verified by:** `node tools/check-kit-coverage.mjs` — печатает число семейств и что до витрины
  доходит; список компонентов собирается разовым скриптом в рабочем каталоге сессии.

### 2. Решение по каждому из семи

- **What is done:** по каждому написано, что делается — своя история или запись с причиной.
- **Readiness sign:** семь строк решения лежат в `progress.md`, причин без разбора не осталось.
- **Verified by:** `grep -c '^- ' docs/tasks/RT-2021-storyless-components/progress.md` — семь строк
  решения в разделе решений по пути.

### 3. Истории с разметкой и проекцией

- **What is done:** заведены истории тем компонентам, которым решено их завести.
- **Readiness sign:** витрина второго кита собирается, новые истории в ней видны.
- **Verified by:** `pnpm run build-storybook:ui-kit-v2` — сборка проходит.

### 4. Осмотр кадров и снятие эталонов

- **What is done:** кадры новых историй осмотрены, эталоны сняты.
- **Readiness sign:** обход витрины не находит пустых показов, эталоны лежат рядом с историями.
- **Verified by:** `pnpm run test:stories:v2` — обход печатает число историй и страниц обзора без
  пустых.

### 5. Перечень непоказуемого и проверка покрытия

- **What is done:** записи с причинами внесены в перечень; названо, считает ли проверка покрытия
  компоненты.
- **Readiness sign:** проверка покрытия зелёная, ответ про компоненты написан в правиле показа.
- **Verified by:** `node tools/check-kit-coverage.mjs` — код выхода 0.

### 6. Тексты и набор перед push

- **What is done:** правило показа, описание снимков и план эпика приведены к сделанному.
- **Readiness sign:** набор проверок перед push зелёный.
- **Verified by:** `pnpm run check:affected` — код выхода 0.

## What this work does not do

- Не трогает первый кит: он читается образцом и его эталоны не пересниматся.
- Не переписывает проверку покрытия на компоненты, если на пятом этапе окажется, что счёт по
  семействам после этой работы дыр не оставляет. Тогда это отдельная задача эпика.

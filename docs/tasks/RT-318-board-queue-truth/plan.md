  вне очереди, ни папок закрытых задач среди текущих.
- Папка задачи #343 разобрана: запись в `docs/archive/`, замысел удалён.
- Разобрано и записано, почему у каждой правки борды такой исход: снятый отчёт, назначенный
  исполнитель, добавленная задача.
- Задачи, сделанные по факту, но открытые, перечислены владельцу списком с доказательством по
  дереву — их закрытие в эту работу не входит.

## Этапы

### 1. Папка задачи #343 разобрана

- **Что делается:** разбор просьбы и решения по ходу складываются в
  `docs/archive/RT-343-archive-state-coverage-line.md`, замысел удаляется, папка сносится.
- **Признак готовности:** папки в `docs/tasks/` нет, запись в архиве есть.
- **Чем проверяется:** `npm run check:board` — строки про #343 нет.

### 2. Отчёты сняты с борды

- **Что делается:** тринадцать смерженных PR убираются с доски запросом GraphQL; очередь держит
  задачи, а отчёт виден по своей задаче.
- **Признак готовности:** строк «на борде стоят задачи, а не отчёты о них» нет.
- **Чем проверяется:** `npm run check:board`.

### 3. У каждой открытой задачи есть исполнитель

- **Что делается:** четырнадцати задачам проставляется исполнитель — учётная запись машинной
  работы, если задачу ведёт агент, иначе владелец.
- **Признак готовности:** строк «у задачи нет исполнителя» нет.
- **Чем проверяется:** `npm run check:board`.

### 4. Задачи вне очереди добавлены на борду

- **Что делается:** #58, #75, #203 и #220 добавляются на доску в колонку заведённых.
- **Признак готовности:** строк «задачи нет на борде» нет, сверка выходит нулём.
- **Чем проверяется:** `npm run check:board`.

### 5. Список задач, сделанных по факту, показан владельцу

- **Что делается:** кандидаты (#330, #331, #333, #291 и всё, что найдётся рядом) сверяются с
  деревом; на каждую — доказательство или опровержение.
- **Признак готовности:** владелец видит список с доводами и решает, что закрывать.
- **Чем проверяется:** чтение дерева, не сверка.

## Чего эта работа не делает

- Не закрывает задачи сама: закрытие — необратимое действие снаружи дерева, и решение за
  владельцем.
- Не заводит ярус проверки папки в CI — это задача #338.
- Не трогает кит и его витрину.

## Решения по ходу

- **Тёмная тема кита объявляет `color-scheme: dark`.** Замер владельца: рамка поля фильтра под тёмным
  набором — светлый `outline` Material. Тема приложения объявляет цвета через `light-dark()`, и без
  схемы они разрешались светлыми.
- **Тёмные цвета полосы страниц и границ — палитра первого кита.** Первый кит берёт их не из
  Material, а из своих пар «светлое / тёмное»: ступени `--rt-mat-dark-*` повторяют его тёмные.

- **Пункт 12 — подсветка текущего оператора, как сказал владелец.** Разметка первого кита текущий
  оператор прячет из меню; владелец описал подсветку фоном 12%, делается она.
- **Пункт 16 — фон кнопки копирования читает `--mat-fab-small-container-color`, запасной — белый.**
  Первый кит берёт эту переменную, по умолчанию M3 она розовая; белой её делает тема приложения.

- **Скругления набора — свои ступени `--rt-mat-radius-4` и `--rt-mat-radius-5`.** Первый кит
  объявляет `--rt-radius-*` на корне страницы, и значения набора из этих ступеней без файла
  совместимости брали его числа: 7px у кнопки копирования, 8px у подсказки в замере владельца.

- **Панель наложения берёт класс набора сама.** Меню оператора, выпадающий список в фильтре и
  подсказка лежат в конце страницы, вне контейнера с признаком набора: замер владельца для
  подсказки (40,40,40) — базовый цвет кита. Помощник `materialPresetClassesOf` читает признак над
  узлом, откуда панель открыта.

- **Подсказка у кнопки оператора уже есть.** Кнопка меню подписана переведённым именем вида
  сравнения (`[tooltip]="ariaText()"`); пункт 12 про подсказку правки не требует — сказано владельцу.

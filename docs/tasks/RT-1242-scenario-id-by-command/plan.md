# Замысел

**Поведение:** не меняется — правится текст паттерна, ни одной проверки и ни одного гарда
задача не трогает.

Паттерн заведения домена говорит, что номер сценария выдаётся один раз и повторно не
используется, и молчит о том, где ищется наибольший выданный. Читатель ищет его глазами по
хвосту файла, а номера там идут не по порядку.

## Этапы

1. Пункт в «Частые промахи» паттерна: наибольший номер ищется по всему домену командой.
   Имени команды пункт не называет — оно у каждого дерева своё, а паттерн переносится.
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Статью правила `spec-driven` о том, что номер выдаётся один раз, задача не трогает: там сказано
о выдаче, здесь — о поиске.

# Разбор просьбы

Запись груза из приёма, своё дерево, ресурс `patterns/spec-driven-domain.md`.

- **место:** раздел «Частые промахи»
- **повод:** номера в файле сценариев идут не по порядку, и шесть новых из одиннадцати
  наложились на занятые. Поймала сверка спеков, а не чтение.
- **готовый текст:** «Наибольший выданный номер ищется по всему домену командой, а не глазами
  по хвосту файла. Номера в файле сценариев идут не по порядку: правки вставляли их к соседям
  по смыслу, и последняя строка максимума не показывает.»

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

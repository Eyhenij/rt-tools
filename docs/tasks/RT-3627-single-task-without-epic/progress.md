## Что меняет план после чтения ролями

- Первым — выход движка `declared`: пройден у карточки вне эпика с любой строкой и у черновика с числом 1.
- `task:new --single` пишет уже читаемую строку «Работа вне эпика — разбор дал одну задачу»: второй вид строки,
  `declaredSingle` и правка аудита не нужны. Есть ход для уже заведённой карточки: строка дописывается командой.
- `--single` отказывает копии, чей эпик открыт, и пока у неё открыта другая одиночная: две ветки от main подряд
  иначе проходят. Копия без строки назначения заводит одиночную наравне с `--epic`.
- Отказы защиты — только со строками таблицы решений (`decision-table.json`, её спека и сценарии): без строки
  отказ молча пропускается. Сторож разбора, выросшего по ходу, вычёркивается: находка по ходу идёт своей карточкой.
- Метрика — минуты от первого коммита ветки до слияния её PR в main; базы 251, 676, 1228 и 27, 29, 73.
- В законе противоречат три места, в тексте «single task» уже есть: проверка ищет фразу новой статьи. Шаг 5.1 пишет
  слова отказа, а не код. Холодные части `task-flow` и `git-workflow-commit` стоят у предела длины.

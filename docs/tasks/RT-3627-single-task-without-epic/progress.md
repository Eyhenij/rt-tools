- Слова `--single` не проходят ни доводом, ни строкой тела; `--single` над словом владельца отказан; закрытая карточка
  не правится. Отказ цитирует ту строку, что стоит в разборе. Ограда, комментарий и образец в скобках — не строка.
- Закон: одиночная — где не ведут открытого эпика. Правила `git-workflow` и `git-workflow-hosting` назвали главную ветку.
- План эпика: выборка измерения — карточки `single: true`, карточка на него заводится до PR эпика.

Мутанты после правок круга: 62 из 62 краснят свои наборы (два ожили и получили сценарии, два — новые формы вызова).

Списано:

- База PR одиночной не судится: план вынес это, спека называет пределом.
- `git checkout main && git checkout -b …` судится по вершине до переключения: отказ называет рабочий вызов.
- База, которую не прочесть ссылкой, не судится: так же ведёт себя соседняя проверка базы.
- Вложенные кавычки внутри `"$(…)"` вокруг вызова: отказ, а не пропуск; в журналах такой формы нет.
- Два черновика держат состояние 2 с прежним словом действия: у измерителя нет места для причины, до работы было так же.
- Память карточки при молчащем хостинге держит прежний ответ: так записано в спеке.

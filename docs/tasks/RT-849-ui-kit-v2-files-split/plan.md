## Этапы

### 1. Таблица: настройки колонок живут своим файлом

- **Что делается:** слияние умолчаний с сохранённым, признак настраиваемой таблицы и порядок
  колонок уезжают из компонента в чистые функции рядом, спека — на них.
- **Признак готовности:** `rt-table.component.ts` короче пятисот строк, отключение снято.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=src/lib/components/table` — 0 провалов.

## Чего эта работа не делает

- Не трогает `rt-design-tokens.ts`: собранный файл выведен из-под предела отдельным решением —
  его пишет сборщик, и делить его надо в сборщике.
- Не меняет ни одного входа, выхода и якоря проверки: это правка раскладки кода, а не поведения.

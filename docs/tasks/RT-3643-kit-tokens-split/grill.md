# Grill

Работа начата по слову владельца в эпике RT-3641; груза из приёмника нет.

## The owner request

> Выпуск `@rt-tools/ui-kit-v2` 0.52.0 заметно тяжелее 0.51.0, и два потребителя вышли за бюджет стартового пакета. Задача: найти, что утяжелило части кита, и вернуть вес без потери возможностей 0.52.0.

> «запускай task flow» — после плана, где `tokens.css` режется на файлы базы, пресета и тёмной темы.

## What the tree already has

- Глобальный `tokens.css` собирается `build:tokens-v2` из `tokens.package.scss` (вход `index`): слои, шрифты, назначения, набор Material, тёмная тема, местный кусок темы, плотность, полоса прокрутки, вход, форма, директивы.
- Измерение по частям (компиляция каждого партиала): местный кусок темы (`_theme-scope`) даёт около 461 КБ из 620 КБ, набор Material — около 23 КБ, тёмная тема — около 13 КБ. Первое утверждение плана эпика («пресет 384 КБ») относилось к блокам, где набор стоит в селекторах островов, а источником их является `_theme-scope`.
- Плотность (`_density`) и местный кусок темы объявляют общие свойства (`--rt-input-height`); плотность в полном файле стоит за ним и выигрывает местом.
- Сторож веса (RT-3642) уже измеряет все файлы `.css` из `dist/ui-kit-v2/styles`.

## What the rules already say

- Слой и порядок: `rt-tools-styling` — тёмная тема побеждает набор местом в файле, местный кусок стоит последним из наборов свойств.
- Поставка: полный `tokens.css` остаётся без изменений, чтобы существующие потребители не ломались.

## Questions and answers

Владелец подтвердил эпик и порядок словами «запускай task flow»; отдельных вопросов по этой задаче не задавалось: способ резки определён измерением.

## Decisions

- **Режутся два файла, а не три: `tokens.base.css` (без местных кусков темы) и `tokens.scope.css` (местные куски и плотность следом).** Набор Material остаётся в base: он весит 23 КБ и нужен любому узлу с `data-preset`, а тяжелы острова. Rejected: отдельный файл набора Material — на нём не сэкономить, основной вес в островах.
- **Файлы получаются разрезанием готового полного `tokens.css`, а не пересборкой.** Так полный файл остаётся побайтно прежним, а скрипт отказывает, если файл не складывается из головы, середины и хвоста. Rejected: две отдельные входные точки Sass — вывод партиалов, зависящих друг от друга, повторяется в каждом файле.
- **Плотность повторена в конце `tokens.scope.css`.** В полном файле она стоит за островами и выигрывает у них; без повтора при раздельной поставке выигрывал бы остров.

## What is left unclear

- Нужны ли потребителю острова: решает потребитель; в документации описан признак (тёмный или светлый узел внутри страницы другой темы, набор на узле под тёмной темой).

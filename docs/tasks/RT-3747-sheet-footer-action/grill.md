## Decisions

- **Эпик из трёх задач: сама шторка, шторки полей кита, асайд-шторка** — первая даёт места в шторке,
  две другие переводят на них потребителей. Rejected: одна задача — правка шторки и всех её
  потребителей одним PR, который владелец смотрит целиком.
- **Кнопка подвала шага `md` (40)** — так на одобренном макете. Rejected: `sm` (32) из прежней шапки.
- **«Сбросить» — значок `reset`, «Удалить» — нейтральная круглая кнопка, как «×»** — так на одобренном
  макете.
- **У шторки два новых места: `[sheetPrimary]` — главная кнопка подвала, `[sheetInfo]` — справка над
  ней; `[sheetAction]` остаётся местом справа в шапке для кнопок-значков** — потребители уходят на новые
  места своими задачами, и ни один не меняет вид, пока его задача не пришла. Rejected: перенести
  `[sheetAction]` в подвал — все поля кита сменили бы вид в этой задаче разом, без своих кадров.

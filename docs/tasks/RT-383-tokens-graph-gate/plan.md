## Что считается сделанным

- Проверка зелёная на текущем дереве и печатает числом: объявлено, ручек, принятых мёртвых
  ссылок.
- Пробы роняют прогон каждая своим сообщением: мёртвая ссылка вне списка, запасное значение у
  имени вне перечня ручек, объявление общего имени на корне из стилей компонента, имя из перечня
  ручек, которого нет в `Theming.mdx`.
- Тридцать три необъявленных имени разнесены поимённо: одиннадцать в перечень ручек, двадцать два
  в список принятого.
- `Theming.mdx` перечисляет ручки, и проверка сверяет оба перечня.
- `pnpm run lint:styles`, `pnpm run check:tokens-styles` и `pnpm run agent-kit:check` остаются
  зелёными.

## Этапы

### 1. Разбор графа и три состояния имени

- **Что делается:** `tools/check-tokens-graph.mjs` читает объявления и обращения по всем стилям
  кита, разводит имя на объявленное, ручку и мёртвую ссылку. Запасное значение, значением
  которого служит другой токен кита, считается ссылкой, а не литералом.
- **Признак готовности:** проверка печатает три числа, и их сумма сходится с замером
  договорённости.
- **Чем проверяется:** запуск; сверка с числами «Замеров».

### 2. Перечень ручек и список принятого

- **Что делается:** одиннадцать ручек уезжают в свой файл данных, двадцать два мёртвых имени — в
  список принятого; заводится отказ на записи, которой больше ничего не отвечает.
- **Признак готовности:** зелёный прогон, красный — на каждой из четырёх проб.
- **Чем проверяется:** пробы заводятся и снимаются в этой же ветке.

### 3. Объявление на корне из стилей компонента

- **Что делается:** правило разводит имена по префиксу блока: `--rt-<блок>-*` у своего блока
  проходит, общее имя — отказ. Сегодняшний отказ один — стили кнопки; он уезжает в список
  принятого, потому что чинит его позиция 6.
- **Признак готовности:** три законных объявления на корне проходят, четвёртое стоит в списке.
- **Чем проверяется:** прогон; чтение списка.

### 4. Имена, общие с первым китом

- **Что делается:** проверка держит сегодняшние девять имён списком и отбивает новое совпадение.
  Найденный по ходу дефект первого кита — он употребляет девять токенов второго, не объявляя их
  — заводится своей задачей, а не чинится здесь.
- **Признак готовности:** новое общее имя роняет прогон; девять сегодняшних — нет.
- **Чем проверяется:** проба с новым общим именем.

### 5. Перечень ручек в текстах и правило

- **Что делается:** `Theming.mdx` получает раздел с перечнем ручек; проверка сверяет его с
  данными. Надстройка `styling-bem` называет проверку и её данные.
- **Признак готовности:** имя, снятое из одного перечня, роняет прогон.
- **Чем проверяется:** проба; `pnpm run agent-kit:check`; `node tools/check-specs.mjs`.

## Чего эта работа не делает

- Не объявляет ни одного недостающего токена и не снимает ни одного запасного значения — это
  позиция 6 линии.
- Не чинит зависимость первого кита от токенов второго: заводит её задачей.
- Не трогает проверку литералов и её список.

## Что считается сделанным

- В правиле слога есть раздел о текстах, обращённых к владельцу: задача, описание заявки, ответ
  в чате.
- Паттерн при нём показывает форму этих трёх текстов на примерах — до и после.
- Правило называет паттерн строкой в разделе «Паттерны».
- Раскладка положила оба файла, сверка зелёная, тесты пакета зелёные.

## Этапы

### 1. Раздел правила и паттерн

- **Что делается:** четыре статьи о языке текстов для человека; паттерн с образцами.
- **Признак готовности:** раскладка кладёт оба ресурса, сверка молчит.
- **Чем проверяется:** `pnpm run agent-kit:sync`, `agent-kit:check`.

### 2. Спека и проверки

- **Что делается:** правила в спеке домена текстов, адреса в компаньоне, сценарий.
- **Признак готовности:** проверка спек и адресов зелёная, набор пакета зелёный.
- **Чем проверяется:** `node tools/check-specs.mjs`, `node tools/check-doc-paths.mjs`,
  `pnpm exec nx test @rt-tools/agent-kit`.

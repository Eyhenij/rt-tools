## Что считается сделанным

- Холодная часть правила о текстах называет молчаливую замену по шаблону и приём против неё.
- Правило проверяемости говорит: запись списка известного, которую больше ничто не вызывает,
  снимается вместе с вызвавшим её местом.
- Правило проверки в браузере говорит: экран, данных для которого в базе разработки не бывает,
  меряется настоящими стилями компонента.
- Компаньоны обоих правил называют, чем это держится здесь.
- Раскладка сходится, длина текстов в пределе, набор обвязки зелёный.

## Этапы

### 1. Ловушка о замене по шаблону

- **Что делается:** пункт в холодную часть правила о текстах
- **Признак готовности:** пункт стоит, раскладка сходится
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

### 2. Статья о мёртвой записи

- **Что делается:** статья правила проверяемости и её привязка
- **Признак готовности:** статья стоит, сверка спеков молчит
- **Чем проверяется:** `npm run check:specs` — молчание сверки

### 3. Статья об экране без данных

- **Что делается:** статья правила проверки в браузере и её привязка
- **Признак готовности:** статья стоит, сверка спеков молчит
- **Чем проверяется:** `npm run check:specs` — молчание сверки

### 4. Закрытие

- **Что делается:** набор обвязки, разбор папки задачи последним коммитом
- **Признак готовности:** папка разобрана, набор зелёный; заявка ждёт утра — владелец просил
  ветки наружу не отправлять
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

## Чего эта работа не делает

- Не заводит сверки мёртвых записей списка известного: у части списков проверка уже стоит, у
  части нет, и общего места под неё в пакете не заведено.

## Что считается сделанным

- Паттерн `task-flow-close` называет раздел тела PR как место, где живёт оставшийся шаг, и
  говорит, что произносить его вслух это не отменяет.
- Образец тела PR стоит во всех трёх видах `git-workflow-commit` и несёт этот раздел.
- Список проверок до публикации PR спрашивает раздел наравне со строкой связи.
- Паттерн прямо говорит, что тело PR не читает ни одна проверка, — второй исход задачи закрыт
  вместе с первым, а не вместо него.
- `pnpm run agent-kit:check` — нулевой код: разложенное в дереве сходится с пакетом.
- Тело PR самой этой задачи написано по новому образцу.

## Этапы

### 1. Раздел тела PR появляется в паттерне закрытия работы

- **Что делается:** в `projects/agent-kit/assets/patterns/task-flow-close.md`, раздел «10.
  Работа отдаётся на разбор», требование расширяется: оставшийся шаг пишется разделом в теле PR
  и произносится вслух — оба, а не одно вместо другого. Там же называется, чем это держится:
  тело PR не читает ни одна проверка.
- **Признак готовности:** в паттерне есть слова «тело PR» и образец самого раздела; статья про
  «вслух» осталась на месте.
- **Чем проверяется:** `grep -n "тело PR" projects/agent-kit/assets/patterns/task-flow-close.md`.

### 2. Образец тела PR заводится в трёх видах паттерна коммита

- **Что делается:** в каждый из `git-workflow-commit.github.md`, `…gitlab.md`, `…azure.md`
  добавляется раздел с цельным образцом тела: строка связи того вида хостинга, что сделано,
  чем подтверждено, оставшийся шаг. Список проверок до публикации получает пункт про раздел
  оставшегося шага.
- **Признак готовности:** образец стоит в трёх файлах, строка связи у каждого своя, счёт
  пунктов списка проверок сходится внутри каждого файла.
- **Чем проверяется:** `grep -c "Оставшийся шаг" projects/agent-kit/assets/patterns/git-workflow-commit.*.md`
  — по единице на файл и выше.

### 3. Раскладка и проверки дерева

- **Что делается:** `pnpm run agent-kit:sync` переносит правку в `.claude/skills/`; гоняется
  набор гейта пуша целиком, включая сверку спеков, проверку повторов и путей в документах.
- **Признак готовности:** `pnpm run agent-kit:check` нулевой; проверки текстов зелёные.
- **Чем проверяется:** `pnpm run agent-kit:check`, `node tools/check-specs.mjs`,
  `node tools/check-doc-paths.mjs`, `node tools/check-dupes.mjs`.

## Чего эта работа не делает

- **Не заводит проверку тела PR машиной.** Тело живого PR не читает ни одна проверка, и завести
  такую — отдельная работа с сетевым вызовом в гейте. Здесь это признаётся текстом, а не
  чинится.
- **Не переписывает тела уже открытых PR.** Образец действует со следующего.
- **Не выпускает новую версию пакета.** Выпуск идёт своим порядком, не этой веткой.
- **Не трогает задачу #754** — сценарии на обход гарда через оболочку. Она берётся следующей.

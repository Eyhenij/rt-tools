## Что считается сделанным

- Гард стоит на завершении хода и отбивает ход, в котором PR открыт, а действия по следующей
  задаче не было ни одного.
- Ход, в котором такое действие есть, гард пропускает.
- Гард не ходит в сеть и при любой своей поломке отпускает ход.
- Сценарии закрывают обе стороны, и снятие тела гарда роняет прогон.
- Правило ведения работы называет гард статьёй, а его разложенная копия сходится с пакетом.

## Этапы

### 1. Гард пишется ресурсом пакета

- **Что делается:** `projects/agent-kit/assets/hooks/waiting-turn-guard.sh` по образцу
  `proposal-guard.sh` — шапка `# rt-hook: Stop`, разбор записи хода через `jq`, признак
  открытия PR, признак действия по следующей задаче, отказ с готовым текстом.
- **Признак готовности:** `bash -n` на файле молчит; гард запускается вручную на рукописном
  вводе и отвечает отказом там, где должен.
- **Чем проверяется:** `bash -n projects/agent-kit/assets/hooks/waiting-turn-guard.sh`.

### 2. Сценарии закрывают обе стороны

- **Что делается:** набор `projects/agent-kit/tests/waiting-turn-guard.test.sh` по образцу
  соседних: ход с открытием PR и без действия — отбит; ход с открытием PR и заведением ветки —
  пропущен; повторный заход — пропущен; сломанный ввод — пропущен.
- **Признак готовности:** набор зелёный, а снятие разбора признака из тела гарда его роняет.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/agent-kit`, затем снятие признака руками и
  повторный прогон.

### 3. Гард встаёт в набор и правило называет его статьёй

- **Что делается:** гард попадает в умолчания раскладки, разложенная копия ложится в
  `.claude/hooks/`, `.claude/settings.json` зовёт его на `Stop`, правило ведения работы получает
  статью.
- **Признак готовности:** `pnpm run agent-kit:check` нулевой; гард стоит в `Stop` рядом с тремя
  соседями.
- **Чем проверяется:** `pnpm run agent-kit:check`, чтение `.claude/settings.json`.

## Чего эта работа не делает

- **Не спрашивает хостинг.** Признак берётся из записи хода; сетевой вызов на завершении хода
  падал бы вместе со связью.
- **Не судит ход, в котором PR не открывали.** Ход, не сделавший ничего, гардам неотличим от
  хода, которому нечего было делать, — это записано в правиле и здесь не чинится.
- **Не объявляет набор образцов полным.** Он пополняется правкой, как у соседних гардов.
- **Не трогает задачу #754** — сценарии на обход гарда через оболочку. Она берётся следующей.

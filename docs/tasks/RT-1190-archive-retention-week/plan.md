# Замысел

**Задача:** RT-1190 · **Ветка:** RT-1190-archive-retention-week
**Поведение:** не меняется — правка задевает описание прошлого, обвязку дерева и тексты правил; кода приложения в ней нет

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## След задачи

| Что     | Где                                                                                                |
| ------- | -------------------------------------------------------------------------------------------------- |
| Спеки   | не задеты — срок хранения груза приёмника это не трогает                                           |

| Код     | `tools/`, `package.json`, `.claude/rt-kit/project.sh`, `.github/workflows/ci.yml`                  |

`doc-style` и `task-flow-archive` приезжают пакетом правил: их правка идёт надстройкой в
`.claude/rt-kit/overrides/`, а не в разложенную копию. `archive-record` — скил этого дерева и
правится прямо.

## Что считается сделанным

- В `docs/archive/` нет записи старше недели: `node tools/check-archive-age.mjs` отвечает
  нулевым кодом и называет число проверенных записей.
- Команда чистки снимает перестоявшие записи и называет каждую снятую по имени.
- Проверка стоит в наборе гейта пуша и шагом конвейера — не в одном из двух.
- Скил записи о закрытой работе называет срок и то, где запись остаётся после снятия.

## Этапы

### 1. Команда чистки

- **Что делается:** `tools/archive-prune.mjs` снимает записи старше срока; возраст берётся
  датой последнего коммита файла. Сухой прогон — умолчание, снос — явным доводом.
- **Признак готовности:** сухой прогон называет 67 записей и не трогает ни одной.
- **Чем проверяется:** `node tools/archive-prune.mjs` — печатает список и строку о том, что
  это сухой прогон; `git status --short` после него пуст.

### 2. Проверка возраста

- **Что делается:** `tools/check-archive-age.mjs` краснеет на записях старше срока; строки в
  `package.json`, в наборе гейта `rt_push_checks` и шагом конвейера.
- **Признак готовности:** до чистки проверка красная и называет число, после — зелёная.
- **Чем проверяется:** `node tools/check-archive-age.mjs` — до чистки ненулевой код и
  «расхождений 67», после чистки нулевой код и число проверенных записей.

### 3. Разовая чистка

- **Что делается:** команда сносит перестоявшие записи, снос едет коммитом.
- **Признак готовности:** в дереве 213 записей, все моложе недели.
- **Чем проверяется:** `ls docs/archive/*.md | wc -l` — 213; `node tools/check-archive-age.mjs`
  — нулевой код.

### 4. Тексты

- **Что делается:** срок называется в скиле `archive-record`; надстройки над пакетными
  текстами — там, где они обещают вечное хранение.
- **Признак готовности:** ни один текст дерева не обещает, что запись лежит вечно.
- **Чем проверяется:** `npm run check:docs` и `pnpm run agent-kit:check` — нулевой код у обеих.

## Чего эта работа не делает

- **Не трогает срок хранения груза приёмника** — это `Q-17` его спека, открытый вопрос домена.
- **Не переносит записи на борду** — решение владельца: истории системы контроля версий хватит.
- **Не заводит указателя каталогу** — его здесь нет намеренно, и чистка этого не меняет.
- **Не чистит `docs/postmortems/`** — разборы происшествий описанием прошлого не являются и под
  просьбу не подпадают.

## Этапы

### 1. Абзац о чужом и своём разборе

- **Что делается:** в раздел состояния дописывается абзац: имя говорит о разборе папки, признак
  наступает в дереве, одобрения ждать не нужно.
- **Признак готовности:** абзац стоит первым в разделе, до порядка действий.
- **Чем проверяется:** `node tools/check-file-size.mjs` — файл паттерна не назван.

### 2. Раскладка

- **Что делается:** пакет собирается, ресурс раскладывается в дерево.
- **Признак готовности:** раскладка совпадает с источником.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет.

# Grill

## The owner request

Работа поручена сессией разбора приёмника, владелец её не писал. Текст поручения:

> При запуске `claude -p --agent product-strategist` проверка конца хода `turn-exit-guard` не
> отпускала роль: правки ей запрещены, поэтому «работы» в ходе нет, а слова владельца о стопе тоже
> нет. Роль 21 ход разбиралась с отказом, и её итоговое сообщение вытеснило отчёт с таблицей точек.
> Это мешает работе всех ролей только для чтения, вызванных отдельной сессией.
>
> Сделать так, чтобы роль без `Write` и `Edit`, запущенная как основная через
> `claude -p --agent <роль>`, могла законно закончить ход отчётом. Готово, когда есть сценарий с
> номером от `pnpm run spec:next-id`, тест проходит, а запуск роли завершается с её отчётом в
> итоговом сообщении. Работа идёт отдельной задачей эпика с PR.

## What the tree already has

- В данных события Stop при `--agent` стоит поле `agent_type` с именем роли. Проба на `claude`
  2.1.311 в пустом дереве: `"agent_type":"probe-role"`. Подроль через инструмент Agent вызывает
  `SubagentStop`, на него проверка не подписана.
- `turn-exit-guard.sh` поле не читает: в файле и его соседях нет ни `agent_type`, ни `agent_id`.
- Роли лежат в `.claude/agents/<имя>.md`, строка `tools:` стоит в заголовке каждой. Сценарии
  SC-AK-1160 и SC-AK-1138 уже держат эту строку у ролей пакета.
- `turn-exit-guard.sh` занимает 498 строк при пределе 500, поэтому чтение роли уходит в соседний файл.

## What the rules already say

- Правило `turn-conduct` называет четыре выхода из хода для исполнителя. Роли только для чтения оно
  не касается: у неё нет работы, которую можно довести.
- Закон о ходе работы не менялся: правка меняет только то, кого судит проверка.

## Questions and answers

Владельцу вопросы не задавались, поручение пришло от другой сессии.

**Какой эпик?**
RT-3129. Роль `product-strategist` появилась в его задаче RT-3133 (#3134), в таблице назначений на
ветках эпика стоит RT-3129, а запись памяти «Какой эпик в работе» говорит, что этот эпик владелец
дал в работу.

**Одна задача или несколько?** Одна: откат идёт одной правкой.

**Что не входит?** Другие проверки конца хода. `claim-guard` судит слова отчёта и своё дело делает.

## Decisions

- **Роль узнаётся по `agent_type` и файлу роли.** Поле ставит сам клиент, исполнитель его не пишет.
  Отвергнуто: признак в тексте хода и переменная окружения в команде запуска. Их надо не забыть, и
  роль снова застрянет.
- **Только-для-чтения значит: строка `tools:` есть и в ней нет `Write`, `Edit`, `MultiEdit`,
  `NotebookEdit`.** Роль без строки и `tools: *` получают все инструменты, такую роль проверка судит
  как раньше. `Bash` не считается: он нужен ролям для чтения, а признак берётся из заголовка роли.
- **Роль отпускается раньше всех ярусов, и при втором проходе, и при открытом эпике.** Круг из 21
  хода шёл именно при открытом эпике: без него второй проход отпускается сам.

# Замысел

**Поведение:** не меняется — правится холодная часть правила ведения работы.

## Что делается

1. В раздел ловушек холодной части встают два пункта: указание работать по ходу — это указание
   делать его шаги, включая меняющие историю; строка ожидания живёт дольше причины, по которой
   её написали.
2. Первый пункт называет границу: прямое слово владельца сильнее хода, и запрет именно на этот
   шаг остаётся запретом.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

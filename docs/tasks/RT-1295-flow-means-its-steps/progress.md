# Где стоим

- **Состояние:** `этапы-кончились`
- **Задача:** RT-1295 — указание работать по ходу и пережившее ожидание

## Сделано

- Разбор груза закрыт: одна запись, два промаха одного захода.
- В холодную часть правила ведения работы встали две ловушки: указание работать по ходу — это
  указание делать его шаги, и строка ожидания живёт дольше своей причины.
- Первая называет границу: прямое слово владельца о самом шаге сильнее хода.
- Прогоны зелёные: раскладка, наборы оболочки, длина файлов, адреса документов.

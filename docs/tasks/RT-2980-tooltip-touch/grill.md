# Grill

## The owner request

> Чинить в ките (Рекомендую)

Ответ владельца 28.10.2026 на вопрос о подсказке кольца расхода в VillaManager: на телефоне она не
открывается, нажатие её закрывает. Следом: «Бери RT-2980: ветка в rt-tools, правка подсказки на
сенсорном экране, тест витрины, выпуск 0.35.1.»

## What the tree already has

- `[rtTooltip]` показывает подсказку по `mouseenter` и фокусу с клавиатуры с задержкой, клик снимает
  отложенный показ.
- Поддомен `docs/specs/ui-kit-v2/tooltip-keep-on-click/` (RT-2788) записал: касание подсказку не
  показывает при любом значении `rtTooltipHideOnClick`.
- `rt-usage-ring` вешает `[rtTooltip]` на кольцо с ролью `img`; своего действия у кольца нет.

## What the rules already say

Статья RT-2788 «касание подсказку не показывает» держит кнопки: их касание выполняет действие.
Менять её смысл без владельца нельзя, поэтому вопрос задан до правки.

## Questions and answers

**Какие подсказки открываются нажатием на телефоне?**
«Только у элементов без действия (Рекомендую)»

## Decisions

- **Новый вход `rtTooltipShowOnTap`, умолчание `false`; кольцо расхода ставит его само** — так
  кнопки по касанию срабатывают по-прежнему. Rejected: касание открывает все подсказки кита, на
  кнопке подсказка закрыла бы результат нажатия.

## What is left unclear

- Сквозного набора у витрины кита нет. Касание на WebKit с профилем iPhone проверяет сквозной тест
  VillaManager SC-AS-128 после подъёма кита.

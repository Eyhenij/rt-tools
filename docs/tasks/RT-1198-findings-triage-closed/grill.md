# Разбор просьбы

## Просьба владельца

> бери следующие задачи из бэклога по порядку начиная с самой свежей

Самая свежая незакрытая задача очереди — RT-1198, карточка эпика «Находки закрытых эпиков
разобраны». Груза приёма у этой работы нет: она заведена своим эпиком.

## Что уже есть в дереве

Замысел эпика — `docs/plans/findings-triage.md`: пятнадцать задач, порядок по цене промаха и
признак закрытия — ноль неразобранных пунктов в шести файлах находок.

Все пятнадцать задач эпика — RT-1199…RT-1213 — закрыты. Шесть файлов находок читаются целиком:
в каждом разделе стоит строка о том, чем пункты кончились, — номером задачи, правкой ресурсов
или доводом, почему пункт отпал. Свой файл находок эпика — `findings-triage-findings.md` —
кончается строкой «Неразобранного по этому эпику не осталось».

## Что уже сказано в правилах

Правило ведения работы: эпик кончается словом владельцу, а не молчаливым закрытием карточки;
замысел эпика получает раздел о том, чем эпик кончился и что он оставил открытым.

## Решения

- **Работа — закрытие эпика, а не новый разбор.** Пункты разобраны пятнадцатью задачами; здесь
  сверяется признак закрытия и пишется, чем эпик кончился.
- **Файлы находок остаются на месте.** Они говорят, чем кончился каждый пункт, и снятые они
  унесли бы этот ответ вместе с собой.

## Что осталось невыясненным

- Находки эпика RT-733 сюда не входили и разбираются вместе с его последней задачей.

# Замысел

**Поведение:** не меняется — правится текст закона о проверяемости.

## Что делается

1. В раздел статей встаёт статья: проговорённый список проверок проверкой не бывает, потому что
   называет замысел, а не то, что ушло в команду.
2. Статья называет, что проверкой считается: чтение полученного — вывод команды, содержимое
   отданного текста, состояние после вызова.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

# Grill

Записей приёмника у задачи нет: промах найден по ходу эпика RT-2674.

## The owner request

> бери замечания и предложения из приёмника - заводи задачи, разбивай их по эписка и бери в работу по очереди

> бери RT-2681

## What the tree already has

- Проверка конца эпика пропускает вызов, когда сообщение владельца или его ответ в меню
  называет номер работы (SC-AK-1201). Ответ меню она узнаёт только по началу «The user
  answered:».
- Проверка разбора узнаёт ответ меню по тому же началу, когда считает два ответа
  «рекомендованный» подряд (SC-AK-1134).
- Настоящий ответ меню приходит в двух видах: «The user answered: …» и «Your questions have been
  answered: …». После него идут пары `"вопрос"="ответ"`.
- Номер ищется во всём тексте ответа, вместе с вопросом исполнителя.

## What the rules already say

Правило `task-flow`: новую работу после конца эпика берут по слову владельца — его сообщению
или ответу в меню, который называет номер. Слова исполнителя не считаются.

## Questions and answers

Вопросов владельцу нет: задача чинит проверку под уже записанное правило.

## Decisions

- **Обе проверки узнают оба вида ответа меню.** Один вид пропускал ответ владельца, и работа
  стояла до повторного сообщения. Отклонено: искать слово «answered» где угодно — так совпадёт
  любой текст результата команды.
- **Номер ищется только в ответах, а не в тексте вопроса.** Вопрос пишет исполнитель, и номер в
  нём не слово владельца. Отклонено: искать во всём тексте — так меню «Бери RT-N?» с ответом
  «нет» пропускало бы вызов.

## What is left unclear

- Ответ в свободной форме с кавычками внутри обрежется на первой кавычке. Номер в начале ответа
  это не задевает.

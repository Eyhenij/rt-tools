## Что считается сделанным

- Правило о документации проекта говорит: расхождение правила и его компаньона решается в
  пользу правила, а найденное расхождение называется владельцу.
- То же правило говорит: утверждение компаньона о состоянии внешней службы проверяется
  командой, которую он сам называет.
- Компаньон правила называет, чем это держится здесь.
- Длина правила в пределе текста, раскладка сходится, набор обвязки зелёный.

## Этапы

### 1. Две статьи о компаньоне

- **Что делается:** статья о старшинстве правила и статья о старении утверждения о службе
- **Признак готовности:** обе статьи стоят с привязками, длина правила в пределе
- **Чем проверяется:** `npm run check:specs` — молчание сверки

### 2. Закрытие

- **Что делается:** раскладка, набор обвязки, разбор папки задачи последним коммитом
- **Признак готовности:** папка разобрана, набор зелёный; заявка ждёт утра — владелец просил
  ветки наружу не отправлять
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом

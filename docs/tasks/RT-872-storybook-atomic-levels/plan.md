## Что считается сделанным

- Заголовок каждой истории компонента начинается уровнем — атомы, молекулы или организмы, — за
  которым идёт необязательная предметная группа и имя компонента.
- Страница обзора компонента стоит под тем же заголовком, что и его истории.
- Порядок разделов сайдбара задан в `preview.ts` перечислением уровней; раздел основ остаётся
  первым.
- Ни один эталон снимка не переснят: все 447 файлов переименованы, содержимое прежнее.
- Правило витрины и его паттерн называют новый порядок сайдбара и новый образец заголовка.

## Этапы

### 1. Раскладка компонентов по уровням

- **Что делается:** все 84 компонента разносятся по трём уровням и предметным группам, список
  показывается владельцу до правки файлов.
- **Признак готовности:** владелец утвердил список; спорные названы отдельно и решены.
- **Чем проверяется:** ответ владельца.

### 2. Заголовки историй и страниц обзора

- **Что делается:** в 155 файлах историй и 73 страницах обзора заголовок переписывается по
  утверждённой раскладке.
- **Признак готовности:** поиска по прежней приставке заголовка в дереве витрины не находит
  ничего.
- **Чем проверяется:** `grep` по `projects/ui-kit-v2`; сборка витрины
  `pnpm run build-storybook:ui-kit-v2`.

### 3. Порядок сайдбара

- **Что делается:** `storySort` в `preview.ts` перечисляет уровни в порядке «основы, атомы,
  молекулы, организмы».
- **Признак готовности:** дерево сайдбара в браузере совпадает с утверждённой раскладкой.
- **Чем проверяется:** витрина поднята, снимок дерева сайдбара.

### 4. Эталоны снимков

- **Что делается:** 447 файлов эталонов переименовываются по новому слагу заголовка.
- **Признак готовности:** прогон снимков зелёный, пересъёмки не было; ни одного эталона без
  истории и ни одной истории без эталона.
- **Чем проверяется:** прогон снимков витрины со сверкой каталога эталонов.

### 5. Правило витрины и его паттерн

- **Что делается:** правило и паттерн приводятся к сделанному — порядок сайдбара и образец
  заголовка истории.
- **Признак готовности:** в обоих текстах нет прежней приставки заголовка.
- **Чем проверяется:** `grep` по `.claude/skills`; `npm run check:specs`.

### 6. Полный набор проверок

- **Что делается:** гоняется `pnpm run check:all` и сборка витрины.
- **Признак готовности:** всё зелёное.
- **Чем проверяется:** вывод команд.

## Чего эта работа не делает

- Первый кит не трогает: его витрина и её эталоны остаются как есть.
- Файлы и папки компонентов не двигает — меняется только заголовок истории.
- Состав историй не меняет: ни новых историй, ни добора покрытия.
- Раздел основ по уровням не разводит.

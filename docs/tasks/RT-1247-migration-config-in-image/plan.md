# Замысел

**Поведение:** не меняется — правится текст паттерна, ни одной проверки и ни одного гарда
задача не трогает.

Раздел «Частые промахи» паттерна миграций говорит о порядке цепочки, о флагах и о записи в
боевую базу и молчит о том, чем накат настраивается внутри образа.

## Этапы

1. Первый пункт раздела «Частые промахи».
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Статью закона и статью правила выкатки об этом же задача не трогает: они записаны отдельной
работой и говорят об артефакте вообще, а здесь — про накат и его файл настройки.

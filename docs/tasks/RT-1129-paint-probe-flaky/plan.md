## Что считается сделанным

- Проба, запущенная подряд несколько раз на неправленом дереве, отвечает зелёным каждый раз.
- Проба на дереве со снятым ожиданием отрисовки отвечает красным.
- Отказ называет, сколько пар снято и что все они совпали.

## Этапы

### 1. Мерцание измерено

- **Что делается:** витрина поднимается, проба гоняется подряд десять раз, считается, на скольких
  прогонах ранний кадр совпал с поздним.
- **Признак готовности:** известна доля совпадений и, значит, число пар, при котором отказ
  перестаёт быть случайным.
- **Чем проверяется:** `for i in $(seq 10); do node tools/snapshot-paint-probe.mjs; done` —
  доля красных ответов и есть замер.

### 2. Проба судит по нескольким парам

- **Что делается:** браузерная половина снимает пары до тех пор, пока не разойдётся, но не
  больше назначенного числа; отказ приходит, только когда совпали все.
- **Признак готовности:** десять прогонов подряд отвечают зелёным.
- **Чем проверяется:** `for i in $(seq 10); do node tools/snapshot-paint-probe.mjs; done` —
  десять зелёных.

### 3. Отказ проверен обратной стороной

- **Что делается:** ожидание отрисовки временно снимается из обвязки, проба гоняется.
- **Признак готовности:** проба отвечает красным и называет причину.
- **Чем проверяется:** `node tools/snapshot-paint-probe.mjs` — красный ответ на снятом
  ожидании, зелёный после возврата.

### 4. Работа отдана

- **Что делается:** папка задачи разбирается, заявка открывается черновиком.
- **Признак готовности:** ветка папки не везёт, заявка открыта.
- **Чем проверяется:** `node tools/check-push-gate.mjs` — гейт пуша не отбивает.

## Чего эта работа не делает

- Не трогает саму обвязку снимков и ни один эталон.
- Не выносит браузерную половину пробы из гейта пуша в конвейер.
- Не трогает пробу второй витрины.

## Что считается сделанным

- Ни одного точечного отключения `sonarjs/function-name` в ките не осталось.
- Ни `\.Open(`, ни `Value` как публичного имени в дереве нет.
- Ломающая правка названа в журнале с переходом.

## Этапы

### 1. Имена приведены к соглашению

- **Что делается:** `Open` → `open`, `get/set Value` → `get/set value`, вызовы и разметка
  правятся тем же движением; отключения снимаются.
- **Признак готовности:** линт кита без единого `function-name`.
- **Чем проверяется:** `pnpm exec nx run @rt-tools/ui-kit:lint --skip-nx-cache` — 0 отказов.

### 2. Переход назван в журнале, поведение закрыто пробами

- **Что делается:** в неизданный раздел журнала дописывается ломающая правка с прежними и
  новыми именами; пробы кита гоняются целиком.
- **Признак готовности:** пробы зелёные, сборка проходит.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit` — 0 провалов; `pnpm exec nx build @rt-tools/ui-kit` — сборка проходит.

## Чего эта работа не делает

- Не поднимает версию пакета и ничего не публикует: это отдельное решение владельца.
- Не заводит псевдонимов под прежними именами: у символа одно имя.

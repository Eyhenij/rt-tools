## Что считается сделанным

- Таблица называет каждый из 84 хуков пакета: строки решений у тех, кто решает, пометка
  «помощник» или «модель» у остальных. Помощник проверен запуском: на входах фикстур он не отказывает.
- Каждая строка с решением совпадает с решением самого хука, запущенного на фикстуре её фактов.
- Перебор идёт по фактам одной области хуков (git, ход работы, браузер, правила, ход сессии), и число
  состояний названо; состояния без разрешённого хода нет.

  состояния есть случай, где сам вопрос не запрещён.
- Каждый отказ таблицы называет ход, и в том же состоянии таблица этот ход разрешает.
- Цепочки выводятся из таблицы; каждая записана сценарием подобласти `decision-table`, начиная с
  SC-AK-1562, и случаем теста.

## Как идёт работа

- **Чтение журнала** — построчно. Строка без разбора пропускается и считается. Запись с уже виденным `uuid` второй раз не считается, набор `uuid` общий на запуск: копии одной сессии лежат в нескольких каталогах.
- **Промежуток** между двумя соседними событиями целиком относится к одной категории по тому, чем он закончился. Промежутки считаются внутри одного журнала, итоги журналов складываются: две сессии внахлёст дают сумму, перерыв между сессиями не считается.
- **Категории:** ответ модели, результат инструмента по виду команды, крючки Stop, меню или сообщение владельца, уведомление о фоне. Уведомление, пришедшее ответом субагента, — ожидание субагентов любой роли; иначе по тому, что шло в фоне, субагент важнее набора. Прочие записи пользователя и системы идут в «Правки и команды», как в исходном измерении.
- **Доли** считаются от активного времени — без ожидания владельца.
- **Шаги** узнаются по журналу: группа ролей ревью с разрывом до трёх минут; без `qa-engineer` — чтение плана, первая с ней — круг один, вторая — круг два; конец группы — последний ответ её участника. Ветка без двух кругов, набора и вызова PR в шаги не входит. Медиана — по веткам полного хода, минуты без владельца.
- **Среднее по веткам** — `--branches` с ключами; ключ без ветки отказывает.
- **Вывод** — числа, категории и названия веток. Текстов сообщений и команд в выводе нет.

# Замысел

**Поведение:** не меняется — сверка отбивает то же и теми же строками; прибавляется строка
сводки, кода возврата она не меняет.

## Что делается

Открытые задачи с сильно совпадающими заголовками перечисляются строкой сводки: совпадение слов
— повод посмотреть, а не признак дубля. Отказ здесь отбивал бы работу на каждой серии однотипных
задач эпика.

Сравниваются значимые слова заголовка без ключа задачи; порог — большинство слов меньшего
заголовка и не меньше трёх общих слов.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run check:board`, `npm run agent-kit:sync`,
`npm run agent-kit:check`.

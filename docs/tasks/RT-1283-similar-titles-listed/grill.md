# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `checks/check-board.github.mjs`. Отметить
её этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт
здесь.

## Дубль в очереди не находит ничто

Обе задачи по отдельности исправны: у каждой номер в заголовке, исполнитель и колонка, и сверка
очереди обе принимает. Разошлись они только словами заголовка, а совпадали дефектом, механизмом
и признаком закрытия. По дублю прошла вся работа целиком, и сводить две задачи в одну пришлось
руками.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

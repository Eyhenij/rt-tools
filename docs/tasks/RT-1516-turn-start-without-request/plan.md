# Замысел

**Задача:** RT-1516 · **Ветка:** RT-1516-turn-start-without-request
**Поведение:** не меняется — правится слой правил и его гарды, кода приложений работа не
задевает.

| Спеки      | `docs/specs/agent-kit/turn-guards/`                   |

| Пробы      | `projects/agent-kit/tests/`                           |

## Этапы

1. **Гард.** Хук события `Stop`: ход, правивший каталоги приложений и либ, при последней реплике
   владельца без просьбы — отбивается. Просьба ловится набором образцов; отказ в пользу работы.
   Готово, когда сценарии набора зелёные.
2. **Объявление и раскладка.** Гард назван ресурсом пакета, объявлен правилом строкой
   «Требует», разложен в дерево и стоит в настройке хуков. Готово, когда `agent-kit:check`
   расхождений не находит.
3. **Закрытие.** Сценарии заведены в спек домена гардов, тексты приведены, набор прогнан, папка
   разобрана, заявка открыта черновиком.

## Что не входит

- Понимание смысла реплики: просьба ловится образцами.
- Правка соседних гардов: каждый судит своё.

## Что считается сделанным

- `git checkout -q -b` судится гардом поставки так же, как `git checkout -b`: имя ветки,
  основание, подпись.
- Гарды спора заявок, набора пуша, ожидания и завершения хода узнают ту же форму.
- На каждую форму есть проба.

## Этапы

### 1. Образец с флагами во всех гардах

- **Что делается:** пять гардов принимают флаги между `checkout` и `-b`, `switch` и `-c`.
- **Признак готовности:** `git checkout -q -b RT-9-GuestToken` отбивается формой имени.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — все наборы зелёные.

### 2. Пробы на форму с флагом

- **Что делается:** в наборах гардов поставки, спора заявок, набора пуша и завершения хода
  появляется проба с флагом.
- **Признак готовности:** проба краснеет на прежнем образце.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — все наборы зелёные.

## Чего эта работа не делает

- Гарда эпика в пакете нет; образец дерева-отправителя — его дело.

# Замысел

**Задача:** RT-203 · **Ветка:** RT-203-publish-lockfile-sync
**Поведение:** не меняется — правятся конвейеры публикации, кода пакетов работа не трогает.

## След задачи

| Что       | Где                                |
| --------- | ---------------------------------- |
| Конвейеры | `.github/workflows/publish*.yml`   |
| Код       | `tools/check-publish-lockfile.mjs` |
| Пробы     | `projects/agent-kit/tests/`        |
| Команды   | `package.json`                     |

## Что считается сделанным

- Шаг обновления версии каждого конвейера публикации пересобирает замок зависимостей.
- Проверка называет конвейер публикации, у которого этой пересборки нет, и роняет прогон.
- Проверка находит конвейеры сама по каталогу, а не списком имён: заведённый копией седьмой
  судится наравне с шестью.
- Набор проб красен, когда пересборку снимают хоть из одного конвейера.

## Этапы

### 1. Пересборка замка в шаге обновления версии

- **Что делается:** во все шесть конвейеров публикации дописывается пересборка замка сразу за
  дописыванием журнала — до шага, который кладёт заявку.
- **Признак готовности:** ни одного конвейера публикации без этой строки.
- **Чем проверяется:** `grep -c 'lockfile-only' .github/workflows/publish*.yml` — по строке на
  каждый из шести файлов.

### 2. Проверка, которая это держит

- **Что делается:** пишется `tools/check-publish-lockfile.mjs` — обход каталога конвейеров, отбор
  публикующих, суд над шагом обновления версии.
- **Признак готовности:** проверка зелена на дереве и красна, если пересборку снять.
- **Чем проверяется:** `node tools/check-publish-lockfile.mjs` — кодом 0 и строкой о числе
  проверенных конвейеров.

### 3. Проба и место в гейте

- **Что делается:** набор проб на дереве-фикстуре и команда дерева рядом с прочими проверками.
- **Признак готовности:** набор зелёный; снятая строка роняет его.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-publish-lockfile.test.sh` — строка
  «0 провалов».

## Чего эта работа не делает

- Живой публикации: её запускает владелец руками, и ночью наружу не уходит ничего.
- Правки конвейера сборки и выкатки — они версий не поднимают и замка не двигают.

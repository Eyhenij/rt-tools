## Этапы

### 1. Находки эпика сведены и названы владельцу

- **Что делается:** шесть находок RT-793 из файла находок и открытые задачи с меткой
  `agent-kit-feedback` сводятся в один список: что предлагается, чему адресовано.
- **Признак готовности:** владелец видит список целиком и знает, что каждая из находок ждёт
  его слова.
- **Чем проверяется:** пересчёт по файлу находок и по выборке задач с меткой.

### 2. Линия уезжает в описание прошлого

- **Что делается:** замысел эпика и его находки становятся одной записью
  `docs/archive/tree-checks-debt-line.md`; оба файла из `docs/plans/` удаляются.
- **Признак готовности:** запись называет день закрытия, шесть задач порядка с их итогами и
  номера задач, которыми продолжено оставшееся; прежние адреса обоих файлов названы в шапке.
- **Чем проверяется:** `npm run check:docs`, чтение указателя архива.

### 3. Указатель архива знает запись

- **Что делается:** строка о новой записи встаёт в таблицу `docs/archive/README.md`.
- **Признак готовности:** запись без строки и строка без записи одинаково отсутствуют.
- **Чем проверяется:** `npm run check:docs`.

### 4. Карточка эпика закрыта

- **Что делается:** задача #806 закрывается с пояснением, чем эпик кончился и где теперь его
  описание.
- **Признак готовности:** задача закрыта, пояснение называет запись архива.
- **Чем проверяется:** ответ очереди работ по номеру.

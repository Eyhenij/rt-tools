# Замысел

Задача: #339. Ветка: `RT-339-archive-closed-task-folders`.

**Задача:** RT-339 · **Ветка:** RT-339-archive-closed-task-folders
**Драфт:** не требуется
**Поведение:** не меняется — переезд документов, снаружи не видно. Подтверждено владельцем.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Каталог `docs/archive/` заведён и имеет README: что сюда попадает, что нет, строка на
  каждую запись.
- Шесть папок закрытых задач разобраны: `grill.md` каждой уехал в архив, `progress.md` — по
  признаку из правила, `plan.md` удалён.
- Каждая запись архива называется `RT-<номер>-<slug>.md` и лежит одним файлом, а не папкой.
- `npm run check:board` не называет ни одной папки закрытой задачи среди текущих.
- `npm run check:docs` зелёный: ни один текст дерева не ссылается на уехавший путь.
- В отчёте показано, по какой папке `progress.md` уехал, а по какой удалён, и почему.

## Этапы

### 1. Каталог архива и его README

- **Что делается:** заводится `docs/archive/` с `README.md`: что сюда попадает (то, что
  объясняет состоявшееся решение), что нет (ходы работы без решений, замыслы), форма имени
  записи и строка-указатель на каждую. Указатель заполняется по мере переезда.
- **Признак готовности:** README существует, форма имени в нём названа, раздел указателя
  заведён.
- **Чем проверяется:** `npm run check:docs`.

### 2. Разбор шести папок

- **Что делается:** каждая из шести папок читается целиком. `grill.md` уезжает в
  `docs/archive/RT-<номер>-<slug>.md` всегда. `progress.md` дописывается в тот же файл, если
  в нём есть решения по ходу с причинами; иначе удаляется. `plan.md` удаляется. Папка
  удаляется целиком, строка о записи добавляется в указатель README.
- **Признак готовности:** шесть записей в архиве, шести папок в `docs/tasks/` нет, каждая
  запись несёт слова владельца из своего разбора.
- **Чем проверяется:** `npm run check:board` — по папкам молчит; чтение владельцем на ревью.

### 3. Тексты, ссылающиеся на уехавшие пути

- **Что делается:** греп по дереву на пути шести папок; найденные ссылки правятся на путь
  записи в архиве или снимаются, если ссылались на ход работы.
- **Признак готовности:** ни один текст не ведёт в удалённую папку.
- **Чем проверяется:** `npm run check:docs`, `grep -rn 'docs/tasks/RT-3'`.

## Чего эта работа не делает

- Не правит гард папки задачи и правила: гард стоит, а ярус на слияние через веб — задача
  #338.
- Не трогает 31 расхождение сверки очереди, не относящееся к папкам: долг задачи #318.
- Не редактирует переезжающие тексты: архив описывает день переезда и правится только вместе
  с признанием, что описывал неверно.
- Не выпускает пакет в реестр — отдельным запуском позже.

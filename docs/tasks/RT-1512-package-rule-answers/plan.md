## Этапы

1. **Сверка семьи.** Каждая из семи записей читается вместе с местом, которое называет.
   Готово, когда о каждой сказано, закрыта она или жива.
2. **Правка живого.** Живое ложится в свой раздел. Готово, когда сверки сходятся.
3. **Закрытие.** Папка разобрана, заявка открыта черновиком на вершине череды.

## Что не входит

- Пятьдесят шесть записей приёма по другим предметам.

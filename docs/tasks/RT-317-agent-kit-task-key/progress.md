## Решения по ходу

- **Ветка заведена прежней формой и переименована после правки профиля.** Гард имени ветки — то
  самое, что чинится этой работой, и новую форму он отбивал; а править профиль на главной ветке
  не даёт гард замысла. Круг разомкнут заходом через законную на тот момент форму
  `chore/317-…` с немедленным `git branch -m`. Затронутый этап замысла: 1.
- **Заголовки отчётов не трогались.** Владелец выбрал охват «все issue репозитория»; отчёты в
  него не входят. Сверка очереди судит заголовки только у открытых отчётов, а таких сейчас нет.
  Затронутый этап замысла: 1.

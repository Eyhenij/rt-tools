## Этапы

### 1. Тёмный ответ в источнике

- **Что делается:** объявлению `--rt-color-bg-surface-subtle-2` в `tokens.source.mjs`
  дописывается поле `dark: var(--rt-charcoal-950)` — тем же видом, что у соседней ступени
  `--rt-color-bg-surface-subtle`.
- **Признак готовности:** источник несёт светлое значение и тёмный ответ в одном объявлении.
- **Чем проверяется:** чтением объявления; строка `dark` стоит рядом со своим `value`.

### 2. Пересборка слоя оформления

- **Что делается:** `pnpm run build:tokens-source`; собранный `_theme-dark.scss` получает
  строку объявления в миксине `rt-theme-dark-tokens`.
- **Признак готовности:** в собранном файле есть строка объявления, и руками он не правился.
- **Чем проверяется:** `pnpm run check:tokens-build` — зелёный.

### 3. Запись из списка принятого снята

- **Что делается:** из `tools/tokens-theme-allowlist.json` убирается ключ
  `молчит --rt-color-bg-surface-subtle-2`. Соседние записи не трогаются — они про RT-394.
- **Признак готовности:** список убыл ровно на одну запись.
- **Чем проверяется:** `pnpm run check:tokens-theme` — зелёный, и в его сводке число принятых
  списком уменьшилось на единицу.

### 4. Проверка глазами и замером

- **Что делается:** витрина в тёмной теме, замер вычисленного значения трека переключателя;
  прогон кадров витрины.
- **Признак готовности:** трек даёт `#17181c` (`rgb(23, 24, 28)`), кадры не разошлись.
- **Чем проверяется:** замер в браузере по правилу `browser-verification`; прогон снимков
  витрины.

### 5. Тексты приведены к сделанному

- **Что делается:** в `docs/specs/ui-kit-v2/spec.md` правятся счётчики — ответов тёмной темы
  и принятых списком; дописывается запись в раздел изменений.
- **Признак готовности:** числа в спеке совпадают с выводом проверок.
- **Чем проверяется:** сверка числа из сводки `check:tokens-theme` с числом в спеке.

## Чего эта работа не делает

- **Пары «текст и фон» ниже порога контраста** — задача RT-394, её записи в списке принятого
  остаются на месте.
- **Разбор всего ряда поверхностей в графите** — почему `page`, `surface` и `subtle` идут не
  по возрастанию глубины, здесь не выясняется.
- **Чистка ставшего избыточным `dark` у `--rt-toggle-color-track`** — после этой работы он
  повторяет то, что назначение отдаёт цепочкой, но снимать его владелец не просил.
- **Неверный комментарий в `rt-toggle-button-group.component.scss:141`** — он утверждает, что
  `subtle` совпадает с `surface` в тёмной теме, чего в дереве нет. Отдельная правка.

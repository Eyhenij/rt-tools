# Замысел

**Задача:** RT-1701 · **Ветка:** RT-1701-broken-check-way-out
**Поведение:** не меняется — правятся закон, гард и текст отказа проверки

## След задачи

| Что      | Где                                                                   |
| -------- | --------------------------------------------------------------------- |
| Закон    | `projects/agent-kit/assets/laws/verifiability.md`                     |

## Что считается сделанным

- Статья закона о сломавшейся проверке называет ход: разбор поимённо, показ владельцу, починка
  самой проверки.
- Отказ гейта пуша называет три хода вместо двух.
- Отказ проверки адресов не учит вносить спорное в список известного.
- Сценарии закрыты, набор пакета зелёный.

## Этапы

### 1. Статья закона и отказ гейта

- **Что делается:** ход в статье закона; третий ход в тексте отказа гарда; сценарий.
- **Признак готовности:** отказ гарда называет починку самой проверки.
- **Чем проверяется:** набор `git-guard-push-tests.test.sh`.

### 2. Отказ проверки адресов

- **Что делается:** текст отказа называет три хода и не зовёт в список спорное; спека и адреса.
- **Признак готовности:** проверки спек и адресов зелёные, набор пакета зелёный.
- **Чем проверяется:** `node tools/check-specs.mjs`, `node tools/check-doc-paths.mjs`, тесты
  пакета.

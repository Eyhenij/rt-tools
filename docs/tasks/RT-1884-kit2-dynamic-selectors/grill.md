По ходу работы над меню:

## Что уже есть в дереве

- Семейство первого кита лежит в `projects/ui-kit/src/lib/ui-kit/dynamic-selectors/`. Селектор
  `rtui-dynamic-selector` — поле формы со списком выбранных строк, кнопками «Добавить»,
  «Сбросить» и «Очистить», строками только для чтения и перетаскиванием. Всплывающий выбор
  `rtui-multi-selector-popup` — поиск, флажки или переключатели, «Выбрать всё», догрузка при
  прокрутке, «Отмена» и «Применить». Ещё поле `rtui-dynamic-input` — список строк, набираемых
  вручную. Всё это стоит на Material: поле формы, кнопки, флажок, переключатель, спиннер,
  подсказка, значок.
- Во втором ките аналога нет. `dynamic-list` — оболочка экрана списка с таблицей, другое.
  `rt-multiselect` закрывает простой выбор нескольких значений фишками, но без списка строк,
  сброса, строк только для чтения, перетаскивания и всплывающего выбора с «Выбрать всё».
- Части второго кита, из которых семейство собирается: всплывающая панель, флажок, переключатель,
  поле ввода, фишка с крестиком, пустое состояние, директива догрузки при прокрутке, кнопки.
- Кадры первого кита: `components-dynamicselector--*` и `components-dynamicinput--*` в
  `projects/ui-kit/.storybook/__snapshots__/`.
- Карточка — RT-1884, эпик RT-2353, строка 4 плана `docs/plans/one-kit-part-2.md`. Строка
  говорила «только по требованию приложения»; владелец выбрал селекторы в работу сам.

## Что уже говорят правила

- Первый кит не правится, он открывается образцом (`docs/adr/0003-one-ui-kit.md`).
- Готовое во втором ките не заменяется, а получает вид первого.
- Семейство без описания, истории и снимка перенесённым не считается.

## Вопросы и ответы

**Брать ли селекторы, хотя строка плана ждала требования приложения?**
Да: владелец выбрал «Динамические селекторы» из списка непереносённого.

**Можно ли в перенесённом Material?**
Нет: «в перенесенных компонентах не должно быть использования материала». Вид сличается с
кадрами первого кита.

**Заменять ли `rt-multiselect` селектором?**
Нет: готовое во втором ките не заменяется. Селектор встаёт отдельным компонентом рядом.

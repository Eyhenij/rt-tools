## Что считается сделанным

- Ни один файл кита не зовёт устаревший пакет анимаций, и ни одного отключения с меткой RT-843
  в дереве не осталось.
- Движение панели действий, шторки, полосы загрузки и всплывающего сообщения — прежнее, и это
  подтверждено замером в браузере, а не взглядом.

## Этапы

### 1. Полоса загрузки

- **Что делается:** набор триггеров снимается вместе со своим выводом наружу; переход
  называется в журнале ломающей правкой.
- **Признак готовности:** в дереве нет ни файла, ни его вывода, ни одного зовущего.
- **Чем проверяется:** `pnpm exec nx build @rt-tools/ui-kit` — сборка проходит.

### 2. Панель действий и шторка

- **Что делается:** движение обеих переезжает на правила стилей; уход придерживается тем же
  кодом, что и сейчас.
- **Признак готовности:** оба компонента не зовут устаревший пакет, и обе стороны движения на
  месте — появление и уход.
- **Чем проверяется:** `pnpm exec nx run @rt-tools/ui-kit:lint --skip-nx-cache` — 0 отказов.

### 3. Всплывающее сообщение

- **Что делается:** проигрыватель заменяется покадровым правилом с остановкой на наведении.
- **Признак готовности:** полоса идёт заданное время, стоит под указателем и закрывает
  сообщение по концу.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit` — 0 провалов.

### 4. Витрина и подтверждение

- **Что делается:** из историй снимается объявление провайдера анимаций; снимки первого кита
  сверяются; движение замеряется в браузере.
- **Признак готовности:** снимки сходятся либо расхождение объяснено, замер назван числами.
- **Чем проверяется:** `pnpm run test:visual` — расхождений нет либо они разобраны;
  `pnpm exec nx run-many --target=lint --all --skip-nx-cache --parallel=1` — ни одного
  `sonarjs/deprecation` про анимации.

## Чего эта работа не делает

- Не трогает второго кита: он на устаревшем пакете не стоит.
- Не меняет времени и кривых движения: задача про способ, а не про вид.

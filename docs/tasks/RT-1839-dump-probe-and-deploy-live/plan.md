## Что считается сделанным

- В `deploy/dump.sh` есть проба одной командой: одноразовая база рядом, загрузка последнего
  дампа, счёт строк по таблицам и отпечатки токенов, предложений и разборов против боевой базы,
  снос контейнера с томом. Боевое хранилище проба не трогает.
- Выкатка запущена из главной ветки рабочим потоком, дошла до узла, и приёмник ответил по
  имени.
- На узле снят дамп и прогнана проба: счёт строк и отпечатки сошлись с боевой базой.
- Спек узла и описание прода говорят о пробе одной командой; сценарий SC-MB-95 называет, чем
  проверен; замысел эпика называет номер этой задачи.

## Этапы

### 1. Проба дампа одной командой

- **Что делается:** в `deploy/dump.sh` добавляется команда `probe`: поднять одноразовую базу
  тем же образом и окружением, загрузить в неё последний дамп, напечатать счёт строк по
  таблицам обеих баз и отпечатки по `tree_token`, `proposal`, `postmortem`, сравнить, снести
  контейнер с томом даже при отказе.
- **Признак готовности:** сценарий разбирается оболочкой; расхождение отпечатков кончает пробу
  ненулевым кодом и называет таблицу.
- **Чем проверяется:** `bash -n deploy/dump.sh` — код 0.

### 2. Выкатка конвейером из главной ветки

- **Что делается:** рабочий поток выкатки запускается с главной ветки; дожидается конца.
- **Признак готовности:** прогон зелёный, шаг пробы печатает «приёмник отвечает», на узле
  стоят образы с sha вершины главной ветки.
- **Чем проверяется:** `gh run list --workflow deploy.yml --limit 1` — `success` на sha вершины
  главной ветки.

### 3. Дамп и проба на узле

- **Что делается:** сценарий с пробой кладётся на узел, снимается дамп, идёт проба.
- **Признак готовности:** проба печатает счёт строк по таблицам и слово о том, что отпечатки
  сошлись; одноразового контейнера после неё нет.
- **Чем проверяется:** `ssh message-bus 'bash /opt/message-bus/dump.sh probe'` — код 0 и строка
  «probe: сошлось».

### 4. Тексты

- **Что делается:** спек узла получает правило о пробе с привязкой к сценарию, SC-MB-95
  называет пробу; описание прода заменяет пять вызовов одной командой; замысел эпика получает
  номер задачи и запись о том, чем закрыт открытый вопрос Q-1.
- **Признак готовности:** сверка спеков не прибавила расхождений, сверка очереди не видит
  задачу без эпика.
- **Чем проверяется:** `npm run check:specs` — код 0; `npm run check:board` — строки об этой
  задаче нет.

## Чего эта работа не делает

- Не заводит выгрузку по расписанию и хранение копий дампа вне узла: замысел эпика называет
  это отдельной работой, и задача под расписание заводится по итогам пробы.
- Не правит загрузку `load` поверх боевого хранилища: проба судит дамп, а не путь загрузки.
- Не закрывает карточку эпика сама: это делает владелец после слияния, по записи в замысле.

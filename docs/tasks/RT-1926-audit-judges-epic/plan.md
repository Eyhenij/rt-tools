## Что считается сделанным

- Сверка называет задачу, у которой эпика нет и слова владельца о работе вне эпика тоже нет.
- Сверка называет заявку задачи, основание которой не ветка её эпика.
- Сверка называет эпик, у которого нет ветки среди удалённых ссылок.
- Сверка называет эпик, все задачи которого закрыты, а заявки от его ветки нет.
- Пробы набора пакета покрывают каждый случай и приняты на нарушении.

## Этапы

### 1. Задача без эпика видна сверке

- **Что делается:** сверка читает объявление эпика в теле каждой открытой задачи; нет ни эпика, ни
  строки о работе вне эпика — строка расхождения.
- **Признак готовности:** задача без обеих строк названа, задача со словом владельца — нет.
- **Проверяется:** пробы набора пакета.

### 2. Основание заявки судится по ветке эпика

- **Что делается:** для открытой заявки задачи, у которой назван эпик, основание сверяется с
  веткой эпика.
- **Признак готовности:** заявка с основанием «главная» названа, с основанием ветки эпика — нет.
- **Проверяется:** пробы набора пакета.

### 3. Эпик без ветки и эпик, которому пора в главную

- **Что делается:** карточка с меткой эпика без ветки среди удалённых ссылок — строка; эпик, все
  задачи которого закрыты, а открытой заявки от его ветки нет, — вторая строка.
- **Признак готовности:** обе строки печатаются на нарушении и молчат на порядке.
- **Проверяется:** пробы набора пакета.

### 4. Раскладка и тексты

- **Что делается:** `pnpm run agent-kit:sync`, спека подобласти и её привязки, компаньон правила.
- **Признак готовности:** `pnpm run agent-kit:check` и `node tools/check-specs.mjs` без
  расхождений.
- **Проверяется:** обе команды и `bash projects/agent-kit/tests/run.sh`.

## Чего эта работа не делает

- Не судит имя ветки задачи: имён веток очередь не хранит, а ветка после слияния исчезает.
- Не закрывает эпик сама и не открывает его заявку: сверка называет расхождение, решает владелец.
- Не переводит на новый порядок эпики, заведённые прежним.

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — статья о составе прода на своей машине
- **Сделано:** задача заведена, ветка и папка на месте, замысел записан, две записи груза отмечены
- **Следующий шаг:** дописать статью в правило выкатки
- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** не открывается — ночью ветки держатся локально по слову владельца

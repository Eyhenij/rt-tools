## Решения по ходу

- **Правка ставится по нынешнему месту статьи, а не по названному в записи** — записи называют
  правило работы с ветками, а статья о признаке режима с тех пор живёт в правиле выкатки.
  Затронутый этап замысла: 1.
- **Привязка статьи — вердикт «Не проверяется», а не файл** — подъёма состава на своей машине
  дерево не видит ничем; сверка спеков отбила первую редакцию привязки, где стоял один файл без
  символа. Затронутый этап замысла: 3.
- **Права токена спрашиваются заголовком ответа, а не снимком** — утверждение о правах стареет
  вместе с настройкой хостинга. Затронутый этап замысла: 2.

# Замысел

**Задача:** RT-539 · **Ветка:** RT-539-app-laws-out-of-package
**Поведение:** не меняется — работа лежит в слое правил, кода приложения не задевает

## След задачи

| Что     | Где                                                        |
| ------- | ---------------------------------------------------------- |
| Спеки   | `docs/specs/agent-kit/package-boundary/`                   |
| Законы  | `docs/constitution/application/access.md`                  |
| Правила | `.claude/skills/permissions/`, `.claude/skills/agent-kit/` |
| Код     | `projects/agent-kit/assets/`                               |

## Что считается сделанным

- Пакет не везёт трёх законов приложения, трёх правил под ними и пяти паттернов при них.
- Закон доступа, правило `permissions` и паттерн при нём живут в этом дереве своими ресурсами:
  гейт зовёт правило по-прежнему.
- Правило раскладки называет шагом установки случай, когда ресурс вообще не должен быть пакетным.

## Этапы

### 1. Снятие ресурсов из пакета

- **Что делается:** восемь файлов уходят из `assets`; живое в дереве остаётся без шапки
  раскладки; строки `skip` про снятое убираются.
- **Признак готовности:** раскладка не кладёт снятого, а гейт зовёт `permissions` как прежде.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится с пакетом.

### 2. Шаг установки в правиле раскладки

- **Что делается:** пятым шагом раздела «Установка туда, где уже всё своё» — ресурс, у которого
  здешняя редакция богаче по существу, в раскладку не берётся.
- **Признак готовности:** шаг называет признак и оба хода — `skip` и предложение наверх.
- **Чем проверяется:** `node tools/check-file-size.mjs` — новых длинных нет.

### 3. Спек границы и раскладка

- **Что делается:** статья и сценарий в спеке границы, привязка, раскладка.
- **Признак готовности:** сверка молчит.
- **Чем проверяется:** `npm run check:specs` — расхождений нет.

## Чего эта работа не делает

- Не пишет своей редакции законов локалей и видимости в поиске: предмета у этого дерева нет.

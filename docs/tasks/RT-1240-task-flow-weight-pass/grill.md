# Разбор просьбы

## Просьба владельца

> после обновления agent kit делай задачи из техдолга из приёмника, одну за другой, без
> остановок… не пуш ветки - храни все ветки локально… твоя задача - закрыть как можно больше
> задач в локальных ветках до утра.

## Откуда эта задача

Не из приёмника. Она вышла из трёх задач подряд, разобранных этой же ночью: RT-1226, RT-1231,
RT-1232 и RT-1239 каждая упёрлись в предел веса правила хода работы и каждая заплатила проходом
сжатия по соседним статьям — девять доводов в одной из них. Записи описания прошлого называют это
трижды одними словами: правило переросло, и всякая новая статья в нём теперь начинается с
прохода по чужим.

Владелец просил закрывать задачи приёмника. Эта работа их не закрывает, а снимает то, что стоит
перед каждой следующей из них: одиннадцать записей приёмника ещё адресованы этому правилу и его
паттернам.

## Прочтение

Правило приводится к запасу, а не к пределу. Режется довод, утверждение остаётся: снятое
утверждение меняет правило, снятый довод — только его цену. Случаи с числами уезжают в холодную
часть, которая грузится по требованию.

## Этапы

### 1. Обход по утверждениям

- **Что делается:** каждый пункт обоих файлов проверяется на нынешнем дереве.
- **Признак готовности:** у каждого пункта есть ответ — закрыт, жив, изменился числом.
- **Чем проверяется:** `pnpm exec nx lint @rt-tools/ui-kit-v2` — предупреждений нет; счёт
  историй и эталонов снимков; чтение настроек и стилей.

### 2. Переписывание списка

- **Что делается:** закрытое снимается, живое остаётся с нынешними числами, порядок разбора
  пересобирается.
- **Признак готовности:** список не называет закрытого и не врёт числами.
- **Чем проверяется:** `node tools/check-file-size.mjs` и `node tools/check-doc-paths.mjs` —
  расхождений нет.

# Разбор просьбы

## Просьба владельца

> Пр влил, пересмотри предложения в md файлах в корне проекта

## Что уже есть в дереве

В корне шесть файлов `.md`. Предложения и списки работ несут два:

- `avalon-proposals-2.md` — девять предложений к пакету правил, приехавших от дерева-потребителя
  на версии 0.5.1. Файл вне истории репозитория.
- `UI-KIT-V2-ISSUES.md` — список незакрытого по второму киту, составлен 5 августа 2026 года,
  лежит в истории.

Остальные четыре предложений не несут: `CLAUDE.md` и `README.md` — описание дерева,
`RUNNER-MONITOR.md` — памятка под отдельный проект, `rt-tools-figma-uikit-task.md` — задание.

## Решения

- **Файл предложений к пакету снят целиком** — все девять проверены по нынешним ресурсам, и
  каждое уже закрыто. По правилу самого файла закрытое предложение удаляется, а не помечается.
- **Список по киту переписан, а не помечен** — тем же правилом, которое в нём записано.
- **Живые пункты остались в файле, задачами не заведены** — их пять, и решение, что из этого
  берётся в работу, за владельцем.

## Что осталось невыясненным

- Пункт о провенансе в комментариях кнопки называет библиотеку, которой в дереве нет; поправить
  комментарий можно только вместе с решением, что там должно быть сказано вместо истории.

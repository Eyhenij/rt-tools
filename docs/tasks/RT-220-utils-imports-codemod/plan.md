# Замысел

**Задача:** RT-220 · **Ветка:** RT-220-utils-imports-codemod
**Поведение:** не меняется — инструмент переписывает объявления импорта в чужом дереве, а кода
пакетов не трогает вовсе.

## След задачи

| Что     | Где                                                         |
| ------- | ----------------------------------------------------------- |
| Код     | `tools/migrate-utils-imports.mjs`                           |
| Пробы   | `projects/agent-kit/tests/`                                 |
| Команды | `package.json`                                              |
| Журналы | `projects/utils/CHANGELOG.md`, `projects/core/CHANGELOG.md` |

## Что считается сделанным

- Инструмент лежит в `tools/`, принимает каталог доводом и обходит его файлы кода сам.
- Объявление, называющее только переехавшие имена, получает новый адрес пакета.
- Объявление, называющее переехавшие имена вместе с оставшимися, делится на два.
- Объявление, у которого переехавших имён нет, не трогается.
- Инструмент ничего не знает ни об одном приложении: таблица имён — его единственное знание о
  предмете.
- Набор проб гоняет инструмент на дереве-фикстуре и красен, когда любое из этого не верно.

## Этапы

### 1. Таблица имён и обход дерева

- **Что делается:** пишется `tools/migrate-utils-imports.mjs` — таблица «имя → пакет», обход
  каталога по расширениям кода, разбор объявлений импорта и переписывание по трём случаям.
- **Признак готовности:** вызов на каталоге переписывает переехавшее и не трогает остальное;
  сухой прогон печатает то же, ничего не записав.
- **Чем проверяется:** `node tools/migrate-utils-imports.mjs --help` — печатает довод каталога и
  сухой прогон, кодом 0.

### 2. Проба на дереве-фикстуре

- **Что делается:** заводится `projects/agent-kit/tests/migrate-utils-imports.test.sh` — дерево из
  файлов на каждый случай, прогон инструмента, сверка получившегося.
- **Признак готовности:** набор зелёный, и красен, если убрать деление смешанного объявления.
- **Чем проверяется:** `bash projects/agent-kit/tests/migrate-utils-imports.test.sh` — строка
  «0 провалов».

### 3. Инструмент назван деревом

- **Что делается:** команда в `package.json` и строка в журналах обоих пакетов о том, чем
  переставить импорты.
- **Признак готовности:** команда зовётся именем, а не путём; журналы называют инструмент рядом с
  таблицей переехавшего.
- **Чем проверяется:** `node tools/check-file-size.mjs` — долг не вырос.

## Чего эта работа не делает

- Переноса из `utils` в `core` — он в главной ветке коммитом `549f393fc`.
- Перестановки импортов первого кита — она сделана тем же коммитом.
- Правки поведения `isEmail` на пустом значении — карточка выводит её за границы и ведёт
  отдельно.

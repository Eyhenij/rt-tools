# Grill

## The owner request

> мержу не я очередь, мжешь дальш работать?

## What the tree already has

Аудит очереди работ печатает сегодня две строки такого вида:

    RT-2161-no-rights-screen: the task folder never travelled into the branch
    RT-2195-tree-tells-truth-about-itself: the task folder never travelled into the branch

Обе ветки — ветки эпиков. Папки задачи у ветки эпика нет по устройству: правило `task-flow`
говорит, что она несёт план эпика и слияния своих задач, и ничего своего.

Проверка — `checkBranchFolders` в `projects/agent-kit/assets/checks/board-folders.mjs`. Она берёт
все ветки вида `<КЛЮЧ>-<цифры>-*` и требует папку от каждой; ветку эпика от ветки задачи не
отличает никак. Читает она только местный репозиторий, без сети, — так и написано в её заголовке.

Признак ветки эпика в дереве уже есть и читается без сети: шапка плана эпика несёт строку
«**Ветка эпика:** `<имя>`». Образец для её чтения тоже написан — `task-new.github.mjs:251`
разбирает ту же строку тремя её видами: «Ветка эпика», «Ветка», «Branch».

Описание доски говорит: «The branch of an epic is recognised by its number in the name of the
base» — это про чтение очереди, где сеть есть. Про местное чтение веток оно не говорит ничего.

## What the rules already say

Правило `task-flow`: «The epic branch carries the plan of the epic and the merges of its tasks, and
no edits of its own» и «A task folder is created for any work» — второе о задачах, не об эпиках.

Правило `agent-kit-extend`: проверка правится в исходниках пакета, потом сборка, потом раскладка;
порядок один.

Правило `testing`: «A check is accepted on a violation, not on a green run».

## Questions and answers

Вопросов владельцу не задавалось: он сказал работать дальше, а расхождение названо самим аудитом.

## Decisions

- **Ветки эпиков читаются из планов, а не из сети.** Проверка объявлена как читающая только
  местный репозиторий, и сеть в неё тащить нельзя: она единственная в аудите работает без неё.
  Отклонено: спрашивать метку эпика у хоста — это меняет её устройство.
- **Образец строки берётся тот же, каким её пишет создающая команда.** Свой второй образец
  разошёлся бы с первым молча.

## What is left unclear

- Дерево, у которого планов эпиков нет вовсе, получит прежнее поведение. Это верно: без планов
  веток эпиков не бывает.

# Замысел

**Поведение:** не меняется — правится холодная часть правила о документации.

## Что делается

1. В раздел ловушек холодной части встаёт пункт: строку требования не проверяет ничто, и
   расхождение видно только счётом.
2. Пункт несёт саму команду счёта: сколько правил объявило требование против того, сколько их
   в каталоге.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

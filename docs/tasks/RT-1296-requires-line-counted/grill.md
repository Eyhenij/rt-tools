# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `rules/spec-driven.md`. Отметить её этому
дереву нечем: токен двигает только свои записи, работа при этом наша.

## Строку требования не считает никто

> Статья про строку требования стоит в разделе применения закона, а признака того, что её
> исполнение видно счётом, нигде нет. Проверка полноты текстов считает разделы и привязки;
> сколько правил объявило свои требования — не считает никто, и промах виден только сплошным
> чтением. Два файла из восьмидесяти двух нашлись именно так.

Здесь то же: строку требования несёт один текст на весь набор правил. Соседней задачей той же
ночи паттерн заведения правила научился её показывать, но написанные раньше правила её не
получили, и узнать, сколько их, можно только счётом.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что в работу не берётся

Проверки на строку не заводится: отсутствующая строка законна — правило, которому нечего
требовать, её не пишет, — и отличить такое от промаха машине нечем.

# Замысел

**Спек:** `docs/specs/agent-kit/observations/spec.md`

## Что делается

Каждый гард, умеющий отказать, пишет наблюдение об отбое. Приём записи собирается один раз общим
файлом, а гард зовёт его одной строкой: повторённый двадцать пять раз, он разошёлся бы при
первой же правке.

## Этап 1 — общий приём записи отбоя

**Что делается:** заводится общий файл, который подключает запись наблюдений и пишет отбой
гарда по имени и признаку сессии. Пять гардов, которые пишут отбой сами, переходят на него.

**Чем проверяется:** `pnpm run agent-kit:hooks` — 0 провалов; сводка за отрезок называет
отбивавших прежним порядком.

## Этап 2 — запись во всех отказывающих гардах

**Что делается:** гарды пакета и гарды дерева, умеющие отказать, зовут запись на своём решении
отказа. Имя в записи совпадает с именем файла.

**Чем проверяется:** `pnpm run agent-kit:hooks` — 0 провалов; отказ, вызванный руками, виден в
сводке счётчиком своего гарда.

## Этап 3 — договорённость домена

**Что делается:** спек поддомена наблюдений получает статью о том, что отказ гарда записывается
всегда, и сценарий; привязки — рядом.

**Чем проверяется:** `node tools/check-specs.mjs` — расхождений нет.

## Чего не делается

- Гейт правил не трогается: он пишет своё событие и стоит в сводке своим разделом.
- Хуки, которые ничего не отбивают, записи не получают: отбоя у них не бывает.

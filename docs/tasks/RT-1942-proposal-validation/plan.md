## What counts as done

- Предложение сверяется со спекой прежде, чем стать работой, и правило называет три исхода.
- Переход записи в работу отбивается, пока не названа спека, с которой предложение сверено.
- Названная спека проверяется на существование до сети: выдуманный путь не уезжает в приёмник.
- Исход «спека молчит» отличается от исхода «спека права» тем, что называет разный следующий шаг.

## Stages

### 1. Договорённость поддомена

- **What is done:** заводится поддомен `proposal-verdict` — спека, сценарии и спутник; сценарии
  берут свободные номера от `SC-AK-947`.
- **Readiness sign:** спека называет три исхода, чем каждый подтверждён и что делает команда
  отметки на переходе в работу.
- **Verified by:** `node tools/spec-next-id.mjs` — свободный номер вырос ровно на число заведённых
  сценариев.

### 2. Отметка требует названной спеки

- **What is done:** команда отметки получает аргумент со спекой; переход в работу без него
  отбивается до сети, а названный путь проверяется на существование.
- **Readiness sign:** вызов без аргумента кончается ненулевым кодом и называет, чего не хватает;
  выдуманный путь тоже отбивается; переход в прочие состояния идёт как прежде.
- **Verified by:** `npm run cargo:mark -- --dry-run` на переходе в работу без спеки — ненулевой код
  и строка о том, с чем предложение не сверено.

### 3. Пробы и привязки

- **What is done:** пробы под сценарии этапа 1 в наборе отметки груза; спутник поддомена
  заполняется привязками.
- **Readiness sign:** набор краснеет на снятой проверке и зеленеет на целой; проверка спек не
  называет ни одной статьи без привязки.
- **Verified by:** `npm run agent-kit:hooks` — «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ»; `npm run check:specs` — код
  ноль.

### 4. Статьи правила разбора

- **What is done:** в правило `cargo-triage` встают статьи о сверке со спекой и о трёх исходах;
  спутник правила называет место каждой.
- **Readiness sign:** статьи стоят в разделе применения закона, у каждой есть привязка.
- **Verified by:** `npm run check:specs` — код ноль, статей без привязки нет.

## What this work does not do

- Не заводит карантин состоянием записи: это RT-1943. Здесь исход назван, а место для спорных
  предложений заводится следующей задачей.
- Не заводит машинного признака «предложение верно». Судит заход; машина держит след сверки.
- Не переписывает уже накопленные записи приёмника: разбор с этого дня идёт по новому правилу.

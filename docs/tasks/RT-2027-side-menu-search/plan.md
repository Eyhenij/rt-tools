## What counts as done

- Запрос с именем пункта, лежащего внутри папки, показывает и папку, и этот пункт; сама папка
  раскрыта, и результат виден без лишнего нажатия.
- Пустой запрос показывает подменю целиком и возвращает ту раскрытость, что была до набора.
- Вложенность глубже одного уровня считается тем же правилом.
- Стрелки вверх и вниз ходят по отобранному списку, вправо и влево раскрывают и сворачивают папку,
  Enter открывает подсвеченный пункт, Escape чистит запрос; набор букв между нажатиями стрелок
  продолжает работать.
- Лупа и крестик очистки стоят на одинаковом отступе от своих краёв, и это число получено
  измерением в браузере.
- Сценарии на всё перечисленное лежат в описании раздела и связаны с тестами.

## Stages

### 1. Отбор спускается внутрь папок

- **Steps:**
    1. `filterSubMenuItems` считает вложенность: папка остаётся, если совпала сама или совпал хотя
       бы один её пункт; пункты папки тоже отобраны
    2. тесты на отбор: имя пункта внутри папки, имя папки, пустой запрос, вложенность глубже уровня
- **What is done:** поиск находит то, что лежит внутри папок.
- **Readiness sign:** тесты отбора зелёные, и без правки отбора они красные.
- **Verified by:** `pnpm exec nx test @rt-tools/ui-kit --testFile=projects/ui-kit/src/lib/ui-kit/side-menu/side-menu.logic.spec.ts` — 0 провалов.

### 2. Совпавшая папка раскрыта

- **Steps:**
    1. раскрытость от поиска считается отдельной функцией и отдельным состоянием от раскрытости
       рукой
    2. меню читает её при непустом запросе и возвращает прежнюю при пустом
    3. тесты на раскрытость: непустой запрос, пустой запрос, вложенность глубже уровня
- **What is done:** результат поиска виден без лишнего нажатия, а стёртый запрос не оставляет
  раскрытым то, чего человек не раскрывал.
- **Readiness sign:** тесты раскрытости зелёные.
- **Verified by:** `pnpm exec nx test @rt-tools/ui-kit --testFile=projects/ui-kit/src/lib/ui-kit/side-menu/side-menu.logic.spec.ts` — 0 провалов.

### 3. Клавиатура

- **Steps:**
    1. поле поиска раздаёт клавиши списку, подсветка держится по `id` пункта
    2. стрелки, Enter и Escape; прочие клавиши уходят полю нетронутыми
    3. тесты харнесса: ходьба стрелками, раскрытие стрелкой вправо, Enter, Escape, набор букв после
       стрелки
- **What is done:** по отобранному списку можно ходить и открывать пункты, не снимая рук с
  клавиатуры.
- **Readiness sign:** тесты меню зелёные.
- **Verified by:** `pnpm exec nx test @rt-tools/ui-kit --testFile=projects/ui-kit/src/lib/ui-kit/side-menu/menu/rtui-side-menu.component.spec.ts` — 0 провалов.

### 4. Отступ лупы

- **Steps:**
    1. отступ крестика измерен в браузере на витрине числом
    2. отступ лупы приведён к нему в оформлении меню
    3. измерение повторено после правки: числа сошлись
- **What is done:** лупа и крестик читаются с одинаковым отступом от своих краёв.
- **Readiness sign:** два числа из браузера равны.
- **Verified by:** измерение через `getBoundingClientRect` на витрине меню — левый отступ лупы и
  правый отступ крестика совпадают.

## What this work does not do

- Не трогает `splitSubMenuTitle`: отметка совпавшего куска подписи уже работает и от глубины не
  зависит.
- Не заводит клавиатуру в узкой разметке меню: там подменю занимает экран целиком, и ходить
  стрелками не по чему.
- Не меняет моду подменю, его ширину и хранение выбора человека.
- Публикация новой версии кита идёт после слияния отдельным запуском, а не этой работой.

## Что уже есть в дереве

Скан Angular Doctor на вершине RT-3508 (23.11.2026) находит 39 находок семи правил задачи:

- `prefer-host-bindings` — 23: `@HostBinding` и `@HostListener` в `escape-key`, `icon-outlined`,
  `navigation` (core), `rt-button`, `rt-file-drop`, `rt-skeleton`, `rt-toast`, `rt-toaster` (кит) и
  `story-states.ts` витрины.
- `prefer-signal-query` — 3 и `lifecycle-interface` — 3: `@ViewChild` и `ngOnInit`/`ngOnDestroy` без
  интерфейсов в `rt-table`; `ngOnInit` в странице брони шаблонов витрины.
- `prefer-inject` — 3: внедрение через конструктор в `BlockDirective` и `ElemDirective` core и
  конструктор двойника `keycloak-fetch-double.ts`.
- `host-via-element-ref` — 1: класс хоста через `nativeElement` в `rt-data-table-row-click`.
- `input-dom-name` — 2: вход `keyExp` списка и таблицы данных, у которого значение по умолчанию —
  строка `'id'`.
- `prefer-class-binding` — 4: слово `[ngClass]` в комментариях и тексте ошибки правила линтера
  `require-bem-directives.ts`.

Семь находок из 39 инструмент даёт не по сути правила: `input-dom-name` читает значение по
умолчанию `'id'` как имя входа, `prefer-class-binding` — слово в комментарии и в строке правила
линтера, `prefer-inject` — конструктор обычного класса-двойника без внедрения.

## Что уже говорят правила

- Правила Angular Doctor не выключаются в настройке: так решил владелец. Правило, которое нельзя
  выполнить, задача приносит владельцу меню.
- Видимая правка кита идёт через макет или через слово владельца «вид не меняется».

## Вопросы и ответы

**Семь находок, которые инструмент даёт не по сути правила, — как с ними?**
Решение эпика от 21.11.2026 «Подогнать код»: правила не выключаются, места переписываются так, чтобы
инструмент их не находил, — значение по умолчанию входа `keyExp` через именованную константу, текст
правила линтера без буквального `[ngClass]` при том же смысле, двойник собирается фабрикой, а не
параметром конструктора. Поведение и API кита не меняются.

**Правка кита: привязки к хосту в `host`, запросы таблицы на `viewChild()`, интерфейсы хуков,
константа значения `keyExp` по умолчанию. Вид не меняется — подтверждаете?**
«Подтверждаю, вид не меняется».

**Behaviour:** unchanged — слово владельца 23.11.2026 «Подтверждаю, вид не меняется»: привязки,
запросы и внедрение меняют форму записи, а классы, атрибуты, события, входы и выходы остаются.

# Замысел

**Поведение:** не меняется — правится разбор доводов запуска пакета, требований к продукту
задача не трогает.

Адрес репозитория берётся у имени `origin` и больше нигде. Рабочая копия, назвавшая свои
удалённые репозитории иначе, остаётся без адреса, хотя он у неё есть.

## Этапы

1. Порядок выбора: `origin`, если он есть; ровно один — он; несколько без `origin` — адреса нет.
2. Имена, среди которых выбор не сделан, доезжают до отказа и называются в нём поимённо.
3. Сценарии на все три исхода.
4. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Выбор за человека задача не делает: несколько имён без `origin` остаются отказом. Угадать, какое
из них называет то же дерево, нечем, а угаданное неверно слило бы в сводке приёма два дерева в
одно.

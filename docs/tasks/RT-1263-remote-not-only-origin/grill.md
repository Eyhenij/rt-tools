# Разбор просьбы

Запись груза из приёма, соседнее дерево. Отметить её этому дереву нечем — токен двигает только
свои записи; работа при этом наша, пакет живёт здесь.

- **место:** разбор доводов запуска, там, где спрашивается адрес репозитория; и абзац о признаке
  дерева в скиле
- **повод:** дерево, у которого удалённый репозиторий назван не `origin`, получает отказ
  отправки, хотя адрес у него есть. Признак дерева считается хешем от адреса, а адрес берётся у
  одного-единственного имени. Имя это соглашение, а не устройство.
- **чем это стоит:** обход, который остаётся дереву, хуже отказа — посчитать хеш руками и
  прибить его ключом настройки. Прибитое значение расходится с адресом молча: сменится адрес —
  признак останется прежним, и в сводке приёма два дерева сойдутся в одно или одно разъедется на
  два.
- **готовый порядок:** `origin`, если он есть; ровно один remote — он; несколько и `origin`
  среди них нет — отказ, называющий их поимённо, чтобы человек выбрал.
- **чем закрывается:** ничего, надстройки под это нет — обход живёт ключом `tree` в настройке
  дерева.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

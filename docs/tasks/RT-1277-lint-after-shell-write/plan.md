# Замысел

**Поведение:** не меняется — линтер по-прежнему возвращает замечания добавленным контекстом, а
не отказом, и по-прежнему молчит на зелёном.

## Что делается

1. `hooks/lint-after-edit.sh`: ветка команды оболочки разбирает не только перенос файла, но и
   запись — путями от `rt_shell_paths`, при признаке `rt_shell_writes`. Выбор линтера, отсев и
   предел числа файлов остаются те же.
2. Отсев до работы перестаёт быть отсевом по слову «git mv»: команда без признака записи уходит
   молча, как уходила.
3. Сценарии при наборе хука: запись перенаправлением линтуется, чтение — нет.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`.

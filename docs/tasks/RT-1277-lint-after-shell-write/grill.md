# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `hooks/lint-after-edit.sh`. Отметить её
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Файл, записанный оболочкой, линтера не получает

Правленые проверка и её список вышли из-под форматтера, и не показали этого ни хук, ни набор
проверок дерева — нашлось ручным прогоном. Правка шла записью через перенаправление, а хук
разбирает у команды оболочки только перенос файла.

Признак записи при этом уже объявлен в профиле дерева и уже используется гейтом правил: одна
функция говорит, что команда пишет, вторая — куда.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

## Что считается сделанным

- Есть истории на все виды из карточки: счётчик числами, нулём и переносом; действия без меню;
  действие с меню; действие со своими стилями; пустой набор кнопок; закрытие.
- Нажатие действия и закрытие видны в показе, меню раскрыто `play`-функцией.
- Отступы и вид кнопок сверены замером.

## Этапы

### 1. Обёртка и истории

- **Что делается:** заводится `TestActionBarComponent` с изменяемым набором и полем последнего
  нажатия, рядом — файл историй на перечисленные виды.
- **Признак готовности:** каждый вид из карточки показан своей историей.
- **Чем проверяется:** `pnpm run build-storybook` — собирается.

### 2. Спека договора и замер вида

- **Что делается:** спека проверяет счётчик, набор кнопок, вызов действия и закрытие; замер на
  витрине снимает отступы кнопок и сброс рамки с фоном.
- **Признак готовности:** числа записаны в ход работы.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit` — зелено.

## Чего эта работа не делает

- Не трогает панель и её стили.
- Не заводит эталонных снимков.

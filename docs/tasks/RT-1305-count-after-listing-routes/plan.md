# Замысел

**Поведение:** не меняется — правится текст паттерна о том, как писать.

## Что делается

1. В раздел о проверке факта встаёт абзац о числе «все N таких-то»: маршруты перечисляются до
   счёта, а скан подтверждает только заложенный в него.
2. Следом — абзац о самой команде: проверяется, что она мерит спрошенное, и число из прошлой
   сессии замером не считается.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

# Grill

## Просьба владельца

> заведи эпик на оставшиеся уязвимости

Затем: «делай всё сам, не останавилвайся». Эта задача — вторая из трёх в эпике RT-2822.

## Что в дереве уже есть

- Prisma 7.10.0 — последняя версия линии 7, новее есть только предвыпуск 8.0.0-rc. Она держит `mysql2` ровно на 3.15.3, а `@prisma/config` — `deepmerge-ts` ровно на 7.1.5.
- Нужны `mysql2` 3.23.1 (две записи аудита: высокая и средняя) и `deepmerge-ts` 8.0.0 (одна высокая). `deepmerge-ts` 8 — мажорное обновление, пакет только на ES-модулях.
- Prisma нужна приёмнику: клиент генерируется командой `pnpm run prisma:generate` при установке.

## Решения

- **Чиним пинами в `overrides`, Prisma не трогаем.** Новой версии линии 7 нет, а Prisma 8 в эпик не входит: у неё только предвыпуск.
- **Проверка — аудит до и после, генерация клиента, сборка и тесты приёмника, проверки перед отправкой.**

## Что осталось неясным

- Работает ли `@prisma/config` с `deepmerge-ts` 8. Покажет генерация клиента и сборка приёмника.

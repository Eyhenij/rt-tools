## Решения по ходу

- **17 августа 2026. Экран приглашений входит в задачу наравне с тремя названными.** Решение
  владельца при разборе: он собран тем же приёмом, а заведён после того, как эпик был расписан.
  Оставленный в стороне, он через задачу читается как принятый приём. Затронутый этап замысла:
  нет — объём назван замыслом с самого начала.
- **17 августа 2026. Паттерн дерева о списочном экране правится этой же работой.** Решение
  владельца при разборе: его готовый код пишет таблицу атрибутом, и следующий раздел собрали бы по
  нему. Затронутый этап замысла: нет — правка стоит в этапе 1.
- **17 августа 2026. Пустое состояние отдельным видом даёт готовый компонент кита.** Разведка
  нашла его у образца: экран отказов ставит вид пустого состояния вместо таблицы, а вход
  `[emptyMessage]` остаётся короткой формой внутри таблицы. В ките этого дерева такой компонент
  тоже есть, заводить свой не надо. Затронутый этап замысла: нет.

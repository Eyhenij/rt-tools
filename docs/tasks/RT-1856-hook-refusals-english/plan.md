## Что считается сделанным

- Комментарии, тексты отказов и вводные хуков и проверок пакета написаны по-английски; цитаты
  статей совпадают с английскими правилами дословно.
- Наборы хуков и проверок переписаны под английский текст; набор пакета целиком зелёный, число
  наборов и проб не меньше прежнего.
- Хуки читают ключи папки задачи под двумя именами; образцы папки задачи несут английские ключи.
- Кириллицы в хуках и проверках не остаётся, кроме перечисленных поимённо исключений: имена
  состояний, русские имена ключей в альтернациях, строки для владельца.
- Раскладка сходится, спеки пакета зелены; замер записан в замысел эпика.

## Этапы

### 1. Комментарии

- **Что делается:** комментарии всех хуков и проверок переводятся заходами по каталогам; код не
  меняется.
- **Признак готовности:** diff без строк комментариев пуст у каждого файла.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — без провалов; `bash -n` и
  `node --check` по файлам — проходят.

### 2. Отказы хуков

- **Что делается:** тексты отказов и вводных хуков переводятся вместе с наборами, по одному
  хуку на заход; цитаты статей берутся из английских правил.
- **Признак готовности:** набор каждого хука зелёный при английском тексте.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — без провалов.

### 3. Отказы проверок

- **Что делается:** тексты отказов проверок переводятся вместе с наборами `checks-*.test.sh`.
- **Признак готовности:** наборы проверок зелены при английском тексте.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — без провалов;
  `pnpm exec nx test @rt-tools/agent-kit` — спеки зелены.

### 4. Ключи папки задачи под двумя именами

- **Что делается:** хуки читают ключи папки задачи под английским и русским именем; образцы
  папки задачи получают английские ключи; наборы получают пробу на английские ключи.
- **Признак готовности:** папка с английскими ключами и папка с русскими проходят одни и те же
  гарды одинаково.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — без провалов.

### 5. Раскладка и замер

- **Что делается:** переведённое раскладывается; замер байтов записывается в замысел эпика.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `pnpm run agent-kit:sync && pnpm run agent-kit:check` — сходится.

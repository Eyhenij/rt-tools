# Grill

## The owner request

> Задача RT-2987: меню разделов шапки на телефоне открывается без затемнения страницы.

Владелец разрешил вести RT-2987 в ките. Приложение, где меню разделов на телефоне стояло без
затемнения, своё затемнение в стилях держать не может: гард единообразия требует, чтобы его давал
кит. Высоту и прокрутку меню приложение исправило у себя.

## What the tree already has

- `[rtPopover]` открывает панель в оверлее CDK с `hasBackdrop: false`; клик мимо закрывает её через
  слушатель документа.
- Бургер `header-nav-burger` шапки `rt-page-header` открывает мобильную панель навигации через
  `[rtPopover]` с `rtPopoverFitViewport`.
- Токен `--rt-color-bg-overlay` уже задаёт цвет затемнения под окнами и шторками кита.

## What the rules already say

Вид затемнения задаётся токеном кита, а не потребителем: закон о единообразии приложения.

## Questions and answers

Вопросов владельцу не было: задача поставлена с готовым решением «затемнение даёт кит».

## Decisions

- **Новый вход `rtPopoverBackdropClass`, умолчание — пусто, подложки нет** — прочие панели кита
  (селекты, меню, подсказки) остаются без затемнения. Rejected: подложка у всех панелей поповера,
  она перекрыла бы страницу под каждым выпадающим списком.
- **Цвет подложки шапки — `--rt-color-bg-overlay`** — тот же, что под окнами и шторками.

## What is left unclear

- Сквозного набора у витрины кита нет. На телефоне затемнение проверит приложение после подъёма
  версии кита.

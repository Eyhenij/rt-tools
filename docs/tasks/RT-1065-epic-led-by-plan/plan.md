## Что считается сделанным

- Закон о ведении работы говорит три вещи, которых в нём не было: следующая задача берётся из
  замысла своего эпика, кончившийся эпик называется владельцу, эпик не закрывается по признаку,
  подтверждённому только чтением.
- Правило ведения работы называет, чем это держится здесь, и компаньон правила — где именно.
- Сценарии в спеке поддомена закрыты тестами, `npm run check:specs` расхождений не даёт.
- Набор обвязки пакета зелёный, раскладка сходится.

## Этапы

### Этап 1 — статьи закона

Три статьи в `work-conduct.md`, рядом с прочими об эпике: чем берётся следующая задача, что
говорится владельцу о кончившемся эпике, чем закрывается эпик.

**Готово, когда:** статьи стоят, длина закона в пределе, сверка текстов зелёная.

### Этап 2 — статьи правила и привязки

Правило ведения работы получает те же требования словами этого слоя, компаньон — строки о том,
чем каждое держится. Спек поддомена получает правила и сценарии.

**Готово, когда:** `npm run check:specs` не называет ни правила без привязки, ни привязки без
правила.

### Этап 3 — сценарии в наборе

Сценарии заводятся в набор пакета там, где их есть чем проверить, а где нечем — правило прямо
говорит, что держится это чтением, и сценарий не заводится.

**Готово, когда:** набор зелёный, каждый заведённый сценарий связан с заголовком теста.

### Этап 4 — закрытие

Раскладка, набор целиком, разбор папки задачи последним коммитом, заявка черновиком.

**Готово, когда:** гейт пуша зелёный, папка разобрана, заявка открыта.

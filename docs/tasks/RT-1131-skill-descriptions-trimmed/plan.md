## Что считается сделанным

- Ни одно описание правила или паттерна не длиннее трёхсот знаков, кроме названных в перечне
  принятого долга поимённо.
- Проверка длины описаний зовётся командой дерева и стоит в наборе гейта пуша.
- Команда счёта показывает вход в работу меньше прежних 55 142 знаков, и число названо в
  замысле эпика.

## Этапы

### 1. Проверка длины описаний заведена

- **Что делается:** проверка читает шапку каждого скила, называет превысивших поимённо с числом
  знаков, знает перечень принятого долга.
- **Признак готовности:** на нынешнем дереве она краснеет и перечисляет сорок описаний.
- **Чем проверяется:** `npm run check:descriptions` — список превысивших с числами.

### 2. Описания обрезаны до предела

- **Что делается:** сорок описаний переписываются так, чтобы отвечать на один вопрос — брать
  правило или нет; у паттернов остаётся и строка о том, когда его не брать.
- **Признак готовности:** проверка молчит либо называет только принятый долг.
- **Чем проверяется:** `npm run check:descriptions` — зелёная; `npm run agent-kit:cost` — вход
  в работу ниже 55 142 знаков.

### 3. Предел назван в слое правил и договорённость влита

- **Что делается:** предел и форма описания встают в правило заведения правил, договорённость
  переезжает поддоменом в спек домена.
- **Признак готовности:** сценарии закрыты тестами, привязки на месте.
- **Чем проверяется:** `npm run check:specs` — ни одной строки о непокрытом сценарии этого
  поддомена.

## Чего эта работа не делает

- Тело правил и паттернов не режется — это задачи RT-1132…RT-1135.
- Предел длины самого правила не пересчитывается — это RT-1139.

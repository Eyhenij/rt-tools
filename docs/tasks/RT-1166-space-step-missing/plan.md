**Поведение:** не меняется — правка задевает шаблон витрины и проверку дерева, а не код

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Мёртвых ссылок на токены в ките не осталось.
- `npm run check:tokens-graph` зелёный.
- Названо, входит ли эта проверка в гейт пуша, и если нет — она туда встаёт либо причина
  записана.
- Кадр, который правка двигает, осмотрен глазами до пересъёмки.

## Этапы

### 1. Мёртвая ссылка снята

- **Что делается:** вызов переводится на существующую ступень шкалы отступов.
- **Признак готовности:** проверка графа токенов расхождений не находит.
- **Чем проверяется:** `npm run check:tokens-graph` — расхождений ноль.

### 2. Проверка встала в гейт пуша

- **Что делается:** выясняется, почему проверка графа не отбивала пуш, и она либо ставится в
  набор, либо получает объявленное исключение с причиной.
- **Признак готовности:** красная проверка графа отбивает пуш, а не проходит мимо.
- **Чем проверяется:** `bash projects/agent-kit/tests/tree-push-checks.test.sh` — набор гейта по
  предмету правки без расхождений.

### 3. Кадр осмотрен и переснят

- **Что делается:** истории, которых касается правка, открываются глазами, потом снимается
  эталон.
- **Признак готовности:** кадр показывает отступ там, где его не было, пустых показов нет.
- **Чем проверяется:** `pnpm run test:visual:v2` — после осмотра и точечной пересъёмки сверка
  зелёная.

### 4. Работа отдана

- **Что делается:** папка задачи разбирается, заявка открывается черновиком.
- **Признак готовности:** ветка папки не везёт, заявка открыта.
- **Чем проверяется:** `node tools/check-push-gate.mjs` — гейт не отбивает.

## Чего эта работа не делает

- Не уплотняет шкалу отступов: разрежённый ряд — решение шкалы, а не промах.
- Не трогает прочие проверки слоя оформления и их место в гейте.

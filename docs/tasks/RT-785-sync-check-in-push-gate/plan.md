## Что считается сделанным

- Статья о сверке раскладки в наборе гейта пуша стоит во всех видах ресурса правила поставки и
  в разложенном `.claude/skills/git-workflow/SKILL.md`.
- Набор гейта этого дерева печатает строку сверки раскладки.
- Умолчание пакета печатает свою форму той же сверки там, где лежит настройка раскладки, и
  молчит там, где её нет; закрыто сценарием в `projects/agent-kit/tests/defaults.test.sh`.
- Наведённое расхождение — правка разложенного файла на месте — отбивает `git push` гардом
  проверок; после отката правки пуш проходит.
- Спутник правила называет, чем статья держится в этом дереве.
- `bash projects/agent-kit/tests/run.sh` и `pnpm run agent-kit:check` зелёные.

## Этапы

### 1. Статья в правиле поставки

- **Что делается:** в раздел «Как закон применяется здесь» каждого вида ресурса правила
  поставки дописывается статья о том, что сверка раскладки стоит в наборе гейта пуша наравне с
  линтом и сборкой.
- **Признак готовности:** статья есть во всех трёх видах одним и тем же текстом — она про слой
  правил, а не про хостинг.
- **Чем проверяется:** поиск по трём файлам; `bash projects/agent-kit/tests/texts.test.sh`.

### 2. Умолчание пакета печатает сверку

- **Что делается:** `rt_push_checks_default` печатает вызов сверки раскладки, когда в дереве
  лежит настройка раскладки; признак — сам файл настройки, а не догадка о том, поставлен ли
  пакет.
- **Признак готовности:** дерево с настройкой получает строку, дерево без настройки — нет.
- **Чем проверяется:** сценарий в `projects/agent-kit/tests/defaults.test.sh`, прогон
  `bash projects/agent-kit/tests/run.sh`.

### 3. Надстройка этого дерева зовёт свою форму

- **Что делается:** в набор гейта профиля дерева встаёт строка сверки. Здесь пакет не ставится
  зависимостью, а собирается из исходников, поэтому зовётся именованный скрипт дерева.
- **Признак готовности:** набор гейта печатает строку, и на сошедшемся дереве она проходит за
  секунды.
- **Чем проверяется:** вывод набора гейта; замер времени прогона.

### 4. Красное отбивает пуш

- **Что делается:** проверяется само требование — расхождение раскладки не пускает пуш.
- **Признак готовности:** правка разложенного файла на месте отбивает `git push` отказом гарда
  проверок, а откат правки пуш возвращает.
- **Чем проверяется:** наведённое расхождение и попытка пуша, затем откат.

### 5. Привязка в спутнике правила и раскладка

- **Что делается:** строка о новой статье встаёт в таблицу привязок спутника правила поставки;
  пакет пересобирается и раскладывается.
- **Признак готовности:** `pnpm run agent-kit:check` зелёный, разложенное правило несёт статью.
- **Чем проверяется:** `pnpm run agent-kit:sync`, затем `pnpm run agent-kit:check`.

## Чего эта работа не делает

- **Сверка не судит образец события у гарда против настройки дерева.** Задача подняла это
  смежным и оставила решение планированию; решено вынести — это предмет задачи RT-768, которая
  берётся следующей и там же называет, чем расхождение находится впредь.
- **Набор конвейера не трогается.** Сверки раскладки в конвейере нет и не заводится: она судит
  разложенное в рабочем дереве, а в конвейер приезжает уже сошедшееся.

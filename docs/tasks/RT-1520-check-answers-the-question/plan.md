## Что считается сделанным

- Закон проверяемости называет, чем признак проверки выбирается, и что чужой отказ службы
  диагнозом чужой настройки не бывает.
- Закон называет, где живёт ответ о прошлом поведении: код той версии, а не тело правки.
- Правило проверки через браузер несёт приём под обе статьи.
- `npm run check:all` и набор проб пакета зелёные, `agent-kit:check` расхождений не находит.

## Этапы

### 1. Статьи закона

- **Что делается:** в раздел «Статьи» закона проверяемости дописываются две статьи — о выборе
  признака и о том, где читается прошлое поведение.
- **Признак готовности:** обе статьи стоят, предел веса текста выдержан.
- **Чем проверяется:** `node tools/check-file-size.mjs` — вывод без строки о законе проверяемости.

### 2. Приём в правиле

- **Что делается:** в правило проверки через браузер дописывается ловушка о признаке, снятом по
  предмету правки, и о чужом отказе службы.
- **Признак готовности:** ловушка стоит, вес правила выдержан.
- **Чем проверяется:** `node tools/check-file-size.mjs` — вывод без строки о правиле.

### 3. Раскладка и закрытие

- **Что делается:** правки разложены в дерево, сценарии заведены в спек домена, тексты приведены,
  папка разобрана, заявка открыта черновиком.
- **Признак готовности:** раскладка сходится, спеки сверены, набор зелёный.
- **Чем проверяется:** `pnpm run agent-kit:check && npm run check:specs && npm run check:all` —
  ни одной строки расхождения.

## Чего эта работа не делает

- Гарда под новые статьи не заводит: выбор признака машине не виден — судить нечем.
- Разрешения работать вне эпика не трогает: оно ждёт слова владельца соседнего дерева.

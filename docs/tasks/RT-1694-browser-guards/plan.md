## Что считается сделанным

- Метка свежести выбора ставится по исходу вызова: отказавший выбор метки не оставляет.
- Сверка запрошенного признака с закреплённым остаётся на событии до вызова.
- Гард завершения хода судит просьбу к владельцу войти или ввести пароль и называет пути, которыми
  препятствие снимается своими силами.
- Оба гарда покрыты сценариями, раскладка положила их, сверка зелёная.

## Этапы

### 1. Метка по исходу вызова

- **Что делается:** гард признака профиля получает вторую ветку на событии после вызова; метка
  ставится там, а сверка признака остаётся до вызова.
- **Признак готовности:** отказавший выбор метки не оставляет, состоявшийся — оставляет.
- **Чем проверяется:** набор `browser-device-id.test.sh`.

### 2. Гард просьбы войти

- **Что делается:** новый гард на завершении хода с набором образцов просьбы; свой набор
  сценариев; запись в карту хуков.
- **Признак готовности:** просьба «введи пароль» отбита, просьба о режиме работы — нет.
- **Чем проверяется:** новый набор сценариев, `pnpm run agent-kit:sync`, `agent-kit:check`,
  тесты пакета.

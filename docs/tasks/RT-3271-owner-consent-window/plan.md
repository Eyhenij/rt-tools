## Чего эта работа не делает

- **Чтение слов владельца движком хода работы** — цитата замены проверки шага и строка плана эпика с
  цитатой — вынесено в задачу RT-3352 эпика. Пункт задачи «ни одна проверка не читает ответ
  владельца» этой работой выполнен для двух проверок из трёх, и описание PR говорит это прямо. Слово
  «стоп» владельца остаётся: это остановка, а не согласие, и его чтение владелец заказал в RT-3329.
- **Окно в приложении живым вызовом не проверяется**: в этом дереве эпик не кончился, и вызвать
  проверку конца эпика по-настоящему нечем. Опора — документация хуков Claude Code: «ask»
  показывает окно и в режиме auto, причина видна владельцу. Первый настоящий конец эпика после
  раскладки — живая проверка; в субагенте и при запуске с `-p` окно не показывается, причина уходит
  модели.
- **Соседние проверки на тех же вызовах** (`tree-assignment-guard`, проверки ветки эпика) судят
  назначение копии и базу ветки, а не согласие владельца; решение `deny` старше `ask`, и их отказ
  окно перекроет. Строка назначения копии, пережившая эпик, — известный промах, вне этой задачи.
- Таблица решений проверок — RT-3275; правила поставки на хостинге — RT-3272.

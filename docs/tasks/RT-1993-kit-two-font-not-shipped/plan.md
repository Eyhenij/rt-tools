# Замысел

**Задача:** RT-1993 · **Ветка:** RT-1993-kit-two-font-not-shipped
**Поведение:** меняется — кит начинает рисоваться тем шрифтом, который называет, а не тем,
который случайно стоит на машине читателя.
**Черновик:** `docs/specs/ui-kit-v2/proposed/font-delivery/`

После записи этот файл не правится. Пересмотр этапа уходит в ход работ решением по пути.

## Что считается сделанным

- Кит везёт начертания, которые называет, либо перестаёт называть те, которых не везёт.
- Витрина рисует тем же шрифтом, каким кит нарисуется у потребителя.
- Прогон снимков второго кита зелёный на машине, где ни одного из названных семейств не
  установлено.
- В README второго кита сказано, откуда шрифт берётся у потребителя.
- Утверждение компаньона правила проверки через браузер про «раннер на той же машине, что и
  разработчик» приведено к правде.

## Этапы

### 1. Решено, откуда шрифт берётся

- **Что делается:** выбирается один из трёх путей — кит везёт начертания файлами, кит называет
  шрифт требованием к потребителю, или витрина и кит расходятся сознательно. Выбор пишется
  договорённостью о продукте с доводами.
- **Признак готовности:** договорённость лежит и называет цену выбранного пути.
- **Проверено:** `node tools/check-specs.mjs` — договорённость видна разбору.

### 2. Шрифт приезжает вместе с китом

- **Что делается:** выбранный путь исполняется в источнике оформления и в витрине.
- **Признак готовности:** на машине без установленных семейств страница рисует именно тот шрифт,
  который назван, а не запасной.
- **Проверено:** замер ширины строки на поднятой витрине — ширина названного семейства не равна
  ширине запасного.

### 3. Эталоны пересняты и перестали зависеть от машины

- **Что делается:** эталонные кадры второго кита переснимаются под приехавший шрифт.
- **Признак готовности:** прогон зелёный дважды подряд на этой машине.
- **Проверено:** `node tools/visual-gate.mjs ui-kit-v2` — два зелёных прогона.

### 4. Тексты приведены к правде

- **Что делается:** README второго кита говорит, откуда шрифт; компаньон правила проверки через
  браузер перестаёт утверждать, что раннер и разработчик стоят на одной машине.
- **Признак готовности:** оба текста отвечают тому, что в дереве.
- **Проверено:** `node tools/check-specs.mjs` и `pnpm run agent-kit:check`.

## Чего эта работа не делает

- Не трогает первый кит и его эталоны.
- Не меняет сами значения токенов размера и отступов: работа возвращает шрифт, под который они
  посчитаны, а не пересчитывает их.
- Не переносит компоненты первого кита: это задачи RT-1878 и далее.

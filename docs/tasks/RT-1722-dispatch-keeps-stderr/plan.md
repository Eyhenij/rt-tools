# Замысел

**Поведение:** не меняется — правится диспетчер слоя правил, кода приложения работа не трогает.

## Этап 1. Поток ошибок ветки доходит до отказа

Диспетчер собирает поток ошибок ветки отдельно и при ненулевом коде печатает его, если ветка не
сказала ничего своим выводом. Строка о сломанном файле остаётся для случая, когда молчат оба.

## Этап 2. Сценарии, спека и набор

Сценарии в наборе диспетчера, статья и адрес в домене, весь shell-набор пакета.

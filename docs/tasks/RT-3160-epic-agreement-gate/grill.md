# Grill

## The owner's request

Владелец выбрал в меню: «Поправить проверку (Recommended)», затем «Отдельный PR в main (Recommended)».

Вопрос был о том, что проверка не даёт открыть PR RT-3152 в ветку эпика. Сессия запускает проверки из основной копии на main, поэтому правка работает только после попадания в main.

## Decisions

- **Проверка смотрит на базу PR.** Договорённость обязана быть влитой только у PR в main.
- **PR эпика судится по планам всех его задач.** Иначе у ветки эпика нет своей папки, и невлитая договорённость уехала бы в main.

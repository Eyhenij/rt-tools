## Этапы

1. **Статьи правил.** Шесть предложений о правилах и законе ложатся статьями в свои разделы;
   каждая получает строку привязки в компаньоне дерева либо вердикт «Не проверяется ничем».
   Готово, когда `check-specs` расхождений не называет.
2. **Паттерны.** Два предложения о паттернах ложатся в их разделы: команда мержа с переменными
   подписи и запись о том, что не выводится из кода. Готово, когда предел длины сходится.
3. **Гард места правки.** Предложение о том, что гейт судит написанное командой, разбирается по
   телу гарда: либо правка с новым сценарием, либо вердикт о том, почему это уже держится.
   Готово, когда набор проб зелёный.
4. **Закрытие.** Тексты приведены, набор проб прогнан, папка разобрана в архив, заявка открыта
   черновиком на вершине череды.

## Что не входит

- Семьдесят две записи приёма без готовой формулировки: их читают по одной, это отдельная работа.
- Отметка записей соседа в приёме: её принимает только отправившее дерево.

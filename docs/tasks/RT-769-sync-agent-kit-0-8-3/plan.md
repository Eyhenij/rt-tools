# Замысел

**Задача:** RT-769 · **Ветка:** RT-769-sync-agent-kit-0-8-3
**Поведение:** не меняется — правятся шапки разложенных файлов слоя правил, содержимое ни одного
из них не меняется; ни `apps/**`, ни `libs/**` работа не задевает. Подтверждено владельцем
просьбой «разложи файлы локально в соответствии с новой версией».

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Разложенное в дереве несёт шапку выпущенной редакции, а не предыдущей.
- `agent-kit sync --check` отвечает, что разложенное сходится с пакетом выпущенной редакции.
- Ни один разложенный файл не правлен на месте: разница с предыдущей раскладкой — только номер
  в шапке, кроме тех ресурсов, которые редакция изменила по существу.
- Гарды, стоящие в настройке дерева, после раскладки зовутся на то же, что объявляют.
- Гейт пуша и конвейер зелёные.

## Этапы

### 1. Раскладка снята с выпущенной редакции

- **Что делается:** главная ветка подтягивается уже с подъёмом номера от конвейера выпуска,
  затем гоняется `pnpm run agent-kit:sync`.
- **Признак готовности:** `agent-kit sync --check` нулевой и называет выпущенный номер.
- **Чем проверяется:** `pnpm run agent-kit:check`.

### 2. Правка разобрана, а не принята на веру

- **Что делается:** разница раскладки читается целиком — отделяется смена номера в шапке от
  правок по существу, и каждая правка по существу называется в теле PR.
- **Признак готовности:** в теле PR сказано, что именно изменила редакция, кроме номера.
- **Чем проверяется:** чтение `git diff`, сверка объявлений гардов с настройкой дерева.

### 3. Дерево проверено целиком

- **Что делается:** гоняются проверки текстов, наборы сценариев по гардам пакета и дерева,
  сборка и линтеры.
- **Признак готовности:** все нули.
- **Чем проверяется:** `npm run check:docs`, `check:specs`, `check:dupes`, `check:hooks`,
  `bash projects/agent-kit/tests/run.sh`, `nx affected -t lint typecheck test build`.

## Чего эта работа не делает

- **Не выпускает версию.** Выпуск — отдельное решение владельца и отдельный конвейер; сюда
  приходит уже выпущенный номер.
- **Не правит разложенные файлы на месте.** Что дереву нужно иначе, чем в пакете, идёт
  надстройкой; правка в месте раскладки теряется на следующем `sync`.
- **Не чинит того, что редакция принесла сломанным.** Найденное заводится задачей и чинится
  в пакете, а не в разложенной копии.

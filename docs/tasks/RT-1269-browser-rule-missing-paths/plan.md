# Замысел

**Поведение:** не меняется — правится правило и его компаньон, требований к продукту задача не
трогает.

Пять записей об одном роде промаха: правило не называет пути, и вывод «нечем» или «можно»
выглядит верным. Правятся два раздела одного файла, и откатываются они вместе.

## Этапы

1. Две статьи в «Как закон применяется здесь»: закрытый входом экран и ненастроенная стража.
2. Три ловушки: замер сквозной спекой, утверждение о прод-сборке, отбитое снятие процесса.
3. Привязки в компаньоне под обе новые статьи.
4. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Шестая запись того же дерева — про экран, данных для которого в базе разработки не бывает, —
уже в правиле стоит и задачей не трогается.

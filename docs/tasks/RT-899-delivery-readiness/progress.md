# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `замысел-записан`
- **Этап:** 1 из 5 — готовность к поставке одним ответом
- **Сделано:** задача взята в работу, ветка и папка собраны, разведка закрыта, разбор и замысел написаны
- **Следующий шаг:** завести функцию готовности к поставке в профиле пакета
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет — владелец назначил автономный ход
- **PR:** не открывается — владелец запретил пуш веток, работа держится локально

## Решения по ходу

- **Вопросы владельцу не задаются** — он назначил автономный ход и запретил вопросы, которые
  прерывают работу. Решения принимает исполнитель и записывает их в разбор просьбы с доводами.
  Затронутый этап замысла: все.

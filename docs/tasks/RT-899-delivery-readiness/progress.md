# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 5 из 5 — тексты и сценарии
- **Сделано:** этапы с первого по четвёртый. Отказ поставки называет несошедшееся целиком; колонка очереди работ вошла в проверку задачи; основание ветки и почта коммитов спрашиваются при заведении ветки; ревьювер спрашивается на снятии черновика
- **Следующий шаг:** принять сценарии и тексты от ролей, разложить пакет и закоммитить
- **Незакоммиченное:** правки ролей — сценарии и тексты
- **Ждём владельца:** нет — владелец назначил автономный ход
- **PR:** не открывается — владелец запретил пуш веток, работа держится локально

## Решения по ходу

- **Ветка задачи выросла из ветки о выключаемых ролях** — команда прогона наборов по хукам
  заведена там, и замысел этой задачи на неё ссылается. Ветка влита сюда целиком. Затронутый
  этап замысла: все.
- **Готовность собирается не одной функцией профиля, а накопителем в самом гарде** — условия
  поставки читаются из разных источников: часть из истории веток, часть из очереди работ, часть
  из настроек рабочей копии. Функция, собирающая их все, звала бы сеть и на тех точках, где она
  не нужна. Накопитель даёт то же, ради чего задумывалась функция: несошедшееся называется
  целиком, а не по одному промаху на круг. Затронутый этап замысла: 1.
- **Подпись коммитов исправлена посреди работы, а прежние коммиты не переписываются** — дерево
  подписывало их учётной записью владельца, хотя профиль объявляет почтой машинной записи
  другую. Дальше коммиты идут от объявленной; уже сделанные остаются как есть: часть из них
  влита из запушенной ветки, и переписывание сменило бы им имена. Нашла это правка самой
  задачи — проверка подписи при заведении ветки. Затронутый этап замысла: 3.
- **Вопросы владельцу не задаются** — он назначил автономный ход и запретил вопросы, которые
  прерывают работу. Решения принимает исполнитель и записывает их в разбор просьбы с доводами.
  Затронутый этап замысла: все.

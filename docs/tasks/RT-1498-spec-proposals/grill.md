# Разбор просьбы

Третья работа по замыслу `docs/plans/proposals-backlog.md` — семья договорённости о продукте,
четыре задачи из остатка. Две из них (#870 и #875) об одном: форма заголовка записи в разделе
решений.

## Просьба владельца

> бери дальше предложения и происшествия из приёмника одну за другой и заводи ветки и делай
> изменения

## Что берётся в работу

- **#826.** Утверждение, стоящее в другом разделе того же спека, заводится вторым пунктом правил:
  признака под этот случай нет, и выбор делается заново каждый раз.
- **#828.** Запись, повторяющая статью правила слово в слово, держится доводом при ней.
- **#870, #875.** Заголовок записи раздела решений называется датой — по образцу спека, который
  дату и просил. Три влитых поддомена приехали с датированными заголовками.

## Решения

- #870 и #875 закрываются одной статьёй: они об одном промахе, приехали из двух деревьев.
- Образец спека правится вместе с паттерном: пока он просит дату, статья остаётся обещанием.

## Что считается сделанным

- Поиск по формам слова не находит его нигде, кроме трёх вхождений второго значения, описания
  прошлого, папок задач и левой колонки раздела «Так не пишем» словаря.
- Словарь несёт строку `PR` в разделе «Работа» и строку `отчёт (о заявке на слияние)` в разделе
  «Так не пишем» — обе приезжают из пакета, а не из надстройки дерева.
- `pnpm run agent-kit:check` говорит, что разложенное сходится с пакетом.
- `npm run check:docs` зелёный, все сценарии гардов пройдены, юниты пакета зелёные.
- Тела задач очереди работ, где слово стоит, обойдены отдельным проходом: проверки текстов туда
  не смотрят.

## Этапы

### 1. Ресурсы пакета — законы, правила, паттерны, скилы, словарь

- **Что делается:** слово меняется в `projects/agent-kit/assets/` — три закона, правила
  поставки во всех трёх редакциях площадок, правила ведения работы, документации и
  проверяемости, паттерны коммита и закрытия работы, скил пакета, словарь. В словарь той же
  правкой встают обе новые строки.
- **Признак готовности:** в `assets/**/*.md` слова нет.
- **Чем проверяется:** поиск по формам слова в каталоге ресурсов.

### 2. Ресурсы пакета — обвязка

- **Что делается:** слово меняется в хуках, сверках, умолчаниях профиля, командах и сценариях
  гардов: `assets/hooks/`, `assets/checks/`, `assets/defaults/`, `assets/commands/`,
  `projects/agent-kit/tests/`. Строки отказов, которые гард печатает агенту, — часть этого.
- **Признак готовности:** слова нет ни в одном исходнике пакета, кроме двух вхождений второго
  значения в коде.
- **Чем проверяется:** сценарии гардов и юниты пакета зелёные.

### 3. Раскладка и своё дерева

- **Что делается:** `prettier --write` на правленых ресурсах, `agent-kit:sync`, затем правка
  того, что раскладкой не собирается: надстройка словаря, профиль дерева, компаньоны правил,
  свои скилы дерева.
- **Признак готовности:** `agent-kit:check` сходится, в `.claude/` слова нет.
- **Чем проверяется:** `pnpm run agent-kit:check`.

### 4. Спеки, разборы, планы, журнал изменений

- **Что делается:** слово меняется в спеке домена и его сценариях, в договорённостях
  `proposed/`, в разборах происшествий, в плане слоя правил, в README и журнале изменений
  пакета.
- **Признак готовности:** слова нет вне оговорённых исключений.
- **Чем проверяется:** сплошной поиск по дереву.

### 5. Проверки и заявка на слияние

- **Что делается:** весь набор гейта, обход тел задач в очереди работ, коммит, заявка.
- **Признак готовности:** заявка открыта и зелёная.
- **Чем проверяется:** набор проверок конвейера и состояние заявки у площадки.

## Чего эта работа не делает

- Не трогает `docs/archive/` — описание прошлого выведено из проверок целиком.
- Не трогает три вхождения второго значения: сводка прогона в спеке раскладки ресурсов, минус в
  счёте задач и текст витрины подсказки.
- Не правит заголовки уже влитых заявок и заголовки коммитов: заголовок коммита после вливания
  переписыванием ветки не правится, а слово в них описывает прошлое.
- Не заводит проверки на слово: `doc-style` прямо говорит, что формулировочные договорённости
  здесь не проверяет ничто. Отдельной задачи на это не заводится — предложение о ней не
  приходило.

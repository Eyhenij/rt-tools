# Разбор просьбы

Две записи груза из приёма, соседние деревья, ресурс `hooks/grill-gate.sh`. Отметить их этому
дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Дерево берёт гарда целиком или не берёт вовсе

Инструмент вопроса — единственный способ спросить владельца, и на нём у дерева уже может стоять
свой гард со своей причиной отказа. Второй отказ на том же инструменте делает вопрос недоступным
вовсе, и дерево отказывается от гарда целиком вместо того, чтобы получить его половину.

Ловля прозаического вопроса на завершении хода и ловля меню на инструменте — два разных
требования, и они разводятся по двум объявлениям.

## Что в работу не берётся

Вторая запись просит считать чтением загрузку правила, которое требуется области работы этого
хода, а не любой файл слоя правил. Область гард берёт из карты гейта, а карта отвечает на путь
правки — у хода с вопросом правки нет вовсе, и брать область неоткуда. Правка отложена до
владельца: она меняет само требование, а не его исполнение.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

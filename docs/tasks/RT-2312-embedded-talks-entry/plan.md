## Stages

### 1. Подпись и признак страницы — чистой логикой

1. Дописать в `chat-hook.logic.ts` счёт подписи входа: ключ сайта и минута.
2. Написать разбор признака страницы: что в нём лежит, когда он истёк.
3. Покрыть обе проверками рядом с файлом.

Признак готовности: проверки `@rt/message-bus-api` зелёные, новые проверки называют сцены.

### 2. Операция обмена подписи на признак

1. Завести операцию в чтении чата: принимает ключ, минуту и подпись, отвечает признаком.
2. Отказы: нет подписи, не сходится, минута вне допуска, неизвестный или выключенный ключ.
3. Покрыть проверками контроллера.

Признак готовности: проверки контроллера зелёные, сцены `SC-CH-83` … `SC-CH-86` закрыты.

### 3. Операции чтения под признаком страницы

1. Пустить чтение списка, чтение сообщений, ответ и закрытие разговора под признаком.
2. Сузить каждую до сайта признака; чужая переписка отвечает как ненайденная.
3. Просроченный признак отвечает своим отказом.

Признак готовности: сцены `SC-CH-87` и `SC-CH-88` закрыты, пометки о непокрытии сняты.

### 4. Отдать работу

1. Привести компаньон описания: правила, которые теперь выполнены, получают адреса в коде.
2. Разобрать папку задачи последним коммитом, добавив запись в `docs/archive/`.
3. Набор перед отправкой, отправка, PR в ветку задачи RT-2311 стопкой, рецензент, номер владельцу.

Признак готовности: PR открыт, номер назван.

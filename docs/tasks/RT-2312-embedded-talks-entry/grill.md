# Grill

## Просьба владельца дословно

«реализуй экраны для админки», затем «делай эпик далее». Задача вторая в эпике RT-2309 и взята по
его плану.

## Что выяснено до первого правки

- Чтение переписок закрыто сеансом оператора приёмника:
  `libs/message-bus-api/chat/feature/src/lib/chat-read.controller.ts`, метка `@SessionOperation()`.
- **У сайта уже есть тайна подписи** — поле `hookSecret` в модели `ChatSite`
  (`prisma/schema.prisma`). Ею сервис подписывает вызовы наружу, и приложение потребителя её уже
  держит у себя на сервере, чтобы эти вызовы проверять.
- Подпись уже считается одним местом: `chatHookSignature` в
  `libs/message-bus-api/chat/util/src/lib/chat-hook.logic.ts` — HMAC-SHA256, шестнадцатеричная
  строка.
- Список разрешённых адресов сайта проверяется отдельным местом:
  `libs/message-bus-api/chat/util/src/lib/chat-origin.logic.ts`.

## Решения и доводы

- **Вторую тайну сайту не заводим: подписываем тем же `hookSecret`.** Он уже лежит у потребителя на
  сервере и заведён ровно для того, чтобы отличать сервис от постороннего. Вторая тайна значила бы
  два секрета в одном приложении и два места, где их теряют. Описание задачи RT-2311 называет
  «секрет сайта» — это он и есть, и компаньон описания это скажет.
- **Сайт без тайны на страницу не пускает.** Так же, как он не получает вызовов наружу: настроенная
  наполовину площадка не должна открывать переписки.

# Замысел

**Поведение:** не меняется — правится текст холодной части скила о переносимом слое.

## Что делается

1. Пункт о прогоне сценариев гардов называет, где эта обвязка живёт, и говорит прямо, что в
   поставке её нет.
2. Там же — что остаётся дереву-потребителю: свои сценарии на свои гарды.

## Чем проверяется

`npm run agent-kit:sync`, `npm run agent-kit:check`, `node tools/check-file-size.mjs`,
`node tools/check-doc-paths.mjs`, `node tools/check-prose-style.mjs` на правленом файле.

## Этапы

### 1. Пункты сверены с деревом

- **Что делается:** каждый из двенадцати пунктов проверяется по нынешним ресурсам пакета.
- **Признак готовности:** у каждого назван исход — закрыт чем-то или жив.
- **Чем проверяется:** `grep -c '^- \*\*' docs/plans/package-boundary-findings.md` — 0 после разбора.

### 2. Живое внесено правкой

- **Что делается:** три живых пункта ложатся статьями в паттерны и ловушки.
- **Признак готовности:** каждый живой пункт назван текстом ресурса.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка кладёт файлы без отказа.

### 3. Файлы находок переписаны

- **Что делается:** оба файла сводятся в таблицы «чем закрыт».
- **Признак готовности:** пунктов ноль в обоих.
- **Чем проверяется:** `npm run check:docs` — пути, названные в текстах, существуют.

## Чего эта работа не делает

- Не трогает три остальных файла находок: их пункты к этим эпикам не относятся.

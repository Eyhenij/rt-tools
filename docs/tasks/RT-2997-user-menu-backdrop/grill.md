# Разбор: меню учётной записи на узком экране без затемнения

## Просьба владельца

Владелец принял кадр админки VillaManager с меню учётной записи на затемнении и ответил на вопрос,
где описана правка шапки кита и новая версия: «Подходит, делай (Рекомендую)». Кадр:
https://www.figma.com/design/I3fuRHUIcEhw6WPIsd29nP/Villa-Manager-V1?node-id=8856-77742, задача
VillaManager VM-3200.

## Что уже есть в дереве

- Кнопка бургера шапки открывает меню разделов с `rtPopoverBackdropClass="rt-page-header-mobile-backdrop"`:
  задача RT-2987. Цвет подложки `--rt-color-bg-overlay`.
- Кнопка имени открывает меню наведением, класса подложки у неё нет.
- Шапка знает узкий экран: `isNarrow`, до 1080.

## Решения

**1. Подложка у меню имени только на узком экране.** На широком меню открывается наведением, и
подложка мигала бы на каждом проходе мыши.

**2. Класс тот же, что у бургера.** Два меню одной шапки на телефоне ведут себя одинаково.

## Шесть вопросов

| Вопрос                     | Ответ                                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------- |
| Меняет ли задача поведение | Да: на узком экране под меню имени затемнение, щелчок по нему закрывает меню            |
| Требует ли правки закона   | Нет                                                                                     |
| Одна задача или несколько  | Одна                                                                                    |
| Что не входит              | Меню на широком экране, меню разделов                                                   |
| Чем видно закрытие         | Тест шапки: на узком экране у меню имени класс подложки, на широком нет; витрина на 375 |
| Есть ли образец            | RT-2987, подложка меню разделов                                                         |

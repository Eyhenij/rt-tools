## Этапы

### 1. Раздел волны 4 в линии работ

- **Что делается:** 26 папок делятся по роду — списки, панели, оболочки, показ данных; на
  каждую называется ось, которую показывает матрица. Раздел дописывается в линию рядом с
  волнами 1–3.
- **Признак готовности:** ни одна из 26 папок не осталась вне списка.
- **Чем проверяется:** сверка списка с выводом обхода папок.

### 2. Матрицы и обзоры по группам

- **Что делается:** группа за группой, внутри группы — от богатой матрицы к бедной. На папку:
  `Overview.mdx`, `<имя>-matrix.stories.ts`, обёртка `test-<имя>-matrix.component.ts` с
  ветками по осям. Обвязка `src/showcase/` берётся готовой.
- **Признак готовности:** у каждой папки группы есть обзор и матрица; `nx verify` зелёный.
- **Чем проверяется:** `nx verify`, `nx run @rt-tools/ui-kit-v2:typecheck`, `lint`.

### 3. Проход глазами

- **Что делается:** витрина поднимается своим портом, каждый компонент волны открывается в
  обеих темах.
- **Признак готовности:** ни одна ячейка не пуста, ни одна ось не показана одним значением.
- **Чем проверяется:** витрина в браузере; замеры вычисленных значений там, где глазами не
  видно.

### 4. Замеры линии и закрытие

- **Что делается:** строка волны 4 в таблице «Ход» линии работ; замеры «Где кит сейчас»
  пересчитываются командой.
- **Признак готовности:** числа в линии сходятся с деревом.
- **Чем проверяется:** `pnpm run check:all`, `pnpm run build-storybook:ui-kit-v2`.

- Не закрывает долг по спекам: 11 папок, где спек меньше, чем компонентов.
- Не чинит дефекты кита, найденные по ходу: они записываются отсутствием предмета в обзоре и
  заводятся задачами.
- Не отправляет ветку и не открывает отчёт — владелец запретил пуш.

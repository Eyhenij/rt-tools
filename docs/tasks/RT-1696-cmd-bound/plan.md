# Замысел

**Задача:** RT-1696 · **Ветка:** RT-1696-cmd-bound
**Поведение:** не меняется — правится признак вызова, которым пользуются гарды

## След задачи

| Что   | Где                                                      |
| ----- | -------------------------------------------------------- |
| Хук   | `projects/agent-kit/assets/hooks/hook-input.sh`          |
| Тесты | `projects/agent-kit/tests/hook-input.test.sh` либо новый |
| Спека | `docs/specs/agent-kit/guards/`                           |

## Что считается сделанным

- Образец границы команды узнаёт вызов, перед которым стоит присваивание со значением-подстановкой
  или значением в кавычках.
- Гард поставки судит команду `GH_TOKEN=$(cat <файл>) gh pr create …` наравне с голой.
- Прежние случаи не поехали: голый вызов, вызов за разделителем, вызов полным путём, упоминание в
  кавычках командой по-прежнему не считается.
- Сценарии закрыты, весь набор пакета зелёный.

## Этапы

### 1. Образец и сценарии

- **Что делается:** значение присваивания принимает форму подстановки и форму в кавычках; сценарии
  на обе и на прежние случаи.
- **Признак готовности:** команда с подстановкой судится, ложных срабатываний на упоминании нет.
- **Чем проверяется:** наборы гардов поставки и разбора команд, весь shell-набор пакета.

### 2. Спека и сверки

- **Что делается:** правило в спеке гардов, адрес в компаньоне, сценарий.
- **Признак готовности:** проверки спек и адресов зелёные, тесты пакета зелёные.
- **Чем проверяется:** `node tools/check-specs.mjs`, `node tools/check-doc-paths.mjs`,
  `pnpm exec nx test @rt-tools/agent-kit`.

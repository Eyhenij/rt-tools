# Замысел

**Задача:** RT-1591 · **Ветка:** RT-1591-archive-overdue-prune
**Поведение:** не меняется — работа снимает дожившие до срока записи описания прошлого и кода
приложения не касается.

## След задачи

| Что      | Где                                                        |
| -------- | ---------------------------------------------------------- |
| Описание | `docs/archive/`                                            |
| Проверки | `tools/check-archive-age.mjs`, `tools/check-doc-paths.mjs` |

## Что считается сделанным

- Проверка срока не называет ни одной записи.
- Сверка адресов не называет ни одной ссылки в снятое.

## Этапы

### 1. Снятие записей

- **Что делается:** дожившие до срока записи снимаются командой дерева, а ссылки на них
  правятся там, где остались.
- **Признак готовности:** обе проверки молчат.
- **Чем проверяется:** `node tools/check-archive-age.mjs` — расхождений нет;
  `node tools/check-doc-paths.mjs` — расхождений нет.

## Чего эта работа не делает

- Не правит ни проверку, ни срок: повторение красного лечится договорённостью, а её меняет
  владелец.

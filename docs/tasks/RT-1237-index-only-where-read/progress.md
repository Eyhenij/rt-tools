# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — указатель заводится каталогу, который читают по нему
- **Сделано:** задача заведена, ветка и папка на месте, замысел записан, две записи отмечены
- **Следующий шаг:** дописать вторую половину статьи
- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** не открывается — ночью ветки держатся локально по слову владельца

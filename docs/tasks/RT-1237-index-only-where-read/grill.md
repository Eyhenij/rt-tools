# Разбор просьбы

## Просьба владельца

> после обновления agent kit делай задачи из техдолга из приёмника, одну за другой, без
> остановок… не пуш ветки - храни все ветки локально… твоя задача - закрыть как можно больше
> задач в локальных ветках до утра.

## Что взято из приёмника

Две записи своего дерева по правилу текстов.

**Ключ `1667b25f`** — статья «Указатель каталога сверяется с его содержимым обеими сторонами», в
конец. Повод: статья требует сверки и молчит о цене самого указателя. Каталог, куда каждая
закрытая работа дописывает строку, ставит конфликт всем веткам сразу, и дерево читает статью как
требование такой указатель держать — то есть чинит сверку, а не убирает причину. Чем закрывается:
надстройка дерева, раздел «Указателя у описания прошлого здесь нет», снимается целиком, когда
правка приедет редакцией.

**Ключ `402c4d40`** — раздел «Ловушки», рядом с ловушкой о том, что выведенное называется
выведенным. Повод: промах пережил первый доклад именно потому, что в докладе не был назван.
Сказано «прочитал задачу по ссылке» — верно по сути и умалчивает о способе. Владелец принял
доклад, подмена осталась незамеченной до второго указания.

## Чего владелец не спрашивал

Вопросов ночью не задаётся. Обе записи правят один файл.

Надстройка дерева снимается не целиком: два её пункта из трёх говорят о том, чего в статье
пакета не будет — о сложении сторон в настройке слияния и о пустом списке каталогов со сверкой.
Снимается то, что статья закрывает.

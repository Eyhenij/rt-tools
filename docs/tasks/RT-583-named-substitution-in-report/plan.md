# Замысел

**Задача:** RT-583 · **Ветка:** RT-583-named-substitution-in-report
**Поведение:** не меняется — работа правит слой правил, кода приложения не трогает

## Что делается

Закон говорит, что случившаяся подмена инструмента называется в том же докладе: чем сделано
вместо названного и почему.

## След задачи

| Что      | Где                                              |
| -------- | ------------------------------------------------ |
| Спеки    | нет — статьи закона проверками не судятся        |
| Законы   | `projects/agent-kit/assets/laws/work-conduct.md` |
| Правила  | `.claude/skills/turn-conduct/`                   |
| Паттерны | нет                                              |

## Что считается сделанным

- В законе есть статья о названной подмене, и она стоит рядом со статьёй о названном
  инструменте.
- Про место разбора сказано в ходе работы, почему требование записи не исполняется.

## Этапы

### 1. Статья о названной подмене

- **Что делается:** статья встаёт следом за статьёй о названном инструменте.
- **Признак готовности:** закон говорит, что подмена называется в докладе, и чем именно.
- **Чем проверяется:** `node tools/check-file-size.mjs` — длиннее предела 0.

### 2. Раскладка и слог

- **Что делается:** пакет собирается, копия закона раскладывается, проза сверяется.
- **Чем проверяется:** `node tools/check-prose-style.mjs` — расхождений нет.

## Чего эта работа не делает

- Гард под статью не заводится: подмену видно только по сравнению просьбы с ходом, а слова
  просьбы и имя инструмента в записи хода не связаны ничем.

## Что уже есть в дереве

- Циклы импортов судит `tools/check-cycles.mjs`: только `.ts` под `projects/`, только относительные пути.
  Скрипты, `apps/`, `libs/` и пути `@rt/*` он не читает. Исходящих, входящих и обходов входного файла не
  считает ничто.
- Границы между библиотеками судит линтер (`@nx/enforce-module-boundaries`). Внутри пакета границы не
  судит ничто.
- Неиспользуемое судит `knip`: он говорит о файле и экспорте, но не о доле отданного модулем.
- Список долга читает общий `parseAllowlist` из `rt-kit-checks.config.mjs`: у записи причина и номер задачи.
- Набор перед отправкой собирает `assets/defaults/push.sh`: проверка, файл которой лежит в дереве, входит
  в него сама.
- Исходники пакета зовут соседа именем разложенной копии: файл `board.github.mjs` импортируется как
  `./board.mjs`.

## Что уже говорят правила

- `lib-layers` (надстройка дерева): цикл через входной файл разрывают прямым импортом файла. Значит, обход,
  без которого замкнулся бы цикл, — не нарушение.
- `testing`: у записи списка долга причина и задача, рядом проверка мёртвой записи; новая проверка входит в
  набор или CI.
- `code-design`: решение живёт в одном модуле; решение не читает диск.

## Вопросы и ответы

Новых вопросов владельцу нет: план эпика одобрен 24.11, границы этой задачи определены ниже и в плане.

## Решения

- **Модуль — файл.** Довод: у файла есть обязанность и импорты, а числа папки прячут рост внутри. Входной
  файл папки и путь `tsconfig` — вход, по нему судится обход.
- **Граф читает `.ts`, `.mjs`, `.js`, `.cjs`, `.tsx` и `.sh`.** Довод: у пакета правил скриптов больше, чем
  `.ts`. Отклонено: готовый `graph.json` — его нет у деревьев с пакетом.
- **Судится рост исходящих, входящие печатаются.** Довод: рост входящих — это переиспользование, отказ за
  него учил бы писать копии.
- **Одна новая связь и новый модуль до четырёх связей проходят без записи в плане.** Довод: 77 из 108
  ростов — на одну связь, 274 из 295 новых модулей не больше четырёх. Отклонено: ноль — отказ получало бы
  каждое третье слияние.
- **Названное в плане читается из истории ветки.** Довод: набор перед отправкой идёт, когда папка задачи
  уже разобрана.
- **Переименование файла — не рост.** Довод: без этого перенос файла выглядит новым модулем со всеми его
  связями.
- **`tools/check-cycles.mjs` удаляется.** Довод: новая команда судит те же циклы и шире; две проверки
  одного разошлись бы.
- **Старые циклы и обходы лежат в списке долга, старый код не правится.** Довод: так сказано в плане
  эпика.

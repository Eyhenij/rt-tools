## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-1`
- **Этап:** 1 из 2
- **Сделано:** разбор закрыт, замысел написан, ветка заведена
- **Следующий шаг:** показ, меряющий полосу, — красным
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет
- **PR:** ещё не открыт

# Разбор просьбы

Запись груза из приёма, соседнее дерево, ресурс `patterns/spec-driven-rule.md`. Отметить её
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

- **место:** раздел «Правило», в образец шапки — строкой под блоком полей
- **повод:** правило слоя правил требует, чтобы переносимый текст называл своё требование к
  соседнему ресурсу строкой в шапке, а не выводил его из фразы в тексте. Паттерн, которым это
  правило велит заводить новое правило, строки не показывает: он даёт поля шапки, перечисляет
  разделы и кончается порядком из пяти шагов. Пишущий правило по паттерну требования не
  встречает — и не пишет строку. В дереве, где паттерн разложен, её несут два файла из
  восьмидесяти двух, и оба написаны до паттерна.
- **готовый текст:** строка `**Требует:**` с ресурсами, названными именами пакета; строки нет —
  правило не требует ничего, пустой она не бывает.
- **чем закрывается:** ничего, надстройки под это нет.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

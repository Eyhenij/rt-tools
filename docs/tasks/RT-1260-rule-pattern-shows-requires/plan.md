# Замысел

**Поведение:** не меняется — правится текст паттерна, ни одной проверки и ни одного гарда задача
не трогает.

Паттерн заведения правила показывает поля шапки и разделы и не показывает строку требования к
соседним ресурсам, которой правило слоя правил требует.

## Этапы

1. Строка требования в образец шапки правила, с пояснением: имена пакета, не пути дерева;
   отсутствие строки значит «не требует ничего».
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Правки существующих правил задача не делает: строку они получают по мере того, как их правят, а
разом проставленная наугад она называла бы требованиями то, что ими не является.

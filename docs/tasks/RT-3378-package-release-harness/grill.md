# Grill

## The owner request

> пиши инцидент, скилл выпуска и проверки этого пакет и правила, ты обязан создать обвязку которая не позволит тебе повторить этот провал

> пиши обвязку которая не позволит тебе выпускать сломанные пакеты

## What the tree already has

Пакет `utils` собирается и проверяется командой `nx verify`, которая загружает собранные `esm` и `cjs`. Пакет протокола чата собран копией его процесса, но без цели `verify`, и набор перед пушем берёт только проекты с такой целью. Версия 0.2.0 вышла и не загружалась в Node. Процесс публикации писал заголовки коммитов с областью, которой не было в списке проверки коммитов.

## What the rules already say

Правило `git-workflow`: выпуск пакета — ручной запуск процесса публикации. Про проверку собранного пакета правила молчат.

## Questions and answers

Вопросов нет: поручение владельца определяет работу.

## Decisions

- **Одна общая проверка собранного пакета вместо проверки под один пакет** — иначе следующий пакет снова остаётся без неё. Отвергнуто: копия проверки для каждого пакета.
- **Проверка привязки читает все пакеты без Angular сразу** — каждый смотрит на один файл, и промах между файлами никто не видел.
- **Хук запуска публикации отказывает, пока проверка не прошла.** Отвергнуто: только запись в правила, 18.11 такая запись не остановила выпуск.

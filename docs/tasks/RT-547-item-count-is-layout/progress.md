# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 1 — Статья и её привязка
- **Сделано:** папка задачи собрана
- **Следующий шаг:** статья в правило
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет — заход автономный
- **PR:** не открывается: ночью наружу ничего не уходит

## Решения по ходу

- **Статья в правило, а не в паттерн** — паттерн отвечает «чем мерить», правило «что требует
  замера». Затронутый этап замысла: 1.

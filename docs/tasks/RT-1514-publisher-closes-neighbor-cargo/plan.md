# Замысел

**Задача:** RT-1514 · **Ветка:** RT-1514-publisher-closes-neighbor-cargo
**Драфт:** `docs/specs/message-bus/proposed/publisher-cargo-close/`

## След задачи

| Что задевается                                    | Чем проверяется                      |
| ------------------------------------------------- | ------------------------------------ |
| `libs/message-bus-api/cargo-state/**`             | спеки домена, сценарии SC-MB-269…274 |
| `libs/message-bus-api/postmortems/data-access/**` | те же                                |
| `libs/message-bus-api/proposals/data-access/**`   | те же                                |
| `tools/cargo-close.mjs`                           | набор проб дерева                    |
| схема хранилища — признак закрывшего              | сборка приёмника                     |

## Этапы

1. **Признак закрывшего в хранилище.** Полю место в схеме, миграция, отдача его чтением груза.
   Готово, когда сборка приёмника проходит, а чтение отдаёт поле.
2. **Операция закрытия.** Контроллер под входом человека, разбор пакета, переходы только вперёд
   по двум последним шагам, приём починки и версия. Готово, когда сценарии SC-MB-269…272 и 274
   закрыты спеками.
3. **Команда дерева.** `tools/cargo-close.mjs` — тот же разбор доводов, что у отметки, но вход
   парой учётной записи. Готово, когда команда переводит записи соседа на живом приёме.
4. **Закрытие работы.** Договорённость вливается в спек домена, тексты приведены, набор прогнан,
   папка разобрана, заявка открыта черновиком.

## Что не входит

- Правка текста чужой записи и возврат её назад.
- Кнопка закрытия в админке: движение состояний идёт командой.

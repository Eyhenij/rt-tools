# Замысел

**Задача:** RT-1130 · **Ветка:** RT-1130-archive-index-dropped
**Поведение:** не меняется — правка задевает `docs/`, `.claude/` и `.gitattributes`; кода
приложения нет ни в одном файле. Снос указателя владелец назвал прямо.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## След задачи

| Что        | Где                                                               |
| ---------- | ----------------------------------------------------------------- |
| Тексты     | `docs/archive/README.md`                                          |
| Правила    | `.claude/skills/doc-style/`, `.claude/skills/git-workflow-stack/` |
| Надстройки | `.claude/rt-kit/overrides/rules/doc-style.md`                     |
| Настройка  | `.claude/rt-kit/checks.json`, `.gitattributes`                    |
| Груз       | `.claude/rt-kit/proposals/`, `docs/postmortems/`                  |

## Что считается сделанным

- Раздела «Что лежит» в `docs/archive/README.md` нет; записи каталога на месте, все 238.
- Сверка адресов отвечает зелёным без сверки указателя.
- `.gitattributes` не объявляет сложения сторон для снятого указателя.
- Надстройка над `doc-style` объясняет отсутствие указателя и называет скил дерева.
- Скил дерева о записи архива лежит и назван в надстройке.
- Приём ответил на отправку предложения и разбора происшествия.

## Этапы

### 1. Указатель снят

- **Что делается:** раздел «Что лежит» уходит из `docs/archive/README.md`, вместо него — абзац
  о том, чем запись находят; `indexedDirs` в `.claude/rt-kit/checks.json` становится пустым;
  строка сложения сторон для этого файла уходит из `.gitattributes`.
- **Признак готовности:** сверка адресов проходит, ни одна её строка не говорит об указателе.
- **Чем проверяется:** `node tools/check-doc-paths.mjs` — «расхождений нет» означает, что
  сошлось.

### 2. Надстройка над правилом

- **Что делается:** надстройка над `doc-style` получает раздел о том, почему у описания
  прошлого указателя здесь нет, и раздел о скилах дерева со ссылкой на новый скил. Разложенная
  копия правила пересобирается раскладкой, а не правится на месте.
- **Признак готовности:** раскладка проходит, надстройка видна в разложенной копии.
- **Чем проверяется:** `pnpm run agent-kit:check` — молчит о расхождениях.

### 3. Скил дерева о записи архива

- **Что делается:** заводится скил дерева — что пишется в запись, чем она находится без
  перечня, чем эта работа не является.
- **Признак готовности:** скил лежит, назван в надстройке, слог проходит проверку.
- **Чем проверяется:** `node tools/check-prose-style.mjs` — молчит о новом файле.

### 4. Груз наверх

- **Что делается:** разбор происшествия о том, что паттерн стопки был написан до этой работы и
  нарушен, и предложение пакету о зазоре между сложением сторон и меткой сливаемости на
  хостинге.
- **Признак готовности:** приём принял обе записи.
- **Чем проверяется:** `npx agent-kit propose` — строка ответа называет, сколько записей легло.

### 5. Работа отдана

- **Что делается:** папка задачи разбирается, PR открывается черновиком.
- **Признак готовности:** ветка папки не везёт, PR открыт.
- **Чем проверяется:** `node tools/check-push-gate.mjs` — гейт пуша не отбивает.

## Чего эта работа не делает

- Не обновляет пятнадцать открытых заявок: до слияния этой ветки в них нечего обновлять.
  Заводится отдельной задачей.
- Не трогает порядок ведения стопки — это RT-1127, паттерн стопки уже написан.
- Не трогает указатель спеков: та же форма, но владелец назвал предметом архив.
- Не удаляет ни одной записи архива.

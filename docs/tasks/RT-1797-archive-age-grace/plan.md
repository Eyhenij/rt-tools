## Что считается сделанным

- Проверка срока называет только записи старше срока плюс сутки.
- Чистка снимает записи старше срока, как прежде.
- Проба в наборе пакета держит обе стороны.

## Этапы

### 1. Запас у проверки

- **Что делается:** отбор перестоявших принимает запас в сутках; проверка зовёт его с сутками,
  чистка — без.
- **Признак готовности:** запись возрастом в 7 суток и час чистка снимает, а проверка молчит.
- **Чем проверяется:** `pnpm run agent-kit:sync` — раскладка сходится, `node tools/check-archive-age.mjs` — зелёная.

### 2. Проба на обе стороны

- **Что делается:** набор пакета получает сценарии на возраст записи: 7 суток и час, 8 суток и
  час.
- **Признак готовности:** проба падает, если запас снят.
- **Чем проверяется:** `bash projects/agent-kit/tests/archive-age.test.sh` — все пробы зелёные.

## Чего эта работа не делает

- Срок хранения не меняет: 7 суток.
- Сверку спеков по возрасту договорённости не трогает: она называет, а не роняет.

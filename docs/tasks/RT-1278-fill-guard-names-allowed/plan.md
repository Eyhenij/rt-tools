# Замысел

**Поведение:** не меняется — пороги, отбой и пропуск остаются прежними; меняется только текст
отказа.

## Что делается

`hooks/window-fill-guard.sh`, текст отказа после порога остановки: вместо строки о том, что
пропускается, встают формы вызова — правка хода работы и передачи, коммит, пуш, заявка, колонка
задачи, сверки, — и слово о том, что команда судится по первому слову: вход в каталог перед ней
снимает совпадение.

Сценарий при наборе стража: отказ называет форму вызова, а не только требование.

## Чем проверяется

`bash projects/agent-kit/tests/run.sh`, `npm run agent-kit:sync`, `npm run agent-kit:check`,
`npm run check:specs`.

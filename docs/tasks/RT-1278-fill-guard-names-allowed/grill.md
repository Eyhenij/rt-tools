# Разбор просьбы

Одна запись груза из приёма, соседнее дерево, ресурс `hooks/window-fill-guard.sh`. Отметить её
этому дереву нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

## Отказ называет требование и не называет формы вызова

После второго порога отказ говорит, что надо написать передачу, и не говорит, какая команда при
этом проходит. Список разрешённых команд стоит в профиле дерева, а вызов считается по первому
слову строки: восемь попыток подряд начинались со входа в каталог и потому не подпадали ни под
один образец. Требование без формы вызова разбирается перебором, и перебор стоит хода за
попытку.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

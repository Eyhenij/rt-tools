## Что считается сделанным

- В шести конвейерах пересборка замка стоит после шага публикации и кладётся своей заявкой.
- Проверка дерева отбивает пересборку до публикации и пересборку без своей заявки.
- Проба проверки зелёная, набор гейта пуша зелёный.

## Этапы

### 1. Конвейеры

- **Что делается:** пересборка замка переносится из шага «Update version» за шаг «Publish»,
  с повтором до ответа реестра, и получает свой шаг заявки.
- **Признак готовности:** в шести файлах строка пересборки стоит после строки публикации, за
  ней шаг заявки.
- **Чем проверяется:** `node tools/check-publish-lockfile.mjs` — код 0 после этапа 2.

### 2. Проверка и проба

- **Что делается:** проверка судит порядок «публикация → пересборка → заявка»; проба
  покрывает все три отказа и зелёный случай.
- **Признак готовности:** проба зелёная на фикстуре, проверка зелёная на дереве.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-publish-lockfile.test.sh` —
  «разошлось: 0».

### 3. Отдача

- **Что делается:** папка задачи разбирается, заявка открывается черновиком.
- **Признак готовности:** заявка открыта, прогон на вершине идёт.
- **Чем проверяется:** `gh pr view` — номер и состояние.

## Чего эта работа не делает

- Не чинит токен npm: секрет обновляет владелец.
- Не переносит публикацию раньше заявки о версии: порядок «версия → тег → публикация» прежний.

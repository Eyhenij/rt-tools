# Замысел

Задача: #334. Ветка: `RT-334-archive-closed-task-folders`.

**Задача:** RT-334 · **Ветка:** RT-334-archive-closed-task-folders
**Поведение:** не меняется — уборка текстов работы, кода задача не трогает

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Ни одной папки закрытой задачи в `docs/tasks/` не осталось — ни в нынешней форме имени, ни
  в старой, с косой.
- У каждой разобранной задачи в `docs/archive/` лежит один файл с говорящим именем: просьба
  владельца дословно, решения разбора с доводами и решения по ходу с причинами. Замыслы
  удалены.
- `npm run check:board` не даёт ни одной строки про папки закрытых задач.
- `npm run check:docs` не даёт новых замечаний против того, что было до работы.
- Ни один текст дерева не называет снятую папку.

## Этапы

### 1. Разбор пяти папок

- **Что делается:** содержимое каждой папки уезжает в `docs/archive/` одним файлом; `plan.md`
  удаляется; папка снимается.
- **Признак готовности:** в `docs/tasks/` остались только `README.md`, `_template` и папка
  этой задачи.
- **Чем проверяется:** `npm run check:board` — строк про папки закрытых задач нет.

### 2. Вычистка ссылок на снятое

- **Что делается:** греп по дереву на имена снятых папок; найденное правится.
- **Признак готовности:** ни одного упоминания вне `docs/archive/`.
- **Чем проверяется:** греп по всему дереву и `npm run check:docs`.

### 3. Разбор папки самой задачи

- **Что делается:** папка этой задачи разбирается последним коммитом отчёта — тем же, что и
  работа, как велит правило.
- **Признак готовности:** в главную ветку папка не попадает вовсе.
- **Чем проверяется:** `npm run check:board` и состав отчёта.

## Чего эта работа не делает

- Не чинит того, что разбор папки просрочивается раз за разом: ничто не держит требования
  разобрать её тем же отчётом, и сверка находит папку только после мержа. Названо открытым
  вопросом в разборе; лечится правкой пакета правил, а не этой уборкой.
- Не трогает 31 расхождение сверки очереди, не относящееся к папкам: отчёты на борде вместо
  задач, задачи без исполнителя и вне очереди — это долг задачи #318.

## Что считается сделанным

- В разделе с двумя десятками записей последняя строка достижима прокруткой, и переключатель
  страниц виден целиком. Подтверждается замером на стенде: высота прокрутки документа больше
  высоты окна, и нижняя граница переключателя попадает в страницу.
- Название раздела набрано тем же кеглем и начертанием, что у образца, — замер сходится
  числами.
- Поля страницы и промежутки между её блоками совпадают с образцом числами.
- Шапка сложена строкой с переносом: название с подсказкой слева, место действий справа.
- Все четыре раздела меняются разом, потому что правится общее.

## Этапы

### 1. Каркас перестаёт быть ростом с окно

- **Что делается:** у оболочки админки снимается режим, прибитый к высоте окна, — тот самый,
  в котором кит обрезает зону содержимого.
- **Признак готовности:** страница раздела с длинным списком прокручивается целиком, и
  переключатель страниц под таблицей достижим.
- **Чем проверяется:** `pnpm exec nx test @rt/message-bus-admin-common-container-feature` —
  зелёный прогон означает, что оболочка поднимается и её спеки сходятся.

### 2. Слой раскладки страницы приводится к образцу

- **Что делается:** поля, промежутки, кегль и начертание заголовка, строка шапки с переносом и
  место действий, зона прокрутки таблицы — всё берётся из слоя раскладки образца.
- **Признак готовности:** замеры вычисленных значений на стенде сходятся с замерами образца по
  полям страницы, промежутку колонки, кеглю и начертанию заголовка.
- **Чем проверяется:** `pnpm run lint:styles` — ноль замечаний означает, что стили приняты
  линтером с его порогом в ноль предупреждений.

### 3. Шапка страницы получает обёртку, которой требует паттерн раскладки

- **Что делается:** название и подсказка уезжают в обёртку шапки, у шапки появляется место
  действий справа.
- **Признак готовности:** раздел без подсказки места под неё не оставляет; раздел с подсказкой
  показывает её своей строкой под названием.
- **Чем проверяется:** `pnpm exec nx test @rt/message-bus-admin-common-core-ui` — зелёный
  прогон означает, что разметка страницы поднимается и её спеки сходятся.

### 4. Проверка глазами и замером на стенде

- **Что делается:** все четыре раздела открываются на стенде, снимаются замеры и сверяются с
  образцом.
- **Признак готовности:** ни один из четырёх разделов не расходится с образцом по замеряемым
  числам, и в каждом достижима последняя строка.
- **Чем проверяется:** `pnpm run check:all` — зелёный прогон означает, что линтеры, спеки,
  юниты и сборка сошлись.

## Чего эта работа не делает

- Отбор по дереву чипами: число деревьев не ограничено, строка чипов поехала бы. Заведено
  открытым вопросом в договорённости.
- Слово-бренд в верхнем ряду: образец о нём мнения не имеет, и это содержимое приложения.
- Столбцы, меню строки и панель подробностей: вид страницы их не касается.

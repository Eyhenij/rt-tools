# Замысел

**Поведение:** не меняется — правится текст паттерна, ни одной проверки и ни одного гарда задача
не трогает.

Раздел «Факт проверяется, а не вспоминается» велит открыть код и посмотреть. Что смотреть можно
не туда, а смотрящий инструмент — отвечать не на тот вопрос, он не говорит.

## Этапы

1. Три утверждения в конец раздела, порядком от предмета к средству: где читается состояние
   чужой ветки, чем подтверждается «все N таких-то», чем проверяется сама команда.
2. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Одной задачей взяты три записи: они правят один раздел одного файла и откатываются вместе.

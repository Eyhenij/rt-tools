# Разбор просьбы

Три записи груза из приёма, соседнее дерево, один раздел ресурса `patterns/doc-style-write.md` —
«Факт проверяется, а не вспоминается». Отметить их этому дереву нечем — токен двигает только свои
записи; работа при этом наша, ресурс живёт здесь.

## Первая: состояние чужой ветки

Своя копия чужой ветки отвечает на любой вопрос и не сообщает, что отстала. Замерено: трижды за
один заход состояние общей ветки выведено из файла на своей, отставшей на семь коммитов. Все три
вывода неверны, один доехал до документа задачи и был назван владельцу как факт. Поймано
ребейзом, то есть случайно.

## Вторая: утверждение «все N таких-то»

Скан подтверждает ровно тот маршрут, который в него заложен, и молчит обо всех прочих. Замерено:
посчитали места по образцу самого вызова, получили 22 и записали в план и в описание заявки, что
порядок держится устройством. Мимо прошли десять вызовов обёртки — она берёт значение
аргументом, и на строке вызова образца нет. Мест оказалось 32, и у десяти значение стояло
числом. Неправда продержалась сутки в файле, едущем в историю.

## Третья: чем получено число

Вывод команды — не подтверждение сам по себе: инструмент отвечает на тот вопрос, который понял,
и о непонятой части образца молчит. Замерено за один заход, три числа подряд: граница слова, не
реализованная в этой сборке инструмента и не объявленная отказом, дала 278 вхождений вместо 79;
счёт вызовов регулярным выражением дал 32 и 42 на одном и том же, а по синтаксическому дереву их 27.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

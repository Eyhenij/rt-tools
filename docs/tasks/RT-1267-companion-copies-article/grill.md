# Разбор просьбы

Запись груза из приёма, соседнее дерево, ресурс `rules/spec-driven.md`. Отметить её этому дереву
нечем — токен двигает только свои записи; работа при этом наша, ресурс живёт здесь.

- **место:** раздел про компаньон правила, к описанию таблицы привязок
- **повод:** строка привязки, написанная пересказом статьи, проходит проверку насквозь. Ключ
  связи — сам текст, поэтому строка, написанная по смыслу, разрывает связь, оставаясь на вид
  заполненной. Проверка это подтверждает: она считает статьи без адреса и о статье, адрес
  которой описывает не её, не знает ничего.
- **замер:** статье про действия, требующие отдельного слова владельца, поставили привязкой
  гард, который держит седьмое действие — не из перечня статьи. Совпал род, а не перечень, и
  строка продержалась до перечитывания диффа.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

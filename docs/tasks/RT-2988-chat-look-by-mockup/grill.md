# Grill

## The owner's request

> смотри новые макеты … ты обязан привести вид страницы к этим макетам

Said 29.10.2026 about the conversations screen of a consumer application.

## Answers

| Question                       | Answer                                                    |
| ------------------------------ | --------------------------------------------------------- |
| Does the work change behaviour | yes, the look of two components                           |
| Does it need a law edit        | no                                                        |
| One task or several            | one: the screen is assembled from both components at once |
| What is out                    | quick replies, scheduled send, the message menu           |
| What shows closing             | the screen matches the frame at 1440, 768 and 375         |
| Is there a sample              | the frame itself; the kit has no such variant yet         |

## Decisions

- **New looks are opt-in inputs.** Other consumers keep today's look: the frame is one screen, not
  a decision about every chat.

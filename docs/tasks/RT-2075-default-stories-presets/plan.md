## What counts as done

- Каждый показ одного экземпляра у затронутого семейства показывает обе половины.
- Показ, которому пара не нужна, назван с причиной: панель поверх страницы, целый экран, семейство
  вне набора.
- Эталоны обёрнутых показов пересняты после осмотра, съёмка зелёная.

## Stages

### 1. Разбор сорока восьми показов по роду

- **What is done:** каждый показ с эталоном и без корня отнесён к роду по своей разметке, и назван
  список тех, кому пара нужна.
- **Readiness sign:** названо число показов, которым пара нужна, и поимённо — роды, которым нет.
- **Verified by:** обход витрины своим скриптом — показов с эталоном без корня 48.

### 2. Обёртка показов одного экземпляра

- **What is done:** показы из списка обёрнуты парой половин; у каждого появился корень показа.
- **Readiness sign:** у каждого обёрнутого показа половин ровно две, обе нарисованы, половины не
  совпали пиксель в пиксель.
- **Verified by:** проверка пары своим скриптом — находок нет.

### 3. Осмотр и пересъёмка

- **What is done:** кадры обёрнутых показов осмотрены, эталоны пересняты.
- **Readiness sign:** съёмка зелёная, кадров без своего показа нет.
- **Verified by:** `node tools/visual-snapshots-v2.mjs` — расхождений нет, сирот нет.

## What this work does not do

- Не оборачивает панели поверх страницы: в кадре панель одна, второй половине негде встать.
- Не оборачивает целые экраны уровня шаблонов: договор покрытия к ним не применяется.
- Не трогает первый кит.

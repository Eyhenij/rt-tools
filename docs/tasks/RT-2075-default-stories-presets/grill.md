# Grill

## Откуда взялась работа

Находка по ходу RT-2057. Владелец её не заказывал: там пара половин встала на все матрицы
затронутых семейств, а показы вне матриц остались за работой.

> У двенадцати семейств есть показ `Default` с эталоном и без пары, у приёма файлов такой же показ
> называется `Zoned`. Корня показа у них нет вовсе, поэтому проверка пары их не видит.

Слова взяты из самой задачи 2075 — их писал исполнитель, не владелец.

## Что дерево уже имеет

- Пара половин — компонент `app-story-presets`: берёт матрицу содержимым и рисует её дважды, своим
  набором оформления и материальным. Хост пары несёт корень показа.
- Правило витрины: пара принадлежит каждому показу семейства, которого набор касается, а не одному
  показу из десяти.
- Затронутых семейств 70 из 84 — счёт RT-2057 по вычисленным значениям узлов кита.

## Измерено

Показов с эталоном и без корня показа — 48. Они распадаются на четыре рода, и пара нужна только
одному из них.

| Род показа                                                | Сколько | Нужна ли пара                                   |
| --------------------------------------------------------- | ------- | ----------------------------------------------- |
| Показ одного экземпляра: `Default`, `Playground`, `Zoned` | 21      | да, если семейство затронуто набором            |
| Панель поверх страницы: `--panel*`, наведение, раскрытие  | 15      | нет: панель в кадре одна, второй половине негде |
| Целый экран уровня шаблонов                               | 6       | нет: договор покрытия к экрану не применяется   |
| Прочее: страница основ, просмотрщик фото                  | 6       | нет: набор их не касается                       |

## Вопросы и ответы

- **Почему проверка пары их не видит?** Она ищет корень показа, а у показа одного экземпляра его
  нет: разметка написана без обвязки — просто компонент в ящике.
- **Оборачивать ли панели?** Нет. Панель лежит в слое поверх страницы, в кадре она одна, и вторая
  половина показала бы ту же панель поверх той же страницы.
- **Оборачивать ли экраны шаблонов?** Нет. Договор покрытия к целому экрану не применяется: у него
  нет ни осей входа, ни состояний в смысле компонента.

## Решения

- **Пару получает показ одного экземпляра у затронутого семейства.** Род показа определяется его
  разметкой, а не именем: панель лежит в слое поверх страницы, экран собран из готовых компонентов.

# Ход работ

## Где стоим

Переписывается каждым заходом, не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 2 — Ветка эпика отдана на хостинг
- **Сделано:** ветка заведена от главной и отправлена; после слияний RT-1977 и RT-1978 вершина
  главной влита в неё местно.
- **Следующий шаг:** отправить ветку с влитой вершиной главной.
- **Не закоммичено:** эта папка.
- **Ждём владельца:** решения по задаче RT-1992 — пока эталоны переписки не сошлись, гейт пуша
  отбивает любую ветку с полным набором проверок.
- **Заявка:** не открывается — ветка эпика заявкой не отдаётся.

## Решения по ходу

- **Ветка эпика заведена посреди эпика, а не в его начале.** Требование пришло с работой RT-1921,
  когда шесть задач эпика уже были влиты от главной. Затронут этап плана: 1.
- **Папка задачи заведена ветке, которая работой не является.** Страж хода судит по имени ветки.
  Написано, чем ветка является. Затронут этап плана: ни один.

## What counts as done

- У каждого ключа русского набора есть текст в английском: имён ключей в кавычках на экране нет.
- Полноту обоих наборов доказывает вызов, а не просмотр глазами.
- На английском выборе подписи экрана раздела — заголовок, столбцы, слова состояний, кнопки —
  не содержат кириллицы.

## Stages

### 1. Английский набор наполнен до русского

- **What is done:** 228 ключей русского набора получают английский текст: заголовки и подсказки
  разделов, подписи столбцов, слова состояний, поля фильтров, панели правок.
- **Readiness sign:** ключей русского набора без английского текста — 0 (было 228).
- **Verified by:** сравнение ключей двух наборов вызовом — расхождений нет.

### 2. Полноту наборов доказывает вызов

- **What is done:** сценарий, который проходит весь русский набор и требует текста в английском;
  он же ловит ключ, заведённый потом только с одной стороны.
- **Readiness sign:** сценарий назван в описании оболочки и закрыт тестом; убери один ключ из
  английского набора — тест краснеет.
- **Verified by:** `pnpm exec nx test message-bus-admin-common-core-util` — 0 провалов.

### 3. Экран раздела на английском без кириллицы

- **What is done:** сквозной тест на выбранном английском смотрит подписи экрана раздела —
  заголовок, столбцы, слова состояний, кнопки тулбара.
- **Readiness sign:** кириллицы в этих подписях нет; имена деревьев и грузов из базы стенда
  проверка не трогает — они данные, а не подписи.
- **Verified by:** `pnpm exec nx run message-bus-admin-e2e:e2e` — 0 провалов.

## What this work does not do

- Восьми языков кита в админке: словаря два. Третий язык — отдельная работа и слово владельца.
- Проверки, запрещающей строку текста мимо словаря: это RT-2214, последняя задача эпика.
- Перевода данных стенда: имена деревьев, проектов и грузов приходят из базы и языка не знают.

## Decisions along the way

- **Своей договорённости задача не пишет.** Обещание двух наборов подписей уже действует с
  RT-2209; эта работа его выполняет. Правится раздел про локали в описании оболочки: разделы
  перестают брать подписи только из русского набора.

- **Измерение в плане завысило число ключей: считался и набор подписей кита.** В наборе админки
  247 ключей, а не 294; без английского текста были 181, а не 228. Работа от этого не изменилась:
  наполнялся весь набор.
- **Полноту набора говорит тип, а не только проверка.** Английский набор объявлен полной записью
  по ключу русского: ключ без перевода теперь не собирается вовсе. Вызов при этом остался — тип
  молчит о пустой строке, а пустая строка на экране читается как «подписи здесь нет».
- **Два теста держались за `columnTree` как за непереведённый ключ.** После наполнения он
  переведён, и признак ненайденного показывается ключом, которого в наборе нет вовсе.

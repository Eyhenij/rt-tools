- **Задача оказалась не «завести шаг», а «починить порог».** Шаг уборки в конвейере уже стоял и
  шёл при падении — тело задачи, написанное до чтения файла, этого не знало. Причина не в
  отсутствии уборки, а в том, что порог по возрасту не видит сегодняшнего кэша. Тело задачи
  задним числом не переписывается; работа идёт по этому решению.

  каталог свой.

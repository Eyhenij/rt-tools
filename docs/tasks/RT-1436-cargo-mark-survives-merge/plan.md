## Что считается сделанным

- Паттерн `task-flow-archive` в состоянии `влито` называет отметку груза шагом с готовым
  вызовом, и правило `cargo-triage` утверждает то же о состоянии, а не о памяти исполнителя.
- Образец папки задачи требует ключ записи груза полным видом, и правило `cargo-triage` говорит,
  где этот ключ живёт после того, как папка разобрана.
- Сверка очереди работ называет отдельной строкой описание прошлого, чьи записи груза стоят не
  в «готово», и проба к ней зелёная.

## Этапы

### 1. Отметка груза становится шагом состояния `влито`

- **Что делается:** в паттерн `task-flow-archive` встаёт подраздел с готовым вызовом отметки, в
  правило `cargo-triage` — статья о том, что переход в «готово» идёт шагом состояния `влито`.
- **Признак готовности:** оба текста называют состояние по имени, вызов отметки стоит целиком, и
  ни один файл не перерос предел длины.
- **Чем проверяется:** `node tools/check-file-size.mjs` — «длиннее предела 0» и
  `npm run check:specs` — привязки статей сходятся в обе стороны.

### 2. Ключ записи груза записывается полным и переживает разбор папки

- **Что делается:** образец папки задачи получает строку о ключах записей груза полным видом;
  правило `cargo-triage` — статью о том, что после разбора папки ключ живёт в описании прошлого.
- **Признак готовности:** образец и правило говорят одно и то же, статья привязана к месту.
- **Чем проверяется:** `npm run check:specs` — расхождений нет; `pnpm run agent-kit:sync` и
  `pnpm run agent-kit:check` — «разложенное сходится с пакетом».

### 3. Сверка очереди называет слитое, но не отмеченное

- **Что делается:** сверка очереди читает ключи записей груза из описаний прошлого и спрашивает
  их состояние у приёма; запись не в «готово» при слитой заявке печатается строкой.
- **Признак готовности:** строка называет описание прошлого и ключ; нет сети или токена — ярус
  молча пропускается, как остальная работа с приёмом.
- **Чем проверяется:** `bash projects/agent-kit/tests/checks-board.test.sh` — «0 провалов» с
  новыми сценариями на обе стороны признака.

## Чего эта работа не делает

- Не разбирает 115 записей в состоянии «новое»: это разбор очереди, а не потеря отметки.
- Не заводит состояния отказа для записи, по которой работы не будет: это открытый вопрос
  договорённости о состояниях.
- Не трогает сторону отправки груза: отметка об отправке уже сходится с ответом приёма.

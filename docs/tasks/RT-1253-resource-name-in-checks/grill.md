# Разбор просьбы

Запись груза из приёма, своё дерево, правило документации проекта.

- **место:** раздел «Как закон применяется здесь», в конец
- **повод:** деление правила на два уронило три проверки дерева подряд — таблица состояний
  называла прежний паттерн, проверка границы состояния искала свою фразу в правиле, откуда та
  уехала, а проба набора ждала прежнего текста отказа. Все три прибиты к имени ресурса, и ни
  одна не сказала об этом заранее: они краснеют после деления, по одной за прогон.
- **ближайшее:** нет — про то, что имя ресурса стоит ещё и в проверках дерева, правило не
  говорит ни строкой.
- **чем закрывается:** ничего, надстройки под это нет.

Владелец разбор не вёл: заход идёт самостоятельно, задачи берутся из приёма одна за другой.

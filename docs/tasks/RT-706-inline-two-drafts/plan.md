## Что считается сделанным

- Каталога `docs/specs/agent-kit/proposed/` в дереве нет вовсе.
- Правила обеих договорённостей стоят в разделах спека домена, сценарии — с прежними номерами.
- То, что за прошедшее время разошлось со сделанным, приведено к сделанному, а не перенесено
  дословно.
- Сверка спеков печатает не больше строк, чем до работы, и ни одной новой.

## Этапы

### 1. Обратная связь слоя правил

- **Что делается:** правила, сценарии, терминология, границы, решения и открытые вопросы
  `feedback-loop` переезжают в спек домена; трём тестам, стоящим под чужим номером, заводятся
  свои сценарии; директория снимается.
- **Признак готовности:** ни один номер не стоит у двух сценариев.
- **Чем проверяется:** `npm run check:specs`, `pnpm exec nx test @rt-tools/agent-kit`.

### 2. Область гейта пуша

- **Что делается:** то же для `push-gate-scope`.
- **Признак готовности:** каталога предложенного нет.
- **Чем проверяется:** `npm run check:specs`, `npm run check:docs`.

## Чего эта работа не делает

- Не делит спек домена на поддомены: деление меняет адрес каждого сценария и каждой привязки.
- Не правит кода пакета — только заголовки тестов, и только там, где номер сценария чужой.

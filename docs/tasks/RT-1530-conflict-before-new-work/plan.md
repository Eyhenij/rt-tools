## Что считается сделанным

- Правило поставки несёт статью о том, что конфликтующая своя заявка чинится раньше новой работы.
- Взятие новой работы отбивается, пока хоть одна своя открытая заявка помечена конфликтующей.
- Судится только прямое «конфликтует»: неопределённость хостинга работу не отбивает.
- Всё, чем конфликт чинится, проходит по-прежнему.
- Привязка статьи в компаньоне называет файл гарда, а не вердикт «не проверяется».

## Этапы

### 1. Опрос своих конфликтующих заявок

- **Что делается:** помощник очереди работ получает точку входа, отдающую свои открытые заявки
  с прямым признаком конфликта; профиль получает функцию, которая печатает их построчно.
- **Признак готовности:** `node tools/board.mjs conflicts` отдаёт объект со списком, а без сети —
  `{"offline":true}`; функция профиля на такой ответ молчит.
- **Чем проверяется:** `node tools/board.mjs conflicts` — строка JSON без поля `error`.

### 2. Ветка гарда поставки

- **Что делается:** помощник гарда рядом с ним отбивает взятие новой работы — заведение задачи,
  заведение ветки под задачу, перевод колонки в работу, открытие заявки, — пока своя открытая
  заявка конфликтует.
- **Признак готовности:** отбита каждая из четырёх команд, пропущены починка конфликта,
  неопределённость хостинга и молчание опроса.
- **Чем проверяется:** `bash projects/agent-kit/tests/git-guard-conflict.test.sh` — «0 провалов».

### 3. Статья правила и привязка

- **Что делается:** статья дописывается в правило поставки, привязка в компаньоне дерева
  называет файл гарда, сценарии заводятся в поддомене гардов хода.
- **Признак готовности:** предел веса правила выдержан, сверка спеков расхождений не находит.
- **Чем проверяется:** `node tools/check-file-size.mjs` и `npm run check:specs` — без строк
  расхождения.

### 4. Раскладка и общий набор

- **Что делается:** пакет пересобирается, раскладка сверяется, гоняется набор проб.
- **Признак готовности:** разложенное сходится с пакетом, набор зелёный целиком.
- **Чем проверяется:** `pnpm run agent-kit:check` и `bash projects/agent-kit/tests/run.sh` —
  «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ».

## Чего эта работа не делает

- Не судит взятие работы по чужим заявкам: свои опознаются машинной записью дерева.
- Не трогает статью закона о поставке — она приносится владельцу текстом отдельно.

# Одобрения

- **Макет:** «тень ок» — https://www.figma.com/design/vyV42sJXccfKNG8yFSCpSL/Design-System-V2?node-id=7448-2186
- **Совпадение:** 17 из 17 чисел
- **Витрина:** «Принимаю (Recommended)» — http://localhost:6007/?path=/story/organisms-table-table--pinned-column

Владельцу был задан вопрос, устраивает ли тень у края закреплённой колонки: остальное в кадрах повторяет
вид кита. Ответ «тень ок» записан как одобрение всех шести кадров.

После одобрения макета тень по слову владельца усилена до 16% и 64%, кадры макета правлены вместе с
кодом. Витрина принята после сравнения до и после и сверки 17 из 17.

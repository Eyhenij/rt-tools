## Что считается сделанным

- Файл каталога хуков кладётся с правом на исполнение независимо от прав источника.
- Ресурсы прочих родов ведут себя как прежде: право берётся с диска.
- Спека закрывает обе стороны.

## Этапы

### 1. Право по роду ресурса

- **Что делается:** раскладка ставит бит на всё, что кладёт в каталог хуков, а прочим родам
  оставляет признак с диска.
- **Признак готовности:** хук с потерянным битом источника ложится исполняемым.
- **Чем проверяется:** спека раскладки.

### 2. Статья и сценарий

- **Что делается:** статья в спек раскладки, сценарий в его список, привязка компаньона.
- **Признак готовности:** `check:specs` без расхождений.
- **Чем проверяется:** `npm run check:specs`, прогон спек пакета и всех наборов.

## Чего эта работа не делает

- Не трогает признак у проверок: часть из них зовётся исполнителем, и бит им не нужен.

## Что считается сделанным

- Пункт меню несёт право, и тот же ключ читает страж маршрута: скрытый пункт закрывает и адрес.
- Набор прав объявлен один раз и на обе стороны — приёмник и админка берут его из общей либы.
- Операции приёмника, которыми живут разделы, закрыты правами: скрытый пункт не оставляет
  открытой операции.
- Человек без прав видит админку без разделов, со своим именем и выходом, а не пустую поломку.
- Пока ответ о вошедшем не приехал, не скрывается ничего.

## Этапы

### 1. Договорённость записана черновиком

- **Что делается:** `docs/specs/message-bus/proposed/section-rights/` — правила, сценарии и
  привязки: чем закрыт пункт, чем адрес, что видит человек без прав, что видно до ответа
  приёмника.
- **Признак готовности:** черновик лежит, сценарии пронумерованы следующими свободными номерами
  префикса `SC-MB`.
- **Проверяется:** `npm run check:specs` — без расхождений по привязкам.

### 2. Набор прав переехал в общую либу

- **Что делается:** `rights.ts` переезжает из `libs/message-bus-api/access/util` в
  `libs/message-bus-common`; приёмник берёт набор оттуда, своей копии не заводит.
- **Признак готовности:** обе стороны собираются, спеки набора остались на месте и зелёные.
- **Проверяется:** `pnpm exec nx run-many -t test -p message-bus-common message-bus-api-access-util`.

### 3. Пункт меню несёт право

- **Что делается:** у записи пункта появляется право; оболочка показывает только те пункты, что
  открыты; человеку без единого права показывается экран о том, что разделов у него нет.
- **Признак готовности:** пункт без права не рисуется, до ответа приёмника рисуются все.
- **Проверяется:** `pnpm exec nx test message-bus-admin-common-container-feature`.

### 4. Адрес раздела закрыт тем же объявлением

- **Что делается:** страж по праву на детях закрытой ветки читает право того пункта, чей адрес
  открывают; прямая ссылка на закрытый раздел уводит туда же, куда и скрытый пункт.
- **Признак готовности:** прямой переход по адресу закрытого раздела не открывает его экран.
- **Проверяется:** `pnpm exec nx test message-bus-admin-auth-shell`.

### 5. Операции приёмника закрыты правами

- **Что делается:** операции чтения разделов объявляются правом чтения своего раздела; засев
  стенда заводит роль со всеми правами и вешает её на учётную запись стенда.
- **Признак готовности:** вошедший без права получает 403 на операцию раздела; набор e2e зелёный.
- **Проверяется:** `pnpm exec nx test message-bus-api-access-feature` и
  `pnpm exec nx run message-bus-admin-e2e:e2e`.

### 6. Договорённость влита, тексты приведены

- **Что делается:** черновик вливается в поддомен `access-rights`; компаньоны правил
  `permissions` и `navigation` теряют строки о том, что закрытия по пункту здесь нет.
- **Признак готовности:** `proposed/` пуст, у статей обоих правил есть строки привязки.
- **Проверяется:** `npm run check:specs` — расхождений нет.

## Чего эта работа не делает

- Не заводит ролей и не правит права: их правит страница ролей, задача #1901.
- Не делит груз по деревьям: кто какой груз видит, остаётся как было.
- Не трогает токен дерева: приём груза закрыт по-прежнему им.

# Ход работы

## Где стоим

Перезаписывается каждым заходом, а не дописывается.

- **Состояние:** `этап-идёт`
- **Этап:** 1 из 3 — Гард требует папку в истории ветки
- **Сделано:** разбор просьбы и замысел написаны, папка заведена в историю первым же коммитом
- **Следующий шаг:** требование в гарде и отказ, называющий команду
- **Незакоммиченное:** нет
- **Ждём владельца:** нет
- **PR:** ещё не открыт

## Решения по ходу

- **Требование встаёт после проверки состояния, а не до неё** — состояния до `этап-идёт` кода
  не правят вовсе, и требовать у них истории значило бы отбивать разбор просьбы, который идёт
  до первого коммита. Затронутый этап замысла: 1.

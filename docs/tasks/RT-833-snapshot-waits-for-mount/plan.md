## Что считается сделанным

- Кадр снимается после того, как показ встал: съёмка ждёт события, а не отсчёта времени.
- `pnpm run test:visual:v2` зелен на своей машине, включая историю
  `Components/RichEditor › Toolbar`, которая падала стабильно.
- Прогон конвейера на вершине ветки зелёный целиком.

## Этапы

### 1. Ожидание вставшего показа

- **Что делается:** обвязка снимков ждёт, пока размеры корня показа не перестанут меняться два
  кадра подряд; отсчёт времени остаётся только поздней границей ожидания.
- **Признак готовности:** история редактора снимается в полный рост, эталон не трогается.
- **Чем проверяется:** `pnpm run test:visual:v2 'rich-editor'`.

### 2. Весь набор снимков зелен

- **Что делается:** прогоняется вся витрина второго кита; расхождения разбираются по одному.
- **Признак готовности:** все снимки сходятся, эталоны не пересняты.
- **Чем проверяется:** `pnpm run test:visual:v2`.

### 3. Тексты приведены, работа отдана

- **Что делается:** правило проверки компонента получает статью об ожидании вставшего показа;
  спек снимков — правило и сценарий; открывается PR.
- **Признак готовности:** `npm run check:specs` и `npm run check:docs` зелёные, PR открыт.
- **Чем проверяется:** прогон на вершине.

## Чего эта работа не делает

- **Не пересъёмывает эталоны.** Эталон верен: он снят с показа, который успел встать.
- **Не трогает первую витрину.** Её обвязка своя, и эталоны у неё свои.
- **Не чинит нестабильность порога расхождения.** Это RT-427, и она про доли процента, а не
  про втрое меньшую высоту кадра.

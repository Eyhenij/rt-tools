| Манифест | `projects/ui-kit-v2/package.json`       |

## Что считается сделанным

- В реестре лежат core 0.4.0, store, ui-kit и ui-kit-v2 с зависимостью от core `^0.4.0`.
- `update-version-core.cjs` переписывает зависимость ui-kit-v2.

## Этапы

### 1. core 0.4.0 и синхронизация лок-файла

- **Что делается:** публикация core, лок-файл и каскад на ui-kit-v2 — правкой в главную ветку
- **Признак готовности:** правка влита, `pnpm install --frozen-lockfile` на main проходит
- **Чем проверяется:** `npm view @rt-tools/core version` — печатает 0.4.0

### 2. store, ui-kit, ui-kit-v2

- **Что делается:** публикация трёх пакетов по порядку с синхронизацией лок-файла между ними
- **Признак готовности:** у всех трёх в реестре зависимость от core `^0.4.0`
- **Чем проверяется:** `npm view @rt-tools/ui-kit dependencies.@rt-tools/core` — печатает ^0.4.0

## Чего эта работа не делает

- Проверку импортов против опубликованных соседей — задача RT-1766.

# Разбор просьбы

## Просьба владельца

> снова проблема у приложения потребителя: ui-kit 0.5.0 импортирует `EPosition` из `@rt-tools/core`, а опубликованный core 0.3.1 экспортирует только `POSITION_ENUM` (переименование лежит на main провайдера, версия пакета там всё ещё 0.3.1).
>
> остановись пока и доопубликуй пакеты

## Что уже есть в дереве

- Вчерашняя задача RT-1764 того же рода: utils 0.4.0 и ui-kit-v2 0.8.1, каскад
  `update-version-utils.cjs` дополнен ui-kit-v2. Каскад `update-version-core.cjs` ui-kit-v2 не знает.
- Порядок публикации и синхронизация лок-файла между пакетами — конвейеры `publish-*.yml`.
- Задача RT-1766 на проверку импортов против опубликованных соседей заведена, не начата.

## Что уже сказано в правилах

Публикация — отдельный запуск конвейера по слову владельца; слово дано в просьбе.

## Вопросы и ответы

Вопросов не задавалось: просьба однозначна, порядок известен по RT-1764.

## Решения

- **core выходит 0.4.0** — переименование экспорта ломающее, в 0.x ломающее идёт минором.
- **store, ui-kit и ui-kit-v2 переопубликовываются с `^0.4.0`** — иначе у потребителя две копии core.
- **ui-kit-v2 добавлен в каскад core** — тот же промах, что вчера с utils.

## Что осталось невыясненным

- Нет.

## Что считается сделанным

- Разбор происшествия лежит в дереве и закрыт правкой правил, а не одними выводами.
- Правило ведения хода называет: состояние дерева, названное владельцем, снимается вызовом
  раньше объяснения.
- Правило поставки называет: готовность отданной работы перечитывается после каждого слияния в
  главную.
- `npm run agent-kit:sync`, `npm run agent-kit:check`, проверка длины и адресов зелёные.

## Этапы

### 1. Статья о слове владельца

- **Что делается:** в правило ведения хода встаёт статья о том, что названное владельцем
  расхождение снимается вызовом того же хода.
- **Признак готовности:** статье отвечает строка компаньона — своя или «не проверяется ничем».
- **Чем проверяется:** `npm run agent-kit:sync` — «статей без адреса» не называет.

### 2. Статья о сроке годности своей готовности

- **Что делается:** в правило поставки встаёт статья о том, что сливаемость отданных заявок
  перечитывается после каждого слияния в главную.
- **Признак готовности:** названо, чем спрашивается, — одним вызовом на все заявки.
- **Чем проверяется:** `node tools/check-file-size.mjs` — правило не переросло предел веса.

  судить его нечем. Это называется в компаньоне прямо.

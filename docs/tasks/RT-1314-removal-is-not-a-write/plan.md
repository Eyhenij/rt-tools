# Замысел

**Поведение:** не меняется — гард судит те же правки; из-под требования выходит одно снятие
неотслеживаемого пути, которое правкой продукта не бывает.

## Что делается

1. В гарде хода работы удаляющая команда узнаётся отдельно, и путь, которого нет в истории,
   такой командой не судится.
2. Отслеживаемый путь судится по-прежнему: снятый файл кода меняет поведение так же, как
   переписанный.
3. Сценарий при гарде: снятие своего временного каталога проходит, снятие файла кода
   отбивается.

## Чем проверяется

`bash projects/agent-kit/tests/task-flow-guard.test.sh`, `npm run agent-kit:sync`,
`npm run agent-kit:check`, `npm run check:specs`, `node tools/check-file-size.mjs`.

## Что считается сделанным

- Шапка принимает моду панели входом и отдаёт запрошенную моду выходом; умолчание оставляет
  сегодняшнее поведение целиком.
- Закреплённая панель стоит в потоке разметки, показывает раздел открытого адреса и не
  закрывается уходом указателя.
- Поле внутри панели отбирает пункты по подстроке подписи; опустевшие группы и колонки не
  рисуются, ширина панели считается по оставшимся колонкам.
- Одиннадцать сценариев договорённости закрыты тестами.
- Витрина показывает обе моды и три состояния поиска.

## Этапы

### 1. Мода панели: контракт, вход, выход, две раскладки

- **Что делается:** тип моды в `rt-page-header.model.ts`, вход и выход в компоненте, вынос
  `#submenuTpl` через `ngTemplateOutlet` в оверлей и в поток, `rtPopoverDisabled` в закреплённой
  моде, пара значков `pin` / `pin-off`, переключатель внутри панели.
- **Признак готовности:** сценарии `SC-UKV-96`, `SC-UKV-97`, `SC-UKV-98`, `SC-UKV-99`,
  `SC-UKV-100`, `SC-UKV-106` проходят.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2` — спека шапки зелёная, заголовки
  тестов называют эти шесть номеров.

### 2. Отбор пунктов по подстроке подписи

- **Что делается:** чистая функция отбора в `rt-page-header.logic.ts`, поле поиска в панели,
  строка о пустой выдаче.
- **Признак готовности:** сценарии `SC-UKV-101` — `SC-UKV-105` проходят; ветвления отбора в
  шаблоне нет.
- **Чем проверяется:** `pnpm exec nx test @rt-tools/ui-kit-v2` — спека логики зелёная и держит
  пять номеров.

### 3. Оформление панели в двух модах

- **Что делается:** блок `rt-page-header-submenu` разделяется — тень всплывающей уходит под
  модификатор; правила поля поиска и переключателя; закреплённая панель встаёт в поток.
- **Признак готовности:** своих значений цвета и размера в файле не появилось, все новые
  правила названы под своим блоком.
- **Чем проверяется:** `pnpm exec nx lint @rt-tools/ui-kit-v2` — без предупреждений.

### 4. Подписи и тексты рядом с кодом

- **Что делается:** две подписи переключателя в `rt-kit-labels.en.ts`; таблица входов и раздел
  «Главное, что нужно знать» в `CONTEXT.md`; страница `Overview.mdx`.
- **Признак готовности:** новые вход и выход названы в обоих текстах, там же сказано, что
  предпочтение хранит потребитель.
- **Чем проверяется:** `npm run check:docs` — пути и пары сходятся.

### 5. Витрина, привязки и прогон набора

- **Что делается:** истории на моду панели и три состояния поиска через обёртку
  `TestPageHeaderComponent`; привязки утверждений и сценариев в компаньоне договорённости;
  пересъёмка эталонов.
- **Признак готовности:** `implementation.md` договорённости не держит ни одной строки «ещё не
  написано»; эталоны сходятся.
- **Чем проверяется:** `pnpm exec nx verify @rt-tools/ui-kit-v2` — снимки зелёные;
  `npm run check:specs` — сценарии закрыты тестами.

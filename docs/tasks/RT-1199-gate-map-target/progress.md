# Ход работы

## Где стоим

- **Состояние:** `этап-идёт`
- **Этап:** 5 из 5 — порядок веток проверен целиком

Этапы 1–4 закрыты одной правкой карты: ветки родственные, и порядок между ними проверяется
только вместе. Этап 5 идёт следом тем же прогоном.

## Решения по ходу

- **Работа идёт без шести вопросов владельцу.** Владелец сказал разбирать находки автономно и
  обращаться к человеку в крайних случаях; ответы записаны допущениями в разборе просьбы.
- **Роли конвейера не зовутся** — настройка сессии запрещает звать их без слова владельца.

## Записи заходов

### 26 августа 2026 — заход первый

Заведён эпик RT-1198 и пятнадцать его задач, RT-1199 — RT-1213. Замысел эпика лежит в каталоге
замыслов, номера возвращены в его таблицу порядка.

Взята задача 1. Прочитаны обе половины карты гейта — надстройка дерева и умолчание пакета.

Симптомы воспроизведены прогоном карты до правки, все восемь строк:

| Путь                                  | Было                 | Стало                    |
| ------------------------------------- | -------------------- | ------------------------ |
| спека библиотеки узла                 | `ui-component-tests` | `testing`                |
| проверка в источнике пакета           | `reuse-first`        | `agent-kit-source`       |
| правило в источнике пакета            | `doc-style`          | `spec-driven` + источник |
| хук в источнике пакета                | молчание             | `agent-kit-source`       |
| разложенная копия правила             | молчание             | `agent-kit`              |
| надстройка карты и хук дерева         | молчание             | `agent-kit-extend`       |
| манифест, правка ключа своей редакции | `dependencies`       | `git-workflow`           |

Семь контрольных путей ответа не сменили: роль помощника молчит, спека компонента кита идёт в
правило проверки компонента, состав зависимостей — в правило о версиях, списочный экран, стили
кита, код приёмника и манифест ng-packagr отвечают прежним.

Наборы сценариев пакета зелёные: умолчания — 79 из 79, гейт правил — 71 из 71.

**Находка.** Надстройка карты гейта не проверяется ничем: сценарии пакета гоняют умолчание, а
своих у дерева нет. Карта решает, какое правило грузится под каждую правку, и держится она
прогоном руками. Адрес — имена этого дерева.

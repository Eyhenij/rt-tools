## Что считается сделанным

- Паттерн говорит, чего просят у владельца на входе: режим работы, а не сам ввод, — и называет
  пути, которыми препятствие обходится своими силами.
- Правило говорит, что показанное человеку собрано с ветки той работы, о которой идёт речь, и
  что ветка держит вершину главной влитой всё время.
- Статьи получили адреса в компаньоне, раскладка положила оба ресурса, сверка зелёная.

## Этапы

### 1. Вход на стенд

- **Что делается:** раздел паттерна о просьбе режима работы и путях обхода препятствия.
- **Признак готовности:** раскладка кладёт паттерн, проверка слога чиста.
- **Чем проверяется:** `pnpm run agent-kit:sync`, `node tools/check-prose-style.mjs`.

### 2. С чего собран стенд

- **Что делается:** две статьи правила — о ветке сборки и о влитой вершине главной; адреса в
  компаньоне.
- **Признак готовности:** сверка раскладки и проверка спек зелёные, набор пакета зелёный.
- **Чем проверяется:** `pnpm run agent-kit:check`, `node tools/check-specs.mjs`,
  `pnpm exec nx test @rt-tools/agent-kit`.

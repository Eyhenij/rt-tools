# Замысел

**Поведение:** не меняется — правится правило и его компаньон, требований к продукту задача не
трогает.

Правило выкатки говорит, где меряется расхождение схемы с миграциями, и молчит о том, что делать
проверке, которая не сумела померять вовсе.

## Этапы

1. Статья следом за статьёй о теневом хранилище.
2. Привязка в компаньоне правила этого дерева.
3. Раскладка, сверка, коммит, запись описания прошлого.

## Границы

Правку самих проверок дерева задача не делает: статья говорит, каким должен быть их выход, а
приводить к ней накопленное — работа, которую заводят отдельно и по одной проверке за раз.

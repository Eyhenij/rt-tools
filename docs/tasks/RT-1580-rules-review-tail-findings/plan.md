## Что считается сделанным

- В файле находок нет ни одного пункта без пометки о том, чем он кончился.
- Живая находка закрыта правкой источника пакета, а не пометкой.
- Все шесть файлов находок пусты — признак закрытия эпика #1198 выполнен.

## Этапы

### 1. Десять пунктов разобраны чтением текстов

- **Что делается:** по каждому пункту читается нынешний текст семьи и называется исход — номер
  закрывшей задачи, своя правка или причина, по которой пункт отпал.
- **Признак готовности:** у каждого из десяти есть ответ.
- **Чем проверяется:** `grep -c '^[0-9]\+\. \*\*' docs/plans/agent-kit-rules-review-findings.md` — число пунктов сходится с числом разобранных.

### 2. Живая находка закрыта правкой правила

- **Что делается:** статья правила о втором пороге заполнения окна называет то же, что отбивает
  гард и говорит паттерн передачи, — папку задачи, а не запись хода работы.
- **Признак готовности:** правило, паттерн и гард говорят одно.
- **Чем проверяется:** `pnpm run agent-kit:check` — расхождений нет.

### 3. Эпик доведён до признака закрытия

- **Что делается:** сверяется, что во всех шести файлах находок неразобранного не осталось.
- **Признак готовности:** ноль в каждом.
- **Чем проверяется:** `node tools/check-file-size.mjs` — новых длиннее предела нет.

## Чего эта работа не делает

- Не снимает сами файлы находок: они читаются как описание прошлого, и снятие — решение владельца.
- Не трогает находки эпика RT-733: он не кончился, и замысел прямо выводит их из разбора.

## След задачи

| ------- | ------------------------------------------------------------ |
| Законы  | `docs/constitution/work-conduct.md`                          |
| Правила | `.claude/skills/status-report/`, `.claude/skills/task-flow/` |
| Пакет   | `projects/agent-kit/assets/rules/`, `.../assets/patterns/`   |

## Что считается сделанным

- Пакет везёт правило ответа о состоянии работы и паттерн при нём; раскладка кладёт их в дерево
  вместе с компаньоном.
- `agent-kit:check` не находит расхождений, `check:specs` по новому правилу молчит,
  `check-doc-paths` зелёная, `check:boundary` не называет ресурс лишним.

## Этапы

### 1. Правило и паттерн заведены в пакете

- **Что делается:** ресурс правила и ресурс паттерна кладутся в `projects/agent-kit/assets`,
  раскладка переносит их в дерево, компаньон заполняется именами этого дерева.
- **Признак готовности:** правило и паттерн видны инструментом скилов, компаньон без пустых
  привязок.
- **Чем проверяется:** `pnpm run agent-kit:check` — строка о том, что разложенное сходится с
  пакетом; `npm run check:specs` — ни одной строки про правило ответа о состоянии.

### 2. Форма ответа сходится с решениями владельца

- **Что делается:** эпик уезжает из таблицы в абзац над ней, в таблице встают все задачи эпика
  по порядку замысла с кратким описанием.
- **Признак готовности:** образец в паттерне показывает абзац и таблицу без строки эпика.
- **Чем проверяется:** `node tools/check-doc-paths.mjs` — расхождений нет.

## Чего эта работа не делает

- Заведение задач эпика карточками и статья закона об этом — задача RT-1143.
- Числа цены слоя и его сжатие — эпик RT-1125.

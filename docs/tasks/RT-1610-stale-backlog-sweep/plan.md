# Замысел

**Задача:** RT-1610 · **Ветка:** RT-1610-stale-backlog-sweep
**Поведение:** не меняется — работа сверяет очередь работ с деревом, кода не трогает

## Что делается

Каждая запись очереди того периода проверяется в дереве вызовом или чтением названного ею
места. Сделанное закрывается вливанием с доказательством; живое остаётся открытым и называется
поимённо.

## Что считается сделанным

- Про каждую проверенную запись сказано, чем именно она закрыта: вызов и его ответ либо строка
  места.
- Живые записи названы поимённо, и сказано, чего в них не хватает.

## Этапы

### 1. Проверка записей

- **Что делается:** записи очереди проверяются вызовом команды либо чтением названного места.
- **Признак готовности:** у каждой записи есть ответ команды или строка файла.
- **Чем проверяется:** `npm run check:board` — очередь работ сходится.

### 2. Закрытие вливанием

- **Что делается:** описание прошлого называет каждую запись и её доказательство, тело заявки
  несёт строки закрытия.
- **Чем проверяется:** `node tools/check-doc-paths.mjs` — пути в текстах живые.

## Чего эта работа не делает

- Живые записи не чинятся: каждая из них — своя работа, и сведённые в одну они потеряют повод.
- Записи о ките и наборе значков не проверяются: они читаются кодом кита, а не вызовом.

# Замысел

**Задача:** RT-950 · **Ветка:** RT-950-button-matrix-snapshot
**Поведение:** не меняется — правится обвязка снимков витрины и шапка её показа, кода
приложения работа не касается. Снаружи это видно только тем, что гейт пуша перестаёт краснеть
на пустом месте.

После написания этот файл не правится. Пересмотр этапа идёт в `progress.md` решением по ходу.

## Что считается сделанным

- Кадр не снимается, пока шрифт значков не встал: ожидание либо дожидается его, либо отказывает
  вслух — молчаливого подавления отказа в обвязке не остаётся.
- Шрифт значков не зависит от чужой сети в тот момент, когда снимается кадр.
- Сто прогонов подряд одной этой истории дают один и тот же кадр.
- Правило проверки компонента говорит о найденной ловушке словами: ожидание, гасящее свой
  отказ, снимает кадр раньше срока и делает эталон делом случая.

## Этапы

### 1. Причина подтверждается замером

- **Что делается:** та же история снимается дважды — со шрифтом значков и с недоступным его
  адресом, — и оба кадра сравниваются с эталоном тем же попиксельным сравнением, что и в
  обвязке. Сценарий разовый и живёт во временном каталоге, в репозиторий не едет.
- **Признак готовности:** кадр без шрифта расходится с эталоном тем же числом, которым
  расходились все три встречи, — `0.10305274566473988` процента, 1141 пиксель; кадр со шрифтом
  сходится.
- **Чем проверяется:** `node <временный сценарий> <адрес витрины>` — печатает оба расхождения
  числами, и число второго совпадает с записанным в задаче.

### 2. Кадр перестаёт сниматься без шрифта

- **Что делается:** ожидание шрифта в обвязке снимков перестаёт гасить свой отказ — не
  дождавшись, оно роняет прогон с внятной причиной вместо тихого кадра; сам шрифт перестаёт
  ехать из чужой сети в момент съёмки.
- **Признак готовности:** прогон с недоступным адресом шрифта кончается отказом, называющим
  шрифт, а не расхождением снимка; при доступном — сходится.
- **Чем проверяется:** `node tools/visual-gate.mjs ui-kit` — 47 снимков сошлись; и тот же
  временный сценарий с блокировкой адреса — обвязка отказывает по шрифту.

### 3. Устойчивость подтверждается сотней прогонов

- **Что делается:** одна история снимается сто раз подряд, счётом расхождений.
- **Признак готовности:** сто кадров из ста совпали с эталоном.
- **Чем проверяется:** `bash <временный сценарий серии> 100` — печатает «разошлось 0 из 100».

### 4. Ловушка записывается в правило

- **Что делается:** в правило проверки компонента дописывается статья о том, что ожидание,
  гасящее свой отказ, снимает кадр раньше срока; в ход работы кладётся находка о слое правил.
- **Признак готовности:** статья стоит в правиле дерева, и её текст называет признак — кадр
  снят, а обещанного узла в нём нет.
- **Чем проверяется:** `npm run check:docs` — код ноль, и `pnpm run agent-kit:check` —
  разложенное сходится с пакетом.

## Чего эта работа не делает

- Не трогает обвязку снимков второго кита: киты разведены намеренно, и правка ради одного
  роняет эталоны другого. Если та же ловушка есть и там, она заводится своей задачей.
- Не пересъёмывает эталоны: расхождение ложное, и закреплять кадр без шрифта нельзя.
- Не трогает состав гейта пуша и конвейера.

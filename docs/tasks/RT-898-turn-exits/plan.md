# Замысел

**Задача:** RT-898 · **Ветка:** RT-898-turn-exits
**Поведение:** не меняется — правка задевает ресурсы слоя правил и его гарды, кода приложения
в ней нет ни строки.

## След задачи

| Что     | Где                                                          |
| ------- | ------------------------------------------------------------ |
| Эпик    | замысел эпика о переработке ведения работы                   |
| Законы  | читается, не правится: закон о ведении работы                |
| Правила | пакет слоя правил: правило ведения работы и паттерны при нём |
| Гарды   | пакет слоя правил: гард ожидания и новый страж хода          |
| Код     | пакет слоя правил: его ресурсы и сценарии его гардов         |

## Что считается сделанным

- Законные выходы хода перечислены: вопрос, ответа на который в правилах нет; отказ гарда;
  заполненное окно; отданная работа с начатой следующей. Всё прочее — продолжение хода.
- Страж завершения хода читает объявленное состояние работы и возвращает ход исполнителю, пока
  работа не отдана и владелец не сказал остановиться.
- Прерывание работы владельцем называется вслух: что стоит, на чём остановлено, что дальше.
- У каждого этапа замысла стоит команда проверки и ожидаемый результат; ход не закрывается,
  пока этап объявлен закрытым, а команда не запускалась.
- Сценарии на каждый законный выход и на каждый отказ; прогон зелёный.

## Этапы

### 1. Законные выходы хода объявлены правилом

- **Что делается:** перечень выходов в правиле ведения работы; связь каждого выхода с
  состоянием работы; ловушки, латавшие эти случаи по одной, снимаются.
- **Признак готовности:** четыре выхода названы, и каждый случай груза сводится к одному из
  них.
- **Чем проверяется:** `bash tests/run.sh` — все наборы зелёные; `node tools/check-specs.mjs` — зелено.

### 2. Страж завершения хода

- **Что делается:** гард на завершении хода читает состояние работы и незакрытый контракт
  этапа; отбивает ход, кончившийся вехой; знает слово владельца об остановке.
- **Признак готовности:** сценарий на каждый законный выход и на каждый отказ.
- **Чем проверяется:** `bash tests/run.sh` — набор стража зелёный и краснеет на его поломке.

### 3. Проверка этапа читается стражем

- **Что делается:** образец замысла требует команду обратными кавычками; страж читает её у
  закрытого этапа; правило и спек приводятся.
- **Признак готовности:** образец, правило и спек говорят о проверке этапа одно и то же.
- **Чем проверяется:** `pnpm run agent-kit:check` — разложенное сходится; `npm run check:specs`
  — зелено.

## Чего эта работа не делает

- Готовность к поставке одним состоянием — задача RT-899.
- Роль совести и роль строгого учителя — задачи RT-918 и RT-919.
- Правку закона о ведении работы: его статьи приносятся владельцу текстом.

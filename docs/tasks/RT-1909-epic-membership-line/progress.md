# Ход работы

## Где стоим

Переписывается каждым заходом, а не дописывается.

- **State:** `этап-идёт`
- **Этап:** 1 из 2 — принадлежность объявляется словом о задаче
- **Сделано:** заведены задача, ветка и папка; замысел написан
- **Следующий шаг:** довести первый этап и отметить его здесь
- **Незакоммиченное:** папка задачи
- **Ждём владельца:** нет
- **Заявка:** ещё не открыта

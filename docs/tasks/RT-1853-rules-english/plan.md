## Этапы

### 1. Правила пакета

- **Что делается:** тридцать файлов правил переводятся; заголовки разделов правила получают
  английские имена, и проверки читают оба имени, как у закона.
- **Признак готовности:** в каждом правиле число статей и строк `rt-when` равно прежнему.
- **Чем проверяется:** `bash projects/agent-kit/tests/run.sh` — без провалов;
  `node tools/check-prose-style.mjs projects/agent-kit/assets/rules/*.md` — без замечаний.

### 2. Холодные части и надстройки

- **Что делается:** десять холодных частей и надстройки правил этого дерева переводятся по
  разделам.
- **Признак готовности:** разложенные правила в `.claude/skills/` английские, кроме шапки
  раскладки.
- **Чем проверяется:** `pnpm run agent-kit:sync && pnpm run agent-kit:check` — сходится.

### 3. Компаньоны и предел веса

- **Что делается:** первая колонка привязок в компаньонах дерева переписывается английскими
  статьями; предел веса текста пересчитывается по замеру.
- **Признак готовности:** гейт пуша зелёный.
- **Чем проверяется:** `npm run check:specs` — привязки сходятся; `node tools/check-file-size.mjs`
  — длиннее предела нет.

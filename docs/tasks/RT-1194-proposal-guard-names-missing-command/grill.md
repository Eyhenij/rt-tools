# Разбор просьбы

## Просьба владельца

Задача заведена не просьбой, а находкой разбора закрытой работы: правило прямо велит вывести из
разбора либо правку слоя правил, либо предложение наружу.

## Что уже есть в дереве

- `projects/agent-kit/assets/hooks/proposal-guard.sh:89` — текст отказа печатает
  `npx agent-kit propose`.
- Бинаря `agent-kit` в `node_modules/.bin/` нет: пакет живёт в этом дереве исходниками.
- Опознание отправки исправно: образец `agent-kit[^|;&]*propose` засчитывает вызов через
  собранный bin.
- Остальные места пакета берут строку запуска из профиля — `rt_runner`, здесь `pnpm exec`.

## Что уже сказано в правилах

- **Разбор без правки закрытым не считается** — из него выходит правка слоя правил либо
  предложение наружу.
- **Утверждение компаньона о состоянии внешней службы проверяется командой, которую он сам
  называет** — текст пишет способ спросить, а не снимок ответа. Здесь тот же случай: отказ
  называет команду, и она обязана работать.
- **Переносимый текст говорит о соседнем ресурсе условно** — сказанное безусловно врёт про
  дерево, где всё устроено иначе.

## Решения

- **Гард называет команду по тому, что в дереве есть.** Пакет стоит зависимостью — строка
  запуска дерева; пакет лежит исходниками — собранный bin. Отвергнуто: печатать обе формы
  всегда — исполнитель выбирает наугад ровно там, где ошибся бы и без подсказки.
- **Опознание отправки не трогается** — оно работает.

## Что осталось невыясненным

- Как зовётся бинарь у дерева, поставившего пакет иначе, чем через npm. Не блокирует: такому
  дереву достаётся общая форма, та же, что и сегодня.

## Что считается сделанным

- Отказ гарда называет команду, которая в этом дереве работает.
- У дерева, где пакет стоит зависимостью, отказ называет прежнюю форму.
- Сценарии гарда закрывают оба случая.

## Этапы

### 1. Гард называет исполнимую команду

- **Что делается:** текст отказа собирается по тому, что есть в дереве: бинарь в зависимостях
  либо собранный bin пакета.
- **Признак готовности:** в этом дереве отказ печатает вызов через собранный bin.
- **Чем проверяется:** `bash .claude/hooks/proposal-guard.sh` на подготовленном вводе — в
  отказе стоит команда, которую дерево исполняет.

### 2. Сценарии закрывают оба случая

- **Что делается:** сценарии гарда дописываются на обе формы.
- **Признак готовности:** сценариев стало больше, все зелёные.
- **Чем проверяется:** `node tools/check-hooks.mjs` — число сценариев выросло, все сошлись.

## Чего эта работа не делает

- **Не трогает опознание отправки** — образец засчитывает и вызов через собранный bin.
- **Не заводит ключа профиля под имя бинаря** — команда выводится из того, что лежит в дереве.
- **Не выпускает пакет** — выпуск идёт отдельным решением владельца.

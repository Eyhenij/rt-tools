## Decisions

- **Обход — комментарий `# discard: <причина>` в самой команде** — так устроен обход проверки
  папки задачи (`# Task-folder-skip: <причина>`); пустая причина обходом не считается. Спросить
  было некого: сессия автономная. Цена ошибки: сменить слово в одной строке проверки и в статье.
- **Проверка судит непустой `git status --porcelain` в каталоге вызова** — для `clean` считаются
  и неотслеживаемые файлы, для остальных — только изменённые отслеживаемые. Цена ошибки: лишний
  отказ на чистом дереве невозможен, на грязном — одна строка причины.

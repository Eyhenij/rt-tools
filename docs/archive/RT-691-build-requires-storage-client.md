# Сборка приёмника и пропавший клиент хранилища

Задача RT-691, PR #748; третья задача эпика RT-733 «Приёмник груза». Прежний адрес записи —
`docs/tasks/RT-691-build-requires-storage-client/`.

## Просьба владельца

> Клиент хранилища генерируется установкой зависимостей и лежит вне истории, поэтому его пропажу
> не показывает ни `git status`, ни один линтер. Сборка приёмника при пустом каталоге клиента
> проходит и кладёт бандл, который отвечает пятьсот третьим на приёме предложений; кэш сборок
> закрепляет этот бандл за всеми следующими прогонами.
>
> Что должно быть верно: сборка приёмника отказывает, когда клиента хранилища нет, и называет
> команду, которой он заводится.

## Что владелец решил на разборе

- **Внятный отказ до сборки**, а не проверка отдельной командой дерева и не закрытие задачи
  объяснением.
- **Отказ живёт в сборке приёмника** — так он срабатывает при любом её вызове: локальном,
  конвейерном, из образа.
- **Граница — только приёмник.** Кеш сборок и другие приложения в задачу не входят.
- **Признак закрытия — спека плюс шаг конвейера.**

## Решения по ходу

- **Посылка задачи проверена и оказалась неверной.** Сборка при убранном каталоге клиента не
  проходит: не разрешается импорт клиента, следом идут ошибки типов на каждом обращении к
  таблицам, бандла нет. Предмет работы поэтому другой — отказ есть, а причины и команды починки
  в нём нет: верная строка стоит первой из ста и читается последней.
- **Каталог без входного файла считается пропажей наравне с отсутствующим.** Оборванная
  генерация оставляет каталог, и судить по его наличию значило бы пропустить ровно тот случай,
  ради которого проверка заводится.
- **Спека написана на языке дерева, а функция — на языке конфига сборки.** Конфиг не может
  позвать типизированный модуль напрямую, а разрешать смешивание языков во всём проекте ради
  одной функции дорого; типы для спеки лежат объявлением рядом с функцией.
- **Шаг конвейера заводить не понадобилось.** Он уже собирает приёмник целью сборки, и её отказ
  роняет прогон — это видно по красному прогону соседней ветки того же дня. Второй шаг гонял бы
  ту же сборку дважды.
- **Сборка себя не чинит.** Запуск генератора из конфига дешевле для того, кто собирает, и
  дороже для всех: дерево, установленное наполовину, продолжает выглядеть целым.

## Что осталось невыясненным

- **Закрепляет ли кеш сборок прежний бандл после пропажи клиента.** Выведено владельцем за
  границу работы; записано в «Что не входит» спека домена.
- **Нужен ли такой же отказ другим приложениям дерева.** Клиента хранилища зовёт только
  приёмник, второго потребителя у него нет.

# RT-1915 — задача с меткой груза выпадала из сверки очереди работ

**Ветка:** `RT-1915-cargo-label-task` · **Эпик:** нет · **Разобрано:** 2026-09-08

## Просьба владельца

Сверка очереди работ делила карточки на задачи и груз по метке, и помеченная карточка не судилась
как задача вовсе — ни по исполнителю, ни по доске, ни по связи с эпиком, ни по совпадению
заголовков. Дерево при этом ставит эту метку и на задачи, выросшие из груза: так помечены полтора
десятка карточек, из них две были открыты. Заявка о такой задаче давала ложную строку «задачи нет
среди открытых — у задачи одна ветка», а настоящее расхождение по ней не нашлось бы никогда.
Найдено при закрытии RT-1910.

## Что сделано

- Груз узнаётся по метке при отсутствии заголовка с номером. У настоящей записи груза такого
  заголовка нет, поэтому признаки не спорят: заголовок решает, метка отсеивает оставшееся.
- Статья спека со строкой компаньона и сценарий `SC-AK-923` — в подобласти о сверке очереди
  работ, там же, где лежали сценарии об отсеве груза. Прежде у этого отбора не было ни статьи, ни
  привязки.
- Шесть проб набора о грузе.

## Чем подтверждается

- `bash projects/agent-kit/tests/checks-board-cargo.test.sh` — `14 ok, 0 провалов`; на прежнем
  отборе краснеют четыре новые пробы.
- `npm run check:board` — 3 расхождения, ложной строки о заявке `#1914` нет.
- `node tools/check-specs.mjs` — расхождений нет; `pnpm run agent-kit:check` — разложенное
  сходится с пакетом.

## Что осталось открытым

- Метка груза ни с одной карточки не снята: она говорит читателю, откуда выросла работа, и это её
  дело.
- Оставшиеся расхождения очереди работ этой работой не закрывались: задача `#1684` без
  исполнителя, отставшая ветка чужой заявки `#1912` и производство, отставшее от главной ветки.

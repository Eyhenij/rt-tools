# RT-3091 — пропуск паттерна в варианте хостинга засчитывается проверкой описаний

Задача RT-3091, ветка `RT-3091-skip-hosting-variant` от ветки `RT-3095-dispatch-one-json`, работа
вне эпика по слову владельца. Папка задачи `docs/tasks/RT-3091-skip-hosting-variant/` разобрана в
эту запись.

## Просьба владельца

> если по текущей открыт пр то бери след задачу, только сначала удали влитые ветки, и проверь перетащились ли тикеты куда нужно

Постоянное поручение: когда PR по текущей задаче открыт, следующая задача вне эпика берётся без
вопроса. В очереди RT-3091 звучит так: дерево законно пропускает паттерн, который пакет держит
только в варианте для GitHub, а проверка описаний всё равно говорит, что у правила нет ни одного
паттерна. Список пропусков читался в имя `status-report-table.github`, а правило называет
`status-report-table`.

## Решения по ходу

- **Всё после первой точки в имени — вариант.** В имени паттерна точки не бывает, поэтому список
  хостингов не нужен, и срез переживёт новую ось вариантов.

## Проверено

- Набор проверок описаний: 57 проверок, 0 провалов; строка SC-AK-1261 падала до правки.
- Проверка описаний этого дерева проходит, разложенные копии сходятся с пакетом v0.33.1.

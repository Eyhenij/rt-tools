# RT-2503 — тесты компонентов идут в устаревшей среде: jsdom 27 → 30

**Ветка:** `RT-2503-jsdom-30` (вне эпика, второй мажор из списка RT-2081) ·
**Разобрано:** 2026-10-03

## Просьба владельца

> обнови npm пакеты

Мажоры этой просьбы вынесены в список RT-2081, по задаче на мажор. RT-2503 взята за RT-2501.

## Решения

- **jsdom поднят до 30.1.1 без потолка.** Его берут `jest-preset-angular` (`>=26.0.0`), среда
  Jest и vitest (`*`) — никто из зависимых не держит младший мажор.
- **webpack-dev-server 6 из того же списка не взят:** `@nx/webpack` 23.2.1 держит `^5.0.0`.

## Проверки

- `pnpm test` — цель `test` прошла в 122 проектах; 120 запущены заново, 2 (`utils`,
  `agent-kit`) взяты из кэша — jsdom они не используют. Чинить ничего не пришлось.

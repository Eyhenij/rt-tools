# RT-2395 — аккордеон второго кита

**Ветка:** `RT-2395-ui-kit-v2-accordion` (от `main`, вне эпика по слову владельца) · **Разобрано:** 2026-09-29

## Просьба владельца

> работай в rt-worktree-2, подтяни туда самый свежий main, изучи правила работы в этом проекте и
> добавь новый компоеннт в соответвии со всеми правилами и требованиями rt-tools

## Решения и куда они ушли

- **Пункты раскрываются независимо, при входе раскрыт пункт из `openIndex`, по умолчанию
  первый.** Читающий сравнивает два ответа, и сворачивать первый при раскрытии второго нельзя. Ушло
  в правила спеки `docs/specs/ui-kit-v2/accordion/` и сценарии SC-UKV-394…405.
- **Решение о раскрытии лежит чистыми функциями рядом с компонентом.** Оно проверяется вызовом, а
  компонент остаётся тонкой обёрткой.
- **Id кнопок и панелей берутся из счётчика на экземпляр**, как у панели выбора и подсказки ввода.
  Два аккордеона на странице не ссылаются на чужие панели.
- **Ось `Opening` витрины показывает первый, третий и ни одного раскрытого.** Несколько раскрытых
  пунктов получаются только нажатиями, их показывает `Playground`.
- **Выпуск версии пакета в задачу не вошёл.** Публикация идёт отдельным ручным прогоном после
  слияния, по слову владельца.

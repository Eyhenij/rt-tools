# RT-2230 — конец эпика, прочитанный по таблице, отпускает ход целиком

**Ветка:** `RT-2230-epic-end-releases-turn` (от `RT-2228-exit-guard-epic-branch`) · **Разобрано:** 2026-09-18

## Просьба владельца

> разбирай Промах проверки выхода из хода на ветке эпика: кандидат в задачу следующего эпика по правилам.

Ответ владельца на вопрос «куда завести работу»: «Новый эпик, две задачи — беру в работу сразу».
Это вторая задача эпика RT-2228; первая, RT-2229, про ветку эпика.

## Что было не так

Признак конца эпика снимал в проверке выхода из хода только ярус «жду твоего слова». Пустой ход
с таблицей эпика и словами «жду распоряжений», который правило называет законной остановкой,
отклонялся следующим ярусом. Проверка ожидания при этом отпускала конец эпика целиком: две
проверки читали один признак по-разному.

## Разбор

Пять вопросов закрыты разведкой, вопрос о числе задач — владельцем на разборе эпика. Место
чтения выбрано по статье описания «The epic is read once per turn and only on the way to a
refusal»: чтение до ярусов ходило бы в сеть на каждом конце хода.

## Решения

- **Конец эпика отпускает ход внутри общей функции отказа** — все ярусы кончаются в ней, и
  чтение остаётся по дороге к отказу. Отклонено: выход с нулём до ярусов — сеть на каждом ходу.
- **Признак конца эпика переехал в файл ярусов и читает общий кэш** — второе определение в файле
  образцов ходило в сеть отдельно. Отклонено: оставить оба — два чтения одного за ход.
- **Нечитаемый эпик не отпускает ничего** — иначе ход на `main` и в дереве без таблицы отпускался
  бы всегда. На `main` ход судится как прежде, правило говорит это словами.
- **Сценарий SC-AK-1119 сужен, SC-AK-1129 новый** — обещание изменилось, номер остался, заголовки
  тестов переписаны тем же коммитом.

## Цена

Одна функция и один признак в файле ярусов, одна строка в общей функции отказа, минус девять
строк в файле образцов. Набор ярусов эпика вырос с 28 до 32 проверок. Правило `turn-conduct`
стоит в четырнадцати знаках от предела длины: следующая статья потребует холодной части.

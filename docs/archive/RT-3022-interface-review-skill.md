# RT-3022 — навык ревью интерфейса одной системой

Задача RT-3022, ветка `RT-3022-interface-review-skill` от `main`, работа вне эпика по слову
владельца. Папка задачи разобрана в эту запись.

## Просьба владельца

> добавь себе в скилы и так же добавь в agent kit; # Review the interface as one system
>
> A strong interface is not five independent audits stapled together. […]

Полный текст навыка пришёл в том же сообщении. Он перенесён в ресурсы пакета без пересказа; своё в
этой работе — только разбиение на файлы и ссылки между ними.

## Что было в дереве

- Навыки пакета лежат в `projects/agent-kit/assets/skills/` и раскладываются как
  `<имя>/SKILL.md`. Закона над навыком нет.
- Ресурс, нужный дереву только при свойстве, несёт суффикс `needs-<свойство>`. Пакет объявляет
  свойства `app` (экраны для людей) и `mockups` (кадры в дизайн-инструменте); у этого дерева есть
  оба.
- Предел текста слоя правил — 330 строк и 24 000 символов на файл.
- Ни в пакете, ни среди личных навыков владельца ревью интерфейса целиком не было.

## Вопросы

Вопросов не было: просьба называет оба места и даёт весь текст.

## Решения

- **Текст лёг семью навыками пакета, а не одним.** Он втрое длиннее предела одного файла.
  Отвергнуто: поднять предел — он держит все остальные тексты слоя.
- **Ядро `interface-review` держит порядок ревью и форму отчёта, остальные шесть — его справочники.**
  Принципы пяти областей, карточки на кадре Figma, поверхности, анимации, значки, производительность.
- **Шесть навыков требуют свойства `app`, карточки Figma — `mockups`.** Дереву без экранов нечего
  ревьюить, дереву без кадров нечего размечать.
- **Личная копия владельца — те же семь навыков.** Один текст в двух формах разошёлся бы на первой
  правке.

## Отступления от присланного текста

- «leverage» заменено на «payoff»: проверка текстов дерева это слово запрещает.
- Ссылки «выше» внутри текста заменены именами соседних навыков: после разбиения «above» никуда не
  ведёт.
- Примеры кода в навыке анимаций сложены, но не урезаны: общий объект вариантов, общие строки
  классов, тело ключевого кадра в одну строку. Файл должен уложиться в 330 строк, поведение каждого
  примера то же.
- В описании навыка значков разбито предложение длиннее 40 слов.

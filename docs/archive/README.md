# Архив закрытых работ

Здесь лежит то, что объясняет состоявшееся решение: почему задача была поставлена так, а не
иначе, и что решили по ходу, когда замысел разошёлся с делом. Читают это, когда старое
решение мешает новому и надо понять, чем оно держалось.

Записи описывают день переезда. Пути и имена в них с тех пор могли измениться — поэтому архив
выведен из проверки путей целиком, и указанием к действию его строки не являются.

## Что сюда попадает

- **Разбор просьбы** закрытой задачи — ответы владельца его словами. Восстановить их неоткуда:
  разговор нигде больше не записан.
- **Закрытая линия работ** — ход, разошедшийся с замыслом, приёмы, отработанные на первых
  волнах, и цена принятых решений. Пока линия открыта, она живёт в `docs/plans/`.
- **Решения по ходу с причинами** — то место хода работы, где дело разошлось с замыслом и
  сказано, почему.

## Чего здесь нет

- **Замыслов.** После выкатки на вопрос «что собирались сделать» отвечает код, а на «как
  работает» — спек домена.
- **Хода работы без решений.** «Где стоим» и записи заходов живут, пока идёт работа, и умирают
  вместе с папкой задачи.
- **Правок задним числом.** Запись правится только вместе с признанием, что описывала неверно,
  — а не потому, что дерево с тех пор изменилось.

## Как называется запись

`RT-<номер задачи>-<slug ветки>.md`, а внутри, третьей строкой, — номер задачи, номер отчёта и
день слияния. По ним от записи есть дорога к обсуждению правки и к коммитам, а имя файла
совпадает с именем ветки, которой работа делалась.

Закрытая линия работ приезжает сюда под своим именем, с суффиксом `-line` и без номера: линия
переживает несколько задач, и номер одной из них называл бы её неверно. Внутри — день закрытия
и номера задач, которыми продолжено то, что осталось за её границей.

Одна работа — один файл, а не папка из трёх: архив читают глазами, и папка, в которую надо
заходить, читаться перестаёт.

## Что лежит

Указатель сверяется с каталогом обеими сторонами — `npm run check:docs`: запись без строки и
строка без записи одинаково расхождение. Молча разойтись он поэтому больше не может, и читают
архив по нему, а не обходом.

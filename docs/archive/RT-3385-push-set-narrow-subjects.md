# RT-3385 — набор перед пушем не поднимает тяжёлые шаги для пакетов без потребителей и для файлов CI

Задача RT-3385, запись от 2026-11-18.

## Просьба владельца

> как исправить гейт чтобы он не гонял лишние проверки?

Затем: «Да, делай».

## Что нашли

Функция выбора предметов в профиле дерева считала всякий неизвестный путь затрагивающим всё. Ветка из одного файла пакета протокола чата или из файла процесса CI запускала все шесть тяжёлых шагов: e2e админки, два образа, снимки кита и стенд входа. Ни один из них эти файлы не читает.

## Что сделано

- Пути `projects/ai-chat-protocol/`, `projects/cms-*` и `.github/` не называют предметов. Их закрывают проверки затронутых проектов.
- Корневые настройки и пакеты, которые приложения берут как исходники (`utils`, `core`, `store`), по-прежнему запускают всё.
- В `tools/tests/push-heavy-subjects.test.sh` четыре сценария о новых путях; два из них падали до правки. Итог: 21 из 21.

## Решения

- Список коротких путей, а не отмена общего случая: неизвестный путь по-прежнему запускает всё, лучше лишний запуск, чем пропуск.
- Пакеты `cms-*` импортируют только друг друга, а `ai-chat-protocol` не импортирует никто, кроме списка путей в `tsconfig.base.json`: приложения их не берут, проверено поиском по импортам.

## Что не доделано

Строка «не запускалось: нет такого файла» для тяжёлых шагов не внесена: сначала надо проверить, как запускающий набор читает такие строки. Отдельная задача.

# RT-2085 — столбец To test на доске и новые идентификаторы вариантов Status

**Ветка:** `RT-2085-board-to-test-column` · **Разобрано:** 2026-09-14

## Просьба владельца

> введи ещё одну колонку to test между in review и done, перемести туда все задачи из done

## Вопросы и ответы

**Что делать с 756 закрытыми карточками, которые ушли в архив доски с пустым статусом?**
Оставить в архиве.

## Решения

- **Столбец добавлен запросом `updateProjectV2Field` с полным списком вариантов.** GitHub
  пересоздал все варианты с новыми идентификаторами: статус слетел у всех карточек, а рабочий
  процесс auto-archive убрал в архив все 784 закрытые. Цена: восстановление доски вручную по
  перечню, снятому в том же сеансе, — 49 видимых карточек вернулись в свои столбцы, 30 закрытых
  за день достали из архива и поставили в To test. В следующий раз столбец добавляется из
  интерфейса доски, а не запросом.
- **Настройка доски, а не инструменты.** `to-test` — ещё один ключ `statusOptions`; команда
  переноса читает любой ключ объекта.
- **Столбец Deployed по-прежнему вне настройки.** Ничто в дереве туда не переносит.

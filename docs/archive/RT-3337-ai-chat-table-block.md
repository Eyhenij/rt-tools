# RT-3337 — блок таблицы в ответе чата

Задача RT-3337 эпика RT-3346, ветка `RT-3337-ai-chat-table-block` от ветки
`RT-3336-ai-chat-chart-data`, 19.11.2026. Бывший адрес — папка задачи
`docs/tasks/RT-3337-ai-chat-table-block/`. Правила блока вошли в подраздел
`docs/specs/ui-kit-v2/ai-chat-table/`, техника — в `Overview.mdx` блока и в `CONTEXT.md` чата и

## Просьба

> Делай эпик дальше

Задача эпика по плану: блок `table` в ответе `rt-ai-chat` — столбцы с родом значения, выравнивание
по роду, минус цветом из токенов, закреплённая шапка, прокрутка вбок внутри блока, строка итога по
желанию, копия CSV и тот же вид у таблиц разметки. Готово, когда таблица на 12 столбцов
прокручивается внутри блока, числа стоят справа, CSV копируется, а в витрине есть узкая, широкая,
с итогом и с минусами.

Слово владельца о выпуске, 15.11.2026: «После 3337 + в конце». Первый выпуск кита идёт после того,
как PR #3398, #3402 и PR этой задачи влиты по очереди, затем PR ветки эпика в главную.

## Вопросы и решения

Шесть вопросов закрыты допущением: владелец пять раз подряд брал рекомендованный вариант.

- Блок — тип кита, не отрисовщик: ему не нужен d3, он стоит рядом с `markdown` и `notice`.
- Запись ячейки и CSV — чистые функции в `core`, общие для блока и разметки.
- Таблица разметки читает `--:` и `:-:`, берёт вид блока, тип по содержимому не угадывает.
- Минус — цветом `--rt-color-state-error-text`, знак минуса — тот, что пишет язык.
- «Copy CSV» — текстовая кнопка под таблицей; копия ответа даёт таблицу строками через табуляцию.

## Решения по пути

- Чтение одобренного макета перед историями нашло заголовок над таблицей, верхнюю границу таблицы,
  целые суммы без копеек и проценты с одним знаком. Всё это вошло в договорённость и в код.
- История `Rtl` нашла дефект: под `dir="rtl"` записанное число рассыпалось в «% 4,2-». Значение
  числового столбца теперь стоит в `bdi`. Ячейка разметки остаётся текстом автора.
- `Wide` и `Scrolled` двигают окно присвоением: событие клавиши из сценария окно не прокручивает.
  `Copied` без кадра: «Скопировано» живёт две секунды, смену подписи проверяет шаг `play`.
- Кадр панели разбора в админке переснят: таблица разметки рисует общий вид. Стенд шёл на
  свободных портах: 3377 и 4378 держал чужой стенд.
- Наложение на макет расходится на 4,53%: растр текста и линии вокруг итога. В макете между
  последней строкой и итогом линия двойная и нет линии под итогом; в витрине — одна линия и линия
  под итогом, как велит договорённость. Минус в макете «−», в витрине «-». Владелец одобрил
  витрину с обоими расхождениями.
- Обход витрины нашёл четыре истории чата с пустым значком: пункт меню просил иконку `archive`,
  которой нет в наборе. По слову владельца правка сделана в этой ветке отдельным коммитом: пункт
  берёт `box`.
- Проверка `product-strategist` нашла, что схема блока для модели не называла `title`: заголовок
  вошёл в договорённость на этапе 5, а схема была написана раньше. Схема называет его, README кита
  называет схему таблицы рядом со схемой графика.
- В плане шаг 4.7 переводит таблицу данных графика на общий вид, а раздел о том, чего работа не
  делает, говорит обратное. Сделано по шагу 4.7: его добавил владелец словами «Одобряю план с
  добавками».

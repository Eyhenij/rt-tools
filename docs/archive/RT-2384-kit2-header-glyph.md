# RT-2384 · Шапка колонки второго кита рисует значок без пары глифом Material Symbols

Задача RT-2384, PR в ветку эпика RT-1870, закрыто 28 сентября 2026 года. Ветка
`RT-2384-kit2-header-glyph`.

## С чего началось

Владелец прислал три замечания по пакету. Первое — в архиве нет собранного CSS: пакет был собран
без `build:tokens-v2`, пересобран верной командой. Третье — подсказка у кнопки оператора: она уже
есть, `rt-menu` показывает её с именем оператора. Второе подтвердилось только в шапке колонки:
ячейка рисовала значок без пары глифом с RT-2374, шапка — нет. Ответ владельца: «Задачей в RT-1870
(Рекомендую)».

## Что сделано

- Шапка рисует имя без пары в перечне глифом Material Symbols, как ячейка. Сценарий SC-UKV-319 расширен на шапку.
- Тесты второго кита — 1804 из 1804, кадры — 642 из 642.

## Куда ушли решения

- Правило — в описании `table-full-port`, рядом с правилом ячейки.

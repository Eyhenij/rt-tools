## What the tree already has

- Пакет собран одной точкой входа: `fesm2022/rt-tools-ui-kit-v2.mjs` весит 2 МБ. Второй вход один —
  `rich-editor`, его каталог с `ng-package.json` лежит рядом с исходниками, а входной файл — в `src`.
- Сборщик приложения не делит один модуль между кусками. Компонент кита внутри `@defer` остаётся в
  начальном куске, если кит где-то подключён сразу.
- Компоненты берут друг друга относительными путями. Граф каталогов без витрины и тестов циклов
  не даёт, кроме ядра и значка: настройки называют модели кнопки, таблицы данных, поля ввода,
  скругления и значка.

## What the rules already say

- Готовое расширяется там, где живёт (`reuse-first`): недостающее делается в ките.
- Пакет не реэкспортирует символ соседнего пакета `@rt-tools` (правило линта в корне дерева).

## Decisions

- **Точка входа на каждый каталог компонента плюс вход `core`.** В ядре настройки, словари, среда
  исполнения, токены, пайпы, прокрутка, чистые функции и шесть файлов моделей, которые называют
  настройки. Так разрывается цикл ядра и значка. Отвергнуто: семьи компонентов — граница семьи
  выбирается на глаз, а приложение всё равно тянет семью целиком.
- **Корень пакета переотдаёт все точки входа.** Прежние импорты у потребителей не меняются.
- **Входной файл ядра — `src/lib/core.ts`.** Корень исходников точки — каталог её входного файла,
  а файлы ядра лежат в соседних каталогах.
- **Внутренние функции, которые компоненты берут друг у друга, отданы своими входами.** Выбор
  даты, дерево выпадающего списка, окно несохранённой правки панели, карта значков Material,
  материальный пресет. Пагинация получила вход, но корень её по-прежнему не называет.
- **Импорт по имени пакета разрешён всем исходникам кита, а реэкспорт своих входов — корню.**
  Исключение `rich-editor` в конфиге линта расширено на весь `src`. Запрет реэкспорта соседнего
  пакета остался: проверено вставкой `export * from '@rt-tools/core'`.

# RT-1946 — таблица задач эпика собирается командой

## Просьба владельца

> изучи как это сделано на дереве-образце - там агент выводит таблицу с задачами эпика и кратким
> описанием и статусами задач - нужно предоставить такой функционал для всех потребителей через
> agent kit.

## Что решали

Вид таблицы был записан — правило отчёта и приём рядом, — а собирал её сам заход: помнил, какие
вызовы сделать, в каком порядке и как свести ответы в клетки. Заход, только начавшийся, не помнит
ничего из этого, а проработавший часы сводит иначе, чем предыдущий: два ответа об одной работе
расходятся.

Дерево-образец собрано тем же пакетом и своей команды не имело: образцом служил вид таблицы, а не
готовое средство.

## Принятые решения

- **Команда живёт в слое проверок, а не рядом с отправкой груза.** Всё, чем клетка заполняется,
  уже лежит в разложенной работе с очередью: клиент хостинга, доска, прогоны. У стороны отправки
  ни того, ни другого нет.
- **Эпик без довода берётся из текущей ветки.** Ветка даёт задачу, тело задачи объявляет эпик,
  тело эпика называет замысел. Довод остаётся: с чужой ветки таблица тоже нужна.
- **Чтение замысла вынесено рядом со сверкой связей.** Второй читатель той же карточки разошёлся
  бы с первым молча: один считал бы строку задачей, другой нет.
- **Клетка называет итог прогона словом владельца.** «Зелёный», «красный», «идёт»: слово хостинга
  владельцу ничего не говорит.
- **Прогон спрашивается по вершине заявки, а не по ветке.** Список прогонов ветки отвечает о
  последнем коммите, который прогон начал, и зелёный прогон ушедшего коммита читается как зелёная
  вершина.
- **Строка задачи, которой нет на доске, не пропускается.** Счёт оставшейся работы — то, ради чего
  таблицу и читают.

## Чем закрыто

Поддомен `docs/specs/agent-kit/epic-table/` — девять сценариев SC-AK-969…977, все закрыты набором
`projects/agent-kit/tests/epic-table.test.sh`: 25 проб зелёные. Все наборы пакета зелёные. Своды
`npm run check:specs`, `npm run check:boundary`, `npm run agent-kit:check` — код ноль. Команда
прогнана на живом эпике RT-1940: семь строк, у каждой номер, о чём задача и состояние.

## Что подвело в ходе работы

Причёсыватель обходит источники пакета и правит разложенную копию на коммите: свод раскладки
краснел на ней после каждого коммита. Вылечено записью источника в том же виде, в каком его кладёт
причёсыватель дерева.

Одноразовое дерево пробы заводилось без первого коммита, и возврат на ветку молча не срабатывал —
следом краснела половина сценариев.

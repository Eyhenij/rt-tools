## Что было

21.10 кит вышел из main, в который вошёл PR без прогона конвейера. Правка объявила корень документа
контейнером места страницы, и фон страниц у приложений кончался под содержимым. Сквозные тесты
приложений этой правки не видели, а конвейер выпуска их не запускает.

## Решение

- В правиле `deploy-flow` появилась статья: пакет, который ставят приложения самого дерева,
  выпускается с вершины, на которой прошли их сквозные наборы. Если после последнего зелёного
  прогона в main вошёл PR без прогона, наборы идут на вершине main до выпуска.
- Статья стоит во всех трёх вариантах правила: выпуск устроен одинаково на любом хостинге.
- Файл привязок говорит, что машина этого не проверяет: конвейеры выпуска наборов не запускают.

## Цена решения

Выпуск после такого PR стал дольше на сквозные наборы. Проверки нет: выпускающий сам читает прогоны
влитых PR. Конвейер выпуска не менялся, потому что задача просила правило.

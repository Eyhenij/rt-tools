# RT-2982 — сценарии ИИ-чата получили свои номера

Задача RT-2982, ветка `RT-2982-scenario-dupes` от `main`. Папка задачи разобрана в эту запись.

## Просьба владельца

Пуш RT-2987 держала красная сверка спеков на `main`. Владелец выбрал: «Сначала починить
RT-2982». Строку копии `rt-tools-overlay` в таблице назначений вписали по его слову «Да, впиши».

## Что было

- Номера SC-UKV-1040…1046 стояли дважды: в сценариях ИИ-чата и в сценариях панели (1040…1044) или
  словаря формы (1045, 1046). Эпик RT-2958 взял номера, пока параллельно вливались эти два поддомена.

## Решения

- **Новые номера получили сценарии ИИ-чата: 1040…1046 → 1073…1079.** Так велит сама задача;
  1073 — первый свободный номер по всем веткам (`pnpm run spec:next-id SC-UKV`). Отказались:
  перенумеровать панель и словарь формы — задача называет ИИ-чат.

## Чем подтверждено

- `node tools/check-specs.mjs`: расхождений нет. Тесты шести затронутых спеков: 95 из 95.

## Не решено

- Ставить ли сверку спеков в конвейер — вопрос задачи остаётся владельцу: без неё двойные номера
  на `main` снова никто не увидит до следующего пуша.

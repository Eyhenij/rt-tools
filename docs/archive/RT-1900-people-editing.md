# RT-1900 — завести пользователя, отключить и сменить пароль можно с экрана

**Ветка:** `RT-1900-people-editing` · **Разобрано:** 2026-09-15 · эпик RT-1896, задача 4

## Просьба владельца

> бери в работу 1896 и доводи до конца

Карточка задачи: завести человека, отключить его или сменить ему пароль можно только с узла по ssh;
владелец без доступа к узлу не может дать доступ никому. Три действия переезжают панелью рядом со
списком, имя и первый пароль назначает заводящий, отключение обрывает прежние входы, действия
закрыты правом на правку людей.

## Что сделано

- Приёмник: три операции под `accounts:manage` — заведение, новый пароль, отключение с обрывом
  входов. Занятое имя, пустой пароль, своя запись, уже отключённая и незнакомое имя отвечают
  словами про действие человека; каждая операция отвечает строкой списка.
- Админка: кнопка «Завести пользователя» и панель с именем и паролем; меню строки — «Сменить
  пароль» с панелью по адресу «people/<имя>/password» и «Отключить» с вопросом. Кнопка и меню
  видны только с правом; своя строка отключения не получает.
- Разбор отказа со словом приёмника поднят из раздела приглашений в общий слой админки.
- Поддомен `people-editing` с девятью сценами; сквозной набор панели, 111 проверок зелёные.

## Умолчания вместо вопросов

- **Две панели и пункт меню, а не одна панель с тремя режимами.** Отключению нечего спрашивать.
- **Пароль вводит заводящий и передаёт человеку сам.** У приёмника нет ни почты, ни второго места
  показа; после удачи панель закрывается.
- **Свою запись приёмник не отключает, а экран не рисует пункт.** Иначе человек выбил бы себя же.
- **Обратного включения нет.** У строки запуска его тоже нет; нужная снова запись заводится заново.
- **Правила пароля нет.** Строка запуска принимает любой непустой; правило — решение владельца.

## Что нашлось по дороге

- Файл границ семьи админки дорос до предела длины: рёбра раздела людей ушли в свой файл, общие
  метки семьи — в файл рядом. Проверка слоёв читает файлы рёбер по окончанию `.config.mjs`.
- `openDetails` основы списочного экрана принимает хвост сегментов: панели одной стороны записи
  нужен адрес «имя/сторона».
- Заведённая без роли запись после входа остаётся на экране входа: ей не открыт ни один раздел, а
  экрана «без разделов» на этом пути нет. Набор читает исход входа по ответу операции. Экран для
  человека без прав — вопрос к эпику, не к этой задаче.

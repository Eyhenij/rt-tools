# RT-1961 — семья подтверждения была разорвана надвое между разделами витрины

**Ветка:** `RT-1961-confirm-family-one-section` · **Разобрано:** 2026-09-14

## Откуда взялась работа

Задача шестого шага плана эпика «Один кит», строка 6.13. Заведена при разборе RT-1960, когда
сверялись адреса страниц витрины. Взята по порядку плана, владелец её не диктовал.

## Что было не так

Человек, открывший обзор семьи подтверждения, соседнюю страницу входов в том же разделе не
находил. Три файла историй одной семьи стояли в двух местах:

| Файл                         | Раздел                     |
| ---------------------------- | -------------------------- |
| `confirm-matrix.stories.ts`  | `Organisms/Dialog/Confirm` |
| `confirm.stories.ts`         | `Organisms/Dialog/Confirm` |
| `confirm-popover.stories.ts` | `Molecules/ConfirmPopover` |

Обзор семьи объявлен как `Organisms/Dialog/Confirm/Overview` — раздел семьи был задан, и третий
файл стоял вне его.

## Что сделано

Одиночка переехал в подраздел семьи — `Organisms/Dialog/Confirm/ConfirmPopover`. Эталон
переименован тем же коммитом.

## Почему так, а не иначе

- **Переезжал одиночка, а не семья.** Раздел семьи уже задан обзором.
- **Всплывающее получило подраздел, а не общий заголовок.** Оба файла объявляют показ с именем
  `Playground`: под одним заголовком их адреса совпали бы и один затёр бы другой. Показывают они
  при этом разное — один указание, другой компонент.
- **Подраздел назван полным именем компонента, а не коротким.** Проверка охвата берёт предмет
  показа из последнего куска заголовка. При коротком имени она назвала компонент предметом ни
  одного показа — то есть молчаливой дырой в охвате.
- **Эталон переименован тем же коммитом.** Оставленный со старым именем, он стал бы сиротой.
- **Кит не правился.** Ни компонент, ни указание, ни их стили.

## Чем проверено

На поднятой витрине адреса, начинающегося с `molecules-confirmpopover`, нет; семья стоит одним
куском из восьми записей, всего историй 625 — как и было. Кадр новой страницы снят и просмотрен:
всплывающее нарисовано в обеих половинах набора оформления. `pnpm run test:visual:v2` — 568
эталонов сошлись, 168 наборов, сирот нет. `check-showcase-links` — 716 страниц, 345 ссылок,
ведущих никуда нет. `check-kit-coverage` — 74 семьи, 116 составляющих, код 0.

## Что осталось за работой

- **Прочие разорванные семьи не сводятся.** Эта работа про одну; сплошной обход разделов витрины —
  работа своего объёма.
- **Имена показов не переименовывались.** Столкновение снято подразделом: под разными заголовками
  оба имени законны.

# Разложенный слой правил судится гардом замысла наравне с кодом

Задача RT-1252, заявки нет — ветка местная, слияния не было.

## Откуда взялась работа

Запись груза из приёма, своё дерево, гард замысла. Повод: гард судит по путям кода приложения, а
ходовая правка слоя правил идёт мимо них — в каталог законов, в каталог агента и в каталог
проверок. Полторы сотни файлов легли, и гард не отозвался; отбил он двумя ходами позже, на
записи в папку задачи.

Владелец разбор не вёл: заход шёл сам, задачи брались из приёма одна за другой.

## Решение и довод

Признак взят готовый — шапка раскладки, по которой слой находит гейт правил. Заводить второй
список путей значило бы держать два ответа на один вопрос: где лежит слой. Список расходится с
раскладкой в тот день, когда ресурс переезжает, и молчит об этом.

Шапка читается у трёх первых строк файла. Ниже она не стоит нигде, а чтение файла целиком гард
делал бы на каждой правке.

## Цена

Гард стал читать файл, а не только его путь. Прежде он отвечал по имени; теперь у каждого
кандидата, не попавшего под пути кода, читаются три строки с диска. Для команды, называющей
десяток путей, это десяток чтений на ход.

Второе: ресурс пакета, из которого раскладка идёт, шапки не несёт — правка исходника слоя
по-прежнему судится своим путём, и в дереве, где пакет живёт исходниками, эта статья не
закрывает ничего.

## Решения разбора

- **Кеш значка пишется на `AsyncSubject`.** Он хранит один ответ и отдаёт его поздним подписчикам, как `shareReplay(1)`.
  Отброшено: обещание с `from` — оно меняет порядок ответа на микрозадачу.
- **Ленивые загрузки не откатываются.** Остаток набирается без них.

## Решения по ходу

- Ответ владельца 27.11 в меню вместе с первым одобрением плана: «Замерить откат». В этой задаче собирается временная
  копия без двух ленивых загрузок, и числа пишутся в план эпика. Код кита откатом не меняется.
- План переписывался до первой отправки, владелец одобрял его трижды. Причины: форма ожидаемого результата в проверке,
  две проверки, зелёные до работы, запрет линтера на подписку внутри метода и рост порога веса кита на 121 байт.
- Откат обеих ленивых загрузок измерен на временной копии: −734 байта и −3957 gzip по файлам. Тесты на такой копии не
  проходят, 172 из 4443, поэтому это только вес.
- **Цена:** в пороге веса кита `icon` вырос на 243 байта, `tooltip` на 6. Приложение, которое само берёт `shareReplay`,
  стало тяжелее на 261 байт.
- **Отменено:** решение разбора «кеш значка пишется на `AsyncSubject`». Отменено и «поведение не меняется»: запрос в
  полёте отменяется при уничтожении реестра, а из нескольких ответов берётся первый.
- Первый круг: `qa-engineer` и `goal-critic`.
    - Высокая, подтверждена и исправлена: значок не рисовался, когда поток запроса отдал ответ и не завершился. Прежнее
      «поведение не меняется» было неверно. Ответ теперь уходит подписчикам сразу, добавлен сценарий SC-UKV-1895.
    - Средняя, исправлена: ни один тест не проверял отдачу приехавшего файла позднему подписчику. С обычным `Subject`
      все тесты проходили. Добавлен второй тест сценария SC-UKV-1882, мутант он ловит.
    - Названы в плане эпика: отмена запроса при уничтожении реестра, условие выигрыша, остаток без проверки в дереве.
      Устаревшие строки плана исправлены. Тип пары «адрес и субъект» получил имя.
    - Не чинится здесь: две обязанности реестра значков (загрузка файлов и спрайт). Было так до этой правки.
- План обещал тесты значка без правок. Старые тесты не менялись, добавлены три новых и один сценарий.
- Второй круг: `qa-engineer`, `product-strategist` и `goal-critic` по всей ветке.
    - Высокая, подтверждена и исправлена: приложению, которое само берёт `shareReplay`, `AsyncSubject` добавлял 755
      байт. Отход от плана: вместо `AsyncSubject` запись адреса хранит ответ, а ждущие получают его через `Subject` и
      `defer`. Пробному приложению −2015, приложению с оператором +261.
    - Низкая, исправлена: поток без ответа не завершал ждущих. Добавлен тест на ошибку после ответа. Мутанты «без
      запомненного ответа» и «поздняя ошибка затирает ответ» тесты ловят.
    - Исправлены пробел в названии теста, комментарий реестра и устаревшие числа.
    - Дописаны в план эпика: цена отката для API 0.53.0, неразобранный рост вне кита, измерение в следующих задачах.
    - Не чинится здесь: отмена запроса при уничтожении реестра без теста, две обязанности реестра. Из нескольких ответов
      берётся первый, это названо в плане эпика.

## Чем подтверждено

- Тесты кита: 432 набора, 4459 тестов.
- Мутанты: без запомненного ответа падают два теста; когда поздняя ошибка затирает ответ, падает один.
- Пробное приложение: 544886 байт при признаке не больше 545644.
- Живая проверка на витрине в закреплённом Chrome: 364 символа по 238 запросам, повторных адресов нет. Она снята на
  первой версии кеша. На окончательной версии повторить не вышло: закреплённый профиль не был подключён.
- Путь ревью: по плану лёгкий, по разнице полный. Первый круг: `qa-engineer` и `goal-critic`. Он нашёл дефект: значок не
  рисовался, когда поток запроса не завершался. Второй круг по всей ветке: `qa-engineer`, `product-strategist`,
  `goal-critic`. Он нашёл вес, добавленный приложению с `shareReplay`. Первый дефект исправлен. Второй уменьшен с +755
  до +261 байта. Код правок второго круга роли не перечитывали; `goal-critic` после них читал это описание.

## Оставшийся шаг

- Откат ленивых загрузок идёт только по слову владельца: −734 байта и −3957 gzip по файлам, ломает API 0.53.0. У копии
  отката измерен только вес: в ней падают 172 теста из 4443, поведение не проверено.
- Остаток 13000 проверки дерева не держат, скрипт пробного приложения лежит вне дерева. RT-3647, RT-3649 и RT-3650
  повторяют измерение, RT-3716 кладёт скрипт в дерево.
- Выпуск и измерение сборки из `npm pack` — RT-3716.
- Не чинится здесь: отмена запроса при уничтожении реестра без теста; у реестра значков две обязанности.

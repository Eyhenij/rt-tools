## What the tree already has

- `node tools/check-reuse.mjs` на свежем main даёт 8 расхождений `inline-template`: обёртки
  витрины `ai-run-status`, `copy-value`, `prompt-suggestion` и `ai-chat` держат шаблон внутри
  компонента. Они пришли в main с эпиком компонентов ИИ-ассистента; CI на push в main не
  запускается, и красное заметил только набор перед push.
- Остальные обёртки второго кита тоже держат шаблон внутри, но стоят в известном списке проверки
  как долг. Долг только сокращается.

## What the rules already say

`reuse-first`: известный список не пополняется ради красной проверки. `rt-tools-storybook`:
обёртка держит демонстрационное состояние и в пакет не уезжает.

## Questions and answers

Вопросов владельцу нет: правка не меняет того, что рисует витрина.

## Decisions

- **Шаблон переносится в `.html` рядом с обёрткой, `template` меняется на `templateUrl`** —
  так требует признак проверки. Отвергнуто: строка в известном списке.
- **Перенос делается инструментом правки, файл за файлом** — правило `component-structure`
  запрещает править разметку скриптом.

# Строка привязки вставляется в таблицу, а не дописывается в конец

Задача #644, PR #645, слияние 2026-08-15. Запись собрана из разбора просьбы и хода работы
при закрытии задачи; после выкатки не правится.

Папка разобрана не своим PR, а работой #658: PR влили раньше, чем до разбора дошли
руки.

## С чего началось

> бера в работу пропозалы из свежих

Работа выведена из записи приёма предложений. Строку привязки дописали в конец компаньона —
после таблицы в файле идут ещё разделы, и дописавший не заметил, что в таблицу строка не попала.
Сверка спеков на это молчит: строка вне таблицы для неё просто проза.

## Ответы владельца

**Сколько берём за этот заход.** «Все семь задач подряд» — весь разбор свежих записей целиком.
Эта задача в нём восьмая и последняя.

## Решения

- **Промах записывается в «Частые промахи», а не в порядок действий.** Порядок уже говорит, что
  строка идёт в таблицу; промах в том, что дописавший этого не заметил.

## Что осталось невыясненным при разборе

- Стоит ли учить сверку спеков видеть такую строку. Не стоит: строка вне таблицы — это просто
  текст, и отличать её от прозы нечем.

## Решения по ходу

- **Промах ставится рядом с промахом о переформулированном утверждении.** Оба про одну связь:
  утверждение и его строка находятся друг по другу текстом.

## Что нашли

- Angular Doctor 0.3.0 читает файлы не только по своему списку. `deprecated-animations` ищет
  `**/package.json` без `node_modules`, `dist`, `.angular` и точечных каталогов, но с `coverage/`.
  Нечитаемый файл он пропускает молча, а из неразборного JSON не берёт находок.
- `tailwind-v3-syntax` читает `**/*.{css,scss}`, только если какой-то `package.json` называет
  `tailwindcss` 4 и выше. Версию решает первый раздел, где она записана строкой. Нечитаемый стиль
  инструмент пропускает молча. `tailwind.config.*` он только ищет по образцу и не читает.
- Корневой `package.json` проверка читает сама, ещё до запуска инструмента: из него она берёт
  версии.
- Мимо прохода инструмент читает ещё `**/project.json`. Это остаток, в задачу он не вошёл.

## Что решили и почему

- **Проход читает `package.json` и стили теми же образцами и тем же списком исключений, что
  инструмент.** Общий список исключений прохода не подошёл: он исключает `coverage/`, а инструмент
  этот каталог читает. Нечитаемый файл даёт отказ «the pass cannot read», неразборный — «is not
  JSON».
- **Стили проход читает, только когда их читает инструмент.** Отвергнуто: читать все стили всегда.
  Правило tailwind на этом дереве выключено, и проверка ловила бы потерю, которой нет.
- **Сломанный корневой `package.json` останавливает проверку строкой с именем файла.** Раньше на
  этом месте был стек без имени.

## Чем подтверждено

- `pnpm run check:ngdoctor` на дереве зелёный, строка прохода: «2694 files, 598 templates, oxlint
  2290 files, 15 package.json, 0 stylesheets». Результат равен порогу.
- Набор `check-ngdoctor`: 80 ok, 0 failures в `C.UTF-8` и в `ru_RU.UTF-8`. Восемь новых сценариев
  покрывают каждую потерю и каждую границу.
- Живая проверка на копии дерева с настоящим инструментом:
    - `projects/utils/package.json` с правами 000 — код 1 и строка «the pass cannot read
      projects/utils/package.json: EACCES»;
    - тот же файл с неразборным текстом — код 1 и строка «is not JSON».
- Два круга ревью тремя ролями. Мутанты, которые нашли проверяющие, гибнут на сценариях.

## Цена

- Проход теперь ещё раз ищет и читает `package.json` дерева. Прогон проверки — около 6,6 с.
- Намеренно битый `package.json` в дереве держит проверку красной, обхода нет. Сегодня все
  15 файлов разбираются.

## Согласия владельца

- **Без вида:** «Подтверждаю, вид не меняется»

Относится к реестру значков кита (`rt-icon.registry.ts`) и ячейке таблицы кита
(`rt-data-table-cell.component.ts`).

- Пайп `sanitize` из `@rt-tools/core`: «Проверь во всех проектах на этой машине где и как
  используется этот пайп», затем — после проверки, что вызовов нет ни в одном из трёх проектов, — «Убрать пайп».
- Адреса превью встроенной ссылки редактора cms: «Любой https, проверенный».
- Обход очистки в превью: «Оставить обход за проверкой (Recommended)».

## Что нашли

- Пайп `sanitize` ничего не чистил: он снимал защиту Angular с HTML через
  `bypassSecurityTrustHtml`. Вызовов не было ни в дереве, ни в проектах на машине.
- `bypassSecurityTrustStyle` в ячейке таблицы ничего не давал: Angular не очищает стили с версии 10.
- Виджет чата рисовал себя строкой через `innerHTML`: предел длины из отказа сервиса и сторона
  реплики попадали в разметку без экранирования.
- Реестр значков клал внутренности файла SVG в символ спрайта как есть. Адрес файлов задаёт токен
  потребителя, поэтому «файлы свои» не довод.
- `pnpm run graph:build` оставляет в каждой `graphify-out/` игнорируемый git файл `graph.html`, и
  `check:ngdoctor` насчитал в них 104 находки `inner-html`. Риск записан в план эпика.

## Что решили и почему

- **Пайп удалён из опубликованного API core.** Импорт `SanitizePipe` у потребителя перестанет
  собираться; это названо в коммите и в PR. Инструмент переноса импортов больше не переносит его.
- **Реестр значков разбирает SVG и чистит его на месте.** Уходят узлы не из пространства имён SVG
  (HTML внутри `desc` и `title`), `script`, `foreignObject`, `image`, `style`, анимация атрибутов,
  обработчики `on*` и значения со схемой `javascript:`, в том числе разбитой управляющими знаками.
  Последние три пункта нашли два круга ревью.
- **Правка блока cms кладёт узлы, очищенные DOMPurify белым списком вставки.** К нему добавлены
  теги выделения, перевод строки и признаки страницы внутренней ссылки — без них правка стирала
  бы, куда ведёт ссылка; нашёл первый круг ревью. Отклонено: очистка Angular — она снимает `style`
  у выделений.
- **Превью встраивания оставляет `bypassSecurityTrustResourceUrl` за разбором адреса** — только
  https с хостом. Одна находка `security-bypass` остаётся, и оговорка вписана в точки C и G плана
  эпика. Отклонено: запись адреса мимо Angular — тот же обход, спрятанный от проверки.
- **Виджет чата строит узлы по одному, текст идёт текстом, признаки — через `setAttribute`.**
- **Порог записан на результате задачи, и ни одно правило в нём не выросло.**
- **Списаны:** превью любого https без `sandbox` — слово владельца; потеря сторонней разметки
  блока при правке — редактор сам пишет только `a`, `div`, `p`, `span`; нажатия виджета без
  модульного теста — их держит сквозной набор.

## Чем подтверждено

- `pnpm run check:ngdoctor`: оценка 37 = порог (было 32.5); `inner-html` 4 → 0,

- Тесты: SC-UKV-1709/1710, SC-CMS-79/80, SC-CH-118; cms-angular 111 из 111, виджет 11 из 11,
  реестр значков 14 из 14.
- Сквозной набор виджета на стенде из сборки ветки — 25 из 25, снимки виджета совпали с
  эталонами; в собранном `widget.js` нет `innerHTML`.
- Два круга ревью тремя ролями; подтверждённые находки исправлены в ветке.

## Цена

- Блок cms со сторонней разметкой вне белого списка теряет её при первой правке.
- Значки потребителя, подставившего свой адрес значков, теряют `<style>` и анимацию: цвета,
  заданные классами в `<style>`, и движение пропадают. Ослабить очистку ради них ревью не дало.
- Графы кода в задаче не пересобраны: `graph:build` переписывает корневой граф в одну строку, и
  пересборка — правка своя.
- Превью встраивания доверяет любому https-адресу с хостом, а сайт показывает только видео трёх
  площадок.

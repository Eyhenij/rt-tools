# RT-3012 — ревью Copilot на своём одноразовом раннере

Задача RT-3012, ветка `RT-3012-copilot-review-runner` от `main`, работа вне эпика по слову
владельца. Папка задачи разобрана в эту запись. Устройство раннера описано в
`deploy/copilot-runner/README.md`.

## Просьба владельца

> напиши локальный раннер для github copilot, пример можно глянуть на […]

Имя образца в запись не входит: это другой репозиторий владельца.

## Что было в дереве

- Ревью Copilot приходило в PR с облачной машины GitHub: файла с заданием `copilot-setup-steps`
  не было. Репозиторий публичный, облачные минуты ему ничего не стоили.
- Раннер проверок `~/actions-runner` — macOS ARM64, рядом с ним ключ прода и сокет Docker.
- На той же машине стоит раннер другого репозитория.

## Вопросы

Меню не задавалось: два ответа «рекомендую» подряд в этой сессии закрывают вопросы допущением.

| Вопрос                                | Ответ                                                                                                                        |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Меняет ли задача поведение приложения | нет: меняется только машина, на которой идёт ревью                                                                           |
| Нужна ли правка закона или правила    | нет                                                                                                                          |
| Одна задача или несколько             | одна: раннер, его сеть и файл запуска откатываются вместе                                                                    |

| Есть ли образец                       | да, владелец назвал готовый раннер того же устройства                                                                        |

## Решения

- **Раннер — одноразовый контейнер Ubuntu x64 под эмуляцией.** Ревью Copilot идёт только на
  Ubuntu x64, а машина — Apple Silicon. Раннер проверок отвергнут: он macOS ARM64, и рядом с ним
  ключ прода и сокет Docker. ARC, который страница GitHub называет поддерживаемым путём, не взят:
  кластера на машине нет.
- **На каждое задание новая регистрация, после задания контейнер удаляется.** Код ревью не
  оставляет следов для следующего задания.
- **Сеть контейнера закрыта, наружу только через прокси со списком хостов.**
- **Список хостов пускает все поддомены `githubcopilot.com`.** Страница GitHub называет только
  `api.githubcopilot.com`, а среда ревью на личном плане ходит на
  `api.individual.githubcopilot.com`: журнал сеанса и загрузка `git-proxy` идут туда. Без этого
  хоста задание падает на шаге настройки.
- **Имена с приставкой `rt-copilot-`, сборка своим сборщиком с пределом кэша 3 ГБ.** На машине
  стоит раннер другого репозитория, а стандартный сборщик кэширует без предела.
- **Службу launchd ставит владелец.** Автоматический режим сессии не пустил `setup.sh` с причиной
  «Unauthorized Persistence». Образы, сеть и прокси подняты теми же командами по одной, раннер
  проверен разовым запуском цикла.

## Чем проверено до PR

- `bash -n` обоих сценариев и `plutil -lint` службы — без ошибок.
- Образ раннера собран под `amd64`, 878 МБ.
- Через прокси `api.github.com` ответил 200, `api.individual.githubcopilot.com` — 404 от своего
  сервера. `example.com` не пропущен: curl 56, в журнале прокси «Proxying refused on filtered
  domain». Без прокси из закрытой сети имя не разрешается.
- Раннер `rt-copilot-review-1793355872` встал на связь с меткой `rt-copilot-review`.

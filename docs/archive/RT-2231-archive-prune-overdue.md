# RT-2231 — просроченные записи архива держат отправку всех веток

**Ветка:** `RT-2231-archive-prune-overdue` (от `main`) · **Разобрано:** 2026-09-18

## Просьба владельца

> разбирай Промах проверки выхода из хода на ветке эпика: кандидат в задачу следующего эпика по правилам.

Ответ владельца о той работе: «Новый эпик, две задачи — беру в работу сразу». Эта задача стоит
вне эпика: ветку эпика RT-2228 нельзя было отправить на хостинг, пока проверка возраста архива
красная.

## Что было не так

Четыре записи (RT-1981…RT-1984) простояли 8 дней при сроке 7 и запасе 1, ещё 24 подошли к сроку.
Проверка стоит в наборе перед отправкой и в CI, и отправка любой ветки дерева стояла.

## Решения

- **Удалены все 28 записей, которые назвала команда очистки, а не только четыре красных** —
  команда и проверка читают один модуль, и записи ровно семи дней покраснели бы назавтра на чужой
  отправке.
- **Задача вне эпика по слову владельца о немедленной работе над RT-2228** — очистка по правилу не
  едет внутри чужой правки.

## Цена

Одна ветка и один PR в main ради удаления файлов; записи остаются в истории и находятся по имени.

# RT-2518 — правила молчали о проверке папки вне индекса и о задаче закрытого эпика

**Ветка:** `RT-2518-rules-after-2015` (вне эпика, по слову владельца) · **Разобрано:** 2026-10-04

## Просьба владельца

> Обе (Recommended)

Ответ на две правки, которые предложила проверка закрытой RT-2015 по правилам.

## Решения

- **Справка task-flow.** У статьи «папка задачи уезжает в ветку коммитом» теперь названы обе
  проверки: проверка правки и проверка доски, которая с RT-2015 называет папку вне индекса.
  Файл принадлежит дереву и правится на месте.
- **Образец git-workflow-commit.** Добавлен абзац о задаче, чей эпик закрылся после её заведения:
  строка эпика в теле задачи меняется на «Работа вне эпика — <слово владельца>», и только потом
  заводится ветка. Это ресурс пакета: строку эпика и проверку, которая её читает, поставляет пакет.
- **Чего не сделано.** Текст отказа проверки ветки эпика по-прежнему советует завести ветку эпика,
  а не перевести задачу в работу вне эпика. Это правка кода пакета, отдельная задача при нужде.

## Проверки

- `pnpm run agent-kit:check` — дерево совпадает с пакетом.
- `npm run check:specs`, `npm run check:docs` — без расхождений.

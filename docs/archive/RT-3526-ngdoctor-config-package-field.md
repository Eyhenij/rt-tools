## Что нашли

- Angular Doctor 0.3.0 читает настройку из двух мест корня дерева: `angular-doctor.config.json` и
  поле `angularDoctor` корневого `package.json`. Поле кладётся поверх файла. Ложное значение поля
  инструмент пропускает. Других мест настройки у него нет: флагов настройки CLI не передаёт,
  окружение не читает.
- Поле, которое выключает правило, инструмент слушает. На копии дерева с новой находкой
  `prefer-ng-optimized-image` поле с этим правилом в `"off"` убрало все его находки, и проверка
  без этой задачи осталась зелёной.
- Отключающие комментарии в исходниках (`eslint-disable` и подобные) тоже прячут находку от
  порога: oxlint и шаблонный линтер их учитывают. Их 125 файлов — это большое изменение, оно
  вынесено в эпик RT-3553.

## Что решили и почему

- **Поле судится так же, как файл: допускается объект с одним `reportPath`.** Так велит карточка.
- **Любое другое значение поля — отказ, ложное тоже.** Признак карточки — «с любым значением,
  кроме разрешённого».
- **Суд над настройкой вынесен в `tools/check-ngdoctor-settings.mjs`.** Основной файл проверки
  перешёл предел длины в 500 строк.
- **`--package` и `--config` работают только рядом с сохранённым выводом и только с файлом, который
  есть.** Иначе флаг подменял судимый файл, а инструмент читал настоящий.

## Чем подтверждено

- `pnpm run check:ngdoctor` на дереве: «score 94.75, 1300 findings of 11 rules — equal to the
  threshold».
- Набор `check-ngdoctor`: 97 ok, 0 failures в `C.UTF-8` и в `ru_RU.UTF-8`. Сценарии держат поле и
  файл настройки рядом с сохранённым выводом, в проверке дерева и при `--write`.
- Живая проверка на копии дерева без флагов:
    - поле с `rules` — код 1, «package.json#angularDoctor holds «rules»»;
    - поле `false` — код 1, «is not an object»;
    - поле с одним `reportPath` — код 0.
- Два круга ревью тремя ролями; мутанты, которые они нашли, гибнут на сценариях.

- Признак шага 1.1 плана ждал ровно 5 сценариев о поле, а ревью добавило ещё семь. Ожидание «= 5»
  было записано неверно: проверка шага заменена на «>= 5», шаг перемерен — 12.

## Цена

- Поле судится строже файла: `false` или `null` в поле — красное, хотя инструмент их пропускает.
- Значение `reportPath` не судится ни в файле, ни в поле, как и до задачи.

# RT-2093 — проверка очереди работ читала только первую страницу подзадач эпика

**Ветка:** `RT-2093-board-audit-subissues-paging` · **Разобрано:** 2026-09-14

## Откуда взялась работа

Найдено при проверке очереди работ по ходу RT-2090. Владелец разрешил завести задачу словом:

> заводи

## Что было не так

Проверка в каждом запуске печатала строку о том, что у эпика «Один кит» шесть задач не привязаны
к карточке. Привязаны были все тридцать шесть. Хостинг отдаёт список страницами по тридцать, а
вызов шёл без пролистывания — шесть последних номеров в ответ не попадали.

Измерено числом: вызов без пролистывания даёт 30 номеров, тот же вызов с пролистыванием — 36,
«недостающими» проверка называла ровно шесть последних.

## Что сделано

- Вызову перечня подзадач добавлено пролистывание — в источнике пакета, не в положенной копии.
- Помощник хостинга в наборе сценариев научился отвечать по-разному на вызов с пролистыванием и
  без него; заведён сценарий SC-AK-1093 с обеими половинами.
- Описание области получило статью про чтение целого перечня с привязкой к коду.
- Файл привязок правила `task-flow` называет размер страницы и цену её чтения.

## Почему так, а не иначе

- **Цена не в ложной строке, а в привычке.** Строка висела в каждом запуске, глаз переставал её
  читать — и настоящее расхождение проехало бы вместе с ней.
- **Помощник хостинга различает два вида вызова.** С одним списком на оба сценарий был бы зелёным
  и на коде, который читает одну страницу из двух. Признак ищется по всей строке вызова: он стоит
  перед путём, а не после него.
- **Сценарий несёт обе половины.** Вторая требует, чтобы пустой перечень по-прежнему назывался:
  без неё зелёным был бы и код, который вовсе перестал сверять.
- **Пролистывание добавлено одному вызову.** Тому, на котором поломка измерена; сплошной
  пересмотр всех вызовов хостинга — работа своего объёма.
- **Правило `task-flow` статьи не получило.** Она ничего не меняет в решении читающего, а текст
  правила входит в каждую сессию. Строка ушла в файл привязок рядом.

## Чем проверено

`bash projects/agent-kit/tests/checks-board.test.sh` — 81 испытание, ноль провалов; до правки
новый сценарий красный. `pnpm run agent-kit:check` — положенное сходится с пакетом v0.27.0.
`node tools/check-specs.mjs` — 1551 сценарий против 1550 до правки, без тестов 131 в обоих
случаях, расхождений нет. `node tools/check-board.mjs` на живой очереди — строк про непривязанные
задачи эпика ноль, было шесть номеров в одной строке.

## Что осталось за работой

- **Столбец задачи на доске не перенесён.** В главной ветке имена столбцов устарели, и любой
  перенос отказывает. Свежие лежат в ветке эпика и в правке #2088 соседней работы.
- **Другие вызовы хостинга не пересмотрены.** Пролистывания может не хватать и им; это отдельная
  работа с отдельным измерением.

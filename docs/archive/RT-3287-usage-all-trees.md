# RT-3287 — раздел «Использование» читает все деревья при «Все проекты»

Задача RT-3287 вне эпика, ветка `RT-3287-usage-all-trees`, 13.11.2026. Папка
`docs/tasks/RT-3287-usage-all-trees/` разобрана в эту запись.

## Просьба

> открой в браузере https://message-bus.dev/usage, почему я не могу прочитать эту страницу?

На странице стояло «Прочитать не удалось». Раздел открывается с отбором «Все проекты», таблица
запрашивала `/api/usage` без дерева, и приёмник отвечал `404 treeUnknown` с пустым признаком. С
выбранным деревом тот же запрос отвечал 200.

Владельцу показали два способа: приёмник без дерева считает все деревья (рекомендованный) или из
отбора раздела убирается «Все проекты». Ответ:

> заведи новое независимое рабочее дерево и делай правки там

Взят рекомендованный способ.

## Что сделано

- Чтения таблицы, сводки и сессий скила без дерева считают строки всех деревьев.
- Названное дерево, которого приёмник не знает, по-прежнему даёт `404 treeUnknown`: опечатка в
  признаке не должна читаться как «все деревья».
- Экран читает и рисует сводку при «Все проекты».
- Сценарии SC-MB-428…430 в спеке раздела; сквозной тест открывает раздел без дерева.

## Решения по ходу

- **Все деревья, а не убранный вариант отбора.** Отбор деревьев общий для разделов, и «Все
  проекты» уже значит «все деревья» у соседей и в разделе «Качество».
- **Условие на дерево было ещё и в шаблоне.** Первый прогон сквозного теста показал таблицу без
  сводки: кроме хранилища сводки, шаблон рисовал её только при выбранном дереве.

## Цена и что не сделано

- Сквозной стенд шёл на своих портах (база 55464, приёмник 3390, админка 4390): порт базы по
  умолчанию был занят стендом соседней рабочей копии.
- У учётной записи владельца нет права `quality:read`, поэтому раздел «Качество» отвечает 403. Это
  настройка прав, а не код; задача её не трогает.

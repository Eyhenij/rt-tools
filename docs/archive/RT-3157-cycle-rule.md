# RT-3157 — правка пакета называет число, которое должна сдвинуть

Задача RT-3157 эпика RT-3151, ветка `RT-3157-cycle-rule`, PR в `RT-3156-quality-section`, 08.11.2026.
Папка задачи разобрана в эту запись. Разбор всего эпика лежит в записи RT-3152.

## Просьба владельца

Карточка задачи: правки идут из мнения, и нельзя понять, помогла ли правка. Нужно правило цикла: отчёт
называет худшую причину, задача и заметка о выпуске называют метрику и ожидаемое направление, следующий
отчёт показывает итог. Правка, которая ничего не сдвинула, называется так прямо. Готово, когда правило
лежит в пакете, а шаблон выпуска требует метрику.

## Решения по ходу работы

- Цикл лёг паттерном `task-flow-cycle` правила `task-flow`, а не статьёй правила. Правило стоит у предела
  веса, и цикл нужен только тому, кто выбирает правку. Граница пакета его пускает: любое дерево может
  выполнить его на своих правилах.
- Шаблоном выпуска стало обязательное поле запуска. Журнал собирается из коммитов, и файла шаблона нет.
- Поле принимает две формы: метрика с направлением или причина, почему метрики нет. Починка ничего не
  обязана сдвигать, а молчание не отличить от забытого поля.
- Разбор поля стоит сразу после сборки журнала: отказ останавливает выпуск до сборки и публикации.
- Договорённость влита поддоменом `metrics`. Правила без исполнения ушли в открытые вопросы, адрес им не
  выдумывался: числа поставки, остановка попыток при утечке, что закрывает эпик, запуск первого цикла.
- Два правила поправлены по коду: отказанный токен останавливает попытки, а найденная утечка нет;
  наблюдением становится смена `send`, а смена `observe` не записывается.
- Отчёт дерева больше не называет выпуск тем, что считает общий отчёт: чисел поставки нигде нет.
- Роль `goal-critic` нашла слабые места поля и цикла, и они закрыты в этой же задаче. Поле сверяется с
  именами отчётов, образец называет шум, у роли появился режим цикла, правило получило статью.
- Выход `нет:` оставлен решением исполнителя, а не словом владельца. Это названо в PR.
- Роль `product-strategist` нашла ещё три места: поле отказывало названиям столбцов, пропускало слова после
  имени, а тест не читал файл запуска. Закрыты здесь же. После имени теперь стоит только имя ресурса.

## Цена

- Файл выпуска проверен только сценариями его команд. Сам файл запускается лишь настоящим выпуском, так
  что первая проверка случится на нём.
- Список имён метрик закрыт и лежит в команде выпуска. Новая метрика отчёта не пройдёт поле, пока её туда
  не добавят. Зато слово без числа за ним отказано до сборки.
- Начало цикла держится текстом паттерна. Задачу без метрики никакая проверка не остановит.
- Числа поставки обещаны, а не посчитаны. Решает владелец.

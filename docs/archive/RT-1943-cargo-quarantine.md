# Спорному предложению в приёмнике не было места

Задача RT-1943 эпика RT-1940. Запись собрана из папки задачи при её разборе; после выкатки не
правится.

## Просьба владельца

> либо класть предложение в карантин, где будут накапливаться сомнительные предложения и они могут
> быть взяты в работу по указанию человека

## Что было не так

Состояний записи груза было четыре, и отказного среди них не было. Предложение, признанное спорным,
оставалось в «новом» — то есть среди неразобранного, и следующий заход разбирал его заново. Отметка
«в работе» на нём лгала: работы по нему не шло. Правило разбора груза прямо называло это открытым
вопросом.

## Решения

- **Карантин — состояние записи, а не папка на диске.** Папка живёт на одной машине и в админке не
  видна: список спорного, который видит один заход, ничего не даёт остальным.
- **Карантин стоит пятым и вне порядка шагов.** В него запись уходит только из «нового» и
  возвращается только туда же. Вперёд дороги нет: она означала бы починку того, о чём решили, что
  чинить нечего.
- **Переход в карантин несёт причину, и без неё строка отбивается.** Состояние без ответа на «чем
  спорно» разбирают заново каждый раз — ровно то, от чего карантин заводится.
- **Причина едет полем строки правки, а не своей операцией.** Своя операция судила бы переход
  второй раз и разошлась бы с первым судом молча.
- **Издатель редакции карантин не ставит.** Он говорит о работе, которую ведёт дерево, а издатель
  видит запись один раз — когда правка вошла в редакцию.
- **Список карантина читается тем же чтением груза отбором по состоянию.** Своё чтение отвечало бы
  на тот же вопрос второй дорогой, и две дороги разошлись бы молча.
- **Довод причины заведён у команды отметки, хотя в след задачи она не входила.** Без него дерево
  не может перевести свою запись в карантин вовсе — то есть условие готовности задачи не
  выполняется ничем.

## Чего эта работа не делает

- Не судит, какое предложение спорно: это делает сверка со спекой из предыдущей задачи эпика.
- Не заводит экрана карантина: запись видна в общем списке отбором по состоянию.
- Не достаёт записи из карантина сама: оттуда их возвращает человек своим словом, и след этого
  слова остаётся только в журнале приёмника — открытый вопрос `Q-CQ-1`.

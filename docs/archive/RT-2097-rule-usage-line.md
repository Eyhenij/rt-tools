## Решения по ходу

- **Развод номеров сделан на ветке эпика, под своей папкой задачи.** Проверка доставки не даёт
  отвести ветку задачи от ветки эпика, пока ветка эпика на хостинге не несёт main; проверка перед
  push не пускает ветку эпика, пока номера повторяются. Ветку задачи завести нельзя, а правка —
  разрешение того самого слияния. Отвергнуто: правка на ветке без номера мимо проверки.
- **Задача #2114, заведённая под этот развод до отказа проверки, закрыта как ненужная** с причиной
  в комментарии.

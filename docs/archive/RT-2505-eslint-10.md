# RT-2505 — линтер кода отстал на мажор: eslint 9 → 10

**Ветка:** `RT-2505-eslint-10` (вне эпика, третий мажор из списка RT-2081) ·
**Разобрано:** 2026-10-03

## Просьба владельца

> обнови npm пакеты

Мажоры этой просьбы вынесены в список RT-2081, по задаче на мажор. RT-2505 взята за RT-2503.

## Решения

- **eslint 10.11.0, а не 10.12.0:** последняя вышла 2 октября и ещё ждёт срока. Вместе с ним
  `@eslint/js` 10.0.1, `eslint-plugin-simple-import-sort` 14.0.0, `jsonc-eslint-parser` 3.3.0.
- **`eslint-plugin-import` убран.** Его последняя версия 2.32.0 принимает eslint только до 9-й, а в
  дереве его никто не подключал — имя стояло только в манифесте.
- **Две находки новых правил.** `preserve-caught-error` в тесте пакета правил исправлена: ошибка
  набора передаёт исходную в `cause`. `no-useless-assignment` нашлась в витрине первого кита;
  первый кит по ADR 0003 не правится, поэтому правило выключено только для `projects/ui-kit/**` с
  причиной в настройке линтера.

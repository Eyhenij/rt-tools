# RT-2354 · Список второго кита сверен с первым китом по списку приложения

Задача RT-2354, PR в ветку эпика RT-1870, закрыто 25 сентября 2026 года. Ветка
`RT-2354-data-list-first-kit-parity`.

## С чего началось

Владелец: «по таблице динамик лист из первого кита перенесеннную во второй». Он трижды прислал
список расхождений, который собрало приложение при переезде на второй кит: сначала девять
пунктов, потом одиннадцать, потом четырнадцать. Последний список и был работой.

Об одном пункте владелец сказал сам: «Я не мерил, проверь». Когда встал вопрос о библиотеке
редактора текста, он спросил: «поясни чтоэто и зачем?», а после пояснения выбрал отдельный вход
пакета.

## Что оказалось

- Пункты 2–5, 8, 10 и 11 подтвердились сверкой с кодом первого кита. Список не тянулся на всю
  ширину. Цвет и вес шапки и фон строки отбора были зашиты. Подписи расходились: «Per page:»
  вместо «Items per page:», «Cancel»/«Save» вместо «Discard Changes»/«SAVE», «userIcon» вместо
  «User Icon».
- Пункт 6: первый кит отдаёт таблице только `appearance`, поэтому поля отбора всегда выглядят
  как поиск списка. Второй кит брал для них `outline`.
- Пункт 7 не подтвердился: 162 − 2 × 8 − 36 − 8 = 102. Выбор занимает всё место после кнопки
  очистки, и первый кит раскладывает ячейку так же.
- Пункт 9: меню второго кита принимает любую разметку, но `mat-menu-item` требует над собой
  меню Material. Сделан запасной вариант владельца — тон success и значок Material у пункта кита.
- Пункт 14: собранный `styles/tokens.css` лежит на каталог выше исходников, и адрес шрифтов вёл
  мимо файлов. `import('quill')` сборщик приложения разрешает всегда, даже без редактора.
- Замер в браузере не снят: профиль браузера на этой машине не закреплён.

## Что сделано

- Список на всю ширину; свойства `--rt-data-table-head-color`, `--rt-data-table-head-font-weight`
  и `--rt-data-table-filter-bg`; подписи как в первом ките.
- Поля отбора без своего вида берут вид поиска списка.
- Пункт меню: вход `success` и вход `glyph` с именем значка Material.
- Список: вход `isToolbarActionsIconsOutlined`. Кнопка со значком: вход `iconFill`.
- Директива отметок отдаёт признак и под именем первого кита `isMultiSelectExtendedModEnabled`.
- Сброс приложения кладётся в подслой `rt-kit.vendor` — так написано в README пакета.
- Адрес шрифтов стал переменной, собранный CSS берёт `../src/assets/fonts`.
- Редактор текста, поле сообщения и чат уехали во второй вход `@rt-tools/ui-kit-v2/rich-editor`.
  Проверки тонов, слоя, покрытия витрины и таблиц входов читают оба входа.

## Цена

- Переезд редактора дороже, чем было сказано владельцу: вместе с ним уехали поле сообщения и чат.
  Приложения, которые берут чат, меняют строку импорта — в этом дереве таких пять мест.
- Кадры: пересняты шесть кадров второго кита; сквозной набор админки прошёл без пересъёмки.

## Урок

Список расхождений от приложения описывает первый кит так, как его видит приложение. Пункт 6 во
втором списке расходился с кодом первого кита, а в третьем списке приложение написало то же, что
показал код. Каждый пункт сверяется с кодом образца до правки.

## Куда ушли решения

- Вид полей отбора — `docs/specs/ui-kit-v2/table-material-theme/`, SC-UKV-359.
- Второй вход пакета и сброс под слоем — README пакета.

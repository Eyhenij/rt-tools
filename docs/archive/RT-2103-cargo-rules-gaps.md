## Что было не так

Правило проверки в браузере не говорило, чем принимается перенос вида с образца: двадцать две
панели получили имена образца, сборка и тесты зелёные, а поле, обрезанное посреди строки, нашёл
владелец. Варианты правила поставки для Azure и GitLab не несли двух статей из варианта для
GitHub — о рабочем дереве до открытия PR и о перечитывании тела после push.

## Что сделано

В правило проверки в браузере добавлена статья о приёмке кадром своего экрана рядом с кадром
образца. Две статьи о поставке перенесены в варианты Azure и GitLab слово в слово. Копия правила
в дереве положена командой установки.

## Чем это подтверждено

- `grep -c "the sample's frame"` по источнику — 1; `grep -c` по двум статьям в вариантах Azure и
  GitLab — 2 и 2.
- `pnpm run agent-kit:check` — разложенное сходится с пакетом.
- `npm run check:specs` — расхождений 0: статья привязана в файле привязок как не проверяемая
  машиной.

## Почему так, а не иначе

- **Статья — в правиле, не в паттерне** — запись адресовала её разделу «Как закон применяется
  здесь»; рядом уже стоит статья об измерении до показа. Спросить было некого: сессия автономная.
- **Статьи о поставке перенесены без своей редакции** — правило одно, хостинги разные; запись
  пришла из дерева не на GitHub, где этих статей не было.
- **Отметки записям не ставились** — обе чужие, их закрывает издатель после слияния; ночью наружу
  ничего не уходит.

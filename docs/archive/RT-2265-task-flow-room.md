# RT-2265 — правило о ходе работ упирается в предел длины

**Ветка:** `RT-2265-task-flow-room` (вне эпика по слову владельца, стоит на ветке RT-2486) ·
**Разобрано:** 2026-10-02

## Просьба владельца

> Задачи вне эпиков

RT-2265 — следующая одиночная задача очереди после того, как RT-2294 закрыта как устаревшая.

## Что нашли

- Правило `task-flow` и его холодная часть стояли у предела длины 24 000 знаков: разложенное
  правило — 23 998, холодная часть — 23 975, из них 4 362 — надстройка этого дерева.
- Статья из находки 4 разбора RT-2263 («счёт, ставший мерой работы, ограничивается объявлением, а
  не файлом») не помещалась и не была записана нигде.

## Решения

- **Место взято из объяснений, а не из требований.** Сжаты абзацы раздела «What of the law is not
  here» и хвост статьи о прогоне главной ветки; каталог плана эпика по-прежнему назван в компаньоне.
- **В надстройке холодной части убраны повторы.** Два пункта пересказывали статьи, которые уже
  действуют в правилах `task-flow` и `doc-style`; оставлены их доводы и ссылки на разборы.
- **Статья записана** рядом со статьёй о плане по замеру своего кода; в компаньоне она отмечена
  как не проверяемая машиной.

## Проверки

- Разложенное правило — 23 639 знаков (запас 361), холодная часть — 23 604 (запас 396).
- `node tools/check-file-size.mjs`: длиннее предела — 0. `pnpm run agent-kit:check`: разложенное
  сходится с пакетом. `pnpm run agent-kit:hooks`: все наборы зелёные. Сверка описаний: расхождений
  нет.

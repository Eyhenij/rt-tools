# Grill

## The owner request

> напиши подробные инструкции для других агетов как подключать и использовать пакеты auth

Задача эпика RT-2528.

## What the tree already has

- README каждого пакета описывает свой пакет: `auth-contract`, `auth-angular`, `auth-server`,
  `auth-import`, `auth-keycloak-theme`. Общего пути «с нуля до работающего входа» нет.
- Настройки Keycloak, которые нужны приложению, есть только в области стенда
  `deploy/auth/realm/rt.json`: публичный клиент с PKCE, клиент выгрузки прав, клиент переноса.
- Пример целиком: `apps/auth-example-admin` и `apps/auth-example-api`.

## What the rules already say

- Тексты дерева пишутся по-английски; текст для владельца — по-русски.
- Другие проекты в текстах дерева не называются: инструкция говорит «приложение».

## Questions and answers

- **Где держать инструкцию.** Владелец место не назвал. Решение исполнителя: полная инструкция
  в `docs/auth-integration.md`, в README каждого пакета — ссылка на неё.

## Decisions

- Инструкция идёт по шагам подключения: Keycloak, сервер, админка, тема, перенос людей, проверка.
- Пакеты, которых ещё нет в npm, названы с этой оговоркой.

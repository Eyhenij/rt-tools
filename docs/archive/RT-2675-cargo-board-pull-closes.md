## What the tree already has

- `projects/agent-kit/assets/checks/check-board.github.mjs` требует строку `Closes #<номер>` в теле
  каждого PR, какой бы ни была его база.
- `projects/agent-kit/assets/checks/board-pull-state.github.mjs` молчит о PR с базой не в main: прогона
  на нём нет по порядку сдачи.

## What the rules already say

Хост исполняет строку `Closes` только при слиянии в главную ветку. PR задачи эпика идёт в ветку
эпика, и задача после его слияния остаётся открытой.

## Questions and answers

Вопросов владельцу нет: предложение называет и место, и текст находки.

## Decisions

- **Отдельной находки на каждый PR нет.** Аудит уже называет оба следствия одной строкой на все
  PR с базой не в main. Строку на каждой задаче эпика перестают читать, и проверка отвергает её в
  своём комментарии.

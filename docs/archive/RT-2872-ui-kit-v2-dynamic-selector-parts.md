# Разбор

## Просьба владельца

> Делай RT-2861

Задача пятая, последняя в эпике RT-2861. Корень `rt-dynamic-selector` передавал окну выбора 23
входа и списку 13 по одному, и новая настройка стоила правок в четырёх файлах. Окно и список
экспортировались из пакета и стали публичными случайно.

## Решения

- **Части читают сервис, который предоставляет корень.** Корень в конструкторе привязывает к нему
  свои входы, вычисленное и обработчики; окно и список берут их оттуда. Окно получает сам корень
  как набор настроек: имена входов те же.
- **Список привязывают оба корня.** Его делят селектор и поле строк `rt-dynamic-input`; поле строк
  осталось публичным, это отдельное поле формы.
- **Окно без корня рисует рамка витрины.** Она принимает прежние настройки входами и встаёт на
  место корня; её рисуют и витрина, и четыре файла тестов окна.
- **Окно и список помечены устаревшими в экспорте и уйдут из него в следующем выпуске.** Сами по
  себе они больше не работают — это названо в пометке.
- Меню о витрине закрыла проверка разбора, поэтому взят рекомендованный вариант; цена названа в
  PR.

## Что подтверждено

2939 тестов кита зелёные, 895 снимков витрины совпали без пересъёмки. Сборка пакета, проверка
типов, линтер, проверки циклов, повторов, спек и путей в документах чистые.

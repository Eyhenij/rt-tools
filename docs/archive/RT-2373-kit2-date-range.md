# RT-2373 — в ките нет поля для выбора диапазона дат

**Ветка:** `RT-2373-kit2-date-range` (от `RT-2372-kit2-date-panel`, эпик RT-2370) · **Разобрано:** 2026-09-30

## Просьба владельца

> бери в работу эпик 2370, перетяни тикет на борде в колонку in progress, создавай ветку и выполняй задачи друг за другом, ветки делай каскадом чтобы при слиянии веток по очереди не было мерж-конфликтов

Задача в очереди: одно поле периода по макету — «дд.мм.гггг — дд.мм.гггг», два месяца рядом,
быстрые варианты слева, первый клик — начало, наведение показывает будущий диапазон, второй клик —
конец, внизу итог с числом дней, «Сбросить» и «Применить»; на узком экране — нижняя шторка с одним
месяцем и вариантами строкой сверху.

Владелец отвечал рекомендованным вариантом во всех меню эпика и велел идти по задачам подряд;
вопросы закрыты тем вариантом, который меню рекомендовало бы.

## Решения и куда они ушли

- **Поле диапазона — свой компонент `rt-date-range`, значение — пара дней `{ start, end }` или
  `null`.** У пары другой тип значения, чем у строки поля даты. Ушло в спек
  `docs/specs/ui-kit-v2/date-range/`. Отвергнуто: режим `range` у `rt-date-picker` — один компонент
  с двумя типами значения.
- **Сетка, текст даты и язык — те же, что у поля даты.** Календарь кита с его состояниями
  диапазона, логика текста даты и `RT_KIT_LOCALE`. Календарь получил выход `dayHover` и два своих
  свойства — зазор колонок и внутреннее скругление диапазона — со значениями по умолчанию, равными
  прежним. Ушло в `CONTEXT.md` календаря.
- **Быстрые варианты заполняют черновик, «Применить» пишет значение.** «Этот месяц» — с первого
  числа по сегодня, «Прошлый месяц» — целиком. «Сбросить» очищает только черновик.
- **День под указателем при выборе конца светлый, полоса диапазона сплошная** — так в макете.
- **Дни соседних месяцев не рисуются** — панель поля даты тоже показывает пустые клетки, и обе
  панели остаются одинаковыми. Отвергнуто: рисовать их, как в макете, — меняет и панель даты.
- **Пара тем панели показана в раскладке шторки.** Половина темы уже широкой панели; цвета у
  раскладок одни. Причина записана в разметке истории.
- **Сценарий текста поля даты из прошлой задачи получил номер `SC-UKV-467`** — номер 430 занят
  боковым меню в соседней ветке; правка сделана в ветке RT-2372 и пришла сюда цепочкой.

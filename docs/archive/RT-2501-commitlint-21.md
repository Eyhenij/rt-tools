# RT-2501 — проверка текста коммитов отстала на мажор: commitlint 20 → 21

**Ветка:** `RT-2501-commitlint-21` (вне эпика, первый мажор из списка RT-2081) ·
**Разобрано:** 2026-10-03

## Просьба владельца

> обнови npm пакеты

Слово сказано для RT-2079, мажоры из него вынесены в список RT-2081 — по задаче на мажор. Работа
взята, пока PR #2500 ждал CI, по слову «Задачи вне эпиков».

## Решения

- **Три пакета commitlint подняты вместе** — `cli`, `config-angular`, `config-conventional`
  выходят одной версией. 21.2.3 вышла 19 сентября 2026, срок ожидания прошёл.

## Проверки

- До и после обновления одни и те же вердикты: `feat(rt:ui-kit-v2): …` и `docs: …` проходят,
  `fix(ci): …` и заголовок без русских букв отбиваются.
- Коммит с обновлением прошёл через новую версию хука `commit-msg`.

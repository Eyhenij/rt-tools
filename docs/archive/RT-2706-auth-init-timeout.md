# Grill

Записей приёмника у задачи нет: её принёс владелец словом в сессии.

## The owner request

> Предел в пакете (Рекомендую)

Выбранный вариант: пакет правится в своём репозитории. Старт ждёт тихую проверку не дольше 5 с,
потом админка поднимается без сессии. Новая версия ставится в приложение номером.

## What the tree already has

- `RtAuthService.init` ждёт `keycloak.init` с тихой проверкой и без предела. Адаптер
  `keycloak-js` 26.2.4 своего предела на тихую проверку не имеет.
- Keycloak, который лёг или отбил адрес возврата, показывает в рамке свою страницу ошибки. Ответа
  рамка не шлёт, старт приложения не кончается, и админка остаётся пустой страницей.
- Двойник адаптера `KeycloakDouble` отвечает на старт сразу. Сценарии пакета —
  `docs/specs/auth/angular/scenarios.md`, последний номер SC-AUTH-75.

## What the rules already say

`spec-driven`: новое поведение получает свой номер сценария, тест называет его в заголовке.
`dependencies`: версия пакета пишется точным номером.

## Questions and answers

**Где ставить предел ожидания тихой проверки?**
Предел в пакете (Рекомендую).

## Decisions

- **Предел 5 с по умолчанию, поле настройки `silentCheckTimeoutMs`** — живая проверка отвечает
  за доли секунды, а пять секунд пустой страницы человек ещё ждёт. Отвергнуто: предел в
  приложении поверх пакета — каждое приложение писало бы его заново.
- **По пределу старт кончается без сессии** — дальше страж маршрута уводит на вход, как при
  отсутствии сессии. Отвергнуто: ошибка старта — приложение не поднялось бы вовсе.
- **Версия 0.1.1** — поведение стало мягче, интерфейс только расширен.

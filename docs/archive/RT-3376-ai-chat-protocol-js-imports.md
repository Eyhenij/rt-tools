# RT-3376 — пакет протокола чата не импортировался в Node

Задача RT-3376, запись от 2026-11-18.

## Просьба владельца

> выпускай кит

Позже: «доведи выпуск кита до конца и только потом бери следующую задачу».

## Что нашли

Версия `0.2.0` пакета протокола чата в npm не загружалась в Node: в собранном `esm` четыре файла импортировали соседей без расширения `.js`, и потребитель получал «Cannot find module». В исходниках было 28 таких импортов.

## Решения

- В исходниках расширение `.js` дописано во все относительные импорты. Отвергнуто: менять настройку `tsc` на разрешение без расширений, Node её не читает.
- Правится только пакет протокола чата. Общая проверка собранного пакета и правило выпуска идут отдельной задачей.

## Что не доделано

Версия `0.2.1` выпускается отдельным запуском процесса публикации после слияния.

# RT-3629 — ветка задачи снимает только затронутые истории витрины

Задача RT-3629 эпика RT-3624, запись от 2026-11-25. Прежний адрес:
`docs/tasks/RT-3629-affected-story-snapshots/`.

## Просьба владельца

> сейчас рабочий процесс занимает слишком много времени, довольно простые правки идут по несколько часов, сделай анализ на какие шаги сколько времени уходит по текущему task flow и как можно оптимизировать весь процесс

П4 одобрен вариантом «Без П5 (Recommended)»: «Ветка задачи снимает затронутые истории, полный набор идёт
один раз на PR в main. Цена: часть расхождений видна позже». Порядок — «RT-3629 (Recommended)» 25.11,
план — «Одобряю план RT-3629 (Recommended)».

## Что решили и почему

- **Затронутые истории находит граф импортов** — статистика сборки требует двух сборок и видит сборщик
  целиком; импорты читаются меньше чем за секунду.
- **Единица — файл историй** — выбор по имени истории ломает окружение прогонщика.
- **Неузнанное снимает всё** — проверка, которая не нашла, с чем сверять, не зелёная. Ссылка, названная не
  строкой, неразрешённый импорт, нечитаемая база, дерево без историй — тоже всё.
- **Добавленная подпись истории не задевает, если её ключ нов** — новую подпись читает компонент, правленный
  той же веткой. Изменённая подпись — всё: её читает `preview.ts`.
- **Обвязка пишет в реестр и исключённую историю, строкой `skip <id>`** — иначе выпавшая история без эталона
  неотличима от исключённой.
- **Набор с пустой базой печатает полную команду** — её сверяет `check-push-gate`.
- **Вид причин 11 красных запусков 21–22.11** — таблица в `docs/plans/delivery-speed.md`.

Списано: символические ссылки — в дереве их нет. Послабление корневого `package.json`, где изменён только
`scripts`, не взято: 8 из 62 ответов «всё», но это новое решение поверх плана.

## Что осталось вне задачи

- Пределы 15 и 30 секунд — #3150; слова «эталон без истории» про упавший файл полного набора — #3280;
  устойчивость CI — эпик RT-3412.
- Доля прошлых слияний кита, где ответ не «всё», — 57–59% при цели 60%.
- Выигрыш в минутах на будущих задачах кита меряет `session:time`; на шести задачах базы он около нуля.

## Чем подтверждено

- Сценарии: `affected-stories` 106, `visual-gate` 52, `push-heavy-subjects` 29, провалов 0; мутанты, названные
  важными, сценарии роняют.
- Живые запуски: правок нет — 0,7 с; один файл историй — 33 с и 5 кадров, при холодных кэшах 42 с; видимая
  правка — 5 кадров разошлись; лишний эталон — отказ. Полный набор стоил 448–575 с.
- Набор перед отправкой зелёный, с полной съёмкой: ветка правит скрипты шага.

## Цена

- Роли прочли план четыре раза: правила «всё» и «ни одной» уточнялись трижды, план в первый коммит лёг до
  чтения ролями, и коммиты пришлось сложить — движок берёт план из первого.
- Первый круг ревью нашёл 12 серьёзных: вызов не из корня давал зелёное «нечего», реэкспорт терялся, стили
  читались неполно. Второй — только мелкие.
- Вопрос владельцу 25.11 называл задачу ведущей к вехе, это неверно; факт принесён вместе с планом.

# RT-3382 — контроллер запуска в пакете протокола чата

Задача RT-3382, запись от 2026-11-18.

## Просьба владельца

> поставь задачу той сессии кита которая делала пакет протокола

## Что нашли

В пакете протокола чата не было готового контроллера запуска: каждое приложение писало заново повтор запроса, остановку и цикл браузерных инструментов.

## Что сделано

- Контроллер запуска: повтор запроса до первого события, остановка через порт, цикл «запуск ждёт ответа браузера, затем идёт следующий».
- Реестр браузерных инструментов по имени; упавший или неизвестный инструмент даёт ответ с ошибкой, а не обрыв.
- Поставщики контекста читаются перед каждым запуском.
- Пустой реестр или его отсутствие: запуск идёт один раз, как раньше. Публичный интерфейс только дополнен.
- 51 тест зелёный, покрытие пакета 100%, сборка с проверкой пакета зелёная.

## Решения

- Транспорта в пакете нет, контроллер работает через порт запуска. Отвергнуто: свой запрос по сети внутри пакета.
- Контроллер и реестр — функции-фабрики без Angular: пакет без фреймворка.

## Что не доделано

Выпуск новой версии идёт отдельным запуском процесса публикации по слову владельца; номер версии сообщается заказчику после выпуска.

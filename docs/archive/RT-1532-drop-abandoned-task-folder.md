# RT-1532 — папка задачи, закрытой без работы, снята из главной ветки

**Ветка:** `RT-1532-drop-abandoned-task-folder` · **Разобрано:** 2026-08-29

## Что было не так

Сверка очереди работ печатала строку о папке `docs/tasks/RT-1460-…/`: задача закрыта, а папка
лежит среди текущих. Задача RT-1460 закрыта владельцем как «не будет сделано», работы по ней не
было, а папка уехала в главную ветку чужим коммитом и осталась там нетронутым образцом.

Пока такая строка печатается на каждом прогоне сверки, настоящее расхождение читается среди неё.

## Что сделано

Папка снята, в архив ушла запись `RT-1460-task-filing-duplicate-and-epic-link.md`. Она называет
прямо, что работы по задаче не было и требований в слой правил из неё не приехало: иначе
следующий читатель ищет сделанное.

## Чем это подтверждено

`npm run check:board` строки о папке закрытой задачи не печатает; проверки текстов — слог, пути
документов, возраст архива, предел длины — зелёные.

## Что осталось открытым

Прочие расхождения сверки очереди — задачи без исполнителя, задачи вне борды и заголовки без
номера — заведены давно и лечатся не здесь.

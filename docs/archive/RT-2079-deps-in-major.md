# RT-2079 — зависимости подняты в пределах своего мажора

**Ветка:** `RT-2079-deps-in-major` · **Разобрано:** 2026-09-13

## Просьба владельца

> подтяни свежий main и почисти ветки, обнови макеты которые используются на проекте

На вопрос, что такое «макеты», владелец ответил:

> пакеты, обнови npm пакеты

## Что было не так

`pnpm outdated` показывал 104 отставших пакета: 81 в пределах своего мажора и 23 с новым
мажором. Angular стоял на 22.0.5 при 22.1.6, Nx — на предвыпуске 23.1.0-rc.0, Storybook для
Angular отстал от остального Storybook на четыре минорных версии. `pnpm audit` считал 37
уязвимостей.

## Что сделано

77 строк манифеста переписаны на последнюю версию в своём мажоре; снимок дерева пересобран, дубли
Angular 22.0.5 в нём схлопнуты. Список подмен пересмотрен: две строки сняты, четыре пола подняты
до исправленных версий. Уязвимостей стало 23. Раннер витрины получил потолок по своей цепочке
Jest и Playwright — пять строк подмен с областью действия только на него.

## Чем это подтверждено

- `pnpm install --frozen-lockfile` принимает снимок без правки; в манифесте ни одного `^` или `~`.
- `pnpm run check:all` — 195 задач Nx и stylelint без провалов.
- Снимки витрин: первая 88 из 88, вторая 549 из 549 — командой `node tools/visual-gate.mjs`.
- `pnpm outdated` перечисляет только мажоры, `@oxc-project/runtime`, устаревший
  `conventional-changelog-cli` и две оставленные версии — `@faker-js/faker` и `@playwright/test`.

## Почему так, а не иначе

- **Мажоры в задачу не вошли** — правило о зависимостях велит поднимать пакет с новым мажором
  своей задачей: откатывается отдельно. Список: eslint 10, typescript 7, vitest 5, NestJS 12,
  stylelint 17, jsdom 30, @types/node 26, commitlint 21, webpack-dev-server 6,
  eslint-plugin-simple-import-sort 14, jsonc-eslint-parser 3.
- **TypeScript остался на 6.0.3** — Angular 22.1 и ng-packagr держат `>=6.0 <6.1`; верхняя граница
  снята с peer-диапазонов, а не с реестра.
- **Свежие версии взяты без ожидания** — срок ожидания в дереве не задан; назначать его самому
  значило бы решать за владельца.
- **`@storybook/angular` поднят с 10.1.2 до 10.6.0** — в истории причины держать его отдельно от
  остального Storybook нет.
- **Подмена нужна, пока хоть один родитель тянет версию ниже пола** — так снимаются
  `http-proxy-middleware@3` (родителей нет) и `launch-editor` (родитель уже требует не ниже пола).
  Новые подмены под оставшиеся 23 уязвимости не заведены: это уже не пересмотр списка, а его рост,
  и пять из них лежат в графе приёмника, а не сборки.
- **Jest в цепочке раннера витрины остановлен на 30.4** — `jest-runtime` 30.5 запрещает
  `module.register()`, а Storybook грузит через него конфиг раннера: 21 набор снимков падал, не
  начав. Потолок стоит подменой с областью действия только на раннер; корневой Jest ушёл на 30.5.1.
- **`@faker-js/faker` остался на 10.5.0** — 10.6 меняет данные, которые витрина генерирует по
  сиду: 14 кадров селекторов и таблицы показывали другие адреса при той же вёрстке. Перезапись
  эталонов — отдельное решение, не обновление пакетов.
- **`@playwright/test` остался на 1.62.1, и раннеру витрины дан тот же потолок** — Chromium из
  1.63 иначе рисует уголок изменения размера у textarea: семь кадров второй витрины расходились на
  60–275 пикселей ровно в нём. Эталоны сняты браузером 1.62, и до их пересъёмки браузер не
  меняется.
- **`@oxc-project/runtime` не тронут** — версия 0.x, её никто не использует; кандидат на удаление,
  но удаление — не обновление.

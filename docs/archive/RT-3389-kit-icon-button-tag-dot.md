# RT-3389 — кнопка-квадрат и точка у метки в ките

Задача RT-3389 эпика RT-3390, запись от 2026-11-18. Прежний адрес: `docs/tasks/RT-3389-kit-icon-button-tag-dot/`.

## Просьба владельца

Поручение пришло от сессии эпика по мессенджерам. Шапка страницы записи на узком экране держит
кнопки квадратами 32 без подписи, а статус записи — цветной точкой. Экранные макеты собираются
только из компонентов дизайн-системы, поэтому обе детали сначала добавляются в кит:

> 1. Кнопка `rtButton` «только значок» в дизайн-системе. […] Нужен вариант или свойство «только
>    значок» у трёх наборов кнопок (Outlined, Filled, Text) во всех размерах и состояниях,
>    квадратом со стороной высоты. […]
> 2. Вид «точка» у `rt-tag`. […] Текст значения уходит в подсказку и в aria-label. […] В коде — вход
>    у `rt-tag` (например `appearance="dot"`), стори на все severity, переводы подписи не нужны.

Позже: нужен выпуск minor-версии на npm, потому что шапка берёт кит из реестра.

## Что сделано

- Figma: у Button/Filled, Outlined, Text свойство `Icon only`, по 180 новых вариантов, квадраты
  32…64. У Tag — `Appearance=dot`, 18 вариантов, 6/8/10 px.
- `rt-tag`: `appearance="dot"` рисует круг цвета палитры, значение в подсказке и в `aria-label`
  при `role="img"`, точка берёт фокус с клавиатуры. Сценарии SC-UKV-1378…1381.
- Код кнопки не менялся: квадрат без подписи в нём уже был. Добавлены стори `IconOnly` и
  `IconOnlyStates`, у метки — `Dot`.

## Решения

- **Эпик RT-3390 заведён под одну задачу.** Проверки работы не знают задачи вне эпика. Решение
  владельца через запустившую сессию: «Решение (а)».
- **У шагов нет зелёных отметок движка.** Код 1.1 и 1.2 написан, пока план ждал одобрения. Движок
  отвечал «step 1.1 has no check line»: у шагов плана нет строк проверки в той форме, которую он
  ждёт. План после одобрения не правится.
- **Наложение квадрата 32×32 расходится на 35% пикселей только по краю рамки и значка.** Это
  сдвиг снимка на долю пикселя. Сверка числами — 121 из 121.

## Что не доделано

- Кольцо загрузки кнопки в коде 18 px вместе с рамкой, в Figma 14 px. Это касается всех кнопок
  кита и лежит вне задачи.
- В кадрах витрины кольца загрузки не видно: съёмка останавливает анимацию появления.
- Библиотеку Figma «Design System V2» публикует человек кнопкой Publish.

# RT-2509 — витрины стояли на старом Playwright: подъём с пересъёмкой эталонов

**Ветка:** `RT-2509-faker-playwright-snapshots` (вне эпика, пункт списка RT-2081) ·
**Разобрано:** 2026-10-03

## Просьба владельца

> обнови npm пакеты

Мажоры этой просьбы вынесены в список RT-2081. Последний подвижный пункт — два пакета, меняющие
кадры витрин: faker и Playwright. RT-2509 взята за RT-2507.

## Решения

- **faker остался на 10.5.0.** Он кормит только витрину первого кита, а ADR 0003 держит её 85
  кадров образцом для сравнения «до и после». Пересъёмка заменила бы этот образец. Отвергнуто:
  поднять faker вместе с пересъёмкой первой витрины.
- **Playwright поднят до 1.63.0**, снята строка в `pnpm-workspace.yaml`, державшая раннер витрин на
  1.62.1. Образ браузера для съёмки берётся по версии `@playwright/test`, так что обе витрины
  снимаются одним Chromium.
- **`pnpm install` оставил раннер на 1.62.1** из старого снимка зависимостей. Его сдвинул
  `pnpm update playwright playwright-core`. После этого в локальной копии пропала поднятая ссылка
  на `playwright`, и проба отрисовки её не находила. Чистая установка `--frozen-lockfile` ссылку
  создаёт — сбой был только в этой копии.
- **NestJS 12 не взят:** `@nx/nest` 23.2.1 и даже 23.3.0-beta.9 объявляют `@nestjs/core <12`.

## Проверки

- Первая витрина: 99 из 99 кадров совпали на Chromium 1.63, ничего не переснято.
- Вторая витрина: разошлись ровно семь кадров textarea. Каждая картинка расхождения просмотрена
  глазом — отличается только уголок изменения размера. После пересъёмки прогон без обновления —
  746 из 746.

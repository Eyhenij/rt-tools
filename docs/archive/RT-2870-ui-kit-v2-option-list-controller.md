# Разбор

## Просьба владельца

> Делай RT-2861

Задача третья из пяти в эпике RT-2861. Выпадающий список, множественный выбор и автодополнение
каждый писали свою клавиатуру списка. Правка доступности в одном поле не доходила до остальных.

## Решения

- **Один контроллер `RtOptionList` в ядре кита.** Он держит подсветку, клавиши открытия, действие
  клавиши в открытом списке, id подсвеченной опции и прокрутку к ней. Правило записано в спеке
  поддомена option-list.
- **Поле отдаёт контроллеру то, чем отличается от соседних.** Это клавиши выбора (в автодополнении
  пробел печатает), боковые стрелки дерева и отключённые опции. Куда встаёт подсветка при открытии,
  решает поле: выпадающий список ставит её на выбранное.
- **Имена `activeIndex` и `activeOptionId` остались у полей** как сигналы контроллера: разметка не
  менялась.
- **id панели передаётся функцией:** поле `panelId` может быть объявлено после контроллера.

## Что подтверждено

2934 теста кита зелёные, в том числе прежние тесты клавиатуры трёх полей. Тесты контроллера
проверяют клавиши без отрисовки компонента. Проверка типов, линтер, проверки спек и путей в
документах чистые. Отправка прошла полный набор проверок, в нём снимки витрины.

# RT-3096 — сторож посторонних драйверов браузера ловит драйверы из плагинов

Задача RT-3096, ветка `RT-3096-plugin-browser-drivers` от `main`, работа вне эпика по слову
владельца. Папка задачи `docs/tasks/RT-3096-plugin-browser-drivers/` разобрана в эту запись.

## Просьба владельца

> бери след задачу

Сказано после трёх описанных задач: RT-3096, RT-3067 и RT-3095. RT-3067 оказалась задачей
соседнего эпика, поэтому взята первая из двух оставшихся. В очереди задача звучит так: сторож
посторонних драйверов браузера знает только `mcp__playwright__*` и `mcp__chrome-devtools__*`. Те
же драйверы из плагинов называются иначе, и через них браузер открывался мимо закреплённого
профиля.

## Решения по ходу

- **Имя плагина ловится образцом, а не одним точным префиксом.** Имя плагина и имя сервера внутри
  него выбирает тот, кто выпускает плагин.
- **Новые строки набора стоят до раздела о ненастроенном дереве.** Тот раздел удаляет дерево
  набора, и строки после него судили сторож без закреплённого профиля.

## Проверено

- Набор сторожа: 22 проверки, 0 провалов; две строки про драйверы из плагинов падали до правки.
- Соседние наборы сторожей браузера без провалов: 7, 10, 8, 6 и 12 проверок.
- Вызов через диспетчер с именем из плагина отбит.
- Разложенные копии сходятся с пакетом v0.33.1.

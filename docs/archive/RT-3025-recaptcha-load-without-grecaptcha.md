# RT-3025 — скрипт reCAPTCHA, загруженный без grecaptcha, заканчивает ожидание

Задача RT-3025, запись от 31.10.2026, до открытия PR. Ветка
`RT-3025-recaptcha-load-without-grecaptcha` стоит каскадом на `RT-3027-owner-text-verbatim`, работа
вне эпика по слову владельца. Папка задачи разобрана в эту запись.

## Просьба владельца

На вопрос, какую задачу брать следующей, владелец выбрал:

> RT-3025 reCAPTCHA (Recommended)

Постановка — тело задачи #3025, находка ревью PR #3024 (RT-3013): после `load` скрипта Google без
`grecaptcha` ожидание не вешается на тот же скрипт повторно.

## Что было в дереве

`whenRecaptchaReady` по `load` снимал слушатели и снова звал ожидание. Без `grecaptcha` оно
находило тот же скрипт и вешало новый `load`, который не придёт: флажок не рисовался, ошибки не
было, регистрация не проходила.

## Решения

- **После `load` без `grecaptcha` ожидание кончается, а не ждёт API дальше.** Скрипт Google ставит
  `grecaptcha` с заглушкой `ready` сразу при исполнении; если после `load` его нет, скрипт подменён
  или сломан. Отвергнуто: опрос `window` по таймеру — он живёт без срока.
- **Тест SC-AUTH-96 написан до правки и был красным:** после первого `load` на скрипт вешались
  два новых слушателя.

## Что правка меняет для человека

Без `grecaptcha` флажка не будет и после правки: рисовать его нечем. Исправлено зависшее ожидание —
страница больше не держит слушатель на скрипте, который второй раз не загрузится. Тело первого
коммита правки описывает видимую поломку так, будто правка её чинит; это неточность, история не
переписывается.

## Код-ревью

Ревью в две оси: правила дерева и задача #3025.

- Исправлено: статья спеки обещала больше, чем делает код. Если страница впервые спрашивает уже
  после загрузки скрипта без API, ожидание висит до ухода со страницы: по тегу `<script>` не узнать,
  загружен ли он. Статья и описание функции называют это границей. Повтор «взять API и позвать
  `ready`» в двух местах сведён в `takeApi`.
- Оставлено: тест не проверяет снятие слушателя `error` — его снимает тот же `release`, что и
  `load`, и это держит SC-AUTH-93.

# RT-2511 — в манифесте стоял неиспользуемый oxc runtime

**Ветка:** `RT-2511-drop-oxc-runtime` (вне эпика, пункт списка RT-2081) ·
**Разобрано:** 2026-10-03

## Просьба владельца

> обнови npm пакеты

Список RT-2081 назвал `@oxc-project/runtime` кандидатом на удаление, а не на обновление. RT-2511
взята за RT-2509.

## Решения

- **Пакет убран.** Код дерева его не импортирует, `pnpm why` показывал только корень. Пришёл он
  вместе с каркасом админки приёмника, причина не была записана.
- **Удаление проверено сборкой, а не поиском.** rolldown внутри сборщика Angular умеет подставлять
  в собранный код импорты помощников из этого пакета, и поиск по исходникам этого не увидит.
  Сборки 11 проектов и обеих витрин прошли без кэша, в собранном коде пакет не упомянут.
- **`pnpm remove` выровнял отступ двух строк скриптов** в манифесте — правка оставлена.

## Проверки

- `nx run-many -t build --skip-nx-cache` — 11 проектов зелёные.
- Сборки обеих витрин — зелёные.

# RT-3087 — открытие PR отбивается, пока договорённость из плана лежит невлитой

Задача RT-3087, ветка `RT-3087-pr-unmerged-agreement` от ветки `RT-3088-spec-length-before-merge`,
работа вне эпика по слову владельца. Папка задачи `docs/tasks/RT-3087-pr-unmerged-agreement/`
разобрана в эту запись.

## Просьба владельца

> RT-3087 (Рекомендуется)

Владелец выбрал её из трёх задач с описанием. В очереди она звучит так: PR открывается, когда
договорённость фичи ещё лежит невлитой в `proposed/`. Сторож отбивает ветку с папкой задачи, а
договорённость не останавливает никто; в дереве, которое ставит пакет, так влились 13 задач.

## Решения по ходу

- **План читается из истории ветки.** К открытию PR папка задачи уже разобрана, и плана на диске
  нет; последний коммит, тронувший план, — тот, что его удалил, и план берётся из его родителя.
- **Обход папки снимает и договорённость.** Работа, которая вливается частями, может влить
  договорённость последней частью.
- **Правило записано в отдельное описание `delivery-agreement`.** У описания работы в файле
  сценариев 494 строки, и места под новый сценарий нет.

# RT-2376 · Описание полосы страниц называет вход numbering

Задача RT-2376, PR в ветку эпика RT-1870, закрыто 27 сентября 2026 года. Ветка
`RT-2376-kit2-pagination-numbering-docs`.

## С чего началось

После слияния RT-2374 владелец попросил проверить влитое и собрать пакет на рабочий стол. Запись
хода эпика не прошла ворота отправки: проверка входов по описаниям витрины не нашла новый вход
`numbering` в таблице «Входы» полосы страниц.

## Что оказалось

- Отправка ветки RT-2374 эту проверку прошла, а ветка эпика — нет: набор отправки считает
  затронутое по-разному для двух веток.

## Что сделано

- Таблица «Входы» и абзац про номера в описании полосы страниц называют `numbering`.
- Ход эпика записывает влитую RT-2374 и пересобранный пакет.

## Урок

Новый вход компонента второго кита описывается в его странице для витрины тем же коммитом:
`node tools/verify-ui-kit-v2-docs.cjs` запускается до отправки, а не только воротами.

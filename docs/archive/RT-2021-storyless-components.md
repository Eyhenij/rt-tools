# RT-2021 — компоненты второго кита без своей истории

**Ветка:** `RT-2021-storyless-components` · **Разобрано:** 2026-09-10

## Просьба владельца

> овервью с ошибками!!! закрываем дыры

Задача заведена в разборе этой просьбы вместе с RT-2019 и RT-2020 — третья из трёх дыр показа
второго кита, найденных обходом витрины.

## Что было не так

Карточка называла семь компонентов, которые своей истории не имеют и попадают в кадр только
внутри обёртки соседнего семейства. Счёт по заголовкам историй дал тридцать: кроме семи, своей
истории не было у 23 маркеров проекции содержимого.

Проверка покрытия этого не видела вовсе. Она считает семейства: у семейства должны быть страница
обзора и папка историй, и все тридцать лежали внутри семейств, которые до витрины доходят.
Семейств 74, доходят 73 — счёт был зелёный.

## Что сделано

- Заведено пять файлов историй, 16 показов: футер панели, футер окна, окно несохранённых правок,
  окно подтверждения пункта меню, нажимаемая строка таблицы.
- Снято 16 эталонных кадров — каждый после осмотра.
- Проверка покрытия научилась второму вопросу: является ли компонент предметом какой-нибудь
  истории. Компонентов и директив 116, предмет истории 91.
- 24 компонента стоят в перечне с причиной, один назван показанным внутри соседней истории.
- Экран-образец называет активную таблицу до перехода к её настройке — кит требует этого от
  потребителя.

## Почему так, а не иначе

- **Считаем по заголовку истории, а не по вхождению имени в разметку.** По второму счёту семь из
  карточки выпадали из списка: их имена стоят в обёртке родителя, а своей истории у них нет.
- **Маркерам проекции содержимого показ не заводится.** Своей разметки у них нет вовсе: в кадре
  виден не маркер, а то, как родитель разложил содержимое. Это уже показывает история семейства.
- **Пара показывается в одном кадре, а не двумя историями.** Проецируемая подсказка поля уже
  стоит рядом со строковой в истории `Hint` семейства поля; вынутая оттуда, она не показала бы
  ни одну сторону против другой.
- **Каждая ячейка окна подтверждения поднимается своим инжектором.** Данные окно берёт из
  инжектора, а не из входов: один общий на весь ряд дал бы четыре одинаковых окна.
- **Нажатие и наведение строки рисует аддон по признаку, а не мышь.** Мышью в статичной сетке ни
  одно из этих состояний не поймать.

## Чего работа не делает

- **Панель настройки колонок показа не получила.** Она открывается и через несколько секунд
  закрывает себя сама: кадр застаёт пустую страницу. Заведена задача RT-2049.
- **Кнопки не показывают материальный набор на каждой истории.** Это слово владельца, сказанное
  по ходу работы; заведена задача RT-2046.
- **Первый кит не тронут.** Он читается образцом, его эталоны не пересниматься.

## Что нашлось попутно

Кадров на диске было 549 при 468 историях со снимком: разница — варианты порогов ширины. Кадров,
которым не отвечает ни одна история, нет ни одного; одинаковых по байтам нет ни пары.

# RT-2274 — состав эпика перестал считать номера PR задачами

**Ветка:** `RT-2274-epic-makeup-counts-pulls` (от ветки задачи RT-2219) · **Разобрано:** 2026-09-19

## Что было не так

Строка состава эпика несёт в столбце состояния номер PR, которым задачу влили: «влито, PR #2198».
Счётчик состава читал из строки любое число после решётки и принимал номер PR за номер задачи
эпика. Аудит очереди из-за этого говорил «план называет задачи, которых нет среди подзадач
карточки» и перечислял номера PR: четыре у эпика #2195, один у #2177.

Видно это стало только теперь: до задачи #2219 планы живых эпиков аудит не читал вовсе.

## Слово владельца

> Чего стоиш

Сказано на отчёте о конце эпика — по нему обе находки задачи #2219 взяты в работу.

## Решения по ходу

- **Номер берётся из столбца задач, а не из всей строки.** Столбец тот самый, по которому строка
  вообще признаётся строкой состава: его заголовок несёт слово «Задача» или «Task».
- **Ветка стоит цепью на ветке задачи #2219.** Обе правят один и тот же счётчик состава, и
  заведённые от ветки эпика они разошлись бы на нём.

## Цена

Одна новая функция чтения столбца, два вызова счётчика, один сценарий и две пробы. Расхождений в
аудите было 16, стало 14.

Осталась настоящая строка про #2177: задача #2181 в плане эпика чата есть, а подзадачей карточки
не привязана. Это правка на доске, не в коде.

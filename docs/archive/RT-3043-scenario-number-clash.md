# RT-3043 — номер SC-AUTH-98 занят дважды

Эпик RT-3043, ветка `RT-3043-cargo-2026-11`, 07.11.2026. Запись сделана из папки на ветке эпика.

## Просьба владельца

> делай эпик с грузами приёмника дальше

## Что было

В `main` два сценария носили номер `SC-AUTH-98`: `docs/specs/auth/angular/scenarios.md` и
`docs/specs/auth/example/scenarios.md`. Правки влились рядом, и `node tools/check-specs.mjs` стал
красным. Ни одна ветка эпика не уходила на сервер, пока номер не разведён.

## Решения

- **Номер получает сценарий примера: SC-AUTH-104.** Команда `npm run spec:next-id -- AUTH` назвала его
  следующим свободным. Сценарий и заголовок теста правятся одним коммитом.
- **Правка идёт по ветке эпика.** Ветка задачи не может открыть PR, пока ветки эпика нет на сервере, а
  ветка эпика не проходила набор с этим номером.

Пришла из сессии, начатой владельцем, 23.10.2026, дословно:

> В `docs/archive/RT-2938-chat-undelivered.md` (уже в main, PR #2939 слит) пункт «Figma не сделана»

> «Chat Bubble» есть вариант `Side=own, Status=undelivered`. Пузыри ленты «Chat» тянутся по ширине
> ленты: FILL с наибольшей шириной 320 и отступом `space/12` со стороны, противоположной автору.
> Текст реплики в вариантах own/undelivered и own/sent привязан к свойству `Text#4662:0` (это
> исправлено отдельно, после найденного дефекта). Нужно поправить этот пункт записи, чтобы он
> описывал сделанное, и отправить правку через задачу, ветку и PR по правилам дерева (task-flow,
> git-workflow, archive-record). Готово, когда PR с правкой записи открыт.

## Решения

- **Пункт переписан, а не дополнен строкой ниже.** Запись читается глазом, два противоречащих
  пункта рядом читаются хуже одного верного. Признание, что первая версия описала дело неверно,
  стоит в самом пункте.

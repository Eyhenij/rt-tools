# RT-1897 — у приёмника не было прав: вошедшему было можно всё

**Ветка:** `RT-1897-rights-and-roles` · **Эпик:** #1896 · **Разобрано:** 2026-09-08

## Просьба владельца

> начинай новый эпик - в приёмнике message bus нужно иметь возможность добавлять других
> пользователей, проверь как это реализовано сейчас и составь план по реализации списка
> пользователей и страницы с правами и ролями

Первая задача эпика: право, роль и проверка, которая их читает. Списка людей и страницы прав
эта задача не делает — они идут задачами #1899 и #1901.

## Что сделано

- Черновик договорённости написан до кода и последним коммитом влит подразделом
  `docs/specs/message-bus/access-rights/` — одиннадцать сценариев SC-MB-287…297.
- В хранилище появились `Role` и `AccountPermission`, у записи человека — роль и точечные правки.
  Переезд написан рукой: базы приёмника на машине не поднято, а `prisma migrate dev` без неё не
  идёт.
- Закрытый набор прав и сложение роли с правками поверх неё — `rights.ts`. Набор закрыт кодом, а
  не таблицей: право называет объявление операции, и строку таблицы, которую не читает ни одна
  операция, от опечатки не отличить.
- Четвёртый вид объявления доступа — `RequiresRight`; проверка доступа читает права на каждом
  вызове и разводит два отказа: 401 «ты не представился» и 403 «тебе это не положено».
- Ответ о том, кто вошёл, несёт имя и права; в админке их держит хранилище входа, и до ответа
  приёмника оно не скрывает ничего.

## Чем подтверждается

- `pnpm exec nx test message-bus-api-access-util` — 14 прошли.
- `pnpm exec nx test message-bus-api-access-feature` — 22 прошли, из них 8 о праве.
- `pnpm exec nx test message-bus-api-accounts-feature` — 37 прошли.
- `pnpm exec nx test message-bus-admin-auth-data-access` — 10 прошли.
- `npm run check:specs`, `npm run check:docs` — без расхождений; десять сценариев из одиннадцати
  сняли отметку «не покрыто» на третьем этапе, одиннадцатый — на четвёртом.

## Что осталось открытым

- Ни одна существующая операция правом ещё не закрыта: объявления менялись бы вместе со сквозным
  набором, и это задача #1898.
- Пункт меню и адрес раздела закрываются одним объявлением — статья правила `permissions`, до
  #1898 не применимая: страж стоит на всей закрытой ветке маршрутов целиком.
- Ролей в хранилище пока не заводится ничем: заводит их страница ролей, задача #1901.
- Чем заводится первая запись, когда команды строки запуска сняты, — решается задачей #1902.

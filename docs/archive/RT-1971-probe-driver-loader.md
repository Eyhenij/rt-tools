# RT-1971 — загрузка драйвера браузера скопирована в четыре проверки

**Ветка:** `RT-1971-probe-driver-loader` (вне эпика по слову владельца, стоит на ветке RT-2265) ·
**Разобрано:** 2026-10-02

## Просьба владельца

> Задачи вне эпиков

RT-1971 — следующая одиночная задача очереди после RT-2265.

## Что нашли

- `loadChromium` стояла четырьмя копиями: в пробах значков, рисования и подгонки окна и в обходе
  историй второго кита. Текст отказа в обходе уже отличался от трёх остальных.
- Общий модуль проб `tools/showcase-probe.mjs` прямо говорил, что пятую копию в него сознательно
  не брали.

## Решения

- **Загрузчик живёт в общем модуле проб.** Он ищет драйвер по имени, потом в общей папке ссылок
  pnpm, как и прежние копии.
- **Отказ передаёт вызывающий.** Обход историй отказывает своим `fail`, пробы по умолчанию печатают
  отказ и выходят — так каждый инструмент ведёт себя, как раньше.
- **Проверка — разовый вызов, а не файл в `tools/`.** План называл файл проверки, но разовый
  проверочный скрипт в репозиторий не кладётся; тот же вызов выполнен встроенным модулем.

## Проверки

- Встроенный вызов общего загрузчика: «one loader, driver found».
- `function loadChromium` осталась в одном месте; eslint по пяти файлам — без замечаний.

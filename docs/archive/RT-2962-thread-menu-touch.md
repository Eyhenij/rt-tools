# RT-2962 — меню беседы в списке бесед видно на сенсорном экране

Ветка `RT-2962-thread-menu-touch`, стоит на ветке RT-2960. Папка задачи разобрана в эту запись.

## Просьба владельца

Та же, что у RT-2961: слово владельца 28.10.2026 в сессии VillaManager, задача VM-3125.

## Что было

- На телефоне кнопка меню строки в списке бесед не появлялась: её показывало только наведение.

## Решения

- **Действия строки прячутся только под `@media (hover: hover)`.** Тот же приём стоит у кнопки
  меню строки таблицы кита. С мышью кнопка появляется по наведению, фокусу и открытому меню.

## Чем подтверждено

- Тесты списка бесед 23 из 23, сценарий SC-UKV-1044.

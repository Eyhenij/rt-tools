# RT-3086 — проверка сценариев узнаёт длинные префиксы и называет сценарии строками таблицы

Задача RT-3086, ветка `RT-3086-scenario-long-prefixes` от ветки `RT-3087-pr-unmerged-agreement`,
работа вне эпика по слову владельца. Папка задачи `docs/tasks/RT-3086-scenario-long-prefixes/`
разобрана в эту запись.

## Просьба владельца

> паралельно не нужно, потом бери RT-3086

Сказано, когда RT-3086 предложена параллельно, пока шли проверки RT-3087. Задачу взял раньше
решения владельца по #3107; владелец сказал «как закончиш с прошлой продолжай эту», и #3107 ушёл в
ревью первым. В очереди задача звучит так: проверка сценариев узнаёт сценарий только по префиксу из
2–6 букв, и в дереве, которое ставит пакет, не узнала ни одного из 403 сценариев.

## Решения по ходу

- **Строка таблицы называется, а не читается.** У строки нет строки обещания и отметок покрытия:
  прочитанная, она была бы сценарием, который нечем проверить.
- **Ширина — пара чисел `scenarioPrefixWidth`, по умолчанию 2–10.** Заголовок и ссылка из теста
  строятся из одной пары.
- **Своя команда номера сценария этого дерева не тронута.** Она читает 2–4 буквы и пакетом не
  поставляется.

## Проверено

- Проверки описаний: 56 проверок, 0 провалов; четыре новые строки SC-AK-1250, три падали до правки.
  Соседние наборы — корни 8, двоеточие 5, покрытие 11, вход по имени 29 — без провалов.
- Сверка описаний этого дерева на новой ширине: 3067 сценариев, новых расхождений нет.
- Разложенные копии сходятся с пакетом v0.33.1.

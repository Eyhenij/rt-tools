# RT-2150 — находка аудита о базе вне главной ветки называет оба следствия

**Ветка:** `RT-2150-audit-base-both-consequences` (на `RT-2146-board-sees-main-and-chains`) · **Разобрано:** 2026-09-15

## Просьба владельца

> бери новый эпик — исправь все замечания и предложения из приёмника, которые ещё не обработаны

Четвёртая задача эпика RT-2146. Груз: разбор «2026-09-16-chain-prs-left-tasks-open-after-merge»,
дерево `70f4a3ad0c32`, знак в приёмнике `e196c214-6e2d-4067-8faa-d1574f0ba427`; предложение 3.

## Что было не так

Находка аудита «запуска на вершине нет и не будет, база не главная» называла одно следствие;
второе — задачу слиянием хостинг не закроет — читалось из той же причины, и о нём находка
молчала. В этом дереве с RT-2066 аудит о таком PR молчит вовсе: строка стояла на каждой задаче
каждого эпика и советовала перенести базу.

## Решения

- **Молчание по каждому PR остаётся, оба следствия названы один раз одной строкой.** Строка
  считает открытые PR с базой не в main и говорит: запуска им конвейер не даёт, задачу слиянием
  хостинг не закрывает — закрывает конвейер дерева или рука. Расхождением не считается; без
  таких PR строки нет. Отклонено: строка на каждый PR — довод RT-2066 в силе.

## Что сделано

Счётчик `offBase` и строка в `check-board.github.mjs`; пробы SC-AK-1107 в наборе доски; правило,
сценарий и привязка в `docs/specs/agent-kit/board/`.

# RT-2233 — номера сценариев SC-AK-1113…1116 заняты дважды

**Ветка:** `RT-2233-scenario-ids-collide` (от `main`) · **Разобрано:** 2026-09-18

## Просьба владельца

> разбирай Промах проверки выхода из хода на ветке эпика: кандидат в задачу следующего эпика по правилам.

Ответ владельца о той работе: «Новый эпик, две задачи — беру в работу сразу». Задача стоит вне
эпика: без неё не отправить ни одну ветку дерева.

## Что было не так

Эпики RT-2190 и RT-2203 влиты в main друг за другом, и оба выдали сценариям номера
SC-AK-1113…1115; SC-AK-1116 заняли описание выхода из хода и описание личности доставки. Проверка
описаний на main красная, набор перед отправкой не пропускал ни одну ветку.

## Решения

- **Новые номера 1123…1126 получили сценарии описания выхода** — их четыре в одном файле и двух
  наборах тестов; соседние домены в те же часы правит другая сессия.
- **Строка назначения копии rt-worktree-2 едет этой же веткой** — слово владельца «впиши сам»;
  таблица лежит в main, и эта ветка первой до него доходит.

## Цена

Одна ветка и один PR в main. Номера выданы заново, потому что два эпика выдавали их врозь и
встретились только в main; проверка занятости номеров читает одно дерево, а не две ветки сразу.

# RT-2365 — виджет чата на сайте выглядит не так, как в макете

**Ветка:** `RT-2365-widget-look-by-mockup` (от `RT-2366-kit2-message-composer`, эпик RT-2370) · **Разобрано:** 2026-09-30

## Просьба владельца

> бери в работу эпик 2370, перетяни тикет на борде в колонку in progress, создавай ветку и выполняй задачи друг за другом, ветки делай каскадом чтобы при слиянии веток по очереди не было мерж-конфликтов

Задача в очереди: посетитель видит кнопку-пилюлю со словом, узкую панель 320 px с белой шапкой и
системный шрифт. В макете — круглая кнопка с иконкой, синяя шапка с крестиком, пузыри сообщений,
поля как в остальном интерфейсе, панель 380 px. Макет решено считать целью.

Владелец отвечал рекомендованным вариантом во всех меню эпика; вопросы закрыты тем вариантом,
который меню рекомендовало бы.

## Решения и куда они ушли

- **Вид повторяется своими значениями в стилях виджета, а не компонентами кита.** Спека виджета
  запрещает кит внутри виджета. Иконки — пути SVG кита, скопированные в виджет. Ушло в спеку
  `docs/specs/chat/widget/`.
- **Поле в фокусе рисует кольцо, как поля кита; обводка браузера снята.**
- **Шрифт — семейство кита по имени с системной заменой, без файла шрифта.** Файл был бы вторым
  запросом. На стенде кадров стоит запасной шрифт без полужирного начертания, поэтому заголовок
  шапки в кадре обычный.
- **Кнопка отправки на пустом поле бледная, но нажимается.** Пустую реплику не пускает проверка
  виджета — это держит сценарий SC-CH-55.
- **Часы стоят в карточке приветствия; вне часов после первой реплики над лентой — заметка.**
- **Окно 380 px вместе с рамкой.** Так в макете; без `border-box` выходило 382.
- **Нет значков доставки у пузырей и имени оператора.** Имя оператора — задача RT-2367.
- **Кадры макета лежат на странице «Переписка с поддержкой» файла кита.** Список страниц файла её
  не называет; кадры открываются по номерам узлов.

## Проверки

- Сквозные спеки виджета: 13 из 13, два кадра сняты заново и подтверждены вторым прогоном.
- Сверка с макетом: кадр широкого экрана и кадр телефона совпадают по раскладке; ширина окна,
  цвет шапки, кольцо фокуса и стороны пузырей проверяются сквозной спекой.
- Цели виджета: линтер, тесты, сборка, типы — зелёные.

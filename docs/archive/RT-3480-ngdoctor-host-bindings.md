Правка `rt-button.directive.ts`, `rt-file-drop.component.ts`, `rt-skeleton.component.ts`,
`rt-toast.component.ts`, `rt-toaster.component.ts`, `rt-table.component.ts`,

- **Без вида:** «Подтверждаю, вид не меняется»

Конструкторы `BlockDirective` и `ElemDirective` опубликованного `@rt-tools/core` теряют параметры
при переходе на `inject()`. Владелец спросил: «Эти изменения сломают поведение?» — нет, те же
классы на тех же узлах; не соберётся только чужой код, что наследует классы с `super(...)` или
создаёт их через `new`. Ответ: «Менять, строка в PR (Recommended)».

## Что нашли

- Девять мест, где инструмент находит правило не по сути: значение `'id'` по умолчанию входа
  `keyExp` списка и таблицы данных он читает как имя входа; слово `[ngClass]` в комментариях и
  тексте правила линтера — как привязку класса; конструктор двойника Keycloak — как внедрение;
  комментарий `story-states.ts` о `@HostBinding` — как привязку; `ngOnInit` страницы брони, чей
  интерфейс стоял после дженерика, — как хук без интерфейса.
- Три запроса таблицы стояли статическими с пометкой `native-ok`: «сигнальный `viewChild()`
  резолвится после первой отрисовки строк». Проба опровергла довод: в Angular 22 сигнальный
  запрос своего вида заполнен уже в `ngOnInit`.
- У директив `escape-key`, `icon-outlined` и `navigation` core нет спек — и до задачи.

## Что решили и почему

- **Места, где инструмент ошибается, переписаны, а не выключены,** по решению эпика «Подогнать
  код»: константа `DEFAULT_KEY_EXP`, текст правила линтера «the ngClass directive», фабрика
  `KeycloakFetchDouble.withClients`, комментарий по смыслу, `OnInit` первым в списке интерфейсов.
- **Атрибут части строки таблицы данных ставится привязкой `host` и только в браузере,** как
  прежде в `ngOnInit`; на сервере значение `null`.
- **Публичный API меняется в трёх местах, вид — нет:** конструкторы директив БЭМ core без
  параметров, у `RtDataTableStopRowClickDirective` нет `ngOnInit`, поля колонки действий
  `RtTableComponent` — защищённые сигналы. Всё названо в PR.
- **База PR — ветка эпика:** PR #3511 задачи RT-3508 влит в неё раньше, чем открылся этот.
- **Списаны в ревью:** литерал атрибута в `host` (расхождение с константой ловят SC-UKV-258 и
  SC-UKV-274), тип `string` у имён БЭМ (прежний публичный тип), спеки трёх директив core (их не
  было и до задачи).

## Цена

- Код, что наследует `BlockDirective` или `ElemDirective` с `super(...)` или зовёт
  `ngOnInit()` директивы части строки, при выпуске пакетов перестанет собираться. Журнал выпуска
  core коммиты `refactor` не берёт — строку о ломающей правке туда ставит выпуск.

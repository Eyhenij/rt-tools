# Копия образца папки задачи несёт шапку раскладки

Задача RT-1049, заявка #1051. Запись собрана из разбора просьбы и хода работы при закрытии
задачи; после выкатки не правится. Заведена находкой работы RT-1046 о чтении груза, просьбы
владельца у неё нет.

## Что было не так

Папка задачи собиралась `cp -r docs/tasks/_template docs/tasks/<ветка>` — эту строку печатала
сама команда заведения задачи. Файлы образца разложены пакетом и несут шапку `rt-kit`, поэтому
гард места правки отбивал первую же правку разбора просьбы, то есть **первое движение любой
работы**. Отказ при этом уводил править образец пакета — тогда как правится копия под конкретную
задачу.

Снималась шапка тремя строками `sed` руками, каждой работой заново. За один заход это случилось
дважды: на RT-1046 и на самой RT-1049.

## Что сделано

Папку собирает сама команда заведения задачи и снимает с копий шапку. Довод тот же, каким пакет
уже кладёт без шапки черновик компаньона: с первой правки это текст проекта, и сверять в нём
нечего. Сам образец шапку по-прежнему несёт и обновляется раскладкой — он текст пакета.

Снятие вынесено в общий модуль команд (`unstampFolder`): сама команда заведения ходит в сеть
первым же действием, и сценарий на неё проверял бы доступность хостинга, а не сборку папки.

Сценарии `SC-AK-570…573` в поддомене места правки, семь проверок. Набор проверен на слом: с
выключенным снятием краснеют три из семи.

## Чего работа не закрыла

Спека раскладки говорит: «разложенным считается файл по пути раскладки, а не всякий, где эта
строка встретилась» — и гард места правки этому не следует, он судит по шапке. Пути раскладки у
него нет: для рода образцов он собирается из настройки дерева, а для правил раскладка ресурс
переименовывает, и общего способа собрать адрес не существует.

Копия образца папки задачи выведена из-под этого своим приёмом. Прочие роды копий остаются, и
первый из них — копия образца спека домена, которую делают руками. Записано вопросом `Q-EP-2`
поддомена места правки.

## Решения

- **Чинится причина, а не срабатывание.** Гард отбивал верно — по его признаку файл с шапкой и
  есть разложенная копия. Неверен был сам признак у копии: она несла след происхождения как
  утверждение о себе. Отвергнуто: ветка в гарде — точного общего признака у него нет.
- **Снятие живёт в модуле команд, а не в команде заведения.** Проверить его иначе нечем: команда
  заведения первым действием заводит задачу на хостинге.
- **Сценарии уехали в поддомен места правки, а не остались при раскладке.** Предмет там — какой
  файл считается разложенным; заодно поддомен раскладки перерос предел длины и делить его ради
  четырёх строк было бы дороже.

## What the tree already has

- Правило `git-workflow` велит PR в стопке ставить на предыдущую ветку.
- `projects/agent-kit/assets/hooks/git-guard-delivery-epic.sh` (`rt_epic_pull_base`) пускает у задачи

- Привязка статьи о стопке говорит, что хук пускает ветку, стоящую на ветке эпика. Это неправда.
- Правило `git-workflow` в варианте GitHub держит 23 564 знака при пределе 24 000; статьи об аудите
  очереди составляют заметную часть.

## Decisions

- **База стопки законна, пока несёт ветку эпика.** Хук пускает базу, в истории которой есть ветка
  эпика, и не пускает main. Аудит пускает базу, чья задача принадлежит тому же эпику.
- **Статьи об аудите очереди уходят в своё правило `queue-audit`** под законом о поставке, вариант
  GitHub; их привязки уходят с ними, карта правил называет его для файлов аудита.

# RT-1803 — гард поставки читал хвост имени ветки -b как флаг тела заявки

**Ветка:** `RT-1803-pull-body-flag-boundary` · **Разобрано:** 2026-09-05

## Что было не так

Гард поставки вынимал тело заявки из команды образцом `(--body|-b)` без границы слова. Имя
ветки, кончающееся на `-b`, в доводе основания совпадало с флагом, и телом становилось следующее
слово команды — `--head`, `2>&1`. Гард отвечал, что в теле нет раздела об оставшемся шаге, хотя
раздел в файле есть. Открыть заявку удавалось только именем последним доводом и без хвоста
команды. Найдено на открытии заявок RT-1799 и RT-1800.

## Что сделано

Оба образца — тела и файла тела — принимают флаг только отдельным словом: перед ним пробел либо
начало строки. Статья и сценарий SC-AK-884 в спеке гейта поставки, привязка «не проверяется
машиной» — как у соседней статьи о теле файлом.

- Три пробы: имя на `-b` с доводами после него, имя последним словом, файл без раздела при том же
  имени. На прежнем образце первая красная.
- Набор гардов поставки: 105 зелёных. Сверка спеков код 0, раскладка сходится.

## Цена решения

Образец файла тела `(--body-file|-F)` поправлен той же строкой, хотя имени на `-F` в дереве не
встречалось. Проба с именем последним словом на прежнем образце тоже зелёная: за `-b` там нет
слова, и тело не вынималось вовсе.

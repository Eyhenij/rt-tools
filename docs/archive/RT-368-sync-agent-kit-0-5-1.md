# Раскладка дерева выпущенной редакцией 0.5.1

Задача #368, отчёт #369. Запись собрана из хода работы при закрытии задачи; после выкатки не
правится.

## Просьба владельца

> я вмержил, подтяни свежий main и почисти ветки, опубликуй agent kit, подними 1 patch

## Почему работа понадобилась

Выпуск поднимает версию пакета, а шапка каждого разложенного файла несёт ту редакцию, которой
его положили. После выпуска 0.5.1 `sync --check` назвал 95 расхождений — по файлу на ресурс, и
ни одно из них не о тексте: разошёлся только номер в шапке. Настоящее расхождение в таком
списке не разглядеть, поэтому дерево раскладывается заново сразу за выпуском.

## Что сделано

`npm run agent-kit:sync` переложил 95 файлов, `--check` стал зелёным на 0.5.1. Надстройки дерева
не тронуты — они сливаются поверх разложенного и от смены редакции не зависят.

Содержательная правка в диффе одна: таблица о жизни номера сценария в паттерне спека домена
вернулась к выравниванию исходника. В прошлой задаче её переформатировал форматтер дерева уже
после раскладки, и разложенная копия разошлась с пакетом на пробелы.

## Чем проверено

- `npm run agent-kit:check` — разложенное сходится с пакетом v0.5.1;
- `npm run check:specs` — 135 расхождений, столько же, сколько до работы;
- `node tools/check-doc-paths.mjs` — расхождений нет;
- `npm view @rt-tools/agent-kit version` — 0.5.1 в реестре.

## Решения

- **Версия поднята патчем, хотя выпуск везёт новую команду.** По принятому в дереве счёту это
  минор; патч назван владельцем прямо, и работа сделана так.
- **Папка задачи не заводилась.** Работа механическая: понимание целиком помещается в тело
  отчёта, а гард замысла на пути раскладки не стоит.

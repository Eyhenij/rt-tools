# RT-768 — гейт правил и вызовы браузера

Прежний адрес: `docs/tasks/RT-768-gate-subscribes-to-browser-calls/`.

## Просьба владельца

> С какой из семи задач начинать и в каком порядке идти дальше?
> — «785 → 768 → остальные».

Задача вышла из сведения предложений, и владелец принял её тогда же. Этим заходом спрашивался
только порядок.

## Что было верно на день работы

- Тело гейта правил разбирало браузерные вызовы отдельной веткой, а строка объявления
  `# rt-hook:` и образец в настройке агента их не называли: на браузерный вызов гейт не звался
  вовсе, и ветка кода не исполнялась ни разу.
- Сценарий на это был зелёным: набор зовёт гард напрямую с подставленным вводом и объявления не
  читает.
- Сверка раскладки судила только то, что путь гарда где-нибудь в настройке назван; образец не
  сверяла вовсе, и расхождение копилось молча.

## Решения и куда они ушли

| Решение                                                               | Куда ушло                                                                             |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Проверка расхождения ставится в карту хуков, а не отдельным средством | обе стороны там уже вычислялись; второе место для той же сверки разошлось бы с первым |
| Расхождение идёт в счёт расхождений сверки, а не предупреждением      | гард с чужим образцом хуже неподключённого: тот хотя бы не притворяется               |
| Настройка, которую не разобрать, расхождением не считается            | образец лежит полем объекта, и вынуть его из текста поиском значило бы гадать         |
| Чинится только браузерное расхождение                                 | остальные, если найдутся, откатываются порознь и заводятся задачами                   |

## На чём споткнулись

Фикстура сквозных сценариев команд писала в настройку звёздочку вместо объявленного образца, и
новая сверка законно называла это расхождением. Чинилась фикстура, а не сверка: настройка со
звёздочкой и есть тот промах, ради которого сверку завели.

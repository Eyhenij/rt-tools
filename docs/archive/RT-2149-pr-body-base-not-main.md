## Что было не так

Образец тела PR требовал строку `Closes #<номер>` и молчал, что хостинг читает её только у PR с
базой в ветке по умолчанию. Два PR череды в дереве-потребителе пообещали закрытие, задачи
остались открытыми, колонка доски отстала от работы. Паттерн череды прямо говорил «задача
закрывается строкой Closes».

## Решения

- **Строка Closes остаётся там, где дерево закрывает задачу конвейером; иначе задача названа
  словами.** Образец даёт две формы строки связи, дерево выбирает одну; в этом дереве закрывает
  `close-epic-tasks.yml`, и переопределение это называет. Аудит очереди читает строку как связь
  PR с задачей на любой базе.
- **Шаг уборки после слияния череды спрашивает задачи командой и закрывает открытые рукой** с
  комментарием, называющим PR. Паттерн слияния получил тот же шаг после каждого известного
  слияния с такой базой.
- **Паттерн PR разделён.** С новыми абзацами он перерос 330 строк: строка связи, ревьюер, метки
  и образец тела ушли в `git-workflow-pr-body`; правило, соседи и описание образцов его называют.

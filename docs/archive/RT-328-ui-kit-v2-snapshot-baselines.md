# Эталоны снимков второй витрины

Задача #328, отчёт #329, слит 2026-08-09. Запись собрана из разбора просьбы и хода работы,
когда задачу закрывали. После выкатки не правится.

## Просьба владельца

> запусти task flow, нужно написать визуальные тесты в storybook для всех компонентов ui kit v2

Та же просьба, что и у задачи #326. Работу поделили на две, потому что откатываются они по
отдельности: первая сделала механику съёмки и замерила её на нескольких компонентах, а эта
сняла эталоны на всю витрину и поставила прогон в CI. С владельцем разбирали один раз, запись
целиком — в `docs/archive/obvyazka-snimkov-vtoroj-vitriny.md`, и ответы оттуда действуют здесь.

## Что определило эту работу

- **«Для всех компонентов» — вся витрина**, а не выборка. Непокрытую папку называем поимённо и
  с причиной: «не снимаем» должно быть отличимо от «забыли».
- **Снимаем матрицы, сравнение тем и по кадру на каждое открытое перекрытие.** Истории со
  значениями по умолчанию помечаем исключением с причиной.
- **Кадр порога** снимаем на каждом пороге ширины, который задаёт сам компонент.
- **Чиним всё, что найдётся.** Объём починки не урезаем, но правка, меняющая вид компонента у
  потребителей пакета, едет отдельным изменением.
- **Готово — это зелёный прогон в CI на своём раннере.**

## Решения по ходу

- **Завели отдельную задачу, а не продолжили ветку #326.** Откатываются они по отдельности:
  механика останется годной, даже если весь каталог эталонов придётся снять заново. Да и PR, где
  сотня картинок лежит вперемешку с правкой механики, читать невозможно.
- **Области приёма файла дали свой признак.** Механика требует открытой панели везде, где на
  странице есть признак триггера перекрытия, а перетаскивание файла панель не открывает вовсе —
  область подсвечивает себя сама. На общем признаке каждая такая история падала бы из-за
  панели, которой там нет. Ослаблять проверку не стали: она затем и сделана, чтобы кадр с
  неоткрывшейся панелью не стал эталоном.
- **Порогов ширины проставили девять наборов, а не одиннадцать.** Из одиннадцати папок, где
  задана ширина, две кадром порога не проверить: у одной нет ни одной истории, у второй
  единственная история рисует пустую обёртку с директивой, а сам компонент с медиазапросом
  витрина нигде не показывает. И то и другое — долг покрытия, а не разметки.
- **Истории без матрицы снимаем кадром целой страницы, а не помечаем исключением.** 35 файлов
  рисуют компонент напрямую, без сетки витрины. Исключение сняло бы их с проверки совсем — а
  это как раз те компоненты, у которых матриц ещё нет. Цена понятна: порог расхождения считается
  от площади всей страницы, поэтому мелкая правка в таком кадре пройдёт незаметно.
- **Наведение больше не переводит фокус на элемент.** Механика ставила фокус на любой жест, а
  подсказка прячется, когда фокус уходит. В ряду из трёх подсказок открытой оставалась только
  последняя, и кадр показывал одну панель там, где история обещает все три.
- **Четырнадцать эталонов из ветки #326 сняты поверх экрана с ошибкой сборки.** В кадре был не
  компонент, а красная плашка отказа сборки витрины. Саму ошибку в дереве уже исправили, а
  эталоны — нет. Отдельно чинить не пришлось: каталог всё равно переснимали целиком.
- **Прогон открывает по две истории разом, а не по потоку на ядро.** Витрина одна на всех, и по
  умолчанию прогон её обгоняет: приложение истории не успевает подняться, ожидание заканчивается
  впустую, кадр расходится или история падает. Замерили: на шести потоках — до восьми
  разошедшихся кадров за прогон, на четырёх — один отказ, на двух — ни одного за четыре прогона.
  Цена: 86 с вместо 43 с. Повторять упавшую историю не стали — так правило о повторяемости
  становится непроверяемым.
- **Восемнадцать историй с пустым набором данных сняли со съёмки поимённо.** От таблицы без
  колонок до полосы вкладок без вкладок: обёртка отдаёт пустой массив, и в кадре либо чистый
  фон, либо одни разделители. Эталон с такого кадра объявил бы пустоту нормой. У каждой истории
  своя причина, число исключений названо.
- **Три истории показывали страницу ошибки внедрения, две из них починили.** Вкладку и
  дополнение полосы показали внутри их контейнера: обе директивы требуют шаблон и сами по себе
  не рисуются. Таблице добавили службу хранилища настроек. Заголовку сортировки сделали двойника
  таблицы, но подпись он берёт из проекции, а обёртка её не отдаёт — кадр остался пустым, и
  историю сняли вместе с остальными пустыми.

## Что сделано

- Разметка: 40 исключений с причиной плюс четыре из ветки #326; 36 файлов и две истории снимаем
  кадром целой страницы; 13 панельных историй; девять наборов порогов ширины. Всего исключений
  62 из 288 историй.
- Каталог снят заново: 255 эталонов, 4.2 МБ, средний кадр 17 КБ, кадров порогов 29.
- Два прогона подряд зелёные — 86.1 с и 91.0 с. Полный прогон — 86 с.
- Нарочно внесённое расхождение (отступ метки плюс пиксель) уронило 14 кадров в четырёх
  компонентах, выложило 14 картинок различий и не оставило в дереве ни одного файла на коммит.
  После отката прогон снова зелёный.
- В CI появился свой шаг для второй витрины: витрина на своём порту, своё вложение с картинками
  различий, блокирующий. Шаг первой витрины не трогали.
- Договорённость влита в спек пакета, каталога `proposed/` не осталось. Добавлены три правила,
  которые вскрыла съёмка. Язык кадра исправлен на русский — витрина работает на нём. Из двадцати
  сценариев четыре покрыты спекой помощников, остальные помечены с причиной: прогон снимков
  заводит тесты по историям и идентификатора сценария не несёт.
- Проверки зелёные. По этому спеку сверка не даёт ни одного замечания, по дереву их 373 против
  375 до правки — работа не добавила ни одного.
- Прогон CI на отчёте зелёный, включая новый шаг и старый шаг первой витрины.

## Чем расплатились и что вынесли в задачи

- `Q-2` договорённости закрыт владельцем: 86 с его устраивают.
- #330 — наполнить восемнадцать историй с пустыми данными и снять с них исключение; заодно
  вернутся кадры порогов у четырёх папок.
- #331 — показать компонент панели инструментов витриной: сейчас рисуется пустая обёртка с
  директивой, и порог ширины не проверяется ничем.
- #332 — служба хранилища не отдаётся общим поставщиком: каждый, кто использует таблицу, обязан
  подключить её сам, иначе таблица падает с ошибкой внедрения. Ни в описании пакета, ни в спеке
  этого нет.
- #333 — заголовок сортировки не показывает подпись вне таблицы: она приходит проекцией.

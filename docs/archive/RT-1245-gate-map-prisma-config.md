# Настройка клиента хранилища ведёт к правилу поставки

Задача RT-1245, заявки нет — ветка местная, слияния не было.

## Откуда взялась работа

Запись груза из приёма, своё дерево, карта гейта правил. Повод: файл настройки клиента
хранилища не вёл ни к одному правилу, и правился он без правила под рукой. Ветка миграций знала
схему хранилища и каталог миграций — то есть ровно то, что этот файл и настраивает.

Владелец разбор не вёл: заход шёл сам, задачи брались из приёма одна за другой.

## Решение и довод

Третий образец встал в ту же ветку, а не в свою. Правило у всех трёх одно, и вторая ветка
отличалась бы от первой только списком путей — читатель карты держал бы в голове два места
вместо одного.

Сценарий проверяет, что путь настройки клиента доходит до правила поставки, а не до правила о
языке: расширение у файла общее с кодом, и ветка кода стоит в карте ниже — порядок веток тут и
есть предмет проверки.

## Цена

Ветка названа образцом пути, а не именем инструмента: дерево, держащее настройку клиента под
другим именем, к правилу по-прежнему не придёт.

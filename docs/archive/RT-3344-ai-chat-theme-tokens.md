# RT-3344 — токены вида чата

Задача RT-3344 эпика RT-3346, ветка `RT-3344-ai-chat-theme-tokens`, 21.11.2026. Бывший адрес —
папка задачи `docs/tasks/RT-3344-ai-chat-theme-tokens/`. Правила вошли в подраздел
`docs/specs/ui-kit-v2/ai-chat-theme-tokens/`, тексты для приложения — в обзоры чата и трёх его
частей и в README кита.

## Просьба

> Делай эпик дальше

> Делать RT-3344

Вопрос перед работой задан после того, как владелец выкинул RT-3343: «я вообще не понимаю что это
за фича… я тебе такое задание не давал». В вопросе было сказано, что даёт задача: приложение меняет
вид чата через внутренние классы кита, каждая правка кита это ломает, а задача даёт токены
`--rt-ai-chat-*` для этих мест. Варианты: «Не делать, закрыть (Recommended)» и «Делать RT-3344»;
владелец выбрал второй.

Карточка задачи: приложение подгоняет вид `rt-ai-chat`, переопределяя внутренние классы кита, и
каждая правка разметки кита молча ломает эти переопределения. Киту нужны входы или токены для
восьми пунктов: шрифт ленты и кегли ответа и вопроса; основной цвет «Отправить» и «Стоп», кольца
фокуса поля и выбранной оценки; высота шапки и разделитель под ней; ширина поиска в списке бесед
без предела 400px; ширина и скругление карточек подсказок; скрытие подписи автора в вопросе; фон
панели отдельно от фона поля; кнопка меню строки беседы — квадратная подсветка, без фона, на месте
времени строки. Готово, когда каждый пункт задаётся входом или токеном без селектора внутреннего
класса, а в витрине есть история с изменёнными токенами.

## Вопросы и решения

Владельца спросили только, нужна ли задача. Остальные вопросы закрыты допущением по карточке и
дереву.

- Без заданных токенов всё рисуется как прежде: умолчание каждого равно нынешнему значению, ни один
  прежний эталон витрины не изменился.
- Макета в Figma нет: вид по умолчанию не меняется, новый вид существует только как значения
  приложения. Владельцу показана витрина.
- Токены живут на компоненте, который рисует часть, а чат передаёт им свои `--rt-ai-chat-*`.
- Подпись автора убирает вход чата `questionAuthor`, а не токен: токен не уберёт узел от диктора.
- Пункт 4 уже сделан деревом: предела ширины поиска нет; договорённость это записывает тестом.
- README кита получает исключение из правила ступеней для кеглей, высоты шапки и ширины подсказки.

## Решения по пути

- Сначала части читали токены с запасным значением на месте. Проверка графа токенов запрещает
  запасное значение у имени, которое кит объявляет сам, и на этом приёме дала 18 расхождений.
  Приём заменён: каждая часть объявляет свои токены на своём блоке и читает без запасного, а чат
  задаёт их правилом на блоке части внутри себя — так README кита советует приложениям
  переопределять свойства блока.
- Семейство шрифта и две оценки — ручки потребителя без умолчания на чате: семейство наследуется
  лентой, оценка берёт заливку и цвет самой кнопки, и то, что приложение задало кнопке, доходит до
  неё как прежде. Они внесены в список ручек и в `Theming.mdx`.
- Проверка графа токенов засчитывала объявления историй витрины как объявления кита. Теперь
  объявление в истории не делает имя «своим» для правила о запасном значении и отвечает на «мёртвую
  ссылку» только для чтения в самой истории: пакет историй не несёт.
- Скрытие под действиями строки сначала брало весь узел времени и счётчика, и счётчик пропадал на
  сенсорном экране. Метка `rtThreadListUnderActions` перенесена на время; токен переименован в
  `--rt-ai-chat-thread-time-under-actions`.
- Аддон псевдосостояний витрины превращает `:not(:hover)` в список, где один вариант совпадает
  всегда. Скрытие времени переписано положительными селекторами.
- Скругление кнопок действий строки завёрнуто в `:where`: оно сильнее объявления кнопки, но уступает
  её входу `radius`.
- Подпись автора выведена заготовкой: ветка `@if` в пузыре подняла сложность шаблона чата за
  предел.
- Таблицы в начале раздела правил договорённости обрывали аудит спек на первой строке; при слиянии
  они перенесены в раздел терминов.

## Что осталось гипотезой

- Сенсорный экран: на нём действия строк видны всегда, и `hidden` прячет время у всех строк.
  Витрина не умеет экран без указателя; вывод сделан по собранному CSS.
- Приложений с чатом в дереве нет, поэтому то, что восемь пунктов карточки покрывают реальные
  переопределения приложения, проверено только по карточке.

# Долг повторов: десять правок кода и шестнадцать законных совпадений

Задача RT-841, PR #844. Пятая задача эпика RT-806.
Прежний адрес записи — `docs/tasks/RT-841-dupes-debt-by-kind/`.

## Откуда взялась задача

Замысел эпика RT-806 велел завести задачи под долг повторов и единообразия, когда кончится
четвёртая задача порядка, — числами того дня. Числа сняты 18 августа 2026 года:
`npm run check:dupes` — повторов 26, принято 0, долг 26.

## Что было верно на день работы

- Список принятого `tools/dupes-allowlist.json` держал 26 строк долга и ни одной принятой; в
  нём не было ни одной причины.
- Долг был неоднороден, и по числу 26 этого не видно: разобрать его нельзя, а принять целиком
  значило погасить и то, что чинится.

## Решение владельца

**Восемь совпадений имён между двумя независимыми китами принять списком с причиной, а проверку
не править.** Предложенный вариант «объявить настройкой дерева пары пакетов, которые кода не
делят» отвергнут. Тем же родом пошли `IMessageBusEvent`, `MessageBus` и `pathOf` — они стоят
между ядром, пакетом правил и вторым китом.

## Решения и куда они ушли

| Решение                                                                    | Куда ушло                                                                                    |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Наборы полей сортировки — договор двух сторон, а не свойство домена        | `libs/message-bus-common/src/lib/sortable.ts`; шесть объявлений стали тремя                   |
| Обязательные поля груза, приезжающего списком записей, объявлены один раз  | `CARGO_ITEMS_FIELDS` в `libs/message-bus-common/src/lib/cargo-shape.ts`                       |
| Состояние панели подробностей — общее у всех разделов, показывающих запись | `libs/message-bus-admin/common/core/util/src/lib/details-state.ts`                            |
| Обвязка снимков витрины читает имена там, где их объявляет кит             | `projects/ui-kit-v2/.storybook/test-runner.ts` и `…/components/icon/rt-icon.const.ts`         |
| Совпадения имён без общего символа принимаются с причиной по родам        | `tools/dupes-allowlist.json`, поле причины перечисляет три рода                               |

## Что нашлось по ходу

**Две договорённости дерева говорят разное про имя блока вёрстки.** Вынос `admin-panel` в
основание семейства отбило своё правило линтера `rt/require-host-bem-block`: оно требует
локальную константу ровно с именем `BEM_BLOCK` и общее объявление не принимает. Ответ нашёлся в
компаньоне правила `component-structure` — «константа рядом с классом», — поэтому вопрос
владельцу не пошёл, а строка принята с причиной. Место остаётся тем, где проверка права по
букве и не права по существу.

**Прогон снимков поймал настоящую поломку правки, которой не видела ни одна другая проверка.**
Обвязка витрины идёт голым узлом: импорт без расширения `.ts` не разрешается вовсе, и все 447
эталонов при этом числились осиротевшими. Сборка витрины, типы, линт и юниты при этом были
зелёными.

## Чем кончилось

Долг повторов пуст: из 26 десять сняты правкой кода, шестнадцать приняты с причиной. Новый
повтор любого рода теперь отбивает пуш.

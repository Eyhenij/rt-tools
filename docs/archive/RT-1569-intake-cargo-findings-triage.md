# RT-1569 — находки эпика о памяти приёма разобраны

**Ветка:** `RT-1569-intake-cargo-findings-triage` · **Заявка:** #PR · **Разобрано:** 2026-08-29

## Что было не так

Эпик #1198 кончается, когда в файлах находок не остаётся неразобранных пунктов. Файл эпика
RT-907 стоял непустым: двадцать пунктов от восьми задач, каждый — промах, замеченный работой и
оставленный текстом.

## Что сделано

Десять пунктов оказались закрытыми правками, доехавшими раньше: пропуск проверки объявляется
кодом возврата, оставшийся шаг стоит в теле заявки с минуты открытия, очередь конвейера
разобрана ловушкой, предел длины срабатывает при росте текста, свободный номер сценария ищется
во всех ветках, спек меряется длиной при вливании, вход в состояние разбора назван двумя
признаками, выемка путей отбрасывает тела документов, компаньон называет команды этого дерева,
сторона обмена, которой нет, называется прямо.

Десять внесены правкой той же задачей:

- четыре ловушки правила ведения работы — имя проекта в признаке этапа, этап без пуша, признак
  закрытия, требующий человека, признак закрытия по ответу вызова вместо хранящей стороны;
- ловушка правила поставки — вывод команды, которой нужен репозиторий, собирается в дереве:
  перенаправление создаёт файл раньше, чем команда успевает отказать;
- два места в паттерне заведения правила — проза в строке требования и дословный вердикт пустой
  привязки;
- раздел паттерна сквозных спек — состояние экрана после действия ждётся опросом;
- статья правила об устройстве кода — значение берётся у той стороны обмена, что его объявила;
- ловушка компаньона правила о договорённости — строка таблицы читается сверкой как процедура.

## Чем это подтверждено

`agent-kit:sync` разложил правленые файлы без отказа, `check-file-size` — 1465 файлов, долг 0,
`check:docs` — 439 документов, `check:specs` без расхождений. Пунктов в файле находок — ноль.

## Что осталось открытым

Два файла находок — разбора находок и правил приёмника — к этому эпику не относятся и
разбираются своей задачей.

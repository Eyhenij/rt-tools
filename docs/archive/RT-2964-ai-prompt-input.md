# RT-2964 — поле ввода ИИ-чата со строкой действий и кольцом расхода

Ветка `RT-2964-ai-prompt-input`, стоит на ветке RT-2962. Папка задачи разобрана в эту запись.

## Просьба владельца

> окей, делай этот компонент в ui kit v2, и бери в работу задачи по тем проблемам что ты заводил
> ранее.

> давай пожалуйста закончим эти правки и изменения, этого очень ждут на проде

Сказано 28.10.2026 в сессии VillaManager после утверждения макета. Макет лежит в Design System V2:
страница AI Prompt Input, наборы AI Prompt Input и Usage Ring. О подсказке владелец сказал так:
«показывай "Ассистент может ошибаться." под или над композером».

## Что было

- `rt-ai-chat` брал поле переписки с людьми: капсула, без модели, усилия, режима и расхода.

## Решения

- **Поле ввода ИИ-чата заведено своим компонентом `rt-ai-prompt-input` основного входа.** Поле
  переписки с людьми `rt-message-composer` осталось прежним.
- **Модель, усилие и режим кит показывает подписью и сообщает о нажатии.** Список моделей и
  усилий знает приложение.
- **Кольцо расхода `rt-usage-ring` стало отдельным компонентом.** С 80 % дуга оранжевая, текст
  подсказки даёт приложение.
- **Голоса в поле нет.** В макете он выключен по умолчанию, а значка микрофона в ките нет.

## Чем подтверждено

- Сценарии SC-UKV-1045…1050. Набор кита на вершине цепочки: lint, typecheck, test, build и verify
  `@rt-tools/ui-kit-v2` с выходом 0, тесты 3326 из 3326.
- `lint:styles` и `check:tokens-styles` без находок.

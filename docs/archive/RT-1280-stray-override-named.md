# RT-1280 — надстройка, не подобранная ни к одному ресурсу

Задача RT-1280, заявки нет — ветка осталась местной. День работы: 27 августа 2026.

## Разбор просьбы

Одна запись груза от соседнего дерева о раскладке. Владелец разбора не вёл: заход шёл сам,
задачи брались из приёма одна за другой.

Надстройка правила лежала под именем без приставки свойства, а идентификатор ресурса у пакета её
несёт. Такая надстройка не привязывается ни к чему: раскладка молча положила пакетный текст, и
разложенное правило двое суток говорило о дереве неправду — тридцать пять строк своей редакции до
него не доехало. Сверка этого не видит и видеть не может: она сравнивает разложенное с тем, что
собирает сама, а неподобранное в сборку не берёт — обе стороны сходятся.

## Что решено

Раскладка перечисляет такие файлы строкой предупреждения: имя и слово о том, что применены они не
были. Строка печатается на любом исходе, в том числе на сошедшемся дереве, и расхождением не
считается.

Решение по ходу, которого в записи не было: файл вне рода ресурсов надстройкой не считается
вовсе. Первый же прогон назвал неприменённым README каталога надстроек — он лежит там законно, и
строка о нём приходила бы при каждой раскладке.

Сценарий SC-AK-730, две спеки при нём.

## Цена

Запись груза отмечена не была: токен дерева двигает только свои записи, а эта приехала от
соседа. Следующий разбор увидит её новой.

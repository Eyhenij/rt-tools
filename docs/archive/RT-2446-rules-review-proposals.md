# RT-2446 — предложения по правилам после эпика RT-2370

**Ветка:** `RT-2446-rules-review-proposals` (от main, вне эпика по слову владельца) · **Разобрано:** 2026-10-01

## Просьба владельца

> применяй предложения по правилам

Предложения принесли разборы задач эпика RT-2370 (RT-2373, RT-2366, RT-2365, RT-2367, RT-2364,
RT-2398, RT-2399) и разбор промаха с правкой коммита в обход хуков.

## Решения и куда они ушли

- **Правила дерева дополнены.** Порядок проверки компонента, подсказка от фокуса, эталон, который
  сквозной набор пишет сам при первом прогоне, шрифт без полужирного начертания, шрифты в `play`,
  пара тем, проверка графа токенов, точечная пересъёмка. Ушло в правила ui-component-tests,
  rt-tools-storybook, rt-tools-styling, ui-component-tests-visual и в компаньоны testing и
  spec-driven.
- **Правила пакета дополнены.** Имя со слешем, которое не путь, пишется без обратных кавычек
  (doc-style); свободный номер сценария спрашивается у команды (spec-driven); счёт ответов
  «рекомендовано» идёт по всей сессии (task-flow-start); действие, добавляющее узел, делается
  дважды, а лимит на адрес считает весь набор одним клиентом (testing-e2e); правка последнего
  коммита проходит хуки (git-workflow-commit).
- **Новая проверка в пакете запрещает коммит и отправку в обход хуков.** Обхода у неё нет. Описана
  подобластью `docs/specs/agent-kit/no-verify-guard/`. Отвергнуто: строка обхода с причиной —
  владелец запретил пропуск проверок для любой правки.
- **Три текста сжаты под лимит размера.** Из правил ui-component-tests, rt-tools-storybook и шаблона
  task-flow-start убраны доводы и история случаев; требования остались.
- **Просроченные записи архива убраны в этой ветке.** Слово владельца: «Коммитом в RT-2446».
- **Команда номера сценария читает номера любой длины.** Она обрезала их до трёх цифр и предлагала
  занятый номер.

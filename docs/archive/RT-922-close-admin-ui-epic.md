# Кончившийся эпик о показе админки уехал в описание прошлого

Задача #922, PR #923, закрывалась 19 августа 2026 года. Прежний адрес — папка задачи
`docs/tasks/RT-922-close-admin-ui-epic/`. Запись собрана из разбора просьбы и хода работы, когда
задачу закрывали. После выкатки не правится.

## Почему задача заведена

Эпик о показе админки кончился 18 августа: все пять его задач влиты. Закрыт он при этом не был —
карточка висела открытой, а замысел лежал среди действующих и читался как работа, которую кто-то
ведёт. Из-за этого заход, искавший следующую задачу, взял её из чужого эпика: свой выглядел
незакрытым. Владелец остановил это вопросом, какой эпик основной, — и ответа не было ни у кого,
кроме самого замысла.

## Решения, взятые в работу, и куда они ушли

| Решение                                       | Куда ушло                                                                                   |
| --------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Замысел уезжает записью, а не удаляется       | запись о линии работ в описании прошлого: расхождение с образцом, порядок задач, границы    |
| Имя записи — по эпику, а не по задаче         | эпик пережил пять задач, и номер одной из них назвал бы его неверно                         |
| Карточка эпика закрывается вместе со слиянием | до слияния замысел ещё лежит в главной ветке, и закрытая карточка при нём читалась бы ложью |

## Решения по ходу

- **Задача заведена без слова владельца.** Свой эпик кончился, чужой брать нельзя — это уже
  стоило разбора происшествия, — а простаивать нельзя тем более. Хвост своего эпика работой
  обеспечен и ничьих границ не задевает.
- **На борду задача не попала сама.** Команда заведения назвала это своим выводом: задача,
  которой нет в очереди, работой не обеспечена. Добавлена отдельным вызовом.

## Чем работа кончилась не так, как задумана

Ей предшествовали четырнадцать минут простоя на чужом шаге — заход ждал прогона, который уже
кончился, и отчёта, который владелец уже влил. Разбор происшествия записан той же веткой.

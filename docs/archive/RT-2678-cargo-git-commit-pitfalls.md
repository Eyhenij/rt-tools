## What the tree already has

- Правило о поставке говорит, когда правку отдают человеку, но не говорит, когда коммит готов.
- Образец коммита называет формат заголовка и молчит о файлах отбитого коммита в цепочке.
- Образец тела PR даёт команду чтения меток через `join(",")` и не говорит, как передать их по
  одной.
- Холодная часть правила о поставке на GitHub держит 23 544 знака при пределе 24 000.

## Decisions

  правила стоит у предела.

# Шторка не закрывается по Esc, источники закрытия называет потребитель

Задача #126, отчёт #934, закрывалась 20 августа 2026 года. Запись собрана из решений по ходу,
когда задачу закрывали. После выкатки не правится. Прежний адрес —
`docs/tasks/RT-126-aside-keeps-open-on-esc/`.

## Просьба владельца

Задача заведена карточкой в очереди работ, тело пустое:

> [RT-126] Avoid close side menu on keydown esc

Разбор просьбы остался незаполненным: работа шла заходом, которому владелец назначил
работать самостоятельно и вопросов не задавать.

## Решения по ходу

- **Умолчание — Esc не закрывает.** Так стоит в самой просьбе. Прежнее поведение осталось
  доступным настройкой открытия. Отвергнуто: оставить умолчание прежним и завести
  выключатель — тогда просьба не исполнена нигде, кроме тех мест, которые кто-то
  перенастроит.
- **Приём взят у второго кита.** Там шторка уже принимает настройку закрытия и подписывается
  на нажатия условно, отдавая пустой поток при запрете. Своё третье решение разошлось бы с
  ним молча.
- **Ветка держалась локально, пока владелец не снял запрет на пуш.**

## Куда уехали решения

- Договорённость осталась в `docs/specs/ui-kit/proposed/aside-close-config/`: домен первого
  кита заводится словом владельца, и оно сказано отдельной задачей — вливание идёт там.

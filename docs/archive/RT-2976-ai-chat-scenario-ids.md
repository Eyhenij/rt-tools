# RT-2976 — сценарии ИИ-чата второго кита на свободных номерах

Ветка `RT-2976-ai-chat-scenario-ids`, отведена от `RT-2972-kit2-footer-references` каскадом. Папка
задачи разобрана в эту запись.

## Просьба владельца

> RT-2972 сейчас, потом RT-2965 (Recommended)

Владелец велел довести RT-2965 до PR. После слияния #2973 (эпик RT-2958) main перестал проходить
проверку спек, и push любой ветки от main останавливался.

## Что было

- `node tools/check-specs.mjs` давал 7 расхождений. Сценарии ИИ-чата `SC-UKV-1040`…`SC-UKV-1046`
  повторяли номера, которые раньше заняли сценарии панели (RT-2957) и словаря формы (RT-2955).

## Решения

- **Перенесены номера, выданные позже**: 1040→1051, 1041→1052, 1042→1053, 1043→1054, 1044→1055,
  1045→1056, 1046→1057. Сессия RT-2957 подтвердила, что номера панели остаются, а номера ИИ-чата
  никто не чинит. Свободный номер выдал `npm run spec:next-id -- UKV`.

## Чем подтверждено

- `node tools/check-specs.mjs` — без расхождений.
- Тесты `@rt-tools/ui-kit-v2` без кэша: 3332 из 3332.

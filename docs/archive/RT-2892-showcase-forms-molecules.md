# Разбор

## Просьба владельца

> бери в работу эпик с правками по сторибуку

Задача первая из трёх в эпике RT-2896. Текст задачи #2892 написан стороной приложения: перенести
семь историй полей формы из организмов в молекулы, переименовать их снимки сравнения вида, деревья
оставить в организмах.

## Решения

- **Семь историй стоят в Molecules/Forms:** DateRange, DateRangePanel, ColorPalette,
  DynamicSelector, TreeSelector, HybridTreeSelector и ImageUpload. Отдельную группу для загрузки
  картинки не заводили: задача называет одну группу на все семь.
- **Снимки переименованы через `git mv`, а не сняты заново.** Вид не менялся, а новая съёмка
  скрыла бы настоящее расхождение. Переименовано 53 файла.
- **В правило сборника добавлено исключение для полей формы.** Статья об уровне относила к
  организмам всё, что открывает панель. Но `Select`, `DatePicker`, `Autocomplete` и `Multiselect`
  с панелями уже стояли в молекулах. Теперь статья говорит: поле формы со своей панелью выбора
  остаётся молекулой. Чтобы файл правила не превысил лимит размера, сокращено обоснование соседней
  фразы.
- **Два снимка PdfViewer сняты заново в этой ветке.** В `main` кнопка «По ширине» стала показывать
  нажатие (#2888), а снимки остались старыми. Проверка снимков не пускала отправку. Новый вид
  правильный.

## Что подтверждено

Поиск старых заголовков и адресов в `projects/ui-kit-v2/src` пуст. 53 снимка носят имена
`molecules-forms-…`. Отправка прошла полный набор проверок, в нём проверка снимков витрины без
сирот и без расхождений.

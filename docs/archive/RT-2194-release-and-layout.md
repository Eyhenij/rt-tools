# RT-2194 — своя проверка дерева и переопределение сняты; издание ставит конвейер публикации

**Ветка:** `RT-2194-release-and-layout` (от `RT-2193-end-conversation-guard`) · **Разобрано:** 2026-09-17

## Просьба владельца

> бери в работу изменения по остановке работ прямо сейчас, заводи новый эпик и бери в работу, эпик по над которым ты работал ранее пока откладываем

Четвёртая, последняя задача эпика RT-2190.

## Что было не так

После правок пакета дерево держало бы переопределение о ходе и свою проверку конца хода рядом с
пакетными: два текста об одном. Оба лежали в ветке RT-2187 с открытым PR #2189 в main.

## Ответы владельца

Владелец ответил указанием на весь эпик; отдельных вопросов задача не открывала.

## Решения

- **Версию и установку издания задача не делает** — конвейер публикации сам поднимает версию,
  ведёт журнал, устанавливает издание в дерево и коммитит одним коммитом в main. Шаг владельца
  после слияния эпика: запустить конвейер в браузере с подъёмом младшей версии.
- **Ветка RT-2187 влита сюда, и её файлы сняты здесь же** — снятие не ждёт слияния #2189; влит он
  или нет, после слияния эпика в main двух текстов об одном не остаётся. Запись о RT-2187 в
  описании прошлого сохранена. Конфликт в установленной копии правила о ходе решён в пользу
  копии из пакета.
- **Таблица эпика называет состояние словами** — аудит доски читает номер с решёткой в плане как
  задачу эпика.
- **CI у #2189 перезапущен** — упал на обрыве сети к базе на шаге о миграциях, не на правке.

## Цена

Задача RT-2187 задержалась в колонке «в работе» при открытом PR; переведена в обзор здесь.

## Что осталось

Шаг владельца: влить PR задач в ветку эпика по порядку (#2200, #2204, #2207, затем PR этой
задачи), открыть и влить PR эпика в main, запустить конвейер публикации пакета правил. PR #2189
после этого закрыть без слияния или влить — итог в main один. Запрет на закрытие разговора в
настройках одной машины снимается по решению владельца после установки издания.

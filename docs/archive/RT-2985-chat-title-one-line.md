# RT-2985 — заголовок шапки чата держится одной строкой

Ветка `RT-2985-chat-title-one-line` от `main`. Папка задачи разобрана в эту запись.

## Просьба владельца

> привести к макетам страницу переписок в приложении

Сказано 28.10.2026. Шапка разговора по макету несёт номер и имя гостя. Длинное имя ломало шапку на
узком экране, и без правки кита страницу по макету не собрать.

## Что было

- Заголовок `rt-chat` переносился по словам. Шапка — плотная полоса постоянной высоты 56.
- На ширине 375 заголовок «№1287 Александра Константинопольская-Вознесенская» занимал четыре
  строки. Текст выходил из полосы вверх и вниз: на кнопки над шапкой и на первое сообщение ленты.

## Решения

- **Заголовок режется многоточием в одну строку.** Так уже устроена строка под ним.
- **Целиком заголовок виден в подсказке `rtTooltip` с признаком `rtTooltipWhenTruncated`.**
  Подсказка появляется только у обрезанного заголовка.
- **Кадры витрины не пересняты.** В витрине заголовки короткие, их вид не меняется.

## Чем подтверждено

- Сценарий SC-UKV-1064: тест `rt-chat` читает подсказку и стили заголовка, 25 из 25.
- Одна строка измерена на экране приложения-потребителя на ширинах 375…1440.
- `npm run check:specs`: расхождения SC-UKV-1040…1046 лежат на `main`, по этой правке замечаний нет.

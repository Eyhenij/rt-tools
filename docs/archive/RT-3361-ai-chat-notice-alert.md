# RT-3361 — плашка notice в ленте ответа не перебивает диктор

Задача RT-3361 эпика RT-3346, ветка `RT-3361-ai-chat-notice-alert` от ветки эпика, 17.11.2026.
Бывший адрес — папка задачи `docs/tasks/RT-3361-ai-chat-notice-alert/`. Правило вошло в описание
`docs/specs/ui-kit-v2/ai-chat/`, вход `live` — в `Overview.mdx` и `CONTEXT.md` компонента
`rt-message`.

## Просьба

> Делай эпик дальше

Задача заведена по находке второго круга ревью RT-3334. Плашка `notice` в ленте ответа рисуется
через `rt-message` с `role="alert"`, и диктор прерывает чтение на каждой такой плашке.

## Что было в дереве

- `rt-message.component.html` ставил `role="alert"` на `aside` всегда.
- Блоки ответа рисуют `notice` через `rt-message` с `severity`.

## Решения

- **Вход `live` у `rt-message`, а не своя разметка в чате.** Своя разметка с ролью обошла бы готовый
  компонент кита.
- **По умолчанию `alert`.** Вне чата плашка остаётся срочной, как была.
- **Сценарий один, SC-UKV-1329 — плашка в ленте.** У `rt-message` нет своего спека, его тесты идут
  без номеров; вход `live` проверен тестом `rt-message` без номера. Номер SC-UKV-1330 не занят.

# RT-2507 — линтер стилей отстал на мажор: stylelint 16 → 17

**Ветка:** `RT-2507-stylelint-17` (вне эпика, четвёртый мажор из списка RT-2081) ·
**Разобрано:** 2026-10-03

## Просьба владельца

> обнови npm пакеты

Мажоры этой просьбы вынесены в список RT-2081, по задаче на мажор. RT-2507 взята за RT-2505.

## Решения

- **stylelint 17.15.0, а не 17.16.0:** последняя вышла 1 октября и ещё ждёт срока. Вместе с ним
  `stylelint-config-standard` 40.0.0 и `stylelint-scss` 7.3.0. До этого набор был собран
  вразнобой: `stylelint-config-standard-scss` 17.0.0 уже требовал stylelint 17.
- **Свои правила дерева остались на CommonJS.** stylelint 17 их грузит, и оба срабатывают:
  `color: #fff` в первом ките запрещает `rt-tools/no-hardcoded-design-tokens`, `:host` во втором
  ките — `rt-tools/no-host-selector`. Перевод на модули не понадобился.
- **Первая проба легла не туда.** Файл с `color: #fff` во втором ките поймал только порядок
  свойств: правило токенов в настройке включено только для первого кита. Проба повторена по
  верному пути.

## Проверки

- `pnpm run lint:styles` — зелёный, без находок.
- `pnpm run check:tokens-styles` — новых значений нет.

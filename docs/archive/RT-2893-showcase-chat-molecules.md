# Разбор

## Просьба владельца

> бери в работу эпик с правками по сторибуку

Задача вторая из трёх в эпике RT-2896. Текст задачи #2893 написан стороной приложения: перенести
поле сообщения и редактор текста из организмов в Molecules/Chat, переименовать их снимки, а Chat,
AiChat, ThreadList и Timeline оставить в организмах.

## Решения

- **Обе истории стоят в Molecules/Chat.** Правило сборника не менялось: исключение для поля формы
  из RT-2892 уже покрывает поле ввода с кнопками.
- **Ссылки исправлены и на соседних страницах описания:** чат, многострочное поле и показ текста
  ссылались на старые адреса.
- **13 снимков переименованы через `git mv`, а не сняты заново.** Вид не менялся.

## Что подтверждено

Поиск старых заголовков и адресов в `projects/ui-kit-v2/src` пуст. 13 снимков носят имена
`molecules-chat-…`. Отправка прошла полный набор проверок со второго раза. В первый раз упал
один сквозной тест панели администратора: отбор по версии выпуска, таблица разборов не
появилась за 10 секунд. Эта ветка код панели не трогает.

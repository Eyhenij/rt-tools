# RT-3188 — степпер второго кита: любой шаг, узкая полоса, свои цвета

Задача RT-3188, ветка `RT-3188-stepper-any-step` от `main`, работа вне эпика по слову владельца.
Папка задачи `docs/tasks/RT-3188-stepper-any-step/` разобрана в эту запись.

## Просьба владельца

Передана сессией приложения, решение владельца: «расширить Stepper в ките, сделать его
универсальным и сохранить вид и значения по умолчанию».

> Макет: любое число шагов (хотя бы 2–7) и любой текущий шаг. Полоса тянется по ширине родителя
> (FILL) от 280 до любой ширины. Подпись у края не выходит за полосу. Нынешний вид — 4 шага, текущий
> второй, ширина 480, цвета `stepper/*` — остаётся вариантом по умолчанию. Код `rt-stepper`:
> произвольные `steps` и `currentIndex`, тянется по ширине контейнера, подпись у краёв не выходит за
> пределы. Входы и умолчания прежние. Сторис на каждое новое состояние: 3 из 4, 5 шагов, ширина 327,
> первый и последний шаг с длинной подписью.

По ходу владелец добавил: «на макетах нет вертикального режима степера», «добавь бг есть не на всех
макетах», «добавь токены для стилей чтобы можно было переопределять цвета». Строку назначения копии
разрешил словами «Разрешаю вписать».

## Решения по ходу

- **Подпись среднего шага стоит в отрезке с центром над точкой и переносится в нём.** Figma не
  умеет сдвигать текст к краю по его ширине, код повторяет макет. Цена: при 7 шагах на 327 подпись
  второго шага в две строки. Правило — в спеке `docs/specs/ui-kit-v2/stepper/`.
- **Строка подписи 18 px, как в Figma, вместо 12 в коде.** Иначе перенесённая подпись налезает на
  себя. В коде буквы подписи опустились на 3 px.
- **Подпись варианта по умолчанию в макете сдвинута на 23 px к точке.** Старый макет расходился с
  кодом, код центрировал по точке.
- **Просвет 5 px под подписью — часть полосы высотой 21 px.** Шага 5 px в шкале нет, проверка
  токенов отклонила `gap: 5px`; пиксели те же.
- **Цвета — ручки потребителя `--rt-stepper-*`, на хосте не объявляются.** Объявление на хосте
  перебивало значение с родителя — витрина это показала. Умолчание — запасное значение с токеном
  темы; имена — в перечне ручек и в `Theming.mdx`.
- **Вертикальный режим нарисован в Figma без правки кода:** набор `Stepper step` и компонент
  `Stepper vertical` по коду и снимку витрины.

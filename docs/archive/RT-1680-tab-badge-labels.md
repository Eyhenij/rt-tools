# RT-1680 — метка вкладки не имела ни подсказки, ни подписи для чтения с экрана

**Ветка:** `RT-1680-tab-badge-labels` · **Разобрано:** 2026-09-06

## Что было не так

Метка вкладки `[rtTab] [badge]` рисовалась голым значением внутри кнопки: человек видел точку
или число и не знал, что они значат, а чтение с экрана озвучивало только название вкладки.
Подсказка кнопки занята неверной вкладкой, и отдать через неё свой текст приложение не могло.
Обход — нарисовать метку своей разметкой через `titleTemplate` — разводил вид метки по
приложениям.

Заведена приложением-потребителем 2026-09-02; взята из очереди работ после того, как долги
приёмника, доступные из дерева, кончились.

## Что сделано

- Два необязательных входа у `[rtTab]`: `badgeTitle` — подсказка при наведении на метку,
  `badgeAriaLabel` — подпись метки для чтения с экрана. Кит ставит их на узел метки сам;
  незаданные — разметка прежняя.
- Три случая в спеке компонента: без входов метка голая и подсказки не показывает; подпись
  становится `aria-label`; подсказка показывается при наведении на метку.
- `CONTEXT.md`, история витрины и её обёртка называют новые входы.

## Решения

- **Два входа, а не один.** Подсказку читают глазами, подпись озвучивает чтение с экрана, и
  текст у них бывает разный.
- **Подсказка на самой метке, а не на кнопке.** Подсказка кнопки занята неверной вкладкой, и
  заменять её значило бы прятать ошибку за счётчиком.
- **Метка остаётся в одну строку разметки.** Перенос внутри тега добавляет пробел в текст
  кнопки и меняет её текстовое имя; форматтер эту строку не трогает.

## Цена решения

Подпись метки и её значение читаются вместе с названием вкладки как одно имя кнопки: отдельного
узла для чтения с экрана у метки нет.

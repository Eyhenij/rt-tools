# RT-3095 — диспетчер сводит ответы нескольких сторожей в один JSON

Задача RT-3095, ветка `RT-3095-dispatch-one-json` от ветки `RT-3096-plugin-browser-drivers`,
работа вне эпика по слову владельца. Папка задачи `docs/tasks/RT-3095-dispatch-one-json/`
разобрана в эту запись.

## Просьба владельца

> бери

Сказано на предложение взять RT-3095 из трёх задач вне эпиков. В очереди задача звучит так:
когда на одно событие отвечают несколько сторожей, диспетчер склеивает их вывод через перевод
строки. Несколько объектов подряд уже не один JSON, и агент читает их сырым текстом. В дереве,
которое ставит пакет, вход в сессию дал три объекта и простой текст, разбор упал на `Extra data`,
и законы, словарь и передача дел пришли обрезанными.

## Решения по ходу

- **Один ответ выходит как есть.** Сводить нужно только несколько, а единственный ответ остаётся
  ровно тем, что напечатал сторож.
- **Простой текст уходит в контекст события, объекты сводятся по полям.** Тексты
  `additionalContext` и `systemMessage` соединяются пустой строкой, остальные поля берутся в
  порядке веток.
- **Событие без поля контекста кладёт текст в системное сообщение.** Конец хода и сжатие поля
  `additionalContext` не принимают.
- **Без разборщика остаётся прежний склеенный вывод.** Молчание потеряло бы подсказки совсем.

## Проверено

- Набор диспетчера: 44 проверки, 0 провалов; три строки SC-AK-1260 падали до правки.
- Настоящий вход в сессию этого дерева через разложенный диспетчер — один объект на 31 КБ.
- Разложенные копии сходятся с пакетом v0.33.1.

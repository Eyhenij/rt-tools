## Decisions

- **Одна статья в doc-style, ссылки на неё из testing и component-structure** — требование одно
  для всех проверок, а три копии разойдутся при первой правке. Отвергнуто: три отдельные статьи.
- **Точка перед `**` закрывает предложение** — правится проверка, а не статьи. Отвергнуто:
  укорачивать статьи под ошибку подсчёта.
- **Откат Red-Green — инструментом правки, затем `git diff`** — уходит в ту же статью
  testing. Отвергнуто: своя задача на одну строку.

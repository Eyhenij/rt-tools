# Проба и протухшая витрина

Задача RT-1968 · ветка `RT-1968-window-probe-navigation-race`

## Разбор просьбы

Отдельной просьбы владельца не было. Работа заведена по отказу, который поймал гейт пуша: проба
подгонки окна отбила пуш, за который дереву нечем было отвечать. Отказ выглядел так:

```
locator.waitFor: Timeout 30000ms exceeded.
  - waiting for locator('[data-story-root]').first() to be visible
    18 x waiting for ".../iframe.html?id=atoms-icon--social&viewMode=story" navigation to finish...
```

## Решения по ходу и доводы

- **Название задачи оказалось неверным, и это выяснилось замером.** Заводя её, я считал отказ
  гонкой с навигацией витрины: страница дописывает к адресу решётку, и ожидание узла проигрывает
  этой навигации. Пять прогонов пробы по витрине на порту 6007 дали пять отказов, три прогона по
  свежей витрине на порту 6017 — три зелёных. Гонки нет: отказ приходит по состоянию витрины, а
  не по случаю.

- **Витрина протухает сама.** Страница истории висела на подготовке, её горячее обновление
  отвечало четырёхсотым на `runtime_main.<хеш>.hot-update.json`, корней показа на странице ноль.
  В дереве при этом не было сломано ничего: свежая витрина отдавала ту же историю без единой
  ошибки в консоли. Отдельная задача — RT-1970.

- **Отвергнуто: менять приём ожидания на `page.waitForSelector`.** Это был первоначальный замысел,
  снятый с соседней пробы значков. Он лечил бы название болезни, а не болезнь: на той же
  протухшей витрине соседняя проба упёрлась бы ровно так же — корня на странице нет вовсе.

- **Чинится речь пробы, а не её ожидание.** Проба обязана отличать «станок сломан» от «витрина не
  отдаёт историю». Отказ теперь называет адрес, счёт корней показа, застряла ли история на
  подготовке и какие запросы витрина отбила. Отказ, который не про истёкшее ожидание, приём не
  глотает: он ушёл бы читателя не туда.

- **Общий модуль не забрал загрузку драйвера браузера.** Своя копия этого приёма лежит в четырёх
  пробах дерева, и пятая была бы новой копией, а не снятой. Отдельная задача — RT-1971.

- **Проба рисования первого кита не тронута.** Ждёт она не корень показа, а свою проверку, и
  общий приём ей не подходит без переделки.

- **Приёмка отказного пути взята не на той витрине, что записана в плане.** Витрина на порту 6007
  ожила сама, пока шла работа, и отказ на ней больше не воспроизводился. Путь снят на заведомо
  пустой странице, поднятой на свободном порту.

- **Статья в правило проверки компонентов не влезала по весу.** Три довода из соседних статей
  ушли в холодную часть, сами статьи сжаты до утверждения с границей. Предел веса — двадцать
  четыре тысячи знаков — держит `tools/check-file-size.mjs`.

## Чем закрыто

Набор `tools/tests/showcase-probe.test.sh` — десять исходов на подменённой странице, без
браузера. На нарочно сломанной копии модуля он краснеет двумя исходами из десяти. Сценарий
`SC-UKV-132` в спеке снимков второго кита.

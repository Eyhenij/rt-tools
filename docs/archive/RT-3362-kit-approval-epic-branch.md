## Вопросы и ответы

Вопрос «задача от main или задача эпика» закрыт допущением: перед ним владелец два раза подряд взял
рекомендованный вариант. Взята рекомендованная: отдельная задача от `main`, потому что та же
проверка встанет у каждого эпика с правками кита.

## Решения

- **У ветки без своей записи правку из слияния PR с `[RT-<номер>]` в теме судит запись задачи.**
  Так уже работал режим выпуска; поиск записи вынесен в общую функцию.
- **Слияние `main` не судится.** Его правки уже в `main` и судились там.
- **Слияние без номера задачи в теме отвечает как коммит самой ветки.** Иначе локальное слияние
  ветки задачи проходило бы без записи.

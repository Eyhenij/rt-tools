Задача RT-3666 эпика RT-3603, запись от 2026-11-25. Прежний адрес: `docs/tasks/RT-3666-task-flow-plan-impl-stale/`.

## Просьба владельца

Задача вышла из шага, который владелец велел сделать: довести эпик RT-3603 до главной ветки и выпуска кита. Ответ
владельца в меню 25.11 о последней задаче эпика — «Отложить RT-3656», вариант «Эпик идёт в main и в выпуск без неё».

## Что решили при разборе

- **Меняется конец строки 22 `.claude/skills/task-flow-plan/implementation.md`.** Строка говорила, что код с
  «Решением» ничто не сравнивает; с RT-3611 это делает `tools/task-flow/measure/design.mjs:held` в конце этапов.
  Поиск по правилам, спекам, законам и ресурсам пакета других таких строк не нашёл.

## Что решили по ходу

- **Первый круг: границы `held` пересказаны неточно.** «Решения нет» судится, двоичный файл пропускается только в
  бюджете строк, связи не судятся, когда команда зацепления не ответила или не посчитала.
- **Второй круг: ссылка вела на неверный текст.** Строка 31 `.claude/skills/code-design/implementation.md` (из RT-3664)
  говорила, что любое расхождение `held` снимается строкой решений. Отказ команды зацепления строкой решений не
  снимается; строка поправлена в этой ветке, потому что на неё ссылается правка задачи.

## Цена

- Две строки текста прошли два круга ревью тремя ролями; оба круга нашли неточности в пересказе кода. Признаки
  `grep` судят слова, а не смысл: смысл каждый раз проверяли роли пробами `held`.
- RT-3664 оставила в строке 31 неточность, которую нашёл только второй круг этой задачи.

# RT-2928 — три проверки пакета по записям приёмника

Задача эпика RT-2922. Ветка `RT-2928-cargo-checks`, папка задачи разобрана в эту запись.

## Просьба владельца

> разбери всё новое что есть в приёмнике

Ответ в меню об объёме: «Разобрать все 31 (Recommended)». Слово на эпик: «бери RT-2922».

## Записи приёмника, которые закрывает задача

- `92055fbd-4c25-41a2-8b53-79b7dd8cb5f1` — предложение к `hooks/grill-gate.sh`: список вариантов
  после отбитого меню считается вопросом.
- `06aa3895-e78d-4974-bba5-d1aedd158c47` — разбор: после отказа меню вопрос ушёл прозой.
- `a5a75cad-9403-460b-8ff0-3b1f06676efe` — разбор: отправка пересоздала ветку влитой заявки.
- `2e8e8224-d3b9-44e3-a2bd-da76d02785a3` — разбор: исполнитель встал на отказе назначений после
  прямого поручения владельца.

Записи чужие. Свой токен их не двигает, поэтому их закрывает публикующий командой `cargo:close` в
состояние «исправлено» после слияния эпика в главную ветку. Этот шаг записан в плане эпика.

## Что сделано

- Проверка вопросов: в ходе с отбитым меню нумерованный список из двух и более пунктов под строкой с
  двоеточием тоже вопрос. Отказ меню говорит, что проза его не обходит. Сценарий SC-AK-1231.
- Отказ назначений во всех четырёх видах говорит: сообщение владельца, которое называет эту работу,
  и есть перенос назначения. Сценарий SC-AK-1232.
- Гард поставки отбивает отправку в ветку, у которой есть влитая заявка и нет открытой. Сценарий
  SC-AK-1233, описание — раздел `docs/specs/agent-kit/delivery-merged/`.

## Решения

- **Список вариантов судится только в ходе с отбитым меню.** Предложение просило признак шире. Но
  список под двоеточием стоит во многих обычных отчётах, и отказ на каждом учил бы убирать списки.
- **Отказ отправки требует двух признаков: влитой заявки и отсутствия открытой.** Ветка, открытая
  новой заявкой после слияния, — законная работа.
- **Новые признаки вынесены в свои файлы.** Проверка вопросов дошла до 511 строк, её набор — до 520,
  описание поставки — до 502, умолчания профиля — до 513 при пределе 500. Отсюда
  `grill-gate-options.sh`, `grill-gate-options.test.sh`, раздел `delivery-merged` и функция хоста
  рядом с проверкой отправки.
- **Правило `task-flow` не правилось.** Его статья уже говорит «до слова владельца», а само правило
  стоит на 23 975 знаках из 24 000. Слово владельца теперь называет текст отказа.
- **Журнал изменений руками не писался.** Его собирает выпуск из заголовков коммитов.
- **Раскладка проверена на живом хосте.** `node tools/board.mjs merged` ответил 2925 для RT-2924 и
  null для RT-2928. Разложенный гард поставки отбил отправку в RT-2924 и пропустил RT-2928.

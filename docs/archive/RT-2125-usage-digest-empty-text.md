# RT-2125 — пустые списки сводки раздела «Использование» говорят по-русски

**Ветка:** `RT-2125-usage-digest-empty-text` · **Разобрано:** 2026-09-15 · эпик RT-2097, задача 7 — найдена при показе быстрого периода RT-2115

## Просьба владельца

Своих слов у задачи нет: она закрывает пробел в ответе на просьбу о графиках из RT-2115 — за период без строк три списка сводки показывали английское «No data yet».

## Что сделано

- Списки загрузок за пустой период говорят «За период загрузок не было», список отказов — «За период отказов не было». Слова — в словаре админки, список кита получает их входом `emptyText`.
- Русский словарь кита получает слово `uiNoData`: другие списки со шкалой в админке тоже не говорят по-английски.
- Правило описания поддомена называет текст пустого списка; сцена SC-MB-358 проверяет оба текста.

## Умолчания вместо вопросов

- **У списка отказов своё слово.** Список без отказов — хорошая новость, и «загрузок не было» под ним читалось бы как ошибка.
- **Английское умолчание кита не трогается.** Кит везёт восемь языков, а админка выбирает свой словарём.

# RT-3352 — согласие владельца на замену проверки и на шаг владельца даётся окном

Задача RT-3352, запись от 2026-11-19.

## Просьба владельца

> продолжай работу по эпику

Постоянное указание владельца по эпику RT-3302. Карточку завела роль `goal-critic` при разборе
плана RT-3271: движок хода работы в двух местах искал слова владельца в записи разговора.

## Что нашли

- Замена проверки шага засчитывалась, только если цитата из строки замены стояла в сообщении,
  которое владелец набрал сам. Ответ в меню или на другой машине не находился, и шаг стоял.
- Строка плана эпика «шаг владельца «…»» блокировала задачу, только если владелец набрал цитату.
  Пока не набрал, замер `ownerStep` заставлял проверку выхода из хода показывать меню.
- В RT-3271 уже было окно «разрешить / запретить»: проверка возвращает решение `ask` из таблицы
  решений.

## Что сделано

- Правка хода работы, которая добавляет или меняет строку замены проверки, получает окно. Правка
  плана эпика, которая ставит или меняет «шаг владельца», тоже. Удаление строки замены и снятие
  шага владельца окна не требуют.
- Движок цитат не ищет: строка замены засчитывается как написана, строка шага владельца блокирует
  задачу. Старая форма строки с цитатой читается, цитата не проверяется.
- Замер `ownerStep` и его причина меню убраны. Меню отказа теперь называет только отказ другой
  проверки или остановку без вызова.
- Статьи спеки движка и правило `turn-conduct`. Сценарии SC-AK-1743…1746; SC-AK-1441, SC-AK-1723
  и SC-AK-1727 сняты вместе со статьёй о поиске цитаты.

## Решения

- Окно стоит на правке, а не на запуске шага: перемер перед PR идёт внутри проверки открытия PR,
  и окна у него нет.
- «Отложено» не тронуто: его судит последнее слово владельца с номером задачи, а не поиск цитаты.
- Слово «стоп» читается как раньше: это остановка, а не согласие.

## Что не доделано

- Живое окно приложения на Edit в этом дереве не проверено. Опора — документация хуков.
- Окно ждёт человека: без владельца такая правка стоит до его ответа. Отчёт вехи не считает
  неотвеченное окно тупиком.
- Строка, принесённая `git apply`, патчем или слиянием, проходит без окна: проверка судит
  инструмент правки и известные ей записи из оболочки.

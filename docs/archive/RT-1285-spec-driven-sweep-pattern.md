# RT-1285 — паттерн сплошного разбора привязки домена

Задача RT-1285, заявки нет — ветка осталась местной. День работы: 27 августа 2026.

## Разбор просьбы

Три записи груза от соседних деревьев. Владелец разбора не вёл: заход шёл сам, задачи брались из
приёма одна за другой.

По делу оказалась одна: сплошной разбор привязки домена идёт десятую задачу подряд одними и теми
же проходами, а записаны они только в файлах находок — в замысле, который читает владелец и
который будущему заходу не достаётся. Каждый заход собирал набор проходов заново и заново
наступал на две вещи: считал срабатывание находкой и ждал от прохода той же урожайности, что на
прошлом домене.

Две записи о предметности в переносимом тексте в работу не брались: у правила видимости в поиске
раздел «Чего из закона здесь нет» уже отсылает к компаньону, а в правиле слоя API пример
серверного стрима уже назван родом.

## Что решено

Паттерн заведён текстом записи почти дословно: пять проходов с их порядком, разбор срабатываний
чтением, доля ложных по слоям и три ловушки. Правило `spec-driven` называет его третьей строкой
в разделе «Паттерны» — иначе связь держится только полем в шапке, а человек ищет глазами.

## Цена

Записи груза отмечены не были: токен дерева двигает только свои записи, а эти приехали от
соседей. Следующий разбор увидит их новыми.

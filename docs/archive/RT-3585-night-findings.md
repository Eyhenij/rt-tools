Задача RT-3585 эпика RT-3586, запись от 2026-11-24. Прежний адрес:
`docs/tasks/RT-3585-night-findings/`.

## Просьба владельца

> Отправь разборы и исправь все что нашел

Сказано утром 24.11.2026 после ночной работы по эпику Angular Doctor (RT-3476). План одобрен словом
«Одобряю RT-3585–3589».

## Согласия владельца

Задача не меняет ни одного файла кита и строки согласий не несёт.

## Что нашли

- Проверка согласий кита отвечала записью ветки за все правки кита от главной. Ветка RT-3569 кит не
  трогала, но получила требование согласий за правки слитых задач, и в её архивную запись легла
  строка «Без вида» с приказом работать самостоятельно вместо слова о виде.
- Ревью показало ещё три дороги, которыми чужие правки кита ложились на ветку: ветка эпика,
  влитая в задачу; коммиты прежней ветки цепочки; эпик, влитый в main. Из-за последней выпуск кита
  был заблокирован: у слияния `[RT-3476]` нет своей записи.
- `graphify update` рисует рядом с графом страницу graph.html; проверка Angular Doctor читает
  неотслеживаемые файлы и краснела на ней.
- Сценарии хуков валил не объём общего временного каталога, а метка `claude-window-stop/tests`,
  которую оставляют сценарии с общим id сессии; тест выпуска копил каталоги `rt-release-*`.

## Что решили и почему

- **Каждый коммит, тронувший видимый файл кита, отвечает записью своей задачи.** Слитый PR — по
  `[RT-N]` в начале темы. Коммит прежней ветки цепочки — по закрывающему `(RT-N)`, если он лежит в
  ветке этой задачи. Слияние без целой записи разбирается по своим коммитам. Своя запись ветки
  отвечает за свои коммиты и за файл, который тронуло только слияние main.
- **Окно подтверждения цитат показывает только запись ветки при её собственной правке кита.**
  Цитаты слитых задач владелец подтверждал в их PR; повтор на PR эпика ночью стал бы остановкой.
- **Сборка графов и образец ручной сборки удаляют graph.html** сразу после `graphify update`, и
  при сбое тоже.
- **Каждый набор сценариев хуков получает свой TMPDIR**, тест выпуска убирает свой каталог.
- **Строка «Без вида» снята из записи RT-3569** с объяснением на её месте.

## Чем подтверждено

- `bash tools/tests/check-kit-approval.test.sh` — 50 из 50; `bash tools/tests/check-package-release.test.sh`
  — 21 из 21, каталогов `rt-release-*` после него не прибавилось.
- На истории ветки RT-3569 (`aff224a6e` против `7f98e7677`, 127 видимых файлов кита): прежнее
  решение — 3 отказа при записи без строки, новое — 0.
- `node tools/check-kit-approval.mjs --publish ui-kit-v2` — exit 0 за 4,1 с; до задачи — отказ на
  `[RT-3476]`.
- Подставной graphify во временной папке: после сборки в graphify-out остаётся только graph.json.
- `pnpm run agent-kit:hooks` — «ВСЕ НАБОРЫ ЗЕЛЁНЫЕ»; `pnpm run agent-kit:check` сходится.
- Два круга ревью тремя ролями; находки исправлены коммитами кругов или списаны с доводом в ходе
  работы.

## Цена

- Проверки с ожиданием `= 0` на `grep -c` не проходят движок шагов: grep без совпадений выходит с
  кодом 1. Проверка шага 1.3 заменена на `… || true`; такие же проверки RT-3587–3589 заменяются так же.
- `--publish` читает записи с диска, как и до задачи; выпуск идёт на копии main.
- Прямой запуск одного набора сценариев в общем TMPDIR машины по-прежнему встречает старую метку;
  набор перед отправкой и `agent-kit:hooks` идут через `run.sh`. Старые 1692 каталога
  `rt-release-*` в TMPDIR машины не тронуты.

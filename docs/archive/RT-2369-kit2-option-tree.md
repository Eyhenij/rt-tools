# RT-2369 · Select и multiselect показывают опции деревом

Задача RT-2369, PR в ветку эпика RT-2370, закрыто 29 сентября 2026 года. Ветка
`RT-2369-kit2-option-tree`, стоит на `RT-2368-kit2-search-icon`.

## С чего началось

Владелец велел выполнять задачи эпика RT-2370 друг за другом, ветки каскадом:

> бери в работу эпик 2370, перетяни тикет на борде в колонку in progress, создавай ветку и выполняй
> задачи друг за другом, ветки делай каскадом чтобы при слиянии веток по очереди не было
> мерж-конфликтов

В макете список нарисован деревом: уровни с шагом 24, стрелка у ветки, флажок родителя с частью
выбранных детей. Во всех меню эпика владелец выбирал рекомендованный вариант, поэтому вопросы
закрыты допущением, каждый — вариантом, который меню рекомендовало бы.

## Что решили

- **Дети — необязательное поле `children` той же опции**; дерево узнаётся по опциям, отдельного
  входа нет. Плоский список рисуется как прежде.
- **В select клик по подписи ветки выбирает саму ветку** — так сказано в макете.
- **В multiselect клик по ветке выбирает все её включённые листья или снимает их**; значение ветки
  в выбор не пишется, флажок ветки выводится из листьев. Хранимое значение ветки разошлось бы с
  листьями при первом снятии фишки.
- **При открытии раскрыты ветки над выбранным**, остальные свёрнуты.
- **Поиск оставляет совпавшие строки и раскрытый путь к ним**; ветка, совпавшая сама, держит детей
  как были.
- **Клавиши — по образцу дерева**: `ArrowRight` раскрывает или спускается к ребёнку, `ArrowLeft`
  сворачивает или поднимается к родителю.
- **Логика дерева — один чистый модуль на обе семьи**; две копии разошлись бы.
- **Тесты дерева — в отдельных файлах рядом**: спека select стоит у предела длины файла.
- **Стрелка ветки подписана метками кита `uiExpand` и `uiCollapse`**; `uiExpand` добавлен в
  английский набор пакета и в русский набор витрины.

## Что сделано

- Подобласть `docs/specs/ui-kit-v2/option-tree/`, сценарии SC-UKV-408–417.
- Общий модуль дерева и его спека; дерево в панелях select и multiselect, их тесты.
- Истории `PanelTree` в обеих семьях на общем примере дерева; два новых кадра, второй подъём
  витрины — 656 из 656.

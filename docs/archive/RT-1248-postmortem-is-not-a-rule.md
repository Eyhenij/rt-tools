# Разбор, написанный заходом, требованием для него не становится

Задача RT-1248, заявки нет — ветка местная, слияния не было.

## Откуда взялась работа

Запись груза из приёма, своё дерево, паттерн возобновления работы. Повод: разбор происшествия,
написанный заходом, на поведение того же захода не повлиял — через один ход после записи
механизм повторился в той же форме. Написать разбор оказалось легче, чем его исполнить.

Владелец разбор не вёл: заход шёл сам, задачи брались из приёма одна за другой.

## Решение и довод

Пункт встал в «Ловушки» паттерна возобновления, а не в правило ведения работы. Правило говорит,
что делается с работой; здесь — про заход, который эту работу продолжает, и промах принадлежит
именно ему: он написал текст и счёл его исполненным.

Число из повода оставлено в самом пункте — «через один ход». Без него утверждение читается как
опасение, а не как состоявшееся.

## Цена

Пункт называет три исхода разбора — правку ресурса, гард и предложение — и молчит о четвёртом:
разбор, из которого не вышло ничего, потому что чинить нечего. Такой случай существует, и текст
велит для него искать исход, которого нет.

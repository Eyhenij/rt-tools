# RT-3355 — хуки пакета берут решение из таблицы

Задача RT-3355 эпика RT-3302, ветка `RT-3355-hooks-read-table` от ветки эпика
`RT-3302-checks-rework-3`, 16–17.11.2026. Что стало правилом:

- хуки пакета собирают факты и спрашивают один решатель: `projects/agent-kit/assets/checks/decide.mjs`,
  вызов из bash — `rt_decide` в `projects/agent-kit/assets/hooks/decide.sh`, набор —
  `projects/agent-kit/tests/decide.test.sh`;
- факты считаются в одном месте: `facts.sh`, `facts-docs.sh`, `facts-flow.sh` рядом с хуками;
- строки «сначала ход соседа» не хранятся в таблице, решатель вычисляет их сам; `rt_move_first`
  удалён, соседей никто не перезапускает;
- проверки таблицы `--mutate` и `--reverse` в `decision-table.mjs`, спека —
  `docs/specs/agent-kit/decision-table/`; оба её открытых вопроса закрыты;
- находки — в `docs/plans/checks-rework-3-findings.md`, раздел RT-3355.

## Разбор: просьба владельца

Текст задачи #3355:

> Каждая из 82 проверок пакета решает сама за себя. Таблица решений из RT-3275 описывает все их
> решения в одном месте, но проверки её не зовут: правка правила в проверке и в таблице
> расходится, и тест перебора перестаёт описывать то, что агент встречает на деле.
>
> Проверки берут решение из таблицы RT-3275, а не держат своё. Отказ называет ход, который
> таблица разрешает. Проверки, у которых не остаётся своего кода, удаляются.
>
> - Каждая проверка пакета берёт решение из таблицы; поиск по файлам проверок не находит решений
>   мимо неё.
> - Число файлов проверок в пакете названо до и после.
> - Тест перебора RT-3275 зелёный после переключения.

Задача отделена от RT-3275 словом владельца «Две задачи». Эпик идёт по слову «делай эпик дальше».

## Решения по ходу

- **Ни один файл хука не удалён: было 83, стало 87.** Из файлов ушли пути отказа, а не сами
  файлы: у каждого хука остались признак вызова и сбор фактов. Добавлены решатель и три файла
  фактов.
- **Проверка, что хуки следуют таблице, — переворот строк.** Каждая строка отказа по очереди
  меняется на «разрешить», и её хук должен разрешить: 1003 из 1003. До работы — 0.
- **Обратная проба спрашивает решатель, а не хуки.** Переворот уже доказал, что ответ хука — ответ
  решателя; 1467 пар «отказ и хук, судящий его ход» дают 0 отказов без отдельной пробы на пару.
- **Простое действие вызова называется решателю, а не спрашивается вторым вызовом.** Хук поставки
  спрашивал простое действие повторно, и перевёрнутая строка класса вызова не соблюдалась.
- **Ответы всех 999 проб совпали со снимком до работы.** Тексты отказов собираются из строк
  таблицы со слотами `{name}`, которые заполняет хук.
- **Без jq и node решатель недоступен, и хук пропускает действие.** Так закрытие разговора без jq
  теперь проходит; сценарий SC-AK-1121 переписан.
- **Раздача хуков стала быстрее: 1532 мс против 1966 мс до работы.**

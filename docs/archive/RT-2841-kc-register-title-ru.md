# Разбор: заголовок русской регистрации по-английски

## Исходная просьба

Замер на проде 14.10.2026 после выкатки темы: страница регистрации по-русски, заголовок
карточки «Register». В одобренном владельцем макете заголовок «Регистрация».

## Что уже есть в дереве

- Заголовок берётся `msgStr('registerTitle')` в `rt-kc-register.component.ts`.
- В русском наборе keycloakify 11.16.1 ключа `registerTitle` нет; в en, de, zh-CN, zh-TW есть.
- Свои переводы темы лежат в `kc-i18n.ts`, там же переопределён ключ Keycloak
  `invalidPasswordNotEmailMessage`.

## Решения

- **Русский заголовок заводится своим переводом темы** — так уже заведён русский текст ошибки
  пароля. Спросить было некого: заход автономный. Цена ошибки: одна строка перевода.
- **Английский набор тоже получает `registerTitle`** — тип своих переводов требует одинаковых
  ключей во всех языках. Текст тот же, что у Keycloak: «Register». Цена ошибки: нет.
- **Наборы de, th, zh-CN и zh-TW заведены целиком.** Язык без своего набора берёт английский набор
  темы, и тот перекрывает текст Keycloak по тому же ключу. После первой правки немецкий заголовок
  вышел «Register», а отказ пароля и подсказки этих языков шли по-английски ещё со времён
  английского отказа пароля. Заголовок и отказ взяты у keycloakify, свои подписи переведены
  заново. Цена ошибки: неточная подпись на одном языке.
- **Языки ko и hi в задачу не входят** — у keycloakify для них нет набора целиком, это отдельная
  работа. Цена ошибки: нет.

## Шесть вопросов

| Вопрос                               | Ответ                                                      |
| ------------------------------------ | ---------------------------------------------------------- |
| Меняет ли задача поведение           | да: русский заголовок регистрации                          |
| Требует ли правки закона или правила | нет                                                        |
| Одна задача или несколько            | одна                                                       |
| Что в задачу не входит               | наборы ko и hi                                             |
| Чем будет видно, что задача закрыта  | в JAR русский набор темы несёт `registerTitle=Регистрация` |
| Есть ли образец                      | `invalidPasswordNotEmailMessage` в `kc-i18n.ts`            |

# RT-1869 — гард совести принимал маркер из прочитанного файла за вердикт роли

**Ветка:** `RT-1869-conscience-guard-quoted-marker` · **Эпик:** нет · **Разобрано:** 2026-09-08

## Просьба владельца

Гард совести отбил конец хода, хотя роль совести в ходе не звалась ни разу. В ходе была прочитана
запись архива, в перечне намеренно оставленной кириллицы которой стоит строка с маркером роли. Гард
читал запись хода целиком — свой текст, команды и ответы инструментов — и искал маркер по всему
потоку. Ход не кончался, пока исполнитель не сделает что-то по несуществующей находке, а отказ учил
обходить гард, а не читать его.

## Что сделано

- Поток записи хода поделён надвое. Вердикт роли ищется только там, где роль отвечает: ответы
  читающих и пишущих инструментов глушатся по опознавателю вызова, собственный текст исполнителя
  вердиктом не считается никогда, записи ведущего считаются целиком. Деяние по находке ищется
  по-прежнему по всей записи — разбор заводится командой, работа правится правкой, слово владельцу
  лежит в тексте реплики.
- Цитата в отказе берётся из того ответа, который судили. Прежде она бралась поиском по сырой
  записи и после починки указывала бы на прочитанный файл.
- У гарда экзамена приём тот же, и в нём нашёлся промах другого рода: опознаватель вызова брался
  точкой внутри трубы, а точка после трубы означает уже сам список. Поиск по нему отвечал нулём на
  любом непустом списке, и одного чтения файла за заход хватало, чтобы заглохли ответы всех
  инструментов разом — вердикт роли оставалось искать только в записях ведущего. Опознаватель
  связан именем в обеих выборках гарда.
- Спеки обоих поддоменов получили четыре статьи со строками компаньонов и четыре сценария:
  SC-AK-915, SC-AK-916, SC-AK-917 у гарда совести и SC-AK-918 у гарда экзамена.

## Что осталось открытым

- Общий отбор двух гардов не сведён в один помощник: выражение фильтра переносится из файла в файл
  текстом, и помощник тут стоил бы больше, чем экономит. Разойдутся — разойдутся на правке, которая
  тронет один гард и забудет второй.
- Перечни намеренно оставленной кириллицы в записях архива не тронуты: после этой правки они
  безвредны.

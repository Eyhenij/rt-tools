# RT-1288 — гард разговора разведён по двум объявлениям

Задача RT-1288, заявки нет — ветка осталась местной. День работы: 27 августа 2026.

## Разбор просьбы

Две записи груза от соседних деревьев о гарде разговора. Владелец разбора не вёл: заход шёл сам,
задачи брались из приёма одна за другой.

Инструмент вопроса — единственный способ спросить владельца, и на нём у дерева уже может стоять
свой гард со своей причиной отказа. Второй отказ на том же инструменте делает вопрос недоступным
вовсе, и дерево отказывается от гарда целиком вместо того, чтобы получить его половину.

Вторая запись — считать чтением загрузку правила, которое требуется области работы этого хода, —
в работу не бралась: область гард брал бы из карты гейта, а карта отвечает на путь правки, у хода
с вопросом правки нет вовсе. Правка меняет само требование, и решать это владельцу.

## Что решено

Объявление события уехало в свой ресурс `hooks/grill-gate-ask.sh`: он объявляет вызов
инструмента, требует соседа и отдаёт ему ввод. Тело осталось одно — расходиться двум редакциям
одного требования нельзя, — и завершение хода судит по-прежнему `hooks/grill-gate.sh`.

Отказ в пользу работы у тонкой половины свой: тела рядом нет — вызов пропускается. Половина
гарда, потерявшая тело, разговор не клинит.

Сценарий SC-AK-735, три проверки при нём.

## Цена

Записи груза отмечены не были: токен дерева двигает только свои записи, а эти приехали от
соседей. Следующий разбор увидит их новыми.

Дерево, отменившее одну половину, остаётся с половиной требования — и знает об этом только по
своему списку отказа. Проверки на «взята одна половина из двух» нет.

# RT-2486 — проверка миграций в CI ловит перезапуск базы

**Ветка:** `RT-2486-db-ready-over-tcp` (вне эпика по слову владельца, стоит на ветке RT-2406) ·
**Разобрано:** 2026-10-02

## Просьба владельца

> Задачи вне эпиков

Дефект найден по ходу RT-2407 и заведён задачей по правилу.

## Что нашли

- Шаг CI «Migrations against a clean database» упал с «read ECONNRESET» на запуске 37004340467
  (PR #2483) без правки, которая могла бы это вызвать.
- Шаг ждёт базу командой `pg_isready` внутри контейнера, через unix-сокет. Так же ждёт базу проба
  дампа в `deploy/dump.sh`.
- Журнал образа Postgres на этой машине: сервер начальной настройки готов на сокете в
  12:22:21.864, останавливается к 12:22:22.187, а настоящий сервер слушает TCP-порт в 12:22:22.277.
  Около 400 мс проверка через сокет отвечает «готов», а по порту база недоступна.

## Решения

- **Готовность спрашивается по TCP** — `pg_isready -h 127.0.0.1` в шаге миграций и в пробе дампа.
  Сервер начальной настройки слушает только сокет и на такой вопрос не отвечает.
- **Ожидания стенда сквозного набора не тронуты.** Они подключаются с машины клиентом и повторяют
  попытку.

## Проверки

- `bash -n deploy/dump.sh`: синтаксис в порядке; `prettier --check` по `ci.yml`: в порядке.
- Живой запуск образа: ожидание по TCP прошло в 12:23:14.093, после того как сервер начал слушать
  порт в 12:23:14.029.

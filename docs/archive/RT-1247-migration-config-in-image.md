# Накат в образе настраивается файлом настройки, а не адресом в окружении

Задача RT-1247, заявки нет — ветка местная, слияния не было.

## Откуда взялась работа

Запись груза из приёма, своё дерево, паттерн работы с изменениями хранилища. Повод — тот же
отказ наката, из которого выросла статья закона о самодостаточности артефакта: чинился он одной
строкой копирования файла настройки в образ.

Владелец разбор не вёл: заход шёл сам, задачи брались из приёма одна за другой.

## Решение и довод

Записей об одном происшествии стало две, и это не повтор. Закон говорит про артефакт вообще —
что в него не попадает само; паттерн говорит про накат — какой именно файл он читает и почему
подмена переменной окружения не помогает. Слитые в одну, они дали бы утверждение, приложимое
только к тому инструменту, у которого файл настройки есть.

Пункт встал первым в разделе: соседние промахи там про порядок цепочки и про флаги — то есть
про то, что видно на своей машине, — а этот виден только на узле.

## Цена

Пункт называет редакцию инструмента числом. Следующая редакция может читать адрес иначе, и
проверить это по тексту нечем: рядом стоит соседний пункт, который прямо велит спрашивать флаги
у справки, а не у этого текста, — здесь такой оговорки нет.

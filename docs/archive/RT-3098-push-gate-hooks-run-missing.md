# RT-3098 — набор перед пушем называет отсутствующий файл сценариев сторожей

Задача RT-3098, ветка `RT-3098-push-gate-hooks-run-missing` от ветки
`RT-3097-turn-exit-own-notification`, работа вне эпика по слову владельца. Папка задачи
`docs/tasks/RT-3098-push-gate-hooks-run-missing/` разобрана в эту запись.

## Просьба владельца

> RT-3098 (Рекомендуется)

Владелец выбрал её из трёх задач с описанием. В очереди она звучит так: набор проверок перед пушем
запускает сценарии сторожей из файла, который называет дерево. Если файла нет, строка молча
выпадает, и пуш, который правит сторожей, не запускает ни одного сценария.

## Решения по ходу

- **Строка проходит, а не отказывает.** Дерево, которое ставит пакет, получает сторожей раскладкой,
  и каждое обновление их правит. Отказ остановил бы каждый пуш обновления в дереве, где файла
  никогда не было.
- **Правило записано в отдельное описание `push-gate-hooks`.** Описание набора заранее выводит
  состав набора за свои границы, а файл сценариев сторожей поставки стоит на 499 строках.
- **Набор перед пушем вынесен в соседний файл профиля.** Профиль стоял на 498 строках из 500, и
  новая функция не помещалась. Так же раньше был вынесен разбор команд оболочки.
- **Это дерево строку отсеивает.** Здесь сценарии сторожей идут своим шагом, а не файлом
  запуска, и строка была бы ложной.

## Проверено

- Набор умолчаний: 129 проверок, 0 провалов; пять новых строк SC-AK-1248. До правки строка с
  именем файла падала.
- Наборы, которые читают набор перед пушем: надстройки профиля 15 из 15, следующее движение 29 из 29. Набор этого дерева собирается из 46 шагов без новой строки.
- Разложенные копии сходятся с пакетом v0.33.1.

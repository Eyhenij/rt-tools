# RT-3160 — договорённость на весь эпик не даёт открыть PR его задач

Задача RT-3160 вне эпика, ветка `RT-3160-epic-agreement-gate`, PR в main, 07.11.2026. Папка задачи разобрана в эту запись.

## Просьба владельца

Проверка не давала открыть PR первой задачи эпика метрик в ветку эпика и требовала влить договорённость всего эпика. Владелец выбрал в меню «Поправить проверку (Recommended)», а когда выяснилось, что сессия запускает проверки из основной копии, «Отдельный PR в main (Recommended)».

## Решения

- **Проверка смотрит на базу PR.** Договорённость обязана быть влитой только у PR в main: PR в ветку эпика туда не попадает, а договорённость эпика живёт до его последней задачи.
- **PR эпика судится по планам всех его задач.** У ветки эпика нет своей папки, поэтому раньше такой PR договорённость не проверял вовсе. Эта дыра закрыта той же правкой.
- **Правка идёт отдельным PR в main.** Сессия запускает хуки из основной копии на main, и правка в ветке задачи ничего бы не сняла.

Цена: сценарии вынесены в отдельный файл `git-guards-agreement.test.sh`, потому что основной файл сценариев перешёл предел в 500 строк.

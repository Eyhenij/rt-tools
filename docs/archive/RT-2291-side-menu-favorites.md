# RT-2291 — избранное в подменю бокового меню и настройки меню под его номером

**Ветка:** `RT-2291-side-menu-favorites` (от главной, вне эпика) · **Разобрано:** 2026-09-21

## Что просили

> задача добавить раздел Избранное в сабменю навигации вверх над контентом + кнопки фав с иконкой звездочкой закрашенной или нет и тултиплй добавить в изюранное/ убрать из избранного + драг дроп порядок избранного + севис который это вс обрабатывает и хранить в локал сторадж и а пке должен быть дотуп к этому сервису для чтения записи и прочего функционала, нужно придумать лучшее решение, использовать директиву для проекции или в апке где использовать меню все это как-то реализовать

## Слово владельца

> эти изменения в 1 кит делаем

Работа — одна задача вне эпика: эпик второго уровня бокового меню RT-1657 закрыт, и на вопрос
«отдельная задача вне эпика или новый эпик» владелец ответил «1».

> в сторадже храним ключ внутри по id храним один объект с настройками для меню, id может быть несколько, id задаются/чтение из апки доступно

Затем владелец прислал спек: в записи меню лежат избранное, мода подменю и его ширина; запись
читает хранилище перед правкой; событие `storage` обновляет сигналы; кит сам ничего не удаляет;
вход приложения важнее сохранённого; старые ключи моды и ширины не читаются.

## Решения по ходу и где они теперь

- **Кит поставляет сервис, приложение читает и пишет через него; директива проекции отвергнута** —
  каждое приложение повторяло бы разметку, перестановку и узкую раскладку. Теперь это правила
  спека избранного бокового меню.
- **Хранятся только номера, строка собирается из пунктов меню** — подпись следует языку пунктов,
  убранный раздел выпадает сам. Там же.
- **Избранное включается флагом `favorites` у пункта полосы и по умолчанию выключено** — пятое
  замечание владельца после витрины. Там же.
- **Блок — свой компонент, удержание подменю — свой сервис** — файл меню стоял у предела длины, а
  удержание поиском расширяет панель, чего звезда и перетаскивание не просят. Позже по той же
  причине тяга края ушла в свой класс.
- **Мода и ширина подменю переехали из рук приложения в настройки меню** — прежнее правило второго
  уровня «предпочтение хранит потребитель» заменено; история этого — в спеке второго уровня.
- **Сервис назван по боковому меню** — по слову владельца «название сервиса должно отсылать к сайд
  меню».
- **Витрина рисует значки шрифтом Material Symbols** — у прежнего шрифта витрины нет
  `arrows_outward`; поднабор собран из всех значков шаблонов кита.
- **Оставлено названным, не сделано** — прыжок списка при первой звезде, прокрутка выдвижной
  панели при перетаскивании, по вычислению на строку. Снимки витрины для историй избранного не
  сняты.

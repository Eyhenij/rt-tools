# Долг единообразия: четыре правки кода и сто девяносто четыре законных места

Задача RT-842, PR #854. Шестая и последняя задача эпика RT-806.
Прежний адрес записи — `docs/tasks/RT-842-reuse-debt-by-kind/`.

## Откуда взялась задача

Замысел эпика RT-806 велел завести задачи под долг повторов и единообразия, когда кончится
четвёртая задача порядка, — числами того дня. Числа сняты 18 августа 2026 года:
`npm run check:reuse` — мест, где готовое обошли, 211 в 198 признаках, принято 0, долг 198.

## Что было верно на день работы

- Список принятого `tools/reuse-allowlist.json` держал 198 строк долга и ни одной принятой.
- Число 198 считало не только долг: признак `inline-template` судит наличие ключа `template`, а
  не то, собирает ли этот ключ вёрстку. Обёртки историй витрины и компоненты с пустым шаблоном
  попадали в него наравне с настоящими обходами готового.
- Признаки `inline-template` и `inline-styles` приезжают набором пакета, и уточнить их в дереве
  нечем: законное отступление объявляется только списком принятого.

## Решения и куда они ушли

| Решение                                                             | Куда ушло                                                                        |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Обёртки историй витрины и обвязка показа приняты, а не переписаны   | `tools/reuse-allowlist.json`, 190 признаков; причина — договорённость витрины    |
| Компоненты, у которых шаблона нет вовсе, приняты отдельным родом    | там же, 4 признака; пустая строка шаблона отличена от инлайновой вёрстки         |
| Шаблон значка уехал в свой файл — за ним настоящая вёрстка          | `projects/ui-kit-v2/src/lib/components/icon/rt-icon.component.html`              |
| Отступления таблицы второго кита помечены маркером, а не переписаны | `projects/ui-kit-v2/src/lib/components/table/rt-table.component.ts`, `native-ok` |
| Вход модификаторов BEM стал сигнальным, слежение — эффектом         | `projects/core/src/lib/bem/block.directive.ts` и `elem.directive.ts`             |
| Тип модификаторов объявлен один раз вместо четырёх повторов союза   | `TMods` в `projects/core/src/lib/bem/bem.types.ts`                               |

Отступления таблицы второго кита остались отступлениями по существу: сигнальный `viewChild()`
резолвится после первой отрисовки строк, а колонка действий обязана попасть в реестр `CdkTable`
до неё. Обоснование стояло в коде и раньше — не хватало только маркера, по которому проверка
отличает решённое отступление от недосмотра.

## Что нашлось по ходу

**Красной была спека, а не код.** Спека, написанная под перевод входа, падала четырьмя случаями
из шести — и ровно так же падала на исходных директивах. Причина не в сборке имени класса:
среда прогона обходится без Zone.js, и `detectChanges()` там обновляет только помеченное
грязным, а присваивание обычному полю хоста грязным его не помечает. Привязка остаётся прежней,
вход директивы не меняется, и ни один из четырёх случаев до кода не доходит вовсе. Модификаторы
в хосте спеки держит сигнал — и все семь случаев зелены на исходных директивах тоже.

Вывод «перевод ломает модификаторы» был сделан по красной спеке и записан в ход работы как
поспешный. Стоил он одного захода: следующий начал разбор со сборки имени — `parseMods` и
`setMods`, — которая правки не потребовала вовсе.

**Гейт правил судит текст команды оболочки, а не только правку.** За две сессии он отбил `cat`,
`node` и `ls` на файлах областей, чьё правило ещё не грузилось; правило грузится один раз за
заход на область, и отказ снимается загрузкой, а не другой командой.

## Чем кончилось

Долг единообразия пуст: из 198 признаков четыре сняты правкой кода, 194 приняты с причиной по
двум родам. Пара чисел — четыре против 194 — и есть главный итог задачи: мерило дня заведения
считало не только долг.

Этим эпик RT-806 кончился. Все семь проверок дерева зелёные, у всех, у кого счёт долга
объявлен, он равен нулю, и новое расхождение любого рода отбивает пуш.

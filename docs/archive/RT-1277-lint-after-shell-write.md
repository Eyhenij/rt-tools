# RT-1277 — линтер идёт и по следам записи оболочкой

Задача RT-1277, заявки нет — ветка осталась местной. День работы: 27 августа 2026.

## Разбор просьбы

Одна запись груза от соседнего дерева о хуке, который гоняет линтер по следам правки. Владелец
разбора не вёл: заход шёл сам, задачи брались из приёма одна за другой.

Правленые проверка и её список вышли из-под форматтера, и не показали этого ни хук, ни набор
проверок дерева — нашлось ручным прогоном. Правка шла записью через перенаправление, а хук
разбирал у команды оболочки только перенос файла. Признак записи при этом уже объявлен в профиле
дерева и уже читается гейтом правил.

## Что решено

Ветка команды оболочки берёт пути у того же признака: пишет ли команда и куда. Отсев по слову
переноса снят — команда без признака записи уходит молча, как уходила.

Два решения по ходу, обоих в записи не было:

- **Каталог в команде записи не разворачивается.** Перенос двигает целые слои, и каталог у него
  разворачивается в файлы; у записи каталог — рабочий, и первый же прогон отдал линтеру половину
  дерева, найдя замечания в файле витрины, которого правка не касалась. Поймано на себе: хук
  сработал на команде этой же задачи.
- **Заголовок различает перенос и запись.** Прежний текст объяснял замечание сменой места файла,
  и после записи он посылал читателя искать промах не там.

Сценарии SC-AK-724…727 и свой набор при них: прежде у этого хука набора не было. Набор проверен
на прежней редакции хука — краснеет двумя сценариями, то есть проверяет хук, а не себя.

## Цена

Запись груза отмечена не была: токен дерева двигает только свои записи, а эта приехала от
соседа. Следующий разбор увидит её новой.

## What the tree already has

- Статья `doc-style` о пределе длины называет два числа в строках — для текста и для кода. О
  пределе в знаках для текстов слоя правил она молчит, хотя проверка размера его судит.
- `patterns/spec-driven-rule.md`, раздел «Common misses», говорит о месте строки привязки и
  молчит о её длине.
- Задача RT-2660 научила проверку слога считать точку перед `**` концом предложения. Утверждение
  в строке привязки теперь отделено, а якорь и пояснение после него остаются одним предложением.

# RT-3347 — таблица входов набора не зависит от файлов вне истории

Задача RT-3347 вне эпика, ветка `RT-3347-push-inputs-env` от main, 15.11.2026. Прежний адрес —
папка задачи `docs/tasks/RT-3347-push-inputs-env/`. Правила вошли в описание агент-кита
`push-gate-ahead`, сценарии SC-AK-1550 и SC-AK-1551.

## The owner request

> Сначала починить проверку

Ответ на вопрос о пуше ветки эпика RT-3346: таблица входов набора записана без `.env`, а в копии
`.env` лежит. Строку назначения владелец велел вписать словами «делай сам».

## What the tree already has

- Проверка — `tools/push-inputs.mjs`, разложена из пакета: источник
  `projects/agent-kit/assets/checks/push-inputs.mjs`, сценарии —
  `projects/agent-kit/tests/push-inputs.test.sh` (SC-AK-1353…1355), спек —
  `docs/specs/agent-kit/push-gate-ahead/`.
- `verify` записывает шаги заново и требует, чтобы таблица покрывала каждое чтение, каждый обход
  и каждый новый вид запущенного процесса.
- В копии с `.env` шаг `check-format-ignore` читает `.env`, а `check-schema-drift` видит адрес базы
  и запускает `npx prisma`. В копии без `.env` ни того ни другого нет.
- `record` переписывает таблицу целиком. В истории main несколько коммитов «таблица входов набора
  переписана»: таблица переходит от машины к машине.

## Decisions

- **Файл вне истории — не вход шага.** Изменение `.env` не попадает в список изменений ветки и шаг
  не запускает. Значит, его чтение не должно влиять на таблицу. Что вне истории, решает
  `git check-ignore`. Отвергнуто: список имён вроде `.env` — он устаревает.
- **`record` не теряет вид процесса, уже записанный в таблице.** Шаг, который на одной машине
  запускает prisma, на другой не запускает. Таблица держит объединение, и `verify` на обеих машинах
  зелёный. Цена: шаг, который перестал запускать процесс, так и остаётся «всегда запускается», пока
  его строку не удалят. Это ошибка в сторону лишнего запуска, а не пропуска. Отвергнуто: чистое
  окружение для записи — шаг читает `.env` сам, а не из переменных.
- **Behaviour** не меняется для приложений: правка проверки набора, кода приложений нет.

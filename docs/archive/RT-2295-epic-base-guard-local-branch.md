# RT-2295 — свежесть главной спрашивается и у основания ветки

**Ветка:** `RT-2295-epic-base-guard-local-branch` (от главной) · **Разобрано:** 2026-09-21

## Что было не так

Проверка поставки требовала, чтобы отправленная ветка эпика несла вершину главной, и судила только
удалённую копию. Слияние главной доходит до неё одной дорогой — отправкой. А отправку иногда не
пропускает проверка над кодом, который чинит задача этого же эпика.

Круг замкнулся на эпике чата RT-2177. Главная включила признаки второго кита для админки, проверка
единообразия увидела список переписок, отправка встала. Ветку задачи, которая этот список
переписывает, завести стало нельзя: ветка эпика не отправлена.

## Слово владельца

> выполняй задачу

Перед этим владелец запретил обход проверки:

> мимо проверки ты ничего не имеешь права отправлять! никогда!

## Решения по ходу

- **Работа заведена вне эпика.** Задачей эпика RT-2177 её сделать нельзя: ровно эта проверка не
  даёт завести ветку такой задачи. Круг разрывается только снаружи.
- **Вершина спрашивается у основания, а не только у удалённой копии.** Слитая местная ветка эпика —
  доказательство, что слияние сделано: ветка задачи от неё несёт вершину главной. Отставшее
  основание отбивается как прежде.
- **Правила об эпике переехали в поддомен `delivery-epic`.** Описание проверок поставки стояло у
  предела длины, новый сценарий в него не влезал. Это же снимает половину задачи RT-2266.

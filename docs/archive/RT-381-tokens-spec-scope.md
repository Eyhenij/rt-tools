# RT-381 — договорённость об оформлении второго кита дорешена

Первая позиция линии `docs/plans/ui-kit-v2-design-tokens.md`. Закрыта 2026-08-12, отчёт #389.
Сюда перенесено то, что объясняет состоявшиеся решения: ответы владельца его словами и то, где
дело разошлось с замыслом.

## С чего началось

Владелец попросил прочитать чужую страницу про оформление и предложить, как улучшить систему
оформления второго кита; следом — завести линию работ и задачи на всё найденное. Разбор дал
десять находок, две из которых уже стояли в очереди работ (RT-272 и RT-274).

## Ответы владельца

| Вопрос                                            | Ответ                                                |
| ------------------------------------------------- | ---------------------------------------------------- |
| Меняет ли линия вид кита у потребителя            | «Меняется, договорённость нужна»                     |
| Правим ли правила дерева                          | «Правим styling-bem и его паттерн»; закон не трогаем |
| Как разложить находки на задачи                   | «Восемь новых + две старые втягиваются в линию»      |
| Что не входит                                     | первый кит, чужая библиотека тем, перерисовка        |
| Чем видно закрытие                                | все четыре признака, включая спеку на контраст       |
| С какого образца снимается подход                 | «Устройство PrimeNG»                                 |
| Где стоит источник токенов                        | «Последней задачей, после уборки»                    |
| Можно ли переименовывать выпущенные имена токенов | «Потребительский код пока один — ломаем свободно»    |
| Сколько ступеней у бренда                         | «Линейка 50…900, как у Prime»                        |
| Считалка контраста или порог текстом              | «Считалка машиной, порог 4.5:1»                      |

## Где дело разошлось с замыслом

**Конвейер ролей вынес «делать урезанно» и предложил две задачи вместо десяти.** Он же предлагал
снять источник токенов совсем, отложить слой каскада до первой жалобы, не сводить шкалу
нейтрального и не втягивать RT-274. Владельцу это было отнесено целиком, и он отверг всё, кроме
довода про цену: десять позиций означают десять полных прогонов по 493 эталонам. Довод записан в
линию, состав оставлен владельческий.

Из этого следует приём, который стоит помнить: роль, пишущая договорённость, не видит владельца и
способна развернуть его ответ в противоположный. Сверка выхода конвейера с разбором построчно —
не формальность: здесь она поймала пять расхождений подряд.

**Замер, снятый разведкой, оказался снят по вложенной части набора.** Первый счёт шёл по
`src/lib/components/*/*.scss` — 78 файлов и 213 пиксельных чисел; настоящий набор
`src/lib/**/*.scss` — 87 файлов и 208 чисел вне медиазапросов. Числа роли (227 файлов литералов и
42 необъявленных имени) не воспроизводились ни одной командой и были заменены снятыми. Отсюда
решение: команда счёта печатается рядом с замером, и число, которое ею не воспроизводится, в спек
не едет.

## Что осталось открытым

`Q-2` (нужна ли настройка оформления кодом) — развилка RT-274. `Q-3` (девять имён, объявляемых
обоими китами) — починка задевает выпущенный первый кит, выведенный за границу линии. `Q-4`
(сколько ступеней остаётся у шкалы нейтрального) — предмет RT-386.

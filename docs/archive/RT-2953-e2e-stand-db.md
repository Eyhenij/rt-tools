# RT-2953 — стенд сквозного набора админки поднимает контейнер базы сам

Ветка `RT-2953-e2e-stand-db`, отведена от `main`. Папка задачи разобрана в эту запись.

## Просьба владельца

> чини е2е

Сказано 27.10.2026 в ответ на сообщение, что проверка перед push падает на сквозном наборе админки.

## Что было

- Стенд падал на подготовке базы: `P1001: Can't reach database server at localhost:55432`.
  Контейнер базы стоял остановленным четыре дня, а скрипт стенда поднимал только Keycloak. README
  набора требовал поднимать базу руками.

## Решения

- **Скрипт стенда поднимает контейнер базы сам, `docker compose up -d --wait db`**, как поднимает
  Keycloak. Отвергнут понятный отказ «подними базу»: проверка перед push всё равно стояла бы.
- **После набора контейнер не гасится**: база общая с локальной работой, Keycloak стенд тоже
  оставляет поднятым.

## Чем подтверждено

- Набор админки при остановленном до запуска контейнере базы: 146/146.

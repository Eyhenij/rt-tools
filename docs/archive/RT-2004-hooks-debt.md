# RT-2004 — стражи пакета расходились со своей записью

**Ветка:** `RT-2004-hooks-debt` · **Разобрано:** 2026-09-10 · **Эпик:** он сам

## Откуда взялся

Эпик RT-1976 завёл спеки о роде стражей и проверок. Они назвали долг поимённо: пакет расходится с
тем, что о нём теперь записано. Три списка исключений лежали прямо в наборе проб и сторожили
только прирост — новый файл, нарушивший требование, ронял пробу, а старый стоял в списке.

## Мера

Списков было три: молчащие помощники — 13, стражи без объявленного отказа в пользу работы — 4,
стражи без проб — 4. Признак конца эпика: все три пусты и убраны, а пробы зелёные без них.

## Состав

| №   | Задача  | О чём                                     |
| --- | ------- | ----------------------------------------- |
| 1   | RT-2005 | Помощники говорят о себе в первых строках |
| 2   | RT-2006 | Стражи объявляют отказ в пользу работы    |
| 3   | RT-2007 | Четыре стража без проб получают пробы     |

Ветки стояли стопкой: каждая от предыдущей. Все три правили один и тот же набор проб, и от ветки
эпика они разошлись бы на первом слиянии.

## Чем закрыт

Набор проб о роде стражей: 11 ok, 0 провалов — без единого списка исключений. Прогон всех наборов
пакета зелёный. Пробы проверены на поломке: подложенный страж без проб роняет пробу о наборах,
подмена слова в заголовке роняет пробу об отказе в пользу работы.

По ходу заведены два поддомена спеки — о втором сервере разработки и о записи в хранилище: раньше
о них говорила только запись о роде.

## Находка, оставленная за эпиком

Страж записи в хранилище пропускает без вопроса цепочку «миграция на местный адрес и доставка
файла флагом». Эпик поведения стражей не правил, поэтому находка ушла отдельной задачей RT-2014 —
владелец завёл её по слову.

# RT-1282 — прогон не требуется там, где конвейер ветку не слушает

Задача RT-1282, заявки нет — ветка осталась местной. День работы: 27 августа 2026.

## Разбор просьбы

Одна запись груза от соседнего дерева о сверке очереди работ. Владелец разбора не вёл: заход шёл
сам, задачи брались из приёма одна за другой.

Ветка, правящая только тексты, разметку, обвязку разработки и инструменты, прогона не создаёт:
все четыре рода путей стоят у конвейера в списке игнорируемых. Сверка требовала прогон и у неё,
называла расхождением и советовала вернуть событие новым коммитом либо перезакрытием PR — ни то
ни другое не помогает, потому что события не будет никогда. За два дня так покраснели два PR
подряд, и красная строка при этом стоит рядом с настоящими расхождениями.

## Что решено

Сверка читает у файла конвейера список `paths-ignore` — построчно, а не разборщиком разметки:
ключей бывает несколько, по событию, и все складываются в один набор. Прогон не требуется у
заявки, каждый файл которой лежит под одним из этих путей.

Три границы названы прямо: список пуст — строка прежняя; состав заявки не прочитать — прежняя;
пустой состав — прежняя. Молчать наугад дороже одной лишней строки.

Сценарий SC-AK-732, четыре проверки при нём. В этом дереве `paths-ignore` у конвейера нет, и
живая сверка ведёт себя как прежде — правка едет потребителям пакета.

## Цена

Запись груза отмечена не была: токен дерева двигает только свои записи, а эта приехала от
соседа. Следующий разбор увидит её новой.

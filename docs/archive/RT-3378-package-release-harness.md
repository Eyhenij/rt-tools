# RT-3378 — выпуск пакета без проверки, что собранное загружается

Задача RT-3378, запись от 2026-11-18.

## Просьба владельца

> пиши обвязку которая не позволит тебе выпускать сломанные пакеты

Раньше в тот же день: «ты обязан создать обвязку которая не позволит тебе повторить этот провал».

## Что нашли

Версия `0.2.0` пакета протокола чата вышла в npm и не загружалась в Node. Пакет собрали копией процесса соседнего пакета без шага `verify`, а набор перед пушем берёт только проекты с такой целью, поэтому зелёный набор ничего не говорил о загрузке. Тот же пробел был у четырёх пакетов авторизации и системы управления содержимым: у них тоже не было цели `verify`. Отдельный пробел: процесс публикации писал заголовки коммитов с областью, которой не было в списке проверки коммитов, и первый выпуск упал на шаге версии.

## Решения

- Общая проверка собранного пакета `tools/verify-package.cjs` вместо копии под каждый пакет. Она загружает `esm` и `cjs`, ищет относительные импорты без расширения, необъявленные зависимости и ставит пакет из тарболла в пустую папку. Отвергнуто: проверка, написанная под один пакет.
- Запрет фреймворка в собранном пакете заменён проверкой «импорт объявлен в манифесте»: серверные пакеты законно зависят от Nest и `rxjs`, у пакета без объявленных зависимостей результат тот же.
- Пакет, зависящий от соседнего пакета рабочего пространства, загружается только из установленного тарболла: соседа не видно из `dist`.
- Проверка привязки `tools/check-package-release.mjs` читает все пакеты, собираемые двумя `tsc`: цель `verify`, корневая сборка с `nx verify`, процесс публикации, заголовки коммитов процесса. Она стоит в наборе перед пушем и в CI.
- Хук `package-release-guard.sh` отказывает на запуск процесса публикации, пока проверка с пересборкой не прошла. Отвергнуто: запись в правила без хука, 18.11 она бы не остановила выпуск.
- Правило `package-release` и шаблон `package-release-run`.

## Что не доделано

- Не проверен сторонний сборщик или среда потребителя: проверка загружает пакет в Node и из тарболла.
- Шаг тарболла берёт зависимости из реестра, версия соседнего пакета в манифесте должна уже быть опубликована.
- Сужение тяжёлых шагов набора перед пушем идёт отдельным предложением в пакет правил.

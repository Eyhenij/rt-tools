# RT-2115 — графики раздела «Использование»: сводка периода над таблицей

**Ветка:** `RT-2115-usage-charts` · **Разобрано:** 2026-09-15 · эпик RT-2097, задача 5 — добавлена после четырёх плановых, стоит на ветке эпика

## Просьба владельца

> открывай аналитику в образце в браузере и описывай что ты видишь там

> там есть графики а у тебя графиков нет! если … не можешь скопировать решение из примера который я тебе предоставил …

Вопросов не задавалось: владелец назвал образец и пробел, образец читается в коде.

## Что сделано

- `GET /api/usage/digest` под правом `usage:read` отвечает сводкой периода: дни с нулями, загрузки по роду, пять скилов по загрузкам и пять по отказам — оба списка без нулевых. Два сгруппированных запроса в data-access, чистая `usageDaysOf` в util заполняет дни без строк.
- Над таблицей раздела — сетка карточек: широкая с графиком загрузок по дням и три списка кита `rt-bar-list` — топ скилов, по роду, отказы гейта. Столбики и строки списков считают чистые функции; свой стор читает сводку по дереву и периоду из адреса, порядок и страница её не трогают.
- В тулбаре — быстрый период `rt-toggle-button-group`: 7, 30, 90 дней от сегодняшнего. Пара дней считается чистой функцией, момент — параметр; в адрес встаёт той же дорогой, что и пара из отбора.
- Раскладка — блок `admin-digest` в общем слое стилей приложения; сутки в миллисекундах — в общей либе контракта.
- Сцены SC-MB-355…SC-MB-358; сквозная спека раздела проверяет сводку и быстрый период, кадр `list-usage` снят заново.

## Умолчания вместо вопросов

- **Сводка — своя операция, не поля страницы.** Страница меняется с порядком и номером, сводка — нет. Цена ошибки: одна операция.
- **График — столбики CSS, без библиотеки графиков.** Так рисует образец; у кита компонента графика нет. Цена ошибки: один блок стилей.
- **Быстрый период считается от «сегодня» экрана, а не приёмника.** Владелец нажимает у себя; приёмник свои тридцать дней подставляет только без периода в адресе.
- **Сравнения с равным периодом до — нет.** Образец его показывает; спека поддомена о нём молчит. Записано в «чего работа не делает».

## Решения по ходу

- **Два топа считает постраничный запрос со страницей в пять строк.** Свой запрос повторил бы группировку.
- **Топ по загрузкам отсеивает нулевые так же, как список отказов.** Стенд показал в «Топ скилов» правило с одним отказом и без загрузок.
- **Сутки в миллисекундах — в `message-bus-common`.** Обе стороны идут по дням периода, а проверка дубликатов считала вторую декларацию.
- **День в сквозной спеке берётся от часов на обоих концах.** Строки стенда лежат в прошлом, и «7 дней» отвечает пустой таблицей с семью столбиками нулей — это и проверяется.

## Чего работа не делает

- Сравнение с равным периодом до.
- Живой признак активных сессий — у приёма нет живого потока строк.
- Воронка — у строк нет шагов, из которых её строить.

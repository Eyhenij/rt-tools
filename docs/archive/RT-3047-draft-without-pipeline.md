# RT-3047 — черновик PR ждал прогон, которого не будет

Задача RT-3047 эпика RT-3043, ветка `RT-3047-draft-without-pipeline` от `RT-3043-cargo-2026-11`,
05.11.2026. Папка задачи разобрана в эту запись. Порядок эпика лежит в
`docs/plans/cargo-2026-11.md`.

## Просьба владельца

> читай что нового в приёмнике, заводи эпик и задачи под каждую находку и бери в работу, открывай
> пр по одному и отдавай мне на ревью, не переходи к следующей задаче пока я не дам аппрув и пока
> не будет вмержен этот пр

После слияния #3111: «влил, бери следующую».

## Что было

PR в ветку эпика открыт с `--draft` по привычке. Конвейер на эту базу не запускается, и черновик
полчаса ждал проверку, которой не будет. Статья правила об этом была, проверки не было.

## Решение

- Проверка поставки читает ветки триггера `pull_request` из файла конвейера и отказывает черновику
  на базе вне списка.
- Файл берётся из настройки `pushGate.pipelineFile`, которую дерево уже завело для проверки набора.
  Второго списка нет: он разошёлся бы с файлом в первый же день правки триггера.
- Нет файла, настройки или фильтра по веткам — черновик не судится. Ложный отказ запретил бы
  законный черновик, а молчание стоит полчаса.
- Проверка лежит в своём файле рядом с проверкой поставки: та стояла у предела длины.

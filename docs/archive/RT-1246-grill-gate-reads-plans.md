# Гард разбора считает чтением замысел эпика и описание прошлого

Задача RT-1246, заявки нет — ветка местная, слияния не было.

## Откуда взялась работа

Запись груза из приёма, своё дерево, гард разговора. Повод: гард отбил вопрос дважды, и второй
отказ снялся только поиском по трём каталогам, которые он сам называет, — а ответ лежал в
каталоге замыслов, в подсказке не названном.

Владелец разбор не вёл: заход шёл сам, задачи брались из приёма одна за другой.

## Решение и довод

Правки две, и обе обязательны. Образец чтения решает, снимается ли отказ; текст отказа решает,
куда пойдёт тот, кого отбило. Одна без другой оставляет ровно тот промах, из которого запись
груза и выросла: прочитавший верное место всё равно отбит, а отбитый идёт искать не туда.

Каталог замыслов объявлен в профиле рядом с каталогом описания прошлого, а не вписан в гард:
имена каталогов у каждого дерева свои, и гард, знающий их наизусть, врал бы в первом же дереве,
где замыслы лежат иначе.

## Цена

Образец чтения стал шире на два каталога, и вместе с этим шире стало то, что гард принимает за
чтение: обращение к описанию прошлого по любому поводу теперь снимает требование читать законы.
Разводить «читал по делу» и «читал мимо» гарду нечем — он и прежде судил по каталогу, а не по
содержанию.

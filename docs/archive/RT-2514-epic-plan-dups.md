# RT-2514 — в плане эпика RT-2472 повторялись строки задач

**Ветка:** `RT-2514-epic-plan-dups` (вне эпика, по слову владельца) · **Разобрано:** 2026-10-03

## Просьба владельца

> Делай RT-2514

Сказано после того, как исполнитель доложил: таблица задач в плане эпика RT-2472 ушла в main с
повторами.

## Решения

- **Откуда повторы.** При снятии конфликтов в ветках задач эпика исполнитель сохранял обе стороны
  целиком. Общие строки таблицы попадали в обе половины, и в main ушли 24 строки на 10 задач, часть
  со старыми состояниями «PR открыт» и «впереди».
- **Что сделано.** Осталось по строке на задачу, у всех — «влит». Других повторов в плане нет.
- **Чего не сделано.** Проверки, которая отказывала бы на повторе номера задачи в таблице эпика,
  нет; это предложение владельцу.

## Проверки

- `node tools/epic-table.mjs 2472` — 10 задач, все влиты.
- `npm run check:docs` — без расхождений.

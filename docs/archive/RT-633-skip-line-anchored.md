# Обход требования не снимается собственным описанием

Задача #633, PR #634, слияние 2026-08-15. Запись собрана из разбора просьбы и хода работы
при закрытии задачи; после выкатки не правится.

Папка разобрана не своим PR, а работой #658: PR влили раньше, чем до разбора дошли
руки.

## С чего началось

> бера в работу пропозалы из свежих

Работа выведена из записи приёма предложений. Признак строки обхода искал её по всему телу
PR и по всей команде — без привязки к началу строки. Текст, который объясняет, что обход
называется так-то, снимал требование сам собой; ту же строку-пример печатает и сам гард в
своём отказе.

## Ответы владельца

**Сколько берём за этот заход.** «Все семь задач подряд» — весь разбор свежих записей целиком.
Эта задача в нём третья.

## Решения

- **Правятся обе формы обхода, а не одна названная.** Их порог причины общий намеренно, и
  комментарий при признаке говорит это прямо: сделанные по-разному, они станут двумя разными
  обходами одного требования. Откатывать порознь их незачем — значит это одна задача.

- **Запрет подстановки записывается набором знаков, а не заглядыванием вперёд.** Признак читает
  расширенный греп, а заглядывания вперёд в нём нет вовсе. Первый знак причины просто не бывает
  угловой скобкой.

## Что осталось невыясненным при разборе

- Считать ли обходом строку, у которой причина начинается с кавычки. Взято: не считать —
  кавычка в начале причины приходит из примера, а не из живого тела.

## Решения по ходу

- **Признак остаётся один на две формы обхода.** Общий порог причины у них объявлен намеренно, и
  держать его дальше двумя разными выражениями значит развести формы молча.

- **Промежуточный прогон показал, чего правка чуть не сломала.** Строгая привязка к началу
  строки отбила законный обход, стоящий комментарием в конце команды. Признак принимает оба
  начала — свою строку и комментарий, — и сценарий это держит.

- **Стороны конфликта слияния сохранены в одинаковом порядке во всех трёх файлах спека.** Иначе
  правило, его сценарий и его строка привязки перестают находиться друг по другу. Номера
  сценариев не пересчитаны.

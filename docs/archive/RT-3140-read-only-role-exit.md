# RT-3140 — роль без инструментов правки не могла закончить ход

Задача RT-3140 эпика RT-3129, ветка `RT-3140-read-only-role-exit` от `RT-3133-product-points`,
06.11.2026. Папка `docs/tasks/RT-3140-read-only-role-exit/` разобрана в эту запись. Порядок эпика
лежит в `docs/plans/pr-product-flow.md`.

## Просьба

Работу поручила сессия разбора приёмника, владелец её не писал:

> При запуске `claude -p --agent product-strategist` проверка конца хода `turn-exit-guard` не
> отпускала роль: правки ей запрещены, поэтому «работы» в ходе нет, а слова владельца о стопе тоже
> нет. Роль 21 ход разбиралась с отказом, и её итоговое сообщение вытеснило отчёт с таблицей точек.
> Это мешает работе всех ролей только для чтения, вызванных отдельной сессией.
>
> Сделать так, чтобы роль без `Write` и `Edit`, запущенная как основная через
> `claude -p --agent <роль>`, могла законно закончить ход отчётом. Готово, когда есть сценарий с
> номером от `pnpm run spec:next-id`, тест проходит, а запуск роли завершается с её отчётом в
> итоговом сообщении. Работа идёт отдельной задачей эпика с PR.

Вопросов владельцу не было. Эпик взят по следам: роль появилась в RT-3133, а на ветках эпика RT-3129
таблица назначений называет его.

## Решения

- **Роль узнаётся по полю `agent_type` и файлу роли.** Поле ставит клиент: проба на `claude` 2.1.311
  показала его в событии Stop. Отвергнуто: признак в тексте хода и переменная в команде запуска, их
  надо не забыть при каждом запуске.
- **Роль без инструментов правки — это строка `tools:` без `Write`, `Edit`, `MultiEdit` и
  `NotebookEdit`.** Роль без строки и `tools: *` получают все инструменты и судятся как раньше.
  `Bash` не считается: роли читают им дерево.
- **Роль отпускается раньше всех ярусов.** Круг шёл при открытом эпике: вне его второй проход
  отпускается сам. Поэтому проверка раньше не ломалась на пробах вне эпика.
- **Чтение роли лежит в `turn-exit-role.sh`.** Проверка занимала 498 строк при пределе 500.
- **Сценарий лежит в подобласти открытого эпика.** Файл сценариев соседней подобласти уже длиннее
  предела для текста.
- **`main` влита в вершину стопки до ветки задачи.** Ветка эпика отставала на 12 коммитов, и проверка
  поставки отказала. Слияние прошло без конфликтов.

## Проверено

- Набор открытого эпика: 42 проверки, 0 провалов; до правки 2 провала, обе строки про роль.
- Основной набор проверки: 115 проверок, 0 провалов.
- Стенд с открытым эпиком, `product-strategist`, `--max-turns 5`: до правки `error_max_turns`,
  6 ходов, `result` пуст; после правки `success`, 1 ход, отчёт в `result`.
- Тот же стенд, `spec-writer` с `Write` и `Edit`: `error_max_turns`. Для такой роли всё как раньше.

## Цена

- Роль с инструментами правки при открытом эпике застревает по-прежнему: она может работать, но в
  запуске без владельца её некому остановить. Правка этого не меняет.
- Встроенные роли и роли из плагинов файла в дереве не имеют и судятся как раньше.

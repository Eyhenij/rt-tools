# RT-1799 — гарды не узнавали заведение ветки с флагом перед -b

**Ветка:** `RT-1799-branch-flags-before-b` · **Разобрано:** 2026-09-05

## Что было не так

Пять гардов пакета — поставки, спора заявок, набора перед отправкой, ожидания и стража выходов
хода — узнавали заведение ветки по строке `git checkout -b` или `git switch -c`. Флаг между
глаголом и `-b` уводил команду мимо всех: `git checkout -q -b` заводил ветку без проверки
основания и подписи, а страж выходов хода читал её как переключение, то есть как разведку. За
один заход так завелись три ветки. Пришло грузом из приёма: предложение
c16a6d69be05a22d532e78e9712eca2052dc3a69416a805000f6d686baaed4ca.

## Что сделано

Образец один на все пять гардов: флаги между глаголом и `-b` (`-c` у switch) принимаются. У
стража выходов хода поправлен и образец чтения — прежде `checkout -q -b` считался переключением.

- Отвергнуто ловить только `-q`: следующий флаг прошёл бы так же.
- Форма с приклеенным именем (`-bRT-1-x`) не судится: ею ветки здесь не заводят.
- Пробы в пяти наборах, сценарий SC-AK-872; на прежнем образце каждая красная. Полный набор проб
  пакета зелёный.

## Цена решения

Флаг с доводом (`--track origin/x -b`) образцом не читается: довод после флага ломает
последовательность «флаг, флаг, -b». Такой формой ветки здесь тоже не заводят.

# Разбор

## Просьба владельца

> Делай RT-2861

Задача вторая из пяти в эпике RT-2861. В ките было два правила поиска. Боковое меню, выпадающий
список, множественный выбор и дерево искали целой фразой. Динамический выбор и выбор из дерева
искали по словам. Подсветка везде отмечала по словам.

## Решения

- **Правило одно:** каждое слово запроса в любом порядке, без учёта регистра, «ё» равна «е». Оно
  записано в спеке поддомена search-match и лежит в ядре кита: `rtSearchMatches` и подсветка
  `rtMatchParts`.
- **«ё» равна «е», и правило действует во всём ките.** Меню вопросов до владельца не дошло:
  проверка вопросов трижды его не пропустила. Оба ответа взяты по рекомендованному варианту, в PR
  это названо.
- **Свои копии поиска удалены.** Из точек входа ушли `dynamicSelectorMatches`, `dynamicMatchParts`
  и `rtTreeSelectorWords`: обёртка со старым именем была бы реэкспортом правила.
- **Кадр поиска бокового меню снят заново.** История набирает «level 2», и теперь «Level»
  отмечено и в строке папки. Кадр просмотрен и подтверждён повторной сверкой при отправке.

## Что подтверждено

2927 тестов кита, проверка типов и линтер зелёные. Сценарии SC-UKV-874…879 покрыты тестами,
проверки спек и путей в документах чистые. Отправка прошла полный набор проверок, в нём снимки
витрины.

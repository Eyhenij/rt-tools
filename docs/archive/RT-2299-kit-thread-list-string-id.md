# RT-2299 — готовый список переписок принимал только числовой номер строки

**Ветка:** `RT-2299-kit-thread-list-string-id` (от ветки эпика RT-2177) · **Разобрано:** 2026-09-21

## Что было не так

Панель оператора рисовала список переписок своими строками, хотя кит везёт готовый
`rt-thread-list`. Взять готовый мешал тип: список знал только числовой номер строки, а у переписки
чата ключ строковый.

## Решения по ходу

- **Тип расширен, а не сделан обобщённым.** Обобщение по номеру строки разошлось бы по каждому
  шаблону потребителя, а сам список с номером ничего не делает, кроме сравнения.
- **Задача отделена от RT-2293.** Панель без этой правки готовый список взять не может, а план
  RT-2293 правки кита не называл.

## Чем подтверждено

- `pnpm exec nx test @rt-tools/ui-kit-v2 --testFile=…/rt-thread-list.component.spec.ts` — 14 passed.
- `pnpm exec nx run @rt-tools/ui-kit-v2:typecheck` и `pnpm exec nx build @rt-tools/ui-kit-v2` —
  проходят.

## Цена для потребителей пакета

Потребитель, который передаёт числа, правки не требует. Тому, кто подписан на выбор строки
обработчиком с числом, тип выхода станет шире — это видно на сборке, молча не сломается.

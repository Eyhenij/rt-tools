# RT-3592 — слово остановки владельца снова отпускает ход

План одобрен владельцем 24.11 ответом «Одобряю план RT-3592». Он отменяет выбор 22.11 «Ожидание и
убрать «стоп»».

## Что решили и почему

- **Слово остановки отпускает ход рядом с Esc.** Слова и функция взяты из версии 0.38 дословно.
- **Слово снимает удержание только свежей вершины CI.** Красный запуск держит до чтения, идущий —
  до слежения.
- **Ключи слов остановки снова законны в описании.** Список снятых ключей убран.

## Чего правка не даёт

- «не двигайся дальше» ход не отпускает: список 0.38 не расширен.
- Новое сообщение владельца после слова остановки или Esc снимает остановку.
- «хватит тупить, чини» отпускает ход: держат только слова из списков исключений.

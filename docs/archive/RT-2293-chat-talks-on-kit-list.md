# RT-2293 — панель оператора рисовала список переписок своей разметкой

**Ветка:** `RT-2293-chat-talks-on-kit-list` (от ветки эпика RT-2177) · **Разобрано:** 2026-09-21

## Что было не так

Список переписок панель собирала сама: цикл по строкам, своя кнопка у строки, свои заглушки
чтения и своя подпись пустого списка. Кит везёт готовый `rt-thread-list`, и вся эта разметка
жила вторым ответом на тот же вопрос.

## Решения по ходу

- **Слот поиска занят отбором по сайту.** Кит рисует поле поиска всегда, а поиска по тексту
  переписок у приёмника нет — это открытый вопрос описания домена.
- **Строка списка осталась видом без своего нажатия.** Выбор, наведение и окраска выбранной —
  дело готового списка; строке остались поля разговора.
- **Разговор переведён в строку списка одним местом.** Перевод лёг рядом с переводом реплики:
  второй перевод у места рисования разошёлся бы с первым молча.
- **Признак непрочитанного стоит ложью.** Приёмник непрочитанные не считает, и догадка по минуте
  последней реплики называла бы непрочитанным что попало.

## Чем подтверждено

- `pnpm exec nx e2e message-bus-admin-e2e --grep "раздел чата"` — девять случаев зелены, прогон
  повторён дважды.
- Эталонный снимок раздела снят заново: в шапке списка встали поле отбора по сайту и иконка
  отборов, выбранная строка окрашена по-китовому. Снимок просмотрен глазами до пересъёмки.
- `node tools/check-reuse.mjs` — расхождений чата не называет.
- `pnpm run check:affected` — зелено на 94 проектах.

## Что осталось за работой

Поиск по тексту переписок: открытый вопрос описания домена, и слот поиска занят отбором по сайту.

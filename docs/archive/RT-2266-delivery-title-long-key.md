# RT-2266 — заголовок PR читался по короткому ключу

**Ветка:** `RT-2266-delivery-title-long-key` (от главной) · **Разобрано:** 2026-09-21

## Что было не так

Проверка поставки искала заголовок по двум ключам сразу — `--title` и `-t`. Короткий ключ занят
соседями: строка запуска `nx affected -t lint` перед вызовом становилась заголовком. Отказ говорил,
что заголовок не начинается с номера задачи, когда заголовок верный.

## Решения по ходу

- **Длинный ключ ищется первым, короткий — только в его отсутствие.** Два поиска подряд вместо
  одного с перечислением.
- **Случай ставит строку запуска перед заголовком.** С заголовком впереди прежний разбор тоже был
  прав: поиск идёт слева направо. Промах виден только там, где короткий ключ стоит раньше длинного.
- **Карточка RT-2297 закрыта как дубль.** Команда заведения задачи вызвана без взгляда в очередь.

## Decisions

- **Четвёртый признак судит меню и вопрос прозой одинаково** — одна смена формы не должна
  обходить требование. Отвергнуто: только меню — тогда выбор переезжает в текст ответа.
- **Строка-метка берётся из профиля дерева, по умолчанию `Без ответа сделано:`** — дерево говорит
  с владельцем на своём языке.
- **Рабочая команда — правка файла или команда по образцу `work_re` проверки конца хода** — один
  образец на две проверки. Чтение и команда состояния не считаются.
- **Отказ узнаётся по ответу инструмента с ошибкой и словами отказа** — так приходят отказы
  проверок и классификатора.

# RT-2448 — широкий компонент обрезался в паре тем витрины второго кита

**Ветка:** `RT-2448-story-themes-wrap` (поверх RT-2446, вне эпика по слову владельца) · **Разобрано:** 2026-10-01

## Просьба владельца

> Взять обе по очереди

Ответ на вопрос, брать ли две задачи, оставшиеся от предложений по правилам: сначала RT-2448,
потом RT-2447.

## Решения и куда они ушли

- **Пара тем переносит половины по ширине содержимого, как пара наборов.** Ушло в
  `projects/ui-kit-v2/src/showcase/story-themes.component.scss` и в строку компаньона правила
  витрины; пункт правила о дорожке 18rem убран. Отвергнуто: дорожка шире — она сдвигает порог, а не
  убирает его.
- **Половина, которую попросили растянуть, ужимается меньше содержимого.** Список держит таблицу
  своей прокруткой; минимум по содержимому вытолкнул бы половину на ширину таблицы.
- **История пары тем панели диапазона дат показывает широкую панель.** Раньше она показывала
  раскладку шторки, потому что широкая панель не входила в узкую дорожку.
- **Ветка стоит поверх RT-2446.** Пункт правила о дорожке есть только в той ветке; PR идёт в неё.
- **Переснято 80 эталонов пары тем.** Каждый вид расхождения посмотрен до пересъёмки.

- Второй полный прогон снимков второго кита: 670 кадров из 670.

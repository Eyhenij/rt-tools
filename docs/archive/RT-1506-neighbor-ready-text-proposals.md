# RT-1506 — предложения соседа с готовым текстом разобраны

**Ветка:** `RT-1506-neighbor-ready-text-proposals` · **Заявка:** #1507 · **Разобрано:** 2026-08-28

## Что было не так

Дерево-потребитель прислало в приём 112 предложений. Читать их по одному дорого, а понять,
сколько из них уже закрыто, по списку нельзя: приём хранит текст предложения, а не признак того,
лежит ли он в пакете.

## Что сделано

Предложения сверены с пакетом по тексту статьи. У сорока при предложении лежит готовая
формулировка; двадцать девять из них пакет уже несёт — закрыты работами прошлых заходов, в том
числе этой чередой. Из оставшихся одиннадцати шесть оказались закрытыми позднейшими правками с
другой формулировкой: сосед знал их по прежнему тексту.

Легли статьями:

- **Поставка.** «Свои открытые заявки перечитываются в трёх местах: перед пушем, при взятии
  задачи и после каждого известного слияния» — с привязкой к `behindMain` и сверке очереди.
- **Ведение работы.** «Указание работать ходом работы — это указание делать его шаги, включая
  те, что меняют историю», с вердиктом «Не проверяется ничем»: прочтение указания машине не
  видно, держится перечнем состояний.
- **Договорённости.** Ловушка о строке требования к соседнему ресурсу: промах в ней виден
  только счётом по каталогу правил.
- **Паттерн слияния.** Промах «команда мержа взята без переменных подписи»: коммит слияния
  подписан человеком, и отбивает его набор пуша там, где все проверки уже зелёные.

## Чем это подтверждено

- Разбор гарда места правки: чтение (`grep`) записью не считается, а запись документа с именами
  файлов в прозе путей не даёт — проверено вызовом `rt_shell_writes_default` и
  `rt_shell_paths_default` на обоих случаях предложения. Правка не нужна.
- `bash projects/agent-kit/tests/run.sh`, `check-specs`, `check-file-size`, `check-doc-paths`,
  `agent-kit:check`.

## Что осталось открытым

- Семьдесят две записи приёма без готовой формулировки: их читают по одной, это отдельная работа.
- Записи соседа в приёме отметить нечем: отметку принимает только отправившее дерево — приём
  отвечает «такой записи у дерева нет». Своих неразобранных записей у дерева ноль.

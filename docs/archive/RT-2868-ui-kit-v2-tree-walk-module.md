# Разбор

## Просьба владельца

> Делай RT-2861

Задача первая из пяти в эпике RT-2861. Обход дерева вариантов лежал в выпадающем списке, подсветка
совпадений в боковом меню. Тег, дерево и перетаскиваемое дерево зависели от этих компонентов.

## Решения

- **Общие функции лежат в `src/lib/options` и выходят из ядра кита.** Ядро — единственное место,
  которое все компоненты берут без круговой зависимости.
- **Типы переехали вместе с функциями.** Ядро не может брать модель выбора из списка: тот сам берёт
  ядро. Имена `IRtSelect.Option`, `Row`, `TBranchState`, `SideKeyAnswer` и `IRtSideMenu.TitlePart`
  остались псевдонимами: это вход компонентов, и их называют приложения.
- **Старых имён функций в `select` и `side-menu` больше нет.** План эпика обещал реэкспорт на один
  выпуск. Правило слоёв запрещает реэкспорт чужого символа в любой форме, и линтер его не пропустил.
  Корень пакета отдаёт обход дерева и прокрутку под прежними именами. Функции подсветки названы
  `rtMatchParts` и `rtMatchPartsByWords`. Код этого дерева убранные имена не берёт.
- **Тест прокрутки остался у выпадающего списка:** он проверяет три поля выбора, а не функцию.
- **У функции резки по словам появились свои тесты.** Раньше её проверяли только через тег и
  дерево.

## Что подтверждено

2914 тестов кита, проверка типов, сборка пакета и линтер зелёные. Проверки путей в документах,
спек и круговых зависимостей чистые. Отправка прошла полный набор проверок, в нём снимки витрины.

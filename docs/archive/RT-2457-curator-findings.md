# RT-2457 — поправки разбора трёх влитых работ

**Ветка:** `RT-2457-curator-findings` (вне эпика по слову владельца) · **Разобрано:** 2026-10-01

## Просьба владельца

> Все семь

Ответ на вопрос, какие из семи находок разбора правил по RT-2446, RT-2448 и RT-2447 применить.

## Решения и куда они ушли

- **Роли разбора называют запас в целевом файле.** Ушло в роли `skill-curator` и `rules-reviewer`
  пакета: строки и знаки сейчас и после вставки против пределов проверки длины.
- **Запас меряется до статьи, а не после отказа коммита.** Ушло во вводный абзац раздела о сжатой
  статье правила `spec-driven`; место под фразу освобождено сжатием двух соседних пунктов.
- **Очистка архива по сроку идёт отдельным коммитом в той ветке, которую она остановила.** Статья
  `doc-style` переписана вместе со строкой компаньона. Отвергнуто: задача на каждую запись — запись
  истекает каждый день. Вынос проверки из гейта отправки остался вне этой работы.
- **Проверка папки задачи судит ветку названного PR.** Состояние PR отдаёт ветку, проверка берёт её
  дерево по удалённой ссылке. Без ветки или без ссылки судится текущая ветка, как прежде.
  Отвергнуто: только заметка в шаблоне — проверка продолжала бы отказывать нижнему PR стопки.
- **У конвейера свой контейнер браузера снимков и свой порт.** Местная проверка перед отправкой
  оставила умолчания. Разбор обрыва `ECONNRESET` записан в шаблон снимков.
- **Точечная пересъёмка сверяется со списком расхождений до коммита.** Ушло в ловушку шаблона
  снимков о мнимо осиротевших эталонах.
- **Голый `tsc` по настройкам спеков — не та проверка, что цель `typecheck`.** Ушло в компаньон
  правила тестов.
- **Номера сценариев SC-AK-1182…1184.** Первые выданные 1177–1179 заняла соседняя работа, влитая
  раньше; сценарии перенумерованы при слиянии главной ветки.
- **Отправки в приём не было.** Проверка конца хода прочла слово «предложения» как приказ
  отправить; владелец ответил «Не отправлять».

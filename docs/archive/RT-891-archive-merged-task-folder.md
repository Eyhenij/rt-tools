# Папка закрытой задачи вынута из главной ветки

Задача #891, PR #895, закрывалась 19 августа 2026 года. Прежний адрес — папка задачи
`docs/tasks/RT-891-archive-merged-task-folder/`. Запись собрана из разбора просьбы и хода
работы, когда задачу закрывали. После выкатки не правится.

## Почему задача заведена

Просьбы словами не было: работа — хвост задачи о чистке диска на прогоне. Владелец влил её
PR, одобрив, раньше, чем ветка получила последний коммит — разбор своей папки. Папка уехала
в главную ветку целой, и сверка очереди работ стала называть её среди текущих. Про этот шов
правило закрытия работы говорит заранее: после слияния папку разбирать уже некому, и стоит это
отдельной задачи.

## Решения, взятые в работу, и куда они ушли

| Решение                                                          | Куда ушло                                                                                        |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Разбирается одна папка, а не две                                 | папка соседней задачи осталась: её задача открыта, и её вели в другой рабочей копии              |
| Разбора происшествия эта работа не пишет                         | механизм промаха уже записан правилом закрытия работы; вторая запись о нём ничего не прибавляет  |
| Граница гарда слияния названа предложением слою правил           | предложение пакету: гард судит вызов агента, а кнопку хостинга не видит                          |
| Подъём версии пакета без раскладки запирает дерево               | второе предложение пакету; здесь же заведена задача о том, чтобы раскладка шла вслед за выпуском |
| Долг указателя, приехавший мержем, чинится той веткой, что везёт | строка о записи соседней работы дописана в указатель описания прошлого                           |

## Решения по ходу

- **Работа остановилась на гейте пуша и стояла по слову владельца.** Сверка раскладки была
  красной в самой главной ветке — выпуск пакета поднял версию, а разложенные копии остались от
  прошлой редакции. Чинить это своей веткой значило смешать две работы; владелец сказал не
  трогать, и работа стояла, пока раскладку не догнала отдельная задача.
- **Дубль в очереди работ закрыт, а не стёрт.** Пока работа стояла, завелась вторая задача о той
  же папке. Правило велит стирать поглощённую вместе с номером, но удаление отбито разрешениями
  машины; обходить нельзя, поэтому задача закрыта с объяснением, а стирание номера осталось
  владельцу.

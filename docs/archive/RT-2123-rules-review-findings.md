# RT-2123 — находки обзора правил после RT-2079

**Ветка:** `RT-2123-rules-review-findings` (на `main`) · **Разобрано:** 2026-09-15

## Просьба владельца

> выпусти новую версию кита и отметь в приёмнике какие задачи включены в новую версию, затем бери
> новый эпик - исправь все замечания и предложения из приёмника которые ещё не обработаны

## Что было не так

Обзор правил после RT-2079 (подъём зависимостей) вернул восемь находок, и они лежали в передаче
той сессии, не применённые. Приёмник к этому дню пуст от чужого груза: `new` — 0 предложений,
`in_work` — 0, карантин — 0. Единственная необработанная работа по правилам — эта карточка.

## Решения

- **Применены четыре правки дерева, четыре предложения в пакет остались в карточке.** Правило
  ведения работы: находки обзора ждут владельца, а предложение, ушедшее без его слова, — чужая
  работа. Цена ошибки: четыре записи в приёмник, если владелец скажет слать.
- **Число переопределений заменено способом его спросить.** 21 запись (16 полов, 5 потолков)
  устарела бы со следующим подъёмом; теперь файл привязок называет команду, которой число
  берётся.
- **Надстройка ловушек ведения работы ужата, а не расширена списком.** Холодная часть с новой
  ловушкой вышла за 24000 символов; срезаны доводы у трёх прежних записей надстройки.

## Что сделано

витрины, эталонный браузер, засеянные данные), строка о PR dependabot, визуальные проверки в
«What this is checked by». `ui-component-tests-visual/SKILL.md`: две ловушки — расхождение
только в нативных элементах после подъёма браузера, только в тексте после подъёма генератора.
Надстройка `pitfalls/task-flow.md`: ловушка о `task:new --slug` без черновика.

Не сделано, ждёт слова владельца — четыре предложения в пакет: зависимый, ломающийся в рантайме
внутри peer-диапазона, и потолок `parent>child`; корневой пин не держит транзитивную копию
(`pnpm why`); промах с диапазоном переопределения при прямом объявлении (postcss); дерево без
minimumReleaseAge не ждёт ничего.

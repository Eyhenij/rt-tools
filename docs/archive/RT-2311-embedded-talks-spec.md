# RT-2311 — договорённость о встраиваемой странице переписок написана до кода

**Ветка:** `RT-2311-embedded-talks-spec` · **Разобрано:** 2026-09-23 · эпик RT-2309, задача 1

## Просьба владельца

> реализуй экраны для админки

На уточнение владелец выбрал встраиваемую страницу переписок для админки потребителя и отдельную
задачу со своим PR. Позже: «делай эпик далее».

## Что сделано

Раздел описания `docs/specs/chat/embedded-talks/` — три файла, написанные до кода:

- **Описание.** Зачем страница нужна, словарь из четырёх слов, восемь правил, договор пяти операций,
  коды отказа, экраны и состояния, языки, узкий экран, несколько объектов, решения и открытый вопрос
  о счётчике непрочитанного.
- **Сцены.** Девять штук, `SC-CH-83` … `SC-CH-91`, каждая с пометкой о непокрытии и причиной: код
  пишут задачи RT-2312, RT-2313 и RT-2314.
- **Компаньон.** Каждое правило с пометкой «не выполнено» и номером задачи, которая его выполнит.

## Умолчания вместо вопросов

- **Вход — подпись потребителя по ключу сайта.** Потребитель сам решает, кого пускать, подписывает
  своим секретом пару «ключ сайта и минута», сервис проверяет подпись и выдаёт признак на время.
  Вопрос владельцу отбила проверка разбора как уже отвеченный; цена названа владельцу в ответе —
  потребителю нужен свой серверный секрет.
- **Отвергнуто: операторы чата, выданные потребителю** — человек держит второй вход и второй пароль.
- **Отвергнуто: один общий токен сайта** — утечка открывает все переписки сайта, отозвать нечем.
- **Признак страницы живёт недолго и берётся заново без человека.** Иначе страница либо спрашивает
  человека о том, чего он не знает, либо держит вход дольше рабочего дня.

## Чего эта работа не сделала

Кода нет: ни обмена подписи на признак, ни самой страницы, ни секрета сайта в хранилище. Это задачи
RT-2312, RT-2313 и RT-2314 того же эпика.

# RT-2229 — проверка выхода из хода не читает ветку эпика как задачу без папки

**Ветка:** `RT-2229-exit-guard-knows-epic-branch` (от `RT-2228-exit-guard-epic-branch`) · **Разобрано:** 2026-09-18

## Просьба владельца

> разбирай Промах проверки выхода из хода на ветке эпика: кандидат в задачу следующего эпика по правилам.

Ответ владельца на вопрос «куда завести работу»: «Новый эпик, две задачи — беру в работу сразу».
Это первая задача эпика RT-2228; вторая, RT-2230, про конец эпика.

## Что было не так

17.09.2026 проверка выхода из хода дважды отклонила конец хода на ветке эпика RT-2190: ярус
«работа взята и не начата» узнаёт ветку задачи по форме `<КЛЮЧ>-<номер>-…` и отсутствию папки
`docs/tasks/<ветка>/`, а ветка эпика той же формы и папки по правилу не несёт. Третий отказ пришёл
на `main` после слияния эпика — он не про эту задачу.

## Разбор

Пять из шести вопросов закрыты разведкой: поведение приложения не меняется, закон не трогается,
правило `turn-conduct` на пределе длины и уплотняется, проверка ожидания уже отпускает конец эпика
и не правится, образец — чтение ветки по истории в самой проверке выхода. Шестой вопрос — одна
задача или несколько — закрыл владелец: две задачи в новом эпике.

## Решения

- **Ветка эпика узнаётся по строке заголовка плана эпика в каталоге `plansDir`, без сети** — команда
  создания эпика пишет эту строку сама, и она переживает слияние. Отклонено: спрашивать хостинг о
  метке карточки — сеть на каждом конце хода; считать веткой эпика любую ветку с номером карточки с
  меткой epic — тот же вызов.
- **На `main` после слияния эпика ход судится как прежде** — номера эпика на `main` нет, а читать
  его из последнего слияния значит отпускать ход по чужому эпику. Отложено, не мешает работе.
- **Сценарий получил номер SC-AK-1128, а не 1127 из плана** — 1127 заняла ветка RT-2195 на
  хостинге, пока писался план; свободный номер ищется по всем веткам.
- **Статья правила сохранила длину за счёт довода, не утверждения** — правило стояло в ста знаках
  от предела; предложение о ветке эпика заменило оборот, пересказывавший соседнюю статью.

## Цена

Одна функция в ярусах эпика, одно условие в проверке выхода, один сценарий с тестом, статья
правила и строка привязки. Набор проверки эпика вырос с 25 до 28 проверок. Отдельно оплачено вне
эпика: очистка архива (RT-2231) и повторно выданные номера сценариев на main (RT-2233) — без них
набор перед отправкой не пропускал ни одну ветку.

# Паттерн заведения правила показывает строку требования к соседним ресурсам

Задача RT-1260, заявки нет — ветка местная, слияния не было.

## Откуда взялась работа

Запись груза от соседнего дерева, ресурс живёт здесь. Правило слоя правил требует, чтобы
переносимый текст называл своё требование к соседнему ресурсу строкой в шапке, а не выводил его
из фразы в тексте. Паттерн, которым это правило велит заводить новое правило, строки не
показывал: поля шапки, разделы, порядок из пяти шагов — и всё. Пишущий правило по паттерну
требования не встречал и строку не писал.

Владелец разбор не вёл: заход шёл сам, задачи брались из приёма одна за другой.

## Что нашлось по дороге

Показать образец строки было нечем. Разбор требования читает строку по всему тексту ресурса, не
разбирая огород: паттерн с образцом объявил бы требование на `hooks/<гард>.sh` — имя, которого в
пакете нет и быть не может. Первая же раскладка это и сказала.

Граница у этого промаха та же, что у разбора разделов надстройки, где заголовок внутри примера
разделом не считается. Разбор требования её просто не имел.

## Решение и довод

Правки две, и вторая вынуждена первой: без неё образец в паттерне положить нельзя.

Огород вырезается построчно, а не выражением по всему тексту: ограда бывает и волнистой, и
разной длины, а строка требования судится по началу строки — вырезав кусок целиком, легко
слепить соседние строки в одну.

## Цена

Существующие правила строки не получили: разом проставленная наугад, она называла бы
требованиями то, что ими не является. Из восьмидесяти двух ресурсов её несёт один.

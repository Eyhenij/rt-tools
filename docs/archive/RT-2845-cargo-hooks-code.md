## Решения

- **Сначала воспроизвести, потом менять.** Пустой отказ диспетчера воспроизведён тестом с раздельными потоками: при коде 2 текст шёл только в выходной поток. После правки текст идёт в оба потока, а тест `dispatch_says` смотрит только выходной поток, чтобы склейка потоков не удваивала строку.
- **Две записи про повторную постановку сведены в одну правку.** Хук читает названия из записи перед удалением и просит загрузить нужные за один ход. Запись `423f89b6…` (гард просит все правила разом) отклонена: гард просит по одному правилу намеренно.
- **Код доводом интерпретатора считается записью, только если пишет.** Список вызовов записи шире предложенного: добавлены `write_text`, `write_bytes`, переименование, копирование, удаление. Цена названа в заголовке `defaults/shell.sh`: запись редким вызовом проходит незамеченной. Документ на входе остаётся записью.
- **Влитый эпик узнаётся по слиянию в главной ветке, которое называет ключ и номер целиком.** Номер `RT-19211` не считается слиянием эпика `RT-1921`. Проверка основы PR на хосте (запись `615f8fa5…`) ушла текстом в задачу RT-2846.
- **Двоеточие проверяется узко.** Первая версия называла любой голый путь в ячейке с якорем, и красным стало почти всё дерево: проза называет файлы рядом с якорями. Остались только форма «`файл` `символ`» и «`файл`:символ» вне кавычек.
- **Выбор порта стража дев-серверов не вошёл:** ему нужен отдельный замысел.

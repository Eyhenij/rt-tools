# RT-1939 — запуск проверок от открытия PR оставался без присмотра

**Ветка:** `RT-1939-watch-the-run` (вне эпика, по слову владельца) · **Разобрано:** 2026-09-22

## Что было не так

Проверка конца хода уже требовала дождаться конца CI — но только там, где CI запустили руками:
`gh run rerun`, `gh workflow run`. Конвейер просыпается у PR сам, команды запуска в ходе нет, и
ярус молчал. Одного чтения состояния хватало, чтобы ход отпустили: PR оставался черновиком с
зелёным CI, пока владелец не спрашивал сам. На эпике чата это стоило сорока минут простоя готовой
работы.

## Решения по ходу

- **Признак берётся из вывода хода, а не из основания PR.** Какие основания будят конвейер,
  проверка знать не может: требование по одному факту открытия отбивало бы каждый PR в ветку
  эпика, где конвейер не просыпается вовсе.
- **Пара, а не один признак.** «PR открыт в этом ходе» и «его CI прочитан идущим». Кончившийся CI
  ожидания не требует — там уже есть ответ.
- **Папка задачи написана руками, без копирования образца.** Копии несут заголовок пакета: после
  этого править их запрещает проверка источника, а удалять — проверка хода работ, пока в копии
  плана стоит заглушка о договорённости. Это отдельная находка, и она осталась за работой.

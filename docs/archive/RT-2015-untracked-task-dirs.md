## Вопросы и ответы

**Что делать с тем, что `task:new` кладёт папку задачи всегда, даже если ветку не берут?**
«Класть, только проверять».

## Решения

- **`task:new` не меняется** — по ответу владельца. Отклонены: не создавать папку без черновика,
  флаг «беру сейчас».
- **Проверка стоит в сверке очереди работ, в модуле, который уже читает местный репозиторий.**
  Сверка спрашивает индекс git: папка с номером без единого файла в индексе — расхождение.
  Черновик `_draft-<slug>` законен и не называется. Сеть проверке не нужна.
- **Сценарий SC-AK-1185** проверяет три случая: папка вне индекса названа, черновик не назван,
  закоммиченная папка не названа.

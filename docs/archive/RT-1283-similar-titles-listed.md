# RT-1283 — совпадающие заголовки задач перечисляются сводкой

Задача RT-1283, заявки нет — ветка осталась местной. День работы: 27 августа 2026.

## Разбор просьбы

Одна запись груза от соседнего дерева о сверке очереди работ. Владелец разбора не вёл: заход шёл
сам, задачи брались из приёма одна за другой.

Дубль в очереди не находило ничто. Обе задачи по отдельности исправны: у каждой номер в
заголовке, исполнитель и колонка, и сверка принимает обе. Разошлись они только словами
заголовка, а совпадали дефектом, механизмом и признаком закрытия — по дублю прошла вся работа
целиком.

## Что решено

Открытые задачи со сильно совпавшими заголовками печатаются строкой сводки, а не отказом: запись
прямо называет цену отказа — он отбивал бы работу на каждой серии однотипных задач эпика.

Два решения по ходу, обоих в записи не было. Первый прогон на живой очереди показал, чем платит
парное сравнение: серия из четырёх задач эпика дала шесть строк, по строке на сочетание. Задачи
поэтому сводятся в группы, и группа печатается одной строкой. Второй прогон дал группу из
шестнадцати задач, у которых совпало одно общее слово: группа больше четырёх не печатается вовсе
— это серия, а не дубль, и строка о ней говорит только то, что эпик существует.

Сценарий SC-AK-733, три проверки при нём.

## Цена

Запись груза отмечена не была: токен дерева двигает только свои записи, а эта приехала от
соседа. Следующий разбор увидит её новой.

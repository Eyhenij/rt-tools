# RT-3418 — конец хода не получает отказ, пока идёт своя фоновая задача

Задача RT-3418 эпика RT-3302, запись от 2026-11-20. Прежний адрес: `docs/tasks/RT-3418-flow-engine-stop-refusals/`.

## Просьба владельца

> я ухожу спать, переключайся в ночной автономный режим, доведи все задачи эпика до завершения и сам эпик до пр в main

Слово владельца от 19.11.2026; задача — строка 17 плана эпика RT-3302. Карточку завёл замер
RT-3276: проверка конца хода дала 190 из 195 отказов за 14–19.11 и три серии из десяти и больше
отказов на одном шаге. Карточка просит найти ложные отказы и снять их. Тем же проходом она
просит разобрать 17 отказов модельной проверки меню и три отказа модельной проверки конца хода.

План одобрен владельцем утром 20.11 словами «Одобряю plan.md RT-3418».

## Что нашли

- За 14–19.11 движок отказал на конце хода 251 раз. В 169 случаях в эту минуту шла фоновая
  задача той же сессии: агент, команда или набор проверок перед отправкой. Делать было нечего, а
  отказ звал «делай шаг».
- Движок не видел фоновых задач вовсе: источник сессии давал только вызовы, меню и отказы.
- После второго отказа подряд без вызова движок называл меню владельцу, хотя шаг был
  исполнителю по силам.
- Запись сессии читалась одной строкой. Запись этой сессии — 292 МБ, предел строки среды — около
  536 МБ.
- Числа карточки «190 из 195» по тем же записям не воспроизвелись.

## Что решили и почему

- **Ход отпускается по записи, а не по словам.** В записи должна быть фоновая задача сессии с
  началом, без конца и моложе двадцати минут. Ход, который только говорит «жду», держится.
- **Одна задача отпускает один конец хода.** Две идущие задачи отпускают два; конец задачи
  возвращает свой; любой вызов инструмента возвращает все.
- **После сдачи работы случай не действует.** Там действие состояния само уходит в фон.
- **Монитор фоновой задачей не считается.** Постоянный монитор не кончается.
- **Конец хода читается по тому, что идёт в записи после него.** Итог хуков остановки пишется
  почти только при отказе: 267 из 273 записей. Отпущенный ход виден по новому сообщению или
  новому вызову. Служебные записи хоста концом хода не считаются: в 34 случаях они стояли между
  закрытым ходом и его отказом.
- **Граница записана в измерителе, а не в словах описания.** Список слов описания принимает
  только строки.
- **Состояние «работа отдана» случай узнаёт по выходу 10.** Условие случая — «сессия ждёт, и
  выход 10 не выполнен».

## Чем подтверждено

- Прогноз по записям 14–18.11: удержано 142 остановки вместо 383.
- На записи этой сессии вердикт при идущей фоновой команде — «отпущен», после её конца —
  «держится». Вживую 20.11 ход кончался без отказа, пока шли роли ревью.
- Два круга ревью тремя ролями. Первый нашёл семь подтверждённых ошибок в чтении записи, второй —
  шесть.

## Цена решения

- **Отпущенную сессию будит только уведомление задачи.** Задача, которая сама не кончается —
  стенд, витрина, — уведомления не шлёт. Ход, кончившийся в первые двадцать минут после её
  запуска, отпускается, и сессия стоит до слова владельца. Отпуск пишется в журнал хука с номером
  сессии; команды, которая считает такие остановки, нет.
- **Правило «один конец хода на задачу» даёт отказ после постороннего пробуждения.** Сессию
  будит служебное уведомление или вопрос владельца, задача ещё идёт, ответ без вызова получает
  отказ. Любой вызов его снимает. Роли обоих кругов считают правило лишним; оно оставлено по
  одобренному плану.
- **Граница в двадцать минут короче части честных ожиданий.** За пять дней 26 остановок держатся
  только из-за неё: 5 на витрине и 21 на долгих задачах, до 51 минуты.
- **Прогноз лучше жизни.** В записях отказ задачу не тратит, и прогноз отпускает каждую
  остановку ожидания; живой движок — одну на задачу.

## Что задача не сделала

- Серия из десяти отказов 19.11 на шаге, который нельзя измерить после разбора папки, остаётся
  за RT-3434.
- Источник слов владельца читает запись одной строкой: его файл не входил в план.
- 17 отказов модельной проверки меню посчитаны, но условие карточки «вопрос после отказа любой
  другой проверки» не измерено. Три отказа модельной проверки конца хода не разобраны.
- Слово владельца посреди хода лежит во вложении записи и не читается — 30 отказов. Измеритель
  записи читает вызовы всей записи, а не хода — 5 отказов. Обе причины без правки.

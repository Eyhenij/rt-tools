# Файлы своей работы называются поимённо, пока в дереве лежит чужое

**Задача:** RT-1473 · **Заявка:** открыта этой веткой · **Слияние:** ждёт владельца

## Разбор просьбы

Работа взята с приехавшего груза — разбором происшествия соседнего дерева. Запись чужая:
состояние ей двигает отправитель, этому дереву отмечать её нечем.

## Что было не так

Чужая папка задачи уехала в главную ветку: каталог добавлен целиком при лежащем рядом чужом
незакоммиченном. Проверять индекс после добавления мало — однажды добавленный чужой файл
становится отслеживаемым, и следующий `git add` его уже не спрашивает.

## Что сделано

Паттерн коммита получил раздел о поимённом добавлении с готовым видом команды и строкой сверки
индекса, а «Частые промахи» — пункт о каталоге, добавленном целиком.

Гарда не заводится: своё от чужого в рабочем дереве отличает только тот, кто там работает.

# RT-3025 — флажок reCAPTCHA не появляется, если скрипт Google загрузился без grecaptcha

Задача RT-3025, ветка `RT-3025-recaptcha-load-wait` от `main`, 31 октября 2026. Папка задачи
разобрана в эту запись.

## Просьба владельца

> делай код ревью на то говно что ты написал и запускай проверки локально

Это первая находка ревью правки RT-3013.

## Что закрыла работа

1. Скрипт Google загрузился, а `grecaptcha` на окне нет. Раньше ожидание в `whenRecaptchaReady`
   снова вешалось на тот же скрипт и ждало второго `load`, которого не будет. Флажок не
   рисовался, ошибки не было. Теперь ожидание на этом заканчивается, как при ошибке загрузки.
2. Сценарий SC-AUTH-96 в спеке темы и тест с его номером. Тест падал на старом коде и проходит
   на новом.

## Решения

- **Загрузка без API заканчивает ожидание.** Отвергнуто: опрашивать окно таймером — на странице,
  которая флажок уже не получит, такой таймер не кончается.
- **E2E-теста нет, в коммите стоит строка `E2E-skip` с причиной.** Стенд отдаёт настоящий
  скрипт Google, а он всегда ставит `grecaptcha` при загрузке. Случай без API на стенде не
  поднять, его закрывает спека SC-AUTH-96.

## Проверки

- Тема входа: lint, сборка и тесты, 54 из 54.
- Аудит спек зелёный, SC-AUTH-96 покрыт.

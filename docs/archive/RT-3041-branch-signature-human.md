# RT-3041 — заведение ветки принимает подпись человека из RT_HUMAN_EMAILS

Задача RT-3041, ветка `RT-3041-branch-signature-human` от главной ветки, работа вне эпика по слову
владельца. Папка задачи разобрана в эту запись.

## Просьба владельца

> Научить проверку (Recommended)

Ответ на вопрос о ветке RT-2927: её не дала завести проверка подписи. Владелец подписывает коммиты
своим адресом, а проверка при создании ветки знала только адрес машинной учётки.

## Что нашлось

- Проверка пуша судит подпись по двум спискам: машинная учётка и люди из `RT_HUMAN_EMAILS`.
- Проверка при создании ветки с номером задачи сверяла только машинную учётку. Адрес владельца уже
  стоял в профиле дерева, но ветку завести было нельзя совсем.

## Решения

- Создание ветки принимает адреса из `RT_HUMAN_EMAILS` так же, как пуш. Чужой адрес по-прежнему
  отбит. Сценарий SC-AK-1234, набор готовности к поставке покрывает оба случая.
- Отвергнуто: сменить почту на один вызов. Дыра осталась бы, и следующая задача упёрлась бы в неё же.
- Строка этой копии в таблице назначений переписана на RT-2927 по слову владельца «давай по порядку».

## Проверено

- Набор готовности к поставке: 64 сценария, 0 провалов.
- `agent-kit:sync` разложил один файл — защиту поставки.
- Ветка RT-3041 заведена этой же правкой: до неё проверка отбивала адрес владельца.

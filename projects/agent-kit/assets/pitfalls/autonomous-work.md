# Autonomous work — cold part

Pitfalls: traps already stepped on. Loaded not with the rule but on demand — an ordinary
decision does not need it.

The rule is `autonomous-work`; the articles that hold the law stand there.

## Pitfalls

- **A branch created from the base by habit is fixed by re-creating it while the work has not
  gone far.** The pattern names the miss; later the branches collide in shared files.
- **A task postponed without a line in the list is lost.** In the morning it is seen neither on the
  board nor in the branches: it looks simply not taken.
- **A default written in the commit body does not reach the owner.** They read the list and the task
  folder, not the branch history.

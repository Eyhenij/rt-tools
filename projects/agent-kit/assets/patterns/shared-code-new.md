# Новое общее заводится так

Паттерн правила `shared-code`. Что при этом должно быть верно — закон `{{lawsDir}}/shared-code.md`.

## Когда брать

- Появилось число-настройка: предел, размер, длительность.
- Появилась функция без каркаса, нужная обеим сторонам.
- Значение приходит строкой и должно быть сверено с конечным набором.

## Куда класть

| Что                                          | Куда                                        |
| -------------------------------------------- | ------------------------------------------- |
| число или функция без каркаса                | общая либа утилит, файл по предмету         |
| готовый тип или набор значений               | берётся из общего пакета, не переписывается |
| токен внедрения, общий двум фронтовым семьям | либа платформы                              |

Файл выбирается по предмету, а не по роду («константы», «функции»): предметный файл читается
целиком, свалка по роду — никогда. Дальше — строка в барель.

## Число объявляется один раз и без довода

```typescript
export const DEFAULT_PAGE_SIZE: number = 20;
```

```typescript
✗ export function listPageOf(query: IListQuery | undefined, defaultPageSize: number): IListPage
✓ export function listPageOf(query: IListQuery | undefined): IListPage
```

Пока умолчание передаётся доводом, домен вправе назвать своё число — и называет, расходясь с
соседним на единицу, которую никто не заметит.

## Строка сверяется с набором, а не приводится к типу

Приведение принимает любую строку. Сверку делает общая функция, а что делать с промахом, решает
вызывающий:

```typescript
const operator: TFilterOperator | null = listFilterOperatorOf(filter.operatorType);
if (!operator) {
    throw new RequestError(`filter operator is required: ${filter.propertyName}`);
}
```

```typescript
const direction: TListSortOrder = listSortOrderOf(rawDirection) ?? LIST_SORT_ORDER_ENUM.ASC;
```

Сервер отбивает запрос, экран берёт умолчание. Общий переводчик здесь не годится: он подал бы
промах умолчанием, и клиент получил бы отбор, которого не просил.

Помощник приведения типов для этого тоже не годится — значение вне набора он пишет в журнал и
возвращает строкой.

## Проверить, что копия не осталась

Проверка повторов падает на четырёх признаках: одно имя из двух либ, два перечисления с
одинаковым набором членов, число-настройка под одним именем в двух либах, перечисление,
повторяющее набор из общего пакета.

Накопленное лежит в списке исключений и отказом не считается. Список только сокращается: новая
строка в нём означает, что повтор завели уже после проверки.

## Частые промахи

- Своё перечисление с теми же членами, что уже есть в общем пакете, — копия, даже если имена
  разошлись.
- Умолчание, переданное доводом, — домен назовёт своё число, и разъезд будет молчаливым.
- Ту же логику, написанную заново под другим именем, проверка не ловит.
- Строковая настройка и таблица соответствий не учитываются вовсе.

# Обработчик серверной стороны

Паттерн правила `typescript-conventions`. Что при этом должно быть верно — закон
`{{lawsDir}}/code-structure.md`.

## Когда брать

- Заводится новый обработчик серверной стороны.
- Правится тело существующего.
- Домен переезжает на вертикальную нарезку.

## Один обработчик — один класс

Файл рядом со своим доменом, класс с публичным полем метода контракта и публичным методом
обработки. Зависимости приходят конструктором: на серверной стороне внедрение конструкторное, и
функции внедрения фронта там нет.

```typescript
@Injectable()
@ConnectProcedure()
@RequiresPermission('<ресурс>:<действие>')
export class PingProcedure implements IConnectProcedure<typeof HealthService.method.ping> {
    readonly #health: HealthCheckService;

    public readonly method: typeof HealthService.method.ping = HealthService.method.ping;

    constructor(health: HealthCheckService) {
        this.#health = health;
    }

    public async handle(): Promise<{ status: EHealthStatus }> {
        return { status: (await this.#health.check()).status };
    }
}
```

Объявление доступа обязательно, и оно ровно одно — паттерн `permissions-procedure`.

## Почему форма такая

Прежняя — регистрация с телами в замыканиях внутри вызова роутера — делала обработчик
недостижимым для спеки: наружу торчал только метод регистрации. А регистрация сервиса целиком
заглушает каждый непереданный метод ответом «не реализовано», поэтому один сервис контракта не
мог обслуживаться двумя доменами.

Класс решает и то, и другое: метод обработки зовётся спекой напрямую, а реестр кладёт
обработчики поштучно.

## Частые промахи

- **Третий суффикс имени файла:** прежние имена уходят вместе с последним переехавшим доменом,
  и новых таких файлов не заводится.
- **Функция внедрения фронта в классе обработчика:** зависимости идут конструктором.
- **Тело в замыкании внутри регистрации:** спека до него не дотянется.
- **Обработчик без объявления доступа:** приложение не поднимется.
- **Приведение к типу в переводе моделей:** на серверной стороне оно запрещено так же, как во
  фронтовом переводчике.
- **Свой тип у результата группирующей выборки:** он условный, собирается из аргументов вызова
  и с выписанным руками не сходится.

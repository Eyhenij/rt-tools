# Разметка публичной страницы

Паттерн правила `seo`. Что при этом должно быть верно — закон `{{lawsDir}}/search-visibility.md`.

## Когда брать

- Правится шаблон публичной страницы, её заголовок, описание или картинка для соцсетей.
- Заводится новый публичный маршрут.
- Появилась страница, которая должна попасть в карту сайта.

## Разметку ставит служба, а не шаблон

Страница собирает данные и одним вызовом отдаёт их общей службе тегов. Своих тегов в шаблоне не
заводить: они не помечены и потому не переписываются при переходе — тег от прошлой страницы
переживёт следующую.

```typescript
readonly #seo: PageSeoService = inject(PageSeoService);

constructor() {
    effect((): void => this.#applySeo());
}

#applySeo(): void {
    const entity: IEntity.State | null = this.entity();
    if (!entity) {
        return;
    }

    this.#seo.apply({
        entity,
        pageTitle: this.title(),
        description: entity.shortDescription || this.#descriptionFallback(),
        ogImageUrl: this.cover() ? ogUrl(this.cover()) : this.#brandImage(),
        locale: this.#localeId,
    });
}
```

Вызов идёт из эффекта, а не из конструктора напрямую: запись приходит реактивным значением, и
на первом кадре её ещё нет. Ранний выход по пустой записи обязателен — без него разметка встала
бы на пустых значениях и второй раз уже не переписалась бы.

У картинки есть запасной вариант: запись без обложки отдаёт брендовый кадр того же формата,
иначе превью в соцсети пустует.

## Новый маршрут заводится веткой на каждую локаль

Ветки собираются из списка локалей; локаль по умолчанию своей ветки не имеет — она отдаётся из
корня.

```typescript
export const appRoutes: Route[] = [
    ...LOCALE_CODES.filter((code: ELocale): boolean => code !== DEFAULT_LOCALE).map((code: ELocale): Route => ({
        path: code,
        children: publicRoutes,
    })),
    ...publicRoutes,
];
```

Новый путь дописывается в общий набор — тогда он появляется во всех ветках сразу. Ветки
перечислены явными кодами, а не параметром: иначе первый же сегмент адреса был бы принят за
язык.

## Страница попадает в карту сайта явно

Карта строится из записей, а не из маршрутов, и новая страница сама туда не попадёт. Правка
идёт вместе со спекой на сборщик карты.

## Тексты идут из словарей

Заголовок и описание собираются из переведённых значений и заводятся во всех локалях. Без
перевода они уезжают в выдачу на одном языке, и заметно это только в чужой локали.

## Частые промахи

- **Тег в шаблоне вместо вызова службы** — он не помечен и переживёт переход.
- **Вызов без раннего выхода по пустой записи** — разметка встаёт на пустых значениях.
- **Новый путь дописан мимо общего набора** — работает только в локали по умолчанию, остальные
  адреса отдают отказ.
- **Свой разбор адреса вместо общего** — теряется всё после второго знака вопроса, и источник
  обращения считается неверно.
- **Правка разметки без проверки на прод-сборке:** на сервере разработки теги ставит другой
  путь. Проверка описана паттерном `seo-verify`.

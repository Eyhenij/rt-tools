# Проверка разметки на прод-сборке

Паттерн правила `seo`. Что при этом должно быть верно — закон `{{lawsDir}}/search-visibility.md`.

## Когда брать

После любой правки, задевающей публичную разметку, теги головы документа, маршруты, серверную
точку входа, правила обхода или конфиг прокси.

## Сервер разработки здесь не показатель

Теги ставятся при отдаче страницы сервером. В режиме разработки этот путь другой, поэтому
проверка идёт на собранном приложении с поднятым сервером отдачи страниц.

Сервер отдачи страниц отвечает отказом на чужое имя хоста — запросы идут с явным заголовком
хоста.

## Что смотреть в отданной разметке

```bash
for locale in "" <остальные локали>; do
    printf '%-10s ' "${locale:-<по умолчанию>}"
    curl -s -H "Host: localhost" "http://localhost:<порт>/${locale}<путь>" \
        | grep -c -E '<title>|name="description"|property="og:|rel="canonical"|hreflang=|application/ld\+json'
done
```

В ответе каждой локали должны быть заголовок, описание, набор тегов соцсетей, канонический
адрес, полный набор языковых ссылок вместе со ссылкой по умолчанию и блок структурированных
данных.

Отдельно проверяется, что канонический адрес ведёт на **свой** язык, а не на локаль по
умолчанию.

## Карта сайта

Карта строится из живых данных, а не из файла. Пустой ответ означает, что не поднялся запрос за
записями, — это отказ, а не «записей нет».

## Кэшируемость перенаправления

Проверяется только на стенде с настоящим конфигом прокси: голый сервер отдачи страниц отдаёт
заголовки, но не показывает, попадёт ли ответ в кэш.

```bash
curl -sI http://<стенд>/<прежний адрес> | grep -i -E 'HTTP/|location|cache-control|x-cache'
```

Ответ обязан быть постоянным перенаправлением, нести срок жизни и попадать в кэш.

## Частые промахи

- **Проверка на сервере разработки:** теги ставит другой путь, и результат ничего не говорит о
  проде.
- **Проверена одна локаль:** ветка маршрутов, забытая для остальных, отдаёт отказ и поисковику,
  и читателю.
- **Заголовки смотрели на голом сервере:** кэш и перенаправления живут в прокси.

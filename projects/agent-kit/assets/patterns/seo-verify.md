# Проверка разметки на прод-сборке

Паттерн правила `seo`. Что при этом должно быть верно — закон
`docs/constitution/application/search-visibility.md`.

## Когда брать

После любой правки, задевающей разметку сайта, `meta`, маршруты, `server.ts`, `robots.txt`
или `deploy/nginx.conf`.

## Дев-сервер здесь не показатель

Теги ставятся при отдаче страницы сервером. В дев-режиме этот путь другой, поэтому проверка
идёт на собранном приложении с поднятым SSR.

```bash
npx nx build site
PORT=4930 node dist/apps/site/server/server.mjs &
```

Порт 4930 — тот же, что берёт стенд; дев-серверы владельца на 4900 и 4901 при этом не
трогаются. Angular SSR отвечает `400` на чужой `Host`, поэтому запросы идут с
`-H "Host: localhost"`.

## Что смотреть в отданном HTML

```bash
for locale in "" ru/ de/ zh-Hans/ zh-Hant/ ko/ th/ hi/; do
    printf '%-10s ' "${locale:-en}"
    curl -s -H "Host: localhost" "http://localhost:4930/${locale}<адрес страницы>" \
        | grep -c -E '<title>|name="description"|property="og:|rel="canonical"|hreflang=|application/ld\+json'
done
```

В ответе каждой локали должны быть `<title>`, `description`, набор `og:*`, `canonical`,
полный набор `hreflang` плюс `x-default` и блок `application/ld+json`.

Отдельно проверяется, что `canonical` ведёт на **свой** язык, а не на локаль по умолчанию:

```bash
curl -s -H "Host: localhost" http://localhost:4930/de/<адрес страницы> \
    | grep -o 'rel="canonical" href="[^"]*"'
```

## Карта сайта

```bash
curl -s -H "Host: localhost" http://localhost:4930/sitemap.xml | head -20
```

Карта строится из живых данных, а не из файла. Пустой ответ означает, что не поднялся запрос
за объектами, — это отказ, а не «объектов нет».

## Кэшируемость перенаправления

Проверяется только на стенде с настоящим `deploy/nginx.conf`: голый SSR отдаёт заголовки, но
не показывает, попадёт ли ответ в кэш.

```bash
curl -sI http://<стенд>/<прежний-slug> | grep -i -E 'HTTP/|location|cache-control|x-cache'
```

Ответ обязан быть `301`, нести `Cache-Control` со сроком и попадать в кэш. Некэшируемое
перенаправление не вытесняет старую запись, и гость видит прежнюю страницу до суток.

## Тексты

`title` и `description` берутся из словарей во всех локалях перевода. Непереведённый ключ уезжает
в выдачу по-английски — полноту словарей держит `npx nx test common-i18n`.

## Частые промахи

- Проверка в дев-сервере: разметку там ставит другой путь, и отсутствие тега не видно.
- Проверка одной локали: расходится обычно та, которую не смотрели.
- Проверка кэша без nginx: заголовки видны, попадание в кэш — нет.
- Вывод по коду ответа: `200` приходит и со страницы без разметки.

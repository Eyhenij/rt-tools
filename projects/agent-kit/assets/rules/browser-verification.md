# Checking the running application

Rule under the law `docs/constitution/verifiability.md`. Cold part: `pitfalls.md`.

## How the law applies here

- **A running application is not raised a second time.** The port's answerer is found first: this branch's is used, another's left alone and the stand goes on a free port; duplicates stop by process id.
- **The browser is driven by one driver on the pinned profile.** Not a second driver, `open`, `osascript` or the binary.
- **A browser a script raises counts as launching the binary.** Its file is judged, not the command line.
- **The browser choice goes stale; the call is repeated.**
- **A refused profile choice stops browser work.** Named to the owner; no workaround.
- **A profile is neither picked from the list nor asked of the owner.**
- **An unconfigured guard is a stop, not a permission.** Empty helper output: tell the owner.
- **A screen behind sign-in is checked on a stand, not a live account.** Through the form, seeded account; asking a person for a step is wrong.
- **A move into sign-in is checked by signing in as a moved person.** The stand holds real profile fields.
- **A container's element count change is a layout edit.** Measure document vs viewport width at each threshold, both sides.
- **A measurement takes the longest value, not the sample.**
- **The longest value is set for every node sharing the line.**
- **A kit piece reused for other-sized values is measured, not looked at.**
- **The stand proxy supplies the request's tenant sign.**
- **Production configuration is checked only behind the real proxy.**
- **What a person is shown is built from the work's branch.** Production build, branch named.
- **A shared frame's edit is checked on every screen under it.** Screens from the frame; their suite runs before the push.
- **The work branch always has its base tip merged in.**
- **A public screen's first visit carries the service-visit sign.**
- **A screen with no dev data is measured with the component's real styles.** Into the open screen, under its scope.
- **A measurement to repeat is an end-to-end test, not the driver.**
- **Measure before showing the owner, not after their remark.** Reference numbers too.
- **A sample's look carried over is accepted by own frame beside the sample's.** Each remade screen opened, shown to the owner; the measure set taken from the acceptance, written before the edit.

A layout conclusion is backed by a number.

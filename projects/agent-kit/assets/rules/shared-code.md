# Общий код — каким приёмом

Правило под закон `{{lawsDir}}/shared-code.md`. Закон говорит, что общим быть обязано; здесь —
каким приёмом это держится. Из какого пакета и какой либы что берётся — `implementation.md`
рядом.

## Когда берётся

Значение, которое должны одинаково понимать разные приложения: число-настройка, набор значений,
форма запроса и ответа списка, длина поля.

## Что здесь действует

- **Число-настройка лежит в общей либе и оттуда берётся всеми сторонами.** Умолчание доводом не
  передаётся: пока довод есть, домен вправе назвать своё число — и называет, расходясь с
  соседним на единицу, которую никто не заметит.
- **Набор значений из общего пакета заново не объявляется.** Своё перечисление с теми же
  членами считается копией, даже если имена разошлись.
- **Значение из набора сверяется общей функцией, а промах разбирает вызывающий.** Сервер
  отбивает запрос отказом, экран берёт умолчание: политика на непонятное значение у сторон
  разная, и общей может быть только сверка.
- **Общим делается лишь то, где политика одна.** Переводчик, у которого стороны читают
  непонятное значение по-разному, общим не становится — он расходится молча.
- **Перечисления полей порядка и отбора домена копией не считаются.** Они повторяют имена, по
  которым сортирует сервер именно этого домена, и совпадение здесь случайное.

## Паттерны

- `shared-code-new` — как завести новое общее число, функцию или тип и не оставить копию.

## Ловушки

- **Помощник приведения типов для сверки с набором не годится.** Значение вне набора он пишет в
  журнал и возвращает строкой, то есть глотает ровно тот случай, ради которого сверку и завели.
- **Накопленные повторы лежат в списке исключений и отказом не считаются.** Гейт падает только
  на новом; список исключений только сокращается.
- **Проверка не ловит ту же логику, написанную заново под другим именем.** Совпадение она ищет
  по тексту, а не по смыслу.

# Локали и переводы — как это устроено здесь

Правило под закон `docs/constitution/application/locales.md`. Закон говорит, что должно быть верно;
здесь — чем это названо в этом дереве и где лежит. Разметка сайта для поиска — `seo` под
своим законом.

## Как это называется здесь

| В законе             | Здесь                                                                                               |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| локаль сайта         | одна из восьми: `en`, `ru`, `de`, `zh-Hans`, `zh-Hant`, `ko`, `th`, `hi`                            |
| локаль по умолчанию  | `en` — отдаётся из корня, без префикса в адресе                                                     |
| локаль ввода         | `source_locale` в запросе сохранения объекта; берётся из языка админки                              |
| словарь              | JSON-словари Transloco в `libs/common/i18n/src/lib/dictionaries/<локаль>/`, разложенные по разделам |
| перевод контента     | jsonb по локалям в базе, заполняется бэкендом                                                       |
| подстановка в шаблон | `\| transloco` в разметке, `translateSignal` в классе                                               |

## Где это лежит

| Что                                 | Где                                                     |
| ----------------------------------- | ------------------------------------------------------- |
| Словари                             | `libs/common/i18n/src/lib/dictionaries/<локаль>/`       |
| Набор локалей и их начальные валюты | `libs/common/i18n/src/lib/locales.const.ts`             |
| Загрузка словаря и запасной словарь | `libs/common/i18n/src/lib/dictionary.ts`                |
| Префиксы локалей в адресе           | `libs/common/site-routing/src/lib/site-routing.ts`      |
| Перевод контента                    | `libs/api/translation/`                                 |
| Язык админки                        | `libs/api/auth/feature/src/lib/set-locale.procedure.ts` |

## Как закон применяется здесь

- **Локаль по умолчанию отдаётся из корня, остальные семь — из-под префикса пути.**
- **Видимый человеку текст берётся из словаря и заводится во всех локалях перевода.** Ключ,
  потерянный в одной локали, гость видит на кнопке как есть.
- **Пустой перевод считается пропуском, а не переводом.** Запасной словарь подставляется
  только на отсутствующий ключ, а пустую строку отдаёт как есть.
- **Переводы контента производные: владелец пишет на своём языке, остальные семь локалей
  заполняет бэкенд при сохранении.** Табов локалей в формах админки нет — правка вручную всё
  равно была бы перезаписана.
- **Отказ перевода сохранение не срывает.** Текст на локали ввода записывается, прежние
  переводы остаются, и владелец видит предупреждение, а не сообщение об успехе.
- **Локаль, для которой перевода не пришло, сохраняет прежнее значение.**
- **Язык админки выбирает владелец, и выбор живёт в его профиле.** Он же уходит в локаль
  ввода при сохранении объекта.
- **У локали есть начальная валюта показа.** Дальше валюту выбирает гость, и его выбор
  сильнее умолчания локали.

## Чего из закона здесь нет

Страница не показывает, что перевод устарел: владелец правку сохранил, провайдер отказал —
и гость по-прежнему видит старый текст. Это `Q-L-1` в законе.

## Паттерны

- `translations-key` — заведение ключа во всех локалях перевода и подстановка в разметку.

## Ловушки

- **Полноту словарей держит не рантайм, а тест.** `nx test common-i18n` роняет сборку на
  недостающем или пустом ключе; дозаполнить недостающее — `npm run i18n:fill`.
- **Наборы ключей сверяются внутри раздела**, а не по всему словарю сразу: словари разложены
  на общий, сайт, письма и админку.
- **Перевод контента идёт до транзакции сохранения:** страница объекта не должна оказаться
  наполовину переведённой. Кэш сбрасывается после записи и один раз.
- **Без ключа `ANTHROPIC_API_KEY` сохранение проходит,** но переводы остаются прежними, и
  владелец видит предупреждение `propertySaveTranslationFailed`.
- Новый маршрут сайта без ветки под каждую локаль существует только в локали по умолчанию:
  `/de/<путь>` отдаст 404 и поисковику, и гостю.

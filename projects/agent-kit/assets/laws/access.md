# Доступ

Кто что может делать: вход владельца, права на действия, поведение публичных путей.
Правила держат все процедуры контракта и все разделы админки.

## Терминология

| Термин         | Определение                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------- |
| Право          | Пара «ресурс и действие», например `bookings:manage`. Не роль: роль набирается из прав      |
| Пресет         | Именованный набор прав, который выдаётся пользователю целиком                               |
| Оверрайд       | Точечная правка права поверх пресета для одного пользователя                                |
| Публичный путь | Процедура, доступная гостю без входа. Публичность объявляется, а не получается по умолчанию |

## Статьи

- **Каждая процедура объявляет свой доступ, и объявление ровно одно.** Процедура без
  объявления или с двумя объявлениями не даёт приложению подняться.
- **Доступов четыре: по праву, любому вошедшему, публично и публично с чтением входа.**
  Последний отдаёт вошедшему больше, чем гостю, — так админ видит скрытые объекты в общем
  списке.
- **Права пользователя — это права пресета, поверх которых применены его оверрайды.**
- **Запрос без входа туда, где вход нужен, отбивается как неаутентифицированный, а вход
  без нужного права — как отказ в доступе.** Это разные ответы: первый лечится входом,
  второй — нет.
- **Право проверяется до тела процедуры.** Обработчик не решает, пускать ли вызывающего.
- **Публичность объявляется с причиной.** Причина живёт в коде рядом с объявлением и
  наружу не уходит.
- **Админка не показывает разделы, на которые у владельца нет права.**
- **Адрес раздела закрыт тем же правом, что и пункт меню.** Иначе скрытый пункт закрывает
  раздел лишь на вид: адрес открывается по прямой ссылке.
- **Пока права не получены, админка ничего не прячет.** Пустая шапка после сетевого сбоя
  выглядит как сломанная админка и не оставляет выхода; запрос без права всё равно
  отобьётся на сервере.

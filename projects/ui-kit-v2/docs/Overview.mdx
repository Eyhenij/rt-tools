Пользовательские свойства CSS (`--rt-*`) — единственный договор между макетом и кодом. Они
объявляются один раз в `projects/ui-kit-v2/src/styles/` и доступны всюду через `var(--rt-…)`.
Собранный файл со всеми свойствами уезжает в пакет как `styles/tokens.css`.

## Главное правило

> Экран берёт **назначения**. Компонент берёт **свои свойства**. Шкалу не берёт никто напрямую.

<div style={good}>
    <strong>✓ Так.</strong> Экран говорит о намерении:
    <Source
        language="scss"
        code={`.card {
    background-color: var(--rt-color-bg-surface);
    color: var(--rt-color-text-primary);
}`}
    />
</div>

<div style={bad}>
    <strong>✖ Не так.</strong> Экран лезет в шкалу:
    <Source
        language="scss"
        code={`.card {
    background-color: var(--rt-neutral-0);   /* тёмная тема это не переопределяет */
    color: var(--rt-neutral-900);            /* на тёмном фоне останется чёрным */
}`}
    />
</div>

Тёмная тема переопределяет **только назначения**. Экран, взявший шкалу напрямую, останется
светлым внутри тёмной страницы, и увидят это уже на выкатке.

## Как читается имя

`--rt-<род>-<роль>-<уточнение>`

| Род                  | Примеры                                                 | О чём                                        |
| -------------------- | ------------------------------------------------------- | -------------------------------------------- |
| `--rt-color-*`       | `--rt-color-bg-page`, `--rt-color-action-primary-hover` | назначения цвета                             |
| `--rt-space-*`       | `--rt-space-4`, `--rt-space-md`                         | отступы: числовая шкала и именованные алиасы |
| `--rt-radius-*`      | `--rt-radius-lg`, `--rt-radius-full`                    | скругления                                   |
| `--rt-text-*`        | `--rt-text-md`, `--rt-text-2xl`                         | кегль                                        |
| `--rt-font-weight-*` | `--rt-font-weight-regular`, `--rt-font-weight-semibold` | начертание                                   |
| `--rt-shadow-*`      | `--rt-shadow-sm`, `--rt-shadow-card`                    | тени                                         |
| `--rt-z-*`           | `--rt-z-modal`, `--rt-z-tooltip`                        | ярусы наложения                              |
| `--rt-duration-*`    | `--rt-duration-fast`, `--rt-duration-base`              | длительности переходов                       |

Пороги ширины — исключение: они остаются переменными препроцессора
(`$rt-bp-sm … $rt-bp-xl` в `_breakpoints.scss`), потому что пользовательские свойства CSS
в `@media` не работают.

## Откуда что берётся

| Файл                | Что держит                                                                              |
| ------------------- | --------------------------------------------------------------------------------------- |
| `_primitives.scss`  | шкалы: нейтральные и цветные ряды, отступы, радиусы, тени, типографика, ярусы. Литералы |
| `_semantic.scss`    | назначения светлой темы и именованные алиасы отступов — через `var(--rt-<шкала>)`       |
| `_theme-dark.scss`  | переопределения назначений для `:root[data-theme='dark']` и `html.rt-theme-dark`        |
| `_scrollbar.scss`   | оформление полос прокрутки                                                              |
| `_breakpoints.scss` | пороги ширины переменными SCSS; в `_index.scss` **не** форвардится                      |
| `_mixins.scss`      | миксины поверхности карточки и её заголовка                                             |
| `_index.scss`       | собирает всё, кроме порогов, — из него собран `tokens.css`                              |

Пороги и миксины подключаются партиалами напрямую:

<Source
    language="scss"
    code={`@use 'pkg:@rt-tools/ui-kit-v2/styles/breakpoints' as bp;
@use 'pkg:@rt-tools/ui-kit-v2/styles/mixins';`}
/>

## Один префикс

Свойства оформления заводятся только в пространстве `--rt-*`. Компонент, взявший чужое
свойство, теряет тёмную тему молча: переопределять его будет некому.

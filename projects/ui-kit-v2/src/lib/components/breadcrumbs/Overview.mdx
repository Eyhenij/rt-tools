<Title>Breadcrumbs — `rt-breadcrumbs`</Title>

Путь до открытой страницы: предки ссылками, текущее звено текстом или заголовком страницы.

```html
<rt-breadcrumbs [back]="true" [crumbs]="[{ label: 'Объекты', link: '/objects' }, { label: object.name }]" />
```

## Когда применять

- Страница записи внутри раздела: карточка объекта, настройки записи, вложенный список.
- Шапка страницы, где путь и заголовок стоят вместе: вид `heading`.

## Когда не применять

- **Переключение разделов одного уровня** — `rt-tabs` или `rt-section-nav`.
- **Шаги мастера** — `rt-stepper`: у шагов есть порядок и состояние, у пути нет.

## Оси

| ось            | значения                          | умолчание |
| -------------- | --------------------------------- | --------- |
| длина пути     | одно звено, цепочка, длинный путь | —         |
| текущее звено  | `inline`, `heading`               | `inline`  |
| кнопка «назад» | нет, есть                         | нет       |
| разделитель    | `/`, свой знак                    | `/`       |
| ширина экрана  | широкий, узкий                    | —         |

## Состояния

- Звено-ссылка: обычное, наведение, фокус с клавиши.
- Узкий экран и три предка и больше: середина пути уходит в меню «…».
- Длинный путь едет внутри своей строки; обрезанное текущее звено показывает подсказку.

## Доступность

- Хост — ориентир `navigation` с именем «Breadcrumb» из подписей кита.
- Текущее звено несёт `aria-current="page"`; разделители скрыты от скринридера.
- Кнопка «назад» называет, куда ведёт: «Back to» и подпись предка.

## Оформление

Свойства блока: `--rt-breadcrumbs-back-radius` — скругление кнопки «назад»,
`--rt-breadcrumbs-duration` — длительность смены цвета ссылки и фона кнопки.

## Входы

| вход        | тип                               | умолчание  |
| ----------- | --------------------------------- | ---------- |
| `crumbs`    | `readonly IRtBreadcrumbs.Crumb[]` | обязателен |
| `look`      | `'inline' \| 'heading'`           | `'inline'` |
| `back`      | `boolean`                         | `false`    |
| `separator` | `string`                          | `'/'`      |

## Выходы

Нет: звенья — ссылки роутера.

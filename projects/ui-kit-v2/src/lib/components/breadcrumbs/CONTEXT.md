# `rt-breadcrumbs`

```html
<rt-breadcrumbs look="heading" [back]="true" [crumbs]="crumbs()">
    <rt-tag>черновик</rt-tag>
</rt-breadcrumbs>
```

| вход        | тип                               | умолчание  |
| ----------- | --------------------------------- | ---------- |
| `crumbs`    | `readonly IRtBreadcrumbs.Crumb[]` | обязателен |
| `look`      | `'inline' \| 'heading'`           | `'inline'` |
| `back`      | `boolean`                         | `false`    |
| `separator` | `string`                          | `'/'`      |

Описание правил — `docs/specs/ui-kit-v2/breadcrumbs/`; здесь только устройство папки.

## Главное, что нужно знать

**Цепочку отдаёт приложение.** Последнее звено — открытая страница: ссылка у него не рисуется.
Маршрутов компонент не читает: имя открытой записи приходит с ответом сервера, и знает его только
страница.

**Свёртка — чистая функция.** `rtBreadcrumbsFold` раскладывает предков на голову, свёрнутое и хвост;
компонент только зовёт её с признаком узкого экрана от `BreakpointsService`.

## Края

- Кнопка «назад» рисуется по просьбе и только при наличии предка: ведёт к последнему из них.
- В виде `heading` строки пути нет, пока нет предков; черта после последнего предка скрыта.
- Корень шаблона — `ng-container`: класс блока висит только на хосте.
- Цвета, кегль, зазоры и кнопка «назад» — свойства `--rt-breadcrumbs-*` на корне блока. Материальный
  набор переназначает шесть из них в том же файле стилей, вид кита от этого не меняется.

<Title>Accordion — `rt-accordion`</Title>

Список пунктов с заголовком-кнопкой и текстом под ней. Нажатие на заголовок раскрывает или
сворачивает ответ, соседние пункты остаются как были.

```html
<rt-accordion [items]="questions()" />
```

## Когда применять

- Блок частых вопросов: читающий ищет свой вопрос по заголовкам и раскрывает только его.
- Длинные пояснения, которые нужны не всем, в форме или на странице настроек.

## Когда не применять

- **Один длинный текст** — `rt-collapsible-text`: у него нет заголовков, есть только «ещё».
- **Переход между разделами страницы** — `rt-section-nav` или `rt-tabs`: аккордеон ничего не
  переключает, он раскрывает.
- **Ответ с разметкой** — компонент принимает строки и разметку внутри пункта не рисует.

## Оси

| ось                 | значения                                   | умолчание |
| ------------------- | ------------------------------------------ | --------- |
| раскрытие при входе | первый, третий, ни одного                  | первый    |
| длина               | короткий заголовок, перенос, длинный ответ | —         |

**Пункты раскрываются независимо.** Нажатие не сворачивает соседей: читающий сравнивает два ответа.
Несколько раскрытых пунктов получаются только нажатиями, их показывает **Playground**.

## Края

| край                   | что происходит                               |
| ---------------------- | -------------------------------------------- |
| пустой список          | не рисуется ничего                           |
| `openIndex` вне списка | все пункты свёрнуты                          |
| новый список пунктов   | раскрытие начинается заново с `openIndex`    |
| длинный заголовок      | переносится, стрелка остаётся у правого края |

## Состояния

| состояние       | чем задаётся  | что меняется                                |
| --------------- | ------------- | ------------------------------------------- |
| свёрнутый пункт | умолчание     | виден заголовок, стрелка смотрит вниз       |
| раскрытый пункт | нажатие, вход | под заголовком текст, стрелка смотрит вверх |
| фокус с клавиши | Tab           | кольцо фокуса кита вокруг кнопки пункта     |

## Доступность

- Кнопка пункта несёт `aria-expanded` и `aria-controls`, панель — регион с подписью по кнопке.
- Кнопка стоит внутри заголовка третьего уровня: по заголовкам находится каждый вопрос.
- Панель свёрнутого пункта скрыта атрибутом `hidden` и не читается вслух.

## Оформление

Пункты разделены тонкой линией, текст ответа приглушён. Светлая и тёмная темы стоят рядом в
истории **Themes**.

## Рядом

- [`rt-collapsible-text`](./?path=/docs/molecules-collapsibletext-overview--docs) — один текст с
  кнопкой «ещё».

## Входы

| вход        | тип                            | умолчание | что делает                                     |
| ----------- | ------------------------------ | --------- | ---------------------------------------------- |
| `items`     | `readonly IRtAccordion.Item[]` | —         | пункты: заголовок и текст, уже переведённые    |
| `openIndex` | `number \| null`               | `0`       | пункт, раскрытый при входе; `null` — ни одного |

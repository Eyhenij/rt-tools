# `rt-accordion`

Список пунктов с заголовком-кнопкой и текстом под ней: вопросы с раскрывающимися ответами.

```html
<rt-accordion [items]="questions()" [openIndex]="null" />
```

| вход        | тип                            | умолчание      |
| ----------- | ------------------------------ | -------------- |
| `items`     | `readonly IRtAccordion.Item[]` | **обязателен** |
| `openIndex` | `number \| null`               | `0`            |

Выходов нет.

## Главное, что нужно знать

**Пункты раскрываются независимо.** Нажатие раскрывает или сворачивает один пункт, соседи остаются
как были. Читающий сравнивает два ответа, и сворачивать первый при раскрытии второго нельзя.

**Решение о раскрытии лежит в `rt-accordion.logic.ts`.** Набор раскрытых номеров — связанный
сигнал компонента. Новый список пунктов начинает раскрытие заново с `openIndex`.

## Края

- `openIndex` вне списка, отрицательный или `null` оставляет все пункты свёрнутыми.
- Панель свёрнутого пункта лежит в разметке с `hidden`. Поисковик страницы с отрисовкой на сервере
  видит все ответы.
- Id кнопок и панелей берутся из счётчика на экземпляр. Два аккордеона на странице не ссылаются на
  чужие панели.
- Заголовок и текст — строки. Разметку внутри пункта компонент не принимает.

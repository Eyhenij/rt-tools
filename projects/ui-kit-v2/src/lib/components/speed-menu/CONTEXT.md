# `rt-speed-menu`

```html
<rt-speed-menu label="Масштаб" icon="zoom_in" [actions]="zoomActions" (actionSelect)="zoom($event)" />
```

Входы — `actions`, `icon`, `label`, `direction`, `size`, `variant`, `closeOnSelect` и `disabled`.
Выходы — `actionSelect` и `openChange`.

Описание — `docs/specs/ui-kit-v2/speed-menu/`; здесь только устройство папки.

## Главное, что нужно знать

**Панель — `rtPopover` на кнопке меню.** Триггер у панели ручной: открывает и закрывает её кнопка.
Места вокруг кнопки задаёт вход панели `rtPopoverPositions`; без него у панели прежние два места.

**Клавиатуру узнают по счёту щелчков.** Нажатие с клавиатуры приходит с `detail` ноль, и тогда фокус
встаёт на первое доступное действие. Мышиное нажатие оставляет фокус на кнопке.

**Ходьбу по действиям решает чистая функция.** `speedMenuNextIndex` знает стрелки, Home и End;
недоступные кнопки отбираются по нативному `disabled` кнопки кита.

## Края

- Escape и Tab в панели ловит сама панель: закрывает меню и ставит фокус на кнопку. Escape на кнопке
  меню закрывает панель её собственным обработчиком.
- Шаг входа действия задан правилами `nth-child` до восьми действий; девятое и дальше входят вместе
  с восьмым.
- Порядок входа считается с конца у столбца вверх и у ряда к началу: ближнее к кнопке там последнее.
- Корень шаблона — `ng-container`: класс блока висит только на хосте.

## Рядом

- `rt-icon-button` — его вход `expanded` пишет `aria-expanded` кнопки меню.

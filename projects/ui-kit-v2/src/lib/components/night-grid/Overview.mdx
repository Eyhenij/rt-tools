<Title>NightGrid — `rt-night-grid`</Title>

Плотная сетка суток: клетка на день, цвет — состояние. Внутри клетки нет ни текста, ни иконки:
весь смысл несёт её подпись.

```html
<rt-night-grid ariaLabel="Март" [cells]="days()" (cellClick)="openDay($event)" />
```

## Когда применять

- Обзор занятости месяца одним взглядом: брони, смены, доступность.

## Когда не применять

- **Выбор даты** — [`rt-date-picker`](./?path=/docs/components-date-picker--docs) или
  [`rt-calendar`](./?path=/docs/components-calendar--docs): там числа и навигация по месяцам.
- **Подробности дня** — сетка их не показывает, для этого открывается панель.

## Оси

| ось              | значения                       | умолчание |
| ---------------- | ------------------------------ | --------- |
| состояние клетки | `free`, `primary`, `secondary` | —         |
| длина месяца     | 28, 30, 31 день                | —         |

Домен в кит не протаскивается: сетка знает про «свободно / основное / второстепенное», а не про
статусы броней. Перевод доменных состояний в эти три — забота потребителя.

Состояния показаны и порознь, и вперемешку: клетки плотные, и различить свободную от
второстепенной можно только рядом друг с другом.

## Края

| край         | что происходит                               |
| ------------ | -------------------------------------------- |
| пустой набор | рисуется пустая сетка                        |
| одна клетка  | сетка из одной ячейки, раскладка не ломается |

## Состояния

| состояние       | чем задаётся     | что меняется         |
| --------------- | ---------------- | -------------------- |
| обычное         | —                | заливка по состоянию |
| наведение       | `:hover`         | заливка светлеет     |
| нажатие         | `:active`        | заливка темнеет      |
| фокус с клавиши | `:focus-visible` | кольцо фокуса        |

## Доступность

- **Подпись клетки обязана быть самодостаточной**: «3 марта — занято», а не «занято». Внутри
  клетки текста нет, и `title` существует только для подсказки и скринридера.
- Клетка — настоящая `<button>`, до неё доходят клавиатурой.
- Сетка объявлена `role="group"`, а клетки роли не несут вовсе: явная роль на кнопке вытеснила
  бы родную, и скринридер называл бы элемент списка, умалчивая, что по нему нажимают.
- Состояние и идентификатор продублированы атрибутами `data-state` и `data-id`.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-calendar`](./?path=/docs/components-calendar--docs) — календарь с числами и навигацией.

## Входы

| вход        | тип                                | умолчание | что делает                                |
| ----------- | ---------------------------------- | --------- | ----------------------------------------- |
| `cells`     | `ReadonlyArray<IRtNightGrid.Cell>` | `[]`      | клетки: идентификатор, состояние, подпись |
| `ariaLabel` | `string`                           | `''`      | имя сетки для скринридера                 |

## Выходы

| выход       | что сообщает                                         |
| ----------- | ---------------------------------------------------- |
| `cellClick` | нажата клетка; что делать дальше, решает потребитель |

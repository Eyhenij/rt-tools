# `rt-night-grid`

Плотная сетка ночей: одна клетка — одна ночь, цвет — её состояние.

```html
<rt-night-grid ariaLabel="Ночи марта" [cells]="cells()" (cellClick)="toggle($event)" />
```

| вход        | тип                                   | умолчание                      |
| ----------- | ------------------------------------- | ------------------------------ |
| `cells`     | `ReadonlyArray<{ id, state, title }>` | **обязателен**                 |
| `ariaLabel` | `string`                              | `''` → `rtKit.uiNightGridAria` |

Выход: `cellClick` — отдаёт **целую клетку**, а не идентификатор.

`state` — `'free' | 'primary' | 'secondary'`.

## Главное, что нужно знать

**Клетка пустая — весь смысл несёт её подпись.** Внутри нет ни текста, ни иконки: сетка плотная,
и `title` существует только для всплывающей подсказки и скринридера. Значит подпись обязана быть
самодостаточной («3 марта — занято»), а не «занято».

## Края

- Клетка — настоящая `<button>`, до неё доходят клавиатурой.
- Состояние и идентификатор продублированы атрибутами `data-state` и `data-id`.
- Сетка объявлена `role="list"`, клетки — `role="listitem"`.

# `rt-pagination`

```html
<rt-pagination
    [pageModel]="page()"
    [perPageOptions]="[20, 50, 100]"
    [loading]="loading()"
    (pageChange)="load($event, page().pageSize)"
    (perPageChange)="load(1, $event)" />
```

| вход             | тип                                                   | умолчание       |
| ---------------- | ----------------------------------------------------- | --------------- |
| `pageModel`      | `IPageModel` (`pageNumber`, `pageSize`, `totalCount`) | **обязателен**  |
| `perPageOptions` | `ReadonlyArray<number>`                               | `[20, 50, 100]` |
| `loading`        | `boolean`                                             | `false`         |

| выход           | тип      |
| --------------- | -------- |
| `pageChange`    | `number` |
| `perPageChange` | `number` |

## Главное, что нужно знать

**Компонент не листает — он просит.** Страницу меняет потребитель, передав новый `pageModel`.
Поэтому клик по уже открытой странице, выход за границы диапазона и выбор того же размера
страницы событий **не поднимают**: лишний запрос был бы за них.

**Полоса прячет себя целиком**, когда записей меньше самого мелкого варианта размера страницы
(`display: none` на host-е): листать нечего, а строка под таблицей всё равно занимала бы место.

## Края

- Во время загрузки заблокированы и номера, и стрелки — иначе второй клик ушёл бы поверх ещё
  не пришедшего ответа.
- Полоса номеров показывает первую, последнюю и по одному соседу открытой страницы; между ними —
  «…». При единственной странице номеров нет вовсе.
- Узкая и широкая разметки живут в DOM **одновременно** (`pagination-compact` и
  `pagination-nav`): какую показать, решает медиазапрос, а не условная отрисовка.
- **У пустого набора нет своего вида строки диапазона — бар при нём спрятан целиком.** Ветка на
  `rtKit.uiRangeEmpty` тут была, но показать её не могло ничто: правило видимости прячет бар
  раньше. Сам ключ в словаре остался (он часть публичного `rtKit`), но кит его больше не читает.
  Про пустоту говорит [`rt-empty-state`](../empty-state/CONTEXT.md), а не пагинация.

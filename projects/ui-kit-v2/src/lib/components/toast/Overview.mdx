<Title>Toast — `rt-toaster`, `rt-toast`</Title>

Всплывающее уведомление, уходящее само. Стопка `rt-toaster` ставится один раз в корне
приложения, а сами тосты приходят **шиной**, а не входом.

```html
<!-- один раз в корне приложения -->
<rt-toaster position="bottom-right" [duration]="4000" [visibleToasts]="3" />
```

```typescript
const bus: NotificationBus = inject(NotificationBus);
bus.success('Договор сохранён');
bus.error('Не удалось отправить', { action: { label: 'Повторить', handler: retry } });
```

## Когда применять

- Короткое сообщение о состоявшемся действии, которое не требует ответа.
- Ошибка с одним действием «повторить», не перекрывающая работу.

## Когда не применять

- **Сообщение, которое надо держать перед глазами** — [`rt-message`](./?path=/docs/molecules-message-overview--docs):
  тост уходит сам, и прочитать его успевают не всегда.
- **Вопрос, на который нужен ответ** — [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs) или
  [`rt-confirm-popover`](./?path=/docs/organisms-dialog-confirm-overview--docs).

## Оси

| ось            | значения                                                      | умолчание       |
| -------------- | ------------------------------------------------------------- | --------------- |
| важность       | `info`, `success`, `warning`, `danger`                        | —               |
| заливка        | обычная, `filled`                                             | обычная         |
| состав         | сообщение, с описанием, с надстрочником, всё вместе           | сообщение       |
| действия       | без, одно, два                                                | без             |
| позиция стопки | шесть углов и центров                                         | `bottom-right`  |
| значок         | значок важности, свой `icon`, без значка (`icon: null`)       | значок важности |
| срок           | срок тостера, свой `duration`, до крестика (`duration: null`) | срок тостера    |
| полоса срока   | без, `progress: true`                                         | без             |
| режим стопки   | `stack`, `replace`                                            | `stack`         |

Важность перемножена с заливкой: `filled` меняет читаемость каждой палитры по-своему, и
расхождение видно только на этой паре. Остальные оси от важности не зависят и идут рядами.

Матрицы целятся в саму плашку `rt-toast`, а не в стопку: **тосты показываются не входом, а
шиной**, и вид плашки надо уметь показать без шины, таймеров и накопления. Поведение самой
стопки — накопление, сворачивание, автоуход — показано историями `rt-toaster`.

Четыре метода шины задают палитру и иконку: `success`, `info`, `warning`, `error`.

Свой значок, тост без значка и тост с полосой срока показывает история **Options**. Полоса там
стоит во всю ширину: плашка матрицы на паузе с первой отрисовки. Как полоса сжимается и как
работает режим `replace`, показывает `Playground` стопки — кнопками «С полосой срока» и
«До крестика».

## Параметры тоста

Третий аргумент методов шины, кроме описания, надстрочника, действий и заливки, несёт ещё четыре поля.

| поле        | тип                    | умолчание       | что делает                                                                             |
| ----------- | ---------------------- | --------------- | -------------------------------------------------------------------------------------- |
| `duration`  | `number \| null`       | срок тостера    | свой срок в миллисекундах; `null` — тост держится до крестика                          |
| `progress`  | `boolean`              | `false`         | полоса срока под тостом; встаёт вместе с таймером                                      |
| `icon`      | `IRtIcon.Name \| null` | значок важности | свой значок; `null` — тост без значка                                                  |
| `onDismiss` | `(reason) => void`     | нет             | зовётся один раз, если тост ушёл без действия: `'close'`, `'timeout'` или `'replaced'` |

Карту значков важности приложение подменяет токеном `RT_TOAST_SEVERITY_ICONS` — например, на
имена Material.

```typescript
providers: [
    { provide: RT_TOAST_SEVERITY_ICONS, useValue: { info: 'info', success: 'check-circle', warning: 'bell', danger: 'times-circle' } },
];
```

## Края

| край              | что происходит                                |
| ----------------- | --------------------------------------------- |
| длинное сообщение | переносится по словам, плашка растёт вниз     |
| длинное описание  | переносится, кнопки действий остаются под ним |
| пустое сообщение  | плашка остаётся с иконкой и кнопкой закрытия  |

## Состояния

| состояние   | чем задаётся           | что меняется                        |
| ----------- | ---------------------- | ----------------------------------- |
| обычное     | —                      | подложка по важности                |
| залитое     | `filled` в самом тосте | сплошная заливка вместо подложки    |
| в стопке    | `index` больше нуля    | плашка уходит назад и уменьшается   |
| развёрнутое | наведение на стопку    | плашки расходятся, таймеры встают   |
| вытесненное | новый тост в `replace` | плашка уходит своей анимацией ухода |

Новый тост встаёт **первым** — стопка растёт сверху.

## Доступность

- Стопка объявлена областью живых сообщений: новый тост читается скринридером без перевода
  фокуса.
- Наведение на стопку останавливает таймеры: тост не уйдёт из-под курсора.
- Кнопка закрытия несёт переведённое имя.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes** — все четыре важности сразу.

Цвета задаются ручками приложения на корне страницы: `--rt-toast-bg`, `--rt-toast-color`,
`--rt-toast-border-color`, `--rt-toast-icon-color`, `--rt-toast-close-color`,
`--rt-toast-action-color`, `--rt-toast-progress-color` и `--rt-toast-progress-height`. У залитого
тоста свои ручки по важности — `--rt-toast-filled-{важность}-bg`, `-color` и `-border-color`:
общая ручка фона его не перекрашивает. Слой стопки — свойство `--rt-toaster-z-index`, по умолчанию
шаг шкалы `--rt-z-sticky`. Всё вместе показывает история **Handles**; перечень ручек — на странице
Theming.

## Рядом

- [`rt-message`](./?path=/docs/molecules-message-overview--docs) — сообщение, остающееся на
  месте.
- [`rt-snack-bar`] первого кита — не путать: у китов разные стопки и разные шины.

## Входы

| вход              | тип                   | умолчание        | что делает                                      |
| ----------------- | --------------------- | ---------------- | ----------------------------------------------- |
| `position`        | `IRtToaster.Position` | `'bottom-right'` | угол, в котором копится стопка                  |
| `duration`        | `number`              | `4000`           | через сколько миллисекунд тост уходит сам       |
| `visibleToasts`   | `number`              | `3`              | сколько плашек видно, остальные в стопке        |
| `expand`          | `boolean`             | `false`          | стопка развёрнута всегда, а не по наведению     |
| `mode`            | `IRtToaster.Mode`     | `'stack'`        | `replace` — новый тост уводит прежние           |
| `toast`           | `IRtToaster.Toast`    | —                | сама плашка: важность, сообщение, действия      |
| `index`           | `number`              | `0`              | место плашки в стопке                           |
| `totalToasts`     | `number`              | `0`              | сколько плашек в стопке всего                   |
| `heights`         | `IRtToaster.Height[]` | `[]`             | высоты соседних плашек — из них считается сдвиг |
| `expanded`        | `boolean`             | `false`          | стопка развёрнута                               |
| `expandByDefault` | `boolean`             | `false`          | развёрнута с самого начала                      |
| `interacting`     | `boolean`             | `false`          | указатель над стопкой — таймеры стоят           |

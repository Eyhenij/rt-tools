<Title>Tooltip — `[rtTooltip]`</Title>

Короткая подсказка при наведении или фокусе. Директива вешается на что угодно, панель рисуется
в оверлее CDK — её не режет `overflow: hidden` у таблицы, панели или карточки.

```html
<button rtButton label="Удалить" rtTooltipPlacement="top" [rtTooltip]="'Удалить строку'"></button>
<rt-icon-button icon="ico-trash" ariaLabel="Удалить" tooltip="Удалить строку" />
```

## Когда применять

- Иконочная кнопка, у которой нет подписи, — подсказка называет действие словами.
- Усечённый текст или сокращение, которому нужна расшифровка.

## Когда не применять

- **В панели нужна разметка** — [`[rtPopover]`](./?path=/docs/atoms-popover-overview--docs):
  подсказка умеет только строку.
- **Текст нужен всегда, а не по наведению** — подпись поля или
  [`rt-info-item`](./?path=/docs/molecules-data-infoitem-overview--docs): с сенсорного экрана
  наведения не бывает.
- **Подсказка вместо доступного имени** — она вспомогательная, `aria-label` задаётся отдельно.

## Оси

| ось          | значения                                      | умолчание |
| ------------ | --------------------------------------------- | --------- |
| сторона      | `top`, `bottom`, `left`, `right`              | `top`     |
| длина текста | короткий, длинный (перенос при ширине 240 px) | —         |
| на чём висит | кнопка, иконочная кнопка, пустой текст        | —         |

**Оси, которых не видно.** Сторона — это только **первая** позиция: у края экрана CDK
разворачивает панель на противоположную. Боковой, не поместившейся ни слева, ни справа, достаётся
верх, затем низ: на узком экране она иначе легла бы на сам элемент. Бока логические — при письме
справа налево `left` встаёт справа. Показать разворот сеткой нечем — он зависит от места
на экране, а не от входа.

**Задержка показа не ось, а время.** Панель появляется через 300 мс: задержка гасит мелькание
при быстром проходе курсора по ряду кнопок. Уход курсора до её истечения не показывает ничего.

## Состояния

Своих состояний у панели нет: она либо есть, либо её нет. Показывают её наведение и фокус с
клавиатуры; прячут уход курсора, потеря фокуса и **щелчок** — панель мешала бы смотреть на
результат нажатия.

**Пустой текст выключает директиву целиком.** `''`, пробелы, `null`, `undefined` — всё это
ничего не делает, а не рисует пустую панель под курсором. Поэтому директиву вешают на иконочные
кнопки безусловно и «включают», выставив строку; в матрице **Hosts** такая ячейка намеренно
остаётся без панели.

## Доступность

- Панель несёт `role="tooltip"` и не перехватывает указатель (`pointer-events: none`) — иначе
  она гасила бы наведение на самом хосте.
- Показывается и по фокусу с клавиатуры, то есть достижима без мыши. Фокус, поставленный мышью
  или кодом, — например, возвращённый кнопке меню после выбора пункта, — подсказку не показывает.
- Доступное имя контрола подсказка **не** задаёт: `aria-label` ставится отдельно.

## Оформление

Подложка инверсная — `--rt-color-bg-inverse` с текстом `--rt-color-text-inverse`, скругление
`--rt-radius-sm`, тень `--rt-shadow-md`, ширина не больше 240 px. Инверсия разворачивается
вместе с темой; это и показывает светло-тёмная пара.

**В паре стоит сама панель `rt-tooltip`, а не директива.** Оверлей уезжает в контейнер CDK —
за пределы блока, которому пара назначает свойства темы, и по-другому обе темы рядом не увидеть.

## Входы

| вход            | тип                                              | умолчание                                                                 |
| --------------- | ------------------------------------------------ | ------------------------------------------------------------------------- |
| `text`          | `string \| null \| undefined`                    | `''`                                                                      |
| `placement`     | `'top' \| 'bottom' \| 'left' \| 'right' \| null` | `null` — из настроек кита, без них сверху, под материальным набором снизу |
| `whenTruncated` | `boolean`                                        | `false`                                                                   |
| `hideOnClick`   | `boolean`                                        | из настроек кита, без них `true`                                          |
| `showDelay`     | `number \| null`                                 | `null` — задержка из настроек кита, без них 300 мс                        |
| `showOnTap`     | `boolean`                                        | `false` — нажатие по хосту без своего действия открывает подсказку сразу  |

**Умолчания на всё приложение — раздел `tooltip` в `provideRtKit`.** `hideOnClick`, `placement` и
`showDelay` (задержка показа, по умолчанию 300 мс) задаются один раз; вход на элементе их перебивает.
`rt-icon-button` берёт умолчание `tooltipHideOnClick` оттуда же.

```typescript
provideRtKit({ components: { tooltip: { hideOnClick: false } } });
```

В разметке они пишутся под алиасами `rtTooltip`, `rtTooltipPlacement`, `rtTooltipWhenTruncated`, `rtTooltipHideOnClick`, `rtTooltipShowDelay` и `rtTooltipShowOnTap`:
имя директивы и есть имя входа текста. Вход текста принимает `null` и `undefined` и сам приводит
их к пустой строке — так `[rtTooltip]="value | date"` не ломает строгую типизацию шаблона.

**`rtTooltipWhenTruncated` показывает подсказку только у обрезанного текста.** Хост меряется в
момент показа: подсказка появляется, если его содержимое шире видимой коробки. Так ведут себя
ячейки таблицы и строки списков: у короткой подписи подсказка только повторяла бы её. Режим
показан историей `WhenTruncated`.

**`rtTooltipHideOnClick="false"` оставляет подсказку после клика.** Так ведёт себя
кнопка-переключатель: после нажатия подсказка остаётся и показывает новое состояние, потому что новый
текст `[rtTooltip]` меняется в открытой панели на месте. Касание на тач-экране подсказку не
показывает и с этим входом: клик снимает отложенный показ. Режим показан историей `KeepOnClick`.

**`rtTooltipShowDelay` задаёт задержку одной подсказке.** `rtTooltipShowDelay="500"` у группы
переключателей не трогает остальные подсказки приложения; `null` берёт общую задержку.

## Выходы

Выходов нет.

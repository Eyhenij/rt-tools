# `rt-dynamic-selector` + `rt-dynamic-input`

Поле формы со списком выбранных записей и поле, в котором строки набирают вручную.

```html
<rt-dynamic-selector keyExp="id" displayExp="name" draggable [entities]="people()" [formControl]="team" />
<rt-dynamic-input editable [formControl]="emails" />
```

Значение селектора — массив ключей в порядке списка, значение поля строк — массив строк.

## Главное, что нужно знать

**Записанное формой — это и список, и значение для сброса.** Сброс возвращает последнюю запись
формы и гаснет, пока список с ней совпадает в том же порядке. Пустой массив от формы опустошает
список.

**Очистка оставляет строки только для чтения.** У такой строки корзина выключена, и очистка гаснет,
когда в списке остались только они.

**Ключ, которого нет среди записей, остаётся в значении и строки не рисует.** Форма не теряет то,
чего не показала.

**Отметки всплывающего окна уходят только по «Применить».** «Отмена», `Escape` и щелчок мимо
снимают их, значение остаётся прежним.

**Вид приглашения, очистки, поиска и пустого результата задаёт приложение входами.** Значок и вид
кнопки приглашения — `invitationButtonIcon` и `invitationButtonAppearance`, значок очистки —
`clearIcon`, вид поля поиска окна — `searchAppearance`, подпись пустого результата —
`emptyResultsText`; у поля строк вид поля новой строки — `fieldAppearance`. Цвет кнопки «Добавить»
— ручка `--rt-dynamic-selector-list-add-color`: кнопку проецируют оба поля, и вид у неё разный.

**Поле строк срезает пробелы по краям и не добавляет пустое и повторное.** Повтор сравнивается
точно, с учётом регистра.

## Как этим пользоваться

- Серверный поиск: `[localSearch]="false"`, запрос приходит выходом `searchChange` через 500 мс
  после последней клавиши; найденное вызывающий кладёт в `entities`.
- Догрузка: `lazyLoad`, выход `loadMore`; пока идёт загрузка страницы, `fetching` держит запрос.
- Свои кнопки у строки — `<ng-template rtDynamicSelectorRowControls let-item>`, своё название —
  `<ng-template rtDynamicSelectorRowTitle let-item>`. Корзина и ручка перетаскивания остаются китовыми.
- Приглашение (`invitation`) встаёт вместо полосы кнопок; его кнопка открывает тот же выбор.
  `listActionsShown = false` убирает сброс и очистку, оставляя кнопку добавления;
  `removeShown = false` убирает корзину строк.
- Правки в своём шаблоне строки — `extraChanged`: сброс и очистка включены при прежних ключах и
  сообщают `listReset` и `listCleared`, значение сброс тогда не трогает.
- Начальный запрос окна — `searchTerm`, событием поиска он не уходит. Открыто ли окно — сигнал
  `popupOpen` и выход `popupOpenChange`.

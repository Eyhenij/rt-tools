<Title>FilterControl — `rt-filter-control`</Title>

Фильтр, который сам выбирает представление по ширине экрана: на широком — сегменты, на узком —
список. Потребитель передаёт один набор вариантов и об этом не думает.

```html
<rt-filter-control ariaLabel="Статус" [options]="statuses" [value]="status()" (valueChange)="status.set($event)" />
```

## Когда применять

- Фильтр над списком или таблицей, который должен работать и на широком экране, и на узком.
- Набор из трёх-пяти взаимоисключающих значений, где «ничего не выбрано» задаётся своей опцией
  («Все»), а не пустотой.

## Когда не применять

- **Представление должно быть одним и тем же везде** —
  [`rt-toggle-button-group`](./?path=/docs/components-togglebuttongroup-overview--docs)
  или [`rt-select`](./?path=/docs/components-select--docs) напрямую.
- **Нужен сброс в «ничего»** — очистка списка здесь выключена намеренно: фильтр всегда в
  каком-то состоянии.

## Оси

| ось               | значения                           | умолчание      |
| ----------------- | ---------------------------------- | -------------- |
| ширина экрана     | широкий (сегменты), узкий (список) | широкий        |
| размер            | `sm`, `md`, `lg`                   | `sm`           |
| наполнение        | только подписи, иконка и подпись   | —              |
| выбранный вариант | сброс («Все»), средний, последний  | —              |
| ширина            | по содержимому, `fullWidth`        | по содержимому |

**Главная ось — не вход, а экран.** Порог — 1080px (`BreakpointsService.narrow`), тот же, что у
`$breakpoint-lg` в стилях кита. Историю **Narrow** нельзя показать сужением окна витрины, поэтому
она подменяет саму службу брейкпоинтов: компонент спрашивает «узко ли», и в этой истории ответ —
«да».

**Что теряется в узком представлении.** Иконки вариантов доезжают только до сегментов; в списке
остаются одни подписи. Размер (`size`) тоже относится к сегментам — список всегда `md`.

## Состояния

Своих состояний взаимодействия у фильтра нет: он только выбирает, какой контрол нарисовать.
Наведение, фокус и раскрытие принадлежат
[`rt-toggle-button-group`](./?path=/docs/components-togglebuttongroup-overview--docs) и
[`rt-select`](./?path=/docs/components-select--docs) и показаны в их матрицах.

| состояние | чем задаётся    | что видно                                        |
| --------- | --------------- | ------------------------------------------------ |
| обычное   | —               | сегменты или список, смотря по ширине экрана     |
| выбран    | `value`         | подсвеченный сегмент или выбранная строка списка |
| отключено | вход `disabled` | гаснет то представление, что сейчас на экране    |

Отключение доходит до обоих представлений — это единственное состояние, которое фильтр
прокидывает сам.

## Доступность

- `ariaLabel` уходит в то представление, которое сейчас нарисовано: в `role="group"` у сегментов
  или в поле списка. Без него у контрола не будет доступного имени ни в одном из режимов.
- Порядок обхода клавиатурой отличается между режимами: сегменты — цепочка кнопок, список —
  одно поле с раскрытием. Это следствие подмены представления, а не настройка.

## Оформление

Своих свойств у фильтра нет: он показывает чужой контрол целиком и берёт его палитру. Проекция
вариантов в форму списка отбрасывает `icon` и `title`.

## Входы

| вход          | тип                                              | умолчание      |
| ------------- | ------------------------------------------------ | -------------- |
| `options`     | `ReadonlyArray<{ value, label, icon?, title? }>` | **обязателен** |
| `value`       | `T \| undefined`                                 | `undefined`    |
| `ariaLabel`   | `string \| null`                                 | `null`         |
| `placeholder` | `string`                                         | `''`           |
| `size`        | `'sm' \| 'md' \| 'lg'`                           | `'sm'`         |
| `disabled`    | `boolean`                                        | `false`        |
| `fullWidth`   | `boolean`                                        | `false`        |

`placeholder` виден только в узком представлении — в списке, пока ничего не выбрано.

## Выходы

| выход         | когда                                                        |
| ------------- | ------------------------------------------------------------ |
| `valueChange` | выбран вариант — в любом из двух представлений, со значением |

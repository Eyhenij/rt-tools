<Title>ExpansionPanel — `rt-expansion-panel`</Title>

Панель с заголовком-кнопкой во всю ширину и телом под ним. Нажатие на заголовок раскрывает и
сворачивает тело, шеврон у правого края поворачивается вслед. Раскрытие и сворачивание идут с
движением. Замена панели раскрытия Material из первого кита.

```html
<rt-expansion-panel [(expanded)]="open">
    <rt-icon name="user" size="sm" />
    <span>Личные данные</span>
    <ng-template rtExpansionPanelContent>
        <p>Имя, телефон и адрес доставки.</p>
    </ng-template>
</rt-expansion-panel>
```

## Когда применять

- Раздел настроек или формы, который нужен не всем: заголовок виден, содержимое — по нажатию.
- Строка списка, которая раскрывается вложенными строками: папка бокового меню, блок избранного.

## Когда не применять

- **Список вопросов с ответами-строками** — `rt-accordion`: пункты приходят данными, и разметку
  писать не нужно.
- **Один длинный текст** — `rt-collapsible-text`: у него нет заголовка, есть только «ещё».
- **Переключение между разделами** — `rt-tabs`: панель ничего не переключает, она раскрывает.

## Оси

| ось       | значения                                  | умолчание |
| --------- | ----------------------------------------- | --------- |
| вид       | карточка, простая                         | карточка  |
| раскрытие | свёрнута, раскрыта, без шеврона           | свёрнута  |
| длина     | короткий заголовок, режется, длинное тело | —         |

**Раскрытие — двусторонняя привязка.** Панель пишет в `expanded` сама. Владелец держит значение в
своём сигнале и меняет его извне: папка бокового меню раскрывается и стрелкой клавиатуры, и нажатием.
Движение раскрытия видно только в **Playground** — матрицы показывают положения.

## Тело

| как задано                              | когда создаётся                          |
| --------------------------------------- | ---------------------------------------- |
| `<ng-template rtExpansionPanelContent>` | при раскрытии, уходит после сворачивания |
| узел с атрибутом `rtExpansionPanelBody` | сразу, показывается при раскрытии        |

Всё остальное содержимое панели — заголовок. Подпись заголовка режет владелец: панель не знает,
что в нём лежит.

## Края

| край                           | что происходит                                              |
| ------------------------------ | ----------------------------------------------------------- |
| `disabled`                     | заголовок приглушён и не нажимается, тело остаётся как было |
| `hideToggle`                   | шеврона нет, заголовок нажимается как прежде                |
| браузер без `interpolate-size` | тело показывается и убирается сразу, без движения           |
| `prefers-reduced-motion`       | движения нет                                                |

## Состояния

| состояние       | чем задаётся  | что меняется                              |
| --------------- | ------------- | ----------------------------------------- |
| свёрнута        | умолчание     | виден заголовок, шеврон смотрит вниз      |
| раскрыта        | нажатие, вход | под заголовком тело, шеврон смотрит вверх |
| наведение       | указатель     | фон заголовка                             |
| фокус с клавиши | Tab           | кольцо фокуса кита внутри заголовка       |
| недоступна      | `disabled`    | приглушённый заголовок и шеврон           |

## Доступность

- Заголовок — кнопка с `aria-expanded`; у раскрытой панели — `aria-controls` на тело.
- Тело — регион с подписью по заголовку.
- `ariaLabel` даёт заголовку имя, когда видимой подписи мало: блок избранного называет им следующее
  нажатие.
- Клавиши — кнопочные: Enter и пробел раскрывают и сворачивают.

## Оформление

Карточка стоит на фоне поверхности с тенью и скруглением. Простая панель без фона, тени и отступов —
её строку рисует список, в котором она стоит. Размеры заголовка и тела — свойства
`--rt-expansion-panel-*`: владелец переназначает их правилом большей силы. Светлая и тёмная темы
стоят рядом в истории **Themes**.

## Рядом

- [`rt-accordion`](./?path=/docs/molecules-accordion-overview--docs) — список вопросов с ответами.
- [`rt-collapsible-text`](./?path=/docs/molecules-collapsibletext-overview--docs) — один текст с
  кнопкой «ещё».

## Входы

| вход         | тип                            | умолчание | что делает                                       |
| ------------ | ------------------------------ | --------- | ------------------------------------------------ |
| `disabled`   | `boolean`                      | `false`   | заголовок не нажимается                          |
| `hideToggle` | `boolean`                      | `false`   | шеврона нет                                      |
| `appearance` | `IRtExpansionPanel.Appearance` | `'card'`  | карточка или простая панель внутри списка        |
| `headerId`   | `string \| null`               | `null`    | id кнопки заголовка; без него — свой             |
| `ariaLabel`  | `string \| null`               | `null`    | имя кнопки заголовка для вспомогательных средств |

## Двусторонняя привязка

`[(expanded)]` — тело раскрыто, `boolean`, по умолчанию `false`. Панель пишет сюда сама при нажатии
на заголовок, владелец меняет значение извне.

## Выходы

| выход            | тип       | когда                                      |
| ---------------- | --------- | ------------------------------------------ |
| `expandedChange` | `boolean` | нажатие на заголовок раскрыло или свернуло |

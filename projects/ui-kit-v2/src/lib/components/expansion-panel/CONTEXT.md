# `rt-expansion-panel`

Раскрывающаяся панель: заголовок-кнопка во всю ширину с шевроном и тело под ним. Замена панели
раскрытия Material из первого кита.

```html
<rt-expansion-panel appearance="plain" [(expanded)]="open">
    <span>Заголовок</span>
    <ng-template rtExpansionPanelContent>Тело</ng-template>
</rt-expansion-panel>
```

| вход              | тип                            | умолчание |
| ----------------- | ------------------------------ | --------- |
| `expanded`        | `boolean` (model)              | `false`   |
| `disabled`        | `boolean`                      | `false`   |
| `hideToggle`      | `boolean`                      | `false`   |
| `appearance`      | `IRtExpansionPanel.Appearance` | `'card'`  |
| `headerId`        | `string \| null`               | `null`    |
| `ariaLabel`       | `string \| null`               | `null`    |
| `preserveContent` | `boolean`                      | `false`   |

Выход — `expandedChange`, половина двусторонней привязки.

## Главное, что нужно знать

**Панель пишет в `expanded` сама.** Владелец, который решает раскрытие по своим правилам, слушает
`expandedChange` и держит значение в своём сигнале. Отказ владельца изменить значение панель не
видит: привязка не передаёт то же самое значение второй раз. Такой владелец держит раскрытие в
`linkedSignal` и привязывает его в обе стороны — так делает блок избранного бокового меню.

**Тело двух видов.** `<ng-template rtExpansionPanelContent>` создаётся при раскрытии и уходит после
сворачивания, узел с `rtExpansionPanelBody` создаётся сразу. Всё прочее содержимое — заголовок.

**Движение — средствами CSS.** Высота тела идёт от нуля через `@starting-style` и
`interpolate-size`, уход доигрывает класс `rt-expansion-panel__body--leaving` через `animate.leave`.
Браузер без `interpolate-size` показывает тело сразу.

**Действия заголовка — узел с `rtExpansionPanelActions`.** Он стоит в строке заголовка вне кнопки,
и нажатие по нему панель не раскрывает. Шеврон тогда выходит из кнопки и встаёт после действий.

**Группа — `rtExpansionPanelGroup` на обёртке.** Раскрытие панели сворачивает остальные панели
обёртки, и вложенные в обёртки владельца тоже; `multi` это отключает. Панель встаёт в группу сама,
по токену `RT_EXPANSION_PANEL_GROUP`, и закрывает токен для своего тела: панель в теле панели в
группу не входит. Действия заголовка и ленивое тело ищутся на любой глубине, в обёртке владельца
тоже, но берутся только свои: директива запоминает ближайшую панель по `RT_EXPANSION_PANEL_OWNER`,
и шаблон вложенной панели остаётся ей.

**`preserveContent` прячет свёрнутое тело, а не убирает.** Тело получает модификатор `--collapsed`
и `inert`, высота уходит в ноль. Ленивое тело создаётся при первом раскрытии.

## Края

- Размеры заголовка и тела — свойства `--rt-expansion-panel-*`. Владелец переназначает их правилом
  двух классов на хосте: одного класса мало, он равен по силе объявлению самой панели на том же
  узле. Вложенная панель объявляет свои значения заново и чужих не наследует.
- Высоту строки и размер шрифта тела задают `--rt-expansion-panel-body-line-height` и
  `--rt-expansion-panel-body-font-size`. Панель их не объявляет: пока набор оформления их не дал,
  тело наследует оба значения, как прежде. Поэтому их можно задать и на предке, а не только на хосте.
- `--rt-expansion-panel-box-sizing` (по умолчанию `border-box`) задаёт box-sizing самой панели.
  С `content-box` хост шириной во весь контейнер вылезает за него на ширину своей рамки, если
  приложение её дало.
- `--rt-expansion-panel-body-box-sizing` задаёт box-sizing тела. Панель его не объявляет, и тело
  наследует значение от хоста. Потомкам тела оно достаётся, только если сброс стилей приложения
  наследует box-sizing: так набор Material даёт телу `content-box`, кружок радио со своей рамкой
  снова занимает 20 px, а хост остаётся во всю ширину контейнера.
- `headerId` нужен владельцу, который нажимает заголовок по своему номеру: боковое меню ищет строки
  по id.
- Id тела берётся из счётчика на экземпляр: две панели на странице не ссылаются на чужое тело.

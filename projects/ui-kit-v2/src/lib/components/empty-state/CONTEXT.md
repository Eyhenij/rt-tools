# `rt-empty-state`

```html
<rt-empty-state icon="folder" title="Файлов нет" description="Прикрепите первый документ">
    <img rtEmptyIllustration src="/img/empty.svg" alt="" />
    <button rtButton (click)="attach()">Прикрепить</button>
</rt-empty-state>
```

| вход          | тип                    | умолчание |
| ------------- | ---------------------- | --------- |
| `icon`        | `IRtIcon.Name \| null` | `null`    |
| `title`       | `string`               | `''`      |
| `description` | `string \| null`       | `null`    |

Выходов нет. Два слота проекции:

- `[rtEmptyIllustration]` — картинка над иконкой;
- слот по умолчанию — действие (кнопка).

## Главное, что нужно знать

**Каждая часть необязательна.** Пустой `title` не создаёт пустой строки в раскладке, `null`-иконка
и `null`-описание просто не рисуются. Заглушка без единого входа — законное состояние: остаётся
только слот действия.

## Как этим пользоваться

- Иконка рисуется крупной (`xl`, 32px) и приглушённой: это заглушка, а не аффорданс. Кликабельным
  должно быть проецируемое действие.
- Слот действия существует всегда, даже пустым; прячет его `:empty` в стилях.
- Размеры и подложка — свойства блока: `--rt-empty-state-icon-wrap-size`,
  `--rt-empty-state-icon-wrap-bg`, `--rt-empty-state-icon-size`, `--rt-empty-state-title-size`,
  `--rt-empty-state-title-weight`. Список ставит им назначения `--rt-list-empty-*`. Под
  материальным набором его заглушка рисуется как у первого кита: значок 48px без круга, заголовок
  32px весом 400.

<Title>Badge — `rtBadge`</Title>

Пузырёк-счётчик на углу любого элемента. Директива ставится на сам элемент, и пузырёк встаёт в него
последним узлом: обёртки нет.

```html
<span rtBadge="12" [rtBadgeOverlap]="false">Отели</span>
<rt-icon name="bell" rtBadgeColor="danger" [rtBadge]="unread()" />
```

## Когда применять

- Счётчик рядом с подписью вкладки или заголовка: «Отели 12».
- Непрочитанное у значка или пункта меню, отметка на ячейке календаря.

## Когда не применять

- **Статус записи словом** — [`rt-tag`](./?path=/docs/atoms-tag-overview--docs): у пузырька нет
  места под слово.
- **Живой счётчик с подписью** — [`rt-live-badge`](./?path=/docs/atoms-livebadge-overview--docs).

## Оси

| ось       | значения                                                          | умолчание     |
| --------- | ----------------------------------------------------------------- | ------------- |
| угол      | `above-after`, `above-before`, `below-after`, `below-before`      | `above-after` |
| наложение | поверх угла (`rtBadgeOverlap`), рядом                             | поверх        |
| размер    | `md`, `sm`                                                        | `md`          |
| цвет      | `primary`, `secondary`, `info`, `success`, `warning`, `danger`    | `primary`     |
| значение  | число, ноль, строка, пустое, `null`, `undefined`, `rtBadgeHidden` | `null`        |

Угол перемножен с наложением: пузырёк меняет место по обеим осям сразу. Поверх угла показан на
значке, рядом — на подписи, как их и ставят. Цвет перемножен с размером: маленький пузырёк меньше
кеглем, и читаемость видна на каждой заливке.

## Состояния

**Своих состояний взаимодействия у пузырька нет:** он не принимает ни фокус, ни нажатие, и
указатель проходит сквозь него к хосту.

| состояние | чем задаётся                                        | что меняется    |
| --------- | --------------------------------------------------- | --------------- |
| виден     | непустое значение                                   | пузырёк на углу |
| скрыт     | пустая строка, `null`, `undefined`, `rtBadgeHidden` | пузырька нет    |

Ноль — значение, а не пустота: пузырёк с нулём виден.

## Доступность

- Текст пузырька — часть хоста: подпись «Отели» с пузырьком читается как «Отели 12».
- Цвет не единственный носитель смысла: число в пузырьке читается и без цвета.

## Оформление

Хост получает класс `rt-badge-host` и `position: relative` в слое кита. Хосту со своей позицией
приложение задаёт её своим правилом. Размер, кегль, скругление и цвета — свойства `--rt-badge-*`.
Светлая и тёмная темы — история **Themes**.

## Входы

| вход              | тип                   | умолчание       |
| ----------------- | --------------------- | --------------- |
| `rtBadge`         | `IRtBadge.ValueInput` | `null`          |
| `rtBadgeOverlap`  | `boolean`             | `true`          |
| `rtBadgeHidden`   | `boolean`             | `false`         |
| `rtBadgePosition` | `IRtBadge.Position`   | `'above-after'` |
| `rtBadgeSize`     | `IRtBadge.Size`       | `'md'`          |
| `rtBadgeColor`    | `IRtBadge.Color`      | `'primary'`     |

## Выходы

Своих выходов нет.

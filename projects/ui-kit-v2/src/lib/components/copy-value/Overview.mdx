<Title>CopyValue — `rt-copy-value`</Title>

Значение, которое человек переносит в другое место, с кнопкой копирования: номер обращения, ключ,
идентификатор.

```html
<rt-copy-value label="Reference" copyLabel="Copy reference" [value]="error.referenceId" />
```

## Когда применять

- Номер обращения в сообщении об ошибке, ключ доступа, идентификатор записи, который просят
  передать в поддержку.

## Когда не применять

- **Ячейка таблицы** — `rt-copy-cell`: кнопка проявляется по наведению строки.
- **Длинный текст** — значение рассчитано на одну строку.

## Оси

| ось     | значения             | умолчание  |
| ------- | -------------------- | ---------- |
| подпись | нет, своя            | нет        |
| ширина  | помещается, обрезано | помещается |

## Состояния

- Покой: иконка `copy`, подсказка — `copyLabel` или «Copy».
- После нажатия две секунды: иконка `check`, подсказка «Copied».

## Доступность

- Кнопка — `rt-icon-button` с именем, равным подсказке; после копирования имя меняется на «Copied».
- Значение — текст на странице, его можно выделить и без кнопки.

## Оформление

Свойство блока: `--rt-copy-value-radius` — скругление подложки значения.

## Входы

| вход        | тип      | умолчание  |
| ----------- | -------- | ---------- |
| `value`     | `string` | обязателен |
| `label`     | `string` | `''`       |
| `copyLabel` | `string` | `''`       |

## Выходы

| выход         | значение                  |
| ------------- | ------------------------- |
| `copiedValue` | значение, ушедшее в буфер |

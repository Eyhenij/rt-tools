# `rt-copy-value`

```html
<rt-copy-value label="Reference" copyLabel="Copy reference" [value]="error.referenceId" />
```

| вход        | тип      | умолчание                    |
| ----------- | -------- | ---------------------------- |
| `value`     | `string` | обязателен                   |
| `label`     | `string` | `''` — не рисуется           |
| `copyLabel` | `string` | `''` → переведённое `uiCopy` |

Выход: `copiedValue` — значение, ушедшее в буфер.

Спек — `docs/specs/ui-kit-v2/copy-value/`; здесь только устройство папки.

## Главное, что нужно знать

**Копируется ровно `value`.** Отображаемое и копируемое совпадают: значение стоит на подложке
целиком, длинное обрезается многоточием, но в буфер уходит полностью.

## Края

- После нажатия подпись кнопки две секунды «Copied», иконка — галочка; таймер гасится при
  уничтожении.
- Корень шаблона — `ng-container`: класс блока висит только на хосте.

<Title>DateRange — `rt-date-range`</Title>

Поле периода со своей панелью: быстрые варианты, два месяца рядом, итог с числом дней. Значение —
**пара дней** `{ start, end }` в форме `YYYY-MM-DD`, оба края включены; пусто — `null`.

```html
<rt-field label="Период">
    <rt-date-range min="2026-01-01" max="2026-12-31" [formControl]="period" />
</rt-field>
```

## Когда применять

- Период «с какого по какое число», который пользователь выбирает сам — щелчками в панели, быстрым
  вариантом или набором двух дат через тире в порядке языка интерфейса.
- Период, ограниченный `min` / `max`: дни и варианты за границами выключены.

## Когда не применять

- **Одна дата или время** — [`rt-date-picker`](./?path=/docs/molecules-forms-datepicker-overview--docs).
- **Сетка месяцев без поля** — [`rt-calendar`](./?path=/docs/molecules-forms-calendar-overview--docs).
- **Период со временем** — такого поля в ките нет: в макете период — только даты.

## Оси

| ось           | значения                        | умолчание |
| ------------- | ------------------------------- | --------- |
| размер        | `sm`, `md`, `lg`                | `md`      |
| наполненность | пусто, диапазон, один день      | пусто     |
| рамка         | видна, снята (`bordered=false`) | видна     |
| вид           | `outline`, `fill`               | `outline` |

**Панель — в своих историях.** Поле кладёт её в поповер, за пределы блока истории, поэтому её
показывают истории раздела `Organisms/Forms/DateRangePanel`: `Selected`, `Selecting`, `Bounds`,
`Sheet` и `Themes` — выбранный диапазон, выбор даты окончания с будущим диапазоном под указателем,
границы, вид в нижней шторке и пара тем. «Сегодня» витрины — 20 октября 2026 года.

**Границы в покое не видны на самом поле.** `min` и `max` проявляются в панели — её показывает
история `DateRangePanel/Bounds`.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у поля нет             |
| фокус внутри  | `:focus-within`                      | рамка фокуса и `--rt-input-focus-shadow`           |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| ошибка набора | текст не читается как диапазон       | та же рамка ошибки; значение формы прежнее         |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | диапазон по локали, пустое — прочерком             |

## Панель

- Первый клик ставит начало, наведение рисует будущий диапазон, второй клик — конец. Клик раньше
  начала ставит дни по порядку, клик после готового диапазона начинает новый.
- Быстрые варианты: «Сегодня», «Вчера», «Последние 7 дней», «Последние 30 дней», «Этот месяц» (с
  первого числа по сегодня), «Прошлый месяц» (целиком). Вариант заполняет черновик и отмечен
  выбранным; вариант за границами выключен.
- Подвал: даты и число дней, пока выбрано только начало — «Выберите дату окончания». «Сбросить»
  очищает черновик, «Применить» выключена до выбора конца, пишет значение и закрывает панель.
- На узком экране — нижняя шторка: заголовок, варианты строкой с прокруткой вбок, один месяц, дни
  44 px под палец, в итоге только число дней.

## Доступность

- Подпись даёт вмещающий `rt-field`; без обёртки полю нужен `ariaLabel`.
- Кнопка панели несёт имя из метки кита `uiOpenCalendar`, группа вариантов — `uiQuickRanges`.
- В месяцах в обходе Tab стоит один день; стрелки, PageUp/PageDown, Home и End двигают его как
  сетку и листают месяцы, Enter выбирает, Escape закрывает панель. Выбранный вариант несёт
  `aria-pressed`, итог объявляется через `aria-live`.
- Ошибка объявляется атрибутом `aria-invalid` на поле — и ошибка формы, и ошибка набора.

## Оформление

Собственных свойств у поля нет: оно берёт группу `--rt-input-*` целиком и стоит в форме вровень с
`rt-input`. У панели два своих свойства: `--rt-date-range-panel-sheet-day-size` — размер дня в
шторке, `--rt-date-range-panel-divider-width` — толщина черт. Поверхность панели в поповере — та
же, что у панели `rt-select`.

## Входы

| вход         | тип                             | умолчание                 |
| ------------ | ------------------------------- | ------------------------- |
| `appearance` | `'outline' \| 'fill'`           | `'outline'`               |
| `min`        | `string \| null` — `YYYY-MM-DD` | `null`                    |
| `max`        | `string \| null` — `YYYY-MM-DD` | `null`                    |
| `radius`     | `TRtRadius \| null`             | `null` → скругление полей |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы. Половина диапазона в форму не попадает: значение пишется только «Применить» или набором
двух дат.

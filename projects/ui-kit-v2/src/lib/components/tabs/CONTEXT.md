# `rt-tabs` + `[rtTab]`

Вкладки объявляются директивой на `<ng-template>` — содержимое неактивной вкладки не создаётся;
с `preserveContent` тело открытой хоть раз вкладки живёт скрытым.

```html
<rt-tabs stretch [activeId]="tab()" (activeIdChange)="tab.set($event)">
    <ng-template rtTab="main" label="Основное">…</ng-template>
    <ng-template rtTab="extra" label="Дополнительно" [badge]="3">…</ng-template>
    <ng-template rtTab="docs" label="Документы" icon="file" [invalid]="hasErrors()">…</ng-template>
</rt-tabs>
```

## `rt-tabs`

| вход                | тип                          | умолчание      |
| ------------------- | ---------------------------- | -------------- |
| `activeId`          | `IRtTabs.Id \| null`         | `null`         |
| `direction`         | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `stretch`           | `boolean`                    | `false`        |
| `contentScrollable` | `boolean`                    | `true`         |
| `headerOnly`        | `boolean`                    | `false`        |
| `activation`        | `'auto' \| 'manual'`         | `'auto'`       |
| `scrollArrows`      | `'overlay' \| 'inline'`      | `'overlay'`    |
| `scrollStep`        | `'page' \| 'third'`          | `'page'`       |
| `animationDuration` | `string \| number \| null`   | `null`         |
| `preserveContent`   | `boolean`                    | `false`        |

Выходы: `activeIdChange: IRtTabs.Id`, `tabClose: IRtTabs.Id` — просьба закрыть вкладку с `closable`.

## `[rtTab]`

| вход                              | тип                                           | умолчание             |
| --------------------------------- | --------------------------------------------- | --------------------- |
| `rtTab`                           | `IRtTabs.Id` — идентификатор вкладки          | `''`                  |
| `label`                           | `string`                                      | `''`                  |
| `titleTemplate`                   | `TemplateRef \| null`                         | `null`                |
| `icon` / `iconColor`              | `IRtIcon.Name \| null` / `IRtTabs.TitleColor` | `null` / `'current'`  |
| `badge`                           | `string \| number \| null`                    | `null`                |
| `badgeTitle`                      | `string` — подсказка при наведении на метку   | `''`                  |
| `badgeAriaLabel`                  | `string` — подпись метки для чтения с экрана  | `''`                  |
| `disabled` / `hidden` / `invalid` | `boolean`                                     | `false`               |
| `invalidMessage`                  | `string`                                      | `''` → `uiTabInvalid` |
| `glyph`                           | `string \| null` — значок Material            | `null`                |
| `tooltip`                         | `string` — подсказка, и у отключённой         | `''`                  |
| `closable`                        | `boolean`                                     | `false`               |
| `closeTooltip`                    | `string` — подсказка крестика                 | `''`                  |
| `closeTooltipPlacement`           | `IRtTooltip.Placement \| null`                | `null`                |

## Главное, что нужно знать

**Вход `activeId` необязателен.** Без него компонент помнит выбор сам — управляемый режим нужен
только когда вкладка лежит в адресе страницы.

**Идентификатор, которого нет, откатывается на первую доступную вкладку.** То же с отключённой:
активной она стать не может. Так вкладка из старой ссылки не оставляет пустой экран.

**Контрол шапки объявляется `[rtTabsControl]` на `<ng-template>`.** Сторона задаётся значением
директивы: `rtTabsControl="left"` слева, `[rtTabsControl]="side"` — вычисленной стороной. Без
значения контрол встаёт справа — пустая строка приводится к правой стороне намеренно, иначе
`<ng-template rtTabsControl>` не попадал бы ни в один слот и пропадал из шапки вовсе.

## Клавиатура и доступность

- Стрелки (влево/вправо, а в вертикальной раскладке вверх/вниз) перешагивают отключённые вкладки
  и заворачиваются по кругу; `Home`/`End` — к первой и последней.
- `activation="manual"`: стрелки и `Home`/`End` только переводят фокус, вкладку открывают `Enter`
  и `Space`. По умолчанию (`auto`) стрелка открывает вкладку сразу.
- В таб-порядке стоит **одна** вкладка (`tabindex="0"`): активная, а в ручном режиме — та, на
  которую перевели фокус. Остальные достаются стрелками.
- Панель и вкладка связаны в обе стороны: `aria-controls` ↔ `aria-labelledby`.

## Края

- `hidden` убирает вкладку из шапки целиком; `disabled` оставляет её видимой, но некликабельной.
- У невалидной вкладки появляется подсказка с текстом `invalidMessage`.
- Метка без `badgeTitle` и `badgeAriaLabel` рисуется как прежде: голое значение, без подсказки и
  без подписи. Подсказка метки — своя, на самой метке: подсказка кнопки занята неверной вкладкой.
- Отключённая вкладка помечена `aria-disabled`, не `disabled`: иначе на неё не навести, и её
  подсказка не показалась бы. Клик по ней ничего не выбирает.
- Крестик закрываемой вкладки — `span` с `aria-hidden`, не кнопка: кнопка внутри кнопки-вкладки
  недопустима. С клавиатуры закрывает `Delete`; фокус после закрытия встаёт на активную вкладку.
- У крестика своя подсказка `closeTooltip`; пока указатель на нём, подсказка вкладки пуста. Вид
  крестика — свойства `--rt-tab-item-close-*` на `.rt-tab-item`; размер иконки идёт через шаг `xs`
  самой иконки, её ширина задана стилем на теге.
- `headerOnly` убирает панель и `aria-controls` у вкладок; выбор по-прежнему уходит в `activeIdChange`.
- Стрелки прокрутки шапки есть в разметке всегда — показывает их модификатор `--visible`,
  который выставляется по замеру ширины после отрисовки.
- Нажатие на стрелку плавно сдвигает полосу на ширину видимой области (`scrollStep="third"` — на её
  треть), удержание дольше 300 мс прокручивает непрерывно. Вкладка, выбранная частично скрытой,
  въезжает в видимую область так же плавно; длительность и кривая — `--rt-tabs-scroll-duration` и
  `--rt-tabs-scroll-easing`, вход `animationDuration` их не трогает. Указатель, ушедший со стрелки до отпускания, полосу не сдвигает.
- Смена вкладки движется: полоса — один элемент полосы вкладок, переезжает на новую вкладку; панель
  прежней уходит, новая въезжает по направлению перехода. Длительности — токены
  `--rt-tabs-indicator-duration` и `--rt-tabs-panel-duration` (своё умолчание панели — `0ms`, смена
  на месте) или вход `animationDuration` для обоих; `prefers-reduced-motion` снимает движение.
  Пока панель уходит, якорь `tabs-panel` стоит только на новой, у уходящей — `tabs-panel-leaving`.
- `preserveContent`: тело создаётся при первом открытии вкладки и дальше живёт; неактивное скрыто
  (`hidden`, `inert`, `aria-hidden`, вне таб-порядка) с якорем `tabs-panel-idle`. Уходит при смене
  живое тело прежней вкладки. Тело вкладки, убранной из набора, уничтожается вместе с ней.
- `scrollArrows="inline"`: при переполнении обе стрелки стоят по краям, полоса между ними уже;
  стрелка, в сторону которой прокручивать некуда, бледная и не нажимается.

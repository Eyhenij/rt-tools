<Title>Tabs — `rt-tabs`, `[rtTab]`, `[rtTabsControl]`</Title>

Вкладки с полосой заголовков и содержимым под ней. Вкладки объявляются разметкой — директивой
`rtTab` на шаблоне, — а не входом-набором: содержимое каждой лежит там же, где написано.

```html
<rt-tabs [activeId]="tab()" (activeIdChange)="tab.set($event)">
    <ng-template rtTab id="overview" label="Обзор" icon="ico-listing">Сводка</ng-template>
    <ng-template rtTab id="members" label="Участники" [badge]="3">Список</ng-template>
    <ng-template rtTab disabled id="billing" label="Оплата">Недоступно</ng-template>
</rt-tabs>
```

## Когда применять

- Переключение содержимого на месте, когда разделов немного и они равноправны.
- Форма, разбитая на части, — тогда часть с ошибками помечается входом `invalid`.

## Когда не применять

- **Переход на другой экран** — [`rt-section-nav`](./?path=/docs/molecules-navigation-sectionnav-overview--docs).
- **Шаги, идущие по порядку** — [`rt-stepper`](./?path=/docs/atoms-feedback-stepper-overview--docs).

## Оси

| ось               | значения                                                         | умолчание      |
| ----------------- | ---------------------------------------------------------------- | -------------- |
| раскладка         | `horizontal`, `vertical`                                         | `horizontal`   |
| растяжение        | по содержимому, `stretch`                                        | по содержимому |
| заголовок вкладки | подпись, с иконкой, со значком, иконка и значок, значок Material | подпись        |
| состояние вкладки | обычная, активная, отключённая, с ошибкой, со значком, скрытая   | обычная        |
| закрытие          | без крестика, `closable`                                         | без крестика   |
| панель            | с панелью, `headerOnly`                                          | с панелью      |

**Ось, которую нельзя показать статикой.** `tooltip` превращается во всплывающую подсказку и до
наведения не отрисован; история **IconOnly** показывает вкладки, у которых она есть.

Виды вкладки показаны одной полосой, где стоят все сразу: порознь их не сравнить — вид вкладки
читается только рядом с соседями. Скрытая показана там же отсутствием: `hidden` убирает её из
полосы вовсе, и ячейки под неё нет — это и есть её вид.

**Вход `activeId` необязателен.** Без него компонент помнит выбор сам; управляемый режим нужен
только когда вкладка лежит в адресе страницы.

## Края

| край                   | что происходит                                                                 |
| ---------------------- | ------------------------------------------------------------------------------ |
| ни одной вкладки       | полоса пуста, содержимого нет                                                  |
| одна вкладка           | полоса из одной, переключать нечего                                            |
| неизвестный `activeId` | откат на первую доступную — вкладка из старой ссылки не оставляет пустой экран |
| активная отключена     | активной она стать не может, откат туда же                                     |
| вкладок больше ширины  | по краям полосы появляются стрелки прокрутки                                   |
| нажатие на стрелку     | полоса сдвигается на ширину видимой области; удержание прокручивает непрерывно |

## Состояния

| состояние   | чем задаётся            | что меняется                                                               |
| ----------- | ----------------------- | -------------------------------------------------------------------------- |
| обычная     | —                       | подпись приглушённым цветом                                                |
| активная    | совпадение с `activeId` | подпись ярче, под ней подчёркивание                                        |
| отключённая | вход `disabled`         | приглушена, не нажимается, пропускается стрелками, но показывает подсказку |
| с ошибкой   | вход `invalid`          | подпись красным, рядом сообщение `invalidMessage`                          |
| скрытая     | вход `hidden`           | вкладки нет в полосе вовсе                                                 |

## Доступность

- Полоса объявлена `role="tablist"` с `aria-orientation` по раскладке.
- Стрелки — влево-вправо, а в вертикальной раскладке вверх-вниз — перешагивают отключённые
  вкладки и заворачиваются по кругу; `Home` и `End` ведут к первой и последней.
- С `activation="manual"` стрелки и `Home`/`End` только переводят фокус, а вкладку открывают
  `Enter` и `Space`: тяжёлая панель не перестраивается на каждом шаге.
- Ошибка передаётся текстом `invalidMessage`, а не только цветом подписи.
- Значок объясняется словами: `badgeAriaLabel` — подпись для чтения с экрана, `badgeTitle` —
  подсказка при наведении. Без них значок читается голым значением.
- Отключённая вкладка помечена `aria-disabled`, а не атрибутом `disabled`: на кнопку с `disabled`
  браузер не даёт навести, и подсказка «почему недоступна» не показалась бы.
- Вкладка без подписи — из одного значка — называется своей подсказкой `tooltip`.
- Крестик закрываемой вкладки — не кнопка: кнопка внутри кнопки-вкладки недопустима. С клавиатуры
  вкладку закрывает `Delete`, вкладка объявляет это `aria-keyshortcuts`. После закрытия фокус встаёт
  на вкладку, которая стала активной.
- В режиме `headerOnly` панели `role="tabpanel"` нет, и вкладки не ссылаются на неё
  `aria-controls`.

## Закрываемые вкладки

Набор вкладок держит потребитель, поэтому вкладка сама не исчезает: крестик и `Delete` поднимают
`tabClose` с её идентификатором, а убирает её потребитель. Закрытая активная откатывается на первую
доступную, и `activeIdChange` сообщает новую активную: владелец, держащий `activeId`, не хранит id
закрытой вкладки. У отключённой вкладки крестика нет.

```html
<rt-tabs (tabClose)="close($event)">
    @for (report of reports(); track report.id) {
    <ng-template closable closeTooltip="Закрыть" [rtTab]="report.id" [label]="report.label">…</ng-template>
    }
</rt-tabs>
```

У крестика своя подсказка — `closeTooltip`, сторона — `closeTooltipPlacement`. Пока указатель на
крестике, подсказка самой вкладки молчит: видна только подсказка крестика. Вид крестика задают
свойства на `.rt-tab-item`:

| свойство                                  | умолчание                                  | что задаёт                     |
| ----------------------------------------- | ------------------------------------------ | ------------------------------ |
| `--rt-tab-item-close-size`                | `var(--rt-size-5)`                         | размер круга                   |
| `--rt-tab-item-close-radius`              | `var(--rt-radius-full)`                    | скругление круга               |
| `--rt-tab-item-close-bg`                  | `transparent`                              | фон в покое                    |
| `--rt-tab-item-close-bg-hover`            | `var(--rt-color-bg-hover)`                 | фон при наведении              |
| `--rt-tab-item-close-color`               | `var(--rt-color-text-muted)`               | цвет иконки в покое            |
| `--rt-tab-item-close-color-hover`         | `var(--rt-color-text-primary)`             | цвет иконки при наведении      |
| `--rt-tab-item-close-icon-size`           | `var(--rt-icon-step-xs, var(--rt-size-3))` | размер иконки                  |
| `--rt-tab-item-close-margin-inline-start` | `0`                                        | отступ от подписи сверх зазора |
| `--rt-tab-item-close-margin-inline-end`   | `calc(-1 * var(--rt-space-2))`             | отступ до края вкладки         |

## Только полоса

`headerOnly` оставляет одну полосу: вкладки служат навигацией, а содержимое лежит в другом месте —
например, полоса стоит в середине `rt-toolbar`. Вкладкам тогда содержимое не нужно.

```html
<rt-tabs headerOnly [activeId]="section()" (activeIdChange)="section.set($event)">
    <ng-template rtTab="rooms" label="Номера" />
    <ng-template rtTab="rates" label="Тарифы" />
</rt-tabs>
```

## Движение при смене вкладки

Полоса выбранной вкладки — один элемент на всю полосу: при смене выбора она переезжает со старой
вкладки на новую. Панель прежней вкладки уходит в сторону, обратную переходу, новая въезжает следом:
к вкладке правее — справа, к вкладке левее — слева. Уходящая панель — та же, что была открыта, а не
её копия, и пока она уходит, она не читается с экрана и не берёт фокус.

| токен                          | своё умолчание            | что задаёт              |
| ------------------------------ | ------------------------- | ----------------------- |
| `--rt-tabs-indicator-duration` | `var(--rt-duration-base)` | время переезда полосы   |
| `--rt-tabs-indicator-easing`   | `ease-out`                | кривая переезда полосы  |
| `--rt-tabs-panel-duration`     | `0ms`                     | время смены панели      |
| `--rt-tabs-panel-easing`       | `ease-out`                | кривая смены панели     |
| `--rt-tabs-scroll-duration`    | `var(--rt-duration-base)` | время прокрутки полосы  |
| `--rt-tabs-scroll-easing`      | `ease-out`                | кривая прокрутки полосы |

В своём виде кита панель меняется на месте: её длительность — ноль. Материальный набор задаёт всем
трём движениям полсекунды с кривой вкладок Material. Вход `animationDuration` задаёт длительность
полосы и панели, как у `mat-tab-group`: `500` и `'500'` — миллисекунды, `'0.5s'` — как есть, `0`
выключает их движение. Прокрутку полосы вход не трогает — так и у Material: её длительность задаёт
только токен. `prefers-reduced-motion` снимает движение целиком, прокрутку тоже.

Прокрутка переполненной полосы — стрелками и к выбранной вкладке, скрытой с края, — тоже плавная.
Двигается сама прокрутка полосы, а не сдвиг её содержимого: колесо и касание работают как обычно.
Шаг нажатия на стрелку задаёт `scrollStep`: `page` — на видимую ширину, `third` — на её треть, как
у Material. Удержание стрелки прокручивает непрерывно и без плавности.

```html
<rt-tabs animationDuration="500ms">…</rt-tabs>
```

## Сохранение содержимого вкладок

По умолчанию тело вкладки создаётся, когда её открывают, и уничтожается, когда с неё уходят:
введённое на ней пропадает. `preserveContent` держит тело открытой хоть раз вкладки, как
`preserveContent` у `mat-tab-group`: неактивное тело скрыто, не читается с экрана и вне
таб-порядка, а вкладка, которую не открывали, по-прежнему не создаётся. Смена панели движется так
же: уходит живое тело прежней вкладки и после движения остаётся скрытым.

```html
<rt-tabs preserveContent animationDuration="500ms">…</rt-tabs>
```

## Входы

| вход                    | тип                            | умолчание      | что делает                                      |
| ----------------------- | ------------------------------ | -------------- | ----------------------------------------------- |
| `activeId`              | `IRtTabs.Id \| null`           | `null`         | открытая вкладка; без него компонент помнит сам |
| `direction`             | `IRtTabs.Direction`            | `'horizontal'` | раскладка полосы                                |
| `stretch`               | `boolean`                      | `false`        | вкладки делят ширину поровну                    |
| `contentScrollable`     | `boolean`                      | `true`         | содержимое прокручивается внутри своей области  |
| `headerOnly`            | `boolean`                      | `false`        | только полоса, без панели содержимого           |
| `activation`            | `IRtTabs.Activation`           | `'auto'`       | стрелки открывают вкладку или только фокус      |
| `scrollArrows`          | `IRtTabs.ScrollArrows`         | `'overlay'`    | стрелки поверх вкладок или в своих местах       |
| `scrollStep`            | `IRtTabs.ScrollStep`           | `'page'`       | шаг стрелки: видимая ширина или её треть        |
| `animationDuration`     | `IRtTabs.AnimationDuration`    | `null`         | длительность переезда полосы и смены панели     |
| `preserveContent`       | `boolean`                      | `false`        | тело открытой хоть раз вкладки живёт скрытым    |
| `side`                  | `IRtTabs.ControlSide`          | `'right'`      | сторона, с которой встаёт `[rtTabsControl]`     |
| `id`                    | `IRtTabs.Id`                   | —              | идентификатор вкладки                           |
| `label`                 | `string`                       | `''`           | подпись вкладки                                 |
| `titleTemplate`         | `TemplateRef \| null`          | `null`         | свой заголовок вместо подписи                   |
| `icon`                  | `IRtIcon.Name \| null`         | `null`         | иконка слева от подписи                         |
| `glyph`                 | `string \| null`               | `null`         | значок Material вместо `icon`                   |
| `iconColor`             | `IRtTabs.TitleColor`           | `'current'`    | цвет иконки                                     |
| `badge`                 | `string \| number \| null`     | `null`         | значок справа от подписи                        |
| `badgeTitle`            | `string`                       | `''`           | подсказка при наведении на значок               |
| `badgeAriaLabel`        | `string`                       | `''`           | подпись значка для чтения с экрана              |
| `disabled`              | `boolean`                      | `false`        | вкладка не выбирается и пропускается стрелками  |
| `hidden`                | `boolean`                      | `false`        | вкладки нет в полосе вовсе                      |
| `invalid`               | `boolean`                      | `false`        | вкладка помечена ошибкой                        |
| `invalidMessage`        | `string`                       | `''`           | текст ошибки рядом с подписью                   |
| `tooltip`               | `string`                       | `''`           | подсказка при наведении, и у отключённой        |
| `closable`              | `boolean`                      | `false`        | крестик и `Delete` просят закрыть вкладку       |
| `closeTooltip`          | `string`                       | `''`           | подсказка крестика                              |
| `closeTooltipPlacement` | `IRtTooltip.Placement \| null` | `null`         | сторона подсказки крестика                      |

| `activeIdChange` | выбрана другая вкладка                         |

# `rt-input`

```html
<rt-field label="Имя">
    <rt-input placeholder="Как в паспорте" iconLeft="search" [formControl]="name" />
</rt-field>

<rt-input type="password" [formControl]="password" [passwordToggle]="true" />
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md)
(`size`, `disabled`, `controlId`, `ariaLabel`, `clearable`, `clearTabbable`, `bordered`):

| вход                                   | тип                                                  | умолчание |
| -------------------------------------- | ---------------------------------------------------- | --------- |
| `type`                                 | `'text' \| 'password' \| 'email' \| 'time' \| 'url'` | `'text'`  |
| `placeholder`                          | `string`                                             | `''`      |
| `iconLeft` / `iconRight`               | `IRtIcon.Name \| null`                               | `null`    |
| `iconLeftAction` / `iconRightAction`   | `boolean`                                            | `false`   |
| `iconLeftTooltip` / `iconRightTooltip` | `string \| null`                                     | `null`    |
| `floatingLabel`                        | `string \| null`                                     | `null`    |
| `passwordToggle`                       | `boolean`                                            | `false`   |
| `autocomplete`                         | `string \| null`                                     | `null`    |
| `maxlength`                            | `number \| null`                                     | `null`    |

| выход                              | тип          |
| ---------------------------------- | ------------ |
| `iconLeftClick` / `iconRightClick` | `MouseEvent` |
| `cleared`                          | `void`       |

Значение — `string`. `maxlength` уходит атрибутом на поле: браузер не даёт набрать больше, а
значение из кода не режет, поэтому проверка формы остаётся за приложением.

## Главное, что нужно знать

**Крестик очистки и переключатель пароля делят один постфикс.** На поле пароля с включённым
переключателем крестика не будет: показать оба некуда.

Крестик показывается при выполнении трёх условий сразу: `clearable` (по умолчанию включён),
в поле есть значение, поле не отключено. Из порядка Tab он исключён, пока поле не попросит
`clearTabbable`. После сброса приходит `cleared` — когда пустое значение уже ушло в форму.

Размер, цвет, подложку и отступы крестика задают свойства `--rt-input-clear-*`. В своём виде кита
крестик без подложки; под материальным набором это крестик первого кита: кнопка 19 px на круглой
серой подложке, значок 12 px, 8 px от края. Поле с `clearable` несёт класс `rt-input--clearable`.

**Иконка с `iconLeftAction` или `iconRightAction` становится кнопкой.** Она берёт фокус с
клавиатуры, нажимается мышью, Enter и пробелом и показывает подсказку из `iconLeftTooltip`. Без
входа иконка остаётся картинкой.

**`floatingLabel` — подпись на рамке.** Пустое поле в покое показывает подпись на месте подсказки,
значение или фокус поднимают её на рамку, и рамка под ней разрывается. Высота поля не меняется.

## Как этим пользоваться

- `type="url"` объявляет браузеру род значения, а не требование к нему: на телефоне он даёт
  клавиатуру для адреса и разбор вставленного, а проверка введённого остаётся за приложением.
- `type="time"` заведён намеренно: браузер сам отдаёт `HH:MM` и раскладку под локаль, а разбор
  строки руками означал бы своё поле ввода времени рядом с китом.
- Клик по рамке (падинги принадлежат host-у, а не `<input>`) переводит фокус в поле — кроме
  кликов по самому полю и по интерактивному постфиксу.
- Режим плоского чтения включает **вмещающий [`rt-field`](../field/CONTEXT.md)**, а не вход
  компонента: `[readonly]` стоит на поле-обёртке. Пустое значение в этом режиме рисуется прочерком.
- Подсветка ошибки (`rt-input--invalid`) включается сама после касания — см. основу полей.

**Кнопка-значок отключается своим входом.** `iconLeftDisabled` и `iconRightDisabled` отключают
только кнопку, поле остаётся доступным; подсказка кнопки остаётся и объясняет почему.

**Под материальным набором кнопка-значок не выше поля без рамки.** Ширину и высоту внутренней
кнопки поле под набором ограничивает `min()` от размера кнопки и своей высоты: низкое поле плотности
или своей высоты приложения не растёт до высоты кнопки. Свой вид кита держит размер кнопки, и малое
поле с крестиком в нём 34 px, как до набора.

## Межбуквенный интервал

Значение берёт интервал из ручки `--rt-input-letter-spacing`, общей для поля, числа, выбора и
текста. Кит её не объявляет: без неё интервал `normal`.

<Title>SideMenu — `rt-side-menu`</Title>

Боковая навигация приложения: полоса пунктов с иконками и подменю раздела рядом с ней. Перенос
бокового меню первого кита на части второго. Подменю держится наведением или закреплением, в нём
есть поиск, папки и ручка ширины.

```html
<rt-side-menu menuId="main" [menuItems]="sections()" [activeMenuIds]="activeIds()">
    <ng-template rtSideMenuHeader>…</ng-template>
    <ng-template rtSideMenuFooter>…</ng-template>
    <ng-template rtSideMenuIcon let-item>…</ng-template>
</rt-side-menu>
```

## Когда применять

- Главная навигация приложения по разделам, у которых есть свои страницы.
- Разделы с вложенными страницами: подменю показывает их списком с поиском и папками.

## Когда не применять

- **Меню действий над записью** — `rt-menu`: выпадающее меню, а не навигация. Боковое меню его не
  заменяет, и `rt-menu` не заменяет боковое.
- **Переход между разделами одного экрана** — `rt-section-nav`, плитки разделов.

## Оси

| ось              | значения                                       | умолчание    |
| ---------------- | ---------------------------------------------- | ------------ |
| режим подменю    | наведение, закрепление                         | наведение    |
| ширина подменю   | ширина оформления, от 120 до 480 пикселей      | оформление   |
| поиск            | пустой, совпадение в папке, ничего не найдено  | пустой       |
| папки            | свёрнута, раскрыта адресом, раскрыта нажатием  | свёрнута     |
| ширина экрана    | широкий — полоса и панель, узкий — столбец 240 | —            |
| избранное        | выключено, включено у пункта полосы флагом     | выключено    |
| число в блоке    | всегда, у свёрнутого блока, никогда            | у свёрнутого |
| место под кнопки | отдаётся подписи, держится всегда              | отдаётся     |

**Активность приходит снаружи.** Какие пункты активны, меню узнаёт из `activeMenuIds`; нажатие
ведёт по ссылке, подсветку двигает новый набор после перехода.

**Режим и ширина — настройка человека.** С `provideRtSideMenuSettings()` они помнятся в хранилище
под номером меню `menuId` и переживают перезагрузку. Входы `subMenuMode` и `subMenuWidth` важнее
сохранённого. С `pinShown="false"` кнопки закрепления нет, и сохранённое закрепление не читается:
подменю всплывает, пока режим не задан входом. `subMenuTooltipsShown="false"` гасит подсказки строк
подменю; имена кнопок для чтения экрана остаются. Оба — в истории `Switches`.

**Вид первого кита.** `railTitlesShown="false"` убирает подписи под значками полосы: имя пункта
уходит в подсказку справа и в доступное имя пункта. Подсказку гасит тот же `subMenuTooltipsShown`.
`railIconFill` заливает значки полосы. `searchSize` и `searchAppearance` задают поле поиска подменю,
как у `rt-input`: размер `md` даёт высоту 40. Строка и папка подменю несут номер пункта в
`data-item-id` — по нему приложение находит строку, например открывающую страницу раздела. Всё
вместе — в истории `FirstKitLook`.

**Избранное — как у первого кита, без Material.** У пункта полосы с флагом `favorites` в подменю
стоят звёзды у пунктов со ссылкой, а вверху — блок «Избранное»: сворачивается заголовком, строки
тянутся за ручку и переставляются стрелками на ней, «убрать» снимает пункт. Список и свёрнутые блоки
лежат в тех же настройках меню; без `provideRtSideMenuSettings()` ни звёзд, ни блока нет. Пункт с
`favoriteDisabled` звезды не получает. Значки «убрать» и ручки меняются настройкой `icons`.

**Значки — имя кита или имя Material первого кита.** Имя Material рисуется своей парой из перечня
кита, как у `rt-menu`; так же — значок кнопки строки. Имя, которого кит не рисует, берёт свой
шаблон меню `<ng-template rtSideMenuIcon let-item let-icon="icon" let-slot="slot">`: он один на
меню, получает пункт, рисуемое имя и место — `'icon'` у пункта или `'iconButton'` у кнопки строки —
и встаёт на место значка его размером и цветом строки. Кнопка строки остаётся кнопкой кита, шаблон
рисует только её знак. Значок, который кит рисует сам, шаблон не перебивает. Имя без значка и без
шаблона в режиме разработки названо в предупреждении консоли. Всё вместе — в истории `Icons`.

## Края

| край            | что происходит                                               |
| --------------- | ------------------------------------------------------------ |
| пустой набор    | рисуется пустая полоса                                       |
| длинная подпись | строка подменю режется многоточием, полное имя — в подсказке |
| отказ хранилища | меню работает, выбор не переживает перезагрузку              |
| пустой `menuId` | читается как не заданный — номер `main`                      |

## Состояния

| состояние             | чем задаётся                | что меняется                                  |
| --------------------- | --------------------------- | --------------------------------------------- |
| обычное               | —                           | прозрачный фон                                |
| наведение             | `:hover`                    | подложка значка пункта или строки             |
| фокус с клавиши       | `:focus-visible`            | кольцо вокруг значка или строки               |
| активный              | модификатор `--active`      | подложка и цвет основного действия            |
| подсветка стрелкой    | модификатор `--highlighted` | подложка строки подменю                       |
| подменю взято поиском | модификатор панели `--held` | панель шире и не закрывается уходом указателя |

## Доступность

- Пункт со ссылкой — настоящая ссылка `<a href>`, раздел без адреса и папка — `<button>`.
- Активная ссылка помечена `aria-current="page"`, папка — `aria-expanded`.
- В поле поиска стрелки ходят по видимым строкам, вправо и влево раскрывают папку, Enter открывает
  строку, Escape стирает запрос.
- Ручка ширины — `role="separator"` со значениями для диктора; стрелки шагают на 16 пикселей,
  `Home` и `End` ведут к пределам.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**, базовый и материальный наборы — половинами
каждой истории матрицы. Живые истории во весь экран повторяют страницы первого кита и пар не
получают: избранное в обоих наборах показывает история **Favorites**. Кнопка закрепления рисует
булавку, как у первого кита.

Свойства меню задаются на `rt-side-menu` или выше, свойства строки — на `rt-side-menu-sub-item`.
Без них меню выглядит как раньше.

| свойство                                 | что задаёт                                   | умолчание                              |
| ---------------------------------------- | -------------------------------------------- | -------------------------------------- |
| `--rt-side-menu-rail-icon-size`          | сторона значка полосы                        | ступень значка `md`                    |
| `--rt-side-menu-rail-gap`                | зазор между пунктами полосы                  | `--rt-space-md`                        |
| `--rt-side-menu-rail-bg`                 | фон полосы                                   | `--rt-color-bg-surface`                |
| `--rt-side-menu-rail-border-width`       | толщина черты справа от полосы               | `--rt-side-menu-panel-border-width`    |
| `--rt-side-menu-panel-bg`                | фон панели подменю                           | `--rt-color-bg-surface`                |
| `--rt-side-menu-panel-head-padding`      | отступ шапки панели с поиском                | `--rt-space-sm`                        |
| `--rt-side-menu-sub-list-padding-inline` | отступ списка подменю от краёв панели        | `--rt-space-2`                         |
| `--rt-side-menu-item-color`              | цвет пункта полосы и строки телефона в покое | цвет меню                              |
| `--rt-side-menu-item-bg-hover`           | подложка пункта и строки под указателем      | `--rt-color-bg-hover`                  |
| `--rt-side-menu-item-bg-active`          | подложка активного пункта и строки           | `--rt-color-action-primary-subtle`     |

| `--rt-side-menu-sub-item-color`          | цвет строки и папки в покое                  | `--rt-color-text-primary`              |

## Рядом

- `rt-menu` — выпадающее меню действий.
- `rt-section-nav` — плитки разделов одного экрана.

- [`rt-expansion-panel`](./?path=/docs/molecules-expansionpanel-overview--docs) — раскрывающаяся
  панель: на ней стоят папки подменю и блок избранного.

## Входы

| вход                     | тип                                    | умолчание     | что делает                                          |
| ------------------------ | -------------------------------------- | ------------- | --------------------------------------------------- |
| `activeMenuIds`          | `ReadonlyArray<string \| number>`      | —             | номера активных пунктов: полосы, подменю и папок    |
| `menuItems`              | `ReadonlyArray<IRtSideMenu.Item>`      | `[]`          | пункты полосы с их подменю                          |
| `subMenuMode`            | `IRtSideMenu.SubMenuMode \| undefined` | —             | режим от приложения; важнее сохранённого            |
| `subMenuWidth`           | `number \| null \| undefined`          | —             | ширина закреплённого подменю; важнее сохранённой    |
| `menuId`                 | `string`                               | `'main'`      | номер, под которым меню хранит свои настройки       |
| `favoritesCount`         | `IRtSideMenu.FavoritesCount`           | `'collapsed'` | число строк в заголовке блока избранного            |
| `favoriteActionsReserve` | `IRtSideMenu.FavoriteActionsReserve`   | `'none'`      | место под кнопки избранного, ждущие наведения       |
| `isFavoritesSearchShown` | `boolean`                              | `true`        | поиск показывает совпавшие строки избранного        |
| `pinShown`               | `boolean`                              | `true`        | кнопка закрепления; без неё сохранённое не читается |
| `subMenuTooltipsShown`   | `boolean`                              | `true`        | подсказки строк подменю и пунктов полосы            |
| `railTitlesShown`        | `boolean`                              | `true`        | подписи под значками полосы                         |
| `railIconFill`           | `boolean`                              | `false`       | залитые значки полосы                               |
| `searchSize`             | `IRtInput.Size`                        | `'sm'`        | размер поля поиска подменю                          |
| `searchAppearance`       | `IRtInput.Appearance`                  | `'outline'`   | вид поля поиска подменю                             |

## Выходы

| выход                          | что сообщает                                                    |
| ------------------------------ | --------------------------------------------------------------- |
| `subMenuModeChange`            | нажат переключатель закрепления                                 |
| `subMenuWidthChange`           | конец тяги или нажатая клавиша на ручке — новая ширина          |
| `subMenuResizeStart`           | тяга ширины началась                                            |
| `subMenuResizeEnd`             | тяга кончилась отпусканием или отнятым указателем               |
| `closeMobileMenuAction`        | на узком экране нажат пункт со ссылкой — мобильное меню закрыть |
| `clickSubMenuAction`           | нажата строка подменю со ссылкой                                |
| `clickSubMenuAdditionalAction` | нажата кнопка строки — её данные, строка не нажимается          |

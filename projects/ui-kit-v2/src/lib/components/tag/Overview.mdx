<Title>Tag — `rt-tag`</Title>

Статусная пилюля: короткая подпись, окрашенная по смыслу. Состояния не держит — крестик только
сообщает о клике.

```html
<rt-tag value="Активен" severity="success" />
<rt-tag value="Черновик" shape="square" appearance="outlined" />
<rt-tag value="Метка" [closable]="true" (closed)="remove()" />
```

## Когда применять

- Статус записи в списке или карточке: «активен», «просрочен», «черновик».
- Снятая метка фильтра, которую можно убрать крестиком.

## Когда не применять

- **Живой счётчик** — [`rt-live-badge`](./?path=/docs/atoms-livebadge-overview--docs):
  у него есть отдельное состояние оборванного потока, которого у тега нет.
- **Иконка без текста** — [`rt-icon-button`](./?path=/docs/atoms-buttons-iconbutton-overview--docs).
  `value` обязателен: тега без подписи не бывает.

## Оси

| ось         | значения                                                       | умолчание    |
| ----------- | -------------------------------------------------------------- | ------------ |
| палитра     | `neutral`, `info`, `success`, `warning`, `danger`, `secondary` | `neutral`    |
| внешний вид | `solid`, `outlined`                                            | `solid`      |
| форма       | `pill`, `square`                                               | `pill`       |
| скругление  | по форме, `none`, `sm`, `md`, `lg`, `full`                     | по форме     |
| размер      | `sm`, `md`, `lg`                                               | `md`         |
| иконки      | нет, слева, справа, с обеих сторон                             | нет          |
| крестик     | без крестика, с крестиком                                      | без крестика |

Перемножена одна пара — палитра с внешним видом: у `outlined` цвет уходит в контур и подпись,
а не в заливку, и одной строкой это не показать. Скругление перемножено с формой, потому что
`null` значит «по форме», а формы дают разный радиус.

## Состояния

**Своих состояний взаимодействия у пилюли нет:** ни `:hover`, ни `:focus-visible`, ни
`:active` в её SCSS не объявлено. Крестик — обычная кнопка, и наведение с фокусом принадлежат
ему, а не тегу.

Отключённого вида у тега тоже нет: он ничего не запускает и не может быть недоступен.

## Доступность

- Палитра дублируется атрибутом `data-severity` — по нему тег находят проверки и внешние стили,
  не завязываясь на BEM-класс.
- Подпись крестика для скринридера берётся из словаря кита (`uiRemove`). Без
  `provideRtKitLabels()` там будет пусто.
- Цвет — не единственный носитель смысла: подпись `value` обязательна и называет статус словами.

## Оформление

Модификаторы выводятся BEM-директивами: `rt-tag--severity--success`, `rt-tag--shape--square`,
булев `closable` даёт `rt-tag--closable` без значения. Вход `radius` перебивает скругление,
заданное формой; без него класс скругления не выводится вовсе.

**Подпись, которой не хватило места, урезается многоточием и получает подсказку с целым
значением.** Ширину пилюле даёт потребитель: шире отведённого места она не становится ни от
длины подписи, ни от ступени размера. Пока подпись влезает целиком, подсказки нет — над целым
значением она ничего не сказала бы.

## Входы

| вход         | тип                                                                        | умолчание      |
| ------------ | -------------------------------------------------------------------------- | -------------- |
| `value`      | `string`                                                                   | **обязателен** |
| `severity`   | `'info' \| 'success' \| 'warning' \| 'danger' \| 'secondary' \| 'neutral'` | `'neutral'`    |
| `size`       | `'sm' \| 'md' \| 'lg'`                                                     | `'md'`         |
| `shape`      | `'pill' \| 'square'`                                                       | `'pill'`       |
| `appearance` | `'solid' \| 'outlined'`                                                    | `'solid'`      |
| `radius`     | `'none' \| 'sm' \| 'md' \| 'lg' \| 'full' \| null`                         | `null`         |
| `icon`       | `IRtIcon.Name \| null`                                                     | `null`         |
| `iconEnd`    | `IRtIcon.Name \| null`                                                     | `null`         |
| `closable`   | `boolean`                                                                  | `false`        |

## Выходы

| выход    | тип          | когда                                           |
| -------- | ------------ | ----------------------------------------------- |
| `closed` | `MouseEvent` | клик по крестику; убрать тег обязан потребитель |

Клик по крестику не всплывает: пилюля целиком часто сама кликабельна, и без этого одно
нажатие срабатывало бы дважды.

## Рядом

- [`rt-live-badge`](./?path=/docs/atoms-livebadge-overview--docs) — пилюля живого счётчика.
- [`rt-icon`](./?path=/docs/atoms-icon-overview--docs) — знак, который тег ставит по краям.

## Переход с первого кита

Тег заменяет `rtui-info-badge` первого кита целиком. Киты стоят рядом, поэтому приложение
переходит по одному экрану: непереписанный экран держит прежний значок и работает как работал.

| в первом ките                                 | во втором                                    |
| --------------------------------------------- | -------------------------------------------- |
| `rtui-info-badge`                             | `rt-tag`                                     |
| `RtuiInfoBadgeComponent`                      | `RtTagComponent`                             |
| вход `text`                                   | `value`                                      |
| вход `size`                                   | `size`, но строками `'sm' \| 'md' \| 'lg'`   |
| вход `glyph`                                  | `icon` или `iconEnd`                         |
| вход `iconSide`                               | выбор между `icon` и `iconEnd`               |
| вход `isFontBold`                             | **нет**                                      |
| вход `isTitleCollapsed`                       | **нет**: тег считает нехватку места сам      |
| `EInfoBadgeSize.LARGE / MEDIUM / SMALL`       | `'lg'`, `'md'`, `'sm'`                       |
| `TInfoBadgeSizeType`                          | `IRtTag.Size`                                |
| `EInfoBadgeType`, `TInfoBadgeType`            | вход `severity`                              |
| `TIconSideType`, `EPosition.LEFT / RIGHT`     | **нет**: сторону называет имя входа          |
| `getColorBasedOnBackground`, `darkenHexColor` | **нет**: палитра закрытая, цвет не считается |
| класс `rtui-info-badge`                       | `rt-tag`                                     |
| класс `c-info-badge`                          | `rt-tag`: внутреннего блока у тега нет       |
| класс `c-info-badge__content`                 | `rt-tag__text`                               |
| класс `c-info-badge--size-l / -m / -s`        | `rt-tag--size--lg / --md / --sm`             |
| класс `c-info-badge--bold`                    | **нет**                                      |

Пять видов старого перечисления ложатся на палитру тега так: `SUCCESS` — `success`, `INFO` —
`info`, `WARNING` — `warning`, `PRIMARY` — `info` либо фирменный цвет через свойство блока,
`DISABLED` — `secondary`. Прямого `danger` у старого значка не было вовсе, а `neutral` — это его
вид по умолчанию.

Сверх переименования приложению придётся сделать вот что.

- **Цвет больше не считается по фону.** Старый значок красился строкой стиля снаружи, а цвет
  подписи вычислялся по яркости фона. У тега палитра закрытая и берётся токеном: вид выбирается
  входом `severity`, а не цветом. Приложению, которому нужен свой фон, отвечает переопределение
  свойства блока — не правило по классу и не строка стиля на хосте.
- **Значок приходит из набора кита.** `glyph` был именем шрифтового знака Material, `icon` и
  `iconEnd` берут имя из `IRtIcon.Name`: нужен `provideRtIcons` с адресом набора, а
  `@angular/material` этой семье больше не нужен вовсе.
- **Жирная подпись не переносится.** `isFontBold` соответствия не имеет: кегль и начертание ведёт
  ступень размера, и второго входа на то же место не заводится.
- **Нехватку места тег считает сам.** `isTitleCollapsed` наружу не выведен, и звать `checkEllipsis`
  больше не надо: тег следит за размером подписи наблюдателем и ставит подсказку сам. Прежний
  значок откладывал счёт на полсекунды после отрисовки и подсказку на узком экране выключал вовсе —
  тег показывает её везде.
- **Прежние правила по классам `c-info-badge__*` молча перестают действовать.** Внутреннего блока у
  тега нет: имя блока одно — `rt-tag`, подпись зовётся `text`, а ступень размера стоит модификатором
  `rt-tag--size--md`.
- **Крестик — новое.** Вход `closable` даёт кнопку, которой у значка не было; убрать тег из списка
  по выходу `closed` обязан потребитель.

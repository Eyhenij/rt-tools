<Title>StatTile — `rt-stat-tile`</Title>

Плитка показателя: значение, изменение к периоду и база сравнения.

```html
<rt-stat-tile
    label="Визиты"
    value="1 240"
    secondary="из них 300 новых"
    hint="Считается по уникальным"
    [deltaPrimary]="{ percent: 12.5, label: 'к прошлой неделе', baseline: '1 100' }"
    [deltaSecondary]="{ percent: 8, label: 'к прошлому году' }" />
```

## Когда применять

- Ряд ключевых показателей над отчётом или на дашборде, где каждый сравнивается с периодом.

## Когда не применять

- **Пара «ключ: значение» без сравнения** — [`rt-info-item`](./?path=/docs/components-infoitem-overview--docs).
- **Живой счётчик** — [`rt-live-badge`](./?path=/docs/components-livebadge-overview--docs).

## Оси

| ось                  | значения                                                             | умолчание |
| -------------------- | -------------------------------------------------------------------- | --------- |
| знак изменения       | рост, падение, без изменений, сравнить не с чем, изменения нет вовсе | нет       |
| база сравнения       | без базы, с базой                                                    | без базы  |
| необязательные части | только значение, подзаголовок, подсказка, второе изменение           | —         |

Главная ось — знак изменения: он выводится из числа, а не задаётся отдельно, и различимых
исходов у него пять — включая **два разных «ничего»**. `percent: null` значит «сравнить не с
чем», и тогда изменение не рисуется вовсе; ноль — это «без изменений», не рост и не падение.
Пустая плашка на месте первого читалась бы как второй.

Последние две ячейки ряда выглядят одинаково, и это не пропуск: «сравнить не с чем»
(`percent: null`) и «изменения нет вовсе» (`deltaPrimary: null`) — разные состояния данных с
одним и тем же видом. Плитка намеренно не показывает разницу: пользователю в обоих случаях
сказать нечего.

Знак и стрелка выводятся из числа: `> 0` — «+» и стрелка вверх, `< 0` — стрелка вниз. Дробная
часть отделяется запятой.

## Состояния

**Своих состояний взаимодействия у плитки нет:** она ничего не запускает и не принимает фокус,
и ни `:hover`, ни `:focus-visible`, ни `:active` в её SCSS не объявлено. Всё, что у неё меняется,
— это состав и знак, и то и другое показано осями.

## Доступность

Цвет изменения не единственный его носитель: рядом со стрелкой стоит знак числа и подпись базы
словами. Подсказка `hint` — обычный текст в потоке, а не всплывающая: скринридер читает её
подряд с остальным.

## Оформление

Направление изменения выводится в модификатор (`up`, `down`, `flat`, `unknown`) — цвет и иконка
строки берутся по нему. Значение базы уходит **параметром перевода**, а не подставляется в
готовую строку: подстановку `{{value}}` делает переводчик приложения, и подставлять к
возвращённой строке уже нечего.

## Входы

| вход             | тип                                     | умолчание      |
| ---------------- | --------------------------------------- | -------------- |
| `label`          | `string`                                | **обязателен** |
| `value`          | `string`                                | **обязателен** |
| `secondary`      | `string \| null`                        | `null`         |
| `hint`           | `string \| null`                        | `null`         |
| `deltaPrimary`   | `{ percent, label, baseline? } \| null` | `null`         |
| `deltaSecondary` | `{ percent, label, baseline? } \| null` | `null`         |

## Выходы

Своих выходов нет.

## Рядом

- [`rt-info-item`](./?path=/docs/components-infoitem-overview--docs) — пара «ключ: значение» без сравнения.
- [`rt-live-badge`](./?path=/docs/components-livebadge-overview--docs) — живой счётчик.

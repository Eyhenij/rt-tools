# `rt-stat-tile`

Плитка показателя: значение, изменение к периоду, база сравнения.

```html
<rt-stat-tile
    label="Визиты"
    value="1 240"
    secondary="из них 300 новых"
    hint="Считается по уникальным"
    [deltaPrimary]="{ percent: 12.5, label: 'к прошлой неделе', baseline: '1 100' }"
    [deltaSecondary]="{ percent: 8, label: 'к прошлому году' }" />
```

| вход                              | тип                                            | умолчание       |
| --------------------------------- | ---------------------------------------------- | --------------- |
| `label` / `value`                 | `string`                                       | **обязательны** |
| `secondary`                       | `string \| null`                               | `null`          |
| `hint`                            | `string \| null`                               | `null`          |
| `deltaPrimary` / `deltaSecondary` | `{ percent, unit?, label, baseline? } \| null` | `null`          |
| `growthIsWorse`                   | `boolean`                                      | `false`         |

Выходов нет.

## Главное, что нужно знать

**`percent: null` означает «сравнить не с чем» — и тогда изменение не рисуется вовсе.**
Пустая плашка на его месте читалась бы как ноль. Ноль же — это `flat`: не рост и не падение.

Знак и стрелка выводятся из числа: `> 0` — «+» и стрелка вверх, `< 0` — стрелка вниз. Дробная
часть отделяется запятой.

`unit: 'points'` пишет строку в процентных пунктах подписью `uiPercentagePoints` («+10 п.п.»),
без `unit` — в процентах. `growthIsWorse` меняет цвета обеих строк местами, стрелка остаётся по
знаку числа.

**Значение базы уходит параметром подписи, а не подставляется в готовую строку.** Переводчик приложения
интерполирует `{{value}}` в момент перевода, и к возвращённой строке подставлять уже нечего:
`String.replace` после `translateSignal` не находил плейсхолдера, и от подписи оставалась одна
приставка («было», «was»). Параметр передан сигналом — смена базы переписывает строку.

# `rt-stat-tile`

Плитка показателя: значение, изменение к периоду, база сравнения.

```html
<rt-stat-tile
    label="Визиты"
    value="1 240"
    secondary="из них 300 новых"
    hint="Считается по уникальным"
    [deltaPrimary]="{ percent: 12.5, label: 'к прошлой неделе', baseline: '1 100' }"
    [deltaSecondary]="{ percent: 8, label: 'к прошлому году' }" />
```

| вход                              | тип                                            | умолчание       |
| --------------------------------- | ---------------------------------------------- | --------------- |
| `label` / `value`                 | `string`                                       | **обязательны** |
| `secondary`                       | `string \| null`                               | `null`          |
| `hint`                            | `string \| null`                               | `null`          |
| `deltaPrimary` / `deltaSecondary` | `{ percent, unit?, label, baseline? } \| null` | `null`          |
| `growthIsWorse`                   | `boolean`                                      | `false`         |
| `size`                            | `'default' \| 'compact'`                       | `'default'`     |
| `deltaLabelVisible`               | `boolean`                                      | `false`         |

Выходов нет.

## Главное, что нужно знать

**`percent: null` означает «сравнить не с чем» — и тогда изменение не рисуется вовсе.**
Пустая плашка на его месте читалась бы как ноль. Ноль же — это `flat`: не рост и не падение.

**Обе строки дельты пишутся по языку подписей кита** (`RT_KIT_LOCALE`) — функцией
`rtDeltaNumber` из `lib/util/delta-number.ts`, той же, что пишет дельту KPI в копии ответа.
`Intl.NumberFormat` ставит плюс на росте, минус языка на падении и не ставит знака у нуля, дробных
знаков не больше одного: в `en` «+12.5%», в `ru` «+12,5 %» с U+00A0 перед знаком. Язык, который
`Intl` не принимает, пишет как `en`. Знак, стрелка и цвет берутся из записанного числа, а не из
присланного: 0.04 и -0.04 записаны «0 %» и ровные.

`unit: 'points'` пишет строку в процентных пунктах подписью `uiPercentagePoints` («+10 п.п.»), в
которую уходит записанное число; без `unit` — в процентах. `growthIsWorse` меняет цвета обеих
строк местами, стрелка остаётся по знаку числа.

**`size="compact"` — плитка для узкой карточки.** Значение 24/24, дельта 14 отдельной строкой под
значением, промежутки 6, нижние строки и подпись базы переносятся между словами вместо
многоточия. Значение, которое не входит в ряд при 24, берёт 20, затем 18: шаг выбирает
`rtStatTileValueFit` из `rt-stat-tile.fit.ts` — меряет текст на холсте шрифтом первого шага против
ширины ряда значения и пересчитывает при смене текста, ширины ряда и после загрузки шрифтов. Не
входит и при 18 — единица переносится на следующую строку. Размер по умолчанию не меняется.

`deltaLabelVisible` показывает подпись основной дельты текстом после числа («+12,5 % vs LY»), и
тогда `title` с той же подписью не ставится.

**Значение базы уходит параметром подписи, а не подставляется в готовую строку.** Переводчик приложения
интерполирует `{{value}}` в момент перевода, и к возвращённой строке подставлять уже нечего:
`String.replace` после `translateSignal` не находил плейсхолдера, и от подписи оставалась одна
приставка («было», «was»). Параметр передан сигналом — смена базы переписывает строку.

<Title>FileCard — `rt-file-card`</Title>

Карточка вложения: иконка по расширению, имя без расширения заголовком, вес под ним и кнопки
действий справа. Иконку и заголовок компонент выводит из имени файла — отдельных входов у них
нет.

```html
<rt-file-card name="договор-2024-118.pdf" showDownload showRemove [sizeBytes]="248000" />
```

## Когда применять

- Показ вложения в списке файлов, в сообщении, в карточке объекта.
- Файл, который можно скачать, переименовать или убрать, — кнопки включаются по отдельности.

## Когда не применять

- **Выбор файла с диска** — [`rt-file-input`](./?path=/docs/molecules-forms-fileinput-overview--docs) или
  [`rt-file-drop`](./?path=/docs/organisms-filedrop-overview--docs).
- **Просмотр изображения** — `rt-photo-viewer`.

## Оси

| ось            | значения                                                               | умолчание  |
| -------------- | ---------------------------------------------------------------------- | ---------- |
| размер         | `sm`, `md`, `lg`                                                       | `md`       |
| набор действий | без кнопок, только скачать, все три                                    | без кнопок |
| имя файла      | pdf, таблица, картинка, незнакомое расширение, без расширения, длинное | —          |
| вес            | нулевой, килобайты, мегабайты, неизвестен                              | —          |
| отключение     | обычная, `disabled`                                                    | обычная    |

Размер перемножен с набором действий: у мелкой карточки кнопки теснятся, и расхождение видно
только на этой паре. Остальные оси от размера не зависят и идут рядами.

**Иконка и заголовок выводятся из имени файла.** Расширение выбирает иконку — незнакомое даёт
общую, — а заголовок это имя без расширения с заменёнными `_` и `-` на пробелы.

## Края

| край                | что происходит                                                |
| ------------------- | ------------------------------------------------------------- |
| длинное имя         | обрезается **в середине**, чтобы расширение осталось видно    |
| без расширения      | иконка общая, заголовок — имя целиком                         |
| вес неизвестен      | строка веса не рисуется                                       |
| нулевой вес         | показывается как есть, а не прячется                          |
| без входов действий | карточка немая — ни одной кнопки: она бывает просто вложением |

## Состояния

| состояние       | чем задаётся     | что меняется                            |
| --------------- | ---------------- | --------------------------------------- |
| обычное         | —                | фон и рамка карточки                    |
| наведение       | `:hover`         | подложка карточки                       |
| нажатие         | `:active`        | подложка темнее                         |
| фокус с клавиши | `:focus-visible` | кольцо фокуса на кнопке                 |
| отключено       | вход `disabled`  | кнопки не нажимаются, карточка тускнеет |

## Доступность

- Каждая кнопка несёт своё имя для скринридера: «скачать», «переименовать», «удалить» — иконка
  без подписи именем не служит.
- Имя файла показано целиком в подсказке, когда обрезано.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-file-list`](./?path=/docs/molecules-files-filelist-overview--docs) — список таких карточек.
- [`rt-download-link`](./?path=/docs/atoms-buttons-downloadlink-overview--docs) — ссылка на скачивание без
  карточки.

## Входы

| вход           | тип                | умолчание | что делает                           |
| -------------- | ------------------ | --------- | ------------------------------------ |
| `name`         | `string`           | `''`      | имя файла: решает иконку и заголовок |
| `sizeBytes`    | `number \| null`   | `null`    | вес; `null` не рисует строку веса    |
| `size`         | `IRtFileCard.Size` | `'md'`    | размер карточки: `sm`, `md`, `lg`    |
| `showDownload` | `boolean`          | `false`   | кнопка скачивания                    |
| `showRemove`   | `boolean`          | `false`   | кнопка удаления                      |
| `showRename`   | `boolean`          | `false`   | кнопка переименования                |
| `disabled`     | `boolean`          | `false`   | кнопки не нажимаются                 |

## Выходы

| выход      | что сообщает                 |
| ---------- | ---------------------------- |
| `download` | нажата кнопка скачивания     |
| `removed`  | нажата кнопка удаления       |
| `rename`   | нажата кнопка переименования |

Сам файл компонент не скачивает и не удаляет — он только просит; делает это потребитель.

# `rt-file-card`

Карточка файла: иконка по типу, имя, размер и необязательные действия.

```html
<rt-file-card name="Договор.pdf" size="md" showDownload showRemove [sizeBytes]="204800" (download)="save()" (removed)="detach()" />
```

| вход                                         | тип                    | умолчание      |
| -------------------------------------------- | ---------------------- | -------------- |
| `name`                                       | `string`               | **обязателен** |
| `sizeBytes`                                  | `number \| null`       | `null`         |
| `size`                                       | `'sm' \| 'md' \| 'lg'` | `'md'`         |
| `showDownload` / `showRename` / `showRemove` | `boolean`              | `false`        |
| `disabled`                                   | `boolean`              | `false`        |

Выходы: `download`, `rename`, `removed`.

## Главное, что нужно знать

**Иконка и заголовок выводятся из имени файла.** Расширение выбирает иконку (незнакомое даёт
общую), а заголовок — это имя без расширения с заменёнными `_` и `-` на пробелы. Отдельных
входов для них нет.

**Длинное имя обрезается в середине**, чтобы расширение осталось видно: `очень-длинн...pdf`.

**Без входов действий карточка немая** — ни одной кнопки. Она бывает просто вложением, которое
показывают.

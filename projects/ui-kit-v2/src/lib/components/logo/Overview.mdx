<Title>Logo — `rt-logo`</Title>

Логотип приложения: начертание названия и, в варианте `lockup`, слоган под ним.

```html
<rt-logo ariaLabel="Панель управления" />
<rt-logo variant="wordmark" ariaLabel="Панель управления" [height]="40" />
```

## Когда применять

- Шапка приложения и экран входа — места, где название показывается фирменным начертанием.

## Когда не применять

- **Иконка приложения** — начертание рассчитано на горизонтальное место; в квадрат оно не
  ужимается.

## Оси

| ось       | значения                                       | умолчание |
| --------- | ---------------------------------------------- | --------- |
| вариант   | `wordmark`, `lockup`                           | `lockup`  |
| высота    | умолчание варианта (`0`), любое число пикселей | `0`       |
| пропорция | умолчание варианта (`0`), любое число          | `0`       |

**Ноль означает «не задано», а не нулевой размер:** числовой вход иначе одно от другого не
отличает. Умолчания: `wordmark` — 51px при отношении 5.4, `lockup` — 75px при 3.6. Ширина
считается как `round(height × aspect)`.

`aspect` нужен, если пропорции своего файла не совпадают с умолчанием: ширину host-а кит
считает сам и чужих пропорций не знает — логотип обрежется или обрастёт пустотой. В ряду
пропорций это видно на значениях по обе стороны от умолчания.

## Что показать нельзя

**Свои начертания.** Кит их не везёт: их даёт приложение четырьмя свойствами оформления на
любом предке.

```css
:root {
    --rt-logo-wordmark: url('/logo/wordmark.svg');
    --rt-logo-wordmark-dark: url('/logo/wordmark-inverse.svg');
    --rt-logo-tagline: url('/logo/tagline.svg');
    --rt-logo-tagline-dark: url('/logo/tagline-inverse.svg');
}
```

Пока свойства не заданы, компонент занимает место и не рисует ничего — это ожидаемое состояние,
а не сбой. В витрине подставлены **безымянные заглушки**: без них каждая ячейка матрицы была бы
пустым местом нужного размера, то есть не показывала бы ни размеров, ни пары «светлое ↔ тёмное».
Настоящий логотип в витрине увидеть нельзя, и это не пропуск, а отсутствие предмета.

## Состояния

**Состояний взаимодействия у компонента нет:** он ничего не запускает, не принимает фокус, и ни
`:hover`, ни `:focus-visible`, ни `:active` в его SCSS не объявлено. Если логотип кликабелен, в
ссылку его оборачивает приложение — состояния тогда принадлежат ссылке.

## Доступность

Подпись задаёт приложение входом `ariaLabel`: названия продукта кит не знает. Начертания лежат
фоном, а не в `<img>`, поэтому своего альтернативного текста у них нет — без `ariaLabel`
логотип для скринридера безымянен.

## Оформление

Начертания лежат фоном, потому что у тёмной темы своя пара файлов, и подмена `background-image`
— единственный способ переключить их одним правилом. В варианте `lockup` начертание и слоган
делят высоту: ~66.7% начертанию, ~22.1% слогану, остальное — зазор.

## Входы

| вход        | тип                      | умолчание                |
| ----------- | ------------------------ | ------------------------ |
| `variant`   | `'wordmark' \| 'lockup'` | `'lockup'`               |
| `height`    | `number \| string` — px  | `0` → умолчание варианта |
| `aspect`    | `number \| string`       | `0` → умолчание варианта |
| `ariaLabel` | `string`                 | `''`                     |

## Выходы

Своих выходов нет.

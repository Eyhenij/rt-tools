# `rt-logo`

```html
<rt-logo variant="lockup" ariaLabel="Панель управления" [height]="75" [aspect]="0" />
```

| вход        | тип                      | умолчание                |
| ----------- | ------------------------ | ------------------------ |
| `variant`   | `'wordmark' \| 'lockup'` | `'lockup'`               |
| `height`    | `number \| string` (px)  | `0` → умолчание варианта |
| `aspect`    | `number \| string`       | `0` → умолчание варианта |
| `ariaLabel` | `string`                 | `''`                     |

Умолчания: `wordmark` — 51px высотой при отношении 5.4; `lockup` — 75px при 3.6.
Ширина считается как `round(height × aspect)`.

## Главное, что нужно знать

**Начертания кит не везёт.** Их даёт приложение четырьмя свойствами оформления на любом предке:

```css
:root {
    --rt-logo-wordmark: url('/logo/wordmark.svg');
    --rt-logo-wordmark-dark: url('/logo/wordmark-inverse.svg');
    --rt-logo-tagline: url('/logo/tagline.svg');
    --rt-logo-tagline-dark: url('/logo/tagline-inverse.svg');
}
```

Пока свойства не заданы, компонент занимает место и не рисует ничего. Это ожидаемое состояние,
а не сбой.

Начертания лежат фоном, а не в `<img>`, потому что у тёмной темы своя пара файлов, и подмена
`background-image` — единственный способ переключить их одним правилом.

## Края

- **Ноль в `height`/`aspect` означает «не задано», а не нулевой размер.** Числовой вход иначе не
  отличает одно от другого.
- `aspect` нужен, если пропорции своего файла не совпадают с умолчанием: ширину host-а кит
  считает сам и чужих пропорций не знает — логотип обрежется или обрастёт пустотой.
- Подпись для скринридера задаёт приложение: названия продукта кит не знает.

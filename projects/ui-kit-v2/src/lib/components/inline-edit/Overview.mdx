<Title>InlineEdit — `rt-inline-edit`</Title>

Короткое значение, которое человек правит там, где его видит: название отчёта в панели, заголовок
страницы, ключ в строке настроек. В покое — значение с карандашом; нажатие открывает поле кита с
кнопками сохранения и отмены.

```html
<rt-inline-edit placeholder="Название отчёта" [value]="report.name" (saved)="rename($event)" />
<rt-inline-edit look="chip" [value]="tag" [closeOnSave]="false" [saving]="saving()" [(editing)]="editing" (saved)="save($event)" />
```

## Когда применять

- Одно короткое значение, которое правят редко и прямо на экране, без отдельной формы.
- Значение, у которого нет соседних полей: всё сохранение — одна строка.

## Когда не применять

- **Форма из нескольких полей** — [`rt-field`](./?path=/docs/molecules-forms-field-overview--docs)
  с `rt-input` и общей кнопкой сохранения.
- **Многострочный и форматированный текст** — поле однострочное.
- **Строки списка выбора с правкой** — у `rt-dynamic-input` свой вход `editable`.

## Оси

| ось     | значения                                                         | умолчание |
| ------- | ---------------------------------------------------------------- | --------- |
| вид     | `text` — строкой, `chip` — плашкой, `chip-field` — плашкой-полем | `text`    |
| ступень | `sm`, `md`, `lg` — как у `rt-input`                              | `sm`      |
| уход    | `keep`, `save`, `cancel`                                         | `keep`    |

Вид действует только в покое: открытое поле в обоих видах — поле кита. Высота покоя равна высоте
поля той же ступени, и строка не прыгает при открытии. История **Look** показывает виды, пустое,
длинное и недоступное значение; **Editing** — открытое поле, пустой черновик и сохранение; **Size** —
ступени в покое и открытыми.

**Сохранение.** Enter и кнопка с галочкой отдают черновик, обрезанный по краям, выходом `saved`.
Черновик, равный значению, закрывает поле и ничего не шлёт. Пустой не уходит, пока не задан
`allowEmpty`: кнопка недоступна, Enter молчит. Компонент значение не хранит — новое показывает
приложение, вернув его во вход `value`.

**Приложение отвечает позже.** С `closeOnSave="false"` поле после сохранения остаётся открытым. Вход
`saving` крутит кнопку сохранения и гасит поле и отмену. Поле закрывает приложение через
`[(editing)]` — или держит его открытым, если сохранение не прошло. Погашенное поле теряет фокус, и
компонент возвращает его сам: в поле при отказе, на значение при закрытии.

**Отмена.** Escape и кнопка с крестиком закрывают поле и отдают `cancelled`; Escape не доходит до
окна или панели вокруг. Фокус после закрытия возвращается на значение.

**Плашка-поле.** `look="chip-field"` повторяет плашку первого приложения: плашка сама поле, покоя,
открытия и кнопок нет. Слева значок из входа `fieldIcon`, по умолчанию карандаш. Плашка растёт с
текстом до 24rem, дальше поле прокручивается, а целиком текст виден в подсказке. Вне фокуса длинный
текст режется в конце; `truncate="middle"` режет его посередине, как приложение: начало с
многоточием и последние десять знаков. Фокус выделяет
текст. Enter и уход сохраняют обрезанный черновик, Escape возвращает значение и отдаёт `cancelled`.
Пустой черновик молча возвращает значение, пока не задан `allowEmpty`. Недоступная плашка заперта.
История **ChipField** показывает её значения и фокус.

**Уход фокуса.** По умолчанию поле остаётся открытым: случайное нажатие мимо не теряет набранное.
`blurAction="save"` сохраняет при уходе, как плашка первого приложения, `cancel` — отменяет. Переход
на свои кнопки уходом не считается.

## Состояния

| состояние            | чем задаётся     | что меняется                                        |
| -------------------- | ---------------- | --------------------------------------------------- |
| обычное              | —                | значение и карандаш, прозрачный фон                 |
| наведение            | `:hover`         | подложка у текста, рамка цвета действия у плашки    |
| фокус                | `:focus-visible` | кольцо вокруг значения                              |
| правка               | `editing`        | поле, кнопки сохранения и отмены                    |
| сохранение           | `saving`         | кнопка крутится, поле и отмена недоступны           |
| недоступно           | `disabled`       | приглушённое значение без карандаша, не открывается |
| плашка-поле в фокусе | `:focus-within`  | рамка цвета фокуса, текст выделен                   |

## Доступность

- Значение в покое — настоящая `<button>`; её имя — «Edit: значение», карандаш скрыт от чтения.
- Поле получает имя из `fieldLabel`, без него — из подсказки.
- Кнопки сохранения и отмены названы ярлыками кита «Save» и «Cancel» и несут подсказки.
- При открытии фокус встаёт в поле и выделяет текст: первое нажатие клавиши заменяет значение.

## Оформление

Базовый и материальный наборы стоят половинами каждой матрицы, светлая и тёмная темы — в истории
**Themes**. Свойства объявлены на самом `rt-inline-edit`, и приложение переназначает их своим правилом
на этот блок. Умолчания — прежние ступени кита, так что без правки вид не меняется.

Материальный набор переназначает пять свойств по образцу плашки приложения. Скругление плашки
становится 6px, подложка — серой подложкой поля, рамка — тонкой без цвета действия, поля значения — 8px.
Плашка-поле в материальном наборе — как у приложения: подложка `--rt-mat-neutral-5`, рамка
`--mat-sys-primary-fixed-dim`, в фокусе `--mat-sys-primary`, текст и значок — `--mat-sys-primary`.
Без темы Material цвета берут запасные значения кита, в тёмной теме подложка — подложка плашки.

## Входы

| вход          | тип                        | умолчание  | что делает                                       |
| ------------- | -------------------------- | ---------- | ------------------------------------------------ |
| `value`       | `string`                   | —          | значение приложения, видно в покое               |
| `placeholder` | `string`                   | `''`       | подсказка пустого значения и пустого поля        |
| `look`        | `IRtInlineEdit.Look`       | `'text'`   | вид в покое: строка, плашка или плашка-поле      |
| `fieldIcon`   | `IRtIcon.Name`             | `'pencil'` | значок перед текстом плашки-поля                 |
| `truncate`    | `IRtInlineEdit.Truncate`   | `'end'`    | где плашка-поле режет длинный текст вне фокуса   |
| `size`        | `IRtInput.Size`            | `'sm'`     | ступень поля и кнопок                            |
| `fieldLabel`  | `string`                   | `''`       | имя поля для чтения экрана                       |
| `disabled`    | `boolean`                  | `false`    | поле не открывается                              |
| `saving`      | `boolean`                  | `false`    | приложение сохраняет: кнопка крутится            |
| `allowEmpty`  | `boolean`                  | `false`    | пустой черновик сохраняется                      |
| `closeOnSave` | `boolean`                  | `true`     | поле закрывается при сохранении                  |
| `blurAction`  | `IRtInlineEdit.BlurAction` | `'keep'`   | что делает уход фокуса                           |
| `editing`     | `boolean`, двусторонний    | `false`    | поле открыто; приложение может открыть и закрыть |

## Выходы

| выход       | тип      | когда                                                   |
| ----------- | -------- | ------------------------------------------------------- |
| `saved`     | `string` | сохранён изменённый черновик, обрезанный по краям       |
| `cancelled` | `void`   | правка отменена Escape, крестиком или уходом с `cancel` |

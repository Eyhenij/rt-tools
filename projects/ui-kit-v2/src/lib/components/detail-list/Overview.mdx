<Title>DetailList — `rt-detail-list`, `rt-detail-row`</Title>

Пары «подпись — значение» в две колонки: список раскладывает строки, строка держит подпись и
показывает значение проекцией. Своих входов у списка нет вовсе.

```html
<rt-detail-list>
    <rt-detail-row label="Договор">№2024-118</rt-detail-row>
    <rt-detail-row label="Сумма" [loading]="pending()">148 000 ₽</rt-detail-row>
</rt-detail-list>
```

## Когда применять

- Показ реквизитов объекта: карточка договора, сводка заявки, свойства файла.
- Значение приходит асинхронно — тогда `loading` рисует скелет ровно на его месте, и список не
  прыгает при подстановке.

## Когда не применять

- **Много однородных записей** — [`rt-table`](./?path=/docs/components-table--docs): у списка
  нет ни заголовков колонок, ни сортировки.
- **Сплошной текст** — [`rt-collapsible-text`](./?path=/docs/components-collapsible-text-overview--docs).

## Оси

| ось                 | значения                              | умолчание |
| ------------------- | ------------------------------------- | --------- |
| загрузка строки     | значение на месте, скелет             | значение  |
| наполнение значения | текст, длинный текст, разметка, пусто | —         |
| длина списка        | одна, две, четыре строки              | —         |

Значение приходит проекцией, поэтому осью значений оно не является: показаны случаи, при
которых строка ведёт себя по-разному.

## Края

| край                  | что происходит                                         |
| --------------------- | ------------------------------------------------------ |
| пустой список         | рисуется пустой контейнер, заглушки нет                |
| строка без значения   | колонка значения остаётся пустой, подпись на месте     |
| длинная подпись       | переносится по словам, значение выравнивается по верху |
| загрузка одной строки | скелет только у неё, остальные показывают значения     |

## Состояния

| состояние | чем задаётся   | что меняется                                    |
| --------- | -------------- | ----------------------------------------------- |
| обычное   | —              | значение показано как есть                      |
| загрузка  | вход `loading` | вместо значения — скелет фиксированного размера |

Состояний взаимодействия нет: строки не нажимаются и фокус не берут.

## Доступность

- Подпись и значение — соседние элементы одной строки; порядок чтения совпадает с показом.
- Скелет загрузки не несёт текста: пока значение не пришло, читать нечего.

## Оформление

Скелет рисуется общим `rt-skeleton-wrapper` с постоянными размерами — при подстановке значения
строка не меняет высоту. Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-money-list`](./?path=/docs/components-money-list--docs) — то же для денежных сумм, с
  итоговой строкой.
- [`rt-info-item`](./?path=/docs/components-info-item--docs) — одна пара, а не список.

## Входы

| вход      | тип       | умолчание | что делает                      |
| --------- | --------- | --------- | ------------------------------- |
| `label`   | `string`  | `''`      | подпись строки в левой колонке  |
| `loading` | `boolean` | `false`   | вместо значения рисуется скелет |

У самого `rt-detail-list` входов нет: он только раскладывает вложенные строки.

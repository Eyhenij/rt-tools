<Title>MessageComposer — `rt-message-composer`</Title>

Поле набора сообщения: растущий по содержимому текст, скрепка вложений, необязательная панель
оформления и кнопка отправки.

```html
<rt-message-composer placeholder="Написать сообщение" attachments accept=".pdf,.png" [sending]="sending()" (submitted)="send($event)" />
```

## Когда применять

- Нижняя часть переписки, форма ответа, поле комментария.

## Когда не применять

- **Длинный текст с оформлением как основной документ** — `rt-rich-editor`.
- **Однострочный ввод** — [`rt-input`](./?path=/docs/components-input--docs).

## Оси

| ось         | значения                         | умолчание |
| ----------- | -------------------------------- | --------- |
| состояние   | обычное, `sending`, `disabled`   | обычное   |
| вложения    | без них, скрепка есть            | без них   |
| оформление  | простой текст, панель оформления | простой   |
| высота поля | одна строка, три строки          | одна      |

**`sending` и `disabled` блокируют одно и то же, а означают разное**: первое — отправка в пути,
второе — поле выключено снаружи. Рядом это видно, и в обзоре сказано прямо, потому что по виду
они не различаются.

## Чего матрицы не показывают

**Отправка разблокируется только при непустом содержимом**, а набранный текст витриной не
подделывается: во всех ячейках кнопка отправки заблокирована. Показать поле «как будто с
текстом» значило бы показать не тот компонент — набор идёт через настоящий ввод, и проверяется
он спекой, а не кадром.

Пробелы значением не считаются; один вложенный файл разблокирует отправку и без текста.

## Края

| край             | что происходит                                                     |
| ---------------- | ------------------------------------------------------------------ |
| после отправки   | форма сбрасывается целиком — и текст, и файлы                      |
| режим оформления | текст уезжает пустым, содержимое едет отдельным полем строкой JSON |
| `droppedFiles`   | **вход, а не выход**: файлы, брошенные в область, приходят снаружи |

## Состояния

| состояние | чем задаётся    | что меняется                                                          |
| --------- | --------------- | --------------------------------------------------------------------- |
| обычное   | —               | поле принимает ввод                                                   |
| отправка  | вход `sending`  | поле и кнопка заблокированы: второе сообщение не уйдёт поверх первого |
| выключено | вход `disabled` | то же, но по решению приложения                                       |

## Доступность

- **Enter отправляет, Shift с Enter переносит строку.** Набор во время композиции ввода
  игнорируется — иначе иероглифическая раскладка отправляла бы недописанное.
- У скрепки и кнопки отправки переведённые имена.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-chat`](./?path=/docs/components-chat-overview--docs) — переписка, в которой это поле
  стоит снизу.

## Входы

| вход           | тип                    | умолчание | что делает                                   |
| -------------- | ---------------------- | --------- | -------------------------------------------- |
| `placeholder`  | `string`               | `''`      | подсказка в пустом поле                      |
| `accept`       | `string`               | `''`      | какие файлы принимает скрепка                |
| `attachments`  | `boolean`              | `false`   | показывает скрепку                           |
| `sending`      | `boolean`              | `false`   | отправка в пути: поле и кнопка заблокированы |
| `disabled`     | `boolean`              | `false`   | поле выключено снаружи                       |
| `formatting`   | `boolean`              | `false`   | панель оформления вместо простого текста     |
| `toolbar`      | `TRtRichEditorToolbar` | —         | какие кнопки в панели оформления             |
| `minRows`      | `number`               | `1`       | высота пустого поля в строках                |
| `maxRows`      | `number`               | `4`       | до скольких строк поле растёт                |
| `droppedFiles` | `File[] \| null`       | `null`    | файлы, брошенные снаружи, — вход, а не выход |

## Выходы

| выход       | что сообщает                                                    |
| ----------- | --------------------------------------------------------------- |
| `submitted` | сообщение отправлено: текст, файлы и, в режиме оформления, тело |

<Title>Message — `rt-message`</Title>

Полоса сообщения на месте: цветная подложка, иконка по важности и текст проекцией. В отличие от
всплывающего уведомления остаётся на экране, пока её не уберут.

```html
<rt-message severity="warning">Срок действия договора истекает через тридцать дней</rt-message>
<rt-message severity="danger" closable (closed)="dismiss()">Не удалось сохранить</rt-message>
```

## Когда применять

- Пояснение или предупреждение рядом с тем, к чему оно относится: над формой, внутри панели.
- Ошибка, которую надо держать перед глазами, пока пользователь её не разберёт.

## Когда не применять

- **Короткое сообщение о состоявшемся действии** — [`rt-toast`](./?path=/docs/atoms-feedback-toast-overview--docs):
  оно само уходит.
- **Метка состояния объекта** — [`rt-tag`](./?path=/docs/atoms-tag-overview--docs): та же палитра,
  но метка стоит в строке, а не занимает полосу.
- **Пустой экран** — [`rt-empty-state`](./?path=/docs/molecules-emptystate-overview--docs).

## Оси

| ось             | значения                                                       | умолчание   |
| --------------- | -------------------------------------------------------------- | ----------- |
| важность        | `info`, `success`, `warning`, `danger`, `secondary`, `neutral` | `info`      |
| иконка          | по важности, своя, без иконки                                  | по важности |
| кнопка закрытия | нет, `closable`                                                | нет         |

Палитра важности та же, что у [`rt-tag`](./?path=/docs/atoms-tag-overview--docs) — тип
`IRtTag.Severity` переиспользуется напрямую, чтобы наборы не разошлись.

Важность перемножена с иконкой: **своя иконка перебивает подобранную по важности**, а
`hideIcon` убирает обе. У `secondary` и `neutral` иконки по умолчанию нет вовсе — в сетке это
видно пустой ячейкой первой колонки, и это не пропуск, а само поведение.

## Края

| край              | что происходит                                         |
| ----------------- | ------------------------------------------------------ |
| пустое содержимое | остаётся подложка с иконкой — полоса без текста        |
| длинный текст     | переносится по словам, иконка остаётся у первой строки |
| разметка внутри   | проходит как есть: ссылки и выделение работают         |

## Состояния

Состояний взаимодействия у самой полосы нет: она ничего не принимает от указателя. Кнопка
закрытия — обычная иконочная кнопка со своими состояниями.

## Доступность

- Иконка помечена скрытой от скринридера: важность передаётся текстом сообщения, а не значком.
- Кнопка закрытия несёт переведённое имя.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes** — все шесть важностей сразу.

## Рядом

- [`rt-tag`](./?path=/docs/atoms-tag-overview--docs) — та же палитра меткой в строке.
- [`rt-toast`](./?path=/docs/atoms-feedback-toast-overview--docs) — уведомление, уходящее само.

## Входы

| вход       | тип                    | умолчание | что делает                                      |
| ---------- | ---------------------- | --------- | ----------------------------------------------- |
| `severity` | `IRtTag.Severity`      | `'info'`  | палитра и иконка по умолчанию                   |
| `icon`     | `IRtIcon.Name \| null` | `null`    | своя иконка; перебивает подобранную по важности |
| `hideIcon` | `boolean`              | `false`   | убирает иконку вовсе, включая подобранную       |
| `closable` | `boolean`              | `false`   | кнопка закрытия справа                          |

## Выходы

| выход    | что сообщает                                                       |
| -------- | ------------------------------------------------------------------ |
| `closed` | нажата кнопка закрытия; убирает полосу потребитель, а не компонент |

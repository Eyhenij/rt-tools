# `rt-usage-ring`

```html
<rt-usage-ring [value]="usedPercent()" [hint]="usageHint()" />
```

| вход     | тип      | умолчание |
| -------- | -------- | --------- |
| `value`  | `number` | `0`       |
| `warnAt` | `number` | `80`      |
| `hint`   | `string` | `''`      |

Выходов нет.

Спек — `docs/specs/ui-kit-v2/ai-chat/`; здесь только устройство папки.

## Главное, что нужно знать

**Кольцо рисует только долю.** Что за лимит и когда сброс, говорит подсказка `hint`: её текст
собирает приложение, кит не знает ни лимита, ни дат.

**С порога `warnAt` дуга оранжевая.** Доля прижимается к 0…100 и округляется до целого.

## Края

- С подсказкой кольцо берёт фокус: подсказку видно и с клавиатуры. Без подсказки кольцо в обход
  фокуса не входит.
- Скринридер слышит долю подписью кита `aiUsageAria`.

## Рядом

- [`rt-ai-prompt-input`](../ai-prompt-input/CONTEXT.md) — поле ввода ИИ-чата, где кольцо стоит в
  ряду действий.

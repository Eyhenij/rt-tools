<Title>BarList — `rt-bar-list`</Title>

Список с горизонтальными полосами: название слева, значение справа, под ними полоса во всю
ширину строки. Показывает распределение — по городам, каналам, статусам.

```html
<rt-bar-list title="Заявки по городам" [rows]="rows()" />
```

## Когда применять

- Распределение по нескольким однородным величинам, где важна не точность, а соотношение.
- Сводка на панели, где столбчатая диаграмма была бы избыточна.

## Когда не применять

- **Точные числа в колонках** — [`rt-table`](./?path=/docs/organisms-tables-lists-table-overview--docs).
- **Изменение во времени** — полосы не про динамику.

## Оси

| ось             | значения                        | умолчание    |
| --------------- | ------------------------------- | ------------ |
| доля полосы     | 0 %, 50 %, 100 %, убывающий ряд | —            |
| приписка `meta` | есть, нет                       | нет          |
| длина набора    | одна, четыре строки             | —            |
| пустой набор    | переведённый текст, свой текст  | переведённый |

**`value` и `sharePercent` — разные вещи.** Первое рисуется текстом справа и бывает чем
угодно — «52 %», «1 240 ₽», «12 шт.». Второе задаёт ширину полосы. Считать проценты компонент
не умеет — он их только показывает, и ячейка «подпись не равна доле» это показывает прямо.

## Края

| край             | что происходит                                           |
| ---------------- | -------------------------------------------------------- |
| пустой набор     | список подменяется заглушкой с иконкой                   |
| свой `emptyText` | перебивает переведённый текст заглушки                   |
| без `meta`       | приписка не рисуется вовсе, строка становится ниже       |
| длинное название | переносится по словам, значение справа остаётся на месте |
| доля 0 %         | полоса не рисуется, значение и название на месте         |

## Состояния

Состояний взаимодействия нет: строки не нажимаются и фокус не берут.

## Доступность

- Значение продублировано текстом справа: ширина полосы не остаётся единственным носителем.
- Идентификатор строки дублируется атрибутом `data-id` — по нему строку находят проверки.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-delta-view`](./?path=/docs/molecules-data-deltaview-overview--docs) — изменение одной величины.
- [`rt-stat-tile`](./?path=/docs/molecules-data-stattile-overview--docs) — одно число крупно.

## Входы

| вход        | тип                             | умолчание | что делает                                        |
| ----------- | ------------------------------- | --------- | ------------------------------------------------- |
| `rows`      | `ReadonlyArray<IRtBarList.Row>` | `[]`      | строки: название, приписка, значение, доля полосы |
| `title`     | `string`                        | `''`      | заголовок над списком                             |
| `emptyText` | `string`                        | `''`      | текст заглушки; пустой оставляет переведённый     |

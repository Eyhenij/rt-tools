# `rt-aside-section`

Раздел внутри асайда: необязательный заголовок и тело.

```html
<rt-aside-section heading="Контакты">
    <rt-detail-list>…</rt-detail-list>
</rt-aside-section>
```

| вход      | тип              | умолчание |
| --------- | ---------------- | --------- |
| `heading` | `string \| null` | `null`    |

Выходов нет; содержимое приходит проекцией.

## Главное, что нужно знать

**Без заголовка пустой строки не появляется.** Разделы асайда часто идут подряд без подписей, и
пустой заголовок добавлял бы им лишний отступ.

Тело раздела рисуется всегда, даже пустым: прячут его стили.

**Внутри раздел размечен словарём формы панели.** Тело — это колонка контролов словаря,
заголовок — заголовок раздела, и промежуток между ними приходит зазором колонки, а не правилом
раздела. Поэтому панель, собранная из готовых разделов, стоит тем же ритмом, что и панель,
размеченная словарём вручную, а потребитель не пишет для неё ни одного правила оформления.

Своих правил у раздела остаётся одно — разделитель между соседними разделами: его словарь не
объявляет.

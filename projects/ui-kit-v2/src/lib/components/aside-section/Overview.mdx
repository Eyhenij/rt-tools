<Title>AsideSection — `rt-aside-section`</Title>

Раздел боковой панели: необязательный заголовок и содержимое проекцией. Задача компонента —
одинаковый отступ между разделами, а не оформление: без него каждая панель отбивала бы разделы
по-своему.

```html
<rt-aside-section heading="Договор">№2024-118</rt-aside-section>
<rt-aside-section>Раздел без заголовка идёт тем же отступом</rt-aside-section>
```

## Когда применять

- Деление содержимого боковой панели на смысловые куски.
- Раздел без заголовка, которому нужен тот же отступ, что и у соседей с заголовками.

## Когда не применять

- **Раздел основного экрана** — отступы панели рассчитаны на её ширину.
- **Складывающийся блок** — здесь нет ни состояния, ни кнопки.

## Оси

| ось        | значения                         | умолчание |
| ---------- | -------------------------------- | --------- |
| заголовок  | нет, короткий, длинный           | нет       |
| наполнение | строка, несколько абзацев, пусто | —         |

Пустой заголовок не рисует ни тега, ни отступа под него: раздел без заголовка не оставляет
дырки на его месте.

## Края

| край              | что происходит                                   |
| ----------------- | ------------------------------------------------ |
| пустое содержимое | тело раздела остаётся пустым, заголовок на месте |
| длинный заголовок | переносится по словам                            |

Как разделы стоят друг под другом, показано историей **Stack**: расстояние между ними — то,
ради чего компонент и заведён, и в одиночной ячейке его не видно.

## Состояния

Состояний у раздела нет: он ничего не принимает от указателя и фокус не берёт.

## Доступность

- Заголовок рисуется тегом `<h3>` — уровень постоянный, потому что раздел всегда живёт внутри
  панели со своим заголовком выше.
- Тело раздела помечено `qa-dataid` — по нему содержимое находят проверки.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-aside`](./?path=/docs/components-aside--docs) — сама боковая панель.
- [`rt-card`](./?path=/docs/components-card-overview--docs) — самостоятельный кусок содержимого
  со своей рамкой.

## Входы

| вход      | тип              | умолчание | что делает                                              |
| --------- | ---------------- | --------- | ------------------------------------------------------- |
| `heading` | `string \| null` | `null`    | заголовок раздела; пустой не рисует ни тега, ни отступа |

# `rt-delta-view`

Только показ содержимого редактора: превращает модель Quill в разметку.

```html
<rt-delta-view [delta]="message.delta" />
```

| вход    | тип                   | умолчание |
| ------- | --------------------- | --------- |
| `delta` | `IQuillDelta \| null` | `null`    |

Выходов нет. Своего шаблона у компонента нет — разметка строится в DOM напрямую.

## Главное, что нужно знать

**Разметка собирается вручную, а не через `innerHTML`.** Каждый узел создаётся отдельно, поэтому
в вывод не попадёт ничего, кроме поддержанного набора: жирный, курсив, подчёркнутый,
зачёркнутый, списки и блок кода. Это и есть защита — чужой HTML из модели не отрисуется.

**Соседние строки списка склеиваются в один `<ul>`/`<ol>`.** Каждая строка приходит своей
операцией; без склейки получился бы список из одного пункта на строку.

## Края

- `null` очищает разметку целиком — состояние «нечего показывать».
- Смена значения перерисовывает содержимое полностью, а не дописывает.

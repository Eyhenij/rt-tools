<Title>DeltaView — `rt-delta-view`</Title>

Только показ: превращает модель редактора Quill в разметку. Ничего не редактирует и своего
шаблона не имеет — разметка строится в DOM напрямую.

```html
<rt-delta-view [delta]="message.delta" />
```

## Когда применять

- Показ уже написанного сообщения: лента чата, история переписки, предпросмотр.

## Когда не применять

- **Редактирование** — [`rt-rich-editor`](./?path=/docs/components-richeditor--docs):
  он эту модель и производит.
- **Обычный текст без форматирования** — интерполяция в шаблоне: заводить модель ради одной
  строки незачем.

## Оси

| ось        | значения                                                      | умолчание |
| ---------- | ------------------------------------------------------------- | --------- |
| начертание | обычный, жирный, курсив, подчёркнутый, зачёркнутый, всё сразу | —         |
| блоки      | маркированный список, нумерованный список, цитата, блок кода  | —         |
| пусто      | модели нет (`null`), модель без операций                      | `null`    |

Ось здесь одна и она не перечислимая — модель редактора. Различимых значений у неё столько,
сколько форматов компонент понимает, поэтому ряды собраны по поддержанному набору.

**То, чего в наборе нет, в разметку не попадёт.** Каждый узел создаётся отдельно, а не через
`innerHTML`, — и это не деталь реализации, а защита: чужой HTML из модели не отрисуется.
Показать «неподдержанный формат» матрицей нельзя — на экране он выглядит как обычный текст.

Соседние строки списка склеиваются в один `<ul>`/`<ol>`: каждая строка приходит своей
операцией, и без склейки получился бы список из одного пункта на строку.

## Состояния

**Своих состояний взаимодействия у компонента нет:** он не принимает ни фокус, ни указатель,
и ни `:hover`, ни `:focus-visible`, ни `:active` в его SCSS не объявлено. Разметка внутри —
обычный текст, а не контролы.

## Доступность

Компонент не объявляет ни роли, ни живой области: это статичный кусок текста. Начертание
передано семантическими тегами (`strong`, `em`, `u`, `s`, `ul`, `ol`, `blockquote`, `code`),
поэтому скринридер читает его как разметку, а не как оформление.

## Оформление

Свойства текста и блоков берутся от кита — компонент рисует голые теги внутри блока
`rt-delta-view`, а стиль им даёт его SCSS.

## Входы

| вход    | тип                   | умолчание |
| ------- | --------------------- | --------- |
| `delta` | `IQuillDelta \| null` | `null`    |

`null` очищает разметку целиком — состояние «нечего показывать». Смена значения перерисовывает
содержимое полностью, а не дописывает.

## Выходы

Своих выходов нет.

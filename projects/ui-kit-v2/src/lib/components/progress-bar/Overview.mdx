<Title>ProgressBar — `rt-progress-bar`</Title>

Полоса прогресса: дорожка во всю ширину и заполнение поверх. С долей заполнение равно `value`
процентов и плавно идёт за ним; без доли по дорожке бежит отрезок.

```html
<rt-progress-bar ariaLabel="Обновление набора данных" [value]="percent()" />
<rt-progress-bar mode="indeterminate" />
```

## Когда применять

- Задача с известной долей: загрузка, обновление набора данных, импорт.
- Задача без доли, когда показать надо только то, что работа идёт.

## Когда не применять

- **Ожидание в кнопке или в небольшом месте** — `rt-spinner`.
- **Шаги, идущие по порядку** — [`rt-stepper`](./?path=/docs/atoms-feedback-stepper-overview--docs).

## Оси

| ось   | значения                                                       | умолчание     |
| ----- | -------------------------------------------------------------- | ------------- |
| доля  | меньше нуля, 0, 25, 60, 100, больше ста                        | `0`           |
| режим | `determinate`, `indeterminate`                                 | `determinate` |
| цвет  | `primary`, `secondary`, `info`, `success`, `warning`, `danger` | `primary`     |

**Оси, которые нельзя показать статикой.** Бегущий отрезок режима `indeterminate` кадр снимает в
одном положении, поэтому история **Mode** без снимка. Живая доля из потока — история **Live**:
«Запустить заново» гонит полосу тиками до ста.

## Состояния

**Своих состояний взаимодействия у полосы нет:** она не принимает ни фокус, ни нажатие.

## Края

| край                     | что происходит                                     |
| ------------------------ | -------------------------------------------------- |
| доля меньше нуля         | полоса пуста, объявляется 0                        |
| доля больше ста          | полоса полна, объявляется 100                      |
| `prefers-reduced-motion` | доля меняется без движения; без доли полоса залита |

## Доступность

- Хост — `role="progressbar"` с `aria-valuemin`, `aria-valuemax` и `aria-valuenow`.
- Без доли `aria-valuenow` не ставится: читается «идёт работа», а не число.
- `ariaLabel` называет задачу, когда рядом нет видимой подписи.

## Оформление

Высота, скругление, дорожка, заполнение и длительности — свойства `--rt-progress-bar-*`. Светлая и
тёмная темы — история **Themes**.

## Входы

| вход        | тип                    | умолчание       | что делает                              |
| ----------- | ---------------------- | --------------- | --------------------------------------- |
| `mode`      | `IRtProgressBar.Mode`  | `'determinate'` | доля или бегущий отрезок                |
| `value`     | `number`               | `0`             | доля в процентах; за краями прижимается |
| `color`     | `IRtProgressBar.Color` | `'primary'`     | цвет заполнения                         |
| `ariaLabel` | `string \| null`       | `null`          | что за задача — для чтения с экрана     |

## Выходы

Своих выходов нет.

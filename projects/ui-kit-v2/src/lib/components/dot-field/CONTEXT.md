# `rt-dot-field`

Фон из квадратных точек на сетке 10px, которые медленно плывут облаками. Заполняет
позиционированного родителя и стоит под его содержимым.

```html
<rt-dot-field />
```

Входов и выходов нет. Цвет точек — CSS-свойство `color` хоста.

## Главное, что нужно знать

**Какая клетка горит, решают чистые функции в `rt-dot-field.logic.ts`.** Клетка горит там, где
медленно движущийся шум проходит порог, а матрица Байера 4x4 сдвигает порог по клеткам: края
облаков выходят рваными. В центре поля плотность ниже — там стоит карточка.

**Рисует `RtDotFieldPainter`.** Кадр — раз в 90 мс, а не каждый кадр анимации: ступенчатое
движение — часть облика. Цвет читается из вычисленного `color` холста на каждом кадре, поэтому
точки идут за темой без кода: назначение темы — `light-dark()` или переопределение по флагу, а
холст принимает только готовый цвет.

**Запуск — в `afterNextRender`, остановка — при уходе компонента.** На сервере поле ничего не
рисует.

## Края

- При `prefers-reduced-motion: reduce` рисуется один кадр, следующий не просится.
- Холст без 2D-контекста (jsdom в спеках) ничего не рисует и `matchMedia` не спрашивает.
- `viewChild` не принимает поле с решёткой, поэтому `canvas` объявлен `protected`.
- Родитель задаёт `position: relative`, а своё содержимое ставит выше через `z-index: 1`.

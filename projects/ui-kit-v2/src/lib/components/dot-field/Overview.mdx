<Title>Dot field — `rt-dot-field`</Title>

Фон из квадратных точек, которые медленно плывут облаками. Заполняет позиционированного родителя и
стоит под его содержимым. В центре точки редеют, чтобы содержимое читалось.

```html
<section class="page">
    <rt-dot-field />
    <div class="card">…</div>
</section>
```

## Когда применять

- Страница с одной карточкой в центре: вход, ошибка, техническая пауза.

## Когда не применять

- **Рабочий экран со списками и формами** — движение под данными мешает их читать.
- **Ожидание загрузки** — [`rt-spinner`](./?path=/docs/atoms-feedback-spinner-overview--docs).

## Оси

Осей нет: сетка, скорость и порог у поля одни. Цвет точек — CSS-свойство `color` хоста, по
умолчанию `--rt-color-action-primary`.

## Состояния

**Состояний взаимодействия у компонента нет:** поле не принимает ни фокус, ни указатель.

Единственная развилка — `prefers-reduced-motion`: у пользователей, попросивших меньше движения,
поле рисует один кадр и останавливается. В витрине это видно только с системной настройкой.

Истории: **Playground** — одна сцена, **Presets** — сцена в обоих наборах, **Themes** — в обеих темах. Снимков у историй нет: поле движется, и кадр зависит от минуты, в которую его сняли.

## Доступность

- Холст объявлен `aria-hidden="true"`: поле — украшение, вспомогательным средствам о нём сказать
  нечего.
- Поле не принимает нажатий (`pointer-events: none`), всё под ним остаётся доступным.

## Оформление

`--rt-dot-field-color` — цвет точек, `--rt-dot-field-opacity` — прозрачность поля. Родитель
задаёт `position: relative` и ставит своё содержимое выше поля через `z-index: 1`.

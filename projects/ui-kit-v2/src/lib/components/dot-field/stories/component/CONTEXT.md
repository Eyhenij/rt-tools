# `TestRtDotFieldComponent`

Обёртка витрины для `rt-dot-field`. В пакет не уезжает.

Рисует сцену так, как поле стоит на странице входа: позиционированный родитель с фоном страницы,
поле под ним и карточка в центре поверх поля. Позиционированный родитель и карточка — забота
страницы, поэтому они живут здесь, а не в компоненте.

Вход `part` выбирает историю: `playground` — одна сцена, `presets` — сцена в обоих наборах, `themes` — в светлой и тёмной теме.
Снимков у историй нет: поле движется.

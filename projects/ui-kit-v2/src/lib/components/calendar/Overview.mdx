<Title>Calendar — `rt-calendar`</Title>

Сетка месяца с числами, подписями под ними и стрелками переключения. Календарь ничего не
считает и значения не хранит: раскладку готовит потребитель, а компонент её показывает.

```html
<rt-calendar
    [months]="months()"
    [weekdayLabels]="weekdays"
    [canPrev]="canPrev()"
    [canNext]="canNext()"
    (prevMonth)="shift(-1)"
    (nextMonth)="shift(1)"
    (dayClick)="pick($event)" />
```

## Когда применять

- Показ занятости месяца с подписями под числами: цены, свободные места.
- Выбор дат отрезком, когда состояние каждого дня считает потребитель.

## Когда не применять

- **Ввод даты в форму** — [`rt-date-picker`](./?path=/docs/molecules-forms-datepicker-overview--docs): это
  не поле ввода, значение календарь не хранит и в форму не пишет.
- **Плотная сводка занятости без чисел** — [`rt-night-grid`](./?path=/docs/molecules-data-nightgrid-overview--docs).

## Оси

| ось              | значения                                        | умолчание |
| ---------------- | ----------------------------------------------- | --------- |
| состояние дня    | `free`, `busy`, `past`, `blocked`               | —         |
| отрезок          | `start`, `in-range`, `end`                      | —         |
| месяцев показано | один, два, три                                  | —         |
| стрелки          | обе, только назад, только вперёд, обе выключены | обе       |
| подписи          | на месте, грузятся                              | на месте  |

**Календарь ничего не считает.** Сколько пустых клеток в начале, какие дни заняты, что писать
под числом, какие дни недоступны — всё приходит готовым. Поэтому он одинаково годится и для
выбора дат, и для витрины занятости.

Состояния показаны **целым месяцем**, а не ячейкой на значение: соседние дни различаются только
рядом друг с другом, а `start`, `in-range` и `end` вне самого отрезка не читаются вовсе.

## Края

| край                  | что происходит                                   |
| --------------------- | ------------------------------------------------ |
| ни одного месяца      | сетки нет, остаётся шапка со стрелками           |
| без пустых клеток     | первое число встаёт в первую ячейку недели       |
| шесть пустых клеток   | первая неделя почти пуста, раскладка не ломается |
| месяц без дней        | пустая сетка под заголовком месяца               |
| отрезок из одного дня | день несёт только `start`, без `end`             |

## Ширина

Календарь объявляет свои пороги сам: 640 px и 374 px. На них сетка месяца ужимается, поэтому у
матриц есть кадры на обоих.

## Состояния

| состояние | чем задаётся               | что меняется                               |
| --------- | -------------------------- | ------------------------------------------ |
| обычное   | —                          | число и подпись под ним                    |
| занято    | `state: busy`              | заливка занятости                          |
| прошедшее | `state: past`              | приглушено                                 |
| закрыто   | `state: blocked`           | перечёркнуто, не нажимается                |
| в отрезке | `start`, `in-range`, `end` | заливка отрезка, скругления по краям       |
| загрузка  | вход `sublabelsLoading`    | вместо подписей — заглушки, числа на месте |

## Доступность

- Стрелки несут имена из входов `prevAriaLabel` и `nextAriaLabel`.
- День — нативная кнопка; недоступный помечен `disabled`, а не только цветом.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-date-picker`](./?path=/docs/molecules-forms-datepicker-overview--docs) — ввод даты в форму.
- [`rt-night-grid`](./?path=/docs/molecules-data-nightgrid-overview--docs) — плотная сетка суток
  без чисел.

## Входы

| вход               | тип                            | умолчание | что делает                                 |
| ------------------ | ------------------------------ | --------- | ------------------------------------------ |
| `months`           | `readonly IRtCalendar.Month[]` | `[]`      | месяцы с готовой раскладкой                |
| `weekdayLabels`    | `readonly string[]`            | `[]`      | подписи дней недели в шапке сетки          |
| `canPrev`          | `boolean`                      | `false`   | доступна ли стрелка назад                  |
| `canNext`          | `boolean`                      | `false`   | доступна ли стрелка вперёд                 |
| `prevAriaLabel`    | `string`                       | `''`      | имя стрелки назад для скринридера          |
| `nextAriaLabel`    | `string`                       | `''`      | имя стрелки вперёд                         |
| `sublabelsLoading` | `boolean`                      | `false`   | подписи под числами подменяются заглушками |

## Выходы

| выход       | что сообщает                                       |
| ----------- | -------------------------------------------------- |
| `prevMonth` | нажата стрелка назад; месяцы подменяет потребитель |
| `nextMonth` | нажата стрелка вперёд                              |
| `dayClick`  | нажат день                                         |

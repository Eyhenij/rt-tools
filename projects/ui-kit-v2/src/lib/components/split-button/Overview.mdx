<Title>SplitButton — `rt-split-button`</Title>

Кнопка основного действия с прикреплённой кареткой: за кареткой — меню второстепенных действий.
Главное действие остаётся на виду, редкие прячутся под каретку.

```html
<rt-split-button
    label="Сохранить"
    [menuItems]="[{ value: 'draft', label: 'Сохранить черновик' }]"
    [loading]="saving()"
    (faceClick)="save()"
    (itemSelect)="run($event)" />
```

## Когда применять

- Есть **одно** главное действие и несколько его вариантов: сохранить / сохранить черновик /
  сохранить копию.
- Главное действие нажимают часто, и прятать его в меню было бы лишним шагом.

## Когда не применять

- **Главного действия нет** — [`rt-menu`](./?path=/docs/components-menu-overview--docs):
  все действия равнозначны.
- **Действие одно** — обычная [`[rtButton]`](./?path=/docs/components-button-overview--docs):
  каретка над пустым меню обещает то, чего нет.
- **Выбор значения, а не действия** — [`rt-select`](./?path=/docs/components-select-overview--docs).

## Оси

Палитра и размер не перемножены: размер меняет только высоту и отступы, и на всех шести
палитрах он один и тот же.

| ось     | значения                                                       | умолчание |
| ------- | -------------------------------------------------------------- | --------- |
| палитра | `primary`, `secondary`, `success`, `warning`, `danger`, `info` | `primary` |
| размер  | `sm`, `md`, `lg`, `xl`, `2xl`                                  | `md`      |
| меню    | обычный пункт, пункт с иконкой, недоступный пункт              | —         |

**Оси, которых не видно.** `menuAriaLabel` уходит в атрибут каретки; пустое значение подставляет
переведённую подпись кита.

**Открытое меню в истории одно.** Поповер висит на всём контроле, и щелчок по второй каретке для
CDK — указатель за пределами первой панели: она закрывается. Виды пунктов показаны набором
внутри одного меню, в истории `Panel`.

## Состояния

| состояние  | чем задаётся     | что меняется                                                         |
| ---------- | ---------------- | -------------------------------------------------------------------- |
| обычное    | —                | обе половины в заливке палитры                                       |
| наведение  | `:hover`         | обе половины красятся заодно, хотя нажимаются порознь                |
| нажатие    | `:active`        | как у [`[rtButton]`](./?path=/docs/components-button-overview--docs) |
| фокус      | `:focus-visible` | кольцо на той половине, что получила фокус                           |
| загрузка   | вход `loading`   | на основной кнопке спиннер, каретка недоступна, меню не открыть      |
| недоступно | вход `disabled`  | обе половины гасятся, меню не открыть                                |
| раскрыто   | нажатие каретки  | меню под кнопкой, шириной ровно с кнопку                             |

**Нажатие основной кнопки меню не открывает, и наоборот.** Это два независимых действия: щелчок
по кнопке поднимает `faceClick`, щелчок по каретке раскрывает меню.

**Поповер висит на всём контроле, а не на узкой каретке.** Так ширина меню равна ширине кнопки, а
левый край совпадает — иначе панель уезжала бы за экран.

## Доступность

- Каретка — отдельная кнопка с доступным именем: `menuAriaLabel` или переведённое умолчание кита.
- Меню объявлено `role="menu"`, пункт — `role="menuitem"`; отключённый пункт не выбирается и меню
  не закрывает.
- `Escape` и щелчок мимо закрывают меню.
- Значение пункта продублировано атрибутом `data-value` — для сквозных проверок.

## Оформление

Обе половины рисует [`[rtButton]`](./?path=/docs/components-button-overview--docs) с общей темой
и размером; пункты меню — та же кнопка в текстовом виде размера `sm`. Панель меню получает класс
`rt-split-button-menu-panel` поверх базового `rt-popover-panel`.

**Меню нет в светло-тёмной паре.** Оно рисуется в контейнере оверлеев CDK — за пределами блока,
которому пара назначает свойства темы. В паре стоит сама кнопка.

## Входы

| вход            | тип                                             | умолчание                    |
| --------------- | ----------------------------------------------- | ---------------------------- |
| `label`         | `string`                                        | **обязателен**               |
| `menuItems`     | `readonly { value, label, icon?, disabled? }[]` | **обязателен**               |
| `theme`         | как у `[rtButton]`                              | `'primary'`                  |
| `size`          | как у `[rtButton]`                              | `'md'`                       |
| `menuAriaLabel` | `string`                                        | `''` → `rtKit.uiMoreActions` |
| `loading`       | `boolean`                                       | `false`                      |
| `disabled`      | `boolean`                                       | `false`                      |

## Выходы

| выход        | тип      | когда                                     |
| ------------ | -------- | ----------------------------------------- |
| `faceClick`  | `void`   | нажата основная кнопка                    |
| `itemSelect` | `string` | выбран пункт меню — приходит его значение |

## Рядом

- [`rt-menu`](./?path=/docs/components-menu-overview--docs) — меню без основного действия.
- [`[rtButton]`](./?path=/docs/components-button-overview--docs) — чем нарисованы обе половины.

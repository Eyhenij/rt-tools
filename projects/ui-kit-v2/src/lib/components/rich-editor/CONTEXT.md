# `rt-rich-editor`

Поле ввода с форматированием поверх Quill. Значение — модель Quill (`IQuillDelta`), а не HTML.

```html
<rt-field label="Описание">
    <rt-rich-editor placeholder="Опишите задачу" toolbar="full" [formControl]="description" />
</rt-field>
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md):

| вход          | тип                    | умолчание |
| ------------- | ---------------------- | --------- |
| `placeholder` | `string`               | `''`      |
| `toolbar`     | `IRtRichEditorToolbar` | `'full'`  |

Выход: `enterPressed` — Enter без Shift (перенос при этом гасится).

## Главное, что нужно знать

**Quill грузится динамическим импортом** и создаётся только после первой отрисовки — чтобы не
тянуть его в основную сборку приложения. Отсюда два следствия:

- значение, пришедшее из формы **до** готовности редактора, откладывается и применяется при его
  создании — оно не теряется;
- в тестах модуль подменяется (`jest.mock('quill', …)`): сам Quill в jsdom не поднимается.

**Пустой текст пишет в форму `null`, а не пустой набор операций.** Так «пусто» отличимо от
«есть форматирование без текста» — на этом стоит проверка обязательности поля.

<Title>InputNumber — `rt-input-number`</Title>

Поле для числа: группирует разряды прямо во время набора, разбирает разделители по локали, на
уходе фокуса зажимает значение в границы и округляет до заданной точности. Значение — `number`
или `null`, приходит и уходит только через форму.

```html
<rt-field label="Сумма">
    <rt-input-number prefix="₽" [min]="0" [max]="1000000" [formControl]="amount" />
</rt-field>

<rt-input-number ariaLabel="Количество" [maxFractionDigits]="0" [formControl]="count" />
```

## Когда применять

- Сумма, количество, процент — всё, что должно уйти в форму числом, а не строкой.
- Значение с фиксированной точностью: цена всегда с двумя знаками, количество — без них.

## Когда не применять

- **Число меняют шагами, а не набирают** — [`rt-counter`](./?path=/docs/components-counter-overview--docs).
- **Строка, которая просто состоит из цифр** (телефон, счёт, ИНН) —
  [`rt-input`](./?path=/docs/components-input-overview--docs): группировка разрядов и округление
  такому значению противопоказаны.

## Оси

Оси не перемножаются: размер, префикс и дробная часть меняют разные части поля.

| ось           | значения                                       | умолчание |
| ------------- | ---------------------------------------------- | --------- |
| размер        | `sm`, `md`, `lg`                               | `md`      |
| слева         | ничего, иконка, текстовый префикс, оба         | ничего    |
| дробная часть | `0/0` целые, `0/2` умолчание, `2/2` всегда две | `0/2`     |
| наполненность | пусто, ноль, со значением                      | пусто     |
| рамка         | видна, снята (`bordered=false`)                | видна     |

**Ось, которую нельзя показать статикой.** `min` и `max` проявляются только на уходе фокуса:
поле зажимает набранное в границы. В неподвижной сетке ячейка «с ограничением» неотличима от
ячейки без него — попробовать это можно в `Playground`, набрав значение вне диапазона.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у поля нет             |
| фокус внутри  | `:focus-within`                      | рамка фокуса и `--rt-input-focus-shadow`           |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | плоский текст, пустое — прочерком                  |

**Ноль — не пустое значение.** Крестик очистки при нём не показывается: очистка числового поля
и есть обнуление, и сбрасывать ноль больше не во что. В матрице **Filling** ноль стоит отдельной
ячейкой рядом с пустым полем — иначе разница между ними читается как ошибка вёрстки.

## Доступность

- Подпись даёт вмещающий `rt-field`; без обёртки полю нужен `ariaLabel`.
- **Текстовый префикс спрятан от скринридера** (`aria-hidden`): валюту он прочитает из подписи
  поля, а не из значка перед числом.
- Поле объявлено как `<input type="text" inputmode="decimal">`: экранная клавиатура открывается
  числовой, но колесо мыши значение не меняет и разделители не зависят от браузера.

## Оформление

Собственных свойств нет — поле берёт группу `--rt-input-*` целиком, поэтому в форме стоит
вровень с `rt-input`. Своё у него только расположение префикса и иконки внутри той же коробки.

## Входы

| вход                | тип                    | умолчание                      |
| ------------------- | ---------------------- | ------------------------------ |
| `iconLeft`          | `IRtIcon.Name \| null` | `null`                         |
| `prefix`            | `string \| null`       | `null`                         |
| `placeholder`       | `string`               | `''`                           |
| `min`               | `number \| null`       | `null` (сторона не ограничена) |
| `max`               | `number \| null`       | `null` (сторона не ограничена) |
| `minFractionDigits` | `number`               | `0`                            |
| `maxFractionDigits` | `number`               | `2`                            |

**Точность фиксирована, а не задана диапазоном:** итоговое число знаков —
`max(minFractionDigits, min(maxFractionDigits, 20))`, и оно же и нижняя, и верхняя граница.
С умолчаниями `12` после ухода фокуса становится `12,00`; целое поле — это `maxFractionDigits: 0`.

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы.

## Рядом

- [`rt-field`](./?path=/docs/components-field-overview--docs) — подпись, звёздочка, ошибка, режим чтения.
- [`rt-input`](./?path=/docs/components-input-overview--docs) — то же поле для строк.
- [`rt-counter`](./?path=/docs/components-counter-overview--docs) — число, которое меняют шагами.

# `rt-input-number`

```html
<rt-field label="Сумма">
    <rt-input-number prefix="₽" [formControl]="amount" [min]="0" [max]="1000000" [maxFractionDigits]="2" />
</rt-field>
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md):

| вход                | тип                    | умолчание                      |
| ------------------- | ---------------------- | ------------------------------ |
| `prefix`            | `string \| null`       | `null`                         |
| `iconLeft`          | `IRtIcon.Name \| null` | `null`                         |
| `placeholder`       | `string`               | `''`                           |
| `min` / `max`       | `number \| null`       | `null` (сторона не ограничена) |
| `minFractionDigits` | `number`               | `0`                            |
| `maxFractionDigits` | `number`               | `2`                            |

Значение — `number | null`.

## Главное, что нужно знать

**Точность фиксирована, а не задана диапазоном.** Итоговое число знаков —
`max(minFractionDigits, min(maxFractionDigits, 20))`, и одно и то же значение служит и нижней, и
верхней границей. С умолчаниями это значит: `12` после ухода фокуса становится `12,00`. Целое
поле — это `maxFractionDigits: 0`.

**Разбор и запись зависят от локали (`LOCALE_ID`).** Поле рассчитано на локали, где разряды
разделяет пробел: `1 234,56`.

> **Известный дефект.** В локали, где разряды разделяет **запятая** (`en-US`), набранное `1000`
> отображается как `1,000`, а обратный разбор режет строку по первой запятой и отдаёт `1`.
> Дефект зафиксирован проверкой `локаль с запятой в разрядах` в спеке, чтобы он не уехал молча.

## Как этим пользоваться

- Это `<input type="text" inputmode="decimal">`, а не `type="number"`: у нативного числового поля
  колесо мыши меняет значение, а разделители зависят от браузера.
- Во время набора разряды группируются на лету, а каретка удерживается на месте (позиция
  пересчитывается по числу значимых символов слева от неё).
- Нечисловой ввод стрипается из отображения, но **прежнее значение держится до ухода фокуса** —
  наружу оно не уходит. Пустое поле пишет `null`.
- На уходе фокуса значение зажимается в границы, округляется до точности и переписывается
  отформатированным.
- **Крестик обнуляет поле, а не опустошает его** (`0,00`): у числового поля ноль осмыслен.
  При нуле крестик не показывается — обнулять больше нечего.
- Префикс спрятан от скринридера: валюту он прочитает из подписи поля.

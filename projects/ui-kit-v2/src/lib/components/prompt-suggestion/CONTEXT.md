# `rt-prompt-suggestion`

```html
@for (q of suggestions(); track q) {
<rt-prompt-suggestion [label]="q" (picked)="ask($event)" />
}
```

| вход       | тип       | умолчание  |
| ---------- | --------- | ---------- |
| `label`    | `string`  | обязателен |
| `disabled` | `boolean` | `false`    |

Выход: `picked` — текст вопроса.

Спек — `docs/specs/ui-kit-v2/prompt-suggestion/`; здесь только устройство папки.

## Главное, что нужно знать

**Карточка занимает всю ширину родителя**, стрелка прижата к правому краю. В столбце подсказок
разной длины стрелки стоят на одной вертикали.

## Края

- Класс блока висит и на хосте, и на кнопке: правила вложены в селектор хоста.

## Рядом

- [`rt-empty-state`](../empty-state/CONTEXT.md) — пустой экран, на котором стоят подсказки.

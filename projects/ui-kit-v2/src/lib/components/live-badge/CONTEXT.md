# `rt-live-badge`

```html
<rt-live-badge label="Смотрят сейчас" [count]="visitors()" [active]="streamAlive()" />
```

| вход     | тип              | умолчание                          |
| -------- | ---------------- | ---------------------------------- |
| `label`  | `string`         | `''` → переведённое `uiLiveOnSite` |
| `count`  | `number \| null` | `null` → прочерк `—`               |
| `active` | `boolean`        | `false`                            |

Выходов нет.

## Главное, что нужно знать

**`active` означает «поток жив», а не «счётчик больше нуля».** Ноль посетителей при живом
потоке — это данные; оборванный поток — их отсутствие, и выглядеть они должны по-разному.
Поэтому `[active]="true"` с `[count]="0"` — законное состояние, а `count === null` рисует
прочерк, а не ноль.

## Как этим пользоваться

- Пустая подпись равна отсутствию входа: подставляется переведённая формулировка кита.
  Значит `[label]="maybeEmpty()"` безопасно.
- Живость дублируется атрибутом `data-active` — по нему бейдж находят проверки, не завязываясь
  на BEM-класс.

<Title>LiveBadge — `rt-live-badge`</Title>

Пилюля живого счётчика: точка живости, подпись и число.

```html
<rt-live-badge label="Смотрят сейчас" [count]="visitors()" [active]="streamAlive()" />
```

## Когда применять

- Показатель, который обновляется сам и может перестать обновляться: посетители на сайте,
  активные сессии, участники комнаты.

## Когда не применять

- **Статус записи** — [`rt-tag`](./?path=/docs/components-tag-overview--docs): у него палитра
  смысла, а не живость потока.
- **Показатель с базой сравнения** — [`rt-stat-tile`](./?path=/docs/components-stattile-overview--docs).

## Оси

| ось     | значения                        | умолчание               |
| ------- | ------------------------------- | ----------------------- |
| живость | поток жив, поток оборван        | оборван (`false`)       |
| счётчик | данных нет (`null`), `0`, число | `null` → прочерк        |
| подпись | пустая → перевод кита, своя     | пустая (`uiLiveOnSite`) |

Живость перемножена со счётчиком — ровно та пара, ради которой у бейджа два входа вместо
одного. **`active` означает «поток жив», а не «счётчик больше нуля».** Ноль посетителей при
живом потоке — это данные; оборванный поток — их отсутствие, и выглядеть они обязаны
по-разному. Поэтому `[active]="true"` с `[count]="0"` — законная ячейка, а `null` рисует
прочерк, а не ноль.

## Состояния

**Своих состояний взаимодействия у бейджа нет:** он ничего не запускает, не принимает фокус,
и ни `:hover`, ни `:focus-visible`, ни `:active` в его SCSS не объявлено. Единственное его
состояние — живость потока, и она показана осью, а не псевдоклассом.

## Доступность

- Живость дублируется атрибутом `data-active` — по нему бейдж находят проверки, не завязываясь
  на BEM-класс.
- Цвет точки не единственный носитель смысла: подпись называет показатель словами, а прочерк
  вместо числа отличает «данных нет» от нуля без цвета.
- Пустая подпись равна отсутствию входа — подставляется переведённая формулировка кита, поэтому
  `[label]="maybeEmpty()"` безопасно.

## Оформление

Модификатор живости выводится BEM-директивой: `rt-live-badge--active`. Точка, подпись и число
— отдельные элементы блока, каждый со своими свойствами.

## Входы

| вход     | тип              | умолчание                          |
| -------- | ---------------- | ---------------------------------- |
| `label`  | `string`         | `''` → переведённое `uiLiveOnSite` |
| `count`  | `number \| null` | `null` → прочерк `—`               |
| `active` | `boolean`        | `false`                            |

## Выходы

Своих выходов нет.

## Рядом

- [`rt-tag`](./?path=/docs/components-tag-overview--docs) — статусная пилюля без счётчика.
- [`rt-stat-tile`](./?path=/docs/components-stattile-overview--docs) — показатель с базой сравнения.

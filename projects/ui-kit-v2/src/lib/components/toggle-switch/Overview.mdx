<Title>ToggleSwitch — `rt-toggle-switch`</Title>

Тумблер «включено / выключено». Значение — `boolean` через форму; своего текста на экране у него
нет, поэтому подпись приходит извне.

```html
<rt-toggle-switch ariaLabel="Уведомления" [formControl]="notify" />
<rt-toggle-switch size="md" iconOff="ico-notificationOff" iconOn="ico-notification" [formControl]="notify" />

<rt-counter-row label="Уведомления">
    <rt-toggle-switch ariaLabel="Уведомления" [formControl]="notify" />
</rt-counter-row>
```

## Когда применять

- Режим, который включается сразу: уведомления, тёмная тема, показ архива.
- Строка настроек, где подпись стоит слева, а контрол справа, — вместе с
  [`rt-counter-row`](./?path=/docs/components-counterrow-overview--docs).

## Когда не применять

- **Отметка в форме, которую ещё надо сохранить** —
  [`rt-checkbox`](./?path=/docs/components-checkbox-overview--docs): тумблер обещает, что
  действие уже произошло.
- **Переключение темы** — [`rt-theme-toggle`](./?path=/docs/components-themetoggle-overview--docs):
  готовый переключатель поверх этого, со своей иконкой и связью с сервисом темы.

## Оси

| ось       | значения                           | умолчание  |
| --------- | ---------------------------------- | ---------- |
| размер    | `sm`, `md`, `lg`                   | `sm`       |
| положение | выключено, включено                | выключено  |
| иконки    | без иконок, обе, только включённая | без иконок |

**Иконки перемножены с положением:** бегунок непрозрачен и наезжает на иконку текущего
состояния, поэтому в каждом положении видна ровно одна из двух — та, куда контрол переключится.
По одному положению набор иконок не прочитать. Размер ни с чем не перемножается: он меняет трек
и бегунок целиком, одинаково в обоих положениях.

Умолчание размера — `sm`: он совпадает по высоте с плотными контролами формы, где тумблер стоит
в одном ряду с текстом.

**Оси, которых не видно.** `inputId` и `ariaLabel` уходят в атрибуты.

## Состояния

| состояние       | чем задаётся                    | что меняется                               |
| --------------- | ------------------------------- | ------------------------------------------ |
| обычное         | —                               | трек `--rt-toggle-*`                       |
| наведение       | —                               | **ничего:** своего `:hover` у тумблера нет |
| фокус с клавиши | `:focus-visible`                | кольцо `--rt-shadow-focus-ring`            |
| включено        | значение формы                  | трек красится, бегунок уезжает в конец     |
| отключено       | вход `disabled` или слово формы | прозрачность, курсор `not-allowed`         |

Отключение приходит двумя путями — вход `disabled` и `FormControl.disable()`, — и оба пишут в
один внутренний сигнал: контрол ведёт себя одинаково, кто бы его ни выключил.

## Доступность

- `role="switch"`, а не `checkbox`: скринридер произносит «switch on/off» вместо «checkbox
  checked» — для тумблера это точнее.
- Своего текста у контрола нет: подпись задаётся входом `ariaLabel` или внешним `<label for>`
  через `inputId`. Без одного из них у контрола не будет доступного имени.
- Иконки на треке помечены как оформление: состояние читается из `aria-checked`, а не из них.

## Оформление

Трек, бегунок и иконки — элементы блока `rt-toggle-switch`; размеры берутся из
`--rt-toggle-track-width`, `--rt-toggle-track-height`, `--rt-toggle-thumb-size`, кольцо фокуса —
из `--rt-shadow-focus-ring`. Достаточно одной из двух иконок, чтобы включился режим с иконками.

## Входы

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `inputId`   | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'sm'`    |
| `iconOff`   | `IRtIcon.Name \| null` | `null`    |
| `iconOn`    | `IRtIcon.Name \| null` | `null`    |
| `disabled`  | `boolean`              | `false`   |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы.

## Рядом

- [`rt-theme-toggle`](./?path=/docs/components-themetoggle-overview--docs) — готовый переключатель темы поверх этого.
- [`rt-counter-row`](./?path=/docs/components-counterrow-overview--docs) — строка настроек, куда тумблер обычно кладут.

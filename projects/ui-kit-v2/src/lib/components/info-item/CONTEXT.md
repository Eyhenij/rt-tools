# `rt-info-item`

```html
<rt-info-item label="Тариф" [loading]="!plan()" [grow]="true">{{ plan()?.title }}</rt-info-item>
```

| вход      | тип       | умолчание      |
| --------- | --------- | -------------- |
| `label`   | `string`  | **обязателен** |
| `loading` | `boolean` | `false`        |
| `grow`    | `boolean` | `false`        |

Значение приходит **проекцией**, а не входом — поэтому внутрь можно положить что угодно:
текст, `rt-tag`, ссылку, `@if`.

## Главное, что нужно знать

**Во время загрузки подменяется только значение.** Подпись остаётся на месте: по ней читается,
чего именно ждут. Заглушка узкая (80px) — под значение, а не под всю строку.

## Как этим пользоваться

- `grow` растягивает элемент по свободному месту строки. Без него он занимает свою ширину —
  так пары «подпись: значение» выстраиваются в ряд.
- Пара подпись/значение — самостоятельный блок; для длинного вертикального перечня
  «ключ → значение» есть [`rt-detail-list`](../detail-list/CONTEXT.md).

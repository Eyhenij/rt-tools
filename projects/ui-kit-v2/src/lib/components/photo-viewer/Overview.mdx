<Title>PhotoViewer — `rt-photo-viewer`</Title>

Полноэкранный просмотр фотографий: кадр во весь показ, счётчик, стрелки и листание жестом.
Открывается окном, поэтому затемнение, `Esc` и блокировку прокрутки фона даёт сам диалог.

```typescript
this.dialogService.open(RtPhotoViewerComponent, {
    data: { photos, startIndex: 2, panel: this.photoPanel() },
});
```

## Когда применять

- Снимок нужно рассмотреть целиком: карточка объекта, вложения переписки, галерея.

## Когда не применять

- **Одна картинка без листания** — обычный `<img>` в разметке потребителя.
- **Выбор файла** — [`rt-file-input`](./?path=/docs/molecules-forms-fileinput-overview--docs).

## Оси

| ось               | значения                                     | умолчание        |
| ----------------- | -------------------------------------------- | ---------------- |
| открытый кадр     | первый, средний, последний                   | заданный данными |
| число кадров      | один — стрелок нет, несколько — стрелки есть | —                |
| панель под кадром | нет, есть                                    | нет              |

**Ряда из ячеек у этого компонента нет.** Просмотрщик занимает весь показ — 100 vw на 100 dvh,
— и два экземпляра рядом наложились бы друг на друга. Поэтому каждый случай показан своей
историей на весь кадр, а сравнивают их переключением между историями.

**Панель под кадром витриной не показана.** Она приходит шаблоном в данных открытия, а данные в
витрине задаются провайдером — то есть раньше, чем шаблоны истории вообще существуют. Показать
её честно можно только из приложения, где панель объявлена в разметке экрана.

## Края

| край               | что происходит                                                       |
| ------------------ | -------------------------------------------------------------------- |
| один кадр          | стрелок нет вовсе, счётчик показывает «1 / 1»                        |
| первый кадр        | стрелка «назад» на месте, но листать назад некуда                    |
| последний кадр     | то же самое со стрелкой «вперёд»                                     |
| кадр не загрузился | место под него остаётся: высоту резервирует соотношение сторон кадра |

## Состояния

| состояние       | чем задаётся        | что меняется                       |
| --------------- | ------------------- | ---------------------------------- |
| обычное         | —                   | кадр во весь показ, счётчик сверху |
| наведение       | `:hover` на стрелке | подложка стрелки                   |
| фокус с клавиши | `:focus-visible`    | кольцо на стрелке или крестике     |

Фокус переводится на сам просмотрщик сразу после открытия: клавиши `←`, `→` и `Esc` слушает он,
и без фокуса они не работали бы, пока человек куда-нибудь не нажмёт.

## Доступность

- Объявляется `role="dialog"` с `aria-modal`, фокус заперт внутри до закрытия.
- У крестика и стрелок есть переведённые подписи для скринридера.
- Подпись кадра берётся из `alt` — её задаёт вызывающая сторона вместе со списком кадров.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**. Подложка у просмотрщика инверсная в
обеих темах — кадр рассматривают на тёмном.

## Рядом

- [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs) — окно, поверх которого он открывается.
- [`rt-file-card`](./?path=/docs/molecules-files-filecard-overview--docs) — карточка файла в списке вложений.

## Входы

Входов нет: список кадров, открытый кадр и шаблон панели приходят данными открытия
(`RtDialogService.open(..., { data })`), а не привязкой в разметке.

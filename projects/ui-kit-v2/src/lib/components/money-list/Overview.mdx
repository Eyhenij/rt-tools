<Title>MoneyList — `rt-money-list`, `rt-money-row`</Title>

Список денежных строк: подпись слева, сумма справа, итог — той же строкой, но выделенной
начертанием. Своих входов у списка нет: он только раскладывает строки.

```html
<rt-money-list>
    <rt-money-row label="Работы">120 000 ₽</rt-money-row>
    <rt-money-row label="Материалы" [loading]="pending()">28 000 ₽</rt-money-row>
    <rt-money-row total label="Итого">148 000 ₽</rt-money-row>
</rt-money-list>
```

## Когда применять

- Смета, счёт, разбивка суммы по статьям — там, где строки однородны и есть итог.

## Когда не применять

- **Реквизиты, а не суммы** — [`rt-detail-list`](./?path=/docs/molecules-data-detaillist-overview--docs):
  там значение бывает любым, здесь оно выровнено по правому краю как число.
- **Много строк с колонками** — [`rt-table`](./?path=/docs/organisms-table-table-overview--docs).

## Оси

| ось             | значения                                 | умолчание |
| --------------- | ---------------------------------------- | --------- |
| итоговая строка | без итога, с итогом, итог не равен сумме | без итога |
| загрузка        | сумма на месте, заглушка                 | на месте  |
| длина списка    | одна, три строки                         | —         |

**Считать компонент не умеет.** Итог — это просто строка с признаком `total`, выделенная
начертанием; складывает суммы вызывающий код. Поэтому в матрице стоит ячейка, где итог
намеренно не равен сложению строк над ним: скидка, налог или округление приходят снаружи.

## Края

| край            | что происходит                                                |
| --------------- | ------------------------------------------------------------- |
| пустой список   | рисуется пустой контейнер, заглушки нет                       |
| только итог     | строка итога законна сама по себе                             |
| пустая сумма    | колонка суммы остаётся пустой, подпись на месте               |
| длинная подпись | переносится по словам, сумма остаётся прижатой к правому краю |

## Состояния

| состояние | чем задаётся   | что меняется                              |
| --------- | -------------- | ----------------------------------------- |
| обычное   | —              | сумма показана как есть                   |
| итог      | вход `total`   | начертание строки выделено                |
| загрузка  | вход `loading` | вместо суммы — заглушка, подпись на месте |

Загрузка и итог сочетаются: итоговая строка ждёт своей суммы так же, как обычная.

## Доступность

- Подпись и сумма — соседние элементы одной строки; порядок чтения совпадает с показом.
- Итог отличается не только цветом, но и начертанием.

## Оформление

Заглушка загрузки постоянного размера — при подстановке суммы строка не меняет высоту. Светлая
и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-detail-list`](./?path=/docs/molecules-data-detaillist-overview--docs) — пары «подпись —
  значение» без денежного выравнивания.

## Входы

| вход      | тип       | умолчание | что делает                           |
| --------- | --------- | --------- | ------------------------------------ |
| `label`   | `string`  | `''`      | подпись строки слева                 |
| `total`   | `boolean` | `false`   | строка итога: выделяется начертанием |
| `loading` | `boolean` | `false`   | вместо суммы рисуется заглушка       |

У самого `rt-money-list` входов нет: он только раскладывает вложенные строки.

# `rt-bottom-sheet-confirm`

Экран вопроса [`rt-bottom-sheet`](../CONTEXT.md) перед закрытием с неприменённым выбором. Внутренний:
в точке входа кита его нет, в разметку его ставит только шторка — через `RtSheetConfirmPlace`, когда
пришёл его код. Код приходит ленивым `import()` из `../rt-bottom-sheet-confirm.loader.ts`, поэтому
экран лежит в своей папке и не весит на старте приложения.

| вход      | тип                     | умолчание  |
| --------- | ----------------------- | ---------- |
| `labels`  | `IRtSheetConfirmLabels` | обязателен |
| `titleId` | `string`                | обязателен |

Ответы «Применить», «Не применять» и «Отмена» экран отдаёт шторке через внутренний токен
`RT_SHEET_CONFIRM_ANSWERS` (`../rt-bottom-sheet-confirm.answers.ts`): решает шторка, экран только
спрашивает. Фокус встаёт на «Применить», как только экран нарисован. Классы экрана — элементы блока
`rt-bottom-sheet`; стили лежат рядом и приходят вместе с кодом экрана.

<Title>BottomSheet — `rt-bottom-sheet`</Title>

Панель, выезжающая снизу, с подложкой поверх содержимого. Единственный оверлей кита, который
берёт открытость **входом**, а не открывается вызовом.

```html
<rt-bottom-sheet [open]="sheetOpen()" (openChange)="sheetOpen.set($event)">
    <span sheetHeader>Действия с договором</span>
    <button rtButton label="Скачать" appearance="text"></button>
    <button sheetFooter rtButton label="Готово"></button>
</rt-bottom-sheet>
```

## Слоты

| слот            | что в нём                                                         |
| --------------- | ----------------------------------------------------------------- |
| `[sheetHeader]` | заголовок в центре шапки                                          |
| `[sheetAction]` | действие справа в шапке: залитая кнопка «Готово» или «Применить»  |
| по умолчанию    | содержимое; лежит в теле, которое прокручивается само             |
| `[sheetFooter]` | подвал под телом: кнопки действий, не уезжают вместе с содержимым |

Свою шапку целиком задаёт `<ng-template rtSheetHeader let-close>`, свой подвал —
`<ng-template rtSheetFooter let-close let-apply="apply">`. Шаблон получает просьбу закрыть `close`
и просьбу применить `apply`. Тот, кто открывает шторку кодом, передаёт шаблоны входами
`headerTemplate` и `footerTemplate`; шторку со своей шапкой называет вход `ariaLabel`.

Вход `unsaved` включает вопрос перед закрытием; ответы приходят выходами `applyRequest` и
`discardRequest`. Закрытая шторка возвращает фокус туда, откуда её открыли. Пока на телефоне
открыта клавиатура, шторка стоит в части окна над ней.

Слева в шапке всегда стоит кнопка закрытия (якорь `bottom-sheet-close`): она просит закрыть так
же, как подложка. Заголовок стоит по центру; без заголовка кнопка остаётся.

## Когда применять

- Набор действий на узком экране, где меню было бы тесным.
- Короткая форма, которую не хочется разворачивать в окно.

## Когда не применять

- **Вопрос, требующий ответа** — [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs).
- **Меню у кнопки на широком экране** — [`rt-menu`](./?path=/docs/molecules-navigation-menu-overview--docs).

## Оси

| ось        | значения                                       | умолчание |
| ---------- | ---------------------------------------------- | --------- |
| открытость | закрыт, открыт                                 | закрыт    |
| наполнение | без шапки, с шапкой, длинное содержимое, пусто | —         |
| подвал     | нет, есть                                      | нет       |

**Лист не закрывает себя сам.** Состоянием владеет потребитель: нажатие на подложку и свайп
вниз поднимают `openChange` со значением `false`, а закрыть должен тот, кто держит сигнал. Так
лист можно не закрывать, если что-то не сохранено.

**Закрытый лист остаётся в разметке.** Прячут его стили, а не условие: анимацию выезда и ухода
рисует оформление, и исчезнувший из разметки узел анимировать было бы нечем. Поэтому ячейка
закрытого листа в матрице не пустая — в ней тот же лист, просто уведённый вниз.

Для спек это значит, что панель найдётся и у закрытого листа: смотреть надо на модификатор
`rt-bottom-sheet--open` на хосте.

## Края

| край                          | что происходит                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------ |
| пустое содержимое             | остаётся панель с ручкой захвата                                               |
| длинное содержимое            | панель встаёт во всю высоту с полосой 12 px сверху, дальше прокручивается тело |
| подвал при длинном содержимом | тело прокручивается, подвал стоит внизу панели                                 |
| подвал шире панели            | спроецированное переносится на следующую строку                                |
| нет подвала                   | элемент подвала пуст и места не занимает                                       |

## Состояния

| состояние | чем задаётся                 | что меняется                            |
| --------- | ---------------------------- | --------------------------------------- |
| закрыт    | `open = false`               | панель уведена вниз, подложки нет       |
| открыт    | `open = true`                | панель на месте, подложка поверх экрана |
| печатают  | показана экранная клавиатура | лист во всю высоту над клавиатурой      |

Высоту листа даёт содержимое. Лист встаёт во всю высоту, пока показана экранная клавиатура;
клавиатуру убрали — высота снова по содержимому. С мышью высота прежняя.

## Доступность

- Подложка — настоящая `<button>` с переведённой подписью, а не немой блок: до неё доходят
  клавиатурой и её называет скринридер.
- Панель объявлена `role="dialog"` с `aria-modal="true"`.
- Свайп начинает только ручка захвата: прокрутка тела и нажатие кнопок подвала лист не тянут.
- Вне оверлея CDK лист сам держит прокрутку страницы и закрывается по Escape.
- Когда система просит убрать движение, лист появляется без выезда.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**. В матрицах каждая ячейка — своя область
с собственной системой координат: иначе панели легли бы поверх страницы и накрыли подписи
соседних ячеек.

## Рядом

- [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs) — модальное окно.
- [`rt-menu`](./?path=/docs/molecules-navigation-menu-overview--docs) — меню у кнопки.

## Входы

| вход             | тип                   | умолчание      | что делает                                                  |
| ---------------- | --------------------- | -------------- | ----------------------------------------------------------- |
| `open`           | `boolean`             | `false`        | открыт ли лист; закрывает его потребитель                   |
| `radius`         | `TRtRadius \| null`   | `null` → `2xl` | шаг общей шкалы для главной поверхности                     |
| `ariaLabelledby` | `string \| null`      | `null`         | id заголовка, которым называется окно листа для скринридера |
| `fullHeight`     | `boolean`             | `false`        | лист во всю высоту экрана сразу; ставит приложение          |
| `unsaved`        | `boolean`             | `false`        | перед закрытием лист спрашивает внизу экрана                |
| `ariaLabel`      | `string \| null`      | `null`         | имя окна листа, когда заголовка в разметке нет              |
| `headerTemplate` | `TemplateRef \| null` | `null`         | своя шапка от того, кто открывает лист кодом                |
| `footerTemplate` | `TemplateRef \| null` | `null`         | свой подвал от того, кто открывает лист кодом               |

## Выходы

| выход            | что сообщает                                                                          |
| ---------------- | ------------------------------------------------------------------------------------- |
| `openChange`     | нажата кнопка закрытия, подложка, Escape или сделан свайп вниз; закрывает потребитель |
| `applyRequest`   | в вопросе нажали «Применить» или шаблон позвал `apply`; применяет потребитель         |
| `discardRequest` | в вопросе нажали «Не применять»; ввод сбрасывает потребитель                          |

С `unsaved` просьба закрыть показывает вопрос с тремя ответами: «Применить», «Не применять»,
«Отмена». Первый поднимает `applyRequest` и просит закрыть, второй просит закрыть, третий убирает
вопрос.

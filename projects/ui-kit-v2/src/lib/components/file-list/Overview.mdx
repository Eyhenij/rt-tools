<Title>FileList — `rt-file-list`</Title>

Вертикальный столбец карточек файлов: задаёт расстояние между ними и растягивает каждую по
ширине. Своего содержимого у списка нет — карточки проецируются внутрь.

```html
<rt-file-list>
    <rt-file-card name="Договор.pdf" [size]="184320" />
    <rt-file-card name="Приложение №1.docx" [size]="20480" />
</rt-file-list>
```

## Когда применять

- Несколько выбранных или уже загруженных файлов подряд — под полем выбора, в карточке
  сущности, в переписке.

## Когда не применять

- **Один файл** — [`rt-file-card`](./?path=/docs/components-filecard--docs) ставится сам по
  себе, обёртка ему ничего не добавляет.
- **Список записей с колонками** — [`rt-table`](./?path=/docs/components-table--docs).

## Оси

| ось                | значения                                   | умолчание |
| ------------------ | ------------------------------------------ | --------- |
| число карточек     | одна, несколько, много                     | —         |
| состояние карточек | обычные, с ошибкой, в загрузке, вперемешку | —         |

Собственных осей у списка нет: он ничего не принимает входами. Ось здесь одна — что в него
положили, и от этого зависит вся его высота и вид.

## Края

| край              | что происходит                                                                 |
| ----------------- | ------------------------------------------------------------------------------ |
| пустой список     | не рисует ничего: ни рамки, ни отступа — пустое место занимает сам потребитель |
| одна карточка     | отступов между карточками нет, столбец равен карточке                          |
| длинное имя файла | обрезает карточка по середине имени, ширина столбца не растёт                  |

## Состояния

Своих состояний у списка нет: он не интерактивен, не получает фокус и не откликается на
наведение. Всё видимое приходит от карточек внутри — их состояния показаны на странице
[`rt-file-card`](./?path=/docs/components-filecard--docs).

## Доступность

- Список не объявляет ни роли, ни подписи: он раскладка, а не перечень для скринридера.
  Название файла и его состояние читаются с самой карточки.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-file-card`](./?path=/docs/components-filecard--docs) — карточка одного файла.
- [`rt-file-drop`](./?path=/docs/components-filedrop--docs) — область, куда файлы перетаскивают.
- [`rt-file-input`](./?path=/docs/components-fileinput--docs) — выбор файла кнопкой.

## Входы

Входов нет: содержимое приходит проекцией, а расстояния между карточками задают стили.

<Title>Header — `rt-header`</Title>

Шапка приложения: кнопка «назад», логотип, необязательное приглашение, колокольчик проекцией и
профиль. Ни маршрутом, ни уведомлениями шапка не владеет — она только сообщает о нажатиях.

```html
<rt-header showInvite [canGoBack]="canGoBack()" (backClick)="back()" (profileClick)="openProfile()">
    <rt-notifications-bell rtHeaderBell ariaLabel="Уведомления" [unread]="hasUnread()" />
</rt-header>
```

## Когда применять

- Верхняя полоса приложения, одна на все экраны.

## Когда не применять

- **Полоса действий над содержимым** — [`rt-toolbar`](./?path=/docs/organisms-tables-lists-toolbar-overview--docs).
- **Заголовок панели или окна** — `rt-page-header`.

## Оси

| ось            | значения                                    | умолчание |
| -------------- | ------------------------------------------- | --------- |
| кнопка «назад» | скрыта, видна                               | скрыта    |
| приглашение    | нет, есть                                   | нет       |
| колокольчик    | без него, всё прочитано, есть непрочитанные | без него  |

Первые две оси перемножены, потому что ведут себя по-разному и рядом это видно:

- **Кнопка «назад» не появляется и не исчезает — она проявляется.** Узел есть в разметке всегда,
  видимость даёт модификатор: иначе соседние элементы шапки прыгали бы при каждом переходе. В
  сетке видно, что место под неё занято в обеих строках.
- **Кнопка приглашения появляется и исчезает** — её узла в разметке нет, пока вход выключен.

**Колокольчик приходит проекцией.** Шапка ничего не знает про уведомления — их состоянием
владеет приложение, и точка непрочитанного приходит вместе с самим колокольчиком.

## Края

| край             | что происходит                     |
| ---------------- | ---------------------------------- |
| без колокольчика | место в ряду не резервируется      |
| «назад» скрыта   | место занято, соседи не сдвигаются |

## Состояния

Своих состояний у шапки нет: всё взаимодействие принадлежит кнопкам внутри — они иконочные, со
своими наведением, нажатием и фокусом.

## Доступность

- У каждой кнопки переведённое имя и подсказка: иконка без подписи именем не служит.
- Логотип — не ссылка: переход по нему вешает приложение, если он ему нужен.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-toolbar`](./?path=/docs/organisms-tables-lists-toolbar-overview--docs) — полоса действий над
  содержимым.
- [`rt-notifications-bell`](./?path=/docs/molecules-notificationsbell-overview--docs) — тот
  самый колокольчик.

## Входы

| вход         | тип       | умолчание | что делает                                            |
| ------------ | --------- | --------- | ----------------------------------------------------- |
| `canGoBack`  | `boolean` | `false`   | проявляет кнопку «назад»; место под неё занято всегда |
| `showInvite` | `boolean` | `false`   | добавляет кнопку приглашения в разметку               |

## Выходы

| выход          | что сообщает                                     |
| -------------- | ------------------------------------------------ |
| `backClick`    | нажата кнопка «назад»; переход делает приложение |
| `inviteClick`  | нажата кнопка приглашения                        |
| `profileClick` | нажата кнопка профиля                            |

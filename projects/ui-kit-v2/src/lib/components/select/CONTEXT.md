# `rt-select<TValue>`

```html
<rt-field label="Город">
    <rt-select placeholder="Выберите" [formControl]="city" [options]="cities" [filter]="true" (selectionChange)="onPicked($event)" />
</rt-field>
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md):

| вход                | тип                                          | умолчание         |
| ------------------- | -------------------------------------------- | ----------------- |
| `options`           | `ReadonlyArray<{ label, value, disabled? }>` | `[]`              |
| `placeholder`       | `string`                                     | `''`              |
| `iconLeft`          | `IRtIcon.Name \| null`                       | `null`            |
| `filter`            | `boolean`                                    | `false`           |
| `filterPlaceholder` | `string`                                     | `''` → `uiSearch` |

| выход             | тип              |
| ----------------- | ---------------- |
| `selectionChange` | `TValue \| null` |

## Главное, что нужно знать

**Подпись выбранного берётся из `options`, а не хранится.** В значении лежит только `value`;
если набор опций пришёл позже или сменился, подпись перерисуется сама. Значение, которого нет в
наборе, покажется пустой строкой.

**`selectionChange` — это не дубль формы.** Форма получает значение через
`ControlValueAccessor`; отдельный выход нужен там, где на выбор надо среагировать (перезагрузить
зависимый список), не подписываясь на `valueChanges` всей формы. Очистка крестиком тоже
поднимает его — со значением `null`.

## Клавиатура

- Закрытый список раскрывают `ArrowDown`, `ArrowUp`, `Enter`, `Space` — и сразу подсвечивают
  первую доступную опцию.
- Стрелки **перешагивают отключённые опции** и заворачиваются по кругу.
- `Enter`/`Space` выбирают подсвеченную, `Escape` закрывает без выбора.
- Опции не фокусируются поодиночке: подсвеченная называется скринридеру через
  `aria-activedescendant` на триггере.

## Края

- Закрытие списка помечает контрол тронутым и сбрасывает строку фильтра.
- `FormControl.disable()` **закрывает уже раскрытый** список — иначе панель висела бы над
  контролом, которым уже нельзя пользоваться.
- Пустой набор опций рисует строку `uiNoOptions`.
- Ширина панели равна ширине триггера (`rtPopoverWidth="trigger"`).

## Рядом

- [`rt-multiselect`](../multiselect/CONTEXT.md) — тот же список, но с несколькими значениями.
- [`rt-autocomplete`](../autocomplete/CONTEXT.md) — когда набор ищут на сервере.

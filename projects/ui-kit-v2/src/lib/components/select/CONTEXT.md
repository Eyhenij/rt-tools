# `rt-select<TValue>`

```html
<rt-field label="Город">
    <rt-select placeholder="Выберите" [formControl]="city" [options]="cities" [filter]="true" (selectionChange)="onPicked($event)" />
</rt-field>
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md):

| вход                | тип                                                     | умолчание         |
| ------------------- | ------------------------------------------------------- | ----------------- |
| `options`           | `ReadonlyArray<{ label, value, disabled?, children? }>` | `[]`              |
| `placeholder`       | `string`                                                | `''`              |
| `iconLeft`          | `IRtIcon.Name \| null`                                  | `null`            |
| `filter`            | `boolean`                                               | `false`           |
| `filterPlaceholder` | `string`                                                | `''` → `uiSearch` |
| `floatingLabel`     | `string \| null`                                        | `null`            |

| выход             | тип              |
| ----------------- | ---------------- |
| `selectionChange` | `TValue \| null` |
| `cleared`         | `void`           |

Своя разметка строки — шаблон `<ng-template rtSelectOption let-option let-selected="selected">`.
Она встаёт на место подписи пункта и ею же поле рисует выбранное значение: цветная метка из списка
остаётся в поле после выбора. Стрелка ветки, галочка, выбор и клавиши остаются у кита.

## Главное, что нужно знать

**Подпись выбранного берётся из `options`, а не хранится.** В значении лежит только `value`;
если набор опций пришёл позже или сменился, подпись перерисуется сама. Значение, которого нет в
наборе, покажется пустой строкой.

**`selectionChange` — это не дубль формы.** Форма получает значение через
`ControlValueAccessor`; отдельный выход нужен там, где на выбор надо среагировать (перезагрузить
зависимый список), не подписываясь на `valueChanges` всей формы. Очистка крестиком тоже
поднимает его — со значением `null`.

## Клавиатура

- Закрытый список раскрывают `ArrowDown`, `ArrowUp`, `Enter`, `Space`. Подсветка встаёт на
  выбранную опцию (`onOpened`, и при открытии мышью тоже), без выбора — на первую доступную.
- Стрелки **перешагивают отключённые опции** и заворачиваются по кругу.
- `Enter`/`Space` выбирают подсвеченную, `Escape` закрывает без выбора.
- В дереве `ArrowRight` раскрывает ветку или спускается к первому ребёнку, `ArrowLeft` сворачивает
  ветку или поднимается к родителю. Опции с `children` рисуются деревом — договорённость в
  `docs/specs/ui-kit-v2/option-tree/`.
- Опции не фокусируются поодиночке: подсвеченная называется скринридеру через
  `aria-activedescendant` на триггере.
- Подсвеченная опция **прокручивается в видимую часть панели** (`block: 'nearest'`): у панели
  предел высоты, а фокус на триггере, и сам браузер её не прокручивает. То же у `rt-multiselect` и
  `rt-autocomplete`.

## Края

- `floatingLabel` кладёт подпись на место подсказки пустого поля и поднимает её на рамку, когда
  значение выбрано или список открыт. Рамка под поднятой подписью разрывается. Подпись вместе с
  выбранным значением называет кнопку скринридеру, если своего `ariaLabel` нет.
- С `clearTabbable` крестик — соседняя кнопка поверх своего места в строке, а не кнопка внутри
  кнопки: вложенную скринридер не объявляет, а её Enter открывал бы список.
- `Escape` в открытом списке закрывает только список и не доходит до слоя под ним.
- Закрытие списка помечает контрол тронутым и сбрасывает строку фильтра.
- `FormControl.disable()` **закрывает уже раскрытый** список — иначе панель висела бы над
  контролом, которым уже нельзя пользоваться.
- Пустой набор опций рисует строку `uiNoOptions`.
- Ширина панели не меньше ширины триггера и дальше растёт по содержимому
  (`rtPopoverWidth="trigger-min"`); вход `panelWidth` возвращает прежнее `trigger` или пускает
  панель по содержимому целиком.
- Высота панели упирается в предел кита `--rt-input-panel-max-height`, длинный список
  прокручивается внутри. Вход `panelMaxHeight` ставит свой предел, `none` снимает его.

**Крестик не выше поля без рамки, наименьшая ширина — свойство.** Как у поля ввода: ступень `size`
ставит `--rt-input-height`, крестик и его место в строке считаются от неё. Наименьшая ширина —
`--rt-input-min-width`, по умолчанию её нет.

**Под материальным набором текст стоит в 16 px от внешнего края, а отключённый выбор не тускнеет.**
Рамка у отключённого выбора — `on-surface` 12 %, текст, подсказка и стрелка — 38 %. Эти правила
лежат в четвёртом листе стилей компонента: с ними основной лист перешёл бы порог в 8 КБ.

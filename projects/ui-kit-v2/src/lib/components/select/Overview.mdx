<Title>Select — `rt-select`</Title>

Выбор одного значения из известного заранее набора. В форме лежит `value` опции, а подпись
берётся из `options` — хранить её отдельно не нужно. Панель списка рисуется поверх страницы
через CDK Overlay, поэтому её не режет `overflow: hidden` у таблицы, панели или карточки.

```html
<rt-field label="Город">
    <rt-select placeholder="Выберите" [options]="cities" [formControl]="city" />
</rt-field>

<rt-select [options]="cities" [filter]="true" [formControl]="city" (selectionChange)="reloadStreets($event)" />
```

## Когда применять

- Набор известен заранее и умещается в список: город, статус, тип документа.
- Список длинный, но конечный — тогда со строкой фильтра (`[filter]="true"`).

## Когда не применять

- **Несколько значений** — [`rt-multiselect`](./?path=/docs/components-multiselect-overview--docs):
  тот же список, но выбранное остаётся фишками в триггере.
- **Набор ищется на сервере** — [`rt-autocomplete`](./?path=/docs/components-autocomplete-overview--docs):
  там значение появляется от набранной строки, а не от готового перечня.
- **Два-три равнозначных варианта** — [`rt-toggle-button-group`](./?path=/docs/components-togglebuttongroup-overview--docs):
  раскрывать список ради выбора из двух дороже, чем показать оба сразу.

## Оси

Оси не перемножаются: размер, наполненность и рамка меняют разные части триггера и вместе
ничего нового не показывают.

| ось           | значения                                  | умолчание |
| ------------- | ----------------------------------------- | --------- |
| размер        | `sm`, `md`, `lg` — 32 / 40 / 48 px        | `md`      |
| наполненность | подсказка, значение, значение без очистки | подсказка |
| иконка слева  | нет, есть                                 | нет       |
| рамка         | видна, снята (`bordered=false`)           | видна     |
| панель        | список, список с фильтром, пустой набор   | список    |

**Оси, которых не видно.** `controlId` и `ariaLabel` уходят в атрибуты: первым связывается
`<label for>` вмещающего поля, второй даёт триггеру доступное имя. `filterPlaceholder` виден
только внутри раскрытой панели с фильтром — он показан там, а не отдельным рядом.

**Панель показана отдельными историями, и открытая панель в истории ровно одна.** Второй жест
для CDK — это указатель за пределами первой панели, и она закрывается; рядом стоящих панелей
не бывает. Поэтому виды опций — выбранная, подсвеченная, отключённая — показаны набором внутри
одной панели.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у триггера нет         |
| фокус         | `:focus`                             | рамка фокуса и `--rt-input-focus-shadow`           |
| раскрыто      | панель открыта                       | рамка фокуса, шеврон повёрнут на 180°              |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | триггер скрыт, значение показано плоским текстом   |

Фокус берётся `:focus`, а не `:focus-visible`: кольцо триггеру нужно и после щелчка мышью —
раскрытая панель обязана показывать, куда вернётся клавиатура.

Опция внутри панели живёт своими состояниями: `--selected` — выбранная (заливка
`--rt-color-action-primary-subtle` и полужирное начертание), `--active` — подсвеченная
клавиатурой, `--disabled` — невыбираемая. Все три показаны в истории **Panel**.

Отключение через форму (`FormControl.disable()`) **закрывает уже раскрытую панель**: иначе
список висел бы над контролом, которым уже нельзя пользоваться.

## Доступность

- Триггер — `<button>` с `aria-haspopup="listbox"`, `aria-expanded` и `aria-controls`.
- **Опции поодиночке не фокусируются.** Подсвеченная называется скринридеру через
  `aria-activedescendant` на триггере — фокус всё это время остаётся на нём.
- Клавиатура: `ArrowDown`, `ArrowUp`, `Enter`, `Space` раскрывают закрытый список и сразу
  подсвечивают первую доступную опцию; стрелки перешагивают отключённые и заворачиваются по
  кругу; `Escape` закрывает без выбора.
- Ошибка объявляется атрибутом `aria-invalid` на триггере, текст ошибки рисует `rt-field`.
- Крестик очистки исключён из таб-порядка (`tabindex="-1"`).

## Оформление

Триггер берёт ту же группу свойств, что и остальные поля кита — `--rt-input-height`,
`--rt-input-color-border`, `--rt-input-color-border-focus`, `--rt-input-color-border-error`,
`--rt-input-radius`: поля в форме стоят одной высоты не по совпадению. Панель отдельно берёт
`--rt-input-panel-max-height`, `--rt-color-bg-surface`, `--rt-color-border-subtle` и
`--rt-shadow-md`.

**Панели нет в светло-тёмной паре.** Она рисуется в контейнере оверлеев CDK — за пределами
блока, которому пара назначает свойства темы. Тёмную панель смотрят переключателем темы в
тулбаре, а не парой.

## Входы

| вход                | тип                                          | умолчание               |
| ------------------- | -------------------------------------------- | ----------------------- |
| `options`           | `ReadonlyArray<{ label, value, disabled? }>` | `[]`                    |
| `placeholder`       | `string`                                     | `''`                    |
| `iconLeft`          | `IRtIcon.Name \| null`                       | `null`                  |
| `filter`            | `boolean`                                    | `false`                 |
| `filterPlaceholder` | `string`                                     | `''` → `rtKit.uiSearch` |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

| выход             | тип              | когда                                          |
| ----------------- | ---------------- | ---------------------------------------------- |
| `selectionChange` | `TValue \| null` | выбор опции и очистка крестиком (тогда `null`) |

`selectionChange` — не дубль формы: значение и так уходит через `ControlValueAccessor`.
Выход нужен там, где на выбор надо среагировать (перезагрузить зависимый список), не
подписываясь на `valueChanges` всей формы.

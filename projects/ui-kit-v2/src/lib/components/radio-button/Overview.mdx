<Title>RadioButton — `rt-radio-button`</Title>

Радиокнопка: выбор одного значения из нескольких. Выбор приходит формой — выбрана та, чьё значение и
есть модель, — или входом `checked` без формы, как строку отмечает таблица.

```html
<rt-radio-button label="Москва" [value]="moscow" [formControl]="city" />
<rt-radio-button label="Сочи" [value]="sochi" [formControl]="city" />

<rt-radio-button ariaLabel="Выбрать запись" [value]="row.id" [checked]="chosen() === row.id" (checkedChange)="chosen.set(row.id)" />
```

## Когда применять

- Выбор одного из немногих вариантов, видимых сразу: способ доставки, тариф, одна строка списка.
- Вид «карточка» — когда у варианта есть пояснение и ему нужна своя рамка.

## Когда не применять

- **Независимый выбор «да / нет»** — [`rt-checkbox`](./?path=/docs/atoms-forms-checkbox-overview--docs).
- **Много вариантов** — [`rt-select`](./?path=/docs/molecules-forms-select-overview--docs).
- **Переключение вида или режима** — [`rt-toggle-button-group`](./?path=/docs/molecules-forms-togglebuttongroup-overview--docs).

## Оси

| ось    | значения                          | умолчание  |
| ------ | --------------------------------- | ---------- |
| выбор  | не выбрана, выбрана               | не выбрана |
| тексты | нет, подпись, подпись и пояснение | нет        |
| вид    | обычный, карточка                 | обычный    |

Выбор перемножен с видом и с отключённостью: отключённая гасит кружок, точку и рамку карточки разом,
и по одной отключённой ячейке не видно, что стало со вторым выбором.

**Ось, которой не видно.** `ariaLabel` уходит в атрибут и даёт кружку без подписи доступное имя.

## Состояния

| состояние       | чем задаётся                    | что меняется                                  |
| --------------- | ------------------------------- | --------------------------------------------- |
| обычное         | —                               | ободок `--rt-color-border-strong`             |
| наведение       | —                               | **ничего:** своего `:hover` нет, как у флажка |
| фокус с клавиши | `:focus-visible`                | кольцо `--rt-shadow-focus-ring`               |
| выбрана         | модель формы или вход `checked` | ободок и точка `--rt-color-action-primary`    |
| карточка        | вход `card`                     | рамка; у выбранной — цвета выбора             |
| отключено       | вход `disabled` или слово формы | приглушение `--rt-opacity-disabled`           |

**Нажатие на выбранную выбор не снимает** — радиокнопку покидают только выбором другой.

## Доступность

- Корень — `role="radio"` с `aria-checked` и `aria-disabled`, `tabindex="0"`: недоступная тоже
  остаётся остановкой фокуса и объявляет себя недоступной.
- Пробел и Enter выбирают; пробел страницу не прокручивает.
- Кружку без подписи имя даёт `ariaLabel`.

## Оформление

Кружок, точка, подпись и пояснение — элементы блока `rt-radio-button`. Цвет выбора —
`--rt-color-action-primary`, поэтому материальный набор перекрашивает радиокнопку без правил своих.
Скругление, рамки, кольцо и длительность — собственные свойства блока `--rt-radio-button-*`.

## Входы

| вход          | тип               | умолчание |
| ------------- | ----------------- | --------- |
| `value`       | `unknown`         | —         |
| `checked`     | `boolean \| null` | `null`    |
| `disabled`    | `boolean`         | `false`   |
| `card`        | `boolean`         | `false`   |
| `label`       | `string`          | `''`      |
| `description` | `string`          | `''`      |
| `ariaLabel`   | `string \| null`  | `null`    |

Не заданный `checked` оставляет выбор форме.

## Выходы

| выход           | что несёт    | когда                       |
| --------------- | ------------ | --------------------------- |
| `clickAction`   | `MouseEvent` | каждое нажатие указателем   |
| `checkedChange` | `boolean`    | радиокнопка стала выбранной |

Значение формы уходит через `ControlValueAccessor`. Нажатие дальше радиокнопки не идёт: строка
таблицы под ней не открывается.

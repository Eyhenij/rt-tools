# `rt-radio-button`

```html
<rt-radio-button label="Москва" [value]="moscow" [formControl]="city" />
<rt-radio-button ariaLabel="Выбрать запись" [value]="row.id" [checked]="chosen() === row.id" (checkedChange)="chosen.set(row.id)" />
```

| вход          | тип               | умолчание |
| ------------- | ----------------- | --------- |
| `value`       | `unknown`         | —         |
| `checked`     | `boolean \| null` | `null`    |
| `disabled`    | `boolean`         | `false`   |
| `card`        | `boolean`         | `false`   |
| `label`       | `string`          | `''`      |
| `description` | `string`          | `''`      |
| `ariaLabel`   | `string \| null`  | `null`    |

Выходы: `clickAction` — каждое нажатие указателем, `checkedChange` — радиокнопка стала выбранной.

## Главное, что нужно знать

**Выбрана та, чьё значение — сама модель, а не равное ей.** Две записи с одинаковым содержимым —
два разных значения.

**Выбор приходит двумя путями.** Форма пишет модель через `ControlValueAccessor`; без формы
выбранность ставится входом `checked`, и он решает раньше модели. Не заданный `checked` — `null`.

**Нажатие на выбранную ничего не меняет**, но помечает контрол тронутым и сообщается `clickAction`.
Нажатие дальше радиокнопки не идёт. Выбор клавишей `clickAction` не сообщает.

## Как этим пользоваться

- Отключение приходит двумя путями — вход `[disabled]` и `FormControl.disable()`; недоступна, если
  так сказал любой.
- Несколько радиокнопок на одном поле реактивной формы: форма не переписывает соседей, выбранная
  раньше может сохранить точку. Для таблицы и списков — вход `checked`.
- Кружок без подписи получает имя через `ariaLabel`.

# `rt-image-cropper`

Обрезка изображения. Исходник вписан в поле целиком, поверх — рамка с восемью ручками; компонент
отдаёт файл, вырезанный рамкой.

```html
<rt-image-cropper round format="webp" [file]="photo" [ratio]="1" [quality]="85" (cropped)="save($event.file)" (loadFailed)="warn()" />
```

| вход          | тип                                 | умолчание                          |
| ------------- | ----------------------------------- | ---------------------------------- |
| `placeholder` | `string`                            | `''` → `uiImageCropperPlaceholder` |
| `file`        | `Blob \| null`                      | `null`                             |
| `ratio`       | `number \| null`                    | `null`                             |
| `round`       | `boolean`                           | `false`                            |
| `minSize`     | `number`                            | `16`                               |
| `format`      | `'png' \| 'jpeg' \| 'webp' \| null` | `null`                             |
| `quality`     | `number`                            | `92`                               |
| `disabled`    | `boolean`                           | `false`                            |

Выходы: `cropped` (`{ file, frame }`), `loadFailed`.

## Главное, что нужно знать

**Рамка живёт в пикселях исходника, а не поля.** Поле меняется с окном, исходник — нет; `frame` в
результате — прямоугольник в пикселях исходника.

**Результат приходит после прочтения исходника и после каждого законченного изменения.** Во время
перетаскивания — ни одного: один жест — один файл. Каждая стрелка — законченное изменение.

**Круглый вид — только маска на экране.** Результат остаётся квадратом, который режет рамка:
скругляет картинку приложение там, где её показывает.

**Без выбранного формата берётся формат исходника**, а если он не png, jpeg или webp — png.

**Поворот снимка по EXIF делает браузер.** Размеры, которые видит компонент, уже повёрнутые.

**В материальном наборе обрезка выглядит как в первом ките.** Поле без подложки и скругления,
вокруг рамки светлая вуаль, по рамке пунктир, ручки мелкие и тёмные. Свой набор держит тёмную
вуаль и крупные белые ручки.

## Края

- Рамка не выходит за исходник и не становится меньше `minSize`; исходник меньше `minSize` не
  выпускает рамку за край.
- Смена `ratio` или `round` ставит рамку заново — наибольшую по центру.
- Исходник, который не прочитался, показывает отказ и поднимает `loadFailed`; рамки нет.
- Недоступная обрезка показывает рамку и не меняет её ни указателем, ни клавишами.
- Высота поля — свойство `--rt-image-cropper-height`.

<Title>ImageCropper — `rt-image-cropper`</Title>

Обрезка изображения. Исходник вписан в поле целиком, поверх — рамка с восемью ручками. После
прочтения исходника и после каждого законченного изменения рамки компонент отдаёт файл, вырезанный
рамкой, в выбранном формате и качестве.

```html
<rt-image-cropper round format="webp" [file]="photo" [ratio]="1" [quality]="85" (cropped)="save($event.file)" (loadFailed)="warn()" />
```

## Когда применять

- Аватар, обложка, превью: картинку надо обрезать до нужной пропорции перед отправкой.
- Файл уже выбран — кнопкой или перетаскиванием — и его надо показать с рамкой.

## Когда не применять

- **Выбор файла** — [`rt-file-input`](./?path=/docs/molecules-forms-fileinput-overview--docs) и
  [`rt-file-drop`](./?path=/docs/organisms-filedrop-overview--docs): обрезка файл не выбирает.
- **Просмотр готовых фотографий** — [`rt-photo-viewer`](./?path=/docs/organisms-photoviewer-overview--docs).

## Оси

| ось       | значения                        | умолчание     |
| --------- | ------------------------------- | ------------- |
| пропорция | свободная, 1 : 1, 16 : 9, 3 : 4 | свободная     |
| вид       | прямоугольная, круглая          | прямоугольная |

**Оси, которых не видно.** `format`, `quality` и `minSize` на вид поля не влияют: первые два
меняют отданный файл, третий — насколько рамку можно сжать.

## Состояния

| состояние      | чем задаётся                | что меняется                                   |
| -------------- | --------------------------- | ---------------------------------------------- |
| без исходника  | `file` пуст                 | пустое поле                                    |
| загрузка       | исходник читается           | крутится загрузка кита                         |
| готова         | исходник прочитан           | картинка, затемнение вокруг рамки, ручки       |
| недоступна     | вход `disabled`             | ручки и картинка приглушены, рамка не меняется |
| не прочиталось | браузер не декодировал файл | текст отказа, рамки нет, `loadFailed`          |

**Загрузка в матрицу не попадает:** нарисованный исходник читается за кадр раньше, чем витрина
снимает. Её показывает тест компонента. **Наведение и фокус** — курсоры сторон и кольцо фокуса
кита; в кадре их не держит ни один вход.

## Доступность

- Рамка и каждая ручка берут фокус клавишей Tab и называют себя подписями кита:
  `uiImageCropperFrame`, `uiImageCropperHandleN` … `uiImageCropperHandleSw`.
- Стрелки двигают рамку или тянут ручку на пиксель поля, со Shift — на десять.
- Недоступная обрезка выводит рамку и ручки из порядка Tab и объявляет их `aria-disabled`.

## Оформление

Всё вне рамки затемнено; в круглом виде светлое место — круг, а ручки остаются на квадрате рамки.
Под палец ручки крупнее. Высота поля — свойство `--rt-image-cropper-height`.

## Входы

| вход       | тип                                 | умолчание |
| ---------- | ----------------------------------- | --------- |
| `file`     | `Blob \| null`                      | `null`    |
| `ratio`    | `number \| null`                    | `null`    |
| `round`    | `boolean`                           | `false`   |
| `minSize`  | `number`                            | `16`      |
| `format`   | `'png' \| 'jpeg' \| 'webp' \| null` | `null`    |
| `quality`  | `number`                            | `92`      |
| `disabled` | `boolean`                           | `false`   |

Без `format` берётся формат исходника, а если он не png, jpeg или webp — png. `quality` — в
процентах, для jpeg и webp.

## Выходы

| выход        | тип               | когда                                                     |
| ------------ | ----------------- | --------------------------------------------------------- |
| `cropped`    | `{ file, frame }` | после прочтения исходника и после каждого изменения рамки |
| `loadFailed` | `void`            | исходник не прочитался                                    |

`frame` — прямоугольник в пикселях исходника. Круглый вид отдаёт квадрат: скругляет приложение.

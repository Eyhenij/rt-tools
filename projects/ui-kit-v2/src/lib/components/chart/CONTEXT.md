# `rt-chart`

График кита на `echarts`: линии, столбики, круг, тепловая карта, точки, дерево прямоугольников и
солнечные лучи. Лежит в своём входе `@rt-tools/ui-kit-v2/chart`: `echarts` и `ngx-echarts` нужны
только тому, кто этот вход берёт.

```html
<rt-chart
    height="280px"
    [option]="{ xAxis: { type: 'category', data: ['Пн', 'Вт'] }, yAxis: {}, series: [{ type: 'bar', data: [3, 5] }] }" />
```

| вход     | тип                 | умолчание      |
| -------- | ------------------- | -------------- |
| `option` | `EChartsCoreOption` | **обязателен** |
| `height` | `string`            | `'320px'`      |

Выход: `rendered` — график дорисован. Метод `toPng()` отдаёт адрес данных PNG с подложкой темы
или `null`, пока график не нарисован.

## Главное, что нужно знать

**Цвета серий даёт кит.** Палитра — восемь свойств `--rt-color-chart-series-1…8`; график читает их
готовые значения со своего узла и передаёт `echarts` темой. Поэтому тёмное поддерево светлой
страницы рисует тёмный график, а смена темы пересоздаёт его в новых цветах. Общий `color` на
верхнем уровне опции палитру не перебивает: опция ложится слиянием поверх темы. Серия, которой нужен
другой цвет, — например, прогноз в цвете факта, — получает `color` на самой серии.

**Вид осей и легенды тоже даёт кит.** Подписи осей 11, легенды 12, приглушённым цветом; оси без
линии и засечек; легенда слева снизу круглыми значками 8; линия серии 2 без маркеров; столбик не
шире 12; швы секторов цвета подложки. Опция включает легенду сама: `legend: {}`.

**Новая опция сливается с нарисованной.** График создаётся один раз и дальше получает опцию
слиянием: серии обновляются без пересоздания. Чтобы убрать серию, её передают с пустыми данными.

**Виды — ровно семь.** Вход регистрирует только их и сетку, легенду, подсказку и непрерывную шкалу
цвета. Восьмой вид потребитель регистрирует сам через `RT_CHART_ECHARTS.use(…)`.

## Края

- Опция без единой точки ни в сериях, ни в наборах данных — заглушка с `chartEmpty` и
  `chartEmptyHint` вместо осей.
- В контейнере нулевой ширины график не создаётся, пока контейнер не получит ширину.
- Рендерер SVG: серии и оси — узлы страницы. PNG собирается из этого SVG на холсте с двойной
  плотностью.
- На сервере график не рисуется: и цвета, и ширина читаются только в браузере.

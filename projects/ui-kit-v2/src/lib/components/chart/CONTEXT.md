# `rt-chart`

График кита: линии, области, столбики, круг, тепловая карта, точки, дерево прямоугольников и
солнечные лучи. Рисует SVG своего шаблона по данным модели кита `IRtChart.TData`. Лежит в своём
входе `@rt-tools/ui-kit-v2/chart`: `d3-shape` и `d3-hierarchy` нужны только тому, кто этот вход
берёт.

```html
<rt-chart
    label="Выручка по дням"
    [data]="{ kind: 'cartesian', categories: ['Пн', 'Вт'], series: [{ name: 'Выручка', type: 'bar', values: [3, 5] }] }" />
```

| вход     | тип              | умолчание      |
| -------- | ---------------- | -------------- |
| `data`   | `IRtChart.TData` | **обязателен** |
| `height` | `string`         | `'188px'`      |
| `label`  | `string \| null` | `null`         |

Метод `toPng()` отдаёт адрес данных PNG с подложкой темы и легендой или `null`, пока поле пусто.

## Главное, что нужно знать

**d3 считает, шаблон рисует.** `rt-chart.layout.ts:rtChartScene` — чистая функция: из данных и
размера поля она строит сцену — пути, подписи и легенду. Шкалы — функции кита в
`rt-chart.scene.ts`, d3 даёт формы линий, областей и секторов и делит площадь дерева на
прямоугольники. Компонент только меряет поле и рисует сцену.

**Цвета — токены прямо в разметке.** Фигура несёт `var(--rt-color-chart-series-N)`, подписи —
токены текста. Поэтому тёмное поддерево светлой страницы рисует тёмный график, а смена темы не
трогает узлы. Цвет серии — номер слота от 1 до 8; без номера слот идёт по порядку.

**Вид осей и легенды взят из макета.** Ось значений — четыре промежутка с шагом 1, 2, 2.5 или 5 на
степень десяти, у двух панелей — по два. Подписи осей 11 приглушённым цветом, сетка цвета
`border-subtle`, линия 2 без маркеров, столбик в группе 12, одиночный 16, стопка 24. Легенда под
полем, значки — круг 8 или отрезок 12 на 2 по полю `mark` серии. У тепловой карты вместо легенды
шкала плотности: подписи нуля и круглого верха и пять плашек между ними.

**Дерево прямоугольников повторяет строение макета.** Группы стоят рядом, и каждая не уже своей
подписи. В группе первый лист занимает верхнюю полосу, остальные стоят рядом под ним. Площадь
листа — по его значению, поэтому доли дерева в витрине не совпадают с макетом до точки: в макете
они нарисованы не по значениям.

**Новые данные меняют фигуры на месте.** Сцена пересчитывается, а `@for` по ключу фигуры
сохраняет узлы: SVG не пересоздаётся.

## Края

- Данные без единого значения — заглушка с `chartEmpty` и `chartEmptyHint` вместо поля.
- В контейнере нулевой ширины поле пусто, пока контейнер не получит ширину.
- Ширина подписей меряется холстом страницы; без холста — на сервере и в jsdom — оценкой по
  числу букв.
- PNG собирается из SVG, где токены заменены готовыми цветами, и легенды, дорисованной на
  холсте с двойной плотностью.

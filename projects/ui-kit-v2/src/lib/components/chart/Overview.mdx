<Title>Chart — `rt-chart`</Title>

График кита: SVG своего шаблона по данным модели кита. Формы и раскладку дерева считает d3,
цвета — токены кита. Лежит в своём входе `@rt-tools/ui-kit-v2/chart`: `d3-shape` и `d3-hierarchy`
ставит только тот, кто этот вход берёт.

```html
<rt-chart label="Выручка по месяцам" [data]="{ kind: 'cartesian', categories: ['Пн', 'Вт'], series: [{ name: 'Выручка', type: 'bar', values: [3, 5] }] }" />
```

## Когда применять

- Динамика, сравнение, доли, распределение, плотность — всё, где нужна ось или площадь.
- Блок ответа ассистента с данными: он берёт `rt-chart` из этого же входа.

## Когда не применять

- **Доли нескольких однородных величин в сводке** — [`rt-bar-list`](./?path=/docs/molecules-data-barlist-overview--docs).
- **Одно число крупно** — [`rt-stat-tile`](./?path=/docs/molecules-data-stattile-overview--docs).
- **Точные значения в колонках** — [`rt-table`](./?path=/docs/organisms-table-table-overview--docs).

## Оси

Ось у графика одна — вид данных. Его значения показаны карточками истории **Kinds** в порядке
макета.

| ось    | значения                                                                                         |
| ------ | ------------------------------------------------------------------------------------------------ |
| вид    | линия, столбики, круговая, тепловая карта, точки, дерево прямоугольников, солнечные лучи         |
| форма  | столбики стопкой, область с полосой прогноза, две панели, гистограмма, области стопкой с линиями |
| данные | есть точки, нет ни одной точки                                                                   |

**Две оси Y в одной панели не рисуются.** Две величины разного масштаба ставятся двумя панелями
с общей осью X — карточка «Две панели».

Высота показана одним значением: она задаётся длиной CSS и меняет только поле графика без
легенды, ширину график берёт у контейнера.

## Края

| край                     | что происходит                                                       |
| ------------------------ | -------------------------------------------------------------------- |
| ни одного значения       | заглушка кита с `chartEmpty` и `chartEmptyHint` вместо осей |
| контейнер нулевой ширины | поле пусто, пока контейнер не получит ширину                |
| новые данные             | фигуры меняются на месте, узел SVG остаётся тот же          |
| длинная легенда          | переносится на следующую строку                             |
| сервер                   | поле пусто: ширина читается только в браузере               |

## Состояния

Подсказка под указателем — единственное состояние взаимодействия. В кадре витрины её нет: снимок
не держит указатель, её проверяет спек компонента.

| состояние | чем задаётся                  | что меняется                  |
| --------- | ----------------------------- | ----------------------------- |
| пусто     | данные без единого значения   | заглушка вместо осей          |
| подсказка | указатель над полем           | значения места под указателем |
| тёмная    | признак темы на узле или выше | палитра и подписи тёмной темы |

## Доступность

- Легенда стоит под полем всегда: цвет не единственный носитель имени серии. У тепловой карты на
  её месте шкала плотности с подписями краёв.
- Поле — изображение с доступным именем из входа `label`.
- Подсказка называет серию и значение текстом.

## Оформление

Цвета серий — восемь свойств `--rt-color-chart-series-1…8`, по паре ступеней на тон в каждой
теме. Фигуры ссылаются на них прямо в разметке, поэтому тёмное поддерево светлой страницы рисует
тёмный график, а смена темы не перерисовывает его. Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-bar-list`](./?path=/docs/molecules-data-barlist-overview--docs) — доли без осей.
- [`rt-empty-state`](./?path=/docs/molecules-emptystate-overview--docs) — заглушка пустого графика.

## Входы

| вход     | тип              | умолчание | что делает                                      |
| -------- | ---------------- | --------- | ----------------------------------------------- |
| `data`   | `IRtChart.TData` | —         | данные графика в модели кита, одна из пяти форм |
| `height` | `string`         | `'188px'` | высота поля без легенды, любая длина CSS        |
| `label`  | `string \| null` | `null`    | доступное имя графика                           |

<Title>Chart — `rt-chart`</Title>

График на `echarts` в палитре и теме кита. Лежит в своём входе `@rt-tools/ui-kit-v2/chart`:
`echarts` и `ngx-echarts` ставит только тот, кто этот вход берёт.

```html
<rt-chart height="280px" [option]="option()" />
```

## Когда применять

- Динамика, сравнение, доли, распределение, плотность — всё, где нужна ось или площадь.
- Блок ответа ассистента с данными: он берёт `rt-chart` из этого же входа.

## Когда не применять

- **Доли нескольких однородных величин в сводке** — [`rt-bar-list`](./?path=/docs/molecules-data-barlist-overview--docs).
- **Одно число крупно** — [`rt-stat-tile`](./?path=/docs/molecules-data-stattile-overview--docs).
- **Точные значения в колонках** — [`rt-table`](./?path=/docs/organisms-table-table-overview--docs).

## Оси

Ось у графика одна — вид серии. Его значения показаны карточками истории **Kinds** в порядке
макета.

| ось    | значения                                                                                         |
| ------ | ------------------------------------------------------------------------------------------------ |
| вид    | линия, столбики, круговая, тепловая карта, точки, дерево прямоугольников, солнечные лучи         |
| форма  | столбики стопкой, область с полосой прогноза, две панели, гистограмма, области стопкой с линиями |
| данные | есть точки, нет ни одной точки                                                                   |

**Две оси Y в одной панели не рисуются.** Две величины разного масштаба ставятся двумя панелями
с общей осью X — карточка «Две панели».

Высота показана одним значением: она задаётся длиной CSS и меняет только поле графика, ширину
график берёт у контейнера.

## Края

| край                     | что происходит                                                       |
| ------------------------ | -------------------------------------------------------------------- |
| ни одной точки           | заглушка кита с `chartEmpty` и `chartEmptyHint` вместо осей          |
| контейнер нулевой ширины | график не создаётся, пока контейнер не получит ширину                |
| новая опция              | сливается с нарисованной; серию убирают пустыми данными              |
| вид вне семи             | не нарисуется: потребитель регистрирует его через `RT_CHART_ECHARTS` |
| сервер                   | график не рисуется, цвета и ширина читаются только в браузере        |

## Состояния

Своих состояний взаимодействия у компонента нет: подсказка над точкой и подсветка серии — поведение
`echarts`, а не кита, и в кадре витрины их нет.

| состояние | чем задаётся                  | что меняется                  |
| --------- | ----------------------------- | ----------------------------- |
| пусто     | опция без единой точки        | заглушка вместо осей          |
| тёмная    | признак темы на узле или выше | палитра и подписи тёмной темы |

## Доступность

- Серии с двух и больше всегда стоят в легенде: цвет не единственный носитель имени серии.
- Подсказка над точкой называет серию и значение текстом.

## Оформление

Цвета серий — восемь свойств `--rt-color-chart-series-1…8`, по паре ступеней на тон в каждой
теме. График читает их готовые значения со своего узла, поэтому тёмное поддерево светлой страницы
рисует тёмный график. Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-bar-list`](./?path=/docs/molecules-data-barlist-overview--docs) — доли без осей.
- [`rt-empty-state`](./?path=/docs/molecules-emptystate-overview--docs) — заглушка пустого графика.

## Входы

| вход     | тип                 | умолчание | что делает                                          |
| -------- | ------------------- | --------- | --------------------------------------------------- |
| `option` | `EChartsCoreOption` | —         | опция `echarts`; палитру и подписи добавляет график |
| `height` | `string`            | `'320px'` | высота поля графика, любая длина CSS                |

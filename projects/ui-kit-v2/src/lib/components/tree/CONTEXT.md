# `rt-tree`

```html
<rt-tree [nodes]="regions" [searchTerm]="term()" [showSelectAll]="true" [(value)]="chosen" (picked)="open($event)">
    <ng-template rtTreeNodeEnd let-node>
        <rt-tag size="sm" [value]="node.description ?? ''" />
    </ng-template>
</rt-tree>
```

| вход            | тип                                   | умолчание      |
| --------------- | ------------------------------------- | -------------- |
| `nodes`         | `ReadonlyArray<IRtTree.Node<TValue>>` | **обязателен** |
| `value` (model) | `ReadonlyArray<TValue>`               | `[]`           |
| `mode`          | `'multiple' \| 'single' \| 'none'`    | `'multiple'`   |
| `cascade`       | `boolean`                             | `true`         |
| `searchTerm`    | `string`                              | `''`           |
| `showSelectAll` | `boolean`                             | `false`        |
| `ariaLabel`     | `string \| null`                      | `null`         |

| выход         | тип                     |
| ------------- | ----------------------- |
| `valueChange` | `ReadonlyArray<TValue>` |
| `picked`      | `IRtTree.Node<TValue>`  |

Публичные методы: `handleKeydown(event)`, `expandAll()`, `collapseAll()`, `clearHighlight()`.

## Главное, что нужно знать

**Дерево считает тот же модуль, что дерево вариантов у `rt-select` и `rt-multiselect`.** Строки,
листья, отметки ветвей, отбор по слову и боковые стрелки — функции `rt-select-tree.ts`. Свою копию
логики дерево не держит: две копии разошлись бы на первой правке.

**Узлы не меняются никогда.** Выбор живёт в `value`, каждый клик даёт новый массив. В каскаде
выбор держит только листья, а отметка ветки выводится из них.

## Края

- Без каскада клик меняет только сам узел, и в выборе может лежать значение ветки.
- В одиночном режиме повторный клик по выбранному узлу его не снимает.
- В режиме без отметок клик по листу отдаёт `picked`, клик по ветке её раскрывает.
- Выключенный узел не меняется ни кликом, ни «выбрать всё».
- `handleKeydown` отвечает, взята ли клавиша: незнакомую дерево не трогает, и приложение может
  отдавать сюда каждую клавишу своего поля поиска.
- Ветки над выбранным раскрыты, когда дерево появилось. Дальше раскрытие меняют только человек
  и методы: первый же выбор фиксирует его, и отметка ветки её не сворачивает.
- Отметку рисуют `rt-checkbox` и `rt-radio-button` кита. Они стоят с `inert`: фокус и нажатие
  берёт строка, а контрол только показывает отметку.

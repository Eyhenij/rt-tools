<Title>Tree — `rt-tree`</Title>

Дерево узлов прямо на странице: флажки с каскадом, радио или просто навигация по веткам. Модель
узла та же, что у дерева вариантов `rt-select` и `rt-multiselect`, — `IRtSelect.Option` с
`children` и необязательным `description`; одни и те же данные кладутся и в выпадающий список,
и в дерево.

```html
<rt-tree ariaLabel="Регионы" [nodes]="regions" [(value)]="picked" />
<rt-tree ariaLabel="Регион" mode="single" [nodes]="regions" [(value)]="picked" />
<rt-tree ariaLabel="Регионы" [nodes]="regions" [showSelectAll]="true" [searchTerm]="term" [(value)]="picked">
    <ng-template rtTreeNodeEnd let-node>
        <rt-tag size="sm" [value]="node.value" />
    </ng-template>
</rt-tree>
```

## Когда применять

- Выбор из иерархии, которую человек должен видеть целиком: регионы, подразделения, права.
- Навигация по веткам без выбора — режим `none`: ветка по нажатию раскрывается, лист сообщает о
  нажатии выходом `picked`.

## Когда не применять

- **Выбор в поле формы, где места мало** —
  [`rt-multiselect`](./?path=/docs/molecules-forms-multiselect-overview--docs) или
  [`rt-select`](./?path=/docs/molecules-forms-select-overview--docs): то же дерево вариантов, но
  в выпадающей панели.
- **Плоский список без вложенности** — дерево добавит пустое место под стрелку раскрытия и ничего
  не даст взамен.

## Оси

| ось           | значения                         | умолчание  |
| ------------- | -------------------------------- | ---------- |
| режим         | `multiple`, `single`, `none`     | `multiple` |
| каскад        | включён, выключен                | включён    |
| «выбрать всё» | нет; есть — ничего, часть, всё   | нет        |
| поиск         | пусто, слово                     | пусто      |
| пустое дерево | поиск ничего не нашёл, узлов нет | —          |
| конец строки  | нет, разметка приложения         | нет        |

Каскад виден только в режиме `multiple`: в `single` отмечается один узел, в `none` отметок нет.
Поэтому история **Cascade** идёт в режиме флажков, а режим с каскадом не перемножается.

Поиск раскрывает путь к каждому совпадению и подсвечивает совпавший кусок подписи и описания;
ветка, в поддереве которой совпадений нет, скрывается.

Каждая история стоит парой половин под двумя наборами оформления: набор перекрашивает фон
выбранной и подсвеченной строки.

**Оси, которых не видно.** `ariaLabel` уходит в атрибут; выход `picked` ничего не рисует.

## Состояния

| состояние           | чем задаётся               | что меняется                                       |
| ------------------- | -------------------------- | -------------------------------------------------- |
| обычное             | —                          | —                                                  |
| наведение           | указатель над строкой      | фон строки `--rt-color-bg-hover`                   |
| фокус с клавиши     | `:focus-visible` на дереве | кольцо `--rt-tree-focus-shadow`                    |
| подсвеченная строка | стрелки клавиатуры         | фон строки, как при наведении                      |
| выбранная строка    | отметка узла               | фон строки `--rt-color-action-primary-subtle`      |
| ветка «частично»    | выбрана часть листьев      | флажок в промежуточном положении                   |
| выключенный узел    | `disabled` у узла          | прозрачность `--rt-input-disabled-opacity`, курсор |

## Клавиатура

Фокус стоит на самом дереве, строки его не берут — строка подсвечивается, как у списка вариантов.

| клавиша | что делает                                                               |
| ------- | ------------------------------------------------------------------------ |
| ↓ / ↑   | следующая / предыдущая видимая строка                                    |
| → / ←   | раскрыть / свернуть ветку и пройти по уровням — как в дереве `rt-select` |
| пробел  | отметить строку; в режиме `none` — раскрыть или свернуть ветку           |
| Enter   | то же, что пробел, и сообщить выходом `picked`                           |

Метод `handleKeydown` открыт: поле поиска над деревом передаёт ему стрелки и Enter, не забирая
фокус у себя. Он возвращает, взята ли клавиша, — по этому поле решает, отменять ли её действие.

## Доступность

- `role="tree"` на хосте, `role="treeitem"` на строках с `aria-level`, `aria-expanded` у веток и
  `aria-selected` в режимах с отметкой.
- `aria-multiselectable` стоит только в режиме `multiple`.
- Доступное имя даёт вход `ariaLabel`; без него у дерева нет имени.
- Флажки и радио строк не берут фокус: состояние читается из атрибутов строки.

## Оформление

Свойства объявлены на корне блока `rt-tree`; правило приложения на теге перебивает их.

| свойство                 | что задаёт                      | умолчание                |
| ------------------------ | ------------------------------- | ------------------------ |
| `--rt-tree-indent`       | шаг отступа на уровень          | `--rt-space-lg`          |
| `--rt-tree-match-bg`     | фон совпадения поиска           | `--rt-yellow-400`        |
| `--rt-tree-match-color`  | цвет текста совпадения          | `--rt-neutral-950`       |
| `--rt-tree-match-radius` | скругление подсветки совпадения | `--rt-radius-xs`         |
| `--rt-tree-focus-shadow` | кольцо фокуса дерева            | `--rt-shadow-focus-ring` |
| `--rt-tree-border-width` | черта под строкой «выбрать всё» | `--rt-border-width-thin` |

Подпись и описание строки, не поместившиеся по ширине, обрезаются многоточием, и полный текст
показывает подсказка кита в режиме `rtTooltipWhenTruncated`.

При `pointer: coarse` строка вырастает до `--rt-control-height-lg`: пальцу нужна цель крупнее.

## Входы

| вход            | тип                                | умолчание    |
| --------------- | ---------------------------------- | ------------ |
| `nodes`         | `ReadonlyArray<IRtTree.Node<T>>`   | обязателен   |
| `value`         | `ReadonlyArray<T>`                 | `[]`         |
| `mode`          | `'multiple' \| 'single' \| 'none'` | `'multiple'` |
| `cascade`       | `boolean`                          | `true`       |
| `searchTerm`    | `string`                           | `''`         |
| `showSelectAll` | `boolean`                          | `false`      |
| `ariaLabel`     | `string \| null`                   | `null`       |

## Выходы

| выход         | что несёт          | когда                                                                     |
| ------------- | ------------------ | ------------------------------------------------------------------------- |
| `valueChange` | `ReadonlyArray<T>` | изменилась отметка — пара к `value`                                       |
| `picked`      | `IRtTree.Node<T>`  | нажатие на строку или Enter; не у выключенного узла и не у ветки в `none` |

## Рядом

- [`rt-multiselect`](./?path=/docs/molecules-forms-multiselect-overview--docs) — то же дерево вариантов в выпадающей панели.
- [`rt-select`](./?path=/docs/molecules-forms-select-overview--docs) — выбор одного узла из дерева в панели.

<Title>ColorPalette — `rt-color-palette`</Title>

Поле выбора цвета: образцы из набора и свой цвет на панели кита. Значение — `#rrggbb` строчными или
`null`.

```html
<rt-field label="Цвет роли">
    <rt-color-palette formControlName="color" [colors]="themeColors" />
</rt-field>
```

## Когда применять

- Цвет записи из короткого набора: роль, сезон, метка, категория.
- Набор темы приложения с возможностью взять свой цвет, когда набора не хватило.

## Когда не применять

- **Свободный цвет без набора** — поле `rt-input` с записью hex: образцы там лишние.
- **Выбор из названий, а не цветов** — `rt-select` или `rt-radio-button`.

## Оси

| ось           | значения                              | умолчание  |
| ------------- | ------------------------------------- | ---------- |
| значение      | без цвета, цвет из набора, свой цвет  | без цвета  |
| набор         | восемнадцать цветов кита, цвета входа | набор кита |
| только чтение | нет, да — с цветом и без              | нет        |
| свой цвет     | разрешён, запрещён                    | разрешён   |

## Состояния

- Образец: обычный, наведение, фокус с клавиши; выбранный обведён кольцом.
- Отключённая палитра: образцы и кнопка своего цвета приглушены, нажатия и клавиши не действуют.
- Панель своего цвета: площадь, полоса оттенка, запись hex; со входом `channels` — ещё поля R, G, B,
  каждое берёт целое от 0 до 255. «Применить» недоступно до изменения.

## Доступность

- Образцы — группа переключателей `radiogroup` с именем «Colour» из подписей кита или `ariaLabel`.
- Каждый образец назван своим hex; в порядке Tab стоит один образец, стрелки, Home и End двигают выбор.
- Площадь и полоса — ползунки со стрелками и значением для скринридера.

## Оформление

Вид кита и материальный вид стоят рядом в каждой матрице, светлая и тёмная темы — в истории
**Themes**. Свойства объявлены на самом `rt-color-palette`, и приложение переназначает их своим
правилом на этот блок. Панель своего цвета живёт в оверлее и объявляет свои свойства на себе.

Материальный набор повторяет образцы приложения: круги 30px без рамки через 10px, выбранный — полое
кольцо 3px своего цвета со свечением 5px, круг под указателем растёт. Кнопка своего цвета стоит в
16px под сеткой, серая (`--rt-sys-on-surface-variant`) 16/400; свой образец — последний в сетке.
Пустое значение только для чтения — белый круг. Панель — 256×320 со скруглением 6px и тенью
`0 8px 16px` серого цвета.

## Входы

| вход            | тип                 | умолчание |
| --------------- | ------------------- | --------- |
| `colors`        | `readonly string[]` | `[]`      |
| `readonly`      | `boolean`           | `false`   |
| `customAllowed` | `boolean`           | `true`    |
| `channels`      | `boolean`           | `false`   |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита. Палитра читает `disabled`, `controlId` и
`ariaLabel`; размер, кнопку очистки и рамку она не рисует, и эти входы ничего не меняют.

| вход            | тип                    | умолчание |
| --------------- | ---------------------- | --------- |
| `size`          | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`      | `boolean`              | `false`   |
| `controlId`     | `string \| null`       | `null`    |
| `ariaLabel`     | `string \| null`       | `null`    |
| `clearable`     | `boolean`              | `true`    |
| `clearTabbable` | `boolean`              | `false`   |
| `bordered`      | `boolean`              | `true`    |

## Выходы

Нет: значение уходит в форму.

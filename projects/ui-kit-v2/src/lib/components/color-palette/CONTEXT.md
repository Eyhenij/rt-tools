# `rt-color-palette`

```html
<rt-field label="Цвет роли">
    <rt-color-palette formControlName="color" [colors]="themeColors" />
</rt-field>
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md): из общих палитра читает
`disabled`, `controlId` и `ariaLabel`, а размер, кнопку очистки и рамку не рисует.

| вход            | тип                 | умолчание                       |
| --------------- | ------------------- | ------------------------------- |
| `colors`        | `readonly string[]` | `[]` → восемнадцать цветов кита |
| `readonly`      | `boolean`           | `false`                         |
| `customAllowed` | `boolean`           | `true`                          |

Выходов нет: значение уходит в форму — `#rrggbb` строчными или `null`.

Договорённость — `docs/specs/ui-kit-v2/color-palette/`.

## Главное, что нужно знать

**Значение одно по форме.** Форма может записать `#ABC`, `00FF00` или `red`; поле держит `#aabbcc`,
`#00ff00` и «цвет не выбран». Чужой цвет, которого нет в наборе, рисуется ещё одним образцом в конце.

**Образцы — группа переключателей.** В порядке Tab стоит один образец — выбранный, а без выбора
первый. Стрелки выбирают соседний по кругу, Home и End — крайние, и фокус идёт за выбором.

**Свой цвет меняет только «Применить».** Панель `rt-color-picker` открывается кнопкой своего цвета
на плавающей панели кита и начинает с текущего цвета. «Отмена», Escape и нажатие мимо закрывают её
без изменений. Площадь, полосу и градиенты строит чистая логика `rt-color-palette.logic.ts`.

## Края

- Только для чтения — один образец текущего цвета; пустое значение — образец с одной рамкой.
- Отключённая палитра не берёт ни нажатия, ни клавиши, образцы приглушены.
- Корень шаблона — `ng-container`: класс блока висит только на хосте.
- Размеры, зазоры, кольцо и рамки — свойства `--rt-color-palette-*` на корне блока. Материальный
  набор переназначает их в том же файле стилей: круги без рамки, полое кольцо, рост под указателем.
  Свой образец в обоих наборах стоит последним в сетке, а кнопка своего цвета — строкой под ней.
- Панель выбора живёт в оверлее и объявляет свои свойства на себе: свойства палитры до неё не
  доходят. Материальный набор доходит классом набора на панели оверлея.

<Title>DialogHeader — `rt-dialog-header`</Title>

Шапка модального окна: заголовок и крестик закрытия. Ставится первым узлом внутри
[`rt-dialog`](./?path=/docs/components-dialog-overview--docs).

```html
<rt-dialog ariaLabel="Удаление">
    <rt-dialog-header title="Удалить запись?" />
    …
</rt-dialog>
```

## Когда применять

- Окну нужен заголовок — то есть почти всегда: он же становится его доступным именем.
- Окно закрывают крестиком, а не только кнопками подвала.

## Когда не применять

- **Окно нельзя закрыть по своей воле** — тогда `closable=false`: крестик, который ничего не
  делает, хуже его отсутствия.
- **Панель сбоку** — у неё своя шапка,
  [`rt-aside-header`](./?path=/docs/components-asideheader-overview--docs), и в ней вместо
  крестика стрелка возврата.

## Оси

| ось             | значения          | умолчание |
| --------------- | ----------------- | --------- |
| крестик         | есть, нет         | есть      |
| длина заголовка | короткий, длинный | —         |

**Оси, которых не видно.** Своих у шапки больше нет: всё остальное решает вмещающее окно.

**Шапка показана без окна.** Она самостоятельный компонент, и её крестик ищет ссылку на окно
**необязательным** инжектом: вне диалога нажатие просто ничего не делает, а не падает. Как шапка
выглядит внутри окна, показывает матрица `Dialog → Parts`.

## Состояния

Своих состояний нет. Состояния крестика — это состояния
[`rt-icon-button`](./?path=/docs/components-iconbutton-overview--docs): наведение, нажатие,
фокус с клавиши.

## Доступность

- Заголовок — `<h2>`: он становится доступным именем окна.
- Крестик несёт переведённое имя из словаря кита.

## Оформление

Заголовок и крестик стоят в строку с разделяющей рамкой снизу; цвета и отступы — свойства кита.

## Входы

| вход       | тип       | умолчание      |
| ---------- | --------- | -------------- |
| `title`    | `string`  | **обязателен** |
| `closable` | `boolean` | `true`         |

## Выходы

Своих выходов нет: крестик закрывает окно сам, через ссылку на него.

## Рядом

- [`rt-dialog`](./?path=/docs/components-dialog-overview--docs) — окно, в которое эта шапка ставится.
- [`rt-icon-button`](./?path=/docs/components-iconbutton-overview--docs) — чем нарисован крестик.

<Title>Dialog — `rt-dialog`</Title>

Модальное окно по центру экрана. Открывается **службой**, а не разметкой: `RtDialogService`
поднимает компонент содержимого в оверлей, а `rt-dialog` — коробка внутри него: шапка, тело,
подвал.

```typescript
const ref: RtDialogRef<boolean> = this.#dialog.open(ConfirmComponent, { data: { id } });
ref.afterClosed().subscribe((ok?: boolean): void => …);
```

```html
<!-- внутри поднятого компонента -->
<rt-dialog width="360px" ariaLabel="Удаление">
    <rt-dialog-header title="Удалить запись?" />
    <p>Действие необратимо.</p>
    <rt-dialog-footer>…</rt-dialog-footer>
</rt-dialog>
```

## Когда применять

- Решение или ввод, ради которого страницу нужно прервать: подтверждение удаления, короткая
  форма, выбор из вариантов.
- Нужна модальность: пока окно открыто, страница за ним не работает.

## Когда не применять

- **Подтверждение одним нажатием** — [`[rtConfirm]`](./?path=/docs/organisms-dialog-confirm-overview--docs):
  панель под кнопкой не прерывает работу.
- **Просмотр без модальности** — [`rt-aside`](./?path=/docs/organisms-aside-aside-overview--docs):
  карточку смотрят, не теряя список.
- **Узкий экран** — [`rt-bottom-sheet`](./?path=/docs/organisms-aside-bottomsheet-overview--docs).

## Оси

| ось                  | значения                               | умолчание |
| -------------------- | -------------------------------------- | --------- |
| размер               | `sm`, `md`, `lg`                       | `md`      |
| своя ширина          | не задана, `280px`, `440px`            | не задана |
| наполнение           | шапка и подвал, без подвала, без шапки | —         |
| тело                 | короткое, длинное под потолком высоты  | —         |
| выравнивание подвала | `start`, `center`, `end`, `between`    | `end`     |

**Оси, которых не видно.** `ariaLabel` уходит в атрибут: он даёт окну доступное имя, когда
заголовка в шапке нет.

**Окно показано прямо в разметке, а не открытым службой.** В оверлей его уносит
`RtDialogService`, а сам компонент — обычная коробка и рисуется где угодно: так размеры встают
рядом, а светло-тёмная пара ловит окно целиком.

**Тело окна — часть `rt-dialog-content`.** Она даёт телу отступ и прокрутку: длинное содержимое
прокручивается между шапкой и подвалом. Часть необязательна, окно со своей обёрткой тела выглядит
как прежде. Короткое и длинное тело показывает история **Content**.

**Чего этим не показать.** Подложку, блокировку прокрутки страницы и ловушку фокуса ставит
служба — в витрине их нет. Это разница между тем, что показано, и тем, что увидит потребитель;
проверять их надо в приложении.

## Состояния

Своих состояний окно не знает: оно либо открыто службой, либо его нет. Что решает служба:

| настройка                                | умолчание                                  | что делает                                                                  |
| ---------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------- |
| `data`                                   | `null`                                     | доезжает до содержимого токеном `RT_DIALOG_DATA`                            |
| `closeOnBackdropClick` / `closeOnEscape` | `true`                                     | закрытие щелчком по подложке и `Escape`                                     |
| `backdropClass` / `panelClass`           | `rt-dialog-backdrop` / `rt-dialog-overlay` | классы подложки и панели                                                    |
| `trapFocus`                              | `false`                                    | Tab ходит только по окну, пока оно открыто                                  |
| `restoreFocus`                           | `false`                                    | после закрытия фокус возвращается, где стоял                                |
| `autoFocus`                              | `false`                                    | `'dialog'` — фокус на рамку, `'first-tabbable'` — на первый элемент под Tab |

**Прокрутка страницы блокируется на время диалога**, а окно объявлено `role="dialog"` с
`aria-modal="true"`.

`RtDialogRef.disableClose` держит окно и под щелчком по подложке, и под `Escape` — его ставит
само содержимое, когда закрывать нельзя (несохранённая форма).

## Доступность

- `role="dialog"` и `aria-modal="true"` на самой коробке.
- Доступное имя — заголовок шапки или `ariaLabel`, если шапки нет.
- `Escape` закрывает окно, пока содержимое не запретило это через `disableClose`.
- Фокус по умолчанию служба не трогает. `trapFocus`, `restoreFocus` и `autoFocus` включают ловушку
  CDK, возврат фокуса и первый фокус; ловушка уходит вместе с окном. Рамка несёт `tabindex="-1"`,
  чтобы `autoFocus: 'dialog'` мог её взять, и кольца фокуса вокруг всего окна не рисует.

## Оформление

Ширина берётся из свойства `--rt-dialog-width`: размер выставляет его сам, вход `width`
перекрывает. Скругление и тень — свойства кита; шапка и подвал разделены рамками.

Вид окна задают ручки приложения на корне страницы: `--rt-dialog-bg`, `--rt-dialog-border`,
`--rt-dialog-header-padding`, `--rt-dialog-header-border`, `--rt-dialog-title-font-size`,
`--rt-dialog-title-weight`, `--rt-dialog-title-transform`, `--rt-dialog-content-padding`,
`--rt-dialog-content-max-height`, `--rt-dialog-footer-padding` и `--rt-dialog-footer-border`. Окно
живёт в оверлее, поэтому они читаются с запасным значением на месте. Всё вместе показывает история
**Properties**; перечень ручек — на странице Theming.

## Входы

| вход        | тип                    | умолчание                             |
| ----------- | ---------------------- | ------------------------------------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`                                |
| `width`     | `string \| null`       | `null` (свойство `--rt-dialog-width`) |
| `ariaLabel` | `string \| null`       | `null`                                |
| `radius`    | `TRtRadius \| null`    | `null` → `xl`                         |

## Выходы

Своих выходов нет: результат отдаёт `RtDialogRef.close(result)`, а получает его подписчик
`afterClosed()`.

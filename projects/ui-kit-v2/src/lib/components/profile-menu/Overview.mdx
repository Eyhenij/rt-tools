<Title>ProfileMenu — `rt-profile-menu`</Title>

Содержимое попапа профиля в шапке: кто вошёл и в какой организации, действия с учётной записью,
язык и тема. Меню само рисует свою панель — фон, рамку, скругление и тень, — поэтому в попап шапки
его кладут как есть, без своих стилей.

```html
<rt-page-header [items]="items" [user]="user" [userMenu]="profileMenu" />

<ng-template #profileMenu>
    <rt-profile-menu
        organizationChange="allowed"
        [userName]="user.name"
        [organizationName]="organization"
        [signOutDisabled]="signingOut()"
        (changeOrganization)="changeOrganization()"
        (signOut)="signOut()" />
</ng-template>
```

## Когда применять

- В попапе профиля шапки [`rt-page-header`](./?path=/docs/molecules-navigation-pageheader-overview--docs).

## Когда не применять

- **Список действий без человека и организации** — [`rt-menu`](./?path=/docs/molecules-navigation-menu-overview--docs).
- **Только переключатель темы** — [`rt-theme-toggle`](./?path=/docs/molecules-themetoggle-overview--docs).

## Части

| часть              | когда видна                                   | вход                 |
| ------------------ | --------------------------------------------- | -------------------- |
| круг и имя         | всегда; в круге первая буква имени            | `userName`           |
| организация        | при непустом названии                         | `organizationName`   |
| смена организации  | `allowed` — доступна, `denied` — с подсказкой | `organizationChange` |
| смена пароля       | когда включена                                | `passwordChange`     |
| выход              | всегда; недоступен, пока приложение его ведёт | `signOutDisabled`    |
| выбор языка        | при непустом списке языков                    | `locales`, `locale`  |
| переключатель темы | всегда; тему держит `ThemeService` кита       | —                    |

Куда ведут действия, решает приложение: они уходят выходами `changeOrganization`,
`changePassword`, `localeChange` и `signOut`. Подписи — из словаря кита, ключи `profileMenu*`.

История **Presets** показывает три сочетания частей в обоих наборах, **Themes** — полное меню в
обеих темах.

## Входы

| вход                 | тип                                    | умолчание  |
| -------------------- | -------------------------------------- | ---------- |
| `userName`           | `string`                               | `''`       |
| `organizationName`   | `string`                               | `''`       |
| `organizationChange` | `'hidden' \| 'denied' \| 'allowed'`    | `'hidden'` |
| `passwordChange`     | `boolean`                              | `false`    |
| `locales`            | `ReadonlyArray<IRtProfileMenu.Locale>` | `[]`       |
| `locale`             | `string`                               | `''`       |
| `signOutDisabled`    | `boolean`                              | `false`    |

## Выходы

| выход                | значение | когда                          |
| -------------------- | -------- | ------------------------------ |
| `changeOrganization` | —        | выбран пункт смены организации |
| `changePassword`     | —        | выбран пункт смены пароля      |
| `localeChange`       | `string` | выбран другой язык, код языка  |
| `signOut`            | —        | выбран пункт выхода            |

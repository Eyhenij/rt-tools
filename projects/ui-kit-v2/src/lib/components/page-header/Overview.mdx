<Title>PageHeader — `rt-page-header`</Title>

Полоса разделов приложения: плоские пункты-ссылки, разделы с раскрывающейся панелью второго
уровня и блок пользователя справа.

```html
<rt-page-header ariaLabel="Разделы" [items]="sections()" [user]="user()" (itemClick)="go($event)" (userClick)="openProfile()" />
```

## Когда применять

- Верхний уровень навигации приложения: разделы, между которыми ходят постоянно.
- Разделов много, и часть из них раскрывается в подразделы колонками.

## Когда не применять

- **Навигация внутри раздела** — [`rt-section-nav`](./?path=/docs/components-sectionnav-overview--docs).
- **Действия, а не переходы** — [`rt-menu`](./?path=/docs/components-menu-overview--docs).
- **Полоса инструментов над списком** — [`rt-toolbar`](./?path=/docs/components-toolbar-overview--docs).

## Оси

| ось               | значения                                        | умолчание |
| ----------------- | ----------------------------------------------- | --------- |
| виды пунктов      | плоские ссылки, раздел с панелью второго уровня | —         |
| блок пользователя | нет, с инициалом, без инициала                  | нет       |

**Вид пункта решают его собственные поля, а не входы полосы.** Пункт с `columns` — кнопка,
раскрывающая панель: вести ему некуда, переходят уже её пункты. Пункт с `route` — ссылка. Пункт
с `unread` несёт точку; у раздела с панелью точка горит и от признака любого пункта внутри.

**Оси, которых не видно.**

- **Подсветку активного раздела даёт маршрутизатор** (`routerLinkActive`), а не входы. В витрине
  маршрут всегда корневой, и активным ни один раздел не станет — смотреть это надо в приложении.
- **Узкая разметка отдельная**, а не свёрнутая стилями: те же разделы доступны через
  кнопку-бургер, и оба варианта живут в разметке одновременно. Какой из них виден, решает ширина
  **окна**, а не ячейки, — сеткой это не показать.
- `userMenu` — шаблон меню пользователя: его содержимое пишет потребитель.

**Панель второго уровня — отдельная история.** Она живёт в оверлее CDK, до наведения её в
документе нет вовсе, и открывает её `play`-функция наведением. Открытая панель в истории ровно
одна.

## Состояния

| состояние       | чем задаётся                  | что меняется                                     |
| --------------- | ----------------------------- | ------------------------------------------------ |
| обычное         | —                             | пункт приглушённым цветом                        |
| наведение       | `:hover`                      | пункт подсвечивается                             |
| активный        | `routerLinkActive`            | пункт выделен, у раздела с панелью — тоже        |
| раскрыт         | наведение на раздел с панелью | панель под полосой, указатель раскрытия повёрнут |
| непросмотренное | поле `unread` пункта          | точка у правого края пункта                      |
| недоступный     | поле `disabled` пункта        | пункт приглушён, переход не работает             |

Недоступный пункт панели несёт подсказку о том, что раздел ещё готовится, — переведённую из
словаря кита.

## Доступность

- Полоса объявлена `<nav>` с доступным именем: `ariaLabel` или переведённое умолчание кита.
- Раздел с панелью — `<button>` с `aria-haspopup` и `aria-expanded`; панель объявлена
  `role="menu"`, её пункты — `role="menuitem"`.
- Точка непросмотренного объявлена картинкой с переведённым именем — иначе она была бы видна
  только глазами.

## Оформление

Ширина панели считается **числом колонок**, а не содержимым: свойство `--rt-nav-panel-columns`
выставляется по длине `columns`. Раскладку внутри — колонки и группы — готовит потребитель:
компонент их не считает.

**Панели нет в светло-тёмной паре.** Она рисуется в контейнере оверлеев CDK — за пределами
блока, которому пара назначает свойства темы.

## Входы

| вход        | тип                         | умолчание                |
| ----------- | --------------------------- | ------------------------ |
| `items`     | `ReadonlyArray<Item>`       | `[]`                     |
| `user`      | `{ name, avatar? } \| null` | `null`                   |
| `userTitle` | `string`                    | `''`                     |
| `userMenu`  | `TemplateRef \| null`       | `null`                   |
| `ariaLabel` | `string`                    | `''` → `rtKit.uiMainNav` |

`avatar` — заранее посчитанный инициал (одна буква); без него берётся первая буква имени.

## Выходы

| выход       | тип      | когда                                               |
| ----------- | -------- | --------------------------------------------------- |
| `itemClick` | `string` | нажат пункт без адреса — приходит его идентификатор |
| `userClick` | `void`   | нажат блок пользователя                             |

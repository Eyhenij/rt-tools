# `rt-page-header`

Полоса разделов приложения: плоские пункты-ссылки и пункты с раскрывающейся панелью.

```html
<rt-page-header
    ariaLabel="Разделы"
    [items]="sections()"
    [user]="user()"
    [panelMode]="panelMode()"
    (itemClick)="go($event)"
    (panelModeChange)="panelMode.set($event)"
    (userClick)="openProfile()" />
```

| вход        | тип                         | умолчание          |
| ----------- | --------------------------- | ------------------ |
| `items`     | `ReadonlyArray<Item>`       | `[]`               |
| `user`      | `{ name, avatar? } \| null` | `null`             |
| `userTitle` | `string`                    | `''`               |
| `userMenu`  | `TemplateRef \| null`       | `null`             |
| `ariaLabel` | `string`                    | `''` → `uiMainNav` |
| `panelMode` | `'hover' \| 'pinned'`       | `'hover'`          |

Выходы: `itemClick`, `panelModeChange`, `userClick`.

## Главное, что нужно знать

**Пункт с `route` — это ссылка, пункт с `columns` — кнопка.** Второму некуда вести: он
раскрывает панель, а переходят уже её пункты. Подсветку активного даёт `routerLinkActive`, то
есть маршрутизатор, а не входы компонента.

**Предпочтение о моде панели хранит потребитель.** Кит получает моду входом и сообщает о
нажатии переключателя выходом; своего состояния о ней он не заводит и в хранилище браузера не
ходит. Запрос поиска — другое дело: он живёт, пока панель открыта, и стирается её закрытием.

**Узкая разметка отдельная**, а не свёрнутая стилями: те же разделы доступны через кнопку-бургер
(`header-nav-burger`), и оба варианта живут в DOM одновременно.

## Края

- `unread: true` у пункта рисует отдельную точку.
- Панель вложенных разделов раскрывается по наведению и живёт в оверлее CDK — до наведения её в
  документе нет.
- Раскладку панели (колонки и группы) готовит потребитель: компонент их не считает.
- Закреплённая панель показывает раздел, чей адрес открыт. Активного раздела нет — панели нет
  вовсе: пустая занимала бы место и читалась бы поломкой.
- На узком экране переключателя моды не видно: панели там нет, разделы раскрываются
  аккордеоном.
- Отбор по подстроке подписи выбрасывает пустые группы и колонки и пересчитывает ширину
  панели; совпадений нет — вместо колонок стоит строка `uiNothingFound`.

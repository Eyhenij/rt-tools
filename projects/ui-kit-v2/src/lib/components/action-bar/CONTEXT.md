# `rt-action-bar`, `rt-action-bar-holder`

```html
<!-- список отмечает строки и пишет в службу; держатель рисует полосу над страницей -->
<rt-action-bar-holder />
```

| вход     | тип                   | умолчание      |
| -------- | --------------------- | -------------- |
| `config` | `IRtActionBar.Config` | **обязателен** |

| выход       | тип                   |
| ----------- | --------------------- |
| `actionRun` | `IRtActionBar.Action` |
| `closed`    | `void`                |

У держателя входов нет вовсе: настройку он читает у службы `RtActionBarService`.

## Главное, что нужно знать

**Полоса открывается счётом выбранного, а не своим признаком.** Два источника одного признака
расходятся молча, и признак, оставшийся поднятым над опустевшим выбором, держал бы полосу над
страницей, где ничего не выбрано.

**Крестик ничего не закрывает.** Он сообщает наружу; выбранное отпускает держатель через службу,
а список принадлежит потребителю.

## Как этим пользоваться

- **Служба объявляется на своём уровне, а не в корне.** Тот, кто отмечает строки, и тот, кто
  рисует полосу, стоят на разной глубине одного экрана: `providers: [RtActionBarService]` идёт
  туда, где живёт список.
- **Действие с вложенным списком само не срабатывает** — оно заголовок группы. Нажатие раскрывает
  список всплывающим слоем кита; нажатие пункта закрывает полосу так же, как обычное действие.
- **Вид действия называется входом `look`, а не объектом стилей.** Палитра кита закрытая, и своего
  цвета в настройку не передать.
- **Подпись действия со значком снимает правило стиля по грубому указателю.** В разметке она стоит
  всегда, и признак значка стоит модификатором — условие в шаблоне было бы оформлением, уехавшим
  в код.

## Края

- Ноль выбранного показан числом: счётчик, прячущийся на нуле, дёргал бы ширину полосы ровно в
  минуту её ухода.
- Полоса остаётся в разметке на длительность ухода. Число одно на разметку и правило стиля и лежит
  в `rt-action-bar.model.ts`.
- Подпись действия не урезается. Ряд, не влезший в предел ширины, переносится; одно действие,
  которое шире места и само по себе, переносит подпись внутри себя по границам слов.

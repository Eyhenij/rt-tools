# `rt-icon`

```html
<rt-icon name="check" size="md" color="current" [rotate]="null" />
```

| вход            | тип                                                                                                                                                            | умолчание   |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| `name`          | `IRtIcon.Name \| null` — литеральный union из `rt-icon-names.ts`; побеждает `glyph`                                                                            | `null`      |
| `glyph`         | `string \| null` — имя кита рисуется рисунком, любое другое — лигатурой шрифта Material                                                                        | `null`      |
| `glyphStrategy` | `'map-first' \| 'font' \| null` — способ рисовать `glyph` у этого значка; `null` — настройка `provideRtIcons`                                                  | `null`      |
| `size`          | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl' \| number` — ступень берёт свойство `--rt-icon-step-*`, число — пиксели                       | `'md'`      |
| `color`         | `'current' \| 'primary' \| 'muted' \| 'disabled' \| 'info' \| 'success' \| 'warning' \| 'danger' \| 'inverse'` — кроме `current`, свойство `--rt-icon-color-*` | `'current'` |
| `rotate`        | `number \| string \| null`                                                                                                                                     | `null`      |
| `fill`          | `boolean` — залитый рисунок материального набора и заливка шрифта лигатуры                                                                                     | `false`     |
| `spin`          | `boolean` — вращение, медленнее при просьбе системы о меньшем движении                                                                                         | `false`     |

Выходов нет. Размер и цвет едут инлайновым стилем host-а (`width`/`height`/`color`), не классом.
Ступень — свойство `--rt-icon-step-<ступень>`, по умолчанию `xs` 12px, `sm` 16px, `md` 20px,
`lg` 24px, `xl` 32px, `2xl` 40px, `3xl` 48px, `4xl` 64px; число — пиксели. Цвет, кроме `current`, —
свойство `--rt-icon-color-<цвет>` с ролью кита по умолчанию. Оси шрифта лигатуры — свойства
`--rt-icon-glyph-weight`, `-grade`, `-opsz`. Лигатура глифа скрыта, пока шрифты страницы не готовы:
её ждёт `RtIconFontService`.

## Главное, что нужно знать

**Значок едет по требованию.** Компонент рисует `<use href="#rt-icon-<name>">` — ссылку на
symbol внутри спрайта — и тем же движением просит имя у `RtIconRegistry`. Реестр ходит за файлом
один раз на страницу и дописывает символ в спрайт; страница платит ровно за те значки, которые
нарисовала, а не за весь набор.

`provideRtIcons()` объявляет наборы и сам не грузит ничего. Без него реестр берёт встроенные
наборы по адресам `/icons` и `/icons-material`; приложение обязано опубликовать туда `assets/icons`
и `assets/icons-material` пакета, иначе разметка верна, а на экране пусто.

**Набор — это данные.** Имя, адрес, запасной набор (`fallback`), перечень своих имён (`names`) и
признак залитых рисунков (`fill`). Имена значков у всех наборов одни — имена кита. Встроенные
описаны в `rt-icon-sets.ts` (`rtIconBuiltInSets`): `kit` полный, `material` держит имена из
`RT_ICON_MATERIAL_NAMES` и берёт остальное из `kit`. Свои наборы приложение добавляет в
`provideRtIcons({ sets, default, glyphStrategy })`; запись с именем встроенного набора меняет только
названные поля, набор без `fallback` берёт недостающее из `kit`. Разбор объявления —
`rt-icon-sets.logic.ts`: негодное даёт предупреждение и набор `kit`.

**Какой набор у значка** (`rtIconSetOf`): ближайшая часть страницы с директивой `rtIconSet`, затем
выбор `RtIconSetService.use(name)`, затем признак material в разметке, затем набор приложения.
`use(null)` возвращает набор из разметки и настройки. При смене набора значок и кнопка держат старый
рисунок, пока новый не приехал (`rtIconDrawn`); новое имя значка старый не держит. Кнопка меняет
только ссылки своих значков, поэтому загрузчик и подпись не перерисовываются.

**Окна берут набор части.** `rtIconSet` пишет атрибут `data-rt-icon-set`; `carryThemeScope` из
`util/material-preset.ts` переносит его на панели при каждом открытии. Диалог и aside берут набор у
узла с фокусом и отдают его инжектору окна, подтверждение пункта меню — набор самого пункта. Уже
открытое окно набор не меняет.

**Признаков material два.** `data-preset='material'` на предке меняет весь набор оформления, а
`data-rt-icon-preset='material'` (`RT_ICON_PRESET_ATTRIBUTE`) — только значки. Оба читаются у
ближайшего предка после первой отрисовки и слабее директивы и `use()`. Значение `'base'` у
признака ничего не делает. Стилями набор не выбирается: ссылку на символ спрайта CSS не подменит.

**Адрес скачивается один раз.** Имя, которого нет в перечне набора, берётся из запасного без
запроса. Недоехавший файл закрывается следующим адресом цепочки (залитый — сначала контурным того
же набора). Отказ запоминается, а рисунок, которого нет нигде, даёт одно предупреждение. Символы
разных наборов различаются приставкой `id`: у `kit` и `material` свои, у набора приложения —
`rt-icon-set-<набор>--<имя>`.

## Как этим пользоваться

- Иконка спрятана от скринридера (`aria-hidden="true"`) — подпись даёт вмещающий её контрол.
  Отдельная `rt-icon` без подписи для AT невидима, и это правильно.
- Цвет по умолчанию наследуется от текста. Явное значение нужно, только когда иконка должна
  отличаться от текста своего контрола.
- **Знаки соцсетей `social-*` цветные, и вход `color` на них не действует.** Заливка задана в
  файле — фирменный цвет сети, у Instagram градиент; тема их не красит. Размер задаётся тем же
  входом, что у остальных. Файлы собирает `tools/build-social-icons.mjs` из контуров
  `simple-icons`; правится сценарий, а не файлы.
- `rotate` принимает строку (`rotate="180"`) — так значение приходит из атрибута разметки.
  Ноль и нечисловая строка гасят поворот: лишний `transform` создавал бы отдельный слой отрисовки.

## Края

- **Имя без файла гасит только свой значок.** Соседние значки приезжают своими потоками, на месте
  промаха остаётся пустое место размера значка, а в консоли — одно предупреждение. Второй раз за
  отказавшим адресом реестр не ходит. Добавляя имя в `rt-icon-names.ts`, положи SVG рядом:
  иначе промах виден только глазами.
- **Значок появляется после первой отрисовки.** Место под него занято сразу — размер задан на
  хосте, — поэтому приход символа соседей не двигает.
- Символ, уже лежащий в спрайте страницы, запроса не даёт: так витрина не ходит за одним и тем
  же между историями, а приложение вправе положить свой спрайт до старта.
- На сервере (SSR) реестр молчит: относительных HTTP-запросов к статике там нет, значки
  дорисуются после гидрации.

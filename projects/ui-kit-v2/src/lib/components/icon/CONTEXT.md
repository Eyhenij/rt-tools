# `rt-icon`

```html
<rt-icon name="check" size="md" color="current" [rotate]="null" />
```

| вход     | тип                                                                                 | умолчание      |
| -------- | ----------------------------------------------------------------------------------- | -------------- |
| `name`   | `IRtIcon.Name` — литеральный union из `rt-icon-names.ts`                            | **обязателен** |
| `size`   | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'`                                     | `'md'`         |
| `color`  | `'current' \| 'muted' \| 'info' \| 'success' \| 'warning' \| 'danger' \| 'inverse'` | `'current'`    |
| `rotate` | `number \| string \| null`                                                          | `null`         |

Выходов нет. Размер и цвет едут инлайновым стилем host-а (`width`/`height`/`color`), не классом:
`xs` 12px, `sm` 16px, `md` 20px, `lg` 24px, `xl` 32px, `2xl` 40px.

## Главное, что нужно знать

**Значок едет по требованию.** Компонент рисует `<use href="#rt-icon-<name>">` — ссылку на
symbol внутри спрайта — и тем же движением просит имя у `RtIconRegistry`. Реестр ходит за файлом
один раз на страницу и дописывает символ в спрайт; страница платит ровно за те значки, которые
нарисовала, а не за весь набор.

`provideRtIcons()` называет адрес набора и сам не грузит ничего. Без него реестр берёт умолчание
`/icons`; приложение обязано опубликовать туда набор из `assets/icons` пакета, иначе разметка
верна, а на экране пусто.

## Как этим пользоваться

- Иконка спрятана от скринридера (`aria-hidden="true"`) — подпись даёт вмещающий её контрол.
  Отдельная `rt-icon` без подписи для AT невидима, и это правильно.
- Цвет по умолчанию наследуется от текста. Явное значение нужно, только когда иконка должна
  отличаться от текста своего контрола.
- **Знаки соцсетей `social-*` цветные, и вход `color` на них не действует.** Заливка задана в
  файле — фирменный цвет сети, у Instagram градиент; тема их не красит. Размер задаётся тем же
  входом, что у остальных. Файлы собирает `tools/build-social-icons.mjs` из контуров
  `simple-icons`; правится сценарий, а не файлы.
- `rotate` принимает строку (`rotate="180"`) — так значение приходит из атрибута разметки.
  Ноль и нечисловая строка гасят поворот: лишний `transform` создавал бы отдельный слой отрисовки.

## Края

- **Имя без файла гасит только свой значок.** Отказ остаётся внутри реестра, соседние значки
  приезжают своими потоками, и на месте промаха остаётся пустое место размера значка. Второй раз
  за отказавшим именем реестр не ходит. Добавляя имя в `rt-icon-names.ts`, положи SVG рядом:
  иначе промах виден только глазами.
- **Значок появляется после первой отрисовки.** Место под него занято сразу — размер задан на
  хосте, — поэтому приход символа соседей не двигает.
- Символ, уже лежащий в спрайте страницы, запроса не даёт: так витрина не ходит за одним и тем
  же между историями, а приложение вправе положить свой спрайт до старта.
- На сервере (SSR) реестр молчит: относительных HTTP-запросов к статике там нет, значки
  дорисуются после гидрации.

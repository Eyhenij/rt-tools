# `rt-icon`

```html
<rt-icon name="check" size="md" color="current" [rotate]="null" />
```

| вход     | тип                                                                                 | умолчание      |
| -------- | ----------------------------------------------------------------------------------- | -------------- |
| `name`   | `IRtIcon.Name` — литеральный union из `rt-icon-names.ts`                            | **обязателен** |
| `size`   | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'`                                     | `'md'`         |
| `color`  | `'current' \| 'muted' \| 'info' \| 'success' \| 'warning' \| 'danger' \| 'inverse'` | `'current'`    |
| `rotate` | `number \| string \| null`                                                          | `null`         |

Выходов нет. Размер и цвет едут инлайновым стилем host-а (`width`/`height`/`color`), не классом:
`xs` 12px, `sm` 16px, `md` 20px, `lg` 24px, `xl` 32px, `2xl` 40px.

## Главное, что нужно знать

**Компонент ничего не грузит.** Он рисует `<use href="#rt-icon-<name>">` — ссылку на symbol
внутри спрайта, который собирает `RtIconRegistry` и вставляет в `<body>`
провайдер `provideRtIcons()`. Без этого провайдера разметка верна, а на экране пусто.

Приложение обязано опубликовать набор из `assets/icons` пакета по адресу, который знает реестр
(по умолчанию `/icons`, иначе `provideRtIcons('/my/icons')`).

## Как этим пользоваться

- Иконка спрятана от скринридера (`aria-hidden="true"`) — подпись даёт вмещающий её контрол.
  Отдельная `rt-icon` без подписи для AT невидима, и это правильно.
- Цвет по умолчанию наследуется от текста. Явное значение нужно, только когда иконка должна
  отличаться от текста своего контрола.
- `rotate` принимает строку (`rotate="180"`) — так значение приходит из атрибута разметки.
  Ноль и нечисловая строка гасят поворот: лишний `transform` создавал бы отдельный слой отрисовки.

## Края

- **Имя без файла роняет весь набор.** Реестр собирает спрайт одним `forkJoin`; один отказ
  гасит иконки во всём приложении. Добавляя имя в `rt-icon-names.ts`, положи SVG рядом.
- Реестр пропускает загрузку, если спрайт уже в DOM (`#rt-icon-sprite`) — так витрина не гоняет
  сотни запросов между историями.
- На сервере (SSR) спрайт не грузится: относительных HTTP-запросов к статике там нет, иконки
  дорисуются после гидрации.

<Title>Icon — `rt-icon`</Title>

Одна иконка из набора кита. Ничего не грузит сама: рисует ссылку на symbol внутри спрайта,
который собирает `RtIconRegistry`, а вставляет в документ провайдер `provideRtIcons()`.

```html
<rt-icon name="check" />
<rt-icon name="alarm-clock" size="lg" color="warning" />
<rt-icon name="arrow-right" [rotate]="180" />
```

## Когда применять

- Знак рядом с подписью внутри контрола: кнопка, поле, пункт меню, строка таблицы.
- Самостоятельный указатель состояния там, где смысл уже назван соседним текстом.

## Когда не применять

- **Кликабельная иконка** — [`rt-icon-button`](./?path=/docs/components-icon-button-overview--docs):
  она несёт роль кнопки и обязательную подпись для скринридера.
- **Иконка как единственный носитель смысла.** `rt-icon` спрятана от скринридера
  (`aria-hidden="true"`), и без соседнего текста смысл теряется целиком.

## Оси

| ось     | значения                                                              | умолчание      |
| ------- | --------------------------------------------------------------------- | -------------- |
| имя     | весь набор из `rt-icon-names.ts`, разложенный по категориям           | **обязателен** |
| размер  | `xs` 12, `sm` 16, `md` 20, `lg` 24, `xl` 32, `2xl` 40 px              | `md`           |
| цвет    | `current`, `muted`, `info`, `success`, `warning`, `danger`, `inverse` | `current`      |
| поворот | без поворота, 90°, 180°, 270°                                         | без поворота   |

Имя — ось с тремя сотнями значений, и показать её выборкой нельзя: история **Catalog**
рисует набор целиком, категориями из `categoryOf`. Размер и цвет друг на друга не влияют
и идут рядами, а не сеткой.

## Состояния

**Состояний взаимодействия у компонента нет и быть не может:** он не принимает ни фокус, ни
указатель — ни одного правила с `:hover`, `:focus-visible` или `:active` в его SCSS. Наведение
и нажатие принадлежат контролу, внутри которого иконка стоит, и показаны в его матрице.

Отключённого вида у иконки тоже нет: цвет наследуется от текста, и погашенный контрол гасит
её вместе с подписью.

## Доступность

- Разметка несёт `aria-hidden="true"` и `focusable="false"` — иконка для скринридера
  отсутствует, и это правильный вид: имя контролу даёт подпись.
- `inverse` рассчитан на тёмную подложку. На светлой странице он сливается с фоном — в ряду
  цветов это штатный вид ячейки, а не пропуск.

## Оформление

Размер и цвет едут инлайновым стилем (`width` / `height` / `color`), а не классом: шкала
отображается в пиксели в самом компоненте, а цвет — в свойства `--rt-icon-color-*`. Умолчание
цвета — `currentColor`, поэтому иконка без явного цвета всегда совпадает с текстом вокруг.

## Входы

| вход     | тип                                                                                 | умолчание      |
| -------- | ----------------------------------------------------------------------------------- | -------------- |
| `name`   | `IRtIcon.Name` — литеральный union из `rt-icon-names.ts`                            | **обязателен** |
| `size`   | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'`                                     | `'md'`         |
| `color`  | `'current' \| 'muted' \| 'info' \| 'success' \| 'warning' \| 'danger' \| 'inverse'` | `'current'`    |
| `rotate` | `number \| string \| null` — ноль и нечисловая строка гасят поворот                 | `null`         |

## Выходы

Своих выходов нет.

<Title>Icon — `rt-icon`</Title>

Одна иконка из набора кита. Рисует ссылку на symbol внутри спрайта и тем же движением просит имя
у `RtIconRegistry`: файл забирается тогда, когда значок с этим именем понадобился странице.
`provideRtIcons()` называет адрес набора и сам не грузит ничего.

```html
<rt-icon name="check" />
<rt-icon name="alarm-clock" size="lg" color="warning" />
<rt-icon name="arrow-right" [rotate]="180" />
<rt-icon glyph="arrow_back" />
<rt-icon name="spinner" spin [size]="14" />
```

## Когда применять

- Знак рядом с подписью внутри контрола: кнопка, поле, пункт меню, строка таблицы.
- Самостоятельный указатель состояния там, где смысл уже назван соседним текстом.

## Когда не применять

- **Кликабельная иконка** — [`rt-icon-button`](./?path=/docs/atoms-buttons-iconbutton-overview--docs):
  она несёт роль кнопки и обязательную подпись для скринридера.
- **Иконка как единственный носитель смысла.** `rt-icon` спрятана от скринридера
  (`aria-hidden="true"`), и без соседнего текста смысл теряется целиком.

## Оси

| ось      | значения                                                                                     | умолчание    |
| -------- | -------------------------------------------------------------------------------------------- | ------------ |
| имя      | весь набор из `rt-icon-names.ts`, разложенный по категориям                                  | нет          |
| глиф     | имя Material: с парой — пара кита, без пары — лигатура шрифта                                | нет          |
| размер   | `xs` 12, `sm` 16, `md` 20, `lg` 24, `xl` 32, `2xl` 40, `3xl` 48, `4xl` 64 px или число px    | `md`         |
| цвет     | `current`, `primary`, `muted`, `disabled`, `info`, `success`, `warning`, `danger`, `inverse` | `current`    |
| поворот  | без поворота, 90°, 180°, 270°                                                                | без поворота |
| заливка  | контурный рисунок, залитый — только в материальном наборе                                    | контурный    |
| вращение | неподвижен, вращается                                                                        | неподвижен   |

Имя — ось с тремя сотнями значений, и показать её выборкой нельзя: история **Catalog**
рисует набор целиком, категориями из `categoryOf`. Размер и цвет друг на друга не влияют
и идут рядами, а не сеткой.

**Заливка есть только у материального набора.** Он хранит на каждое имя два рисунка Material
Symbols толщиной 700 — контурный и залитый, как их рисует первый кит шрифтом. Вход `fill` берёт
залитый; свой набор кита рисует имя одним рисунком, и вход на нём ничего не меняет. Оба рисунка
стоят рядами в истории **MaterialSet**.

**Знаки соцсетей — второй род значка.** Имена `social-*` — двенадцать сетей в фирменных
цветах: заливка задана в самом файле, и ось цвета на них не действует, а тема их не красит.
В каталоге они стоят своим рядом `Social`; история **Social** показывает их в обеих темах.
У X и TikTok плашка чёрная — на тёмной теме её край сливается с фоном, знак остаётся виден;
так их показывают сами сети.

**Имя Material — вход `glyph`.** Приложение, пришедшее с первого кита, называет значки именами
Material. Имя с парой в перечне кита рисуется этой парой, без пары — лигатурой шрифта Material
Symbols. Шрифт кит не везёт, его подключает приложение; семью можно переназначить свойством
`--rt-icon-glyph-font`. Пока шрифты страницы не готовы, лигатура скрыта. Когда переданы и `name`,
и `glyph`, рисуется `name`. Третий аргумент `provideRtIcons(base, material, { glyphStrategy })`
выбирает способ: `map-first` по умолчанию или `font` — шрифт для любого имени Material. Имя кита,
которое шрифт нарисовать не может (`ico-plus`, `docBox`), и при `font` рисуется рисунком кита, а
не текстом; имя кита, совпавшее с лигатурой (`search`), при `font` остаётся шрифтом. Вход
`glyphStrategy` у одного значка перекрывает выбор приложения. Оси шрифта лигатуры — вес, градация
и оптический размер — приложение задаёт свойствами `--rt-icon-glyph-weight`, `-grade` и `-opsz`
(400, 0 и сторона значка в пикселях — так браузер ставил оптический размер без оси); заливку даёт вход `fill`. История **Glyph** показывает обе ветки рядом.

**Вращение и размер в пикселях.** Вход `spin` вращает значок; когда система просит меньше
движения, вращение в четыре раза медленнее. Размер принимает число пикселей рядом со ступенями —
для 14, 48 и 56. История **SpinAndPixels** показывает оба входа.

## Состояния

**Состояний взаимодействия у компонента нет и быть не может:** он не принимает ни фокус, ни
указатель — ни одного правила с `:hover`, `:focus-visible` или `:active` в его SCSS. Наведение
и нажатие принадлежат контролу, внутри которого иконка стоит, и показаны в его матрице.

Отключённого состояния у иконки тоже нет: цвет наследуется от текста, и погашенный контрол гасит
её вместе с подписью. Цвет `disabled` — тон недоступности для значка, который стоит сам по себе.

## Доступность

- Разметка несёт `aria-hidden="true"` и `focusable="false"` — иконка для скринридера
  отсутствует, и это правильный вид: имя контролу даёт подпись.
- `inverse` рассчитан на тёмную подложку. На светлой странице он сливается с фоном — в ряду
  цветов это штатный вид ячейки, а не пропуск.

## Оформление

Размер и цвет едут инлайновым стилем (`width` / `height` / `color`), а не классом. Ступень
размера — свойство `--rt-icon-step-<ступень>` с шагом шкалы `--rt-size-*` по умолчанию, цвет —
свойство `--rt-icon-color-<цвет>` с ролью кита по умолчанию; приложение задаёт их на значке или
выше. Ступени названы `--rt-icon-step-*`, а не `--rt-icon-size-*`: те объявляет первый кит со своими
значениями, и в приложении с обоими китами значки второго выросли бы. Умолчание цвета — `currentColor`, поэтому иконка без явного цвета всегда совпадает с текстом
вокруг.
Знак соцсети собран сценарием `tools/build-social-icons.mjs` из контуров `simple-icons`, и
перекрасить его нечем: цвет — часть знака.

## Входы

| вход            | тип                                                                                                                                                            | умолчание   |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| `name`          | `IRtIcon.Name \| null` — литеральный union из `rt-icon-names.ts`; побеждает `glyph`                                                                            | `null`      |
| `glyph`         | `string \| null` — имя Material, рисуется парой кита или лигатурой шрифта                                                                                      | `null`      |
| `glyphStrategy` | `'map-first' \| 'font' \| null` — способ рисовать `glyph` у этого значка; `null` — настройка `provideRtIcons`                                                  | `null`      |
| `size`          | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl' \| number` — ступень берёт свойство `--rt-icon-step-*`, число — пиксели                       | `'md'`      |
| `color`         | `'current' \| 'primary' \| 'muted' \| 'disabled' \| 'info' \| 'success' \| 'warning' \| 'danger' \| 'inverse'` — кроме `current`, свойство `--rt-icon-color-*` | `'current'` |
| `rotate`        | `number \| string \| null` — ноль и нечисловая строка гасят поворот                                                                                            | `null`      |
| `fill`          | `boolean` — залитый рисунок материального набора и заливка шрифта лигатуры                                                                                     | `false`     |
| `spin`          | `boolean` — значок вращается, медленнее при просьбе системы о меньшем движении                                                                                 | `false`     |

## Выходы

Своих выходов нет.

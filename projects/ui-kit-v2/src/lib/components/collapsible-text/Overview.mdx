<Title>CollapsibleText — `rt-collapsible-text`</Title>

Многоабзацный текст, обрезанный по числу строк, с кнопкой «ещё» под ним. Кнопка появляется
только тогда, когда текст действительно не поместился.

```html
<rt-collapsible-text [paragraphs]="description()" [clampLines]="3" />
```

## Когда применять

- Длинное описание в карточке или панели, где место ограничено, а текст нужен целиком по
  требованию.

## Когда не применять

- **Текст с разметкой** — компонент принимает массив строк и разбивать разметку не умеет.
- **Короткий текст известной длины** — обычный абзац: обрезка ничего не даст, а замер стоит
  наблюдателя ширины.

## Оси

| ось            | значения                | умолчание |
| -------------- | ----------------------- | --------- |
| предел строк   | 1, 2, 3, 6              | `6`       |
| число абзацев  | один, два, три          | —         |
| ширина колонки | узкая, средняя, широкая | —         |

**Кнопка «ещё» появляется по замеру, а не по длине текста.** После отрисовки компонент
сравнивает высоту содержимого с высотой обрезки и следит за изменением ширины наблюдателем:
тот же текст в узкой колонке переполняет обрезку, а в широкой — нет. Поэтому ширина здесь
такая же ось, как предел строк, и показана рядом **Width**.

Отсюда следствие для спек: в среде без раскладки высоты нулевые, переполнения нет, и кнопки не
будет — это верное поведение, а не сбой.

## Края

| край                 | что происходит                        |
| -------------------- | ------------------------------------- |
| короткий текст       | обрезка не срабатывает, кнопки нет    |
| пустой набор         | не рисуется ни абзаца, ни кнопки      |
| предел в одну строку | обрезка по первой строке, кнопка есть |

## Состояния

| состояние   | чем задаётся   | что меняется                                         |
| ----------- | -------------- | ---------------------------------------------------- |
| свёрнутое   | умолчание      | обрезка по `clampLines`, кнопка «ещё»                |
| развёрнутое | нажатие кнопки | обрезка снята целиком, кнопка меняется на «свернуть» |

Разворот снимает и класс обрезки, и ограничение по строкам; свёрнутое состояние возвращается
повторным нажатием. Матрицами показано только свёрнутое: развёрнутое отличается лишь снятой
обрезкой, и ряд был бы теми же абзацами целиком.

## Доступность

- Кнопка несёт `aria-expanded` — состояние читается, а не выводится из подписи.
- Подписи кнопки берутся из словаря кита, а не зашиты в разметку.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-detail-list`](./?path=/docs/molecules-data-detaillist-overview--docs) — пары «подпись —
  значение», а не сплошной текст.

## Входы

| вход         | тип                 | умолчание | что делает                                 |
| ------------ | ------------------- | --------- | ------------------------------------------ |
| `paragraphs` | `readonly string[]` | `[]`      | абзацы текста; каждый рисуется своим `<p>` |
| `clampLines` | `number`            | `6`       | сколько строк видно в свёрнутом состоянии  |

# `rt-collapsible-text`

Длинный текст, свёрнутый до нескольких строк, с кнопкой «ещё».

```html
<rt-collapsible-text [paragraphs]="description()" [clampLines]="4" />
```

| вход         | тип                 | умолчание      |
| ------------ | ------------------- | -------------- |
| `paragraphs` | `readonly string[]` | **обязателен** |
| `clampLines` | `number \| string`  | `6`            |

Выходов нет.

## Главное, что нужно знать

**Кнопка «ещё» появляется по замеру, а не по длине текста.** После отрисовки компонент сравнивает
`scrollHeight` с `clientHeight` и следит за изменением ширины через `ResizeObserver`: тот же текст
в узкой колонке переполняет обрезку, а в широкой — нет.

Отсюда следствие для тестов: в среде без раскладки (jsdom) высоты нулевые, переполнения нет, и
кнопки не будет — это верное поведение, а не сбой.

## Края

- Текст приходит **массивом абзацев**, а не одной строкой: разбивать HTML компонент не умеет.
- Разворот снимает и класс обрезки, и ограничение по строкам; свёрнутое состояние возвращается
  повторным нажатием.

# `rt-drawer`

Боковая панель внутри участка страницы. `rt-drawer-container` — строка из содержимого и
панелей, `rt-drawer` — панель у края, `rt-resize-handle` — ручка ширины.

```html
<rt-drawer-container>
    <rt-drawer mode="over" position="end" resizable [(opened)]="open" [(width)]="width">…</rt-drawer>
    <section>Отчёт</section>
</rt-drawer-container>
```

| вход           | тип                   | умолчание |
| -------------- | --------------------- | --------- |
| `opened`       | `boolean`             | `false`   |
| `mode`         | `'side' \| 'over'`    | `'side'`  |
| `position`     | `'start' \| 'end'`    | `'start'` |
| `hasBackdrop`  | `boolean`             | `true`    |
| `disableClose` | `boolean`             | `false`   |
| `width`        | `number \| null`      | `320`     |
| `minWidth`     | `number`              | `200`     |
| `maxWidth`     | `number`              | `640`     |
| `resizable`    | `boolean`             | `false`   |
| `ariaLabel`    | `string \| null`      | `null`    |
| `overflow`     | `'clip' \| 'visible'` | `'clip'`  |
| `autoFocus`    | `boolean \| string`   | `true`    |

Выходы: `openedChange`, `widthChange`, `openedStart`, `closedStart`, `afterOpened`, `afterClosed`,
`backdropClick`. Методы: `open()`, `close()`, `toggle()`.

## Главное, что нужно знать

**Хост панели — `display: contents`.** Подложка и `<aside>` становятся участниками гибкой строки
контейнера; порядок на экране задаёт `order` по краю, а в разметке содержимое идёт первым, чтобы
панель поверх рисовалась над его узлами с положением без слоёв.

**Закрытая панель не уходит из разметки.** Рядом — `inline-size: 0`, поверх — сдвиг за край;
видимость гаснет после перехода, `inert` снимает её из фокуса.

**Escape и подложка закрывают только поверх.** Рядом панель — часть страницы.

**Ярусы — внутри контейнера.** Поверх подложка стоит на `--rt-drawer-backdrop-z-index`, панель на
`--rt-drawer-over-z-index`, а контейнер с `isolation: isolate` не пускает их над страницей. Узел
содержимого со своим `z-index` под подложкой. Рядом ярус панели — `--rt-drawer-z-index`, по умолчанию
`auto`: начальная панель стоит в строке раньше содержимого, и содержимое со своим контекстом
наложения накрывает её тень. Тень рядом — `--rt-drawer-side-shadow`, по умолчанию её нет. Справа
налево закрытая панель уезжает за свой край по `:dir(rtl)`.

**Ручка ширину не хранит.** Она сообщает новую в пределах; без `width` меряет родителя в момент
первого движения — так её берёт правая панель `rt-container` шириной по содержимому. Шаблон ручки
пуст и лежит в своём файле, `rt-resize-handle.component.html`: всё, что она рисует, висит на хосте.

**Начало и конец смены — разные выходы.** `openedStart` и `closedStart` приходят в момент смены
`opened`, `afterOpened` и `afterClosed` — по `transitionend` ширины рядом и сдвига поверх, со
страховочным таймером на случай, когда перехода нет. Исходное состояние ничего не сообщает; конец,
обогнанный новой сменой, молчит.

**`overflow: 'visible'` снимает обрезку только с открытой панели.** Закрываясь, панель обрезает
содержимое сразу: иначе оно висело бы над страницей, пока панель сжимается.

**`width: null` — ширина по содержимому.** Своей ширины нет, ручки ширины тоже; переход рядом от
неё к нулю не анимируется, конец закрытия приходит по таймеру.

**`autoFocus` по умолчанию — как раньше:** поверх содержимого фокус встаёт на панель, рядом не
трогается. Селектор и `'first-tabbable'` работают в обоих местах; узел не нашёлся — фокус на панели.
Панель, открытая с первой отрисовки, фокус не берёт: страницу только загрузили.
Пустой атрибут и строка `'true'` значат `true`, строка `'false'` — `false`.

**`backdropClick` приходит до закрытия и с `disableClose`.** Так приложение узнаёт о нажатии, даже
когда закрывать панель решает само.

**Высота окна — от контейнера.** Контейнер высотой в окно обрезает края, а прокручивается его
содержимое: панели остаются высотой в окно без отдельного входа.

<Title>Drawer — `rt-drawer`</Title>

Боковая панель внутри участка страницы: рядом с содержимым, которое она сужает, или поверх
него. Участок задаёт `rt-drawer-container`, панель — `rt-drawer` внутри него.

```html
<rt-drawer-container>
    <rt-drawer resizable [(opened)]="filtersOpen" [(width)]="filtersWidth">…</rt-drawer>
    <section>Отчёт</section>
</rt-drawer-container>
```

## Когда применять

- Панель фильтров, настроек или списка рядом с рабочей областью вкладки.
- Разделённая область, где человек сам выбирает ширину боковой части.

## Когда не применять

- **Правая панель каркаса приложения** — это `rt-container` с `rightMode`.
- **Панель над всем окном с подложкой** — это `rt-aside`.

## Оси

| ось   | значения                        | умолчание |
| ----- | ------------------------------- | --------- |
| место | `side` — рядом, `over` — поверх | `side`    |
| край  | `start`, `end`                  | `start`   |

Место перемножено с краем — история **Mode**: у каждого края своя граница, своя ручка и своя
сторона ухода.

## Состояния

| состояние   | чем задаётся | что меняется                                                        |
| ----------- | ------------ | ------------------------------------------------------------------- |
| открыта     | `opened`     | рядом — занимает ширину, поверх — лежит на содержимом с подложкой   |
| закрыта     | `opened`     | рядом — сжата до нуля, поверх — за своим краем; фокуса не принимает |
| с ручкой    | `resizable`  | у внутреннего края полоса, которую тянут и двигают стрелками        |
| тянут ручку | —            | переход ширины погашен, ширина идёт за указателем                   |

История **States**. Ручка в покое прозрачна: её линия видна на наведении и фокусе, поэтому в
кадре ячейка «с ручкой» совпадает с открытой — смотреть её надо в **Playground**.

**Закрытая панель остаётся в разметке.** Набранное в ней переживает закрытие, а фокуса она не
принимает (`inert`).

**Закрывают панель поверх подложка и Escape.** С `disableClose` — только владелец. Рядом с
содержимым панель — часть страницы: ни подложки, ни закрытия по Escape у неё нет.

## Доступность

- Поверх содержимого панель на открытии забирает фокус, на закрытии возвращает его туда, где он
  был. Escape из панели дальше не всплывает.
- `ariaLabel` называет панель (`aria-label` на `<aside>`) и её ручку.
- Ручка — `role="separator"` с текущей шириной и пределами: стрелки меняют ширину на 16 px,
  `Home` и `End` ставят пределы.

## Оформление

Свойства `--rt-drawer-*`: фон, граница, тень поверх, длительность перехода; подложка —
`--rt-drawer-backdrop-*`, ручка — `--rt-resize-handle-*`. Светлая и тёмная темы — история
**Themes**, оба набора — **Presets**.

**Высоту даёт место.** Контейнер растягивается на высоту, которую ему дали, и панель — вместе с
ним; без заданной высоты участок высотой в содержимое. Контейнер высотой в окно держит панели
высотой в окно, пока прокручивается содержимое: отдельного входа для этого нет.

**Содержимое за краем и ширина по содержимому.** `overflow="visible"` выпускает за край открытой
панели выезжающую подпанель или ручку на краю; закрываясь, панель обрезает содержимое сразу.
`width` со значением `null` даёт панели ширину её содержимого. Оба входа показывает **Playground**.

## Входы

| вход           | тип                   | умолчание | что делает                                                                                                  |
| -------------- | --------------------- | --------- | ----------------------------------------------------------------------------------------------------------- |
| `opened`       | `boolean`             | `false`   | открыта ли панель; двусторонний                                                                             |
| `mode`         | `'side' \| 'over'`    | `'side'`  | рядом с содержимым или поверх                                                                               |
| `position`     | `'start' \| 'end'`    | `'start'` | у какого края                                                                                               |
| `hasBackdrop`  | `boolean`             | `true`    | подложка в режиме поверх                                                                                    |
| `disableClose` | `boolean`             | `false`   | подложка и Escape не закрывают                                                                              |
| `width`        | `number \| null`      | `320`     | ширина в пикселях; двусторонний; `null` — по содержимому, без ручки                                         |
| `minWidth`     | `number`              | `200`     | нижний предел ширины                                                                                        |
| `maxWidth`     | `number`              | `640`     | верхний предел ширины                                                                                       |
| `resizable`    | `boolean`             | `false`   | ручка ширины у внутреннего края                                                                             |
| `ariaLabel`    | `string \| null`      | `null`    | имя панели и ручки                                                                                          |
| `overflow`     | `'clip' \| 'visible'` | `'clip'`  | `visible` — содержимое открытой панели выходит за её край                                                   |
| `autoFocus`    | `boolean \| string`   | `true`    | куда встаёт фокус на открытии: `true` — на панель поверх, `false` — никуда, `'first-tabbable'` или селектор |

У `rt-drawer-container` входов нет. Ручка `rt-resize-handle` — отдельный компонент, панель
ставит её сама; её входы:

| вход        | тип                | умолчание  | что делает                                   |
| ----------- | ------------------ | ---------- | -------------------------------------------- |
| `width`     | `number \| null`   | `null`     | текущая ширина; `null` — ручка меряет панель |
| `min`       | `number`           | `0`        | нижний предел                                |
| `max`       | `number`           | наибольшее | верхний предел                               |
| `step`      | `number`           | `16`       | шаг стрелки                                  |
| `edge`      | `'start' \| 'end'` | `'end'`    | на каком краю панели стоит                   |
| `ariaLabel` | `string \| null`   | `null`     | имя ручки                                    |

Её выходы — `widthChange` (новая ширина) и `resizing` (тянут или отпустили).

## Выходы

| выход           | тип          | когда                                           |
| --------------- | ------------ | ----------------------------------------------- |
| `openedChange`  | `boolean`    | панель закрыли подложкой или Escape             |
| `widthChange`   | `number`     | ручка задала новую ширину                       |
| `openedStart`   | `void`       | панель начала открываться                       |
| `closedStart`   | `void`       | панель начала закрываться                       |
| `afterOpened`   | `void`       | панель доехала открытой; без движения — сразу   |
| `afterClosed`   | `void`       | панель доехала закрытой; без движения — сразу   |
| `backdropClick` | `MouseEvent` | нажали подложку; до закрытия и с `disableClose` |

Публичное API: `open()`, `close()`, `toggle()`.

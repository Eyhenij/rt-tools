# `rt-divider`

```html
<rt-divider inset />
<rt-divider vertical />
```

| вход       | тип       | умолчание |
| ---------- | --------- | --------- |
| `vertical` | `boolean` | `false`   |
| `inset`    | `boolean` | `false`   |

Выходов нет.

## Главное, что нужно знать

**Линия — граница хоста.** Вертикальная тянется по поперечной оси flex-строки (`align-self:
stretch`); в обычной строке она высотой в строку текста.

**`inset` значит разное по направлению.** Горизонтальная отступает от начала на
`--rt-divider-inset`, вертикальная укорачивается сверху и снизу на `--rt-divider-inset-block`.

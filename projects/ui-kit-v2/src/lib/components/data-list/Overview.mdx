<Title>DataList — `rt-data-list`</Title>

Список записей первого кита во втором: полоса действий сверху, таблица посередине, полоса страниц
снизу. Своего состояния список не ведёт вовсе — страницу, порядок, условия отбора и поиск он просит
у приложения.

```html
<rt-data-list
    rtDataListSelectors
    tableConfigStorageKey="orders"
    [entities]="rows()"
    [pageModel]="page()"
    [currentSortModel]="sort()"
    (searchChange)="onSearch($event)"
    (pageModelChange)="onPage($event)"
    (refresh)="reload()" />
```

## Когда применять

- Приложение переезжает со списка первого кита и держит его договор: тот же ключ настроек, те же
  поля колонок, те же события наружу.

## Когда не применять

- **Одна таблица без поиска, страниц и настройки колонок** —
  [`rt-data-table`](./?path=/docs/organisms-first-kit-table-datatable-overview--docs).
- **Новый экран без наследства первого кита** — [`rt-table`](./?path=/docs/organisms-table-table--docs).

## Оси

| ось            | значения                                                | умолчание           |
| -------------- | ------------------------------------------------------- | ------------------- |
| загрузка       | записи на месте, первая загрузка, дозагрузка            | записи на месте     |
| пустой список  | ни строк ни условий, условие задано и ответ пуст        | ни строк ни условий |
| полоса страниц | всё помещается, три страницы, много страниц с разрывами | всё помещается      |
| строка отбора  | не показана, показана с заданным условием               | не показана         |
| выбор записей  | «отметить все», счётчик вместо него, выбор по одной     | «отметить все»      |
| узкая коробка  | шире таблицы, уже таблицы                               | шире таблицы        |

**Две загрузки выглядят по-разному.** Первая заменяет список крутилкой: показывать нечего.
Дозагрузка оставляет строки на месте и кладёт крутилку поверх них с подложкой — человек видит,
что список тот же, а не новый.

**Заглушку показывают только без строк и без условий отбора.** Пустой ответ на заданное условие —
это не пустой список: тогда видны таблица со строкой отбора и «снять отбор» в полосе действий.

**Полосы страниц нет вовсе, пока все записи помещаются на самую маленькую страницу.** Это приём
первого кита, и он перенесён как есть.

**Карточек у таблицы нет вовсе, и на узком ничего не переключается.** Строки остаются таблицей и
едут вбок своей прокруткой. История `Narrow` показывает именно это — узкую коробку, а не узкое
окно: порог кита это запрос к ширине окна, а окно показа узким не бывает.

## Края

| край                          | что происходит                                                              |
| ----------------------------- | --------------------------------------------------------------------------- |
| `isPaginationShown`           | список его принимает и ничем не меняет — полоса рисуется по своим правилам  |
| полосы прокрутки              | их размер список ставит на корень страницы: выбор общий на все списки рядом |
| смена страницы                | флажок страницы пересчитывается, когда новая страница приходит              |
| пустой ответ на условие       | флажок страницы при этом стоит отмеченным — странность первого кита         |
| исключения под «отметить все» | не уходят вместе с отметками: их очищает отдельная просьба приложения       |
| панель настройки колонок      | второе нажатие при открытой панели ничего не открывает                      |

## Состояния

| состояние       | чем задаётся        | что меняется                                     |
| --------------- | ------------------- | ------------------------------------------------ |
| первая загрузка | `loading`           | вместо списка крутилка                           |
| дозагрузка      | `fetching`          | строки на месте, поверх них крутилка с подложкой |
| пустой список   | нет строк и условий | заглушка «Записей нет» вместо таблицы            |
| записи отмечены | директивой выбора   | счётчик в полосе действий, флажки в строках      |

## Доступность

- «Отметить все» и флажки строк несут своё слово для скринридера, а отмеченность читается
  признаком `aria-checked`.
- Стрелки и номера полосы страниц — кнопки: недоступная страница недоступна и с клавиатуры.
- Набранное в поиске уходит приложению через полсекунды после остановки набора, а не на каждой
  букве: скринридер не зачитывает ответ на каждое нажатие.

## Оформление

По умолчанию список рисуется видом первого кита: материальный набор стоит на нём самом, и боковая
панель колонок и меню строки получают его же. Свой вид второго кита задаёт вход `look` или раздел
`dataTable` настроек кита; вид поиска и полей отбора по умолчанию — раздел `dataList`. Оба вида
стоят рядом в истории `Presets`, обе темы — в `Themes`; остальные истории показывают вид по
умолчанию под фиолетовой темой первого кита, как его витрина.

Истории `ManyItems`, `FewItems` и `NoItems` показывают весь список с тем же наполнением, что у
списка первого кита на его витрине: те же колонки, свои ячейки, кнопки в панели, действия строки.

## Рядом

- [`rt-data-table`](./?path=/docs/organisms-first-kit-table-datatable-overview--docs) — таблица внутри этого списка.
- [`rt-table`](./?path=/docs/organisms-table-table--docs) — таблица без наследства первого кита.

## Входы

| вход                        | тип                   | умолчание      | что делает                                                                           |
| --------------------------- | --------------------- | -------------- | ------------------------------------------------------------------------------------ |
| `look`                      | `'material' \| 'own'` | `'material'`   | вид семьи: как в первом ките или свой вид второго кита; умолчание — из настроек кита |
| `appearance`                | `'outline' \| 'fill'` | `'fill'`       | вид поля поиска; умолчание — из настроек кита, как у первого кита                    |
| `filterAppearance`          | `'outline' \| 'fill'` | `'outline'`    | вид полей отбора: рамка со всех сторон или залитое поле с чертой снизу               |
| `tableConfigStorageKey`     | `string`              | **обязателен** | ключ, под которым лежит настройка колонок                                            |
| `entities`                  | `ENTITY[]`            | **обязателен** | записи нынешней страницы                                                             |
| `pageModel`                 | `IPageModel`          | **обязателен** | нынешняя страница: номер, размер, всего записей                                      |
| `currentSortModel`          | `ISortModel \| null`  | **обязателен** | нынешний порядок                                                                     |
| `filterModel`               | `IFilterModel[]`      | `[]`           | нынешние условия отбора                                                              |
| `searchTerm`                | `string \| null`      | `''`           | что стоит в поле поиска                                                              |
| `keyExp`                    | `keyof ENTITY`        | `'id'`         | чем различаются записи                                                               |
| `loading`                   | `boolean`             | `false`        | первая загрузка: вместо списка крутилка                                              |
| `fetching`                  | `boolean`             | `false`        | дозагрузка: крутилка поверх строк                                                    |
| `isTableRowsClickable`      | `boolean`             | `false`        | отзывается ли строка на нажатие                                                      |
| `isFiltersShown`            | `boolean`             | `false`        | показывать ли строку отбора                                                          |
| `isRefreshButtonShown`      | `boolean`             | `true`         | показывать ли кнопку обновления                                                      |
| `isTableConfigButtonShown`  | `boolean`             | `true`         | показывать ли кнопку настройки колонок                                               |
| `isPaginationShown`         | `boolean`             | `true`         | принят ради переезда без правок и ничего не меняет                                   |
| `isMultiSelect`             | `boolean`             | `true`         | выбор многих или по одной — вход директивы выбора                                    |
| `isMultiSelectExtendedMod`  | `boolean`             | `true`         | отмечать ли не пришедшие страницы — вход директивы выбора                            |
| `isSelectAllSelectorShown`  | `boolean`             | `true`         | показывать ли «отметить все» — вход директивы выбора                                 |
| `isSelectorsColumnDisabled` | `boolean`             | `false`        | недоступна ли колонка выбора — вход директивы выбора                                 |
| `selectedEntitiesKeys`      | `Array<ENTITY[KEY]>`  | `[]`           | отметки, названные заранее — вход директивы выбора                                   |

## Выходы

| выход                | что сообщает                                   |
| -------------------- | ---------------------------------------------- |
| `searchChange`       | набранное в поиске, без пробелов по краям      |
| `pageModelChange`    | страница или её размер, которых просит человек |
| `sortChange`         | новый порядок                                  |
| `filterChange`       | новый набор условий отбора                     |
| `refresh`            | нажата кнопка обновления                       |
| `clearFiltersAction` | нажато «снять отбор»                           |
| `rowClick`           | нажатие на строку: запись и само событие       |
| `rowDoubleClick`     | двойное нажатие на строку с её записью         |

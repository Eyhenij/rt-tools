<Title>MarkdownText — `rt-markdown-text`</Title>

Текст, написанный разметкой, показанный узлами: заголовки, списки, таблицы, цитаты и код вместо
частокола знаков.

```html
<rt-markdown-text [text]="record.text" />
```

## Когда применять

- Чужой текст, который приехал целиком и написан разметкой: разбор происшествия, предложение,
  сводка.
- Показ в панели или на странице, где текст читают, а не правят.

## Когда не применять

- **Правка текста** — компонент только показывает; ввод разметки — дело редактора.
- **Строка списка** — там текст не показывают вовсе: страница со ста строками несла бы тексты
  всех своих записей.
- **Своя вёрстка вместо текста** — если содержимое собирает само приложение, оно рисует узлы
  напрямую, а не собирает строку разметки ради этого компонента.

## Входы

| вход   | тип              | умолчание      | что значит                                                   |
| ------ | ---------------- | -------------- | ------------------------------------------------------------ |
| `text` | `string \| null` | **обязателен** | Текст записи. Пустота и отсутствие значения не рисуют ничего |

Выходов нет.

## Оси

| ось               | значения                                                                    |
| ----------------- | --------------------------------------------------------------------------- |
| блоки разметки    | заголовок, абзац, список простой и нумерованный, цитата, таблица, блок кода |
| разметка в строке | жирный, курсив, зачёркнутый, код строкой, ссылка                            |
| вне перечня       | сырой HTML, картинка, ссылка чужой схемы, непарный знак                     |

Оси не перемножаются: род блока и род куска строки друг на друга не влияют — куски одинаковы
внутри любого блока.

## Состояния

| состояние            | что видно                                                              |
| -------------------- | ---------------------------------------------------------------------- |
| текст с разметкой    | узлы по перечню                                                        |
| текст без разметки   | один абзац, слово в слово                                              |
| текста нет           | ничего: ни пустого абзаца, ни отступа                                  |
| текст вне перечня    | сама разметка видна текстом, узла для неё не появляется                |
| длинная строка кода  | блок кода прокручивается вбок, ширина родителя остаётся прежней        |
| таблица шире колонки | таблица прокручивается вбок в своей обёртке, а не растягивает родителя |

Состояний наведения, фокуса и нажатия у компонента нет: он ничего не принимает от указателя.
Единственный интерактивный узел — ссылка, и она ведёт себя как обычная ссылка страницы.

## Доступность

- Заголовок объявлен ролью и уровнем: читалка видит уровень так же, как видит его глаз.
- Ссылка открывается отдельной вкладкой и несёт `rel="noopener noreferrer"`.
- Таблица собрана строкой заголовка и телом, поэтому читается таблицей, а не набором строк.
- Собственных подписей компонент не заводит — переводить в нём нечего.

## Оформление

Цвет, кегль и отступы берутся у шкал кита и меняются вместе с темой. Своих свойств у блока два —
скругление кода и толщина рамки таблицы; переопределяются они правилом на самом блоке.

## Рядом

- `rt-collapsible-text` — свой текст приложения, свёрнутый до нескольких строк.
- `rt-rich-editor` — ввод размеченного текста, а не показ чужого.

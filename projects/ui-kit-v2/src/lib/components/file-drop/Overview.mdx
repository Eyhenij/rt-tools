<Title>FileDrop — `rt-file-drop`</Title>

Область приёма файлов перетаскиванием. Оборачивает любое содержимое и, пока над ней тащат файл,
показывает подсказку поверх него. Сами файлы компонент не хранит — он только сообщает, что их
бросили.

```html
<rt-file-drop accept=".pdf" [zones]="zones" (filesDropped)="attach($event)" (zoneFilesDropped)="attachTo($event)">
    <app-form />
</rt-file-drop>
```

## Когда применять

- Файлы прикладывают перетаскиванием к целому экрану или к его части: карточка заявки, форма.
- Файл надо разложить по назначению — тогда с зонами: документы отдельно, фотографии отдельно.

## Когда не применять

- **Выбор файлов кнопкой** — [`rt-file-input`](./?path=/docs/components-fileinput-overview--docs):
  перетаскивание не единственный способ, и на сенсорном экране его нет вовсе.
- **Показ уже приложенных файлов** — [`rt-file-card`](./?path=/docs/components-filecard-overview--docs).

## Оси

| ось                 | значения                              | умолчание    |
| ------------------- | ------------------------------------- | ------------ |
| область в покое     | обычная, отключена                    | обычная      |
| под перетаскиванием | подпись кита, своя подпись, отключена | подпись кита |
| зоны                | две, три                              | без зон      |

**Подсветку рисует не вход, а признак, который компонент поднимает сам**, поймав перетаскивание.
Ни контролом, ни ячейкой сетки до неё не добраться — в витрине жест повторяет `play`-функция:
она посылает событие перетаскивания с настоящим файлом внутри, как это делает браузер.

**В покое отключённость не видна намеренно.** Область в покое — это её содержимое и ничего
больше; разница появляется только под перетаскиванием, где отключённая не показывает подсказки.

**Оси, которых не видно.** `accept` отсекает файлы не того типа **после** сброса: на вид области
это никак не влияет, и отбрасывание молчаливое — как у самого файлового выбора.

## Состояния

| состояние         | чем задаётся            | что меняется                             |
| ----------------- | ----------------------- | ---------------------------------------- |
| покой             | —                       | видно только содержимое                  |
| перетаскивание    | файл тащат над областью | подсказка поверх содержимого             |
| зона под курсором | координата курсора      | подсвечена та полоса, над которой курсор |
| отключена         | вход `disabled`         | подсказки нет, файлы не принимаются      |

**Уход курсора гасит подсказку не сразу** (80 мс). Без задержки рамка мерцала бы при переходе
между дочерними элементами области.

**С зонами общего события сброса не бывает** — зона обязана быть названа. Без зон, наоборот,
приходит только общее.

Зона выбирается долей от высоты области. Пока высоты нет (первый кадр, скрытая вкладка), выбор
детерминирован — первая зона, а не отказ: файл терять нельзя.

## Доступность

- Подсказка объявлена скрытой от читалок (`aria-hidden`): она — отклик на жест мышью, и озвучивать
  её нечего.
- Подсказка не перехватывает указатель, иначе события перетаскивания не доходили бы до области.
- **Перетаскивание — не единственный способ приложить файл.** Рядом должен стоять
  [`rt-file-input`](./?path=/docs/components-fileinput-overview--docs): с клавиатуры и с
  сенсорного экрана перетащить нельзя.

## Оформление

Подсказка — приглушающий слой поверх содержимого с рамкой-приглашением; в многозонном режиме
слой делится на вертикальную стопку **равных** зон с подписями, и зона под курсором
подсвечивается.

## Входы

| вход           | тип               | умолчание                        |
| -------------- | ----------------- | -------------------------------- |
| `disabled`     | `boolean`         | `false`                          |
| `overlayLabel` | `string`          | `''` → `rtKit.uiFileDropOverlay` |
| `zones`        | `readonly Zone[]` | `[]`                             |
| `accept`       | `string`          | `''`                             |

`accept` пишется как у файлового выбора: `.pdf`, `image/png`, `image/*` через запятую.

## Выходы

| выход              | тип                 | когда                                       |
| ------------------ | ------------------- | ------------------------------------------- |
| `filesDropped`     | `File[]`            | сброс **без зон**, после отсева по `accept` |
| `zoneFilesDropped` | `{ zoneId, files }` | сброс **с зонами**, с именем зоны           |
| `draggingChange`   | `boolean`           | подсветка появилась или пропала             |

Пустой после отсева сброс события не поднимает.

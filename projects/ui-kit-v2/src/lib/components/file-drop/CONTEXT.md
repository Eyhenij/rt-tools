# `rt-file-drop`

Область приёма файлов перетаскиванием. Оборачивает любое содержимое и показывает подсказку
поверх него.

```html
<rt-file-drop accept=".pdf" [zones]="zones" (filesDropped)="attach($event)" (zoneFilesDropped)="attachTo($event)">
    <app-form />
</rt-file-drop>
```

| вход           | тип               | умолчание                  |
| -------------- | ----------------- | -------------------------- |
| `disabled`     | `boolean`         | `false`                    |
| `overlayLabel` | `string`          | `''` → `uiFileDropOverlay` |
| `zones`        | `readonly Zone[]` | `[]`                       |
| `accept`       | `string`          | `''`                       |

Выходы: `filesDropped` (`File[]`), `zoneFilesDropped` (`{ zoneId, files }`), `draggingChange`.

## Главное, что нужно знать

**С зонами общее событие сброса не поднимается** — зона обязана быть названа. Без зон, наоборот,
приходит только `filesDropped`.

**Уход курсора гасит подсказку не сразу** (80 мс). Без задержки рамка мерцала бы при переходе
между дочерними элементами области.

**Файлы не того типа отсекаются по `accept`**, и пустой после фильтра сброс события не поднимает.

## Края

- Зона выбирается долей от высоты области. Пока высоты нет (первый кадр, скрытая вкладка),
  выбор детерминирован — первая зона, а не отказ: файл терять нельзя.
- Отключённая область не показывает подсказку и не принимает файлы.

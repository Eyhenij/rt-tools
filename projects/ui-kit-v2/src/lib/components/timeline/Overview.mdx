<Title>Timeline — `rt-timeline`</Title>

Лента состоявшихся событий: точка на каждое, соединительная линия между ними, подпись со
временем и исполнителем. Порядок событий — часть смысла, поэтому лента рисуется тегом `<ol>`, а
не набором блоков.

```html
<rt-timeline [steps]="history()" />
```

## Когда применять

- Журнал того, что уже произошло: движение заявки, история правок, цепочка согласований.
- Показ, где процесс стоит сейчас, когда позади — состоявшиеся шаги с временем.

## Когда не применять

- **Линейный прогресс к цели** — [`rt-stepper`](./?path=/docs/atoms-feedback-stepper-overview--docs):
  там доля пройденного, а не перечень событий.
- **Список без порядка** — [`rt-detail-list`](./?path=/docs/molecules-data-detaillist-overview--docs) или
  обычный список: соединительная линия в нём соврёт про последовательность.

## Оси

| ось                   | значения                         | умолчание |
| --------------------- | -------------------------------- | --------- |
| состояние шага        | `complete`, `current`, `pending` | —         |
| время (`meta`)        | есть, нет                        | нет       |
| исполнитель (`actor`) | есть, нет                        | нет       |

Состояния показаны одной лентой, где стоят все три сразу: порознь не видно, чем полая точка
отличается от заполненной. `meta` и `actor` необязательны и рисуются по отдельности —
исполнитель без времени допустим.

## Края

| край            | что происходит                                                                      |
| --------------- | ----------------------------------------------------------------------------------- |
| один шаг        | соединительной линии нет вовсе                                                      |
| последний шаг   | линия под ним не рисуется: хвост читался бы как «продолжение есть»                  |
| пустой набор    | рисуется пустой `<ol>`, а не заглушка — текст «событий нет» подставляет потребитель |
| длинная подпись | переносится по словам, точка остаётся у первой строки                               |

## Состояния

Состояний взаимодействия у ленты нет: события не нажимаются и фокус не берут. Наведение и
фокус в матрицах не показаны не по недосмотру — их нет в стилях.

Состояние шага дублируется атрибутом `data-status` — по нему шаг находят проверки.

## Доступность

- Лента — нативный `<ol>`: порядок и число пунктов скринридер читает сам.
- Состояние шага передаётся текстом подписи, а не только цветом точки.

## Оформление

Пройденный шаг — заполненная точка, текущий — увеличенная и подсвеченная, предстоящий — полая.
Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-stepper`](./?path=/docs/atoms-feedback-stepper-overview--docs) — линейный прогресс к цели.

## Входы

| вход    | тип                           | умолчание | что делает                                            |
| ------- | ----------------------------- | --------- | ----------------------------------------------------- |
| `steps` | `readonly IRtTimeline.Step[]` | `[]`      | события ленты: подпись, время, исполнитель, состояние |

Выходов у компонента нет: события не нажимаются, и сообщать наружу нечего.

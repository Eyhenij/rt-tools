# `rt-timeline`

```html
<rt-timeline
    [steps]="[
    { label: 'Заявка создана', meta: '12 марта, 10:00', actor: 'Иванов', status: 'complete' },
    { label: 'На проверке', meta: '12 марта, 12:30', status: 'current' },
    { label: 'Решение', status: 'pending' },
]" />
```

| вход    | тип                                           | умолчание |
| ------- | --------------------------------------------- | --------- |
| `steps` | `readonly { label, meta?, actor?, status }[]` | `[]`      |

`status` — `'complete' \| 'current' \| 'pending'`. Выходов нет: лента только показывает.

## Главное, что нужно знать

**Порядок шагов — часть смысла**, поэтому лента рисуется тегом `<ol>`, а не набором блоков.

Соединительная линия рисуется **между** пунктами и не рисуется после последнего: хвост под
последним шагом читался бы как «продолжение есть».

## Края

- `meta` и `actor` необязательны и рисуются по отдельности: исполнитель без времени допустим.
- Состояние дублируется атрибутом `data-status` — по нему шаг находят проверки.
- Пустой набор рисует пустой `<ol>`, а не заглушку: текст «событий нет» подставляет потребитель.

# `rt-stepper`

Полоса прогресса по шагам: точки, подпись текущего шага и его описание.

```html
<rt-stepper [steps]="[{ label: 'Заявка', description: 'Заполните данные' }, …]" [currentIndex]="1" />
```

| вход           | тип                                 | умолчание      |
| -------------- | ----------------------------------- | -------------- |
| `steps`        | `readonly { label, description }[]` | `[]`           |
| `currentIndex` | `number \| string`                  | `0`            |
| `orientation`  | `'horizontal' \| 'vertical'`        | `'horizontal'` |

Выходов нет — шаги переключает потребитель. Описание шага необязательно.

Полоса тянется по ширине места, от узкой панели в 280 px до любой. Шагов сколько угодно, текущий —
любой.

## Цвета

Цвета — свойства хоста `rt-stepper`. Приложение переопределяет их правилом на `rt-stepper` или на
родителе; по умолчанию стоят токены темы.

| свойство                              | что красит                    | умолчание                     |
| ------------------------------------- | ----------------------------- | ----------------------------- |
| `--rt-stepper-track-color`            | трек и будущие точки          | `--rt-color-stepper-track`    |
| `--rt-stepper-progress-color`         | заполнение и пройденные точки | `--rt-color-stepper-progress` |
| `--rt-stepper-current-color`          | текущая точка                 | `--rt-color-stepper-current`  |
| `--rt-stepper-label-color`            | подпись текущего шага         | `--rt-stepper-current-color`  |
| `--rt-stepper-description-color`      | описание под полосой          | `--rt-color-text-primary`     |
| `--rt-stepper-point-shadow`           | ореол текущей точки           | `--rt-shadow-step-indicator`  |
| `--rt-stepper-line-color`             | линия между метками списка    | `--rt-color-border-default`   |
| `--rt-stepper-step-label-color`       | подпись шага в списке         | `--rt-color-text-primary`     |
| `--rt-stepper-step-description-color` | описание шага в списке        | `--rt-color-text-muted`       |
| `--rt-stepper-mark-<состояние>-bg`    | фон метки списка              | по состоянию                  |
| `--rt-stepper-mark-<состояние>-color` | цифра метки списка            | по состоянию                  |

Состояния метки: `complete`, `current`, `upcoming`, `neutral`.

## Вертикальный список

`orientation="vertical"` рисует `<ol>`: метка с номером, подпись, описание, линия между метками.
Номер ниже нуля даёт инструкцию: все метки нейтральные, `aria-current` нет ни у одного шага.
Подпись можно заменить шаблоном `ng-template[rtStepLabel]`; в его контексте `$implicit` — шаг,
`index` — номер с нуля. Полоса и её зажим номера к вертикальному списку не относятся.

## Главное, что нужно знать

**Заполнение считается по промежуткам, а не по шагам.** Первый шаг даёт 0 %, последний — 100 %:
при трёх шагах середина это 50 %. Единственный шаг всегда даёт 0 % — делить не на что.

Номер шага за пределами набора зажимается **один раз, до всего остального**: и полоса, и якорь
подписи, и объявление для скринридера читают уже зажатый индекс. Иначе показ и объявление
расходятся — полоса упирается в 100 %, а на прогрессбаре оказывается `aria-valuenow` больше
`aria-valuemax`, и подпись шага пропадает. Пустой набор объявляется нулём.

## Края

- Описание разбивается на абзацы по пустой строке (`\n\n`); пустое описание не создаёт абзаца.
- Точки спрятаны от скринридера — прогресс он читает с самой полосы: `role="progressbar"`,
  `aria-valuemin/max/now` и `aria-valuetext` с подписью текущего шага.
- Подпись текущего шага стоит в отрезке полосы: на первом шаге вся полоса и прижим к началу, на
  последнем — к концу, на среднем отрезок с центром над точкой шириной в два расстояния до ближнего
  края. За полосу подпись не выходит, длинная переносится и растит полосу вниз. Так же собран макет.

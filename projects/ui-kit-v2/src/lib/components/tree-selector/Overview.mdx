<Title>TreeSelector — `rt-tree-selector`</Title>

Выбор деревом с поиском: поле поиска, строка контролов и [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs)
под ними. Выбор пишется сразу или копится в черновике до «Применить». Где селектор стоит — на
странице, в боковой панели или во всплывающем окне, — решает приложение; высоту он берёт у места.

```html
<rt-tree-selector ariaLabel="Справочник" [nodes]="accounts" [(value)]="chosen" />

<rt-aside title="Гостиницы">
    <rt-tree-selector
        #selector
        confirm
        expandControls
        revertable
        multiToggle
        [footer]="false"
        [emptyAllowed]="false"
        [nodes]="hotels"
        [(value)]="hotelIds">
        <ng-template rtTreeSelectorControls>
            <button rtButton size="sm" appearance="outlined" [label]="groupingLabel" (click)="openGrouping()"></button>
        </ng-template>
    </rt-tree-selector>
</rt-aside>
```

Во второй форме кнопки рисует боковая панель: «Применить» зовёт `selector.apply()` и выключено,
пока `selector.canApply()` ложно.

## Когда применять

- Выбор из иерархии, где нужен поиск, а то и кнопки «развернуть всё» и «свернуть всё»: справочники,
  гостиницы по странам и городам, отчёты по группам.
- Выбор, который должен уйти одним действием, — подтверждаемая форма с «Применить».

## Когда не применять

- **Дерево без поиска и контролов** — [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs).
- **Выбор в поле формы** — [`rt-multiselect`](./?path=/docs/molecules-forms-multiselect-overview--docs):
  то же дерево вариантов в выпадающей панели.

## Оси

| ось                 | значения                                                     | умолчание     |
| ------------------- | ------------------------------------------------------------ | ------------- |
| форма               | прямая, подтверждаемая                                       | прямая        |
| подвал              | свой, кнопки приложения                                      | свой          |
| пустой выбор        | разрешён, запрещён                                           | разрешён      |
| поиск               | пусто, слова, ничего не нашлось                              | пусто         |
| строка контролов    | раскрытие; очистка; откат; переключатель; контрол приложения | пусто         |
| режим               | `multiple`, `single`, `none`                                 | `multiple`    |
| раскрытие на старте | над выбранным, всё, ничего                                   | над выбранным |

Поиск оставляет узлы, в которых нашлось каждое слово — в подписи, описании или метках. Совпавшая
группа остаётся со всеми детьми, остальные группы — путём к совпадениям; пока строка набрана, всё
раскрыто. История **Search** показывает три случая.

В подтверждаемой форме «Применить» выключено, пока черновик равен выбору, и пока он пуст там, где
пустой выбор запрещён. «Отмена» возвращает черновик к выбору. В режиме `single` Enter на узле
применяет его сразу, а Enter на уже выбранном узле закрывает без изменений.

Кнопки строки контролов иконочные и стоят у левого края, контролы приложения прижаты к правому. «Развернуть всё» и «свернуть всё» просит `expandControls`,
очистку с корзиной — `clearable`, откат — `revertable`. Откат возвращает черновик к выбору и не
закрывает селектор. Он есть только в подтверждаемой форме и выключен, пока черновик равен выбору.

Переключатель множественного выбора выключен — клик оставляет один узел, Ctrl или Cmd добавляет.
Включён — клик добавляет. Без переключателя клик всегда добавляет.

Каждая история стоит парой половин под двумя наборами оформления.

**Оси, которых не видно.** `ariaLabel` уходит в атрибут дерева. Выходы ничего не рисуют.
Раскрытие на старте и переключение множественного выбора видно в **Playground**.

## Состояния

Своих состояний взаимодействия у селектора нет: наведение, фокус и выключенность принадлежат
частям — полю поиска, кнопкам и строкам дерева, и они показаны в историях этих частей.

| состояние           | чем задаётся         | что меняется                     |
| ------------------- | -------------------- | -------------------------------- |
| черновик не изменён | подтверждаемая форма | «Применить» и откат выключены    |
| черновик изменён    | клик по узлу         | «Применить» и откат включены     |
| ничего не нашлось   | строка поиска        | дерево пишет «Ничего не найдено» |
| выбор пуст          | —                    | кнопки «Очистить выбор» нет      |

## Клавиатура

Фокус стоит в поле поиска с первого кадра и не уходит из него. Стрелки, пробел, Enter и боковые
стрелки поле передаёт дереву — `rt-tree.handleKeydown`; клавиша, которую дерево не взяло,
набирается как обычно.

## Доступность

- Поле поиска подписано подписью кита «Search…».
- У кнопок контролов и подвала есть `aria-label` с их подписью. У иконочных та же подпись стоит
  подсказкой.
- Доступное имя дерева даёт вход `ariaLabel`.

## Оформление

| свойство                          | что задаёт         | умолчание                |
| --------------------------------- | ------------------ | ------------------------ |
| `--rt-tree-selector-border-width` | черта над подвалом | `--rt-border-width-thin` |

На узком экране контролы переносятся на вторую строку; дерево прокручивается внутри, поле поиска
и подвал стоят на месте.

## Входы

| вход             | тип                                | умолчание    |
| ---------------- | ---------------------------------- | ------------ |
| `nodes`          | `ReadonlyArray<IRtTree.Node<T>>`   | обязателен   |
| `value`          | `ReadonlyArray<T>`                 | `[]`         |
| `mode`           | `'multiple' \| 'single' \| 'none'` | `'multiple'` |
| `cascade`        | `boolean`                          | `true`       |
| `branchMarks`    | `boolean`                          | `true`       |
| `selectAll`      | `boolean`                          | `true`       |
| `confirm`        | `boolean`                          | `false`      |
| `footer`         | `boolean`                          | `true`       |
| `emptyAllowed`   | `boolean`                          | `true`       |
| `expandControls` | `boolean`                          | `false`      |
| `clearable`      | `boolean`                          | `false`      |
| `revertable`     | `boolean`                          | `false`      |
| `multiToggle`    | `boolean`                          | `false`      |
| `multiDefault`   | `boolean`                          | `false`      |
| `expandOnStart`  | `'chosen' \| 'all' \| 'none'`      | `'chosen'`   |
| `label`          | `string`                           | `''`         |
| `searchTerm`     | `string`                           | `''`         |
| `ariaLabel`      | `string \| null`                   | `null`       |

## Выходы

| выход         | что несёт          | когда                                                   |
| ------------- | ------------------ | ------------------------------------------------------- |
| `valueChange` | `ReadonlyArray<T>` | выбор изменился — пара к `value`                        |
| `applied`     | `ReadonlyArray<T>` | подтверждаемая форма: черновик применён                 |
| `cancelled`   | —                  | подтверждаемая форма: «Отмена» или Enter на том же узле |

Открыты `canApply`, `apply()` и `cancel()`: ими пользуется приложение, которое рисует свои кнопки.

## Рядом

- [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs) — дерево, которое селектор рисует внутри.
- [`rt-aside`](./?path=/docs/organisms-aside-aside-overview--docs) — боковая панель, куда селектор ставят с подтверждением.

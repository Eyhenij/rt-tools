# `rt-theme-toggle`

Переключатель светлой и тёмной темы.

```html
<rt-theme-toggle appearance="icon" />
```

| вход         | тип                  | умолчание |
| ------------ | -------------------- | --------- |
| `appearance` | `'icon' \| 'switch'` | `'icon'`  |

Выходов нет.

## Главное, что нужно знать

**Своего состояния у контрола нет — тему держит [`ThemeService`](../../platform/theme.service.ts).**
Он пишет `data-theme` на `<html>` и сохраняет выбор в хранилище устройства, поэтому тема
переживает перезагрузку, а два переключателя на странице всегда согласованы.

**Иконка показывает, куда переключит**, а не текущее состояние: в светлой теме это луна.
В виде кнопки текущая тёмная тема помечается `aria-pressed="true"`.

## Края

- Подпись берётся из словаря кита (`rtKit.themeToggleLabel`) и вычисляется один раз при создании.
- В тестах между случаями надо чистить хранилище: иначе выбор предыдущего теста становится
  начальным состоянием следующего.

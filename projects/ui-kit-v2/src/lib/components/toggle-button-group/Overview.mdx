<Title>ToggleButtonGroup — `rt-toggle-button-group`</Title>

Сегментированная группа: один выбранный вариант из нескольких, все видны сразу. Состояния группа
не держит — нажатие только просит сменить значение.

```html
<rt-toggle-button-group
    ariaLabel="Период"
    [options]="[{ value: 'day', label: 'День' }, { value: 'week', label: 'Неделя' }]"
    [value]="period()"
    (valueChange)="period.set($event)" />
```

## Когда применять

- Три-пять взаимоисключающих вариантов, между которыми переключаются часто: период, вид списка,
  режим показа.
- Панель над таблицей или в тулбаре, где выбор должен читаться без раскрытия.

## Когда не применять

- **Вариантов больше пяти или они длинные** — [`rt-select`](./?path=/docs/components-select--docs):
  сегменты перестанут помещаться в строку.
- **Нужен тот же выбор и на узком экране** —
  [`rt-filter-control`](./?path=/docs/components-filtercontrol-overview--docs): он сам подменит
  сегменты списком.
- **Несколько значений сразу** — набор [`rt-checkbox`](./?path=/docs/components-checkbox-overview--docs).

## Оси

| ось               | значения                                         | умолчание      |
| ----------------- | ------------------------------------------------ | -------------- |
| размер            | `sm`, `md`, `lg` — 30 / 40 / 50 px               | `sm`           |
| наполнение        | только подписи, иконка и подпись, пять сегментов | —              |
| выбранный сегмент | ничего, первый, средний, последний               | ничего         |
| ширина            | по содержимому, `fullWidth`                      | по содержимому |

**Выбранный сегмент — отдельная ось.** У крайних кнопок скругление своё (модификаторы `--first`
и `--last`), поэтому подсветка первого, среднего и последнего выглядит по-разному, и одной
ячейки «что-то выбрано» недостаточно. Отдельно показано «ничего не выбрано»: `value`, не
совпавшее ни с одной опцией, — обычное состояние, а не ошибка.

**Ось, которую нельзя показать статикой.** `title` варианта превращается во всплывающую
подсказку и до наведения не отрисован.

## Состояния

| состояние       | чем задаётся                    | что меняется                                 |
| --------------- | ------------------------------- | -------------------------------------------- |
| обычное         | —                               | прозрачный сегмент на общей подложке         |
| наведение       | `:hover:not(:disabled, active)` | подложка сегмента                            |
| нажатие         | —                               | **ничего:** своего `:active` у сегмента нет  |
| фокус с клавиши | `:focus-visible`                | кольцо `--rt-shadow-focus-ring`              |
| выбран          | `value` совпало с опцией        | заливка `--rt-toggle-button-group-active-bg` |
| отключено       | вход `disabled`                 | гаснет группа целиком, включая выбранный     |

Отключение принадлежит группе, а не сегменту: погасить один вариант из пяти нельзя — такой
опции просто не должно быть в наборе.

**Группа не держит состояния.** Повторное нажатие по выбранному тоже поднимает `valueChange`;
снимать выбор она не умеет. Подсветка сдвинется, когда потребитель вернёт новое `value`.

## Доступность

- Обёртка объявлена `role="group"` с `aria-label`; каждый сегмент — нативная `<button>` с
  `aria-pressed`, поэтому клавиатура и озвучка достаются от браузера.
- Иконка сегмента — оформление: выбор читается из `aria-pressed`, а не из неё.
- Размер иконки выводится из размера группы: `sm` → 12px, `md` и `lg` → 16px.

## Оформление

Подложка и сегменты — элементы блока `rt-toggle-button-group`; заливка выбранного берётся из
`--rt-toggle-button-group-active-bg`, кольцо фокуса — из `--rt-shadow-focus-ring`. Высота ступеней
совпадает с [`[rtButton]`](./?path=/docs/components-button-overview--docs), чтобы группа
выравнивалась с кнопками в одном ряду.

## Входы

| вход        | тип                                              | умолчание      |
| ----------- | ------------------------------------------------ | -------------- |
| `options`   | `ReadonlyArray<{ value, label, icon?, title? }>` | **обязателен** |
| `value`     | `T \| undefined`                                 | `undefined`    |
| `ariaLabel` | `string \| null`                                 | `null`         |
| `size`      | `'sm' \| 'md' \| 'lg'`                           | `'sm'`         |
| `disabled`  | `boolean`                                        | `false`        |
| `fullWidth` | `boolean`                                        | `false`        |

## Выходы

| выход         | когда                                                                  |
| ------------- | ---------------------------------------------------------------------- |
| `valueChange` | нажатие по любому сегменту, включая уже выбранный — со значением опции |

<Title>DataTable — `rt-data-table`</Title>

Таблица записей первого кита во втором: шапка, строка отбора, готовые ячейки по виду колонки,
колонка выбора и полоса действий в конце строки. Колонки приходят не входом, а от службы настроек.

```html
<rt-data-table
    rtDataTableSelectors
    [entities]="rows()"
    [currentSortModel]="sort()"
    [filterModel]="filters()"
    [isFiltersShown]="true"
    [isSelectorColumnShown]="true"
    (sortChange)="onSort($event)"
    (filterChange)="onFilter($event)">
    <ng-template rtDataTableRowActions let-row>
        <rt-menu-item label="Открыть" icon="ico-eye" />
    </ng-template>
</rt-data-table>
```

## Когда применять

- Приложение переезжает с таблицы первого кита и держит её договор: те же поля колонок, те же
  сохранённые настройки.

## Когда не применять

- **Новый экран без наследства первого кита** — [`rt-table`](./?path=/docs/organisms-table-table--docs):
  колонки объявляются разметкой, на узком экране она сама переходит на карточки.
- **Реквизиты одного объекта** — [`rt-detail-list`](./?path=/docs/molecules-data-detaillist--docs).

## Оси

| ось             | значения                                                     | умолчание   |
| --------------- | ------------------------------------------------------------ | ----------- |
| вид колонки     | текст, деньги, доля, дата, признак, набор меток, своя ячейка | текст       |
| порядок строк   | без порядка, по возрастанию, по убыванию                     | без порядка |
| строка отбора   | не показана, показана, условие задано                        | не показана |
| колонка выбора  | нет, выбор многих, выбор по одной, недоступна                | нет         |
| действия строки | нет, меню строки скрыто, строка наведена — меню проявилось   | нет         |
| нажимаемость    | обычная, отзывается на нажатие                               | обычная     |

**Колонки приходят от службы настроек, а не входом.** `RtDataTableConfigService` объявляет и
наполняет приложение; таблица её только читает. Поэтому каждая ячейка матрицы несёт свою службу и
свой ключ хранения: под общим ключом настройка одной ячейки досталась бы соседним.

**Заданное условие отбора строк не сужает.** Таблица сообщает приложению набор условий, а какие
строки прислать в ответ — решает приложение. В матрице третья ячейка стоит именно за этим.

**Полоса действий строки скрыта, пока строка не наведена.** В неподвижном кадре наведения не
поймать, и матрица ставит его признаком витрины: третья ячейка — та же вторая под наведением.

**Ось нажимаемости в кадре не видна, и это объявлено, а не пропущено.** Нажимаемая строка
отличается от обычной только указателем-рукой; ни фона, ни рамки она не меняет — как в первом
ките. Обе ячейки матрицы поэтому выглядят одинаково, и различие названо подписями.

## Края

| край                                      | что происходит                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------------ |
| колонка вида `custom` без шаблона         | ячейка пустая: готовую таблица в ней не берёт                                  |
| вид колонки и значение                    | вид не форматирует: без `transform` в ячейке стоит то, что лежит в записи      |
| `filtering`, `href`, `className`, `fixed` | описание колонки их принимает и ничем не меняет — как в первом ките            |
| смена строк                               | флажок страницы остаётся прежним, пока список не попросит его пересчитать      |
| пустая страница                           | флажок страницы стоит отмеченным: «неотмеченных строк нет» — как в первом ките |
| выбор по одной                            | рисуется радиокнопка, флажка страницы в шапке нет                              |
| отметки, названные заранее                | ставятся один раз — к первым непустым строкам                                  |
| размер полос прокрутки                    | приходит с корня страницы: туда его ставит список по сохранённой настройке     |

## Состояния

| состояние          | чем задаётся                | что меняется                               |
| ------------------ | --------------------------- | ------------------------------------------ |
| строка наведена    | указателем                  | проявляется полоса действий в конце строки |
| строка нажимаема   | `isTableRowsClickable`      | указатель-рука, нажатие уходит приложению  |
| строка отмечена    | директивой выбора           | флажок или радиокнопка в колонке выбора    |
| колонка недоступна | `isSelectorsColumnDisabled` | флажки не нажимаются                       |

## Доступность

- Флажок строки и флажок страницы несут своё слово для скринридера, и отмеченность читается
  признаком `aria-checked`: оба рисуются кнопкой, а не полем ввода.
- Нажатие на строку приходит по опусканию кнопки указателя — так двойное нажатие приходит после
  двух одинарных, а не вместо них.
- Нажатие в ячейке выбора и на кнопке меню строки до строки не доходит: обе помечены признаком
  `rt-data-table-stop-row-click`.

## Оформление

По умолчанию таблица рисуется видом первого кита: материальный набор стоит на ней самой, и меню
строки получает его же. Свой вид второго кита задаёт вход `look` или раздел `dataTable` настроек
кита. Оба вида стоят рядом в истории `Presets`, обе темы — в `Themes`; остальные истории показывают
вид по умолчанию под фиолетовой темой первого кита, как его витрина.

## Рядом

- [`rt-data-list`](./?path=/docs/organisms-first-kit-table-datalist-overview--docs) — список вокруг этой таблицы:
  полоса действий, страницы, настройка колонок.
- [`rt-table`](./?path=/docs/organisms-table-table--docs) — таблица без наследства первого кита.

## Входы

| вход                        | тип                   | умолчание      | что делает                                                                           |
| --------------------------- | --------------------- | -------------- | ------------------------------------------------------------------------------------ |
| `look`                      | `'material' \| 'own'` | `'material'`   | вид семьи: как в первом ките или свой вид второго кита; умолчание — из настроек кита |
| `filterAppearance`          | `'outline' \| 'fill'` | `'outline'`    | вид полей отбора: рамка со всех сторон или залитое поле с чертой снизу               |
| `entities`                  | `ENTITY[]`            | **обязателен** | строки, которые таблица рисует                                                       |
| `currentSortModel`          | `ISortModel \| null`  | **обязателен** | нынешний порядок: по нему рисуются стрелки шапки                                     |
| `filterModel`               | `IFilterModel[]`      | `[]`           | нынешние условия отбора                                                              |
| `keyExp`                    | `keyof ENTITY`        | `'id'`         | чем различаются строки: им идёт слежение и отметки                                   |
| `isFiltersShown`            | `boolean`             | `false`        | показывать ли строку отбора                                                          |
| `isTableRowsClickable`      | `boolean`             | `false`        | отзывается ли строка на нажатие                                                      |
| `entity`                    | `ENTITY`              | **обязателен** | запись строки — вход директивы нажатия строки                                        |
| `isTableRowClickable`       | `boolean`             | `true`         | отзывается ли эта строка — вход директивы нажатия                                    |
| `isMultiSelect`             | `boolean`             | `true`         | выбор многих или по одной — вход директивы выбора                                    |
| `isSelectorColumnShown`     | `boolean`             | `false`        | показывать ли колонку выбора — вход директивы выбора                                 |
| `isSelectorsColumnDisabled` | `boolean`             | `false`        | недоступна ли колонка выбора — вход директивы выбора                                 |
| `selectedEntitiesKeys`      | `Array<ENTITY[KEY]>`  | `[]`           | отметки, названные заранее — вход директивы выбора                                   |

## Выходы

| выход            | что сообщает                             |
| ---------------- | ---------------------------------------- |
| `rowClick`       | нажатие на строку: запись и само событие |
| `rowDoubleClick` | двойное нажатие на строку с её записью   |
| `sortChange`     | новый порядок, которого просит человек   |
| `filterChange`   | новый набор условий отбора               |

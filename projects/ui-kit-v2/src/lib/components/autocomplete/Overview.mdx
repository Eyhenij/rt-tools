<Title>Autocomplete — `rt-autocomplete`</Title>

Поле с подсказками. **Ищет потребитель**, а компонент только сообщает, что набрано: на каждый
ввод длиной не меньше `minLength` он поднимает `(complete)` и рисует то, что ему вернули в
`suggestions`. В форме лежит выбранный объект, а не набранная строка.

```html
<rt-autocomplete
    [suggestions]="found()"
    [displayWith]="cityLabel"
    [minLength]="2"
    [formControl]="city"
    (complete)="search($event.query)"
    (itemSelect)="onPicked($event)" />
```

## Когда применять

- Набор велик или живёт на сервере: адрес, контрагент, товар.
- Списку нужен поиск по мере ввода, а не прокрутка готового перечня.

## Когда не применять

- **Набор известен заранее** — [`rt-select`](./?path=/docs/components-select-overview--docs):
  раскрывающийся список не требует ни запроса, ни набора текста.
- **Несколько значений** — [`rt-multiselect`](./?path=/docs/components-multiselect-overview--docs).
- **Свободный ввод** — [`rt-input`](./?path=/docs/components-input-overview--docs). Набранный
  текст здесь **не становится значением**: значение появляется только при выборе подсказки.

## Оси

Оси не перемножаются: размер, наполненность и рамка меняют разные части поля и вместе ничего
нового не показывают.

| ось           | значения                                              | умолчание |
| ------------- | ----------------------------------------------------- | --------- |
| размер        | `sm`, `md`, `lg` — 32 / 40 / 48 px                    | `md`      |
| наполненность | пусто, со значением, со значением и иконкой           | пусто     |
| рамка         | видна, снята (`bordered=false`)                       | видна     |
| панель        | подсказки, своя разметка подсказки, ничего не найдено | подсказки |

**Оси, которых не видно.** `minLength` и `openOnFocus` меняют не вид, а момент раскрытия:
первый — сколько символов надо набрать, второй — раскрывать ли уже при фокусе. Показать их
сеткой нечем; `openOnFocus` показан отдельной историей `Playground → OpenOnFocus`. `controlId`
и `ariaLabel` уходят в атрибуты.

**Панель показана отдельными историями, и открытая панель в истории ровно одна.** Открывает её
набор текста, а не щелчок: щелчком поле с подсказками не раскрывается.

**Подсказки в витрине не ищутся.** Обёртка держит готовый набор и на `(complete)` не отвечает:
искать — дело потребителя, и подменять это витриной значило бы показывать поведение, которого
у компонента нет.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у коробки поля нет     |
| фокус внутри  | `:focus-within`                      | рамка фокуса и `--rt-input-focus-shadow`           |
| раскрыто      | панель открыта                       | рамка фокуса                                       |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | контрол подменяется плоским текстом                |

Фокус ловится `:focus-within`, а не `:focus-visible`: принимает его `<input>` внутри, а рисует
окружающая коробка. Подсказка внутри панели знает одно состояние — `--active`, подсветку
клавиатурой; выбранной подсказки в раскрытой панели не бывает, потому что выбор её закрывает.

## Доступность

- `<input role="combobox">` с `aria-expanded`, `aria-controls` и `aria-autocomplete="list"`.
- Подсказки поодиночке не фокусируются: подсвеченная называется через `aria-activedescendant`,
  фокус остаётся в поле.
- Клавиатура: `ArrowDown` и `ArrowUp` водят по подсказкам, `Enter` выбирает подсвеченную,
  `Escape` закрывает. При закрытой панели клавиши ничего не делают.
- Подпись даёт вмещающий `rt-field`; без обёртки поле обязано нести `ariaLabel`.

## Оформление

Коробка поля берёт общую группу свойств полей кита (`--rt-input-*`) — потому и стоит в форме
вровень с `rt-input` и `rt-select`. Панель берёт `--rt-color-bg-surface`,
`--rt-color-border-subtle` и `--rt-shadow-md`.

**`displayWith` задавать обязательно.** Без него и подпись подсказки, и текст в поле, и плоский
режим чтения собираются через `String(item)`, а объект превращается в `[object Object]`.

**Панели нет в светло-тёмной паре.** Она рисуется в контейнере оверлеев CDK — за пределами
блока, которому пара назначает свойства темы. Тёмную панель смотрят переключателем темы.

## Входы

| вход           | тип                                         | умолчание            |
| -------------- | ------------------------------------------- | -------------------- |
| `suggestions`  | `ReadonlyArray<TItem>`                      | `[]`                 |
| `displayWith`  | `(item: TItem \| null) => string`           | `String(item ?? '')` |
| `placeholder`  | `string`                                    | `''`                 |
| `minLength`    | `number`                                    | `1`                  |
| `iconLeft`     | `IRtIcon.Name \| null`                      | `null`               |
| `openOnFocus`  | `boolean`                                   | `false`              |
| `itemTemplate` | `TemplateRef<{ $implicit: TItem }> \| null` | `null`               |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

| выход        | тип                        | когда                                         |
| ------------ | -------------------------- | --------------------------------------------- |
| `complete`   | `{ query, originalEvent }` | набрано не меньше `minLength` символов        |
| `itemSelect` | `TItem`                    | выбрана подсказка (значение уходит и в форму) |

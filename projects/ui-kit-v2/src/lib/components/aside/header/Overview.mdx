<Title>AsideHeader — `rt-aside-header`</Title>

Шапка боковой панели: стрелка возврата, надзаголовок, заголовок, ряд бэйджей и место под
действия. Ставится первым узлом внутри
[`rt-aside`](./?path=/docs/organisms-aside-aside-overview--docs).

```html
<rt-aside ariaLabel="Карточка тура">
    <rt-aside-header title="Тур в Сочи" overline="Заявка № 1024" [badges]="[{ value: 'Оплачен', severity: 'success' }]">
        <button rtButton asideActions label="Печать"></button>
    </rt-aside-header>
    …
</rt-aside>
```

## Когда применять

- Панели нужен заголовок — то есть почти всегда: он же становится её доступным именем.
- Над заголовком уместен машинный признак объекта: номер заявки, артикул, дата.

## Когда не применять

- **Шапка модального окна** — [`rt-dialog-header`](./?path=/docs/organisms-dialog-dialogheader-overview--docs):
  там вместо стрелки возврата крестик, и бэйджей нет.
- **Заголовок раздела внутри панели** — [`rt-aside-section`](./?path=/docs/organisms-aside-asidesection-overview--docs).

## Оси

| ось       | значения                                         | умолчание  |
| --------- | ------------------------------------------------ | ---------- |
| заголовок | заголовок, с надзаголовком, без стрелки, длинный | —          |
| бэйджи    | нет, один, несколько, со ссылкой                 | нет        |
| загрузка  | загружено, загрузка                              | загружено  |
| строка    | без строки, со строкой                           | без строки |

**Оси, которых не видно.** Вид бэйджа (палитра, форма, иконка) задаёт не шапка, а сам бэйдж —
это те же входы, что у [`rt-tag`](./?path=/docs/atoms-tag-overview--docs), и показаны они
там. Действия справа приходят проекцией `[asideActions]`: их вид решает тот, кто их кладёт.

**Шапка показана без вмещающей панели.** Она самостоятельный компонент; как она выглядит внутри
панели, показывает матрица `Aside → Size`.

## Состояния

| состояние | чем задаётся   | что меняется                                        |
| --------- | -------------- | --------------------------------------------------- |
| обычное   | —              | заголовок текстом                                   |
| загрузка  | вход `loading` | заголовок подменяется заглушкой, остальное на месте |

Стрелка возврата живёт состояниями [`rt-icon-button`](./?path=/docs/atoms-buttons-iconbutton-overview--docs):
наведение, нажатие, фокус с клавиши.

Заглушка загрузки нарисована
[`rt-skeleton-wrapper`](./?path=/docs/molecules-feedback-skeletonwrapper-overview--docs) — она держит
размер заголовка, поэтому шапка при загрузке не прыгает.

## Доступность

- Заголовок — `<h2>`: он становится доступным именем панели.
- Стрелка возврата несёт переведённое имя из словаря кита и ту же подсказку.
- Бэйдж со ссылкой рисуется якорем и открывает адрес в новой вкладке — с `rel="noopener"` и
  иконкой внешней ссылки, чтобы переход не был неожиданным.

## Оформление

Строка шапки: стрелка, блок заголовка, действия. Надзаголовок — приглушённый мелкий текст над
заголовком, подпись — приглушённая фраза под ним, она переносится; бэйджи стоят под заголовком в ряд и переносятся.

Узел с атрибутом `asideHeaderContent` встаёт строкой под всей строкой шапки на её полную ширину:
поиск, вкладки, сводка. Пустая строка места не занимает. Узел с атрибутом `asideHeadingContent`
встаёт в колонку заголовка под подписью и бэйджами, по её левому краю: стрелка и действия остаются
рядом с ним. Пустой слот ничего не рисует.

## Свойства приложения

Каждое свойство читается с любого предка — с панели оверлея, контейнера страницы или корня. Без
него шапка выглядит как раньше.

| свойство                           | что задаёт                     | без него                 |
| ---------------------------------- | ------------------------------ | ------------------------ |
| `--rt-aside-header-inset`          | отступ шапки                   | `--rt-aside-inset`       |
| `--rt-aside-header-title-leading`  | высота строки заголовка        | наследуется              |
| `--rt-aside-header-title-size`     | кегль заголовка                | `--rt-text-xl`           |
| `--rt-aside-header-title-weight`   | насыщенность заголовка         | `--rt-font-weight-bold`  |
| `--rt-aside-header-subtitle-size`  | кегль подписи                  | `--rt-text-sm`           |
| `--rt-aside-header-gap`            | зазор в строке и над строкой   | `--rt-space-sm`          |
| `--rt-aside-header-min-height`     | наименьшая высота строки шапки | `auto`                   |
| `--rt-aside-header-back-size`      | сторона кнопки «назад»         | `--rt-control-height-sm` |
| `--rt-aside-header-back-icon-size` | сторона значка кнопки «назад»  | `--rt-size-4`            |

Значок кнопки «назад» берёт размер только из `--rt-aside-header-back-icon-size`: ступень
`--rt-icon-step-sm`, заданная приложением выше, до него не доходит. `--rt-icon-button-size` на
предке по-прежнему важнее размера кнопки.

## Входы

| вход       | тип                               | умолчание |
| ---------- | --------------------------------- | --------- |
| `title`    | `string \| null`                  | `null`    |
| `overline` | `string \| null`                  | `null`    |
| `subtitle` | `string \| null`                  | `null`    |
| `badges`   | `readonly IRtAsideHeader.Badge[]` | `[]`      |
| `closable` | `boolean`                         | `true`    |
| `loading`  | `boolean`                         | `false`   |

`closable` управляет **стрелкой возврата**, а не крестиком: панель закрывают возвратом назад,
как в мобильном экране карточки.

## Выходы

| выход     | тип    | когда                   |
| --------- | ------ | ----------------------- |
| `dismiss` | `void` | нажата стрелка возврата |

<Title>AsideHeader — `rt-aside-header`</Title>

Шапка боковой панели: стрелка возврата, надзаголовок, заголовок, ряд бэйджей и место под
действия. Ставится первым узлом внутри
[`rt-aside`](./?path=/docs/components-aside-overview--docs).

```html
<rt-aside ariaLabel="Карточка тура">
    <rt-aside-header title="Тур в Сочи" overline="Заявка № 1024" [badges]="[{ value: 'Оплачен', severity: 'success' }]">
        <button rtButton asideActions label="Печать"></button>
    </rt-aside-header>
    …
</rt-aside>
```

## Когда применять

- Панели нужен заголовок — то есть почти всегда: он же становится её доступным именем.
- Над заголовком уместен машинный признак объекта: номер заявки, артикул, дата.

## Когда не применять

- **Шапка модального окна** — [`rt-dialog-header`](./?path=/docs/components-dialogheader-overview--docs):
  там вместо стрелки возврата крестик, и бэйджей нет.
- **Заголовок раздела внутри панели** — [`rt-aside-section`](./?path=/docs/components-asidesection-overview--docs).

## Оси

| ось       | значения                                         | умолчание |
| --------- | ------------------------------------------------ | --------- |
| заголовок | заголовок, с надзаголовком, без стрелки, длинный | —         |
| бэйджи    | нет, один, несколько, со ссылкой                 | нет       |
| загрузка  | загружено, загрузка                              | загружено |

**Оси, которых не видно.** Вид бэйджа (палитра, форма, иконка) задаёт не шапка, а сам бэйдж —
это те же входы, что у [`rt-tag`](./?path=/docs/components-tag-overview--docs), и показаны они
там. Действия справа приходят проекцией `[asideActions]`: их вид решает тот, кто их кладёт.

**Шапка показана без вмещающей панели.** Она самостоятельный компонент; как она выглядит внутри
панели, показывает матрица `Aside → Size`.

## Состояния

| состояние | чем задаётся   | что меняется                                        |
| --------- | -------------- | --------------------------------------------------- |
| обычное   | —              | заголовок текстом                                   |
| загрузка  | вход `loading` | заголовок подменяется заглушкой, остальное на месте |

Стрелка возврата живёт состояниями [`rt-icon-button`](./?path=/docs/components-iconbutton-overview--docs):
наведение, нажатие, фокус с клавиши.

Заглушка загрузки нарисована
[`rt-skeleton-wrapper`](./?path=/docs/components-skeletonwrapper-overview--docs) — она держит
размер заголовка, поэтому шапка при загрузке не прыгает.

## Доступность

- Заголовок — `<h2>`: он становится доступным именем панели.
- Стрелка возврата несёт переведённое имя из словаря кита и ту же подсказку.
- Бэйдж со ссылкой рисуется якорем и открывает адрес в новой вкладке — с `rel="noopener"` и
  иконкой внешней ссылки, чтобы переход не был неожиданным.

## Оформление

Строка шапки: стрелка, блок заголовка, действия. Надзаголовок — приглушённый мелкий текст над
заголовком; бэйджи стоят под заголовком в ряд и переносятся.

## Входы

| вход       | тип                               | умолчание |
| ---------- | --------------------------------- | --------- |
| `title`    | `string \| null`                  | `null`    |
| `overline` | `string \| null`                  | `null`    |
| `badges`   | `readonly IRtAsideHeader.Badge[]` | `[]`      |
| `closable` | `boolean`                         | `true`    |
| `loading`  | `boolean`                         | `false`   |

`closable` управляет **стрелкой возврата**, а не крестиком: панель закрывают возвратом назад,
как в мобильном экране карточки.

## Выходы

| выход     | тип    | когда                   |
| --------- | ------ | ----------------------- |
| `dismiss` | `void` | нажата стрелка возврата |

## Рядом

- [`rt-aside`](./?path=/docs/components-aside-overview--docs) — панель, в которую эта шапка ставится.
- [`rt-tag`](./?path=/docs/components-tag-overview--docs) — чем нарисованы бэйджи.
- [`rt-skeleton-wrapper`](./?path=/docs/components-skeletonwrapper-overview--docs) — чем нарисована заглушка загрузки.

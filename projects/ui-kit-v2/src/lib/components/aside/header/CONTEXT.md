# `rt-aside-header`

Шапка панели: стрелка закрытия, надзаголовок, заголовок, подпись, бэйджи и значки действий справа.

```html
<rt-aside-header title="Запись 7" (dismiss)="onClose()">
    <rt-icon-button asideActions icon="undo" ariaLabel="Сбросить" (clicked)="reset()" />
</rt-aside-header>
```

| вход       | тип                      | умолчание |
| ---------- | ------------------------ | --------- |
| `title`    | `string \| null`         | `null`    |
| `overline` | `string \| null`         | `null`    |
| `subtitle` | `string \| null`         | `null`    |
| `badges`   | `IRtAsideHeader.Badge[]` | `[]`      |
| `closable` | `boolean`                | `true`    |
| `loading`  | `boolean`                | `false`   |

| выход     | тип    |
| --------- | ------ |
| `dismiss` | `void` |

## Главное, что нужно знать

**Стрелка закрывает панель двумя путями.** Сперва выход `dismiss` — его слушает панель маршрута, —
затем `RtAsideRef.close()`, если панель открыта службой.

**В шторке телефона «×» стоит всегда.** До 480 точек шапка — шапка шторки: «×» слева, заголовок по
центру, главная кнопка подвала справа. `closable` прячет стрелку на широком экране, но не «×» в
шторке: иначе панель с выключенным закрытием по фону оставалась без выхода. «×» панели службы идёт
дорогой стрелки и закрывает и под `disableClose`, как стрелка: кнопка выхода подвала в шторке
спрятана. «×» панели маршрута, чья шапка выключила
стрелку, просит рамку закрыть, как свайп.

# `rt-aside` + `RtAsideService`

Панель, выезжающая сбоку поверх страницы; на телефоне, до 480 точек, — шторка снизу во всю
высоту. Открывается **сервисом**, а не разметкой.

```typescript
readonly #aside: RtAsideService = inject(RtAsideService);

const ref: RtAsideRef<ITour> = this.#aside.open(TourCardComponent, { data: tour, position: 'right' });
ref.afterClosed().subscribe((result?: ITour): void => …);
```

```html
<!-- внутри поднятого компонента -->
<rt-aside size="md" ariaLabel="Карточка тура">
    <rt-aside-header title="Тур в Сочи" />
    <ng-template rtAsideContent>
        <rt-aside-section heading="Клиент">…</rt-aside-section>
    </ng-template>
    <rt-aside-footer>…</rt-aside-footer>
</rt-aside>
```

| вход `rt-aside`    | тип                    | умолчание               |
| ------------------ | ---------------------- | ----------------------- |
| `size`             | `'sm' \| 'md' \| 'lg'` | `'md'`                  |
| `contentLayout`    | `'default' \| 'tabs'`  | `'default'`             |
| `width`            | `string \| null`       | `null`                  |
| `ariaLabel`        | `string \| null`       | `null`                  |
| `requestError`     | `unknown`              | `null`                  |
| `trapFocus`        | `boolean`              | `false`                 |
| `modal`            | `boolean`              | `false`                 |
| `pending`          | `boolean`              | `false`                 |
| `empty`            | `boolean`              | `false`                 |
| `emptyIcon`        | `IRtIcon.Name \| null` | `'inbox'`               |
| `emptyTitle`       | `string \| null`       | `null` → `uiEmptyTitle` |
| `emptyDescription` | `string \| null`       | `null`                  |

| настройка `open()`                       | умолчание                                  |
| ---------------------------------------- | ------------------------------------------ |
| `data`                                   | `null` — доезжает токеном `RT_ASIDE_DATA`  |
| `position`                               | `'right'`; на телефоне не читается         |
| `closeOnBackdropClick` / `closeOnEscape` | `true`; второе — из настроек кита          |
| `backdropClass` / `panelClass`           | `rt-aside-backdrop` / `rt-aside-overlay`   |
| `injector`                               | корневой — уничтожение хозяина закрывает   |
| `iconSet`                                | набор части с фокусом, затем из `injector` |
| `disposeOnNavigation`                    | `true` — переход по адресу снимает         |

**На телефоне `backdropClass` и `position` не читаются.** Панель там — шторка во всю ширину окна
со своим затемнением: подложки оверлея нет, и класс подложки повесить не на что, а сторона выезда
не нужна — шторка поднимается снизу. `panelClass` доходит до коробки шторки как и шире телефона.

**Шторкой на телефоне становится только `<rt-aside>`.** Служба решает вид при открытии, а рисует
шторку рамка панели: компонент, открытый службой, должен рисовать `<rt-aside>` с шапкой и
подвалом кита. Компонент без неё на телефоне стоит в коробке шторки без шторки — без ручки, «×» и
затемнения.

## Главное, что нужно знать

**Панель берёт материальный набор от кнопки в фокусе.** Панель лежит в конце страницы, вне
контейнера с признаком набора, и класс набора получает, если признак стоит над узлом в фокусе в
минуту открытия. Открытая не по нажатию — через `panelClass` приложения.

**Асайд объявлен `role="complementary"`, а не диалогом.** Он не модален: страница за ним
остаётся видна, и это осознанный выбор — карточку смотрят, не теряя список. Панель, которая
блокирует страницу подложкой и держит фокус, включает вход `modal`: рамка становится
`role="dialog"` с `aria-modal="true"`. Шторка на телефоне модальна всегда: она перекрывает
страницу.

**Закрытие двухтактное.** `close(result)` отдаёт результат **сразу**, а панель убирает через
200 мс — чтобы доиграла анимация ухода. В тестах это значит: подписчик получил значение, а
`.rt-aside-overlay` ещё в документе. Повторный `close()` игнорируется.

**Прозрачность и нажатия подложки объявлены вне слоя оформления.** Остальные правила панели
лежат в подслое `rt-kit.components`, а эти два — нет: CDK объявляет свои правила той же
подложки вне слоёв, и неслоевое правило сильнее любого слоевого независимо от специфичности.
В слое они проигрывают, и подложка закрытой панели накрывает экран целиком у потребителя,
который берёт стили кита слоями. Цвет, размытие и переход остаются в слое — их приложение
переопределяет своими правилами. Стережёт это `rt-aside-overlay.styles.spec.ts`.

**`disableClose`** на `RtAsideRef` держит панель под кликом по подложке и под Escape — ставится
самим содержимым, когда в форме есть несохранённое. Отказанный жест — под `disableClose` или
выключенный настройкой — приходит в `closeRequests()`: `'escape'` или `'backdrop'`.

**Снятый без `close()` слой завершает `afterClosed()` значением `undefined`.** Переход по адресу
(`disposeOnNavigation`) и уничтожение хозяина больше не оставляют подписчика ждать. То же у
`RtDialogRef`.

**Ошибку запроса показывает сама панель.** Вход `requestError` ставит между шапкой и содержимым
блок `rt-aside-error-box` с кнопкой копирования ошибки; `null` и `undefined` его убирают. Своя
разметка ошибки в содержимом панели не пишется.

**Пустую панель показывает сама панель.** Вход `empty` ставит в тело `rt-empty-state` со значком
`inbox` и подписью `uiEmptyTitle`; `emptyIcon`, `emptyTitle`, `emptyDescription` её меняют,
`<ng-template rtAsideEmpty>` заменяет целиком. Шапка и подвал на месте. Панель с вкладками
пуста по вкладке: вход `empty` ставится на `rtTab`. Заголовок по умолчанию — подпись кита
`uiEmptyTitle` («No data»); приложение на другом языке добавляет `rtKit.uiEmptyTitle` в свой
словарь, иначе виден английский текст. Под `empty` спроецированное содержимое остаётся созданным
(Angular создаёт его в любом случае), оно только не показано; вкладка под `empty` своё тело не
создаёт. С `contentLayout="tabs"` собственный `empty` панели не работает, работает `empty` вкладки: у тела панели тогда нет вертикальных отступов, и заглушку может обрезать.

**От 481 до 768 точек панель во всё окно.** Ширину держит `--rt-aside-narrow-width`, по
умолчанию `100dvw`; размер и `width` там не действуют. Коробка, в которую панель поставлена
разметкой, задаёт свойству `100%`.

## На телефоне — шторка во всю высоту

**До 480 точек каждая панель открывается снизу шторкой кита во всю высоту.** Так встаёт панель,
открытая `RtAsideService`, и правая панель `rt-container` в обоих режимах; панель, стоящая в
странице сама, без них, остаётся сбоку. Вид выбирается окном в миг открытия
(`BreakpointsService.phone`) и держится до закрытия: окно, перешедшее 480 точек при открытой
панели, вид не меняет. Вид одного открытия — `RtAsideSheet`, его дают токеном `RT_ASIDE_SHEET`
служба и рамка; настройки, оставляющей панель сбоку, нет.

**Шторка — та же `rt-aside` внутри `rt-bottom-sheet`.** Сверху полоса 12 px, всегда затемнение,
ширина окна; `position`, `size`, `width` и ручка ширины рамки к ней не относятся. Шапка — шапка
шторки: ручка, «×» слева (`aside-sheet-close`, идёт дорогой стрелки шапки), заголовок в одну
строку — по центру шапки, если влазит, иначе на всём месте между «×» и кнопками
(`RtAsideHeaderTitle`), справа значки шапки и через 8 главная кнопка. Главная кнопка — последняя кнопка слота
`asidePrimary`: её узел переносится из подвала в шапку (`RtAsideMainAction`) и делает то же, что
делал. Шапка без стрелки (`closable` выключен) «×» не рисует. Надзаголовок, подпись и бэйджи стоят
под шапкой. Вкладки — один ряд; не влазят — ряд по кругу с затенёнными краями (`RtAsideSheetTabs`). Объявлена
модальным диалогом по `ariaLabel`, иначе по заголовку; фокус при открытии — на «×», если панель не
пометила своё поле `cdkFocusInitial`.

**Проекция одна на оба вида.** Шапка, подвал и содержимое колонки заголовка проецируются один раз
и не под условием: сбоку они стоят в рамке панели. В шторке панель переносит те же узлы
(`RtAsideNodePlace`): рамку — в тело шторки, шапку — в её шапку, подвал — в её подвал, а подвал без
кнопок снимает со страницы; шапка ставит содержимое колонки заголовка под собой. Кнопку «Закрыть»
подвал в шторке прячет модификатором `rt-aside-footer--close-hidden`.

**Подвал шторки.** Кнопка слота `asideDismiss`, которая только закрывает (короткая подпись
«Закрыть» на телефоне, `phoneCloseLabel` по умолчанию), в шторке не рисуется — её заменяет «×».
Остальные кнопки остаются в подвале шагом `sm`, как действие шапки, с полями 12 сверху и снизу;
кнопка с темой `danger` остаётся красной. Пустой подвал места не берёт.

**Закрытие шторки.** «×», свайп вниз за порог, нажатие по полосе сверху и Escape. Свайп слушается
`closeOnBackdropClick`, Escape — `closeOnEscape`; выключенный жест и `disableClose` оставляют
шторку и шлют `closeRequests()` (`'backdrop'` и у свайпа). Escape закрывает только верхний слой.

**Вопрос о несохранённом на телефоне — внизу экрана, листом действий.** Две карточки: в первой
заголовок, пояснение, красное «Закрыть без сохранения» и «Сохранить и закрыть» (на нём фокус), во
второй — «Остаться». Панель записи с охраной правок (`RtRouteAsideComponent`) спрашивает так сама,
и кнопка «назад» тоже. Панели службы признак даёт приложение: `ref.unsaved.set(true)`, пока есть
несохранённое; «Сохранить и закрыть» приходит в `ref.saveRequests()`, и приложение записывает и
закрывает панель через `close()` — признак снимать не обязательно. `close()` признак не читает. От
481 точки признак ничего не меняет, а вопрос — прежнее окно по центру. Отборы панели инструментов
в шторке спрашивают «Применить изменения?», если значение поля отличается от открытого;
«Не применять» уходит в `filtersDiscard` панели инструментов.

**Шторка из шторки — второй экран той же шторки.** Список селекта, шторка поля даты, меню кнопки,
открытые из панели-шторки, встают на её место не ниже её, «×» становится шевроном «назад»;
шеврон, выбор, свайп и Escape возвращают панель с набранным.

**Форму внутри панели размечает словарь кита, а не правила потребителя.** Блок `rt-form`
объявляется ровно один раз на панель и стоит над полосой вкладок; внутри него идут раздел
`rt-form__item`, колонка контролов `rt-form__controls` с заголовком `rt-form__title` и
описанием `rt-form__title-descr`, строка контрола `rt-form__control-item` и элемент в ряду
`rt-form__control-sub-item`. Все промежутки задают зазоры этих контейнеров, поэтому своего
файла раскладки панели у приложения нет. Носителем блока бывает и `<form>`, и `<div>`: форма
Angular и блок формы — разные вещи. Показан словарь историей витрины «Form Dictionary».

<Title>Aside — `rt-aside`</Title>

Панель, выезжающая сбоку поверх страницы. Открывается **службой**, а не разметкой:
`RtAsideService` поднимает компонент содержимого, а `rt-aside` — коробка внутри него: шапка,
разделы, подвал.

```typescript
const ref: RtAsideRef<ITour> = this.#aside.open(TourCardComponent, { data: tour, position: 'right' });
ref.afterClosed().subscribe((result?: ITour): void => …);
```

```html
<!-- внутри поднятого компонента -->
<rt-aside size="md" ariaLabel="Карточка тура">
    <rt-aside-header title="Тур в Сочи" />
    <rt-aside-section heading="Клиент">…</rt-aside-section>
    <rt-aside-footer>…</rt-aside-footer>
</rt-aside>
```

## Когда применять

- Карточку объекта смотрят, **не теряя список**: заявка рядом с таблицей заявок.
- Правка в стороне от основного экрана, которую можно закрыть, ничего не потеряв.

## Когда не применять

- **Нужна модальность** — [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs): панель
  не модальна намеренно, страница за ней остаётся видна.
- **Узкий экран** — [`rt-bottom-sheet`](./?path=/docs/organisms-aside-bottomsheet-overview--docs).
- **Постоянная колонка, а не всплывающая панель** — [`rt-container`](./?path=/docs/organisms-layout-container-overview--docs).

## Оси

| ось         | значения                    | умолчание |
| ----------- | --------------------------- | --------- |
| размер      | `sm`, `md`, `lg`            | `md`      |
| своя ширина | не задана, `260px`, `420px` | не задана |
| раскладка   | обычная, под вкладки        | обычная   |
| ошибка      | нет, есть                   | нет       |
| ожидание    | нет, есть                   | нет       |
| ручки вида  | без них, с ними             | без них   |

**Оси, которых не видно.** `ariaLabel` уходит в атрибут: он даёт панели доступное имя. Вход
`trapFocus` ловушкой держит Tab внутри панели, а в кадре фокуса не видно — его проверяют тесты.

**Панель показана прямо в разметке, а не открытой службой.** В оверлей её уносит
`RtAsideService`, а сам компонент — обычная коробка: так размеры встают рядом, а светло-тёмная
пара ловит панель целиком.

**Чего этим не показать.** Выезд сбоку, подложку и сторону открытия ставит служба; в витрине их
нет. Проверять их надо в приложении.

## Состояния

Своих состояний панель не знает: она либо поднята службой, либо её нет. Что решает служба:

| настройка                                | умолчание                                | что делает                                                                                                   |
| ---------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `data`                                   | `null`                                   | доезжает до содержимого токеном `RT_ASIDE_DATA`                                                              |
| `position`                               | `'right'`                                | сторона, с которой выезжает панель                                                                           |
| `closeOnBackdropClick` / `closeOnEscape` | `true`                                   | закрытие щелчком по подложке и `Escape`; умолчание второго приложение задаёт киту разом через `provideRtKit` |
| `backdropClass` / `panelClass`           | `rt-aside-backdrop` / `rt-aside-overlay` | классы подложки и панели                                                                                     |
| `injector`                               | корневой                                 | injector хозяина: содержимое видит его провайдеры, а уничтожение хозяина закрывает панель                    |

**Закрытие двухтактное.** `close(result)` отдаёт результат **сразу**, а панель убирает через
200 мс — чтобы доиграла анимация ухода. В проверках это значит: подписчик уже получил значение,
а панель ещё в документе. Повторный вызов игнорируется.

`RtAsideRef.disableClose` держит панель под щелчком по подложке и под `Escape` — его ставит само
содержимое, когда в форме есть несохранённое. Каждый жест, на который панель не закрылась, —
под `disableClose` или выключенный настройкой — приходит в `RtAsideRef.closeRequests()` словом
`'escape'` или `'backdrop'`: так содержимое спрашивает, сохранить ли правки.

**Слой, снятый без `close()`,** — переходом по адресу или уничтожением хозяина — тоже завершает
`afterClosed()`: подписчик получает `undefined`.

**Ожидание.** Вход `pending` накрывает всю панель полупрозрачным слоем с крутилкой и помечает её
`aria-busy`: пока идёт запрос, шапка, содержимое и подвал не нажимаются.

**Ошибка запроса.** Когда сохранение не удалось, содержимое отдаёт ошибку во вход `requestError`.
Панель остаётся открытой с введёнными данными, а между шапкой и содержимым встаёт блок
`rt-aside-error-box`: надпись «Request Error» и кнопка «Copy error info». Кнопка кладёт в буфер
обмена время и ошибку в JSON и секунду показывает «Copied» со значком. Блок не уезжает с
прокруткой. `null` и `undefined` — ошибки нет; любое другое значение, пустая строка тоже, блок
показывает. Подтверждение «Copied» живёт секунду после нажатия, поэтому в кадр витрины не
попадает — его держат тесты блока. Отдельно блок нужен приложению, которое показывает ошибку в
другом месте; его единственный вход — `error`.

## Доступность

- Панель объявлена `role="complementary"`, **а не диалогом**: она не модальна, и страница за ней
  остаётся видна. Это осознанный выбор — карточку смотрят, не теряя список.
- Доступное имя — заголовок шапки или `ariaLabel`.
- `Escape` закрывает панель, пока содержимое не запретило это через `disableClose`.
- Вход `trapFocus` держит Tab внутри панели: фокус встаёт на элемент с `cdkFocusInitial` или на
  первый под Tab, а когда панель уходит, возвращается туда, где стоял. По умолчанию выключен.

## Оформление

Ширина берётся из свойства `--rt-aside-width`: размер выставляет его сам, вход `width`
перекрывает. Раскладка `tabs` отдаёт прокрутку внутрь содержимого — так шапка вкладок остаётся
на месте, а прокручивается только их содержимое.

На экране до 768 точек панель встаёт во всё окно, и размер с входом `width` там не действуют.
Эту ширину держит свойство `--rt-aside-narrow-width`, по умолчанию `100dvw`. Коробка, в которую
панель поставлена прямо разметкой, задаёт ему `100%` и держит панель в своей ширине — так
поступает витрина.

Отступы и подвал приложение задаёт с корня страницы ручками: `--rt-aside-header-inset`,
`--rt-aside-content-inset`, `--rt-aside-footer-inset`, `--rt-aside-footer-margin`,
`--rt-aside-footer-justify`, `--rt-aside-footer-gap`, `--rt-aside-header-title-leading` и
`--rt-aside-error-margin-block`. Имена отличаются от имён первого кита: приложение, где стоят оба
кита, иначе красило бы одну панель значениями другой. Раскладка `tabs` держит общий инсет панели.

## Входы

| вход            | тип                    | умолчание   |
| --------------- | ---------------------- | ----------- |
| `size`          | `'sm' \| 'md' \| 'lg'` | `'md'`      |
| `contentLayout` | `'default' \| 'tabs'`  | `'default'` |
| `width`         | `string \| null`       | `null`      |
| `ariaLabel`     | `string \| null`       | `null`      |
| `requestError`  | `unknown`              | `null`      |
| `trapFocus`     | `boolean`              | `false`     |
| `pending`       | `boolean`              | `false`     |

## Выходы

Своих выходов нет: результат отдаёт `RtAsideRef.close(result)`, а получает его подписчик
`afterClosed()`.

# `rt-aside-footer`

Низ панели над чертой: «Закрыть» и одно позитивное действие. Кнопки ставятся в два слота, а вид
им задаёт подвал, не разметка потребителя.

```html
<rt-aside-footer>
    <button rtButton asideDismiss label="Закрыть и не сохранять" (click)="close()"></button>
    <button rtButton asidePrimary label="Сохранить" (click)="save()"></button>
</rt-aside-footer>
```

| вход              | тип       | умолчание |
| ----------------- | --------- | --------- |
| `phoneCloseLabel` | `boolean` | `true`    |

## Главное, что нужно знать

**Порядок кнопок у подвала один.** «Закрыть» в рамке слева, позитивное действие залито, без
значка и стоит справа. Обе кнопки в одной строке на любой ширине.

**На телефоне «Закрыть» подписана коротко** — подписью кита `uiClose`. Так строка помещается без
переноса.

# `rt-aside-footer`

Низ панели над чертой: «Закрыть» и одно позитивное действие. Кнопки ставятся в два слота, а вид
им задаёт подвал, не разметка потребителя.

```html
<rt-aside-footer>
    <button rtButton asideDismiss label="Закрыть и не сохранять" (click)="close()"></button>
    <button rtButton asidePrimary label="Сохранить" (click)="save()"></button>
</rt-aside-footer>
```

| вход     | тип                    | умолчание   |
| -------- | ---------------------- | ----------- |
| `layout` | `'between' \| 'start'` | `'between'` |

## Главное, что нужно знать

**`between` — раскладка панели записи.** «Закрыть» в рамке слева, позитивное действие залито,
без значка и стоит справа.

**`start` — раскладка панели подключения службы.** Позитивное действие стоит первым со своим
значком, «Закрыть» идёт текстом сразу за ним, обе кнопки у левого края. Порядок меняет стиль, а не
разметка: слоты проецируются в одном порядке при любой раскладке.

**На телефоне «Закрыть» подписана коротко** — подписью кита `uiClose`, в обеих раскладках.

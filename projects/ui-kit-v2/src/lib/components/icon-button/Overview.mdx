<Title>IconButton — `rt-icon-button`</Title>

Кнопка без подписи. Настоящую `<button>` компонент рисует внутри себя, host остаётся обычным
элементом.

```html
<rt-icon-button icon="ico-trash" ariaLabel="Удалить" variant="danger" (clicked)="remove()" />
<rt-icon-button icon="ico-bell" ariaLabel="Уведомления" [indicator]="hasUnread()" />
```

## Когда применять

- Действие, для которого нет места под подпись: панель инструментов, строка таблицы, угол
  карточки.
- Кнопка-переключатель — тогда `active` превращается в `aria-pressed`.
- Рисунок не из набора кита — `[icon]="null"` и рисунок внутри кнопки, история `Content`.

## Когда не применять

- **Есть место под подпись** — [`[rtButton]`](./?path=/docs/atoms-buttons-button-overview--docs):
  подпись понятнее иконки всем, а не только тем, кто её уже знает.
- **Неинтерактивный знак** — [`rt-icon`](./?path=/docs/atoms-icon-overview--docs).

## Оси

| ось           | значения                                                           | умолчание |
| ------------- | ------------------------------------------------------------------ | --------- |
| палитра       | `ghost`, `primary`, `secondary`, `danger`, `success`, `warning`    | `ghost`   |
| размер        | `2xs` 20, `xs` 22, `sm` 32, `md` 40, `lg` 48, `xl` 56, `2xl` 64 px | `md`      |
| размер иконки | от кнопки (`null`), `xs`…`2xl`                                     | от кнопки |
| скругление    | умолчание `md`, `none`…`full` — шаг общей шкалы                    | `md`      |
| признаки      | обычная, нажата, с точкой, загрузка, отключена                     | обычная   |

Перемножены палитра с формой (у круглой кнопки заливка читается иначе) и признак с палитрой.
Отдельная сетка — **размер кнопки на размер иконки**: ровно та пара, ради которой `iconSize`
и существует. Крупная кнопка, в которую целятся пальцем, с иконкой во весь диаметр выглядит
тяжеловесно, и одной строкой это не показать.

Свой размер и свою заливку приложение задаёт на теге `<rt-icon-button>` или выше:
`--rt-icon-button-size`, `--rt-icon-button-bg` и `--rt-icon-button-bg-hover` для заливки под
указателем. Модификаторы размера и вида пишут свои шаги в частные свойства, а кнопка читает их
только тогда, когда приложение ничего не задало. Правило на теге показывает история **HostRule**.
У `2xs` и `xs` значок 16px.

## Состояния

| состояние       | чем задаётся            | что меняется                                    |
| --------------- | ----------------------- | ----------------------------------------------- |
| обычное         | —                       | заливка по палитре                              |
| наведение       | `:hover:not(:disabled)` | заливка уходит в свою пару для наведения        |
| нажатие         | `:active`               | заливка ещё на ступень                          |
| фокус с клавиши | `:focus-visible`        | кольцо фокуса                                   |
| нажата          | вход `active`           | заливка как у наведения + `aria-pressed="true"` |
| загрузка        | вход `loading`          | кольцо вместо иконки, клик наружу не уходит     |
| отключена       | вход `disabled`         | палитра гасится, клик не проходит               |

`loading` — это `disabled` плюс кольцо. Наведение, нажатие и фокус смотрятся аддоном
псевдосостояний: признак ставится на host, а стилизована `<button>` внутри шаблона, поэтому
аддону передан спуск до неё.

## Доступность

- **`ariaLabel` обязателен.** У кнопки нет текста, и без подписи она для скринридера
  безымянна — это единственная причина, по которой вход помечен `required`.
- `active` превращается в `aria-pressed="true"` — для кнопок-переключателей.
- `tabIndex="-1"` оставляет клик мышью, но убирает кнопку из таб-порядка: так сделаны
  вспомогательные крестики внутри полей.
- Точка `indicator` помечена `aria-hidden`: она дублирует то, что уже сказано в подписи или
  рядом, и читать её отдельно нечего.

## Оформление

Диаметр — `--rt-icon-button-size`, заливка наведения — `--rt-icon-button-color-bg-hover`.
Модификаторы в камелкейсе конвертируются в дефис: `indicator` → `rt-icon-button--has-indicator`.

Тень покоя — `--rt-icon-button-shadow`; по умолчанию тени нет, и потребитель поднимает кнопку сам.
Под указателем тень берётся из `--rt-icon-button-shadow-hover`, а цвет значка прозрачной кнопки — из
`--rt-icon-button-color-hover`. По умолчанию оба равны значениям покоя, и без них кнопка под указателем
меняет только заливку. Этими ручками панель списка делает из кнопок круглые кнопки действия первого кита.

Материальный набор — второй слой назначений поверх светлой темы: он переписывает цвет, скругление
и тень, не трогая ни разметку, ни размеры, и включается признаком `data-preset='material'` на
корне страницы или на любом контейнере. Пара наборов рядом показана историей **Presets**.

## Входы

| вход        | тип                                                                                 | умолчание                   |
| ----------- | ----------------------------------------------------------------------------------- | --------------------------- |
| `icon`      | `IRtIcon.Name \| null` — нужен он или `glyph`; побеждает имя; без обоих — вложенное | `null`                      |
| `glyph`     | `string \| null` — имя Material, рисуется как `glyph` у `rt-icon`                   | `null`                      |
| `ariaLabel` | `string`                                                                            | **обязателен**              |
| `variant`   | `'primary' \| 'secondary' \| 'ghost' \| 'danger' \| 'success' \| 'warning'`         | `'ghost'`                   |
| `size`      | `'2xs' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'`                            | `'md'`                      |
| `iconSize`  | `IRtIcon.Size \| null`                                                              | `null` → от размера кнопки  |
| `iconColor` | `IRtIcon.Color`                                                                     | `'current'`                 |
| `iconFill`  | `boolean`                                                                           | `false`                     |
| `radius`    | `TRtRadius \| null` — шаг общей шкалы                                               | `null` → `md`               |
| `type`      | `'button' \| 'submit'`                                                              | `'button'`                  |
| `tooltip`   | `string`                                                                            | `''` — пусто, подсказки нет |
| `tabIndex`  | `number`                                                                            | `0`                         |
| `loading`   | `boolean`                                                                           | `false`                     |
| `disabled`  | `boolean`                                                                           | `false`                     |
| `active`    | `boolean`                                                                           | `false`                     |
| `indicator` | `boolean`                                                                           | `false`                     |

## Выходы

| выход     | тип          | когда                                          |
| --------- | ------------ | ---------------------------------------------- |
| `clicked` | `MouseEvent` | клик; в загрузке и отключении наружу не уходит |

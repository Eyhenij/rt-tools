<Title>ThreadList — `rt-thread-list`</Title>

Левая колонка переписки: поиск сверху, список строк под ним, догрузка снизу. Вид строки задаёт
потребитель шаблоном — список знает только про идентификатор, непрочитанное и просрочку.

```html
<rt-thread-list [rows]="threads()" [activeId]="openId()" (selectRow)="open($event)">
    <ng-template rtThreadListRow let-row>
        <strong>{{ row.title }}</strong>
    </ng-template>
</rt-thread-list>
```

## Когда применять

- Список переписок, заявок, обращений рядом с их содержимым.

## Когда не применять

- **Список с колонками** — [`rt-table`](./?path=/docs/components-table-overview--docs).
- **Навигация по разделам** — [`rt-section-nav`](./?path=/docs/components-section-nav-overview--docs).

## Оси

| ось              | значения                                                          | умолчание    |
| ---------------- | ----------------------------------------------------------------- | ------------ |
| состояние строки | обычная, непрочитанная, просроченная, выбранная                   | обычная      |
| загрузка         | строки на месте, пустой грузится, загрузка поверх строк, догрузка | на месте     |
| догрузка снизу   | список кончился, есть ещё                                         | кончился     |
| пустой список    | переведённый текст, свой текст, ничего не нашлось по фильтрам     | переведённый |

Состояния строки показаны **одним списком, где стоят все виды сразу**: порознь их не сравнить,
а выбранная читается только рядом с невыбранными.

**`loading` подменяет строки заглушками только при пустом списке.** Загрузка поверх уже
показанных строк их не трогает — иначе список мигал бы при каждой смене фильтра. Оба случая
стоят в матрице рядом, потому что вход у них один и тот же.

## Края

| край                         | что происходит                                    |
| ---------------------------- | ------------------------------------------------- |
| пустой список без фильтров   | текст «переписок нет»                             |
| пустой при активных фильтрах | текст про фильтры: список не пуст, а отфильтрован |
| список кончился              | кнопки догрузки нет                               |

## Состояния

| состояние     | чем задаётся            | что меняется                  |
| ------------- | ----------------------- | ----------------------------- |
| обычная       | —                       | подпись как есть              |
| непрочитанная | `hasUnread` строки      | точка и жирная подпись        |
| просроченная  | `overdue` строки        | цветной признак у края строки |
| выбранная     | совпадение с `activeId` | подложка строки               |
| наведение     | `:hover`                | подложка светлее              |

## Доступность

- **Ctrl или Cmd с нажатием просит открыть в новой вкладке**, а не выбирает строку: список — это
  навигация, и привычка «открыть рядом» должна работать.
- Поиск отдаёт значение с задержкой и без повторов: каждая буква не уходит запросом.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-chat`](./?path=/docs/components-chat-overview--docs) — правая половина того же экрана.

## Входы

| вход                | тип               | умолчание | что делает                                            |
| ------------------- | ----------------- | --------- | ----------------------------------------------------- |
| `rows`              | `readonly TRow[]` | `[]`      | строки списка                                         |
| `activeId`          | `number \| null`  | `null`    | какая строка выбрана                                  |
| `searchPlaceholder` | `string`          | `''`      | подсказка в поле поиска                               |
| `emptyText`         | `string`          | `''`      | текст пустого списка; пустой оставляет переведённый   |
| `loading`           | `boolean`         | `false`   | заглушки вместо строк, но только при пустом списке    |
| `fetching`          | `boolean`         | `false`   | догрузка: строки остаются на месте                    |
| `hasMore`           | `boolean`         | `false`   | внизу есть кнопка догрузки                            |
| `filtersActive`     | `boolean`         | `false`   | пустой список объясняется фильтрами, а не отсутствием |

## Выходы

| выход          | что сообщает                                           |
| -------------- | ------------------------------------------------------ |
| `selectRow`    | выбрана строка                                         |
| `openInNewTab` | строка нажата с Ctrl или Cmd — открыть рядом           |
| `searchChange` | изменилось значение поиска, с задержкой и без повторов |
| `loadMore`     | нажата кнопка догрузки                                 |

<Title>FileInput — `rt-file-input`</Title>

Поле выбора файлов: кнопка, спрятанное нативное поле и список выбранного карточками. Значение —
`File[]`, даже в одиночном режиме.

```html
<rt-field label="Документы">
    <rt-file-input accept=".pdf,.docx" buttonLabel="Прикрепить" [multiple]="true" [formControl]="docs" />
</rt-field>
```

## Когда применять

- Вложение к форме, которое выбирают через системный диалог: договор, скан, фотография.
- Список выбранного нужно показать тут же и дать убрать лишнее — карточки рисуются полем.

## Когда не применять

- **Файлы перетаскивают в область** — [`rt-file-drop`](./?path=/docs/components-filedrop--docs).
- **Только показать уже загруженное** — [`rt-file-list`](./?path=/docs/components-filelist--docs)
  с [`rt-file-card`](./?path=/docs/components-filecard--docs): поле выбора здесь лишнее.

## Оси

| ось            | значения                             | умолчание      |
| -------------- | ------------------------------------ | -------------- |
| что выбрано    | пусто, один файл, несколько файлов   | пусто          |
| подпись кнопки | умолчание кита, своя (`buttonLabel`) | умолчание кита |
| отключённость  | включено, отключено                  | включено       |

**Оси, которых не видно.** `accept`, `multiple` и `directory` меняют не поле, а системный диалог:
какие файлы в нём выбираются, сколько их и берётся ли папка целиком. В неподвижной сетке эти
входы неразличимы — их видно, только когда диалог открыт.

**Без `multiple` берётся только первый файл**, даже если браузер отдал набор: так бывает при
перетаскивании в одиночное поле.

## Состояния

| состояние     | чем задаётся                         | что видно                                     |
| ------------- | ------------------------------------ | --------------------------------------------- |
| обычное       | —                                    | кнопка выбора и список выбранного             |
| ошибка        | контрол `invalid` после касания      | текст ошибки рисует `rt-field`                |
| отключено     | вход `disabled` или слово формы      | кнопка и карточки гаснут, удаление недоступно |
| только чтение | `[readonly]` на вмещающем `rt-field` | плоский перечень имён, пустое — прочерком     |

Своих состояний взаимодействия у поля нет: наведение, нажатие и фокус принадлежат кнопке
[`[rtButton]`](./?path=/docs/components-button-overview--docs) и карточкам
[`rt-file-card`](./?path=/docs/components-filecard--docs) и показаны в их матрицах.

**Удаление файла сбрасывает значение нативного поля.** Иначе повторный выбор того же файла не
дал бы события `change`, и вернуть только что удалённое было бы нельзя.

## Доступность

- Нативное поле спрятано (`hidden`): оформить его нельзя, поэтому диалог открывает своя кнопка,
  кликая по нему программно. Само поле остаётся в разметке — по нему работают `accept` и
  `multiple`.
- Подпись даёт вмещающий `rt-field`; без обёртки полю нужен `ariaLabel`.
- Подпись кнопки берётся из словаря кита (`rtKit.uiChooseFile`), пока не задан `buttonLabel`.

## Оформление

Кнопка, список и карточки — элементы блока `rt-file-input`; кнопка нарисована `[rtButton]` в
облике `outlined` с иконкой `ico-upload`, список — `rt-file-list`, каждая карточка —
`rt-file-card` с крестиком удаления.

## Входы

| вход          | тип              | умолчание                   |
| ------------- | ---------------- | --------------------------- |
| `multiple`    | `boolean`        | `false`                     |
| `accept`      | `string \| null` | `null`                      |
| `directory`   | `boolean`        | `false`                     |
| `buttonLabel` | `string`         | `''` → `rtKit.uiChooseFile` |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание | здесь                           |
| ----------- | ---------------------- | --------- | ------------------------------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    | принимается, но не рисуется     |
| `disabled`  | `boolean`              | `false`   | —                               |
| `controlId` | `string \| null`       | `null`    | —                               |
| `ariaLabel` | `string \| null`       | `null`    | —                               |
| `clearable` | `boolean`              | `true`    | крестик стоит у каждой карточки |
| `bordered`  | `boolean`              | `true`    | принимается, но не рисуется     |

## Выходы

Своих выходов нет: набор файлов уходит через `ControlValueAccessor`, то есть в связанный контрол
формы.

## Рядом

- [`rt-file-drop`](./?path=/docs/components-filedrop--docs) — приём файлов перетаскиванием.
- [`rt-file-card`](./?path=/docs/components-filecard--docs) — чем нарисован каждый выбранный файл.

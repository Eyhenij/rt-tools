# `rt-section-nav`

Плитки разделов: иконка, подпись, подсветка текущего.

```html
<rt-section-nav [items]="sections()" (itemSelect)="goTo($event)" />
```

| вход    | тип                                      | умолчание      |
| ------- | ---------------------------------------- | -------------- |
| `items` | `readonly { id, icon, label, active }[]` | **обязателен** |

| выход        | тип                              |
| ------------ | -------------------------------- |
| `itemSelect` | `string` — идентификатор раздела |

## Главное, что нужно знать

**Активность приходит снаружи, в самом наборе.** Нажатие только просит открыть раздел; подсветку
двигает уже новый набор, пришедший после перехода. Компонент состояния не держит.

## Края

- Плитка — настоящая `<button>`: до неё доходят клавиатурой.
- Активная плитка помечена тремя способами: модификатором, `data-active` и `aria-current="page"`.
- Идентификатор дублируется атрибутом `data-key`.
- Пустой набор рисует пустую навигацию.

<Title>SectionNav — `rt-section-nav`</Title>

Полоса плиток для перехода между разделами: иконка, подпись и подсветка активной. Плитка —
настоящая `<button>`, до неё доходят клавиатурой.

```html
<rt-section-nav [items]="sections()" (itemSelect)="openSection($event)" />
```

## Когда применять

- Переход между разделами одного экрана, когда их немного и у каждого есть иконка.
- Боковая навигация карточки или панели, где вкладки были бы тесны.

## Когда не применять

- **Переключение содержимого на месте** — [`rt-tabs`](./?path=/docs/components-tabs--docs):
  вкладки не уводят с экрана, а плитки читаются как переход.
- **Длинный список разделов** — обычный список: плитки рассчитаны на несколько штук.

## Оси

Своя ось у компонента одна, и приходит она снаружи — в самом наборе.

| ось               | значения                  | умолчание |
| ----------------- | ------------------------- | --------- |
| активность плитки | первая, средняя, ни одной | ни одной  |
| длина набора      | одна, три, пять плиток    | —         |

**Активность приходит снаружи, в самом наборе.** Нажатие только просит открыть раздел;
подсветку двигает уже новый набор, пришедший после перехода. Компонент состояния не держит —
подсветка, не сдвинувшаяся после нажатия, означает, что потребитель не прислал новый набор.

## Края

| край            | что происходит                                |
| --------------- | --------------------------------------------- |
| пустой набор    | рисуется пустая навигация                     |
| длинная подпись | переносится по словам, иконка остаётся сверху |

## Состояния

| состояние | чем задаётся                    | что меняется             |
| --------- | ------------------------------- | ------------------------ |
| обычное   | —                               | прозрачный фон           |
| наведение | `:hover:not(--active)`          | подложка плитки          |
| нажатие   | `:active`                       | подложка темнее          |
| активная  | модификатор `--active` из входа | подсветка и цвет подписи |

Активная плитка наведением не подсвечивается: правило прямо исключает её, иначе переход на
текущий раздел выглядел бы доступным.

## Доступность

- Плитка — нативная `<button>`: фокус, `Enter` и `Space` достаются от браузера.
- Активная помечена тремя способами: модификатором, `data-active` и `aria-current="page"` —
  цвет не остаётся единственным признаком.
- Идентификатор дублируется атрибутом `data-key`: по нему плитку находят проверки.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**. В тёмной подсветка активной плитки
уходит от яркого синего.

## Рядом

- [`rt-tabs`](./?path=/docs/components-tabs--docs) — переключение содержимого на месте.

## Входы

| вход    | тип                             | умолчание | что делает                                         |
| ------- | ------------------------------- | --------- | -------------------------------------------------- |
| `items` | `readonly IRtSectionNav.Item[]` | `[]`      | плитки: идентификатор, иконка, подпись, активность |

## Выходы

| выход        | что сообщает                                                      |
| ------------ | ----------------------------------------------------------------- |
| `itemSelect` | нажата плитка; подсветку двигает потребитель, прислав новый набор |

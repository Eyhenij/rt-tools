# `rt-service-logo`

```html
<rt-service-logo size="sm" [logos]="[{ src: method.logoUrl, label: method.name }, { icon: 'wallet', label: 'Bank transfer' }]" />
```

| вход    | тип                              | умолчание  |
| ------- | -------------------------------- | ---------- |
| `logos` | `readonly IRtServiceLogo.Item[]` | обязателен |
| `size`  | `'xs' \| 'sm' \| 'md' \| 'lg'`   | `'md'`     |

Выходов нет.

Спек — `docs/specs/ui-kit-v2/service-logo/`; здесь только устройство папки.

## Главное, что нужно знать

**Числа — атома «Service Logo», и все они в свойствах блока.** Круг, высота знака, шаг внахлёст и
тень объявлены на корне блока ступенями шкалы, модификатор размера их переназначает. Тени и
заливка круга — свои имена слоя оформления: `--rt-shadow-service-logo-*` и
`--rt-color-service-logo-bg`.

**Следующий круг лежит поверх предыдущего порядком разметки.** Круги позиционированы без
`z-index`, нахлёст — отрицательный отступ, равный разнице круга и шага.

**Знак значком — `rt-icon` ступенью, равной высоте знака:** `xs` → `sm` (16), `sm` → `md` (20), `md` → `xl` (32),
`lg` → `3xl` (48). `rt-icon` сам скрыт от диктора, поэтому имя несёт обёртка с `role="img"`.

## Края

- Знаков компаний в пакете нет: картинку даёт приложение адресом. В витрине стоят заглушки из
  `stories/component/story-placeholder-marks.ts`.
- Круг светлый и в тёмной теме: знаки нарисованы под светлый фон. Цвет значка задан кругом
  (`--rt-color-service-logo-mark`), иначе в тёмной теме значок берёт светлый текст и пропадает.
- Корень шаблона — `ng-container`: класс блока висит только на хосте.

## Рядом

- [`rt-logo`](../logo/rt-logo.component.ts) — знак самого приложения.
- [`rt-icon`](../icon/rt-icon.component.ts) — значок кита внутри круга.

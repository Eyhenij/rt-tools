<Title>ServiceLogo — `rt-service-logo`</Title>

Знак внешней службы в светлом круге с мягкой тенью. Несколько знаков ложатся внахлёст, каждый
следующий поверх предыдущего. Числа — атома «Service Logo» дизайн-системы.

```html
<rt-service-logo size="sm" [logos]="[{ src: '/logos/card-network.svg', label: 'Card network' }]" />
<rt-service-logo [logos]="[{ src: method.logoUrl, label: method.name }, { icon: 'wallet', label: 'Bank transfer' }]" />
```

## Когда применять

- Список способов оплаты, подключённых служб, площадок — везде, где служба показана своим знаком.
- Способ, который обслуживают несколько компаний сразу: их знаки встают одним рядом внахлёст.

## Когда не применять

- **Знак самого приложения** — `rt-logo`.
- **Нажимаемый знак** — компонент картинка, а не кнопка: нажатие вешает приложение снаружи.

## Оси

| ось          | значения                               | умолчание |
| ------------ | -------------------------------------- | --------- |
| размер       | `sm`, `md`, `lg`                       | `md`      |
| число знаков | один, два, три (и больше тем же шагом) | —         |
| род знака    | картинка по адресу, значок кита        | —         |

| размер | круг | высота знака | рамка знака | шаг внахлёст | размытие тени |
| ------ | ---- | ------------ | ----------- | ------------ | ------------- |
| `sm`   | 40   | 20           | 27.5×20     | 24           | 24            |
| `md`   | 64   | 32           | 44×32       | 40           | 40            |
| `lg`   | 96   | 48           | 66×48       | 60           | 56            |

Картинка вписывается в рамку знака целиком (`object-fit: contain`), по центру круга. Ширина ряда —
круг плюс шаг на каждый знак после первого.

## Что показать нельзя

**Знаки настоящих компаний.** В пакете их нет: это чужие товарные знаки, и меняются они по
расписанию своих владельцев. Адрес картинки даёт приложение. В витрине стоят **безымянные
заглушки** — простые фигуры, без них матрица не показывала бы ни рамки знака, ни нахлёста.

## Состояния

**Состояний взаимодействия у компонента нет:** он ничего не запускает, не принимает фокус, и ни
`:hover`, ни `:focus-visible`, ни `:active` в его SCSS не объявлено.

## Доступность

- Ряд — список (`role="list"`), каждый круг — его пункт.
- Картинка несёт `alt`, равный подписи знака; знак значком — `role="img"` с `aria-label`, равным
  подписи. Диктор читает ряд как список имён служб в заданном порядке.

## Оформление

Круг светлый в обеих темах: знаки чужих компаний нарисованы под светлый фон. Значок кита в круге
тёмный тоже в обеих темах.

Свойства блока: `--rt-service-logo-size` — сторона круга, `--rt-service-logo-mark-height` — высота
знака, `--rt-service-logo-step` — шаг внахлёст, `--rt-service-logo-shadow` — тень круга,
`--rt-service-logo-radius` — скругление круга, `--rt-service-logo-bg` — заливка круга, `--rt-service-logo-color` — цвет значка кита в круге.

## Входы

| вход    | тип                              | умолчание  |
| ------- | -------------------------------- | ---------- |
| `logos` | `readonly IRtServiceLogo.Item[]` | обязателен |
| `size`  | `'sm' \| 'md' \| 'lg'`           | `'md'`     |

`IRtServiceLogo.Item` — `{ src: string; label: string }` либо `{ icon: IRtIcon.Name; label: string }`.

## Выходы

Своих выходов нет.

## Рядом

- [`rt-logo`](./?path=/docs/atoms-logo-overview--docs) — знак самого приложения.
- [`rt-icon`](./?path=/docs/atoms-icon-overview--docs) — значок кита, которым рисуется знак без картинки.

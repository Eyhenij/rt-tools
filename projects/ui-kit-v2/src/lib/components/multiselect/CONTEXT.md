# `rt-multiselect<TValue>`

```html
<rt-field label="Города">
    <rt-multiselect [formControl]="cities" [options]="options" [maxChips]="3" />
</rt-field>
```

Свои входы поверх общих из [`RtFormControlBase`](../form-control/CONTEXT.md):

| вход          | тип                                                                          | умолчание                     |
| ------------- | ---------------------------------------------------------------------------- | ----------------------------- |
| `options`     | `ReadonlyArray<{ label, value, disabled? }>` (тот же тип, что у `rt-select`) | `[]`                          |
| `placeholder` | `string`                                                                     | `''` → `rtKit.uiSelectValues` |
| `maxChips`    | `number`                                                                     | `3`                           |

Значение — `ReadonlyArray<TValue>`. Отдельного выхода выбора нет: значение едет только формой.

## Главное, что нужно знать

**Список не закрывается после выбора.** Иначе каждый следующий вариант приходилось бы выбирать,
открывая панель заново. Закрывают его Escape, клик мимо или повторный клик по триггеру.

**Выбранное рисуется фишками внутри триггера**, а сверх лимита появляется счётчик `+N`.
Крестик на фишке снимает выбор и **не раскрывает список** — хотя фишка и лежит внутри кнопки.

## Края

- Значение всегда заменяется новым массивом, прежний не правится: форма видит новую ссылку.
- `null` в форме читается как пустой выбор.
- Закрытие панели помечает контрол тронутым; `FormControl.disable()` закрывает раскрытую панель.
- Подпись фишки берётся из `options` пайпом `rtMultiselectLabel`; для значения вне набора
  подставляется его строковое представление.
- Отключённые опции не выбираются, пустой набор даёт `rtKit.uiNoOptions`.

## Клавиатура

Как у [`rt-select`](../select/CONTEXT.md), с одним отличием: `Enter`/`Space` **переключают**
подсвеченную опцию, оставляя список открытым.

## Рядом

- [`rt-select`](../select/CONTEXT.md) — одно значение.

<Title>Multiselect — `rt-multiselect`</Title>

Выбор нескольких значений из известного заранее набора. Выбранное остаётся в триггере фишками,
а сверх лимита появляется счётчик `+N`. В форме лежит массив `value`; подписи берутся из
`options` и отдельно не хранятся.

```html
<rt-field label="Города">
    <rt-multiselect [options]="cities" [maxChips]="3" [formControl]="selectedCities" />
</rt-field>
```

## Когда применять

- Из набора выбирают несколько: города, роли, признаки фильтра.
- Выбранное надо видеть, не раскрывая списка, — фишки для этого и нужны.

## Когда не применять

- **Одно значение** — [`rt-select`](./?path=/docs/molecules-forms-select-overview--docs).
- **Набор ищется на сервере** — [`rt-autocomplete`](./?path=/docs/molecules-forms-autocomplete-overview--docs).
- **Два-три независимых признака** — [`rt-checkbox`](./?path=/docs/atoms-forms-checkbox-overview--docs):
  раскрывать список ради двух флажков дороже, чем показать оба.

## Оси

Оси не перемножаются: размер, число фишек и рамка меняют разные части триггера и вместе ничего
нового не показывают.

| ось    | значения                                                    | умолчание |
| ------ | ----------------------------------------------------------- | --------- |
| размер | `sm`, `md`, `lg` — 32 / 40 / 48 px                          | `md`      |
| фишки  | пусто, одна, до предела, сверх предела (`+N`), `maxChips=1` | пусто     |
| рамка  | видна, снята (`bordered=false`)                             | видна     |
| панель | список, пустой набор                                        | список    |

**Оси, которых не видно.** `controlId` и `ariaLabel` уходят в атрибуты; `placeholder` виден
только при пустом выборе — он и показан первой ячейкой ряда фишек.

**Панель показана отдельными историями, и открытая панель в истории ровно одна.** Второй жест
для CDK — указатель за пределами первой панели, и она закрывается; рядом стоящих панелей не
бывает. Поэтому виды опций — отмеченная, подсвеченная, отключённая — показаны набором внутри
одной панели.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у триггера нет         |
| фокус         | `:focus`                             | рамка фокуса и `--rt-input-focus-shadow`           |
| раскрыто      | панель открыта                       | рамка фокуса, шеврон повёрнут на 180°              |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | триггер скрыт, выбранное перечислено через запятую |

Опция внутри панели живёт своими состояниями: `--selected` — отмеченная (флажок и заливка),
`--active` — подсвеченная клавиатурой, `--disabled` — невыбираемая. Все три показаны в истории
**Panel**.

**Список не закрывается после выбора** — иначе каждый следующий вариант приходилось бы выбирать
заново. Закрывают его `Escape`, щелчок мимо или повторный щелчок по триггеру.
`FormControl.disable()` закрывает раскрытую панель.

## Доступность

- Триггер — `<button>` с `aria-haspopup="listbox"`, `aria-expanded` и `aria-controls`.
- Опции поодиночке не фокусируются: подсвеченная называется через `aria-activedescendant` на
  триггере. Флажок внутри опции исключён из таб-порядка — он рисует состояние, а не принимает
  жест.
- Клавиатура как у [`rt-select`](./?path=/docs/molecules-forms-select-overview--docs), с одним
  отличием: `Enter` и `Space` **переключают** подсвеченную опцию, оставляя список открытым.
- Крестик на фишке снимает выбор и **не раскрывает список**, хотя фишка и лежит внутри кнопки.

## Оформление

Триггер берёт общую группу свойств полей кита (`--rt-input-*`), фишку рисует
[`rt-tag`](./?path=/docs/atoms-tag-overview--docs) с `severity="info"`, панель —
`--rt-color-bg-surface`, `--rt-color-border-subtle`, `--rt-shadow-md`.

**Панели нет в светло-тёмной паре.** Она рисуется в контейнере оверлеев CDK — за пределами
блока, которому пара назначает свойства темы. Тёмную панель смотрят переключателем темы в
тулбаре.

## Входы

| вход             | тип                                          | умолчание               |
| ---------------- | -------------------------------------------- | ----------------------- |
| `options`        | `ReadonlyArray<{ label, value, disabled? }>` | `[]`                    |
| `placeholder`    | `string`                                     | `''` → `uiSelectValues` |
| `maxChips`       | `number`                                     | `3`                     |
| `panelWidth`     | `'trigger' \| 'trigger-min' \| 'auto'`       | `'trigger-min'`         |
| `panelMaxHeight` | `string \| null`                             | `null`                  |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы. Массив всегда заменяется новым — прежний не правится, и форма видит новую ссылку.

## Свой указатель

Разметку кнопки потребитель объявляет шаблоном с признаком `rtSelectTrigger` — тем же, что у
`rt-select`. Обстановка шаблона несёт четыре значения: открыт ли список, что выбрано, подпись и
отключён ли выбор.

С объявленным шаблоном кнопка перестаёт выглядеть полем: уходят фон, рамка покоя и ширина хозяина,
уходят и полевые состояния — кольцо фокуса, рамка открытого списка и рамка ошибки. Ход клавишами
остаётся видимым: вместо кольца встаёт обводка по содержимому кнопки.

Показы указателя стоят отдельной страницей — [`SelectTrigger`](./?path=/story/molecules-forms-selecttrigger--families).

Панель при этом не мерится кнопкой: её ширина не меньше кнопки и дальше растёт по содержимому,
а прокрутки внутри нет вовсе — содержимое помещается целиком. Прежнее поведение возвращает вход
`panelWidth`, предел высоты назначает `panelMaxHeight`, и с ним появляется прокрутка.

## Рядом

- [`rt-select`](./?path=/docs/molecules-forms-select-overview--docs) — тот же список для одного значения.
- [`rt-tag`](./?path=/docs/atoms-tag-overview--docs) — чем нарисована фишка выбранного.
- [`rt-field`](./?path=/docs/molecules-forms-field-overview--docs) — подпись, звёздочка, текст ошибки, режим чтения.

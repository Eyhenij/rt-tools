# `rt-spinner`

```html
<rt-spinner color="primary" [diameter]="32" />
```

| вход         | тип                                      | умолчание   |
| ------------ | ---------------------------------------- | ----------- |
| `diameter`   | `number \| string` (px)                  | `32`        |
| `color`      | `'primary' \| 'neutral' \| 'on-primary'` | `'primary'` |
| `appearance` | `'border' \| 'arc'`                      | `'border'`  |
| `overlay`    | `boolean`                                | `false`     |
| `backdrop`   | `boolean` — только вместе с `overlay`    | `false`     |
| `plate`      | `boolean`                                | `false`     |

Выходов нет. Без `overlay`, `plate` и `arc` собственной разметки нет — кольцо рисуется на host-е,
и так спиннер стоит в компонентах кита. Любой из этих входов включает внутреннюю разметку.

## Главное, что нужно знать

**Спиннер не решает, показывать ли себя.** Условной отрисовки внутри нет — это дело вмещающего.
Подложку и накрытие блока он рисует по просьбе: `overlay` занимает позиционированного родителя,
`backdrop` приглушает его содержимое. Слой оверлея — `sticky`, переназначается свойством
`--rt-spinner-overlay-z`. Таблица рисует свой sticky-overlay и кладёт спиннер внутрь, кнопка
подменяет им иконку.

Диаметр едет свойством оформления `--rt-spinner-diameter`, а не классом, — поэтому размер
задаётся произвольным числом, а не шкалой.

## Как этим пользоваться

- `on-primary` — для спиннера поверх залитой основной палитрой поверхности (кнопка, баннер).
- `neutral` — для тонких строчных индикаторов рядом с текстом.
- Host объявлен `role="status"` с `aria-live="polite"`: скринридер сообщит о появлении, не
  перебивая чтение. Отдельной подписи компонент не даёт — если состояние важно назвать словами,
  положи текст рядом.

## Края

- Вращение выключается у пользователей с `prefers-reduced-motion`. Проверять это в спеке нечем —
  правило живёт в SCSS.

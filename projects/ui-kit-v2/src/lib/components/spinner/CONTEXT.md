# `rt-spinner`

```html
<rt-spinner color="primary" [diameter]="32" />
```

| вход       | тип                                      | умолчание   |
| ---------- | ---------------------------------------- | ----------- |
| `diameter` | `number \| string` (px)                  | `32`        |
| `color`    | `'primary' \| 'neutral' \| 'on-primary'` | `'primary'` |

Выходов нет. Собственной разметки нет — кольцо рисуется на host-е.

## Главное, что нужно знать

**Спиннер не решает, показывать ли себя.** Ни условной отрисовки, ни подложки внутри нет: и то,
и другое — дело вмещающего. Таблица рисует свой sticky-overlay и кладёт спиннер внутрь, кнопка
подменяет им иконку.

Диаметр едет свойством оформления `--rt-spinner-diameter`, а не классом, — поэтому размер
задаётся произвольным числом, а не шкалой.

## Как этим пользоваться

- `on-primary` — для спиннера поверх залитой основной палитрой поверхности (кнопка, баннер).
- `neutral` — для тонких строчных индикаторов рядом с текстом.
- Host объявлен `role="status"` с `aria-live="polite"`: скринридер сообщит о появлении, не
  перебивая чтение. Отдельной подписи компонент не даёт — если состояние важно назвать словами,
  положи текст рядом.

## Края

- Вращение выключается у пользователей с `prefers-reduced-motion`. Проверять это в спеке нечем —
  правило живёт в SCSS.

<Title>Card — `rt-card`</Title>

Прямоугольный кусок содержимого со своей шапкой, телом и подвалом. Рисуется тегом `<article>` —
карточка самостоятельна, а не украшение вокруг чужого текста.

```html
<rt-card header="Договор">Подписан 14 марта</rt-card>

<rt-card clickable ariaLabel="Открыть договор" (cardClick)="open()">
    <span rtCardHeader>Договор №2024-118</span>
    Подписан 14 марта
    <span rtCardFooter>Действует до 14 марта 2027</span>
</rt-card>
```

## Когда применять

- Самостоятельный кусок содержимого в списке или на панели: запись, объект, сводка.
- Плитка, открывающая подробности, — тогда с `clickable` и обязательным `ariaLabel`.

## Когда не применять

- **Просто рамка вокруг текста** — карточка объявляет себя `<article>`, и скринридер прочтёт
  её как отдельный материал.
- **Строка таблицы** — [`rt-table`](./?path=/docs/organisms-tables-lists-table-overview--docs).

## Оси

| ось          | значения                                                         | умолчание         |
| ------------ | ---------------------------------------------------------------- | ----------------- |
| заголовок    | нет, короткий, длинный                                           | нет               |
| наполнение   | только содержимое, заголовок входом, шапка проекцией, с подвалом | только содержимое |
| нажимаемость | обычная, `clickable`                                             | обычная           |

Заголовок задаётся двумя способами и оба показаны: входом `header` — тогда он рисуется тегом
`<h3>`, — и проекцией `[rtCardHeader]`, когда в шапке нужна разметка.

## Края

| край              | что происходит                                   |
| ----------------- | ------------------------------------------------ |
| пустая шапка      | существует всегда, прячут её стили — не разметка |
| пустой подвал     | то же самое                                      |
| длинный заголовок | переносится по словам, высота карточки растёт    |

## Состояния

**Без `clickable` карточка не интерактивна вовсе**: ни `role`, ни `tabindex`, ни событий. Это
намеренно — иначе текст внутри нельзя было бы выделить, не «нажав» карточку.

| состояние       | чем задаётся              | что меняется         |
| --------------- | ------------------------- | -------------------- |
| обычное         | —                         | фон и рамка карточки |
| наведение       | `:hover` при `clickable`  | подложка и тень      |
| нажатие         | `:active` при `clickable` | подложка темнее      |
| фокус с клавиши | `:focus-visible`          | кольцо фокуса        |

Состояния показаны только у нажимаемой: у обычной их нет в стилях, и ряд был бы четырьмя
одинаковыми ячейками.

## Доступность

- С `clickable` карточка объявляется `role="button"`, встаёт в таб-порядок и реагирует на
  `Enter` и `Space`.
- **`ariaLabel` при `clickable` обязателен**: содержимое карточки именем контрола не служит —
  скринридер прочтёт весь текст подряд вместо названия действия.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-stat-tile`](./?path=/docs/molecules-data-stattile-overview--docs) — плитка с одним числом.
- [`rt-empty-state`](./?path=/docs/molecules-emptystate-overview--docs) — заглушка вместо содержимого.

## Входы

| вход        | тип              | умолчание | что делает                                            |
| ----------- | ---------------- | --------- | ----------------------------------------------------- |
| `header`    | `string \| null` | `null`    | заголовок шапки тегом `<h3>`                          |
| `ariaLabel` | `string \| null` | `null`    | имя для скринридера; при `clickable` обязателен       |
| `clickable` | `boolean`        | `false`   | роль кнопки, таб-порядок, отклик на `Enter` и `Space` |

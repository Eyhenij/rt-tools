<Title>ServiceBlock — `rt-service-block`</Title>

Блок службы — первый блок тела панели настройки подключения: знак службы, справа имя службы и
строка-описание, под блоком черта. Одна разметка на интеграции, способы оплаты и мессенджеры.
Числа — компонента «Service Block» дизайн-системы.

```html
<rt-service-block [logos]="[{ src: service.logoUrl, label: service.name }]" [name]="service.name" [description]="service.purpose" />
```

## Когда применять

- Панель настройки подключения к внешней службе: оплата, интеграция, мессенджер. Блок стоит
  первым в её теле и говорит, что именно настраивается.

## Когда не применять

- **Строка списка служб** — знак в строке берётся [`rt-service-logo`](./?path=/docs/molecules-servicelogo-overview--docs)
  размера `sm`, без черты.
- **Нажимаемая карточка службы** — блок не элемент управления: нажатие он не принимает.

## Оси

| ось    | значения                                         | умолчание |
| ------ | ------------------------------------------------ | --------- |
| состав | один знак, три знака, знак значком, без описания | —         |
| ширина | место панели 492, место телефона 288             | —         |

| часть             | число                                                       |
| ----------------- | ----------------------------------------------------------- |
| знак              | `rt-service-logo` размера `md`: круг 64                     |
| знак — текст      | 16                                                          |
| имя — описание    | 2                                                           |
| имя               | ступень `xl` (20), полужирный, высота строки 1.35           |
| описание          | ступень `sm` (14), обычный, высота строки 1.5, приглушённый |
| под текстом черта | отступ 20, черта 1 цвета `--rt-color-border-subtle`         |

Блок занимает всю ширину своего места. Знак держит свой размер, текст берёт остаток: на узком
месте имя и описание переносятся на следующие строки, длинное слово рвётся.

Размера знака у блока нет: компонент дизайн-системы рисует только `md`.

## Состояния

**Состояний взаимодействия у компонента нет:** он ничего не запускает, не принимает фокус, и ни
`:hover`, ни `:focus-visible`, ни `:active` в его SCSS не объявлено.

## Доступность

- Знак — список имён служб, его читает `rt-service-logo` по подписям знаков.
- Имя и описание — обычный текст в потоке, диктор читает их подряд после знака.

## Оформление

Свойства блока: `--rt-service-block-gap` — промежуток от знака до текста,
`--rt-service-block-text-gap` — от имени до описания, `--rt-service-block-padding-bottom` —
отступ до черты, `--rt-service-block-divider` — черта, `--rt-service-block-name-size`,
`--rt-service-block-name-weight`, `--rt-service-block-name-line-height`,
`--rt-service-block-name-color` — имя, `--rt-service-block-description-size`,
`--rt-service-block-description-weight`, `--rt-service-block-description-line-height`,
`--rt-service-block-description-color` — описание.

## Входы

| вход          | тип                              | умолчание  |
| ------------- | -------------------------------- | ---------- |
| `logos`       | `readonly IRtServiceLogo.Item[]` | обязателен |
| `name`        | `string`                         | обязателен |
| `description` | `string`                         | `''`       |

`IRtServiceLogo.Item` — тот же знак, что принимает `rt-service-logo`: `{ src: string; label: string }`
либо `{ icon: IRtIcon.Name; label: string }`.

## Выходы

Своих выходов нет.

  которым блок рисует свою левую часть.

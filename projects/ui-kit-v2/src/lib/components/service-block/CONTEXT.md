# `rt-service-block`

```html
<rt-service-block [logos]="[{ src: service.logoUrl, label: service.name }]" [name]="service.name" [description]="service.purpose" />
```

| вход          | тип                              | умолчание  |
| ------------- | -------------------------------- | ---------- |
| `logos`       | `readonly IRtServiceLogo.Item[]` | обязателен |
| `name`        | `string`                         | обязателен |
| `description` | `string`                         | `''`       |

Выходов нет.

Спек — `docs/specs/ui-kit-v2/service-block/`; здесь только устройство папки.

## Главное, что нужно знать

**Знак — готовый `rt-service-logo` без входа размера, то есть `md`.** Знаки передаются тем же
типом `IRtServiceLogo.Item`, своей модели у блока нет: второе имя одного типа разошлось бы с
первым.

**Числа — компонента «Service Block», и все они в свойствах блока.** Промежутки, ступени шрифта,
цвета и черта объявлены на корне блока ступенями шкалы.

**Текст переносится, знак — нет.** Знак стоит `flex: none`, место текста ужимается до нуля и
переносит слова по любому знаку (`overflow-wrap: anywhere`).

## Края

- Пустое описание не рисуется: имя остаётся одно, по центру знака.
- Корень шаблона — `ng-container`: класс блока висит только на хосте.
- Своих текстов нет: имя, описание и подписи знаков даёт приложение.

<Title>DraggableTree — `rt-draggable-tree`</Title>

Дерево, узлы которого человек переставляет: перетаскивает строку за ручку до, после или внутрь
другой, или двигает клавишами с Alt. Узел — тот же `IRtTree.Node`, что у
[`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs); дерево ничего не выбирает и отдаёт
приложению новый порядок тех же узлов.

```html
<rt-draggable-tree ariaLabel="Разделы" [(nodes)]="sections" (moved)="save($event)" />
<rt-draggable-tree ariaLabel="Разделы" [canDrop]="onlyIntoFolders" [(nodes)]="sections">
    <ng-template rtDraggableTreeNode let-node>
        <span>{{ node.label }}</span>
        <rt-tag size="sm" [value]="node.description ?? ''" />
    </ng-template>
</rt-draggable-tree>
```

## Когда применять

- Порядок разделов, папок отчётов, пунктов меню, который человек задаёт сам.
- Перенос узла в другую папку того же дерева.

## Когда не применять

- **Выбор узлов** — [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs): там флажки,
  радио и поиск; здесь отметок нет.
- **Плоский список без вложенности** — перетаскивание строк есть у списков кита, например у
  настроек колонок таблицы.

## Оси

| ось              | значения                           | умолчание |
| ---------------- | ---------------------------------- | --------- |
| содержимое       | плоский список, вложенность, пусто | —         |
| выключенный узел | нет, есть                          | нет       |
| разметка строки  | подпись, разметка приложения       | подпись   |

**Оси, которых не видно.** Места сброса — черта над строкой, черта под строкой и рамка строки —
существуют только пока строку тянут: это состояние перетаскивания, в неподвижном кадре его нет. Их
видно в **Playground**: строку тянут за ручку слева. `canDrop` и `ariaLabel` ничего не рисуют сами.

## Состояния

| состояние           | чем задаётся                             | что меняется                              |
| ------------------- | ---------------------------------------- | ----------------------------------------- |
| обычное             | —                                        | —                                         |
| наведение           | указатель над строкой                    | фон строки `--rt-color-bg-hover`          |
| фокус с клавиши     | `:focus-visible` на дереве               | кольцо `--rt-draggable-tree-focus-shadow` |
| подсвеченная строка | стрелки клавиатуры, клик                 | фон строки, как при наведении             |
| строка в руке       | перетаскивание                           | строка идёт за указателем с тенью         |
| место перед, после  | указатель в верхней, нижней трети строки | черта у края строки цели                  |
| место внутрь        | указатель в середине строки контейнера   | рамка строки цели                         |
| выключенный узел    | `disabled` у узла                        | строка приглушена, ручки нет              |

## Клавиатура

| клавиша     | что делает                                                      |
| ----------- | --------------------------------------------------------------- |
| ↓ / ↑       | следующая / предыдущая видимая строка                           |
| → / ←       | раскрыть / свернуть ветку и пройти по уровням — как в `rt-tree` |
| Alt + ↑ / ↓ | сдвинуть узел среди соседей                                     |
| Alt + ←     | вынести узел из ветки — он встаёт сразу после неё               |
| Alt + →     | положить узел последним в контейнер прямо над ним               |
| Enter       | сообщить выходом `picked`                                       |

## Правила переноса

- Внутрь принимает только контейнер — узел с массивом `children`, даже пустым.
- Узел не уходит в своё поддерево.
- Выключенный узел не двигается, но остаётся целью.
- Функция `canDrop(узел, цель, место)` запрещает места приложения: `false` — место не предлагается.

## Доступность

- `role="tree"` на хосте, `role="treeitem"` на строках с `aria-level`, `aria-expanded` у веток и
  `aria-selected` у подсвеченной строки.
- Ручка помечена как оформление: без мыши узел переставляют клавишами с Alt.
- Доступное имя даёт вход `ariaLabel`.

## Оформление

Строку в руке CDK выносит в конец страницы, поэтому свойства строки объявлены на самой строке.

| свойство                             | что задаёт                   | умолчание                   |
| ------------------------------------ | ---------------------------- | --------------------------- |
| `--rt-draggable-tree-focus-shadow`   | кольцо фокуса дерева         | `--rt-shadow-focus-ring`    |
| `--rt-draggable-tree-indent`         | шаг отступа на уровень       | `--rt-space-lg`             |
| `--rt-draggable-tree-mark-width`     | толщина черты и рамки сброса | `--rt-border-width-thick`   |
| `--rt-draggable-tree-mark-color`     | цвет черты и рамки сброса    | `--rt-color-action-primary` |
| `--rt-draggable-tree-mark-radius`    | скругление рамки «внутрь»    | `--rt-radius-xs`            |
| `--rt-draggable-tree-preview-shadow` | тень строки в руке           | `--rt-shadow-md`            |

Длинная подпись обрезается многоточием, полный текст — в подсказке кита. При `pointer: coarse`
строка вырастает до `--rt-control-height-lg`.

## Входы

| вход        | тип                                   | умолчание  |
| ----------- | ------------------------------------- | ---------- |
| `nodes`     | `ReadonlyArray<IRtTree.Node<T>>`      | обязателен |
| `canDrop`   | `IRtDraggableTree.CanDrop<T> \| null` | `null`     |
| `ariaLabel` | `string \| null`                      | `null`     |

## Выходы

| выход         | что несёт                        | когда                                 |
| ------------- | -------------------------------- | ------------------------------------- |
| `nodesChange` | `ReadonlyArray<IRtTree.Node<T>>` | после переноса — пара к `nodes`       |
| `moved`       | `IRtDraggableTree.Moved<T>`      | после переноса: узел, родитель, место |
| `picked`      | `IRtTree.Node<T>`                | нажатие на строку или Enter           |

## Рядом

- [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs) — то же дерево для выбора узлов.

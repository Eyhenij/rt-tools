# `rt-draggable-tree`

```html
<rt-draggable-tree ariaLabel="Разделы" [canDrop]="canDrop" [(nodes)]="sections" (moved)="save($event)" (picked)="open($event)">
    <ng-template rtDraggableTreeNode let-node>
        <span>{{ node.label }}</span>
        <rt-tag size="sm" [value]="node.description ?? ''" />
    </ng-template>
</rt-draggable-tree>
```

| вход        | тип                                           | умолчание      |
| ----------- | --------------------------------------------- | -------------- |
| `nodes`     | `ReadonlyArray<IRtTree.Node<TValue>>` (model) | **обязателен** |
| `canDrop`   | `IRtDraggableTree.CanDrop<TValue> \| null`    | `null`         |
| `ariaLabel` | `string \| null`                              | `null`         |

| выход         | тип                                   |
| ------------- | ------------------------------------- |
| `nodesChange` | `ReadonlyArray<IRtTree.Node<TValue>>` |
| `moved`       | `IRtDraggableTree.Moved<TValue>`      |
| `picked`      | `IRtTree.Node<TValue>`                |

Публичный метод: `handleKeydown(event)`.

## Главное, что нужно знать

**Узел и строки — те же, что у `rt-tree`.** Строки и уровни считает `rtTreeRows`, боковые стрелки —
`rtTreeSideKey`. Своей модели дерева у компонента нет.

**Узлы не меняются никогда.** Перенос пишет в `nodes` новый массив: ветки на пути к узлу строятся
заново, остальные объекты остаются прежними. `moved` называет узел, его нового родителя и место
среди новых соседей.

**Место сброса считает чистая функция** `rtDragPlace` по рамке строки под указателем: верхняя треть —
перед, нижняя — после, середина — внутрь. Документ дерево не читает: рамки строк берутся у своих
узлов разметки.

## Края

- Внутрь принимает только контейнер — узел с массивом `children`, даже пустым.
- Узел не уходит в своё поддерево ни мышью, ни клавишей.
- Выключенный узел не тащится и не двигается клавишами, но остаётся целью.
- Alt+↑/↓ — среди соседей, Alt+← — сразу после своей ветки, Alt+→ — последним в контейнер прямо над
  узлом. Двигаться некуда — клавиша всё равно взята, порядок не меняется.
- При появлении раскрыты все ветки; свёрнутое человеком остаётся свёрнутым, а ветка, в которую
  положили узел, раскрывается.
- Строку тянут за ручку; ручка помечена как оформление, переставлять без мыши — клавишами.
- Длинная подпись обрезается многоточием, полный текст — в подсказке кита.

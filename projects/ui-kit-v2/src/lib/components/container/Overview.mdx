<Title>Container — `rt-container`</Title>

Каркас страницы: шапка, боковое меню, полосы панели инструментов, содержимое и правая
выезжающая панель. Зоны объявляются директивами на `ng-template` — каркас решает, **где** они
лежат, а не что в них.

```html
<rt-container height="viewport" mobileLeftNav="bottom">
    <ng-template rtContainerHeader><rt-header /></ng-template>
    <ng-template rtContainerLeftSidenav><rt-section-nav … /></ng-template>
    <ng-template rtContainerToolbarLeft><rt-filter-control … /></ng-template>
    <ng-template rtContainerContent><router-outlet /></ng-template>
    <ng-template rtContainerRightSidenav><app-details /></ng-template>
</rt-container>
```

## Когда применять

- Каркас приложения целиком: одна страница — один контейнер.
- Нужны зоны, которые не прокручиваются вместе с содержимым: меню, панель инструментов.

## Когда не применять

- **Раскладка внутри содержимого** — [`rt-workspace`](./?path=/docs/organisms-workspace-workspace-overview--docs):
  три колонки внутри одной зоны, а не каркас страницы.
- **Всплывающая панель** — [`rt-aside`](./?path=/docs/organisms-aside-aside-overview--docs).

## Оси

| ось              | значения                                 | умолчание |
| ---------------- | ---------------------------------------- | --------- |
| объявленные зоны | весь каркас, без меню, только содержимое | —         |

**Оси, которых не видно.**

- `height` — `auto` растёт под содержимое, `viewport` жёстко равен окну и отдаёт прокрутку
  зонам. Разницу видно только в настоящем окне: в уменьшенной ячейке витрины обе одинаковы.
- `mobileLeftNav` — `bottom` сворачивает меню в нижний ряд, но правило включается по ширине
  **окна** (не более 768 px), а не по ширине ячейки. Сеткой это не показать; смотреть надо,
  сузив окно.
- Правой панели в матрицах нет: её создаёт оверлей, открывается она вызовом `openRight()`, а
  событие открытия привязано к концу перехода. В статичной ячейке этого не увидеть. Её место,
  подложка и ширина показаны живыми историями **RightSide** и **RightOver**: кнопки в них
  открывают панель и переносят её между местами, ручка у левого края меняет ширину.

**Каркас показан уменьшенным.** Настоящий занимает окно целиком, и рядом два таких не поставить;
зоны наполнены полосками, а не компонентами кита.

## Состояния

| состояние             | чем задаётся          | что меняется                            |
| --------------------- | --------------------- | --------------------------------------- |
| зона объявлена        | `ng-template` с зоной | появляется её узел                      |
| зона не объявлена     | —                     | **узла нет вовсе**, а не пустой узел    |
| правая панель открыта | `openRight()`         | панель выезжает справа, поверх подложки |
| панель рядом          | `rightMode="side"`    | колонка справа, содержимое сужается     |
| панель без подложки   | `rightBackdrop=false` | страница доступна и прокручивается      |

**Правая панель существует, только когда её зона объявлена.** Оверлей под неё создаётся заранее
(`rightOverlayReady()`), а `openRight()` без объявленной зоны ничего не делает.

**Место правой панели переключается на ходу.** В `rightMode="side"` она стоит колонкой справа от
панели инструментов и содержимого и сужает их, закрытая сжимается до нуля и не принимает фокус.
В `over` — прежний оверлей. Открытая панель при переносе остаётся открытой, а её содержимое
создаётся заново на новом месте: набранное в нём не переносится. Рядом с содержимым подложки и
закрытия по Escape нет — панель часть страницы. На узком экране (не более 768 px) колонке нет
места, и панель ложится на зону содержимого во всю её ширину.

**Подложка под панелью поверх — по выбору.** `rightBackdrop=false` убирает её: страница не
замирает и принимает нажатия, а Escape по-прежнему сообщает `backdropClick`.

**Ширина правой панели — `rightWidth`, двусторонний вход в пикселях.** Без него панель шириной
по содержимому, как прежде. С `rightResizable` у её левого края стоит ручка: тянуть указателем,
стрелки — шаг 16 px, `Home` и `End` — пределы `rightMinWidth` и `rightMaxWidth`. Ручка объявлена
разделителем с текущей шириной.

**`rightOpened` и `rightClosed` привязаны к концу перехода панели.** Там, где анимаций нет
(проверки, `prefers-reduced-motion`), события не придут, а `rightOpen()` уже верен — смотреть
надо на него.

**Стопка уведомлений встроена в каркас** ([`rt-toaster`](./?path=/docs/atoms-feedback-toast-overview--docs)
внизу по центру): заводить её отдельно не нужно.

## Доступность

Зоны рисуются смысловыми тегами: `<header>`, `<aside>`, `<main>` — читалка находит их без
дополнительных ролей.

## Оформление

Раскладка — сетка с именованными областями; в `viewport` контейнер равен окну, документ не
прокручивается вовсе, а прокрутку берут зоны — каждая своя.

## Входы

| вход             | тип                    | умолчание |
| ---------------- | ---------------------- | --------- |
| `mobileLeftNav`  | `'keep' \| 'bottom'`   | `'keep'`  |
| `height`         | `'auto' \| 'viewport'` | `'auto'`  |
| `rightMode`      | `'over' \| 'side'`     | `'over'`  |
| `rightBackdrop`  | `boolean`              | `true`    |
| `rightWidth`     | `number \| null`       | `null`    |
| `rightResizable` | `boolean`              | `false`   |
| `rightMinWidth`  | `number`               | `240`     |
| `rightMaxWidth`  | `number`               | `960`     |

Зоны объявляются директивами: `rtContainerHeader`, `rtContainerLeftSidenav`,
`rtContainerRightSidenav`, `rtContainerToolbarLeft`, `rtContainerToolbarCenter`,
`rtContainerToolbarRight`, `rtContainerContent`.

## Выходы

| выход              | тип      | когда                             |
| ------------------ | -------- | --------------------------------- |
| `backdropClick`    | `void`   | щелчок по подложке правой панели  |
| `rightOpened`      | `void`   | правая панель доехала до открытия |
| `rightClosed`      | `void`   | правая панель доехала до закрытия |
| `rightWidthChange` | `number` | ручка задала новую ширину         |

Публичное API: `openRight()`, `closeRight()`, `rightOpen()`, `rightOverlayReady()`.

## Рядом

- [`rt-toaster`](./?path=/docs/atoms-feedback-toast-overview--docs) — та самая встроенная стопка уведомлений.
- [`rt-drawer`](./?path=/docs/organisms-layout-drawer-overview--docs) — боковая панель внутри участка страницы, а не каркаса.
- [`rt-workspace`](./?path=/docs/organisms-workspace-workspace-overview--docs) — раскладка внутри содержимого.
- [`rt-header`](./?path=/docs/organisms-layout-header-overview--docs) — что обычно кладут в зону шапки.

<Title>WelcomeDialog — `rt-welcome-dialog`</Title>

Окно первого входа: короткое приветствие роли и одна кнопка, которая его закрывает. Ни шапки,
ни крестика — уйти из окна можно только через кнопку.

```typescript
this.dialogService.open(RtWelcomeDialogComponent, {
    data: {
        message: 'Добро пожаловать\n\nЗдесь собраны договоры вашей организации.',
        ctaLabel: 'Перейти к договорам',
    },
});
```

## Когда применять

- Первый вход роли: коротко сказать, что человек видит и что делать дальше.

## Когда не применять

- **Вопрос с двумя исходами** — [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs) с двумя
  кнопками: у приветствия исход один.
- **Сообщение о результате действия** — [`rt-toast`](./?path=/docs/atoms-feedback-toast-overview--docs).

## Оси

| ось            | значения                                     | умолчание              |
| -------------- | -------------------------------------------- | ---------------------- |
| текст          | заголовок и абзацы, только заголовок, пустой | —                      |
| подпись кнопки | переведённое умолчание, своя подпись         | переведённое умолчание |

**Текст приходит одной строкой.** Первый абзац до пустой строки становится заголовком,
остальные — текстом окна. Разделитель — пустая строка, а не перенос: строки внутри абзаца
остаются одним абзацем.

## Края

| край          | что происходит                                                       |
| ------------- | -------------------------------------------------------------------- |
| пустой текст  | остаётся одна кнопка: ни заголовка, ни абзацев окно не рисует        |
| один абзац    | становится заголовком, текста под ним нет                            |
| длинный текст | абзацы переносятся по словам, окно растёт в высоту при ширине 335 px |

## Состояния

Своих состояний у окна нет: единственный интерактивный элемент — кнопка, её состояния описаны
на странице [`rt-button`](./?path=/docs/atoms-buttons-button-overview--docs).

**Данными открытия окно управляется целиком.** Входов у него нет ни одного, поэтому в витрине
каждая ячейка матрицы — свой экземпляр со своими данными.

## Доступность

- Окно объявляется как диалог с подписью для скринридера — она берётся из переведённых подписей
  кита, а не из текста приветствия.
- Кнопка — единственный способ уйти: закрытия по клавише или по щелчку мимо окно не даёт.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-dialog`](./?path=/docs/organisms-dialog-dialog-overview--docs) — обычное окно с шапкой и подвалом.
- [`rt-empty-state`](./?path=/docs/molecules-emptystate-overview--docs) — заглушка вместо содержимого.

## Входы

Входов нет: текст приветствия и подпись кнопки приходят данными открытия
(`RtDialogService.open(..., { data })`), а не привязкой в разметке.

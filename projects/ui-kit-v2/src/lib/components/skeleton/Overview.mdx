<Title>Skeleton — `rt-skeleton`</Title>

Серая заглушка формы будущего содержимого с мерцанием. Ничего не решает сама: показывать её
или нет — дело вмещающего.

```html
<rt-skeleton width="240px" height="16px" />
<rt-skeleton shape="circle" size="lg" />
```

## Когда применять

- Сетка карточек-призраков или макет страницы, который рисуется до прихода данных.
- Место, где пары «загрузка ↔ содержимое» нет: заглушка стоит сама по себе.

## Когда не применять

- **Есть пара «загрузка ↔ содержимое»** — [`rt-skeleton-wrapper`](./?path=/docs/components-skeletonwrapper-overview--docs):
  он решает, что показать, и пробрасывает сюда все эти входы. Это основной путь.
- **Ожидание без формы** — [`rt-spinner`](./?path=/docs/components-spinner-overview--docs):
  заглушка обещает форму содержимого, и обещать её незачем, когда содержимого не будет.

## Оси

| ось        | значения                                | умолчание          |
| ---------- | --------------------------------------- | ------------------ |
| фигура     | `rectangle`, `circle`, `square`         | `rectangle`        |
| размер     | `sm` 10, `md` 15, `lg` 20 px            | `md`               |
| скругление | по фигуре, `xs`, `sm`, `md`, `lg`, `xl` | по фигуре (`null`) |
| мерцание   | включено, выключено                     | включено           |

Перемножены две пары, и обе — по делу. **Фигура с размером:** круг и квадрат берут из размера
сторону, а прямоугольник его игнорирует и слушается `height`. **Фигура со скруглением:**
`null` значит не «без скругления», а «по фигуре», и у прямоугольника это `xl`, у квадрата —
`sm`. Круг всегда `50%` и скругление игнорирует.

Ширина и высота — свободные CSS-длины, а не шкала: осью их не показать, они меняются плавно.

## Состояния

**Состояний взаимодействия у компонента нет:** он не принимает ни фокус, ни указатель, и ни
одного правила с `:hover`, `:focus-visible` или `:active` в его SCSS не объявлено.

Мерцание снимается у пользователей с `prefers-reduced-motion`. В витрине это видно только с
системной настройкой и матрицей не показывается — вход `animation` выключает его вручную и
показан рядом.

## Доступность

Заглушка не несёт ни роли, ни подписи: для скринридера содержимого ещё нет, и объявлять о нём
нечего. Сообщение о загрузке даёт вмещающий — [`rt-spinner`](./?path=/docs/components-spinner-overview--docs)
делает это ролью `status`.

## Оформление

Цвет и мерцание идут от свойств поверхностей кита, поэтому заглушка совпадает с фоном, на
котором стоит. Размер и скругление отображаются в пиксели внутри компонента: шкала размеров
`sm` 10 / `md` 15 / `lg` 20, шкала скруглений `xs` 2 / `sm` 4 / `md` 6 / `lg` 10 / `xl` 999.

## Входы

| вход           | тип                                            | умолчание          |
| -------------- | ---------------------------------------------- | ------------------ |
| `shape`        | `'rectangle' \| 'circle' \| 'square'`          | `'rectangle'`      |
| `size`         | `'sm' \| 'md' \| 'lg'`                         | `'md'`             |
| `width`        | `string` — любая CSS-длина                     | `'100%'`           |
| `height`       | `string`                                       | `'10px'`           |
| `borderRadius` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| null` | `null` — по фигуре |
| `animation`    | `boolean`                                      | `true`             |

Умолчание высоты — 10px, хотя умолчание размера — `md` (15px). Расхождение намеренное: полоска
текста тоньше шага размера.

## Выходы

Своих выходов нет.

## Рядом

- [`rt-skeleton-wrapper`](./?path=/docs/components-skeletonwrapper-overview--docs) — обёртка «загрузка ↔ содержимое».
- [`rt-spinner`](./?path=/docs/components-spinner-overview--docs) — кольцо вместо формы.

<Title>WorkspaceDetails — `rt-workspace-details`</Title>

Правая панель рабочего стола: поля объекта, суммы, переключатели, действия, переход по этапам и
история событий. Какие блоки показывать, решают входы — заданный блок рисуется, пустой не
занимает места.

```html
<rt-workspace-details
    [title]="title()"
    [entityId]="id()"
    [rows]="rows()"
    [money]="money()"
    [actions]="actions()"
    [audit]="audit()"
    (actionClicked)="run($event)" />
```

## Когда применять

- Правый слот [`rt-workspace`](./?path=/docs/components-workspace-overview--docs): подробности
  выбранной записи.

## Когда не применять

- **Реквизиты без действий и этапов** — [`rt-detail-list`](./?path=/docs/components-detail-list-overview--docs)
  проще и не тянет за собой ни переходы, ни историю.

## Оси

| ось            | значения                                                         | умолчание |
| -------------- | ---------------------------------------------------------------- | --------- |
| заданные блоки | только поля; поля и суммы; поля, суммы, переключатели; ни одного | ни одного |
| вкладки        | одни поля — вкладок нет; с историей; с переходом                 | нет       |
| загрузка       | данные на месте, `loading`, `busy`                               | на месте  |
| действия       | без них, одно, три — с одним в работе и одним с подтверждением   | без них   |
| история        | события есть, грузится, догрузка снизу, событий нет              | —         |

Осью значений здесь не служит ни один вход: каждый включает свой блок, и вид панели решает то,
какие блоки заданы. Поэтому ряды сложены из наборов.

**Вкладки появляются только вместе с переходом или историей.** Пока есть одни поля, они
рисуются сразу: одна вкладка вместо содержимого была бы лишним щелчком.

## Чего матрицы не показывают

**Ошибка не рисуется внутри панели — она уходит уведомлением поверх.** Панель узкая, и
сообщение в ней сдвигало бы данные; одна и та же строка при этом не повторяется на каждой
перерисовке. Ячейки под ошибку в матрице поэтому нет — не потому, что её забыли.

## Края

| край                      | что происходит                                                               |
| ------------------------- | ---------------------------------------------------------------------------- |
| `loading`                 | заглушками подменяются значения полей и сумм; подписи остаются               |
| действие с подтверждением | открывает поповер подтверждения, и событие приходит только после него        |
| смена исполнителя         | отдельный сценарий: выбор и подтверждение, событие отдаёт нового исполнителя |
| ни одного блока           | панель остаётся с заголовком                                                 |

## Состояния

| состояние | чем задаётся   | что меняется                                   |
| --------- | -------------- | ---------------------------------------------- |
| обычное   | —              | значения на местах                             |
| загрузка  | вход `loading` | заглушки вместо значений, подписи остаются     |
| занятость | вход `busy`    | панель не принимает действий, пока идёт запрос |

## Доступность

- Подпись каждой строки остаётся на месте и во время загрузки: место значения не схлопывается.
- Действие с подтверждением объявляет своё последствие текстом, а не только цветом кнопки.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-workspace`](./?path=/docs/components-workspace-overview--docs) — рабочий стол, в правый
  слот которого панель и встаёт.
- [`rt-timeline`](./?path=/docs/components-timeline-overview--docs) — лента, которой рисуется
  история событий.

## Входы

| вход         | тип                                       | умолчание | что делает                                             |
| ------------ | ----------------------------------------- | --------- | ------------------------------------------------------ |
| `title`      | `string \| null`                          | `null`    | заголовок панели                                       |
| `entityId`   | `number \| null`                          | `null`    | идентификатор показанной записи                        |
| `loading`    | `boolean`                                 | `false`   | заглушки вместо значений полей и сумм                  |
| `busy`       | `boolean`                                 | `false`   | панель занята: действия не принимаются                 |
| `rows`       | `readonly IRtWorkspaceDetails.Row[]`      | `[]`      | поля «подпись — значение»                              |
| `agentEdit`  | `IRtWorkspaceDetails.AgentEdit \| null`   | `null`    | смена исполнителя: варианты и признак загрузки         |
| `money`      | `readonly IRtWorkspaceDetails.MoneyRow[]` | `[]`      | денежные строки с итогом                               |
| `toggles`    | `readonly IRtWorkspaceDetails.Toggle[]`   | `[]`      | переключатели свойств записи                           |
| `toggleHint` | `string \| null`                          | `null`    | пояснение под переключателями                          |
| `transition` | `IRtWorkspaceDetails.Transition \| null`  | `null`    | переход по этапам: варианты, ход и итог отправки       |
| `audit`      | `IRtWorkspaceDetails.Audit \| null`       | `null`    | история событий с догрузкой                            |
| `actions`    | `readonly IRtWorkspaceDetails.Action[]`   | `[]`      | кнопки действий, часть — с подтверждением              |
| `error`      | `string \| null`                          | `null`    | текст ошибки; показывается уведомлением, а не в панели |

## Выходы

| выход                    | что сообщает                                                     |
| ------------------------ | ---------------------------------------------------------------- |
| `toggleChange`           | переключён признак: идентификатор и новое значение               |
| `agentReassign`          | выбран новый исполнитель                                         |
| `transitionSubmit`       | отправлен переход по этапу с комментарием                        |
| `transitionSuccessClose` | закрыто сообщение об успешном переходе                           |
| `transitionErrorClose`   | закрыто сообщение об ошибке перехода                             |
| `auditLoadMore`          | запрошена догрузка истории                                       |
| `actionClicked`          | нажато действие; у действий с подтверждением — только после него |

# `rt-toolbar`

Полоса действий с тремя слотами. Слоты объявляются директивами на `ng-template`.

```html
<rt-toolbar dense>
    <ng-template rtToolbarLeft><rt-icon-button icon="arrow-left" ariaLabel="Назад" /></ng-template>
    <ng-template rtToolbarCenter><h3>Заявка №12</h3></ng-template>
    <ng-template rtToolbarRight><rt-menu … /></ng-template>
</rt-toolbar>
```

| вход            | тип              | умолчание |
| --------------- | ---------------- | --------- |
| `dense`         | `boolean`        | `false`   |
| `filtersActive` | `boolean`        | `false`   |
| `filtersPanel`  | `'kit' \| 'app'` | `'kit'`   |

| выход          | когда                                           |
| -------------- | ----------------------------------------------- |
| `filtersApply` | нажата «Применить» панели отборов               |
| `filtersReset` | нажата «Сбросить» панели отборов                |
| `filtersOpen`  | нажата кнопка фильтров при `filtersPanel="app"` |

`rt-toolbar-filters-route-aside` — маршрутная панель отборов для `filtersPanel="app"`, входов и
выходов нет. `rt-toolbar-filters-panel` — её содержимое и содержимое панели кита: вход `filters`
(`IRtToolbar.IFiltersPanelData | null`, умолчание `null` — отборы полосы с `filtersPanel="app"`),
выход `dismiss` (нажата стрелка или «Применить»).

## Главное, что нужно знать

**Без единого слота панель не рисуется вовсе** — ни одного узла в DOM. Необъявленный слот тоже
не создаёт пустой полосы: пустая полоса занимала бы место и растягивала соседние.

**Отступ полосы сверху и снизу — свойства блока** `--rt-toolbar-padding-top` и
`--rt-toolbar-padding-bottom`, по умолчанию 8px. Список ставит им свои имена.

**Поле ввода в левой части берёт ширину из свойства блока `--rt-toolbar-field-width`**, по
умолчанию 400px (`--rt-size-100`), и не бывает шире самой части. Своей ширины у `rt-input` нет, и
без этого поиск списка сжимался до подсказки. Выпадающие отборы `rt-select` слева держат ширину по
содержимому (`width: auto`): они стоят рядами, и по 400px каждый растягивали строку и вылезали за
узкий экран, а при своей ширине 100% все отборы ряда сжимались до одной ширины и обрезали
подсказку многоточием. В
центре поле и отбор по-прежнему занимают всю ширину центра. Ширину берёт только поле, стоящее в
левой части прямо: поле внутри своего компонента приложения остаётся по содержимому, иначе обёртка
растёт до 400px и не сжимается, и несколько отборов не влезают в строку. На узком экране левая
часть стекает в колонку и не шире окна: у неё `min-width: 0`, иначе её наименьшая ширина бралась по
полю в 400px, и оно уходило за правый край.

**Плотная полоса остаётся строкой на любой ширине, и её левая часть сжимается.** Длинный
заголовок в ней переносится по словам и не выходит за правый край. Кнопки справа держат свою
ширину. Обычная полоса левую часть не сжимает: на узком экране она стекает в колонку.

**Отборы списка объявляются слотом `rtToolbarFilters`, и на узком месте они уходят за кнопку.** На
широком месте слот стоит в левой части после её содержимого. На месте уже 1080
(`BreakpointsService.belowNarrow`) вместо полей рисуется кнопка фильтров, последней в ряду кнопок правой
части, после настроек таблицы; ряд прижат к правому краю на любой ширине. Вход `filtersActive` ставит точку в угол значка.
Кнопка открывает панель `RtToolbarFiltersAsideComponent` службой боковых панелей. «Сбросить»
сообщает `filtersReset`, и панель остаётся открытой; «Применить» сообщает `filtersApply` и
закрывает её. Контекст шаблона — место, где он нарисован: `bar` или `panel`. Хозяин панели —
инжектор полосы: уничтожение полосы закрывает панель, и расширение места тоже — иначе поля отборов
стояли бы в полосе и в панели сразу; фокус из закрытой так панели уходит в левую секцию полосы.
Второе нажатие кнопки, пока панель открыта, ничего не открывает. Панель держит фокус
(`trapFocus`) и объявлена модальным диалогом (`modal`), а имя кнопки при `filtersActive` говорит
скринридеру, что отбор включён.

**Порог отборов — 1080: на 1080 и шире поля в строке, на 1079 и уже — кнопка.** Отборы читают
признак `BreakpointsService.belowNarrow` (место или окно уже 1080). Общий `narrow` остаётся `≤1080`:
по нему таблица, шапка страницы, боковое меню и прочие компоненты переходят в узкий вид, и стили
кита держат тот же порог `$rt-bp-lg`.

**При `filtersPanel="app"` панель отборов открывает приложение своим маршрутом.** Кнопка не
открывает панель кита и сообщает `filtersOpen`, приложение переходит на маршрут
`rt-toolbar-filters-route-aside` в аутлете `ro`. Маршрут переживает перезагрузку, передаётся
ссылкой и попадает в историю браузера. Панель — наследник `RtRouteAsideComponent`, как
`rt-table-settings-aside`, и рисует `rt-toolbar-filters-panel`: шапку «Фильтры» со стрелкой, поля
слота с контекстом `panel`, подвал «Сбросить» и «Применить». Полоса отдаёт отборы через связку кита,
пока живёт; отвечает полоса, отдавшая их последней. «Сбросить» доходит до `filtersReset` полосы и
панель не закрывает. «Применить» доходит до `filtersApply` и закрывает панель; если приложение
начало переход по адресу, панель закрывается после него, иначе второй переход отменил бы первый.
Панель решает через одну макрозадачу после нажатия: переход начинается в обработчике
`filtersApply`, в микрозадаче или в эффекте хранилища, но не по таймеру и не после запроса. Стрелка, нажатие мимо панели и Esc закрывают панель общим путём `onClose()`.
Панель закрывается сама, когда отборы вернулись в полосу на широком месте и когда полоса ушла со
страницы, — но только готовая. Отборы в строке закрывают её после замера места каркасом или если
они уже стояли за кнопкой: до замера ширину даёт окно, и на перезагрузке широкое окно при узком
месте закрыло бы панель. Маршрут, вставший раньше полосы (страница открыта по ссылке), ждёт её и
берёт отборы. Поэтому маршрут панели объявляется только у разделов, где полоса стоит с
`filtersPanel="app"` и слотом отборов: без неё панель ждёт с пустым телом. Полоса, которую
страница пересоздаёт, пока панель открыта, закрывает её как ушедшая. Когда панель закрылась на
широком месте с фокусом внутри, фокус уходит в поле левой секции полосы, как у панели кита. После
остальных закрытий маршрута фокус возвращает каркас приложения, не полоса.

```ts
// маршрут раздела
{ path: 'filters', outlet: 'ro', canDeactivate: [rtAsideUnsavedGuard], component: RtToolbarFiltersRouteAsideComponent }
```

```html
<!-- список: кнопка открывает маршрут -->
<rt-toolbar filtersPanel="app" (filtersOpen)="openFilters()" (filtersApply)="apply()" (filtersReset)="reset()">
    <ng-template rtToolbarFilters let-place>…</ng-template>
</rt-toolbar>
```

```ts
protected openFilters(): void {
    void this.router.navigate([{ outlets: { ro: ['filters'] } }], { relativeTo: this.route });
}
```

# `rt-hybrid-tree`

```html
<rt-hybrid-tree [branchMarks]="false" [nodes]="fields" [(value)]="chosenFields" />
```

Входы и выходы — на странице обзора `Overview.mdx` рядом. Договорённость —
`docs/specs/ui-kit-v2/hybrid-tree-selector/spec.md`.

## Главное, что нужно знать

**Это `rt-tree` с другим расчётом выбора.** Класс наследует `RtTreeComponent` и берёт его разметку
и стили: клавиши, поиск, метки и разметка приложения общие. Переопределены четыре точки —
`rowState`, `selectAllMarkOf`, `selectAllChoice` и `nextChoice`. Правка разметки дерева доходит до
обоих.

**Группа с `single: true` держит один прямой лист.** Правила в `rt-hybrid-tree.logic.ts`: выбор листа
снимает соседей по группе, радио группы снимает её или выбирает первый включённый лист.
«Выбрать всё» и каскад ветки листья такой группы не набирают, а снимают.

**Группа без отметки показывает число выбранного под собой.** Число считается по всем листьям,
выключенные тоже.

## Края

- Выбор всегда новый массив, узлы не правятся.
- Группа «один лист» внутри другой такой же рисуется обычной веткой: её листья — радио только своей
  группы.
- В режимах `single` и `none` правила групп «один лист» не действуют, дерево ведёт себя как `rt-tree`.

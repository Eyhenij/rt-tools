<Title>HybridTree — `rt-hybrid-tree`</Title>

Дерево выбора, где часть групп выбирает один лист. У такой группы на узле стоит `single: true`, и её
листья рисуются радио. Остальные группы остаются с флажками, как в
[`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs): строки, клавиши, поиск, метки и
разметка приложения у деревьев общие.

```html
<rt-hybrid-tree ariaLabel="Поля отчёта" [nodes]="fields" [(value)]="chosenFields" />
<rt-hybrid-tree ariaLabel="Поля отчёта" [branchMarks]="false" [nodes]="fields" [(value)]="chosenFields" />
```

```ts
const fields: IRtHybridTree.Node<string>[] = [
    { label: 'Группировки', value: 'grouping', children: [{ label: 'Гостиница', value: 'hotel' }] },
    { label: 'Этот год', value: 'ty', single: true, children: [{ label: 'Выручка', value: 'ty-revenue' }] },
];
```

## Когда применять

- Выбор из иерархии, где в одних группах берётся одно значение, а в других — сколько угодно:
  поля отчёта, где показатель года берётся один.

## Когда не применять

- **Во всех группах берётся сколько угодно или везде одно** — [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs)
  в режиме `multiple` или `single`.
- **Выбор с поиском и «Применить»** — [`rt-hybrid-tree-selector`](./?path=/docs/organisms-forms-hybridtreeselector-overview--docs):
  то же дерево в панели выбора.

## Оси

| ось                | значения                                        | умолчание |
| ------------------ | ----------------------------------------------- | --------- |
| группа «один лист» | ничего не выбрано, выбран лист                  | —         |
| отметки групп      | есть — радио и флажки; нет — число выбранного   | есть      |
| «выбрать всё»      | нет; есть — ничего, часть, все свободные листья | нет       |

Остальные оси — режим, каскад, поиск, конец строки, клик — те же, что у `rt-tree`, и показаны в его
историях.

Выбор листа группы «один лист» снимает соседей по группе; клик по выбранному снимает его. Радио
самой группы снимает её выбор, а когда в ней ничего не выбрано — выбирает первый включённый лист.
«Выбрать всё» и каскад ветки набирают только свободные листья, а снимают все. Группа без отметки
показывает в конце строки, сколько листьев под ней выбрано.

Правила групп «один лист» действуют в режиме `multiple`. В режимах `single` и `none` дерево ведёт
себя как `rt-tree`.

Каждая история стоит парой половин под двумя наборами оформления.

**Оси, которых не видно.** Клик без Ctrl и Cmd в режиме `exclusive` — поведение: лист группы «один
лист» выбор вне группы не трогает. Это видно в **Playground**.

## Состояния

Свои состояния строк — наведение, фокус, подсветка, выключенный узел — у дерева те же, что у
`rt-tree`, и показаны в его истории **States**.

| состояние          | чем задаётся           | что меняется                   |
| ------------------ | ---------------------- | ------------------------------ |
| группа «один лист» | `single: true` у ветки | радио у группы и у её листьев  |
| выбран лист группы | клик по листу          | радио группы и листа заполнены |
| число выбранного   | `branchMarks = false`  | число в конце строки группы    |

## Клавиатура

Та же, что у `rt-tree`: стрелки, пробел и Enter. Пробел на листе группы «один лист» выбирает его
вместо соседа.

## Доступность

- Роли и атрибуты строк те же, что у `rt-tree`.
- Радио группы «один лист» не берёт фокус: состояние читается из `aria-selected` строки.

## Оформление

Свойства те же, что у `rt-tree`: разметка и стили у деревьев одни. Число выбранного рисуется
приглушённым цветом мелкого текста кита.

## Входы

Своих входов нет: все входы — у `rt-tree`, таблица на его
[странице обзора](./?path=/docs/organisms-forms-tree-overview--docs). Узлы — `IRtHybridTree.Node<T>`,
узел `rt-tree` с признаком `single`.

## Выходы

Те же, что у `rt-tree`: `valueChange` и `picked`.

## Рядом

- [`rt-tree`](./?path=/docs/organisms-forms-tree-overview--docs) — дерево, которое это дерево наследует.
- [`rt-hybrid-tree-selector`](./?path=/docs/organisms-forms-hybridtreeselector-overview--docs) — выбор
  этим деревом с поиском и «Применить».

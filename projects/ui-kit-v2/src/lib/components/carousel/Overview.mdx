<Title>Carousel — `rt-carousel`</Title>

Стопка цветных карточек с короткой подписью: роли, права, метки записи в узкой ячейке таблицы.
Карточки наезжают одна на другую, а открытая — под указателем или в фокусе — показывает подпись
целиком.

```html
<rt-carousel [cards]="row.roles" />
```

## Когда применять

- Несколько коротких цветных меток записи в ячейке, где их полный ряд не помещается.
- Роли и права пользователя, теги записи со своими цветами.

## Когда не применять

- **Одна метка состояния** — `rt-tag`: у него палитра важности и подпись целиком.
- **Листание крупных карточек со стрелками** — такой части в ките нет; стопка не листается.

## Оси

| ось      | значения                                                         | умолчание |
| -------- | ---------------------------------------------------------------- | --------- |
| карточки | одна, несколько, пустой список                                   | `[]`      |
| цвет     | светлый — тёмная подпись, тёмный — светлая, без цвета — фон кита | без цвета |

## Состояния

- Карточка: обычная, под указателем, в фокусе с клавиши. Открытая приподнята, растёт до всей
  подписи и стоит поверх соседей; следующие отходят в сторону. Ширина стопки при этом не меняется —
  ячейка таблицы под ней не растягивается.
- Пустой список: ничего не рисуется.

## Доступность

- Хост — список `role="list"`, карточки — `role="listitem"`, и каждая стоит в порядке Tab: подпись
  целиком открывается и с клавиатуры.
- Полная подпись лежит в разметке, скринридер читает её без открытия.
- Подпись на цвете карточки — тёмная или светлая по яркости цвета.
- С `prefers-reduced-motion` карточки двигаются без перехода.

## Оформление

Вид кита и материальный вид стоят рядом в каждой матрице, светлая и тёмная темы — в истории
**Themes**. Свойства объявлены на самом `rt-carousel`, и приложение переназначает их своим правилом
на этот блок.

Материальный набор повторяет стопку приложения: скругление 4px, большая тень кита, тёмная подпись
цвета текста Material, подпись обычного начертания с заглавной буквы каждого слова и движение
300 мс. Шага начертания 300 в ките нет, и
набор берёт ближайший обычный.

| свойство                            | что задаёт                      | умолчание                 |
| ----------------------------------- | ------------------------------- | ------------------------- |
| `--rt-carousel-card-width`          | ширина закрытой карточки        | `--rt-size-16`            |
| `--rt-carousel-card-padding-inline` | поля карточки по бокам          | `--rt-space-2`            |
| `--rt-carousel-card-radius`         | скругление карточки             | `--rt-radius-ms`          |
| `--rt-carousel-card-shadow`         | тень карточки                   | `--rt-shadow-sm`          |
| `--rt-carousel-card-bg`             | фон карточки без цвета          | `--rt-color-bg-subtle`    |
| `--rt-carousel-card-color`          | подпись карточки без цвета      | `--rt-color-text-primary` |
| `--rt-carousel-tone-dark`           | тёмная подпись на светлом цвете | `--rt-neutral-950`        |
| `--rt-carousel-tone-light`          | светлая подпись на тёмном цвете | `--rt-neutral-0`          |
| `--rt-carousel-overlap`             | наезд на левую соседку          | половина `--rt-size-16`   |
| `--rt-carousel-lift`                | подъём открытой карточки        | `--rt-space-1`            |
| `--rt-carousel-shift`               | сдвиг карточек после открытой   | `--rt-space-4`            |
| `--rt-carousel-label-size`          | кегль подписи                   | `--rt-text-xs`            |
| `--rt-carousel-label-weight`        | начертание подписи              | `--rt-font-weight-medium` |
| `--rt-carousel-label-height`        | высота строки подписи           | `--rt-size-6`             |
| `--rt-carousel-label-transform`     | регистр подписи                 | `none`                    |
| `--rt-carousel-duration`            | подъём и сдвиг                  | `--rt-duration-base`      |

## Входы

| вход    | тип                                   | умолчание |
| ------- | ------------------------------------- | --------- |
| `cards` | `readonly IRtCarousel.Card[] \| null` | `[]`      |

## Выходы

Нет: стопка только показывает подписи.

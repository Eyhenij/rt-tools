<Title>Chat — `rt-chat`</Title>

Правая половина экрана переписки: лента сообщений, поле ответа снизу и необязательная шапка с
кнопками. Ни загрузкой, ни отправкой чат не занимается — он показывает и просит.

```html
<rt-chat
    placeholder="Написать сообщение"
    emptyHint="Выберите переписку слева"
    [hasThread]="selected()"
    [messages]="messages()"
    [canReply]="canReply()"
    [sending]="sending()"
    (send)="send($event)" />
```

## Когда применять

- Экран переписки рядом с [`rt-thread-list`](./?path=/docs/organisms-chat-threadlist-overview--docs).

## Когда не применять

- **Одно поле комментария** — [`rt-message-composer`](./?path=/docs/organisms-chat-messagecomposer-overview--docs)
  отдельно, без ленты.

## Оси

| ось             | значения                                                      | умолчание  |
| --------------- | ------------------------------------------------------------- | ---------- |
| выбор переписки | не выбрана, выбрана и пуста, выбрана с сообщениями            | не выбрана |
| вид сообщения   | своё, чужое, системное, с вложением                           | —          |
| доставка своего | `sending`, `sent`, `read`, `failed`                           | —          |
| ответ           | можно, отправка в пути, нельзя с причиной, нельзя без причины | можно      |
| шапка           | нет, с обновлением, с разворотом, обе кнопки                  | нет        |
| загрузка        | сообщения на месте, первая загрузка, догрузка сверху          | на месте   |

Три утверждения, которые матрицы показывают прямо, потому что по одному экрану они неотличимы:

- **Без `hasThread` чат рисует только подсказку выбора.** Ни ленты, ни поля ответа не будет —
  это состояние «переписка не выбрана», а не «переписка пустая».
- **Шапка появляется только вместе с кнопками.** Один заголовок её не создаёт: `showRefresh`
  или `showExpand` — вот что её включает.
- **Поле ответа гейтится `canReply`.** Когда отвечать нельзя, вместо поля рисуется причина; без
  причины остаётся пустое место, и это видно ячейкой «нельзя, причина не названа».

Виды сообщения стоят **одной лентой**: порознь не видно, что своё прижато вправо, а чужое
влево. Состояние доставки есть только у своих — чужому сообщению нечего сообщать о доставке.

## Ширина

Переписка объявляет свой порог сама — 1441 px, — поэтому у матриц есть второй кадр.

## Края

| край                 | что происходит                               |
| -------------------- | -------------------------------------------- |
| переписка не выбрана | только подсказка `emptyHint`                 |
| выбрана и пуста      | лента пуста, поле ответа на месте            |
| ответ запрещён       | вместо поля — текст `replyBlockReason`       |
| сообщение не ушло    | статус `failed` и кнопка повтора у сообщения |

## Состояния

| состояние       | чем задаётся | что меняется                             |
| --------------- | ------------ | ---------------------------------------- |
| обычное         | —            | лента и поле ответа                      |
| первая загрузка | `loading`    | вместо ленты — заглушки                  |
| догрузка        | `fetching`   | лента остаётся, признак занятости сверху |
| отправка        | `sending`    | поле ответа заблокировано                |

## Доступность

- Своё и чужое сообщение различаются не только стороной, но и подписью автора.
- Кнопки шапки несут переведённые имена.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-thread-list`](./?path=/docs/organisms-chat-threadlist-overview--docs) — левая половина
  того же экрана.
- [`rt-message-composer`](./?path=/docs/organisms-chat-messagecomposer-overview--docs) — поле
  ответа само по себе.

## Входы

| вход                | тип                                       | умолчание | что делает                                        |
| ------------------- | ----------------------------------------- | --------- | ------------------------------------------------- |
| `messages`          | `readonly IRtChat.Message[]`              | `[]`      | лента сообщений                                   |
| `loading`           | `boolean`                                 | `false`   | первая загрузка: вместо ленты заглушки            |
| `fetching`          | `boolean`                                 | `false`   | догрузка: лента остаётся на месте                 |
| `canReply`          | `boolean`                                 | `false`   | показывать ли поле ответа                         |
| `replyBlockReason`  | `string \| null`                          | `null`    | почему отвечать нельзя — вместо поля              |
| `sending`           | `boolean`                                 | `false`   | отправка в пути: поле заблокировано               |
| `placeholder`       | `string`                                  | `''`      | подсказка в поле ответа                           |
| `title`             | `string`                                  | `''`      | заголовок шапки; сам по себе шапку не создаёт     |
| `emptyHint`         | `string`                                  | `''`      | подсказка, когда переписка не выбрана             |
| `hasThread`         | `boolean`                                 | `false`   | выбрана ли переписка                              |
| `attachments`       | `boolean`                                 | `false`   | скрепка в поле ответа                             |
| `accept`            | `string`                                  | `''`      | какие файлы принимает скрепка                     |
| `richComposer`      | `boolean`                                 | `false`   | поле ответа с оформлением                         |
| `formatting`        | `boolean`                                 | `false`   | панель оформления в поле ответа                   |
| `formattingToolbar` | `TRtRichEditorToolbar`                    | —         | какие кнопки в панели оформления                  |
| `fill`              | `boolean`                                 | `false`   | занимать всю высоту родителя                      |
| `showRefresh`       | `boolean`                                 | `false`   | кнопка обновления в шапке — она же создаёт шапку  |
| `showExpand`        | `boolean`                                 | `false`   | кнопка разворота в шапке                          |
| `messageHasActions` | `IRtChat.MessageActionsPredicate \| null` | `null`    | есть ли у реплики свои действия — гейт кнопки «…» |

## Проекция содержимого

| точка                   | что кладут                                                                   |
| ----------------------- | ---------------------------------------------------------------------------- |
| `[rtChatHeaderActions]` | свои кнопки в шапку, рядом с обновлением и разворотом                        |
| `[rtChatFooter]`        | своё содержимое под диалогом                                                 |
| `rtChatMessageActions`  | `<ng-template rtChatMessageActions let-message>` — пункты меню «…» у реплики |

Шаблон действий у реплики нужен тем действиям, которых кит не знает и знать не должен: удаление,
повтор отправки и скачивание общи для любой переписки и остаются своими входами и выходами.
Видимость точки держит `messageHasActions` — предикат, а не подсчёт отрисованных пунктов:
содержимое спроецированного шаблона известно только после отрисовки, и кнопка успевала бы мигнуть
на первом кадре. Признак не задан — точка показывается у каждой реплики.

```html
<rt-chat [messages]="messages()" [messageHasActions]="canAct">
    <ng-template rtChatMessageActions let-message>
        <rt-menu-item icon="link" label="Скопировать ссылку" (selected)="copy(message)" />
    </ng-template>
</rt-chat>
```

## Выходы

| выход                | что сообщает                                  |
| -------------------- | --------------------------------------------- |
| `send`               | отправлено сообщение: текст и файлы           |
| `refresh`            | нажато обновление                             |
| `downloadFile`       | запрошен файл сообщения                       |
| `downloadAttachment` | запрошено вложение                            |
| `expandedChange`     | нажат разворот                                |
| `deleteMessage`      | запрошено удаление сообщения                  |
| `retryMessage`       | запрошен повтор отправки неушедшего сообщения |

<Title>DownloadLink — `rt-download-link`</Title>

Кнопка скачивания: иконка и имя файла. **Это кнопка, а не ссылка** — адреса компонент не знает
и ничего не качает, качает потребитель по событию.

```html
<rt-download-link label="Договор.pdf" (downloadClick)="save(file)" />
```

## Когда применять

- Одиночное вложение, адрес которого нельзя поставить в разметку заранее: подписанная ссылка с
  коротким сроком жизни, выгрузка, которую сначала надо построить.

## Когда не применять

- **Перечень вложений** — [`rt-file-list`](./?path=/docs/components-filelist--docs).
- **Обычная ссылка с известным адресом** — `<a href download>`: браузер сделает это сам, без
  обработчика.

## Оси

| ось     | значения                                 | умолчание       |
| ------- | ---------------------------------------- | --------------- |
| подпись | свободная строка — короткое имя, длинное | **обязательна** |

Вход у кнопки один, и перемножать его не с чем. Ряд показывает края длины: имя файла приходит
извне и коротким не гарантировано.

## Состояния

| состояние       | чем задаётся     | что меняется                    |
| --------------- | ---------------- | ------------------------------- |
| обычное         | —                | цвет ссылки, без подчёркивания  |
| наведение       | `:hover`         | подпись подчёркивается          |
| фокус с клавиши | `:focus-visible` | кольцо `--rt-shadow-focus-ring` |

Отключённого состояния и загрузки у кнопки нет: она только сообщает о клике, а ждать ответа —
дело потребителя. Если ожидание надо показать, рядом ставится
[`rt-spinner`](./?path=/docs/components-spinner-overview--docs).

## Доступность

- Подпись для скринридера собирается из переведённой формулировки и имени файла
  (`rtKit.uiDownloadFile` с подстановкой `{{name}}`): на экране видно имя, а вслух читается
  «Download: Договор.pdf».
- Кнопка нарисована как ссылка, поэтому умолчательный контур браузер снимает вместе с рамкой —
  видимый фокус кольцом объявлен явно. Без него место фокуса с клавиатуры не видно вовсе.

## Оформление

Цвет берётся от `--rt-color-text-link`, кольцо фокуса — от `--rt-shadow-focus-ring`. Своей
рамки и заливки у кнопки нет: это ссылка по виду и кнопка по поведению.

## Входы

| вход    | тип      | умолчание      |
| ------- | -------- | -------------- |
| `label` | `string` | **обязателен** |

## Выходы

| выход           | тип    | когда                                  |
| --------------- | ------ | -------------------------------------- |
| `downloadClick` | `void` | клик; скачивание запускает потребитель |

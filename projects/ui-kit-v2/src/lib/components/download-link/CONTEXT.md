# `rt-download-link`

```html
<rt-download-link label="Договор.pdf" (downloadClick)="save(file)" />
```

| вход    | тип      | умолчание      |
| ------- | -------- | -------------- |
| `label` | `string` | **обязателен** |

| выход           | тип    |
| --------------- | ------ |
| `downloadClick` | `void` |

## Главное, что нужно знать

**Это кнопка, а не ссылка.** Адреса компонент не знает и ничего не скачивает — качает
потребитель по событию. Так работают и подписанные ссылки с коротким сроком жизни, и выгрузки,
которые сначала надо построить.

## Как этим пользоваться

- Подпись для скринридера собирается из переведённой формулировки и имени файла
  (`uiDownloadFile` с подстановкой `{{name}}`) — на экране видно имя, а вслух читается
  «Download: Договор.pdf».
- Для перечня вложений есть [`rt-file-list`](../file-list/CONTEXT.md); эта кнопка — одиночная.

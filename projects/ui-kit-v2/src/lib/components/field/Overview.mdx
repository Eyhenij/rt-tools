<Title>Field — `rt-field`</Title>

Единая анатомия поля формы: подпись сверху, контрол посередине, подсказка или ошибка снизу.
Собственного ввода у обёртки нет — она находит контрол кита внутри себя и разговаривает с ним.

```html
<rt-field label="Город" hint="Как в адресе доставки" help="Совпадает с документом">
    <rt-input placeholder="Москва" [formControl]="city" />
</rt-field>

<rt-field label="Комментарий">
    <rt-textarea [formControl]="comment" />
    <span rtFieldHint>
        Не короче
        <strong>трёх</strong>
        символов
    </span>
</rt-field>
```

## Когда применять

- Любой контрол кита в форме: подпись, звёздочка обязательности, текст ошибки и режим чтения
  берутся отсюда, а не пишутся заново рядом с каждым полем.
- Экран, который сначала показывает форму, а потом получает данные, — `loading` рисует заглушку
  на месте контрола, оставляя подпись читаемой.

## Когда не применять

- **Переключатель с собственной подписью** — [`rt-checkbox`](./?path=/docs/components-checkbox-overview--docs)
  и [`rt-toggle-switch`](./?path=/docs/components-toggleswitch-overview--docs) несут подпись сами;
  обёртка добавила бы вторую.
- **Обычный `<input>`** — положить внутрь можно, но подписи, звёздочки и ошибки он не получит:
  поле разговаривает только с контролами кита.

## Оси

Оси не перемножаются: анатомия, обязательность и строка сообщений живут в разных частях блока.

| ось            | значения                                                          | умолчание |
| -------------- | ----------------------------------------------------------------- | --------- |
| анатомия       | только контрол, подпись, подпись и подсказка, подпись и пояснение | —         |
| обязательность | нет, звёздочка, звёздочка снята (`hideRequiredMark`)              | нет       |
| ошибка         | умолчание кита, свой текст, поверх подсказки, с резервом строки   | нет       |
| подсказка      | строкой `hint`, проекцией `rtFieldHint`                           | нет       |
| режим          | обычный, только чтение, загрузка                                  | обычный   |

**Ось, которую нельзя показать статикой.** Пояснение (`help`) живёт в поповере и до наведения
не отрисовано: в матрице **Anatomy** от него видно только кнопку со знаком вопроса рядом с
подписью. Текст пояснения смотрится наведением в `Playground`.

## Состояния

Своих состояний взаимодействия у обёртки нет: наведение и фокус принадлежат контролу внутри и
показаны в его матрице. Меняется у неё строка сообщений под контролом.

| состояние         | чем задаётся                      | что видно                                          |
| ----------------- | --------------------------------- | -------------------------------------------------- |
| подсказка         | `hint` или проекция `rtFieldHint` | серая строка под контролом                         |
| ошибка            | контрол `invalid` после касания   | подсказка уступает место тексту ошибки             |
| ошибка с резервом | `reserveHintSpace`                | подсказка остаётся в потоке, но спрятана от чтения |
| только чтение     | `readonly`                        | контрол подменяется плоским текстом                |
| загрузка          | `loading`                         | на месте контрола заглушка, подпись остаётся       |

**Показывается одно сообщение** — первого сработавшего валидатора. Текст берётся так:
`errors[имяВалидатора]`, переданный формой → переведённое умолчание кита (`required`, `email`,
`minlength`, `maxlength`, `min`, `max`, `pattern`) → пусто, если валидатор незнаком и своего
текста нет.

**Ошибка появляется только после касания или правки.** Это решает контрол, а не обёртка: пустое
обязательное поле невалидно с самого начала, но краснеть до первого касания не должно. В матрице
касание проставлено заранее — иначе ячейка «ошибка» показывала бы исправное поле.

## Доступность

- Обёртка выдаёт контролу авто-идентификатор (`rt-field-N`) и связывает с ним `<label for>` —
  щелчок по подписи ставит фокус в поле. Явный `controlId` контрола важнее авто-идентификатора.
- Звёздочка обязательности помечена `aria-hidden`: она дублирует то, что уже сказано валидатором,
  и в озвучке становилась бы шумом.
- С резервом строки скрытая подсказка получает `aria-hidden` — под ошибкой её не должно быть
  слышно, хотя место она занимает.

## Оформление

Блок `rt-field` объявляет группу `--rt-field-*`: `--rt-field-value-color`,
`--rt-field-value-empty-color`, `--rt-field-value-font-size` — ими же рисуют плоский режим
чтения сами контролы. Заглушка загрузки нарисована
[`rt-skeleton-wrapper`](./?path=/docs/components-skeletonwrapper-overview--docs) высотой в
`--rt-input-height`.

## Входы

| вход               | тип                            | умолчание |
| ------------------ | ------------------------------ | --------- |
| `label`            | `string`                       | `''`      |
| `hint`             | `string`                       | `''`      |
| `help`             | `string`                       | `''`      |
| `readonly`         | `boolean`                      | `false`   |
| `loading`          | `boolean`                      | `false`   |
| `hideRequiredMark` | `boolean`                      | `false`   |
| `reserveHintSpace` | `boolean`                      | `false`   |
| `errors`           | `Record<validatorKey, string>` | `{}`      |

Входа обязательности здесь нет намеренно: звёздочку поле рисует, обнаружив у контрола валидатор
`required`. `hideRequiredMark` её глушит — для форм, где обязательны все поля и маркер становится
шумом.

## Выходы

Своих выходов нет.

## Рядом

- [`rt-input`](./?path=/docs/components-input-overview--docs) — самый частый контрол внутри.
- [`rt-textarea`](./?path=/docs/components-textarea-overview--docs), [`rt-input-number`](./?path=/docs/components-inputnumber-overview--docs) — то же самое для текста и чисел.
- [`rt-skeleton-wrapper`](./?path=/docs/components-skeletonwrapper-overview--docs) — чем нарисована заглушка загрузки.

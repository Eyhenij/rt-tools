<Title>Checkbox — `rt-checkbox`</Title>

Флажок с тремя положениями: снят, отмечен, смешанный. Значение — `boolean`, приходит и уходит
через форму; подпись кладётся проекцией.

```html
<rt-checkbox [formControl]="agree">Согласен с условиями</rt-checkbox>
<rt-checkbox ariaLabel="Выбрать всё" [indeterminate]="someSelected()" [formControl]="all" />
```

## Когда применять

- Независимый выбор «да / нет»: согласие, признак, фильтр в списке.
- Заголовок группы флажков — со смешанным положением, когда отмечена часть подчинённых.

## Когда не применять

- **Включатель режима** — [`rt-toggle-switch`](./?path=/docs/components-toggleswitch-overview--docs):
  «включено / выключено» и «отмечено» читаются по-разному, и скринридер произносит их разными
  словами.
- **Выбор одного из нескольких** — [`rt-toggle-button-group`](./?path=/docs/components-togglebuttongroup-overview--docs)
  или [`rt-select`](./?path=/docs/components-select--docs).

## Оси

| ось       | значения                 | умолчание |
| --------- | ------------------------ | --------- |
| положение | снят, отмечен, смешанный | снят      |
| подпись   | нет, короткая, длинная   | нет       |

Положение перемножено с отключённостью: отключённый флажок гасит и рамку, и заливку, и галочку,
и по одному отключённому положению не видно, что стало с остальными двумя.

**Оси, которых не видно.** `inputId` и `ariaLabel` уходят в атрибуты: первым связывается внешний
`<label for>`, второй даёт контролу доступное имя. Показывать их сеткой нечем.

## Состояния

| состояние       | чем задаётся                    | что меняется                             |
| --------------- | ------------------------------- | ---------------------------------------- |
| обычное         | —                               | рамка `--rt-color-border-strong`         |
| наведение       | —                               | **ничего:** своего `:hover` у флажка нет |
| фокус с клавиши | `:focus-visible`                | кольцо `--rt-shadow-focus-ring`          |
| отмечен         | значение формы                  | заливка `--rt-color-action-primary`      |
| смешанный       | вход `indeterminate`            | та же заливка, вместо галочки прочерк    |
| отключено       | вход `disabled` или слово формы | прозрачность 0.5, курсор `not-allowed`   |

**`indeterminate` — чисто визуальный вход, компонент его не сбрасывает.** Щелчок по смешанному
разрешается в «отмечен» и поднимает `true` наружу, но прочерк на экране останется, пока вход
держит его сверху. Снимать вход — дело потребителя.

## Доступность

- Это `<button role="checkbox">`, а не `<input type="checkbox">`: `Enter` и `Space` обрабатывает
  браузер, своих обработчиков клавиатуры здесь нет. `aria-checked` принимает три значения —
  `true`, `false`, `mixed`.
- **Проекция не становится доступным именем контрола.** Если подпись важна для чтения с экрана,
  задаётся `ariaLabel`; `inputId` кладётся на кнопку — по нему связывается внешний `<label for>`.

## Оформление

Бокс, галочка и подпись — элементы блока `rt-checkbox`; заливка отмеченного и смешанного берётся
из `--rt-color-action-primary`, кольцо фокуса — из `--rt-shadow-focus-ring`. Галочка и прочерк
нарисованы [`rt-icon`](./?path=/docs/components-icon-overview--docs) (`check` и `minus`).

## Входы

| вход            | тип              | умолчание |
| --------------- | ---------------- | --------- |
| `inputId`       | `string \| null` | `null`    |
| `ariaLabel`     | `string \| null` | `null`    |
| `disabled`      | `boolean`        | `false`   |
| `indeterminate` | `boolean`        | `false`   |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы.

## Рядом

- [`rt-toggle-switch`](./?path=/docs/components-toggleswitch-overview--docs) — то же булево значение для «включено / выключено».
- [`rt-icon`](./?path=/docs/components-icon-overview--docs) — чем нарисованы галочка и прочерк.

<Title>NotificationsBell — `rt-notifications-bell`</Title>

Иконочная кнопка колокольчика с точкой непрочитанного. Ни списка, ни счётчика она не держит —
только сообщает о нажатии и показывает, есть ли что смотреть.

```html
<rt-notifications-bell ariaLabel="Уведомления" [unread]="hasUnread()" (clicked)="openPanel()" />
```

## Когда применять

- В шапке приложения рядом с профилем, когда уведомления открываются панелью или списком.

## Когда не применять

- **Показать число непрочитанных** — [`rt-info-badge`](./?path=/docs/components-info-badge--docs)
  или счётчик: здесь только точка «есть или нет».
- **Сам список уведомлений** — [`rt-menu`](./?path=/docs/components-menu--docs) или
  [`rt-aside`](./?path=/docs/components-aside--docs), которые эта кнопка открывает.

## Оси

| ось           | значения  | умолчание |
| ------------- | --------- | --------- |
| непрочитанное | нет, есть | нет       |

Ось одна и двоичная: весь компонент про то, видно ли точку. Больше показывать здесь нечего —
это объявлено прямо, а не оставлено пустым местом в матрице.

## Края

| край                 | что происходит                                        |
| -------------------- | ----------------------------------------------------- |
| пустой `unreadLabel` | точка остаётся видимой, но скринридеру не объявляется |

## Состояния

| состояние       | чем задаётся     | что меняется    |
| --------------- | ---------------- | --------------- |
| обычное         | —                | прозрачный фон  |
| наведение       | `:hover`         | подложка кнопки |
| нажатие         | `:active`        | подложка темнее |
| фокус с клавиши | `:focus-visible` | кольцо фокуса   |

## Доступность

- `ariaLabel` — имя самой кнопки: иконка без подписи именем не служит.
- `unreadLabel` объявляет наличие непрочитанного отдельно: точка цветом читается только глазами.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**, обе с точкой и без.

## Рядом

- [`rt-icon-button`](./?path=/docs/components-icon-button-overview--docs) — иконочная кнопка
  без точки.

## Входы

| вход          | тип       | умолчание | что делает                                 |
| ------------- | --------- | --------- | ------------------------------------------ |
| `unread`      | `boolean` | `false`   | показывает точку непрочитанного            |
| `ariaLabel`   | `string`  | `''`      | имя кнопки для скринридера                 |
| `unreadLabel` | `string`  | `''`      | объявление о непрочитанном для скринридера |

## Выходы

| выход     | что сообщает                                    |
| --------- | ----------------------------------------------- |
| `clicked` | колокольчик нажат; панель открывает потребитель |

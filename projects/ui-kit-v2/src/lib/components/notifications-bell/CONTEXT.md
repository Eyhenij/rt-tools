# `rt-notifications-bell`

Колокольчик уведомлений с меткой непрочитанного.

```html
<rt-notifications-bell ariaLabel="Уведомления" unreadLabel="Есть непрочитанные" [unread]="hasUnread()" (clicked)="openPanel()" />
```

| вход          | тип       | умолчание |
| ------------- | --------- | --------- |
| `unread`      | `boolean` | `false`   |
| `ariaLabel`   | `string`  | `''`      |
| `unreadLabel` | `string`  | `''`      |

Выход: `clicked`.

## Главное, что нужно знать

**Компонент ничего не открывает** — он только сообщает о нажатии. Панель уведомлений рисует
приложение.

**У метки своя подпись.** Точка несёт смысл, а не оформление: она объявлена `role="img"` с
`aria-label`, иначе скринридер сказал бы только «Уведомления», не упомянув непрочитанное.

Обе подписи задаёт приложение — своих слов у кита здесь нет.

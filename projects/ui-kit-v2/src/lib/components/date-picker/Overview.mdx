<Title>DatePicker — `rt-date-picker`</Title>

Поле даты и времени со своей панелью: месяц, колонки часов и минут, подвал по типу. Значение —
**строка** той же формы, что отдавало нативное поле: `2026-03-15`, `09:30`, `2026-03-15T09:30`.

```html
<rt-field label="Дата заезда">
    <rt-date-picker min="2026-01-01" max="2026-12-31" [formControl]="checkIn" />
</rt-field>

<rt-date-picker type="datetime-local" ariaLabel="Начало смены" [formControl]="startsAt" />
```

## Когда применять

- Дата, время или дата со временем, которые пользователь выбирает сам — щелчком в панели или
  набором текста в порядке языка интерфейса (`01.08.2026` под `ru`).
- Диапазон, ограниченный `min` / `max`: дни и время за границами выключены.
- Время с шагом минут — вход `minuteStep`.

## Когда не применять

- **Сетка месяца без поля** — [`rt-calendar`](./?path=/docs/molecules-forms-calendar-overview--docs).
- **Только время без обёртки** — [`rt-input`](./?path=/docs/atoms-forms-input-overview--docs)
  с `type="time"`.
- **Отрезок дат** — [`rt-date-range`](./?path=/docs/organisms-forms-daterange-overview--docs).

## Оси

| ось           | значения                         | умолчание |
| ------------- | -------------------------------- | --------- |
| размер        | `sm`, `md`, `lg`                 | `md`      |
| тип           | `date`, `datetime-local`, `time` | `date`    |
| наполненность | пусто, со значением              | пусто     |
| рамка         | видна, снята (`bordered=false`)  | видна     |

**Панель — в своих историях.** Поле кладёт её в поповер, за пределы блока истории, поэтому её
показывают истории раздела `Molecules/Forms/DatePanel`: `Types`, `Bounds`, `Months`, `Sheet` и `Themes` — три типа,
границы, выбор месяца и года, вид в нижней шторке и пара тем. «Сегодня» витрины — 10 марта 2026
года.

**Границы в покое не видны на самом поле.** `min` и `max` проявляются в панели — её показывает
история `DatePanel/Bounds`.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у поля нет             |
| фокус внутри  | `:focus-within`                      | рамка фокуса и `--rt-input-focus-shadow`           |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| ошибка набора | текст не читается как значение       | та же рамка ошибки; значение формы прежнее         |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | локализованный текст даты, пустое — прочерком      |

**В режиме чтения строка переписывается на язык интерфейса** через `Intl.DateTimeFormat`:
`2026-03-15` → `15 мар. 2026 г.` под `ru`. Нераспознанная строка показывается как есть, а не
исчезает: значение может прийти из формы, минуя набор.

## Доступность

- Подпись даёт вмещающий `rt-field`; без обёртки полю нужен `ariaLabel`.
- Кнопка панели несёт имя из метки кита `uiOpenCalendar`.
- В месяце в обходе Tab стоит один день; стрелки, PageUp/PageDown, Home и End двигают его как
  сетку, Enter выбирает, Escape закрывает панель. Сегодняшний день несёт `aria-current="date"`,
  выбранный — `aria-pressed`.
- Ошибка объявляется атрибутом `aria-invalid` на поле — и ошибка формы, и ошибка набора.

## Оформление

Собственных свойств у поля нет: оно берёт группу `--rt-input-*` целиком и стоит в форме вровень с
`rt-input`. Поверхность панели в поповере — та же, что у панели `rt-select`. Размер дня в шторке —
44 px под палец.

## Входы

| вход         | тип                                    | умолчание                 |
| ------------ | -------------------------------------- | ------------------------- |
| `appearance` | `'outline' \| 'fill'`                  | `'outline'`               |
| `type`       | `'date' \| 'datetime-local' \| 'time'` | `'date'`                  |
| `min`        | `string \| null` — форма значения      | `null`                    |
| `max`        | `string \| null` — форма значения      | `null`                    |
| `minuteStep` | `number` — шаг колонки минут           | `5`                       |
| `radius`     | `TRtRadius \| null`                    | `null` → скругление полей |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы. Разбор строки и часовые пояса остаются на стороне потребителя — `Date` компонент не
создаёт.

## Рядом

- [`rt-field`](./?path=/docs/molecules-forms-field-overview--docs) — подпись, звёздочка, ошибка, режим чтения.
- [`rt-input`](./?path=/docs/atoms-forms-input-overview--docs) — то же поле для строк.
- [`rt-calendar`](./?path=/docs/molecules-forms-calendar-overview--docs) — сетка месяца, на которой стоит панель.

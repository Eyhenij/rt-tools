<Title>DatePicker — `rt-date-picker`</Title>

Поле даты и времени поверх нативного `<input type="date">`. Значение — **строка ISO**, ровно та,
что отдаёт браузер: `2026-03-15`, `09:30`, `2026-03-15T09:30`.

```html
<rt-field label="Дата заезда">
    <rt-date-picker min="2026-01-01" max="2026-12-31" [formControl]="checkIn" />
</rt-field>

<rt-date-picker type="datetime-local" ariaLabel="Начало смены" [formControl]="startsAt" />
```

## Когда применять

- Дата или время, которые пользователь выбирает сам, а формат ввода должен совпадать с
  системным: календарь, раскладку и клавиатуру рисует браузер.
- Диапазон, ограниченный `min` / `max`: проверку выхода за границы тоже делает браузер.

## Когда не применять

- **Нужен одинаковый календарь во всех браузерах** — этот компонент не подойдёт: своего
  календаря кит не везёт.
- **Календарь-витрина, а не поле** — [`rt-calendar`](./?path=/docs/components-calendar--docs).
- **Только время без обёртки** — [`rt-input`](./?path=/docs/components-input-overview--docs)
  с `type="time"`.

## Оси

| ось           | значения                         | умолчание |
| ------------- | -------------------------------- | --------- |
| размер        | `sm`, `md`, `lg`                 | `md`      |
| тип           | `date`, `datetime-local`, `time` | `date`    |
| наполненность | пусто, со значением              | пусто     |
| рамка         | видна, снята (`bordered=false`)  | видна     |

**Ось, которую нельзя показать статикой.** `min` и `max` уезжают на нативное поле, и в покое
ячейка с ограничением неотличима от ячейки без него: границы проявляются, только когда календарь
открыт или значение вводят руками.

**Вид зависит от браузера.** Кнопка календаря, порядок частей даты и всплывающая панель
принадлежат платформе — на другой ОС те же ячейки выглядят иначе. Это контракт компонента, а не
расхождение вёрстки.

## Состояния

| состояние     | чем задаётся                         | что меняется                                       |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| обычное       | —                                    | рамка `--rt-input-color-border`                    |
| наведение     | —                                    | **ничего:** своего `:hover` у поля нет             |
| фокус внутри  | `:focus-within`                      | рамка фокуса и `--rt-input-focus-shadow`           |
| ошибка        | контрол `invalid` после касания      | рамка `--rt-input-color-border-error`              |
| отключено     | вход `disabled` или слово формы      | прозрачность `--rt-input-disabled-opacity`, курсор |
| только чтение | `[readonly]` на вмещающем `rt-field` | локализованный текст даты, пустое — прочерком      |

**В режиме чтения ISO-строка переписывается на язык интерфейса** через `Intl.DateTimeFormat`:
`2026-03-15` → `15 мар. 2026 г.` под `ru`. Нераспознанная строка показывается как есть, а не
исчезает: значение может прийти из формы, минуя нативное поле.

## Доступность

- Подпись даёт вмещающий `rt-field`; без обёртки полю нужен `ariaLabel`.
- Клавиатурный ввод, перемещение между частями даты и открытие календаря обрабатывает браузер —
  своих обработчиков клавиатуры здесь нет.
- Ошибка объявляется атрибутом `aria-invalid` на нативном поле.

## Оформление

Собственных свойств нет: поле берёт группу `--rt-input-*` целиком и стоит в форме вровень с
`rt-input`. Внутренние элементы нативного поля (кнопку календаря, разделители) оформить нельзя —
они принадлежат браузеру.

## Входы

| вход   | тип                                    | умолчание |
| ------ | -------------------------------------- | --------- |
| `type` | `'date' \| 'datetime-local' \| 'time'` | `'date'`  |
| `min`  | `string \| null` — ISO                 | `null`    |
| `max`  | `string \| null` — ISO                 | `null`    |

## Входы от основы полей

Достались от `RtFormControlBase` — общей основы полей кита; в ней же они и меняются, сразу для
всех наследников.

| вход        | тип                    | умолчание |
| ----------- | ---------------------- | --------- |
| `size`      | `'sm' \| 'md' \| 'lg'` | `'md'`    |
| `disabled`  | `boolean`              | `false`   |
| `controlId` | `string \| null`       | `null`    |
| `ariaLabel` | `string \| null`       | `null`    |
| `clearable` | `boolean`              | `true`    |
| `bordered`  | `boolean`              | `true`    |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы. Разбор строки и часовые пояса остаются на стороне потребителя — `Date` компонент не
создаёт.

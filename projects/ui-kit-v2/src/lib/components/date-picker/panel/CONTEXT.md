# `rt-date-panel`

```html
<rt-date-panel type="datetime-local" [value]="value()" (picked)="value.set($event)" (closed)="close()" />
```

Панель выбора даты и времени. Её открывает [`rt-date-picker`](../CONTEXT.md), а для выбора без
текстового поля она идёт из той же точки входа `@rt-tools/ui-kit-v2/date-picker`.

| вход                 | тип                                    | умолчание  |
| -------------------- | -------------------------------------- | ---------- |
| `type`               | `'date' \| 'time' \| 'datetime-local'` | обязателен |
| `value`              | `string` (форма значения поля)         | `''`       |
| `min` / `max`        | `string \| null` (форма значения)      | `null`     |
| `minuteStep`         | `number`                               | `5`        |
| `sheet`              | `boolean`                              | `false`    |
| `now`                | `Date \| null`                         | `null`     |
| `isTodayButtonShown` | `boolean`                              | `true`     |

`isTodayButtonShown` показывает «Сегодня» у типа `date`. Без кнопки подвала у даты нет, день
выбирается нажатием и сразу закрывает панель. Подвал других типов этот вход не трогает.

| выход    | значение | когда                                                       |
| -------- | -------- | ----------------------------------------------------------- |
| `picked` | `string` | готовое значение в форме `value`                            |
| `closed` | —        | панель просит закрыть себя: после выбора и по Escape в днях |

## Главное, что нужно знать

**Поповер или шторку держит потребитель.** Панель сама не открывается и не закрывается: он создаёт
её заново на каждое открытие и закрывает по `closed`. Черновик живёт, пока панель открыта.

**Своей поверхности у панели нет.** В поповере фон, рамку и тень даёт потребитель, в
`rt-bottom-sheet` их даёт шторка. Вход `sheet` включает вид для шторки: дни под палец, а у даты со
временем переключатель «Дата | Время».

Как это выглядит, показывают истории раздела `Molecules/Forms/DatePanelOpening`.

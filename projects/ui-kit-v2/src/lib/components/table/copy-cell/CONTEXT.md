# `rt-copy-cell`

Значение с кнопкой копирования. Кнопка рисует `ico-copy`, после нажатия на две секунды — `check`.

```html
<rt-copy-cell [value]="row.id">{{ row.id }}</rt-copy-cell>
<rt-copy-cell framed>https://example.com/hook</rt-copy-cell>
```

| вход            | тип                     | умолчание |
| --------------- | ----------------------- | --------- |
| `value`         | `string \| number`      | `null`    |
| `variant`       | `IRtIconButton.Variant` | `'ghost'` |
| `revealOnHover` | `boolean`               | `true`    |
| `framed`        | `boolean`               | `false`   |

## Главное, что нужно знать

**В таблице кнопка появляется при наведении на строку.** Вне таблицы строки для наведения нет,
и `revealOnHover="false"` держит кнопку видимой всегда.

**`framed` ставит ячейку в рамку поля ввода.** Фон, рамка и радиус поля, значение кеглем поля,
отступ слева как у текста поля, кнопка видна всегда и прижата к правому краю рамки. Так адрес для
копирования стоит в форме панели подключения службы. Длинное значение в рамке переносится на
следующую строку, а не обрезается: на телефоне адрес идёт в две строки.

**Обрезанное значение показывает подсказку целиком.** Обрезка меряется в минуту наведения; в
рамке значение не обрезается.

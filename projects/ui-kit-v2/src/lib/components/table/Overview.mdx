<Title>Table — `rt-table`</Title>

Таблица поверх CDK: колонки объявляются директивами, строки приходят набором. На узком экране
сама переключается на карточки.

```html
<table rt-table ariaLabel="Договоры" [dataSource]="rows()" [columns]="columns" [columnsConfig]="config">
    <ng-container cdkColumnDef="title">
        <th *cdkHeaderCellDef cdk-header-cell>Договор</th>
        <td *cdkCellDef="let row" cdk-cell>{{ row.title }}</td>
    </ng-container>
    <tr *cdkHeaderRowDef="columns" cdk-header-row></tr>
    <tr *cdkRowDef="let row; columns: columns" cdk-row></tr>
</table>
```

## Когда применять

- Много однородных записей с колонками, сортировкой и действиями над строкой.

## Когда не применять

- **Реквизиты одного объекта** — [`rt-detail-list`](./?path=/docs/components-detail-list-overview--docs).
- **Распределение по величинам** — [`rt-bar-list`](./?path=/docs/components-bar-list-overview--docs).

## Оси

| ось            | значения                                                      | умолчание    |
| -------------- | ------------------------------------------------------------- | ------------ |
| плотность      | `default`, `compact`                                          | `default`    |
| загрузка       | данные на месте, первая загрузка, догрузка                    | на месте     |
| порядок строк  | без порядка, по возрастанию, по убыванию                      | без порядка  |
| пустая таблица | переведённый текст, свой текст, текст и пояснение, без иконки | переведённый |
| нажимаемость   | обычная, `clickable`                                          | обычная      |

**`loading` и `fetching` — разные состояния.** Первая загрузка при пустых данных подменяет
строки заглушками; догрузка оставляет уже показанное на месте — иначе таблица мигала бы при
каждой смене страницы. Порознь их не различить, поэтому в матрице они стоят рядом.

Колонки объявляются директивами таблицы, а не входом-набором, поэтому каждая ячейка матрицы
несёт свою копию разметки: одну таблицу в несколько ячеек не поставить.

## Карточки

**Карточки — это другая разметка, а не перестроенная стилями таблица.** Компонент сам решает по
ширине показа, что показать, — порог берётся у службы порогов ширины, а не у медиазапроса в
стилях. Поэтому у матриц есть второй кадр, на узком показе.

Подписью в карточке служит **ключ колонки**: заголовки живут в шаблонах ячеек CDK, куда карточка
не дотягивается. Осмысленные подписи даёт `columnsConfig` — без него в карточке будут видны
`title` и `city` вместо «Договор» и «Город».

## Края

| край                     | что происходит                                     |
| ------------------------ | -------------------------------------------------- |
| пустой набор             | вместо строк — заглушка с иконкой и текстом        |
| пустой `emptyMessage`    | остаётся переведённый текст                        |
| `emptyIcon` равен `null` | заглушка без иконки                                |
| колонка без `sortable`   | её заголовок не переключает порядок                |
| `locked` у колонки       | её нельзя скрыть и передвинуть в настройке колонок |

## Состояния

| состояние           | чем задаётся                | что меняется                                |
| ------------------- | --------------------------- | ------------------------------------------- |
| обычное             | —                           | строки как есть                             |
| первая загрузка     | `loading` при пустых данных | строки подменяются заглушками               |
| догрузка            | `fetching`                  | строки остаются, поверх — признак занятости |
| наведение на строку | `:hover` при `clickable`    | подложка строки                             |
| пустая              | пустой набор                | заглушка вместо строк                       |

## Доступность

- Таблица несёт `ariaLabel`: без него скринридер называет её просто таблицей.
- Заголовок сортируемой колонки — кнопка с объявленным направлением, а не только стрелка.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

## Рядом

- [`rt-pagination`](./?path=/docs/components-pagination-overview--docs) — полоса под таблицей.
- [`rt-table-settings-aside`] — панель настройки колонок.

## Входы

| вход                       | тип                                    | умолчание   | что делает                                                             |
| -------------------------- | -------------------------------------- | ----------- | ---------------------------------------------------------------------- |
| `ariaLabel`                | `string \| null`                       | `null`      | имя таблицы для скринридера                                            |
| `density`                  | `IRtTable.Density`                     | `'default'` | высота строк                                                           |
| `cards`                    | `boolean`                              | `true`      | разрешает переключение на карточки на узком показе                     |
| `clickable`                | `boolean`                              | `false`     | строка отзывается на наведение и нажатие                               |
| `loading`                  | `boolean`                              | `false`     | первая загрузка: строки подменяются заглушками                         |
| `fetching`                 | `boolean`                              | `false`     | догрузка: показанные строки остаются на месте                          |
| `columns`                  | `ReadonlyArray<string>`                | `[]`        | ключи колонок в порядке показа                                         |
| `columnsConfig`            | `ReadonlyArray<IRtTable.ColumnConfig>` | `[]`        | подписи колонок, сортируемость, скрытие и закрепление                  |
| `tableId`                  | `string \| null`                       | `null`      | ключ, под которым запоминается настройка колонок                       |
| `showRowActions`           | `boolean`                              | `false`     | колонка действий над строкой                                           |
| `rowHasActions`            | `RowActionsPredicate \| null`          | `null`      | у каких строк действия есть                                            |
| `sort`                     | `ISortModel<string> \| null`           | `null`      | текущий порядок строк                                                  |
| `skeletonRows`             | `number`                               | `5`         | сколько заглушек рисовать при первой загрузке                          |
| `emptyMessage`             | `string`                               | `''`        | текст заглушки; пустой оставляет переведённый                          |
| `emptyIcon`                | `IRtIcon.Name \| null`                 | `'inbox'`   | иконка заглушки; `null` убирает её                                     |
| `emptyDescription`         | `string \| null`                       | `null`      | пояснение под текстом заглушки                                         |
| `rtTableCardRowType`       | `readonly TRow[]`                      | `[]`        | носитель типа строки для своего шаблона карточки; в работе не читается |
| `rtTableRowActionsRowType` | `readonly TRow[]`                      | `[]`        | то же для шаблона действий над строкой                                 |

Последние два входа значения не несут: в них биндят тот же набор, что в `dataSource`, и служат
они только выводу типа `let-row` в своих шаблонах. Убрать их нельзя — без них строка в шаблоне
теряет тип, — и описаны они здесь потому, что это входы, а не потому, что их настраивают.

## Выходы

| выход        | что сообщает                                        |
| ------------ | --------------------------------------------------- |
| `sortChange` | нажат заголовок колонки; порядок меняет потребитель |

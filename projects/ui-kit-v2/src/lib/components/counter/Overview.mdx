<Title>Counter — `rt-counter`</Title>

Счётчик «− N +» для целых величин: гостей, мест, единиц. Значение меняется только шагами —
набрать его с клавиатуры нельзя.

```html
<rt-counter ariaLabel="Гостей" [min]="1" [max]="4" [formControl]="guests" />

<rt-counter-row label="Взрослых" hint="От 14 лет">
    <rt-counter ariaLabel="Взрослых" [min]="1" [formControl]="adults" />
</rt-counter-row>
```

## Когда применять

- Небольшое целое, которое набирают на один-два шага: количество гостей, мест, штук.
- Строка списка настроек — вместе с [`rt-counter-row`](./?path=/docs/components-counterrow-overview--docs).

## Когда не применять

- **Число набирают, а не наращивают** — [`rt-input-number`](./?path=/docs/components-inputnumber-overview--docs):
  дойти шагами до 1500 нельзя.
- **Дробное значение** — здесь нет ни дробной части, ни маски: шаг всегда целый.

## Оси

Ось у счётчика по сути одна — значение; остальное решает, как оно выглядит и что доступно.

| ось           | значения                                                            | умолчание       |
| ------------- | ------------------------------------------------------------------- | --------------- |
| положение     | на нижней границе, между границами, на верхней границе, без потолка | между границами |
| разрядность   | ноль, две цифры, три цифры                                          | —               |
| отключённость | включён, отключён целиком                                           | включён         |

**Границы — не отдельная ось, а то, что гасит кнопку.** На нижней границе гаснет «минус», на
верхней — «плюс», и по одному только входу `min` или `max` этого не видно: важно, где между
ними стоит значение. Поэтому в матрице ячейки различаются положением, а не входами.

**Оси, которых не видно.** `step` проявляется только в движении — на статичной картинке шаг 1
и шаг 5 выглядят одинаково; попробовать его можно в `Playground`. `ariaLabel`, `decreaseLabel`
и `increaseLabel` уходят в атрибуты для скринридера.

## Состояния

Своих состояний взаимодействия у счётчика нет: наведение, нажатие и фокус принадлежат кнопкам
[`rt-icon-button`](./?path=/docs/components-iconbutton-overview--docs) и показаны в их матрице.
Собственных состояний три, и все они — про доступность шага.

| состояние        | чем задаётся                    | что видно           |
| ---------------- | ------------------------------- | ------------------- |
| обычное          | значение между границами        | обе кнопки активны  |
| минус погашен    | значение на `min`               | уменьшать некуда    |
| плюс погашен     | значение на `max`               | увеличивать некуда  |
| отключён целиком | вход `disabled` или слово формы | обе кнопки погашены |

**Границы держатся и при записи из формы.** `control.setValue(99)` при `max=4` даст 4, а `null` —
нижнюю границу: иначе кнопки блокировались бы по состоянию, которого на экране нет. Шаг,
упирающийся в границу, останавливается на ней, и если значение не изменилось, наружу не уходит
ни `change`, ни `touched`.

## Доступность

- Хост объявлен `role="group"` с `aria-label`, значение помечено `aria-live="polite"`: скринридер
  называет назначение счётчика и проговаривает новое число.
- Подписи кнопок берутся из словаря кита и перекрываются поштучно — форма знает, что именно
  считает («Убрать гостя» вместо «Уменьшить»).

## Оформление

Кнопки и значение — элементы блока `rt-counter`; сами кнопки нарисованы
[`rt-icon-button`](./?path=/docs/components-iconbutton-overview--docs) в облике `secondary`
размера `sm`, поэтому счётчик наследует их палитру и кольцо фокуса.

## Входы

| вход            | тип              | умолчание                     |
| --------------- | ---------------- | ----------------------------- |
| `ariaLabel`     | `string \| null` | `null`                        |
| `min`           | `number`         | `0`                           |
| `max`           | `number`         | `Number.MAX_SAFE_INTEGER`     |
| `step`          | `number`         | `1`                           |
| `decreaseLabel` | `string`         | `''` → переведённое умолчание |
| `increaseLabel` | `string`         | `''` → переведённое умолчание |
| `disabled`      | `boolean`        | `false`                       |

## Выходы

Своих выходов нет: значение уходит через `ControlValueAccessor`, то есть в связанный контрол
формы.

## Рядом

- [`rt-input-number`](./?path=/docs/components-inputnumber-overview--docs) — когда число набирают.
- [`rt-counter-row`](./?path=/docs/components-counterrow-overview--docs) — строка с подписью, куда счётчик кладут.
- [`rt-icon-button`](./?path=/docs/components-iconbutton-overview--docs) — чем нарисованы «−» и «+».

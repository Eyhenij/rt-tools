# `rt-counter`

Счётчик «− N +» для целых величин: гости, места, единицы.

```html
<rt-counter ariaLabel="Гостей" [formControl]="guests" [min]="1" [max]="4" [step]="1" />
```

| вход                              | тип                | умолчание                     |
| --------------------------------- | ------------------ | ----------------------------- |
| `ariaLabel`                       | `string \| null`   | `null`                        |
| `min`                             | `number \| string` | `0`                           |
| `max`                             | `number \| string` | `Number.MAX_SAFE_INTEGER`     |
| `step`                            | `number \| string` | `1`                           |
| `decreaseLabel` / `increaseLabel` | `string`           | `''` → переведённые умолчания |
| `disabled`                        | `boolean`          | `false`                       |

Значение — `number` через `ControlValueAccessor`.

## Главное, что нужно знать

**Значение с клавиатуры не вводится — только шагами.** Поэтому здесь нет ни маски, ни дробной
части, ни кнопки очистки. Если число нужно набирать, это
[`rt-input-number`](../input-number/CONTEXT.md), а не счётчик.

**Границы держатся и при записи из формы.** `control.setValue(99)` при `max=4` даст 4, а `null` —
нижнюю границу. Иначе кнопки блокировались бы по состоянию, которого на экране нет.

## Как этим пользоваться

- Шаг, упирающийся в границу, не перепрыгивает её, а останавливается на ней; если значение при
  этом не изменилось, наружу не уходит ни `change`, ни `touched`.
- Подписи кнопок для скринридера берутся из словаря кита и перекрываются поштучно — форма знает,
  что именно считает («Убрать гостя» вместо «Уменьшить»).
- Host объявлен `role="group"` с `aria-label`, значение помечено `aria-live="polite"`: скринридер
  называет назначение счётчика и проговаривает новое число.

## Рядом

- [`rt-input-number`](../input-number/CONTEXT.md) — когда число набирают.

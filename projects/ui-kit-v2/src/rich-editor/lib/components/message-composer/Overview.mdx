<Title>MessageComposer — `rt-message-composer`</Title>

Поле набора сообщения — капсула: слева круглая скрепка, по центру растущий по содержимому текст,
справа круглая кнопка отправки со стрелкой. Вложения стоят внутри капсулы над строкой; под ней
можно включить подсказку про Enter.

Импорт — из второго входа пакета, `@rt-tools/ui-kit-v2/rich-editor`: компонент работает на quill, и
основной вход его не отдаёт.

```html
<rt-message-composer placeholder="Написать сообщение" attachments accept=".pdf,.png" [sending]="sending()" (submitted)="send($event)" />
```

## Когда применять

- Нижняя часть переписки, форма ответа, поле комментария.

## Когда не применять

- **Длинный текст с оформлением как основной документ** — `rt-rich-editor`.
- **Однострочный ввод** — [`rt-input`](./?path=/docs/atoms-forms-input-overview--docs).

## Оси

| ось         | значения                                    | умолчание |
| ----------- | ------------------------------------------- | --------- |
| состояние   | девять состояний макета и остановимый ответ | пустое    |
| вложения    | без них, скрепка есть, с файлом             | без них   |
| оформление  | простой текст, панель оформления            | простой   |
| высота поля | одна строка, три строки                     | одна      |
| подсказка   | без неё, строка про Enter                   | без неё   |

**`sending` и `disabled` блокируют одно и то же, а означают разное**: первое — отправка в пути,
второе — поле выключено снаружи. Рядом это видно, и в обзоре сказано прямо, потому что по виду
они не различаются.

## Как показаны набор и фокус

Значения у поля нет: текст живёт в его форме. Поэтому в матрице состояний текст набирает
директива витрины тем же событием ввода, что и человек, — компонент тот же. Фокус в ряду может
быть только у одной ячейки, поэтому его рисует аддон псевдосостояний: он переписывает
`:focus-within` капсулы на класс.

Отправка разблокируется только при непустом содержимом. Пробелы значением не считаются; один
вложенный файл разблокирует отправку и без текста.

## Вид

- **Капсула** полностью скруглена на одной строке. Когда текст перенёсся, внутри лежат файлы или
  включено оформление, она берёт шаг скругления 20.
- **В покое** у капсулы фон и рамка полей кита, **в фокусе** — поверхность, рамка фокуса и кольцо.
- **Кнопки** — круглые `rt-icon-button` 40: скрепка прозрачная с приглушённой иконкой, отправка
  основная. Пока отправлять нечего, стрелка бледная; во время отправки её сменяет индикатор.
- **Текст** растёт до `maxRows` строк, кнопки прижаты к низу; дальше поле прокручивается.
- **Размер текста** — как у полей кита: 14, под пальцем 16. В макете 15, но такого шага в шкале нет.
- **Режим оформления** в макете не нарисован: редактор стоит в той же капсуле со своим фоном.

## Края

| край             | что происходит                                                     |
| ---------------- | ------------------------------------------------------------------ |
| после отправки   | форма сбрасывается целиком — и текст, и файлы                      |
| режим оформления | текст уезжает пустым, содержимое едет отдельным полем строкой JSON |
| `droppedFiles`   | **вход, а не выход**: файлы, брошенные в область, приходят снаружи |

## Состояния

| состояние       | чем задаётся            | что меняется                                                   |
| --------------- | ----------------------- | -------------------------------------------------------------- |
| пустое          | —                       | подсказка в поле, бледная стрелка                              |
| фокус           | фокус в тексте          | белая капсула, рамка фокуса и кольцо                           |
| набор           | текст                   | стрелка синяя                                                  |
| несколько строк | перенос текста          | скругление 20, кнопки внизу                                    |
| отправка        | вход `sending`          | поле и кнопки заблокированы, вместо стрелки индикатор          |
| ответ идёт      | `stoppable` и `sending` | поле открыто, вместо стрелки кнопка «Стоп»                     |
| выключено       | вход `disabled`         | то же без индикатора, по решению приложения; подсказка бледнее |
| предел роста    | `maxRows` строк         | поле больше не растёт                                          |
| прокрутка       | текст длиннее           | текст прокручивается внутри, виден тонкий ползунок             |

## Доступность

- **Enter отправляет, Shift с Enter переносит строку.** Набор во время композиции ввода
  игнорируется — иначе иероглифическая раскладка отправляла бы недописанное.
- У скрепки, кнопки отправки и кнопки «Стоп» переведённые имена.
- Метод `focus()` возвращает фокус в поле, когда кнопка с фокусом ушла с экрана.

## Оформление

Светлая и тёмная темы стоят рядом в истории **Themes**.

- [`rt-chat`](./?path=/docs/organisms-chat-chat-overview--docs) — переписка, в которой это поле
  стоит снизу.

## Входы

| вход           | тип                    | умолчание | что делает                                   |
| -------------- | ---------------------- | --------- | -------------------------------------------- |
| `placeholder`  | `string`               | `''`      | подсказка в пустом поле                      |
| `accept`       | `string`               | `''`      | какие файлы принимает скрепка                |
| `attachments`  | `boolean`              | `false`   | показывает скрепку                           |
| `sending`      | `boolean`              | `false`   | отправка в пути: поле и кнопка заблокированы |
| `stoppable`    | `boolean`              | `false`   | при `sending` — кнопка «Стоп», поле открыто  |
| `text`         | `string` (model)       | `''`      | черновик поля, двусторонний                  |
| `disabled`     | `boolean`              | `false`   | поле выключено снаружи                       |
| `formatting`   | `boolean`              | `false`   | панель оформления вместо простого текста     |
| `hint`         | `boolean`              | `false`   | строка про Enter под капсулой                |
| `toolbar`      | `TRtRichEditorToolbar` | —         | какие кнопки в панели оформления             |
| `minRows`      | `number`               | `1`       | высота пустого поля в строках                |
| `maxRows`      | `number`               | `6`       | до скольких строк поле растёт                |
| `droppedFiles` | `File[] \| null`       | `null`    | файлы, брошенные снаружи, — вход, а не выход |

## Выходы

| выход       | что сообщает                                                    |
| ----------- | --------------------------------------------------------------- |
| `submitted` | сообщение отправлено: текст, файлы и, в режиме оформления, тело |
| `stopped`   | нажата кнопка «Стоп» во время остановимого ответа               |

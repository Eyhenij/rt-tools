<Title>AiChatSources — `rt-ai-chat-sources`</Title>

Блок `sources` ответа ассистента: список источников, из которых взяты цифры ответа. Модель отдаёт
названия источников, уточнения (страница, период, фильтры), имена значков и адреса. Кит рисует блок
сам, без регистрации отрисовщика, свёрнутым под заголовком «Источники» с числом источников. Источник
он не открывает: нажатие источника с адресом уходит из чата событием `sourceOpen`, а открывает
источник приложение.

```ts
// Блок ответа — как его отдала модель.
{
    type: 'sources',
    items: [
        { title: 'Отчёт «Продажи»', detail: 'Ноябрь 2026 · все филиалы', icon: 'chart-bar', url: '/reports/sales' },
        { title: 'Склад (внутренний учёт)', detail: 'Обновлено вчера', icon: 'database' },
    ],
}
```

Схему блока для модели кит отдаёт значением `RT_AI_CHAT_SOURCES_SCHEMA` (JSON Schema 2020-12): в
ней `items`, а у источника `title`, `detail`, `icon` и `url`. Приведение данных — `rtSourcesData`.

## Нажатие источника

Приложение слушает `sourceOpen` и открывает источник. Событие приходит синхронно, внутри
обработчика нажатия, поэтому новую вкладку браузер открыть разрешает.

```ts
protected onSourceOpen(event: IRtAiChat.SourceOpen): void {
    // Адрес написала модель: свои маршруты приложение узнаёт само, чужой адрес не открывает.
    if (this.isKnownRoute(event.url)) {
        this.router.navigateByUrl(event.url);
    }
}
```

```html
<rt-ai-chat [messages]="messages()" (sourceOpen)="onSourceOpen($event)" />
```

Круг показан историей **Panel**: оба блока раскрываются, нажатие каждого источника с адресом пишет
событие строкой под чатом. Второй блок стоит в секции составного ответа и ведёт себя так же.

- **Источник с адресом — кнопка, без адреса — текст.** Нажатие текста ничего не отдаёт.
- **Адрес пишет модель.** Кит его не проверяет и не открывает; схему адреса сверяет приложение.
- **Событие называет сообщение, адрес и название.** Повторное нажатие даёт повторное событие.
- **Раскрытое или свёрнутое состояние хранит панель и никому не отдаёт.** Блок, в который
  строки приходят по ходу потока, остаётся раскрытым; блок нового сообщения начинает свёрнутым.

## Когда применять

- Ответ ассистента с цифрами, у которых есть происхождение: отчёт, страница, период, фильтры.

## Когда не применять

- **Одна страница, на которую ведёт ответ** — блок `link`: у него карточка с кнопками.
- **Ссылка в тексте ответа** — блок `markdown`.

## Оси

| ось              | значения                                                       |
| ---------------- | -------------------------------------------------------------- |
| список           | свёрнут, раскрыт                                               |
| число источников | один, пять                                                     |
| источник         | с адресом (кнопка), без адреса (текст)                         |
| уточнение        | есть, нет                                                      |
| значок           | имя из набора кита; без имени и с чужим именем — `file`        |
| ширина ленты     | 328 и 386 — узкая панель, 640 — колонка чтения в полном экране |

Состояния списка показаны историей **States**, ширины макета — **Widths**, уточнение, адрес и значок
— **Parts**. `Playground` — блок с контролами текста первого источника и ширины.

## Края

| край                                 | что происходит                                               |
| ------------------------------------ | ------------------------------------------------------------ |
| длинное название или уточнение       | одна строка и многоточие; целый текст остаётся в разметке    |
| равные источники                     | не склеиваются: строк и число столько же, сколько источников |
| имя значка, которого в наборе нет    | значок `file`: запроса за рисунком по чужому имени нет       |
| источник без названия                | выпадает; число считает оставшиеся                           |
| нет списка, он пуст или без названий | заглушка ленты на месте блока                                |

Края показаны историями **Widths** (длинные тексты), **Parts** и **Invalid**.

## Состояния

| состояние           | чем задаётся      | что видно                                     |
| ------------------- | ----------------- | --------------------------------------------- |
| свёрнут             | по умолчанию      | заголовок с подписью, числом и шевроном вниз  |
| раскрыт             | нажатие заголовка | шеврон вверх, строки под заголовком           |
| источник с адресом  | поле `url`        | строка — кнопка, наведение и фокус рисует кит |
| источник без адреса | нет `url`         | строка — текст                                |
| тёмная              | признак темы      | цвета тёмной темы                             |

## Доступность

- Заголовок — кнопка панели: Enter и Space раскрывают и сворачивают список, состояние читается из `aria-expanded`.
- Тело — область (`role="region"`), названная заголовком; строки — пункты списка.
- Значок источника от читалки скрыт; источник с адресом — кнопка с именем по названию, уточнение — её описание.
- Название и уточнение обрезаются многоточием, но остаются в разметке целиком.
- При письме справа налево строка и шеврон зеркалятся — история **Rtl**.
- Текст ответа при копировании несёт блок строкой заголовка и строкой на источник: название, уточнение и адрес через табуляцию.

## Оформление

Карточка: рамка `--rt-color-border-default` в 1, фон `--rt-color-bg-surface`, скругление 12, поля 4 со всех сторон; 8 до подписи и значка дают заголовок и строки. Заголовок — плоский вид `rt-expansion-panel` высотой 40, число того же цвета, что подпись. Строка: отступ 8 сверху и снизу, значок 20, от него до текста 12; название 14 средним начертанием, уточнение 12 приглушённым, между ними 2. Под списком 8. Наведение занимает строку целиком со скруглением 8, кольцо фокуса идёт внутрь строки: снаружи его срезало бы тело панели. Светлая и тёмная темы — история **Themes**, наборы оформления — **Presets**.

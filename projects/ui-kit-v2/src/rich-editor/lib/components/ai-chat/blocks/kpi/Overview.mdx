<Title>AiChatKpi — `rt-ai-chat-kpi`</Title>

Блок `kpi` ответа ассистента. Модель отдаёт карточки данными: подпись, значение, род значения,
дельту, базу сравнения и период. Кит рисует их сам, без регистрации отрисовщика: каждая карточка —
компактная плитка [`rt-stat-tile`](./?path=/docs/molecules-data-stattile-overview--docs) в рамке
блока. Значение пишется по роду в языке кита, от миллиона — коротко: «1,24 млн ₽».

```ts
// Блок ответа — как его отдала модель.
{
    type: 'kpi',
    items: [
        { label: 'Выручка', value: 1240000, format: 'currency', currency: 'RUB', delta: 12.5, base: 'vs LY', period: 'ноябрь 2026' },
        { label: 'Загрузка', value: 0.78, format: 'percent', delta: 0, deltaUnit: 'points', base: 'vs LM' },
        { label: 'Отмены', value: 14, delta: 8, growthIsGood: false },
    ],
}
```

Схему блока для модели кит отдаёт значением `RT_AI_CHAT_KPI_SCHEMA` (JSON Schema 2020-12).
Приведение данных — `rtKpiItems`, запись значения — `rtKpiValueWriter`.

## Когда применять

- Ответ ассистента, где модель отдаёт одно или несколько итоговых чисел с изменением.

## Когда не применять

- **Плитки на экране приложения** — `rt-stat-tile` прямо в разметке экрана.
- **Значения в колонках, сравнение строк** — блок [`table`](./?path=/docs/organisms-chat-aichattable-overview--docs).

## Оси

| ось            | значения                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| род значения   | `number`, `percent` (доля: 0.78 — «78,0 %»), `currency` с кодом ISO 4217 |
| единица дельты | `percent`, `points` — процентные пункты                                  |
| рост хорош     | да, нет — тогда рост красится цветом опасности                           |
| ширина блока   | уже 328, от 328, от 664                                                  |

Колонки задаёт ширина самого блока, а не окна: одна колонка уже 328, две от 328, четыре от 664.
Ширины показаны историями **Widths**, **Threshold** и **Below**; ответ в панели, во весь экран и в
колонке чтения 40rem — **Panel**, **FullScreen** и **ReadingColumn**. Колонка чтения уже 664,
поэтому в ней две колонки. Дельты — **Deltas**, короткая запись — **Short**.

## Края

| край                                   | что происходит                                         |
| -------------------------------------- | ------------------------------------------------------ |
| значение от миллиона                   | коротко: «1,24 млн ₽», «2,5 млрд»; доля — всегда полно |
| строка вместо числа                    | стоит как пришла                                       |
| дельта, записанная нулём               | ровная, без знака и без стрелки вверх или вниз         |
| нет дельты, базы или периода           | строки нет, карточки ряда остаются одной высоты        |
| длинная подпись, база или период       | переносятся в пределах карточки, лента не раздвигается |
| нечётное число карточек                | последний ряд держит ширину колонки                    |
| карточка без подписи или значения      | выпадает из блока                                      |
| `items` не список, пуст или все выпали | заглушка ленты на месте блока                          |

Края показаны историями **Parts**, **Odd**, **Long**, **Several** и **Invalid**.

## Состояния

| состояние | чем задаётся                  | что видно         |
| --------- | ----------------------------- | ----------------- |
| обычное   | годный блок                   | сетка карточек    |
| тёмная    | признак темы на узле или выше | цвета тёмной темы |

Своих состояний взаимодействия у блока нет: карточки ничего не запускают и фокус не принимают.

## Доступность

- Блок — список `ul`, карточка — пункт `li`: скринридер называет число карточек.
- Изменение несёт не только цвет: знак числа, стрелка и подпись базы словами.
- При письме справа налево сетка зеркалится, числа читаются в своём порядке — история **Rtl**.
- Текст ответа при копировании несёт каждую карточку строкой: подпись, значение, дельта с базой и
  период через табуляцию.

## Оформление

Рамка карточки — `--rt-color-border-default`, фон `--rt-color-bg-surface`, отступ 12, скругление 12,
промежуток сетки 8. Светлая и тёмная темы — история **Themes**, наборы оформления — **Presets**.

## Рядом

- [`rt-ai-chat`](./?path=/docs/organisms-chat-aichat-overview--docs) — беседа, в ленте которой стоит блок.
- [`rt-stat-tile`](./?path=/docs/molecules-data-stattile-overview--docs) — плитка карточки в компактном размере.
- [`rt-ai-chat-table`](./?path=/docs/organisms-chat-aichattable-overview--docs) — блок таблицы ответа.

## Входы

| вход    | тип                     | умолчание      | что делает                                        |
| ------- | ----------------------- | -------------- | ------------------------------------------------- |
| `items` | `readonly IRtKpiItem[]` | **обязателен** | карточки, приведённые лентой к виду для рисования |

<Title>AiChatTable — `rt-ai-chat-table`</Title>

Блок `table` ответа ассистента. Модель отдаёт таблицу данными: столбцы с родом значения, строки
значений по порядку столбцов и строку итога по желанию. Кит рисует её сам, без регистрации
отрисовщика: числа пишутся по роду столбца в языке кита, отрицательные — цветом ошибки. Под
таблицей «Copy CSV» кладёт в буфер CSV тех строк, что нарисованы.

```ts
// Блок ответа — как его отдала модель.
{
    type: 'table',
    title: 'Выручка по типам номеров',
    columns: [
        { label: 'Тип номера', type: 'text' },
        { label: 'Брони', type: 'number' },
        { label: 'Выручка', type: 'currency', currency: 'RUB' },
        { label: 'Изменение', type: 'percent' },
    ],
    rows: [['Апартаменты', 27, 1240000, 0.125]],
    total: ['Итого', 27, 1240000, 0.125],
}
```

Схему блока для модели кит отдаёт значением `RT_AI_CHAT_TABLE_SCHEMA` (JSON Schema 2020-12).
Приведение данных — `rtTableData`, запись ячейки — `rtTableCellWriter`, CSV — `rtTableCsv`.

## Когда применять

- Ответ ассистента, где модель отдаёт значения в колонках: сравнение, разбивка, итог.

## Когда не применять

- **Таблица на экране приложения** — [`rt-table`](./?path=/docs/organisms-table-table-overview--docs):
  столбцы, настройки и карточки узкого экрана.
- **Пара строк в тексте ответа** — таблица разметки в блоке `markdown`; она берёт тот же вид.

## Оси

| ось         | значения                                                           |
| ----------- | ------------------------------------------------------------------ |
| род столбца | `text`, `number`, `percent`, `currency` с кодом валюты из ISO 4217 |
| итог        | есть, нет                                                          |
| заголовок   | есть, нет                                                          |
| ширина      | узкая лента 328, панель ассистента 386, широкий экран              |

Текстовые столбцы стоят у начала, числовые — у конца; первый текстовый забирает остаток ширины.
Таблица без текстовых столбцов идёт по своему содержимому. Роды столбцов — история **Narrow**,
итог — **WithTotal**, ширины — **Narrow** и **Wide**, заголовок — `Playground`.

## Края

| край                               | что происходит                                           |
| ---------------------------------- | -------------------------------------------------------- |
| таблица шире блока                 | окно прокручивается вбок, блок не шире ленты             |
| таблица выше 200                   | окно прокручивается вниз, шапка остаётся у верха окна    |
| значение ниже нуля                 | цвет ошибки; запись, равная нулю, без минуса и без цвета |
| строка в числовом столбце          | стоит как пришла, у конца столбца, без цвета             |
| `null`, `NaN`, бесконечность       | пустая ячейка                                            |
| неизвестный род столбца            | текст                                                    |
| строка длиннее или короче столбцов | лишнее отброшено, недостающее пусто                      |
| нет строк                          | рисуется шапка                                           |
| нет столбцов или строки не списком | заглушка ленты на месте блока                            |

Края показаны историями **Wide**, **Scrolled**, **Negatives**, **Empty** и **Invalid**.

## Состояния

| состояние   | чем задаётся                  | что видно                       |
| ----------- | ----------------------------- | ------------------------------- |
| обычное     | годный блок                   | заголовок, таблица, «Copy CSV»  |
| скопировано | нажатие «Copy CSV»            | «Copied» с галочкой две секунды |
| тёмная      | признак темы на узле или выше | цвета тёмной темы               |

Наведение, фокус и нажатие кнопки — состояния `rtButton`, показаны в его истории **States**.
«Copied» живёт две секунды и в кадр наверняка не попадает: история **Copied** проверяет смену
подписи шагом `play`, а кадра не снимает.

## Доступность

- Окно прокрутки — область с `tabindex="0"`: до него доходят с клавиатуры и прокручивают стрелками.
  Его имя — заголовок блока, без заголовка — подпись кита `aiTableLabel`.
- Ячейки шапки — `th` со `scope="col"`, итог стоит в `tfoot`.
- После копии сообщение «Copied» читается с экрана через `role="status"`.
- Текст ответа при копировании несёт таблицу строками через табуляцию, заголовок — первой строкой.

## Оформление

Таблица берёт общий вид таблиц чата: тот же у таблицы разметки и у таблицы данных графика. Шапка на
фоне `--rt-color-bg-surface`, строки 28, граница строк — `--rt-color-border-subtle`. Толщина
границы над итогом — свойство блока `--rt-ai-chat-table-total-border-width`. Светлая и тёмная
темы — история **Themes**, наборы оформления — **Presets**, письмо справа налево — **Rtl**.

## Рядом

- [`rt-ai-chat`](./?path=/docs/organisms-chat-aichat-overview--docs) — беседа, в ленте которой стоит блок.
- [`rt-ai-chat-chart`](./?path=/docs/organisms-chat-aichatchart-overview--docs) — блок графика с таблицей данных того же вида.
- [`rt-markdown-text`](./?path=/docs/molecules-markdowntext-overview--docs) — текст ответа; его таблица того же вида.

## Входы

| вход    | тип              | умолчание | что делает                                       |
| ------- | ---------------- | --------- | ------------------------------------------------ |
| `data`  | `IRtTableData`   | —         | таблица, приведённая лентой к виду для рисования |
| `title` | `string \| null` | `null`    | заголовок над таблицей и имя окна прокрутки      |

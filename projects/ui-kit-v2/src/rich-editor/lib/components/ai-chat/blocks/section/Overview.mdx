<Title>AiChatSection — `rt-ai-chat-section`</Title>

Блок `section` ответа ассистента: заголовок и сетка других блоков. Им модель собирает составной
ответ — обзор месяца, сводку по объекту — одним списком `blocks`. Кит рисует секцию сам, без
регистрации отрисовщика. В узкой панели блоки стоят друг под другом, в широкой ленте графики
встают в два столбца.

```ts
// Ответ «обзор месяца» — весь список blocks, как его отдала модель.
[
    {
        type: 'section',
        title: 'Обзор ноября',
        blocks: [
            { type: 'markdown', text: 'Ноябрь закрыт с ростом выручки на **12,5 %**.' },
            {
                type: 'kpi',
                items: [
                    { label: 'Выручка', value: 1240000, format: 'currency', currency: 'RUB', delta: 12.5, base: 'vs LY' },
                    { label: 'Средний чек', value: 8400, format: 'currency', currency: 'RUB', delta: -4, base: 'vs LY' },
                    { label: 'Загрузка', value: 0.78, format: 'percent', delta: 0, deltaUnit: 'points', base: 'vs LM' },
                    { label: 'Отмены', value: 14, delta: 8, growthIsGood: false, base: 'vs LM' },
                ],
            },
            { type: 'chart', spec: { kind: 'line', title: 'Выручка по месяцам', series: [/* … */] } },
            { type: 'chart', spec: { kind: 'bar', title: 'Брони по месяцам', series: [/* … */] } },
            {
                type: 'table',
                title: 'Объекты месяца',
                columns: [
                    { label: 'Объект', type: 'text' },
                    { label: 'Выручка', type: 'currency', currency: 'RUB' },
                ],
                rows: [['Вилла у моря', 412000]],
            },
        ],
    },
];
```

Графики в секции рисует вход `@rt-tools/ui-kit-v2/ai-chat-chart`: приложение подключает
`provideRtAiChatChart()`, иначе на месте графика стоит заглушка с именем типа.

## Схема для модели

Модели отдают схему, которую собирает функция `rtAiChatSectionSchema`. Блоки, которые кит рисует
сам, — `markdown`, `notice`, `kpi` и `table` — в ней уже есть. Приложение добавляет остальные типы
по их именам: график и свои блоки.

```ts
import { rtAiChatSectionSchema } from '@rt-tools/ui-kit-v2';
import { RT_AI_CHAT_CHART_BLOCK_SCHEMA } from '@rt-tools/ui-kit-v2/ai-chat-chart';

const parameters = rtAiChatSectionSchema({ chart: RT_AI_CHAT_CHART_BLOCK_SCHEMA });
```

- **Под именем `chart` называют схему блока графика, а не схему спецификации.** Блок графика читает
  спецификацию из поля `spec`. `RT_AI_CHAT_CHART_SCHEMA` описывает саму спецификацию: названная под
  именем `chart`, она кладёт её поля в корень блока, и график показан плашкой «не удалось».
- **Поле `type: 'section'` дописывает приложение.** Схема описывает аргументы инструмента: `title` и
  `blocks`. Блок ленты из них получается, когда приложение добавляет к ним `type: 'section'`.
- **Схема под именем своего типа кита заменяет его схему.** Так приложение сужает, например, список
  оттенков плашки.
- **Результат каждый раз новый.** Его можно менять: ни схемы кита, ни переданные схемы от этого не
  меняются.
- **Переданная схема должна быть цельной.** Она встаёт не в корень результата, и ссылка `$ref` от
  корня в ней перестаёт находить свою цель. Поле `span` принадлежит секции: своё поле с этим именем
  в переданной схеме заменяется.
- **Строгая проверка схемы требует настройки.** Схема KPI называет значение двумя типами, и Ajv в
  строгом режиме её не собирает: нужен `allowUnionTypes` или `strict: false`.
- **Строгий режим инструментов у модели проверяет приложение.** В схеме есть `oneOf`, `not`,
  `if` с `then` и `pattern`. Поставщик модели в строгом режиме может часть этих слов не принять.

Значение `RT_AI_CHAT_SECTION_SCHEMA` — схема секции без полей вложенных блоков: она требует только
`type` блока. Модели её отдают лишь там, где схема с ветками по типам слишком велика.

## Когда применять

- Ответ из нескольких блоков одной темы под общим заголовком.
- Два графика или график с таблицей, которые в широкой ленте читаются рядом.

## Когда не применять

- **Один блок** — он стоит в ленте сам, секция ему ничего не добавляет.
- **Раскладка экрана приложения** — сетка секции живёт только в ответе чата.

## Оси

| ось            | значения                                                                    |
| -------------- | --------------------------------------------------------------------------- |
| ширина секции  | уже 600 — одна колонка, от 600 — две равные                                 |
| место блока    | `span: 'full'` — вся строка, `span: 'column'` — один столбец                |
| место без span | `markdown`, `notice`, `kpi`, `table` — вся строка; остальные — один столбец |
| заголовок      | есть, нет                                                                   |

Колонки задаёт ширина самой секции, а не окна и не режим чата. Полноэкранный чат в узком окне, где
секция уже 600, рисует одну колонку. Секция уже окна на поля ленты, полосу прокрутки и колонку бесед.
Блок приложения в ячейке, который сам спрашивает ширину контейнера без имени, получает ширину
секции, а не ячейки: такому блоку нужен свой контейнер. Ширины макета показаны историей
**Widths**, порог — **Threshold**, своё место блока — **Span**. Ответ в узкой панели — **Panel**, во
весь экран — **FullScreen**, с колонкой бесед — **FullScreenThreads**, в колонке чтения 40rem —
**ReadingColumn**: в трёх последних графики стоят рядом.

Шаг сетки 16 между рядами и столбцами. Блок в ячейке раскладывается по ширине ячейки: KPI в
столбце уже 328 встаёт в одну колонку — история **KpiInCell**.

## Края

| край                                 | что происходит                                                       |
| ------------------------------------ | -------------------------------------------------------------------- |
| блок один в ряду                     | держит ширину столбца, не растягивается — **Lone**                   |
| одна колонка                         | каждый блок занимает строку, каким бы ни был его `span`              |
| блоки ряда разной высоты             | стоят на одном верхе, каждый своей высоты                            |
| длинный заголовок                    | переносится; слово длиннее секции ломается — **Titles**              |
| секция в секции                      | не рисуется: заглушка с именем типа `section` — **Plates**           |
| блок неизвестного типа               | заглушка с именем типа в своей ячейке — **Plates**                   |
| `blocks` не список, пуст, без блоков | заглушка ленты на месте секции — **Invalid**                         |
| элемент списка не блок               | выпадает, остальные рисуются                                         |
| две секции в ответе                  | каждая раскладывается по своей ширине, соседи в 16 — **TwoSections** |

## Состояния

| состояние | чем задаётся                  | что видно         |
| --------- | ----------------------------- | ----------------- |
| обычное   | годный блок                   | заголовок и сетка |
| тёмная    | признак темы на узле или выше | цвета тёмной темы |

Своих состояний взаимодействия у секции нет: она ничего не запускает и фокус не принимает.
Секция в ответе, который ещё пишется, рисуется как пришла: без блоков — заглушкой.

## Доступность

- Секция с заголовком — группа (`role="group"`), названная заголовком; без заголовка роли нет.
- Заголовок несёт уровень 3, как заголовки текста ответа.
- Блоки стоят в разметке в порядке списка: скринридер читает их так же, как в одной колонке.
- При письме справа налево столбцы зеркалятся — история **Rtl**.
- Текст ответа при копировании несёт заголовок секции и тексты её блоков через пустую строку.

## Оформление

Заголовок — 16 полужирный на строке 20, цвет `--rt-color-text-primary`, 12 над сеткой. Шаг сетки —
`--rt-space-md`. Рамки и фона у секции нет. Светлая и тёмная темы — история **Themes**, наборы
оформления — **Presets**.

## Playground

Страницы `Playground` у секции нет: её содержимое — список блоков, а не значения входов, и витрина
подставляет значения, а не разметку. Все случаи показаны матрицами.

## Входы

| вход           | тип                                  | умолчание      | что делает                                         |
| -------------- | ------------------------------------ | -------------- | -------------------------------------------------- |
| `title`        | `string \| null`                     | `null`         | заголовок секции, уже обрезанный; `null` — его нет |
| `cells`        | `readonly IRtAiChat.SectionCell[]`   | **обязателен** | ячейки сетки по порядку списка                     |
| `cellTemplate` | `TemplateRef<IRtAiChat.CellContext>` | **обязателен** | шаблон ленты, который рисует блок в ячейке         |

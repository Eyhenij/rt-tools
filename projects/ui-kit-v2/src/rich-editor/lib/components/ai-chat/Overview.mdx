<Title>AiChat — `rt-ai-chat`</Title>

Панель ИИ-ассистента одним компонентом: шапка, лента вопросов и ответов с ходом работы, пустой экран
с подсказками, ошибка с номером обращения, поле сообщения, список бесед.

```html
<rt-ai-chat [messages]="messages()" [sending]="running()" (send)="ask($event)" (stop)="stop()" />
```

Импорт — `@rt-tools/ui-kit-v2/rich-editor`.

## Когда применять

- Ассистент, который отвечает на вопросы человека и показывает ход работы.

## Когда не применять

- **Переписка людей** — [`rt-chat`](./?path=/docs/organisms-chat-chat-overview--docs).

## Состояния

- Пусто: приветствие и карточки подсказок.
- Загрузка: крутилка, пока сообщений нет.
- Думает и пишет: строка хода работы с бликом, поле с кнопкой «Стоп».
- Готов: текст, строка хода работы с шагами, строка действий — копирование и оценка.
- Ошибка: текст ошибки, номер обращения с копированием, «Ask again».
- Беседы: на месте ленты в узкой панели, колонкой слева на весь экран.

## Доступность

- Лента — `aria-live="polite"`.
- Кнопки шапки, копирования и оценки — `rt-icon-button` с именем и подсказкой; выбранная оценка —
  `aria-pressed`. После копирования имя и подсказка на две секунды — «Copied», значок — галочка.
- Ошибка — `role="alert"`.
- Фокус: на «Back to conversation» при открытии бесед, в поле сообщения после выбора беседы, новой
  беседы и «Стоп».

## Оформление

Свойства блока: `--rt-ai-chat-bubble-radius`, `--rt-ai-chat-column-border-width`,
`--rt-ai-chat-column-width`, `--rt-ai-chat-content-max-width`, `--rt-ai-chat-match-bg`, `--rt-ai-chat-match-color`,
`--rt-ai-chat-match-radius`, `--rt-ai-chat-unread-radius`.

Вид чата приложение задаёт правилом на элементе `rt-ai-chat`, без селекторов внутренних классов
чата и его частей. Без этих свойств чат выглядит как прежде.

| `--rt-ai-chat-answer-font-size`              | кегль текста ответа                                     | `--rt-text-xs`                      |
| `--rt-ai-chat-send-bg`                       | фон «Отправить» и «Стоп»                                | `--rt-color-action-primary`         |

Свойства ставятся правилом на `rt-ai-chat` или на классе приложения на нём, вне слоёв кита. С
`:root` и с обёртки они не доходят: чат объявляет их у себя. С предка наследуются только
`--rt-ai-chat-font-family`, `--rt-ai-chat-rating-active-bg` и `--rt-ai-chat-rating-active-color`.

```css
rt-ai-chat {
    --rt-ai-chat-send-bg: var(--app-primary);
    --rt-ai-chat-header-height: 4rem;
}
```

- Заголовки ответа 3–6 уровня держат `--rt-text-sm`: при кегле ответа крупнее этой ступени они
  выходят мельче текста.
- Высота шапки меньше её содержимого не сжимает кнопки: они выходят за край шапки.
- На сенсорном экране действия строк видны всегда, и `hidden` прячет время у всех строк.

## Методы

- `focusComposer()` — фокус в поле сообщения после отрисовки.

## Шаблоны

- `ng-template[rtAiChatMessageExtra]` — вложения под блоками ответа; получает сообщение ответа.
  Часть самого ответа — график, таблица — идёт блоком ленты, а не этим шаблоном.

## Блоки ответа

Ответ — `IRtAiChat.AssistantMessage` с массивом `blocks`, вопрос — `IRtAiChat.UserMessage` со
строкой `text`. Кит сам рисует семь типов блока:

| тип        | поля                                  | что рисуется                                                                                                  |
| ---------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `markdown` | `text`                                | `rt-markdown-text`                                                                                            |
| `notice`   | `severity`, `text`                    | `rt-message` этой severity                                                                                    |
| `table`    | `columns`, `rows`, `total?`, `title?` | таблица с «Copy CSV» — [AiChatTable](./?path=/docs/organisms-chat-aichattable-overview--docs)                 |
| `kpi`      | `items`                               | сетка карточек-плиток — [AiChatKpi](./?path=/docs/organisms-chat-aichatkpi-overview--docs)                    |
| `link`     | `title`, `url`, `section?`, `icon?`   | карточка страницы с двумя кнопками — [AiChatLink](./?path=/docs/organisms-chat-aichatlink-overview--docs)     |
| `sources`  | `items`                               | свёрнутый список источников цифр — [AiChatSources](./?path=/docs/organisms-chat-aichatsources-overview--docs) |
| `section`  | `blocks`, `title?`                    | заголовок и сетка блоков — [AiChatSection](./?path=/docs/organisms-chat-aichatsection-overview--docs)         |

Блоки `table`, `kpi`, `link`, `sources` и `section` кит рисует сам, даже если приложение зарегистрировало
отрисовщик этого типа. Карточка `link` никуда не переходит: нажатие её кнопки чат отдаёт событием
`linkOpen` с номером сообщения, адресом и признаком новой вкладки, а страницу открывает приложение. Блок `sources` рисуется свёрнутым списком источников; нажатие источника с адресом чат отдаёт событием `sourceOpen` с номером сообщения, адресом и названием. Секция держит другие блоки и раскладывает их в один или два столбца по своей ширине. Ответ с `interrupted: true` рисует под собой тихую строку «прерван», а в строке действий — кнопку-иконку «спросить снова»; нажатие чат отдаёт событием `askAgain` с id ответа, обрыв распознаёт и вопрос отправляет приложение.

Остальные типы рисует отрисовщик приложения: `provideRtAiChatBlock('chart', MyChartBlockComponent,
(block) => '…')` в провайдерах корня приложения, компонент получает блок во вход `block`. Все
отрисовщики регистрируются на одном уровне: регистрация в маршруте или компоненте скрыла бы корневые.
Блок без отрисовщика показан пунктирной заглушкой «The “chart” block is not supported» — пропуск
спрятал бы забытую регистрацию. Заглушкой показан и свой тип без нужных полей: `markdown` без
`text`, `notice` без известной `rt-message` severity.

Копирование ответа берёт текст `markdown` и `notice`, таблицу и карточки KPI — строками через
табуляцию. Блок из реестра идёт в копию, если у его отрисовщика есть третий аргумент — функция
текста; блок без неё в буфер не попадает. Секция идёт в копию заголовком и текстами своих блоков. Если текста у блоков нет совсем,
«Копировать» не рисуется, оценка остаётся.

Проверки `isMarkdownBlock` и `isNoticeBlock` экспортируются: `block.type === 'markdown'` тип не
сужает, потому что список типов открыт.

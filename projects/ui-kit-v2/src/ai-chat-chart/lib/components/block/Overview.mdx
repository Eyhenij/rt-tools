<Title>AiChatChart — `rt-ai-chat-chart`</Title>

Блок `chart` ответа ассистента. Модель рисует график вызовом инструмента, аргументы вызова — это
спецификация графика. Блок разбирает её из строки JSON или берёт готовый объект, проверяет,
переводит в данные `rt-chart` и рисует со строкой заголовка. Лежит в своём входе
`@rt-tools/ui-kit-v2/ai-chat-chart`: редактор не тянет d3, а график не тянет редактор.

```ts
// В корне приложения, рядом с прочими отрисовщиками блоков.
providers: [provideRtAiChatChart()];

// Блок ответа — аргументы вызова инструмента, пока они идут — с признаком ожидания.
{ type: 'chart', spec: '{"kind":"line","title":"Выручка","series":[…]}', pending: true }
```

Схему спецификации для модели вход отдаёт значением `RT_AI_CHAT_CHART_SCHEMA` (JSON Schema
2020-12), проверку — функцией `rtAiChatChartCheck`.

## Когда применять

- Ответ ассистента, где модель вызвала инструмент построения графика.

## Когда не применять

- **График на экране приложения, не в ответе ассистента** — [`rt-chart`](./?path=/docs/molecules-data-chart-overview--docs)
  прямо, данными кита.
- **Точные значения в колонках** — [`rt-table`](./?path=/docs/organisms-table-table-overview--docs).

## Оси

| ось    | значения                                                                                                  |
| ------ | --------------------------------------------------------------------------------------------------------- |
| вид    | `line`, `bar`, `grouped_bar`, `stacked_bar`, `pie`, `histogram`, `heatmap`, `scatter`, `treemap`, `sunburst` |
| формат | `number`, `percent`, `currency`                                                                           |
| ширина | вся ширина ленты: узкий экран, панель ассистента, широкий экран                                           |

Виды стоят в истории **Kinds**, ширины — в **Widths**. Формат подписывает значения на оси, в
подсказке, в круге, тепловой карте и дереве; в кадре он виден по образцам: `grouped_bar` в
рублях, `pie` и `scatter` в долях.

## Края

| край                               | что происходит                                                       |
| ---------------------------------- | -------------------------------------------------------------------- |
| аргументы ещё идут                 | заглушка `aiChartPending` в размер поля, что бы ни лежало в строке   |
| строка не разбирается, схема нарушена | плашка `aiChartInvalid` на месте графика, соседние блоки на месте |
| ни одной точки, круг или дерево из нулей | пустое состояние `rt-chart` под заголовком, без кнопок          |
| нет заголовка и подзаголовка       | в строке только две кнопки у правого края                            |
| длинный заголовок                  | обрезается многоточием, целиком — в подсказке                        |
| много категорий                    | подписи оси идут через одну или реже, не налезая друг на друга       |
| график ещё не нарисован            | «Скачать PNG» выключена                                              |

## Состояния

Наведение, фокус и нажатие кнопок строки заголовка — состояния `rt-icon-button`, показаны в его
истории **States**. Подсказка графика — состояние `rt-chart`. Окно на весь экран открывает история
**FullScreen**.

| состояние  | чем задаётся                        | что видно                                    |
| ---------- | ----------------------------------- | -------------------------------------------- |
| ожидание   | `pending: true`                     | заглушка «Drawing the chart…»                |
| нарисован  | годная спецификация                 | заголовок, подзаголовок, имена осей, график  |
| негодный   | строка не разбирается или не годна  | плашка «The chart could not be drawn»        |
| пусто      | нет значений                        | пустое состояние графика, кнопок нет         |
| весь экран | «Open full screen»                  | диалог кита с графиком и «Download PNG»      |
| тёмная     | признак темы на узле или выше       | палитра тёмной темы                          |

## Доступность

- Доступное имя графика — заголовок спецификации, без заголовка — подпись кита `aiChartLabel`.
- Обе кнопки строки заголовка названы подписями кита и несут подсказку.
- «Close» и Escape закрывают окно на весь экран, фокус возвращается на «Open full screen».
- Текст ответа при копировании несёт график строками: заголовок, подзаголовок и точки рядов.

## Оформление

Цвета рядов — те же восемь свойств `--rt-color-chart-series-1…8`, что у `rt-chart`. Заглушка
ожидания берёт фон `--rt-color-bg-surface-subtle` и скругление `--rt-ai-chat-chart-placeholder-radius`.
Высота строк подписей — по метрикам шрифта, как в макете. Светлая и тёмная темы — история
**Themes**, наборы оформления — **Presets**.

## Рядом

- [`rt-chart`](./?path=/docs/molecules-data-chart-overview--docs) — график, который блок рисует.
- [`rt-ai-chat`](./?path=/docs/organisms-chat-aichat-overview--docs) — беседа, в ленте которой стоит блок.
